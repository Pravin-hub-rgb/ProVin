## RAG â€” jab model sirf apni yaad se nahi, balki sahi page se likhe

Socho ek exam â€” sirf 80% syllabus aata hai, 20% sirf classroom notes mein. Jo student sirf apni notebook yaad karega â€” uska "extra" answer galat ho jayega (hallucinate). RAG wala: examiner usse pehle kehte hain â€*chehra khol ke woh extra page dikhaoâ€, phir likhoâ€. Matlab: **tum LLM ko document ka sahi hissa (context) dedo, phir LLM uss context se hi jawab banaye** â€” bina model ko retrain/fine-tune kiye.

## The 5-step pipeline â€” ek nazar

1. **Load** â€ documents (PDF/TXT/site) lao â†’ *3.2*
2. **Chunk** â€ bade doc ko chhote pieces mein tod â†’ *3.2*
3. **Embed** â€ har chunk â†’ 384-number vector â†’ *3.3*
4. **Store** â€ vectors â†’ FAISS vector DB â†’ *3.4*
5. **Retrieve + Generate** â€ sawaal se top chunks nikal, LLM ko context+sawaal bhej â†’ *3.5*

## Code: skeleton â€” har step ek function

```python
# rag_overview.py â€” RAG ka minimum skeleton (har line samjho)
# Setup: pip install langchain-community langchain-huggingface faiss-cpu
# rag_example.txt banao â€ andar daalo:
#   "Student discount 10th standard ko 50% off milta hai."

from langchain_community.document_loaders import TextLoader          # (1) loader
from langchain.text_splitter import RecursiveCharacterTextSplitter  # (2) chunker
from langchain_huggingface import HuggingFaceEmbeddings             # (3) embed
from langchain_community.vectorstores import FAISS                  # (4) vector DB

def load_documents(path):                                  # step-1
    return TextLoader(path).load()

def split_chunks(docs, size=1000, overlap=200):            # step-2
    sp = RecursiveCharacterTextSplitter(chunk_size=size, chunk_overlap=overlap)
    return sp.split_documents(docs)

def make_embeddings():                                     # step-3
    return HuggingFaceEmbeddings(model_name="BAAI/bge-small-en-v1.5")

def build_vector_store(chunks, emb):                       # step-4
    return FAISS.from_documents(chunks, emb)

def retrieve(db, question, k=3):                           # step-5
    ret = db.as_retriever(search_kwargs={"k": k})
    return ret.get_relevant_documents(question)

docs   = load_documents("rag_example.txt")   # 1. load
chunks = split_chunks(docs)                  # 2. chunk
emb    = make_embeddings()                   # 3. embed model
db     = build_vector_store(chunks, emb)     # 4. store
hits   = retrieve(db, "Student discount kya hai?")
print("Retrieved", len(hits), "chunks")
```

Line-by-line: `TextLoader(path).load()` â€ text file â†’ `Document` list (har ek `page_content` + `metadata`). `RecursiveCharacterTextSplitter` â€ 1000 chars/chunk, last 200 chars agla chunk mein repeat. `HuggingFaceEmbeddings("bge-small-en-v1.5")` â€ local 384-dim model (free, ~84MB). `FAISS.from_documents` â€ vectors + similarity index (first run 10-20s lagta hai). `as_retriever(k=3)` â€ top-3 chunks dega. `get_relevant_documents(q)` â€ q ko bhi embed karo, FAISS se nearest-3 lao.

## Nutshell

RAG = document ka sahi hissa lo, phir likhao â€” bina retrain kiye. 5 steps: load â†’ chunk â†’ embed â†’ store â†’ retrieve + generate.

## Common Mistakes
- ❌ Prompt mein *â€use docs se answer karoâ€* likhne se model apni yaad se likhta â†’ fix: hard `Answer using ONLY this context`
- ❌ Poora doc ek chunk mein â†’ context overflow + dilated retrieval â†’ fix: chunk_size 500-1000
- ❌ Embedding dim mismatch (384 vs 768) â†’ FAISS crash â†’ fix: index + query dono same model se

## What It Is NOT
- ⚠️ Fine-tuning nahi â€’ model kabhi update nahi hota, bas uss context ko prompt mein daal kar dete hain
- ⚠️ Hallucination-proof nahi â€’ agar chunk bhi galat ho, LLM phir bhi galat bana sakta â€’ garbage in, garbage out
- ⚠️ â€Docs jod do, answer milleâ€ nahi â€’ chunks ache hon chahiye â€’ 3.2/3.4 pe dhyan do
