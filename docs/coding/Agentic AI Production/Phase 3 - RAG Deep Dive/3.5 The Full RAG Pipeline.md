# 3.5 The Full RAG Pipeline

3.4 til chunk â† embed â† store â† retrieve poora hogaya. Ab last â€ sabse exciting step: **generate** â€– LLM ko retrieved chunks + sawaal milta hai, â€ ek natural-language jawab banata hai. Ye hi poori RAG pipeline hai â€ data side + LLM side ek saath.

## Full pipeline â€– 6 boxes, ek arrow

```
[Documents] â†’ [Chunk] â†’ [Embed] â†’ [Vector Store] â†’ [Retrieve top-k] â†’ [LLM generate]
    3.1      3.2/3.4   3.3        3.4          3.4              THIS FILE
```

Generate sirf LLM karega â€– lekin LLM sirf tabhi sahi jawab dega jab uske paas **seedha context mile, bina hallucination ke.** Isliye hard zaroori â€ prompt: *"Answer using ONLY this context."*

## LLM â€ ChatGroq + llama-3.3-70b-versatile

3.1-3.4 tak sirf embeddings the (bge, local, free). Ab generation ke liye ek chat LLM chahiye â€– user spec: **ChatGroq** + `llama-3.3-70b-versatile` (Groq free tier), key `GROQ_API_KEY` env se.

## Code: end-to-end RAG

```python
# 3.5_full_rag.py â€– ek saath poora pipeline
import os
from dotenv import load_dotenv
load_dotenv()                                  # (1) .env se GROQ_API_KEY

from langchain_community.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_groq import ChatGroq
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

# (2) data side â€ load â† chunk â† embed â† store â† retrieve
docs   = TextLoader("rag_example.txt").load()
chunks = RecursiveCharacterTextSplitter(500, 50).split_documents(docs)
emb    = HuggingFaceEmbeddings(model_name="BAAI/bge-small-en-v1.5")
db     = FAISS.from_documents(chunks, emb)
retriever = db.as_retriever(search_kwargs={"k": 3})

# (3) generation side â€ LLM + "ONLY context" prompt
llm    = ChatGroq(model="llama-3.3-70b-versatile", temperature=0.3)
prompt = ChatPromptTemplate.from_template(
    "Answer using ONLY this context:\n{context}\n\nQuestion: {question}")

# (4) Document list â†Œ string joiner
def fmt_docs(d): return "\n\n".join(x.page_content for x in d)

# (5) LCEL chain â€ context(retriever|fmt) + question(passthrough) â† prompt â† llm â† text
chain = {"context": retriever | fmt_docs,
         "question": RunnablePassthrough()} | prompt | llm | StrOutputParser()

# (6) run
print(chain.invoke("Student discount kya hai?"))
```

Line-by-line: (1) `load_dotenv()` â€ `.env` se `GROQ_API_KEY` â€ kabhi code mein hardcode mat karo. (2) data side â€ 3.1-3.4 wala pipeline; `as_retriever(k=3)` top-3. (3) `ChatGroq(model="llama-3.3-70b-versaâ€¦", temperature=0.3)` â€ generation; temp kam â€ deterministic. â€"ONLY this contextâ€" â€ anti-hallucination instruction. (4) `fmt_docs` â€ Document list â† ek string â€ LLM string pasand karta â€. (5) LCEL dict: `context`=`retriever|fmt_docs` (2 runnables chain), `question`=`RunnablePassthrough()` â€ user input seedha â€; phir `|prompt|llm|StrOutputParser()`. (6) `chain.invoke(q)` â€â† retrieverâ† chunksâ promptâ llmâ final text.

## Nutshell

Full RAG = load â† chunk â† embed â† store â† retrieve(top-k) â† LLM; hard â€œONLY contextâ€ prompt hallucinations kam karta.

## Common Mistakes
- ❌ â€˜use this contextâ€™ likhne se bhool gae â†â LLM apni yaad se likhega â† fix: hard `Answer using ONLY this context`
- ❌ k bahut bada (10) â†â LLM ko bahut context â€ overflow â† fix: k=2-3
- ❌ temperature 0.7 â†â random answer â† fix: 0.1-0.3 (fact Q&A mein)

## What It Is NOT
- Ï € Magic â€“ agar doc galat ho â€ LLM galat dogma â€ RAG uss galatko amplify karega
- Ï € Vector DB ka alternative â€“ poora pipeline chalne ke liye embedâ†storeâ†retrieve chahiye
- Ï € Static â€“ retrieval query hi badal do (rewrite), toh answer improve hoti hai (3.6/3.7)
