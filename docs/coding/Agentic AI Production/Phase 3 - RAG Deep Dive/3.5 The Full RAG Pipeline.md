# 3.5 The Full RAG Pipeline

3.4 tak chunk → embed → store → retrieve poora ho gaya. Ab last — sabse exciting step: **generate** — LLM ko retrieved chunks + sawaal milta hai, aur ek natural-language jawab banata hai. Ye hi poori RAG pipeline hai — data side + LLM side ek saath.

## Full pipeline — 6 boxes, ek arrow

```
[Documents] → [Chunk] → [Embed] → [Vector Store] → [Retrieve top-k] → [LLM generate]
    3.1      3.2/3.4   3.3        3.4          3.4              THIS FILE
```

Generate sirf LLM karega — lekin LLM sirf tabhi sahi jawab dega jab uske paas **seedha context mile, bina hallucination ke.** Isliye hard zaroori — prompt: *"Answer using ONLY this context."*

## LLM — ChatGroq + llama-3.3-70b-versatile

3.1-3.4 tak sirf embeddings the (bge, local, free). Ab generation ke liye ek chat LLM chahiye — user spec: **ChatGroq** + `llama-3.3-70b-versatile` (Groq free tier), key `GROQ_API_KEY` env se.

## Code: end-to-end RAG

```python
# 3.5_full_rag.py — ek saath poora pipeline
import os
from dotenv import load_dotenv
load_dotenv()                                  # (1) .env se GROQ_API_KEY

from langchain_community.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_groq import ChatGroq
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

# (2) data side — load → chunk → embed → store → retrieve
docs   = TextLoader("rag_example.txt").load()
chunks = RecursiveCharacterTextSplitter(500, 50).split_documents(docs)
emb    = HuggingFaceEmbeddings(model_name="BAAI/bge-small-en-v1.5")
db     = FAISS.from_documents(chunks, emb)
retriever = db.as_retriever(search_kwargs={"k": 3})

# (3) generation side — LLM + "ONLY context" prompt
llm    = ChatGroq(model="llama-3.3-70b-versatile", temperature=0.3)
prompt = ChatPromptTemplate.from_template(
    "Answer using ONLY this context:\n{context}\n\nQuestion: {question}")

# (4) Document list → string joiner
def fmt_docs(d): return "\n\n".join(x.page_content for x in d)

# (5) LCEL chain — context(retriever|fmt) + question(passthrough) → prompt → llm → text
chain = {"context": retriever | fmt_docs,
         "question": RunnablePassthrough()} | prompt | llm | StrOutputParser()

# (6) run
print(chain.invoke("Student discount kya hai?"))
```

Line-by-line: (1) `load_dotenv()` — `.env` se `GROQ_API_KEY` — kabhi code mein hardcode mat karo. (2) data side — 3.1-3.4 wala pipeline; `as_retriever(k=3)` top-3. (3) `ChatGroq(model="llama-3.3-70b-versatile", temperature=0.3)` — generation; temp kam — deterministic. "ONLY this context" — anti-hallucination instruction. (4) `fmt_docs` — Document list → ek string — LLM string pasand karta. (5) LCEL dict: `context`=`retriever|fmt_docs` (2 runnables chain), `question`=`RunnablePassthrough()` — user input seedha; phir `|prompt|llm|StrOutputParser()`. (6) `chain.invoke(q)` — retriever → chunks → prompt → llm → final text.

## Wrong vs Right — kyun RAG kaam karta hai

- **Bina RAG (sirf prompt):** LLM "shayad 10th grade students bhi kisi offer pe mil sakte hain?" — guessed — could be wrong.
- **RAG:** "Student discount 10th standard ko 50% off milta hai (source: rag_example.txt)" — doc se quote — verifiable.

**Troubleshooting:**
- `401 Unauthorized` → `GROQ_API_KEY` set nahi → export karo ya `.env` mein daalo
- model name `not found` → try `llama-3-70b-8192`
- answer still hallucinating → temperature=0.1, prompt "ONLY" aur strong karo
- retriever empty → chunks=0 — chunk_size 500 se kam — file load check karo

## Nutshell

Full RAG = load → chunk → embed → store → retrieve(top-k) → LLM; hard "ONLY context" prompt hallucinations kam karta.

## Common Mistakes
- ❌ 'use this context' likhne se bhool gaye → LLM apni yaad se likhega → fix: hard `Answer using ONLY this context`
- ❌ k bahut bada (10) → LLM ko bahut context — overflow → fix: k=2-3
- ❌ temperature 0.7 → random answer → fix: 0.1-0.3 (fact Q&A mein)

## What It Is NOT
- ⚠️ Magic — agar doc galat ho — LLM galat dogma — RAG uss galat ko amplify karega
- ⚠️ Vector DB ka alternative — poora pipeline chalne ke liye embed→store→retrieve chahiye
- ⚠️ Static — retrieval query hi badal do (rewrite), toh answer improve hoti hai (3.6/3.7)
