# 3.7 Agentic RAG

3.6 mein humne dekha â€ ek `RAG` class jo ek beparaah query lega, ekhi baar search karega (k=3), LLM ko context do, answer dega. Par real mein agent ek baar search se kaf nahi samajhta â€ kabhi dobara search karta hai, query reword karke phir try karta, kabhi decide karta hai ki kafi hai. **Simple RAG = ek fixed search. Agentic RAG = LLM khud decide karta hai ki kitni baar, kya search kare, kab takhein.**

## Simple RAG ka limit

Simple pipeline (3.5) ekhi baar `retriever.get_relevant_documents(q)` call karega â€ fir LLM generate. Agar pehla chunk galat lage â€ LLM uss galat context par chhula fuk jayega. Agent kehenge: *"kya mujhe aur dhoondhna chahiye?"* â€ phir dubara search karenge â€ query change karke phir se â€ tab tak sahih nahi milta.

## Agentic RAG = agent loop + retrieval tool

Bridge (Phase 2, 2.3): ReAct agent â€"**soch â† action â† observe â† soch..."**. Waisehi agent â€â€“ uske "action" ki jagah sirf retrieval nahi, ek ya do retrieval tools honge â€â€ LLM decide karega ki kaunse call karein, kitni baar, kab takhein. Structure doc: *"Agentic RAG = the LLM decides how to search (rewrite the query, search multiple times, decide when it has enough)."*

## Code: retrieval ek TOOL â€â†â agent

```python
# 3.7_agentic_rag.py â€– LangChain ReAct agent + retrieval tool
import os
from dotenv import load_dotenv; load_dotenv()
from langchain_community.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_groq import ChatGroq
from langchain_core.tools import tool
from langchain.agents import create_react_agent, AgentExecutor
from langchain_core.prompts import ChatPromptTemplate

# (1) data side â€ same as 3.5
docs   = TextLoader("rag_example.txt").load()
chunks = RecursiveCharacterTextSplitter(500, 50).split_documents(docs)
emb    = HuggingFaceEmbeddings(model_name="BAAI/bge-small-en-v1.5")
db     = FAISS.from_documents(chunks, emb)

# (2) retrieval ek TOOL â€– LLM ise call karega jab dhoondhna ho
@tool
def search(query: str) -> str:
    """Search company documents for discounts/policies."""
    docs = db.as_retriever(search_kwargs={"k": 3}).get_relevant_documents(query)
    return "\n\n".join(d.page_content for d in docs)

# (3) LLM â€ ChatGroq + llama-3.3-70b-versa
llm = ChatGroq(model="llama-3.3-70b-versatile", temperature=0.3)

# (4) ReAct prompt â€ tool call ke baad LLM phir sochne aayega
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful RAG agent. Use the search tool only when needed."),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}"),
])

# (5) agent + executor
agent = create_react_agent(llm, tools=[search], prompt=prompt)
ex    = AgentExecutor(agent=agent, tools=[search], verbose=True, max_iterations=3)

# (6) run â€– LLM khud decide karega kitni baar search kare
print(ex.invoke({"input": "College students ke liye discount kya milta?"})["output"])
```

Line-by-line: (1) data side â€ 3.5 waala, ab `db` ready. (2) `@tool` â€ `search` ko LangChain tool banata â€ docstring â€ LLM ko bataati â€ kabhi call kare; `get_relevant_documents` â€ chunks â† string. (3) `ChatGroq(..., temperature=0.3)` â€ generation LLM. (4) ReAct prompt â€ system role + user input + `agent_scratchpad` placeholder â€ agent ke thought-trace yehin aayega. (5) `create_react_agent` â€ agent banata; `AgentExecutor` run karta â€ `verbose=True` tool calls dikhata â€ `max_iterations=3` anti-loop. (6) `ex.invoke({"input": q})` â€ LLM pehle sochta â€ (maybe tool call) â€ result dekhta â€ fir generate karta â€â€“ **yehi agentic behavior: LLM ne khud decide kiya ki search zaroori tha.**
