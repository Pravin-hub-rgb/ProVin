# 1.2 Your First LangChain Call

**LLM** (large language model) — ChatGPT ke peeche ka dimaag. Woh cheez jo tumhare words padhti hai aur reply likhti hai. Code se usse baat karne ke liye tum ek message internet ke through bhejte ho, woh reply bhejta hai. LangChain mein ye baat ek **model object** ke through hoti hai — ek Python object jo AI model ko represent karta hai aur usse call karna jaanta hai.

## First, You Need an API Key (a Free One!)

Code se pehle ek cheez chahiye: **API key**. Isse aise socho — ek key card jo prove karta hai ki tumhe model use karne ki permission hai, aur provider tumse har request ka hisaab karta hai.

Ab ek good news — tum is course ko ek actual model se **bilkul free** practice kar sakte ho. Hum **Groq** use karenge — ek service jo free tier deti hai (bahut fast, open models). OpenAI jaisi paid service abhi chahiye nahi.

**Free Groq key kaise mile:**
1. `console.groq.com` pe jao, free account banao (Google se sign in bhi chalega).
2. "API Keys" section mein ek nayi key banao — `gsk_` se shuru hoti hai.
3. Wo key copy karo, abhi ke liye apne paas rakho.

(OpenAI ya Google ka model bhi chala sakte ho — pattern bilkul same. Par free practice ke liye Groq perfect hai.)

### Store the Key Safely in a `.env` File

API key ko kabhi **seedha code mein mat likhna.** Agar code share kiya (jaise GitHub pe), toh key bhi share ho gayi. Iske bajaye, key ko ek special file `.env` mein rakho — jo secrets rakhti hai — aur wahan se load karo.

Project folder mein ek `.env` file banao:

```
GROQ_API_KEY=gsk_your-free-key-here
```

Aur `.env` ko `.gitignore` file mein add karo (wo list jisse Git ignore karta hai), taaki kabhi upload na ho. Key tumhare computer pe private, safe rehti hai.

### The Full Program

Yeh sabse chhota complete LangChain program hai jo ek model ko call karta hai. Pehle padho, phir har line todte hain, kyunki "dost ne samjhaya" style mein code jaldi nahi bhulte:

```python
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model

load_dotenv()

model = init_chat_model("llama-3.3-70b-versatile")

response = model.invoke("What is the capital of France?")
print(response.content)
```

Ab recipe ki tarah har line samjhte hain:

1. `from dotenv import load_dotenv` — ek helper laata hai jo `.env` file ko padh sakta hai. "dotenv" ek package hai jo tumhari secret keys ko program mein load karta hai.
2. `from langchain.chat_models import init_chat_model` — `init_chat_model`, woh handy LangChain function import karta hai jo model set up karta hai. "init" = "initialize" = kuch taiyaar karna.
3. `load_dotenv()` — ye line actually tumhari `.env` file padhti hai aur `GROQ_API_KEY` ko program mein available banati hai. Khali parentheses `()` isliye — isko koi extra info nahi chahiye.
4. `model = init_chat_model("llama-3.3-70b-versatile")` — ek model object banata hai aur `model` naam ke variable mein rakhta hai. Bata rahe ho *kaunsa* model use karna hai naam se. "llama-3.3-70b-versatile" Groq ka free, open model hai. LangChain isko dekhke samajhta hai ki Groq se call karna hai (kyunki humne `langchain-groq` 1.1 mein install kiya tha).
5. `response = model.invoke("What is the capital of France?")` — star of the show. `invoke` matlab "call karo." Model ko question bhej rahe ho. Model ka pura jawab `response` variable mein store hota hai.
6. `print(response.content)` — jawab screen pe print karta hai. `response` ek object hai jiske parts hain; `.content` wo text part hai — asli written jawab.

Chalao:

```powershell
python main.py
```

Tumhe `Paris` (ya pura sentence) print hote dikhna chahiye. Congratulations — Python se tumhari pehli AI call hai.

## Two Ways to Create a Model

Code chala ke jawab to mil gaya. Par model object banane ka ek aur, equally important tareeka hai — isse tab use karte ho jab tumhe kisi specific provider (jaise OpenAI) ke settings pe zyada control chahiye. Humaara Groq wala shortcut modern tareeka hai; direct class purana, explicit tareeka. Dono real code mein dikhte hain, isliye dono dekh lete hain.

### Way 1 — The Shortcut: `init_chat_model`

Jo humne abhi use kiya. Tum bas **model name string** dete ho aur LangChain khud provider ko name se samajh leta hai, sahi class load karta hai, aur ready model object de deta hai. Ek line, zero fuss. Yeh hai setup ka "Go" — sniff karke bata dega kya chahiye.

### Way 2 — The Direct Class: `ChatOpenAI(...)`

Har provider ki apni class hoti hai. OpenAI ki `ChatOpenAI` hai. Joh shortcut khud provider guessed karta hai (jaise Groq wala), is direct class mein tum khud decide karte ho ki kaunsa provider — isliye iska naam. Yeh example OpenAI ke liye hai; agar tum OpenAI ki key use karte ho toh:

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()

model = ChatOpenAI(model="gpt-4o-mini")

response = model.invoke("What is the capital of France?")
print(response.content)
```

Line by line:

1. `from dotenv import load_dotenv` — pehle jaisa, key load karne ke liye.
2. `from langchain_openai import ChatOpenAI` — OpenAI-specific class import karta hai. Package naam `langchain_openai` batata hai ki yeh OpenAI ke liye ek alag helper library se aaya.
3. `load_dotenv()` — key load karta hai.
4. `model = ChatOpenAI(model="gpt-4o-mini")` — model banata hai. Isme model name ek clear label ke saath: `model="gpt-4o-mini"`. Class ko pehle se pata hai ke wo "OpenAI" hai, toh tum sirf specific model ka naam dete ho.
5. `response = model.invoke("What is the capital of France?")` — message bhejta hai, jawab store karta hai.
6. `print(response.content)` — text jawab print karta hai.

Dono apne ko same `model` object dete hain jise `invoke` kar sakte ho. `init_model` provider switch karne mein tez hai (Google, OpenAI, whatever) kyunki bas name string badalni padti hai. `ChatOpenAI` explicit hai jab tum OpenAI-specific options set karna chahte ho. Jo clear lage usse shuru karo.

## Raw Response vs Just the Text

`response` koi plain string nahi — yeh ek neat object hai jise **AIMessage** kehte hain, jo jawab + kuch metadata (call ke baare mein extra info) rakhta hai.

* `response.content` — sirf text jawab. Jo tumhe usually chahiye.
* `response.metadata` — extras ka dictionary: token usage, model name, time, waghera. Jaise coffee ke saath aane wali receipt — coffee khud `.content` hai; printed details `.metadata`.

Khel ke dekho:

```python
print(response)                # pura AIMessage object
print(response.content)        # sirf written jawab
print(response.metadata)       # "receipt" — tokens, model, timing
```

Real app mein tum almost hamesha `.content` padhte ho user ko dikhane ke liye, par kabhi kabhi `.metadata` bhi — cost ya usage track karne ke liye. Same call, do lens.

## What It Is NOT

⚠️ **Ye pehli call koi conversation nahi hai.** Model ne is request se pehle ya baad kuch yaad nahi rakha — har `invoke` ek fresh, bhoolne wala moment hai, jaise abhi abhi mile kisi stranger se. Isko **stateless** kehte hain, aur LLMs ke liye default yehi hai. Use baad mein yaad dilaana ek pura topic hai (isko memory kehte hain).

⚠️ **Ye web page nahi hai.** Browser mein kuch render nahi hua — yeh pure Python hai jo internet ke through server se baat karke string print karta hai. Yeh wo foundation hai jispe har AI app banta hai.
