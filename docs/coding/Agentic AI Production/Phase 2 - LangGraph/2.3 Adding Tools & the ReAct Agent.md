# 2.3 Adding Tools & the ReAct Agent

2.2 mein jo chatbot bangaya — woh bas soch-puchh ke beech baat cheet karta tha. Ek real agent itna kam nahi karta. Kabhi koi sawaal poocha jaye toh uska jawab sirf "soch kar" nahin, balki **kaam karke** (tool use) dena padta hai — jaise date poochhiye ya calculation maange.

LangGraph iske liye ek inbuilt shortcut de rakha hai: **`create_react_agent()`**. Yeh koī ek ready-made agent deta hai jo sochta hai (think) → kaam karta hua (act = tool call) → phir se sochhta hai — jabtak kaam poora na ho jaye.

## ReAct loop = think → act → observe → think → ...

Agent sochte hain: "User ne date poocha. Main ek tool call karu." Tool chale, result milta hai. Phir vahin sochna: "Result mil gaya. Ab jawab de do." Ye loop `create_react_agent` apne app run karta hai.

## Tool banao — @tool se

```python
from langchain_core.tools import tool
from datetime import date

@tool
def get_current_date(dummy: str = "") -> str:
    """Aaj ki date return karta hai."""
    return str(date.today())
```

`@tool` decorator uss Python function ko ek aise tool mein badalta hai jisko model dekh saka — docstring jo description hoti hai, return jo tool-result hota hai.

## Agent banayen

```python
from langchain_groq import ChatGroq
from langchain_core.messages import HumanMessage
from langgraph.prebuilt import create_react_agent

llm = ChatGroq(model_name="llama-3.3-70b-versatile")

# ek tool wala agent
agent = create_react_agent(llm, [get_current_date])

# run — agent ko dekho: sochta hai, tool call karta, result dekh ke jawab deta
user_query = "Aaj ki date kya hai?"
result = agent.invoke({"messages": [HumanMessage(content=user_query)]})
print(result["messages"][-1].content)
```

1. `create_react_agent(llm, [get_current_date])` — model + tool list se ek agent graph banata hai. Andar automatically ek **tool node** hota hai jo jab model usk tool call kare to use chalata hai.
2. `agent.invoke(...)` — poora agent loop chalta hai: model sochta → tool call → tool-result → model jawab deta. Sab ek hi invoke mein.
3. result["messages"][-1] — agent ke aakhiri reply (tool result tak saare messages ek saath state mein hote hain).

## Agent loop ke andar kya hota hai (step by step)

- Step 1: State = `[HumanMessage("Aaj ki date kya hai?")]`. Model soch raha: "Mujhe date chahiye." → tool call karta `get_current_date`.
- Step 2: LangGraph us tool call ko pick karta, function chala karta, `ToolMessage` as result add karta state mein.
- Step 3: Model phir se dekhta — ab usse pata hai ki date `2025-...` hai → seedhi `AIMessage` jawab deta.
- Loop tab tak chalta hai jabtak "stop" na aaye.

## What It Is NOT

⚠️ **Agent ek LLM call nahi.** Agent ek **loop** hai — repeatedly sochti-re, act-karti-re. Isliye ek baar ka model hi nahi, ek state machine jo tak poora natak naa ho.

⚠️ **Tool ek jad-free function call nahi.** Tool model ke paas ek "schema" hota hai (koi input, description, name). Model uska faisla karta hai, LangGraph uska execution handle karta hai — isliye galat input na de.

⚠️ **create_react_agent koi "smart" nahi.** Yeh ek preset graph structure hai. Custom behavior (custom stop conditions, custom routing) ke liye tumhe 2.1 ke `StateGraph` se khud graph banana pad sakta hai.

## In Your Own Words

<details>
<summary>1. ReAct mein think/act/observe ek doosre pe kaisse chal-ta hai?</summary>

**Jawab:** Model sochta hai (think), phir ek tool call karta (act), us tool ka result milta hai (observe), phir model phir se sochta. Ye loop tab tak chalta hai jabtak final text answer naa mile.

</details>

<details>
<summary>2. @tool decorator kyun use karte hain?</summary>

**Jawab:** @tool function ko ek aise object mein badalta jise model "tool" samajhe — uska name, description (docstring se), input schema automatically nikalta hai. Baghair iske model nahi pata chalta ki ye function ek tool hai.

</details>

<details>
<summary>3. create_react_agent vs khud graph banana — kab konsa?</summary>

**Jawab:** Jab bas standard "think→act→observe" chahiye toh create_react_agent samaajh le. Jab tumhe koi custom flow chahiye (condition, parallel, multi-agent handoff) tabs khud StateGraph banana padega.

</details>
