# 2.5 Human-in-the-Loop

2.4 ka agent ab yaad rakhta bhi tha, lekin ek baat bhi nahi maan sakta — bilkul seedha badhta hai. Kahan pata agent galati action lele. Production agents se better hote hain jab **ek insaan intervene kare** — jaise ek intern jo boss se approval leke kaam karta hai.

LangGraph `interrupt()` ke zamee — jisse graph ek jagah ruk sakta hai, insaan feedback de, phir waise hi resume karsake.

## Analogy — intern + boss

Socho ek intern (agent) jo kehta hai: "Boss, maine yeh tool call maara hai, please approve karo." Boss (human) "Haan" ya "Nahi" bole. Agar "Haan" → intern aage badhega. Agar "Nahi" → cancel. Graph ka `interrupt()` bilkul yehi "intern ko ruku" ka kaam karta hai.

## Code — pause at a critical action, resume with approval

```python
from langchain_groq import ChatGroq
from langchain_core.messages import HumanMessage, SystemMessage, AIMessage
from langgraph.graph import StateGraph, START, END, MessagesState
from langgraph.types import interrupt, Command

llm = ChatGroq(model_name="llama-3.3-70b-versatile")

# Ek node jo pehle insaan se poochhe, phir aage badhe
def cautious_assistant(state: MessagesState):
    action = state["messages"][-1].content

    # 🔴 Graph yahan rukega — insaan ko feedback milega
    human_ok = interrupt(
        f"Agent ne kaha: {action!r}. Kya main isse approve karoonse? (yes/no)"
    )

    if human_ok and human_ok.strip().lower() == "yes":
        answer = llm.invoke([SystemMessage(content="Tum ek helpful dost ho."),
                             HumanMessage(content=action)])
        return {"messages": [AIMessage(content=answer.content)]}
    return {"messages": [AIMessage(content="Action user response cancel kar diya — approved nahi hua.")]}

graph = StateGraph(MessagesState)
graph.add_node("assistant", cautious_assistant)
graph.add_edge(START, "assistant")
graph.add_edge("assistant", END)
graph = graph.compile()

# 1st invoke — graph interrupt pe ruk jaayega
result = graph.invoke({"messages": [HumanMessage(content="Send email to CEO")]} )
print("__interrupt__" in result)   # True — matlab graph paused

# 2nd invoke — human feedback do (resume):
result2 = graph.invoke(Command(resume="yes"))
print(result2["messages"][-1].content)
```

Kaise chalta hai:

1. `interrupt("...?")` — graph turant **ruk sakta** (pause). Uska return value insaan ke response se hota hai.
2. Jab `interrupt()` chalega toh `result` mein `__interrupt__` key aayegi — matlab "main paused hoon, aap bolo kya karein".
3. `graph.invoke(Command(resume="yes"))` — bilkul seedhi tarah "aage badho" ke signal. `resume` value hi wo hoti hai jo `interrupt()` ne return kiya — yani `human_ok`.

> Note: isi tarah aap approval UI, Slack message, ya koi bhi tool ke zamie aap insaan se pooch sakte hain. Real production mein aksar ek dashboard button hota hai jo `resume` bhejta hai.

## Use case

Jab bhi agent eek **high-impact action** (payment, email to CEO, account delete) le raha ho — pehle insaan ke haath se approval nikal lo. Risk ko control me rakho.

## What It Is NOT

⚠️ **interrupt() ek exception/halt nahi.** Graph "band" nahi hota — bas **paused**. Resume hone ka intezaar raha. Ek crash nahi, ek intentional stop.

⚠️ **Human feedback sirf resume string tak mein hi sakta.** Agar tumhe structured object chahiye (JSON) toh usse bhi `resume` mein daal sakte — `Command(resume={"approved": True, "notes": "OK"})`.

⚠️ **Har node pe lagana bekar.** Intervene tabhi karo jab zaroorat ho — overuse se agent bahut der ruk karega. Critical actions ke liye hi istemaal karo.

## In Your Own Words

<details>
<summary>1. interrupt() aur resume() dono ek hi baat ke hain?</summary>

**Jawab:** Nahi. `interrupt()` graph ko **pause** karta hai (ek jagah rukta hai). `Command(resume=...)` graph ko **aage badhata** hai. Pehla rokta hai, dusra chalu karta hai.

</details>

<details>
<summary>2. Agar aap 2nd invoke mein Command(resume="no") bhej doge toh kya hoga?</summary>

**Jawab:** `interrupt()` ne `"yes"` expect kiya tha — to `human_ok = "no"` hoga. code mein `if human_ok... == "yes"` fail hoga, toh else wali branch chalegi "cancelled" message dikhayegi. Matlab insaan ne "no" bhej diya, toh action cancel.

</details>

<details>
<summary>3. Production mein ye interrupt() kahan kaam aata hai?</summary>

**Jawab:** Jab agent risky kaam karta hai — jaise paisa bhejna, koi delete karna, koi email bhejna. Pehle ek UI button/door se human se approval nikal lo, phir `resume` bhej ke proceed karo.

</details>
