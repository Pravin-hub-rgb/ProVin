# 2.7 MCP from Scratch

2.6 mein agent sochta, tool call karta, jawab deta. Lekin wo sab tools kahaan se aate hain? Agar har baar aap manually ek tool banaye ya toh bahut mehnat hai. 

Isliye **MCP (Model Context Protocol)** hai — ek open standard (Anthropic ne banayi) jo tools ko ek *universal plug* banati hai. Agar koi bhi MCP server banaye, toh koi bhi compatible agent ussko use kar sakta hai — bila kisi custom integration.

## Recap — MCP = USB for AI tools

Introduction course 7.2 mein tumne seekha: MCP ek aisa hai jisme ek tool/function ek *standard tarah* expose karti hai, aur koi bhi agent usse "plug" kar ke use kar sakta hai. Jaise USB-C — ek hi slot, sabhi device lagte hain.

## Ek simple MCP server banayen

```python
# mcp_date_server.py
from mcp import App

app = App("date-tools")

@app.tool()
def current_date(dummy: str = "") -> str:
    """Aaj ki date provide karta hai."""
    from datetime import date
    return date.today().isoformat()

# Run:  mcp run mcp_date_server.py
```

1. `App("date-tools")` — ek MCP app/server banao ek naam se.
2. `@app.tool()` — decorator se ye function ek *tool* ban jata hai jisko koi agent dekh sakta hai.
3. `"""Aaj ki date provide karta hai."""` — docstring = tool ki description (agent isse sunega).
4. Return value ka type (`-> str`) hi tool ka output hota hai.
5. `mcp run mcp_date_server.py` se server chalta hai (stdio transport pe).

Install: `uv pip install mcp`.

## LangGraph agent ko isse connect karo

```python
from langchain_mcp import MultiServerMCPClient
from langgraph.prebuilt import create_react_agent
from langchain_groq import ChatGroq
from langchain_core.messages import HumanMessage
import asyncio

llm = ChatGroq(model_name="llama-3.3-70b-versatile")

async def main():
    # MCP server (hume apne date tool) se connect
    client = MultiServerMCPClient({
        "date-tools": {
            "command": "python",
            "args": ["mcp_date_server.py"],
            "transport": "stdio",
        }
    })
    tools = await client.get_tools()    # server se tools nikal lo

    agent = create_react_agent(llm, tools)
    result = await agent.ainvoke(
        {"messages": [HumanMessage(content="Aaj ki date kya hai?")]}
    )
    print(result["messages"][-1].content)

asyncio.run(main())
```

- `MultiServerMCPClient` ek MCP server ko langchain-usable tools mein badalta hai.
- `client.get_tools()` — server expose karti tool (yahan `current_date`) ek langchain `Tool` ke roop mein laati hai.
- `create_react_agent(llm, tools)` — ab agent is tool ka istemal kar sakta hai, bina aapne manually inject kiye.

## MCP ka asli fayda

- **Ek tool, sabhi agents.** Ek MCP server = GitHub, Slack, Notion, database, file-system — koi bhi compatible agent use kar sakta hai.
- **No vendor lock-in.** Custom code nahi likhna toh har framework ke liye alag. Ek server, sabko same rahega.
- **Security sandbox.** Server apni marzi se decide karta hai ki kaunse tool kiske liye accessible hain.

## What It Is NOT

⚠️ **MCP ek framework nahi.** Framework kuchh features de raha hota hai — MCP ek **protocol/transport standard** hai (jaise USB cable). Usse server/client banana framework-in-independent hota hai.

⚠️ **Har tool ek MCP server nahi hota.** Aap ek MCP server mein bahut tools rakh sakte hain (date + weather + calculator). Server = ek tool-collection.

⚠️ **MCP sirf LangGraph tak mein hi milti.** Koi bhi MCP-compatible agent (Claude Code, Cursor, etc.) use kar sakta hai — isliye ye standard aisa hi hoti hai.

## In Your Own Words

<details>
<summary>1. MCP aur ek langchain @tool function — dono mein kya fark?</summary>

**Jawab:** @tool ek function ko langchain tool mein badalta hai — sirf LangChain tak hi jata hai, ek process ke andar. MCP ek protocol hai — usse tools ek alag process/server pe expose hote hain, koi bhi MCP-client use kar sakta hai (multi-language, cross-framework).

</details>

<details>
<summary>2. MultiServerMCPClient.kyun "multi-server"?</summary>

**Jawab:** Aap ek client attach karsakte hain multiple MCP servers — ek GitHub ke liye, ek Notion ke liye, ek database ke liye. Client sabhi servers se tools nikalega ek saath.

</details>

<details>
<summary>3. mcp server ke transport kya hoti hai?</summary>

**Jawab:** Transport = server aur client ka connection mode. `stdio` = dono ek process ke andar/through stdin-stdout (simple, local). `sse` = HTTP via server-sent events (remote, jab server network par ho).

</details>
