# Doc 0.1 — How the Browser Renders HTML and CSS

## Cheat Sheet (Quick Recall)

- Browser parses HTML → DOM tree.
- Browser parses CSS → CSSOM tree.
- DOM + CSSOM → Render tree → Layout → Paint → Composite.
- JavaScript can block parsing (use `defer`/`async`).
- Understanding this helps debug layout and performance issues.

## Main Content

### THINK

HTML and CSS are written as text files. The browser reads them and turns them into pixels on screen. How? First HTML → DOM, CSS → CSSOM, then combine → render tree → layout → paint. Understanding this helps explain why certain CSS is slow or why JS blocks rendering.

### CONCEPT

**Step 1 — Parse HTML → DOM:**

The browser reads HTML top-to-bottom and builds the DOM (Document Object Model) tree. Each tag becomes a node.

```html
<body>
  <h1>Hello</h1>
  <p>World</p>
</body>
```

Becomes a tree: `body` → `h1`, `p`.

**Step 2 — Parse CSS → CSSOM:**

CSS is parsed into the CSSOM (CSS Object Model) — a tree of styles.

**Step 3 — Combine → Render Tree:**

DOM + CSSOM → Render Tree. Only visible elements (display:none excluded) are included.

**Step 4 — Layout:**

Calculate position and size of each element (box model).

**Step 5 — Paint:**

Fill in pixels (colors, text, images).

**Step 6 — Composite:**

Layers combined into the final screen.

**JavaScript interaction:**

- `<script>` without `defer`/`async` blocks HTML parsing.
- Use `defer` (run after parse) or `async` (run when ready) for non-blocking scripts.

```html
<script src="app.js" defer></script>
```

### CODE (gradual)

Stage 1 — Plain HTML (parsing):

```html
<!DOCTYPE html>
<html>
  <body>
    <h1>Hello</h1>
  </body>
</html>
```

Stage 2 — Add CSS (CSSOM):

```html
<style>
  h1 { color: blue; }
</style>
```

Stage 3 — Add deferred JS:

```html
<script src="app.js" defer></script>
```

## Common Mistakes

- Blocking scripts without `defer`/`async` → slow first paint.
- Not understanding that CSS is render-blocking.
- Inline styles causing reflows.

## Try It Yourself

1. Open Chrome DevTools → Performance → record page load.
2. Add `defer` to a script and compare.
3. Inspect the DOM tree in the Elements tab.

## Summary

- HTML → DOM, CSS → CSSOM.
- Combine → Render Tree → Layout → Paint → Composite.
- JS can block parsing; use `defer`/`async`.

## What It Is NOT

- ❌ The DOM is **not** the HTML source — it is the parsed tree.
- ❌ CSS is **not** non-blocking — it blocks rendering.
- ❌ `async` is **not** the same as `defer`.
