# Doc 0.3 — How to View, Inspect, and Debug

## Cheat Sheet (Quick Recall)

- Open HTML file in browser (double-click or `Live Server`).
- DevTools: Elements, Console, Network, Sources.
- Inspect element: right-click → Inspect.
- Edit CSS live in the Styles pane.
- Console shows JS errors; Network shows failed requests.

## Main Content

### THINK

HTML/CSS files are written, but how to view them and debug issues? The browser + DevTools are the tools. First open the file, then inspect elements, then edit CSS live, then console/network for errors.

### CONCEPT

**Viewing:**

- Double-click `index.html` → opens in default browser.
- Better: use VS Code "Live Server" extension → auto-refresh on save.

**DevTools (F12 / Ctrl+Shift+I):**

- **Elements:** view/edit HTML and CSS live.
- **Console:** JS errors, logs.
- **Network:** requests, failed loads.
- **Sources:** view files, set breakpoints.

**Inspect element:**

Right-click any element → "Inspect" → jumps to that node in Elements tab.

**Edit CSS live:**

In the Styles pane, toggle properties or add new ones — changes reflect instantly (not saved to file).

**Common debugging:**

- Element not styled? Check selector matches.
- Image not loading? Check Network tab for 404.
- CSS not applying? Check specificity/typos.

### CODE (gradual)

Stage 1 — Open file:

```bash
# Double-click index.html, or
# VS Code: right-click → Open with Live Server
```

Stage 2 — Inspect element:

Right-click heading → Inspect → see `<h1>` in Elements.

Stage 3 — Edit CSS live:

In Styles pane, change `color: red;` → heading turns red instantly.

Stage 4 — Check console/network:

Console for JS errors; Network for failed image/CSS loads.

## Common Mistakes

- Editing in DevTools and expecting it to save to file (it does not).
- Not checking the Network tab for 404s.
- Forgetting to save the file before refreshing.

## Try It Yourself

1. Install "Live Server" in VS Code and use it.
2. Inspect an element and edit its CSS live.
3. Find a 404 in the Network tab.

## Summary

- DevTools: Elements, Console, Network, Sources.
- Inspect + edit CSS live (not saved).
