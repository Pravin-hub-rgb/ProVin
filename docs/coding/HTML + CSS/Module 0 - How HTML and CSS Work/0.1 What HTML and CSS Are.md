# Doc 0.1 — What HTML and CSS Are

## Cheat Sheet (Quick Recall)

- HTML = HyperText Markup Language. Describes structure and meaning of content using tags like `<h1>`, `<p>`, `<a>`.
- CSS = Cascading Style Sheets. Describes look and layout - colors, fonts, spacing, where things sit.
- Markup is not layout. HTML labels content; CSS styles it.
- Cascading = priority rules that settle style conflicts. Details in the CSS module.
- JavaScript adds behavior - covered in a separate course. One paragraph mention only.

## Broader Goal

The goal of this doc is to make the roles of HTML and CSS crystal clear before writing any code. No tags, no file paths, no browser tools yet - just the concepts and how they connect. By the end you should be able to answer "what is HTML?" and "what is CSS?" in your own words without hesitation.

---

Every web page you have ever seen is built on HTML. CSS makes it look good. Without HTML there is no content; without CSS everything is plain black text on white.

But what are they, exactly? And why are they separate? That is what this doc answers.

Think of it like building a house. HTML is the walls, the rooms, the doors - the structure. CSS is the paint, the furniture, the decoration - the look. You need both, but they are different jobs. And keeping them separate means you can repaint the house without rebuilding the walls.

**HTML (HyperText Markup Language)** describes the structure and meaning of content. "Hypertext" means text that links to other text - you can click a word and jump to another document. "Markup" means labeling the structure and meaning of content. "This is a heading." "This is a paragraph." "This is a link." Markup is not layout. Layout is CSS's job. This is a point that trips up a lot of beginners, so let it sink in: HTML labels, CSS styles.

HTML is the labeled content. The labels are what let the browser, and even search engines, understand what each piece is.

```html
<h1>Hello World</h1>
<p>This is a paragraph.</p>
<a href="https://example.com">A link</a>
```

**CSS (Cascading Style Sheets)** describes the look and layout. It selects HTML elements and applies styles like color, font-size, margin, flexbox, grid.

```css
h1 {
  color: blue;
  font-size: 32px;
}

p {
  margin: 16px 0;
}
```

Cascading in one short paragraph: a page can have many style rules, and sometimes they conflict - one rule says the heading is blue, another says it is red. Cascading is the set of priority rules that decides which one wins. Details come in the CSS module. Do not teach specificity or the `!important` flag here.

HTML provides the structure; CSS styles it. You can put CSS inside HTML with a `<style>` tag or in a separate `.css` file (preferred for larger projects). We will learn the connection methods in the CSS module - for now, just know they connect.

**JavaScript** exists and adds behavior to a page - making buttons clickable, validating forms, fetching data. Analogy: HTML is the walls and rooms, CSS is the paint and decoration, JavaScript is the electricity that makes things work. This course does not teach JavaScript; it is a separate course. Scripts can pause the browser while it reads the page - that is a topic for the JavaScript course.

## Common Mistakes

- **Using HTML for styling** (like old `<font>` tags) instead of CSS. HTML labels; CSS styles.
- **Mixing structure and presentation** in the same tags. Keep them separate.
- **Forgetting that markup is not layout** - HTML labels structure and meaning; layout (colors, spacing, position) is CSS's job.

## What It Is NOT

- HTML is **not** a programming language - it is markup (labels content).
- CSS is **not** HTML - CSS styles HTML; they are separate concerns.
- Markup is **not** layout - HTML labels structure and meaning; layout (colors, spacing, position) is CSS's job.
- `style` attribute is **not** the preferred way to add CSS - external `.css` files are preferred for maintainability.
