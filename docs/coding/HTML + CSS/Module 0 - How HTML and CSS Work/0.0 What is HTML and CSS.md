# Doc 0.0 — What is HTML and CSS

## Cheat Sheet (Quick Recall)

- HTML = structure and meaning of a web page (headings, paragraphs, links, forms, media).
- CSS = look and layout of a web page (colors, spacing, typography, responsive design).
- HTML is content; CSS is presentation. Keep them separate where possible.
- Every web page is HTML; CSS makes it look good.

## Main Content

### THINK

Every web page you have ever seen is built on HTML. CSS makes it look good. Without HTML there is no content; without CSS everything is plain black text on white. So first understand the two roles, then start writing them.

### CONCEPT

**HTML (HyperText Markup Language):**

HTML describes the **structure and meaning** of content. It uses tags like `<h1>`, `<p>`, `<a>`, `<img>`, `<form>` to say "this is a heading", "this is a paragraph", "this is a link".

```html
<h1>Hello World</h1>
<p>This is a paragraph.</p>
<a href="https://example.com">A link</a>
```

**CSS (Cascading Style Sheets):**

CSS describes the **look and layout**. It selects HTML elements and applies styles like color, font-size, margin, flexbox, grid.

```css
h1 {
  color: blue;
  font-size: 32px;
}

p {
  margin: 16px 0;
}
```

**How they connect:**

HTML provides the structure; CSS styles it. You can put CSS inside HTML with a `<style>` tag or in a separate `.css` file (preferred).

```html
<!DOCTYPE html>
<html>
  <head>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <h1>Hello</h1>
  </body>
</html>
```

### CODE (gradual)

Stage 1 — Plain HTML (no CSS):

```html
<h1>Hello World</h1>
<p>This is a paragraph.</p>
```

Stage 2 — Inline CSS:

```html
<h1 style="color: blue;">Hello World</h1>
```

Stage 3 — External CSS (preferred):

```html
<link rel="stylesheet" href="styles.css" />
```

### TEST

Three questions:

1. What is HTML for? (structure and meaning)
2. What is CSS for? (look and layout)
3. What are the three ways to add CSS? (inline, internal `<style>`, external file)

**Checkpoint:** Create an `index.html` with a heading and paragraph, open it in the browser. It should show plain text. Then add a `<style>` tag and change the color.

## Common Mistakes

- Using HTML for styling (e.g., `<font>` tags) instead of CSS.
- Mixing structure and presentation in the same tags.
- Forgetting the `<!DOCTYPE html>` declaration.

## Try It Yourself

1. Create `index.html` with a heading, paragraph, and link.
2. Open it in the browser and view the source.
3. Add a `<style>` block and change the heading color.

## Summary

- HTML = structure and meaning.
- CSS = look and layout.
- Connect via inline, internal, or external CSS.

## What It Is NOT

- ❌ HTML is **not** a programming language — it is markup.
- ❌ CSS is **not** HTML — it styles HTML.
- ❌ Inline styles are **not** preferred for large projects.
