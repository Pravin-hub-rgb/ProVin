# Doc 8.3 — Grid 12-column Layout

## Cheat Sheet (Quick Recall)

- 12-column grid: `grid-template-columns: repeat(12, 1fr);`.
- Items span: `grid-column: span 6;` (half), `span 4` (third), `span 3` (quarter).
- Responsive: change column count via media queries.
- Common framework pattern (Bootstrap-like).

## Main Content

### THINK

Many CSS frameworks use a 12-column grid. CSS Grid makes this easy. First 12 columns, then spanning, then responsive.

### CONCEPT

```css
.grid {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 20px;
}
.col-6 { grid-column: span 6; }  /* half */
.col-4 { grid-column: span 4; }  /* third */
.col-3 { grid-column: span 3; }  /* quarter */
.col-12 { grid-column: span 12; } /* full */
```

- 12 columns = flexible (divides by 2, 3, 4, 6).
- `span N` for column width.
- Responsive: change to 1 column on mobile.

### CODE (gradual)

Stage 1 — 12 columns:

```css
.grid { display: grid; grid-template-columns: repeat(12, 1fr); gap: 20px; }
```

Stage 2 — Span classes:

```css
.col-6 { grid-column: span 6; }
.col-4 { grid-column: span 4; }
.col-3 { grid-column: span 3; }
```

Stage 3 — Responsive:

```css
@media (max-width: 768px) {
  .col-6, .col-4, .col-3 { grid-column: span 12; }
}
```

## Common Mistakes

- Span values not adding to 12 per row.
- Not making responsive (stack on mobile).
- Confusing `span` with column start/end.

## What It Is NOT

- ❌ 12 columns are **not** automatic — define them.
- ❌ `span` values must **add up** to 12 per row.
- ❌ Fixed widths are **not** responsive.
