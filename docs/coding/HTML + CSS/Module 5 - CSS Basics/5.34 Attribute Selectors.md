# Doc 5.34 — Attribute Selectors

## Cheat Sheet (Quick Recall)

- `[attr]` — has attribute.
- `[attr="value"]` — exact match.
- `[attr^="value"]` — starts with.
- `[attr$="value"]` — ends with.
- `[attr*="value"]` — contains.

## Main Content

### THINK

Selectors can target attributes, not just tags/classes/IDs. First exact match, then starts/ends/contains.

### CONCEPT

```css
a[target] { color: red; }              /* has target attr */
a[target="_blank"] { color: blue; }    /* exact match */
a[href^="https"] { color: green; }     /* starts with */
a[href$=".pdf"] { color: orange; }     /* ends with */
a[href*="example"] { color: purple; }  /* contains */
```

### CODE (gradual)

Stage 1 — Has attribute:

```css
input[required] { border-color: red; }
```

Stage 2 — Exact match:

```css
input[type="text"] { border-color: blue; }
```

Stage 3 — Starts/ends/contains:

```css
a[href^="https"] { color: green; }
a[href$=".pdf"] { color: orange; }
```

## Common Mistakes

- Wrong operator (`^=` vs `$=` vs `*=`).
- Case sensitivity (attribute values).
- Overusing (specificity).

## What It Is NOT

- ❌ `^=` is **not** `$=` (starts vs ends).
- ❌ Attribute selectors are **not** case-insensitive (usually).
- ❌ `[attr]` is **not** `[attr=""]`.
