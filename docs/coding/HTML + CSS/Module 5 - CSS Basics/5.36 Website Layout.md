# Doc 5.36 — Website Layout

## Cheat Sheet (Quick Recall)

- Common layout: header, nav, main, sidebar, footer.
- CSS Grid or Flexbox for arrangement.
- `max-width` container centered.
- Responsive: stack on mobile.

## Main Content

### THINK

A website has regions: header, nav, main, sidebar, footer. CSS arranges them. First structure (HTML), then layout (CSS Grid/Flexbox), then responsive.

### CONCEPT

```html
<header>Header</header>
<nav>Nav</nav>
<main>
  <article>Main</article>
  <aside>Sidebar</aside>
</main>
<footer>Footer</footer>
```

```css
body { display: grid; grid-template-rows: auto auto 1fr auto; }
main { display: flex; gap: 20px; }
article { flex: 3; }
aside { flex: 1; }
@media (max-width: 768px) {
  main { flex-direction: column; }
}
```

### CODE (gradual)

Stage 1 — Structure:

```html
<header>...</header>
<main>...</main>
<footer>...</footer>
```

Stage 2 — Grid layout:

```css
body { display: grid; grid-template-rows: auto 1fr auto; }
```

Stage 3 — Flex main:

```css
main { display: flex; gap: 20px; }
```

Stage 4 — Responsive:

```css
@media (max-width: 768px) { main { flex-direction: column; } }
```

### TEST

Three questions:

1. What CSS property for page layout? (`display: grid` or `flex`)
2. How to make sidebar + main side-by-side? (flex on main)
3. How to stack on mobile? (media query + `flex-direction: column`)

**Checkpoint:** Build a responsive page layout.

## Common Mistakes

- Using tables for layout.
- Not making it responsive.
- Fixed widths.
