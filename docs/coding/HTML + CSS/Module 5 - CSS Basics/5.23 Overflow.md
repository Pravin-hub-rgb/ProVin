# Doc 5.23 — Overflow

## Cheat Sheet (Quick Recall)

- `overflow: visible` (default) — content spills out.
- `overflow: hidden` — clips content.
- `overflow: scroll` — always shows scrollbar.
- `overflow: auto` — scrollbar only when needed.

## Main Content

### THINK

Content may exceed its container. Overflow controls what happens. First values, then scroll vs auto, then hidden for clipping.

### CONCEPT

```css
div {
  overflow: visible; /* default */
  overflow: hidden;  /* clip */
  overflow: scroll;   /* always scrollbar */
  overflow: auto;     /* scrollbar when needed */
}
```

- `visible`: spills out (default).
- `hidden`: clipped, no scrollbar.
- `scroll`: always scrollbar.
- `auto`: scrollbar only when overflowing.

**Per-direction:** `overflow-x`, `overflow-y`.

### CODE (gradual)

Stage 1 — Visible (default):

```css
div { width: 100px; height: 50px; }
/* content spills out */
```

Stage 2 — Hidden:

```css
div { overflow: hidden; }
```

Stage 3 — Auto scroll:

```css
div { overflow: auto; }
```

### TEST

Three questions:

1. What is the default overflow? (`visible`)
2. Which value shows scrollbar only when needed? (`auto`)
3. Difference between `hidden` and `scroll`? (`hidden` clips, `scroll` always shows scrollbar)

**Checkpoint:** Create a small container with overflowing content and test each value.

## Common Mistakes

- Using `scroll` when `auto` is better (unnecessary scrollbar).
- `hidden` clipping needed content.
- Forgetting `overflow-x`/`overflow-y` for one direction.

## Try It Yourself

1. Set `overflow: hidden`.
2. Set `overflow: auto`.
3. Set `overflow-x: hidden; overflow-y: auto`.

## Summary

- `visible`, `hidden`, `scroll`, `auto`.
- `auto` = scrollbar only when needed.
- Per-direction: `overflow-x`/`overflow-y`.
