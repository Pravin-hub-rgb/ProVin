# Doc 5.11 — Box Model

## Cheat Sheet (Quick Recall)

- Content → Padding → Border → Margin.
- `box-sizing: content-box` (default): width = content only.
- `box-sizing: border-box`: width includes padding + border.
- Use `* { box-sizing: border-box; }` for predictable sizing.

## Main Content

### THINK

Every element is a box: content, padding, border, margin. Understanding this explains sizing and spacing. First the layers, then box-sizing.

### CONCEPT

```
┌─────────────────────┐
│       Margin        │
│  ┌───────────────┐  │
│  │    Border     │  │
│  │ ┌───────────┐ │  │
│  │ │  Padding  │ │  │
│  │ │ ┌───────┐ │ │  │
│  │ │ │Content│ │ │  │
│  │ │ └───────┘ │ │  │
│  │ └───────────┘ │  │
│  └───────────────┘  │
└─────────────────────┘
```

- Content: the actual content.
- Padding: inside space.
- Border: outline.
- Margin: outside space.

**box-sizing:**

- `content-box` (default): width = content only (padding/border add to total).
- `border-box`: width includes padding + border.

### CODE (gradual)

Stage 1 — content-box (default):

```css
div { width: 200px; padding: 20px; border: 5px solid black; }
/* total width = 200 + 40 + 10 = 250px */
```

Stage 2 — border-box:

```css
div { box-sizing: border-box; width: 200px; padding: 20px; border: 5px solid black; }
/* total width = 200px */
```

Stage 3 — Global reset:

```css
* { box-sizing: border-box; }
```

### TEST

Three questions:

1. Box model layers? (content, padding, border, margin)
2. Default box-sizing? (`content-box`)
3. What does `border-box` include in width? (padding + border)

**Checkpoint:** Create a div with padding/border and compare content-box vs border-box.

## Common Mistakes

- Forgetting box-sizing → unexpected sizes.
- Confusing margin (outside) with padding (inside).
- Not using global `border-box` reset.

## Try It Yourself

1. Create a div with width, padding, border.
2. Toggle box-sizing and observe.
3. Add global `border-box` reset.

## Summary

- Box model: content → padding → border → margin.
- `content-box` (default) vs `border-box`.
- Use `* { box-sizing: border-box; }`.
