# Doc 5.9 — Padding

## Cheat Sheet (Quick Recall)

- `padding` = space inside element (between content and border).
- Shorthand same as margin: 1/2/4 values.
- Cannot be negative.
- Affects element size (unless `box-sizing: border-box`).

## Main Content

### THINK

Padding creates space inside an element (between content and border). Similar to margin but inside. First all sides, then shorthand, then box-sizing.

### CONCEPT

```css
div {
  padding: 10px;              /* all sides */
  padding: 10px 20px;         /* vertical horizontal */
  padding: 10px 20px 30px 40px; /* top right bottom left */
  padding-top: 10px;
}
```

- `padding` = inside space.
- Shorthand same as margin.
- Cannot be negative.
- Adds to element size unless `box-sizing: border-box`.

### CODE (gradual)

Stage 1 — All sides:

```css
div { padding: 10px; }
```

Stage 2 — Vertical/horizontal:

```css
div { padding: 10px 20px; }
```

Stage 3 — box-sizing:

```css
* { box-sizing: border-box; }
```

### TEST

Three questions:

1. What does `padding` control? (space inside element)
2. Can padding be negative? (No)
3. What does `border-box` do? (includes padding in width/height)

**Checkpoint:** Add padding and observe inner spacing.

## Common Mistakes

- Confusing margin (outside) with padding (inside).
- Forgetting box-sizing → unexpected sizes.
- Using padding for layout instead of flexbox.
