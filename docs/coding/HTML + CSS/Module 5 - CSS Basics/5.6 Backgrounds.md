# Doc 5.6 — Backgrounds

## Cheat Sheet (Quick Recall)

- `background-color`, `background-image`.
- `background-repeat`: repeat/no-repeat.
- `background-position`: center, top left, etc.
- `background-size`: cover, contain, 100%.
- Shorthand: `background: color image repeat position/size`.

## Where We Are So Far

CSS 06 covered colors. Now backgrounds — images and colors behind elements.

## Broader Goal

## Main Content

### THINK

Backgrounds add visual depth. First color, then image, then repeat/position/size, then shorthand.

### CONCEPT

```css
div {
  background-color: #f0f0f0;
  background-image: url("bg.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}
```

**Shorthand:**

```css
div {
  background: #f0f0f0 url("bg.jpg") no-repeat center/cover;
}
```

### CODE (gradual)

Stage 1 — Color:

```css
body { background-color: lightgray; }
```

Stage 2 — Image:

```css
body { background-image: url("bg.jpg"); }
```

Stage 3 — No-repeat + center:

```css
body {
  background-repeat: no-repeat;
  background-position: center;
}
```

Stage 4 — Size cover:

```css
body { background-size: cover; }
```

### TEST

Three questions:

1. Property for background image? (`background-image`)
2. Value to prevent tiling? (`no-repeat`)
3. Shorthand property? (`background`)

**Checkpoint:** Add a background image with no-repeat and cover.

## Common Mistakes

- Wrong image path.
- Forgetting `no-repeat` (tiles by default).
- Not setting `background-size`.

## What It Is NOT

- ❌ Backgrounds are **not** foreground content.
- ❌ `cover` is **not** `contain` (contain shows full image).
- ❌ Default repeat is **not** no-repeat.
