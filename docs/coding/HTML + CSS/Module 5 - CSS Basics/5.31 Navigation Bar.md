# Doc 5.31 — Navigation Bar

## Cheat Sheet (Quick Recall)

- Horizontal nav: `display: flex` or `inline-block` items.
- Remove bullets: `list-style: none`.
- Sticky navbar: `position: sticky; top: 0;`.
- Responsive: hamburger menu with media queries.

## Main Content

### THINK

A navbar is a horizontal list of links. First structure (ul/li/a), then styling (flex, remove bullets), then sticky, then responsive (hamburger).

### CONCEPT

```html
<nav>
  <ul>
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
  </ul>
</nav>
```

```css
nav ul {
  list-style: none;
  display: flex;
  gap: 16px;
  padding: 0;
}
nav a {
  text-decoration: none;
  color: #333;
}
nav a:hover { color: blue; }
```

- `position: sticky; top: 0;` for sticky navbar.
- Media queries for hamburger on mobile.

### CODE (gradual)

Stage 1 — Basic list:

```html
<ul>
  <li><a href="#">Home</a></li>
  <li><a href="#">About</a></li>
</ul>
```

Stage 2 — Horizontal + no bullets:

```css
ul { list-style: none; display: flex; gap: 16px; padding: 0; }
```

Stage 3 — Sticky:

```css
nav { position: sticky; top: 0; background: white; }
```

## Common Mistakes

- Forgetting `padding: 0` on ul.
- Not making it sticky when needed.
- No mobile responsiveness (hamburger).
