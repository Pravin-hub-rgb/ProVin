### CONCEPT

CSS (Cascading Style Sheets) describes the **look and layout** of HTML elements.

```css
h1 {
  color: blue;
  font-size: 32px;
}
```

- **Cascading**: styles cascade from multiple sources (browser, user, author).
- **Selectors** target HTML elements.
- **Properties** define appearance.

### CODE (gradual)

Stage 1 — Inline:

```html
<h1 style="color: blue;">Hello</h1>
```

Stage 2 — Internal:

```html
<style>
  h1 { color: blue; }
</style>
```

Stage 3 — External (preferred):

```html
<link rel="stylesheet" href="styles.css" />
```
