## Main Content

### THINK

CSS needs to target HTML elements. Selectors do that. First element, class, ID, then universal and grouping.

### CONCEPT

```css
p { color: red; }        /* element */
.intro { color: blue; }  /* class */
#main { color: green; }  /* ID */
* { margin: 0; }         /* universal */
h1, h2 { color: blue; }  /* group */
```

- Element selector: tag name.
- Class selector: `.classname`.
- ID selector: `#idname`.
- Universal: `*` (all elements).
- Group: comma-separated.

## Common Mistakes

- Confusing class (`.`) and ID (`#`).
- Missing dot/hash.
- Overusing ID selectors (high specificity).
