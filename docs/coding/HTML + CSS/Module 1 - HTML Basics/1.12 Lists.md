## Main Content

Lists group related items. HTML gives three kinds. The problem beginners create: they use `<ol>` for everything (or `<ul>` for everything), losing the meaning of "order matters" vs "order does not matter." Another: they nest a list directly inside the parent list instead of inside an `<li>`, producing invalid HTML.

Start from a shopping list. Guess: use `<ol>`? That numbers the items, implying sequence — wrong for groceries. Guess: use `<ul>`? That bullets them, implying "just a group" — right. For recipe steps, `<ol>` is right because order matters.

**Unordered list (bullets):**

```html
<ul>
  <li>Apples</li>
  <li>Bananas</li>
  <li>Cherries</li>
</ul>
```

Line by line: `<ul>` wraps the list. Each `<li>` is one item. The browser renders bullets because the list is unordered.

**Ordered list (numbers):**

```html
<ol>
  <li>First step</li>
  <li>Second step</li>
  <li>Third step</li>
</ol>
```

Same structure, but `<ol>` numbers the items in order. Use this when sequence matters (steps, rankings, instructions).

**Ordered list attributes:**

```html
<ol start="5" type="A" reversed>
  <li>Item</li>
</ol>
```

Line by line: `start="5"` begins numbering at 5. `type="A"` uses uppercase letters (A, B, C) instead of numbers (1, 2, 3); other values: `1`, `a`, `I`, `i`. `reversed` counts down.

**Description list (term + definition):**

```html
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>
```

Line by line: `<dl>` wraps. `<dt>` is the term. `<dd>` is the definition. Use for glossaries or metadata.

**Nested lists:**

```html
<ul>
  <li>Fruits
    <ul>
      <li>Apple</li>
      <li>Banana</li>
    </ul>
  </li>
  <li>Vegetables</li>
</ul>
```

Line by line: the nested `<ul>` sits inside an `<li>` of the parent, not directly inside the parent `<ul>`. That is the only valid placement.

**Debugging scenarios:**

- "My list has no bullets/numbers" — you used `<li>` without a `<ul>`/`<ol>` wrapper, or CSS reset removed markers. Wrap items and check CSS.
- "My nested list is invalid" — you put `<ul>` directly inside `<ul>`. Move it inside an `<li>`.
- "My ordered list starts at 1 but I wanted 5" — add `start="5"`.
- "My description list terms are not bold" — `<dt>` is not bold by default in all browsers. Style with CSS if needed.

## Common Mistakes

- Putting `<li>` directly in `<ul>`'s sibling (not wrapped) — invalid.
- Nesting a list directly inside `<ul>` instead of inside an `<li>`.
- Using lists for layout/indentation instead of CSS.
- Using `<ol>` when order does not matter (and vice versa).
- Forgetting that only `<li>` (or `<dt>`/`<dd>` for dl) are valid children.
- Using `<br>` between items instead of separate `<li>`.

## Try It Yourself

1. Build a shopping list with `<ul>`.
2. Build a recipe steps list with `<ol start="1">`.
3. Create a nested list (categories -> items).
4. Build a glossary with `<dl>`.
5. Use `type="A"` and `reversed` on an ordered list.

## Summary

- `<ul>` = bullets; `<ol>` = numbers; `<li>` = item.
- `<dl>`/`<dt>`/`<dd>` = term/definition.
- Nest lists inside `<li>`.
- `ol` supports `start`, `type`, `reversed`.
- Pick list type by whether order matters.

## In Your Own Words

1. When should you use `<ul>` vs `<ol>`?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Use `<ul>` (unordered) when order does not matter (shopping list, features). Use `<ol>` (ordered) when sequence matters (steps, rankings, instructions). The choice conveys meaning, not just appearance.

</details>

2. What is a description list and what tags does it use?

<details>
<summary>Show Answer</summary>

**Sample Answer:** A description list pairs terms with definitions. It uses `<dl>` (wrapper), `<dt>` (term), and `<dd>` (definition). Example: a glossary or metadata list.

</details>

3. How do you nest a list correctly?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Put the nested `<ul>` or `<ol>` inside an `<li>` of the parent list, not directly inside the parent `<ul>`/`<ol>`. The nested list becomes a child of that list item.

</details>

## Cheat Sheet (Quick Recall)

**`<ul>`** bullets, **`<ol>`** numbers (+start/type/reversed), **`<li>`** item.

**`<dl>`**/**`<dt>`**/**`<dd>`** term+definition.

**Nest** inside `<li>`.
