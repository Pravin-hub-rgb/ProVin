# Doc 1.17 — Lists

HTML 17 covered tables. Now lists — ordered and unordered.

---

Lists are everywhere: menus, steps, glossaries. HTML has unordered (bullets), ordered (numbers), and definition lists. First basic, then nested, then definition lists.


**Unordered:**

```html
<ul>
  <li>Apple</li>
  <li>Banana</li>
</ul>
```

**Ordered:**

```html
<ol>
  <li>First</li>
  <li>Second</li>
</ol>
```

**Definition list:**

```html
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
</dl>
```

**Nested:**

```html
<ul>
  <li>Fruits
    <ul>
      <li>Apple</li>
    </ul>
  </li>
</ul>
```


Stage 1 — Unordered:

```html
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
```

Stage 2 — Ordered:

```html
<ol>
  <li>Step 1</li>
  <li>Step 2</li>
</ol>
```

Stage 3 — Nested:

```html
<ul>
  <li>Parent
    <ul><li>Child</li></ul>
  </li>
</ul>
```


Three questions:

1. Tag for unordered list? (`<ul>`)
2. Tag for ordered list? (`<ol>`)
3. Tag for list item? (`<li>`)
