# Doc 1.7 — Formatting

## Where We Are So Far

`1.6` covered paragraphs. Now formatting — inline text styling with semantic meaning. Connection: paragraphs hold text; now how to mark parts of that text as important, emphasized, or edited.

## Broader Goal

Learn the formatting tags and, crucially, the semantic-vs-presentational distinction, so you choose the right tag for the right reason.

---

## Main Content

Formatting tags change how text looks, but the good ones also carry meaning. The problem beginners create: they reach for `<b>` and `<i>` for everything, losing the meaning that `<strong>` and `<em>` carry for screen readers and search engines. The key lesson: some tags say "make it bold" while others say "this is important." Pick by meaning, not by appearance.

Start from a sentence where one word matters more than the rest. Guess: wrap it in `<b>`? That makes it bold but says nothing about importance. Guess: wrap it in `<strong>`? That makes it bold *and* marks it important. The second guess is the one to reach for when importance is the point.

**Semantic vs presentational pairs:**

```html
<!-- Semantic: meaning -->
<strong>This is important.</strong>
<em>This is emphasized.</em>

<!-- Presentational: appearance only -->
<b>Bold text.</b>
<i>Italic text.</i>
```

Line by line: `<strong>` marks important text (bold by default, semantic). `<em>` marks emphasized text (italic by default, semantic — stress changes sentence meaning). `<b>` only makes text bold with no semantic meaning. `<i>` only italicizes with no semantic meaning (e.g., a ship name, a foreign word). Use semantic when the meaning matters; presentational when it is purely visual.

**Other formatting tags:**

```html
<p>Price: <mark>$49</mark> (was <del>$99</del>, now <ins>$49</ins>)</p>
<p>This is <small>small print</small> and H<sub>2</sub>O and x<sup>2</sup>.</p>
```

Line by line: `<mark>` highlights text like a highlighter. `<small>` marks smaller text (disclaimers, fine print). `<del>` marks deleted text (strikethrough). `<ins>` marks inserted text (underline). `<sub>` is subscript (H₂O). `<sup>` is superscript (x²).

**Debugging scenarios:**

- "My important word is not announced as important" — you used `<b>` instead of `<strong>`. Switch to `<strong>`.
- "My edited price shows no strikethrough" — you used `<s>` or styled manually instead of `<del>`. Use `<del>` for removed content and `<ins>` for added content.
- "My chemical formula looks wrong" — you typed `H2O` without `<sub>`. Wrap the 2 in `<sub>`.
- "My highlight does not show" — `<mark>` has default yellow styling; if your CSS resets backgrounds, re-add it.

## Common Mistakes

- Using `<b>`/`<i>` when `<strong>`/`<em>` is meant — loses semantic meaning.
- Using formatting tags for layout/spacing instead of CSS.
- Nesting formatting tags incorrectly across paragraphs.
- Forgetting that `<del>`/`<ins>` are for edits, not for "wrong" text.
- Styling these tags to look like normal text — defeats their purpose.

## Try It Yourself

1. Write a sentence with both `<strong>` and `<b>` and inspect in DevTools (look at the accessibility tree).
2. Highlight a price with `<mark>` and add `<del>` for the old price.
3. Write H₂O and x² using sub/sup.
4. Style an `<em>` with CSS to see meaning vs appearance.

## Summary

- `<strong>` (important) vs `<b>` (bold only).
- `<em>` (emphasized) vs `<i>` (italic only).
- `<mark>`, `<small>`, `<del>`, `<ins>`, `<sub>`, `<sup>`.
- Prefer semantic tags when meaning matters.
- Styling beyond these is CSS's job.

<details>
<summary>Show Answer</summary>

**Sample Answer:** `<em>` emphasizes text (italic by default, semantic meaning — stress changes sentence meaning). `<i>` only italicizes with no semantic meaning (e.g., a ship name, foreign word). Use `<em>` for emphasis, `<i>` for visual italics only.

</details>

<details>
<summary>Show Answer</summary>

**Sample Answer:** `<del>` marks deleted text (shown with strikethrough) and `<ins>` marks inserted text (shown underlined). They are used to show edits/revisions to content, not for "wrong" text or styling.

## Cheat Sheet (Quick Recall)

**Semantic:** `<strong>`, `<em>`. **Presentational:** `<b>`, `<i>`.

**Others:** `<mark>`, `<small>`, `<del>`, `<ins>`, `<sub>`, `<sup>`.

**Rule:** meaning first, appearance via CSS.
