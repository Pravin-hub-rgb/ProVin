# Doc 1.36 — How to View, Inspect, and Debug

HTML Basics covered structure, elements, forms-related basics, and file paths. Now that you can write HTML, this doc covers how to view and debug it in the browser.

---



---

## Questions

1. How do you open DevTools?

<details>
<summary>Show Answer</summary>

**Answer:** Press F12 or Ctrl+Shift+I. You can also right-click anywhere on the page and choose "Inspect."

</details>

2. What are the four key DevTools tabs and what does each do?

<details>
<summary>Show Answer</summary>

**Answer:** Elements (view/edit HTML and CSS live), Console (JS errors and logs), Network (file requests and 404s), Sources (view files, set breakpoints). Elements and Console are the ones you use most for HTML/CSS work.

</details>

3. How do you inspect a specific element?

<details>
<summary>Show Answer</summary>

**Answer:** Right-click the element on the page and choose "Inspect." DevTools opens and jumps to that node in the Elements tab. The Styles pane shows all CSS rules that apply to it.

</details>

4. Do edits in DevTools save to your files?

<details>
<summary>Show Answer</summary>

**Answer:** No. Edits in DevTools are temporary - they update the page instantly but are lost on refresh. Copy the CSS you like into your actual file.

</details>

5. Where do you look if an image is not showing?

<details>
<summary>Show Answer</summary>

**Answer:** The Network tab. Look for a 404 (Not Found) status on the image request. That tells you the path is wrong.

</details>
