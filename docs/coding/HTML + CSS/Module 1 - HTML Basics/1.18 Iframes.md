# Doc 1.18 — Iframes

## Where We Are So Far

`1.17` covered the head element. Now iframes — embedding another page inside yours. Connection: links and images showed `src`; iframes reuse the same idea for whole pages.

## Broader Goal

Embed external or local pages with `<iframe>`, understand `src`/`title`/`name`, and target an iframe with a link.

---

## Main Content

An iframe is an inline frame: a window cut into your page that shows another page. It keeps its own scrolling and styles and cannot mess with your page. The problem beginners create: they forget `title` (accessibility failure), they use a normal page URL instead of an embed URL (site refuses), or they expect every site to embed (many block it).

Start from a page that needs to show a map or a video. Guess: use `<img>`? That shows a static picture, not an interactive page. Guess: use `<iframe src="...">`? That embeds a live page. The second guess is right — but only if the site allows framing.

**Basic iframe:**

```html
<iframe src="pages/about.html" width="600" height="400" title="About page"></iframe>
```

Line by line: `src` is the URL or relative path of the page to embed. `width`/`height` set the size of the box. `title` describes the frame for screen readers (always include).

**Embedding a web address:**

```html
<iframe src="https://example.com" width="600" height="400" title="Example"></iframe>
```

Some sites allow this (example.com does); others refuse. Try google.com and you will see a "can't open this page" message — the site's clickjacking protection blocked embedding. That is a policy decision by the site, not a bug in your HTML.

**Targeting an iframe with a link:**

```html
<iframe name="box" src="home.html" width="600" height="400" title="Content box"></iframe>
<a href="about.html" target="box">Load About into the box</a>
```

Line by line: give the iframe a `name`. A link with `target` equal to that name loads its page inside the iframe instead of replacing your page. The `name` on the iframe is like an address for that box.

**Sandboxing (security):** the `sandbox` attribute restricts what the embedded page can do (scripts, forms, popups). Useful when embedding untrusted content. An empty `sandbox` blocks almost everything; add tokens like `allow-scripts` to permit specific features.

**Debugging scenarios:**

- "My iframe is blank" — the site blocks framing (clickjacking protection). Use an embed URL provided by the site.
- "My iframe has no accessible name" — `title` is missing. Add it.
- "My iframe collapsed to nothing" — width/height are missing. Add them.
- "My link opens a new tab instead of the iframe" — the `target` does not match the iframe's `name`. Match them exactly (case-sensitive).
- "My embedded page runs scripts I did not expect" — you did not sandbox it. Add `sandbox`.

## Common Mistakes

- Forgetting `title` — screen readers cannot announce the frame's purpose.
- Using the normal page URL for YouTube/maps instead of the provided embed URL.
- Expecting every site to embed — many block it by policy.
- Omitting width/height — the iframe may collapse or cause layout shift.
- Trusting embedded content without `sandbox` when it is untrusted.

## Try It Yourself

1. Embed your own `about.html` in an iframe and confirm it renders.
2. Try embedding google.com and observe the block.
3. Add a `name` to the iframe and a link with matching `target`; click and watch it load inside.
4. Add `sandbox` and observe restricted behavior.
5. Embed a YouTube video using its embed URL.

## Summary

- `<iframe src>` embeds another page in a box.
- Attributes: `src`, `width`, `height`, `title`, `name`, `sandbox`.
- `title` is required for accessibility.
- Links can target an iframe via matching `name`/`target`.
- Sites may refuse embedding (clickjacking protection); use provided embed URLs.

## In Your Own Words

1. What is an iframe?

<details>
<summary>Show Answer</summary>

**Sample Answer:** An iframe (inline frame) is an element that embeds another HTML page inside a box within your page. It has its own scrolling and styles and cannot affect your page. It uses `src` like an image or link.

</details>

2. How can a link load a page inside an iframe?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Give the iframe a `name` attribute. Then set a link's `target` to that same name. Clicking the link loads its `href` into the iframe instead of replacing the current page.

</details>

3. Why might an iframe show a blank or error box?

<details>
<summary>Show Answer</summary>

**Sample Answer:** The embedded site may refuse to be framed (clickjacking protection), or the URL may be wrong/blocked. Many sites (Google, banks) block framing. Use embed URLs provided by sites (YouTube, maps) for allowed embedding.

</details>
