# Doc 1.1 — Editors and DevTools

Module 0 is complete. You now know why the web exists, what HTML and CSS are, and how the browser renders them. Before writing your first HTML page, you need a place to write it and a way to view it. That is what this lecture covers.

HTML is just text. You can write it in Notepad, but a good editor makes life easier. VS Code is the standard. Install it, add a few useful extensions, create an `.html` file, and open it with Live Server for auto-refresh while you code.

**Recommended editor:** VS Code (free, cross-platform).

**Useful extensions:**

- **Live Server** — auto-refreshes the browser on save.
- **Prettier** — auto-formats code.
- **HTML CSS Support** — autocomplete CSS class names.

**Creating a file:**

1. Open VS Code.
2. Create a new file.
3. Save as `index.html`.
4. Write HTML.
5. Open with Live Server.

```text
File → New File → Save As → index.html
```

```html
<!DOCTYPE html>
<html>
  <head><title>Test</title></head>
  <body><h1>Hello</h1></body>
</html>
```

Right-click `index.html` → "Open with Live Server."

Once you have a page open, you need to inspect and debug it. Press `F12` or `Ctrl+Shift+I` to open DevTools. Four tabs matter most:

- **Elements:** view/edit HTML and CSS live (changes are temporary).
- **Console:** JavaScript errors and logs.
- **Network:** file requests and 404s.
- **Sources:** view files, set breakpoints.

Right-click any element on the page and choose "Inspect" to jump to that node in the Elements tab. The Styles pane shows which CSS rules apply to it. You can toggle properties, change values, or add new ones — the page updates instantly, but these changes are not saved to your file.

**Common debugging scenarios:**

- "My image is not showing" → check the Network tab for a 404.
- "My CSS is not applying" → check the Elements tab for selector mismatches.
- "The layout is broken" → check the Computed pane for width, height, margin, padding, border.

**Common mistakes:**

- Saving as `.txt` instead of `.html`.
- Not installing Live Server and manually refreshing.
- Editing in DevTools and expecting it to save (it does not).
- Forgetting to save before refreshing.

**Try it yourself:**

1. Install VS Code and Live Server.
2. Create and run `index.html`.
3. Format code with Prettier.
4. Press F12, explore the tabs, inspect an element.
