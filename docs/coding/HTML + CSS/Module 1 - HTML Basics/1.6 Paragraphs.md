## Main Content

Headings are understood. Now the body text — paragraphs. The first surprise for beginners: pressing Enter in the source does not create a new line on screen, and typing ten spaces shows one. HTML collapses whitespace. First basic paragraph, then whitespace behavior, then line breaks.

```html
<p>This is a paragraph.</p>
<p>This is another paragraph.</p>
```

Line by line: each `<p>` is a block-level paragraph. The browser renders them as separate blocks with a vertical gap between them, from the browser's default stylesheet.

**Whitespace collapsing:** the browser treats any run of spaces, tabs, or newlines as a single space.

```html
<p>Hello    World</p>
<!-- renders as "Hello World" -->
```

This means you cannot create spacing by typing extra spaces. Use CSS (margin/padding) or `<br>` for line breaks.

**Line break within a paragraph:**

```html
<p>Line one.<br>Line two.</p>
```

`<br>` is a void element for a single line break. Use it for addresses, poems, or short breaks — not for spacing between blocks (use paragraphs or CSS).

**Horizontal rule:** `<hr>` is a void element that draws a horizontal line across the page. It carries meaning, not just a look: it marks a real shift in topic/scene. Use it for a genuine change of subject, not decoration (decoration is CSS's job).

**Debugging scenarios:**

- "My text runs together on one line" — you used newlines in source expecting line breaks. Use separate `<p>` tags or `<br>`.
- "My extra spaces disappeared" — whitespace collapsing is by design. Use CSS for spacing, `&nbsp;` (entities, `1.20`) for a non-breaking space.
- "I used `<br><br>` to make a gap and it looks wrong" — that fakes paragraph spacing. Use two `<p>` tags instead.
- "A paragraph swallowed my heading" — you nested a block element inside `<p>`. `<p>` cannot contain block elements; close it first.

## Common Mistakes

- Typing many spaces expecting visible gaps — they collapse.
- Using `<br><br>` to create paragraph spacing instead of separate `<p>` tags.
- Forgetting that Enter in the source does not create a new line on screen.
- Putting block elements (like another `<p>`) inside a `<p>` — invalid nesting.
- Using `<pre>` (code element, `1.16`) when you only wanted one line break.

## Try It Yourself

1. Write a paragraph with 5 spaces between two words and observe collapse.
2. Add a `<br>` and see the line break.
3. Compare two `<p>` tags vs one `<p>` with `<br><br>`.
4. Inspect default margin on `<p>` in DevTools Computed pane.

## Summary

- `<p>` is the paragraph element (block).
- Whitespace collapses to a single space.
- `<br>` is the void element for a single line break.
- Use separate `<p>` for paragraphs; CSS for spacing.
- `<pre>` preserves whitespace (see `1.16`).

## In Your Own Words

1. What happens to multiple spaces in HTML source?

<details>
<summary>Show Answer</summary>

**Sample Answer:** They collapse to a single space. The browser ignores extra whitespace (spaces, tabs, newlines) when rendering. To create real spacing, use CSS (margin/padding) or `<br>` for line breaks.

</details>

2. When should you use `<br>`?

<details>
<summary>Show Answer</summary>

**Sample Answer:** For a single line break inside a paragraph — addresses, poems, song lyrics. Not for spacing between blocks; use separate `<p>` tags or CSS margins for that.

</details>

3. What is the difference between `<p>` and `<br>`?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `<p>` is a block-level paragraph with its own spacing; `<br>` is a void element that forces a single line break within the current block. Use `<p>` for separate paragraphs, `<br>` only for breaks inside one paragraph.

</details>
