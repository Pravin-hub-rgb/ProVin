# Doc 1.4 — Attributes

## Where We Are So Far

`1.3` covered elements. Elements alone are not enough — they need extra info (where a link points, what an image shows). Attributes provide that. Connection: elements defined; now how to configure them.

## Broader Goal

Learn attribute syntax, the common attributes, and boolean attributes so you can configure any element correctly.

---

## Main Content

An attribute adds information to an element. It is written inside the opening tag as `name="value"`. The first problem beginners hit: they put attributes on the closing tag or forget quotes, and the element silently ignores the configuration.

**Syntax:**

```html
<tag attribute="value">content</tag>
```

The attribute lives only in the opening tag. The closing tag never gets attributes.

**Common attributes:**

- `href` — link destination (on `<a>`).
- `src` — source path (on `<img>`, `<script>`, `<iframe>`).
- `alt` — alternative text for images.
- `class` — CSS class hook (multiple allowed, space-separated).
- `id` — unique identifier for one element.
- `title` — tooltip text on hover.
- `lang` — language of the element's content.
- `style` — inline CSS (avoid when possible; prefer classes).

```html
<a href="https://example.com" title="Visit Example">Link</a>
<img src="photo.jpg" alt="A photo of a sunset" width="200" height="150" />
```

Line by line: the `<a>` has two attributes — `href` sets where it goes, `title` sets the hover tooltip. The `<img>` has four — `src` locates the file, `alt` describes it for screen readers and fallback, `width`/`height` reserve space so the page does not jump when the image loads.

**Boolean attributes** (presence = true, absence = false):

```html
<input type="checkbox" checked />
<input type="text" required disabled />
```

No value is needed; writing `checked="checked"` is the old XHTML form and still works but is unnecessary. The browser checks whether the attribute is present, not what its value is.

**Multiple attributes:** separate with spaces; order does not matter.

```html
<img src="photo.jpg" alt="Photo" width="200" class="thumb" id="hero" />
```

**Quoting:** always quote values with double quotes. Single quotes work, but double is the convention. Unquoted values break on spaces — `href=https://example.com/search?q=hello world` would be read as two attributes.

**Debugging scenarios:**

- "My link goes nowhere" — `href` is misspelled (`herf`) or missing. Check the spelling and that it sits in the opening tag.
- "My image has no description for screen readers" — `alt` is missing. Add it.
- "My styling hook does nothing" — `class` name does not match the CSS selector, or you used `id` in CSS with a `.` instead of `#`. Check the spelling and the CSS.
- "Two elements share an id and CSS only styles one" — `id` must be unique. Switch to `class` for groups.
- "My checkbox is always checked" — you wrote `checked` without thinking; remove the attribute to make it unchecked.

## Common Mistakes

- Forgetting quotes: `<a href=https://example.com>` breaks on spaces.
- Misspelling attribute names (`scr` instead of `src`).
- Putting attributes on the closing tag — they only go on the opening tag.
- Confusing `class` (many) with `id` (one, unique).
- Using `style` for everything instead of classes (harder to maintain).
- Writing `checked="false"` expecting it to uncheck — presence is what matters.

## Try It Yourself

1. Add `title` to a link and hover to see the tooltip.
2. Give an image `alt` text and view it in DevTools.
3. Mark an input `required` and try to submit an empty form.
4. Give one element both `class` and `id` and inspect.
5. Try an unquoted attribute value with a space and observe the breakage.

## Summary

- Attribute syntax: `name="value"` inside the opening tag.
- Common: `href`, `src`, `alt`, `class`, `id`, `title`, `lang`.
- Boolean attributes need no value: `checked`, `disabled`, `required`.
- Always quote values; separate multiple attributes with spaces.
- `class` = reusable; `id` = unique.

## In Your Own Words

1. What is an attribute and where does it go?

<details>
<summary>Show Answer</summary>

**Sample Answer:** An attribute is extra information attached to an element that configures it (e.g., where a link points). It goes inside the opening tag, written as `name="value"` (e.g., `<a href="https://example.com">`). It never goes on the closing tag.

</details>

2. What is a boolean attribute?

<details>
<summary>Show Answer</summary>

**Sample Answer:** An attribute that is either on or off, where presence means true and absence means false. Examples: `checked`, `disabled`, `required`. No value is needed: `<input required>` is enough.

</details>

3. What is the difference between `class` and `id`?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `class` can be shared by many elements (reusable styling hook). `id` must be unique on the page (one element only) and is used for anchoring, scripting, and special styling. Use `class` for styling groups; `id` for unique targets.

</details>

## Cheat Sheet (Quick Recall)

**Syntax:** `<tag name="value">`. **Boolean:** `<input required>`. **Quote values always.**

**Common:** `href`, `src`, `alt`, `class`, `id`, `title`, `lang`, `style`.

**class** = many; **id** = one.
