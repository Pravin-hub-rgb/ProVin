# Doc 1.8 — Quotations

`1.7` covered inline formatting. Now quotations — quoting other sources. Connection: text formatting known; now how to mark text that came from someone else.

## Broader Goal

Learn the quotation tags and the abbreviation tag, and when to use each.

---

## Main Content

Quotations need their own tags so the browser and assistive tech know "this is someone else's words, not mine." The problem beginners create: they use `<blockquote>` for any indented text, or type quotation marks manually around `<q>` and get double quotes. First the long quote, then the inline quote, then citation and abbreviation.

**Blockquote (long quotation, block-level):**

```html
<blockquote cite="https://example.com/source">
  <p>To be or not to be, that is the question.</p>
</blockquote>
```

Line by line: `<blockquote>` is a block element, indented by default. The `cite` attribute holds the source URL (not shown to users). The quoted text sits inside, usually in a `<p>`.

**Inline quotation:**

```html
<p>He said <q>hello</q> and left.</p>
```

`<q>` is inline and the browser automatically adds quotation marks. Do not type quotes around it — you will get double quotes.

**Citing a work:**

```html
<p><cite>Hamlet</cite> by Shakespeare.</p>
```

`<cite>` marks the title of a creative work (book, article, song).

**Cite attribute vs cite element:** the `cite` *attribute* (on `<blockquote>`/`<q>`) holds the source URL silently — it is never shown. The `<cite>` *element* visibly names the work (book title, article) and usually renders in italics. They are separate tools: one records the URL invisibly, the other names the work visibly.

**Source link pattern:** to let readers actually visit the source, pair the quote with a visible link — `<blockquote>` with the quote, then a `<p>` with the author/work name inside an `<a href="...">`. The `cite` attribute alone is not clickable.

**Abbreviation:**

```html
<p><abbr title="HyperText Markup Language">HTML</abbr> is a markup language.</p>
```

Hovering shows the full form via the `title` attribute.

**Debugging scenarios:**

- "My quote shows double quotation marks" — you typed quotes around `<q>` text. Remove your manual quotes; the browser adds them.
- "My blockquote is not indented" — your CSS reset removed the default margin. Re-add margin or use CSS.
- "My abbreviation tooltip does not appear" — `title` is missing or misspelled. Add `title="..."`.
- "Screen reader reads my quote as my own words" — you used `<p>` instead of `<blockquote>`/`<q>`. Use the quote tags for quoted content.

## Common Mistakes

- Using `<blockquote>` for any indented text — it implies a quotation.
- Manually typing quotes around `<q>` text — the browser adds them, causing double quotes.
- Confusing `<cite>` (title of a work) with `<q>` (quoted text).
- Forgetting the `title` on `<abbr>`.
- Using `<cite>` to italicize any title instead of only creative works.

## Try It Yourself

1. Wrap a multi-sentence quote in `<blockquote>` with a `cite` URL.
2. Use `<q>` inside a sentence and inspect the auto-quotes in DevTools.
3. Add `<abbr title="...">` and hover to see the tooltip.
4. Mark a book title with `<cite>`.

## Summary

- `<blockquote>` = block quotation (long, indented).
- `<q>` = inline quotation (auto-quotes).
- `<cite>` = title of a work.
- `<abbr title="...">` = abbreviation with full form.
- Use these for semantic meaning, not for styling.

## In Your Own Words

1. What is the difference between `<blockquote>` and `<q>`?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `<blockquote>` is block-level for long quotations (indented by default, can contain paragraphs). `<q>` is inline for short quotations within a sentence, and the browser automatically adds quotation marks. Use `<blockquote>` for standalone quotes, `<q>` for inline ones.

</details>

2. What does `<abbr title="...">` do?

<details>
<summary>Show Answer</summary>

**Sample Answer:** It marks an abbreviation; the `title` attribute holds the full form, shown as a tooltip on hover. Example: `<abbr title="HyperText Markup Language">HTML</abbr>`.

</details>

3. Why use `<cite>` instead of just italicizing a title?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `<cite>` semantically marks the title of a creative work (book, article, song). It conveys meaning to screen readers and search engines, not just appearance. Styling (italics) can be added via CSS.

</details>

## Cheat Sheet (Quick Recall)

**`<blockquote>`** = block quote (long). **`<q>`** = inline quote (auto-quotes). **`<cite>`** = title of work. **`<abbr title>`** = abbreviation.

**Rule:** quote tags carry meaning, not just styling.
