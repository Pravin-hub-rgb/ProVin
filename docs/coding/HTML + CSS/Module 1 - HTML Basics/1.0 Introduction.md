# Doc 1.0 — Introduction

## Where We Are So Far

Module 0 is complete. You now know why the web exists (URL, HTTP, HTML, DNS), what HTML and CSS are (HTML = labeled content, CSS = look and layout), and how the browser turns files into a page (DOM, CSSOM, render tree, layout, paint, composite). You also know how to view and debug pages (DevTools, Live Server).

Module 1 begins here: HTML Basics. This is where you stop reading about HTML and start writing it. No CSS styling yet — that waits until Module 5. This module is about structure and meaning only.

## Broader Goal

The overall goal of Module 1 is to learn the structure and meaning of web content using HTML tags. By the end you should be able to build a complete, semantic HTML page from scratch — headings, paragraphs, links, images, lists, tables, code blocks, semantic layout, and special characters.

Current step: understand what this module covers and how to approach it, so you do not get lost in 24 lectures.

## Main Content

Picture a blank folder on your desktop. No `index.html`, no browser tab, no rendered page — just an empty directory. That is where every web project starts. The question is not "which tag first?" The question is "what does the path from empty folder to a real page look like?" This module is that path, one small step at a time.

**How this module is structured:**

- **One topic per lecture.** Each lecture covers one concept. Read it, try the code, move on.
- **Small examples first.** Every lecture starts with a minimal example, then builds up. You will see a two-line snippet before you see a full page.
- **No CSS styling yet.** This module is about structure and meaning. CSS comes in Module 5. If a tag looks plain, that is expected.
- **Hands-on from day one.** You will write HTML in `index.html` and open it in the browser from lecture 1.2 onward. Typing the code yourself matters — copy-paste hides typos that you need to learn to spot.

**What you will be able to do by the end of Module 1:**

- Write a complete HTML5 document from scratch, without copying a template.
- Use headings, paragraphs, links, images, lists, tables, and code blocks.
- Understand block vs inline elements and when to use each.
- Write semantic HTML (`header`, `nav`, `main`, `article`, `footer`).
- Handle special characters, entities, symbols, emojis, and charsets.
- Embed other pages with iframes.
- Understand URL encoding and the difference between HTML and XHTML.

**Prerequisites (from Module 0):**

- You know what HTML is (labeled content).
- You know what CSS is (look and layout).
- You know how the browser renders HTML (DOM, CSSOM, render tree).
- You know how to view and debug a page (DevTools, Live Server).

**How to approach this module:**

1. Read one lecture at a time — do not skim ahead.
2. Type the code examples yourself. If a tag does not render, that is the lesson.
3. Open the file in the browser and verify before moving on.
4. If something does not work, use DevTools (Elements, Network) to debug.
5. Move to the next lecture only when the current one makes sense.

## Common Mistakes

- Treating Module 1 as reading-only. The code only sticks when you type it and break it.
- Jumping to CSS questions before finishing HTML structure. Structure first, styling later.
- Skipping lectures because they "look simple." Small topics (comments, entities) cause big bugs when missed.
- Copy-pasting snippets without changing a value to see what breaks. Breaking things on purpose is how you learn the rules.
