# Doc 1.0 — Introduction

## Where We Are So Far

Module 0 is complete. You now know why the web exists (URL, HTTP, HTML, DNS), what HTML and CSS are (HTML = labeled content, CSS = look and layout), and how the browser turns files into a page (DOM, CSSOM, render tree, layout, paint, composite). You also know how to view and debug pages in the browser (DevTools, Live Server).

Now Module 1 begins: HTML Basics. This is where you stop reading about HTML and start writing it.

## Broader Goal

The overall goal of Module 1 is to learn the structure and meaning of web content using HTML tags. By the end you should be able to build a complete, semantic HTML page from scratch — headings, paragraphs, links, images, lists, tables, forms, and more.

Current step: understand what this module covers and how to approach it.

---

You have the foundation. You know what HTML is (labeled content) and how the browser reads it (the rendering pipeline). But knowing is not doing. Module 1 is where you start doing.

Think of Module 0 as learning how a car works (engine, wheels, fuel). Module 1 is getting behind the wheel and driving. You will write real HTML, open it in the browser, and see it on screen.

**How this module is structured:**

- **One topic per lecture.** Each lecture covers one concept (e.g., headings, links, images). Read it, try the code, move on.
- **Small examples first.** Every lecture starts with a minimal example, then builds up.
- **No CSS styling yet.** This module is about structure and meaning. CSS comes in Module 5.
- **Hands-on from day one.** You will write HTML in `index.html` and open it in the browser from lecture 1.2 onward.

**What you will be able to do by the end of Module 1:**

- Write a complete HTML5 document from scratch.
- Use headings, paragraphs, links, images, lists, tables, and forms.
- Understand block vs inline elements.
- Use classes and IDs for styling hooks.
- Write semantic HTML (header, nav, main, article, footer).
- Handle special characters, entities, and charsets.
- Embed media (images, audio, video, iframes).
- Follow a style guide and validate your HTML.

**Prerequisites (from Module 0):**

- You know what HTML is (labeled content).
- You know what CSS is (look and layout).
- You know how the browser renders HTML (DOM, CSSOM, render tree).
- You know how to view and debug a page (DevTools, Live Server).

**How to approach this module:**

1. Read one lecture at a time.
2. Type the code examples yourself (do not copy-paste).
3. Open the file in the browser and verify.
4. If something does not work, use DevTools (Elements, Network) to debug.
5. Move to the next lecture only when the current one makes sense.

**What comes after Module 1:**

- Module 2: HTML Forms (collecting user input).
- Module 3: HTML Graphics (Canvas, SVG).
- Module 4: HTML Media (audio, video, YouTube).
- Module 5: CSS Basics (styling and layout).
- Module 6: CSS Advanced (gradients, transforms, animations).
- Module 7: CSS Flexbox (modern 1D layout).
- Module 8: CSS Grid (modern 2D layout).
- Module 9: Project — Responsive Landing Page (combine everything).
