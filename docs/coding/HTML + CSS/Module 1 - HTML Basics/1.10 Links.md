## Main Content

A link is the web's core invention: text that points somewhere else. The tag is `<a>` (anchor), with `href` (hypertext reference) giving the destination. The first problem beginners create: they forget `href` and get a placeholder that does nothing. The second: they use wrong relative paths and get 404s.

Start from a page that needs to send the reader to another page. Guess: write `<a>About</a>`? That renders text but no link. Guess: add `href="about.html"`? That makes it clickable. The second guess is right — `href` is what makes an anchor a link.

**Basic link:**

```html
<a href="https://example.com">Visit Example</a>
```

Line by line: `<a>` is the anchor element. `href="https://example.com"` sets the destination URL. The text between the tags is what the user clicks.

**Linking to a local file (relative path):**

```html
<a href="pages/about.html">About</a>
<a href="./contact.html">Contact</a>
<a href="../index.html">Home</a>
```

Line by line: `pages/about.html` looks in a `pages` folder next to this file. `./contact.html` means the current folder explicitly. `../index.html` goes one folder up, then into `index.html`.

**Relative vs absolute paths:**

| Type | Example | When to use |
|---|---|---|
| Relative | `pages/about.html`, `./img.png`, `../index.html` | Your own files; keeps the site portable. |
| Absolute | `https://example.com/page`, `/images/logo.png` | External sites; or root-absolute within a deployed site. |

- `./` = current folder.
- `../` = one folder up.
- No prefix = relative to current folder.

**Opening in a new tab:**

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer">Open</a>
```

Line by line: `target="_blank"` opens a new tab. `rel="noopener noreferrer"` prevents the new tab from accessing your page (security) and avoids leaking referrer info (privacy). Never use `target="_blank"` without the `rel`.

**Anchor links (jump to a section on the same or another page):**

```html
<h2 id="introduction">Introduction</h2>
...
<a href="#introduction">Jump to intro</a>
```

Line by line: the `id` on the target element becomes the anchor. `href="#id"` scrolls to it. This is where IDs earn their keep in HTML basics: as anchor targets, not as styling hooks (CSS handles those later).

**Email and phone links:**

```html
<a href="mailto:hello@example.com">Email us</a>
<a href="tel:+1234567890">Call us</a>
```

`mailto:` opens the email client; `tel:` prompts a call on mobile. You can add a subject: `mailto:hello@example.com?subject=Hi`.

**Link to a file for download:**

```html
<a href="report.pdf" download>Download report</a>
```

The `download` attribute tells the browser to download instead of navigate.

**Debugging scenarios:**

- "My link does nothing" — `href` is missing. Add it.
- "I get a 404 on a local link" — the relative path is wrong. Count your `../` and check folder names; use DevTools Network tab to see the requested URL.
- "My new tab can access my page" — you used `target="_blank"` without `rel="noopener noreferrer"`. Add the rel.
- "My anchor link does not scroll" — the `id` does not exist or is misspelled. Match `href="#id"` to `id="id"` exactly.
- "My mailto link does not open email" — you forgot the colon (`mailto` instead of `mailto:`) or added spaces. Fix the scheme.

## Common Mistakes

- Forgetting `href` — the `<a>` becomes a placeholder, not a link.
- Using `target="_blank"` without `rel="noopener noreferrer"`.
- Broken relative paths (`../` one too many or too few).
- Anchors pointing to an `id` that does not exist — no scroll happens.
- Using `mailto:` without the colon or with spaces.
- Linking to a local file with an absolute path that only works on your machine.

## Try It Yourself

1. Create `index.html` and `about.html`; link between them with relative paths.
2. Add an `id` to a heading and an anchor link that jumps to it.
3. Create a `mailto:` and `tel:` link and test on mobile/with an email client.
4. Add a `target="_blank"` link and confirm the new tab opens.
5. Break a relative path on purpose and observe the 404 in the Network tab.

## Summary

- `<a href="...">` creates a hyperlink.
- `href` accepts URLs, relative paths, anchors (`#id`), `mailto:`, `tel:`, `download`.
- Relative (`./`, `../`) vs absolute (full URL or `/root`).
- `target="_blank"` + `rel="noopener noreferrer"` for new tabs.
- IDs serve as anchor targets for in-page navigation.

## In Your Own Words

1. What is the difference between a relative and an absolute path?

<details>
<summary>Show Answer</summary>

**Sample Answer:** A relative path is relative to the current file's location (e.g., `pages/about.html`, `./img.png`, `../index.html`) and keeps the site portable. An absolute path is a full URL (`https://example.com/page`) or root-absolute (`/images/logo.png`) and points to a fixed location. Use relative for your own files.

</details>

2. How do anchor links work?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Give the target element an `id` (e.g., `<h2 id="intro">`). Then link to it with `href="#intro"`. Clicking scrolls to that element. This works on the same page or across pages (append `#id` to a URL).

</details>

3. What do `mailto:` and `tel:` do?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `mailto:address` opens the user's email client to compose a message to that address. `tel:number` prompts a phone call on mobile devices (and may open a dialer on desktop). Add `?subject=...` to prefill an email subject.

</details>

4. Why add `rel="noopener noreferrer"` with `target="_blank"`?

<details>
<summary>Show Answer</summary>

**Sample Answer:** It prevents the newly opened tab from accessing your page via `window.opener` (security) and avoids leaking referrer info (privacy/performance). Without it, the new tab could manipulate your page or slow it down.

</details>

## Cheat Sheet (Quick Recall)

**`<a href>`** accepts: URL, relative path, `#anchor`, `mailto:`, `tel:`, `download`.

**Relative:** `./`, `../`, or bare. **Absolute:** full URL or `/root`.

**New tab:** `target="_blank" rel="noopener noreferrer"`.

**Anchor:** `id` on target + `href="#id"`.
