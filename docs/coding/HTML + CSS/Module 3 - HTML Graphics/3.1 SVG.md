# Doc 3.1 — SVG

## Cheat Sheet (Quick Recall)

- SVG = Scalable Vector Graphics.
- XML-based, resolution-independent.
- Inline in HTML: `<svg>...</svg>`.
- Shapes: `<circle>`, `<rect>`, `<path>`, `<line>`.
- Style with CSS.

## Main Content

### THINK

Canvas is bitmap (JS-drawn). SVG is vector (XML-based, scalable). First basic shapes, then styling, then inline vs external.

### CONCEPT

```html
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="blue" />
</svg>
```

- `<svg>` container.
- Shapes: `circle`, `rect`, `line`, `path`, `polygon`.
- Attributes: `cx`, `cy`, `r`, `fill`, `stroke`.
- Scalable without quality loss.

### CODE (gradual)

Stage 1 — Circle:

```html
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="red" />
</svg>
```

Stage 2 — Rectangle:

```html
<rect x="10" y="10" width="80" height="60" fill="green" />
```

Stage 3 — Path:

```html
<path d="M10 10 L90 90" stroke="black" />
```

## Common Mistakes

- Missing `width`/`height` on `<svg>`.
- Forgetting `fill`/`stroke`.
- Complex paths without tools (use editors).
