# Doc 2.3 — Input Types

## Cheat Sheet (Quick Recall)

- Text: `text`, `email`, `password`, `tel`, `url`, `search`.
- Numbers: `number`, `range`.
- Date/time: `date`, `time`, `datetime-local`, `month`, `week`.
- Choice: `checkbox`, `radio`, `color`, `file`.
- Other: `hidden`, `submit`, `reset`, `button`.

## Main Content

### THINK

`<input>` is versatile via the `type` attribute. First text inputs, then numbers/dates, then choices, then others.

### CONCEPT

```html
<input type="text" />
<input type="email" />
<input type="password" />
<input type="number" />
<input type="date" />
<input type="checkbox" />
<input type="radio" name="group" />
<input type="file" />
<input type="color" />
<input type="range" />
<input type="hidden" />
<input type="submit" />
```

- Text types trigger appropriate keyboards on mobile.
- `checkbox`/`radio` need `name` for grouping.
- `file` allows uploads.

### CODE (gradual)

Stage 1 — Text inputs:

```html
<input type="text" placeholder="Name" />
<input type="email" placeholder="Email" />
<input type="password" placeholder="Password" />
```

Stage 2 — Number/date:

```html
<input type="number" min="0" max="100" />
<input type="date" />
```

Stage 3 — Choice:

```html
<input type="checkbox" id="agree" />
<label for="agree">I agree</label>

<input type="radio" name="gender" value="m" /> Male
<input type="radio" name="gender" value="f" /> Female
```

## Common Mistakes

- Using `type="text"` for email (no validation).
- Radio buttons without shared `name`.
- Missing `value` on radio/checkbox.

## What It Is NOT

- ❌ `type="text"` is **not** for email validation.
- ❌ Radio without shared `name` is **not** a group.
- ❌ `file` input is **not** for text.
