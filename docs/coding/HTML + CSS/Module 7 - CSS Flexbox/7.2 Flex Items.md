# Doc 7.2 — Flex Items

## Cheat Sheet (Quick Recall)

- `flex-grow`: grow factor (0 = no grow).
- `flex-shrink`: shrink factor (1 = shrink).
- `flex-basis`: initial size.
- Shorthand: `flex: grow shrink basis;` (e.g., `flex: 1 1 200px`).
- `align-self`: override container's `align-items` for one item.
- `order`: visual order.

## Where We Are So Far

## Main Content

### THINK

Items inside a flex container can grow, shrink, and have initial size. First grow/shrink/basis, then shorthand, then align-self/order.

### CONCEPT

```css
.item {
  flex-grow: 1;      /* grow to fill space */
  flex-shrink: 1;    /* shrink if needed */
  flex-basis: 200px; /* initial size */
  /* shorthand: */
  flex: 1 1 200px;
  align-self: center; /* override container align-items */
  order: 2;          /* visual order */
}
```

- `flex-grow`: how much to grow (0 = no grow).
- `flex-shrink`: how much to shrink (0 = no shrink).
- `flex-basis`: initial size before grow/shrink.
- `flex: 1` = `flex: 1 1 0%` (grow, shrink, no basis).
- `align-self`: override cross-axis alignment for one item.
- `order`: visual order (default 0).

### CODE (gradual)

Stage 1 — Grow:

```css
.item { flex-grow: 1; }
```

Stage 2 — Shorthand:

```css
.item { flex: 1; } /* grow + shrink + 0 basis */
```

Stage 3 — Align-self:

```css
.item { align-self: flex-end; }
```

Stage 4 — Order:

```css
.item { order: 2; }
```

### TEST

Three questions:

1. What does `flex: 1` do? (grow + shrink, no basis)
2. What is `align-self`? (override cross-axis alignment for one item)
3. What is `order`? (visual order)

**Checkpoint:** Create items with different flex values and observe.

## Common Mistakes

- Using `flex: 1` on all items (equal width).
- Forgetting `flex-basis` when needed.
- `order` affecting accessibility (DOM order unchanged).

## Try It Yourself

1. Make one item grow twice as much (`flex: 2`).
2. Use `align-self` to override.
3. Reorder items with `order`.

## Summary

- `flex-grow`, `flex-shrink`, `flex-basis`, `flex` shorthand.
- `align-self`, `order`.

## What It Is NOT

- ❌ `flex: 1` is **not** just grow.
- ❌ `order` does **not** change DOM order.
- ❌ `align-self` is **not** `align-items`.
