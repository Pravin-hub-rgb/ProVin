# Doc 6.2 — Backgrounds

## Cheat Sheet (Quick Recall)

- Multiple backgrounds: comma-separated.
- `background-clip`: border-box/content-box/padding-box/text.
- `background-origin`: border-box/padding-box/content-box.
- Layered backgrounds (image + gradient).

### CONCEPT

**Multiple backgrounds:**

```css
div {
  background:
    url("top.png") no-repeat top,
    url("bottom.png") no-repeat bottom,
    #f0f0f0;
}
```

**background-clip:**

```css
div { background-clip: text; color: transparent; } /* text gradient */
```

**background-origin:**

```css
div { background-origin: content-box; }
```

### CODE (gradual)

Stage 1 — Multiple:

```css
div {
  background: url("a.png") top, url("b.png") bottom, white;
}
```

Stage 2 — Clip (text):

```css
h1 {
  background: linear-gradient(to right, red, blue);
  background-clip: text;
  color: transparent;
}
```

Stage 3 — Origin:

```css
div { background-origin: padding-box; }
```

## Common Mistakes

- Wrong order in multiple backgrounds (top first).
- Forgetting `color: transparent` for text clip.
- Confusing clip and origin.

## What It Is NOT

- ❌ Multiple backgrounds are **not** layers in z-index.
- ❌ `background-clip: text` needs `color: transparent`.
- ❌ Origin is **not** clip.
