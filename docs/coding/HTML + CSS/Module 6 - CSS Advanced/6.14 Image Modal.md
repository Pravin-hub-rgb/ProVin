# Doc 6.14 — Image Modal

## Cheat Sheet (Quick Recall)

- Modal: hidden overlay shown on click.
- CSS-only: `:target` pseudo-class.
- JS for click toggle (accessibility).
- Position `fixed`, center with flexbox.

## Main Content

### THINK

A modal shows a larger image on click. First CSS-only with `:target`, then JS toggle, then centering.

### CONCEPT

**CSS-only (using `:target`):**

```html
<a href="#modal">Open</a>
<div id="modal" class="modal">
  <a href="#" class="close">&times;</a>
  <img src="large.jpg" />
</div>
```

```css
.modal { display: none; position: fixed; top: 0; left: 0; width: 100%; height: 100%; background: rgba(0,0,0,0.8); }
.modal:target { display: flex; justify-content: center; align-items: center; }
```

- `:target` matches when URL hash matches id.
- `position: fixed` covers screen.
- Flexbox centers content.

### CODE (gradual)

Stage 1 — Hidden modal:

```css
.modal { display: none; }
```

Stage 2 — Show on target:

```css
.modal:target { display: flex; }
```

Stage 3 — Full styling:

```css
.modal { position: fixed; top: 0; left: 0; width: 100%; height: 100%; background: rgba(0,0,0,0.8); }
.modal:target { display: flex; justify-content: center; align-items: center; }
```

## Common Mistakes

- Using `:target` for production (accessibility issues).
- Not providing close button.
- Fixed dimensions not responsive.

## What It Is NOT

- ❌ CSS-only modal is **not** accessible.
- ❌ `:target` is **not** for production modals (use JS).
- ❌ Modal is **not** just `display: block`.
