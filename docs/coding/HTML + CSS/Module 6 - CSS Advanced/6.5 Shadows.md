# Doc 6.5 — Shadows

## Cheat Sheet (Quick Recall)

- `box-shadow: x y blur spread color;`.
- `text-shadow: x y blur color;`.
- Multiple shadows: comma-separated.
- `inset` for inner shadow.

## Main Content

### THINK

Shadows add depth. First box-shadow, then text-shadow, then multiple/inset.

### CONCEPT

```css
div {
  box-shadow: 2px 2px 4px 0 rgba(0,0,0,0.3);
  box-shadow: inset 0 0 5px black;
}
p {
  text-shadow: 1px 1px 2px gray;
}
```

- `box-shadow`: x, y, blur, spread, color.
- `text-shadow`: x, y, blur, color.
- Multiple: comma-separated.
- `inset`: inner shadow.

### CODE (gradual)

Stage 1 — Basic box-shadow:

```css
div { box-shadow: 2px 2px 4px black; }
```

Stage 2 — With spread:

```css
div { box-shadow: 2px 2px 4px 2px rgba(0,0,0,0.3); }
```

Stage 3 — Inset:

```css
div { box-shadow: inset 0 0 5px black; }
```

Stage 4 — Text shadow:

```css
p { text-shadow: 1px 1px 2px gray; }
```

- Too much blur (muddy).
- Forgetting fallback (no shadow in some browsers).

## What It Is NOT

- ❌ `box-shadow` is **not** `text-shadow`.
- ❌ `inset` is **not** default.
- ❌ Multiple shadows are **not** layers in z-index.
