# Doc 6.8 — 2D Transforms

## Cheat Sheet (Quick Recall)

- `transform: translate(x, y)` — move.
- `transform: rotate(deg)` — rotate.
- `transform: scale(x, y)` — scale.
- `transform: skew(x, y)` — skew.
- Combine: `transform: translate() rotate() scale();`.

## Main Content

### THINK

Transforms change an element's shape/position without affecting layout. First translate (move), then rotate, then scale, then skew, then combine.

### CONCEPT

```css
div {
  transform: translate(50px, 20px);
  transform: rotate(45deg);
  transform: scale(1.5);
  transform: skew(10deg, 5deg);
  transform: translate(50px) rotate(45deg) scale(1.5);
}
```

- `translate(x, y)`: move.
- `rotate(deg)`: rotate.
- `scale(x, y)`: scale (1 = original).
- `skew(x, y)`: skew.
- Multiple: space-separated.

### CODE (gradual)

Stage 1 — Translate:

```css
div { transform: translate(50px, 20px); }
```

Stage 2 — Rotate:

```css
div { transform: rotate(45deg); }
```

Stage 3 — Scale:

```css
div { transform: scale(1.5); }
```

Stage 4 — Combine:

```css
div { transform: translate(50px) rotate(45deg) scale(1.2); }
```

### TEST

**Checkpoint:** Apply translate, rotate, scale, and combine.

## Common Mistakes

- Using separate `transform` properties (overwrites).
- Forgetting `transform-origin`.
- Not using `transition` for smooth animation.

## Try It Yourself

## Summary

- `translate`, `rotate`, `scale`, `skew`.
- Combine in one `transform` property (space-separated).

## What It Is NOT

- ❌ Multiple `transform` properties **overwrite** (use one).
- ❌ Transforms do **not** affect layout (no reflow).
- ❌ `scale(0)` makes element **invisible**.
