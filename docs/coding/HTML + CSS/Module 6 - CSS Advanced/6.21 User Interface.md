# Doc 6.21 — User Interface

## Cheat Sheet (Quick Recall)

- `resize: both/none/horizontal/vertical` — resizable element.
- `caret-color`: color of text cursor.
- `user-select: none` — prevent text selection.
- `pointer-events: none` — ignore mouse events.

## Main Content

### THINK

CSS has properties for UI behavior: resizable elements, caret color, text selection, pointer events. First resize, then caret-color, then user-select, then pointer-events.

### CONCEPT

```css
textarea { resize: vertical; }
input { caret-color: red; }
.no-select { user-select: none; }
.overlay { pointer-events: none; }
```

- `resize`: allows resizing (none, both, horizontal, vertical).
- `caret-color`: color of the text cursor.
- `user-select`: control text selection.
- `pointer-events`: control mouse interaction.

### CODE (gradual)

Stage 1 — Resize:

Stage 2 — Caret color:


Stage 3 — No select:



## Common Mistakes

- `resize` without `overflow: auto` (no scrollbar).
- `pointer-events: none` making element unclickable (intended).
- `user-select: none` hurting accessibility.

## What It Is NOT

- ❌ `resize` is **not** automatic (user drags).
- ❌ `pointer-events: none` is **not** `visibility: hidden`.
- ❌ `user-select: none` is **not** for accessibility.
