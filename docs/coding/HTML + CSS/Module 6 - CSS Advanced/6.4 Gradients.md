# Doc 6.4 — Gradients

## Cheat Sheet (Quick Recall)

- `linear-gradient(direction, color1, color2)`.
- `radial-gradient(shape, color1, color2)`.
- `conic-gradient(from angle, colors)`.
- Multiple color stops: `red 0%, blue 50%, green 100%`.

## Main Content

### THINK

Gradients create smooth color transitions. First linear (direction), then radial (shape), then conic (angle).

### CONCEPT

```css
div {
  background: linear-gradient(to right, red, blue);
  background: radial-gradient(circle, red, blue);
  background: conic-gradient(from 0deg, red, blue, green);
}
```

- `linear-gradient`: straight line (to right, 45deg, etc.).
- `radial-gradient`: from center outward (circle/ellipse).
- `conic-gradient`: around a center point (pie chart).
- Color stops: `red 0%, blue 50%, green 100%`.

### CODE (gradual)

Stage 1 — Linear:

```css
div { background: linear-gradient(to right, red, blue); }
```

Stage 2 — Radial:

```css
div { background: radial-gradient(circle, red, blue); }
```

Stage 3 — Conic:

```css
div { background: conic-gradient(from 0deg, red, blue, green); }
```

## Common Mistakes

- Missing direction (defaults to top-to-bottom).
- No fallback color (accessibility).
- Hard color stops (use percentages).

## What It Is NOT

- ❌ Gradients are **not** images.
