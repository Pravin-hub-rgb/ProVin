# Doc 6.3 — Colors

## Cheat Sheet (Quick Recall)

- Modern color functions: `rgb()`, `hsl()`, `hwb()`, `lab()`, `lch()`, `oklch()`.
- Relative color syntax: `rgb(from red r g b / 0.5)`.
- Color spaces: sRGB, Display P3.
- `color-mix()` to blend colors.

## Main Content

### THINK

Basic colors (names, HEX, RGB, HSL) are known. Now modern functions: `hwb`, `lab`, `lch`, `oklch`, `color-mix`. First `hwb`/`lab`/`lch`, then `color-mix`, then relative color syntax.

### CONCEPT

```css
div {
  color: hwb(0 0% 0%);        /* hue, whiteness, blackness */
  color: lab(50% 0 0);         /* lightness, a, b */
  color: lch(50% 0 0);         /* lightness, chroma, hue */
  color: oklch(0.5 0.1 0);    /* perceptual */
  color: color-mix(in srgb, red, blue); /* blend */
}
```

- `hwb`: hue, whiteness, blackness.
- `lab`/`lch`: perceptual color spaces.
- `oklch`: better perceptual uniformity.
- `color-mix()`: blend two colors.

### CODE (gradual)

Stage 1 — hwb:

```css
div { color: hwb(0 0% 0%); }
```

Stage 2 — color-mix:

```css
div { color: color-mix(in srgb, red 50%, blue 50%); }
```

Stage 3 — oklch:

```css
div { color: oklch(0.5 0.1 0); }
```
