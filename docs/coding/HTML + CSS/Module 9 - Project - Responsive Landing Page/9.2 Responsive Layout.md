# Doc 9.2 — Responsive Layout

## Cheat Sheet (Quick Recall)

- Media queries for larger screens.
- Flexbox/grid for layout.
- Viewport meta essential.

## Main Content

### THINK

The page is styled but may not adapt to mobile. Make it responsive: viewport meta, mobile-first, media queries, flexible layout.

### CONCEPT

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

```css
/* Mobile-first base */
.hero { padding: 32px 16px; }
.features { grid-template-columns: 1fr; }

/* Tablet */
@media (min-width: 768px) {
  .features { grid-template-columns: repeat(2, 1fr); }
}

/* Desktop */
@media (min-width: 1024px) {
  .features { grid-template-columns: repeat(3, 1fr); }
  .hero { padding: 64px 16px; }
}
```

### CODE (gradual)

Stage 1 — Viewport meta:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

Stage 2 — Mobile-first base:

Stage 3 — Media queries:

```css
@media (min-width: 768px) { .features { grid-template-columns: repeat(2, 1fr); } }
@media (min-width: 1024px) { .features { grid-template-columns: repeat(3, 1fr); } }
```

## Common Mistakes

- Missing viewport meta.
- Desktop-first (max-width).
- Fixed widths.
