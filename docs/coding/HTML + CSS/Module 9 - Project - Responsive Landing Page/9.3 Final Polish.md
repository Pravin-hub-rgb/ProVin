### THINK

The page is responsive. Now polish: accessibility, performance, SEO, testing. First accessibility, then performance, then SEO, then testing.

### CONCEPT

**Accessibility:**

- Alt text on images.
- Semantic HTML.
- Focus outlines (`:focus`).
- Sufficient color contrast.

**Performance:**

- Compress images (WebP).
- Minify CSS.
- Avoid large files.

**SEO:**

- `<title>`, `<meta name="description">`.
- Semantic tags.
- Heading hierarchy.

**Testing:**

- Test on mobile devices.
- Cross-browser (Chrome, Safari, Firefox).
- Lighthouse audit.

### CODE (gradual)

Stage 1 — Accessibility:

```html
<img src="photo.jpg" alt="Description" />
```

Stage 2 — SEO meta:


Run Lighthouse in Chrome DevTools.
