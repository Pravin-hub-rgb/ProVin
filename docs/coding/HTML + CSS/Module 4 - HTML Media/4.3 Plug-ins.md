# Doc 4.3 — Plug-ins

## Cheat Sheet (Quick Recall)

- `<object>` and `<embed>` for external content/plug-ins.
- Largely obsolete (Flash, Java applets).
- Modern alternative: `<iframe>` or native HTML (audio/video/canvas).
- `data` attribute for `<object>`.

## Main Content

### THINK

Plug-ins (Flash, Java) are largely obsolete. Modern HTML uses native tags. But `<object>`/`<embed>` still exist. First what they are, then why obsolete, then modern alternatives.

### CONCEPT

```html
<object data="file.pdf" type="application/pdf" width="600" height="400">
  <p>PDF not supported.</p>
</object>

<embed src="file.swf" type="application/x-shockwave-flash" />
```

- `<object>`: embeds external resource with fallback.
- `<embed>`: simpler, no fallback.

**Modern alternatives:**

- Video: `<video>` instead of Flash.
- Audio: `<audio>`.
- Graphics: `<canvas>`/SVG.
- PDF: `<iframe>` or `<a>` download.

### CODE (gradual)

Stage 1 — Object:

```html
<object data="doc.pdf" type="application/pdf" width="600" height="400">
  <p>Cannot display PDF.</p>
</object>
```

Stage 2 — Embed:

```html
<embed src="doc.pdf" type="application/pdf" />
```

Stage 3 — Modern (iframe):

```html
<iframe src="doc.pdf" width="600" height="400"></iframe>
```

### TEST

Three questions:

1. Tag for embedding with fallback? (`<object>`)
2. Simpler embed tag? (`<embed>`)
3. Modern alternative for PDF? (`<iframe>` or `<a>`)

**Checkpoint:** Compare `<object>` and `<iframe>` for embedding a PDF.

## Common Mistakes

- Using Flash/Java plug-ins (obsolete).
- Missing fallback content.
- Wrong MIME type.
