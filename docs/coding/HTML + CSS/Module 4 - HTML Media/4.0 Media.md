# Doc 4.0 — Media

## Cheat Sheet (Quick Recall)

- `<audio>` and `<video>` for media.
- `controls` attribute shows play/pause.
- `src` or `<source>` for file.
- Formats: MP3, WAV, OGG (audio); MP4, WebM, OGG (video).

## Main Content

### THINK

Media (audio/video) is common on the web. HTML has `<audio>` and `<video>` tags. First basic audio, then video, then formats.

### CONCEPT

```html
<audio controls>
  <source src="audio.mp3" type="audio/mpeg" />
  Your browser does not support audio.
</audio>

<video controls width="640">
  <source src="video.mp4" type="video/mp4" />
  Your browser does not support video.
</video>
```

- `controls` shows play/pause/volume.
- `<source>` allows multiple formats (browser picks supported).
- Fallback text for unsupported browsers.

### CODE (gradual)

Stage 1 — Audio:

```html
<audio controls src="audio.mp3"></audio>
```

Stage 2 — Video:

```html
<video controls width="640" src="video.mp4"></video>
```

Stage 3 — Multiple sources:

```html
<video controls>
  <source src="video.mp4" type="video/mp4" />
  <source src="video.webm" type="video/webm" />
</video>
```

## Common Mistakes

- Missing `controls` (no UI).
- Wrong MIME type in `<source>`.
- Large files without compression.

## What It Is NOT

- ❌ Media without `controls` has **no UI**.
- ❌ `<source>` order matters (browser picks first supported).
- ❌ Large media is **not** auto-compressed.
