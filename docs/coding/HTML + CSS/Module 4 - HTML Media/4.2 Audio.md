# Doc 4.2 — Audio

## Cheat Sheet (Quick Recall)

- `<audio controls src="audio.mp3"></audio>`.
- Attributes: `controls`, `autoplay`, `muted`, `loop`, `preload`.
- Multiple `<source>` for format fallback.
- No visual by default (use controls).

## Main Content

### THINK

Audio is simpler than video (no visual). First basic audio, then attributes, then multiple sources.

### CONCEPT

```html
<audio controls>
  <source src="audio.mp3" type="audio/mpeg" />
  <source src="audio.ogg" type="audio/ogg" />
  Your browser does not support audio.
</audio>
```

- `controls`: play/pause/volume.
- `autoplay`, `muted`, `loop`.
- `preload`: `none`, `metadata`, `auto`.

### CODE (gradual)

Stage 1 — Basic audio:

```html
<audio controls src="audio.mp3"></audio>
```

Stage 2 — Multiple sources:

```html
<audio controls>
  <source src="audio.mp3" type="audio/mpeg" />
  <source src="audio.ogg" type="audio/ogg" />
</audio>
```

Stage 3 — With preload:

```html
<audio controls preload="metadata" src="audio.mp3"></audio>
```

### TEST

Three questions:

1. Tag for audio? (`<audio>`)
2. What attribute shows controls? (`controls`)
3. What does `preload="metadata"` do? (loads only metadata)

**Checkpoint:** Embed an audio file with controls.

## Common Mistakes

- Missing `controls` (no UI).
- Wrong MIME type.
- Large files without compression.

## What It Is NOT

- ❌ `<audio>` without `controls` has **no UI**.
- ❌ `preload="auto"` is **not** always best (bandwidth).
- ❌ Audio is **not** video.
