# Doc 4.4 — YouTube Embedding

## Cheat Sheet (Quick Recall)

- Use `<iframe>` with YouTube embed URL.
- URL format: `https://www.youtube.com/embed/VIDEO_ID`.
- Attributes: `width`, `height`, `allow`, `allowfullscreen`.
- Responsive: wrap in container with aspect ratio.

## Main Content

### THINK

Embedding YouTube videos is common. Use an `<iframe>` with the embed URL. First basic embed, then attributes, then responsive wrapper.

### CONCEPT

```html
<iframe
  width="560"
  height="315"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="YouTube video player"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen>
</iframe>
```

- URL: `https://www.youtube.com/embed/VIDEO_ID`.
- `allowfullscreen` enables fullscreen.
- `allow` specifies permissions.

**Responsive wrapper:**

```html
<div style="position: relative; padding-bottom: 56.25%; height: 0;">
  <iframe style="position: absolute; top: 0; left: 0; width: 100%; height: 100%;" src="..." ></iframe>
</div>
```

### CODE (gradual)

Stage 1 — Basic embed:

```html
<iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ" width="560" height="315"></iframe>
```

Stage 2 — With attributes:

```html
<iframe src="..." title="Video" allowfullscreen></iframe>
```

Stage 3 — Responsive:

```html
<div class="video-container">
  <iframe src="..." allowfullscreen></iframe>
</div>
```

```css
.video-container { position: relative; padding-bottom: 56.25%; height: 0; }
.video-container iframe { position: absolute; top: 0; left: 0; width: 100%; height: 100%; }
```

## Common Mistakes

- Using watch URL instead of embed URL.
- Missing `title` (accessibility).
- Fixed dimensions (not responsive).
