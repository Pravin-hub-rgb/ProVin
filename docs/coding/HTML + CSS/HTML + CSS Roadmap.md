# HTML + CSS Roadmap

Vin's personal roadmap for learning HTML and CSS, one topic per lecture, ending with a responsive landing page project.

## The Goal

Learn HTML structure and CSS styling well enough to build and style real web pages, then combine both into a responsive landing page.

## Setup and Tools

- **Editor:** VS Code.
- **Preview:** any modern browser (Chrome/Edge/Firefox).
- **No install needed:** HTML and CSS run directly in the browser.
- **Styling approach:** plain CSS first; understand the fundamentals before frameworks.

## Mental Model

- HTML gives the page **structure and meaning** (headings, paragraphs, links, forms, media).
- CSS gives the page **look and layout** (colors, spacing, typography, flexbox, grid, responsive design).
- HTML is the content; CSS is the presentation. Keep them separate where possible.

## What Carries Over

HTML and CSS are the foundation of the web. React, Next.js, and every frontend framework ultimately render HTML and style it with CSS. Understanding the basics here makes later frameworks feel like tools on top of known building blocks.
