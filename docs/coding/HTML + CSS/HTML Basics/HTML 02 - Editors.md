- Any text editor can write HTML.

- Save files with `.html` extension.

## Main Content

### THINK

HTML is just text. You can write it in Notepad, but a good editor makes life easier. VS Code is the standard. First install VS Code, then add useful extensions, then create and save an `.html` file.

### CONCEPT

**Recommended editor:** VS Code (free, cross-platform).

**Useful extensions:**

- **Live Server** — auto-refresh browser on save.
- **Prettier** — auto-format code.
- **HTML CSS Support** — autocomplete CSS class names.

**Creating a file:**

1. Open VS Code.
2. Create a new file.
3. Save as `index.html`.
4. Write HTML.
5. Open with Live Server.

### CODE (gradual)

Stage 1 — Create file:

```text
File → New File → Save As → index.html
```

Stage 2 — Write minimal HTML:

```html
<!DOCTYPE html>
<html>
  <head><title>Test</title></head>
  <body><h1>Hello</h1></body>
</html>
```

Stage 3 — Run with Live Server:

Right-click `index.html` → "Open with Live Server".

### TEST

Three questions:

1. What editor is recommended? (VS Code)
2. What extension auto-refreshes the browser? (Live Server)
3. What file extension for HTML? (`.html`)

**Checkpoint:** Install VS Code + Live Server, create `index.html`, run it.

## Common Mistakes

- Saving as `.txt` instead of `.html`.
- Not installing Live Server and manually refreshing.
- Editing in the wrong folder.

## Try It Yourself

1. Install VS Code and Live Server.
2. Create and run `index.html`.
3. Format code with Prettier.

## Summary

- VS Code is the recommended editor.
- Live Server auto-refreshes on save.
- Save files with `.html`.
