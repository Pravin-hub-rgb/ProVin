In the last chapter, we learned formatting — bold, headings, lists, alignment. Now let's learn **tables**. Tables are used everywhere in office documents — marksheets, schedules, price lists, attendance records. In this chapter, we'll learn how to create, edit, and design tables. In the next chapter, we'll complete the document with page layout, headers, and PDF export.


### Inserting a Table

**Method 1 — Grid (for small tables):**
1. Go to **Insert → Table**
2. Hover over the grid to select how many rows and columns you want
3. Click — the table appears

**Method 2 — Exact numbers (for larger tables):**
1. Go to **Insert → Table → Insert Table**
2. Enter the exact number of columns and rows
3. Click OK

> **💡 Tip:** A marksheet usually has columns like Roll No, Name, Subject 1, Subject 2, Subject 3, Total. Plan your columns before inserting.

---

### Navigating and Entering Data

| Key | Action |
|---|---|
| **Click** | Select a cell |
| **Tab** | Move to the next cell (right) |
| **Shift+Tab** | Move to the previous cell (left) |
| **Arrow keys** | Move between cells in any direction |
| **Enter** | Add a new line within the same cell (for multi-line content) |

> **💡 Tip:** After entering data in the last cell, pressing **Tab** adds a new row automatically — very useful for adding entries quickly.

---

### Adding and Deleting Rows/Columns

**Add a row:**
  - Right-click on a cell → **Insert** → Insert Rows Above / Below
  - Or click in the last cell of the last row and press **Tab**

**Add a column:**
  - Right-click on a cell → **Insert** → Insert Columns Left / Right

**Delete a row or column:**
  - Select the row/column → Right-click → **Delete Cells** → Delete entire row / column

**Merge cells (combine two or more cells into one):**
  - Select the cells → Right-click → **Merge Cells**
  - Useful for creating a title row that spans across all columns

---

### Designing the Table

Once your table has data, you can make it look professional:

| Feature | How to Access | When to Use |
|---|---|---|
| **Table Styles** | Click the table → **Table Design** tab → choose a style | One-click professional look |
| **Header Row** | Table Design → Header Row checkbox | Makes the first row bold with different background |
| **Borders** | Home → Borders dropdown | Add or remove borders around cells |
| **Shading** | Table Design → Shading | Add background color to cells or rows |
| **Bold header** | Select header row → `Ctrl+B` | Emphasize column titles |
| **Center align** | Select cells → `Ctrl+E` | Center text in cells (like numbers) |

> **⚠️ Common mistake:** Don't use spaces or Tab to create fake tables — use the actual Table tool. Fake tables break when you edit text.

---

### 🧠 Chapter Summary

> ✅ **Insert a table:** Insert → Table → choose rows and columns  
> ✅ **Navigate:** Tab (next cell), Enter (new line in same cell)  
> ✅ **Add rows:** Right-click → Insert → Rows Above/Below or Tab in last cell  
> ✅ **Merge cells:** Select → Right-click → Merge Cells  
> ✅ **Design:** Use Table Styles for a one-click professional look  
> ✅ **Plan your columns before inserting the table**
