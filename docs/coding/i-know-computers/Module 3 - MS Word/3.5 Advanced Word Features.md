### 📨 Mail Merge — One Letter to Many People

  Imagine you need to send a letter to 50 parents about the annual parent-teacher meeting. Each letter needs the parent's name, student's name, and class. Do you write 50 separate letters? No — you use **Mail Merge**.

  **How Mail Merge works:**
  You create two things:
  1. A **main document** — the letter template with placeholders like `<<Name>>`, `<<Student>>`, `<<Class>>`
  2. A **data source** — an Excel or Word table with the actual information

  Word combines them and creates one personalized letter per row.

  **Step-by-step Mail Merge:**

  **Step 1 — Prepare your data in Excel:**
  Create an Excel file with a header row and one row per person:

  | Name | Student | Class | Fee |
  |---|---|---|---|
  | Mr. Sharma | Rahul | 10A | 5000 |
  | Mrs. Patel | Priya | 9B | 4500 |
  | Mr. Singh | Aman | 8C | 4200 |

  Save the Excel file.

  **Step 2 — Create the main letter in Word:**
  Write your letter normally, leaving blank spaces where personalized information goes.

  **Step 3 — Start Mail Merge:**
  1. Go to **Mailings → Start Mail Merge → Letters**
  2. **Select Recipients → Use an Existing List** → browse to your Excel file
  3. Select the sheet (e.g., Sheet1) → OK

  **Step 4 — Insert merge fields:**
  1. Place your cursor where the name should go
  2. Click **Mailings → Insert Merge Field** → choose "Name"
  3. Repeat for Student, Class, Fee

  Your letter now looks like:
  ```
  Dear <<Name>>,

  This is regarding <<Student>> of class <<Class>>. The pending fee of Rs. <<Fee>> is due.
  ```

  **Step 5 — Preview and finish:**
  1. Click **Mailings → Preview Results** — you see the first letter with real data
  2. Use the arrow buttons to preview each letter
  3. Click **Finish & Merge → Print Documents** (to print) or **Edit Individual Documents** (to create a new Word file with all letters)

  > **💡 Pro tip:** Always preview a few letters before printing. Check that names, genders, and formatting look correct.

  > **⚠️ What Mail Merge is NOT:** Mail Merge does NOT send emails. It creates printed letters or a Word document. For email blasts, you need a different tool (like Gmail's mail merge or a CRM system).

### ✏️ Track Changes — See What Changed

  When multiple people work on the same document, you need to know who changed what. **Track Changes** records every edit — insertions, deletions, formatting changes — with the author's name.

  **Turning on Track Changes:**
  - Go to **Review → Track Changes** (or press `Ctrl+Shift+E`)
  - Everything you now do (type, delete, format) is recorded with a colored marker

  **What Track Changes looks like:**
  - **Inserted text:** Underlined in color (usually blue or red)
  - **Deleted text:** Strikethrough in color — shown in a balloon on the right side
  - **Changed formatting:** Shown in the margin
  - Each change shows the author's name and timestamp when you hover over it

  **Accepting or rejecting changes:**
  - **Review → Accept** — keeps the change and removes the markup
  - **Review → Reject** — removes the change, restores original text
  - **Accept All Changes** — accepts everything at once (when you're done reviewing)
  - **Reject All Changes** — removes all changes

  **Comments:**
  - **Review → New Comment** — add a note without changing the text
  - Useful for asking questions: "Should this number be updated?"
  - Right-click a comment → Delete Comment to remove it

  **When to use Track Changes:**
  - Your manager edits a report — you can see exactly what they changed
  - Reviewing a colleague's document — you suggest edits without permanently changing their text
  - Final approval process — the manager accepts changes one by one

  > **⚠️ Always turn OFF Track Changes before making final edits.** If Track Changes is on, even your corrections are recorded as changes, and the document looks messy.

### 📑 Table of Contents — Auto-Generated Index

  A Table of Contents (TOC) at the beginning of a report tells readers what's inside and which page to find it on. The best part — **Word builds it automatically** from your headings.

  **Why use a TOC:**
  - Looks professional — all reports and books have one
  - Saves readers time — they jump directly to the section they need
  - Updates automatically — if you add or remove content, just click "Update Table"

  **Step-by-step TOC:**

  **Step 1 — Use Heading Styles:**
  This is the most important rule. Word can only create a TOC from **Heading Styles** (Heading 1, Heading 2, Heading 3). If you just made text big and bold, Word won't see it as a heading.

  Select each section title → apply **Heading 1**, **Heading 2**, or **Heading 3** from the Home tab → Styles.

  **Step 2 — Insert the TOC:**
  1. Click at the beginning of your document (first page — leave a blank page for the TOC)
  2. Go to **References → Table of Contents**
  3. Choose a style (Automatic Table 1 and Automatic Table 2 are the most common)

  Word scans your document, finds all headings, and builds a table with page numbers.

  **Step 3 — Update the TOC:**
  Whenever you add, remove, or move content, the page numbers change. Update the TOC:
  1. Click anywhere in the TOC
  2. Click **Update Table** (or press F9)
  3. Choose: **Update page numbers only** (if you just moved content) or **Update entire table** (if you added/removed headings)

  > **💡 Keyboard shortcut for update:** Click the TOC → press **F9** → choose update option.

  > **⚠️ What a TOC is NOT:** The TOC is NOT static. It's a live field that updates. If you type page numbers manually, they'll be wrong as soon as you edit the document. Always let Word generate it automatically.

### 🎯 Real Task

1. **Mail Merge practice:** Open Excel and create a table with 5 rows: Name, City, Event (e.g., Annual Day). Save as `Event_Data.xlsx`. Open Word and write: "Dear <<Name>>, You are invited to our <<Event>> in <<City>>." Complete the mail merge and generate the combined document.
2. **Track Changes practice:** Open any document you created earlier. Turn on Track Changes (`Ctrl+Shift+E`). Make 5 edits — change some words, delete a sentence, add a new paragraph. Now go through and accept or reject each change.
3. **TOC practice:** Open the business letter you wrote in the last chapter. Apply Heading 1 to the title, Heading 2 to section headers. Go to References → Table of Contents → insert an automatic table. Add a new section, then update the TOC (F9 → Update entire table).
