In the last chapter, we learned how to type and save a document. But a plain document doesn't look professional — you need **formatting**. Formatting means changing how text looks — bold, italic, headings, alignment, spacing. In this chapter, we'll learn all the formatting tools. In the next chapter, we'll add tables.


### Text Formatting — Home Tab

The **Home tab** on the ribbon has all the basic formatting tools. Here are the most common ones:

| Option | Shortcut | What It Does |
|---|---|---|
| **Bold** | `Ctrl+B` | Makes text thick and dark |
| **Italic** | `Ctrl+I` | Makes text slanted |
| **Underline** | `Ctrl+U` | Adds a line under text |
| **Font Size** | `Ctrl+Shift+>` / `<` | Increase / decrease text size |
| **Font Color** | Home → Font Color (A with underline) | Change text color |
| **Highlight** | Home → Text Highlight Color | Add background color to text (like a marker) |
| **Align Left** | `Ctrl+L` | Text lines up on the left |
| **Center** | `Ctrl+E` | Text is centered |
| **Align Right** | `Ctrl+R` | Text lines up on the right |
| **Justify** | `Ctrl+J` | Text lines up on both left and right (looks neat) |

> **💡 Tip:** To apply formatting to existing text, first **select the text** (click and drag over it), then click the formatting option. Or select the text and use the shortcut.

### Headings and Styles

The professional way to structure a document is using **Styles** — not just making text bigger manually.

**Why use styles instead of just increasing font size?**
  - Styles create a consistent look throughout the document
  - You can generate a **Table of Contents** automatically from headings
  - The document looks professional and is easy to navigate

| Style | When to Use | Shortcut |
|---|---|---|
| **Heading 1** | Main title of your document | `Ctrl+Alt+1` |
| **Heading 2** | Major sections | `Ctrl+Alt+2` |
| **Heading 3** | Sub-sections within a major section | `Ctrl+Alt+3` |
| **Normal** | Regular body text | `Ctrl+Shift+N` |

> **⚠️ Common mistake:** Don't just make text big and bold and call it a heading. Use the actual Heading styles. Otherwise, Word doesn't know it's a heading, and you can't create a Table of Contents.

### Lists — Bullets and Numbering

| Type | When to Use | How to Add |
|---|---|---|
| **Bullet list** | Items with no specific order | Home → Bullets (or type `-` + space) |
| **Numbered list** | Steps or items in a specific order | Home → Numbering (or type `1.` + space) |
| **Multi-level list** | Sub-items within a list | Home → Multilevel List (or press Tab after a bullet) |

**Shortcuts:**
  - `Ctrl+Shift+L` — quick bullet point
  - Press **Enter** within a list to add a new item
  - Press **Enter** twice to exit the list

### Paragraph Formatting

**Line Spacing:**
  - Home → Line and Paragraph Spacing (the icon with up/down arrows next to text lines)
  - **1.0** = single spacing (tight)
  - **1.5** = comfortable for reading (good for office documents)
  - **2.0** = double spacing (for drafts or school assignments)

**Paragraph Spacing:**
  - Layout tab → Spacing → Before / After
  - Adds space before or after a paragraph (better than pressing Enter twice)

**Indentation:**
  - **Increase Indent:** Home → Increase Indent (or `Tab`) — moves text to the right
  - **Decrease Indent:** Home → Decrease Indent (or `Shift+Tab`) — moves text to the left
  - **First Line Indent:** Drag the top triangle on the ruler → indents only the first line of a paragraph

### 🧠 Chapter Summary

> ✅ **Bold** `Ctrl+B` | **Italic** `Ctrl+I` | **Underline** `Ctrl+U`  
> ✅ **Use Styles** (Heading 1, Heading 2) instead of manually changing font size  
> ✅ **Bullet list** = unordered items | **Numbered list** = ordered steps  
> ✅ **Alignment:** Left `Ctrl+L`, Center `Ctrl+E`, Right `Ctrl+R`, Justify `Ctrl+J`  
> ✅ **Line spacing:** 1.5 is comfortable for most office documents  
> ✅ **Always select text first**, then apply formatting
