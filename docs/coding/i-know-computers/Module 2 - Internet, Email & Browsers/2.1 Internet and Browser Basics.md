### Internet vs World Wide Web

Most people use these words interchangeably, but they're different. Think of it this way:

| Concept | What It Is | Analogy |
|---|---|---|
| **Internet** | The global network that connects all computers | The road system |
| **World Wide Web (WWW)** | Websites and web pages you access through a browser | The cars driving on the road |

  - **Internet** is the infrastructure — cables, satellites, routers, servers. Email, video calls, file transfers — all use the internet.
  - **WWW** is a service that runs on top of the internet. When you type a URL in Chrome and visit a website, you're using the web.
  - **The internet can exist without the web** — email and video calls don't need websites. But the web cannot exist without the internet.

> **💡 Simple memory trick:** The internet is the physical network. The web is what you see in your browser.

### What is a Browser

A browser is the software that opens and displays websites. It's your window to the internet.

Common browsers: **Google Chrome** (most popular), **Mozilla Firefox**, **Microsoft Edge**, **Safari** (Mac)

![Browser Interface — Annotated](/diagrams/iknowcomputers/browser-interface.svg)

#### Browser Interface — Parts

| Part | What It Does | Shortcut |
|---|---|---|
| **Address Bar** | Type a URL (like `google.com`) or search directly | `Ctrl+L` |
| **Tabs** | Open multiple websites in one window | `Ctrl+T` (new), `Ctrl+W` (close) |
| **Back / Forward** | Go to previous or next page | `Alt+Left` / `Alt+Right` |
| **Refresh** | Reload the current page | `F5` or `Ctrl+R` |
| **Bookmarks** | Save your favorite websites for quick access | `Ctrl+D` |
| **History** | See all websites you've visited | `Ctrl+H` |
| **Downloads** | See files you've downloaded from the internet | `Ctrl+J` |
| **Incognito / Private Mode** | Browse without saving history | `Ctrl+Shift+N` |

> **💡 Tip:** The address bar is also a search bar. You don't need to go to Google first — just type what you want and press Enter.

### Smart Search — Find Anything Faster

Knowing how to search saves you minutes every day. Here are techniques that work in Google and most search engines:

| Technique | What It Does | Example |
|---|---|---|
| **Quotes `" "`** | Search for an exact phrase | `"annual report 2024"` |
| **`site:`** | Search only within one website | `site:wikipedia.org computer history` |
| **`filetype:`** | Find only specific file types | `filetype:pdf invoice template` |
| **`-word`** | Exclude a word from results | `jobs -internship` |
| **`OR`** | Search for either word | `mark sheet OR report card` |

> **⚠️ Common mistake:** Don't type full questions like "How do I create a table in Word?" — just type `create table Word` — it's faster and gives better results.

### Downloads — Saving Files from the Internet

When you download a file from the internet (a PDF, image, document, or software), it goes to your **Downloads** folder by default.

  - **To see your downloads:** Open your browser → `Ctrl+J`
  - **To find the file on your computer:** Open File Explorer `Windows+E` → Click **Downloads** in the left panel
  - **To change where files save:** Browser Settings → Advanced → Downloads → Change location

> **💡 Tip:** Keep your Downloads folder clean. Every week, move important files to the right folders and delete the rest.

### Browser Shortcuts — Quick Reference

| Shortcut | Action |
|---|---|
| `Ctrl+T` | New tab |
| `Ctrl+W` | Close current tab |

| `Ctrl+Tab` | Switch to the next tab |
| `Ctrl+Shift+Tab` | Switch to the previous tab |
| `Ctrl++` / `Ctrl+-` | Zoom in / Zoom out |
| `Ctrl+0` | Reset zoom to 100% |
| `F5` | Refresh page |
