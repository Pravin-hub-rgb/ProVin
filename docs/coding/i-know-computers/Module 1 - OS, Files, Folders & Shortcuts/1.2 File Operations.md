## Chapter 1.2 — File Operations

Here's what we'll cover: first, the **basic operations** — copy, cut, paste, delete, rename, undo — these are the actions you'll perform dozens of times every day. Next, how to **select multiple files** at once (saving tons of time). Then we'll look at the **Recycle Bin** — where deleted files go and how to recover them. Finally, we'll talk about **professional file naming** — because `final_v2_actual_final.docx` is not a good look in an office.

### Basic Operations

  - **Copy (Ctrl+C) and Paste (Ctrl+V)**
    The file is copied — the original stays, and a copy is created.
    Steps: Select the file → Ctrl+C → open the destination folder → Ctrl+V
  - **Cut (Ctrl+X) and Paste (Ctrl+V)**
    The file is moved — it leaves its original place and goes to the new one.
    Steps: Select the file → Ctrl+X → open the destination folder → Ctrl+V
  - **Delete (Delete key)**
    The file goes to the Recycle Bin — it's not permanently gone yet.
  - **Permanent Delete (Shift+Delete)**
    The file is deleted immediately — it doesn't go to the Recycle Bin. Be careful!
  - **Rename (F2)**
    Select the file → press F2 → type the new name → press Enter
  - **Undo (Ctrl+Z)**
    Made a mistake? Press Ctrl+Z — your last action will be undone.

Those were the basic operations on individual files. But what if you want to work with multiple files at once? You need to know how to **select** them first.

### Selecting Multiple Files

- **One by one:** Hold Ctrl and click on each file
- **Range:** Click the first file → hold Shift → click the last file — everything in between is selected
- **All:** Ctrl+A — selects all files in the folder

Once files are deleted, where do they go? They're not gone forever — they sit in the **Recycle Bin** until you empty it. Let's see how that works.

### Recycle Bin

- Deleted files go here
- **Restore:** Right-click → Restore — the file goes back to its original location
- **Empty Recycle Bin:** Permanently deletes everything — frees up space

Now that you know how to copy, move, and organize files, there's one more thing that makes you look professional — **how you name your files**. A good file name tells you everything about the file without even opening it.

### File Naming — Professional Convention

Bad naming: `file1.xlsx`, `untitled.docx`, `final_FINAL_v3_use_this.xlsx`  
Good naming: `Class10A_Marksheet_Oct2024.xlsx`, `Invoice_RahulSharma_Nov2024.pdf`

Rules:
- Include the date: `YYYY` or `MonYYYY`
- Include a version number if needed: `_v1`, `_v2`
- Don't use spaces — use underscores `_` instead
- Keep names clear and short
