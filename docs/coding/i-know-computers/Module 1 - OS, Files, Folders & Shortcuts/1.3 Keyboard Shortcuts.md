## Chapter 1.3 — Keyboard Shortcuts

**Why shortcuts:**  
Working with the mouse is slow. Shortcuts make you 3x faster. People at the office notice and get impressed — plus your own work gets done quicker.

Let's start with the shortcuts you'll use most often. If you remember nothing else, memorize these first five: **Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Z, Ctrl+S**.

### Essential Shortcuts — Always Useful

| Shortcut | What It Does | Category |
|---|---|---|
| Ctrl+C | Copy | 📋 Basic |
| Ctrl+X | Cut | 📋 Basic |
| Ctrl+V | Paste | 📋 Basic |
| Ctrl+Z | Undo | 📋 Basic |
| Ctrl+Y | Redo | 📋 Basic |
| Ctrl+S | Save | 📋 Basic |
| Ctrl+A | Select All | 📋 Selection |
| Ctrl+F | Find (in any document or webpage) | 📋 Search |
| Ctrl+P | Print | 🖨️ Document |
| Ctrl+N | New file/window | 🖨️ Document |
| Ctrl+W | Close current window/tab | 🖨️ Document |

Those handle the basics. Now let's look at shortcuts that help you **navigate** between programs and around your computer.

| Shortcut | What It Does | Category |
|---|---|---|
| Alt+Tab | Switch between open programs | 🔄 Navigation |
| Windows+D | Show desktop (minimize everything) | 🔄 Navigation |
| Windows+E | Open File Explorer | 🔄 Navigation |
| Windows+L | Lock your computer | 🔒 Security |
| Alt+F4 | Close the current program | 🔄 Navigation |
| Ctrl+Home | Go to top of document | 🔄 Navigation |
| Ctrl+End | Go to bottom of document | 🔄 Navigation |

And finally, shortcuts for **managing files** — renaming, deleting, and checking what's running on your computer.

| Shortcut | What It Does | Category |
|---|---|---|
| Ctrl+Shift+Esc | Open Task Manager | ⚙️ System |
| F2 | Rename selected file | 📁 File |
| Delete | Send to Recycle Bin | 📁 File |
| Shift+Delete | Permanently delete (skips Recycle Bin) | 📁 File |

> **💡 Tip:** Start with just 3-4 shortcuts. Use them until they become habit. Then add more. Don't try to memorize all 20 at once.
