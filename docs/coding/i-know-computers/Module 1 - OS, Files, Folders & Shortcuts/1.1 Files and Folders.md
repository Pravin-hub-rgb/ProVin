# Module 1 — OS, Files, Folders & Shortcuts

**Why this module matters:**  
To work on a computer, you need to know how to organize files. Just like a house has cupboards, a computer has folders. These basics are needed every single day in any office job.


In Module 0, we learned about the computer's body (hardware) and soul (software/OS). One of the OS's jobs was **File Management** — organizing files. Now in this chapter, we'll learn that skill ourselves.

### What is a File

A file is a **single unit** — anything saved on your computer. A photo, a document, a song — they're all files. Every file has a **name** and a **type**.

> **💡 Real Life Analogy:** A file is like a single sheet of paper. A folder is like a file-folder where you keep many papers together.

### What is a Folder

A folder is a **container** that can hold files and other folders (sub-folders). It is also called a **directory**.

### File Extension — The "Surname" of a File

Now that we know what files and folders are, the next question is — how do we tell what type a file is? You might have a `photo.jpg` and a `report.docx` — both are files, but they work differently. The answer lies in the **file extension**.

The part that comes after a dot (`.`) in the file name is the **extension**. It tells you what type of file it is and which program should open it.

| Extension | What It Does | Opens With |
|---|---|---|
| `.docx` | Word document | MS Word |
| `.xlsx` | Excel spreadsheet | MS Excel |
| `.pptx` | PowerPoint presentation | MS PowerPoint |
| `.pdf` | Document (read-only format) | Adobe Reader / Browser |
| `.jpg` / `.png` | Image / Photo | Photos / Paint |
| `.mp4` | Video | VLC / Windows Media Player |
| `.mp3` | Audio / Song | VLC / Windows Media Player |
| `.zip` | Compressed folder | WinZip / Built-in |
| `.exe` | Program / Installer | Double-click → install |

> **⚠️ Common Mistake:** Don't change the extension when renaming a file. Renaming `report.docx` to `report.pdf` will NOT turn it into a PDF — it will just break the file. To change the format, use **Save As**.

### File Explorer — Your Computer's Library

We've talked about files, folders, and extensions. But where do you actually see and manage all of them? That's what **File Explorer** is for.

File Explorer is the tool where you can see all your files and folders. To open it: **`Windows key + E`**

![File Explorer — Annotated UI](/diagrams/iknowcomputers/file-explorer.svg)

| Part | Location | What It Does |
|---|---|---|
| **Navigation Pane** | Left side | Quick Access, Desktop, Downloads, Documents, This PC |
| **Content Area** | Right side | Shows what's inside the current folder |
| **Address Bar** | Top (shows the path) | Tells you which folder you're in |
| **Search Bar** | Top-right | Search for a file by name |
| **Ribbon / Toolbar** | Top (Home, Share, View) | Buttons for Copy, Paste, Delete, Rename |
| **Status Bar** | Bottom | Shows how many items, how much space |

---

### File Path — The "Address" of a File

File Explorer shows us our folders visually, but there's also a **text-based address** that describes exactly where a file lives. This is called a **file path** — it tells you the route from the drive all the way to the file itself.

Just like a house has an address, every file has a **path**:

```
C:\Users\Rahul\Documents\Office\Report.xlsx
```

| Part | What It Means |
|---|---|
| `C:\` | C drive (main storage) |
| `Users\` | Users folder |
| `Rahul\` | Your account folder |
| `Documents\` | Documents library |
| `Office\` | A folder you created |
| `Report.xlsx` | The file name |

![File Path — Visual Tree](/diagrams/iknowcomputers/file-path.svg)

> **⚠️ Note:** In Windows, paths use `\` (backslash). Each `\` means you go one folder level deeper.

### Folder Structure — How to Organize

We now know what files and folders are, how to identify them by extension, where to find them (File Explorer), and how their address (path) works. The next logical question is — how should you arrange them so you can find things easily?

Organizing files in an office is a **skill**. Just like everything has a place in your home, every file should have a folder on your computer.

**Bad habit (everything in one place):**
```
Documents/
├── photo.jpg
├── Marksheet.pdf
├── resume.docx
├── song.mp3
├── budget.xlsx
├── project.pptx
└── invoice.pdf
```

**Good habit (organized into folders):**
```
Documents/
├── Photos/
│   └── birthday.jpg
├── Work/
│   ├── Reports/
│   │   └── Marksheet.pdf
│   ├── Projects/
│   │   └── project.pptx
│   └── Finance/
│       ├── budget.xlsx
│       └── invoice.pdf
└── Personal/
    └── resume.docx
```

> **💡 Rule of thumb:** Don't keep more than 30-40 files in one folder. If there are too many, create sub-folders.

### Basic File Operations (Right-Click Menu)

Once your folders are set up, you'll need to work with files — copy them, move them around, rename them, delete the ones you don't need. These are called **file operations**, and the quickest way to do most of them is through the right-click menu.

| Operation | How to Do It | Shortcut |
|---|---|---|
| **New Folder** | Right-click → New → Folder | `Ctrl + Shift + N` |
| **Rename** | Right-click → Rename | `F2` |
| **Delete** | Right-click → Delete | `Delete` key |
| **Copy** | Right-click → Copy | `Ctrl + C` |
| **Paste** | Right-click → Paste | `Ctrl + V` |
| **Cut (Move)** | Right-click → Cut | `Ctrl + X` |

### 🎯 Real Task

1. Open **File Explorer** (`Windows key + E`) → go to your **Documents** folder
2. Create a **new folder**: Right-click → New → Folder → name it "Office Work"
3. Inside it, create **3 sub-folders**: "Reports", "Data Entry", "Emails"
4. In each folder, create a **text file**: Right-click → New → Text Document → give it a name
5. Check the file **extension** — can you see `.txt`? If not, go to File Explorer → **View → Show → File name extensions** and turn it on
