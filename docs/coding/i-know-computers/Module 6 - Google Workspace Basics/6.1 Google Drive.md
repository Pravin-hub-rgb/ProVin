You've learned Microsoft Office — Word, Excel, PowerPoint. Now let's explore **Google Workspace** — Google's free online alternative. In the next chapter, we'll learn Google Sheets.

### What is Google Drive

Google Drive is **cloud storage** — your files are stored on Google's servers on the internet, not on your computer.

**Benefits of cloud storage:**
  - Access your files from **any device** — laptop, phone, tablet, anywhere
  - Your files are **safe** — if your computer breaks, files are still online
  - **Share** files with others easily
  - **15 GB free storage** with every Google account

---

### Drive Interface

When you open drive.google.com, you see:

| Part | What It Contains |
|---|---|
| **My Drive** | Your files and folders — like File Explorer on Windows |
| **Shared with me** | Files that other people have shared with you |
| **Recent** | Files you've opened recently |
| **Starred** | Files you've marked as important (click the star icon) |
| **Trash** | Deleted files (permanently removed after 30 days) |

---

### Uploading and Creating Files

**Upload a file from your computer:**
  - Click **New** → **File Upload** → select the file
  - Or drag and drop files directly into the browser window

**Create a new file:**
  - Click **New** → choose: Google Docs, Google Sheets, Google Slides, Google Forms
  - A new browser tab opens with the blank file

**Create folders:**
  - Click **New** → **New Folder**
  - Give it a name → click Create
  - Build the same folder structure you learned in Module 1

---

### Sharing Files and Folders

This is where Google Drive shines — sharing is simple and instant.

**To share a file or folder:**
1. Right-click the file/folder → **Share**
2. Type the email address of the person
3. Choose permission level:
   - **Viewer** — can only view (best for most situations)
   - **Commenter** — can view and add comments
   - **Editor** — can view and edit
4. Click Send

**Or get a shareable link:**
1. Right-click → **Share** → **Copy link**
2. Send the link to anyone — they can access it (with the permission you set)

> **💡 Office tip:** For important documents, use **Viewer** permission when sharing externally. Only give **Editor** access to trusted team members.

---

### Downloading from Drive

  - Right-click any file → **Download**
  - The file downloads in its original format:
    - Google Docs → `.docx`
    - Google Sheets → `.xlsx`
    - Google Slides → `.pptx`
