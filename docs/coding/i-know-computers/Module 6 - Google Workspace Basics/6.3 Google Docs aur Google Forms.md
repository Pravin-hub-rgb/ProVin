## Chapter 6.3 — Google Docs & Google Forms

Here's what we'll cover: first, **Google Docs** basics — how it's similar to Word. Then **Google Forms** — creating surveys and quizzes. After that, **how responses are collected** automatically in Sheets. Finally, **office use cases** for Forms.

### Google Docs

Google Docs is the free, browser-based version of Word.

**What's the same as Word:**
  - Bold, italic, underline (`Ctrl+B`, `Ctrl+I`, `Ctrl+U`)
  - Headings (Heading 1, Heading 2)
  - Bullet lists and numbered lists
  - Tables
  - Alignment (left, center, right, justify)

**What's different (better):**
  - **Auto-save** — every change saves instantly
  - **Real-time collaboration** — multiple people edit at once
  - **Comments:** Select text → `Ctrl+Alt+M` → add a comment
  - **Version history:** File → Version History

**Download as Word:** File → Download → Microsoft Word (`.docx`)

> **💡 Tip:** Use Google Docs when collaborating with a team. Use MS Word when you need advanced formatting features.

### Google Forms — Create Surveys and Forms

Google Forms lets you create online forms, surveys, and quizzes. Responses are automatically collected in Google Sheets.

**How to create a form:**
1. Go to [forms.google.com](https://forms.google.com) or Drive → New → Google Forms
2. Click the title to rename it
3. Click **Untitled Question** to add your first question

**Question types:**

| Type | Best For | Example |
|---|---|---|
| **Short answer** | Text responses (name, phone) | "Enter your name" |
| **Paragraph** | Longer text | "Any comments or suggestions?" |
| **Multiple choice** | One option from many | "Gender: Male / Female / Other" |
| **Checkboxes** | Multiple options | "Which skills do you have?" |
| **Dropdown** | One option from a long list | "Department: Sales, HR, IT, Operations" |
| **Date** | Pick a date | "Date of joining" |
| **File upload** | User uploads a file | "Upload your resume" |

---

### How Responses Flow

1. Create your form → click **Send** (top-right)
2. Copy the link → share it via email, WhatsApp, or any other way
3. People fill the form → click Submit
4. Their responses are automatically saved in Google Sheets

**To view responses:**
  - In the form, click the **Responses** tab
  - You'll see a summary with charts
  - Click the green Sheets icon → **Create new spreadsheet** → all responses go to a Sheet

### Office Use Cases for Forms

| Use Case | How |
|---|---|
