## Chapter 6.2 — Google Sheets (vs Excel)

### Excel vs Google Sheets — Key Differences

| Feature | MS Excel | Google Sheets |
|---|---|---|
| **Price** | Paid (Microsoft 365 subscription) | **Free** (with Google account) |
| **Access** | Desktop software | Browser-based (works on any computer) |
| **Auto-save** | Manual (`Ctrl+S`) | **Automatic** — every change is saved instantly |
| **Collaboration** | Limited (OneDrive) | **Real-time** — multiple people can edit together |
| **Offline** | Full offline access | Limited (requires offline mode setup) |
| **File format** | `.xlsx` | `.gsheet` or export to `.xlsx` |
| **Advanced features** | More (Power Query, advanced macros) | Fewer but growing |
| **Formulas** | Same core formulas | **Same core formulas** — SUM, IF, VLOOKUP all work |

> **💡 Key takeaway:** If you know Excel, you already know 90% of Google Sheets. The main differences are: auto-save (always on), collaboration (real-time), and it's free.

---

### Formulas — The Same!

All the formulas you learned in Excel work in Google Sheets:

| Formula | Works in Sheets? |
|---|---|
| `=SUM(A1:A10)` | ✅ Same |
| `=AVERAGE(B2:B51)` | ✅ Same |
| `=IF(F2>=33,"Pass","Fail")` | ✅ Same |
| `=VLOOKUP(B2, A2:F51, 2, FALSE)` | ✅ Same |
| `=COUNTIF(G2:G51,"Pass")` | ✅ Same |
| `=MAX(A1:A10)` | ✅ Same |

**Shortcuts are also mostly the same:** `Ctrl+C`, `Ctrl+V`, `Ctrl+Z`, `Ctrl+B`, `Ctrl+Shift+L` (filter), `F4` (absolute reference toggle).

---

### Collaboration — Sheets' Superpower

This is the main reason offices use Google Sheets:

  - **Multiple people** can edit the same sheet at the same time
  - Each person has a **different colored cursor** — you can see what others are typing in real time
  - **Comments:** Select a cell → `Ctrl+Alt+M` → type a comment → tag someone with `@name`
  - **Version history:** File → Version History → See all changes, who made them, and restore old versions

**Office use case:** Imagine 5 team members entering sales data from different cities into the same sheet at the same time. With Excel, you'd need to merge files. With Sheets, it's automatic.

---

### Importing Excel Files

You can upload your Excel files to Google Drive and open them in Google Sheets:

1. Upload the `.xlsx` file to Google Drive
2. Right-click the file → **Open with** → **Google Sheets**
3. The file opens with all formulas, formatting, and data intact
4. You can now edit, share, and collaborate

> **⚠️ Note:** Very complex Excel files (with macros, advanced charts, or very large data) may not open perfectly in Sheets. For most office work, the transition is smooth.
