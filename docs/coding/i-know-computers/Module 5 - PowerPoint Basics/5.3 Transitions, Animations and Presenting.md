In the last chapter, we designed our slides with themes, images, and SmartArt. Now let's add motion and learn how to **present**. Transitions control how one slide moves to the next. Animations control how individual elements appear on a slide. In the next module, we'll learn Google Workspace.


### Transitions — Between Slides

A **transition** is the effect you see when one slide moves to the next.

**To add a transition:**
1. Select a slide in the Slide Panel (left side)
2. Go to **Transitions** tab
3. Choose an effect from the gallery
4. Set **Duration** (how fast the transition is — 0.5 to 1 second is good)
5. Click **Apply to All** to use the same transition on every slide

| Transition | When to Use |
|---|---|
| **Fade** | Professional, clean — use for most office presentations |
| **Push** | Modern feel |
| **Wipe** | Good for revealing content |
| **Random** | Avoid in professional settings — looks messy |

> **💡 Rule:** Simple transitions (Fade, Push) for office work. Don't use flashy or spinning effects — they look unprofessional.

---

### Animations — On Individual Elements

An **animation** makes a single element (text, image, shape) appear, move, or disappear.

**Types of animations:**
  - **Entrance:** Element appears on the slide (Appear, Fade, Fly In)
  - **Emphasis:** Element gets highlighted (Spin, Grow, Pulse)
  - **Exit:** Element leaves the slide (Disappear, Fade Out)

**To add an animation:**
1. Select an element (text box, image, shape)
2. Go to **Animations** tab
3. Choose an effect
4. Set **Duration** and **Start** option:
   - **On Click** — starts when you click the mouse
   - **With Previous** — starts at the same time as the previous animation
   - **After Previous** — starts automatically after the previous animation

> **💡 Office rule:** In most office presentations, use minimal animations. A simple Fade or Appear effect is enough. Too many animations distract the audience.

### Presenting Your Slideshow

| Action | Shortcut |
|---|---|
| Start from the first slide | `F5` |
| Start from the current slide | `Shift+F5` |
| Next slide | Click, Space, Right Arrow, Enter, or Down Arrow |
| Previous slide | Backspace, Left Arrow, or Up Arrow |
| Go to a specific slide | Type the slide number → Enter |
| End the slideshow | `Esc` |

**During a presentation:**
  - Press **B** — screen goes black (pause attention)
  - Press **W** — screen goes white
  - Press **Ctrl+H** — hide cursor
  - Right-click on a slide → **See all slides** — shows thumbnails for quick navigation

---

### Presenter View

When you connect your laptop to a projector or external screen, Presenter View shows:
  - **Your screen:** Current slide, next slide preview, speaker notes, timer
  - **Projector screen:** Only the current slide (audience doesn't see notes)

**To enable:** Slide Show → check **Use Presenter View** (or press `Alt+F5` to test)

---

### Save as PDF or Video

**Save as PDF:**
  - File → Save As → choose PDF format
  - Each slide becomes one page in the PDF
  - Good for sharing handouts

**Save as Video:**
  - File → Export → Create a Video
  - Choose quality and timing
  - Creates an MP4 file — good for sharing when the recipient can't attend
