## Chapter 5.1 — PowerPoint Interface & Basic Slides

You've completed Word and Excel. Now let's learn **PowerPoint** — the tool for creating presentations. In an office, you'll use PowerPoint to present reports, proposals, and updates to your team or clients. In this chapter, we'll learn the interface and how to create basic slides. In the next chapter, we'll add design and images.

Here's what we'll cover: first, the **PowerPoint interface** — slide panel, main area, notes, ribbon. Then how to **create and save** a new presentation. After that, adding **new slides** and choosing **layouts**. Finally, adding text and basic content.

### PowerPoint Interface

![PowerPoint Interface — Annotated](/diagrams/iknowcomputers/powerpoint-interface.svg)

| Part | Location | What It Does |
|---|---|---|
| **Slide Panel** | Left side | Shows thumbnails of all slides |
| **Main Area** | Center | The current slide — where you edit content |
| **Notes Panel** | Bottom | Speaker notes — only you see them during a presentation |
| **Ribbon** | Top | Home, Insert, Design, Transitions, Animations, Slide Show |
| **Status Bar** | Bottom | Slide number, theme name, zoom |

---

### Creating and Saving

| Action | How | Shortcut |
|---|---|---|
| **New presentation** | File → New → Blank Presentation | `Ctrl+N` |
| **Save** | File → Save As → choose location | `Ctrl+S` |
| **Open** | File → Open → browse to file | `Ctrl+O` |

---

### Adding and Managing Slides

| Action | How | Shortcut |
|---|---|---|
| **New slide** | Home → New Slide | `Ctrl+M` |
| **Delete slide** | Right-click slide thumbnail → Delete Slide | Select + Delete key |
| **Duplicate slide** | Right-click → Duplicate Slide | — |
| **Move slide** | Drag the thumbnail up or down | — |

---

### Slide Layouts

Every slide has a **layout** that defines where content goes:

| Layout | Best For |
|---|---|
| **Title Slide** | The first slide (title + subtitle) |
| **Title and Content** | Most slides — has a title and a content area for text, images, or tables |
| **Blank** | Starting from scratch |
| **Two Content** | Comparing two things side by side |

**To change a slide's layout:** Home → Layout → choose from the gallery

---

### Adding Text

  - Click inside a text placeholder (like "Click to add title") and type
  - To add a new text box: **Insert → Text Box** → click and drag on the slide
  - To add bullet points: type text → press Enter → the next line automatically becomes a bullet

### 🎯 Real Task

1. Open PowerPoint (`Ctrl+N`). The first slide (Title Slide) is already there. Type: Title = "My School Introduction", Subtitle = "By [Your Name]".

3. Add two more slides: "Facilities" (bullet list) and "Contact" (text). Save as `SchoolIntro.pptx`.
