## Chapter 7.2 — File Naming, Versioning & Folder Organization

Here's what we'll cover: first, **why file organization matters** in an office. Then **file naming conventions** — the standard format. After that, **versioning** — managing multiple drafts. Finally, **folder structure** — the standard office setup.

### Why This Matters

In an office, you'll deal with hundreds of files. Without proper organization:
  - You waste time searching for files
  - You might send the wrong version to your boss
  - You might accidentally delete important files
  - You look unprofessional

---

### File Naming Convention

**Standard format:** `ProjectName_Description_YYYY-MM-DD_v1.ext`

| Part | Example | Why It Helps |
|---|---|---|
| **Project name** | `Class10A` | Groups related files together |
| **Description** | `Marksheet` | Tells you what it is |
| **Date** | `2024-10-15` | Sorts chronologically — use **YYYY-MM-DD** format |
| **Version** | `v1` | Tracks which draft |
| **Extension** | `.xlsx` | Tells file type |

**Good examples:**
  - `Class10A_Marksheet_2024-10-15_v1.xlsx`
  - `Invoice_RahulSharma_2024-11-01.pdf`
  - `MeetingNotes_SalesTeam_2024-10-20.docx`
  - `Logo_Company_Final.png`

**Bad examples (avoid these):**
  - `document1.docx` — tells you nothing
  - `final_FINAL_v3_use_this.xlsx` — confusing and unprofessional
  - `report (2).docx` — looks like a duplicate

**Rules:**
  - No spaces — use underscore `_` or hyphen `-`
  - No special characters: `\ / : * ? " < > |`
  - Short but descriptive
  - Date in **YYYY-MM-DD** format for proper sorting

---

### Versioning

When you work on documents that go through multiple drafts:

| Version | When to Save |
|---|---|
| `_v1` | First draft |
| `_v2` | After first round of changes |
| `_v3` | After second round |
| `_Final` | Final approved version |
| `_Final_v2` | ❌ Wrong! If it's final, don't make more versions |

**Best practice:**
  - Keep all versions in one folder
  - Don't delete old versions immediately — move them to an "Archive" folder
  - Use version numbers, not words like "new" or "latest"

> **💡 Tip:** Before sending a file to anyone, check: is this the correct version? Does the filename include a clear description? Is it saved in the right folder?

### Folder Structure — Standard Office Setup

```
My Documents /
└── Company Name /
    ├── 2024 /
    │   ├── January /
    │   ├── February /
    │   ├── March /
    │   └── ... /
    ├── Clients /
    │   ├── Client A /
    │   └── Client B /
    ├── Reports /
    ├── Templates /
    │   └── (reusable document templates)
    └── Archive /
        └── (old files you might need later)
```

**Key principles:**
  - **Year → Month** structure for time-based files
  - **Client name** structure for client work
  - **Templates** folder for documents you reuse
  - **Archive** folder for old files (don't delete, just move)
