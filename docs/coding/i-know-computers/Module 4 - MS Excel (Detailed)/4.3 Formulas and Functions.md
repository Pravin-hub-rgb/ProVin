In the last chapter, we entered and formatted data. Now comes the powerful part — **formulas**. Formulas let Excel do calculations automatically. No manual addition, no calculator needed. In this chapter, we'll learn basic math formulas and essential functions like SUM, AVERAGE, IF, and COUNT. In the next chapter, we'll learn VLOOKUP — the most useful function for finding data.


### Formula Basics

Every formula in Excel starts with an **equals sign (`=`)** . The rest is the calculation you want Excel to do.

| Operator | What It Does | Example | Result |
|---|---|---|---|
| `+` | Addition | `=A1+B1` | Adds values in A1 and B1 |
| `-` | Subtraction | `=A1-B1` | Subtracts B1 from A1 |
| `*` | Multiplication | `=A1*B1` | Multiplies A1 and B1 |
| `/` | Division | `=A1/B1` | Divides A1 by B1 |
| `^` | Power (exponent) | `=A1^2` | A1 squared |

**Steps to write a formula:**
1. Click the cell where you want the result
2. Type `=` (equals)
3. Click the first cell or type its address
4. Type the operator (`+`, `-`, `*`, `/`)
5. Click the second cell or type its address
6. Press Enter

> **💡 Tip:** You can click cells instead of typing addresses. Excel automatically inserts the cell reference.

### Essential Functions

Functions are pre-built formulas that save you time.

#### SUM — Add Numbers

`=SUM(range)` adds up all numbers in a range of cells.

| Example | What It Does |
|---|---|
| `=SUM(B2:D2)` | Adds all cells from B2 to D2 |
| `=SUM(B2,B5,B8)` | Adds only cells B2, B5, and B8 |
| `=SUM(B2:B51)` | Adds all values in column B from row 2 to 51 |

#### AVERAGE — Find the Average

`=AVERAGE(range)` calculates the average (mean) of a range.

`=AVERAGE(B2:B51)` — average of all values in B2 to B51

#### MAX and MIN — Highest and Lowest

| Function | What It Does | Example |
|---|---|---|
| `=MAX(range)` | Finds the largest number | `=MAX(B2:B51)` |
| `=MIN(range)` | Finds the smallest number | `=MIN(B2:B51)` |

#### COUNT and COUNTA — Count Cells

| Function | What It Counts | Example |
|---|---|---|
| `=COUNT(range)` | Only cells with numbers | `=COUNT(B2:B51)` |
| `=COUNTA(range)` | All non-empty cells (text + numbers) | `=COUNTA(A2:A51)` |

#### IF — Check a Condition

`=IF(condition, value_if_true, value_if_false)` checks a condition and returns different values.

`=IF(F2>=33, "Pass", "Fail")` — if F2 is 33 or more, show "Pass"; otherwise show "Fail"

**Nested IF (multiple conditions):**
`=IF(F2>=75, "Distinction", IF(F2>=60, "First", IF(F2>=45, "Second", "Fail")))`

#### COUNTIF and SUMIF — Conditional Count and Sum

| Function | What It Does | Example |
|---|---|---|
| `=COUNTIF(range, "condition")` | Count cells matching a condition | `=COUNTIF(G2:G51, "Pass")` |
| `=SUMIF(range, "condition", sum_range)` | Sum cells matching a condition | `=SUMIF(A2:A51, "Class A", F2:F51)` |

### Date Functions

Dates in Excel are actually numbers behind the scenes. Each day has a serial number (1 = 1 Jan 1900). Date functions let you work with dates in formulas.

**=TODAY() and =NOW():**
- `=TODAY()` — returns today's date. *Example: Today it shows 08-Jun-2026, tomorrow it auto-updates to 09-Jun-2026*
- `=NOW()` — returns current date + time. *Example: 08-Jun-2026 14:30 — updates every time the sheet recalculates*

**=DATE(year, month, day):**
Builds a date from separate numbers. Useful when your data has year, month, and day in different columns.

```
=DATE(2024, 6, 15)
```
Returns: 15-Jun-2024

*Example: If A1=2024, B1=6, C1=15, then `=DATE(A1, B1, C1)` gives 15-Jun-2024*

**=DATEVALUE(date_text):**
Converts a date written as text into Excel's serial number. This is useful when someone types a date as text (like "15-Jun-2024") and you need to use it in calculations.

```
=DATEVALUE("15-Jun-2024")
```
Returns: 45458 (Excel's serial number for that date)

*Example: A1 contains "15-Jun-2024" as text. `=DATEVALUE(A1)` converts it so you can subtract dates or use it in formulas.*

**=EOMONTH(start_date, months):**
Returns the **last day of the month**, a specified number of months before or after a given date. EOMONTH = End Of MONTH. Very commonly used for billing, deadlines, and reporting dates.

```
=EOMONTH(TODAY(), 0)
```
Returns: the last day of the current month. *If today is 08-Jun-2026, result is 30-Jun-2026*

| Formula | What It Does | Example Result |
|---|---|---|
| `=EOMONTH("15-Jun-2024", 0)` | Last day of June 2024 | 30-Jun-2024 |
| `=EOMONTH("15-Jun-2024", 1)` | Last day of next month (July) | 31-Jul-2024 |
| `=EOMONTH("15-Jun-2024", -1)` | Last day of previous month (May) | 31-May-2024 |
| `=EOMONTH("15-Jun-2024", 3)` | Last day, 3 months ahead (September) | 30-Sep-2024 |

*Real-life use: An invoice dated 15-Mar-2024 with "Net 30" terms — due date is 30 days later. `=EOMONTH("15-Mar-2024", 1)` gives 30-Apr-2024, which could be used as the payment deadline.*

**=TEXT(value, format_text):**
Converts a number or date into **text** with a specific format. This is useful when you want to display a date in a particular format without changing the cell format, or combine a formatted date with other text.

```
=TEXT(TODAY(), "dddd")
```
Returns: Monday (the current day's name)

| Formula | What It Does | Example Result |
|---|---|---|
| `=TEXT(TODAY(), "dddd")` | Full day name | Monday |
| `=TEXT(TODAY(), "ddd")` | Short day name | Mon |
| `=TEXT(TODAY(), "mmmm yyyy")` | Month and year | June 2026 |
| `=TEXT(TODAY(), "dd-mmm-yyyy")` | Day-Month-Year | 08-Jun-2026 |
| `=TEXT(A1, "₹#,##0.00")` | Number as currency text | ₹1,500.00 |
| `=TEXT(A1, "0%")` | Number as percentage text | 15% |

*Real-life use: You have a date in A1 and want to show "Your order was placed on Monday, 08-Jun-2026" in a report. Use `="Your order was placed on " & TEXT(A1, "dddd, dd-mmm-yyyy")`. The TEXT function lets you control exactly how the date looks inside a sentence.*

### Cell References — Relative vs Absolute

| Type | Example | What Happens When You Copy It |
|---|---|---|
| **Relative** | `=A1` | Changes based on the new location — most common |
| **Absolute** | `=$A$1` | Stays fixed — the `$` locks both column and row |
| **Mixed** | `=$A1` or `=A$1` | Only one part is locked |

**How to use absolute references:**
  - Type `$` manually before the column letter and/or row number
  - Or select the cell reference in the formula and press **F4** to toggle through options

**When to use absolute:** When you have a fixed value like a tax rate, passing marks, or a discount percentage that should stay the same in every formula.

> **💡 Tip:** Press **F4** while editing a formula to cycle through reference types: A1 → $A$1 → A$1 → $A1.
