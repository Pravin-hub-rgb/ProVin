In the last chapter, we learned the Excel interface and how to navigate. Now let's start working with data. **Data entry** is what you'll do most in an office — typing information into cells. And **formatting** makes that data clear and professional. In this chapter, we'll learn how to enter different types of data, use AutoFill, and format cells. In the next chapter, we'll learn formulas.


### Data Types in Excel

| Type | Example | How It Behaves |
|---|---|---|
| **Text** | `Rahul`, `Delhi` | Left-aligned by default |
| **Number** | `95`, `3.14`, `-10` | Right-aligned by default |
| **Date** | `15/10/2024` | Right-aligned, special format |
| **Formula** | `=A1+B1` | Starts with `=`, calculates automatically |
| **Boolean** | `TRUE`, `FALSE` | Special logical values |

> **⚠️ Common mistake:** If you type a number but Excel treats it as text (left-aligned), check if there's a space or apostrophe before the number.

---

### Data Entry Tips

| Technique | How | When to Use |
|---|---|---|
| **Quick entry** | Type → Enter (down) or Tab (right) | Entering data row by row |
| **Same value in multiple cells** | Select cells → type value → `Ctrl+Enter` | Filling multiple cells with the same value |
| **AutoFill** | Drag the small square at the bottom-right of a selected cell | Auto-completes series: 1,2,3 or Mon,Tue,Wed or dates |
| **Today's date** | `Ctrl+;` (semicolon) | Quickly enter the current date |
| **Current time** | `Ctrl+Shift+;` | Quickly enter the current time |

> **💡 AutoFill is powerful:** Type "January" in a cell → drag the bottom-right corner down → Excel automatically fills February, March, April... Works with numbers, dates, days, and custom lists.

### Formatting Cells

**Why format cells?**  
Raw data in Excel's default look is hard to read — everything looks the same. Formatting gives your data **visual meaning**:

- A **header row** with blue background + white bold text instantly says "this is the title, not data"
- **₹25.00** with the rupee symbol tells the reader it's currency — just `25` does not
- **15%** is immediately understood as a percentage — `0.15` is confusing
- **05-Jun-2024** removes the confusion of `05/06/2024` (is it May 6 or June 5?)

A formatted sheet looks professional; an unformatted one looks like a rough draft. Let's learn how.

Press **`Ctrl+1`** to open the Format Cells dialog — this is where most formatting happens.

**Number Formatting (Home → Number group):**
  - **General** — default, no special format
  - **Number** — choose decimal places. *Example: Format ₹124.5 as ₹124.50 (2 decimal places) — standard for prices*
  - **Currency** — adds ₹ symbol. *Example: A cell with `1500` formatted as Currency shows ₹1,500.00 — instantly recognizable as money*
  - **Percentage** — turns 0.95 into 95%. *Example: If your sales grew by 0.15, format as Percentage → it shows 15% growth, easy to read*
  - **Date** — choose a format like `15-Oct-2024`. *Example: `05/06/2024` is ambiguous (May 6 or June 5?). Format as `05-Jun-2024` — clear and professional*

**Text Formatting:**
  - Font, size, bold (`Ctrl+B`), italic (`Ctrl+I`) — same as Word
  - Text color — Home → Font Color. *Example: Make negative numbers red so losses stand out*
  - Fill color (background) — Home → Fill Color (paint bucket icon). *Example: Blue header row with white text — the most common office look*
  - Borders — Home → Borders dropdown. *Example: Add borders to a table so each cell has clear boundaries — prints better*

**Alignment:**
  - Left, Center, Right — `Ctrl+L`, `Ctrl+E`, `Ctrl+R`
  - Top, Middle, Bottom — Home → Alignment → vertical options
  - **Merge & Center:** Select multiple cells → Home → Merge & Center — great for titles. *Example: Type "Monthly Sales Report" in A1, select A1 through E1, click Merge & Center — the title sits beautifully across the sheet*
  - **Wrap Text:** Home → Wrap Text — text stays in one cell and wraps to multiple lines. *Example: A long customer address in one cell — without Wrap Text, it spills into the next column*

### Column Width and Row Height

| Action | How |
|---|---|
| **Auto-fit column width** | Double-click the right edge of the column header |
| **Auto-fit row height** | Double-click the bottom edge of the row number |
| **Manual width** | Drag the column border left or right |
| **Set exact width** | Right-click column → Column Width → enter a number |

> **💡 Tip:** After entering all your data, select all cells (`Ctrl+A`) and double-click between any two column headers — all columns will auto-fit at once.

### 🎯 Real Task

1. Open Excel. In **column A**, type numbers 1 to 20. Use AutoFill: type `1` in A1, `2` in A2, select both cells, then drag the bottom-right corner down to A20.
2. In **column B**, type `=A1*10` in B1 and drag down to B20 — Excel multiplies each number by 10.
3. Format the header row: Type "Number" in A1 and "Times 10" in B1. Make them bold (`Ctrl+B`), add a blue background with white text. Auto-fit the columns (`Ctrl+A` then double-click any column divider).
4. **Try Currency formatting:** In **column C**, type `=A1*25` in C1 and drag down to C20 — this calculates 25 times each number (imagine a price list). Select C2 to C20, press `Ctrl+1` → Category → **Currency** → choose ₹ symbol, 2 decimal places. Now you see prices like ₹25.00, ₹50.00 etc.
5. **Try Percentage formatting:** In **column D**, type `=A1*0.05` in D1 and drag down to D20 — this calculates 5% of each number. Select D2 to D20, press `Ctrl+1` → Category → **Percentage** → 0 decimal places. Now you see 5%, 10%, 15% etc.

> **🎯 Bonus challenge:** Merge & Center — type "My Practice Sheet" in A1, then select A1 through D1, click Home → Merge & Center. Your title is now centered across the whole sheet.
