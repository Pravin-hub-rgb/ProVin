## Chapter 4.4 — VLOOKUP & HLOOKUP

Here's what we'll cover: first, **what VLOOKUP does** and its syntax. Then a **step-by-step example** — building a student lookup system. After that, **common VLOOKUP errors** and how to fix them. Finally, **HLOOKUP** — the horizontal version.

### What is VLOOKUP

VLOOKUP stands for **Vertical Lookup**. It searches for a value in the first column of a table, and returns a value from the same row in another column.

**Syntax:** `=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])`

| Part | What It Means | Example |
|---|---|---|
| `lookup_value` | What you're searching for | `A2` (the value to find) |
| `table_array` | The range where you're searching | `$A$2:$H$51` (use absolute reference `$` to lock it) |
| `col_index_num` | Which column to return from (1 = first column, 2 = second, etc.) | `2` (return the value from column 2) |
| `range_lookup` | `FALSE` for exact match, `TRUE` for approximate | `FALSE` (always use FALSE for exact match) |

> **⚠️ Important:** Always use `FALSE` as the last argument unless you specifically need an approximate match. FALSE means "find exactly this value." TRUE means "find the closest match" — which often gives wrong results.

### Step-by-Step — Student Lookup System

Imagine Sheet 1 has student data:
- Column A: Roll Number
- Column B: Student Name
- Column C: English Marks
- Column D: Math Marks
- Column E: Science Marks
- Column F: Total

**Goal:** On Sheet 2, create a lookup form. When you type a roll number, all details appear automatically.

**On Sheet 2, set up:**
- Cell B1: "Enter Roll Number:" (label)
- Cell B2: Type a roll number (like `5`) — this is the input
- Cell B3: `=VLOOKUP(B2, Sheet1!$A$2:$F$51, 2, FALSE)` → Returns the student name
- Cell B4: `=VLOOKUP(B2, Sheet1!$A$2:$F$51, 3, FALSE)` → Returns English marks
- Cell B5: `=VLOOKUP(B2, Sheet1!$A$2:$F$51, 4, FALSE)` → Returns Math marks
- Cell B6: `=VLOOKUP(B2, Sheet1!$A$2:$F$51, 5, FALSE)` → Returns Science marks
- Cell B7: `=VLOOKUP(B2, Sheet1!$A$2:$F$51, 6, FALSE)` → Returns Total

Now whenever you change the roll number in B2, all the information updates automatically.

> **💡 Tip:** Use absolute references `$A$2:$F$51` (with `$`) so you can copy the formula across rows without the table range shifting.

### Common VLOOKUP Errors

| Error | Meaning | Fix |
|---|---|---|
| `#N/A` | Value not found | Check that the lookup value actually exists in the first column |
| `#REF!` | Column number is out of range | Increase `col_index_num` — it must be within the table range |
| Wrong result | Got a different value than expected | Check if `range_lookup` is `FALSE` — TRUE mode gives approximate matches |

**Why VLOOKUP fails (and how to fix):**
  - The lookup column is not the **first column** of the table array — VLOOKUP can only search in the first column
  - Extra **spaces** in the data — use `=TRIM()` to clean data
  - Numbers stored as **text** — format both columns consistently

### HLOOKUP — Horizontal Lookup

HLOOKUP is the same idea as VLOOKUP, but it searches horizontally (by rows instead of columns).

`=HLOOKUP(lookup_value, table_array, row_index_num, FALSE)`

**When to use HLOOKUP:** When your data is arranged horizontally — categories in the first row, values underneath.

### 🧠 Chapter Summary

> ✅ **VLOOKUP** = searches vertically in the first column, returns a value from another column  
> ✅ **Syntax:** `=VLOOKUP(value, table, column_number, FALSE)`  
> ✅ **Always use FALSE** for exact match — TRUE gives unpredictable results  
> ✅ **Absolute references** `$` to lock the table range when copying formulas  
> ✅ **#N/A error** = value not found — check spelling, spaces, and data type  
> ✅ **HLOOKUP** = same concept but searches horizontally by rows
