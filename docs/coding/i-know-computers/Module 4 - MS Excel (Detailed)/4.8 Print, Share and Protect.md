## Chapter 4.8 — Print, Share & Protect

### Printing in Excel

Printing Excel is different from Word because data can span many columns. Here's how to control what gets printed:

**Set Print Area:**
  - Select the cells you want to print
  - Page Layout → Print Area → Set Print Area
  - This tells Excel to print only the selected range

**Page Layout for printing:**
  - **Orientation:** Portrait (tall) for narrow data, Landscape (wide) for wide tables
  - **Size:** A4 (standard in India)
  - **Margins:** Normal or Narrow
  - **Scale to Fit:** Page Layout → Scale to Fit group → set Width and Height to **1 page** — this shrinks the sheet to fit on one page

**Freeze Panes (keep headers visible while scrolling):**
  - View → Freeze Panes → Freeze Top Row
  - Your header row stays visible even when scrolling down hundreds of rows
  - Shortcut: `Alt → W → F → R`

**Print Preview:** Always check `Ctrl+P` before printing. Look at the preview on the right — is everything fitting? Are headers repeating?

### Sharing as PDF

**Method 1 — Save As:**
  - File → Save As → choose location
  - In "Save as type", select **PDF**
  - Click Save

**Method 2 — Print to PDF:**
  - `Ctrl+P` → in Printer dropdown, select **Microsoft Print to PDF**
  - Click Print → choose location
  - The PDF saves with exactly what you see in Print Preview

**File naming convention:** Use a clear name: `Class10_Marksheet_Oct2024.pdf`

**When to send .xlsx vs .pdf:**
  - Send **.xlsx** when the person needs to edit the data
  - Send **.pdf** when the person only needs to view it (formatting stays perfect)

### Protecting Data

**Protect a Sheet (prevent editing):**
1. Review → Protect Sheet
2. Enter a password
3. Choose what users can do (selecting cells is usually allowed)
4. Click OK
5. Now anyone who tries to edit gets a warning

**Protect a Workbook (prevent adding/deleting sheets):**
1. Review → Protect Workbook
2. Enter a password
3. Users can't add, delete, move, or rename sheets

**Unprotect:**
  - Review → Unprotect Sheet / Unprotect Workbook
  - Enter the password

**Selective cell locking (let users edit only specific cells):**
1. Select all cells (`Ctrl+A`) → Format Cells (`Ctrl+1`) → Protection tab → uncheck "Locked"
2. Select only the cells you want to protect → Format Cells → Protection → check "Locked"
3. Review → Protect Sheet → set password
4. Result: Only the locked cells are protected, unlocked cells can still be edited

> **⚠️ Warning:** Excel passwords can be removed by third-party tools. Use them to prevent accidental changes, not for absolute security. Always keep a backup of important passwords.
