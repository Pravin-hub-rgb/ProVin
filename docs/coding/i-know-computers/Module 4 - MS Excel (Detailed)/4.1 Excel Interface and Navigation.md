### What is Excel

Excel is a **spreadsheet** program. Data is organized in rows and columns, and calculations happen automatically using formulas.

  - **Workbook:** An entire Excel file (`.xlsx`). One workbook can have many sheets.
  - **Worksheet (Sheet):** One tab within a workbook — like one page in a notebook.
  - **Cell:** The intersection of a row and column. Each cell has an address like `A1`, `B3`, `F10`.
  - **Row:** Horizontal — labeled with numbers (1, 2, 3...)
  - **Column:** Vertical — labeled with letters (A, B, C...)

> **💡 Analogy:** Think of a workbook as a binder. Each sheet is a page in that binder. Each cell is a single box where you write one piece of information.

### Excel Interface

![Excel Interface — Annotated](/diagrams/iknowcomputers/excel-interface.svg)

| Part | Location | What It Does |
|---|---|---|
| **Ribbon** | Top (Home, Insert, Formulas, Data, etc.) | All tools organized in tabs |
| **Name Box** | Top-left (shows `A1`) | Shows which cell is currently selected |
| **Formula Bar** | Next to Name Box | Shows the content of the selected cell |
| **Column Letters** | Top of the grid (A, B, C...) | Identify columns |
| **Row Numbers** | Left of the grid (1, 2, 3...) | Identify rows |
| **Cell** | Intersection of a row and column | Where you enter data |
| **Sheet Tabs** | Bottom-left (Sheet1, Sheet2...) | Switch between sheets in the workbook |
| **Status Bar** | Bottom | Sum, average, count of selected cells |

### Navigation Shortcuts

Moving around Excel without a mouse makes you much faster:

| Shortcut | Where It Takes You |
|---|---|
| **Arrow keys** | One cell in that direction |
| **Tab** | One cell to the right |
| **Enter** | One cell down |
| **Shift+Tab** | One cell to the left |
| **Ctrl+Arrow** | Jump to the last cell with data in that direction |
| **Ctrl+Home** | Cell A1 (the beginning of the sheet) |
| **Ctrl+End** | The last cell that has data in the sheet |
| **Page Up / Page Down** | One screen up / down |
| **Ctrl+G or F5** | Go To dialog — type a cell address (like `G50`) and jump to it |

> **💡 Tip:** Try to navigate Excel using only the keyboard for 5 minutes. You'll notice how much faster it is than clicking with the mouse.

### Selecting Cells

| Action | How to Do It |
|---|---|
| **Single cell** | Click it or arrow-key to it |
| **Range of cells** | Click the first cell → hold Shift → click the last cell |
| **Multiple non-adjacent cells** | Hold Ctrl and click each cell |
| **Entire row** | Click the row number (or `Shift+Space`) |
| **Entire column** | Click the column letter (or `Ctrl+Space`) |
| **Entire sheet** | Click the triangle at the top-left corner (or `Ctrl+A` twice) |

### 🧠 Chapter Summary

> ✅ **Excel** = spreadsheet software for data and calculations  
> ✅ **Workbook** = file (`.xlsx`). **Worksheet** = one tab inside the workbook  
> ✅ **Cell address** = Column letter + Row number (like `B5`)  
> ✅ **Navigation:** Arrow keys, Tab, Enter — or Ctrl+Arrow to jump to data edges  
> ✅ **Name Box** shows your current cell. **Formula Bar** shows cell content  
> ✅ **Selecting:** Click + Shift for ranges, Ctrl for multiple separate cells

### 🎯 Real Task

1. Open Excel (`Ctrl+N`). Navigate using only the keyboard: press `Ctrl+End` to find the last used cell (should be A1 since it's blank). Press `Ctrl+Home` to return to A1.
2. Press `F5` → type `Z100` → Enter — you jump to cell Z100. Type your name there. Press `Ctrl+Home` to go back to A1.
3. Hold Ctrl and press the **Down Arrow** — you jump to Z100 (the last cell with data). This is how you navigate large sheets quickly.
