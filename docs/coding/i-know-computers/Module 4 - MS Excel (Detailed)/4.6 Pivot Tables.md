In the last chapter, we learned how to sort, filter, and clean data. Now let's learn one of Excel's most powerful tools — **Pivot Tables**. A Pivot Table summarizes large amounts of data in seconds. Instead of writing formulas manually, you drag and drop to get instant insights. In the next chapter, we'll learn charts and graphs.


### What is a Pivot Table

A Pivot Table is a tool that **summarizes** large data with drag and drop. No formulas needed.

**Example:** You have 500 rows of sales data. With a Pivot Table, you can find:
  - Total sales by region (in 2 clicks)
  - Average sale amount per salesperson
  - Number of orders by month
  - All of the above in one table

Without a Pivot Table, you'd need complex formulas. With a Pivot Table, you just drag fields.

---

### Creating a Pivot Table

1. Click anywhere in your data
2. **Insert → PivotTable** (or press `Alt+N+V`)
3. A dialog box appears — make sure the range is correct
4. Choose **New Worksheet** (so the Pivot Table is on a separate sheet)
5. Click OK

A blank Pivot Table appears with the **PivotTable Fields** panel on the right.

---

### PivotTable Fields Panel

The panel has four areas:

| Area | What It Does | Example |
|---|---|---|
| **Rows** | Categories that appear as rows | "Department" → each department is a row |
| **Columns** | Categories that appear as column headers | "Year" → each year is a column |
| **Values** | The numbers to calculate | "Salary" → sum of salaries |
| **Filters** | Filter the entire Pivot Table | "City" → show only Delhi data |

**To use it:** Drag field names from the top list into the four areas below. Excel instantly builds the table.

---

### Examples

**Example 1 — Count of Pass/Fail:**
1. Drag "Result" into **Rows**
2. Drag "Student Name" (or any text field) into **Values** — it automatically counts
3. Result: Pass = 45, Fail = 5

**Example 2 — Average marks by subject:**
1. Leave **Rows** empty (or add "Result" if you want pass/fail separate)
2. Drag "English" into **Values** → click the field → Value Field Settings → **Average**
3. Drag "Math" into **Values** → Average
4. Drag "Science" into **Values** → Average
5. Result: Class average for each subject

**Example 3 — Sales by region and month:**
1. Drag "Region" into **Rows**
2. Drag "Month" into **Columns**
3. Drag "Amount" into **Values** → Sum
4. Result: Total sales for each region in each month

---

### Refreshing a Pivot Table

If you change the original data, the Pivot Table does **not** update automatically.

To refresh: Right-click anywhere on the Pivot Table → **Refresh** (or Data tab → Refresh)

> **💡 Tip:** Make it a habit to refresh your Pivot Table after changing source data. If your table doesn't look right, Refresh is usually the fix.

**Pivot Table 1 — Total Sales by Region:**
1. Click anywhere in your data → Insert → PivotTable → New Worksheet → OK
2. Drag **Region** into **Rows**
3. Drag **Amount** into **Values**
4. Done — you now see total sales for North, South, East, West

**Pivot Table 2 — Sales by Region (rows) and Month (columns):**
1. Create a new Pivot Table (or copy and paste the first one)
2. Drag **Region** into **Rows**
3. Drag **Month** into **Columns**
4. Drag **Amount** into **Values**
5. Now you see a grid: each region's sales broken down by month

**Pivot Table 3 — Average Qty per Salesperson:**
1. Create a new Pivot Table
2. Drag **Salesperson** into **Rows**
3. Drag **Qty** into **Values** → click the field → Value Field Settings → **Average**
4. Now you see average quantity sold by each person

**Pivot Table 4 — Filter by Item:**
1. Create a new Pivot Table
2. Drag **Salesperson** into **Rows**, **Amount** into **Values**
3. Drag **Item** into **Filters**
4. A filter appears above the Pivot Table — click the dropdown, select "Laptop", click OK
5. Now you see only Laptop sales per person

**Pivot Table 5 — Refresh practice:**
1. Go back to the original data. Change cell A2 ("North") to "West". 
2. Go back to Pivot Table 1 → right-click → **Refresh**. See how North's total decreased and West's increased.
