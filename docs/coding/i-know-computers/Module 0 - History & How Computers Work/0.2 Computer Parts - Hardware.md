In the last chapter, we saw where computers came from — now let's talk about what's inside. CPU, RAM, storage, motherboard — these parts together make a computer. When you know what each part does, you can decide for yourself — "which laptop should I buy?" — and when your computer is slow, you'll understand why.

# Module 0 — History & How Computers Work

**Why this module matters:**  
Using a computer is one thing, understanding it is another. When you know what the CPU does and what RAM is — troubleshooting becomes much easier. It also helps in interviews.


**What is Hardware:**  
Anything you can physically touch — monitor, keyboard, CPU box — that's all hardware.

### Main Components

  **CPU — Central Processing Unit**  
  "Brain of the computer." Every task happens here — calculations, decisions, following instructions. Speed is measured in GHz. Higher GHz means faster.  
  Example: Intel Core i5, i7 | AMD Ryzen 5

  ![CPU — Brain of the Computer](/diagrams/iknowcomputers/cpu-chip.svg)

  Now that we know the CPU is the brain, the next question is — where does it do its work? It needs a workspace to hold whatever it's currently processing. That workspace is called **RAM**.

  **RAM — Random Access Memory**  
  "Short-term memory." Whatever task is running right now lives in RAM. Close your browser → RAM is freed. More RAM means more programs can run at the same time.  
  Measure: In GB. For office work, 8GB is enough.

  **Storage — Hard Disk / SSD**  
  "Long-term memory." Files, photos, videos, software — everything is saved here permanently. Power off → data stays.  
  HDD (Hard Disk Drive) — old, slow, cheap  
  SSD (Solid State Drive) — fast, slightly expensive, what modern laptops use

  ![RAM vs Storage — Short-term vs Long-term Memory](/diagrams/iknowcomputers/ram-storage.svg)

  We've covered the brain (CPU), the workspace (RAM), and the filing cabinet (Storage). But how do all these parts talk to each other? They need a central connection point. That's the **Motherboard**.

  **Motherboard**  
  All parts are connected to this — CPU, RAM, storage, ports, everything. The "backbone" of the computer.

  **Monitor**  
  Screen — what you're looking at. Size in inches. Resolution — HD (1280x720), Full HD (1920x1080).

  **Keyboard + Mouse**  
  Input devices — this is how you give instructions to the computer.

  **Power Supply**  
  Converts electricity into a usable form. In laptops: battery + adapter.

  Now that we know all the internal parts, let's step back and look at how we interact with the computer. We give it information through **input devices**, and it shows us results through **output devices**.

### Input vs Output Devices

| Input (you → computer) | Output (computer → you) |
|---|---|
| Keyboard | Monitor |
| Mouse | Printer |
| Scanner | Speakers |
| Microphone | Projector |
| Camera | Headphones |
