🔧 1. COMPUTER HARDWARE
> Hardware means everything you can physically touch. A Computer Operator should know how to identify all of these and solve basic problems.
📦 Components — Identify and function
☐ CPU (Processor) — The "brain" of the computer. Intel and AMD are both brands. Know the difference between Core i3, i5, i7. More cores/GHz = faster.
🔍 YouTube: `"CPU kya hota hai Hindi mein explained"`
☐ RAM (Random Access Memory) — The computer's short-term memory. Comes in 4GB, 8GB, 16GB. Know the difference between DDR3 and DDR4. Watch how to install a RAM stick.
🔍 YouTube: `"how to install RAM in PC step by step"`
🔍 YouTube: `"DDR3 vs DDR4 RAM difference explained"`
☐ Motherboard — All components connect to this. Identify the CPU socket, RAM slots, SATA ports.
🔍 YouTube: `"motherboard parts explained for beginners"`
☐ Hard Disk Drive (HDD) vs SSD — HDD is slow, SSD is fast. Connects via SATA cable. Understand storage sizes (500GB, 1TB).
🔍 YouTube: `"HDD vs SSD difference Hindi"`
☐ SMPS (Switch Mode Power Supply) — The power supply unit. Sits inside the CPU cabinet, takes power from the wall and feeds all parts. Ratings like 450W, 600W.
🔍 YouTube: `"SMPS kya hota hai computer mein"`
☐ GPU / Graphics Card — For display. Basic computers have integrated graphics (inside the CPU). A dedicated GPU is a separate card.
🔍 YouTube: `"integrated vs dedicated graphics card difference"`
☐ Monitor — VGA, HDMI, DisplayPort — three port types. Understand refresh rate (60Hz, 144Hz) and resolution (1080p, 4K).
🔍 YouTube: `"monitor ports explained VGA HDMI DisplayPort"`
☐ Keyboard & Mouse — PS/2 vs USB ports. Wireless vs wired. Know what the function keys (F1–F12) do.
🔍 YouTube: `"keyboard function keys F1 to F12 uses"`
☐ UPS (Uninterruptible Power Supply) — Gives you a little time to shut down when power goes out. Understand VA rating (600VA, 1KVA) and battery backup.
🔍 YouTube: `"UPS kaise kaam karta hai Hindi mein"`
☐ Printer — Difference between Inkjet and Laser. Know how to install drivers. Know how to clear a paper jam.
🔍 YouTube: `"printer driver install kaise kare Windows 10"`
🔍 YouTube: `"paper jam clear kaise kare printer mein"`
---
🛠️ Hardware Diagnosis — What to do when a problem occurs
☐ No display — Diagnose step by step:
Is the monitor powered on? Is the cable (VGA/HDMI) connected?
Is the CPU powered on? Are the fans running?
Is the RAM seated properly? Remove it, clean it, reseat it.
Is there a beep sound? (Beep codes = hardware error signals)
🔍 YouTube: `"computer no display troubleshooting step by step"`
☐ Computer hangs — Could be low RAM, a virus, or a full HDD. Check Task Manager (Ctrl+Shift+Esc) to see which program is using too much CPU/RAM.
🔍 YouTube: `"computer hang problem solution Windows 10 Hindi"`
☐ Computer runs slowly — Disable startup programs, run disk cleanup, uninstall unnecessary software.
🔍 YouTube: `"Windows 10 slow speed up kaise kare Hindi"`
☐ Keyboard/Mouse not working — Change the USB port. Check Device Manager. Update the driver.
🔍 YouTube: `"keyboard not working Windows 10 fix"`
☐ Printer not printing — Is the printer online? Clear the print queue. Reinstall the driver.
🔍 YouTube: `"printer not printing fix Windows"`
☐ Understanding Beep Codes — A beep during POST (Power On Self Test) is an error code. 1 beep = normal. Multiple beeps = RAM/GPU problem.
🔍 YouTube: `"BIOS beep codes meaning explained"`

⌨️ 4. TYPING SPEED
> Current speed is 50 WPM. Take it to 60+. This comes from practice, not theory.
☐ Learn touch typing — Typing without looking at the keyboard. Memorize the home position of fingers (ASDF JKL;)
🔍 YouTube: `"touch typing kaise seekhe Hindi beginners"`
🔍 Practice site: `typingclub.com` (free, structured lessons)
☐ Daily 20 min practice — Practice on `10fastfingers.com` or `typeracer.com`
☐ Accuracy first, speed later — Fast wrong typing is useless. Be accurate first; speed will grow on its own.
☐ Number row practice — Touch type the top-row numbers (1-9-0) too, especially for Excel.
☐ Achieve 60 WPM — A comfortable speed for data entry.

📋 7. DATA ENTRY SKILLS
> Accuracy + Speed = Perfect Data Entry Operator
☐ Double-check — Verify after entering. One wrong number can ruin everything.
☐ Work from the keyboard — Use the mouse less. Keyboard shortcuts make work faster.
☐ Tab key in Excel — While entering data, press Tab instead of Enter; it moves to the next column, which is faster.
☐ Use AutoFill — Serial numbers, dates, and patterns fill automatically in Excel.
☐ Copy-paste smartly — Paste Special (Ctrl+Alt+V) — paste only values, not formatting.
☐ Number formats — Set date format (DD/MM/YYYY), currency format, percentage correctly.
