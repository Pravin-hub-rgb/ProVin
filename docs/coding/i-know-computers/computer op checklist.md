🔧 1. COMPUTER HARDWARE
> Hardware matlab woh sab cheez jo tum haath se chhoo sako. Ek Computer Operator ko yeh sab pehchanna aana chahiye aur basic problems solve karni aani chahiye.
📦 Components — Pehchaan aur kaam
☐ CPU (Processor) — Computer ka "brain". Intel aur AMD dono brands hain. Core i3, i5, i7 ka difference pata ho. Jitna zyada cores/GHz, utna fast.
🔍 YouTube: `"CPU kya hota hai Hindi mein explained"`
☐ RAM (Random Access Memory) — Computer ki short-term memory. 4GB, 8GB, 16GB hoti hai. DDR3 vs DDR4 ka difference pata ho. RAM slot mein kaise lagaate hain yeh dekho.
🔍 YouTube: `"how to install RAM in PC step by step"`
🔍 YouTube: `"DDR3 vs DDR4 RAM difference explained"`
☐ Motherboard — Sab components isi mein lagte hain. CPU socket, RAM slots, SATA ports — yeh sab pehchaan.
🔍 YouTube: `"motherboard parts explained for beginners"`
☐ Hard Disk Drive (HDD) vs SSD — HDD slow hai, SSD fast. SATA cable se connect hota hai. Storage size (500GB, 1TB) samajh.
🔍 YouTube: `"HDD vs SSD difference Hindi"`
☐ SMPS (Switch Mode Power Supply) — Power supply unit. Yeh CPU cabinet ke andar hota hai, wall se bijli leke sab parts ko deta hai. 450W, 600W ratings hoti hain.
🔍 YouTube: `"SMPS kya hota hai computer mein"`
☐ GPU / Graphics Card — Display ke liye. Basic computers mein integrated graphics hoti hai (CPU ke andar). Dedicated GPU alag card hota hai.
🔍 YouTube: `"integrated vs dedicated graphics card difference"`
☐ Monitor — VGA, HDMI, DisplayPort — teen types ke ports hote hain. Refresh rate (60Hz, 144Hz) aur resolution (1080p, 4K) samajh.
🔍 YouTube: `"monitor ports explained VGA HDMI DisplayPort"`
☐ Keyboard & Mouse — PS/2 vs USB ports. Wireless vs wired. Keyboard shortcut keys (Function keys F1–F12) ka kaam pata ho.
🔍 YouTube: `"keyboard function keys F1 to F12 uses"`
☐ UPS (Uninterruptible Power Supply) — Light jaane par thoda time deta hai computer band karne ka. VA rating (600VA, 1KVA) samajh. Battery backup.
🔍 YouTube: `"UPS kaise kaam karta hai Hindi mein"`
☐ Printer — Inkjet vs Laser printer ka difference. Driver install karna aana chahiye. Paper jam clear karna aana chahiye.
🔍 YouTube: `"printer driver install kaise kare Windows 10"`
🔍 YouTube: `"paper jam clear kaise kare printer mein"`
---
🛠️ Hardware Diagnosis — Problem aaye toh kya kare?
☐ Display nahi aa raha (No Display) — Step by step diagnose karo:
Monitor ka power on hai? Cable (VGA/HDMI) connected hai?
CPU ka power on hai? Fans chal rahe hain?
RAM theek se lagi hai? Nikal ke saaf karke wapas lagao.
Beep sound aa rahi hai? (Beep codes = hardware error signals)
🔍 YouTube: `"computer no display troubleshooting step by step"`
☐ Computer hang ho raha hai — RAM kam ho sakti hai, virus ho sakta hai, ya HDD full ho sakti hai. Task Manager (Ctrl+Shift+Esc) se check karo kaunsa program zyada CPU/RAM le raha hai.
🔍 YouTube: `"computer hang problem solution Windows 10 Hindi"`
☐ Computer slow chal raha hai — Startup programs disable karo, disk cleanup karo, unnecessary software uninstall karo.
🔍 YouTube: `"Windows 10 slow speed up kaise kare Hindi"`
☐ Keyboard/Mouse kaam nahi kar raha — USB port change karo. Device Manager check karo. Driver update karo.
🔍 YouTube: `"keyboard not working Windows 10 fix"`
☐ Printer print nahi kar raha — Printer online hai? Print queue clear karo. Driver reinstall karo.
🔍 YouTube: `"printer not printing fix Windows"`
☐ Beep Codes samajhna — POST (Power On Self Test) ke time beep aati hai toh woh error code hai. 1 beep = normal. Multiple beeps = RAM/GPU problem.
🔍 YouTube: `"BIOS beep codes meaning explained"`

📊 2. MS EXCEL
> Excel ek Computer Operator ka sabse important tool hai. Deep level tak seekho — sirf basic nahi.
✅ Basics
☐ Interface samajhna — Ribbon, Cells, Rows, Columns, Sheet tabs, Formula bar — sab pehchaan.
🔍 YouTube: `"MS Excel complete tutorial for beginners Hindi"`
☐ Data entry aur formatting — Bold, Italic, Font size, Cell color, Borders, Merge & Center, Wrap Text.
🔍 YouTube: `"Excel cell formatting Hindi tutorial"`
☐ Column width aur Row height adjust karna
☐ Freeze Panes — Bade data mein header row hamesha dikhti rahe isliye.
🔍 YouTube: `"Excel freeze panes kaise kare"`
✅ Formulas — Yeh sabse important hain
☐ Basic formulas — `=SUM()`, `=AVERAGE()`, `=COUNT()`, `=MAX()`, `=MIN()`
☐ IF formula — `=IF(condition, value_if_true, value_if_false)` — conditions ke hisaab se result deta hai
🔍 YouTube: `"Excel IF formula Hindi mein explained"`
☐ VLOOKUP — Ek table se doosri table mein data dhundta hai (vertical). Bahut common interview question!
`=VLOOKUP(lookup_value, table_array, col_index, 0)`
🔍 YouTube: `"VLOOKUP Excel Hindi tutorial with example"`
☐ HLOOKUP — VLOOKUP jaisa, par horizontal (row mein dhundta hai)
🔍 YouTube: `"HLOOKUP Excel Hindi tutorial"`
☐ XLOOKUP — VLOOKUP ka improved version. Error handling bhi karta hai. New Excel mein hota hai.
🔍 YouTube: `"XLOOKUP Excel tutorial Hindi 2023"`
☐ COUNTIF / SUMIF — Condition ke hisaab se count ya sum karo
`=COUNTIF(range, criteria)` — kitni baar koi value aayi
`=SUMIF(range, criteria, sum_range)` — condition wali cheezein add karo
🔍 YouTube: `"Excel COUNTIF SUMIF Hindi tutorial"`
☐ CONCATENATE / & — Do cells ko join karna. `=A1&" "&B1` ya `=CONCAT(A1,B1)`
☐ LEFT, RIGHT, MID — Text se kuch characters nikaalte hain
🔍 YouTube: `"Excel text functions LEFT RIGHT MID Hindi"`
☐ DATE functions — `=TODAY()`, `=NOW()`, `=DATEDIF()` — dates ke saath kaam karna
🔍 YouTube: `"Excel date functions Hindi tutorial"`
✅ Data Management
☐ Sort & Filter — Data ko A-Z, Z-A, ya condition ke hisaab se filter karna
🔍 YouTube: `"Excel sort and filter kaise kare Hindi"`
☐ Data Validation — Cell mein sirf certain values allow karna (dropdown list banana)
🔍 YouTube: `"Excel data validation dropdown list Hindi"`
☐ Remove Duplicates — Duplicate entries hatana
🔍 YouTube: `"Excel remove duplicates Hindi"`
☐ Find & Replace — Ctrl+H — bade data mein kuch change karna ho toh
☐ Conditional Formatting — Values ke hisaab se color change hoti hai automatically
🔍 YouTube: `"Excel conditional formatting Hindi tutorial"`
✅ Pivot Table — Advance level
☐ Pivot Table banana — Bada data ka summary ek second mein. Bahut powerful tool.
🔍 YouTube: `"Excel pivot table tutorial Hindi beginners"`
☐ Pivot Chart — Pivot table se chart banana
✅ Charts & Graphs
☐ Bar Chart, Pie Chart, Line Chart — Data select karo, Insert > Chart.
🔍 YouTube: `"Excel charts kaise banaye Hindi tutorial"`

⌨️ 4. TYPING SPEED
> Abhi 50 WPM hai. 60+ tak le jaana hai. Yeh practice se hoga, theory se nahi.
☐ Touch typing seekhna — Bina keyboard dekhe likhna. Fingers ki home position yaad karo (ASDF JKL;)
🔍 YouTube: `"touch typing kaise seekhe Hindi beginners"`
🔍 Practice site: `typingclub.com` (free, structured lessons)
☐ Daily 20 min practice — `10fastfingers.com` ya `typeracer.com` pe practice karo
☐ Accuracy pehle, speed baad mein — Galat typing fast karna kaam ka nahi. Pehle accurate ho, speed apne aap badhegi.
☐ Number row practice — Top row numbers (1-9-0) bhi touch type karo, specially Excel ke liye
☐ 60 WPM achieve karna — Yeh ek comfortable speed hai data entry ke liye

🌐 5. INTERNET & EMAIL
> Office mein email professionally likhna bahut important hai.
✅ Email (Gmail)
☐ Professional email likhna — Subject line clear ho, body mein proper greeting (Dear Sir/Ma'am), proper closing (Regards, Yours sincerely)
🔍 YouTube: `"professional email kaise likhe Hindi"`

☐ Email folder management — Inbox, Sent, Drafts, Labels — organized rakhna
☐ Spam identify karna — Phishing emails pehchanna. Suspicious links pe click mat karo.
🔍 YouTube: `"email phishing scam kaise pehchane Hindi"`
✅ Internet
☐ Browser shortcuts — Ctrl+T (new tab), Ctrl+W (close tab), Ctrl+L (address bar), Ctrl+D (bookmark)
☐ Effective search karna — Google pe exact search ke liye quotes use karo `"exact phrase"`
☐ File download karna safely — Trusted sites se hi download karo. .exe files se careful raho.
☐ Google Drive basics — File upload, share, download. Office mein common hai.
🔍 YouTube: `"Google Drive kaise use kare Hindi beginners"`

📋 7. DATA ENTRY SKILLS
> Accuracy + Speed = Perfect Data Entry Operator
☐ Double-check karna — Enter karne ke baad verify karo. Ek galat number sab bigaad sakti hai.
☐ Keyboard se kaam karna — Mouse kam use karo. Keyboard shortcuts se fast kaam hota hai.
☐ Excel mein Tab key — Data entry ke time Enter ki jagah Tab dabaao, next column mein jaata hai, zyada fast.
☐ AutoFill use karna — Excel mein serial numbers, dates, patterns automatically fill hoti hain.
☐ Copy-paste smartly — Paste Special (Ctrl+Alt+V) — sirf values paste karo, formatting nahi.
☐ Number formats — Date format (DD/MM/YYYY), currency format, percentage — correctly set karo.
