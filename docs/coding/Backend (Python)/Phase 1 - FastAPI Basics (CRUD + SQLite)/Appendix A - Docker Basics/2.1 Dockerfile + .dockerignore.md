Ek `.dockerignore` file se Dockerfile ko **batao** ki kya files image me **nahi** jaayein. Jaise `.gitignore` — Docker bhi bohot saare cheezein skip karta hai.

---

## Step 1: `.dockerignore` likho

Project folder root me `.dockerignore` create karo:

```text
# Python bytecode
__pycache__/
*.py[cod]
*$py.class
*.so

# Virtual environment
venv/
.env
.venv/

# Git
.git/
.gitignore

# Data (SQLite DB — runtime pe generate hoti hai)
data/

# Docs (no need to ship docs in image)
*.md
!README.md

# IDE
.vscode/
.idea/
*.swp
.DS_Store

# OS
Thumbs.db
```

**Kyun?**
- Image chhota rehta hai — `venv/` nahi bhi gaya to 500MB+ image banti.
- Build fast rehta hai — `__pycache__/` rebuild se bacha deta.
- Security — `.env` secrets nahi jaate image me.
- SQLite DB runtime pe ban rahi hai (volume mount se — aage dekhoenge).

---

## Step 2: `Dockerfile` likho

Project folder root me `Dockerfile` create karo (koi extension nahi):

```dockerfile
# Base image — Python 3.12 slim (chhota, security-patched)
FROM python:3.12-slim

# Working directory set karo image ke andar
WORKDIR /app

# Pehle copy karo requirements.txt (cache optimize ke liye)
COPY requirements.txt .

# Install dependencies — --no-cache-dir se layer small rehta hai
RUN pip install --no-cache-dir -r requirements.txt

# Ab copy karo poora app folder
COPY . .

# Environment variables
ENV PYTHONUNBUFFERED=1
ENV PYTHONDONTWRITEBYTECODE=1

# Expose port
EXPOSE 8000

# Run command — uvicorn se app start karo
# 0.0.0.0 = sabhi interfaces pe suno (container ke bahar bhi reach paye)
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

## Step 3: Har line samjho

```dockerfile
FROM python:3.12-slim
```
- **Base image = python:3.12-slim**. `slim` = Debian ke upar minimal Python. Chhota (~150MB vs 900MB full image).
- Python 3.12 = tumhara Phase 1 project usi version pe ban chuka hai. Version match = dependency issues-free.

```dockerfile
WORKDIR /app
```
- Image ke andar ek `/app` folder ban jaye ga. Command `COPY . .` se sab kuch yahi aayega.
- Agar `WORKDIR` nahi deta to `COPY` working directory se relate hoti hai.

```dockerfile
COPY requirements.txt .
```
- Pehle sirf `requirements.txt` copy karo. **Yehi line cache-optimized hoti hai.**
- Agar app code change karo to Docker **nahi rebuild** karega `pip install` ko agar `requirements.txt` same ho.

```dockerfile
RUN pip install --no-cache-dir -r requirements.txt
```
- `--no-cache-dir` = pip cache files nahi banaye image me. Image 100MB+ chhota rehta.
- `fastapi`, `uvicorn`, `pandas` yahan install hote hain.

```dockerfile
COPY . .
```
- Ab baki sab (app/, data/, etc.) copy karo.
- `.dockerignore` se `venv/`, `__pycache__/`, `data/` skip honge.

```dockerfile
EXPOSE 8000
```
- Sirf **documentation** — image ko batao ki ye app port 8000 pe sunegga.
- Actual port mapping `docker-compose.yml` me hota (aage).

```dockerfile
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```
- `CMD` = container start hone pe konsi command chalegi.
- Format: `["executable", "arg1", "arg2"]` — **JSON array** style.
  - `app.main:app` = `app` folder ka `main` module, `app` wala variable (tumhara FastAPI app object).
  - `--host 0.0.0.0` = container ke bahar se bhi accessible. `127.0.0.1` localhi pe bandh deta.
  - `--port 8000` = container ke andar port.

---

## Common Mistakes

1. **`CMD` as string nahi dena** — `CMD uvicorn ...` likhne se shell parsing issues aati hain. JSON format use karo.
2. **`COPY . .` pehle nahi dena** — agar requirements install se pehle sab kuch copy kar diya, to har code change pe pura `pip install` rerun hoga.
3. **`requirements.txt` me `uvicorn[standard]` na dena** — basic `uvicorn` bhi chalta hai. Agar performance chahiye to upgrade karo.
4. **`__pycache__/` ko ignore na karna** — image me bloat hoti hai.

---

## What It Is NOT

- ❌ **Multi-stage build** — sirf ek hi `FROM`. Real production me build-stage + runtime-stage hote hain (100MB vs 20MB).
- ❌ **Non-root user** — production me `USER` add karte hain. Yeh basic setup hai.
- ❌ **Healthcheck** — container health monitor nahi. Post-offer the topic.

## Test Karo (Quick Check)

```bash
# Build image
docker build -t trading-backend-basic .

# Run container
docker run -p 8000:8000 trading-backend-basic

# Test — browser ya terminal dono se
curl http://localhost:8000/health
```

Expected response:
```json
{"status": "ok", "db": "connected"}
```

## Nutshell

- `.dockerignore` = `venv/`, `data/`, `__pycache__/`, `*.md` skip karta hai.
- `Dockerfile` = `python:3.12-slim` → copy requirements → install → copy app → run uvicorn.
- Har line ka purpose: base image, cache optimization, non-root, port exposure, host binding.
- `docker build -t <name> .` → `docker run -p 8000:8000 <name>`.
