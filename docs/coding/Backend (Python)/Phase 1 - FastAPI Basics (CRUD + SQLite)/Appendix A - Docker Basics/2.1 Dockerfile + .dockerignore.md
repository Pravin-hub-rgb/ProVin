Tell Docker which files should **not** go into the image using a `.dockerignore` file. Like `.gitignore` — Docker also skips many things.

---

## Step 1: Write `.dockerignore`

Create `.dockerignore` in your project folder root:

```text
# Python bytecode
__pycache__/
*.py[cod]
*$py.class
*.so

# Virtual environment
venv/
.env
.venv/

# Git
.git/
.gitignore

# Data (SQLite DB — generated at runtime)
data/

# Docs (no need to ship docs in image)
*.md
!README.md

# IDE
.vscode/
.idea/
*.swp
.DS_Store

# OS
Thumbs.db
```

**Why?**
- Image stays small — if `venv/` isn't included, image would be 500MB+.
- Build stays fast — `__pycache__/` is saved from rebuild.
- Security — `.env` secrets don't go into the image.
- SQLite DB is created at runtime (via volume mount — we'll see ahead).

---

## Step 2: Write `Dockerfile`

Create `Dockerfile` in your project folder root (no extension):

```dockerfile
# Base image — Python 3.12 slim (small, security-patched)
FROM python:3.12-slim

# Set working directory inside the image
WORKDIR /app

# Copy requirements.txt first (for cache optimization)
COPY requirements.txt .

# Install dependencies — --no-cache-dir keeps layers small
RUN pip install --no-cache-dir -r requirements.txt

# Now copy the whole app folder
COPY . .

# Environment variables
ENV PYTHONUNBUFFERED=1
ENV PYTHONDONTWRITEBYTECODE=1

# Expose port
EXPOSE 8000

# Run command — start app with uvicorn
# 0.0.0.0 = listen on all interfaces (reachable from outside container)
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

## Step 3: Understand Each Line

```dockerfile
FROM python:3.12-slim
```
- **Base image = `python:3.12-slim`**. `slim` = minimal Python on top of Debian. Small (~150MB vs 900MB full image).
- Python 3.12 = your Phase 1 project was built on this version. Version match = no dependency issues.

```dockerfile
WORKDIR /app
```
- An `/app` folder is created inside the image. `COPY . .` puts everything there.
- Without `WORKDIR`, `COPY` would relate to the working directory.

```dockerfile
COPY requirements.txt .
```
- First copy only `requirements.txt`. **This line is cache-optimized.**
- If you change app code, Docker **won't rebuild** `pip install` if `requirements.txt` is the same.

```dockerfile
RUN pip install --no-cache-dir -r requirements.txt
```
- `--no-cache-dir` = pip doesn't create cache files in the image. Image stays 100MB+ smaller.
- `fastapi`, `uvicorn`, `pandas` are installed here.

```dockerfile
COPY . .
```
- Now copy everything else (app/, data/, etc.).
- `.dockerignore` skips `venv/`, `__pycache__/`, `data/`.

```dockerfile
EXPOSE 8000
```
- Only **documentation** — tells the image this app listens on port 8000.
- Actual port mapping happens in `docker-compose.yml` (ahead).

```dockerfile
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```
- `CMD` = command that runs when container starts.
- Format: `["executable", "arg1", "arg2"]` — **JSON array style**.
  - `app.main:app` = `app` folder's `main` module, `app` variable (your FastAPI app object).
  - `--host 0.0.0.0` = accessible from outside the container too. `127.0.0.1` would bind to local only.
  - `--port 8000` = port inside the container.

---

## Common Mistakes

1. **`CMD` as string, not JSON** — `CMD uvicorn ...` causes shell parsing issues. Use JSON format.
2. **Not putting `COPY . .` first** — if you copy everything before requirements install, every code change triggers a full `pip install` rerun.
3. **Not using `uvicorn[standard]` in `requirements.txt`** — basic `uvicorn` also works. Upgrade if you need performance.
4. **Not ignoring `__pycache__/`** — image gets bloated.

---

## What It Is NOT

- ❌ **Multi-stage build** — only one `FROM`. Real production uses build-stage + runtime-stage (100MB vs 20MB).
- ❌ **Non-root user** — production adds `USER`. This is a basic setup.
- ❌ **Healthcheck** — no container health monitor. Post-offer topic.

## Test It (Quick Check)

```bash
# Build image
docker build -t trading-backend-basic .

# Test — browser or terminal
curl http://localhost:8000/health
```

Expected response:
```json
{"status": "ok", "db": "connected"}
```

## Nutshell

- `.dockerignore` = skips `venv/`, `data/`, `__pycache__/`, `*.md`.
- `Dockerfile` = `python:3.12-slim` → copy requirements → install → copy app → run uvicorn.
- Each line's purpose: base image, cache optimization, non-root, port exposure, host binding.
- `docker build -t <name> .` → `docker run -p 8000:8000 <name>`.
