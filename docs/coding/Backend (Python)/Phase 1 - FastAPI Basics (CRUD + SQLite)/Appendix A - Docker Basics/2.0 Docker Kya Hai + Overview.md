## What Is Docker (Understand in One Minute)

Think you have a **gift box**. Inside the gift box:
- Your FastAPI app (`app/` folder)
- Its dependencies (`requirements.txt`)
- A `data/` folder where SQLite DB lives

Gift box without Docker = raw code. If your friend doesn't have Python, or their `venv` broke, or their SQLite version is different — **the gift arrives broken**.

Gift box packed (with Docker) = **frozen environment**. Whatever works on your machine becomes the same image. Bring the "gift" to your friend, they open it and see it work.

Just like in Phase 1, every concept comes with a "pain first, then easy" comparison:

|--------------|----------------|

## How It Connects to Real TradeStack

TradeStack's `backend/server.py` is also FastAPI. Copy the same pattern:
- `Dockerfile` → `backend/Dockerfile`
- `docker-compose.yml` → root `docker-compose.yml`
- Volume mount → SQLite persistence in TradeStack too (`data/` folder)
- Port mapping → `5000:8000` (TradeStack ran on 5000)

**Phase 1 mini-project = TradeStack's 1% size.** Learn Docker here, then apply to real project — same pattern, bigger scale.
