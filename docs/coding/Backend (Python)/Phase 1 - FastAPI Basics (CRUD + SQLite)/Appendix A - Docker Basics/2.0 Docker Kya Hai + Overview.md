## Docker Kya Hai (Ek Minute Mein Samjho)

Socho tumhare paas ek **gift box** hai. Gift box ke andar:
- Teri FastAPI app (`app/` folder)
- Uske dependencies (`requirements.txt`)
- Ek `data/` folder jahan SQLite DB rakhti hai

Gift box bina Docker ke = seedha code. Jab tumhare friend ke paas Python ni hai, ya uska `venv` toot gaya, ya uski SQLite version alag hai — **gift toote hue aata hai**.

Gift box me bandhakar (Docker) = **environment freeze**. Jo teri machine pe kaam karta hai, wahi image ban jata hai. Friend ke saamne "gift" le aana, usko khulwa ke dekhna padta.

## Kya Chahiye Tumhe Pehle Se?

## Manual → Better

Jaise Phase 1 me dekha tha, har concept ke saath ek "pehle dard, phir aasaan" comparison milta hai:

| Pehle (dard) | Phir (Docker) |
|-------------|---------------|
| Friend ko bata "Python 3.12 chahiye, uvicorn chahiye, pandas chahiye" | Ek hi line: `docker compose up` |
| Manual `venv` + `pip install` har machine pe | `pip install` sirf image build time pe |
| Data folder manually copy karna | Volume auto-mount |
| Port conflict — 8000 doosre process pe | Isolated port mapping |

## Real TradeStack Se Kaise Jodenge?

TradeStack ka `backend/server.py` bhi FastAPI hai. Isi pattern ko copy karke:
- `Dockerfile` → `backend/Dockerfile`
- `docker-compose.yml` → root `docker-compose.yml`
- Volume mount → SQLite persistence TradeStack me bhi same hai (`data/` folder)
- Port mapping → `5000:8000` (TradeStack 5000 pe chalta tha)

**Phase 1 mini-project = TradeStack ka 1% size.** Docker seekh lo yahan pe, phir asli pe laga lo — same pattern, bigger scale.

## Kya Nahi Hai Ye Phase?

- ❌ **Production deployment** — no cloud, no CI/CD, no reverse proxy
- ❌ **Multi-stage builds** — sirf ek hi stage (`python:3.12-slim`)
- ❌ **Kubernetes / scaling workers** — ek service, ek container kaafi hai
- ❌ **Real TradeStack code nahi** — sirf Phase 1 project ka container banayenge
