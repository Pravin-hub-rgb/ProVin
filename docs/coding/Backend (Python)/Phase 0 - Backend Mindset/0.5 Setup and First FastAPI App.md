# 0.5 Setup + Pehla FastAPI App (Hello World)

Pichli file mein humne decide kiya ki FastAPI kyun chunna hai. Ab chal use chalte hain machine pe. Is file mein Python environment banayenge, FastAPI install karenge, aur pehla "Hello World" app chala ke `/docs` (auto Swagger documentation) dekhenge.

## Soch — Naye Kitchen Mein Pehla Khana

Tu ek naye restaurant open kar raha hai. Pehle kitchen ki workstation thik karni hai, tools arrange karne hain, phir ek simple dish (basic) banana practice karni hai. Java machine pe backend ka code likhne ke pehle bhi ek **environment** set up karna padta hai.

## Step 1 — Python Check

Pehle confirm karo ki Python installed hai. Terminal/command prompt mein:
```bash
python --version
# ya
python3 --version
```
Toh kuch aisa dikhega: `Python 3.12.x`. (FastAPI ke liye 3.8+ chahiye)

## Step 2 — Virtual Environment (venv)

**Problem:** Saare projects ek hi Python mein na mix ho jaayein (ek project ko Flask chahiye, doosre ko FastAPI — packages collide na ho). Isliye har project ka apna ek isolated environment banate hain.

```bash
# ek folder mein (apne project ka folder banao)
mkdir fastapi-course
cd fastapi-course

# venv banao
python -m venv venv
```

Yeh ek `venv` folder banata hai — project-specific Python copy.

## Step 3 — venv Activate

Linux/Mac:
```bash
source venv/bin/activate
```
Windows:
```powershell
.\venv\Scripts\activate
```

Terminal mein ab `(venv)` dikhega — matlab tu us isolated environment ke andar hai.

## Step 4 — FastAPI Aur "Uvicorn" Install

FastAPI ek Python framework hai — aur usse chalane ke liye ek **server** bhi chahiye (jaise database wali cheez main soch sakte hain). Server ko **uvicorn** kehte hain:

```bash
pip install fastapi
pip install "uvicorn[standard]"
```

> **FastAPI vs uvicorn:** FastAPI = framework (routes, validation, docs), uvicorn = ASGI server jo incoming requests handle karke FastAPI tak laata hai. TradeStack bhi inhi dono ko use karta hai (`backend/server.py`).

## Step 5 — Pehla App (main.py)

Ek `main.py` file banao jiska code yeh hai:

```python
from fastapi import FastAPI

# FastAPI ka app object bana (yeh poora "server program" hai)
app = FastAPI()

# '/' pe GET request aaye toh yeh function chalayega
@app.get("/")
def read_root():
    return {"message": "Hello, FastAPI!"}
```

Har line:
- `from fastapi import FastAPI` — FastAPI ko import karo
- `app = FastAPI()` — app banaya
- `@app.get("/")` — decorator: jab `/` pe GET request aaye
- `def read_root()` — function jo run hoga
- `return {"message": ...}` — yeh dict JSON ban ke response mein jayegi

## Step 6 — Chalao

```bash
uvicorn main:app --reload
```

- `main` = filename (`main.py`)
- `app` = variable naam (app object)
- `--reload` = code badalne pe khud restart (dev ke liye)

Browser kholo:
- **http://localhost:8000** → `{"message": "Hello, FastAPI!"}`
- **http://localhost:8000/docs** → 🎉 Swagger auto documentation (FastAPI ki superpower)

## Nutshell

**FastAPI install + uvicorn server + main.py = pehla app. `/docs` ise interactive documentation free deta hai — aur yahi TradeStack ka bhi core hai.**

## Ye Yeh Is NOT (Setup ke baare mein)

- ❌ **venv = Python ka second version nahi** — bas package isolation ka wrapper.
- ❌ **uvicorn = FastAPI ka hissa nahi** — alag server, FastAPI uska use karta hai.
- ❌ **`--reload` production ke liye nahi** — sirf dev ke liye hai.
