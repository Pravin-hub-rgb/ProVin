# 0.0 Course Kaise Chalega — Backend Ki Map

Socha hai tumne kabhi — jab tu google.com mein type karke Enter dabaata hai, toh screen pe pehle se bhari-2000 ki jaldi results kaise aa jaate hain? Woh saara kaam tumhare laptop mein nahi hota, tumhare screen ke peeche kahin dusre computer hota hai jo results dhokha deta hai, bhejta hai, aur tumhara browser usse dikhaata hai. Yeh "tumhare screen ke peeche ka computer" wali cheez hi backend hai.

Fir tera yakin bhi hai React, Next.js ka experience — frontend (jo user dekhta hai) toh tumne banaaya. Ab is course mein woh "peeche ka wala hissa" seekhenge — jo data ko store karta hai, calculations karta hai, aur rules decide karta hai ki kaun kya dekh sakta hai.

## Ye Course Kiske Liye Hai

Toh ek honest baat — likhna khud wahi padho jo upar likha hai: *"mujhe jhaat bhar bhi nahi aata backend, Flask kya hai, FastAPI kuch nahi pata."* Yeh course bilkul zero se hai, isliye koi sharminda hone ki zaroorat nahi. Tu khud hi bolega ki hum framework names sunte the, ab inke peeche ka concept nahi aata tha — youtube pe "backend roadmap" search karta tha par kuch samajh nahi aata tha.

Is course mein har cheez **zero** se, **familiar wali cheez** se shuru hoti hai. Har naye concept ko tune apni zindagi mein kisi na kisi cheez se compare karunga — restaurant, phone, email — taaki dar nahi lage, bal ki "haan yeh toh simple cheez hai" lage.

## Course Ka Structure

```
Phase 0: Backend Mindset   → (current) pure understanding, no project
Phase 1: Todo/Notes API    → simple project (CRUD + SQLite)
Phase 2: Chat App           → real-time (WebSocket)
Phase 3: TradeStack apply   → apne asli project pe
```

Pehle "backend duniya kaisi hai" samjhenge (Phase 0), phir code likhenge (Phase 1-2), phir sab ko apne TradeStack se jodenge (Phase 3).

## Abhi Tak Kya Hua

Kuch nahi — yeh pehli file hai. Isliye poori journey yahan se shuru padhi, seedha Phase 0 ke pehle note (0.1) par chalein.

## Ye Course Kya Hai — 1 Line Mein

**Backend = screen ke peeche ka hissa jo data store karta hai, requests process karta hai, aur bhejta hai — isse FastAPI (Python) se seekhenge, kyunki tera TradeStack hi isi pe bana hai.**

## What This Course Is NOT

- ❌ **Flask course** — Flask sirf ek jagah comparison mein aayega. Build hum FastAPI se karenge.
- ❌ **Django course** — sirf jaandari ke liye.
- ❌ **Python syntax course** — Python basics already maani gayi hai (pehle python notes kar lo).
- ❌ **Frontend course** — frontend tu already jaanta hai, yahan toh usse call karenge.

**In Your Own Words**

1. Backend kya hota hai, apne words mein? (Yeh soch ke answer karo ki jab tu kisi website pe login karte ho toh data kahan jaata hai?)

<details>
<summary>Sample Jawab</summary>

**Jawab:** Backend screen ke peeche ka wo hissa hai jahan data store hota hai, aur jo requests process karta hai. Jaise login karte waqt, password seedha browser mein saved nahi hota — woh backend ke paas jaata hai, wahan validate hota hai, aur response aata hai ki "login sahi" ya "galat". Jo user dekhta hai wo frontend hai, jo na dikhe wo backend.

</details>

2. Is course mein hum kaunsa framework seekhenge, aur kyun?

<details>
<summary>Sample Jawab</summary>

**Jawab:** FastAPI. Kyunki woh modern hai (auto docs, built-in validation, real-time support) aur sabse badi baat — tera TradeStack (`backend/server.py`) bilkul FastAPI pe bana hai. Jo seekhenge, wohi apne project mein dikhega aur kaam aayega.

</details>

3. Phase 0 mein project banaa toh jayega?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Nahi. Phase 0 pure understanding ke liye hai — backend ki duniya ka map. Code sirf Phase 1 se shuru hoga (0.5 mein chhota Hello World wahaan bhi aata hai setup karte waqt, lekin poora project Phase 1 mein).

</details>

4. Tu khud soch — ek website ka backend kyun chahiye? Sirf frontend se kaam kyon nahi chalta?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Kyunki data user ke browser ke andar nahi rehna chahiye. Agar sab frontend mein hota, toh kisi bhi user ke paas jo data website ka hai, woh kisi aur ke liye bhi access ho jaata. Backend data ko ek protected jagah (server/database) mein rakhta hai aur rules decide karta hai ki kaun kya dekh sakta hai. Frontend sirf us data ko dikhaata hai jo backend ne allow kiya.

</details>
