# 0.1 Client–Server Model — Jab Tu URL Kholta Hai

Pichli file mein humne backend ka mental map banaya tha — "screen ke peeche ka hissa". Ab is file mein isi ka sabse aasaan base model samajhte hain. Aur shuruaat karte hain ek aisi cheez se jo tu roz karta hai.

## Soch — Restaurant Ka Example

Ek restaurant mein do alag hisse hote hain:
- **Menu + Waiter ya tum (customer)** — yeh saamne dikhta hai
- **Kitchen** — peeche, jo order banata hai

Tu (customer) waiter ko kehta hai — *"khana order kar raha hoon."* Waiter us order ko kitchen tak le jaata hai. Kitchen khaana banata hai, phir waiter wapas leke aata hai aur table pe rakhta hai.

Is poori scene mein **tum** kabhi kitchen ke andar nahi jaate. Sirf order (request) bhejta hai, aur cooked dish (response) milta hai. Kitchen ke PEEHE ka logic — kya ingredients hain, kaise pakana hai — yeh sab tumhe nahi dikhta.

Ab yeh 1:1 wahi hota hai jo browser ke saath hota hai.

## Concept — Client Aur Server

| Naam | Kaun hai | Kya karta hai |
|------|----------|---------------|
| **Client** | Browser (aur mobile app, desktop app) | Request maangta hai — "mujhe yeh data do" |
| **Server** | Wo computer jo website ki files/data rakhta hai | Request process karta hai, data ya response bhejta hai |

Relationship simple hai:
```
Client (browser) --request--> Server (computer)
Client (browser) <--response-- Server
```

Yahi **Client–Server model** hai — duniya ki sabse basic internet architecture. Client server ko request bhejta hai, server wapas response bhejta hai. Yehi pair har website, har app ke peeche hota hai.

## Bas Example — Kaise Hoti Hai Request

Jab tu `google.com` kholta hai:
1. Tera browser (client) google ke server ko request bhejta hai — "mujhe home page do"
2. Google ka server request process karta hai
3. Server response bhejta hai — home page ka HTML/CSS/JS
4. Browser usko dikhaata hai

Yeh poora round trip mobile se Instagram chalaate waqt bhi hota hai — har photo load karne mein server se request/response.

## Analogy — Restaurant Hi

- Client = customer (jo dekh raha hai, maang raha hai)
- Server = kitchen + restaurant management (jo bana raha hai, decide kar raha hai)
- Browser (request) = order slip
- Response = cooked khaana

Restaurant ke saath ek khaas baat — tu kabhi kitchen ko nahi badal sakta ki "isse aise banao". Tu sirf order kar sakta hai. Wahi web mein — client server ke andar ghus kar data nahi badal sakta, sirf request kar sakta hai. Server hi decide karta hai.

## What Client–Server Is NOT

- ❌ **Client matlab sirf browser nahi** — mobile app, smartwatch, koi bhi device jo request bheje wo client hai.
- ❌ **Server = website ka pura code nahi** — server ek *computer/process* hai jo dono data rakhta hai aur request handle karta hai. Web hosting par jo files hoti hain unko host karta hai.
- ❌ **Server = WordPress/Dashboard nahi** — WordPress jaisi cheez server *pe chalti hai*, serve khud nahi hai.

## Analogy Summary

Client–Server pura model ek **waiter (client request) + kitchen (server)** hai. Client request karta hai, server decide + banata hai, response bhejta hai.

## Nutshell

**Client se request, server se response — yeh hi Client–Server model hai. Internet ki sabse basic architecture.**

**In Your Own Words**

1. Jab tu Instagram kholta hai, toh kaun client hai aur kaun server?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Tera phone/browser hamesha client hai — wo request bhejta hai ("mujhe feed do"). Instagram ke servers response bhejta hai (photos, posts). Kyunki data Instagram ke servers par store hota hai, tera phone sirf request/display karta hai, khud data nahi rakhta.

</details>

2. Client aur server ke beech kya hota hai? (2 steps)

<details>
<summary>Sample Jawab</summary>

**Jawab:** Client server ko **request** bhejta hai, aur server **response** wapas bhejta hai. Yeh hi round trip har website pe hota hai.

</details>

3. "Client server ke andar ghus kar data badal nahi sakta" — iska matlab kya hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Matlab - client sirf request kar sakta hai, server ki andar ki files ko directly touch nahi kar sakta. Saari authority server ke paas hai. Yehi security ka base hai.

</details>
