# 0.3 API + JSON — Data Kaise Hoti Hai Client Aur Server Ke Beech

Pichli file mein HTTP ke basics samjhe — GET/POST, status codes. Ab asli data ka topic aata hai. Jab server "data" bhejta hai (for example bank account details, Instagram posts, stock prices), woh data **kis format** mein bheja jaata hai? Yeh file isi ka jawab hai.

## Soch — Restaurant Menu Ka Order Form

Restaurant mein jab tu dish order karta hai, toh waiter ek **pad** (checklist/slip) pe likhta hai ek fixed way mein:
```
Dish: "Paneer Butter Masala"
Quantity: 2
Extra: "Less spicy"
```
Agar har restaurant apne alag tareeke se likhta — *"2 paneer medium spicy wala"* ya *"do paneer, less o*khali* — toh gaddbadd ho jaati. Isliye fixed format mein order likhte hain. **Server-client ke liye bhi format chahiye** — isi ko **JSON** kehte hain.

## Concept — What Is JSON

**JSON (JavaScript Object Notation)** ek format hai jismein data ko **key-value pairs** ke roop mein likha jaata hai. Sab modern APIs (aur FastAPI) isi format mein data bhejte hain.

JSON ka example:
```json
{
  "name": "Rahul",
  "age": 27,
  "city": "Mumbai",
  "isActive": true,
  "skills": ["Python", "FastAPI"]
}
```

Dekh — `"name": "Rahul"` matlab key `name` ki value `"Rahul"`. Strings `"..."` mein, numbers plain, booleans `true/false`, arrays `[...]`. Yehi wo "universal order slip" hai.

## API Kya Hai

**API (Application Programming Interface)** ek set of rules/URLs hai jisse client ko server (ya dusra program) se baat karta hai. Yaad karo restaurant wala — menu hota hai jisse tu order karta hai. **API = menu/server ka door**, jisse client data maangta hai.

| Cheez | Restaurant analogy |
|-------|--------------------|
| **API** | Menu — jisse tu jan ta hai ki kya maang sakte ho |
| **Endpoint** | Ek specific dish (kisi URL pe ek resource) |
| **JSON response** | Cooked dish — jo server wapas bhejta hai |

Real example:
```
GET https://api.twitter.com/2/tweets → (JSON) { "tweets": [ ... ] }
```

## Kya Isse Data Serialize Kar Ke Transmit Karte Hain

Yahan samajhne wali baat — python dict/object direct bitstream mein nahi bhej sakta. **Python objects ko text/string mein convert karte hain (serialize)** — wahi conversion JSON hai. Aur jab client kholo (React/Next.js) toh JSON wapas **parse** karta hai (deserialize) object mein.

Graph:
```
Python dict { "name": "Rahul" }
   ↓ (serialize)
JSON string: {"name": "Rahul" }
   ↓ (network pe bheja)
Client parse → JavaScript object
```

## Nutshell

**JSON = data ka universal text format. API = server se data maangne ke door (URLs + rules).**

## What API Is NOT

- ❌ **API = UI nahi** — API data/logic deta hai, UI dikhaata hai.
- ❌ **JSON = JavaScript-only nahi** — har language parse karti hai, bas naam JavaScript se aaya.
- ❌ **API sirf backend ke liye nahi** — tumhara frontend bhi kisi API ko call kar sakta hai.
