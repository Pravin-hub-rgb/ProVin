# Python Practice Set - Variables and Functions

**Instructions:** Complete each exercise by writing Python code that uses only the concepts covered in the notes. Do not use conditionals, loops, or any advanced features not mentioned in the notes.

## Basic Functions & Variables

### Exercise 1: Simple Greeting
Write a program that prints "Hello, World!" to the screen.

### Exercise 2: Personalized Greeting
Write a program that asks the user for their name and then prints "Hello, [name]!" where [name] is what the user typed.

### Exercise 3: User Input Storage
Write a program that:
1. Asks the user for their favorite color
2. Stores it in a variable called `favorite_color`
3. Prints "Your favorite color is [color]" where [color] is the stored value

### Exercise 4: Multiple Inputs
Write a program that asks for a person's first name and last name separately, then prints them together with a space between them.

## String Methods

### Exercise 7: Name Splitting

### Exercise 8: Text Formatting

### Exercise 9: Multiple String Operations

## Custom Functions

### Exercise 15: Simple Function

### Exercise 17: Function with Default Value

### Exercise 18: Function that Returns a Value

### Exercise 19: Multiple Return Values
