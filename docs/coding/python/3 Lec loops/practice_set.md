# Python Practice Set - Loops

**Instructions:** Complete each exercise by writing Python code that uses only the concepts covered in the 3rd lecture notes. Do not use advanced data structures, classes, or any features not mentioned in the notes.

## Basic Loops

### Exercise 1: Simple Counting
Write a program that prints the numbers 1 through 5 using a `while` loop.

### Exercise 2: Countdown
Write a program that counts down from 10 to 1, then prints "Blast off!" using a `while` loop.

### Exercise 3: For Loop Counting
Write a program that prints the numbers 0 through 4 using a `for` loop with `range()`.

### Exercise 4: String Multiplication
Write a program that prints a row of 10 asterisks (*) using string multiplication.

### Exercise 5: Input Validation
Write a program that keeps asking the user for a positive number until they enter one. Use `while True` with `break`.

## Lists and Iteration

### Exercise 6: List Creation and Access

### Exercise 7: List with Indices

### Exercise 8: List Operations

### Exercise 9: List Search

### Exercise 10: List Building
