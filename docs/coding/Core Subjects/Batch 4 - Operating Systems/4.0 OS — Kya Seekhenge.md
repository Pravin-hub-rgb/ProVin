## Kya Seekhenge Is Batch Mein

Paanch concepts hain, bas basics:

**A — Process vs Thread.** Node.js single-threaded hai but background mein threads hote hain. Process aur thread mein kya fark hai.

**B — Deadlock.** Do processes ek-dusre ka resource wait kar rahe hain, koi release nahi kar raha — sab stuck. Ye real bugs mein hota hai.

**C — Memory Management Basics.** Virtual memory, paging — ye OS kaise decide karta hai kaunsa program kitni memory use kare.

**D — Process States + Context Switching.** Process apni lifetime mein kis states se guzarta hai, aur CPU kaise switch karta hai.

**E — CPU Scheduling Algorithms.** OS decide karta hai kaunsa process kab CPU pe chalega — FCFS, SJF, Round Robin.
