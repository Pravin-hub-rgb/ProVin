Tumhara DukaanOS frontend browser mein chal raha hai, backend Vercel pe deploy hai, database Supabase pe hai. Ye sab kaise communicate karta hai? Frontend se request jaati hai, server response bhejta hai, data JSON mein aata hai. Ye sab kya hai? Ye sab **Computer Networks** ke concepts hain.

Tum `fetch('https://api.example.com/products')` likhte ho — but ye request kaise jaati hai? Server tak kaise pahunchti hai? Response wapas kaise aata hai? HTTP kya hai? TCP kya hai? DNS kya hai? Ye sab samajhna zaroori hai — sirf `fetch()` likhna nahi, andar kya ho raha hai ye jaanna hai.

## Kya Seekhenge Is Batch Mein

Che concepts hain, har ek tumhare daily kaam se connected:

**A — OSI Model.** Internet ka 7-layer architecture. Ye jaanna zaroori hai ki data ek device se dusre tak kaise jaata hai — bas layers ka order yaad rakho.

**B — TCP vs UDP.** Do tareeke hain data bhejne ke — reliable (TCP) ya fast (UDP). Tumhara WebSocket TCP pe based hai — kyunki trading data mein reliability chahiye.

**C — HTTP vs HTTPS.** Tum daily HTTP requests bhej rahe ho — but HTTPS kaise secure karta hai? SSL/TLS handshake kya hai?

**D — DNS.** Domain name (jaise `google.com`) IP address mein kaise convert hota hai? Ye tumhari Trishul Insurance deployment mein directly use hua hai.

**E — REST API + HTTP Methods + Status Codes.** Tum Next.js API routes banate ho — GET, POST, PUT, DELETE. Ye REST principles hain.

**F — WebSockets.** REST ki limitation — client ko har baar khud request bhejni padti hai. WebSocket se server khud data push kar sakta hai. Tumhara trading bot WebSocket use karta hai.
