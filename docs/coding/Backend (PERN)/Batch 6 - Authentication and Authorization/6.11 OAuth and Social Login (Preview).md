One lesson, no code. What "Sign in with Google" does conceptually, and why teams use identity providers.

**What OAuth does:**

1. User clicks "Sign in with Google."
2. Redirected to Google (identity provider).
3. Google authenticates user.
4. Google redirects back with authorization code.
5. Backend exchanges code for tokens.
6. Backend creates/links user account.

**Why teams use it:**

- No password storage (less security burden).
- SSO (single sign-on across apps).
- Trust (Google handles auth).

**Trade-offs:**

- Dependency on identity provider.
- Complexity (redirect flows, token exchange).
- Less control over user data.
