# Doc 6.5 — Login and the Access Token

## Cheat Sheet (Quick Recall)

- Verify password with `argon2.verify`.
- Issue short-lived JWT with `jose`.
- JWT: three parts (header, payload, signature). Signed, not encrypted.
- Never put secrets in JWT payload.
- Algorithm pinning: specify `alg` explicitly.
- Generic error: "Invalid credentials" (no enumeration).

Verify the password, then issue a short-lived signed JWT with `jose`.

```ts
import { SignJWT } from "jose";

app.post("/auth/login", validate(loginSchema), async (req, res) => {
  const { email, password } = req.body;
  const user = await prisma.user.findUnique({ where: { email } });
  if (!user) {
    res.status(401).json({ error: { code: "UNAUTHORIZED", message: "Invalid credentials" } });
    return;
  }
  const valid = await argon2.verify(user.passwordHash, password);
  if (!valid) {
    res.status(401).json({ error: { code: "UNAUTHORIZED", message: "Invalid credentials" } });
    return;
  }
  const secret = new TextEncoder().encode(process.env.JWT_SECRET);
  const token = await new SignJWT({ sub: user.id, role: user.role })
    .setProtectedHeader({ alg: "HS256" })
    .setExpirationTime("15m")
    .sign(secret);
  res.json({ data: { accessToken: token } });
});
```

- **JWT:** three parts (header, payload, signature). Signed, not encrypted.
- **Claims:** `sub` (subject/user ID), `exp` (expiry).
- **Secret:** kept in config (env var).
- **Algorithm pinning:** specify `alg` explicitly (HS256).
- **Generic error:** same message for unknown email or wrong password (prevents enumeration).

**Break it on purpose:** decode a token by hand, change a character, watch verification fail.

## What It Is NOT

- JWT is **not** encrypted — it is signed (payload is readable).
- Secrets are **not** for the payload — anyone can decode it.
- Algorithm is **not** optional — pin it explicitly.

---

## Common Mistakes

- Putting secrets in JWT payload.
- Not pinning algorithm (algorithm confusion attack).
- Different error messages for unknown email vs wrong password (enumeration).
- Access token never expiring.
