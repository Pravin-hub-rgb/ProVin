# Doc 6.10 — Logout, Password Change and Session Invalidation

## Cheat Sheet (Quick Recall)

- Logout: revoke refresh token.
- Password change: invalidate other sessions.
- Stateless tokens: logout means revoke refresh token.
- Revoke refresh token family on logout.

What logout actually does with stateless tokens: revoke refresh tokens, change password and invalidate other sessions.

```ts
app.post("/auth/logout", authMiddleware, async (req, res) => {
  // revoke refresh token family
  await prisma.refreshToken.updateMany({
    where: { userId: req.user.id },
    data: { revoked: true },
  });
  res.clearCookie("refreshToken");
  res.status(204).send();
});

app.post("/auth/change-password", authMiddleware, validate(changePasswordSchema), async (req, res) => {
  const { currentPassword, newPassword } = req.body;
  const user = await prisma.user.findUnique({ where: { id: req.user.id } });
  if (!user || !(await argon2.verify(user.passwordHash, currentPassword))) {
    res.status(401).json({ error: { code: "UNAUTHORIZED", message: "Invalid credentials" } });
    return;
  }
  const hash = await argon2.hash(newPassword);
  await prisma.user.update({ where: { id: user.id }, data: { passwordHash: hash } });
  // invalidate other sessions
  await prisma.refreshToken.updateMany({
    where: { userId: user.id },
    data: { revoked: true },
  });
  res.status(204).send();
});
```

- **Logout:** revoke refresh token, clear cookie.
- **Password change:** verify current, hash new, revoke all other sessions.
- **Stateless tokens:** access token expires on its own; refresh token must be revoked.

## What It Is NOT

- Logout is **not** deleting the access token (it expires on its own).
- Password change is **not** just updating the hash — invalidate other sessions.
- Revoking is **not** optional — stolen refresh tokens must be invalidated.

---

## Common Mistakes

- Not revoking refresh tokens on logout.
- Not invalidating other sessions on password change.
- Thinking stateless means no server-side state (refresh tokens are stored).
