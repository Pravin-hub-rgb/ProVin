Auth has many pitfalls. First user enumeration, then JWT pitfalls, then XSS vs CSRF, then token storage.

**User enumeration:**

- Different error messages ("email not found" vs "wrong password") leak info.
- Different response times leak info.
- Fix: generic "Invalid credentials" + constant-time comparison.

**JWT pitfalls:**

- No algorithm pinning → algorithm confusion attack.
- No expiry → stolen token valid forever.
- Secrets in payload → anyone can decode.

**XSS vs CSRF:**

- XSS: injected script steals token (if in localStorage).
- CSRF: cross-site request forges action (cookie-based).
- `SameSite` and `httpOnly` help.

**Token storage in React:**

- `localStorage` → XSS risk.
- `httpOnly` cookie → CSRF risk (mitigated by `SameSite`).
- Understand the trade-offs.
