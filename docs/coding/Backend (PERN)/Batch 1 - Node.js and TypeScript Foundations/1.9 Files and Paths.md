Node provides built-in modules for filesystem operations.

```ts
import { readFile, writeFile, readdir } from "node:fs/promises";
import path from "node:path";
import os from "node:os";

// Read
const content = await readFile("file.txt", "utf-8");

// Write
await writeFile("out.txt", "Hello");

// List
const files = await readdir(".");

// Path operations
const full = path.join("src", "index.ts");
const base = path.basename(full); // "index.ts"
const dir = path.dirname(full);   // "src"
const ext = path.extname(full);   // ".ts"

// OS info
console.log(os.homedir());
console.log(os.tmpdir());
console.log(os.platform());
```

- `node:fs/promises` for async file operations.
- `node:path` for path manipulation (cross-platform).
- `node:os` for system info.
- `import.meta.url` for current file location.

## Common Mistakes

- Using `fs.readFileSync` on huge files (blocks the loop).
- Hardcoding path separators (`/` vs `\`).
- Not handling file errors (try/catch).

## Questions

1. Which module for async file operations?

**Answer:** `node:fs/promises`.

2. How to join paths cross-platform?

**Answer:** `path.join("src", "index.ts")`.

3. What does `path.basename` return?

**Answer:** The file name (e.g., "index.ts").

4. What does `path.extname` return?

**Answer:** The extension (e.g., ".ts").

5. What does `os.homedir()` return?

**Answer:** The user's home directory.
