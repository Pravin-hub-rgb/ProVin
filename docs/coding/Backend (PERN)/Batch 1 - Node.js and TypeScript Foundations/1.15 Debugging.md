## Problem — How Do You Find and Fix Bugs?

Debugging is finding and fixing bugs. Node + VS Code make it easy. First console methods, then VS Code debugger, then attach.

**Console methods:**

```ts
console.log("value:", x);
console.error("error:", err);
console.table([{ a: 1 }, { a: 2 }]);
console.time("label");
// ... work ...
console.timeEnd("label");
```

**VS Code debugger:**

1. Set breakpoints (click left of line number).
2. Press F5 (or Run -> Start Debugging).
3. Use launch.json for config.

**Attach to running process:**

```bash
node --inspect src/server.ts
```

Then attach VS Code debugger to the running process.

**Debugging workflow:**

1. Reproduce the bug.
2. Set a breakpoint near the suspected code.
3. Inspect variables, step through.
4. Fix and verify.

## What It Is NOT

- `console.log` is **not** a debugger — it is a print statement.
- Breakpoints are **not** guesses — they pause execution.
- `--inspect` is **not** automatic — you must attach.

---

## Common Mistakes

- Using `console.log` everywhere (use debugger).
- Not setting breakpoints (guessing).
- Forgetting `--inspect` for attach.
