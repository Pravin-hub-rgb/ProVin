## Problem — How Do You Start a Node Project from Scratch?

You have Node installed. But an empty folder is not a project. You need `package.json`, scripts, a source folder, and a way to run and type-check. First create the project, then add scripts, then run it.

Start from an empty folder. Create a Node project from scratch.

```bash
mkdir my-api
cd my-api
npm init -y
```

This creates `package.json`. Add `"type": "module"` for ES modules:

```json
{
  "name": "my-api",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "dev": "node --watch src/server.ts",
    "check": "tsc --noEmit"
  }
}
```

Create `src/` folder and a first file:

```bash
mkdir src
echo "console.log('Hello, Node!')" > src/server.ts
```

Run it:

```bash
npm run dev
```

## What It Is NOT

- `"type": "module"` is **not** optional — without it, Node uses CommonJS.
- `npm run dev` is **not** type-checking — it only runs the code.
- Code in root is **not** organized — use `src/`.

---

## Common Mistakes

- Forgetting `"type": "module"` → CommonJS errors.
- Not adding scripts → typing long commands.
- Putting code in root instead of `src/`.

---

## Try It Yourself

1. Start from an empty folder and add `dev` and `check` scripts.
2. Run `npm run dev` and see "Hello, Node!".
3. Run `npm run check` (should pass).
