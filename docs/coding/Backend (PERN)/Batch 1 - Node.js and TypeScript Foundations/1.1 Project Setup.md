Start from an empty folder. Create a Node project from scratch.

```bash
mkdir my-api
cd my-api
npm init -y
```

This creates `package.json`. Add `"type": "module"` for ES modules:

```json
{
  "name": "my-api",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "dev": "node --watch src/server.ts",
    "check": "tsc --noEmit"
  }
}
```

Create `src/` folder and a first file:

```bash
mkdir src
echo "console.log('Hello, Node!')" > src/server.ts
```

Run it:

```bash
npm run dev
```

## Common Mistakes

- Forgetting `"type": "module"` → CommonJS errors.
- Not adding scripts → typing long commands.
- Putting code in root instead of `src/`.

## Try It Yourself

1. Start from an empty folder and add `dev` and `check` scripts.
2. Run `npm run dev` and see "Hello, Node!".
3. Run `npm run check` (should pass).

## Questions

1. What command creates `package.json`?

**Answer:** `npm init -y`.

2. What does `"type": "module"` do?

**Answer:** Enables ES modules (import/export) in Node.

3. What is the `dev` script?

**Answer:** `node --watch src/server.ts` (runs with auto-restart).

4. What is the `check` script?

**Answer:** `tsc --noEmit` (type-checks without emitting files).

5. Why put code in `src/`?

**Answer:** Organization; separates source from config.
