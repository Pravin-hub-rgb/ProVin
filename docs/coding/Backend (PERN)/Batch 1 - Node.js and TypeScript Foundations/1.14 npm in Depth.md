# Doc 1.14 — npm in Depth

## Cheat Sheet (Quick Recall)

- `dependencies`: needed at runtime.
- `devDependencies`: needed for development only.
- `package-lock.json`: locks exact versions.
- `npm ci`: clean install from lockfile (CI).
- `npm audit`: security vulnerabilities.
- `npx`: run package binaries.

npm manages packages and dependencies.

```bash
npm install express        # add dependency
npm install -D typescript  # add devDependency
npm ci                     # clean install from lockfile
npm audit                  # check vulnerabilities
npx tsc --noEmit           # run binary
```

- `dependencies`: needed at runtime (shipped to production).
- `devDependencies`: dev tools (TypeScript, ESLint, Prettier).
- `package-lock.json`: exact versions for reproducible installs.
- `npm ci`: clean install (used in CI, faster, stricter).
- `npx`: run a package binary without global install.

**Semver:**

- `^1.2.3` → `>=1.2.3 <2.0.0` (minor updates).
- `~1.2.3` → `>=1.2.3 <1.3.0` (patch updates).
- `1.2.3` → exact version.

## Common Mistakes

- Committing `node_modules` (add to `.gitignore`).
- Not committing `package-lock.json`.
- Using `npm install` in CI instead of `npm ci`.
