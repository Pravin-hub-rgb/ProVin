Register and login forms with React Hook Form and Zod, access token in memory, refresh token in httpOnly cookie.

```ts
// Login form
const { register, handleSubmit } = useForm<LoginInput>({
  resolver: zodResolver(loginSchema),
});

const onSubmit = async (data: LoginInput) => {
  const res = await apiClient("/auth/login", { method: "POST", body: JSON.stringify(data) });
  setAccessToken(res.data.accessToken); // in memory, NOT localStorage
};

// API client with credentials
const res = await fetch(url, { credentials: "include" });
```

- **Access token:** in memory (not localStorage — XSS risk).
- **Refresh token:** httpOnly cookie (automatic with `credentials: 'include'`).
- **CORS:** `credentials: true` on backend.
- **Forms:** React Hook Form + shared Zod schema.

## What It Is NOT

- Access token in `localStorage` is **not** safe — XSS risk.
- `credentials: 'include'` is **not** optional — needed for cookies.
- CORS without `credentials: true` is **not** enough for cookies.

---

## Common Mistakes

- Storing access token in `localStorage` (XSS).
- Forgetting `credentials: 'include'`.
- CORS not configured for credentials.
