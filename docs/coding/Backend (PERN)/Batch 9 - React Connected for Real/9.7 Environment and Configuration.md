# Doc 9.7 — Environment and Configuration

## Cheat Sheet (Quick Recall)

- Frontend env vars are public (visible in bundle).
- Different API URLs per environment.
- No secrets in frontend.
- `VITE_API_URL` for Vite.

---

Frontend environment variables are public — anything in the bundle is visible. Different API URLs per environment. No secrets in the frontend.

```ts
// .env (frontend)
VITE_API_URL=http://localhost:3000

// In code
const apiUrl = import.meta.env.VITE_API_URL;
```

- **Public:** all `VITE_` vars are in the bundle (visible to anyone).
- **No secrets:** never put API keys or tokens in frontend env.
- **Per environment:** `.env.development`, `.env.production`.
- **Different API URLs:** local vs production.

## What It Is NOT

- Frontend env vars are **not** secret — they are in the bundle.
- `VITE_` prefix is **not** optional — Vite only exposes prefixed vars.
- Backend secrets are **not** for the frontend.

---

## Common Mistakes

- Putting secrets in frontend env.
- Hardcoding API URL.
- Not using per-environment files.
