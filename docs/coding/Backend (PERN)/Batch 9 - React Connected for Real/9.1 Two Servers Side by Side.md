# Doc 9.1 — Two Servers Side by Side

## Cheat Sheet (Quick Recall)

- Frontend (Vite) and backend (Express) run on different ports.
- Browser treats them as two origins.
- CORS: allow cross-origin with configured origin.
- Dev proxy: Vite proxies `/api` to backend (avoids CORS in dev).

Running the Vite dev server and the API together. The browser sees them as two origins. Two ways to cross: CORS (2B.7/7.3) or a dev proxy in Vite.

```ts
// vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      "/api": "http://localhost:3000",
    },
  },
});
```

- **CORS:** allow cross-origin with configured origin (needed in production).
- **Dev proxy:** Vite forwards `/api` to backend (avoids CORS in dev).
- **When to use which:** proxy in dev, CORS in production.

## What It Is NOT

- Proxy is **not** for production — use CORS.
- CORS is **not** needed in dev if using proxy.
- Two servers are **not** one origin — different ports = different origins.

---

## Common Mistakes

- Forgetting `credentials: 'include'` with CORS.
- Not configuring proxy in dev (CORS errors).
- Mixing proxy and CORS (confusing).
