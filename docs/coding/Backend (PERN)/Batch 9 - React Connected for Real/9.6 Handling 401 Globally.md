On a 401, attempt one refresh, retry the original request, and on failure send the user to login. Avoid refresh storms.

```ts
let isRefreshing = false;
let refreshPromise: Promise<string> | null = null;

async function apiClient<T>(path: string, options?: RequestInit): Promise<T> {
  const res = await fetch(url, { ...options, credentials: "include" });
  if (res.status === 401 && !isRefreshing) {
    isRefreshing = true;
    refreshPromise = refreshToken();
    try {
      await refreshPromise;
      // retry original request
      return apiClient(path, options);
    } catch {
      redirectToLogin();
      throw new ApiError(401, "UNAUTHORIZED", "Session expired");
    } finally {
      isRefreshing = false;
      refreshPromise = null;
    }
  }
  // ...
}
```

- **One refresh at a time:** `isRefreshing` flag.
- **Shared promise:** all 401s await the same refresh.
- **Retry:** original request retried after refresh.
- **Failure:** redirect to login.

## What It Is NOT

- Refresh storms are **not** acceptable — use a single shared promise.
- Multiple refreshes are **not** needed — one refresh serves all.
- Silent refresh is **not** infinite — redirect on failure.

---

## Common Mistakes

- Multiple refreshes (refresh storm).
- Not redirecting on failure.
- Infinite retry loop.
