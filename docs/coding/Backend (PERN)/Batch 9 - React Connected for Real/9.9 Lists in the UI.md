Pagination controls, tag filter, search wired to API query params. URL as source of truth.

```ts
import { useSearchParams } from "react-router";

function BookmarksPage() {
  const [searchParams, setSearchParams] = useSearchParams();
  const tag = searchParams.get("tag") || "";
  const page = Number(searchParams.get("page")) || 1;

  const { data } = useQuery({
    queryKey: ["bookmarks", { tag, page }],
    queryFn: () => apiClient(`/bookmarks?tag=${tag}&page=${page}`),
  });

  return (
    <div>
      <input value={tag} onChange={(e) => setSearchParams({ tag: e.target.value, page: "1" })} />
      {/* list + pagination controls */}
    </div>
  );
}
```

- **Pagination controls:** next/prev, page numbers.
- **Tag filter:** dropdown or chips.
- **Search:** text input (debounced).
- **URL as source of truth:** query params in URL (`?tag=js&page=2`).

## What It Is NOT

- URL state is **not** optional — it enables sharing/bookmarking.
- Filters are **not** in component state — they are in URL.
- Pagination is **not** client-side — it is server-side.

---

## Common Mistakes

- Not syncing filters to URL.
- Client-side pagination (should be server-side).
- Not debouncing search.
