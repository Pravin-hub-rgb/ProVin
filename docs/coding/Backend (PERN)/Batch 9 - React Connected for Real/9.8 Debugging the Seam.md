A guided tour of failures: CORS error (really server error), cookie not set (SameSite/Secure), preflight failing, 401 loop. Use Network tab, API logs, request id to trace.

**Common failures:**

1. **CORS error that is really a server error:** The browser shows CORS, but the actual error is 500. Check Network tab → response body.
2. **Cookie not set:** `SameSite` or `Secure` on localhost. Use `SameSite=Lax` in dev.
3. **Preflight failing:** OPTIONS request returns 404/500. Check server handles OPTIONS.
4. **401 loop:** refresh fails, retries infinitely. Check refresh logic.

**Debugging workflow:**

1. Open Network tab.
2. Find the failing request.
3. Check request/response headers.
4. Check API logs (request id).
5. Trace end-to-end.

## What It Is NOT

- CORS error is **not** always a CORS issue — check the response body.
- Cookie issues are **not** always code — check `SameSite`/`Secure`.
- 401 loop is **not** normal — fix refresh logic.

---

## Common Mistakes

- Assuming CORS error is CORS.
- Not checking `SameSite`/`Secure`.
- Not tracing with request id.
