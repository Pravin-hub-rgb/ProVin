Socket.IO adds rooms, acknowledgements, auto-reconnect, fallbacks over raw `ws`.

```ts
import { Server } from "socket.io";

const io = new Server(3000, { cors: { origin: "http://localhost:5173" } });

io.on("connection", (socket) => {
  socket.join("room1");
  io.to("room1").emit("message", "Hello room");
  socket.emit("event", { data: 1 }, (ack) => {
    console.log("Client acknowledged:", ack);
  });
});
```

- **Rooms:** `socket.join("room")`, `io.to("room").emit()`.
- **Acknowledgements:** callback on `emit`.
- **Auto-reconnect:** client reconnects automatically.
- **Fallbacks:** falls back to polling if WebSocket unavailable.

**Compare line counts:** manual `ws` (heartbeats, rooms, reconnect) vs Socket.IO (built-in).

## What It Is NOT

- Socket.IO is **not** raw `ws` — it adds features.
- Rooms are **not** in `ws` — manual grouping.
- Auto-reconnect is **not** in `ws` — manual handling.

---

## Common Mistakes

- Using Socket.IO when raw `ws` suffices.
- Not using rooms (broadcast to all).
- Ignoring acknowledgements.
