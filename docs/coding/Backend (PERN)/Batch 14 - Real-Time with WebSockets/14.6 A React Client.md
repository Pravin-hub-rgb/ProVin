A hook that connects, handles reconnect, and updates TanStack Query's cache when events arrive.

```ts
import { useEffect } from "react";
import { io, Socket } from "socket.io-client";
import { useQueryClient } from "@tanstack/react-query";

function useSocket(userId: string) {
  const queryClient = useQueryClient();

  useEffect(() => {
    const socket: Socket = io("http://localhost:3000", { auth: { token: accessToken } });

    socket.on("bookmark:updated", (data) => {
      queryClient.invalidateQueries({ queryKey: ["bookmarks"] });
    });

    socket.on("disconnect", () => {
      console.log("Disconnected");
    });

    return () => {
      socket.disconnect();
    };
  }, [userId]);
}
```

- **Connection:** `io(url, { auth })`.
- **Receive:** `socket.on("event", callback)`.
- **Send:** `socket.emit("event", data)`.
- **Cleanup:** `socket.disconnect()` on unmount.
- **Reconnect:** Socket.IO auto-reconnects.

## What It Is NOT

- Socket is **not** HTTP — it is persistent.
- Cleanup is **not** optional — prevent leaks.
- Auto-reconnect is **not** in raw `ws` — Socket.IO provides it.

---

## Common Mistakes

- Not cleaning up on unmount (memory leaks).
- Not handling reconnect.
- Not invalidating cache on events.
