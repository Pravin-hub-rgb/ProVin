Raw `ws` has manual problems. First heartbeats (dead connections), then rooms (grouping), then reconnect, then message formats.

```ts
// Heartbeat
ws.isAlive = true;
ws.on("pong", () => { ws.isAlive = true; });
setInterval(() => {
  wss.clients.forEach((ws) => {
    if (!ws.isAlive) ws.terminate();
    ws.isAlive = false;
    ws.ping();
  });
}, 30000);

// Rooms (manual)
const rooms = new Map<string, Set<WebSocket>>();
function joinRoom(ws, room) {
  if (!rooms.has(room)) rooms.set(room, new Set());
  rooms.get(room)!.add(ws);
}
```

- **Heartbeats:** detect dead connections (ping/pong).
- **Rooms:** group connections by hand (Map of Sets).
- **Reconnect:** client must handle reconnection.
- **Message formats:** JSON strings (`JSON.stringify`/`parse`).

**Break it on purpose:** drop a connection silently and watch it pile up.

## What It Is NOT

- Heartbeats are **not** automatic — you must implement.
- Rooms are **not** built into `ws` — manual grouping.
- Reconnect is **not** automatic — client must handle.

---

## Common Mistakes

- No heartbeat → dead connections pile up.
- No room cleanup → memory leaks.
- No reconnect logic → client stuck.
