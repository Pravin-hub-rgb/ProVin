WebSockets give a persistent bidirectional connection. First handshake, then messages, then connection lifecycle.

```ts
import { WebSocketServer } from "ws";

const wss = new WebSocketServer({ port: 8080 });

wss.on("connection", (ws) => {
  console.log("Client connected");

  ws.on("message", (data) => {
    console.log("Received:", data.toString());
    ws.send(`Echo: ${data}`); // echo back
  });

  ws.on("close", () => {
    console.log("Client disconnected");
  });

  ws.send("Welcome!");
});
```

- **Handshake:** HTTP upgrade request → WebSocket connection.
- **`wss.on("connection")`:** fires when a client connects.
- **`ws.on("message")`:** fires when a message arrives.
- **`ws.send()`:** sends a message to the client.
- **`ws.on("close")`:** fires when connection closes.

**Broadcast to all clients:**

```ts
wss.clients.forEach((client) => {
  if (client.readyState === WebSocket.OPEN) {
    client.send("Hello all");
  }
});
```

## What It Is NOT

- WebSocket is **not** HTTP — it is a persistent connection.
- `ws` is **not** Socket.IO — raw library, no rooms/reconnect.
- `ws.send()` is **not** `res.json()` — it is a message, not an HTTP response.

---

## Common Mistakes

- Not handling `close` (memory leaks).
- Not checking `readyState` before sending.
- Blocking the event loop in message handler.
