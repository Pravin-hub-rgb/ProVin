## Problem — Why Is an In-Memory Data Store Useful?

Redis is an in-memory data store. Memory is fast but costs size and persistence. First what Redis is, then where it sits, then the cost.

```bash
docker run --name redis -p 6379:6379 -d redis:8
redis-cli
> SET key value
> GET key
```

- **In-memory:** data in RAM (fast).
- **Cost:** size (RAM is limited), persistence (data lost on restart unless configured).
- **Where it sits:** between app and database, as cache/shared state.

## What It Is NOT

- Redis is **not** a database replacement — it is a cache/shared store.
- Redis is **not** persistent by default — data lost on restart.
- Redis is **not** for large data — RAM is limited.

---

## Common Mistakes

- Treating Redis as source of truth.
- Not configuring persistence.
- Storing large data in Redis.
