Redis has five core data types. Each has specific commands.

```bash
SET key value
HSET user:1 name "Vin" age 25
LPUSH list "item1"
SADD set "a" "b"
ZADD leaderboard 100 "player1"
EXPIRE key 3600   # TTL 1 hour
```

- **Strings:** simple key-value.
- **Hashes:** field-value pairs (like objects).
- **Lists:** ordered collection (push/pop).
- **Sets:** unique values.
- **Sorted sets:** scored values (leaderboards).
- **TTL:** `EXPIRE key seconds` (auto-delete).

## What It Is NOT

- Redis is **not** a relational database — no joins, no constraints.
- TTL is **not** optional — set expiry to prevent memory growth.
- Key naming is **not** arbitrary — use consistent patterns.

---

## Common Mistakes

- No TTL → memory grows forever.
- Wrong data type for the use case.
- Inconsistent key naming.
