`ioredis` is the one client used throughout (BullMQ in Batch 13 is built on it).

```ts
import Redis from "ioredis";

const redis = new Redis(process.env.REDIS_URL || "redis://localhost:6379");

// Strings
await redis.set("key", "value", "EX", 3600); // TTL 1 hour
const val = await redis.get("key");

// Hashes
await redis.hset("user:1", "name", "Vin", "age", "25");
const name = await redis.hget("user:1", "name");

// Shutdown
process.on("SIGTERM", () => redis.quit());
```

- `new Redis(url)` — connects.
- Commands: `set`, `get`, `hset`, `hget`, `lpush`, `sadd`, `zadd`.
- JSON values: `JSON.stringify` / `JSON.parse`.
- Connection handling: auto-reconnect.
- Shutdown: `redis.quit()`.

## What It Is NOT

- `ioredis` is **not** the only client — but it is the one used here.
- Redis is **not** the source of truth — it is a cache.
- `redis.quit()` is **not** optional — close on shutdown.

---

## Common Mistakes

- Not handling connection errors.
- Not closing on shutdown.
- Storing objects without stringify.
