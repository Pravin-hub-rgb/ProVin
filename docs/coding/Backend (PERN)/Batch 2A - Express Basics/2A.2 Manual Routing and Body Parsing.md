## Problem — Why Is Raw Routing Painful?

You handle `req.method` and `req.url` manually. Body parsing requires reading chunks. Every route repeats the same parsing and header code. First feel the pain, then Express solves it.

```ts
import http from "node:http";

const server = http.createServer(async (req, res) => {
  if (req.method === "GET" && req.url === "/items") {
    res.setHeader("Content-Type", "application/json");
    res.end(JSON.stringify([{ id: 1, name: "Item" }]));
    return;
  }

  if (req.method === "POST" && req.url === "/items") {
    const chunks: Buffer[] = [];
    for await (const chunk of req) {
      chunks.push(chunk);
    }
    const body = Buffer.concat(chunks).toString();
    let data;
    try {
      data = JSON.parse(body);
    } catch {
      res.statusCode = 400;
      res.end(JSON.stringify({ error: "Bad JSON" }));
      return;
    }
    res.statusCode = 201;
    res.setHeader("Content-Type", "application/json");
    res.end(JSON.stringify({ id: 2, ...data }));
    return;
  }

  res.statusCode = 404;
  res.end("Not found");
});

server.listen(3000);
```

- Branch on `req.method` and `req.url`.
- Read body as stream of chunks.
- `JSON.parse` inside `try`/`catch`.
- Return 400 on bad JSON.
- Every route repeats parsing and header code.

## What It Is NOT

- Manual routing is **not** scalable — Express solves this.
- `JSON.parse` is **not** safe on untrusted input — use try/catch.
- Body parsing is **not** automatic in raw Node.

---

## Common Mistakes

- Not handling bad JSON → crash.
- Forgetting to set `Content-Type`.
- Repeating parsing code in every route.
