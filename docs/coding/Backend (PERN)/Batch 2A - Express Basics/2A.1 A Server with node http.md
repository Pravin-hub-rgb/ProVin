## Problem — How Does a Server Actually Receive and Send Data?

Before Express, you need to feel the raw version. Node's `http` module gives you a server. You handle `req` (request) and `res` (response). First create a server, then route by method+URL, then end the response.

```ts
import http from "node:http";

const server = http.createServer((req, res) => {
  if (req.method === "GET" && req.url === "/health") {
    res.statusCode = 200;
    res.setHeader("Content-Type", "application/json");
    res.end(JSON.stringify({ status: "ok" }));
  } else {
    res.statusCode = 404;
    res.end("Not found");
  }
});

server.listen(3000, () => {
  console.log("Server on http://localhost:3000");
});
```

- `http.createServer(callback)` — creates a server.
- `req` — the incoming request (method, url, headers).
- `res` — the response you send back.
- `res.end()` — ends the response (must call it).
- `server.listen(port)` — starts listening.

**Break it on purpose:**

- Forget `res.end()` → client hangs forever.
- Send two responses → "Cannot set headers after they are sent."

## What It Is NOT

- `http.createServer` is **not** Express — it is raw Node.
- `res.end()` is **not** optional — the response must be ended.
- `server.listen` is **not** `app.listen` — that is Express.

---

## Common Mistakes

- Forgetting `res.end()` → client hangs.
- Sending two responses → header error.
- Not setting `Content-Type`.

## Summary

- `http.createServer(callback)` creates a raw server.
- `req` = request, `res` = response.
- `res.end()` must be called to send the response.
- `server.listen(port)` starts the server.
