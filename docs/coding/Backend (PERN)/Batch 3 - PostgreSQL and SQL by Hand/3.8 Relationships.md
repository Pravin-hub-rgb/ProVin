Relationships connect tables. Three types: one-to-many, many-to-many, one-to-one.

```
One-to-many:
  authors (1) ──► books (many)
  books.author_id → authors.id

Many-to-many:
  books ◄──► book_authors ◄──► authors
  (join table with two FKs)

One-to-one:
  users (1) ──► profiles (1)
  profiles.user_id → users.id (UNIQUE)
```

- **One-to-many:** FK in the "many" table (e.g., `books.author_id`).
- **Many-to-many:** join table with two FKs (e.g., `book_authors`).
- **One-to-one:** FK with `UNIQUE` (e.g., `profiles.user_id`).

## What It Is NOT

- FK is **not** automatic — you must define it.
- Many-to-many is **not** two columns in one table — use a join table.
- One-to-one is **not** just a FK — it needs `UNIQUE`.

---

## Common Mistakes

- Storing arrays in a column (use join table).
- Missing FK constraints.
- Not using `ON DELETE CASCADE`.
