## Problem — How Do You Start Postgres and Connect to It?

PostgreSQL runs as a server. Start it with Docker (or native installer), then connect with `psql` or a GUI client.

```bash
# Docker (recommended)
docker run --name pg -e POSTGRES_PASSWORD=secret -p 5432:5432 -d postgres:18

# Connect with psql
psql -h localhost -U postgres -d postgres
```

- **Docker:** run Postgres in a container (teaches Docker later in Batch 10).
- **psql:** command-line client.
- **GUI client:** DBeaver or pgAdmin (shown, not taught).

**Connect string:** `postgres://user:pass@localhost:5432/dbname`.

## What It Is NOT

- Docker is **not** required — native installer works too.
- `psql` is **not** the only client — GUI clients exist.
- Postgres is **not** running in your app — it is a separate server.

---

## Common Mistakes

- Wrong port (5432 default).
- Wrong credentials.
- Not starting the server before connecting.
