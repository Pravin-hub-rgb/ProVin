Connect Node to Postgres using the `pg` driver. Always use parameterized queries.

```ts
import { Pool } from "pg";

const pool = new Pool({ connectionString: process.env.DATABASE_URL });

// Parameterized query (safe)
const result = await pool.query(
  "SELECT * FROM bookmarks WHERE url = $1",
  ["https://example.com"]
);
console.log(result.rows);

// SQL injection (dangerous — never do this)
const bad = await pool.query(
  `SELECT * FROM bookmarks WHERE url = '${userInput}'` // INJECTION!
);
```

- `Pool`: manages connections (reuse, not one per request).
- `$1`, `$2`: parameterized placeholders (safe).
- `pool.query(sql, params)`: executes query.
- SQL injection: string concatenation is dangerous.

**Break it on purpose:** an injection attempt that succeeds against string concatenation and fails against parameters.

## What It Is NOT

- String concatenation is **not** safe — always parameterize.
- `Pool` is **not** a single connection — it manages many.
- `pg` is **not** an ORM — it is a driver.

---

## Common Mistakes

- Building SQL by concatenating user input (injection).
- Not using `Pool` (one connection per request).
- Not closing the pool (leaks).
