# Doc 7.9 — Secrets and Dependency Hygiene

## Cheat Sheet (Quick Recall)

- Secrets: never in Git, use env vars or secret managers.
- Rotate leaked secrets immediately.
- `npm audit`: checks vulnerabilities.
- Pin dependencies, review updates.
- Supply-chain risk: malicious packages.

```bash
# Never commit secrets
echo ".env" >> .gitignore

# Run audit
npm audit

# Pin a dependency
npm install express@5.0.0 --save-exact
```

- **Secrets:** env vars or secret managers (never Git).
- **Rotate:** if leaked, change immediately + invalidate old.
- **`npm audit`:** checks known vulnerabilities.
- **Pinning:** lock exact versions.
- **Supply-chain risk:** malicious packages, typosquatting.

## What It Is NOT

- `npm audit` is **not** gospel — review findings.
- Secrets in Git are **not** recoverable — rotate immediately.
- Pinning is **not** always best — balance security and updates.

---

## Common Mistakes

- Committing `.env` (secrets leaked).
- Ignoring `npm audit` findings.
- Not rotating leaked secrets.
- Blindly updating dependencies.
