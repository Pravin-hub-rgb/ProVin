## Problem — What Can Go Wrong with Your API?

A plain-language tour of the OWASP Top 10 categories that matter for an API. Each item is tied to something you have already built.

- **Broken access control** — user A reads user B's data. You fixed this in 6.8 (ownership check).
- **Injection** — SQL injection via string concatenation. You fixed this in 3.16 (parameterized queries).
- **Security misconfiguration** — missing headers, open CORS, default credentials.
- **Vulnerable dependencies** — outdated packages with known CVEs.
- **Identification and authentication failures** — weak passwords, no rate limiting.
- **Logging failures** — no logs, or logs with secrets.

## What It Is NOT

- OWASP is **not** a checklist to memorize — it is a lens for thinking.
- Security is **not** a one-time task — it is ongoing.
- This is **not** a full penetration test — it is awareness.

---

## Common Mistakes

- Thinking security is someone else's job.
- Ignoring OWASP categories that apply to your API.
- Not tying categories to your own code.
