Deployment concepts: PaaS vs server, managed DB, env vars, HTTPS, domain.

- **PaaS (Platform-as-a-Service):** Render, Railway, Fly.io. Easy, managed.
- **Renting a server:** VPS (DigitalOcean, AWS EC2). Full control, more work.
- **Managed Postgres:** database hosted by provider (e.g., Supabase, Neon).
- **Self-hosted Postgres:** you manage it (Docker).
- **Env vars/secrets:** set on the hosting platform.
- **HTTPS:** certificates (Let's Encrypt, or platform-managed).
- **Domain:** DNS points to the app (callback to Module 0.8).

**One-page deployment plan:** choose platform, DB, env vars, domain.

## What It Is NOT

- PaaS is **not** the only option — VPS works too.
- Managed DB is **not** free — check pricing.
- HTTPS is **not** optional — always use it.

---

## Common Mistakes

- Hardcoding secrets in code.
- Not using HTTPS.
- Wrong DNS configuration.
