Deploy the database, the API, and the React app. Set production env vars, run migrations, confirm `/ready`, fix production-only problems.

```bash
# Deploy DB (managed Postgres)
# Set DATABASE_URL in platform env

# Deploy API
docker build -t my-api .
# Push to registry
# Deploy on platform

# Deploy web
npm run build
# Deploy static files

# Run migrations
npx prisma migrate deploy

# Verify
curl https://api.example.com/ready
```

**Production-only problems:**

- CORS origin (must be production URL, not localhost).
- Cookie `Secure` and `SameSite` (must work over HTTPS).
- Proxy IP (`trust proxy`).

**Mini-project:** a live URL.

## What It Is NOT

- Deploying is **not** instant — migrations and config take time.
- Production env is **not** dev env — different URLs, secrets.
- `localhost` is **not** for production — use real domain.

---

## Common Mistakes

- Not running migrations in production.
- Wrong CORS origin (localhost in prod).
- Cookie not working (SameSite/Secure).
- Not setting `trust proxy`.
