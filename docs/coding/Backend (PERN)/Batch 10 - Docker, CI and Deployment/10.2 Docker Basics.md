Docker commands for running containers, viewing logs, executing commands, mapping ports, and using volumes.

```bash
docker run --name pg -e POSTGRES_PASSWORD=secret -p 5432:5432 -d postgres:18
docker ps
docker logs pg
docker exec -it pg psql -U postgres
```

- `docker run`: start a container.
  - `-e`: env var.
  - `-p`: port mapping (host:container).
  - `-d`: detached (background).
- `docker ps`: list running containers.
- `docker logs`: view output.
- `docker exec -it`: run command inside container.
- **Volumes:** `-v pgdata:/var/lib/postgresql/data` keeps data across restarts.

**Break it on purpose:** remove a container without a volume and lose the data.

## What It Is NOT

- `docker run` is **not** `docker start` — run creates new, start restarts existing.
- Without a volume, data is **not** persisted.
- `docker exec` is **not** `docker run` — exec runs in existing container.

---

## Common Mistakes

- Removing container without volume → data lost.
- Wrong port mapping (container:host vs host:container).
- Not using `-d` (blocks terminal).

---

## Try It Yourself

1. Run Postgres with a named volume.
2. Remove container, recreate, verify data persists.
3. Run without volume and lose data.
