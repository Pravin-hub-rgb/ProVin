---

CI runs checks on every push. Workflow, jobs, steps, triggers, caching.

```yaml
# .github/workflows/ci.yml
name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:18
        env:
          POSTGRES_PASSWORD: secret
        ports:
          - 5432:5432
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm ci
      - run: npm run check
      - run: npm run lint
      - run: npm test
```

- **Workflow:** defined in `.github/workflows/`.
- **Jobs:** parallel units of work.
- **Steps:** sequential commands.
- **Triggers:** `push`, `pull_request`.
- **Caching:** `actions/cache` for npm.

**Break it on purpose:** push a failing test and watch the check go red.

## What It Is NOT

- CI is **not** CD — CI checks, CD deploys.
- `npm install` is **not** for CI — use `npm ci`.
- CI is **not** optional — it catches bugs before merge.

---

## Common Mistakes

- Using `npm install` instead of `npm ci`.
- Not caching dependencies (slow).
- Not running tests in CI.
