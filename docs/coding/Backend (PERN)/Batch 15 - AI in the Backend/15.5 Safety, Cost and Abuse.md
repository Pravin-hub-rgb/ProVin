Prompt injection, per-user limits, timeouts, retries, logging without leaking PII.

```ts
// Per-user rate limit
const aiLimiter = rateLimit({
  windowMs: 60 * 1000,
  max: 10, // 10 AI requests per minute per user
  keyGenerator: (req) => req.user?.id || req.ip,
});

// Timeout
const response = await client.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 1024,
  messages: [{ role: "user", content: userInput }],
  // timeout handled by SDK or AbortController
});
```

- **Prompt injection:** user input can manipulate the model (e.g., "ignore previous instructions").
- **Tool permissions:** never give a tool more power than the user has.
- **Per-user limits:** rate limit + spending cap per user.
- **Timeouts/retries:** prevent hanging and handle failures.
- **Logging:** log without leaking personal data (redact PII).

## What It Is NOT

- Prompt injection is **not** fully preventable — reduce risk.
- AI is **not** free — set spending limits.
- Model output is **not** trusted — validate it.

---

## Common Mistakes

- Putting API key in frontend (leaked).
- Trusting model output (no validation).
- Giving tools broader access than user.
- No per-user limits (one user spends budget).
- Treating fetched web pages as trusted instructions.
