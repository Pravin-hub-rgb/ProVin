Tool use: let the model call functions in your code. The loop: request → tool call → tool result → final answer.

```ts
const tools = [{
  name: "search_bookmarks",
  description: "Search the user's bookmarks",
  input_schema: zodToJsonSchema(searchSchema),
}];

const response = await client.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 1024,
  tools,
  messages: [{ role: "user", content: "Find my bookmarks about React" }],
});

// If response has tool_use, execute the tool and send result back
```

- **Tool definition:** name, description, input schema.
- **Loop:** request → model calls tool → you execute → send result → model responds.
- **Permission risk:** tools must enforce the current user's permissions (callback to 6.8).
- **Never** give a tool broader access than the user has.

## What It Is NOT

- Tool use is **not** automatic — you must execute the tool.
- Tools are **not** safe by default — enforce permissions.
- Model output is **not** trusted — validate tool inputs.

---

## Common Mistakes

- Giving tools broader access than the user.
- Not validating tool inputs.
- Not enforcing permissions in tools.
