Ask for JSON, validate with a Zod schema (same discipline as request validation), handle mismatch.

```ts
const schema = z.object({
  summary: z.string(),
  tags: z.array(z.string()).max(5),
});

const response = await client.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 1024,
  messages: [{ role: "user", content: "Summarize and tag this article: ..." }],
});

const parsed = schema.safeParse(JSON.parse(response.content[0].text));
if (!parsed.success) {
  // retry or fail gracefully
}
```

- **Ask for JSON:** prompt the model to return JSON.
- **Validate with Zod:** same as request validation.
- **Handle mismatch:** retry or fail gracefully.
- **Break it:** make model return off-schema and handle it.

## What It Is NOT

- Model output is **not** trusted — validate it.
- JSON is **not** guaranteed — model may return markdown.
- Validation failure is **not** a crash — handle gracefully.

---

## Common Mistakes

- Trusting model output without validation.
- Not handling parse failures.
- Not asking for JSON in the prompt.
