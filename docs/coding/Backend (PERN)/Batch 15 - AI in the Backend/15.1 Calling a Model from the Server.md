The Messages API: roles, system prompt, parameters, tokens. API key only on the server.

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY });

const response = await client.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 1024,
  system: "You are a helpful assistant.",
  messages: [{ role: "user", content: "Hello" }],
});

console.log(response.content[0].text);
```

- **Roles:** user (input), assistant (response), system (behavior).
- **System prompt:** sets behavior/persona.
- **Parameters:** `max_tokens`, `temperature`.
- **API key:** only on server (never in frontend bundle).
- **Tokens:** input + output tokens (cost).

## What It Is NOT

- API key is **not** for the frontend — it is server-only.
- Model output is **not** trusted — validate it (15.3).
- Streaming is **not** covered here — next doc (15.2).

---

## Common Mistakes

- Putting API key in frontend code.
- Not setting `max_tokens` (unbounded cost).
- Trusting model output without validation.
