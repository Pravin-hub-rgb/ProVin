Streaming improves perceived speed. Send tokens as they arrive via SSE.

```ts
const stream = await client.messages.stream({
  model: "claude-sonnet-4-20250514",
  max_tokens: 1024,
  messages: [{ role: "user", content: "Tell me a story" }],
});

for await (const event of stream) {
  if (event.type === "content_block_delta") {
    process.stdout.write(event.delta.text);
  }
}
```

- **SSE (Server-Sent Events):** `text/event-stream`.
- **Streaming to browser:** `res.write()` chunks.
- **Closed connection:** handle `req.on("close")`.
- **Perceived speed:** user sees tokens as they arrive.

## What It Is NOT

- Streaming is **not** faster (total time same) — perceived speed improves.
- SSE is **not** WebSocket — one-way, text-only.
- Closed connection is **not** automatic — handle it.

---

## Common Mistakes

- Not handling closed connections (memory leak).
- Buffering instead of streaming.
- Not setting `Content-Type: text/event-stream`.
