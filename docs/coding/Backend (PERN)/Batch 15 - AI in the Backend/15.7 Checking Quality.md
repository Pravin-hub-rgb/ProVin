A small set of example inputs with expected properties, run before and after prompt changes. AI features need tests that tolerate variation.

```ts
const testCases = [
  { input: "https://example.com/article1", expectedTags: ["tech", "news"] },
  { input: "https://example.com/article2", expectedTags: ["science"] },
  // ... 10 cases
];

for (const tc of testCases) {
  const result = await enrichBookmark(tc.input);
  const hasExpectedTags = tc.expectedTags.every((t) => result.tags.includes(t));
  console.log(tc.input, hasExpectedTags ? "PASS" : "FAIL");
}
```

- **Example inputs:** 10 cases with expected properties.
- **Run before/after prompt changes:** detect regressions.
- **Tolerate variation:** check properties, not exact match.

## What It Is NOT

- AI tests are **not** deterministic — they tolerate variation.
- Exact match is **not** the goal — check properties.
- Quality checks are **not** optional — prompt changes can break things.

---

## Common Mistakes

- Expecting exact output (AI is non-deterministic).
- Not testing before prompt changes.
- No evaluation script.
