## Problem — What Happens When You Add a Field?

Re-read your 2B.4 hand-written validation and your own list of problems. Add one new field to a bookmark and count how many places must change: validation, types, handler, docs.

```ts
// Hand-written validation (from 2B.4)
function validateBookmark(body: unknown) {
  if (typeof body !== "object" || body === null) throw new Error("Body must be object");
  const b = body as Record<string, unknown>;
  if (typeof b.url !== "string" || !b.url.startsWith("http")) throw new Error("bad url");
  if (typeof b.title !== "string" || b.title.length < 1 || b.title.length > 200) throw new Error("bad title");
  return { url: b.url, title: b.title };
}
```

Now add a `note` field. You must update:

1. The validation function.
2. The TypeScript type.
3. The handler.
4. The docs/README.

**The pain:** validation repeats, drifts out of sync with types, and is tedious to maintain. This is the setup for Zod (5.2).
