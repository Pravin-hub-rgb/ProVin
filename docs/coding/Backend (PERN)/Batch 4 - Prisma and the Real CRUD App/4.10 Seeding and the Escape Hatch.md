A seed script populates development data. `$queryRaw` is the escape hatch for queries Prisma cannot express.

```ts
// seed.ts
import { PrismaClient } from "@prisma/client";
const prisma = new PrismaClient();

async function main() {
  await prisma.bookmark.createMany({
    data: [
      { url: "https://example.com", title: "Example" },
      { url: "https://example.org", title: "Example Org" },
    ],
  });
}

main().finally(() => prisma.$disconnect());
```

```ts
// Raw SQL (escape hatch)
const result = await prisma.$queryRaw`
  SELECT * FROM bookmarks WHERE title ILIKE ${`%${search}%`}
`;
```

- `seed.ts`: populates dev data.
- `prisma db seed`: runs the seed script.
- `$queryRaw`: raw SQL for complex queries.
- Parameters still matter (template literals are parameterized).

## What It Is NOT

- Seed data is **not** for production — dev only.
- `$queryRaw` is **not** unsafe — template literals are parameterized.
- Raw SQL is **not** preferred — use Prisma Client first.

---

## Common Mistakes

- Committing seed data to production.
- Using string concatenation in `$queryRaw` (injection).
- Not disconnecting after seed (`prisma.$disconnect()`).
