Prisma Studio is a GUI for your database. Query logging shows generated SQL. `EXPLAIN` finds slow queries.

```bash
npx prisma studio   # opens GUI on localhost:5555
```

```ts
const prisma = new PrismaClient({
  log: ["query", "info", "warn", "error"],
});
```

- **Prisma Studio:** GUI for browsing/editing data.
- **Query logging:** see the SQL Prisma generates.
- **`EXPLAIN`:** analyze slow queries.
- **Generated SQL:** read it to understand Prisma.

**Find and fix a slow query:**

1. Enable query logging.
2. Find a slow query.
3. Run `EXPLAIN ANALYZE` on it.
4. Add an index.
5. Verify improvement.

## What It Is NOT

- Prisma Studio is **not** for production — dev only.
- Query logging is **not** for production — too verbose.
- `EXPLAIN` is **not** `EXPLAIN ANALYZE` — ANALYZE runs the query.

---

## Common Mistakes

- Using Prisma Studio in production.
- Not enabling query logging during development.
- Ignoring slow queries.

## Try It Yourself

1. Open Prisma Studio and browse data.
2. Enable query logging and see SQL.
3. Find a slow query and fix it with an index.
