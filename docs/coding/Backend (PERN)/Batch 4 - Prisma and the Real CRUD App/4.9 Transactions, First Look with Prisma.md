`$transaction` wraps multiple writes that must succeed or fail together.

```ts
await prisma.$transaction(async (tx) => {
  const bookmark = await tx.bookmark.create({ data: { url, title } });
  await tx.tag.create({ data: { name: "js", bookmarks: { connect: { id: bookmark.id } } } });
  return bookmark;
});
```

- If any write fails, all are rolled back.
- Compare with manual `BEGIN`/`COMMIT` from 3.14.
- `tx` is the transaction client (use it for all writes inside).

## What It Is NOT

- `$transaction` is **not** optional for multi-step writes — use it.
- `tx` is **not** `prisma` — use `tx` inside the transaction.
- Transaction is **not** just "try/catch" — it is database-level atomicity.

---

## Common Mistakes

- Using `prisma` instead of `tx` inside transaction.
- Not awaiting the transaction.
- Thinking try/catch is enough (it is not — use $transaction).
