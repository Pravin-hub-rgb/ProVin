Prisma is a schema file, a migration tool, and a generated typed client.

```bash
npm install prisma@7 @prisma/client@7
npx prisma init
```

This creates `prisma/schema.prisma`:

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

- `generator`: generates the typed client.
- `datasource`: connects to Postgres via `DATABASE_URL`.
- `prisma-client-js`: the client package.

**Verify connection:**

```bash
npx prisma db pull   # or npx prisma migrate dev
```

## What It Is NOT

- Prisma is **not** a database — it connects to Postgres.
- `prisma init` is **not** a migration — it creates the schema file.
- Prisma 7 is **not** Prisma 8 — check version at build time.

---

## Common Mistakes

- Using an old Prisma version (check docs).
- Missing `DATABASE_URL` in `.env`.
- Not running `prisma generate` after schema changes.

## Try It Yourself

1. Install Prisma 7 and init.
2. Connect to your Postgres.
3. Run one query with the client.
