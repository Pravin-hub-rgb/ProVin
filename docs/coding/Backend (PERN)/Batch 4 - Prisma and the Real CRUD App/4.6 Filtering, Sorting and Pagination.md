# Doc 4.6 — Filtering, Sorting and Pagination

## Cheat Sheet (Quick Recall)

- `where`: filter conditions.
- `orderBy`: sort.
- `take`: limit.
- `skip`: offset.
- `select` vs `include`: choose fields or include relations.

Reproduce the 2B.6 list endpoint behavior with Prisma.

```ts
const bookmarks = await prisma.bookmark.findMany({
  where: {
    tags: { some: { name: tag } },
    title: { contains: q, mode: "insensitive" },
  },
  orderBy: { createdAt: "desc" },
  take: 10,
  skip: (page - 1) * 10,
  select: { id: true, url: true, title: true },
});
```

- `where`: filter conditions (operators: `equals`, `contains`, `some`, `every`).
- `orderBy`: sort (`asc` or `desc`).
- `take`: limit (page size).
- `skip`: offset (for pagination).
- `select`: choose specific fields.
- `include`: include related models.

**Cursor pagination:** PREVIEW only (not covered).

## What It Is NOT

- `take`/`skip` is **not** cursor pagination — it is offset pagination.
- `select` is **not** `include` — `select` chooses fields, `include` adds relations.
- Prisma is **not** SQL — but it generates SQL.

---

## Common Mistakes

- Using `include` when `select` suffices (over-fetching).
- Not capping `take` (unbounded lists).
- Forgetting `orderBy` (inconsistent order).
