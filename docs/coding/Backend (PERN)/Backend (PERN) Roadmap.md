# Backend (PERN) Roadmap

Vin's roadmap for learning backend engineering with Node, Express, TypeScript, and Postgres.

## The Goal

Go from a React/TypeScript developer to a backend engineer who can build, secure, test, deploy, and scale a Node API.

## Prerequisites

- React with TypeScript
- Basic terminal and Git comfort

## Stack

- Runtime: Node.js 26 (LTS)
- Language: TypeScript 6.x, strict
- Web framework: Express 5
- Database: PostgreSQL 18
- ORM: Prisma 7
- Validation: Zod 4
- Cache/queues: Redis 8
- Testing: Vitest 4, Supertest 7, Testcontainers
- Delivery: Docker, Docker Compose, GitHub Actions

## Batches

- Module 0: How the Web and a Backend Work (no project)
- Batch 1: Node.js and TypeScript Foundations — Log Analyzer CLI
- Batch 2: HTTP and Express — Bookmarks API v1
- Batch 3: PostgreSQL and SQL by Hand — Library Database
- Batch 4: Prisma and Data Access — Bookmarks API v2
- Batch 5: Validation, Auth, and Security Basics
- Batch 6: Authentication and Authorization
- Batch 7: Hardening and Production Readiness
- Batch 8: Testing Backend Code
- Batch 9: Frontend + Backend Together
- Batch 10: Docker and Deployment
- Batch 11: Transactions and Concurrency
- Batch 12: Caching and Redis
- Batch 13: Background Jobs and Queues
- Batch 14: Real-Time with WebSockets
- Batch 15: AI Integration

## What Carries Over from React

React with TypeScript, Vite, Tailwind, React Hook Form + Zod, TanStack Query, React Router, Context, Zustand, Redux Toolkit. These are tagged REVISITED or USED where they appear.

## Out of Scope

Real money/payments, NestJS, GraphQL, microservices/Kubernetes, Bun as runtime. Capstone decided later.
