# Doc 0.3 — HTTP Messages

## Cheat Sheet (Quick Recall)

- Request: method, path, headers, body.
- Response: status code, headers, body.
- Methods: GET, POST, PUT, PATCH, DELETE.
- Status: 2xx success, 3xx redirect, 4xx client error, 5xx server error.
- Common codes: 200, 201, 204, 400, 401, 403, 404, 409, 422, 500.

HTTP is how client and server talk. A request asks for something; a response answers.

**Request:**

```
GET /bookmarks HTTP/1.1
Host: localhost:3000
Accept: application/json
```

- Method (GET, POST, etc.)
- Path (/bookmarks)
- Headers (Host, Accept, etc.)
- Body (for POST/PUT/PATCH)

**Response:**

```
HTTP/1.1 200 OK
Content-Type: application/json

[{"id": 1, "title": "Example"}]
```

- Status code (200, 404, etc.)
- Headers (Content-Type, etc.)
- Body (the data)

**Methods:**

- GET: read
- POST: create
- PUT: replace
- PATCH: partial update
- DELETE: remove

**Status codes:**

- 2xx: success (200 OK, 201 Created, 204 No Content)
- 3xx: redirect
- 4xx: client error (400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 409 Conflict, 422 Unprocessable)
- 5xx: server error (500 Internal Server Error)

**401 vs 403:** 401 = "who are you?" (not authenticated). 403 = "you may not" (authenticated but not allowed).

## Common Mistakes

- Mixing up 401 and 403.
- Using 200 for everything.
- Thinking HTTP is only for HTML.

## Questions

1. What are the four parts of an HTTP request?

**Answer:** Method, path, headers, body.

2. What are the three parts of an HTTP response?

**Answer:** Status code, headers, body.

3. What does 201 mean?

**Answer:** Created (resource created successfully).

4. What does 404 mean?

**Answer:** Not Found (resource does not exist).

5. Difference between 401 and 403?

**Answer:** 401 = not authenticated (who are you?); 403 = not authorized (you may not).
