## Problem — What Do You Need to Start Writing Backend Code?

Before writing backend code, set up your tools. Node, an editor, an API client, curl, Git — each has a job.

**Required:**

- **Node.js 26 (LTS):** download from nodejs.org. Verify: `node --version`.
- **npm:** comes with Node. Verify: `npm --version`.
- **VS Code:** free editor. Install extensions: ESLint, Prettier.
- **API client:** Bruno (free, open-source) or Postman. For testing endpoints.
- **curl:** terminal HTTP client. Usually pre-installed on Mac/Linux; Windows: use Git Bash or WSL.
- **Git:** version control. Verify: `git --version`.

**Quick verification:**

```bash
node --version    # should print v26.x.x
npm --version     # should print 10.x.x
git --version     # should print git version
```

**One-line script test:**

```bash
node -e "console.log('Hello, Node!')"
```

**Call a public API:**

```bash
curl https://jsonplaceholder.typicode.com/todos/1
```

## What It Is NOT

- Node is **not** multi-threaded — single-threaded event loop.
- `node --version` is **not** optional — verify your setup.
- Git is **not** optional for real projects.

---

## Common Mistakes

- Using an old Node version.
- Not verifying installations.
- Skipping Git setup.
