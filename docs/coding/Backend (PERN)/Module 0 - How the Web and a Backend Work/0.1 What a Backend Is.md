# Doc 0.1 — What a Backend Is

## Cheat Sheet (Quick Recall)

- Frontend runs in the browser; backend runs on a server.
- Client sends a request; server sends a response.
- Request: method, URL, headers, body.
- Response: status code, headers, body.
- The backend is just a program that listens on a port and responds.

You have called `fetch("/api/users")` from React. But what is on the other side of that request? A backend is just a program running on a server (or your own machine). It listens on a port, waits for requests, and sends responses.

```
┌──────────────┐         HTTP request          ┌──────────────┐
│   Browser    │  ──────────────────────────►  │   Server     │
│  (React app) │                               │  (Node.js)   │
│              │  ◄──────────────────────────  │              │
└──────────────┘         HTTP response         └──────────────┘
```

- **Client:** the browser (or mobile app) that sends requests.
- **Server:** the backend program that receives requests and sends responses.
- **Request:** method (GET/POST/etc.), URL, headers, body.
- **Response:** status code (200, 404, etc.), headers, body.

The backend is not magic. It is a program that opens a port (e.g., 3000), waits, and responds. You will write one in Batch 1 using Node's built-in `http` module.

## Common Mistakes

- Thinking the backend runs in the browser.
- Confusing client and server.
- Thinking `fetch` runs on the server.

## Questions

1. What is a backend?

**Answer:** A program running on a server that listens for requests and sends responses.

2. What are the four parts of an HTTP request?

**Answer:** Method, URL, headers, body.

3. What are the three parts of an HTTP response?

**Answer:** Status code, headers, body.

4. Where does the backend run?

**Answer:** On a server (or your own machine), not in the browser.

5. What does `fetch` do?

**Answer:** Sends an HTTP request from the browser to the backend.
