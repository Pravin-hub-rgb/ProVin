## Problem — What Runs on the Other Side of fetch?

You write `fetch("/api/users")` in React. The data comes back. But where does it come from? What is "the server"? Is it inside React? Is it in the browser? No.

A **backend is just a program running on a machine** (a server, or your own laptop). It listens on a port, waits for requests, and sends responses. That is the whole idea. Nothing magic.

Think of it like a restaurant. The **client** (browser) is the customer who places an order. The **server** (backend) is the kitchen that receives the order, prepares the food, and sends it back. The customer never enters the kitchen — they just send a request and get a response.

```
┌──────────────┐         HTTP request          ┌──────────────┐
│   Browser    │  ──────────────────────────►  │   Server     │
│  (React app) │                               │  (Node.js)   │
│              │  ◄──────────────────────────  │              │
└──────────────┘         HTTP response         └──────────────┘
```

An HTTP request has four parts:

- **Method** — what you want to do (GET, POST, PUT, PATCH, DELETE)
- **URL** — where to send it (`/api/users`)
- **Headers** — metadata (Content-Type, Authorization)
- **Body** — the data (for POST/PUT/PATCH)

An HTTP response has three parts:

- **Status code** — did it work? (200, 404, 500)
- **Headers** — metadata about the response
- **Body** — the data coming back (usually JSON)

## What It Is NOT

- The backend is **not** inside React or the browser — it runs on a separate machine (or your own machine in development).
- The backend is **not** a database — it is a program that talks to the database.
- `fetch` does **not** run on the server — it runs in the browser and sends a request to the server.

---

## Common Mistakes

- Thinking the backend runs in the browser or inside React.
- Confusing client (browser) with server (backend).
- Thinking `fetch` runs on the server.

- Client (browser) -> request -> Server (Node) -> response -> Client.

## Cheat Sheet (Quick Recall)

- Frontend runs in the browser; backend runs on a server.
- Client sends a request; server sends a response.
- Request: method, URL, headers, body.
- Response: status code, headers, body.
- The backend is just a program that listens on a port and responds.
