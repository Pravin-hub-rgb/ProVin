# Doc 0.4 — JSON and Content-Type

## Cheat Sheet (Quick Recall)

- JSON = JavaScript Object Notation (text format for data).
- `Content-Type: application/json` tells the server/client the body is JSON.
- `JSON.stringify()` and `JSON.parse()` in JS.
- Always set Content-Type when sending JSON.

JSON (JavaScript Object Notation) is a text format for sending data between client and server.

```json
{
  "id": 1,
  "title": "Example",
  "tags": ["node", "ts"]
}
```

- Keys are strings (double quotes).
- Values: string, number, boolean, null, array, object.

**Content-Type header:**

```
Content-Type: application/json
```

Tells the receiver "the body is JSON, parse it as JSON."

**In Node/JS:**

```js
const body = JSON.stringify({ id: 1, title: "Example" });
const data = JSON.parse(body);
```

**Sending as JSON vs form data:**

- JSON: `Content-Type: application/json`, body is JSON string.
- Form data: `Content-Type: application/x-www-form-urlencoded`, body is `key=value&key2=value2`.

## Common Mistakes

- Forgetting to set Content-Type → server cannot parse body.
- Sending JSON without stringifying.
- Mixing JSON and form data.

## Questions

1. What is JSON?

**Answer:** A text format for sending data between client and server.

2. What Content-Type for JSON?

**Answer:** `application/json`.

3. How to convert object to JSON string in JS?

**Answer:** `JSON.stringify(obj)`.

4. How to parse JSON string to object in JS?

**Answer:** `JSON.parse(str)`.

5. Difference between JSON and form data?

**Answer:** JSON is structured text; form data is key=value pairs.
