---

`node-cron` schedules jobs by time. Same flaws as `setInterval`.

```ts
import cron from "node-cron";

cron.schedule("0 2 * * *", async () => {
  await cleanupExpiredSessions();
});
```

- Cron expression: `minute hour day month weekday`.
- `0 2 * * *` = 2:00 AM daily.
- Same flaws: lost on restart, no retry, duplicate runs with multiple instances.

**Mini-project:** a nightly job.

## What It Is NOT

- `node-cron` is **not** a job system — it is a scheduler.
- It is **not** reliable — same flaws as setInterval.
- It is **not** for production — use a queue.

---

## Common Mistakes

- Using node-cron for critical work.
- Not handling failures.
- Duplicate runs with multiple instances.
