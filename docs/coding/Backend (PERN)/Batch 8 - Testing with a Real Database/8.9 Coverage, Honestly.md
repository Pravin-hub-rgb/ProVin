## Broader Goal

The goal of Batch 8 is to write tests that give real confidence. Current step: coverage.

---

What a coverage number measures, what it misses, why 100% is not the goal.

```bash
npx vitest --coverage
```

- **What coverage measures:** lines/branches/functions executed during tests.
- **What it misses:** edge cases, logic errors, integration issues, untested paths that happen to be covered.
- **Why 100% is not the goal:** coverage is a tool, not a target. 80% meaningful tests > 100% trivial tests.

**Mini-project:** generate a report and write down three important things it does not prove.

## What It Is NOT

- Coverage is **not** correctness — 100% coverage does not mean bug-free.
- Coverage is **not** a target — it is a tool.
- Coverage is **not** a replacement for good tests.

---

## Common Mistakes

- Chasing 100% coverage.
- Writing trivial tests for coverage.
- Ignoring untested risks.
