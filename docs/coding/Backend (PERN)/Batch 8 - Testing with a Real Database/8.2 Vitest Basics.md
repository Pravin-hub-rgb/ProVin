Vitest is a test runner for TypeScript/ES modules. `describe`, `it`, `expect`.

```ts
import { describe, it, expect } from "vitest";

describe("add", () => {
  it("adds two numbers", () => {
    expect(1 + 2).toBe(3);
  });
});
```

- `describe`: groups tests.
- `it`/`test`: defines a test.
- `expect`: assertion.
- Matchers: `toBe`, `toEqual`, `toThrow`, etc.

**Running:**

```bash
npm test              # run once
npx vitest --watch    # watch mode
```

**Test files:** `*.test.ts` or `*.spec.ts`.

**First tests:** pure functions (Zod schemas, helpers, `paginate`).

## What It Is NOT

- Vitest is **not** Jest — similar API but ESM-native.
- `toBe` is **not** `toEqual` — `toBe` uses `===`, `toEqual` deep compares.
- Watch mode is **not** run-once.

---

## Common Mistakes

- Wrong file naming (not `.test.ts`).
- Using `toBe` for objects (use `toEqual`).
- Not running in watch mode during development.
