Jab tumne JavaScript seekhi thi, tumhe pata chala tha ki JS ka apna ghar nahi hai — wo browser mein ya Node.js ke andar chalta hai. JavaScript tumhari language thi, Node.js usko chalane wala engine tha. Ab tumhe wahi cheez nayi duniya mein karni hai — aur wahan ka language **C#** hai, usko chalane wala engine **.NET**.

# C# aur .NET kya hai

**C# (C-Sharp) ek programming language hai** — waise hi jaise JavaScript ek language hai. Microsoft ne 2000 mein banayi. Tumhara purana code JS mein aisa tha:

```javascript
// JavaScript
const naam = "Vin";
console.log("Hello " + naam);
```

C# mein wahi kaam:

```csharp
// C#
string naam = "Vin";
Console.WriteLine("Hello " + naam);
```

Syntax dekh kar samajh aa gaya hoga — kahani wahi hai, bas **type pehle likhna padta hai** (`string naam` — JS wala `const naam` jaisa, par compiler ko pehle hi bata do ki ye string hai).

Ab fark ka asli sawal: JS chalta hai bina check ke — `console.log(naam.toUpperCase())` agar naam number hua toh error aakhir mein aayega, runtime pe. C# ka **compiler** code ko chalane se **pehle hi poora padh leta hai** — type galat, method galat, kuch bhi galat toh program chalega hi nahi. Isliye bade professional projects (banks, large systems) mein C# pasand ki jaati hai — galti pakadne ka mauka pehle hi mil jaata hai.

## .NET — C# ka engine

Language akeli kuch nahi kar sakti. JavaScript ko chalane ke liye Node.js chahiye tha — files padhna, server banana, sab usne diya. Waise hi **C# ko chalane ke liye .NET chahiye** — Microsoft ka apna platform jo C# code ko execute karta hai aur saath mein hazaron ready-made tools deta hai.

Toh rishta ekdum seedha hai:

| JS duniya | C# duniya |
|---|---|
| JavaScript (language) | **C# (language)** |
| Node.js (engine/runtime) | **.NET (engine/runtime)** |
| npm | NuGet |
| Express / Next.js API routes | **ASP.NET Core (Web API)** |
| package.json | .csproj file |
| `node app.js` | `dotnet run` |
| JavaScript (types run-time pe) | C# (types compile-time pe) |

Dhyan se dekho — yeh table hi tumhara poora map hai. Jo tumne JS mein seekha, uska har cheez ka yahan equivalent hai. Naya sirf syntax aur ye strictness hai.

## .NET "Basics" mein kya aata hai

Is course ka syllabus: **C#, .NET Basics, SQL Basics, JavaScript, HTML & CSS, Git**. Dekh ke lagta hai bahut kuch hai, par actually:

- **C# + .NET Basics** — yahi course hai, module 0 se 5 tak
- **SQL Basics** — DBMS course mein tum already padh chuke (joins, indexes waghera); yahan sirf C# se SQL kaise jodate hai wo aayega
- **JavaScript, HTML & CSS, Git** — tum already jaante ho, is course ka faayda seedha hai

Aam taur par kaam yeh hota hai: tumhara React/Next frontend **API call** karega, aur wo API hogi **ASP.NET Core** mein — database se Entity Framework ke through judi hogi. Yehi teen cheezein (C# → .NET → ASP.NET Core) course ke core hain.

## Yeh kya NAHI hai (galat fehmiyan door)

- **C++ ka chhota bhai nahi** — naam milta hai, syntax milta hai, par C++ manual memory jaisa dard nahi hai. .NET garbage collector khud sambhalta hai (wo kya hai aage module 3 mein).
- **.NET ek language nahi hai** — .NET platform hai, language C# hai. Yeh mix-up bahut hota hai — yaad rakhna.
- **.NET sirf Windows pe nahi chalta** — pehle aisa tha, par aaj wala .NET (jo tum seekhoge) Linux, Mac, sab pe chalta hai — isi liye servers pe chal jaata hai.
- **Java nahi hai** — bahut similar lagta hai, par syntax aur ecosystem alag hai.

## Pehla nazara — C# kaise dikhta hai

Ek poora chhota program, taaki darr nikal jaaye:

```csharp
// Program.cs — C# ka entry file, JS ka app.js jaisa
Console.WriteLine("Hello, C#!");   // console.log ka equivalent

string naam = "Vin";               // string type, JS wala variable
int umar = 25;                     // int = pura number (JS mein sab number hote the, yahan type alag hai)

Console.WriteLine(naam + " ki umar " + umar + " hai");
```

Har line clear hai na? `Console.WriteLine` = `console.log`, variable = variable, bas type likhna padta hai. Bas itna hi C# hai shuruaat mein — baki sab isi ke upar khada hai.

</details>

3. "C++ ka chhota bhai hai" — yeh baat galat kyun hai?

<details>
<summary>Sample Jawab</summary>

</details>
