## MCQ

Q: What is the correct relationship between C# and .NET?
A. C# is a framework that runs the .NET language
B. .NET is a language that compiles C#
C. C# is a language that runs on the .NET platform
D. They are two separate competing technologies that can replace each other
> C. C# is the language you write in (like JavaScript) and .NET is the platform/engine that runs it (like Node.js). They work together — a language alone does nothing without an engine.

---

Q: What is the biggest structural difference between JavaScript and C#?
A. JavaScript only runs in the browser, C# only runs in the terminal
B. In JavaScript types are checked while running, in C# the compiler checks them up front
C. JavaScript uses objects, C# only uses arrays
D. C# has no compiler, everything happens at runtime
> B. JavaScript is loosely typed — mistakes show up while running (runtime). C#'s compiler reads the whole code before running and catches type errors up front (compile time), so mistakes get caught earlier.

---

Q: What is Node.js's equivalent in the C#/.NET world?
A. npm
B. Visual Studio
C. .NET (platform/runtime)
D. SQL Server
> C. Node.js runs JavaScript; likewise .NET runs C#. npm's equivalent is NuGet (for packages), Visual Studio is an editor/IDE, and SQL Server is a database.

---

Q: What is the real difference between `.NET Framework` and the newer `.NET` (which most projects use today)?
A. They are exactly the same thing, only the name changed
B. The old .NET only ran on Windows, the new .NET runs on Windows, Linux, and Mac
C. The new .NET uses a different language
D. The old .NET never existed
> B. Servers often run on Linux. The old .NET Framework was Windows-only, so Microsoft built the cross-platform new .NET (.NET Core and after) that runs on every OS — which is why it's used today.

---

Q: What is the closest equivalent of `dotnet new console` in the JS world?
A. node app.js
B. npx create-next-app (new project from a template)
C. npm install
D. package.json
> B. `dotnet new console` creates a new project folder from a ready-made template — just like `npx create-next-app` creates a Next.js project. `node app.js` is the run command, `npm install` installs packages.

## TrueFalse

Q: In C#, `int umar = "pachees";` will run because a string can be converted to a number.
- True
- False
> False. C#'s compiler rejects this before it runs (CS0029 error) — a string is not implicitly converted to int. This code would have run in JavaScript because it is loosely typed.

---

Q: The `.csproj` file is the file where we write all our C# code.
- True
- False
> False. Code goes in `Program.cs` (or other `.cs`) files. `.csproj` is the project's metadata file — project name, which .NET version, which packages — just like package.json.

---

Q: This course's format is to explain C# against JS, because you already know JS.
- True
- False
> True. The idea behind every file: "you did it this way in JS, here's how it's done in C#". This JS reference is the biggest plus point of the course.
