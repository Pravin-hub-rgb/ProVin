## MCQ

Q: C# aur .NET ka sahi rishta kaunsa hai?
A. C# ek framework hai jo .NET language ko chalata hai
B. .NET ek language hai jo C# ko compile karti hai
C. C# language hai jo .NET platform par chalti hai
D. Dono alag-alag competing technologies hain jo ek doosre ki jagah le sakte hain
> C. C# likhne wali language hai (jaise JavaScript) aur .NET usko chalane wala platform/engine hai (jaise Node.js). Dono saath mein kaam karte hain — language akeli kuch nahi karti, engine ke bina.

---

Q: JavaScript aur C# mein sabse bada structural fark kya hai?
A. JavaScript sirf browser mein chalta hai, C# sirf terminal mein
B. JavaScript mein type chalne ke waqt check hote hain, C# mein compiler pehle hi check kar leta hai
C. JavaScript objects use karta hai, C# sirf arrays use karta hai
D. C# ka compiler nahi hota, sab runtime pe hota hai
> B. JavaScript loosely typed hai — galti chalne ke baad milti hai (runtime). C# ka compiler code chalane se pehle poora padh kar type errors pakad deta hai (compile-time), isliye galtiyan pehle pakdi jaati hain.

---

Q: Node.js ka C#/.NET duniya mein equivalent kya hai?
A. npm
B. Visual Studio
C. .NET (platform/runtime)
D. SQL Server
> C. Node.js JavaScript ko chalata hai, waise hi .NET C# ko chalata hai. npm ka equivalent NuGet hai (packages ke liye), Visual Studio ek editor/IDE hai, aur SQL Server database hai.

---

Q: `.NET Framework` aur naya `.NET` (jo aaj zyadatar projects use karte hain) ka asli fark kya hai?
A. Dono bilkul same cheez hain, sirf naam badla
B. Purana .NET sirf Windows pe chalta tha, naya .NET Windows, Linux, Mac sab pe chalta hai
C. Naya .NET ek alag language use karta hai
D. Purana .NET kabhi exist nahi karta tha
> B. Servers aksar Linux pe chalte hain. Purana .NET Framework sirf Windows ka tha, isliye Microsoft ne cross-platform wala naya .NET (.NET Core ke baad) banaya jo har OS pe chalta hai — isi liye aajkal yahi use hota hai.

---

Q: `dotnet new console` ka JS duniya mein sabse kareebi equivalent kya hai?
A. node app.js
B. npx create-next-app (template se naya project)
C. npm install
D. package.json
> B. `dotnet new console` ek ready-made template se naya project folder bana deta hai — bilkul waise jaise `npx create-next-app` Next.js ka project banata hai. `node app.js` chalane ka command hai, `npm install` packages install karta hai.

## TrueFalse

Q: C# mein `int umar = "pachees";` likhne par program chalega kyunki string ko number mein convert kiya ja sakta hai.
- True
- False
> False. C# compiler ise chalne se pehle reject kar deta hai (CS0029 error) — string seedhe int mein convert nahi hoti. JavaScript mein yeh code chal jaata tha kyunki woh loosely typed hai.

---

Q: `.csproj` file woh file hai jisme humara saara C# code likhte hain.
- True
- False
> False. Code `Program.cs` (ya dusre .cs) files mein likhte hain. `.csproj` project ki metadata file hai — project ka naam, konsa .NET version, kaun se packages — bilkul package.json jaisa.

---

Q: Is course ka format yahi hai — har file C# ko JS ke against samjhayegi, kyunki JS tumhe pehle se aata hai.
- True
- False
> True. Har file ka funda: "JS mein tum aise karte the, C# mein yahan aise hoga". Yeh JS reference hi is course ki sabse badi plus point hai.
