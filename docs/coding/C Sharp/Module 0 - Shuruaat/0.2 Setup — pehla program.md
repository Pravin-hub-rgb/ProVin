Pichhle file mein tumne dekha ki C# likhne ke liye compiler chahiye aur wo compiler .NET ke saath aata hai. Toh sabse pehla kaam — wo .NET apni machine pe laana, aur phir wahi wala feeling lena jo `node app.js` chalane pe mili thi.

# Setup — .NET SDK aur pehla program

## Step 1: .NET SDK install karo

SDK ka matlab hai **Software Development Kit** — compiler + runtime + `dotnet` command, sab ek package mein. Node.js install karna padta tha na JS chalane ke liye? Exactly wahi cheez, bas naam hai .NET SDK.

Browser mein jaao → `dotnet.microsoft.com/download` → apna OS (Windows) chuno → latest **SDK** wala installer download karke chala do. (LTS version chuno — "LTS" ka matlab long-term support, companies hamesha LTS use karti hain.)

Install ke baad terminal (PowerShell) kholo:

```bash
dotnet --version
```

Version number aaya (jaise `8.0.xxx`) — matlab setup done. Nahi aaya toh terminal band karke dobara kholo (PATH refresh hota hai).

> **Yaad rakho:** sirf "Runtime" mat install lena — runtime toh sirf chalata hai, likhe hue code ko check/compile karne ke liye SDK chahiye. SDK mein runtime dono hota hai.

## Step 2: Pehla project

Terminal mein, ek folder ke andar:

```bash
dotnet new console -n MeraPehlaProgram
cd MeraPehlaProgram
```

- `dotnet new console` — `npx create-next-app` jaisa magic: ready-made template bana diya. "Console" matlab terminal mein chalne wala program (koi website nahi — abhi sirf seekhna hai).
- `-n MeraPehlaProgram` — project ka naam.
- `cd` — us folder mein jaana.

Folder mein ye bana hoga:

```
MeraPehlaProgram/
├── MeraPehlaProgram.csproj   ← project ki details (package.json jaisa)
├── Program.cs                ← tumhara code yahan (app.js jaisa)
└── obj/ bin/                 ← build ki generated files (node_modules jaisa — chhuo mat)
```

**`Program.cs`** kholo — kuch aisa milega:

```csharp
// See https://aka.ms/new-console-template for more information
Console.WriteLine("Hello, World!");
```

Yehi entry file hai — JS mein `console.log` se shuru hote the, yahan `Console.WriteLine` se. (C# mein `Console` bada C isliye hai — woh class ka naam hai, module 2 mein sab clear hoga.)

## Step 3: chalao

```bash
dotnet run
```

Output:

```
Hello, World!
```

**Feel pehchana?** `node app.js` → output. Yahan `dotnet run` → output. Fark sirf itna ki beech mein compile bhi ho raha hai — pehli baar thoda slow (1-2 second), phir fast ho jaata hai kyunki build cache ban jaati hai.

## Program.cs ko badal ke dekho

`Program.cs` ka content ye kar do:

```csharp
// Program.cs
Console.WriteLine("Hello, C#!");          // line 1: print karo
string naam = "Vin";                      // line 2: string variable banaya
int umar = 25;                            // line 3: int (pura number)
Console.WriteLine(naam + " ki umar " + umar + " hai");  // line 4: jod ke print
```

`dotnet run` do:

```
Hello, C#!
Vin ki umar 25 hai
```

Har line ka hisaab:

1. `Console.WriteLine("...")` — string literal print karta hai (JS: `console.log`)
2. `string naam = "Vin"` — variable, par type pehle (JS mein `const naam` likhte the, yahan `string`)
3. `int umar = 25` — int matlab **pura number**. JS mein ek hi `number` type tha, yahan `int` (integer), `double` (decimal) alag hain
4. `+` se strings jod diye — JS jaisa hi, par sirf same type jod sakte ho. `naam + umar` chalega (string + int), par `umar + 10` toh number addition hoga

## Galat likh ke dekho (compiler ka asli faayda)

Ye karo — line 3 mein galti se string likh do:

```csharp
int umar = "pachees";   // galat! number ki jagah string
```

Ab `dotnet run`:

```
error CS0029: Cannot implicitly convert type 'string' to 'int'
```

**Yahi JS aur C# ka asli fark hai.** JS mein yeh code chal jaata aur baad mein ulta-seedha hota. C# compiler ne **chalti baar hi rok diya** — galti file aur line number ke saath. Error dekh ke thoda darr lagega pehle, par yeh tumhara bodyguard hai — jab tak code sahi nahi, chalega hi nahi.

Ek aur aam galti try karo:

```csharp
Console.Writeline("hello");   // 'W' chhota — galat
```

```
error CS0117: 'Console' does not contain a definition for 'Writeline'
```

Compiler batata hai kya galat hai aur kahan. Bas — yehi debugging hai abhi ke liye.

## VS Code se likhna (recommended)

Terminal se bhi ho jaata hai, par VS Code se zyada comfortable hoga:

1. VS Code kholo → **C# extension** install karo (Microsoft wala, "C#" search karo) — IntelliSense (autocomplete) aur error underline ke liye
2. `File → Open Folder` se apna `MeraPehlaProgram` folder kholo
3. `Program.cs` pe click karo → neeche right corner mein **▷ Run** button (C# extension aane ke baad) ya terminal mein `dotnet run`

> **VS aur VS Code dono chalte hain** — Visual Studio (bada wala, .exe) .NET ka apna IDE hai, companies use karti hain. Par abhi ke liye VS Code + extension kaafi hai, aur tum already usme comfortable ho.

## Yeh kya NAHI hai

- **`dotnet run` = `npm run dev` nahi hai** — `dotnet run` ek baar chala ke program khatam ho jaata hai (console app). `npm run dev` server chalu rakhta hai. Server wala scene Module 5 mein aayega (`dotnet run` wahan server chalayega — par structure alag hoga).
- **`.csproj` file koi code nahi hai** — woh project ki metadata hai (naam, konsa .NET version, kaun se packages). package.json jaisa. Khol ke dekh lo, samajh aa jayega.
- **`obj/ bin/` folders gand nahi hain** — build ki generated files hain, git mein ignore hoti hain (`.gitignore` template khud karta hai).
