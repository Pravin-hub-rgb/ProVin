You learned React and Next.js in the JavaScript world — components, API routes, `npm run dev`. Now you're stepping into a new world — **C# and .NET**. But not just the language — the platform that runs it (.NET), connecting to databases (SQL + Entity Framework), and building APIs (ASP.NET Core). That's the whole course.

# 📋 C# & .NET Crash Course Roadmap

**Who it's for:** learning C#/.NET from zero — from basics to a complete Web API project, with JS references throughout.

**How to study:** 2 files a day — first read the lecture, then take its quiz. Each file is short; run the code (in the terminal) — that's when it clicks. Reading without hands-on won't work — this course is a crash course, not a heavy one.

**Your advantage:** you know JavaScript. So every file explains C# against JS — "in JS you did it this way, in C# it's done this way here". That reference is your biggest plus point.

## Phase map

**Module 0 — Start (2 files)**
What C# and .NET are, how they relate, and machine setup — running your first program.

**Module 1 — C# Basics (6 files)**
Variables, types, input, conditions, loops, arrays, methods. All the JS concepts, just with slightly stricter syntax.

**Module 2 — OOP in C# (4 files)**
Class, object, encapsulation, inheritance, interfaces. The OOP from the Core Subjects course, now in C# syntax.

**Module 3 — .NET Toolbox (3 files)**
What .NET gives you ready-made — LINQ, async/await, JSON, files, generics. This is the "framework" part.

**Module 4 — Database (3 files)**
A crash recap of SQL, then talking to the database with Entity Framework Core — connection strings, migrations, CRUD.

**Module 5 — ASP.NET Core Web API ⭐ (5 files)**
This is the real core. From building your first API to routing, validation, JWT auth, and CORS — so your React frontend can call this API.

**Module 6 — Project: Library Management API (4 files)**
A small complete project — models, database, CRUD, search, test. The course capstone, tying everything together.

## What Can You Skip?

If you're short on time, definitely do Module 0 → 1 → 5 → 6 (basics + API + project = the working core). Modules 2, 3, 4 can be filled in later — but without Module 4, Module 6 will feel incomplete.

There's a quiz after every module — don't skip it, that's what tells you whether there's a hole in your understanding. Let's start from Module 0 — first we understand what C# and .NET actually are, since hearing the names makes everyone think they're separate things.
