# Input aur Operators

## User se input lena

```csharp
// Program.cs — pehla interactive program
Console.Write("Apna naam batao: ");       // Print ke bagal wali line pe likhega
string naam = Console.ReadLine();          // user type karke Enter dabayega

Console.Write("Umar batao: ");
string umarText = Console.ReadLine();      // input hamesha STRING aata hai!

Console.WriteLine("Namaste " + naam + ", tum " + umarText + " saal ke ho.");
```

```bash
dotnet run
```
```
Apna naam batao: Vin
Umar batao: 25
Namaste Vin, tum 25 saal ke ho.
```

3 lines ka scheme samjho:

1. `Console.Write` — line break nahi deta (cursor wahi rehta hai), isliye prompt ekdum saath likh sakta hai. `Console.WriteLine` wala `Line` = baad mein nayi line.
2. `Console.ReadLine()` — user ka input **roka hua** leta hai (jab tak Enter na dabaye), aur **hamesha string** lauta hai. JS ka `prompt()` bhi string hi deta tha na — wahi aadat.
3. String + string = jodna — JS wala `+` wala kaam.

> **Note:** `Console.ReadLine()` null lauta sakta hai agar input stream band ho jaye (Ctrl+Z) — abhi ignore karo, normal chalne pe string hi milti hai.

## Input number hai? (yahan JS se fark dikhega)

Upar wale program mein `umarText` **string** hai — "25". Agar calculation karni ho toh abhi rukna padega:

```csharp
Console.Write("Umar batao: ");
int umar = int.Parse(Console.ReadLine());   // "25" → 25 — ab number hai

Console.WriteLine("Saalon mein mahine: " + umar * 12);   // 300
```

`int.Parse` ne string ko number mein badal diya. Ab `umar * 12` asli multiplication hai.

**Warning:** agar user ne "bees" likh diya toh `int.Parse` chalne pe exception fekega aur program mar jaayega. Hamesha aise user input ke liye safer version hai:

```csharp
string text = Console.ReadLine();
if (int.TryParse(text, out int umar))     // parse ho gaya?
{
    Console.WriteLine("Mahine: " + umar * 12);
}
else
{
    Console.WriteLine("Number likho bhai!");
}
```

`TryParse` boolean lauta deta hai — sahi hua toh `true` + value (`out int umar` mein value aa jaati hai), nahi toh `false` + koi crash nahi. `if` tum jaante ho, detail next file mein — abhi bas yaad rakho: **user input = string → Parse/TryParse se number.**

## Operators — sab JS wale

Maths wale ekdum same hain:

```csharp
int a = 10, b = 3;
Console.WriteLine(a + b);   // 13
Console.WriteLine(a - b);   // 7
Console.WriteLine(a * b);   // 30
Console.WriteLine(a / b);   // 3 !!! — 3.33 nahi, 3
Console.WriteLine(a % b);   // 1 — modulus (bachi hui value)
```

**Ek jagah JS se fark:** `10 / 3` JS mein `3.33` deta tha (sab number the). C# mein `int / int = int` — decimal ka part kaat ke fek deta hai. Decimal chahiye toh ekko double banao:

```csharp
Console.WriteLine((double)a / b);   // 3.333333...
```

Yehi galti interview mein aksar aati hai — yaad rakhna.

**Comparison wale** bhi same hain: `==`, `!=`, `<`, `>`, `<=`, `>=` — par inka result `bool` hota hai (`true`/`false`), jo condition mein seedha lag jaata hai.

**Logical:** `&&` (AND), `||` (OR), `!` (NOT) — JS jaisa hi:

```csharp
bool eligible = umar >= 18 && umar <= 60;   // dono condition sahi honi chahiye
```

## Compound assignment — chhote shortcuts

```csharp
int count = 0;
count = count + 1;    // lamba
count += 1;           // same kaam — yehi likho
count -= 2;           // count = count - 2
count *= 3;           // count = count * 3
count++;              // +1 ka shortcut (JS jaisa), count-- bhi
```

Sab bilkul JS wale. Roz use hote hain.

## String operators ke chhote tips

```csharp
string a = "Hello";
string b = "World";

Console.WriteLine(a + " " + b);     // Hello World — + join
Console.WriteLine(a.Length);         // 5 — property (JS jaisa .length)
Console.WriteLine(a.ToUpper());      // HELLO — method (JS: toUpperCase())
Console.WriteLine(a.Contains("ell")); // true (JS: includes)
Console.WriteLine($"Aap {a}, kitne? {a.Length}");  // string interpolation ⭐
```

**String interpolation** (`$"..."`) — C# ka sabse sundar jugaad. JS template literal (backtick wala) ka exact equivalent:

```javascript
// JS
console.log(`Hello ${name}, you are ${age}`);
```
```csharp
// C#
Console.WriteLine($"Hello {name}, you are {age}");
```

Fark sirf `$` lagana `"` se pehle. Yehi style daily kaam mein use karo — `+` se jodna jaldi messy ho jaata hai.

## Ek complete chhota program sab jodta hua

```csharp
// Program.cs — bill calculator
Console.Write("Item ka price batao: ");
int price = int.Parse(Console.ReadLine());

Console.Write("Kitne quantity: ");
int qty = int.Parse(Console.ReadLine());

int total = price * qty;
int discount = total / 10;        // 10% discount (integer maths)
int final = total - discount;

Console.WriteLine($"Price: {price} x {qty} = {total}");
Console.WriteLine($"Discount (10%): -{discount}");
Console.WriteLine($"Final bill: {final}");
```

Isme input, parse, maths, compound logic, interpolation — sab aa gaya. Chala ke dekho.

Yeh kya NAHI hai:

- **`Console.ReadLine()` number nahi deta** — hamesha string. Number chahiye toh Parse karna padega (JS `prompt()` jaisa hi behavior).
- **`/` hamesha divide nahi jo socha** — int/int pe floor value milti hai. Decimal chahiye toh `(double)` lagao.
- **`= aur == alag hain** — assignment `==` comparison. C# mein galat likha toh compiler error de dega (`=` condition mein nahi chalta — JS ki tarah silent galti nahi).

## In Your Own Words

1. `Console.ReadLine()` aur `Console.Write` — ek-ek line mein kya karte hain, aur `WriteLine` se kya fark?

<details>
<summary>Sample Jawab</summary>

**Jawab:** `ReadLine()` user se line input leta hai aur hamesha string deta hai. `Write` prompt bina line-break ke chhapta hai; `WriteLine` ke baad cursor agla ho jaata hai (print + newline).

</details>

2. User se li hui string "25" ko 12 se multiply karne se pehle kya karna padega — aur safe version kaunsa hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Pehle string ko int mein convert karna padega — `int.Parse("25")`. Par galat input pe ye exception fekta hai, isliye safe version `int.TryParse(text, out int n)` hai jo `true/false` deta hai bina crash kiye.

</details>

3. `10 / 3` C# mein kyun 3.33 nahi deta, aur asli decimal result kaise nikalte hain?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Kyunki dono `int` hain aur int/int ka result int hota hai (decimal kaat ke fekta hai). Decimal chahiye toh kam se kam ek operand ko double banana padega: `(double)10 / 3` → 3.33.

</details>

4. JS template literal aur C# string interpolation ka farq — syntax ke saath batao.

<details>
<summary>Sample Jawab</summary>

**Jawab:** JS: backtick ke saath `` `Hello ${name}` ``. C# (modern): `$"Hello {name}"` — `$` quotes se pehle, braces `${}` nahi, sirf `{}`. Dono ka kaam same — variable ko text ke andar bharana.

</details>
