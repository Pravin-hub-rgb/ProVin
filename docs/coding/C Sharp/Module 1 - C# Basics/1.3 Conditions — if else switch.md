Pichhle file mein ek bill calculator banaya tha — par usme ek hi raasta tha: input → maths → print. Asli program wahi hai jo sochta hai: agar discount hoga toh yeh, nahi toh woh. JS mein `if`/`else`/`switch` ka saara gyaan tum already rakhte ho — C# mein wahi sab, bas thoda zyada strict.

# Conditions — if, else, switch

## if / else — bilkul JS jaisa

```csharp
Console.Write("Umar batao: ");
int umar = int.Parse(Console.ReadLine());

if (umar >= 18)
{
    Console.WriteLine("Vote de sakte ho!");
}
else
{
    Console.WriteLine("Abhi nahi.");
}
```

Syntax dekh lo — bracket `{}` hamesha mandatory (JS mein single line pe chhod sakte the, yahan nahi), condition ke andar `( )`, aur `true/false` ki jagah koi bhi expression jo boolean de. `umar >= 18` boolean hai, seedha chalega.

Multiple conditions:

```csharp
if (umar < 13)
{
    Console.WriteLine("Bachcha");
}
else if (umar < 60)
{
    Console.WriteLine("Adult");
}
else
{
    Console.WriteLine("Senior");
}
```

`else if` — bilkul JS wala, order matter karta hai (pehla match hilega, baaki chhod dega).

## Condition kaise "true" hoti hai — C# thoda strict

JS mein `if (umar)` jaisa chalta tha (truthy/falsy — 0, "", null sab false). C# mein **condition mein boolean chahiye, seedha**:

```csharp
int umar = 0;
if (umar)           // ❌ ERROR — int ko bool mein nahi daal sakte
{
}

if (umar != 0)      // ✅ — explicitly boolean likho
{
}
```

Yeh JS walo ke liye sabse pehla shock hai. C# nahi bolta "0 toh false hi hai" — wo bolta hai "condition likho jiska result boolean ho". `&&`, `||`, `!` ya comparison operators se boolean banao.

> Ek exception hai (C# 9+): `if (umar is not 0)` type pattern waghera — par basics mein hamesha comparison likho.

## Ternary — wahi ek-line wala

```csharp
string status = (umar >= 18) ? "Adult" : "Minor";
Console.WriteLine(status);
```

`(condition) ? value1 : value2` — JS ka bilkul same. Parentheses C# mein chhod sakte ho (`umar >= 18 ? ...` bhi chalega), par lagana clear rehta hai.

## switch — same kaam, naya syntax

JS mein `switch` + `break` ka dard tha (bhool gaye toh fall-through). C# mein structure wahi hai, par **case ke end pe `break` zaroori hai** (ya `return`), warna compiler error de deta hai — bhoolne ka chance hi nahi:

```csharp
Console.Write("Option chuno (1/2/3): ");
string ch = Console.ReadLine();

switch (ch)
{
    case "1":
        Console.WriteLine("Naya order");
        break;               // ❗ case khatam yahan
    case "2":
        Console.WriteLine("Order dekho");
        break;
    case "3":
        Console.WriteLine("Bahar");
        break;
    default:                 // default = else
        Console.WriteLine("Galat option");
        break;
}
```

Ek cheez aur — `switch` sirf string/int nahi, har type pe chalta hai (enum waghera mein roz kaam aata hai — module 2 mein dekhenge). Aur modern C# mein pattern matching bhi hai (agar values ke saath condition bhi ho):

```csharp
switch (score)
{
    case >= 90:                    // score 90 se bada?
        Console.WriteLine("A grade");
        break;
    case >= 75:
        Console.WriteLine("B grade");
        break;
    default:
        Console.WriteLine("Aur mehnat");
        break;
}
```

Yeh thoda advanced hai — abhi ke liye classic `case "1":` wala kaafi hai, par jaan lo ki C# ka switch JS wale se zyada powerful hai.

## Logical operators se condition jodna

```csharp
if (umar >= 18 && umar <= 60 && active)
{
    Console.WriteLine("Eligible");
}
```

- `&&` dono sahi chahiye (AND)
- `||` koi ek sahi ho (OR)
- `!` ulta kar do (NOT)

Ek hi file mein do condition — bilkul JS. Fark sirf itna ki operands hamesha boolean hone chahiye (`&&` ke dono taraf `true/false` value).

## Nested if — aur ek chhota pattern

```csharp
if (loggedIn)
{
    if (isAdmin)
    {
        Console.WriteLine("Admin panel");
    }
    else
    {
        Console.WriteLine("Normal user");
    }
}
else
{
    Console.WriteLine("Pehle login karo");
}
```

Chal jaata hai (JS jaisa), par deep nested if padhne mein mushkil hota hai. Professionally isko **early return** se sidha karte hain — functions aate hain toh module 1 ke end mein dikhaunga.

## Ek complete program — ATM jaisa

```csharp
// Program.cs
Console.Write("Balance batao: ");
int balance = int.Parse(Console.ReadLine());

Console.Write("Kitna withdraw karna hai: ");
int amount = int.Parse(Console.ReadLine());

if (amount <= 0)
{
    Console.WriteLine("Amount galat hai.");
}
else if (amount > balance)
{
    Console.WriteLine("Balance kam hai.");
}
else if (amount % 100 != 0)
{
    Console.WriteLine("Sirf 100 ke multiple chalte hain.");
}
else
{
    balance = balance - amount;    // ya balance -= amount;
    Console.WriteLine($"Naya balance: {balance}");
}
```

`amount % 100 != 0` — modulus se check kiya ki 100 ka multiple hai ya nahi. Yahi chhoti chhoti conditions milkar asli logic banati hain.

Yeh kya NAHI hai:

- **`if (umar)` nahi chalta** — JS wali truthy-falsy aadat C# mein nahi. Hamesha boolean condition likho (`umar > 0`).
- **`switch` mein `break` optional nahi hai** — JS mein bhool gaye toh agla case chal jaata tha (bug ban gaya); C# compiler seedha error de deta hai.
- **Condition koi bhi value nahi de sakti** — JS ki tarah `if (stringVar)` (empty string = false wali baat) nahi hoti. `stringVar != ""` likhna padega.

## In Your Own Words

1. JS `if (umar)` chal jaata tha, C# mein `if (umar)` kyun nahi chalta?

<details>
<summary>Sample Jawab</summary>

**Jawab:** C# condition mein strictly boolean chahta hai. `umar` int hai, use directly bool mein nahi daal sakte. JS ki truthy/falsy convention nahi hai — `if (umar > 0)` jaisa explicit boolean comparison likhna padta hai.

</details>

2. C# `switch` mein `break` na likho toh kya hoga — JS ke mukable?

<details>
<summary>Sample Jawab</summary>

**Jawab:** C# mein compiler error aa jaayega (case block ke end mein break/return/throw mandatory hai). JS mein code chal jaata tha aur agle case tak fall-through ho jaata tha — chup-chaap bug. C# ne is possibility ko hi khatam kar diya.

</details>

3. ATM wale program mein `amount % 100 != 0` kya check kar raha hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Modulus `%` 100 se baantne pe bachi hui value deta hai. Agar `% 100 != 0` hai matlab amount 100 ka pura multiple nahi (jaise 250) — toh ATM (wala logic) reject kar raha hai kyunki machine sirf 100 ke notes deti hai.

</details>

4. `else if` vs nested `if` — ek hi kaam ke do tariko mein kya fark hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** `else if` ek hi level pe saari alternative conditions check karta hai — padhne mein saaf. Nested if-andar-if tab hota hai jab condition ki condition ho (pehle login, phir admin) — kyunki dono cheezein ek saath required hain, ek doosre ke andar jaati hain.

</details>

Conditions se program decide kar leta hai — par har decision ke liye line likhna pad raha hai (10 users ke liye 10 baar?). Ab aata hai sabse roz wala kaam: ek kaam baar-baar karne ke liye loops.
