# 17.3 Design Add and Search Words Data Structure

**Problem:** Design a data structure that supports adding words and searching for a word, where the search word can contain '.' (matches any single character). (LeetCode #211)

**Link:** https://leetcode.com/problems/design-add-and-search-words-data-structure/

---

## Which Technique, and Why?

"Add words, search with wildcards" → **Trie + DFS for wildcards**. Insert is O(L). Search: walk the trie; on '.', try all 26 children recursively. O(26^L) worst case for wildcards, but O(L) for exact matches.

**Signal in the problem:** "add word" + "search with '.' wildcard" → Trie with DFS for wildcard matching.

## Approach

Trie with insert (standard) and search (DFS). On a normal char, go to that child. On '.', try all 26 children recursively. Return true if any path leads to a word ending.

## Pseudocode

```
search(word, node, index):
    if index == word.length: return node.isEnd
    c = word[index]
    if c == '.':
        for each child in node.children:
            if child != null and search(child, index+1): return true
        return false
    else:
        if node.children[c-'a'] == null: return false
        return search(node.children[c-'a'], index+1)
```

## Java Code

```java
class WordDictionary {
    private TrieNode root;

    public WordDictionary() {
        root = new TrieNode();
    }

    public void addWord(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) node.children[idx] = new TrieNode();
            node = node.children[idx];
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        return searchHelper(root, word, 0);
    }

    private boolean searchHelper(TrieNode node, String word, int index) {
        if (index == word.length()) return node.isEnd;

        char c = word.charAt(index);
        if (c == '.') {
            for (TrieNode child : node.children) {
                if (child != null && searchHelper(child, word, index + 1)) {
                    return true;
                }
            }
            return false;
        } else {
            int idx = c - 'a';
            if (node.children[idx] == null) return false;
            return searchHelper(node.children[idx], word, index + 1);
        }
    }
}

class TrieNode {
    TrieNode[] children = new TrieNode[26];
    boolean isEnd = false;
}
```

## Line-by-line

- `addWord`: standard Trie insert.
- `search`: delegates to `searchHelper(root, word, 0)`.
- `searchHelper`: if index == word.length, return `node.isEnd` (must be a complete word).
- If `c == '.'`: try all 26 children recursively. If any leads to a match, return true.
- If `c` is a letter: go to that child. If null, return false.

## Complexity

- `addWord`: O(L) where L = word length.
- `search`: O(26^L) worst case (all wildcards), O(L) for exact matches.

## Common Mistakes

- **Not checking `isEnd` at the end.** `search("app")` on a Trie with "apple" should return false. The `index == word.length()` check with `node.isEnd` handles this.
- **Wildcard at the end.** "app." should match "apps" but not "app". The recursion handles this.
- **Not trying all children on '.'.** You must try all 26, not just the first non-null one.
- **Stack overflow on long words with many wildcards.** Deep recursion. For very long words with wildcards, iterative is safer (rare in practice).

## How to Explain (interview)

**Opening:** Design Add and Search Words extends a Trie with wildcard search ('.' matches any char). Insert is O(L). Search is O(L) for exact matches, O(26^L) worst case for wildcards (DFS over all children on '.'). The key difference from standard Trie search: on '.', try all 26 children recursively.

**The basic flow:**
```java
boolean search(String word, TrieNode node, int index) {
    if (index == word.length()) return node.isEnd;
    char c = word.charAt(index);
    if (c == '.') {
        for (TrieNode child : node.children)
            if (child != null && search(child, word, index + 1)) return true;
        return false;
    }
    // normal char: go to that child
}
```

**The part that trips everyone up:** on '.', you must try **all 26 children** recursively, not just the first match. Also, `search` must check `isEnd` at the end (a prefix isn't a match).

**The mistakes to remember:**
- Not checking isEnd at the end (prefix matches word)
- Only trying one child on '.' instead of all 26
- Not handling empty word (returns root.isEnd)
- Stack overflow on very long wildcard words
