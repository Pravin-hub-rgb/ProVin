## The Core Idea

A **Trie** (prefix tree) stores strings character by character. Each node has children for each possible next character. A boolean `isEnd` marks whether a complete word ends at that node.

**Why a Trie?** For prefix search ("all words starting with 'pre'"), a hash set would require scanning all words. A Trie walks the prefix once (O(L)) and collects all words in that subtree.

**Operations:**
- **Insert:** walk/create nodes for each character, mark `isEnd = true` at the last.
- **Search:** walk nodes for each character; return `isEnd` at the last.
- **StartsWith (prefix):** walk nodes for the prefix; return true if the path exists (regardless of `isEnd`).

All operations are O(L) where L = length of the word/prefix.

## Data Structure Primer: Trie

### The Node

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26]; // for lowercase a-z
    boolean isEnd = false;
}
```

- `children[26]` — one slot per letter. `children[c - 'a']` gives the node for char c.
- `isEnd` — true if a complete word ends here.

### The Trie Class

```java
class Trie {
    private TrieNode root;

    public Trie() {
        root = new TrieNode();
    }

    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) node.children[idx] = new TrieNode();
            node = node.children[idx];
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        TrieNode node = findNode(word);
        return node != null && node.isEnd;
    }

    public boolean startsWith(String prefix) {
        return findNode(prefix) != null;
    }

    private TrieNode findNode(String s) {
        TrieNode node = root;
        for (char c : s.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) return null;
            node = node.children[idx];
        }
        return node;
    }
}
```

**Line-by-line:**
- `root` is an empty node (not a character).
- `insert`: walk/create nodes for each char; mark `isEnd` at the end.
- `search`: walk nodes; return `isEnd` (must be a complete word, not just a prefix).
- `startsWith`: walk nodes; return true if the path exists (prefix is present, even if no word ends there).
- `findNode`: shared helper — walks the trie for a string, returns the last node (or null if path breaks).

## How to Recognize It

Think "Trie" when:
- The problem involves **prefix search** or **autocomplete** ("words starting with...").
- The problem involves **word search in a dictionary** (e.g., "Word Search II" — find all words in a grid).
- The problem involves **longest common prefix** among many words.
- Keywords: "prefix," "autocomplete," "dictionary," "word search," "trie."

**Signal words:** "prefix," "words starting with," "dictionary," "word search," "trie," "autocomplete."

## Common Mistakes

- **Not marking `isEnd`.** Without it, `search("app")` returns true for "apple" (prefix exists but not a complete word). `search` checks `isEnd`; `startsWith` doesn't.
- **Assuming lowercase only.** The `children[26]` array assumes lowercase a–z. For uppercase or unicode, use a `HashMap<Character, TrieNode>` instead.
- **Memory overhead.** Each node has 26 pointers (26 × 8 bytes = 208 bytes per node). For large dictionaries, this is significant. `HashMap`-based children are more memory-efficient for sparse tries.
- **Not handling empty string.** `insert("")` marks root as `isEnd = true`. `search("")` returns root.isEnd. Handle consistently.

## How to Explain (interview)

**Opening:** A Trie is a tree where each node represents a character. Paths from root to marked nodes spell words. Shared prefixes share nodes — efficient for prefix search and autocomplete. Insert, search, and prefix check are all O(L) where L = word length. Each node has children (array or map) and an `isEnd` flag.

**The basic flow:**
```java
class TrieNode { TrieNode[] children = new TrieNode[26]; boolean isEnd; }
void insert(String word) { /* walk/create nodes, mark isEnd */ }
boolean search(String word) { /* walk nodes, return isEnd */ }
boolean startsWith(String prefix) { /* walk nodes, return true if path exists */ }
```

**The part that trips everyone up:** `search` checks `isEnd` (must be a complete word); `startsWith` only checks the path (prefix exists). Also, `children[26]` assumes lowercase a–z — use a HashMap for general characters.

**The mistakes to remember:**
- Not marking `isEnd` (prefix vs complete word)
- Assuming lowercase only (use HashMap for general chars)
- Memory overhead (26 pointers per node)
- Not handling empty string
