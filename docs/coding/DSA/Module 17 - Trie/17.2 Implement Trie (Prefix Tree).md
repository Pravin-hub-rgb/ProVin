## Which Technique, and Why?

"Implement a Trie" → **Trie data structure** (Module 17.1). Insert: walk/create nodes for each char, mark isEnd. Search: walk nodes, return isEnd. StartsWith: walk nodes, return true if path exists. O(L) per operation where L = word length.

**Signal in the problem:** "implement trie" / "prefix tree" → Trie (Module 17.1).

## Approach

TrieNode with children[26] and isEnd. Trie class with root. insert/search/startsWith as described in 17.1.

## Java Code

```java
class Trie {
    private TrieNode root;

    public Trie() {
        root = new TrieNode();
    }

    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) node.children[idx] = new TrieNode();
            node = node.children[idx];
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        TrieNode node = findNode(word);
        return node != null && node.isEnd;
    }

    public boolean startsWith(String prefix) {
        return findNode(prefix) != null;
    }

    private TrieNode findNode(String s) {
        TrieNode node = root;
        for (char c : s.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) return null;
            node = node.children[idx];
        }
        return node;
    }
}

class TrieNode {
    TrieNode[] children = new TrieNode[26];
    boolean isEnd = false;
}
```

## Line-by-line

- `root` is an empty node (not a character).
- `insert`: walk/create nodes for each char; mark `isEnd` at the end.
- `search`: walk nodes; return `isEnd` (must be a complete word).
- `startsWith`: walk nodes; return true if path exists (prefix present).
- `findNode`: shared helper — walks the trie, returns last node or null.

## Complexity

- Time: O(L) per operation where L = word/prefix length.
- Space: O(n × L) worst case (no shared prefixes). With shared prefixes, less.

## Common Mistakes

- **Not marking `isEnd`.** `search("app")` would return true for "apple" (prefix exists). `search` checks `isEnd`; `startsWith` doesn't.
- **Assuming lowercase only.** `children[26]` assumes a–z. For general input, use `Map<Character, TrieNode>`.
- **Not handling empty string.** `insert("")` marks root as `isEnd = true`. `search("")` returns root.isEnd. Handle consistently.
