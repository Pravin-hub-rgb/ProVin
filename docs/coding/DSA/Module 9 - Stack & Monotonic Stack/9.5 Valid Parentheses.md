**Problem:** Given a string of brackets, determine if it's valid (every opening bracket has a matching closing bracket in the correct order). (LeetCode #20)

**Link:** https://leetcode.com/problems/valid-parentheses/

---

## Which Technique, and Why?

Bracket matching → **Stack (LIFO)**. Push opening brackets; on a closing bracket, pop and check if it matches. If the stack is empty at the end, it's valid.

Why a stack and not a counter? A counter works for a single bracket type `()` but not for multiple types `()[]{}` — you need to track *which* opening bracket matches each closing one. LIFO gives you the most recent opening bracket.

**Signal in the problem:** "valid parentheses" / "matching brackets" / "balanced" → stack.

## Approach

For each character: if opening bracket, push. If closing bracket: if stack is empty → invalid; pop top and check it matches. At the end, valid iff stack is empty.

## Pseudocode

```
stack = empty
for each c in s:
    if c is opening: stack.push(c)
    else if c is closing:
        if stack is empty: return false
        if !matches(stack.pop(), c): return false
return stack.isEmpty()
```

## Java Code

```java
class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) return false;
                char top = stack.pop();
                if (!matches(top, c)) return false;
            }
        }
        return stack.isEmpty();
    }

    private boolean matches(char open, char close) {
        return (open == '(' && close == ')') ||
               (open == '[' && close == ']') ||
               (open == '{' && close == '}');
    }
}
```

## Line-by-line

- `stack` holds opening brackets.
- Opening bracket → push.
- Closing bracket → if stack empty, invalid (no matching open). Pop top; if it doesn't match the closing type → invalid.
- `matches` checks the open-close pair.
- `return stack.isEmpty()` — all opens must be closed. If stack non-empty, there are unmatched opens.

## Complexity

- Time: O(n) — single pass.
- Space: O(n) — stack can hold up to n opens.

## Common Mistakes

- **Not checking empty stack before pop.** `stack.pop()` on empty throws `NoSuchElementException`. Check `isEmpty()` first.
- **Forgetting the final `isEmpty()` check.** `"("` → stack has `(`, loop ends, returns true if you skip the check. Always check empty at the end.
- **Using `==` for char comparison** — fine for primitives. The issue is logic, not syntax.
- **Not handling all three bracket types.** Make sure `matches` covers `()`, `[]`, `{}`.

## How to Explain (interview)

**Opening:** Valid Parentheses checks if brackets are balanced and properly nested. Stack (LIFO): push opening brackets, pop on closing and check it matches. Valid iff the stack is empty at the end. O(n) time, O(n) space.

**The basic flow:**
```java
Deque<Character> stack = new ArrayDeque<>();
for (char c : s.toCharArray()) {
    if (isOpen(c)) stack.push(c);
    else {
        if (stack.isEmpty()) return false;
        if (!matches(stack.pop(), c)) return false;
    }
}
return stack.isEmpty();
```

**The part that trips everyone up:** you must check `stack.isEmpty()` before popping (otherwise NPE/exception) AND at the end (unmatched opens). Also, LIFO ensures correct nesting — the most recent open must match the current close.

**The mistakes to remember:**
- Popping from an empty stack (exception)
- Forgetting the final `isEmpty()` check (unmatched opens pass)
- Using a counter instead of a stack for multiple bracket types
