**Tier 2 problem.** (LeetCode #402)

**Problem:** Given a string representing a non-negative integer, remove k digits to form the smallest possible number. (LeetCode #402)

**Link:** https://leetcode.com/problems/remove-k-digits/

---

## Which Technique, and Why?

"Remove k digits to form smallest number" → **Monotonic Stack (increasing)**. Build the result digit by digit: for each digit, while the stack is non-empty and the top is greater than the current digit and we still have removals left, pop (remove the larger digit). Push the current digit. At the end, if removals remain, remove from the end. Strip leading zeros.

**Signal in the problem:** "remove k digits" / "smallest number" → monotonic increasing stack.

## Approach

Monotonic increasing stack. For each digit: while stack non-empty, top > current, and k > 0 → pop (remove), k--. Push current. After processing all digits, if k > 0, remove k from the end. Strip leading zeros. If empty, return "0".

## Pseudocode

```
stack = empty
for each digit c in num:
    while stack not empty and stack.peek() > c and k > 0:
        stack.pop()
        k--
    stack.push(c)
// remove remaining k from the end
while k > 0: stack.pop(); k--
// build result, strip leading zeros
result = stack joined
if result is empty or all zeros: return "0"
return result (stripped)
```

## Java Code

```java
class Solution {
    public String removeKdigits(String num, int k) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : num.toCharArray()) {
            while (!stack.isEmpty() && stack.peek() > c && k > 0) {
                stack.pop();
                k--;
            }
            stack.push(c);
        }

        // Remove remaining k from the end
        while (k > 0 && !stack.isEmpty()) {
            stack.pop();
            k--;
        }

        // Build result, strip leading zeros
        StringBuilder sb = new StringBuilder();
        boolean leadingZero = true;
        for (char c : stack) {
            if (leadingZero && c == '0') continue;
            leadingZero = false;
            sb.append(c);
        }

        return sb.length() == 0 ? "0" : sb.toString();
    }
}
```

## Line-by-line

- `while (stack.peek() > c && k > 0)` — if the top is larger than current and we can still remove, pop. This ensures the result is as small as possible (larger digits removed from the left).
- `stack.push(c)` — push current digit.
- After the loop, if `k > 0`, remove from the end (the largest remaining digits).
- Strip leading zeros: skip '0's until a non-zero is found.
- If result is empty, return "0".

## Complexity

- Time: O(n) — each digit pushed and popped at most once.
- Space: O(n) — stack.

## Common Mistakes

- **Using `>=` instead of `>`.** Use `>` (strictly greater). If equal, don't remove (removing equal doesn't help; keeping it preserves order).
- **Not stripping leading zeros.** "0200" → "200" (strip leading 0). "000" → "0".
- **Not handling remaining k.** If the number is already increasing (e.g., "12345"), no pops happen during the loop. Remove k from the end.
- **Empty result.** If all digits are removed, return "0".

## How to Explain (interview)

**Opening:** Remove K Digits forms the smallest number after removing k digits. Monotonic increasing stack: for each digit, pop larger digits from the top (while k > 0). Push current. Remove remaining k from the end. Strip leading zeros. O(n) time, O(n) space.

**The basic flow:**
```java
Deque<Character> stack = new ArrayDeque<>();
for (char c : num.toCharArray()) {
    while (!stack.isEmpty() && stack.peek() > c && k > 0) { stack.pop(); k--; }
    stack.push(c);
}
while (k > 0) { stack.pop(); k--; }
// strip leading zeros, return "0" if empty
```

**The part that trips everyone up:** the `>` (not `>=`) in the while condition. Also, after the loop, remove remaining k from the **end** (not the beginning). And strip leading zeros.

**The mistakes to remember:**
- Using `>=` instead of `>` (removes equal, unnecessary)
- Not removing remaining k from the end
- Not stripping leading zeros
- Returning empty string instead of "0"
