# 9.18 Basic Calculator II

**Tier 2 problem.** (LeetCode #227)

**Problem:** Given a string with +, -, *, / and non-negative integers, evaluate the expression. Integer division truncates toward zero. (LeetCode #227)

**Link:** https://leetcode.com/problems/basic-calculator-ii/

---

## Which Technique, and Why?

"Evaluate expression with +, -, *, /" → **Stack (for * and /) + running sum (for + and -)**. Process left to right. On + or -, push the current number (with sign) to a stack. On * or /, pop the top, apply the operation, push back. At the end, sum all elements in the stack. O(n) time, O(n) space.

**Signal in the problem:** "evaluate expression" + "+, -, *, /" + "no parentheses" → stack for * and /, running sum for + and -.

## Approach

Walk the string. Accumulate digits into `num`. On an operator or end of string: apply the previous operator. If prev op is + or -, push ±num to stack. If * or /, pop top, apply, push back. Reset num. At the end, sum the stack.

## Pseudocode

```
stack = empty
num = 0
prevOp = '+'
for i from 0 to s.length:
    c = (i < n) ? s[i] : '+'  // process last number
    if c is digit: num = num * 10 + (c - '0')
    else if c is operator or end:
        if prevOp == '+': stack.push(num)
        elif prevOp == '-': stack.push(-num)
        elif prevOp == '*': stack.push(stack.pop() * num)
        elif prevOp == '/': stack.push(stack.pop() / num)  // integer division
        prevOp = c
        num = 0
return sum of stack
```

## Java Code

```java
class Solution {
    public int calculate(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        int num = 0;
        char prevOp = '+';

        for (int i = 0; i <= s.length(); i++) {
            char c = (i < s.length()) ? s.charAt(i) : '+';

            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == ' ') {
                continue;
            } else {
                if (prevOp == '+') stack.push(num);
                else if (prevOp == '-') stack.push(-num);
                else if (prevOp == '*') stack.push(stack.pop() * num);
                else if (prevOp == '/') stack.push(stack.pop() / num);

                prevOp = c;
                num = 0;
            }
        }

        int result = 0;
        for (int val : stack) result += val;
        return result;
    }
}
```

## Line-by-line

- `prevOp = '+'` — the first number is added.
- Loop goes to `s.length()` (inclusive) — the `+` at the end triggers processing of the last number.
- Digit → accumulate `num`.
- Space → skip.
- Operator (or end): apply `prevOp` to `num`. For +/−, push ±num. For */÷, pop top, apply, push back.
- Set `prevOp = c`, reset `num = 0`.
- Sum all stack elements for the result.

## Complexity

- Time: O(n) — single pass.
- Space: O(n) — stack holds up to n/2 numbers.

## Common Mistakes

- **Not processing the last number.** The loop goes to `s.length()` (inclusive) with a virtual '+' to trigger processing. Without this, the last number is lost.
- **Spaces in the string.** Skip spaces with `continue`. Don't treat space as an operator.
- **Integer division.** Java's `/` truncates toward zero. The problem specifies this. Don't use `Math.floor`.
- **Operand order for `/`.** `stack.pop() / num` (top / current), not `num / stack.pop()`.
- **Using two stacks (one for ops, one for nums).** Works but unnecessary — the "prevOp" approach is simpler for +, -, *, /.

## How to Explain (interview)

**Opening:** Basic Calculator II evaluates +, -, *, / without parentheses. Stack for * and /, running accumulation for + and -. Walk left to right; on an operator, apply the previous operator to the accumulated number. At the end, sum the stack. O(n) time, O(n) space.

**The basic flow:**
```java
Deque<Integer> stack = new ArrayDeque<>();
int num = 0; char prevOp = '+';
for (int i = 0; i <= s.length(); i++) {
    char c = (i < s.length()) ? s.charAt(i) : '+';
    if (isDigit(c)) num = num * 10 + (c - '0');
    else if (c != ' ') {
        if (prevOp == '+') stack.push(num);
        else if (prevOp == '-') stack.push(-num);
        else if (prevOp == '*') stack.push(stack.pop() * num);
        else if (prevOp == '/') stack.push(stack.pop() / num);
        prevOp = c; num = 0;
    }
}
return sum(stack);
```

**The part that trips everyone up:** the loop goes to `s.length()` (inclusive) with a virtual '+' to process the last number. Also, for `/`, it's `stack.pop() / num` (top / current), not the reverse.

**The mistakes to remember:**
- Not processing the last number (loop bound)
- Not skipping spaces (treats space as operator)
- Wrong operand order for `/`
- Using `Math.floor` instead of truncation (Java `/` truncates toward zero)
- Using two stacks when one suffices
