**Problem:** Given daily temperatures, return an array where each element is the number of days until a warmer temperature. If no warmer day exists, 0. (LeetCode #739)

**Link:** https://leetcode.com/problems/daily-temperatures/

---

## Which Technique, and Why?

"Number of days until a warmer temperature" = "next greater element" (distance version) → **Monotonic Stack (decreasing)**. Store indices of days whose warmer day hasn't been found. When a warmer day arrives, pop and compute the distance. O(n) time, O(n) space.

**Signal in the problem:** "days until warmer" / "next greater element (distance)" → monotonic stack (decreasing). Store indices, not values.

## Approach

Stack of indices (decreasing temperatures). For each day i: while stack non-empty and `temperatures[i] > temperatures[stack.peek()]`, pop idx, set `result[idx] = i - idx`. Push i. Unresolved indices keep result 0 (default).

## Pseudocode

```
result = new int[n] (default 0)
stack = empty (indices)
for i from 0 to n-1:
    while stack not empty and temperatures[i] > temperatures[stack.peek()]:
        idx = stack.pop()
        result[idx] = i - idx
    stack.push(i)
return result
```

## Java Code

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] result = new int[n];
        Deque<Integer> stack = new ArrayDeque<>(); // indices, decreasing temps

        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && temperatures[stack.peek()] < temperatures[i]) {
                int idx = stack.pop();
                result[idx] = i - idx;
            }
            stack.push(i);
        }
        return result;
    }
}
```

## Line-by-line

- `result` initialized to 0 — unresolved days stay 0 (correct answer).
- `stack` holds indices of days waiting for a warmer day. Temperatures at these indices are in **decreasing** order (monotonic decreasing stack).
- For day `i`: while the top index has a lower temperature than `temperatures[i]`, pop it — `i` is its next warmer day. Record `i - idx` days.
- Push `i` onto the stack.
- Each index pushed once, popped at most once → O(n) total.

## Complexity

- Time: O(n) — each element pushed and popped at most once.
- Space: O(n) — stack and result array.

## Common Mistakes

- **Storing values instead of indices.** You need indices to compute `i - idx` (days). Store indices, look up values via the array.
- **Using `if` instead of `while`.** A single warmer day may resolve multiple previous days. Use `while` to pop all that are resolved.
- **Wrong monotonic order.** For "next greater," the stack must be **decreasing** (so a new larger value resolves the top). If you maintain increasing, the logic breaks.
- **Forgetting unresolved elements.** They stay in the stack with result 0 — correct, since there's no warmer day. The default 0 handles this.

## How to Explain (interview)

**Opening:** Daily Temperatures asks how many days until a warmer temperature. Monotonic stack (decreasing): store indices of days waiting for a warmer day. For each new day, pop all indices with lower temperature — the new day is their "next warmer." Record the distance. O(n) time, O(n) space. Unresolved days keep 0.

**The basic flow:**
```java
Deque<Integer> stack = new ArrayDeque<>();
for (int i = 0; i < n; i++) {
    while (!stack.isEmpty() && temp[stack.peek()] < temp[i]) {
        int idx = stack.pop();
        result[idx] = i - idx;
    }
    stack.push(i);
}
```

**The part that trips everyone up:** store **indices**, not temperatures (you need the distance). Use `while`, not `if`. The stack is monotonic **decreasing** — if you maintain increasing, the logic is wrong.

**The mistakes to remember:**
- Storing values instead of indices
- Using `if` instead of `while`
- Wrong monotonic order (decreasing for next-greater)
- Forgetting that unresolved elements stay 0 (default)
