**Tier 2 problem.** (LeetCode #394)

**Problem:** Given an encoded string like "3[a2[c]]", decode it to "accaccacc". (LeetCode #394)

**Link:** https://leetcode.com/problems/decode-string/

---

## Which Technique, and Why?

"Decode encoded string with nested brackets" → **Stack (two stacks or one stack of strings/counts)**. Process left to right. On digit: parse the full number. On '[': push current string and count, reset. On ']': pop count and previous string, repeat current string count times. O(n) time, O(n) space.

**Signal in the problem:** "decode string" / "nested brackets" / "k[encoded_string]" → stack-based decoding.

## Approach

Two stacks: one for counts, one for strings. Walk the string:
- Digit: parse the full number.
- '[': push count and current string to stacks, reset.
- ']': pop count and previous string; repeat current string count times; append to previous.
- Letter: append to current string.

## Pseudocode

```
stack = empty (of (count, prevString))
current = ""
num = 0
for each char c in s:
    if c is digit: num = num * 10 + (c - '0')
    elif c == '[':
        stack.push((num, current))
        current = ""
        num = 0
    elif c == ']':
        (prevNum, prevStr) = stack.pop()
        current = prevStr + current.repeat(prevNum)
    else:
        current += c
return current
```

## Java Code

```java
class Solution {
    public String decodeString(String s) {
        Deque<Integer> countStack = new ArrayDeque<>();
        Deque<String> strStack = new ArrayDeque<>();
        StringBuilder current = new StringBuilder();
        int num = 0;

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                countStack.push(num);
                strStack.push(current.toString());
                current = new StringBuilder();
                num = 0;
            } else if (c == ']') {
                int count = countStack.pop();
                String prev = strStack.pop();
                StringBuilder temp = new StringBuilder(prev);
                for (int i = 0; i < count; i++) temp.append(current);
                current = temp;
            } else {
                current.append(c);
            }
        }
        return current.toString();
    }
}
```

## Line-by-line

- `num` accumulates multi-digit numbers (e.g., "12[a]" → num = 12).
- On '[': push num and current string to stacks, reset both.
- On ']': pop count and prev string; repeat current count times; append to prev.
- On letter: append to current.
- `StringBuilder` for efficient append (String concatenation would be O(n²)).

## Complexity

- Time: O(n × maxRepeat) — each character may be repeated up to maxRepeat times.
- Space: O(n) — stacks + StringBuilder.

## Common Mistakes

- **Not parsing multi-digit numbers.** "12[a]" → num = 12, not 1 then 2. Accumulate: `num = num * 10 + digit`.
- **Using String instead of StringBuilder.** O(n²) due to immutability. Use StringBuilder.
- **Wrong repeat count.** Repeat `current` count times, not count-1 or count+1.
- **Not resetting num after '['.** Set `num = 0` after pushing.
- **Nested brackets.** The stack handles nesting naturally (push/pop).
