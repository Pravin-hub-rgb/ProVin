**Tier 2 problem.** (LeetCode #503)

**Problem:** Given a circular array, find the next greater element for each element (the first greater element to its right, wrapping around). (LeetCode #503)

**Link:** https://leetcode.com/problems/next-greater-element-ii/

---

## Which Technique, and Why?

"Next greater element in a circular array" → **Monotonic Stack (decreasing) + circular traversal**. Duplicate the array conceptually (or iterate 2n times with mod). For each element, pop all smaller elements from the stack — the current element is their next greater. O(n) time, O(n) space.

**Signal in the problem:** "next greater element" + "circular" → monotonic stack + double the array (or mod n).

## Approach

Iterate 2n times (i = 0 to 2n-1). Use `i % n` to index the array. Maintain a decreasing stack of indices. For each i, pop while `nums[stack.peek()] < nums[i % n]`, record `nums[i % n]` as the next greater for the popped index. Push `i % n` (only in the first pass, i < n, to avoid duplicates). Unresolved indices get -1.

## Pseudocode

```
result = new int[n] (default -1)
stack = empty
for i from 0 to 2n - 1:
    idx = i % n
    while stack not empty and nums[stack.peek()] < nums[idx]:
        result[stack.pop()] = nums[idx]
    if i < n: stack.push(idx)
return result
```

## Java Code

```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        Arrays.fill(result, -1);
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < 2 * n; i++) {
            int idx = i % n;
            while (!stack.isEmpty() && nums[stack.peek()] < nums[idx]) {
                result[stack.pop()] = nums[idx];
            }
            if (i < n) stack.push(idx);
        }
        return result;
    }
}
```

## Line-by-line

- `result` initialized to -1 (unresolved → -1).
- `i` from 0 to 2n-1 (simulates circular array).
- `idx = i % n` — wraps around.
- `while (nums[stack.peek()] < nums[idx])` — current is greater → pop and record.
- `if (i < n) stack.push(idx)` — only push in the first pass (avoid duplicate pushes).

## Complexity

- Time: O(n) — each element pushed and popped at most once (in the first pass).
- Space: O(n) — stack and result.

## Common Mistakes

- **Pushing in both passes.** Only push in the first pass (`i < n`). Otherwise, duplicates cause wrong results.
- **Using `<=` instead of `<`.** For "next greater" (strictly greater), use `<`. For "next greater or equal," use `<=`.
- **Not initializing result to -1.** Unresolved elements should be -1.
- **Modifying the array.** Don't duplicate the array (wastes space). Use `i % n`.
