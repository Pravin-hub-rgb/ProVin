**Tier 2 problem.** (LeetCode #735)

**Problem:** Given asteroids moving in a row (positive = right, negative = left), find the state after all collisions. Larger asteroid survives; equal ones destroy each other. (LeetCode #735)

**Link:** https://leetcode.com/problems/asteroid-collision/

---

## Which Technique, and Why?

"Asteroid collision" → **Stack**. Process left to right. For each asteroid: if it's moving right (positive) or stack is empty, push. If moving left (negative), it collides with right-moving asteroids on the stack: pop while top is smaller (and positive), handle equal (both destroyed), keep if top is larger. O(n) time, O(n) space.

**Signal in the problem:** "collision" / "asteroids moving toward each other" → stack (process collisions).

## Approach

Stack of surviving asteroids. For each new asteroid:
- If positive (moving right) or stack empty → push.
- If negative (moving left): while stack top is positive and smaller → pop. If top is equal → pop both (destroyed, skip pushing). If top is larger → new asteroid destroyed (don't push). If stack empty or top is negative → push.

## Pseudocode

```
stack = empty
for a in asteroids:
    if a > 0 or stack empty or stack.peek() < 0:
        stack.push(a)
    else:  // a < 0, stack top > 0 → collision
        while !stack.empty and stack.peek() > 0 and stack.peek() < -a:
            stack.pop()
        if stack.empty or stack.peek() < 0:
            stack.push(a)
        elif stack.peek() == -a:
            stack.pop()  // both destroyed
        // else: top > -a, new asteroid destroyed, do nothing
return stack
```

## Java Code

```java
class Solution {
    public int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (int a : asteroids) {
            if (a > 0 || stack.isEmpty() || stack.peek() < 0) {
                stack.push(a);
            } else {
                // a < 0, stack top > 0 → collision
                while (!stack.isEmpty() && stack.peek() > 0 && stack.peek() < -a) {
                    stack.pop();
                }
                if (stack.isEmpty() || stack.peek() < 0) {
                    stack.push(a);
                } else if (stack.peek() == -a) {
                    stack.pop();  // both destroyed
                }
                // else: top > -a, new asteroid destroyed
            }
        }

        int[] result = new int[stack.size()];
        for (int i = result.length - 1; i >= 0; i--) {
            result[i] = stack.pop();
        }
        return result;
    }
}
```

## Line-by-line

- `a > 0 || stack.isEmpty() || stack.peek() < 0` — no collision: push. (Right-moving, empty stack, or top is also left-moving.)
- Collision case: `a < 0`, top > 0.
- `while (stack.peek() > 0 && stack.peek() < -a)` — pop smaller right-moving asteroids (new asteroid is bigger).
- `if (stack.isEmpty() || stack.peek() < 0)` — new asteroid survives (push).
- `else if (stack.peek() == -a)` — equal → both destroyed (pop, don't push).
- `else` — top is bigger → new asteroid destroyed (do nothing).
- Result: stack is LIFO, so pop into array from the end to get correct order.

## Complexity

- Time: O(n) — each asteroid pushed and popped at most once.
- Space: O(n) — stack.

## Common Mistakes

- **Not handling equal magnitudes.** If `stack.peek() == -a`, both are destroyed — pop and don't push. Missing this causes wrong results.
- **Result order.** The stack is LIFO; pop into the array from the end to preserve left-to-right order.
- **Using `>` instead of `<` in the while condition.** You pop when the top is **smaller** than the new asteroid (`stack.peek() < -a`). Using `>` would pop larger ones (wrong).
- **Not handling the case where the new asteroid is destroyed.** If the top is larger, do nothing (don't push). Missing the `else` branch causes the destroyed asteroid to be pushed.

## How to Explain (interview)

**Opening:** Asteroid Collision processes asteroids left to right with a stack. Right-moving asteroids are pushed. A left-moving asteroid collides with right-moving ones on the stack: pop smaller ones, destroy both if equal, keep if the stack top is larger. O(n) time, O(n) space.

**The basic flow:**
```java
for (int a : asteroids) {
    if (a > 0 || stack.isEmpty() || stack.peek() < 0) stack.push(a);
    else {
        while (!stack.isEmpty() && stack.peek() > 0 && stack.peek() < -a) stack.pop();
        if (stack.isEmpty() || stack.peek() < 0) stack.push(a);
        else if (stack.peek() == -a) stack.pop();
    }
}
```

**The part that trips everyone up:** three cases after the while loop — (1) stack empty or top is negative → push new asteroid; (2) top equals magnitude → both destroyed (pop, don't push); (3) top is larger → new asteroid destroyed (do nothing). Also, result order: pop into array from the end.

**The mistakes to remember:**
- Not handling equal magnitudes (both destroyed)
- Wrong while condition (`>` instead of `<`)
- Not un-pushing (pushing destroyed asteroids)
- Result order (stack is LIFO)
