**Tier 2 problem.** (LeetCode #1094)

**Problem:** Given trips (passengers, start, end) and a car capacity, determine if all trips can be completed (i.e., at no point do passengers exceed capacity). (LeetCode #1094)

**Link:** https://leetcode.com/problems/car-pooling/

---

## Which Technique, and Why?

"Can all trips be completed without exceeding capacity?" → **Difference Array / Sweep Line**. Create an array of size (max location + 1). For each trip: `+passengers` at start, `-passengers` at end. Then compute prefix sums; if any exceeds capacity → false. O(n + maxLocation) time, O(maxLocation) space.

**Signal in the problem:** "car pooling" / "trips with start/end" / "capacity" / "can all be completed" → difference array + prefix sum.

## Approach

Difference array: `diff[start] += passengers`, `diff[end] -= passengers`. Then prefix sum gives the number of passengers at each location. If any prefix sum > capacity → false.

## Pseudocode

```
maxLoc = max end location
diff = new int[maxLoc + 1]
for each trip (p, start, end):
    diff[start] += p
    diff[end] -= p   // passenger gets off at end
prefix = 0
for i from 0 to maxLoc:
    prefix += diff[i]
    if prefix > capacity: return false
return true
```

## Java Code

```java
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {
        int maxLoc = 0;
        for (int[] trip : trips) maxLoc = Math.max(maxLoc, trip[2]);

        int[] diff = new int[maxLoc + 1];
        for (int[] trip : trips) {
            diff[trip[1]] += trip[0];
            diff[trip[2]] -= trip[0];
        }

        int passengers = 0;
        for (int i = 0; i <= maxLoc; i++) {
            passengers += diff[i];
            if (passengers > capacity) return false;
        }
        return true;
    }
}
```

## Line-by-line

- `maxLoc` — the furthest end location (array size).
- `diff[start] += passengers` — passengers board at start.
- `diff[end] -= passengers` — passengers alight at end.
- Prefix sum (`passengers`) = current passengers at location i.
- If `passengers > capacity` at any point → can't complete → false.

## Complexity

- Time: O(n + maxLoc) where n = number of trips.
- Space: O(maxLoc) — the diff array.

## Common Mistakes

- **Off-by-one at end.** `diff[trip[2]] -= passengers` (passenger gets off AT end, so subtract at end, not end+1). The prefix sum at location `end` includes the subtraction (passenger already off). If you want "passenger on during [start, end)", subtract at end. If "on during [start, end]", subtract at end+1. The problem says "from start to end" (passenger is on during [start, end-1] essentially, off at end). The code above subtracts at `end`, which means at location `end`, the passenger is already off. This matches the problem's semantics.
- **Not finding maxLoc.** If you use a fixed size, you might miss locations or waste space. Compute maxLoc from the trips.
- **Using a TreeMap instead of an array.** Works (O(n log n)) but array is O(n + maxLoc) and simpler.
- **Not handling trips with 0 passengers.** Harmless (adds 0), but the code handles it.

## How to Explain (interview)

**Opening:** Car Pooling checks if all trips can be completed without exceeding capacity. Difference array: for each trip, +passengers at start, -passengers at end. Prefix sum gives passengers at each location. If any exceeds capacity → false. O(n + maxLoc) time, O(maxLoc) space.

**The basic flow:**
```java
int[] diff = new int[maxLoc + 1];
for (int[] trip : trips) { diff[trip[1]] += trip[0]; diff[trip[2]] -= trip[0]; }
int passengers = 0;
for (int i = 0; i <= maxLoc; i++) {
    passengers += diff[i];
    if (passengers > capacity) return false;
}
return true;
```

**The part that trips everyone up:** the subtraction happens at `end` (passenger gets off at end). Also, use a difference array, not a 2D grid or a TreeMap (simpler and faster).

**The mistakes to remember:**
- Off-by-one: subtract at `end`, not `end + 1` (or vice versa, depending on semantics)
- Not computing maxLoc (fixed size may miss locations)
- Using TreeMap (O(n log n)) when array is O(n + maxLoc)
- Not handling 0-passenger trips (harmless but verify)
