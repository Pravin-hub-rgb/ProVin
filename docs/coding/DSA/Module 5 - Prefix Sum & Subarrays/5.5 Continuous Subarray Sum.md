# 5.5 Continuous Subarray Sum

**Tier 2 problem.** (LeetCode #523)

**Problem:** Given an integer array and k, return true if there's a contiguous subarray of size ≥ 2 whose sum is a multiple of k. (LeetCode #523)

**Link:** https://leetcode.com/problems/continuous-subarray-sum/

---

## Which Technique, and Why?

"Subarray sum divisible by k" with size ≥ 2 → **Prefix Sum + HashMap (mod k)**. If two prefix sums have the same remainder mod k, the subarray between them is divisible by k. Also need to ensure the subarray has at least 2 elements (track the index). O(n) time, O(k) space.

**Signal in the problem:** "subarray sum multiple of k" / "divisible by k" → prefix sum mod k + hash map.

## Approach

Walk the array, maintaining prefix sum mod k. Store the first index where each remainder was seen. If the same remainder appears again and the distance ≥ 2, return true.

## Pseudocode

```
prefixMod = 0
map = {0: -1}  // remainder 0 seen at index -1 (empty prefix)
for i from 0 to n-1:
    prefixMod = (prefixMod + nums[i]) % k
    if prefixMod < 0: prefixMod += k  // handle negatives
    if map contains prefixMod:
        if i - map[prefixMod] >= 2: return true
    else: map[prefixMod] = i
return false
```

## Java Code

```java
class Solution {
    public boolean checkSubarraySum(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, -1);  // empty prefix
        int prefixMod = 0;

        for (int i = 0; i < nums.length; i++) {
            prefixMod = (prefixMod + nums[i]) % k;
            if (prefixMod < 0) prefixMod += k;

            if (map.containsKey(prefixMod)) {
                if (i - map.get(prefixMod) >= 2) return true;
            } else {
                map.put(prefixMod, i);
            }
        }
        return false;
    }
}
```

## Line-by-line

- `map` stores remainder → first index where it was seen.
- `map.put(0, -1)` — empty prefix has remainder 0 at index -1. Handles subarrays starting at index 0.
- `prefixMod = (prefixMod + nums[i]) % k` — running sum mod k.
- `if (prefixMod < 0) prefixMod += k` — handle negative numbers (Java's % can be negative).
- If remainder seen before and distance ≥ 2 → subarray of size ≥ 2 divisible by k → true.
- Otherwise, record the first occurrence of this remainder.

## Complexity

- Time: O(n) — single pass.
- Space: O(min(n, k)) — at most k distinct remainders.

## Common Mistakes

- **Not handling negative numbers.** Java's `%` can be negative. Add `if (prefixMod < 0) prefixMod += k;`.
- **Not checking subarray size ≥ 2.** `i - map.get(prefixMod) >= 2` ensures at least 2 elements.
- **Storing the latest index instead of the first.** Store the first occurrence (use `putIfAbsent` or check `containsKey` first). Storing the latest would miss valid subarrays.
- **k = 0.** Division by zero. Problem guarantees k ≥ 1, but handle defensively.

## How to Explain (interview)

**Opening:** Continuous Subarray Sum checks if any subarray of size ≥ 2 has sum divisible by k. Prefix sum mod k: if two prefix sums have the same remainder mod k, the subarray between them is divisible by k. Track first occurrence of each remainder. O(n) time, O(k) space.

**The basic flow:**
```java
Map<Integer, Integer> map = new HashMap<>();
map.put(0, -1);
int prefixMod = 0;
for (int i = 0; i < nums.length; i++) {
    prefixMod = (prefixMod + nums[i]) % k;
    if (prefixMod < 0) prefixMod += k;
    if (map.containsKey(prefixMod) && i - map.get(prefixMod) >= 2) return true;
    if (!map.containsKey(prefixMod)) map.put(prefixMod, i);
}
```

**The part that trips everyone up:** handle **negative numbers** (Java's % can be negative). Also, store the **first** occurrence of each remainder (not the latest) to maximize subarray length. And check `distance >= 2` for the size constraint.

**The mistakes to remember:**
- Not handling negative remainders (Java % can be negative)
- Not checking subarray size ≥ 2
- Storing latest index instead of first (misses valid subarrays)
- k = 0 (division by zero)
