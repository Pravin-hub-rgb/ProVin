# 5.8 Maximum Product Subarray

**Tier 2 problem.** (LeetCode #152)

**Problem:** Given an integer array, find the contiguous subarray with the largest product. (LeetCode #152)

**Link:** https://leetcode.com/problems/maximum-product-subarray/

---

## Which Technique, and Why?

"Maximum product subarray" → **DP with running min and max**. Since negatives flip signs, you must track both the max and min product ending at each position. `maxProd = max(nums[i], maxProd * nums[i], minProd * nums[i])`. Same for min. O(n) time, O(1) space.

**Signal in the problem:** "maximum product subarray" → track both max and min (because negatives flip signs).

## Approach

Walk the array. At each position, compute the new max and min product ending here: `newMax = max(nums[i], maxProd * nums[i], minProd * nums[i])`, `newMin = min(...)`. Track the global max.

## Pseudocode

```
maxProd = nums[0], minProd = nums[0], result = nums[0]
for i from 1 to n-1:
    candidates = {nums[i], maxProd * nums[i], minProd * nums[i]}
    newMax = max(candidates)
    newMin = min(candidates)
    maxProd = newMax
    minProd = newMin
    result = max(result, maxProd)
return result
```

## Java Code

```java
class Solution {
    public int maxProduct(int[] nums) {
        int maxProd = nums[0];
        int minProd = nums[0];
        int result = nums[0];

        for (int i = 1; i < nums.length; i++) {
            int tempMax = Math.max(nums[i], Math.max(maxProd * nums[i], minProd * nums[i]));
            int tempMin = Math.min(nums[i], Math.min(maxProd * nums[i], minProd * nums[i]));
            maxProd = tempMax;
            minProd = tempMin;
            result = Math.max(result, maxProd);
        }
        return result;
    }
}
```

## Line-by-line

- `maxProd` / `minProd` — max/min product of subarray ending at current position.
- `tempMax` / `tempMin` — computed from previous values (use temp to avoid using updated maxProd for minProd).
- `result` — global max across all positions.
- Handle zeros: if `nums[i] == 0`, both maxProd and minProd become 0, and the next element starts fresh (since `max(0, 0, 0) = 0` and `min(...) = 0`, but `nums[i+1]` will be `max(nums[i+1], 0, 0) = nums[i+1]`).

## Complexity

- Time: O(n) — single pass.
- Space: O(1) — three variables.

## Common Mistakes

- **Only tracking max.** With negatives, the min product can become the max (e.g., -2 × -3 = 6). Track both.
- **Updating maxProd before computing minProd.** Use temp variables: compute both from old values, then update.
- **Not handling zeros.** Zeros reset the product. The code handles this naturally (max/min become 0, next element starts fresh).
- **Confusing with "Maximum Subarray" (#53).** That's sum (Kadane's), this is product (track min too).

## How to Explain (interview)

**Opening:** Maximum Product Subarray finds the contiguous subarray with the largest product. Unlike sum (Kadane's), product has a twist: negatives flip signs, so a min product can become max. Track both max and min products ending at each position. O(n) time, O(1) space.

**The basic flow:**
```java
int maxProd = nums[0], minProd = nums[0], result = nums[0];
for (int i = 1; i < nums.length; i++) {
    int tempMax = Math.max(nums[i], Math.max(maxProd * nums[i], minProd * nums[i]));
    int tempMin = Math.min(nums[i], Math.min(maxProd * nums[i], minProd * nums[i]));
    maxProd = tempMax; minProd = tempMin;
    result = Math.max(result, maxProd);
}
```

**The part that trips everyone up:** track **both** max and min (because negatives flip). Use **temp variables** to compute both from old values (don't use updated maxProd for minProd).

**The mistakes to remember:**
- Only tracking max (misses negative × negative = positive)
- Updating maxProd before computing minProd (uses wrong value)
- Not handling zeros (resets product — handled naturally)
- Confusing with Maximum Subarray (#53, sum not product)
