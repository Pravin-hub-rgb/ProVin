# 5.9 Range Sum Query 2D - Immutable

**Tier 2 problem.** (LeetCode #304)

**Problem:** Given a 2D matrix, handle multiple queries asking for the sum of elements in a rectangle (row1, col1) to (row2, col2). (LeetCode #304)

**Link:** https://leetcode.com/problems/range-sum-query-2d-immutable/

---

## Which Technique, and Why?

"2D range sum queries on a static matrix" → **2D Prefix Sum**. Precompute a 2D prefix array where `prefix[i][j]` = sum of all elements in the rectangle from (0,0) to (i-1, j-1). Each query is O(1). O(m × n) preprocessing, O(m × n) space.

**Signal in the problem:** "2D range sum" / "matrix sum query" / "sum of rectangle" → 2D prefix sum.

## Approach

Build a 2D prefix array (size (m+1) × (n+1)) with a dummy row/column of zeros. `prefix[i][j]` = sum of elements in rows 0..i-1, cols 0..j-1. Query: `prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]` (inclusion-exclusion).

## Pseudocode

```
constructor(matrix):
    m = rows, n = cols
    prefix = new int[m+1][n+1]
    for i from 1 to m:
        for j from 1 to n:
            prefix[i][j] = matrix[i-1][j-1] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]

sumRegion(r1, c1, r2, c2):
    return prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]
```

## Java Code

```java
class NumMatrix {
    private int[][] prefix;

    public NumMatrix(int[][] matrix) {
        int m = matrix.length;
        int n = (m == 0) ? 0 : matrix[0].length;
        prefix = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                prefix[i][j] = matrix[i - 1][j - 1]
                             + prefix[i - 1][j]
                             + prefix[i][j - 1]
                             - prefix[i - 1][j - 1];
            }
        }
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        return prefix[row2 + 1][col2 + 1]
             - prefix[row1][col2 + 1]
             - prefix[row2 + 1][col1]
             + prefix[row1][col1];
    }
}
```

## Line-by-line

- `prefix` is (m+1) × (n+1) with a dummy row/column of zeros.
- `prefix[i][j]` = sum of elements in rows 0..i-1, cols 0..j-1.
- The formula: `matrix[i-1][j-1] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]` — inclusion-exclusion to avoid double-counting the overlap.
- Query: inclusion-exclusion on the 2D prefix. Add the full rectangle, subtract the top strip and left strip, add back the double-subtracted corner.

## Complexity

- Constructor: O(m × n) time, O(m × n) space.
- `sumRegion`: O(1) time, O(1) space.

## Common Mistakes

- **Off-by-one in the formula.** The +1 in `prefix[row2+1][col2+1]` accounts for the 1-indexed prefix. Forgetting it gives wrong results.
- **Inclusion-exclusion sign errors.** The formula is: full − top − left + corner. The corner is added back because it was subtracted twice.
- **Empty matrix.** Check `m == 0` before accessing `matrix[0]`.
- **Confusing with 1D prefix sum.** 2D extends the same idea with inclusion-exclusion.
