**Tier 2 problem.** (LeetCode #525)

**Problem:** Given a binary array, find the maximum length of a contiguous subarray with an equal number of 0s and 1s. (LeetCode #525)

**Link:** https://leetcode.com/problems/contiguous-array/

---

## Which Technique, and Why?

"Max length subarray with equal 0s and 1s" → **Prefix Sum + HashMap**. Treat 0 as -1. Now "equal 0s and 1s" becomes "subarray sum = 0". Find the longest subarray with sum 0 using prefix sums + hash map (store first occurrence of each prefix sum). O(n) time, O(n) space.

**Signal in the problem:** "equal number of 0 and 1" / "contiguous subarray with equal 0s and 1s" → treat 0 as -1, find longest subarray sum = 0.

## Approach

Replace 0 with -1 (conceptually). Now the problem becomes: find the longest subarray with sum 0. Walk the array, maintaining prefix sum. Store the first index where each prefix sum was seen. If the same prefix sum appears again, the subarray between them sums to 0 → update max length.

## Pseudocode

```
map = {0: -1}  // prefix 0 at index -1
prefix = 0, maxLen = 0
for i from 0 to n-1:
    prefix += (nums[i] == 0) ? -1 : 1
    if map contains prefix:
        maxLen = max(maxLen, i - map[prefix])
    else:
        map[prefix] = i
return maxLen
```

## Java Code

```java
class Solution {
    public int findMaxLength(int[] nums) {
        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, -1);  // prefix 0 at index -1
        int prefix = 0, maxLen = 0;

        for (int i = 0; i < nums.length; i++) {
            prefix += (nums[i] == 0) ? -1 : 1;
            if (map.containsKey(prefix)) {
                maxLen = Math.max(maxLen, i - map.get(prefix));
            } else {
                map.put(prefix, i);
            }
        }
        return maxLen;
    }
}
```

## Line-by-line

- `map` stores prefix sum → first index where it was seen.
- `map.put(0, -1)` — empty prefix has sum 0 at index -1. Handles subarrays starting at index 0.
- `prefix += (nums[i] == 0) ? -1 : 1` — treat 0 as -1, 1 as +1. Equal 0s and 1s → sum = 0.
- If `prefix` seen before → subarray from `map[prefix]+1` to `i` sums to 0 → update maxLen.
- Else → record first occurrence of this prefix.

## Complexity

- Time: O(n) — single pass.
- Space: O(n) — hash map stores up to n prefix sums.

## Common Mistakes

- **Not treating 0 as -1.** Without this transformation, the problem isn't "sum = 0."
- **Forgetting the empty prefix.** `map.put(0, -1)` handles subarrays starting at index 0.
- **Storing latest index instead of first.** Store the first occurrence to maximize length. Use `putIfAbsent` or check `containsKey` first.
- **Off-by-one in length.** Length = `i - map.get(prefix)` (not `i - map.get(prefix) + 1`). Because map stores the index *before* the subarray start.

## How to Explain (interview)

**Opening:** Contiguous Array finds the longest subarray with equal 0s and 1s. Treat 0 as -1, so "equal 0s and 1s" becomes "subarray sum = 0." Prefix sum + hash map: store first occurrence of each prefix sum; if the same prefix appears again, the subarray between them sums to 0. O(n) time, O(n) space.

**The basic flow:**
```java
Map<Integer, Integer> map = new HashMap<>();
map.put(0, -1);
int prefix = 0, maxLen = 0;
for (int i = 0; i < nums.length; i++) {
    prefix += (nums[i] == 0) ? -1 : 1;
    if (map.containsKey(prefix)) maxLen = Math.max(maxLen, i - map.get(prefix));
    else map.put(prefix, i);
}
```

**The part that trips everyone up:** the 0 → -1 transformation. Without it, the problem isn't "sum = 0." Also, store the **first** occurrence (not latest) to maximize length.

**The mistakes to remember:**
- Not treating 0 as -1 (wrong problem)
- Forgetting empty prefix (map.put(0, -1))
- Storing latest index instead of first (shorter subarrays)
- Length is `i - map.get(prefix)`, not `i - map.get(prefix) + 1`
