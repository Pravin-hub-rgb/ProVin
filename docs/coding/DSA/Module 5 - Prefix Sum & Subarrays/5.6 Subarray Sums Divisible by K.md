# 5.6 Subarray Sums Divisible by K

**Tier 2 problem.** (LeetCode #974)

**Problem:** Given an integer array, return the number of (contiguous, non-empty) subarrays whose sum is divisible by k. (LeetCode #974)

**Link:** https://leetcode.com/problems/subarray-sums-divisible-by-k/

---

## Which Technique, and Why?

"Count subarrays with sum divisible by k" → **Prefix Sum + HashMap (mod k)**. If two prefix sums have the same remainder mod k, the subarray between them is divisible by k. Count pairs of equal remainders. O(n) time, O(k) space.

**Signal in the problem:** "count subarrays" + "sum divisible by k" → prefix sum mod k + hash map (count occurrences of each remainder).

## Approach

Walk the array, maintaining prefix sum mod k. Use a map to count how many times each remainder has been seen. For each element, if the current remainder was seen before, add that count to the result. Then increment the count for this remainder.

## Pseudocode

```
map = {0: 1}  // empty prefix
prefixMod = 0, count = 0
for x in nums:
    prefixMod = (prefixMod + x) % k
    if prefixMod < 0: prefixMod += k
    count += map.getOrDefault(prefixMod, 0)
    map.put(prefixMod, map.getOrDefault(prefixMod, 0) + 1)
return count
```

## Java Code

```java
class Solution {
    public int subarraysDivByK(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, 1);  // empty prefix
        int prefixMod = 0, count = 0;

        for (int x : nums) {
            prefixMod = (prefixMod + x) % k;
            if (prefixMod < 0) prefixMod += k;

            count += map.getOrDefault(prefixMod, 0);
            map.put(prefixMod, map.getOrDefault(prefixMod, 0) + 1);
        }
        return count;
    }
}
```

## Line-by-line

- `map` counts how many times each remainder has been seen.
- `map.put(0, 1)` — empty prefix has remainder 0.
- `prefixMod = (prefixMod + x) % k` — running sum mod k.
- `if (prefixMod < 0) prefixMod += k` — handle negatives.
- `count += map.getOrDefault(prefixMod, 0)` — if this remainder was seen before, each previous occurrence forms a valid subarray.
- `map.put(prefixMod, ...)` — record this remainder.

## Complexity

- Time: O(n) — single pass.
- Space: O(min(n, k)) — at most k distinct remainders.

## Common Mistakes

- **Not handling negative numbers.** Java's `%` can be negative. Add `if (prefixMod < 0) prefixMod += k`.
- **Forgetting the empty prefix.** `map.put(0, 1)` is essential — handles subarrays starting at index 0.
- **Using `get` instead of `getOrDefault`.** NPE on missing keys.
- **Confusing with Continuous Subarray Sum (#523).** That problem checks if *any* subarray exists (boolean). This one counts *all* subarrays.

## How to Explain (interview)

**Opening:** Subarray Sums Divisible by K counts subarrays whose sum is divisible by k. Prefix sum mod k: if two prefix sums have the same remainder mod k, the subarray between them is divisible by k. Count pairs of equal remainders using a hash map. O(n) time, O(k) space.

**The basic flow:**
```java
Map<Integer, Integer> map = new HashMap<>();
map.put(0, 1);
int prefixMod = 0, count = 0;
for (int x : nums) {
    prefixMod = (prefixMod + x) % k;
    if (prefixMod < 0) prefixMod += k;
    count += map.getOrDefault(prefixMod, 0);
    map.put(prefixMod, map.getOrDefault(prefixMod, 0) + 1);
}
```

**The part that trips everyone up:** handle **negative numbers** (Java % can be negative). Also, `count += map.getOrDefault(...)` counts all pairs — if the same remainder appears 3 times, it forms 3 subarrays (C(3,2) = 3).

**The mistakes to remember:**
- Not handling negative remainders
- Forgetting the empty prefix (map.put(0, 1))
- Using `get` instead of `getOrDefault`
- Confusing with Continuous Subarray Sum (#523) (boolean vs count)
