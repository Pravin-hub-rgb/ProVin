# 5.3 Find Pivot Index

**Problem:** Given an array, find the pivot index where the sum of elements to the left equals the sum of elements to the right. Return the leftmost pivot, or -1 if none. (LeetCode #724)

**Link:** https://leetcode.com/problems/find-pivot-index/

---

## Which Technique, and Why?

You need to find an index where left sum == right sum. Two approaches:
1. **Prefix sum:** compute total sum. For each index, left sum = running sum so far; right sum = total - left sum - nums[i]. Check equality. O(n) time, O(1) space.
2. **Two prefix arrays:** leftPrefix[i] and rightPrefix[i]. O(n) space. Simpler but uses more memory.

The single-pass with total sum is optimal.

**Signal in the problem:** "pivot index" / "equilibrium point" / "left sum equals right sum" → prefix sum (running sum + total).

## Approach

Compute total sum. Walk the array maintaining `leftSum`. At each index i: `rightSum = total - leftSum - nums[i]`. If `leftSum == rightSum`, return i. Then `leftSum += nums[i]`.

## Pseudocode

```
total = sum of all elements
leftSum = 0
for i from 0 to n-1:
    rightSum = total - leftSum - nums[i]
    if leftSum == rightSum: return i
    leftSum += nums[i]
return -1
```

## Java Code

```java
class Solution {
    public int pivotIndex(int[] nums) {
        int total = 0;
        for (int x : nums) total += x;

        int leftSum = 0;
        for (int i = 0; i < nums.length; i++) {
            int rightSum = total - leftSum - nums[i];
            if (leftSum == rightSum) return i;
            leftSum += nums[i];
        }
        return -1;
    }
}
```

## Line-by-line

- `total` = sum of all elements.
- `leftSum` = sum of elements before index i (starts at 0).
- `rightSum = total - leftSum - nums[i]` — total minus left side minus current element.
- If `leftSum == rightSum`, i is the pivot → return i.
- `leftSum += nums[i]` — include current element for the next iteration.
- Returns -1 if no pivot found. Returns the leftmost (first match).

## Complexity

- Time: O(n) — two passes (one for total, one for search).
- Space: O(1) — two variables.

## Common Mistakes

- **Using `leftSum` before updating.** `rightSum = total - leftSum - nums[i]` uses `leftSum` *before* including `nums[i]`. Then update `leftSum += nums[i]`. Order matters.
- **Off-by-one in total.** `total` includes `nums[i]`. Subtract both `leftSum` and `nums[i]` to get the right side.
- **Returning the last pivot instead of the first.** Return on the first match (leftmost).
- **Empty array / single element.** Single element: leftSum = 0, rightSum = 0 → pivot is index 0. Correct.

## How to Explain (interview)

**Opening:** Find Pivot Index finds an index where left sum equals right sum. Compute the total sum first. Then walk the array: at each index, right sum = total − left sum − current element. If left sum equals right sum, that's the pivot. O(n) time, O(1) space.

**The basic flow:**
```java
int total = sum(nums), leftSum = 0;
for (int i = 0; i < nums.length; i++) {
    if (leftSum == total - leftSum - nums[i]) return i;
    leftSum += nums[i];
}
return -1;
```

**The part that trips everyone up:** `leftSum` is the sum *before* the current index. Compute `rightSum` using `total - leftSum - nums[i]` (subtract both the left side and the current element). Then update `leftSum` after the check.

**The mistakes to remember:**
- Updating `leftSum` before computing `rightSum` (off-by-one)
- Forgetting that `total` includes the current element
- Not returning on the first match (leftmost pivot)
