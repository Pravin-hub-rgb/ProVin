# 3.8 Merge Sorted Array

**Problem:** Given two sorted arrays `nums1` (size m+n, with n trailing zeros as placeholders) and `nums2` (size n), merge `nums2` into `nums1` in-place in sorted order. (LeetCode #88)

**Link:** https://leetcode.com/problems/merge-sorted-array/

---

## Which Technique, and Why?

You're merging two sorted arrays → **Two Pointers** (one per array). The trick: merge **from the end** (right to left) so you don't overwrite `nums1`'s elements before reading them. Three pointers: `i` (end of nums1's real data), `j` (end of nums2), `k` (end of merged result).

Why from the end? If you merge from the front, you'd overwrite nums1's elements that haven't been read yet. Merging from the back writes into the empty placeholder slots.

**Signal in the problem:** "merge two sorted arrays in place" → two pointers, merge from the end.

## Approach

Three pointers from the end: `i = m-1` (last real element of nums1), `j = n-1` (last of nums2), `k = m+n-1` (last slot of nums1). Compare `nums1[i]` and `nums2[j]`, put the larger at `nums1[k]`, decrement the chosen pointer and k. Continue until nums2 is exhausted.

## Pseudocode

```
i = m - 1, j = n - 1, k = m + n - 1
while j >= 0:
    if i >= 0 and nums1[i] > nums2[j]:
        nums1[k] = nums1[i]; i--
    else:
        nums1[k] = nums2[j]; j--
    k--
```

## Java Code

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = m - 1;       // last real element of nums1
        int j = n - 1;       // last element of nums2
        int k = m + n - 1;   // last slot of nums1

        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) {
                nums1[k] = nums1[i];
                i--;
            } else {
                nums1[k] = nums2[j];
                j--;
            }
            k--;
        }
    }
}
```

## Line-by-line

- `i` starts at the last real element of nums1 (index m-1). `j` at last of nums2. `k` at the very end of nums1's allocated space.
- Loop condition `j >= 0` — once nums2 is exhausted, nums1's remaining elements are already in place.
- Compare `nums1[i]` and `nums2[j]`; write the larger to `nums1[k]`.
- `i >= 0` check handles when nums1's real elements are exhausted (just copy rest of nums2).
- Decrement the chosen pointer and `k` each iteration.

## Complexity

- Time: O(m + n) — each element written once.
- Space: O(1) — in place.

## Common Mistakes

- **Merging from the front.** Overwrites nums1 elements before reading them. Always merge from the end.
- **Forgetting the `i >= 0` check.** When nums1's real elements run out, `nums1[i]` is garbage/placeholder — only copy from nums2.
- **Looping while both i >= 0 and j >= 0.** If you stop when either runs out, you miss copying remaining nums2 elements. Loop while `j >= 0`.
- **Off-by-one in indices.** nums1 has m real elements at indices 0..m-1, then n placeholders. `k` starts at m+n-1.

## How to Explain (interview)

**Opening:** Merge Sorted Array merges two sorted arrays in place. Three pointers from the end: i (last real element of nums1), j (last of nums2), k (last slot of nums1). Compare nums1[i] and nums2[j], write the larger to nums1[k], decrement. Merge from the end so you don't overwrite unread elements. O(m+n) time, O(1) space.

**The basic flow:**
```java
int i = m - 1, j = n - 1, k = m + n - 1;
while (j >= 0) {
    if (i >= 0 && nums1[i] > nums2[j]) { nums1[k--] = nums1[i--]; }
    else { nums1[k--] = nums2[j--]; }
}
```

**The part that trips everyone up:** merge **from the end** (right to left). Merging from the front overwrites nums1's unread elements. Also loop while `j >= 0`, not `i >= 0 && j >= 0`.

**The mistakes to remember:**
- Merging from the front (overwrites data)
- Forgetting `i >= 0` check (reads garbage)
- Stopping when i runs out (misses remaining nums2)
