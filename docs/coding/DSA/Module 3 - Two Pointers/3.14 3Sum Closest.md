# 3.14 3Sum Closest

**Tier 2 problem.** (LeetCode #16)

**Problem:** Given an array and a target, find three integers whose sum is closest to target. Return the sum. (LeetCode #16)

**Link:** https://leetcode.com/problems/3sum-closest/

---

## Which Technique, and Why?

"3 numbers closest to target" → **Sort + Two Pointers**. Sort the array. Fix one element, use two pointers on the rest to find the pair closest to `target - nums[i]`. Track the closest sum. O(n²) time, O(1) space (or O(log n) for sort).

**Signal in the problem:** "3Sum closest" / "closest to target" → sort + fix one + two pointers, track closest.

## Approach

Sort. For each i, two pointers (left = i+1, right = n-1) on the rest. Compute sum. If sum == target, return immediately. If sum < target, left++ (need bigger). If sum > target, right-- (need smaller). Track the closest sum (min absolute difference).

## Pseudocode

```
sort nums
closest = nums[0] + nums[1] + nums[2]
for i from 0 to n-3:
    left = i + 1, right = n - 1
    while left < right:
        sum = nums[i] + nums[left] + nums[right]
        if abs(sum - target) < abs(closest - target): closest = sum
        if sum == target: return target
        if sum < target: left++
        else: right--
return closest
```

## Java Code

```java
class Solution {
    public int threeSumClosest(int[] nums, int target) {
        Arrays.sort(nums);
        int closest = nums[0] + nums[1] + nums[2];

        for (int i = 0; i < nums.length - 2; i++) {
            int left = i + 1, right = nums.length - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (Math.abs(sum - target) < Math.abs(closest - target)) {
                    closest = sum;
                }
                if (sum == target) return target;
                if (sum < target) left++;
                else right--;
            }
        }
        return closest;
    }
}
```

## Line-by-line

- Sort first — enables two pointers.
- `closest` initialized to the sum of the first three.
- For each i, two pointers on the rest.
- `Math.abs(sum - target) < Math.abs(closest - target)` — update closest if this sum is nearer.
- `sum == target` → exact match, return immediately.
- `sum < target` → need bigger sum → left++. `sum > target` → need smaller → right--.

## Complexity

- Time: O(n²) — outer loop O(n) × inner two-pointer O(n). Sorting O(n log n) is dominated.
- Space: O(1) extra (or O(log n) for sort stack).

## Common Mistakes

- **Not updating closest on every iteration.** You must check `Math.abs(sum - target) < Math.abs(closest - target)` for every sum, not just when sum < or > target.
- **Not returning early on exact match.** If `sum == target`, you can return immediately (can't get closer than 0).
- **Using `<=` instead of `<` for comparison.** Either works for correctness, but `<` is the standard.
- **Not handling n = 3.** If the array has exactly 3 elements, the loop runs once (i = 0), returns their sum. Correct.
