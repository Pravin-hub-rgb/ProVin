**Problem:** Given strings `s` and `t`, return `true` if `s` is a subsequence of `t` (all chars of `s` appear in `t` in the same order, not necessarily contiguous). (LeetCode #392)

**Link:** https://leetcode.com/problems/is-subsequence/

---

## Which Technique, and Why?

You need to check if all characters of `s` appear in `t` in order. Two pointers: one on `s` (the pattern), one on `t` (the text). Advance the `s` pointer only when there's a match; always advance the `t` pointer. If the `s` pointer reaches the end, `s` is a subsequence.

No data structure needed — just two indices. This is the simplest two-pointer (same direction) pattern.

**Signal in the problem:** "subsequence" / "appears in order" / "not necessarily contiguous" → two pointers, one per string.

## Approach

`i = 0` (index in s), `j = 0` (index in t). While `i < s.length()` and `j < t.length()`: if `s[i] == t[j]`, advance `i`. Always advance `j`. At the end, `s` is a subsequence iff `i == s.length()`.

## Pseudocode

```
i = 0
for j from 0 to t.length()-1:
    if i < s.length() and s[i] == t[j]:
        i++
return i == s.length()
```

## Java Code

```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        int i = 0; // pointer in s
        for (int j = 0; j < t.length() && i < s.length(); j++) {
            if (s.charAt(i) == t.charAt(j)) {
                i++;
            }
        }
        return i == s.length();
    }
}
```

## Line-by-line

- `i` tracks how many characters of `s` have been matched.
- `j` scans through `t`.
- When `s.charAt(i) == t.charAt(j)`, we matched a character — advance `i`.
- `j` always advances.
- Loop stops when `j` reaches end of `t` or `i` reaches end of `s` (early exit).
- `i == s.length()` means all of `s` was matched → subsequence.

## Complexity

- Time: O(|t|) — single pass through t.
- Space: O(1) — two pointers.

## Common Mistakes

- **Confusing subsequence with substring.** Subsequence = characters in order, not necessarily contiguous. Substring = contiguous. Don't require adjacency.
- **Not handling empty `s`.** Empty string is a subsequence of any string (including empty). `i == 0 == s.length()` → true. Correct.
- **Not handling empty `t`.** If `t` is empty and `s` is not, `i` stays 0 ≠ s.length() → false. Correct.
- **Using contains/indexOf in a loop** — works but O(n × m) in worst case. Two pointers is O(n).

## How to Explain (interview)

**Opening:** Is Subsequence checks if all characters of `s` appear in `t` in order (not necessarily contiguous). Two pointers: `i` on `s`, `j` on `t`. Advance `i` only on a match; always advance `j`. If `i` reaches the end of `s`, it's a subsequence. O(|t|) time, O(1) space.

**The basic flow:**
```java
int i = 0;
for (int j = 0; j < t.length() && i < s.length(); j++) {
    if (s.charAt(i) == t.charAt(j)) i++;
}
return i == s.length();
```

**The part that trips everyone up:** subsequence ≠ substring. Subsequence characters need not be contiguous — just in order. Also handle empty `s` (always true) and empty `t` (false unless s is empty).

**The mistakes to remember:**
- Confusing subsequence with substring (contiguous)
- Not handling empty strings (edge cases)
- Using indexOf in a loop (O(n×m)) instead of two pointers (O(n))
