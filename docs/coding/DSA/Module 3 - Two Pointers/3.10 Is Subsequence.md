**Problem:** Given two strings `s` and `t`, return `true` if `s` is a subsequence of `t`, or `false` otherwise.

A **subsequence** of a string is a new string that is formed from the original string by deleting some (can be none) of the characters without disturbing the relative positions of the remaining characters. (i.e., `"ace"` is a subsequence of `"abcde"` while `"aec"` is not). (LeetCode #392)

**Link:** https://leetcode.com/problems/is-subsequence/

---

## What This Problem Is Asking (Simple Terms)

You have two strings, `s` and `t`. You need to check whether all characters of `s` appear in `t` **in the same order**, though not necessarily consecutively.

For example, `s = "abc"`, `t = "ahbgdc"` → `true` because `a`, `b`, `c` appear in `t` in that order.

But `s = "axc"`, `t = "ahbgdc"` → `false` because `x` doesn't appear in `t` after `a`.

You return `true` or `false`.

---

## Example 1

**Input:** `s = "abc"`, `t = "ahbgdc"`

**Output:** `true`

**Explanation:** `a` at index 0, `b` at index 3, `c` at index 5 — all appear in order.

---

## Example 2

**Input:** `s = "axc"`, `t = "ahbgdc"`

**Output:** `false`

**Explanation:** `a` at index 0, but `x` never appears in `t` after index 0.

---

## Example 3

**Input:** `s = ""`, `t = "anystring"`

**Output:** `true`

**Explanation:** Empty string is a subsequence of any string.

---

## Constraints

- `0 <= s.length <= 100`
- `0 <= t.length <= 10^4`
- `s` and `t` consist only of lowercase English letters.

**Follow-up:** Suppose there are lots of incoming `s` strings (say, `s1, s2, ..., sk` where `k >= 10^9`), and you want to check each one against `t`. How would you change your code?

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could use two pointers: one on `s` (the pattern to find), one on `t` (the text to search). Advance `s` only when there's a match; always advance `t`. If `s` reaches its end, it's a subsequence.

### Brute Force Pseudocode

```
i = 0, j = 0
while i < s.length() and j < t.length():
    if s[i] == t[j]: i++
    j++
return i == s.length()
```

This is actually already O(n) and optimal. There's no simpler brute force that's worse.

## Which Data Structure/Technique, and Why?

You need to check if all characters of `s` appear in `t` in order. Two pointers: one on `s` (the pattern), one on `t` (the text). Advance the `s` pointer only when there's a match; always advance the `t` pointer. If the `s` pointer reaches the end, `s` is a subsequence.

No data structure needed — just two indices. This is the simplest two-pointer (same direction) pattern.

**Signal in the problem:** "subsequence" / "appears in order" / "not necessarily contiguous" → two pointers, one per string.

---

## Optimized Approach (Two Pointers, Same Direction)

`i = 0` (index in `s`), `j = 0` (index in `t`). While `i < s.length()` and `j < t.length()`: if `s[i] == t[j]`, advance `i`. Always advance `j`. At the end, `s` is a subsequence iff `i == s.length()`.

### Pseudocode

```
i = 0, j = 0
while i < s.length() and j < t.length():
    if s[i] == t[j]: i++
    j++
return i == s.length()
```

### Java Code

```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        int i = 0, j = 0;
        while (i < s.length() && j < t.length()) {
            if (s.charAt(i) == t.charAt(j)) i++;
            j++;
        }
        return i == s.length();
    }
}
```

### Line-by-line

- `i = 0, j = 0` — `i` tracks position in `s`, `j` tracks position in `t`.
- `while i < s.length() && j < t.length()` — continue while both strings have characters left.
- `if s.charAt(i) == t.charAt(j)) i++` — match found, advance `s` pointer.
- `j++` — always advance `t` pointer (consume one character from text).
- `return i == s.length()` — if `i` reached end of `s`, all characters matched in order.

## Complexity

- Time: O(n) where n = `t.length()` — each character of `t` visited once.
- Space: O(1) — only two pointers.

## Common Mistakes

- **Advancing `i` on every `t` character** — `i` should only advance on match.
- **Returning `j == t.length()` instead of `i == s.length()`** — you want to know if all of `s` matched, not all of `t`.
- **Not handling empty `s`** — empty string is always a subsequence (loop doesn't execute, `i == 0 == s.length()` → true).
- **Using `substring` or creating new strings** — unnecessary O(n) space; use `charAt` with indices.

## How to Explain (interview)

**Opening:** Is Subsequence checks if string `s` is a subsequence of string `t` — all characters of `s` appear in `t` in order, not necessarily contiguously. Two pointers: one on `s`, one on `t`. Advance `s` only on match; always advance `t`. If `s` reaches its end, it's a subsequence. O(n) time, O(1) space.

**The basic flow:**
```java
int i = 0, j = 0;
while (i < s.length() && j < t.length()) {
    if (s.charAt(i) == t.charAt(j)) i++;
    j++;
}
return i == s.length();
```

**The part that trips everyone up:** `i` only advances on match; `j` always advances. And return `i == s.length()` (did we find all of `s`?), not `j == t.length()`.

**The mistakes to remember:**
- Advancing `i` on every character of `t`
- Returning wrong condition (`j == t.length()`)
- Not handling empty `s` (edge case)
