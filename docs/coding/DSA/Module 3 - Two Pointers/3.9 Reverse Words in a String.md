**Problem:** Given an input string `s`, reverse the order of the words.

A **word** is defined as a sequence of non-space characters. The words in `s` will be separated by at least one space.

Return a string of the words in reverse order concatenated by a single space.

**Note:** `s` may contain leading or trailing spaces or multiple spaces between two words. The returned string should only have a single space separating the words. Do not include any extra spaces.

**Link:** https://leetcode.com/problems/reverse-words-in-a-string/

---

## What This Problem Is Asking (Simple Terms)

You have a string with words separated by spaces. You need to reverse the **order** of the words — not reverse each word itself — but keep the characters inside each word in the same order.

For example, `"the sky is blue"` becomes `"blue is sky the"`.

You also need to clean up extra spaces: trim leading/trailing spaces and collapse multiple spaces between words into a single space.

You return the final string.

---

## Example 1

**Input:** `s = "the sky is blue"`

**Output:** `"blue is sky the"`

**Explanation:** Reverse the order of words: "the", "sky", "is", "blue" become "blue", "is", "sky", "the". Join them with single spaces: `"blue is sky the"`.

---

## Example 2

**Input:** `s = "  hello world  "`

**Output:** `"world hello"`

**Explanation:** Trim leading/trailing spaces. Words: "hello", "world" → reversed: "world", "hello". Join: `"world hello"`.

---

## Example 3

**Input:** `s = "a good   example"`

**Output:** `"example good a"`

**Explanation:** Multiple spaces reduced to single. Words: "a", "good", "example" → reversed: "example", "good", "a".

---

## Constraints

- `1 <= s.length <= 10^4`
- `s` contains English letters (upper-case and lower-case), digits, and spaces `' '`.
- There is at least one word in `s`.

**Follow-up:** Could you solve it in O(n) time and O(1) space?

---

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could split the string into words, collect them into a list, reverse that list, then join them back together with single spaces.

### Brute Force Pseudocode

```
words = split(s by spaces, removing empties)
reverse(words)
result = join(words, " ")
return result
```

### Why Brute Force Is Not Ideal

It uses extra space for the list of words and the result string. In Java, strings are immutable, so every concatenation creates a new string. But with modern string joining, it's O(n) time and O(n) space, which is acceptable. The interview challenge is usually to think about doing it with less space, using a character array.

---

## Which Data Structure/Technique, and Why?

"Reverse words in a string" → **Two Pointers (reverse + reverse)**.

You can do this two ways:

**Approach A (Split + Reverse + Join):** Split the string into words, reverse the array of words, join back. O(n) time, O(n) space. Simple but uses extra space for the word list.

**Approach B (Reverse whole, then reverse each word):** Convert to char array. Reverse the entire array (so words appear in right order but each word is backwards). Then reverse each word individually. O(n) time, O(1) extra space if you don't count the char array (since strings are immutable in Java, `toCharArray` allocates one array).

**Signal in the problem:** "reverse words" + "string" → reverse the word order, either by splitting/reversing/joining or by reversing whole then each word.

---

## Optimized Approach 1: Split + Reverse Words + Join (Easier)

Split the string on whitespace (handles multiple spaces automatically), reverse the word array, join with single spaces.

### Pseudocode

```
words = split(s by whitespace)
reverse(words)
return join(words, " ")
```

### Java Code

```java
class Solution {
    public String reverseWords(String s) {
        String[] words = s.trim().split("\\s+");
        int left = 0, right = words.length - 1;
        while (left < right) {
            String temp = words[left];
            words[left] = words[right];
            words[right] = temp;
            left++;
            right--;
        }
        return String.join(" ", words);
    }
}
```

### Line-by-line

- `s.trim().split("\\s+")` — trim leading/trailing spaces, split on one or more spaces. `"\\s+"` means one or more whitespace characters; the double backslash is because Java strings treat backslash specially.
- `left = 0, right = words.length - 1` — two pointers from both ends.
- `while (left < right)` — swap words from both ends toward the middle.
- `String.join(" ", words)` — join all words with single spaces between them.

### Complexity

- Time: O(n) — split O(n), reverse O(w) where w = word count, join O(n).
- Space: O(n) — the words array holds all words.

---

## Optimized Approach 2: Reverse Whole, Then Reverse Each Word (In-Place Feel)

Reverse the whole character array first, so words appear in correct order but each word is backwards. Then reverse each individual word so they read correctly.

### Pseudocode

```
chars = s.toCharArray()
reverse(chars, 0, n-1)  // reverse whole array
start = 0
for i from 0 to n:
    if chars[i] == ' ' or i == n:
        reverse(chars, start, i-1)  // reverse current word
        start = i + 1
return new String(chars)
```

### Java Code

```java
class Solution {
    public String reverseWords(String s) {
        s = s.trim();
        char[] chars = s.toCharArray();
        int n = chars.length;
        
        // Step 1: reverse whole array
        reverse(chars, 0, n - 1);
        
        // Step 2: reverse each word
        int start = 0;
        for (int i = 0; i <= n; i++) {
            if (i == n || chars[i] == ' ') {
                reverse(chars, start, i - 1);
                start = i + 1;
            }
        }
        
        return new String(chars);
    }
    
    private void reverse(char[] chars, int left, int right) {
        while (left < right) {
            char temp = chars[left];
            chars[left] = chars[right];
            chars[right] = temp;
            left++;
            right--;
        }
    }
}
```

### Line-by-line

- `s.trim()` — remove leading/trailing spaces.
- `chars = s.toCharArray()` — convert to mutable char array.
- `reverse(chars, 0, n - 1)` — reverse whole array.
- `start = 0` — track start of current word.
- `for i from 0 to n` — walk through array.
- `if i == n or chars[i] == ' '` — word boundary found.
- `reverse(chars, start, i - 1)` — reverse current word.
- `start = i + 1` — next word starts after space.

### Complexity

- Time: O(n) — reverse whole array O(n), reverse each word O(n), convert to string O(n).
- Space: O(n) — char array of size n (strings are immutable in Java, so you can't avoid at least one array).

## Common Mistakes

- **Not trimming** — leading/trailing spaces create empty words or wrong results.
- **Multiple spaces** — need to skip empty words when splitting, or handle multiple spaces in-place.
- **Forgetting the last word** — if you reverse words only when you hit a space, the last word (no space after it) gets missed unless you handle it after the loop.
- **Trying to reverse strings directly** — Java strings are immutable; you can't swap characters in place without converting to char array first.

## How to Explain (interview)

**Opening:** Reverse Words in a String reverses the order of words in a string while cleaning up extra spaces. Two approaches:

**Approach 1 (Split + Reverse + Join):** Split on whitespace, reverse the word array, join with single spaces. O(n) time, O(n) space. Simple and clean.

**Approach 2 (Reverse whole, then reverse each word):** Convert to char array, reverse the whole array so words are in right order but backwards, then reverse each word individually. O(n) time, O(n) space (for the char array).

**The basic flow (Approach 1):**
```java
String[] words = s.trim().split("\\s+");
int left = 0, right = words.length - 1;
while (left < right) {
    String temp = words[left];
    words[left] = words[right];
    words[right] = temp;
    left++;
    right--;
}
return String.join(" ", words);
```

**The part that trips everyone up:** `split("\\s+")` not `split(" ")`. The double backslash is because Java needs an escaped backslash in string literals; `\\s` means whitespace character, and `+` means one or more. So `\\s+` splits on any run of spaces, automatically handling multiple spaces between words.

**The mistakes to remember:**
- Using `split(" ")` instead of `split("\\s+")` — creates empty strings for multiple spaces
- Forgetting to trim leading/trailing spaces
- Forgetting that Java strings are immutable — you can't swap characters in a string directly; need `toCharArray` for the reverse-in-place approach
