**Problem:** Given an input string `s`, reverse the order of the words.

A word is defined as a sequence of non-space characters. The words in `s` will be separated by at least one space.

Return a string of the words in reverse order concatenated by a single space.

Note that `s` may contain leading or trailing spaces or multiple spaces between two words. The returned string should only have a single space separating the words. Do not include any extra spaces. (LeetCode #151)

**Link:** https://leetcode.com/problems/reverse-words-in-a-string/

---

## What This Problem Is Asking (Simple Terms)

You have a string with words separated by spaces. There may be extra spaces at the beginning, end, or between words. You need to reverse the order of the words and return them joined by single spaces, with no extra leading/trailing spaces.

For example, `"the sky is blue"` → `"blue is sky the"`.

And `"  hello world  "` → `"world hello"` (trim leading/trailing spaces, single space between words).

---

## Example 1

**Input:** `s = "the sky is blue"`

**Output:** `"blue is sky the"`

**Explanation:** Words reversed: blue, is, sky, the. Joined with single spaces: `"blue is sky the"`.

---

## Example 2

**Input:** `s = "  hello world  "`

**Output:** `"world hello"`

**Explanation:** Leading/trailing spaces trimmed. Words: hello, world → reversed: world, hello.

---

## Example 3

**Input:** `s = "a good   example"`

**Output:** `"example good a"`

**Explanation:** Multiple spaces reduced to single. Words: a, good, example → reversed: example, good, a.

---

## Constraints

- `1 <= s.length <= 10^4`
- `s` contains English letters (upper-case and lower-case), digits, and spaces `' '`.
- There is at least one word in `s`.

**Follow-up:** If the string data type is mutable in your language, can you solve it in O(1) extra space?

---

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could split the string by spaces, filter out empty strings, reverse the array of words, and join them back with single spaces.

### Brute Force Pseudocode

```
words = split(s by spaces)  // may include empty strings
filtered = filter(words, w => w != "")  // remove empty strings
reverse(filtered)
return join(filtered, " ")
```

### Why Brute Force Is Not Ideal

Uses O(n) extra space for the split array. The follow-up asks for O(1) extra space (if string is mutable).

---

## Which Data Structure/Technique, and Why?

You need to reverse the order of words. Two approaches:

1. **Split + reverse + join** — split by whitespace, reverse the array, join with single space. O(n) time, O(n) space. Simplest.
2. **In-place (O(1) space)** — reverse the whole string, then reverse each word. Uses two pointers for reversing. Harder but meets strict space constraints.

The problem usually allows O(n) space, so approach 1 is preferred for clarity. The in-place approach is the "interview flex."

**Signal in the problem:** "reverse words" → split/reverse/join (simple) or in-place reverse (if O(1) space required). "Trim spaces / reduce multiple spaces" → split with regex handles this.

---

## Optimized Approach (Split + Reverse + Join)

Split the string by whitespace (handles multiple spaces), reverse the resulting array, join with a single space.

### Pseudocode

```
words = split(s by whitespace)  // handles multiple spaces automatically
words = reverse(words)
return join(words, " ")
```

### Java Code

```java
class Solution {
    public String reverseWords(String s) {
        String[] words = s.trim().split("\\s+");  // split on one or more spaces
        int left = 0, right = words.length - 1;
        while (left < right) {
            String temp = words[left];
            words[left] = words[right];
            words[right] = temp;
            left++;
            right--;
        }
        return String.join(" ", words);
    }
}
```

### Line-by-line

- `s.trim().split("\\s+")` — trim leading/trailing spaces, split on one or more spaces (handles multiple spaces between words).
- `left = 0, right = words.length - 1` — two pointers for reversing the array.
- `while (left < right)` — swap words from both ends toward the middle.
- `String.join(" ", words)` — join reversed words with single spaces.

## Complexity

- Time: O(n) — split O(n), reverse O(w) where w = number of words, join O(n).
- Space: O(n) — for the words array.

## Common Mistakes

- **Not trimming leading/trailing spaces** — results in empty strings at start/end of split array.
- **Not handling multiple spaces** — `split(" ")` creates empty strings for consecutive spaces; use `split("\\s+")` instead.
- **Forgetting to reverse** — just splitting and joining keeps original order.
- **Returning with extra spaces** — `String.join(" ", ...)` ensures single spaces only.
