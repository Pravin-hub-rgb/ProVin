# 3.9 Reverse Words in a String

**Problem:** Given a string with words separated by spaces, reverse the order of the words. Trim leading/trailing spaces and reduce multiple spaces to single. (LeetCode #151)

**Link:** https://leetcode.com/problems/reverse-words-in-a-string/

---

## Which Technique, and Why?

You need to reverse the order of words. Two approaches:
1. **Split + reverse + join** — split by whitespace, reverse the array, join with single space. O(n) time, O(n) space. Simplest.
2. **In-place (O(1) space)** — reverse the whole string, then reverse each word. Uses two pointers for reversing. Harder but meets strict space constraints.

The problem usually allows O(n) space, so approach 1 is preferred for clarity. The in-place approach is the "interview flex."

**Signal in the problem:** "reverse words" → split/reverse/join (simple) or in-place reverse (if O(1) space required). "Trim spaces / reduce multiple spaces" → split with regex handles this.

## Approach (Split + Reverse + Join)

Split the string by whitespace (handles multiple spaces), reverse the resulting array, join with a single space.

## Pseudocode

```
words = s.trim().split("\\s+")
reverse words array
return String.join(" ", words)
```

## Java Code (Split + Reverse + Join)

```java
class Solution {
    public String reverseWords(String s) {
        String[] words = s.trim().split("\\s+");
        int left = 0, right = words.length - 1;
        while (left < right) {
            String temp = words[left];
            words[left] = words[right];
            words[right] = temp;
            left++;
            right--;
        }
        return String.join(" ", words);
    }
}
```

## Java Code (In-Place, O(1) space)

```java
class Solution {
    public String reverseWords(String s) {
        char[] chars = s.toCharArray();
        int n = chars.length;

        // Step 1: reverse entire string
        reverse(chars, 0, n - 1);

        // Step 2: reverse each word
        int start = 0;
        for (int end = 0; end <= n; end++) {
            if (end == n || chars[end] == ' ') {
                reverse(chars, start, end - 1);
                start = end + 1;
            }
        }

        // Step 3: clean up extra spaces (trim + collapse)
        // (left as exercise — or use the split approach above)
        return new String(chars).trim().replaceAll("\\s+", " ");
    }

    private void reverse(char[] c, int l, int r) {
        while (l < r) {
            char t = c[l]; c[l] = c[r]; c[r] = t;
            l++; r--;
        }
    }
}
```

## Line-by-line (Split approach)

- `s.trim()` — remove leading/trailing spaces.
- `split("\\s+")` — split on one-or-more whitespace (handles multiple spaces between words).
- Two-pointer reversal of the `words` array.
- `String.join(" ", words)` — join with single space.

## Complexity

- Split approach: O(n) time, O(n) space.
- In-place approach: O(n) time, O(1) extra space (char array is the input).

## Common Mistakes

- **Not trimming leading/trailing spaces** — produces empty strings in the result.
- **Not collapsing multiple spaces** — `split(" ")` (single space) gives empty strings for multiple spaces. Use `split("\\s+")`.
- **Off-by-one in the in-place reversal** — `reverse(chars, start, end - 1)` because `end` points at the space, not the last char of the word.
- **Returning char[] instead of String** — convert with `new String(chars)`.

## How to Explain (interview)

**Opening:** Reverse Words in a String reverses the order of words, trimming extra spaces. The simple approach: trim, split by whitespace (handles multiple spaces), reverse the word array, join with single space. O(n) time, O(n) space. The in-place approach reverses the whole string, then reverses each word, then cleans up spaces — O(n) time, O(1) space.

**The basic flow (simple):**
```java
String[] words = s.trim().split("\\s+");
int l = 0, r = words.length - 1;
while (l < r) { swap(words, l, r); l++; r--; }
return String.join(" ", words);
```

**The part that trips everyone up:** `split("\\s+")` (regex for one-or-more whitespace), not `split(" ")` (single space, leaves empty strings). Also trim first.

**The mistakes to remember:**
- Using `split(" ")` instead of `split("\\s+")` (empty strings in result)
- Forgetting to trim leading/trailing spaces
- In-place: not decrementing `end` when reversing each word (off-by-one)
