# 3.16 Longest Palindromic Substring

**Tier 2 problem.** (LeetCode #5)

**Problem:** Given a string, find the longest palindromic substring. (LeetCode #5)

**Link:** https://leetcode.com/problems/longest-palindromic-substring/

---

## Which Technique, and Why?

"Longest palindromic substring" → **Expand around center**. A palindrome mirrors around its center. For each position (and between positions), expand outward while characters match. O(n²) time, O(1) space. (Manacher's algorithm is O(n) but complex.)

**Signal in the problem:** "longest palindromic substring" → expand around center (or DP). Expand-around-center is simpler and O(1) space.

## Approach

For each center (2n-1 centers: n single-char centers + n-1 between-char centers), expand outward while `s[left] == s[right]`. Track the longest palindrome found.

## Pseudocode

```
result = ""
for i from 0 to n-1:
    // odd-length palindromes (center at i)
    l = i, r = i
    while l >= 0 and r < n and s[l] == s[r]:
        if r - l + 1 > result.length: result = s.substring(l, r+1)
        l--; r++
    // even-length palindromes (center between i and i+1)
    l = i, r = i + 1
    while l >= 0 and r < n and s[l] == s[r]:
        if r - l + 1 > result.length: result = s.substring(l, r+1)
        l--; r++
return result
```

## Java Code

```java
class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) return s;

        int start = 0, maxLen = 1;
        for (int i = 0; i < s.length(); i++) {
            // Odd-length palindromes
            int l = i, r = i;
            while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
                if (r - l + 1 > maxLen) {
                    start = l;
                    maxLen = r - l + 1;
                }
                l--;
                r++;
            }
            // Even-length palindromes
            l = i;
            r = i + 1;
            while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
                if (r - l + 1 > maxLen) {
                    start = l;
                    maxLen = r - l + 1;
                }
                l--;
                r++;
            }
        }
        return s.substring(start, start + maxLen);
    }
}
```

## Line-by-line

- `start` and `maxLen` track the best palindrome found.
- For each center `i`: try odd-length (center at `i`) and even-length (center between `i` and `i+1`).
- Expand while characters match. Update `start`/`maxLen` if this palindrome is longer.
- Return `s.substring(start, start + maxLen)`.

## Complexity

- Time: O(n²) — 2n-1 centers, each expansion up to O(n).
- Space: O(1) — only indices.

## Common Mistakes

- **Only checking odd-length palindromes.** You must also check even-length (e.g., "abba"). The second while loop handles this.
- **Not updating maxLen correctly.** Update on every match, not just at the end of expansion.
- **Using DP instead.** DP works (O(n²) time, O(n²) space) but expand-around-center is simpler and O(1) space.
- **Off-by-one in substring.** `s.substring(start, start + maxLen)` — end is exclusive.

## How to Explain (interview)

**Opening:** Longest Palindromic Substring finds the longest palindrome in a string. Expand around center: for each position (and between positions), expand outward while characters match. 2n-1 centers, each expansion O(n) → O(n²) time, O(1) space. Simpler than Manacher's (O(n)) and DP (O(n²) space).

**The basic flow:**
```java
for (int i = 0; i < n; i++) {
    // odd-length
    expand(i, i);
    // even-length
    expand(i, i + 1);
}
```

**The part that trips everyone up:** you must check **both** odd and even lengths. Odd: center at a character. Even: center between two characters. Missing even misses palindromes like "abba."

**The mistakes to remember:**
- Only checking odd-length (misses even palindromes like "abba")
- Not updating max on every match
- Using DP when expand-around-center is simpler
- Off-by-one in substring bounds
