**Problem:** Given a string `s`, return the longest palindromic substring in `s`. (LeetCode #5)

**Link:** https://leetcode.com/problems/longest-palindromic-substring/

---

## What This Problem Is Asking (Simple Terms)

You have a string. You need to find the longest substring that reads the same forwards and backwards (a palindrome).

For example, `s = "babad"` → `"bab"` or `"aba"` (both length 3).
`s = "cbbd"` → `"bb"` (length 2).

You return the substring itself, not just the length.

---

## Example 1

**Input:** `s = "babad"`

**Output:** `"bab"`

**Explanation:** `"aba"` is also a valid answer.

---

## Example 2

**Input:** `s = "cbbd"`

**Output:** `"bb"`

**Explanation:** `"bb"` is the longest palindromic substring.

---

## Constraints

- `1 <= s.length <= 1000`
- `s` consist of only digits and English letters.

**Follow-up:** Could you solve it in O(n²) time?

---

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could check every possible substring, test if it's a palindrome, and track the longest one.

### Brute Force Pseudocode

```
longest = ""
for i from 0 to n-1:
    for j from i to n-1:
        substr = s[i..j]
        if isPalindrome(substr) and len(substr) > len(longest):
            longest = substr
return longest
```

### Why Brute Force Is Slow

O(n³) — O(n²) substrings, each palindrome check O(n). Too slow for `n = 1000`.

---

## Which Data Structure/Technique, and Why?

"Longest palindromic substring" → **Expand around center**. A palindrome mirrors around its center. For each position (and between positions), expand outward while characters match. O(n²) time, O(1) space. (Manacher's algorithm is O(n) but complex.)

**Signal in the problem:** "longest palindromic substring" → expand around center (or DP). Expand-around-center is simpler and O(1) space.

---

## Optimized Approach (Expand Around Center)

For each center (2n-1 centers: n single-char centers + n-1 between-char centers), expand outward while `s[left] == s[right]`. Track the longest palindrome found.

### Pseudocode

```
longest = ""
for center from 0 to 2n-2:
    left = center / 2
    right = left + center % 2
    while left >= 0 and right < n and s[left] == s[right]:
        left--; right++
    // palindrome is s[left+1..right-1]
    if (right - left - 1) > len(longest):
        longest = s[left+1..right-1]
return longest
```

### Java Code

```java
class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 1) return "";
        int start = 0, end = 0;
        for (int i = 0; i < s.length(); i++) {
            int len1 = expandAroundCenter(s, i, i);      // odd length
            int len2 = expandAroundCenter(s, i, i + 1);  // even length
            int len = Math.max(len1, len2);
            if (len > end - start) {
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }
        return s.substring(start, end + 1);
    }

    private int expandAroundCenter(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;
    }
}
```

### Line-by-line

- `expandAroundCenter(s, i, i)` — odd-length palindrome centered at `i`.
- `expandAroundCenter(s, i, i + 1)` — even-length palindrome centered between `i` and `i+1`.
- `while left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)` — expand while characters match.
- `return right - left - 1` — length of the palindrome (right and left are one past the palindrome).
- `start = i - (len - 1) / 2` — compute start index from center and length.
- `end = i + len / 2` — compute end index.

## Complexity

- Time: O(n²) — 2n-1 centers, each expansion O(n).
- Space: O(1) — only a few variables.

## Common Mistakes

- **Not handling even-length palindromes** — need both `(i, i)` and `(i, i+1)` centers.
- **Off-by-one in substring** — `substring(start, end + 1)` includes `end`.
- **Not tracking the best palindrome** — need to update `start` and `end` when a longer one is found.
- **Empty/single character string** — handle edge case (returns itself).
