**Tier 2 problem.** (LeetCode #18)

**Problem:** Given an array, find all unique quadruplets that sum to target. (LeetCode #18)

**Link:** https://leetcode.com/problems/4sum/

---

## Which Technique, and Why?

"Find all unique quadruplets summing to target" → **Two Pointers (nested)**. Sort the array. Fix two elements (i, j), then use two pointers (left, right) on the rest to find pairs summing to `target - nums[i] - nums[j]`. Skip duplicates at all levels. O(n³) time, O(1) space.

**Signal in the problem:** "4Sum" / "k-sum" / "quadruplets summing to target" → sort + fix k-2 elements + two pointers.

## Approach

Sort the array. Two outer loops fix `nums[i]` and `nums[j]`. Inner two-pointer search for pair summing to `target - nums[i] - nums[j]`. Skip duplicates at i, j, left, right. Prune: if `nums[i] + nums[i+1] + nums[i+2] + nums[i+3] > target` (smallest possible sum with i) → break. If `nums[i] + nums[n-3] + nums[n-2] + nums[n-1] < target` (largest possible sum with i) → continue.

## Pseudocode

```
sort nums
result = []
for i from 0 to n-4:
    if i > 0 and nums[i] == nums[i-1]: continue
    if nums[i] + nums[i+1] + nums[i+2] + nums[i+3] > target: break
    if nums[i] + nums[n-3] + nums[n-2] + nums[n-1] < target: continue
    for j from i+1 to n-3:
        if j > i+1 and nums[j] == nums[j-1]: continue
        left = j + 1, right = n - 1
        while left < right:
            sum = nums[i] + nums[j] + nums[left] + nums[right]
            if sum == target:
                result.add([nums[i], nums[j], nums[left], nums[right]])
                left++; right--
                while left < right and nums[left] == nums[left-1]: left++
                while left < right and nums[right] == nums[right+1]: right--
            else if sum < target: left++
            else: right--
return result
```

## Java Code

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();
        int n = nums.length;

        for (int i = 0; i < n - 3; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            if ((long) nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target) break;
            if ((long) nums[i] + nums[n - 3] + nums[n - 2] + nums[n - 1] < target) continue;

            for (int j = i + 1; j < n - 2; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;
                if ((long) nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target) break;
                if ((long) nums[i] + nums[j] + nums[n - 2] + nums[n - 1] < target) continue;

                int left = j + 1, right = n - 1;
                while (left < right) {
                    long sum = (long) nums[i] + nums[j] + nums[left] + nums[right];
                    if (sum == target) {
                        result.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));
                        left++;
                        right--;
                        while (left < right && nums[left] == nums[left - 1]) left++;
                        while (left < right && nums[right] == nums[right + 1]) right--;
                    } else if (sum < target) {
                        left++;
                    } else {
                        right--;
                    }
                }
            }
        }
        return result;
    }
}
```

## Line-by-line

- Sort first — enables two pointers and duplicate skipping.
- Outer loop fixes `nums[i]` (first element). Skip duplicates. Prune: smallest possible sum with i > target → break; largest possible sum with i < target → continue.
- Inner loop fixes `nums[j]` (second element). Same pruning.
- Two-pointer search on the rest for pair summing to `target - nums[i] - nums[j]`.
- On a match: record, advance both, skip duplicates.

## Complexity

- Time: O(n³) — two outer loops O(n²) × inner two-pointer O(n). Sorting O(n log n) is dominated.
- Space: O(1) extra (excluding output).

## Common Mistakes

- **Integer overflow.** Sums of 4 ints can exceed int range. Use `long` for sum comparisons.
- **Not skipping duplicates at all levels.** Skip at i, j, left, and right. Missing any level produces duplicate quadruplets.
- **Wrong pruning.** `nums[i] + nums[i+1] + nums[i+2] + nums[i+3] > target` → break (smallest sum with i exceeds target). `nums[i] + nums[n-3] + nums[n-2] + nums[n-1] < target` → continue (largest sum with i is too small).
- **Confusing with 3Sum.** 4Sum is 3Sum + one more outer loop. The two-pointer core is the same.

## How to Explain (interview)

**Opening:** 4Sum finds all unique quadruplets summing to target. Sort first. Fix two elements (i, j), then two pointers on the rest for the pair. Skip duplicates at all four levels. Prune when the smallest/largest possible sum with i exceeds/skips target. O(n³) time, O(1) space.

**The basic flow:**
```java
Arrays.sort(nums);
for (int i = 0; i < n - 3; i++) {
    if (i > 0 && nums[i] == nums[i-1]) continue;
    for (int j = i + 1; j < n - 2; j++) {
        if (j > i + 1 && nums[j] == nums[j-1]) continue;
        int left = j + 1, right = n - 1;
        while (left < right) {
            long sum = nums[i] + nums[j] + nums[left] + nums[right];
            if (sum == target) { /* record, skip dups */ }
            else if (sum < target) left++;
            else right--;
        }
    }
}
```

**The part that trips everyone up:** pruning and duplicate skipping at **all four levels** (i, j, left, right). Also, use `long` for sums to avoid overflow.

**The mistakes to remember:**
- Integer overflow (use long for sums)
- Not skipping duplicates at all levels (duplicate results)
- Wrong pruning conditions (break vs continue)
- Confusing with 3Sum (same core, one more loop)
