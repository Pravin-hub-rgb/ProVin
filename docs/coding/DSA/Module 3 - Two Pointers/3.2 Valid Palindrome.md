**Problem:** Given a string, determine if it is a palindrome, considering only alphanumeric characters and ignoring case. (LeetCode #125)

**Link:** https://leetcode.com/problems/valid-palindrome/

---

## Which Technique, and Why?

A palindrome reads the same forwards and backwards. You need to compare characters from both ends moving inward → **Two Pointers (converging)**. No extra data structure needed — just two indices.

Why not reverse the string and compare? That works but uses O(n) extra space. Two pointers is O(1) space.

**Signal in the problem:** "palindrome" / "reads the same forwards and backwards" / "symmetric" → two pointers from both ends.

## Approach

Two pointers: `left = 0`, `right = len - 1`. While `left < right`: skip non-alphanumeric characters, compare (case-insensitive), move both pointers inward. If any mismatch → not a palindrome.

## Pseudocode

```
left = 0, right = s.length() - 1
while left < right:
    while left < right and !isAlphanumeric(s[left]): left++
    while left < right and !isAlphanumeric(s[right]): right--
    if toLowerCase(s[left]) != toLowerCase(s[right]): return false
    left++; right--
return true
```

## Java Code

```java
class Solution {
    public boolean isPalindrome(String s) {
        int left = 0, right = s.length() - 1;

        while (left < right) {
            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) left++;
            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) right--;

            if (Character.toLowerCase(s.charAt(left)) !=
                Character.toLowerCase(s.charAt(right))) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

## Line-by-line

- Outer `while (left < right)` — converge until pointers meet.
- Inner whiles skip non-alphanumeric characters (spaces, punctuation).
- Compare case-insensitively using `Character.toLowerCase`.
- On mismatch, return false immediately (short-circuit).
- Otherwise advance both pointers.

## Complexity

- Time: O(n) — each character visited at most once.
- Space: O(1) — only two pointers.

## Common Mistakes

- **Not skipping non-alphanumeric characters.** "A man, a plan, a canal: Panama" is a palindrome only after ignoring spaces/punctuation.
- **Case sensitivity.** "Racecar" vs "racecar" — must compare case-insensitively.
- **Using `==` on chars is fine** (char is primitive), but `Character.toLowerCase` is needed for case.
- **Empty string / single char** — loop doesn't execute, returns true (correct).

## How to Explain (interview)

**Opening:** Valid Palindrome checks if a string reads the same forwards and backwards, ignoring non-alphanumeric characters and case. Two pointers from both ends converge inward, skipping non-alphanumeric chars and comparing case-insensitively. O(n) time, O(1) space.

**The basic flow:**
```java
int left = 0, right = s.length() - 1;
while (left < right) {
    while (!isLetterOrDigit(s.charAt(left))) left++;
    while (!isLetterOrDigit(s.charAt(right))) right--;
    if (toLowerCase(s.charAt(left)) != toLowerCase(s.charAt(right))) return false;
    left++; right--;
}
return true;
```

**The part that trips everyone up:** skipping non-alphanumeric characters correctly (use `Character.isLetterOrDigit`), and handling case (use `toLowerCase`). Empty string returns true.

**The mistakes to remember:**
- Forgetting to skip punctuation/spaces
- Case-sensitive comparison
- Off-by-one: `left < right`, not `left <= right`
