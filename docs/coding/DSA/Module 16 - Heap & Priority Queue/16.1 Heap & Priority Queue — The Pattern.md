# 16.1 Heap & Priority Queue — The Pattern

## What This Problem Is Asking (Simple Terms)

A **Heap** is a specialized tree-based data structure that satisfies the heap property: in a **max-heap**, every parent node is greater than or equal to its children; in a **min-heap**, every parent node is less than or equal to its children.

A **Priority Queue** is an abstract data type where each element has a priority, and elements with higher priority are served before elements with lower priority.

---

## Example 1

**Input:** `["MaxHeap","push","push","push","top","pop","top"]`, `[[],[3],[1],[5],[]]`

**Output:** `[null,null,null,5,5,3]`

**Explanation:**
- `MaxHeap()` - initialize empty heap
- `push(3)` → heap: [3]
- `push(1)` → heap: [3,1]
- `push(5)` → heap: [5,1,3]
- `top()` → 5 (max element)
- `pop()` → removes 5, heap: [3,1]
- `top()` → 3

---

## Example 2

**Input:** `nums = [3,1,5,2]`, `k = 2`

**Output:** `[5,3]`

**Explanation:** Top 2 elements are 5 and 3.

---

## Constraints

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`

---

## Which Technique, and Why?

Heap (Priority Queue) is used when:
- You need to repeatedly access the **minimum or maximum** element
- You need to maintain a dynamic set with frequent insertions/removals of min/max

**Signal in the problem:** "top k elements," "merge k sorted lists," "meeting rooms," "task scheduler" → Heap/Priority Queue

---

## Approach

**Binary Heap (Min-Heap):**
- Complete binary tree where parent <= children
- Root is always the minimum element
- `push`: add to end, bubble up
- `pop`: remove root, move last element to root, bubble down

### Pseudocode (Min-Heap)

```
class MinHeap:
    heap = []
    
    push(val):
        heap.append(val)
        bubbleUp(len(heap) - 1)
    
    pop():
        if len(heap) == 0: return None
        if len(heap) == 1: return heap.pop()
        min = heap[0]
        heap[0] = heap.pop()
        bubbleDown(0)
        return min
    
    peek():
        return heap[0] if heap else None

def bubbleUp(i):
    while i > 0:
        parent = (i - 1) // 2
        if heap[parent] > heap[i]:
            swap(heap, parent, i)
            i = parent
        else: break

def bubbleDown(i):
    while True:
        left = 2*i + 1, right = 2*i + 2
        smallest = i
        if left < len(heap) and heap[left] < heap[smallest]:
            smallest = left
        if right < len(heap) and heap[right] < heap[smallest]:
            smallest = right
        if smallest != i:
            swap(heap, i, smallest)
            i = smallest
        else: break
```

### Java Code (Min-Heap)

```java
class MinHeap {
    private List<Integer> heap = new ArrayList<>();
    
    public void push(int val) {
        heap.add(val);
        bubbleUp(heap.size() - 1);
    }
    
    public int pop() {
        if (heap.isEmpty()) return -1;
        int min = heap.get(0);
        heap.set(0, heap.get(heap.size() - 1));
        heap.remove(heap.size() - 1);
        bubbleDown(0);
        return min;
    }
    
    public int peek() {
        return heap.isEmpty() ? -1 : heap.get(0);
    }
    
    private void bubbleUp(int i) {
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (heap.get(parent) > heap.get(i)) {
                swap(i, parent);
                i = parent;
            } else break;
        }
    }
    
    private void bubbleDown(int i) {
        int n = heap.size();
        while (true) {
            int left = 2*i + 1, right = 2*i + 2, smallest = i;
            if (left < n && heap.get(left) < heap.get(smallest)) smallest = left;
            if (right < n && heap.get(right) < heap.get(smallest)) smallest = right;
            if (smallest == i) break;
            swap(i, smallest);
            i = smallest;
        }
    }
    
    private void swap(int i, int j) {
        int temp = heap.get(i);
        heap.set(i, heap.get(j));
        heap.set(j, temp);
    }
}
```

### Line-by-line

- `heap.add(val)` — add new element to end
- `bubbleUp(heap.size() - 1)` — bubble up new element to maintain heap property
- `heap.get(0)` — root is always minimum (min-heap)
- `heap.set(0, heap.get(heap.size() - 1))` — move last element to root
- `heap.remove(heap.size() - 1)` — remove last element
- `bubbleDown(0)` — bubble down new root to maintain heap property

## Complexity

- Time: O(log n) for push/pop (height of heap), O(1) for peek
- Space: O(n) — heap array stores all elements

## Common Mistakes

- **Forgetting heap property** — after insertion/deletion, must bubble up/down to maintain heap property
- **Using wrong index calculations** — left child = 2*i+1, right child = 2*i+2, parent = (i-1)/2
- **Not handling empty heap** — check if heap is empty before pop/peek

## How to Explain (interview)

**Opening:** Heap is a complete binary tree where parent <= children (min-heap) or parent >= children (max-heap). Root is always min/max. Used for priority queues.

**The basic flow:**
```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) freq.put(x, freq.getOrDefault(x, 0) + 1);
        PriorityQueue<Integer> heap = new PriorityQueue<>((a, b) -> freq.get(a) - freq.get(b));
        for (int x : freq.keySet()) {
            heap.offer(x);
            if (heap.size() > k) heap.poll();
        }
        int[] result = new int[k];
        for (int i = 0; i < k; i++) result[i] = heap.poll();
        return result;
    }
}
```

**The part that trips everyone up:**
- **Min-heap vs Max-heap** — for top K largest, use min-heap (keep smallest at top, pop when size > k)
- **Heap size** — keep heap size ≤ k, poll when exceeds k

**The mistakes to remember:**
- Using max-heap instead of min-heap for top K
- Forgetting to check heap size before poll
- Confusing min-heap vs max-heap behavior
