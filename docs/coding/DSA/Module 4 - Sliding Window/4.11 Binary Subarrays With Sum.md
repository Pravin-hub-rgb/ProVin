# 4.11 Binary Subarrays With Sum

**Tier 2 problem.** (LeetCode #930)

**Problem:** Given a binary array and a goal, return the number of non-empty subarrays with sum equal to goal. (LeetCode #930)

**Link:** https://leetcode.com/problems/binary-subarrays-with-sum/

---

## Which Technique, and Why?

"Count subarrays with sum = goal" in a binary array → **Prefix Sum + HashMap** or **Sliding Window (at most)**. Since elements are 0/1, "at most goal" is monotonic → sliding window works. Count = (subarrays with sum ≤ goal) - (subarrays with sum ≤ goal-1). O(n) time, O(1) space.

**Signal in the problem:** "binary array" + "count subarrays with sum = goal" → prefix sum + map, or sliding window (at most trick).

## Approach (Sliding Window — at most trick)

`countAtMost(goal) - countAtMost(goal - 1)` = number of subarrays with sum exactly goal. `countAtMost(k)` counts subarrays with sum ≤ k using a sliding window.

## Pseudocode

```
return countAtMost(nums, goal) - countAtMost(nums, goal - 1)

countAtMost(nums, k):
    if k < 0: return 0
    left = 0, sum = 0, count = 0
    for right from 0 to n-1:
        sum += nums[right]
        while sum > k:
            sum -= nums[left]
            left++
        count += right - left + 1
    return count
```

## Java Code

```java
class Solution {
    public int numSubarraysWithSum(int[] nums, int goal) {
        return countAtMost(nums, goal) - countAtMost(nums, goal - 1);
    }

    private int countAtMost(int[] nums, int k) {
        if (k < 0) return 0;
        int left = 0, sum = 0, count = 0;
        for (int right = 0; right < nums.length; right++) {
            sum += nums[right];
            while (sum > k) {
                sum -= nums[left];
                left++;
            }
            count += right - left + 1;
        }
        return count;
    }
}
```

## Line-by-line

- `countAtMost(k)` counts subarrays with sum ≤ k.
- Expand right, add to sum. While sum > k, shrink left.
- `count += right - left + 1` — all subarrays ending at right with sum ≤ k. There are `right - left + 1` of them (starting at left, left+1, ..., right).
- `countAtMost(goal) - countAtMost(goal - 1)` = subarrays with sum exactly goal.

## Complexity

- Time: O(n) — two passes, each O(n).
- Space: O(1).

## Common Mistakes

- **Using prefix sum + map on a binary array.** Works (O(n) time, O(n) space) but the sliding window approach is O(1) space.
- **Not handling k < 0.** `countAtMost(-1)` should return 0 (no subarray has negative sum). The `if (k < 0) return 0` handles this.
- **Using `if` instead of `while` for shrinking.** You may need to shrink multiple times.
- **Confusing with "Subarray Sum Equals K" (#560).** That problem allows negatives (use prefix sum + map). This one is binary (use sliding window).

## How to Explain (interview)

**Opening:** Binary Subarrays With Sum counts subarrays with sum = goal in a binary array. Sliding window "at most" trick: count subarrays with sum ≤ goal, subtract those with sum ≤ goal-1. O(n) time, O(1) space. (Sliding window works because binary arrays have monotonic sums.)

**The basic flow:**
```java
return countAtMost(goal) - countAtMost(goal - 1);
// countAtMost(k): expand right, shrink while sum > k, count += right - left + 1
```

**The part that trips everyone up:** the "at most" trick — count(≤ goal) − count(≤ goal−1) = count(= goal). Also, `count += right - left + 1` counts all valid subarrays ending at right.

**The mistakes to remember:**
- Using prefix sum + map (works but O(n) space; sliding window is O(1))
- Not handling k < 0 (return 0)
- Using `if` instead of `while` for shrinking
- Confusing with #560 (allows negatives — different approach)
