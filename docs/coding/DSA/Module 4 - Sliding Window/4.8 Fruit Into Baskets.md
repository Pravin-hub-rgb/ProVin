**Tier 2 problem.** (LeetCode #904)

**Problem:** Given an array of fruit types, find the longest subarray containing at most 2 distinct types. (LeetCode #904)

**Link:** https://leetcode.com/problems/fruit-into-baskets/

---

## Which Technique, and Why?

"Longest subarray with at most 2 distinct values" → **Sliding Window (variable size)** with a frequency map. Expand right; when distinct count exceeds 2, shrink left. O(n) time, O(1) space (at most 3 distinct types in the map).

**Signal in the problem:** "at most K distinct" / "longest subarray with at most 2 types" → sliding window with frequency map.

## Approach

Variable-size window. Expand right, add to freq map. While distinct count > 2, shrink left (decrement freq, remove if 0, left++). Track max window size.

## Pseudocode

```
freq = empty map
left = 0, maxLen = 0
for right from 0 to n-1:
    freq[nums[right]]++
    while freq.size > 2:
        freq[nums[left]]--
        if freq[nums[left]] == 0: freq.remove(nums[left])
        left++
    maxLen = max(maxLen, right - left + 1)
return maxLen
```

## Java Code

```java
class Solution {
    public int totalFruit(int[] fruits) {
        Map<Integer, Integer> freq = new HashMap<>();
        int left = 0, maxLen = 0;

        for (int right = 0; right < fruits.length; right++) {
            freq.put(fruits[right], freq.getOrDefault(fruits[right], 0) + 1);

            while (freq.size() > 2) {
                freq.put(fruits[left], freq.get(fruits[left]) - 1);
                if (freq.get(fruits[left]) == 0) freq.remove(fruits[left]);
                left++;
            }

            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

## Line-by-line

- `freq` maps fruit type → count in the current window.
- Expand `right`: add fruit to freq.
- `while (freq.size() > 2)` — more than 2 distinct types → shrink: decrement count, remove if 0, advance left.
- `maxLen` tracks the largest valid window.

## Complexity

- Time: O(n) — right and left each move at most n times.
- Space: O(1) — at most 3 distinct types in the map (2 valid + 1 being removed).

## Common Mistakes

- **Using `if` instead of `while`.** You may need to shrink multiple times. Use `while`.
- **Not removing zero-count entries.** `freq.size()` counts distinct keys, including those with count 0. Must `remove` when count hits 0.
- **Window size formula.** `right - left + 1`, not `right - left`.
- **Confusing with "Longest Substring with At Most K Distinct Characters"** — same pattern, general K. This problem is K = 2.
