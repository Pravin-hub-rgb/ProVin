# 4.3 Minimum Size Subarray Sum

**Problem:** Given an array of positive integers and a target, find the minimum length of a contiguous subarray whose sum ≥ target. Return 0 if none exists. (LeetCode #209)

**Link:** https://leetcode.com/problems/minimum-size-subarray-sum/

---

## Which Technique, and Why?

"Minimum length contiguous subarray with sum ≥ target" → **Sliding Window (variable size)**. Expand right to add elements (increase sum); when sum ≥ target, shrink left to find the minimum valid window. All elements are positive, so shrinking always decreases the sum — this monotonicity is what makes sliding window work.

Why not prefix sum + binary search? That also works (O(n log n)) but sliding window is O(n) and simpler.

**Signal in the problem:** "minimum size subarray" + "sum ≥ target" + "positive integers" → sliding window. (If elements can be negative, sliding window breaks — use prefix sum + binary search instead.)

## Approach

`left = 0`, `sum = 0`, `minLen = infinity`. Expand `right`: add `nums[right]` to sum. While `sum >= target`: update `minLen`, subtract `nums[left]`, advance `left`. At the end, return `minLen` (or 0 if never found).

## Pseudocode

```
left = 0, sum = 0, minLen = infinity
for right from 0 to n-1:
    sum += nums[right]
    while sum >= target:
        minLen = min(minLen, right - left + 1)
        sum -= nums[left]
        left++
return minLen == infinity ? 0 : minLen
```

## Java Code

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int left = 0, sum = 0;
        int minLen = Integer.MAX_VALUE;

        for (int right = 0; right < nums.length; right++) {
            sum += nums[right];

            while (sum >= target) {
                minLen = Math.min(minLen, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }

        return minLen == Integer.MAX_VALUE ? 0 : minLen;
    }
}
```

## Line-by-line

- `sum` accumulates the current window's sum.
- Expand `right` by adding `nums[right]`.
- `while (sum >= target)` — while the window is valid, try to shrink: record length, subtract `nums[left]`, advance `left`. This finds the minimum valid window ending at `right`.
- `minLen == Integer.MAX_VALUE` → no valid window found → return 0.

## Complexity

- Time: O(n) — each element added once and removed once. The inner while loop total is O(n) across all iterations.
- Space: O(1) — a few variables.

## Common Mistakes

- **Elements can be negative.** Sliding window relies on monotonicity (sum decreases when you shrink). If elements can be negative, the sum isn't monotonic — use prefix sum + binary search instead.
- **Forgetting the `while` (using `if`).** Use `while`, not `if` — you may need to shrink multiple times to find the minimum.
- **Returning `minLen` directly.** If no valid window exists, `minLen` is still `MAX_VALUE`. Return 0 in that case.
- **Off-by-one in length:** `right - left + 1`, not `right - left`.

## How to Explain (interview)

**Opening:** Minimum Size Subarray Sum asks for the shortest contiguous subarray with sum ≥ target. Sliding window: expand right to add elements; when sum ≥ target, shrink left to find the minimum valid window. Requires positive integers (so the sum is monotonic when shrinking). O(n) time, O(1) space.

**The basic flow:**
```java
int left = 0, sum = 0, minLen = Integer.MAX_VALUE;
for (int right = 0; right < nums.length; right++) {
    sum += nums[right];
    while (sum >= target) {
        minLen = Math.min(minLen, right - left + 1);
        sum -= nums[left++];
    }
}
return minLen == Integer.MAX_VALUE ? 0 : minLen;
```

**The part that trips everyone up:** use `while`, not `if` — you may need to shrink multiple times. Also, this only works for **positive** numbers. If negatives are possible, use prefix sum + binary search.

**The mistakes to remember:**
- Using `if` instead of `while` (misses smaller windows)
- Applying sliding window to arrays with negatives (wrong answer)
- Forgetting to return 0 when no valid window exists
- Window length is `right - left + 1`
