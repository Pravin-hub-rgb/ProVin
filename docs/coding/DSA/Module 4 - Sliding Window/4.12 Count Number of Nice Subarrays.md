**Tier 2 problem.** (LeetCode #1248)

**Problem:** Given an array of integers and k, return the number of subarrays with exactly k odd numbers. (LeetCode #1248)

**Link:** https://leetcode.com/problems/count-number-of-nice-subarrays/

---

## Which Technique, and Why?

"Count subarrays with exactly k odd numbers" → **Sliding Window (at most)** or **Prefix Sum + HashMap**. The "at most" trick: count subarrays with at most k odd numbers, subtract those with at most k-1. O(n) time, O(1) space. Or prefix sum + map: O(n) time, O(n) space.

**Signal in the problem:** "exactly k odd numbers" / "nice subarray" → sliding window (at most) or prefix sum + map.

## Approach (Sliding Window — at most trick)

`countAtMost(k) - countAtMost(k - 1)` = subarrays with exactly k odd numbers. `countAtMost(k)` counts subarrays with at most k odd numbers using a sliding window (count odd numbers instead of sum).

## Pseudocode

```
return countAtMost(nums, k) - countAtMost(nums, k - 1)

countAtMost(nums, k):
    if k < 0: return 0
    left = 0, oddCount = 0, count = 0
    for right from 0 to n-1:
        if nums[right] % 2 != 0: oddCount++
        while oddCount > k:
            if nums[left] % 2 != 0: oddCount--
            left++
        count += right - left + 1
    return count
```

## Java Code

```java
class Solution {
    public int numberOfSubarrays(int[] nums, int k) {
        return countAtMost(nums, k) - countAtMost(nums, k - 1);
    }

    private int countAtMost(int[] nums, int k) {
        if (k < 0) return 0;
        int left = 0, oddCount = 0, count = 0;
        for (int right = 0; right < nums.length; right++) {
            if (nums[right] % 2 != 0) oddCount++;
            while (oddCount > k) {
                if (nums[left] % 2 != 0) oddCount--;
                left++;
            }
            count += right - left + 1;
        }
        return count;
    }
}
```

## Line-by-line

- `countAtMost(k)` counts subarrays with at most k odd numbers.
- `oddCount` tracks odd numbers in the current window.
- Expand right: if odd, increment `oddCount`.
- `while (oddCount > k)` — too many odds → shrink left.
- `count += right - left + 1` — all subarrays ending at right with ≤ k odds.
- `countAtMost(k) - countAtMost(k-1)` = exactly k odds.

## Complexity

- Time: O(n) — two passes, each O(n).
- Space: O(1).

## Common Mistakes

- **Using prefix sum + map.** Works (O(n) time, O(n) space) but sliding window is O(1) space.
- **Not handling k = 0.** `countAtMost(0)` counts subarrays with 0 odd numbers (all even). `countAtMost(-1)` returns 0. The subtraction handles this.
- **Using `if` instead of `while`.** You may need to shrink multiple times.
- **Off-by-one in `oddCount` update.** Decrement before advancing `left` (check `nums[left]` first).

## How to Explain (interview)

**Opening:** Count Number of Nice Subarrays counts subarrays with exactly k odd numbers. Sliding window "at most" trick: count(≤ k) − count(≤ k−1) = count(= k). Track odd count in the window. O(n) time, O(1) space.

**The basic flow:**
```java
return countAtMost(k) - countAtMost(k - 1);
// countAtMost(k): expand right, count odds, shrink while odds > k, count += right - left + 1
```

**The part that trips everyone up:** the "at most" trick — count(≤ k) − count(≤ k−1) = count(= k). Also, `count += right - left + 1` counts all valid subarrays ending at right.

**The mistakes to remember:**
- Using prefix sum + map (works but O(n) space)
- Not handling k = 0 (countAtMost(-1) returns 0)
- Using `if` instead of `while` for shrinking
- Off-by-one in odd count update
