**Problem:** Given an array of integers `nums` and an integer `k`. A **continuous subarray** is called **nice** if there are `k` odd numbers on it.

Return the number of nice subarrays. (LeetCode #1248)

**Link:** https://leetcode.com/problems/count-number-of-nice-subarrays/

---

## What This Problem Is Asking (Simple Terms)

You have an array of integers and a target `k`. You need to count the number of contiguous subarrays that contain exactly `k` odd numbers.

For example, `nums = [1,1,2,1,1]`, `k = 3` → subarrays with exactly 3 odd numbers: `[1,1,2,1]` (indices 0-3), `[1,1,2,1]` (indices 1-4)... wait, let me recount. `nums = [1,1,2,1,1]`, k=3:
- [1,1,2,1] (indices 0-3) has 3 odds ✓
- [1,2,1,1] (indices 1-4) has 3 odds ✓
- [1,1,2,1,1] (indices 0-4) has 4 odds ✗
So output is 2.

You return just the count.

---

## Example 1

**Input:** `nums = [1,1,2,1,1]`, `k = 3`

**Output:** `2`

**Explanation:** The only subarrays with exactly 3 odd numbers are `[1,1,2,1]` and `[1,2,1,1]`.

---

## Example 2

**Input:** `nums = [2,4,6]`, `k = 1`

**Output:** `0`

**Explanation:** No odd numbers at all.

---

## Example 3

**Input:** `nums = [2,2,2,1,2,2,1,2,2,2]`, `k = 2`

**Output:** `16`

**Explanation:** Multiple subarrays with exactly 2 odd numbers.

## Constraints

- `1 <= nums.length <= 50000`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

**Follow-up:** Could you solve it in O(n) time and O(1) space?

---

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could check every possible subarray, count odd numbers in it, and count those with exactly `k` odd numbers.

### Brute Force Pseudocode

```
count = 0
for i from 0 to n-1:
    oddCount = 0
    for j from i to n-1:
        if nums[j] % 2 == 1: oddCount++
        if oddCount == k: count++
return count
```

### Why Brute Force Is Slow

O(n²) — too slow for n = 5 * 10^4.

---

## Which Data Structure/Technique, and Why?

"Count subarrays with exactly k odd numbers" → **Prefix Sum + HashMap** OR **Sliding Window (at-most trick)**.

Convert the problem: replace each number with `nums[i] % 2` (1 if odd, 0 if even). Now count subarrays with sum = `k` in a binary array.

Use prefix sum + hashmap: track cumulative count of odd numbers. For each position, check if `prefixSum - k` has been seen before.

**Signal in the problem:** "count subarrays with exactly k odd numbers" → prefix sum + hashmap (treat odd as 1, even as 0).

---

## Optimized Approach (Prefix Sum + HashMap)

Convert each number to `nums[i] % 2` (1 for odd, 0 for even). Track cumulative sum of odd numbers. Use HashMap to count how many times each prefix sum has been seen. For each position, if `prefixSum - k` was seen before, add to result.

### Pseudocode

```
count = {0: 1}
prefixSum = 0, result = 0
for x in nums:
    prefixSum += x % 2
    result += count[prefixSum - k]
    count[prefixSum]++
return result
```

### Java Code

```java
class Solution {
    public int numberOfSubarrays(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        count.put(0, 1);
        int prefixSum = 0, result = 0;

        for (int x : nums) {
            prefixSum += x % 2;
            result += count.getOrDefault(prefixSum - k, 0);
            count.put(prefixSum, count.getOrDefault(prefixSum, 0) + 1);
        }
        return result;
    }
}
```

### Line-by-line

- `prefixSum += x % 2` — add 1 if odd, 0 if even.
- `result += count.getOrDefault(prefixSum - k, 0)` — if `prefixSum - k` was seen, those subarrays end here.
- `count.put(prefixSum, ...)` — record current prefix sum.

## Complexity

- Time: O(n) — single pass.
- Space: O(n) — hash map can have up to n entries.

## Common Mistakes

- **Not initializing `count[0] = 1`** — subarrays starting at index 0 would be missed.
- **Trying sliding window directly for "exactly k"** — sliding window works for "at most k", not "exactly k". Use prefix sum + hashmap, or `atMost(k) - atMost(k-1)`.
- **Not converting to binary first** — need `x % 2` to convert odd/even to 1/0.

## How to Explain (interview)

**Opening:** Count Number of Nice Subarrays asks for subarrays with exactly `k` odd numbers. Convert each number to `nums[i] % 2` (1 if odd). Prefix sum + hashmap: track cumulative odd count; for each position, check if `prefixSum - k` was seen before. O(n) time, O(n) space.

**The basic flow:**
```java
Map<Integer, Integer> count = new HashMap<>();
count.put(0, 1);
int prefixSum = 0, result = 0;
for (int x : nums) {
    prefixSum += x % 2;
    result += count.getOrDefault(prefixSum - k, 0);
    count.put(prefixSum, count.getOrDefault(prefixSum, 0) + 1);
}
return result;
```

**The part that trips everyone up:** `count.put(0, 1)` — the empty prefix sum. Without it, subarrays starting at index 0 with exactly `k` odds are missed.

**The mistakes to remember:**
- Not initializing `count[0] = 1`
- Using sliding window for "exactly k" directly (use prefix sum or at-most trick)
- Not converting numbers to 0/1 first
