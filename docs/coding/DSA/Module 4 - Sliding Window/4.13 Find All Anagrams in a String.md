**Tier 2 problem.** (LeetCode #438)

**Problem:** Given strings s and p, find all starting indices of p's anagrams in s. (LeetCode #438)

**Link:** https://leetcode.com/problems/find-all-anagrams-in-a-string/

---

## Which Technique, and Why?

"Find all anagrams of p in s" → **Fixed-size Sliding Window + frequency comparison**. Slide a window of size p.length() across s; check if the window's char frequency matches p's. Use a `matches` counter for O(1) per slide. O(n) time, O(1) space.

**Signal in the problem:** "find all anagrams" / "anagrams of p in s" → fixed-size sliding window + frequency comparison (same as Permutation in String, but return all indices).

## Approach

Same as Permutation in String (#567), but collect all starting indices where the window matches, instead of returning on the first match.

## Pseudocode

```
if p.length > s.length: return []
freqP = count of chars in p
freqS = count of chars in first window of s
matches = count of chars where freqP == freqS
result = []
if matches == 26: result.add(0)
for right from p.length to s.length-1:
    add s[right], remove s[right - p.length], update matches
    if matches == 26: result.add(right - p.length + 1)
return result
```

## Java Code

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        if (p.length() > s.length()) return result;

        int[] freqP = new int[26];
        int[] freqS = new int[26];
        for (char c : p.toCharArray()) freqP[c - 'a']++;
        for (int i = 0; i < p.length(); i++) freqS[s.charAt(i) - 'a']++;

        int matches = 0;
        for (int i = 0; i < 26; i++) {
            if (freqP[i] == freqS[i]) matches++;
        }
        if (matches == 26) result.add(0);

        for (int right = p.length(); right < s.length(); right++) {
            int addIdx = s.charAt(right) - 'a';
            int removeIdx = s.charAt(right - p.length()) - 'a';

            if (freqS[addIdx] == freqP[addIdx]) matches--;
            freqS[addIdx]++;
            if (freqS[addIdx] == freqP[addIdx]) matches++;

            if (freqS[removeIdx] == freqP[removeIdx]) matches--;
            freqS[removeIdx]--;
            if (freqS[removeIdx] == freqP[removeIdx]) matches++;

            if (matches == 26) result.add(right - p.length() + 1);
        }
        return result;
    }
}
```

## Line-by-line

- `freqP` = char counts of p.
- `freqS` = counts of the first window of s (size p.length()).
- `matches` = number of chars where freqP == freqS. If 26 → window is an anagram → record index 0.
- Slide: add new char, remove old char, update matches on both. If matches == 26 → record starting index `right - p.length() + 1`.

## Complexity

- Time: O(n) where n = s.length(). Each slide is O(1).
- Space: O(1) — two arrays of 26.

## Common Mistakes

- **Returning on first match.** This problem wants ALL starting indices. Don't return early.
- **Wrong starting index.** After sliding, the window starts at `right - p.length() + 1`, not `right`.
- **Not handling p longer than s.** Return empty list.
- **Using `matches` incorrectly.** Update matches before checking: decrement if it was matching before the change, increment if it matches after.
