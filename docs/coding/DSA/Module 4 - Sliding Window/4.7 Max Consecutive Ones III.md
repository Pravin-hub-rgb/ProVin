**Tier 2 problem.** (LeetCode #1004)

**Problem:** Given a binary array and an integer k, return the maximum number of consecutive 1s if you can flip at most k 0s to 1s. (LeetCode #1004)

**Link:** https://leetcode.com/problems/max-consecutive-ones-iii/

---

## Which Technique, and Why?

"Max consecutive 1s with at most k flips" → **Sliding Window (variable size)**. Maintain a window [left, right] with at most k zeros. Expand right; when zeros exceed k, shrink left. The window size is the answer. O(n) time, O(1) space.

**Signal in the problem:** "max consecutive ones" + "flip at most k zeros" → sliding window with a zero counter.

## Approach

Variable-size window. Expand right. Count zeros in the window. While zeros > k, shrink left (decrement zero count if the left element was 0, left++). Track max window size.

## Pseudocode

```
left = 0, zeros = 0, maxLen = 0
for right from 0 to n-1:
    if nums[right] == 0: zeros++
    while zeros > k:
        if nums[left] == 0: zeros--
        left++
    maxLen = max(maxLen, right - left + 1)
return maxLen
```

## Java Code

```java
class Solution {
    public int longestOnes(int[] nums, int k) {
        int left = 0, zeros = 0, maxLen = 0;

        for (int right = 0; right < nums.length; right++) {
            if (nums[right] == 0) zeros++;

            while (zeros > k) {
                if (nums[left] == 0) zeros--;
                left++;
            }

            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

## Line-by-line

- `zeros` counts 0s in the current window.
- Expand `right`: if it's a 0, increment `zeros`.
- `while (zeros > k)` — too many 0s → shrink from left: if left was a 0, decrement `zeros`; advance `left`.
- `maxLen` tracks the largest valid window.

## Complexity

- Time: O(n) — right and left each move at most n times.
- Space: O(1) — a few variables.

## Common Mistakes

- **Using `if` instead of `while`.** You may need to shrink multiple times. Use `while`.
- **Not counting zeros correctly.** Increment on `nums[right] == 0`, decrement on `nums[left] == 0` (before advancing left).
- **Window size formula.** `right - left + 1`, not `right - left`.
- **Assuming the array has only 0s and 1s.** Problem guarantees binary. If not, adjust.

## How to Explain (interview)

**Opening:** Max Consecutive Ones III finds the longest run of 1s after flipping at most k 0s. Sliding window: expand right, count zeros; when zeros exceed k, shrink left. The window always has ≤ k zeros. O(n) time, O(1) space.

**The basic flow:**
```java
int left = 0, zeros = 0, maxLen = 0;
for (int right = 0; right < nums.length; right++) {
    if (nums[right] == 0) zeros++;
    while (zeros > k) {
        if (nums[left] == 0) zeros--;
        left++;
    }
    maxLen = Math.max(maxLen, right - left + 1);
}
```

**The part that trips everyone up:** use `while`, not `if` — you may need to shrink multiple times. Also, decrement `zeros` **before** advancing `left` (check `nums[left]` first).

**The mistakes to remember:**
- Using `if` instead of `while` for shrinking
- Decrementing zeros after advancing left (wrong element checked)
- Window size is `right - left + 1`
- Not handling k = 0 (no flips allowed — just longest run of 1s)
