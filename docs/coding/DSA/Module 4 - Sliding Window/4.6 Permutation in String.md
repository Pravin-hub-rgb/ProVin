# 4.6 Permutation in String

**Tier 2 problem.** (LeetCode #567)

**Problem:** Given two strings s1 and s2, return true if s2 contains a permutation of s1. (LeetCode #567)

**Link:** https://leetcode.com/problems/permutation-in-string/

---

## Which Technique, and Why?

"Does s2 contain a permutation of s1?" → **Sliding Window (fixed size) + frequency comparison**. A permutation of s1 has the same character frequencies as s1. Slide a window of size s1.length() across s2; check if the window's frequency matches s1's. O(n) time, O(26) = O(1) space.

**Signal in the problem:** "permutation of s1 in s2" / "anagram of s1 in s2" → fixed-size sliding window + frequency comparison.

## Approach

Fixed window of size `s1.length()`. Compute frequency of s1. Slide the window across s2: add new char, remove old char, compare frequencies. Use a matches counter to avoid comparing all 26 letters each time.

## Pseudocode

```
if s1.length > s2.length: return false
freq1 = count of each char in s1
freq2 = count of each char in first window of s2
matches = count of chars where freq1 == freq2
if matches == 26: return true
for right from s1.length to s2.length-1:
    add s2[right] to freq2, update matches
    remove s2[right - s1.length] from freq2, update matches
    if matches == 26: return true
return false
```

## Java Code

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        if (s1.length() > s2.length()) return false;

        int[] freq1 = new int[26];
        int[] freq2 = new int[26];
        for (char c : s1.toCharArray()) freq1[c - 'a']++;
        for (int i = 0; i < s1.length(); i++) freq2[s2.charAt(i) - 'a']++;

        int matches = 0;
        for (int i = 0; i < 26; i++) {
            if (freq1[i] == freq2[i]) matches++;
        }
        if (matches == 26) return true;

        for (int right = s1.length(); right < s2.length(); right++) {
            int addIdx = s2.charAt(right) - 'a';
            int removeIdx = s2.charAt(right - s1.length()) - 'a';

            // add new char
            if (freq2[addIdx] == freq1[addIdx]) matches--;
            freq2[addIdx]++;
            if (freq2[addIdx] == freq1[addIdx]) matches++;

            // remove old char
            if (freq2[removeIdx] == freq1[removeIdx]) matches--;
            freq2[removeIdx]--;
            if (freq2[removeIdx] == freq1[removeIdx]) matches++;

            if (matches == 26) return true;
        }
        return false;
    }
}
```

## Line-by-line

- `freq1` = character counts of s1.
- `freq2` = counts of the first window of s2 (size s1.length()).
- `matches` = number of chars where freq1 == freq2. If 26, the window is a permutation.
- Slide the window: add new char (update matches), remove old char (update matches). Check matches == 26.

## Complexity

- Time: O(n) where n = s2.length(). Each slide is O(1) (matches updated incrementally).
- Space: O(1) — two arrays of 26.

## Common Mistakes

- **Comparing all 26 letters on every slide.** O(26 × n) — works but slower. Use the `matches` counter for O(n).
- **Wrong window size.** Window must be exactly s1.length(). Off-by-one in the loop bounds.
- **Not handling s1 longer than s2.** Return false immediately.
- **Assuming only lowercase.** If uppercase/other chars, use a HashMap.

**The part that trips everyone up:** the `matches` counter. When you add/remove a char, update matches: if the char's count was matching before the change, decrement matches; if it matches after, increment. This avoids comparing all 26 letters each slide.

**The mistakes to remember:**
- Comparing all 26 letters on every slide (O(26n) instead of O(n))
- Wrong window size (off by one)
- Not handling s1 longer than s2
- Assuming only lowercase letters
