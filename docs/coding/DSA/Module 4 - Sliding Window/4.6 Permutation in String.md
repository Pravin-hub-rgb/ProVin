**Problem:** Given two strings `s1` and `s2`, return `true` if `s2` contains a permutation of `s1`, or `false` otherwise.

In other words, return `true` if one of `s1`'s permutations is the substring of `s2`. (LeetCode #567)

**Link:** https://leetcode.com/problems/permutation-in-string/

---

## What This Problem Is Asking (Simple Terms)

You have two strings `s1` and `s2`. You need to check if any contiguous substring of `s2` is a permutation (anagram) of `s1`.

For example, `s1 = "ab"`, `s2 = "eidbaooo"` → `"ba"` is a substring of `s2` and is a permutation of `"ab"` → `true`.

You return `true` or `false`.

---

## Example 1

**Input:** `s1 = "ab"`, `s2 = "eidbaooo"`

**Output:** `true`

**Explanation:** `s2` contains `"ba"` which is a permutation of `"ab"`.

---

## Example 2

**Input:** `s1 = "ab"`, `s2 = "eidboaoo"`

**Output:** `false`

**Explanation:** No substring of `s2` is a permutation of `"ab"`.

---

## Constraints

- `1 <= s1.length, s2.length <= 10^4`
- `s1` and `s2` consist of lowercase English letters.

**Follow-up:** Could you solve it in O(n) time and O(1) space?

---

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could extract every substring of `s2` with length `s1.length()`, check if it's an anagram of `s1`, and return `true` if any match.

### Brute Force Pseudocode

```
for i from 0 to s2.length() - s1.length():
    substr = s2[i..i+s1.length()-1]
    if isAnagram(substr, s1): return true
return false
```

### Why Brute Force Is Slow

O(n × m) where n = s2.length(), m = s1.length(). For large inputs, too slow.

---

## Which Data Structure/Technique, and Why?

"Find if any substring is a permutation of s1" → **Sliding Window (fixed size = s1.length())**. Maintain a frequency map of characters in `s1` and a sliding window of the same size in `s2`. Slide the window one character at a time; if the frequency maps match, it's a permutation. O(n) time, O(26) = O(1) space.

**Signal in the problem:** "permutation" / "anagram" + "substring" → fixed-size sliding window with frequency map.

---

## Optimized Approach (Fixed-Size Sliding Window)

1. Count character frequencies in `s1`.
2. Initialize a sliding window of size `s1.length()` in `s2` with its frequency map.
3. If maps match, return `true`.
4. Slide window: remove `s2[left]`, add `s2[right]`, update map, check match.
5. If no match found after all windows, return `false`.

### Pseudocode

```
count1 = frequency map of s1
count2 = frequency map of s2[0..s1.length()-1]
if count1 == count2: return true
for right from s1.length() to s2.length()-1:
    count2[s2[right]]++
    count2[s2[right - s1.length()]]--
    if count1 == count2: return true
return false
```

### Java Code

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        if (s1.length() > s2.length()) return false;

        int[] count1 = new int[26];
        int[] count2 = new int[26];

        for (int i = 0; i < s1.length(); i++) {
            count1[s1.charAt(i) - 'a']++;
            count2[s2.charAt(i) - 'a']++;
        }

        if (Arrays.equals(count1, count2)) return true;

        for (int i = s1.length(); i < s2.length(); i++) {
            count2[s2.charAt(i) - 'a']++;
            count2[s2.charAt(i - s1.length()) - 'a']--;
            if (Arrays.equals(count1, count2)) return true;
        }
        return false;
    }
}
```

### Line-by-line

- `count1[s1.charAt(i) - 'a']++` — build frequency map of s1.
- `count2[s2.charAt(i) - 'a']++` — build initial window frequency map.
- `Arrays.equals(count1, count2)` — check if frequency maps match.
- Slide window: add new char, remove leftmost char.
- Check match after each slide.

## Complexity

- Time: O(n) where n = s2.length() — each character processed once.
- Space: O(1) — two arrays of 26.

## Common Mistakes

- **Not handling `s1.length() > s2.length()`** — return false immediately.
- **Using HashMap instead of array** — array of 26 is faster and simpler for lowercase letters.
- **Forgetting to remove the leftmost char when sliding** — window would grow unbounded.
- **Off-by-one in initial window** — window size should be exactly `s1.length()`.
