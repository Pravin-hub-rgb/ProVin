**Problem:** Given a string `s` consisting only of characters `a`, `b` and `c`. Return the number of substrings containing at least one occurrence of all three characters `a`, `b` and `c`. (LeetCode #1358)

**Link:** https://leetcode.com/problems/number-of-substrings-containing-all-three-characters/

---

## What This Problem Is Asking (Simple Terms)

You have a string containing only 'a', 'b', 'c'. You need to count the number of substrings that contain at least one of each character ('a', 'b', and 'c').

For example, `s = "abcabc"` → substrings containing all three: "abc" (indices 0-2), "abca" (0-3), "abcab" (0-4), "abcabc" (0-5), "bca" (1-3), "bcab" (1-4), "bcabc" (1-5), "cab" (2-4), "cabc" (2-5), "abc" (3-5) → 10 total.

You return just the count.

---

## Example 1

**Input:** `s = "abcabc"`

**Output:** `10`

**Explanation:** The substrings containing at least one 'a', one 'b', and one 'c' are: "abc", "abca", "abcab", "abcabc", "bca", "bcab", "bcabc", "cab", "cabc", "abc" → 10 total.

---

## Example 2

**Input:** `s = "aaacb"`

**Output:** `3`

**Explanation:** Substrings: "aaacb", "aacb", "acb" → 3 total.

---

## Example 3

**Input:** `s = "abc"`

**Output:** `1`

**Explanation:** "abc" → 1 total.

---

## Constraints

- `3 <= s.length <= 5 * 10^4`
- `s` consists only of characters 'a', 'b', 'c'.

**Follow-up:** Could you solve it in O(n) time and O(1) space?

---

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could check every possible substring, count characters, and if all three appear, increment count.

### Brute Force Pseudocode

```
count = 0
for i from 0 to n-1:
    for j from i to n-1:
        if substring s[i..j] contains 'a', 'b', and 'c':
            count++
return count
```

### Why Brute Force Is Slow

O(n³) — O(n²) substrings, each check O(n). Too slow for n = 5 * 10^4.

---

## Which Data Structure/Technique, and Why?

"Count substrings containing all three characters" → **Sliding Window (variable size)**. Key insight: for each `right`, find the smallest `left` such that `s[left..right]` contains all three characters. Then ALL substrings starting at `0, 1, ..., left` and ending at `right` also contain all three. So add `left + 1` to count.

**Signal in the problem:** "number of substrings containing all three characters" → sliding window counting valid substrings ending at each position.

---

## Optimized Approach (Sliding Window)

Track counts of 'a', 'b', 'c' in current window. Expand `right`; when window contains all three, shrink `left` as much as possible while still containing all three. Then all substrings starting from `0` to `left` and ending at `right` are valid → add `left + 1`.

### Pseudocode

```
count = {a:0, b:0, c:0}
left = 0, result = 0
for right from 0 to n-1:
    count[s[right]]++
    while count['a'] > 0 and count['b'] > 0 and count['c'] > 0:
        count[s[left]]--
        left++
    result += left
return result
```

### Java Code

```java
class Solution {
    public int numberOfSubstrings(String s) {
        int[] count = new int[3];
        int left = 0, result = 0;

        for (int right = 0; right < s.length(); right++) {
            count[s.charAt(right) - 'a']++;
            while (count[0] > 0 && count[1] > 0 && count[2] > 0) {
                count[s.charAt(left) - 'a']--;
                left++;
            }
            result += left;
        }
        return result;
    }
}
```

### Line-by-line

- `count[s.charAt(right) - 'a']++` — add current char to window counts.
- `while count[0] > 0 && count[1] > 0 && count[2] > 0` — window contains all three.
- `count[s.charAt(left) - 'a']--` — remove left char, try to shrink.
- `left++` — shrink window.
- `result += left` — all substrings starting at indices `0` to `left-1` ending at `right` are valid.

## Complexity

- Time: O(n) — each character enters and leaves the window at most once.
- Space: O(1) — array of 3.

## Common Mistakes

- **Not understanding why `result += left`** — when window `[left..right]` is the smallest valid window ending at `right`, all substrings starting at `0, 1, ..., left-1` and ending at `right` also contain all three characters.
- **Not using `while` instead of `if`** — need to shrink as much as possible.
- **Forgetting that `s` only contains 'a', 'b', 'c'** — can use array of 3 instead of HashMap.

## How to Explain (interview)

**Opening:** Number of Substrings Containing All Three Characters asks for the count of substrings containing 'a', 'b', and 'c'. Sliding window: expand right; when window contains all three, shrink left as much as possible. All substrings starting before `left` and ending at `right` are valid → add `left` to result. O(n) time, O(1) space.

**The basic flow:**
```java
int[] count = new int[3];
int left = 0, result = 0;
for (int right = 0; right < s.length(); right++) {
    count[s.charAt(right) - 'a']++;
    while (count[0] > 0 && count[1] > 0 && count[2] > 0) {
        count[s.charAt(left) - 'a']--;
        left++;
    }
    result += left;
}
return result;
```

**The part that trips everyone up:** `result += left` — understanding that when `[left..right]` is the smallest valid window, all start positions `0` to `left-1` also work.

**The mistakes to remember:**
- Using `if` instead of `while` for shrinking
- Not understanding why `result += left`
- Not resetting `left` properly (it only moves forward)
