# 4.10 Number of Substrings Containing All Three Characters

**Tier 2 problem.** (LeetCode #1358)

**Problem:** Given a string containing only 'a', 'b', 'c', count the number of substrings that contain at least one of each. (LeetCode #1358)

**Link:** https://leetcode.com/problems/number-of-substrings-containing-all-three-characters/

---

## Which Technique, and Why?

"Count substrings containing all three characters" → **Sliding Window (variable size) + counting**. Find the smallest window ending at each position that contains all three; every extension of that window to the left is also valid. O(n) time, O(1) space.

**Signal in the problem:** "count substrings" + "containing all of X, Y, Z" → sliding window, count valid windows ending at each position.

## Approach

Maintain counts of a, b, c in the window. Expand right. When all three counts > 0, the window [left, right] is valid, and so is every window [0..left, right], [1..left, right], ..., [left, right]. That's `left + 1` valid substrings ending at `right`. Then shrink left as much as possible while still valid (to find the minimum left for the next right).

## Pseudocode

```
count = [0, 0, 0]  // a, b, c
left = 0, result = 0
for right from 0 to n-1:
    count[s[right] - 'a']++
    while count[0] > 0 and count[1] > 0 and count[2] > 0:
        result += left + 1?  // no — see below
        // Actually: when valid, all windows [0..left..right]...[left..right] are valid
        // = (left + 1) valid substrings ending at right
        // Then shrink left
        count[s[left] - 'a']--
        left++
    // Wait — restructure: shrink first, then count
```

Actually, the cleaner version: shrink left while still valid, then the number of valid substrings ending at right is `left + 1` (if we track left as the first position where the window becomes invalid when shrunk further). Let me restructure:

```
count = [0,0,0], left = 0, result = 0
for right:
    count[s[right]-'a']++
    while (all three > 0):
        count[s[left]-'a']--
        left++
    // now window [left, right] is the smallest INVALID window (one char count is 0)
    // valid substrings ending at right: [0..right], [1..right], ..., [left-1..right] = left
    result += left
```

Wait, let me re-derive. After the while loop, `left` is the first index where removing it broke validity. So windows [0..right], [1..right], ..., [left-1..right] are all valid (they all contain all three). That's `left` valid substrings. Yes.

## Java Code

```java
class Solution {
    public int numberOfSubstrings(String s) {
        int[] count = new int[3]; // a, b, c
        int left = 0, result = 0;

        for (int right = 0; right < s.length(); right++) {
            count[s.charAt(right) - 'a']++;

            while (count[0] > 0 && count[1] > 0 && count[2] > 0) {
                count[s.charAt(left) - 'a']--;
                left++;
            }

            // left is now the first index where window is invalid
            // valid substrings ending at right: [0..right] to [left-1..right] = left count
            result += left;
        }
        return result;
    }
}
```

## Line-by-line

- `count[3]` tracks a, b, c counts.
- Expand `right`: increment count.
- `while (all three > 0)`: shrink left as much as possible while still valid. After loop, `left` is the first index making the window invalid (one char count is 0).
- `result += left`: windows [0..right], [1..right], ..., [left-1..right] are all valid → `left` valid substrings.

## Complexity

- Time: O(n) — right and left each move at most n times.
- Space: O(1) — fixed array of 3.

## Common Mistakes

- **Counting `left + 1` instead of `left`.** After shrinking, `left` valid substrings end at `right` (indices 0 to left-1 start). Not `left + 1`.
- **Using `if` instead of `while` for shrinking.** You may need to shrink multiple times.
- **Not handling the case where no valid window exists yet.** If `left == 0` and the window isn't valid, `result += 0` — correct (no valid substrings ending at right).
- **Assuming only a, b, c.** Problem guarantees only these three characters.

## How to Explain (interview)

**Opening:** Number of Substrings Containing All Three Characters counts substrings with at least one a, b, and c. Sliding window: expand right, shrink left while all three are present. After shrinking, `left` valid substrings end at `right`. O(n) time, O(1) space.

**The basic flow:**

- Counting `left + 1` instead of `left`

- Not handling the case where no valid window exists yet (result += 0)
