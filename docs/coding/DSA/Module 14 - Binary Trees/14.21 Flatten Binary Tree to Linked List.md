# 14.21 Flatten Binary Tree to Linked List

**Tier 2 problem.** (LeetCode #114)

**Problem:** Given a binary tree, flatten it to a linked list in-place (preorder order). The right child should point to the next node; left should be null. (LeetCode #114)

**Link:** https://leetcode.com/problems/flatten-binary-tree-to-linked-list/

---

## Which Technique, and Why?

"Flatten tree to linked list (preorder)" → **DFS (post-order)** or **iterative with a stack**. The key: process children before the parent (post-order), then rewire: `node.right = prev` (the last processed node), `node.left = null`. O(n) time, O(h) space (recursion) or O(n) (iterative).

**Signal in the problem:** "flatten" / "to linked list" / "in place" / "preorder order" → DFS post-order (process children first, then rewire).

## Approach

Post-order DFS: flatten right subtree first, then left subtree, then rewire: `node.right = prev` (the last node in the flattened right+left), `node.left = null`, update `prev = node`.

## Pseudocode

```
prev = null
flatten(node):
    if node == null: return
    flatten(node.right)   // right first
    flatten(node.left)    // then left
    node.right = prev     // rewire
    node.left = null
    prev = node
```

## Java Code

```java
class Solution {
    private TreeNode prev = null;

    public void flatten(TreeNode root) {
        if (root == null) return;
        flatten(root.right);   // process right first
        flatten(root.left);    // then left
        root.right = prev;     // rewire
        root.left = null;
        prev = root;
    }
}
```

## Iterative version (O(1) extra space)

```java
class Solution {
    public void flatten(TreeNode root) {
        TreeNode curr = root;
        while (curr != null) {
            if (curr.left != null) {
                // find the rightmost node in the left subtree
                TreeNode prev = curr.left;
                while (prev.right != null) prev = prev.right;
                // rewire: prev.right = curr.right, curr.right = curr.left, curr.left = null
                prev.right = curr.right;
                curr.right = curr.left;
                curr.left = null;
            }
            curr = curr.right;
        }
    }
}
```

## Line-by-line (recursive)

- Process right subtree first, then left (post-order: children before parent).
- `root.right = prev` — the right child becomes the last node processed (which is the next in preorder).
- `root.left = null` — clear left child.
- `prev = root` — update prev for the parent.

**Why right first?** Preorder is root, left, right. Flattening gives root → left → right. Processing right first, then left, then rewireing `right = prev` gives: root's right = (last of left subtree), and left's right = (first of right subtree). This produces preorder order.

## Complexity

- Recursive: O(n) time, O(h) space.
- Iterative: O(n) time, O(1) space.

## Common Mistakes

- **Processing left first.** If you process left first, the order is wrong. Process **right first**, then left, then rewire.
- **Not setting `left = null`.** The problem requires left to be null. Forgetting this leaves the tree partially linked.
- **Modifying during traversal.** If you rewire before processing children, you lose references. Process children first (post-order), then rewire.
- **Using `prev` as a class variable.** Works but is stateful. The iterative version avoids this.

## How to Explain (interview)

**Opening:** Flatten Binary Tree to Linked List converts a tree to a linked list in preorder order, in place. Post-order DFS: process right subtree first, then left, then rewire (`node.right = prev`, `node.left = null`). O(n) time, O(h) space (recursive) or O(1) (iterative).

**The basic flow:**
```java
TreeNode prev = null;
void flatten(TreeNode root) {
    if (root == null) return;
    flatten(root.right);   // right first
    flatten(root.left);    // then left
    root.right = prev;     // rewire
    root.left = null;
    prev = root;
}
```

**The part that trips everyone up:** process **right first, then left** (post-order reversed). If you process left first, the order is wrong. Also, set `left = null` — the problem requires it.

**The mistakes to remember:**
- Processing left first (wrong order)
- Not setting left = null
- Rewiring before processing children (loses references)
- Stack overflow on skewed trees (use iterative)
