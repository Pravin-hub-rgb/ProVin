**Tier 2 problem.** (LeetCode #106)

**Problem:** Given inorder and postorder traversal arrays, reconstruct the binary tree. (LeetCode #106)

**Link:** https://leetcode.com/problems/construct-binary-tree-from-inorder-and-postorder-traversal/

---

## Which Technique, and Why?

"Reconstruct tree from inorder and postorder" → **Divide and Conquer + HashMap**. Postorder's last element is the root. Find it in inorder to split left/right subtrees. Recurse. Same as #105 but using postorder's last element.

**Signal in the problem:** "construct from inorder and postorder" → postorder's last element is root; inorder gives split.

## Approach

1. Build map: value → index in inorder.
2. `postIdx` starts at the last element of postorder.
3. `build(inStart, inEnd)`: if `inStart > inEnd` → null. Root = `postorder[postIdx--]`. Find position in inorder (`inRoot`). Right subtree = `build(inRoot + 1, inEnd)` (build right first!). Left subtree = `build(inStart, inRoot - 1)`.

**Key difference from #105:** build **right** subtree first, then left (because postorder is left, right, root — processing from the end gives root, then right, then left).

## Pseudocode

```
map = value -> index in inorder
postIdx = n - 1
build(inStart, inEnd):
    if inStart > inEnd: return null
    root = new TreeNode(postorder[postIdx--])
    inRoot = map[root.val]
    root.right = build(inRoot + 1, inEnd)   // right first!
    root.left = build(inStart, inRoot - 1)
    return root
```

## Java Code

```java
class Solution {
    private int postIdx;
    private Map<Integer, Integer> inMap;

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        inMap = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) inMap.put(inorder[i], i);
        postIdx = postorder.length - 1;
        return build(inorder, postorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] inorder, int[] postorder, int inStart, int inEnd) {
        if (inStart > inEnd) return null;
        TreeNode root = new TreeNode(postorder[postIdx--]);
        int inRoot = inMap.get(root.val);
        root.right = build(inorder, postorder, inRoot + 1, inEnd);  // right first
        root.left = build(inorder, postorder, inStart, inRoot - 1);
        return root;
    }
}
```

## Line-by-line

- `postIdx` starts at `n - 1` (last element of postorder = root).
- `root = postorder[postIdx--]` — consume root from the end.
- `inRoot = inMap.get(root.val)` — position in inorder.
- **Build right first** (`inRoot + 1` to `inEnd`), then left (`inStart` to `inRoot - 1`). Because postorder order is left, right, root — processing from the end gives root, right, left.

## Complexity

- Time: O(n) — each node created once, HashMap lookup O(1).
- Space: O(n) — map + recursion stack.

## Common Mistakes

- **Building left first.** In #105 (preorder), you build left first. In #106 (postorder), you must build **right first** (postorder is left, right, root — processing from the end reverses this to root, right, left).
- **Not using a HashMap.** O(n²) instead of O(n).
- **Wrong recursion bounds.** Right: `build(inRoot + 1, inEnd)`. Left: `build(inStart, inRoot - 1)`.
- **Assuming duplicates.** Problem guarantees unique values.

## How to Explain (interview)

**Opening:** Construct Binary Tree from Inorder and Postorder reconstructs a tree. Postorder's last element is the root. Find it in inorder to split. Build **right subtree first**, then left (because postorder is left, right, root — processing from the end gives root, right, left). HashMap for O(1) lookup. O(n) time, O(n) space.

**The basic flow:**
```java
int postIdx = n - 1;
TreeNode build(int inStart, int inEnd) {
    if (inStart > inEnd) return null;
    TreeNode root = new TreeNode(postorder[postIdx--]);
    int inRoot = inMap.get(root.val);
    root.right = build(inRoot + 1, inEnd);  // right first!
    root.left = build(inStart, inRoot - 1);
    return root;
}
```

**The part that trips everyone up:** build **right** first, then left. In #105 (preorder), you build left first. The difference: preorder is root, left, right (process left first); postorder is left, right, root (process right first when going backwards).

**The mistakes to remember:**
- Building left first (wrong for postorder)
- Not using HashMap (O(n²))
- Wrong recursion bounds
- Assuming duplicates
