# 14.13 Path Sum

**Problem:** Given a binary tree and a target sum, determine if there's a root-to-leaf path whose node values sum to target. (LeetCode #112)

**Link:** https://leetcode.com/problems/path-sum/

---

## Which Technique, and Why?

Root-to-leaf path sum → **DFS with running sum**. At each node, subtract `node.val` from the target. At a leaf, check if the remaining target is 0. O(n) time, O(h) space.

**Signal in the problem:** "path sum" / "root to leaf" / "sum equals target" → DFS, subtract as you go, check at leaf.

## Approach

DFS: if node is null → false. If leaf (no children) → check if `node.val == target`. Otherwise, recurse on children with `target - node.val`. Return true if either subtree has a valid path.

## Pseudocode

```
hasPathSum(node, target):
    if node == null: return false
    if node.left == null and node.right == null:  // leaf
        return node.val == target
    return hasPathSum(node.left, target - node.val) or hasPathSum(node.right, target - node.val)
```

## Java Code

```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) return false;
        if (root.left == null && root.right == null) {
            return root.val == targetSum;
        }
        return hasPathSum(root.left, targetSum - root.val) ||
               hasPathSum(root.right, targetSum - root.val);
    }
}
```

## Line-by-line

- `root == null` → false (no path).
- Leaf check: `root.left == null && root.right == null` → return `root.val == targetSum`.
- Otherwise: recurse on left and right with `targetSum - root.val`. Return true if either subtree has a valid path.

## Complexity

- Time: O(n) — visit every node (early exit on first valid path).
- Space: O(h) — recursion stack.

## Common Mistakes

- **Checking `targetSum == 0` at null.** If the tree has a path that sums to 0 and you check `node == null && target == 0`, you'd return true incorrectly. The correct base case is `leaf → check value`. Don't check at null.
- **Not checking for leaf.** A "path" must end at a leaf (node with no children). A path ending at an internal node doesn't count.
- **Off-by-one in subtraction.** Subtract `node.val` when recursing to children, not when checking. `hasPathSum(child, targetSum - root.val)`, not `hasPathSum(child, targetSum) - root.val`.
- **Empty tree.** `root == null` → false (no path exists).

## How to Explain (interview)

**Opening:** Path Sum checks if a root-to-leaf path sums to target. DFS: at each node, subtract its value from the target. At a leaf, check if the remaining target is 0. O(n) time, O(h) space. The path must end at a leaf (node with no children).

**The basic flow:**
```java
if (root == null) return false;
if (root.left == null && root.right == null) return root.val == targetSum;
return hasPathSum(root.left, targetSum - root.val) ||
       hasPathSum(root.right, targetSum - root.val);
```

**The part that trips everyone up:** the path must end at a **leaf** (both children null). A path ending at an internal node doesn't count. Also, don't check `target == 0` at null — that gives false positives.

**The mistakes to remember:**
- Checking `target == 0` at null (false positive)
- Not checking for leaf (path ending at internal node)
- Off-by-one in subtraction (subtract at recursion, not at check)
- Empty tree (return false, not true)
