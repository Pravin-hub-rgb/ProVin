# 14.15 Binary Tree Zigzag Level Order Traversal

**Tier 2 problem.** (LeetCode #103)

**Problem:** Given a binary tree, return the level order traversal but alternating direction per level (left-to-right, then right-to-left, ...). (LeetCode #103)

**Link:** https://leetcode.com/problems/binary-tree-zigzag-level-order-traversal/

---

## Which Technique, and Why?

"Zigzag level order" → **BFS (level order) + reverse every other level**. Same as level order traversal (Module 14.9), but reverse the list for odd-indexed levels. O(n) time, O(n) space.

**Signal in the problem:** "zigzag" / "alternating direction" / "level order" → BFS + reverse odd levels.

## Approach

BFS level by level. For each level, collect node values. If the level index is odd, reverse the list before adding to result.

## Pseudocode

```
if root == null: return []
result = []
queue = [root]
leftToRight = true
while queue not empty:
    levelSize = queue.size()
    level = []
    for i from 0 to levelSize-1:
        node = queue.poll()
        level.add(node.val)
        if node.left != null: queue.offer(node.left)
        if node.right != null: queue.offer(node.right)
    if !leftToRight: reverse(level)
    result.add(level)
    leftToRight = !leftToRight
return result
```

## Java Code

```java
class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        boolean leftToRight = true;

        while (!q.isEmpty()) {
            int levelSize = q.size();
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = q.poll();
                level.add(node.val);
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            if (!leftToRight) Collections.reverse(level);
            result.add(level);
            leftToRight = !leftToRight;
        }
        return result;
    }
}
```

## Line-by-line

- BFS level order (same as #102).
- `leftToRight` toggles each level. If false, reverse the level list.
- `Collections.reverse(level)` reverses in place.

## Complexity

- Time: O(n) — visit every node once. Reverse is O(level size), total O(n).
- Space: O(n) — queue + result.

## Common Mistakes

- **Reversing the queue instead of the level list.** You must reverse the collected level, not the queue (queue order must stay left-to-right for next level).
- **Toggling at the wrong time.** Toggle `leftToRight` after adding the level, not before.
- **Not handling null root.** Return empty list.

## How to Explain (interview)

**Opening:** Zigzag Level Order is level order (BFS) but alternating direction. Same as #102, but reverse every other level's list. O(n) time, O(n) space.

**The basic flow:**
```java
boolean leftToRight = true;
while (!q.isEmpty()) {
    // collect level (same as level order)
    if (!leftToRight) Collections.reverse(level);
    result.add(level);
    leftToRight = !leftToRight;
}
```

**The part that trips everyone up:** reverse the **level list**, not the queue. The queue must stay left-to-right for the next level's children to be enqueued correctly.

**The mistakes to remember:**
- Reversing the queue instead of the level list
- Toggling direction at the wrong time
- Not handling null root
- Confusing with #102 (level order) — same technique, just reverse odd levels
