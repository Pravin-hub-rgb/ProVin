**Problem:** Given the root of a binary tree, return the preorder traversal (root → left → right). (LeetCode #144)

**Link:** https://leetcode.com/problems/binary-tree-preorder-traversal/

---

## Which Technique, and Why?

Preorder traversal (root → left → right) → **DFS (recursive or iterative with a stack)**. Recursive is simplest. O(n) time, O(h) space.

**Signal in the problem:** "preorder traversal" → root, left, right. Used for copying a tree, prefix expression evaluation.

## Approach

Recursive: if null, return. Record root.val, recurse left, recurse right.

Iterative: use a stack. Push root. Pop, record, push right then left (so left is processed first).

## Pseudocode (recursive)

```
preorder(node):
    if node == null: return
    result.add(node.val)
    preorder(node.left)
    preorder(node.right)
```

## Java Code (recursive)

```java
class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        preorder(root, result);
        return result;
    }

    private void preorder(TreeNode node, List<Integer> result) {
        if (node == null) return;
        result.add(node.val);
        preorder(node.left, result);
        preorder(node.right, result);
    }
}
```

## Java Code (iterative)

```java
class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);

        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            result.add(node.val);
            if (node.right != null) stack.push(node.right); // right first
            if (node.left != null) stack.push(node.left);   // left last (processed first)
        }
        return result;
    }
}
```

## Line-by-line (iterative)

- Push root.
- Pop, record value.
- Push right first, then left — so left is on top and processed next (LIFO).
- Continue until stack is empty.

## Complexity

- Time: O(n) — visit every node once.
- Space: O(h) — stack holds at most h nodes.

## Common Mistakes

- **Pushing left before right.** In iterative preorder, push right first, then left (so left is on top). If you push left first, right gets processed first — that's not preorder.
- **Order of operations.** Preorder = root, left, right. Not left, root, right (that's inorder).
- **Not handling null root.** Return empty list.

## How to Explain (interview)

**Opening:** Preorder Traversal visits nodes in root → left → right order. Recursive: record root, recurse left, recurse right. O(n) time, O(h) space. Iterative: stack, push root, pop-record, push right then left.

**The basic flow (recursive):**
```java
void preorder(TreeNode node) {
    if (node == null) return;
    result.add(node.val);   // root first
    preorder(node.left);
    preorder(node.right);
}
```

**The part that trips everyone up:** in iterative preorder, push **right first, then left** (so left is on top of the stack and processed next). Pushing left first gives wrong order.

**The mistakes to remember:**
- Pushing left before right in iterative (wrong order)
- Mixing up traversal orders
- Not handling null root
