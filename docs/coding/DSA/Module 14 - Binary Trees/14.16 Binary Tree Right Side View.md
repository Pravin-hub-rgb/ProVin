# 14.16 Binary Tree Right Side View

**Tier 2 problem.** (LeetCode #199)

**Problem:** Given a binary tree, return the values of the nodes visible from the right side (rightmost node at each level). (LeetCode #199)

**Link:** https://leetcode.com/problems/binary-tree-right-side-view/

---

## Which Technique, and Why?

"Right side view" → **BFS (level order) — take the last element of each level**, or **DFS (preorder, right first) — first node visited at each depth**. BFS is simpler. O(n) time, O(n) space.

**Signal in the problem:** "right side view" / "visible from right" → BFS level order, take last element of each level. Or DFS right-first, record first at each depth.

## Approach (BFS)

Level order traversal. For each level, the last element added is the rightmost → add it to result.

## Pseudocode

```
if root == null: return []
result = []
queue = [root]
while queue not empty:
    levelSize = queue.size()
    for i from 0 to levelSize-1:
        node = queue.poll()
        if i == levelSize - 1: result.add(node.val)  // last in level
        if node.left != null: queue.offer(node.left)
        if node.right != null: queue.offer(node.right)
return result
```

## Java Code (BFS)

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);

        while (!q.isEmpty()) {
            int levelSize = q.size();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = q.poll();
                if (i == levelSize - 1) result.add(node.val);
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
        }
        return result;
    }
}
```

## Java Code (DFS — right first)

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        dfs(root, 0, result);
        return result;
    }

    private void dfs(TreeNode node, int depth, List<Integer> result) {
        if (node == null) return;
        if (depth == result.size()) result.add(node.val);  // first node at this depth
        dfs(node.right, depth + 1, result);  // right first
        dfs(node.left, depth + 1, result);
    }
}
```

## Line-by-line (BFS)

- BFS level order. For each level, the last node polled (`i == levelSize - 1`) is the rightmost → add to result.
- Enqueue left then right (so right is processed last in the level).

## Line-by-line (DFS)

- DFS with right child first. The first node visited at each depth is the rightmost.
- `depth == result.size()` → this is the first node at this depth → record it.

## Complexity

- Time: O(n) — visit every node once.
- Space: O(n) — queue (BFS) or recursion stack (DFS).

## Common Mistakes

- **Enqueuing right before left.** If you enqueue right first, the level order changes and the "last element" isn't the rightmost. Enqueue left then right (BFS). Or use DFS right-first.
- **Using `result.size()` as depth check in DFS.** This works because we add the first node at each depth, making result.size() == depth for the first node at that depth.
- **Not handling null root.** Return empty list.
- **Confusing with "Left Side View."** Same technique, but take the first element of each level (or DFS left-first).

## How to Explain (interview)

**Opening:** Right Side View returns the rightmost node at each level. BFS: level order, take the last element of each level. Or DFS: visit right child first, record the first node at each depth. O(n) time, O(n) space.

**The basic flow (BFS):**
```java
Queue<TreeNode> q = new ArrayDeque<>();
q.offer(root);
while (!q.isEmpty()) {
    int size = q.size();
    for (int i = 0; i < size; i++) {
        TreeNode node = q.poll();
        if (i == size - 1) result.add(node.val);  // last in level
        if (node.left != null) q.offer(node.left);
        if (node.right != null) q.offer(node.right);
    }
}
```

**The part that trips everyone up:** enqueue **left then right** (so right is last in the level). Or use DFS visiting right first. Also, `depth == result.size()` in DFS means "first node at this depth."

**The mistakes to remember:**
- Enqueuing right before left (wrong last element)
- Confusing with Left Side View (take first, not last)
- Not handling null root
- DFS: visiting left first (would give left side view)
