# 14.12 Binary Tree Postorder Traversal

**Problem:** Given the root of a binary tree, return the postorder traversal (left → right → root). (LeetCode #145)

**Link:** https://leetcode.com/problems/binary-tree-postorder-traversal/

---

## Which Technique, and Why?

Postorder traversal (left → right → root) → **DFS (recursive or iterative)**. Recursive is simplest. O(n) time, O(h) space. Postorder processes children before the parent — used for deletion, height, diameter, expression evaluation.

**Signal in the problem:** "postorder traversal" → left, right, root. Used when you need children's results before processing the parent.

## Approach

Recursive: if null, return. Recurse left, recurse right, record root.val.

Iterative: trickier. Use two stacks or a modified preorder (root, right, left) then reverse. Or use a single stack with a "visited" flag.

## Pseudocode (recursive)

```
postorder(node):
    if node == null: return
    postorder(node.left)
    postorder(node.right)
    result.add(node.val)
```

## Java Code (recursive)

```java
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        postorder(root, result);
        return result;
    }

    private void postorder(TreeNode node, List<Integer> result) {
        if (node == null) return;
        postorder(node.left, result);
        postorder(node.right, result);
        result.add(node.val);
    }
}
```

## Java Code (iterative — two-stack trick)

```java
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        Deque<TreeNode> stack1 = new ArrayDeque<>();
        Deque<TreeNode> stack2 = new ArrayDeque<>();
        stack1.push(root);

        while (!stack1.isEmpty()) {
            TreeNode node = stack1.pop();
            stack2.push(node);
            if (node.left != null) stack1.push(node.left);
            if (node.right != null) stack1.push(node.right);
        }
        while (!stack2.isEmpty()) {
            result.add(stack2.pop().val);
        }
        return result;
    }
}
```

**Trick:** stack1 gives root, right, left order (modified preorder). Pushing to stack2 reverses it → left, right, root (postorder).

## Complexity

- Time: O(n) — visit every node once.
- Space: O(h) — stack holds at most h nodes (two stacks in iterative).

## Common Mistakes

- **Order of operations.** Postorder = left, right, root. Recording root first gives preorder, not postorder.
- **Iterative complexity.** Postorder iterative is trickier than preorder/inorder. The two-stack trick is simplest. Single-stack with "visited" flag is also common but more error-prone.
- **Not handling null root.** Return empty list.

## How to Explain (interview)

**Opening:** Postorder Traversal visits nodes in left → right → root order. Recursive: recurse left, recurse right, record root. O(n) time, O(h) space. Iterative version uses two stacks (modified preorder into stack2, then pop). Postorder is used when you need children's results before the parent (height, diameter, deletion).

**The basic flow (recursive):**
```java
void postorder(TreeNode node) {
    if (node == null) return;
    postorder(node.left);
    postorder(node.right);
    result.add(node.val);   // root last
}
```

**The part that trips everyone up:** root is processed **last**. For iterative, use the two-stack trick (push root to stack1, children left/right; pop to stack2; reverse gives postorder). Single-stack postorder is error-prone.

**The mistakes to remember:**
- Recording root first (that's preorder, not postorder)
- Iterative postorder is tricky — use two-stack trick
- Not handling null root
- Confusing with inorder (left, root, right)
