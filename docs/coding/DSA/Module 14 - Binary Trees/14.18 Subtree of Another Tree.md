**Tier 2 problem.** (LeetCode #572)

**Problem:** Given two binary trees, check if one is a subtree of the other (same structure and values). (LeetCode #572)

**Link:** https://leetcode.com/problems/subtree-of-another-tree/

---

## Which Technique, and Why?

"Is subtree B contained in tree A?" → **DFS + Same Tree check**. For each node in A, check if the subtree rooted there is identical to B (using the Same Tree algorithm from 14.5). O(n × m) time (n = size of A, m = size of B), O(h) space.

**Signal in the problem:** "subtree" / "is B contained in A" → for each node in A, check Same Tree with B.

## Approach

DFS through A. At each node, check if `isSameTree(node, B)`. If yes → true. If not, recurse on left and right. If no match → false.

## Pseudocode

```
isSubtree(A, B):
    if A == null: return B == null
    if isSameTree(A, B): return true
    return isSubtree(A.left, B) or isSubtree(A.right, B)

isSameTree(p, q):
    if p == null and q == null: return true
    if p == null or q == null: return false
    if p.val != q.val: return false
    return isSameTree(p.left, q.left) and isSameTree(p.right, q.right)
```

## Java Code

```java
class Solution {
    public boolean isSubtree(TreeNode root, TreeNode subRoot) {
        if (root == null) return subRoot == null;
        if (isSameTree(root, subRoot)) return true;
        return isSubtree(root.left, subRoot) || isSubtree(root.right, subRoot);
    }

    private boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) return true;
        if (p == null || q == null) return false;
        if (p.val != q.val) return false;
        return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}
```

## Line-by-line

- `isSubtree`: if root is null, return (subRoot == null). Check if current subtree matches subRoot. If not, recurse on left and right.
- `isSameTree`: standard tree equality check (Module 14.5).

## Complexity

- Time: O(n × m) where n = size of A, m = size of B. For each node in A (n), check Same Tree (O(m)).
- Space: O(h) — recursion stack.

## Common Mistakes

- **Using `==` for TreeNode comparison.** Compare values and structure, not references.
- **Not handling null.** If `subRoot` is null, it's a subtree of any tree (including null). If `root` is null and `subRoot` is not, return false.
- **O(n × m) is acceptable.** For large inputs, use tree hashing (serialize both trees, check if subRoot's serialization is a substring of root's) for O(n + m). But the simple approach is fine for interviews.
- **Confusing with "Same Tree" (#100).** Same Tree checks if two trees are identical. Subtree checks if one is contained in the other.

## How to Explain (interview)

**Opening:** Subtree of Another Tree checks if tree B is contained in tree A. For each node in A, check if the subtree rooted there is identical to B (using Same Tree algorithm). O(n×m) time, O(h) space. The simple approach is acceptable; tree hashing gives O(n+m) but is more complex.

**The basic flow:**
```java
boolean isSubtree(TreeNode root, TreeNode subRoot) {
    if (root == null) return subRoot == null;
    if (isSameTree(root, subRoot)) return true;
    return isSubtree(root.left, subRoot) || isSubtree(root.right, subRoot);
}
```

**The part that trips everyone up:** you must check `isSameTree` at **every** node, not just the root. Also, `isSameTree` is the standard equality check (Module 14.5).

**The mistakes to remember:**
- Using `==` instead of value comparison
- Not handling null (subRoot null → true; root null, subRoot non-null → false)
- Only checking the root (must check all nodes)
- Confusing with Same Tree (#100)
