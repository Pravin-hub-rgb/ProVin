**Tier 2 problem.** (LeetCode #105)

**Problem:** Given preorder and inorder traversal arrays, reconstruct the binary tree. (LeetCode #105)

**Link:** https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/

---

## Which Technique, and Why?

"Reconstruct tree from traversals" → **Divide and Conquer + HashMap**. Preorder's first element is the root. Find it in inorder to split left/right subtrees. Recurse. Use a HashMap for O(1) lookup of inorder positions. O(n) time, O(n) space.

**Signal in the problem:** "construct binary tree from preorder and inorder" → divide and conquer. Preorder gives root; inorder gives split.

## Approach

1. Build a map: value → index in inorder.
2. Preorder index `preIdx` starts at 0 (root).
3. `build(inStart, inEnd)`: if `inStart > inEnd` → null. Root = `preorder[preIdx++]`. Find root's position in inorder (`inRoot`). Left subtree = `build(inStart, inRoot - 1)`. Right subtree = `build(inRoot + 1, inEnd)`.

## Pseudocode

```
map = value -> index in inorder
preIdx = 0
build(inStart, inEnd):
    if inStart > inEnd: return null
    root = new TreeNode(preorder[preIdx++])
    inRoot = map[root.val]
    root.left = build(inStart, inRoot - 1)
    root.right = build(inRoot + 1, inEnd)
    return root
```

## Java Code

```java
class Solution {
    private int preIdx = 0;
    private Map<Integer, Integer> inMap;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        inMap = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) inMap.put(inorder[i], i);
        return build(preorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] preorder, int inStart, int inEnd) {
        if (inStart > inEnd) return null;
        TreeNode root = new TreeNode(preorder[preIdx++]);
        int inRoot = inMap.get(root.val);
        root.left = build(preorder, inStart, inRoot - 1);
        root.right = build(preorder, inRoot + 1, inEnd);
        return root;
    }
}
```

## Line-by-line

- `inMap` — O(1) lookup of a value's position in inorder.
- `preIdx` — global index into preorder. Each call consumes one preorder element (the root).
- `inRoot = inMap.get(root.val)` — position of root in inorder. Left subtree = elements before it; right = elements after.
- Recurse on left and right halves.

## Complexity

- Time: O(n) — each node created once, HashMap lookup O(1).
- Space: O(n) — map + recursion stack.

## Common Mistakes

- **Not using a HashMap.** Searching inorder linearly makes it O(n²). Use a map for O(1) lookup.
- **Wrong recursion bounds.** Left subtree: `build(inStart, inRoot - 1)`. Right: `build(inRoot + 1, inEnd)`. Off-by-one here breaks the tree.
- **Not incrementing preIdx.** Each call must consume one preorder element. Use `preorder[preIdx++]`.
- **Assuming duplicates.** Problem guarantees unique values. If duplicates exist, this approach fails.
