**Problem:** Given a binary tree, return the length of the diameter (longest path between any two nodes). The path may or may not pass through the root. (LeetCode #543)

**Link:** https://leetcode.com/problems/diameter-of-binary-tree/

---

## Which Technique, and Why?

Diameter = longest path between any two nodes. At each node, the longest path through it = height(left) + height(right). Track the max across all nodes. Use a post-order DFS (compute height bottom-up, update diameter at each node). O(n) time, O(h) space.

**Signal in the problem:** "diameter" / "longest path between any two nodes" → post-order DFS, track max of (left height + right height).

## Approach

Post-order: compute height of left and right subtrees. At each node, `diameter = max(diameter, leftHeight + rightHeight)`. Return `max(leftHeight, rightHeight) + 1` (height of this subtree). Track diameter in a class variable or pass an array.

## Pseudocode

```
diameter = 0
height(node):
    if node == null: return 0
    left = height(node.left)
    right = height(node.right)
    diameter = max(diameter, left + right)
    return max(left, right) + 1
```

## Java Code

```java
class Solution {
    private int diameter = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        height(root);
        return diameter;
    }

    private int height(TreeNode node) {
        if (node == null) return 0;
        int left = height(node.left);
        int right = height(node.right);
        diameter = Math.max(diameter, left + right);
        return Math.max(left, right) + 1;
    }
}
```

## Line-by-line

- `height(node)` returns the height of the subtree rooted at `node`.
- At each node, `left + right` = longest path through this node (left height + right height, in edges).
- Update `diameter` = max of all such paths.
- Return `max(left, right) + 1` — height of this subtree (for parent's computation).

## Complexity

- Time: O(n) — visit every node once.
- Space: O(h) — recursion stack.

## Common Mistakes

- **Counting nodes instead of edges.** The diameter is the number of **edges** in the longest path. `left + right` counts edges (height in edges). If height is measured in nodes, subtract 1. LeetCode #543 counts edges.
- **Only checking the root.** The diameter may not pass through the root. Must check every node (the `diameter = max(...)` in the recursive function handles this).
- **Modifying the tree.** This problem doesn't require it. Don't mutate.
- **Stack overflow on skewed trees.** Use iterative if needed.

**The mistakes to remember:**
- Counting nodes instead of edges
- Only checking the root (misses paths in subtrees)
- Forgetting to update diameter at every node
