# 14.3 Maximum Depth of Binary Tree

**Problem:** Given the root of a binary tree, return its maximum depth (number of nodes along the longest path from root to leaf). (LeetCode #104)

**Link:** https://leetcode.com/problems/maximum-depth-of-binary-tree/

---

## Which Technique, and Why?

Maximum depth of a tree → **DFS (post-order)**. Recursively compute depth of left and right subtrees, return max + 1. O(n) time, O(h) space.

**Signal in the problem:** "maximum depth" / "height of tree" → DFS: depth = max(left, right) + 1. Base case: null → 0.

## Approach

Base case: `root == null` → 0. Recursively compute left depth and right depth. Return `max(left, right) + 1`.

## Pseudocode

```
if root == null: return 0
left = maxDepth(root.left)
right = maxDepth(root.right)
return max(left, right) + 1
```

## Java Code

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        int left = maxDepth(root.left);
        int right = maxDepth(root.right);
        return Math.max(left, right) + 1;
    }
}
```

## Line-by-line

- `root == null` → 0 (base case: empty tree has depth 0).
- Recursively compute depth of left and right subtrees.
- Return `max(left, right) + 1` — the deeper subtree plus this node.

## Complexity

- Time: O(n) — visit every node once.
- Space: O(h) — recursion stack, h = height. O(log n) for balanced, O(n) for skewed.

## Common Mistakes

- **Returning 0 for a single node.** A single node has depth 1, not 0. `max(0, 0) + 1 = 1`. Correct.
- **Confusing depth and height.** Depth is from root; height is from node to leaf. This problem asks for height (max depth from root). For a single node, height = 1 (or 0, depending on convention). LeetCode uses 1.
- **Stack overflow on skewed trees.** Depth 10⁵ → StackOverflowError. Use iterative BFS for deep trees.

## How to Explain (interview)

**Opening:** Maximum Depth of a Binary Tree finds the longest path from root to leaf. DFS: base case (null → 0), recurse on left and right, return max + 1. O(n) time, O(h) space. Classic recursive tree template.

**The basic flow:**
```java
if (root == null) return 0;
return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
```

**The part that trips everyone up:** base case is `null → 0`, and a single node has depth 1 (`max(0,0)+1 = 1`). Also, deep/skewed trees can stack-overflow — use iterative BFS.

**The mistakes to remember:**
- Returning 0 for a single node (should be 1)
- Confusing depth and height conventions
- Stack overflow on skewed trees (use iterative)
- Forgetting the null base case
