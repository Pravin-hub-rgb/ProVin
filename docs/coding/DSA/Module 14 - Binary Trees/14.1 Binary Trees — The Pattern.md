# 14.1 Binary Trees — The Pattern

## What This Problem Is Asking (Simple Terms)

A **binary tree** is a hierarchical data structure where each node has at most two children: left and right. Unlike arrays or linked lists (linear structures), trees are hierarchical/non-linear structures.

Common binary tree operations:
- **Traversal:** Preorder, Inorder, Postorder, Level-order (BFS)
- **Search:** Find if a value exists
- **Insert/Delete:** Add or remove nodes
- **Traversal-specific:** Calculate height, diameter, diameter, check balance, etc.

---

## Example 1

**Input:** `root = [3,9,20,null,null,15,7]`

**Output:** `[3,9,20,null,null,15,7]` (level order traversal)

**Explanation:** Level order traversal: [3], [9,20], [15,7]

## Example 2

## Constraints

- `1 <= nums.length <= 10^4`
- `-100 <= nums[i] <= 100`
- Number of nodes in tree: `[1, 10^4]`

---

## Which Technique, and Why?

Trees are **non-linear** data structures where each node can have multiple children. Binary trees specifically have at most 2 children per node.

**Signal in the problem:** "binary tree," "tree traversal," "tree depth," "lowest common ancestor" → Tree traversal (DFS/BFS).

---

## Approach

**Depth-First Search (DFS):**
- **Preorder:** Root → Left → Right
- **Inorder:** Left → Root → Right
- **Postorder:** Left → Right → Root

**Breadth-First Search (BFS):**
- Level-order traversal using a queue

### Pseudocode (Preorder Traversal)

```
function traverse(node):
    if node is null: return
    visit(node)
    traverse(node.left)
    traverse(node.right)
```

### Java Code (Preorder Traversal)

```java
class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        dfs(root, result);
        return result;
    }
    
    private void dfs(TreeNode node, List<Integer> result) {
        if (node == null) return;
        result.add(node.val);
        dfs(node.left, result);
        dfs(node.right, result);
    }
}
```

### Line-by-line

- `if (node == null) return;` — base case: empty subtree
- `result.add(node.val);` — visit current node (preorder: root first)
- `dfs(node.left, result)` — recursively traverse left subtree
- `dfs(node.right, result);` — recursively traverse right subtree

## Complexity

- Time: O(n) — visit each node once
- Space: O(h) — recursion stack depth, h = tree height

## Common Mistakes

- **Forgetting base case** — `if (node == null) return;` prevents null pointer exceptions
- **Wrong traversal order** — preorder/inorder/postorder visit nodes in different orders
- **Using wrong data structure** — DFS uses recursion/stack, BFS uses queue

---

## How to Explain (interview)

**Opening:** Binary trees are hierarchical data structures where each node has at most 2 children. Tree traversal visits all nodes in a specific order: DFS (preorder/inorder/postorder) or BFS (level order).

**The basic flow:**
```java
void dfs(TreeNode node) {
    if (node == null) return;
    // process node
    dfs(node.left);
    dfs(node.right);
}
```

**The part that trips everyone up:**
- **Recursion base case** — `if (node == null) return;` prevents null pointer exceptions
- **Traversal order** — preorder/inorder/postorder visit nodes in different orders
- **Space complexity** — O(h) recursion stack depth, not O(n)

**The mistakes to remember:**
- Forgetting base case → infinite recursion → StackOverflowError
- Wrong traversal order — preorder/inorder/postorder visit different orders
- Confusing DFS with BFS — DFS uses recursion/stack, BFS uses queue
