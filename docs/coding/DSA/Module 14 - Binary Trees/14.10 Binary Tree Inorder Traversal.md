# 14.10 Binary Tree Inorder Traversal

**Problem:** Given the root of a binary tree, return the inorder traversal (left → root → right). (LeetCode #94)

**Link:** https://leetcode.com/problems/binary-tree-inorder-traversal/

---

## Which Technique, and Why?

Inorder traversal (left → root → right) → **DFS (recursive or iterative with a stack)**. Recursive is simplest. Iterative uses an explicit stack to simulate recursion. O(n) time, O(h) space.

**Signal in the problem:** "inorder traversal" → left, root, right. For BST, this gives sorted order.

## Approach

Recursive: if null, return. Recurse left, record root.val, recurse right.

Iterative: use a stack. Go left as far as possible (pushing nodes). When you can't go left, pop, record, go right.

## Pseudocode (recursive)

```
inorder(node):
    if node == null: return
    inorder(node.left)
    result.add(node.val)
    inorder(node.right)
```

## Java Code (recursive)

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        inorder(root, result);
        return result;
    }

    private void inorder(TreeNode node, List<Integer> result) {
        if (node == null) return;
        inorder(node.left, result);
        result.add(node.val);
        inorder(node.right, result);
    }
}
```

## Java Code (iterative)

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode curr = root;

        while (curr != null || !stack.isEmpty()) {
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;
            }
            curr = stack.pop();
            result.add(curr.val);
            curr = curr.right;
        }
        return result;
    }
}
```

## Line-by-line (iterative)

- `curr` walks left as far as possible, pushing nodes onto the stack.
- When `curr` is null, pop from the stack (the leftmost unvisited node), record its value, then go right.
- `curr != null || !stack.isEmpty()` — continue until both the current pointer and stack are empty.

## Complexity

- Time: O(n) — visit every node once.
- Space: O(h) — recursion stack or explicit stack.

## Common Mistakes

- **Order of operations.** Inorder is left, root, right. Preorder is root, left, right. Postorder is left, right, root. Mixing them up is the #1 error.
- **Not handling null.** `if (node == null) return;` is the base case.
- **Iterative: forgetting to check `!stack.isEmpty()`.** The loop condition must include both `curr != null` and `!stack.isEmpty()`.
- **Confusing with BST sorted order.** Inorder gives sorted order ONLY for a BST. For a general binary tree, it's just a traversal order.

## How to Explain (interview)

**Opening:** Inorder Traversal visits nodes in left → root → right order. Recursive: base case (null), recurse left, record, recurse right. O(n) time, O(h) space. For a BST, inorder gives sorted order. Iterative version uses an explicit stack.

**The basic flow (recursive):**
```java
void inorder(TreeNode node) {
    if (node == null) return;
    inorder(node.left);
    result.add(node.val);
    inorder(node.right);
}
```

**The part that trips everyone up:** the order of the three lines. Inorder = left, root, right. Preorder = root, left, right. Postorder = left, right, root. Memorize the order, not the name.

**The mistakes to remember:**
- Mixing up traversal orders
- Not handling null base case
- Iterative: wrong loop condition (must check both curr and stack)
- Assuming inorder is always sorted (only true for BST)
