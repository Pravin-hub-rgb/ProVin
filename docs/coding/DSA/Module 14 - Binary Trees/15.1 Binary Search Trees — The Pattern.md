# 15.1 Binary Search Trees — The Pattern

## What This Problem Is Asking (Simple Terms)

A **Binary Search Tree (BST)** is a binary tree where each node satisfies the BST property:
- All values in the left subtree are **less than** the node's value
- All values in the right subtree are **greater than** the node's value
- No duplicate values

This property enables efficient search, insert, and delete operations in O(h) time where h is tree height.

---

## Example 1

**Input:** `root = [4,2,7,1,3]`, `val = 2`

**Output:** `[2,1,3]` (the subtree rooted at node with value 2)

**Explanation:** The node with value 2 has left child 1 and right child 3.

---

## Example 2

**Input:** `nums = [4,2,7,1,3]`, `val = 5`

**Output:** `[]`

**Explanation:** Value 5 doesn't exist in the tree.

---

## Constraints

- `1 <= nums.length <= 10^4`
- `-10^5 <= nums[i] <= 10^5`
- All values in BST are unique
- `-10^5 <= target <= 10^5`

---

## Which Technique, and Why?

Binary Search Trees (BST) maintain sorted order through the BST property: left subtree < root < right subtree. This enables O(h) search, insert, and delete operations where h is tree height.

**Signal in the problem:** "sorted," "search," "insert," "delete," "BST," "binary search tree" → Binary Search Tree operations.

---

## Approach

**BST Operations:**
1. **Search:** Compare target with root, go left if smaller, right if larger
2. **Insert:** Find empty spot following BST property, insert new node
3. **Delete:** 3 cases - leaf node, node with 1 child, node with 2 children

### Pseudocode (Search)

```
function search(node, target):
    if node is null or node.val == target: return node
    if target < node.val: return search(node.left, target)
    else: return search(node.right, target)
```

### Java Code (Search in BST)

```java
class Solution {
    public TreeNode searchBST(TreeNode root, int val) {
        if (root == null || root.val == val) return root;
        if (root.val > val) return searchBST(root.left, val);
        return searchBST(root.right, val);
    }
}
```

### Line-by-line

- `if (root == null || root.val == val) return root;` — base case: found target or reached null
- `if (root.val > val) return searchBST(root.left, val);` — target is smaller, go left
- `return searchBST(root.right, val);` — target is greater, go right

## Complexity

- Time: O(h) where h is tree height (O(log n) balanced, O(n) worst case skewed)
- Space: O(h) recursion stack

## Common Mistakes

- **Forgetting BST property** — left < root < right must hold
- **Not handling empty tree** — check root == null first
- **Not returning recursive result** — must return recursive call result

---

## How to Explain (interview)

**Opening:** Binary Search Tree maintains sorted order through BST property: left < root < right. This enables O(h) search, insert, delete operations.

**The basic flow:**
```java
public TreeNode searchBST(TreeNode root, int val) {
    if (root == null || root.val == val) return root;
    if (root.val > val) return searchBST(root.left, val);
    return searchBST(root.right, val);
}
```

**The part that trips everyone up:**
- **BST property** — left < root < right must hold for ALL nodes, not just immediate children
- **Recursion returns** — must return recursive call result to propagate found node up the call stack

**The mistakes to remember:**
- Forgetting base case (root == null)
- Not returning recursive call result
- Violating BST property when inserting/deleting
