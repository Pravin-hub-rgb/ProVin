**Problem:** Given a binary tree, check if it is a mirror of itself (symmetric around its center). (LeetCode #101)

**Link:** https://leetcode.com/problems/symmetric-tree/

---

## Which Technique, and Why?

Check if a tree is symmetric (mirror) → **DFS with two pointers** (compare left subtree with right subtree mirrored). Or convert to "isSameTree(left, right)" where right is checked as mirror. O(n) time, O(h) space.

**Signal in the problem:** "symmetric" / "mirror" → compare left child of one with right child of the other.

## Approach

A tree is symmetric if its left subtree is a mirror of its right subtree. Define a helper `isMirror(left, right)`: both null → true; one null → false; values differ → false; then `isMirror(left.left, right.right) && isMirror(left.right, right.left)` (cross comparison).

## Pseudocode

```
isSymmetric(root):
    if root == null: return true
    return isMirror(root.left, root.right)

isMirror(left, right):
    if left == null and right == null: return true
    if left == null or right == null: return false
    if left.val != right.val: return false
    return isMirror(left.left, right.right) && isMirror(left.right, right.left)
```

## Java Code

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) return true;
        return isMirror(root.left, root.right);
    }

    private boolean isMirror(TreeNode left, TreeNode right) {
        if (left == null && right == null) return true;
        if (left == null || right == null) return false;
        if (left.val != right.val) return false;
        return isMirror(left.left, right.right) && isMirror(left.right, right.left);
    }
}
```

## Line-by-line

- `isSymmetric` delegates to `isMirror(root.left, root.right)`.
- `isMirror`: both null → true; one null → false; values differ → false.
- The key: cross-compare — `left.left` with `right.right`, and `left.right` with `right.left`. This is the "mirror" comparison.

## Complexity

- Time: O(n) — visit every node once.
- Space: O(h) — recursion stack.

## Common Mistakes

- **Comparing left-left with right-left** (same-side comparison). For symmetry, you must cross-compare: left's left with right's right.
- **Not handling null root.** Empty tree is symmetric → true.
- **Using isSameTree directly.** `isSameTree(root.left, root.right)` is wrong — it compares same positions, not mirrored positions. Use the cross-comparison.

## How to Explain (interview)

**Opening:** Symmetric Tree checks if the tree is a mirror of itself. Compare left subtree with right subtree, but cross-compare: left's left with right's right, left's right with right's left. O(n) time, O(h) space.

**The basic flow:**
```java
boolean isMirror(TreeNode l, TreeNode r) {
    if (l == null && r == null) return true;
    if (l == null || r == null) return false;
    if (l.val != r.val) return false;
    return isMirror(l.left, r.right) && isMirror(l.right, r.left);
}
```

**The part that trips everyone up:** the **cross-comparison** — `left.left` with `right.right`, `left.right` with `right.left`. Using `isSameTree(left, right)` (same-side) is wrong.

**The mistakes to remember:**
- Same-side comparison instead of cross (mirror) comparison
- Not handling null root (empty tree is symmetric)
- Confusing with Same Tree (#100) — different comparison
