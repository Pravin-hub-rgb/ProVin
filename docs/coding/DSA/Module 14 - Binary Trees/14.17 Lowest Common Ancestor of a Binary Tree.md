# 14.17 Lowest Common Ancestor of a Binary Tree

**Tier 2 problem.** (LeetCode #236)

**Problem:** Given a binary tree and two nodes p and q, find their lowest common ancestor (LCA). (LeetCode #236)

**Link:** https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/

---

## Which Technique, and Why?

LCA in a **general** binary tree (not BST) → **DFS (post-order)**. The LCA is the node where p and q are in different subtrees (or one is the node itself). Recurse on left and right; if both return non-null, current node is the LCA. O(n) time, O(h) space.

**Signal in the problem:** "LCA of a binary tree" (not BST) → DFS, check both subtrees. (For BST, use the BST property for O(h).)

## Approach

DFS: if node is null → return null. If node == p or node == q → return node. Recurse on left and right. If both non-null → current is LCA. If one non-null → return that. If both null → return null.

## Pseudocode

```
lca(node, p, q):
    if node == null: return null
    if node == p or node == q: return node
    left = lca(node.left, p, q)
    right = lca(node.right, p, q)
    if left != null and right != null: return node  // LCA found
    return (left != null) ? left : right
```

## Java Code

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        if (left != null && right != null) return root;  // LCA found
        return (left != null) ? left : right;
    }
}
```

## Line-by-line

- `root == null` → not found (null).
- `root == p || root == q` → found one of them → return it (it's an ancestor of itself and possibly the other).
- Recurse on left and right.
- Both non-null → p and q are in different subtrees → current node is LCA.
- One non-null → both are in that subtree (or one is the node itself) → return it.
- Both null → neither found → null.

## Complexity

- Time: O(n) — visit every node.
- Space: O(h) — recursion stack.

## Common Mistakes

- **Using BST LCA on a general tree.** BST LCA uses the ordering property (O(h)). General tree LCA checks both subtrees (O(n)).
- **Not handling the case where p or q is an ancestor of the other.** The `root == p || root == q` check handles this.
- **Confusing with "LCA of a BST" (#235).** Different problem — that one uses the BST property.
- **Assuming p and q are distinct.** Problem guarantees distinct nodes.

## How to Explain (interview)

**Opening:** LCA of a Binary Tree finds the lowest common ancestor in a general (non-BST) tree. DFS: if node is p or q, return it. Recurse on both subtrees. If both return non-null, current is LCA. O(n) time, O(h) space. For BST, use the BST property for O(h).

**The basic flow:**
```java
if (root == null || root == p || root == q) return root;
TreeNode left = lca(root.left, p, q);
TreeNode right = lca(root.right, p, q);
if (left != null && right != null) return root;
return (left != null) ? left : right;
```

**The part that trips everyone up:** p or q can be an ancestor of the other — the `root == p || root == q` check handles this. Also, this is the **general** tree LCA (O(n)); for BST, use the BST property (O(h)).

**The mistakes to remember:**
- Using BST LCA on a general tree (wrong algorithm)
- Not handling p/q as ancestor of the other
- Confusing with "LCA of BST" (#235) — different problem
- Assuming p and q are at the same depth
