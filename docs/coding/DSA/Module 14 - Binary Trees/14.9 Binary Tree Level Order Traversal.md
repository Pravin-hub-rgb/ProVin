# 14.9 Binary Tree Level Order Traversal

**Problem:** Given the root of a binary tree, return the level order traversal (left to right, level by level). (LeetCode #102)

**Link:** https://leetcode.com/problems/binary-tree-level-order-traversal/

---

## Which Technique, and Why?

Level-by-level traversal → **BFS (queue)**. Process nodes level by level: for each level, record all nodes, then enqueue their children. O(n) time, O(n) space (queue).

**Signal in the problem:** "level order" / "level by level" / "zigzag" → BFS with a queue. Track level size to separate levels.

## Approach

Queue-based BFS. For each level, record the queue size, process that many nodes (popping and recording), enqueue their children. Each iteration of the outer loop = one level.

## Pseudocode

```
if root == null: return []
result = []
queue = [root]
while queue not empty:
    levelSize = queue.size()
    level = []
    for i from 0 to levelSize-1:
        node = queue.poll()
        level.add(node.val)
        if node.left != null: queue.offer(node.left)
        if node.right != null: queue.offer(node.right)
    result.add(level)
return result
```

## Java Code

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);

        while (!q.isEmpty()) {
            int levelSize = q.size();
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = q.poll();
                level.add(node.val);
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            result.add(level);
        }
        return result;
    }
}
```

## Line-by-line

- `q` holds nodes to process. Start with root.
- `levelSize = q.size()` — snapshot of how many nodes are in the current level.
- Inner loop processes exactly `levelSize` nodes, recording their values and enqueuing children.
- After the inner loop, `q` holds only the next level's nodes.
- `result.add(level)` — one list per level.

## Complexity

- Time: O(n) — visit every node once.
- Space: O(n) — queue holds up to one level (worst case n/2 for a complete tree's last level).

## Common Mistakes

- **Not tracking level size.** Without `levelSize = q.size()` snapshot, you can't separate levels — the inner loop would process the entire queue (all remaining nodes).
- **Using DFS instead of BFS.** DFS can do level-order with a depth parameter, but BFS is more natural and simpler.
- **Null root.** Return empty list, not null.
- **Enqueuing null children.** Check `!= null` before offering, or handle nulls in the loop. The code above checks.

## How to Explain (interview)

**Opening:** Level Order Traversal returns nodes level by level (left to right). BFS with a queue: snapshot the level size, process that many nodes, enqueue their children. Each outer loop iteration = one level. O(n) time, O(n) space.

**The basic flow:**
```java
Queue<TreeNode> q = new ArrayDeque<>();
q.offer(root);
while (!q.isEmpty()) {
    int size = q.size();
    List<Integer> level = new ArrayList<>();
    for (int i = 0; i < size; i++) {
        TreeNode node = q.poll();
        level.add(node.val);
        if (node.left != null) q.offer(node.left);
        if (node.right != null) q.offer(node.right);
    }
    result.add(level);
}
```

**The part that trips everyone up:** snapshot `q.size()` **before** the inner loop. The queue grows during the inner loop (children enqueued), so `q.size()` changes. The snapshot ensures you process exactly one level.

**The mistakes to remember:**
- Not snapshotting level size (processes entire queue as one level)
- Using DFS when BFS is simpler
- Not handling null root
- Enqueuing null children (NPE or extra work)
