# 22.9 Partition Labels

**Tier 2 problem.** (LeetCode #763)

**Problem:** Given a string, partition it into as many parts as possible so that each letter appears in at most one part. Return the sizes of the parts. (LeetCode #763)

**Link:** https://leetcode.com/problems/partition-labels/

---

## Which Technique, and Why?

"Partition into as many parts as possible, each letter in at most one part" → **Greedy**. For each character, record its last occurrence. Walk the string; maintain the furthest last-occurrence seen. When current index reaches the furthest, cut a partition. O(n) time, O(1) space (26 letters).

**Signal in the problem:** "partition labels" / "each letter in at most one part" / "as many parts as possible" → greedy with last-occurrence tracking.

## Approach

1. Record the last occurrence of each character.
2. Walk the string, tracking `end` = furthest last-occurrence seen so far.
3. When `i == end`, cut a partition: size = `end - start + 1`, start = `end + 1`.

## Pseudocode

```
last = array of 26 (last occurrence of each char)
for i from 0 to n-1: last[s[i] - 'a'] = i

start = 0, end = 0, result = []
for i from 0 to n-1:
    end = max(end, last[s[i] - 'a'])
    if i == end:
        result.add(end - start + 1)
        start = end + 1
return result
```

## Java Code

```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        List<Integer> result = new ArrayList<>();
        int start = 0, end = 0;
        for (int i = 0; i < s.length(); i++) {
            end = Math.max(end, last[s.charAt(i) - 'a']);
            if (i == end) {
                result.add(end - start + 1);
                start = end + 1;
            }
        }
        return result;
    }
}
```

## Line-by-line

- `last[c]` = the last index where character `c` appears.
- `end = max(end, last[s[i]])` — extend the partition boundary to include the last occurrence of the current char.
- `if (i == end)` — we've reached the furthest boundary → cut a partition. Size = `end - start + 1`. Reset `start`.
- The greedy choice: extend the partition as little as possible (cut as soon as `i == end`).

## Complexity

- Time: O(n) — two passes.
- Space: O(1) — array of 26 (or O(n) for the result).

## Common Mistakes

- **Not updating `end` with `max`.** `end = max(end, last[s[i]])` — you must extend to the furthest last-occurrence seen so far, not just the current char's last occurrence.
- **Cutting too early.** Only cut when `i == end`. If you cut earlier, a letter might appear in two parts.
- **Using a HashMap instead of an array.** Array of 26 is simpler and faster for lowercase letters.
- **Off-by-one in size.** Size = `end - start + 1`, not `end - start`.
