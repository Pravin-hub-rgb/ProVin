**Problem:** You have boxes with (units per box, count). A truck has a capacity (max boxes). Maximize total units loaded, choosing boxes with the most units first. (LeetCode #1710)

**Link:** https://leetcode.com/problems/maximum-units-on-a-truck/

---

## Which Technique, and Why?

Maximize units loaded with limited capacity → **Greedy (sort by units descending, take as many as possible)**. Sort box types by units per box (descending), then greedily take boxes from the highest-unit type until capacity is full. O(n log n) time, O(1) space.

**Signal in the problem:** "maximize units" + "limited capacity" + "choose boxes" → sort by value per unit, take greedily.

## Approach

Sort `boxTypes` by units per box (descending). Iterate: take `min(count, remaining capacity)` boxes from each type, add `taken * units` to total. Stop when capacity is full.

## Pseudocode

```
sort boxTypes by units (descending)
total = 0, remaining = truckSize
for each (units, count) in boxTypes:
    take = min(count, remaining)
    total += take * units
    remaining -= take
    if remaining == 0: break
return total
```

## Java Code

```java
class Solution {
    public int maximumUnits(int[][] boxTypes, int truckSize) {
        // Sort by units per box (descending)
        Arrays.sort(boxTypes, (a, b) -> b[1] - a[1]);

        int total = 0, remaining = truckSize;
        for (int[] box : boxTypes) {
            int count = box[0];
            int units = box[1];
            int take = Math.min(count, remaining);
            total += take * units;
            remaining -= take;
            if (remaining == 0) break;
        }
        return total;
    }
}
```

## Line-by-line

- `Arrays.sort(boxTypes, (a, b) -> b[1] - a[1])` — sort by units (column 1) descending. (Use `Integer.compare` for safety, but values are small here.)
- `take = min(count, remaining)` — take as many as possible from this type.
- `total += take * units` — add units.
- `remaining -= take` — reduce capacity.
- `if (remaining == 0) break` — truck is full, stop.

## Complexity

- Time: O(n log n) — sorting dominates.
- Space: O(1) extra (sorting may use O(log n) stack).

## Common Mistakes

- **Sorting ascending instead of descending.** You want the highest-unit boxes first. Sort descending.
- **Comparator overflow.** `b[1] - a[1]` can overflow for large values. Use `Integer.compare(b[1], a[1])` for safety.
- **Not breaking when remaining == 0.** Without the break, you'd keep iterating (harmless but wasteful).
- **Confusing count and units.** `box[0]` = number of boxes, `box[1]` = units per box. Swap them and you get wrong answers.

**The basic flow:**
