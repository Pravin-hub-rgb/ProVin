**Problem:** Given a non-empty array where every element appears twice except one, find the single one. (LeetCode #136)

**Link:** https://leetcode.com/problems/single-number/

---

## Which Technique, and Why?

Every element appears twice except one → **XOR**. XOR all elements: pairs cancel (`a ^ a = 0`), leaving only the single element (`0 ^ single = single`). O(n) time, O(1) space. No hash map needed.

**Signal in the problem:** "every element appears twice except one" / "single number" → XOR all elements.

## Approach

XOR all elements. Pairs cancel, single remains.

## Pseudocode

```
result = 0
for each x in nums:
    result ^= x
return result
```

## Java Code

```java
class Solution {
    public int singleNumber(int[] nums) {
        int result = 0;
        for (int x : nums) {
            result ^= x;
        }
        return result;
    }
}
```

## Line-by-line

- `result` starts at 0 (XOR identity: `0 ^ x = x`).
- XOR all elements. Pairs cancel (`a ^ a = 0`). Single remains (`0 ^ single = single`).
- O(n) time, O(1) space.

## Complexity

- Time: O(n) — single pass.
- Space: O(1) — one variable.

## Common Mistakes

- **Using a hash set** — works but O(n) space. XOR gives O(1) space.
- **Assuming the array is sorted.** It's not. XOR works regardless of order (commutative/associative).
- **Not handling negative numbers.** XOR works on the binary representation, including two's complement for negatives. Fine.

## How to Explain (interview)

**Opening:** Single Number finds the element that appears once when all others appear twice. XOR all elements: pairs cancel (`a ^ a = 0`), leaving only the single one (`0 ^ single = single`). O(n) time, O(1) space — no hash map needed.

**The basic flow:**
```java
int result = 0;
for (int x : nums) result ^= x;
return result;
```

**The part that trips everyone up:** XOR is commutative and associative, so order doesn't matter. `a ^ a = 0` (cancels pairs), `0 ^ a = a` (identity). The answer is the XOR of all elements.

**The mistakes to remember:**
- Using a hash set (O(n) space) when XOR gives O(1)
- Assuming the array is sorted (XOR doesn't need sorting)
- Not understanding why XOR works (pairs cancel)
