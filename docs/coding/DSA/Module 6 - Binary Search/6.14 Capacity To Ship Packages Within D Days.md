**Tier 2 problem.** (LeetCode #1011)

**Problem:** Given weights of packages and D days, find the minimum ship capacity such that all packages are shipped within D days (in order). (LeetCode #1011)

**Link:** https://leetcode.com/problems/capacity-to-ship-packages-within-d-days/

---

## Which Technique, and Why?

"Minimum capacity to ship within D days" → **Binary Search on Answer**. The answer (capacity) lies in [max(weights), sum(weights)]. For a candidate capacity, check if all packages can be shipped in D days (greedy: load as much as possible per day without exceeding capacity). Feasibility is monotonic. O(n log(sum)) time.

**Signal in the problem:** "minimum capacity" / "within D days" / "ship packages" → binary search on answer + greedy feasibility.

## Approach

Binary search on [maxWeight, totalWeight]. For candidate mid (capacity), greedily load packages: add to current day until exceeding mid, then start a new day. If days needed ≤ D → feasible → try smaller. Else → need bigger.

## Pseudocode

```
left = max(weights), right = sum(weights)
while left <= right:
    mid = left + (right - left) / 2
    days = 1, currentLoad = 0
    for w in weights:
        if currentLoad + w > mid:
            days++
            currentLoad = 0
        currentLoad += w
    if days <= D:
        answer = mid
        right = mid - 1
    else:
        left = mid + 1
return answer
```

## Java Code

```java
class Solution {
    public int shipWithinDays(int[] weights, int days) {
        int left = 0, right = 0;
        for (int w : weights) {
            left = Math.max(left, w);
            right += w;
        }

        int answer = right;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            int d = 1, load = 0;
            for (int w : weights) {
                if (load + w > mid) {
                    d++;
                    load = 0;
                }
                load += w;
            }
            if (d <= days) {
                answer = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return answer;
    }
}
```

## Line-by-line

- `left = max(weights)` — capacity must be at least the heaviest package.
- `right = sum(weights)` — capacity = total weight ships in 1 day.
- For candidate `mid`: greedily load packages. If adding a package exceeds capacity, start a new day.
- `d <= days` → feasible → try smaller capacity. Else → need bigger.

## Complexity

- Time: O(n log(sum)) — n packages, log(sum) binary search steps.
- Space: O(1).

## Common Mistakes

- **Wrong bounds.** `left = max(weights)` (not 1 or 0), `right = sum(weights)` (not max × n).
- **Greedy loading wrong.** You must load packages in order (can't reorder). Greedy: add to current day until exceeding capacity, then new day.
- **Not tracking answer.** When feasible, record `answer = mid` and search lower. Don't return immediately.
- **Off-by-one in the feasibility check.** `if (load + w > mid)` — start a new day when adding would exceed. Not `>=` (equal is fine).

## How to Explain (interview)

**Opening:** Capacity to Ship Packages finds the minimum ship capacity to ship all packages in D days. Binary search on answer [maxWeight, sumWeights]. Feasibility check: greedily load packages in order, starting a new day when capacity would be exceeded. O(n log(sum)) time, O(1) space.

**The basic flow:**
```java
int left = max(weights), right = sum(weights), answer = right;
while (left <= right) {
    int mid = left + (right - left) / 2;
    int days = 1, load = 0;
    for (int w : weights) {
        if (load + w > mid) { days++; load = 0; }
        load += w;
    }
    if (days <= D) { answer = mid; right = mid - 1; }
    else left = mid + 1;
}
```

**The part that trips everyone up:** packages must be shipped **in order** (can't reorder). The greedy loading is: add to current day until exceeding capacity, then new day. Also, `left = max(weights)` (capacity must fit the heaviest package).

**The mistakes to remember:**
- Wrong bounds (left = 0 or 1, right = max × n)
- Reordering packages (must ship in given order)
- Using `>=` instead of `>` in the capacity check (equal is fine)
- Not tracking the answer (returning immediately)
