**Tier 2 problem.** (LeetCode #240)

**Problem:** Given an m×n matrix where each row is sorted left-to-right and each column is sorted top-to-bottom, determine if target exists. (LeetCode #240)

**Link:** https://leetcode.com/problems/search-a-2d-matrix-ii/

---

## Which Technique, and Why?

"Sorted rows AND columns" (not the "first of row > last of prev row" property of #74) → **Start from top-right** (or bottom-left). If target < current, move left (eliminate column). If target > current, move down (eliminate row). O(m + n) time, O(1) space.

**Signal in the problem:** "each row sorted AND each column sorted" (but NOT "first of row > last of prev row") → start top-right, move left/down. (Different from #74 which treats the matrix as 1D.)

## Approach

Start at top-right corner. If target == current → found. If target < current → move left (eliminate the column, all elements below are ≥ current > target). If target > current → move down (eliminate the row, all elements to the left are ≤ current < target).

## Pseudocode

```
row = 0, col = n - 1
while row < m and col >= 0:
    if matrix[row][col] == target: return true
    if matrix[row][col] > target: col--
    else: row++
return false
```

## Java Code

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return false;

        int row = 0, col = matrix[0].length - 1;

        while (row < matrix.length && col >= 0) {
            if (matrix[row][col] == target) return true;
            if (matrix[row][col] > target) col--;
            else row++;
        }
        return false;
    }
}
```

## Line-by-line

- Start at top-right: `row = 0, col = n - 1`.
- `matrix[row][col] == target` → found.
- `matrix[row][col] > target` → target is smaller → move left (eliminate this column; all elements below are ≥ current).
- `matrix[row][col] < target` → target is larger → move down (eliminate this row; all elements to the left are ≤ current).
- Each step eliminates one row or one column → O(m + n) total.

## Complexity

- Time: O(m + n) — each step eliminates one row or column.
- Space: O(1).

## Common Mistakes

- **Using #74's approach (treat as 1D).** #74 requires "first of row > last of prev row" (fully sorted when flattened). #240 only has sorted rows and columns independently — 1D binary search doesn't work.
- **Starting from top-left.** From top-left, you can't decide which direction to go (both right and down are larger). Start from top-right (or bottom-left).
- **Not handling empty matrix.** Check `matrix.length == 0 || matrix[0].length == 0`.
- **Infinite loop.** Ensure `col--` or `row++` happens on every non-match iteration.

**Opening:** Search a 2D Matrix II searches a matrix where rows and columns are independently sorted (not the "flattened sorted" property of #74). Start at top-right: if target < current, move left (eliminate column); if target > current, move down (eliminate row). Each step eliminates one row or column → O(m+n) time, O(1) space.
