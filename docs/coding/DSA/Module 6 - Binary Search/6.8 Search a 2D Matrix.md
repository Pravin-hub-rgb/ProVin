# 6.8 Search a 2D Matrix

**Problem:** Given an m×n matrix where each row is sorted and the first element of each row is greater than the last element of the previous row, determine if a target exists. (LeetCode #74)

**Link:** https://leetcode.com/problems/search-a-2d-matrix/

---

## Which Technique, and Why?

The matrix is "sorted" in a flattened sense: rows are sorted, and each row's first element > previous row's last element. This means the entire matrix is sorted if you read it row by row. Two approaches:

1. **Treat as 1D array:** binary search on the flattened index. Map index `mid` to `matrix[mid / n][mid % n]`. O(log(m×n)) time.
2. **Two binary searches:** first find the row (by comparing target with row boundaries), then search within that row. O(log m + log n).

Both are O(log(m×n)). The first is simpler.

**Signal in the problem:** "sorted 2D matrix" / "each row sorted, first of row > last of prev row" → binary search (treat as 1D or two-step).

## Approach (1D binary search)

Treat the matrix as a 1D sorted array of size m×n. Binary search on index [0, m×n-1]. Convert index to (row, col): `row = mid / n`, `col = mid % n`.

## Pseudocode

```
m = matrix.length, n = matrix[0].length
left = 0, right = m * n - 1
while left <= right:
    mid = left + (right - left) / 2
    row = mid / n, col = mid % n
    if matrix[row][col] == target: return true
    if matrix[row][col] < target: left = mid + 1
    else: right = mid - 1
return false
```

## Java Code

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length;
        int n = matrix[0].length;
        int left = 0, right = m * n - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            int row = mid / n;
            int col = mid % n;
            if (matrix[row][col] == target) return true;
            if (matrix[row][col] < target) left = mid + 1;
            else right = mid - 1;
        }
        return false;
    }
}
```

## Line-by-line

- `m * n - 1` — total elements minus 1 (last index of the flattened array).
- `row = mid / n` — integer division gives the row (since each row has n elements).
- `col = mid % n` — remainder gives the column within the row.
- Standard binary search from there.

## Complexity

- Time: O(log(m×n)) — binary search over m×n elements.
- Space: O(1).

## Common Mistakes

- **Using `matrix[0].length` when matrix is empty.** Check `matrix.length == 0 || matrix[0].length == 0` first.
- **Wrong index conversion.** `row = mid / n` and `col = mid % n` (not `mid / m` and `mid % m`). n is the number of columns.
- **Overflow in `m * n`.** For very large matrices, `m * n` can overflow int. Use `long` if needed (LeetCode constraints are small enough for int).
- **Confusing with "Search a 2D Matrix II"** (LeetCode #240) — that matrix has sorted rows and columns but NOT the "first of row > last of prev row" property. Different problem: start from top-right, move left/down. O(m+n).

## How to Explain (interview)

**Opening:** Search a 2D Matrix searches a matrix where each row is sorted and each row's first element exceeds the previous row's last. This means the matrix is sorted if read row-by-row. Treat it as a 1D sorted array of size m×n and binary search. Convert index to (row, col) with `row = mid / n`, `col = mid % n`. O(log(m×n)) time, O(1) space.

**The basic flow:**
```java
int left = 0, right = m * n - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    int val = matrix[mid / n][mid % n];
    if (val == target) return true;
    if (val < target) left = mid + 1;
    else right = mid - 1;
}
return false;
```

**The part that trips everyone up:** the index conversion `row = mid / n`, `col = mid % n` (n = number of columns). Also distinguish from "Search a 2D Matrix II" (#240) where rows and columns are sorted independently — different algorithm (start top-right).

**The mistakes to remember:**
- `mid / m` instead of `mid / n` (swapping rows/cols)
- Not handling empty matrix
- Confusing with Matrix II (#240) — different structure, different algorithm
