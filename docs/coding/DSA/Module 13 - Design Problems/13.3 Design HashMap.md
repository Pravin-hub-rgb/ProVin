**Problem:** Design a HashMap without using any built-in hash table libraries. (LeetCode #706)

**Link:** https://leetcode.com/problems/design-hashmap/

---

## Which Technique, and Why?

Implement a hash map from scratch → **array of buckets + chaining** (or open addressing). Each bucket is a list of (key, value) pairs. Hash function maps key → bucket index. O(1) average for put/get/remove, O(n) worst case (all keys in one bucket).

**Signal in the problem:** "design a hash map" / "implement hash map" → array of buckets + linked list (chaining) or array (open addressing).

## Approach

Use an array of size 10000 (or a prime). Hash function: `key % capacity`. Each bucket is a `LinkedList<int[]>` (key, value pairs). `put`: find bucket, update if key exists, else append. `get`: find bucket, search for key. `remove`: find bucket, remove the pair.

## Pseudocode

```
buckets = array of LinkedList (size 10000)
hash(key) = key % 10000

put(key, value):
    bucket = buckets[hash(key)]
    for pair in bucket:
        if pair[0] == key: pair[1] = value; return
    bucket.add({key, value})

get(key):
    bucket = buckets[hash(key)]
    for pair in bucket:
        if pair[0] == key: return pair[1]
    return -1

remove(key):
    bucket = buckets[hash(key)]
    for pair in bucket:
        if pair[0] == key: bucket.remove(pair); return
```

## Java Code

```java
class MyHashMap {
    private static final int SIZE = 10000;
    private final LinkedList<int[]>[] buckets;

    public MyHashMap() {
        buckets = new LinkedList[SIZE];
        for (int i = 0; i < SIZE; i++) buckets[i] = new LinkedList<>();
    }

    private int hash(int key) {
        return key % SIZE;
    }

    public void put(int key, int value) {
        int idx = hash(key);
        for (int[] pair : buckets[idx]) {
            if (pair[0] == key) {
                pair[1] = value;
                return;
            }
        }
        buckets[idx].add(new int[]{key, value});
    }

    public int get(int key) {
        int idx = hash(key);
        for (int[] pair : buckets[idx]) {
            if (pair[0] == key) return pair[1];
        }
        return -1;
    }

    public void remove(int key) {
        int idx = hash(key);
        Iterator<int[]> it = buckets[idx].iterator();
        while (it.hasNext()) {
            if (it.next()[0] == key) {
                it.remove();
                return;
            }
        }
    }
}
```

## Line-by-line

- `buckets` — array of LinkedLists. Each bucket holds key-value pairs that hash to the same index.
- `hash(key) = key % SIZE` — simple hash function. SIZE = 10000 (a prime would be better, but 10000 is fine for this problem's constraints).
- `put`: find bucket, update value if key exists, else append new pair.
- `get`: find bucket, search for key, return value or -1.
- `remove`: find bucket, remove the pair with matching key. Uses Iterator to safely remove during iteration.

## Complexity

- Time: O(1) average (good hash distribution), O(n) worst case (all keys in one bucket).
- Space: O(n) — stores all key-value pairs.

## Common Mistakes

- **Not handling collisions.** Two keys can hash to the same bucket. Use chaining (list per bucket) or open addressing.
- **Using `buckets[idx].remove(pair)` directly.** Removing during enhanced for-loop throws `ConcurrentModificationException`. Use an Iterator.
- **Wrong hash function.** `key % SIZE` works but can cause clustering if keys are multiples of SIZE. A better hash: `(key * 31) % SIZE` or use a prime SIZE.
- **Not initializing buckets.** `new LinkedList[SIZE]` creates null references. Initialize each bucket in the constructor.
