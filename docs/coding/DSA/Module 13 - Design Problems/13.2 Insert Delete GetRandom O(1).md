# 13.2 Insert Delete GetRandom O(1)

**Problem:** Design a data structure that supports insert, remove, and getRandom (uniform random) in O(1) average time. (LeetCode #380)

**Link:** https://leetcode.com/problems/insert-delete-getrandom-o1/

---

## Which Technique, and Why?

You need O(1) insert, O(1) delete, and O(1) random access. A single ArrayList gives O(1) insert and O(1) random access but O(n) delete (shifting). A single HashSet gives O(1) insert/delete but O(n) random access. **Combine both:** ArrayList for O(1) random access + HashMap (value → index in the list) for O(1) delete. On delete, swap the target with the last element, then pop — O(1).

**Signal in the problem:** "O(1) insert, delete, getRandom" → ArrayList + HashMap (value → index). The swap-and-pop trick for O(1) delete.

## Approach

- `insert(val)`: if already present → false. Else append to list, record index in map → true.
- `remove(val)`: if not present → false. Else swap with last element (update map for the swapped element), pop last, remove from map → true.
- `getRandom()`: pick a random index in [0, size-1], return list.get(index).

## Pseudocode

```
insert(val):
    if map contains val: return false
    map[val] = list.size()
    list.add(val)
    return true

remove(val):
    if !map contains val: return false
    idx = map[val]
    last = list.get(list.size()-1)
    list.set(idx, last)        // swap with last
    map[last] = idx            // update last's index
    list.remove(list.size()-1) // pop last
    map.remove(val)
    return true

getRandom():
    return list.get(random.nextInt(list.size()))
```

## Java Code

```java
class RandomizedSet {
    private final List<Integer> list;
    private final Map<Integer, Integer> indexMap;
    private final Random rand;

    public RandomizedSet() {
        list = new ArrayList<>();
        indexMap = new HashMap<>();
        rand = new Random();
    }

    public boolean insert(int val) {
        if (indexMap.containsKey(val)) return false;
        indexMap.put(val, list.size());
        list.add(val);
        return true;
    }

    public boolean remove(int val) {
        if (!indexMap.containsKey(val)) return false;
        int idx = indexMap.get(val);
        int last = list.get(list.size() - 1);
        list.set(idx, last);
        indexMap.put(last, idx);
        list.remove(list.size() - 1);
        indexMap.remove(val);
        return true;
    }

    public int getRandom() {
        return list.get(rand.nextInt(list.size()));
    }
}
```

## Line-by-line

- `list` holds values; `indexMap` maps value → its index in `list`.
- `insert`: record index, append. O(1) amortized.
- `remove`: get index of val. Swap with last element (O(1) set). Update last's index in map. Pop last (O(1) amortized). Remove val from map. O(1) average.
- `getRandom`: random index into list → O(1).

## Complexity

- Time: O(1) average for insert, remove, getRandom.
- Space: O(n) — list + map.

## Common Mistakes

- **Not updating the swapped element's index.** After swapping, `last` is now at `idx` — you must update `indexMap[last] = idx`. Forgetting this breaks future removes.
- **Using `list.remove(idx)` directly.** That's O(n) (shifts elements). The swap-and-pop trick makes it O(1).
- **Not checking existence before insert/remove.** `insert` returns false if already present; `remove` returns false if absent. Handle these.
- **Random on empty list.** Problem guarantees getRandom is called on non-empty set. But defensive code checks `list.size() > 0`.

## How to Explain (interview)

**Opening:** Insert Delete GetRandom O(1) combines an ArrayList (O(1) random access) with a HashMap (value → index, O(1) lookup). Insert: append + record index. Remove: swap with last element, pop last, update map — O(1) instead of O(n) shift. getRandom: random index into list. O(1) average all operations.

**The basic flow:**
```java
// insert: map.put(val, list.size()); list.add(val);
// remove: swap with last, pop, update map
// getRandom: list.get(random.nextInt(list.size()))
```

**The part that trips everyone up:** the **swap-and-pop** trick for O(1) delete. After swapping, update the swapped element's index in the map. Forgetting this breaks future operations.

**The mistakes to remember:**
- Not updating the swapped element's index (silent bugs)
- Using `list.remove(idx)` (O(n) instead of O(1))
- Not checking existence before insert/remove
- Confusing with Design HashMap (different problem)
