# 15.8 Validate Binary Search Tree

**Tier 2 problem.** (LeetCode #98)

**Problem:** Given the root of a binary tree, determine if it is a valid BST. (LeetCode #98)

**Link:** https://leetcode.com/problems/validate-binary-search-tree/

---

## Which Technique, and Why?

"Validate BST" → **DFS with min/max bounds**. A BST requires that ALL nodes in the left subtree are < root.val and ALL in the right subtree are > root.val. Just checking `left.val < root.val < right.val` is insufficient. Pass bounds down: `isValid(node, min, max)` checks `min < node.val < max`, then recurses with updated bounds. O(n) time, O(h) space.

**Signal in the problem:** "validate BST" / "is it a BST" → DFS with min/max bounds (not just direct children).

## Approach

DFS with bounds. `isValid(node, min, max)`: if null → true. If `node.val <= min || node.val >= max` → false. Recurse left with `(min, node.val)`, right with `(node.val, max)`.

## Pseudocode

```
isValid(node, min, max):
    if node == null: return true
    if node.val <= min or node.val >= max: return false
    return isValid(node.left, min, node.val) and isValid(node.right, node.val, max)
```

## Java Code

```java
class Solution {
    public boolean isValidBST(TreeNode root) {
        return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean isValid(TreeNode node, long min, long max) {
        if (node == null) return true;
        if (node.val <= min || node.val >= max) return false;
        return isValid(node.left, min, node.val) && isValid(node.right, node.val, max);
    }
}
```

## Line-by-line

- `isValid(root, Long.MIN_VALUE, Long.MAX_VALUE)` — initial bounds (no constraint).
- `node.val <= min || node.val >= max` — violated BST property → false.
- Left subtree: `max = node.val` (all must be < node.val).
- Right subtree: `min = node.val` (all must be > node.val).
- Use `long` for bounds to handle `Integer.MIN_VALUE` / `Integer.MAX_VALUE` in the tree.

## Complexity

- Time: O(n) — visit every node once.
- Space: O(h) — recursion stack.

## Common Mistakes

- **Only checking direct children.** `left.val < root.val < right.val` is necessary but not sufficient. The entire left subtree must be < root.val. Use bounds.
- **Using int for bounds.** If a node has value `Integer.MAX_VALUE`, the bound `max = node.val` would be `Integer.MAX_VALUE`, and a right child with value `Integer.MAX_VALUE` would pass `node.val < max` (false, since not strictly less). Use `long` for bounds.
- **Inorder approach.** Inorder of a BST is sorted. Check if inorder is strictly increasing. O(n) time, O(n) space (or O(1) with Morris traversal). Works but less direct.
- **Not handling null.** `node == null` → true (empty subtree is valid).

## How to Explain (interview)

**Opening:** Validate BST checks if a tree is a valid BST. The BST property applies to the entire subtree, not just direct children. DFS with min/max bounds: `isValid(node, min, max)` checks `min < node.val < max`, then recurses with updated bounds. O(n) time, O(h) space.

**The basic flow:**
```java
boolean isValid(TreeNode node, long min, long max) {
    if (node == null) return true;
    if (node.val <= min || node.val >= max) return false;
    return isValid(node.left, min, node.val) && isValid(node.right, node.val, max);
}
```

**The part that trips everyone up:** use **bounds**, not just direct children. `left.val < root.val < right.val` is necessary but not sufficient. Also, use `long` for bounds to handle `Integer.MAX_VALUE`/`MIN_VALUE`.

**The mistakes to remember:**
- Only checking direct children (not sufficient)
- Using int for bounds (overflow on MAX_VALUE/MIN_VALUE)
- Not handling null
- Confusing with "Validate Binary Tree" (different problem)
