# 15.6 Two Sum IV - Input is a BST

**Problem:** Given the root of a BST and a target, return true if there exist two elements in the BST that sum to target. (LeetCode #653)

**Link:** https://leetcode.com/problems/two-sum-iv-input-is-a-bst/

---

## Which Technique, and Why?

Two elements in a BST summing to target → **BST inorder (sorted) + two pointers**, or **DFS + HashSet**. The BST property gives you sorted order via inorder traversal, then two pointers finds the pair in O(n). Alternatively, DFS with a set is O(n) time, O(n) space — simpler.

**Signal in the problem:** "two sum" + "BST" → inorder gives sorted array, then two pointers (O(n) time, O(n) space) OR DFS + set (O(n) time, O(n) space).

## Approach (DFS + HashSet — simplest)

DFS through the tree. For each node, check if `target - node.val` is in the set. If yes → true. Otherwise add `node.val` to the set and recurse on children.

## Pseudocode

```
set = empty
dfs(node):
    if node == null: return false
    if (target - node.val) in set: return true
    set.add(node.val)
    return dfs(node.left) or dfs(node.right)
```

## Java Code (DFS + HashSet)

```java
class Solution {
    public boolean findTarget(TreeNode root, int k) {
        Set<Integer> seen = new HashSet<>();
        return dfs(root, k, seen);
    }

    private boolean dfs(TreeNode node, int k, Set<Integer> seen) {
        if (node == null) return false;
        if (seen.contains(k - node.val)) return true;
        seen.add(node.val);
        return dfs(node.left, k, seen) || dfs(node.right, k, seen);
    }
}
```

## Approach (Inorder + Two Pointers)

Inorder traversal gives a sorted array. Then use two pointers (one at each end) to find a pair summing to k. O(n) time, O(n) space.

## Java Code (Inorder + Two Pointers)

```java
class Solution {
    public boolean findTarget(TreeNode root, int k) {
        List<Integer> inorder = new ArrayList<>();
        inorder(root, inorder);

        int left = 0, right = inorder.size() - 1;
        while (left < right) {
            int sum = inorder.get(left) + inorder.get(right);
            if (sum == k) return true;
            if (sum < k) left++;
            else right--;
        }
        return false;
    }

    private void inorder(TreeNode node, List<Integer> list) {
        if (node == null) return;
        inorder(node.left, list);
        list.add(node.val);
        inorder(node.right, list);
    }
}
```

## Line-by-line (DFS + HashSet)

- `seen` stores values encountered so far.
- For each node: if `k - node.val` is in `seen`, we found a pair → return true.
- Otherwise, add `node.val` to `seen` and recurse on children.
- Short-circuit: `||` stops as soon as a match is found.

## Complexity

- DFS + HashSet: O(n) time, O(n) space.
- Inorder + Two Pointers: O(n) time, O(n) space (for the list).

## Common Mistakes

- **Using the same node twice.** `seen.contains(k - node.val)` checks before adding `node.val`, so a node can't pair with itself. Correct.
- **Assuming the BST is balanced.** Both approaches are O(n) regardless of balance — the BST property isn't strictly needed for correctness (but inorder gives sorted order, enabling two pointers).
- **Not short-circuiting.** Use `||` to stop early when a match is found.
- **Confusing with "Two Sum" (#1) on an array.** Same idea, different input (BST instead of array).

## How to Explain (interview)

**Opening:** Two Sum IV checks if two elements in a BST sum to a target. Two approaches: (1) DFS + HashSet — walk the tree, for each node check if complement is in the set, add current value. O(n) time, O(n) space. (2) Inorder traversal gives a sorted array, then two pointers. Both O(n). The DFS+set approach is simpler and doesn't need the BST property for correctness.

**The basic flow (DFS + set):**
```java
Set<Integer> seen = new HashSet<>();
boolean dfs(TreeNode node, int k) {
    if (node == null) return false;
    if (seen.contains(k - node.val)) return true;
    seen.add(node.val);
    return dfs(node.left, k) || dfs(node.right, k);
}
```

**The part that trips everyone up:** check `seen.contains(k - node.val)` **before** adding `node.val` — this prevents a node from pairing with itself. Also, the BST property isn't strictly needed for the DFS+set approach (it works on any tree).

**The mistakes to remember:**
- Adding node.val before checking (node pairs with itself)
- Not short-circuiting (wasted work)
- Confusing with Two Sum on array (same idea, different input)
