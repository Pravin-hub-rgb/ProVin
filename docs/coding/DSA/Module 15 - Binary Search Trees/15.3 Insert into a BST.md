**Problem:** Given the root of a BST and a value, insert the value into the BST and return the root. (LeetCode #701)

**Link:** https://leetcode.com/problems/insert-into-a-binary-search-tree/

---

## Which Technique, and Why?

Insert into a BST → **BST search for the position, then insert as a leaf.** O(h) time, O(h) space (recursion) or O(1) (iterative). The new node is always inserted as a leaf (no rebalancing in a basic BST).

**Signal in the problem:** "insert into a BST" → search for the position, insert as leaf. O(h) time.

## Approach

Recursive: if root is null, return new node. If val < root.val, recurse on left and set root.left. Else recurse on right and set root.right. Return root.

## Pseudocode

```
if root == null: return new TreeNode(val)
if val < root.val: root.left = insert(root.left, val)
else: root.right = insert(root.right, val)
return root
```

## Java Code

```java
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if (root == null) return new TreeNode(val);
        if (val < root.val) {
            root.left = insertIntoBST(root.left, val);
        } else {
            root.right = insertIntoBST(root.right, val);
        }
        return root;
    }
}
```

## Iterative version

```java
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if (root == null) return new TreeNode(val);

        TreeNode curr = root;
        while (true) {
            if (val < curr.val) {
                if (curr.left == null) {
                    curr.left = new TreeNode(val);
                    break;
                }
                curr = curr.left;
            } else {
                if (curr.right == null) {
                    curr.right = new TreeNode(val);
                    break;
                }
                curr = curr.right;
            }
        }
        return root;
    }
}
```

## Line-by-line

- Recursive: base case `root == null` → return new node. Otherwise, go left or right based on comparison, and set the child.
- The new node is always a leaf (inserted at the bottom).
- Return root (the tree structure is modified in place, but we return the root for convenience).

## Complexity

- Time: O(h) — search for the position. O(log n) balanced, O(n) skewed.
- Space: O(h) recursive, O(1) iterative.

## Common Mistakes

- **Not handling empty tree.** `root == null` → return new node (the new root).
- **Returning the new node instead of root.** Return `root` (the original root), not the inserted node.
- **Inserting in the wrong subtree.** `val < root.val` → left, `val > root.val` → right. Don't swap.
- **Assuming balanced.** Insertion doesn't rebalance — a BST can become skewed. If balance matters, use AVL/Red-Black (not in this course).

**Opening:** Insert into a BST adds a value as a leaf. Search for the position using the BST property (go left if smaller, right if larger), then insert at the first null. O(h) time, O(h) space (recursive) or O(1) (iterative). The tree is modified in place.

**The basic flow:**
```java
if (root == null) return new TreeNode(val);
if (val < root.val) root.left = insertIntoBST(root.left, val);
else root.right = insertIntoBST(root.right, val);
return root;
```

**The part that trips everyone up:** return `root`, not the new node. Also, insertion doesn't rebalance — the tree can become skewed.

**The mistakes to remember:**
- Returning the new node instead of root
- Inserting in the wrong subtree
- Not handling empty tree (root == null)
- Assuming the tree stays balanced (it doesn't)
