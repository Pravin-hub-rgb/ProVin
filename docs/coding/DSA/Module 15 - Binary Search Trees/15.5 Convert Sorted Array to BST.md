# 15.5 Convert Sorted Array to BST

**Problem:** Given a sorted array, convert it to a height-balanced BST. (LeetCode #108)

**Link:** https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/

---

## Which Technique, and Why?

Sorted array → balanced BST → **divide and conquer**. The middle element becomes the root; left half becomes left subtree, right half becomes right subtree. Recursively. O(n) time, O(log n) space (recursion stack).

**Signal in the problem:** "sorted array to BST" / "height-balanced BST" → pick middle as root, recurse on halves.

## Approach

If the array is empty, return null. Find mid = (left + right) / 2. Create node with nums[mid]. Recurse on left half [left, mid-1] and right half [mid+1, right].

## Pseudocode

```
build(nums, left, right):
    if left > right: return null
    mid = left + (right - left) / 2
    node = new TreeNode(nums[mid])
    node.left = build(nums, left, mid - 1)
    node.right = build(nums, mid + 1, right)
    return node
```

## Java Code

```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    private TreeNode build(int[] nums, int left, int right) {
        if (left > right) return null;
        int mid = left + (right - left) / 2;
        TreeNode node = new TreeNode(nums[mid]);
        node.left = build(nums, left, mid - 1);
        node.right = build(nums, mid + 1, right);
        return node;
    }
}
```

## Line-by-line

- `build(nums, left, right)` builds a BST from `nums[left..right]`.
- `left > right` → null (base case: empty range).
- `mid = left + (right - left) / 2` — middle element (overflow-safe).
- `new TreeNode(nums[mid])` — root of this subtree.
- Recurse on left half and right half.

## Complexity

- Time: O(n) — visit every element once.
- Space: O(log n) — recursion stack (balanced tree, height = log n).

## Common Mistakes

- **Using `(left + right) / 2`.** Overflow for large arrays. Use `left + (right - left) / 2`.
- **Not handling empty array.** `nums.length == 0` → `build(nums, 0, -1)` → returns null. Correct.
- **Choosing the wrong middle.** For even-length arrays, either middle works. The formula picks the left middle. Both give a balanced tree.
- **Creating an unbalanced tree.** If you always pick the first element as root, you get a skewed tree. Pick the middle.

## How to Explain (interview)

**Opening:** Convert Sorted Array to BST builds a height-balanced BST from a sorted array. Pick the middle element as root (so left and right subtrees have equal size), recurse on both halves. O(n) time, O(log n) space. The BST property is satisfied automatically (left < root < right) because the array is sorted.

**The basic flow:**
```java
TreeNode build(int[] nums, int left, int right) {
    if (left > right) return null;
    int mid = left + (right - left) / 2;
    TreeNode node = new TreeNode(nums[mid]);
    node.left = build(nums, left, mid - 1);
    node.right = build(nums, mid + 1, right);
    return node;
}
```

**The part that trips everyone up:** pick the **middle** as root (not the first element). This ensures balance. Use `left + (right - left) / 2` to avoid overflow.

**The mistakes to remember:**
- Picking the first element as root (skewed tree)
- Overflow in mid calculation
- Not handling empty array
- Confusing with "Convert BST to Sorted List" (reverse problem)
