# 15.4 Lowest Common Ancestor of a BST

**Problem:** Given a BST and two nodes p and q, find their lowest common ancestor (LCA). (LeetCode #235)

**Link:** https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-search-tree/

---

## Which Technique, and Why?

LCA in a BST → **exploit the BST property**. The LCA is the first node where p and q diverge — one is ≤ node.val and the other is ≥ node.val. O(h) time, O(h) space (recursion) or O(1) (iterative). Much simpler than the general tree LCA (which checks both subtrees).

**Signal in the problem:** "LCA of a BST" → use the BST property. Don't use the general tree LCA algorithm (O(n)).

## Approach

If both p and q are < root.val → LCA is in the left subtree. If both > root.val → LCA is in the right subtree. Otherwise (one ≤ root, other ≥ root) → root is the LCA.

## Pseudocode

```
if p.val < root.val and q.val < root.val: return LCA(root.left, p, q)
if p.val > root.val and q.val > root.val: return LCA(root.right, p, q)
return root  // divergence point
```

## Java Code

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (p.val < root.val && q.val < root.val) {
            return lowestCommonAncestor(root.left, p, q);
        }
        if (p.val > root.val && q.val > root.val) {
            return lowestCommonAncestor(root.right, p, q);
        }
        return root;  // divergence point
    }
}
```

## Iterative version

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        while (root != null) {
            if (p.val < root.val && q.val < root.val) root = root.left;
            else if (p.val > root.val && q.val > root.val) root = root.right;
            else return root;
        }
        return null;
    }
}
```

## Line-by-line

- Both p and q < root.val → both in left subtree → recurse left.
- Both p and q > root.val → both in right subtree → recurse right.
- Otherwise (one ≤ root, other ≥ root) → root is the LCA (divergence point).

## Complexity

- Time: O(h) — single path down the tree. O(log n) balanced, O(n) skewed.
- Space: O(h) recursive, O(1) iterative.

## Common Mistakes

- **Using general tree LCA.** The general algorithm (check both subtrees) is O(n) and unnecessary. The BST property gives O(h).
- **Not handling the case where p or q equals root.** If p.val == root.val, the second condition (both >) is false, and the first (both <) is false → returns root. Correct.
- **Assuming p and q are distinct.** Problem guarantees distinct values.
- **Confusing with "LCA of a Binary Tree" (#236).** That's a general tree — uses a different algorithm (check both subtrees). This problem is BST-specific.

## How to Explain (interview)

**Opening:** LCA of a BST finds the lowest common ancestor using the BST property. If both p and q are less than root, go left. If both are greater, go right. Otherwise, root is the LCA (divergence point). O(h) time, O(1) space (iterative). Much simpler than general tree LCA.

**The basic flow:**
```java
while (root != null) {
    if (p.val < root.val && q.val < root.val) root = root.left;
    else if (p.val > root.val && q.val > root.val) root = root.right;
    else return root;  // divergence
}
```

**The part that trips everyone up:** the BST property means you only follow one path down — no need to search both subtrees. The LCA is where p and q "diverge" (one goes left, one goes right, or one is the root).

**The mistakes to remember:**
- Using general tree LCA (O(n)) instead of BST LCA (O(h))
- Not handling the case where p or q equals root
- Confusing with "LCA of Binary Tree" (#236) — different problem
