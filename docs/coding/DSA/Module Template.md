### Where we are / Flow

A standard block at the top of every module file. State:
- Where we are: module number and name, and which step of the module this file is (pattern / data structure / practice).
- For a **pattern file**: list the data structures this pattern needs, and that we learn them next (file numbers). State the mental model in one line.
- For a **data structure file**: name the pattern it serves, and the next file to read. State when we return to the pattern and when we solve problems.
- For a **practice file**: confirm all DS and the pattern are learned; state that this file is for solving problems, quiz, and revision.

Keep it to 3-5 lines. No analogies.
