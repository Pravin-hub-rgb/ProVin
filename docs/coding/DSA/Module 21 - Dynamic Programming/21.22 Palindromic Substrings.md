**Tier 2 problem.** (LeetCode #647)

**Problem:** Given a string, count the number of palindromic substrings. (LeetCode #647)

**Link:** https://leetcode.com/problems/palindromic-substrings/

---

## Which Technique, and Why?

"Count palindromic substrings" → **Expand around center** (O(n²) time, O(1) space) or **DP (O(n²) time, O(n²) space)**. Expand around center is simpler and uses less space: for each of 2n-1 centers, expand while characters match, counting each valid palindrome.

**Signal in the problem:** "count palindromic substrings" → expand around center (or DP).

## Approach

Expand around center. For each center (n single-char + n-1 between-char), expand outward while `s[left] == s[right]`, incrementing count for each valid palindrome.

## Pseudocode

```
count = 0
for i from 0 to n-1:
    // odd-length
    l = i, r = i
    while l >= 0 and r < n and s[l] == s[r]:
        count++
        l--; r++
    // even-length
    l = i; r = i + 1
    while l >= 0 and r < n and s[l] == s[r]:
        count++
        l--; r++
return count
```

## Java Code

```java
class Solution {
    public int countSubstrings(String s) {
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            // odd-length palindromes
            int l = i, r = i;
            while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
                count++;
                l--;
                r++;
            }
            // even-length palindromes
            l = i;
            r = i + 1;
            while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
                count++;
                l--;
                r++;
            }
        }
        return count;
    }
}
```

## Line-by-line

- For each center `i`: try odd-length (center at `i`) and even-length (center between `i` and `i+1`).
- Expand while characters match; each valid expansion is a palindrome → `count++`.
- Total centers: 2n - 1 (n single + n-1 between).

## Complexity

- Time: O(n²) — 2n-1 centers, each expansion up to O(n).
- Space: O(1) — only indices.

## Common Mistakes

- **Only checking odd-length.** You must also check even-length (e.g., "aa" is a palindrome). The second while loop handles this.
- **Using DP instead.** DP works (O(n²) time, O(n²) space) but expand-around-center is O(1) space.
- **Not counting each expansion.** Each valid expansion is a palindrome — increment on every match, not just the longest.
- **Off-by-one in bounds.** `l >= 0 && r < s.length()`.
