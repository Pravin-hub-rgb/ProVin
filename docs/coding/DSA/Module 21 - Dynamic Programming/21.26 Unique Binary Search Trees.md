**Tier 2 problem.** (LeetCode #96)

**Problem:** Given n, return the number of structurally unique BSTs that can be formed with values 1 to n. (LeetCode #96)

**Link:** https://leetcode.com/problems/unique-binary-search-trees/

---

## Which Technique, and Why?

"Number of unique BSTs with values 1..n" → **DP (Catalan numbers)**. `dp[i]` = number of unique BSTs with i nodes. For i nodes, pick each as root: left has j-1 nodes, right has i-j nodes → `dp[i] += dp[j-1] * dp[i-j]`. O(n²) time, O(n) space.

**Signal in the problem:** "number of unique BSTs" / "structurally unique" → DP with Catalan numbers.

## Approach

`dp[0] = 1` (empty tree), `dp[1] = 1`. For i from 2 to n: for j from 1 to i: `dp[i] += dp[j-1] * dp[i-j]`. Return `dp[n]`.

## Pseudocode

```
dp = new int[n + 1]
dp[0] = 1
dp[1] = 1
for i from 2 to n:
    for j from 1 to i:
        dp[i] += dp[j - 1] * dp[i - j]
return dp[n]
```

## Java Code

```java
class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;

        for (int i = 2; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }
        return dp[n];
    }
}
```

## Line-by-line

- `dp[i]` = number of unique BSTs with i nodes.
- `dp[0] = 1` — empty tree (one way).
- `dp[1] = 1` — single node.
- For i nodes: pick each j (1 to i) as root. Left subtree has j-1 nodes, right has i-j nodes. Number of combinations = `dp[j-1] × dp[i-j]`. Sum over all j.
- This is the Catalan number C_n.

## Complexity

- Time: O(n²) — n outer × n inner.
- Space: O(n) — dp array.

## Common Mistakes

- **Not initializing dp[0] = 1.** Empty tree counts as 1 (needed for the recurrence: when j=1, left has 0 nodes → dp[0]=1).
- **Wrong recurrence.** `dp[i] += dp[j-1] * dp[i-j]`, not `dp[i] += dp[j] * dp[i-j]` or `dp[i-1] * dp[i-j]`.
- **Confusing with "Unique BSTs II" (#95).** That one returns the actual trees (not just the count). Much harder — uses the same DP but constructs trees.
- **Overflow.** Catalan numbers grow fast. For n = 19, C_19 = 1767263190 (fits in int). For n = 20, it overflows. Use `long` if needed (LeetCode n ≤ 19).

## How to Explain (interview)

**Opening:** Unique Binary Search Trees counts structurally unique BSTs with values 1..n. DP (Catalan numbers): `dp[i]` = number of BSTs with i nodes. For i nodes, pick each as root: left has j-1 nodes, right has i-j nodes → `dp[i] += dp[j-1] * dp[i-j]`. O(n²) time, O(n) space.

**The basic flow:**
```java
int[] dp = new int[n + 1];
dp[0] = 1; dp[1] = 1;
for (int i = 2; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        dp[i] += dp[j - 1] * dp[i - j];
    }
}
return dp[n];
```

**The part that trips everyone up:** `dp[j-1] * dp[i-j]` — left subtree has j-1 nodes, right has i-j nodes. Also, `dp[0] = 1` is essential (empty tree counts as one).

**The mistakes to remember:**
- Not initializing dp[0] = 1 (wrong recurrence)
- Wrong recurrence (dp[j] instead of dp[j-1])
- Confusing with #95 (returns actual trees, not just count)
- Overflow for n ≥ 20 (use long)
