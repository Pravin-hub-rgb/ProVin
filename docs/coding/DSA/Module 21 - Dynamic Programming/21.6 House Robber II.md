# 21.6 House Robber II

**Tier 2 problem.** (LeetCode #213)

**Problem:** Houses are arranged in a circle (first and last are adjacent). Find the max money without robbing adjacent houses. (LeetCode #213)

**Link:** https://leetcode.com/problems/house-robber-ii/

---

## Which Technique, and Why?

"Circular array, can't rob adjacent" → **DP (House Robber) twice**. Since first and last are adjacent, you can't rob both. Compute max of: rob houses [0..n-2] (exclude last) and rob houses [1..n-1] (exclude first). O(n) time, O(1) space.

**Signal in the problem:** "house robber" + "circular" / "first and last adjacent" → two linear House Robber calls.

## Approach

If n == 1 → return nums[0]. Otherwise, return max(rob(nums, 0, n-2), rob(nums, 1, n-1)) where rob is the linear House Robber from Module 21.3.

## Pseudocode

```
if n == 1: return nums[0]
return max(robLinear(nums, 0, n-2), robLinear(nums, 1, n-1))

robLinear(nums, start, end):
    prev2 = 0, prev1 = 0
    for i from start to end:
        curr = max(prev1, prev2 + nums[i])
        prev2 = prev1
        prev1 = curr
    return prev1
```

## Java Code

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];
        return Math.max(robLinear(nums, 0, n - 2), robLinear(nums, 1, n - 1));
    }

    private int robLinear(int[] nums, int start, int end) {
        int prev2 = 0, prev1 = 0;
        for (int i = start; i <= end; i++) {
            int curr = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
}
```

## Line-by-line

- `n == 1` → return `nums[0]` (only one house).
- Otherwise, compute max of two scenarios: exclude last house, or exclude first house.
- `robLinear` is the same DP as House Robber (#198) but on a subarray range.

## Complexity

- Time: O(n) — two linear passes.
- Space: O(1) — two variables per pass.

## Common Mistakes

- **Not handling n = 1.** Single house → return nums[0]. Without this, `robLinear(nums, 0, -1)` returns 0 (wrong).
- **Robbing both first and last.** They're adjacent (circular) — can't rob both. The two-scenario approach avoids this.
- **Using the linear House Robber on the whole array.** That allows robbing both first and last — wrong for circular.
- **Confusing with House Robber (#198).** That's linear (no circular). This is circular (first and last adjacent).

**Opening:** House Robber II is House Robber on a circular array (first and last adjacent). Can't rob both. Solution: compute max of two linear subproblems — rob [0..n-2] (exclude last) and rob [1..n-1] (exclude first). O(n) time, O(1) space.

**The basic flow:**
```java
if (n == 1) return nums[0];
return Math.max(robLinear(nums, 0, n - 2), robLinear(nums, 1, n - 1));
```

**The part that trips everyone up:** the circular constraint means you can't rob both first and last. The two-scenario approach (exclude one) handles this. Also handle n = 1.

**The mistakes to remember:**
- Not handling n = 1
- Robbing both first and last (circular constraint)
- Using linear House Robber on whole array
- Confusing with #198 (linear)
