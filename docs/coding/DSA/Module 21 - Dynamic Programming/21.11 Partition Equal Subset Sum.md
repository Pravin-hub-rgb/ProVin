**Tier 2 problem.** (LeetCode #416)

**Problem:** Given an array of positive integers, determine if it can be partitioned into two subsets with equal sum. (LeetCode #416)

**Link:** https://leetcode.com/problems/partition-equal-subset-sum/

---

## Which Technique, and Why?

"Can array be partitioned into two equal-sum subsets?" → **DP (0/1 knapsack)**. Total sum must be even. Then: can we select a subset summing to `total / 2`? `dp[i]` = can we make sum i. O(n × sum) time, O(sum) space.

**Signal in the problem:** "partition into two equal subsets" → subset sum = total/2 → 0/1 knapsack.

## Approach

1. If total sum is odd → false.
2. Target = total / 2.
3. DP: `dp[0] = true`. For each number, for sum from target down to number: `dp[sum] |= dp[sum - num]`. (Descending inner loop = 0/1 knapsack, each number used at most once.)
4. Return `dp[target]`.

## Pseudocode

```
total = sum(nums)
if total % 2 != 0: return false
target = total / 2
dp = boolean array of size target+1, all false
dp[0] = true
for num in nums:
    for sum from target down to num:
        dp[sum] = dp[sum] or dp[sum - num]
return dp[target]
```

## Java Code

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int total = 0;
        for (int x : nums) total += x;
        if (total % 2 != 0) return false;

        int target = total / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;

        for (int num : nums) {
            for (int sum = target; sum >= num; sum--) {
                dp[sum] = dp[sum] || dp[sum - num];
            }
        }
        return dp[target];
    }
}
```

## Line-by-line

- `total % 2 != 0` → false (can't split odd sum equally).
- `target = total / 2` — we need a subset summing to this.
- `dp[0] = true` — empty subset sums to 0.
- For each number: for sum from target down to num: `dp[sum] |= dp[sum - num]` — if we can make `sum - num`, we can make `sum` by adding `num`.
- Inner loop **descending** — 0/1 knapsack (each number used at most once). Ascending would allow reuse (unbounded).

## Complexity

- Time: O(n × target) where target = total/2.
- Space: O(target) — dp array.

## Common Mistakes

- **Ascending inner loop.** That allows reuse (unbounded knapsack). For "at most once," use descending.
- **Not checking odd total.** If total is odd, impossible → return false immediately.
- **Not handling single element.** `nums = [1]` → total = 1 (odd) → false. Correct.
- **Confusing with "Target Sum" (#494).** That one assigns +/- to each element. Different recurrence.

## How to Explain (interview)

**Opening:** Partition Equal Subset Sum checks if an array can be split into two equal-sum subsets. Total must be even. Then it's a 0/1 knapsack: can we select a subset summing to total/2? `dp[sum] = dp[sum] || dp[sum - num]`. Descending inner loop (each number used at most once). O(n × target) time, O(target) space.

**The basic flow:**
```java
int total = sum(nums);
if (total % 2 != 0) return false;
int target = total / 2;
boolean[] dp = new boolean[target + 1];
dp[0] = true;
for (int num : nums) {
    for (int sum = target; sum >= num; sum--) {
        dp[sum] = dp[sum] || dp[sum - num];
    }
}
return dp[target];
```

**The part that trips everyone up:** the inner loop is **descending** (target → num). Ascending would allow reuse (unbounded knapsack). Also, check `total % 2 != 0` first.

**The mistakes to remember:**
- Ascending inner loop (allows reuse — wrong)
- Not checking odd total first
- Not handling single element
- Confusing with Target Sum (#494) (different recurrence)
