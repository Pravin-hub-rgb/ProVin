**Tier 2 problem.** (LeetCode #91)

**Problem:** Given a string of digits, determine how many ways to decode it (A=1, B=2, ..., Z=26). (LeetCode #91)

**Link:** https://leetcode.com/problems/decode-ways/

---

## Which Technique, and Why?

"Number of ways to decode a digit string" → **DP**. `dp[i]` = number of ways to decode first i characters. `dp[i] = dp[i-1]` (if s[i-1] is valid single digit) + `dp[i-2]` (if s[i-2..i-1] is a valid two-digit code). O(n) time, O(1) space (optimized).

**Signal in the problem:** "number of ways to decode" / "decode ways" → DP with single and double digit transitions.

## Approach

Bottom-up DP. `dp[i]` = ways to decode first i chars. Base: `dp[0] = 1` (empty string has one way). For each i: if s[i-1] is valid single digit (1-9), `dp[i] += dp[i-1]`. If s[i-2..i-1] is valid two-digit (10-26), `dp[i] += dp[i-2]`.

## Pseudocode

```
n = s.length
dp = new int[n + 1]
dp[0] = 1
for i from 1 to n:
    if s[i-1] != '0': dp[i] += dp[i-1]        // single digit
    if i >= 2 and s[i-2] != '0' and parseInt(s[i-2..i-1]) <= 26:
        dp[i] += dp[i-2]                        // two digit
return dp[n]
```

## Java Code

```java
class Solution {
    public int numDecodings(String s) {
        int n = s.length();
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = s.charAt(0) != '0' ? 1 : 0;

        for (int i = 2; i <= n; i++) {
            // single digit
            if (s.charAt(i - 1) != '0') {
                dp[i] += dp[i - 1];
            }
            // two digit
            int twoDigit = (s.charAt(i - 2) - '0') * 10 + (s.charAt(i - 1) - '0');
            if (twoDigit >= 10 && twoDigit <= 26) {
                dp[i] += dp[i - 2];
            }
        }
        return dp[n];
    }
}
```

## Line-by-line

- `dp[0] = 1` — empty string has one way to decode (do nothing).
- `dp[1]` — first char: 1 if it's a valid single digit (1-9), 0 if '0'.
- Single digit: if `s[i-1] != '0'`, add `dp[i-1]` (decode first i-1, then this digit).
- Two digit: if `s[i-2..i-1]` is 10-26, add `dp[i-2]`.
- Return `dp[n]`.

## Complexity

- Time: O(n) — single pass.
- Space: O(n) — dp array. Can be O(1) with two variables.

## Common Mistakes

- **Not handling '0'.** '0' alone is invalid (no letter maps to 0). But "10" and "20" are valid (J, T). Check `s[i-1] != '0'` for single digit and `twoDigit >= 10` for two-digit.
- **Leading zero.** "06" → 0 ways (0 is invalid single, 06 is invalid two-digit since 6 < 10).
- **Off-by-one in dp indexing.** `dp[i]` uses `s.charAt(i-1)` (0-indexed string, 1-indexed dp).
- **Confusing with "Decode Ways II"** (#639) — that one has wildcards ('*'). Different problem.

## How to Explain (interview)

**Opening:** Decode Ways counts how many ways to decode a digit string (A=1, ..., Z=26). DP: `dp[i]` = ways to decode first i chars. `dp[i] = dp[i-1]` (if single digit valid) + `dp[i-2]` (if two-digit 10-26 valid). O(n) time, O(n) space (O(1) optimized).

**The basic flow:**
```java
dp[0] = 1; dp[1] = (s.charAt(0) != '0') ? 1 : 0;
for (int i = 2; i <= n; i++) {
    if (s.charAt(i-1) != '0') dp[i] += dp[i-1];
    int two = (s.charAt(i-2)-'0')*10 + (s.charAt(i-1)-'0');
    if (two >= 10 && two <= 26) dp[i] += dp[i-2];
}
```

**The part that trips everyone up:** '0' handling. '0' alone is invalid (no letter). "10" and "20" are valid. Check `s[i-1] != '0'` for single digit and `twoDigit >= 10` for two-digit.

**The mistakes to remember:**
- Not handling '0' (returns wrong count)
- Leading zeros ("06" → 0)
- Off-by-one in dp indexing
- Confusing with Decode Ways II (#639, has wildcards)
