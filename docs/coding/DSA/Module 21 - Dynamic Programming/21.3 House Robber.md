# 21.3 House Robber

**Problem:** Given an array of non-negative integers representing money in houses, find the maximum amount you can rob without robbing two adjacent houses. (LeetCode #198)

**Link:** https://leetcode.com/problems/house-robber/

---

## Which Technique, and Why?

"Maximum value with no adjacent selection" → **DP**. At each house, you either rob it (add its value + best from 2 houses ago) or skip it (best from previous house). `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`. O(n) time, O(1) space.

**Signal in the problem:** "maximum" + "can't pick adjacent" / "no two adjacent" → DP with skip-or-take recurrence.

## Approach

Bottom-up DP. `dp[i]` = max money from first i houses. `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`. Base: `dp[0] = nums[0]`, `dp[1] = max(nums[0], nums[1])`. Optimize to O(1) space.

## Pseudocode

```
if n == 0: return 0
if n == 1: return nums[0]
prev2 = nums[0], prev1 = max(nums[0], nums[1])
for i from 2 to n-1:
    curr = max(prev1, prev2 + nums[i])
    prev2 = prev1
    prev1 = curr
return prev1
```

## Java Code

```java
class Solution {
    public int rob(int[] nums) {
        if (nums.length == 0) return 0;
        if (nums.length == 1) return nums[0];

        int prev2 = nums[0];                    // dp[i-2]
        int prev1 = Math.max(nums[0], nums[1]); // dp[i-1]

        for (int i = 2; i < nums.length; i++) {
            int curr = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
}
```

## Line-by-line

- `prev2 = dp[i-2]`, `prev1 = dp[i-1]`.
- `curr = max(prev1, prev2 + nums[i])` — either skip house i (keep prev1) or rob it (prev2 + nums[i]).
- Shift: `prev2 = prev1`, `prev1 = curr`.

## Complexity

- Time: O(n) — single pass.
- Space: O(1) — two variables.

## Common Mistakes

- **Not handling n = 0 or n = 1.** Empty array → 0. Single house → nums[0].
- **Robbing adjacent houses.** The recurrence `dp[i-2] + nums[i]` ensures you skip the previous house. Don't use `dp[i-1] + nums[i]`.
- **Not optimizing space.** O(n) array works but O(1) is trivial here.
- **Confusing with "House Robber II"** (circular array) — different problem. For circular, compute max(rob(0..n-2), rob(1..n-1)).

## How to Explain (interview)

**Opening:** House Robber asks for the max money without robbing adjacent houses. DP: at each house, either skip it (keep previous best) or rob it (previous best 2 ago + current). `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`. O(n) time, O(1) space.

**The basic flow:**
```java
int prev2 = nums[0], prev1 = Math.max(nums[0], nums[1]);
for (int i = 2; i < nums.length; i++) {
    int curr = Math.max(prev1, prev2 + nums[i]);
    prev2 = prev1;
    prev1 = curr;
}
return prev1;
```

**The part that trips everyone up:** the recurrence is `max(skip, take)` where `take = dp[i-2] + nums[i]` (skip the previous house). Don't use `dp[i-1] + nums[i]` (that's adjacent — invalid).

**The mistakes to remember:**
- Using `dp[i-1] + nums[i]` (adjacent robbery — wrong)
- Not handling n = 0 or n = 1
- Not optimizing space (O(n) array when O(1) suffices)
- Confusing with House Robber II (circular)
