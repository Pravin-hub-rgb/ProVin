**Tier 2 problem.** (LeetCode #72)

**Problem:** Given two strings, find the minimum number of operations (insert, delete, replace) to convert one to the other. (LeetCode #72)

**Link:** https://leetcode.com/problems/edit-distance/

---

## Which Technique, and Why?

"Minimum edits to convert string A to B" → **DP (2D)**. `dp[i][j]` = min edits for first i chars of word1 and first j chars of word2. If `word1[i-1] == word2[j-1]`: `dp[i][j] = dp[i-1][j-1]`. Else: `dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])` (delete, insert, replace). O(m × n) time, O(n) space (optimized).

**Signal in the problem:** "edit distance" / "minimum operations to convert" → 2D DP with insert/delete/replace.

## Approach

Bottom-up. `dp[j]` for current row. If chars match: `dp[j] = prev` (diagonal). If not: `dp[j] = 1 + min(dp[j] (delete), dp[j-1] (insert), prev (replace))`. Use `prev` for diagonal.

## Pseudocode

```
m = word1.length, n = word2.length
dp = new int[n + 1]
for j from 0 to n: dp[j] = j  // base: insert all
for i from 1 to m:
    prev = dp[0]  // dp[i-1][0]
    dp[0] = i     // delete all
    for j from 1 to n:
        temp = dp[j]
        if word1[i-1] == word2[j-1]: dp[j] = prev
        else: dp[j] = 1 + min(dp[j], dp[j-1], prev)
        prev = temp
return dp[n]
```

## Java Code

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        int[] dp = new int[n + 1];
        for (int j = 0; j <= n; j++) dp[j] = j;

        for (int i = 1; i <= m; i++) {
            int prev = dp[0];
            dp[0] = i;
            for (int j = 1; j <= n; j++) {
                int temp = dp[j];
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[j] = prev;
                } else {
                    dp[j] = 1 + Math.min(dp[j], Math.min(dp[j - 1], prev));
                }
                prev = temp;
            }
        }
        return dp[n];
    }
}
```

## Line-by-line

- `dp[j]` initialized to j (insert j chars into empty word1).
- `dp[0] = i` — delete i chars from word1 to make empty word2.
- `prev` = `dp[i-1][j-1]` (diagonal, saved before update).
- Match: `dp[j] = prev` (no edit needed).
- Mismatch: `1 + min(delete, insert, replace)` = `1 + min(dp[j] (delete from word1), dp[j-1] (insert into word1), prev (replace))`.
- `prev = temp` — update for next column.

## Complexity

- Time: O(m × n).
- Space: O(n) — optimized from O(m × n).

## Common Mistakes

- **Not using `prev` for the diagonal.** `dp[j]` before update = `dp[i-1][j]` (above). `dp[j-1]` after update = `dp[i][j-1]` (left). The diagonal `dp[i-1][j-1]` must be saved in `prev` before overwriting.
- **Wrong operation mapping.** Delete = `dp[i-1][j]` (remove from word1). Insert = `dp[i][j-1]` (add to word1). Replace = `dp[i-1][j-1]`. Getting these wrong gives wrong answers.
- **Not initializing dp[0] = i.** The first column (word2 is empty) requires deleting all i chars from word1.
- **Confusing with LCS (#1143).** LCS counts matches; Edit Distance counts edits. Related but different.

## How to Explain (interview)

**Opening:** Edit Distance finds the minimum edits (insert, delete, replace) to convert word1 to word2. DP: `dp[i][j]` = min edits for first i chars of word1 and first j of word2. Match → diagonal. Mismatch → 1 + min(delete, insert, replace). O(m×n) time, O(n) space.

**The basic flow:**
```java
int[] dp = new int[n + 1];
for (int j = 0; j <= n; j++) dp[j] = j;
for (int i = 1; i <= m; i++) {
    int prev = dp[0]; dp[0] = i;
    for (int j = 1; j <= n; j++) {
        int temp = dp[j];
        if (word1.charAt(i-1) == word2.charAt(j-1)) dp[j] = prev;
        else dp[j] = 1 + Math.min(dp[j], Math.min(dp[j-1], prev));
        prev = temp;
    }
}
```

**The part that trips everyone up:** the **diagonal** (`dp[i-1][j-1]`) must be saved in `prev` before overwriting `dp[j]`. Also, the three operations: delete (from word1), insert (into word1), replace.

**The mistakes to remember:**
- Not saving prev (diagonal) before overwriting
- Wrong operation mapping (delete/insert/replace)
- Not initializing dp[0] = i (first column)
- Confusing with LCS (#1143)
