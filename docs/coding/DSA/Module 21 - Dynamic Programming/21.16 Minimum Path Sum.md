# 21.16 Minimum Path Sum

**Tier 2 problem.** (LeetCode #64)

**Problem:** Given an m×n grid of non-negative numbers, find the path from top-left to bottom-right (right/down) that minimizes the sum. (LeetCode #64)

**Link:** https://leetcode.com/problems/minimum-path-sum/

---

## Which Technique, and Why?

"Minimum path sum in a grid" → **DP (2D)**. `dp[i][j]` = min sum to reach (i,j). `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`. O(m × n) time, O(n) space (optimized).

**Signal in the problem:** "minimum path sum" / "min sum path in grid" → 2D DP (min of from-above and from-left).

## Approach

Bottom-up. `dp[j]` for the current row. `dp[j] = grid[i][j] + min(dp[j] (from above, prev row), dp[j-1] (from left, current row))`. Base: first row and first column are cumulative sums (only one way to reach them).

## Pseudocode

```
dp = new int[n]
dp[0] = grid[0][0]
for j from 1 to n-1: dp[j] = dp[j-1] + grid[0][j]
for i from 1 to m-1:
    dp[0] += grid[i][0]  // first column: only from above
    for j from 1 to n-1:
        dp[j] = grid[i][j] + min(dp[j], dp[j-1])
return dp[n-1]
```

## Java Code

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] dp = new int[n];

        dp[0] = grid[0][0];
        for (int j = 1; j < n; j++) dp[j] = dp[j - 1] + grid[0][j];

        for (int i = 1; i < m; i++) {
            dp[0] += grid[i][0];  // first column: only from above
            for (int j = 1; j < n; j++) {
                dp[j] = grid[i][j] + Math.min(dp[j], dp[j - 1]);
            }
        }
        return dp[n - 1];
    }
}
```

## Line-by-line

- `dp[0] = grid[0][0]` — start cell.
- First row: `dp[j] = dp[j-1] + grid[0][j]` — only from left.
- For each subsequent row: `dp[0] += grid[i][0]` — first column only from above.
- `dp[j] = grid[i][j] + min(dp[j], dp[j-1])` — `dp[j]` before update = from above (prev row); `dp[j-1]` after update = from left (current row).
- Return `dp[n-1]`.

## Complexity

- Time: O(m × n).
- Space: O(n) — optimized from O(m × n).

## Common Mistakes

- **Not initializing the first row/column.** First row: only from left. First column: only from above. If you use the general recurrence for these, you get index out of bounds or wrong values.
- **Updating dp[0] inside the inner loop.** `dp[0] += grid[i][0]` must be done before the inner loop (first column only from above).
- **Confusing with "Maximum Path Sum" (#124, triangle).** That's a different problem (triangle, not grid). Similar DP but different structure.
- **Modifying the input.** This problem allows it (you can use `grid` as dp). If not, use a separate array.

## How to Explain (interview)

**Opening:** Minimum Path Sum finds the min-sum path from top-left to bottom-right (right/down). DP: `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`. O(m×n) time, O(n) space (optimized).

**The basic flow:**
```java
int[] dp = new int[n];
dp[0] = grid[0][0];
for (int j = 1; j < n; j++) dp[j] = dp[j-1] + grid[0][j];
for (int i = 1; i < m; i++) {
    dp[0] += grid[i][0];
    for (int j = 1; j < n; j++) dp[j] = grid[i][j] + Math.min(dp[j], dp[j-1]);
}
return dp[n-1];
```

**The part that trips everyone up:** first row and first column are base cases (only one way to reach them). `dp[0] += grid[i][0]` must be done before the inner loop. In the inner loop, `dp[j]` before update = from above; `dp[j-1]` after update = from left.

**The mistakes to remember:**
- Not initializing first row/column (wrong answer)
- Updating dp[0] inside the inner loop (wrong)
- Confusing with Maximum Path Sum (#124, triangle)
- Modifying input when problem forbids it
