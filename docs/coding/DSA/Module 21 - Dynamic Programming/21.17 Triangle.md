**Tier 2 problem.** (LeetCode #120)

**Problem:** Given a triangle of numbers, find the minimum path sum from top to bottom (move to adjacent numbers in the row below). (LeetCode #120)

**Link:** https://leetcode.com/problems/triangle/

---

## Which Technique, and Why?

"Minimum path sum in a triangle" → **DP (bottom-up)**. `dp[j]` for the current row = min path to column j. `dp[j] = triangle[i][j] + min(dp[j], dp[j-1])` (from above or above-left). O(n²) time, O(n) space.

**Signal in the problem:** "triangle" + "minimum path sum" + "adjacent numbers" → bottom-up DP.

## Approach

Bottom-up (from second-to-last row up to top). `dp[j] = triangle[i][j] + min(dp[j], dp[j+1])`. Start with the last row as dp. Work upward. O(n²) time, O(n) space.

## Pseudocode

```
dp = copy of last row
for i from n-2 down to 0:
    for j from 0 to i:
        dp[j] = triangle[i][j] + min(dp[j], dp[j+1])
return dp[0]
```

## Java Code

```java
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int n = triangle.size();
        int[] dp = new int[n];
        for (int i = 0; i < n; i++) dp[i] = triangle.get(n - 1).get(i);

        for (int i = n - 2; i >= 0; i--) {
            for (int j = 0; j <= i; j++) {
                dp[j] = triangle.get(i).get(j) + Math.min(dp[j], dp[j + 1]);
            }
        }
        return dp[0];
    }
}
```

## Line-by-line

- `dp` initialized to the last row (base case: min path to each bottom cell is its value).
- Work upward: `dp[j] = triangle[i][j] + min(dp[j], dp[j+1])`. `dp[j]` = path from below (same column), `dp[j+1]` = path from below-right.
- After processing row 0, `dp[0]` = min path from top to bottom.

## Complexity

- Time: O(n²) — n rows, up to n elements per row.
- Space: O(n) — dp array.

## Common Mistakes

- **Top-down instead of bottom-up.** Top-down works but is harder (need to track paths from top). Bottom-up is simpler.
- **Using `dp[j-1]` instead of `dp[j+1]`.** In bottom-up, from (i, j) you can go to (i+1, j) or (i+1, j+1). So `dp[j] = triangle[i][j] + min(dp[j], dp[j+1])`.
- **Not handling single row.** `n = 1` → return `triangle[0][0]`. The loop doesn't execute (i from -1... wait, n-2 = -1, loop doesn't run). Returns dp[0] = triangle[0][0]. Correct.
- **Confusing with "Minimum Path Sum" (#64).** That's a grid (right/down). This is a triangle (down-left/down-right).

## How to Explain (interview)

**Opening:** Triangle finds the minimum path sum from top to bottom. Bottom-up DP: start from the last row, work upward. `dp[j] = triangle[i][j] + min(dp[j], dp[j+1])` (from below or below-right). O(n²) time, O(n) space.

**The basic flow:**
```java
int[] dp = last row;
for (int i = n - 2; i >= 0; i--) {
    for (int j = 0; j <= i; j++) {
        dp[j] = triangle[i][j] + Math.min(dp[j], dp[j + 1]);
    }
}
return dp[0];
```

**The part that trips everyone up:** bottom-up (not top-down). Also, `dp[j+1]` (not `dp[j-1]`) — from (i,j) you go to (i+1,j) or (i+1,j+1).

**The mistakes to remember:**
- Top-down instead of bottom-up (harder)
- Using dp[j-1] instead of dp[j+1]
- Not handling single row
- Confusing with Minimum Path Sum (#64, grid not triangle)
