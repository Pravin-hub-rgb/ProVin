# 21.18 Maximal Square

**Tier 2 problem.** (LeetCode #221)

**Problem:** Given a binary matrix, find the largest square containing only 1s. Return its area. (LeetCode #221)

**Link:** https://leetcode.com/problems/maximal-square/

---

## Which Technique, and Why?

"Largest square of 1s in a binary matrix" → **DP (2D)**. `dp[i][j]` = side length of the largest square ending at (i,j). If `matrix[i][j] == 1`: `dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1`. Else 0. O(m × n) time, O(n) space (optimized).

**Signal in the problem:** "maximal square" / "largest square of 1s" → DP with min of three neighbors + 1.

## Approach

Bottom-up. `dp[j]` for current row. If `matrix[i][j] == 1`: `dp[j] = min(dp[j] (from above), dp[j-1] (from left), prev (from diagonal)) + 1`. Track max side length. Return max².

## Pseudocode

```
dp = new int[n] (all 0)
maxSide = 0
for i from 0 to m-1:
    prev = 0  // dp[i-1][j-1] (diagonal)
    for j from 0 to n-1:
        temp = dp[j]  // save for next iteration's diagonal
        if matrix[i][j] == 1:
            if i == 0 or j == 0: dp[j] = 1
            else: dp[j] = Math.min(dp[j], Math.min(dp[j-1], prev)) + 1
            maxSide = max(maxSide, dp[j])
        else:
            dp[j] = 0
        prev = temp
return maxSide * maxSide
```

## Java Code

```java
class Solution {
    public int maximalSquare(char[][] matrix) {
        if (matrix == null || matrix.length == 0) return 0;
        int m = matrix.length, n = matrix[0].length;
        int[] dp = new int[n];
        int maxSide = 0, prev = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int temp = dp[j];
                if (matrix[i][j] == '1') {
                    if (i == 0 || j == 0) dp[j] = 1;
                    else dp[j] = Math.min(dp[j], Math.min(dp[j - 1], prev)) + 1;
                    maxSide = Math.max(maxSide, dp[j]);
                } else {
                    dp[j] = 0;
                }
                prev = temp;
            }
            prev = 0;  // reset for next row
        }
        return maxSide * maxSide;
    }
}
```

## Line-by-line

- `dp[j]` = side length of largest square ending at (i, j).
- If `matrix[i][j] == '1'`: `dp[j] = min(dp[j] (above), dp[j-1] (left), prev (diagonal)) + 1`.
- `prev` stores the old `dp[j]` (diagonal for next iteration).
- `maxSide` tracks the largest side length seen.
- Return `maxSide²` (area).

## Complexity

- Time: O(m × n).
- Space: O(n) — optimized from O(m × n).

## Common Mistakes

- **Not using min of three neighbors.** The square is limited by the smallest neighbor. Using max or sum gives wrong answers.
- **Not handling the first row/column.** If `i == 0` or `j == 0`, `dp[j] = 1` (a single cell). The min formula would access `dp[-1]` or `dp[j-1]` out of bounds.
- **Not tracking `prev` (diagonal).** `dp[j]` is overwritten before it's used as the diagonal for the next cell. Save it in `temp` first.
- **Returning side length instead of area.** Return `maxSide * maxSide`.

## How to Explain (interview)

**Opening:** Maximal Square finds the largest square of 1s. DP: `dp[i][j]` = side length of the largest square ending at (i,j). If `matrix[i][j] == 1`: `dp = min(above, left, diagonal) + 1`. The square is limited by the smallest neighbor. O(m×n) time, O(n) space.

**The basic flow:**
```java
if (matrix[i][j] == '1') {
    dp[j] = Math.min(dp[j], Math.min(dp[j-1], prev)) + 1;
    maxSide = Math.max(maxSide, dp[j]);
}
```

**The part that trips everyone up:** use **min** of three neighbors (above, left, diagonal) + 1. The square is limited by the smallest adjacent square. Also, save `dp[j]` in `prev` before overwriting (it's the diagonal for the next cell).

**The mistakes to remember:**
- Using max instead of min (wrong answer)
- Not handling first row/column (index out of bounds)
- Not saving prev (diagonal) before overwriting
- Returning side length instead of area (maxSide²)
