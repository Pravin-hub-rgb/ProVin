# 21.19 Minimum Falling Path Sum

**Tier 2 problem.** (LeetCode #931)

**Problem:** Given an n×n matrix, find the minimum sum of a falling path (move down, down-left, or down-right). (LeetCode #931)

**Link:** https://leetcode.com/problems/minimum-falling-path-sum/

---

## Which Technique, and Why?

"Minimum falling path sum" → **DP (bottom-up)**. `dp[j]` for current row = `matrix[i][j] + min(dp[j-1], dp[j], dp[j+1])` from the previous row. O(n²) time, O(n) space.

**Signal in the problem:** "falling path" / "move down, down-left, down-right" / "minimum path sum in matrix" → DP with 3-way min.

## Approach

Bottom-up. `dp[j]` for row i = `matrix[i][j] + min(dp[j-1], dp[j], dp[j+1])` from row i-1. Start with the first row as dp. Process row by row.

## Pseudocode

```
dp = copy of first row
for i from 1 to n-1:
    newDp = new int[n]
    for j from 0 to n-1:
        minPrev = dp[j]
        if j > 0: minPrev = min(minPrev, dp[j-1])
        if j < n-1: minPrev = min(minPrev, dp[j+1])
        newDp[j] = matrix[i][j] + minPrev
    dp = newDp
return min(dp)
```

## Java Code

```java
class Solution {
    public int minFallingPathSum(int[][] matrix) {
        int n = matrix.length;
        int[] dp = matrix[0].clone();

        for (int i = 1; i < n; i++) {
            int[] newDp = new int[n];
            for (int j = 0; j < n; j++) {
                int minPrev = dp[j];
                if (j > 0) minPrev = Math.min(minPrev, dp[j - 1]);
                if (j < n - 1) minPrev = Math.min(minPrev, dp[j + 1]);
                newDp[j] = matrix[i][j] + minPrev;
            }
            dp = newDp;
        }

        int min = Integer.MAX_VALUE;
        for (int v : dp) min = Math.min(min, v);
        return min;
    }
}
```

## Line-by-line

- `dp` initialized to the first row.
- For each subsequent row: `newDp[j] = matrix[i][j] + min(dp[j], dp[j-1], dp[j+1])` (with bounds checks).
- `dp = newDp` — move to next row.
- Return the min of the last row.

## Complexity

- Time: O(n²) — n rows × n columns.
- Space: O(n) — two rows.

## Common Mistakes

- **Not handling boundaries.** `j = 0` has no left neighbor; `j = n-1` has no right neighbor. Check `j > 0` and `j < n-1`.
- **Modifying dp in place.** If you update `dp[j]` in place (left to right), `dp[j-1]` is already updated (current row) instead of previous row. Use a separate `newDp` array.
- **Confusing with "Minimum Path Sum" (#64).** That's a grid (right/down). This is a falling path (down, down-left, down-right). Different transitions.
- **Not taking the min of the last row.** The answer is the minimum of the last row, not `dp[0]`.

## How to Explain (interview)

**Opening:** Minimum Falling Path Sum finds the min sum of a path from top to bottom (move down, down-left, down-right). DP: `dp[j] = matrix[i][j] + min(dp[j-1], dp[j], dp[j+1])` from the previous row. O(n²) time, O(n) space.

**The basic flow:**
```java
int[] dp = matrix[0].clone();
for (int i = 1; i < n; i++) {
    int[] newDp = new int[n];
    for (int j = 0; j < n; j++) {
        int minPrev = dp[j];
        if (j > 0) minPrev = Math.min(minPrev, dp[j - 1]);
        if (j < n - 1) minPrev = Math.min(minPrev, dp[j + 1]);
        newDp[j] = matrix[i][j] + minPrev;
    }
    dp = newDp;
}
return min(dp);
```

**The part that trips everyone up:** use a separate `newDp` array (don't update in place — you'd use current-row values instead of previous-row). Also, handle boundaries (j=0 has no left, j=n-1 has no right).

**The mistakes to remember:**
- Updating dp in place (uses current row instead of previous)
- Not handling boundaries (index out of bounds)
- Not taking min of last row
- Confusing with Minimum Path Sum (#64, grid not triangle/matrix)
