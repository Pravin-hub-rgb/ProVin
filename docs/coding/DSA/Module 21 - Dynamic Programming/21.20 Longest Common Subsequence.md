# 21.20 Longest Common Subsequence

**Tier 2 problem.** (LeetCode #1143)

**Problem:** Given two strings, find the length of their longest common subsequence (LCS). (LeetCode #1143)

**Link:** https://leetcode.com/problems/longest-common-subsequence/

---

## Which Technique, and Why?

"Longest common subsequence" → **DP (2D)**. `dp[i][j]` = LCS of first i chars of text1 and first j chars of text2. If `text1[i-1] == text2[j-1]`: `dp[i][j] = dp[i-1][j-1] + 1`. Else: `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`. O(m × n) time, O(n) space (optimized).

**Signal in the problem:** "longest common subsequence" / "LCS" → 2D DP with match/mismatch recurrence.

## Approach

Bottom-up 2D DP. If chars match, extend the diagonal. If not, take the max of skipping one char from either string. Optimize space to O(n).

## Pseudocode

```
m = text1.length, n = text2.length
dp = new int[n + 1]
for i from 1 to m:
    prev = 0  // dp[i-1][j-1]
    for j from 1 to n:
        temp = dp[j]
        if text1[i-1] == text2[j-1]:
            dp[j] = prev + 1
        else:
            dp[j] = Math.max(dp[j], dp[j-1])
        prev = temp
return dp[n]
```

## Java Code

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        int[] dp = new int[n + 1];

        for (int i = 1; i <= m; i++) {
            int prev = 0;  // dp[i-1][j-1]
            for (int j = 1; j <= n; j++) {
                int temp = dp[j];
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[j] = prev + 1;
                } else {
                    dp[j] = Math.max(dp[j], dp[j - 1]);
                }
                prev = temp;
            }
        }
        return dp[n];
    }
}
```

## Line-by-line

- `dp[j]` = LCS of first i chars of text1 and first j chars of text2.
- `prev` saves `dp[j]` before update (which is `dp[i-1][j]`, the value from the previous row at column j). After update, `prev` becomes `dp[i-1][j-1]` for the next column.
- Match: `dp[j] = prev + 1` (extend diagonal).
- Mismatch: `dp[j] = max(dp[j] (skip text1[i-1]), dp[j-1] (skip text2[j-1]))`.
- Return `dp[n]`.

## Complexity

- Time: O(m × n).
- Space: O(n) — optimized from O(m × n).

## Common Mistakes

- **Not handling the 1-indexed dp.** `dp[j]` uses `text1.charAt(i-1)` and `text2.charAt(j-1)`. The +1 offset accounts for the empty prefix (dp[0] = 0).
- **Overwriting dp[j] before using it.** Save `temp = dp[j]` before updating (it's the diagonal for the next column). Using `prev` correctly handles this.
- **Confusing with "Longest Increasing Subsequence" (#300).** LIS is on one array; LCS is on two strings.
- **Confusing with "Edit Distance" (#72).** LCS counts matches; Edit Distance counts edits. Related but different.

## How to Explain (interview)

**Opening:** Longest Common Subsequence finds the longest subsequence common to two strings. DP: if chars match, extend the diagonal (`dp[i][j] = dp[i-1][j-1] + 1`). If not, take the max of skipping one char from either string. O(m×n) time, O(n) space.

**The basic flow:**
```java
int[] dp = new int[n + 1];
for (int i = 1; i <= m; i++) {
    int prev = 0;
    for (int j = 1; j <= n; j++) {
        int temp = dp[j];
        if (text1.charAt(i-1) == text2.charAt(j-1)) dp[j] = prev + 1;
        else dp[j] = Math.max(dp[j], dp[j-1]);
        prev = temp;
    }
}
return dp[n];
```

**The part that trips everyone up:** the space optimization. `prev` saves `dp[j]` (old value = `dp[i-1][j]`) before update, so it becomes `dp[i-1][j-1]` for the next column. Without this, you'd use the updated value (wrong).

**The mistakes to remember:**
- Not handling 1-indexed dp (off-by-one)
- Overwriting dp[j] before saving (wrong diagonal)
- Confusing with LIS (#300) or Edit Distance (#72)
- Using O(mn) space when O(n) suffices
