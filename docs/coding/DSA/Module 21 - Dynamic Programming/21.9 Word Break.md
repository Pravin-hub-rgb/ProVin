**Tier 2 problem.** (LeetCode #139)

**Problem:** Given a string and a dictionary, determine if the string can be segmented into a sequence of dictionary words. (LeetCode #139)

**Link:** https://leetcode.com/problems/word-break/

---

## Which Technique, and Why?

"Can string be segmented into dictionary words?" → **DP (1D)**. `dp[i]` = can the first i characters be segmented. `dp[i] = true` if there exists j < i such that `dp[j]` is true and `s[j..i-1]` is a dictionary word. O(n² × L) time where L = max word length, O(n) space.

**Signal in the problem:** "segment into dictionary words" / "can be broken into words" → DP with dictionary lookup.

## Approach

Bottom-up. `dp[0] = true` (empty string is segmentable). For each i from 1 to n: for each j from 0 to i-1: if `dp[j]` and `s.substring(j, i)` is in the dictionary → `dp[i] = true`, break. Return `dp[n]`.

## Pseudocode

```
dp = boolean array of size n+1
dp[0] = true
dict = set of words
for i from 1 to n:
    for j from 0 to i-1:
        if dp[j] and dict.contains(s.substring(j, i)):
            dp[i] = true
            break
return dp[n]
```

## Java Code

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> dict = new HashSet<>(wordDict);
        int n = s.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && dict.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
}
```

## Line-by-line

- `dp[0] = true` — empty string is segmentable.
- For each position i: check all possible last words `s[j..i-1]`. If `dp[j]` is true (first j chars segmentable) and the word is in the dict → `dp[i] = true`.
- `break` — once found, no need to check other j.
- Return `dp[n]`.

## Complexity

- Time: O(n² × L) where L = average word length (substring + hash lookup). Can optimize by limiting j to `i - maxWordLength`.
- Space: O(n) — dp array + dictionary set.

## Common Mistakes

- **Not optimizing the inner loop.** Limit `j` to `i - maxWordLength` (words longer than maxWordLength can't match). Reduces time to O(n × maxWordLength).
- **Using `dp[i]` instead of `dp[j]`.** The recurrence: `dp[i] = true` if `dp[j]` is true AND `s[j..i-1]` is a word. The `dp[j]` (not `dp[i]`) is the condition.
- **Not handling empty string.** `s = ""` → dp[0] = true → return true (empty string is trivially segmentable). Problem usually guarantees non-empty.
- **Confusing with "Word Break II"** (#140) — that one returns all possible segmentations (much harder, exponential).

## How to Explain (interview)

**Opening:** Word Break checks if a string can be segmented into dictionary words. DP: `dp[i]` = can first i chars be segmented. For each i, check if there's a j where `dp[j]` is true and `s[j..i-1]` is a dictionary word. O(n²) time, O(n) space.

**The basic flow:**
```java
boolean[] dp = new boolean[n + 1];
dp[0] = true;
for (int i = 1; i <= n; i++) {
    for (int j = 0; j < i; j++) {
        if (dp[j] && dict.contains(s.substring(j, i))) { dp[i] = true; break; }
    }
}
return dp[n];
```

**The part that trips everyone up:** the recurrence uses `dp[j]` (not `dp[i]`) as the condition. Also, limit the inner loop to `maxWordLength` for optimization.

**The mistakes to remember:**
- Using `dp[i]` instead of `dp[j]` in the condition
- Not limiting the inner loop (O(n² × L) instead of O(n × maxWordLength))
- Not handling empty string
- Confusing with Word Break II (#140, returns all segmentations)
