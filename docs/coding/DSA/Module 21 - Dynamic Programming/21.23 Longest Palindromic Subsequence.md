**Tier 2 problem.** (LeetCode #516)

**Problem:** Given a string, find the length of the longest palindromic subsequence. (LeetCode #516)

**Link:** https://leetcode.com/problems/longest-palindromic-subsequence/

---

## Which Technique, and Why?

"Longest palindromic subsequence" → **DP (2D)**. `dp[i][j]` = LPS of `s[i..j]`. If `s[i] == s[j]`: `dp[i][j] = dp[i+1][j-1] + 2`. Else: `dp[i][j] = max(dp[i+1][j], dp[i][j-1])`. O(n²) time, O(n) space (optimized).

**Signal in the problem:** "longest palindromic subsequence" → 2D DP. (Not "substring" — subsequence doesn't need to be contiguous.)

## Approach

Bottom-up. Fill the table by substring length (from 1 to n). `dp[i][j]` depends on `dp[i+1][j-1]`, `dp[i+1][j]`, `dp[i][j-1]`. Optimize space to O(n).

## Pseudocode

```
n = s.length
dp = new int[n]  // dp[j] for current i
for i from n-1 down to 0:
    prev = 0  // dp[i+1][j-1]
    for j from i to n-1:
        if i == j: dp[j] = 1
        else if s[i] == s[j]: 
            temp = dp[j]
            dp[j] = prev + 2
            prev = temp
        else:
            temp = dp[j]
            dp[j] = Math.max(dp[j], dp[j-1])
            prev = temp
return dp[n-1]
```

## Java Code

```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        int[] dp = new int[n];

        for (int i = n - 1; i >= 0; i--) {
            int prev = 0;  // dp[i+1][j-1]
            for (int j = i; j < n; j++) {
                int temp = dp[j];
                if (i == j) {
                    dp[j] = 1;
                } else if (s.charAt(i) == s.charAt(j)) {
                    dp[j] = prev + 2;
                } else {
                    dp[j] = Math.max(dp[j], dp[j - 1]);
                }
                prev = temp;
            }
        }
        return dp[n - 1];
    }
}
```

## Line-by-line

- Outer loop `i` from n-1 down to 0 (bottom-up by starting position).
- `prev` saves `dp[j]` before update (which is `dp[i+1][j]`, the value from the previous row). After update, `prev` becomes `dp[i+1][j-1]` for the next column.
- `i == j`: single char → 1.
- `s[i] == s[j]`: `dp[j] = prev + 2` (extend by 2: s[i] and s[j]).
- Else: `dp[j] = max(dp[j] (skip s[i]), dp[j-1] (skip s[j]))`.
- Return `dp[n-1]` (LPS of entire string).

## Complexity

- Time: O(n²) — n² states.
- Space: O(n) — optimized from O(n²).

## Common Mistakes

- **Confusing with "Longest Palindromic Substring" (#5).** Substring = contiguous. Subsequence = not necessarily contiguous. Different problems.
- **Not handling single characters.** `i == j` → 1 (a single char is a palindrome of length 1).
- **Overwriting dp[j] before saving.** Use `temp` to save the old value (diagonal for next column).
- **Wrong loop order.** Outer loop must go from n-1 down to 0 (so `dp[j]` from the previous row is available).

## How to Explain (interview)

**Opening:** Longest Palindromic Subsequence finds the longest palindromic subsequence (not necessarily contiguous). DP: `dp[i][j]` = LPS of s[i..j]. If s[i] == s[j]: dp = dp[i+1][j-1] + 2. Else: dp = max(dp[i+1][j], dp[i][j-1]). O(n²) time, O(n) space.

**The basic flow:**
```java
int[] dp = new int[n];
for (int i = n - 1; i >= 0; i--) {
    int prev = 0;
    for (int j = i; j < n; j++) {
        int temp = dp[j];
        if (i == j) dp[j] = 1;
        else if (s.charAt(i) == s.charAt(j)) dp[j] = prev + 2;
        else dp[j] = Math.max(dp[j], dp[j - 1]);
        prev = temp;
    }
}
return dp[n - 1];
```

**The part that trips everyone up:** the space optimization. `prev` saves `dp[j]` (old value = dp[i+1][j]) before update, so it becomes dp[i+1][j-1] for the next column. Without this, you'd use the updated value (wrong).

**The mistakes to remember:**
- Confusing with Longest Palindromic Substring (#5) (contiguous vs subsequence)
- Not handling single characters (i == j → 1)
- Overwriting dp[j] before saving (wrong diagonal)
- Wrong loop order (outer must go bottom-up)
