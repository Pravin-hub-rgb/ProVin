# 21.25 Best Time to Buy and Sell Stock with Cooldown

**Tier 2 problem.** (LeetCode #309)

**Problem:** Given daily prices, find max profit with unlimited transactions, but after selling, you must wait one day before buying again (cooldown). (LeetCode #309)

**Link:** https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/

---

## Which Technique, and Why?

"Max profit with cooldown" → **DP (state machine)**. Three states: hold (have stock), sold (just sold, cooldown), rest (can buy). Transitions: hold → hold or buy; sold → rest; rest → rest or buy. O(n) time, O(1) space.

**Signal in the problem:** "cooldown" / "wait one day after selling" → state machine DP (can't use greedy).

## Approach

State machine with 3 states:
- `hold` = max profit ending with holding a stock.
- `sold` = max profit ending with just selling (cooldown next day).
- `rest` = max profit ending in cooldown/done (can buy).

Transitions:
- `hold = max(hold, rest - price)` — keep holding or buy today (from rest).
- `sold = hold_prev + price` — sell today (from yesterday's hold).
- `rest = max(rest, sold_prev)` — stay in rest or recover from cooldown.

## Pseudocode

```
hold = -prices[0], sold = 0, rest = 0
for i from 1 to n-1:
    prevHold = hold, prevSold = sold
    hold = max(hold, rest - prices[i])
    sold = prevHold + prices[i]
    rest = max(rest, prevSold)
return max(sold, rest)
```

## Java Code

```java
class Solution {
    public int maxProfit(int[] prices) {
        if (prices.length < 2) return 0;

        int hold = -prices[0];  // bought on day 0
        int sold = 0;           // can't sell on day 0
        int rest = 0;           // no stock, no cooldown

        for (int i = 1; i < prices.length; i++) {
            int prevHold = hold;
            int prevSold = sold;

            hold = Math.max(hold, rest - prices[i]);  // keep or buy
            sold = prevHold + prices[i];               // sell
            rest = Math.max(rest, prevSold);           // rest or recover
        }
        return Math.max(sold, rest);
    }
}
```

## Line-by-line

- `hold` — max profit with a stock in hand. Start: bought on day 0 → `-prices[0]`.
- `sold` — max profit after selling today (cooldown tomorrow).
- `rest` — max profit in cooldown or idle (can buy).
- Transitions use `prevHold`/`prevSold` to avoid using updated values.
- Final answer: `max(sold, rest)` — either just sold or in rest (holding is never optimal at the end).

## Complexity

- Time: O(n) — single pass.
- Space: O(1) — three variables.

## Common Mistakes

- **Using greedy.** Greedy (sum positive differences) doesn't work with cooldown. Need state machine DP.
- **Not using prev variables.** `sold = hold + prices[i]` must use yesterday's `hold`, not today's updated `hold`. Save `prevHold` before updating.
- **Wrong transitions.** `rest = max(rest, sold_prev)` — recover from cooldown. Not `rest = max(rest, hold)` — you can't buy immediately after holding without selling.
- **Confusing with "Stock II" (#122) or "Stock with Transaction Fee" (#714).** Different constraints, different state machines.
