# 21.10 Longest Increasing Subsequence

**Tier 2 problem.** (LeetCode #300)

**Problem:** Given an integer array, find the length of the longest strictly increasing subsequence. (LeetCode #300)

**Link:** https://leetcode.com/problems/longest-increasing-subsequence/

---

## Which Technique, and Why?

"Longest increasing subsequence" → **DP (O(n²)) or Binary Search (O(n log n))**. DP: `dp[i]` = length of LIS ending at i. For each i, check all j < i: if `nums[j] < nums[i]`, `dp[i] = max(dp[i], dp[j] + 1)`. The binary search approach maintains a "tails" array and binary searches for the insertion point. O(n log n) time, O(n) space.

**Signal in the problem:** "longest increasing subsequence" / "LIS" → DP (O(n²)) or patience sorting (O(n log n)).

## Approach (DP — O(n²))

`dp[i]` = length of LIS ending at index i. For each i, check all j < i: if `nums[j] < nums[i]`, update `dp[i] = max(dp[i], dp[j] + 1)`. Answer = max(dp).

## Pseudocode (DP)

```
dp = new int[n], all 1
for i from 1 to n-1:
    for j from 0 to i-1:
        if nums[j] < nums[i]:
            dp[i] = max(dp[i], dp[j] + 1)
return max(dp)
```

## Java Code (DP — O(n²))

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        int max = 1;

        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            max = Math.max(max, dp[i]);
        }
        return max;
    }
}
```

## Java Code (Binary Search — O(n log n))

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;

        for (int x : nums) {
            int lo = 0, hi = size;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (tails[mid] < x) lo = mid + 1;
                else hi = mid;
            }
            tails[lo] = x;
            if (lo == size) size++;
        }
        return size;
    }
}
```

## Line-by-line (DP)

- `dp[i]` = length of LIS ending at i.
- Base: `dp[i] = 1` (the element itself).
- For each i, check all j < i. If `nums[j] < nums[i]`, we can extend the subsequence ending at j.
- `max = max(max, dp[i])` — track the best.

## Complexity

- DP: O(n²) time, O(n) space.
- Binary search: O(n log n) time, O(n) space.

## Common Mistakes

- **Not initializing dp to 1.** Each element is a subsequence of length 1. `Arrays.fill(dp, 1)`.
- **Using `<=` instead of `<`.** Strictly increasing means `nums[j] < nums[i]`. Using `<=` allows equal elements (wrong).
- **Confusing with "Longest Common Subsequence" (#1143).** LCS compares two strings; LIS is on one array.
- **Not tracking the global max.** `dp[n-1]` isn't necessarily the answer. Track `max(dp)`.

## How to Explain (interview)

**Opening:** Longest Increasing Subsequence (LIS) finds the longest strictly increasing subsequence. DP: `dp[i]` = LIS ending at i. For each i, check all j < i; if `nums[j] < nums[i]`, `dp[i] = max(dp[i], dp[j] + 1)`. O(n²) time, O(n) space. Optimized to O(n log n) with binary search (patience sorting).

**The basic flow (DP):**
```java
int[] dp = new int[n]; Arrays.fill(dp, 1);
for (int i = 1; i < n; i++) {
    for (int j = 0; j < i; j++) {
        if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
    }
}
return Arrays.stream(dp).max().orElse(0);
```

**The part that trips everyone up:** `dp[i]` is the LIS **ending at i**, not the LIS of the first i elements. Also, track the global max (not just `dp[n-1]`).

**The mistakes to remember:**
- Not initializing dp to 1
- Using `<=` instead of `<` (strictly increasing)
- Not tracking global max
- Confusing with LCS (#1143) (different problem)
