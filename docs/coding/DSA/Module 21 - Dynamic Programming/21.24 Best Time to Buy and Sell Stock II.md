**Tier 2 problem.** (LeetCode #122)

**Problem:** Given daily prices, find the maximum profit with unlimited transactions (buy and sell multiple times, but must sell before buying again). (LeetCode #122)

**Link:** https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/

---

## Which Technique, and Why?

"Max profit with unlimited transactions" → **Greedy** (sum all positive differences) or **DP**. Greedy: buy at every valley, sell at every peak → sum all positive day-to-day differences. O(n) time, O(1) space. Simpler than DP.

**Signal in the problem:** "unlimited transactions" / "buy and sell multiple times" → greedy (sum positive differences) or DP (state machine).

## Approach (Greedy)

Sum all positive differences between consecutive days. If price[i] > price[i-1], add the difference. This captures every "up" movement.

## Pseudocode

```
profit = 0
for i from 1 to n-1:
    if prices[i] > prices[i-1]:
        profit += prices[i] - prices[i-1]
return profit
```

## Java Code

```java
class Solution {
    public int maxProfit(int[] prices) {
        int profit = 0;
        for (int i = 1; i < prices.length; i++) {
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }
        return profit;
    }
}
```

## Line-by-line

- For each day, if the price went up from yesterday, "buy yesterday, sell today" and capture the profit.
- Summing all positive differences captures all up-movements (which can be combined into fewer transactions, but the total is the same).

## Complexity

- Time: O(n) — single pass.
- Space: O(1).

## Common Mistakes

- **Trying DP when greedy works.** Greedy is simpler and faster. DP (state machine) is for "with cooldown" or "with transaction fee" variants.
- **Thinking you need to find all peaks/valleys.** You don't — just sum positive differences. This naturally captures all profitable segments.
- **Confusing with Stock I (#121).** Stock I allows only ONE transaction. Stock II allows unlimited. Different algorithms.
- **Confusing with Stock with Cooldown (#309) or Transaction Fee (#714).** Those need DP (state machine).

## How to Explain (interview)

**Opening:** Best Time to Buy and Sell Stock II maximizes profit with unlimited transactions. Greedy: sum all positive day-to-day differences. Every up-movement is captured. O(n) time, O(1) space. Simpler than DP.

**The basic flow:**
```java
int profit = 0;
for (int i = 1; i < prices.length; i++) {
    if (prices[i] > prices[i - 1]) profit += prices[i] - prices[i - 1];
}
return profit;
```

**The part that trips everyone up:** greedy works because you can "buy and sell" on consecutive days. If prices go 1→3→5, you can buy at 1, sell at 3, buy at 3, sell at 5 = (3-1)+(5-3) = (5-1). Same total. So summing positive differences is correct.

**The mistakes to remember:**
- Using DP when greedy works (overcomplicating)
- Confusing with Stock I (#121, one transaction)
- Confusing with Stock with Cooldown (#309) or Transaction Fee (#714) (need DP)
- Not handling empty/single-element arrays (returns 0)
