# 7.7 Minimum Number of Arrows to Burst Balloons

**Tier 2 problem.** (LeetCode #452)

**Problem:** Given balloons as intervals [start, end] on a number line, find the minimum number of arrows (each arrow at one x-position bursts all balloons covering that x). (LeetCode #452)

**Link:** https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/

---

## Which Technique, and Why?

"Minimum arrows to burst all balloons" → **Greedy: sort by end, shoot arrow at the end of the first balloon, burst all overlapping.** Same idea as Non-overlapping Intervals but counting arrows instead of removals. O(n log n) time, O(1) space.

**Signal in the problem:** "minimum arrows" / "burst balloons" / "points covering intervals" → sort by end, greedy shoot.

## Approach

Sort balloons by end. Shoot an arrow at the end of the first balloon. This bursts all balloons whose start ≤ arrow position. Count arrows. Move to the next unburst balloon.

## Pseudocode

```
sort balloons by end
arrows = 1
arrowPos = balloons[0][1]
for i from 1 to n-1:
    if balloons[i][0] > arrowPos:  // not burst
        arrows++
        arrowPos = balloons[i][1]
return arrows
```

## Java Code

```java
class Solution {
    public int findMinArrowShots(int[][] points) {
        if (points.length == 0) return 0;
        Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1])); // sort by end

        int arrows = 1;
        int arrowPos = points[0][1];

        for (int i = 1; i < points.length; i++) {
            if (points[i][0] > arrowPos) {  // not burst by current arrow
                arrows++;
                arrowPos = points[i][1];
            }
        }
        return arrows;
    }
}
```

## Line-by-line

- Sort by end position.
- First arrow at the end of the first balloon.
- For each balloon: if its start > arrowPos, it's not burst → shoot a new arrow at its end.
- If `points[i][0] <= arrowPos`, the balloon is already burst (covered by the current arrow).

## Complexity

- Time: O(n log n) — sorting dominates.
- Space: O(1) extra (or O(log n) for sort stack).

## Common Mistakes

- **Sorting by start instead of end.** Sort by end for the greedy "shoot at end" strategy.
- **Using `>=` instead of `>`.** If `points[i][0] == arrowPos`, the balloon is burst (arrow at that position covers it). Use `>`.
- **Not handling empty input.** Return 0.
- **Confusing with Non-overlapping Intervals (#435).** Same greedy idea, different counting (arrows vs removals).

## How to Explain (interview)

**Opening:** Minimum Arrows to Burst Balloons finds the minimum arrows to burst all balloons. Greedy: sort by end, shoot an arrow at the end of the first balloon (bursts all overlapping). Count arrows. O(n log n) time, O(1) space.

**The basic flow:**
```java
Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));
int arrows = 1, pos = points[0][1];
for (int i = 1; i < points.length; i++) {
    if (points[i][0] > pos) { arrows++; pos = points[i][1]; }
}
```

**The part that trips everyone up:** sort by **end**, not start. The arrow is shot at the **end** of the first balloon, bursting all that overlap. Also, `points[i][0] > pos` (strictly greater) — if equal, the balloon is already burst.

**The mistakes to remember:**
- Sorting by start instead of end
- Using `>=` instead of `>` (touching balloons are burst)
- Not handling empty input
- Confusing with Non-overlapping Intervals (#435)
