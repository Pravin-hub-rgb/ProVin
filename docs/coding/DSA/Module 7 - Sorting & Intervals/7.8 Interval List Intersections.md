# 7.8 Interval List Intersections

**Tier 2 problem.** (LeetCode #986)

**Problem:** Given two lists of disjoint intervals (each sorted by start), find their intersection. (LeetCode #986)

**Link:** https://leetcode.com/problems/interval-list-intersections/

---

## Which Technique, and Why?

"Find intersections of two sorted interval lists" → **Two Pointers (one per list)**. Compare current intervals from both lists; if they overlap, add the intersection (max of starts, min of ends). Advance the pointer with the smaller end. O(m + n) time, O(1) extra space.

**Signal in the problem:** "interval list intersections" / "two lists of intervals" → two pointers, advance the one with smaller end.

## Approach

Two pointers i (first list) and j (second list). While both valid: compute overlap (if `max(starts) <= min(ends)`). If overlap, add `{max(starts), min(ends)}`. Advance the pointer with the smaller end (that interval can't overlap with anything else).

## Pseudocode

```
i = 0, j = 0
result = []
while i < A.length and j < B.length:
    lo = max(A[i][0], B[j][0])
    hi = min(A[i][1], B[j][1])
    if lo <= hi: result.add({lo, hi})
    if A[i][1] < B[j][1]: i++
    else: j++
return result
```

## Java Code

```java
class Solution {
    public int[][] intervalIntersection(int[][] firstList, int[][] secondList) {
        List<int[]> result = new ArrayList<>();
        int i = 0, j = 0;

        while (i < firstList.length && j < secondList.length) {
            int lo = Math.max(firstList[i][0], secondList[j][0]);
            int hi = Math.min(firstList[i][1], secondList[j][1]);

            if (lo <= hi) result.add(new int[]{lo, hi});

            if (firstList[i][1] < secondList[j][1]) i++;
            else j++;
        }

        return result.toArray(new int[result.size()][]);
    }
}
```

## Line-by-line

- `lo = max(starts)`, `hi = min(ends)` — the intersection (if any).
- `if (lo <= hi)` — overlap exists → add.
- Advance the pointer with the smaller end — that interval can't overlap with any future interval from the other list.

## Complexity

- Time: O(m + n) — each pointer advances at most m or n times.
- Space: O(1) extra (result is output).

## Common Mistakes

- **Advancing both pointers.** Only advance the one with the smaller end. Advancing both skips potential intersections.
- **Not checking `lo <= hi`.** If `lo > hi`, no overlap → don't add.
- **Assuming lists are sorted.** Problem guarantees sorted by start. If not, sort first.
- **Confusing with "Merge Intervals" (#56).** Merge merges overlapping intervals in one list. This finds intersections between two lists.
