## How to use
1. Work **pattern by pattern**, in the order below (it is the order that builds on itself).
2. For each problem: try honestly for 20-25 minutes, then read the editorial or a solution, then **re-solve it from scratch the next day**.
3. Tick the box when you can solve it alone, without hints.
4. Revisit the ones you struggled with after a week.

*Difficulty labels and tiers are best-effort judgments, and links are built from problem titles. If a link does not open, search the title on LeetCode.*
