# 2.22 Majority Element II

**Tier 2 problem.** (LeetCode #229)

**Problem:** Given an array, find all elements that appear more than ⌊n/3⌋ times. (LeetCode #229)

**Link:** https://leetcode.com/problems/majority-element-ii/

---

## Which Technique, and Why?

"Elements appearing more than n/3 times" → at most 2 such elements. **Boyer-Moore Voting (extended)** — track two candidates and two counts. O(n) time, O(1) space. Or use a HashMap (O(n) space) — simpler.

**Signal in the problem:** "more than n/3" / "majority element II" → at most 2 candidates → Boyer-Moore with two counters, or HashMap.

## Approach (HashMap — simpler)

Count frequencies. Return keys with count > n/3.

## Approach (Boyer-Moore — O(1) space)

Track two candidates and two counts. For each element: if it matches a candidate, increment that count. If a count is 0, set that candidate. Otherwise decrement both. After the pass, verify each candidate's count > n/3 (Boyer-Moore only guarantees candidates; verification is needed).

## Pseudocode (Boyer-Moore)

```
cand1 = null, cand2 = null, count1 = 0, count2 = 0
for x in nums:
    if x == cand1: count1++
    else if x == cand2: count2++
    else if count1 == 0: cand1 = x; count1 = 1
    else if count2 == 0: cand2 = x; count2 = 1
    else: count1--; count2--
// verify
result = []
for c in {cand1, cand2}:
    if count of c in nums > n/3: result.add(c)
return result
```

## Java Code (HashMap)

```java
class Solution {
    public List<Integer> majorityElement(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) freq.put(x, freq.getOrDefault(x, 0) + 1);
        List<Integer> result = new ArrayList<>();
        int n = nums.length;
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            if (e.getValue() > n / 3) result.add(e.getKey());
        }
        return result;
    }
}
```

## Java Code (Boyer-Moore)

```java
class Solution {
    public List<Integer> majorityElement(int[] nums) {
        Integer cand1 = null, cand2 = null;
        int count1 = 0, count2 = 0;

        for (int x : nums) {
            if (cand1 != null && x == cand1) count1++;
            else if (cand2 != null && x == cand2) count2++;
            else if (count1 == 0) { cand1 = x; count1 = 1; }
            else if (count2 == 0) { cand2 = x; count2 = 1; }
            else { count1--; count2--; }
        }

        // Verify
        List<Integer> result = new ArrayList<>();
        int n = nums.length;
        if (cand1 != null && count(nums, cand1) > n / 3) result.add(cand1);
        if (cand2 != null && cand2 != cand1 && count(nums, cand2) > n / 3) result.add(cand2);
        return result;
    }

    private int count(int[] nums, int target) {
        int c = 0;
        for (int x : nums) if (x == target) c++;
        return c;
    }
}
```

## Line-by-line (Boyer-Moore)

- Track two candidates and counts.
- For each element: if it matches a candidate, increment; if a count is 0, set candidate; otherwise decrement both.
- After the pass, verify each candidate's actual count > n/3 (Boyer-Moore only guarantees candidates, not majority).

## Complexity

- HashMap: O(n) time, O(n) space.
- Boyer-Moore: O(n) time, O(1) space.

## Common Mistakes

- **Not verifying candidates.** Boyer-Moore only gives candidates; you must verify their counts.
- **Duplicate candidate.** If cand1 == cand2, don't add twice. Check `cand2 != cand1`.
- **Threshold.** "More than n/3" means `> n/3`, not `>= n/3`. For n=3, threshold is >1, so 2+ occurrences.
- **Using HashMap when O(1) space is required.** HashMap is simpler; Boyer-Moore is for O(1) space.

## How to Explain (interview)

**Opening:** Majority Element II finds elements appearing more than n/3 times (at most 2 such elements). HashMap approach: count frequencies, return keys with count > n/3 — O(n) time, O(n) space. Boyer-Moore (extended): track two candidates and counts; verify each candidate's actual count. O(n) time, O(1) space.

**The basic flow (Boyer-Moore):**
```java
Integer cand1 = null, cand2 = null;
int count1 = 0, count2 = 0;
for (int x : nums) {
    if (x == cand1) count1++;
    else if (x == cand2) count2++;
    else if (count1 == 0) { cand1 = x; count1 = 1; }
    else if (count2 == 0) { cand2 = x; count2 = 1; }
    else { count1--; count2--; }
}
// verify both candidates
```

**The part that trips everyone up:** Boyer-Moore only gives **candidates**, not guaranteed majority elements. You must verify each candidate's actual count > n/3. Also, handle the case where cand1 == cand2 (don't add twice).

**The mistakes to remember:**
- Not verifying candidates (wrong answer on non-majority inputs)
- Duplicate candidate (cand1 == cand2)
- Threshold: "more than n/3" means strictly greater
- Using HashMap when O(1) space is required
