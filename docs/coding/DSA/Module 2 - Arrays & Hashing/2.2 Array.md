An array is a fixed-size, contiguous block of elements of the same type, accessed by index. It is the most basic data structure and the input to almost every DSA problem.

---

## Declaration and Creation

```java
// Method 1 — declare size, fill later (default 0 for int)
int[] arr = new int[5];              // [0, 0, 0, 0, 0]

// Method 2 — initialize with values
int[] nums = {10, 20, 30, 40, 50};

// Method 3 — new with values
int[] vals = new int[]{1, 2, 3};

// Other primitive types
double[] prices = new double[3];     // [0.0, 0.0, 0.0]
char[] letters = {'a', 'b', 'c'};
boolean[] flags = new boolean[4];    // [false, false, false, false]
```

**Note:** `new int[5]` fills with 0. `new String[5]` fills with `null` (not empty strings). Don't assume a default for reference types.

## Accessing and Modifying

```java
int[] arr = {10, 20, 30, 40, 50};

System.out.println(arr[0]);            // 10 — first element
System.out.println(arr[4]);            // 50 — last element
System.out.println(arr.length);        // 5 — length is a FIELD (no parens)

arr[2] = 99;                          // modify in place
System.out.println(arr[arr.length - 1]); // 50 — last element idiom
```

**Important:** `arr.length` is a field (no parentheses). For Strings it's `s.length()` (a method). This inconsistency trips everyone up once.

## Traversing

```java
int[] arr = {10, 20, 30, 40, 50};

// Classic for loop — use when you need the index
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}

// Enhanced for — cleaner, values only
for (int x : arr) {
    System.out.println(x);
}
```

## Common Operations (java.util.Arrays)

```java
import java.util.Arrays;

int[] arr = {30, 10, 50, 20, 40};

Arrays.sort(arr);                          // in place: [10,20,30,40,50]
int idx = Arrays.binarySearch(arr, 30);    // 2 (index of 30)
int[] copy = Arrays.copyOf(arr, arr.length); // copy
Arrays.fill(arr, 0);                       // fill all with 0
System.out.println(Arrays.toString(arr));  // "[0, 0, 0, 0, 0]"
```

- `Arrays.sort` on primitives uses a tuned quicksort. On objects it uses TimSort (stable).
- `Arrays.toString` is how you print an array — printing `arr` directly gives a hash like `[I@6d06d69c`.

## Cost (Big-O)

| Operation | Time |
|---|---|
| Access by index `arr[i]` | O(1) |
| Search (linear) | O(n) |
| Insert/remove at end | O(1) (if space available) |
| Insert/remove in middle | O(n) (shifts elements) |
| Sort | O(n log n) |

## Pitfalls

- **Off-by-one:** loop condition must be `i < arr.length`, not `i <= arr.length`. Last valid index is `length - 1`.
- **Fixed size:** you can't grow an array. Use `ArrayList` when size is unknown (see 2.2).
- **Reference copy:** `int[] b = a;` does NOT copy — both point to the same array. Use `Arrays.copyOf` or `clone()`.
- **Default values:** `new int[5]` → 0; `new boolean[5]` → false; `new String[5]` → null.
- **Printing:** use `Arrays.toString(arr)`, not `System.out.println(arr)`.

## A Small Program: Find Max and Min

```java
public class FindMaxMin {
    static int findMax(int[] arr) {
        int max = arr[0];
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max) max = arr[i];
        }
        return max;
    }

    static int findMin(int[] arr) {
        int min = arr[0];
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] < min) min = arr[i];
        }
        return min;
    }

    public static void main(String[] args) {
        int[] arr = {3, 1, 4, 1, 5, 9, 2, 6};
        System.out.println("Max = " + findMax(arr));  // 9
        System.out.println("Min = " + findMin(arr));  // 1
    }
}
```

## In Your Own Words

1. What is the time complexity of accessing an array element by index, and why?

<details>
<summary>Show Answer</summary>

**Sample Answer:** O(1). Arrays store elements in contiguous memory, so the address of `arr[i]` is computed as `base_address + i * element_size` — a single arithmetic operation, no traversal needed.

</details>

2. Why does `int[] b = a;` not create a copy?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Arrays are reference types. `a` holds a reference (memory address) to the array object. `b = a` copies that reference, so both point to the same array. To copy, use `Arrays.copyOf(a, a.length)` or `a.clone()`.

</details>

3. What's the difference between `arr.length` and `s.length()`?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `arr.length` is a public field of the array object (no parentheses). `s.length()` is a method of the String class (with parentheses). Arrays use a field; Strings use a method. The compiler enforces the difference — `arr.length()` and `s.length` won't compile.

</details>
