**Problem:** Given an integer array `nums`, return an array `answer` such that `answer[i]` is equal to the product of all the elements of `nums` except `nums[i]`.

The product of any prefix or suffix of `nums` is **guaranteed** to fit in a 32-bit integer.

You must write an algorithm that runs in O(n) time and **without using the division operation**.

**Link:** https://leetcode.com/problems/product-of-array-except-self/

---

## Example 1

**Input:** `nums = [1,2,3,4]`

**Output:** `[24,12,8,6]`

**Explanation:**
- answer[0] = 2×3×4 = 24
- answer[1] = 1×3×4 = 12
- answer[2] = 1×2×4 = 8
- answer[3] = 1×2×3 = 6

---

## Example 2

**Input:** `nums = [-1,1,0,-3,3]`

**Output:** `[0,0,12,0,0]`

---

## Constraints

- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- The product of any prefix or suffix of `nums` is **guaranteed** to fit in a 32-bit integer.

**Follow-up:** Can you solve it in O(1) extra space complexity? (The output array does not count as extra space for the purpose of space complexity analysis.)

---

## Which Data Structure, and Why?

The key insight: `result[i] = (product of elements left of i) × (product of elements right of i)`. You don't need a complex data structure — you need **prefix and suffix products**. Use the output array itself to store intermediate results (O(1) extra space).

Why no division? The problem forbids it (and division by zero is a problem anyway). Prefix/suffix products avoid division entirely.

**Signal in the problem:** "product of all elements except self" + "no division" → prefix/suffix products.

## Approach

Two passes:
1. Left to right: `output[i] = product of all elements before i` (prefix).
2. Right to left: multiply `output[i]` by the running product of all elements after i (suffix).

O(n) time, O(1) extra space (output array doesn't count as extra).

## Pseudocode

```
n = nums.length
output = new array of size n
output[0] = 1
for i from 1 to n-1:
    output[i] = output[i-1] * nums[i-1]     // prefix
suffix = 1
for i from n-1 down to 0:
    output[i] *= suffix                      // multiply by suffix
    suffix *= nums[i]
return output
```

## Java Code

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] output = new int[n];

        // Pass 1: prefix products
        output[0] = 1;
        for (int i = 1; i < n; i++) {
            output[i] = output[i - 1] * nums[i - 1];
        }

        // Pass 2: multiply by suffix products
        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {
            output[i] *= suffix;
            suffix *= nums[i];
        }

        return output;
    }
}
```

## Line-by-line

- `output[0] = 1` — no elements to the left of index 0, so prefix product is 1.
- Pass 1: `output[i] = output[i-1] * nums[i-1]` — prefix product up to i.
- Pass 2: `suffix` tracks the running product of elements to the right. `output[i] *= suffix` multiplies prefix by suffix. Then `suffix *= nums[i]` extends suffix leftward.
- After both passes, `output[i] = prefix[i] × suffix[i]` = product of all except self.

## Complexity

- Time: O(n) — two passes.
- Space: O(1) extra (output array is the return value, not counted as extra).

## Common Mistakes

- **Using division** — problem forbids it; also division by zero if any element is 0.
- **O(n) extra space** — allocating separate prefix and suffix arrays. The trick is reusing the output array.
- **Overflow:** products can exceed int range. If the problem has large values, use `long` and cast. (LeetCode #238 uses ints and expects int output, so int is fine here.)
- **Off-by-one in prefix:** `output[i] = output[i-1] * nums[i-1]`, not `nums[i]`.

## How to Explain (interview)

**Opening:** Product Except Self asks for the product of all elements except the current one, without division. The key idea: result[i] = (product of elements to the left) × (product of elements to the right). Two passes: first pass fills the output array with prefix products; second pass multiplies each by the running suffix product. O(n) time, O(1) extra space.

**The basic flow:**
```java
int[] out = new int[n];
out[0] = 1;
for (int i = 1; i < n; i++) out[i] = out[i-1] * nums[i-1];
int suffix = 1;
for (int i = n-1; i >= 0; i--) { out[i] *= suffix; suffix *= nums[i]; }
```

**The part that trips everyone up:** no division allowed (and division by zero). Also reuse the output array for both passes — don't allocate separate prefix/suffix arrays.

**The mistakes to remember:**
- Using division (forbidden, and breaks on zeros)
- Allocating O(n) extra space instead of reusing output
- Off-by-one: prefix uses `nums[i-1]`, not `nums[i]`
