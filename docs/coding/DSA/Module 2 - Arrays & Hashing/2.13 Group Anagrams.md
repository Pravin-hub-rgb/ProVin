**Problem:** Given an array of strings `strs`, group the anagrams together. You can return the answer in **any order**.

An **Anagram** is a word or phrase formed by rearranging the letters of a different word or phrase, typically using all the original letters exactly once.

**Link:** https://leetcode.com/problems/group-anagrams/

---

## What This Problem Is Asking (Simple Terms)

You have an array of strings. You need to group together all strings that are anagrams of each other — strings that contain the same characters with the same frequencies.

For example, `"eat"`, `"tea"`, and `"ate"` are all anagrams (they all contain e×1, a×1, t×1), so they belong in the same group. `"bat"` is alone — it's not an anagram of any other string.

You are not asked to find *which* strings are anagrams of a specific one — just to group all anagrams together into separate lists.

---

## Example 1

**Input:** `strs = ["eat","tea","tan","ate","nat","bat"]`

**Output:** `[["bat"],["nat","tan"],["ate","eat","tea"]]`

**Explanation:**
- `"bat"` is alone → its own group.
- `"nat"` and `"tan"` are anagrams → same group.
- `"ate"`, `"eat"`, `"tea"` are anagrams → same group.

---

## Example 2

**Input:** `strs = [""]`

**Output:** `[[""]]`

---

## Example 3

**Input:** `strs = ["a"]`

**Output:** `[["a"]]`

## Constraints

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` consists of lowercase English letters.

**Follow-up:** How would you handle Unicode characters or very long strings efficiently?

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could compare every pair of strings to check if they're anagrams (sort each, compare). If two strings are anagrams, put them in the same group. This requires comparing every pair — O(n²) comparisons, each taking O(k log k) to sort.

### Brute Force Pseudocode

```
groups = empty list of lists
used = array of false, size n
for i from 0 to n-1:
    if used[i]: continue
    group = [strs[i]]
    used[i] = true
    for j from i+1 to n-1:
        if used[j]: continue
        if sorted(strs[i]) == sorted(strs[j]):
            group.add(strs[j])
            used[j] = true
    groups.add(group)
return groups
```

### Why Brute Force Is Slow

Comparing every pair takes O(n²) string comparisons. Each comparison sorts both strings (O(k log k)). Total: O(n² × k log k) — too slow for large inputs.

## Which Data Structure, and Why?

You need to group strings that share the same "anagram signature." Two strings are anagrams if their **sorted versions are identical**. So:

- Sort each string to get a key (e.g., `"eat"` → `"aet"`, `"tea"` → `"aet"`, `"bat"` → `"abt"`)
- Map each key → list of strings that share it
- At the end, return all the lists

This is a **HashMap<String, List<String>>** because:
- **Key** = the sorted string (the anagram signature)
- **Value** = list of all strings with that key

**Signal in the problem:** "group" + "anagrams" → group by a computed key → HashMap<String, List<String>>.

---

## Optimized Approach (HashMap with Sorted Key)

1. Create an empty HashMap<String, List<String>>
2. For each string:
   - Convert to char array, sort it, make a String key
   - Use `computeIfAbsent(key, k -> new ArrayList<>())` to get or create the list
   - Add the string to that list
3. Return all values from the map

### Pseudocode

```
groups = empty map (String -> List<String>)
for each word in words:
    key = sorted(word)   // sort characters
    groups[key].add(word)
return all values of groups
```

### Java Code

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new HashMap<>();

        for (String s : strs) {
            char[] chars = s.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);

            groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }

        return new ArrayList<>(groups.values());
    }
}
```

### Line-by-line

- `groups` maps a sorted key to the list of anagram strings.
- For each string: convert to char array, sort it, make a new String key.
- `computeIfAbsent(key, k -> new ArrayList<>())` — creates the list if the key is new, returns it (existing or new). Then `.add(s)` adds the string.
- `groups.values()` returns all the lists; wrap in `new ArrayList<>(...)` to return as `List<List<String>>`.

## Complexity

- Time: O(n × k log k) where n = number of strings, k = max string length (sorting each string).
- Space: O(n × k) — storing all strings in the map.

Alternative with counting key: O(n × k) time (no sorting), but the key construction is longer.

## Common Mistakes

- **Using the original string as the key.** "eat" and "tea" are different strings but anagrams — key must be the sorted form (or frequency signature).
- **Forgetting `computeIfAbsent` / creating duplicate lists.** Use `computeIfAbsent` or check `containsKey` before `put`.
- **Returning `groups.values()` directly.** It's a `Collection`, not a `List`. Wrap with `new ArrayList<>(...)`.
- **Empty string / single char edge cases.** `""` sorts to `""` — works fine, but make sure your code handles it.

## How to Explain (interview)

**Opening:** Group Anagrams groups strings that are anagrams of each other. The idea: two strings are anagrams iff their sorted character sequences are identical. So sort each string to get a "key," then group all strings sharing the same key using a HashMap<String, List<String>>. O(n × k log k) time where k is string length.

**The basic flow:**
```java
Map<String, List<String>> groups = new HashMap<>();
for (String s : strs) {
    char[] c = s.toCharArray();
    Arrays.sort(c);
    groups.computeIfAbsent(new String(c), k -> new ArrayList<>()).add(s);
}
return new ArrayList<>(groups.values());
```

**The part that trips everyone up:** the key must be the **sorted string**, not the original. Also `groups.values()` is a Collection — wrap it in `new ArrayList<>()` to match the return type.

**The mistakes to remember:**
- Using the original string as the key (won't group anagrams)
- Forgetting to wrap `values()` in a new ArrayList
- Not handling empty strings
