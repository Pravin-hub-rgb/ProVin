# 2.13 Group Anagrams

**Problem:** Given an array of strings, group the anagrams together. (LeetCode #49)

**Link:** https://leetcode.com/problems/group-anagrams/

---

## Which Data Structure, and Why?

You need to group strings that are anagrams of each other. Two strings are anagrams if their **sorted versions are identical** (or their character frequency maps match). So the "key" for grouping is the sorted string (or frequency signature). Map key → list of strings → **HashMap<String, List<String>>**.

Why a map of lists? Each key (sorted form) maps to all strings that share it. The value is a list because multiple strings can be anagrams.

**Signal in the problem:** "group" + "anagrams" → group by a computed key → HashMap<String, List<String>>.

## Approach

**Brute force (O(n² × k log k)):** compare every pair of strings for anagram (sort each, compare). Group manually.

**Optimized (O(n × k log k)):** for each string, compute its key (sorted characters). Put it in the map under that key. At the end, return all the lists.

The sorting of each string (k log k) dominates. Alternative: use a character count array as the key (O(n × k) total) — faster for long strings.

## Pseudocode

```
groups = empty map (String -> List<String>)
for each word in words:
    key = sorted(word)   // sort characters
    groups[key].add(word)
return all values of groups
```

## Java Code

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new HashMap<>();

        for (String s : strs) {
            char[] chars = s.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);

            groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }

        return new ArrayList<>(groups.values());
    }
}
```

## Line-by-line

- `groups` maps a sorted key to the list of anagram strings.
- For each string: convert to char array, sort it, make a new String key.
- `computeIfAbsent(key, k -> new ArrayList<>())` — creates the list if the key is new, returns it (existing or new). Then `.add(s)` adds the string.
- `groups.values()` returns all the lists; wrap in `new ArrayList<>(...)` to return as `List<List<String>>`.

## Complexity

- Time: O(n × k log k) where n = number of strings, k = max string length (sorting each string).
- Space: O(n × k) — storing all strings in the map.

Alternative with counting key: O(n × k) time (no sorting), but the key construction is longer.

## Common Mistakes

- **Using the original string as the key.** "eat" and "tea" are different strings but anagrams — key must be the sorted form (or frequency signature).
- **Forgetting `computeIfAbsent` / creating duplicate lists.** Use `computeIfAbsent` or check `containsKey` before `put`.
- **Returning `groups.values()` directly.** It's a `Collection`, not a `List`. Wrap with `new ArrayList<>(...)`.
- **Empty string / single char edge cases.** `""` sorts to `""` — works fine, but make sure your code handles it.

## How to Explain (interview)

**Opening:** Group Anagrams groups strings that are anagrams of each other. The idea: two strings are anagrams iff their sorted character sequences are identical. So sort each string to get a "key," then group all strings sharing the same key using a HashMap<String, List<String>>. O(n × k log k) time where k is string length.

**The basic flow:**
```java
Map<String, List<String>> groups = new HashMap<>();
for (String s : strs) {
    char[] c = s.toCharArray();
    Arrays.sort(c);
    groups.computeIfAbsent(new String(c), k -> new ArrayList<>()).add(s);
}
return new ArrayList<>(groups.values());
```

**The part that trips everyone up:** the key must be the **sorted string**, not the original. Also `groups.values()` is a Collection — wrap it in `new ArrayList<>()` to match the return type.

**The mistakes to remember:**
- Using the original string as the key (won't group anagrams)
- Forgetting to wrap `values()` in a new ArrayList
- Not handling empty strings
