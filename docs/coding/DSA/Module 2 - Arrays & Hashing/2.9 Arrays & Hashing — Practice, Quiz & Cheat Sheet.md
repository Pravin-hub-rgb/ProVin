## Mini Quiz

Answer these before looking at solutions:

1. **Contains Duplicate:** Which data structure gives O(1) lookup to check "have I seen this value before?"

<details>
<summary>Show Answer</summary>
**HashSet.** It stores unique values with O(1) add and contains. Perfect for "have I seen this?" membership testing.
</details>

2. **Two Sum:** Why use HashMap instead of HashSet?

<details>
<summary>Show Answer</summary>
Because we need the **index** of the complement, not just yes/no. HashMap stores `value → index`, so when we find the complement we also get its position. HashSet only tells us yes/no.
</details>

3. **Valid Anagram:** Why can't we use a HashSet instead of a frequency map?

<details>
<summary>Show Answer</summary>
A set only tracks presence, not count. "aabc" and "abbc" both have {a, b, c} but different frequencies. You need counts (HashMap or int[26]).
</details>

4. **Best Time to Buy and Sell Stock:** What do we track as we walk the array?

<details>
<summary>Show Answer</summary>
`minPrice` (lowest seen so far) and `maxProfit`. At each day, profit = today's price − min so far; track the max.
</details>

5. **Majority Element:** What threshold must the majority element exceed?

<details>
<summary>Show Answer</sup>
More than `n/2` times. For n=4, need 3+ occurrences (strictly greater than n/2).
</details>

## Cheat Sheet

| Problem | Data Structure | Time | Space | Key Insight |
|---|---|---|---|---|
| Two Sum | HashMap | O(n) | O(n) | Store value → index; check complement |
| Contains Duplicate | HashSet | O(n) | O(n) | add() returns false on duplicate |
| Valid Anagram | int[26] or HashMap | O(n) | O(1) | Count chars: increment s, decrement t |
| Group Anagrams | HashMap<String, List> | O(n×k log k) | O(n×k) | Sort each string to get grouping key |
| Top K Frequent | HashMap + MinHeap | O(n log k) | O(n) | Min-heap of size k by frequency |
| Product Except Self | Prefix/Suffix | O(n) | O(1) | Left products × right products |
| Majority Element | HashMap or Boyer-Moore | O(n) | O(n)/O(1) | Boyer-Moore cancels non-majorities |
| Best Time to Buy/Sell | 2 variables | O(n) | O(1) | Track min so far, compute profit |
| Maximum Subarray | Kadane's | O(n) | O(1) | currentSum = max(x, currentSum + x) |
| Sort Colors | Dutch National Flag | O(n) | O(1) | 3 pointers: low, mid, high |

## Pattern Summary (Traverse, Check, Store)

The Arrays & Hashing pattern:

1. **Traverse** the array once (one element at a time).
2. **Check** your memory (HashMap/HashSet): "do I already have what I need?"
3. **Store** the current element in memory if not found.

This turns O(n²) nested loops into O(n) single pass by trading space for time.

**When to use:** "find two numbers," "have I seen this," "group by property," "count frequencies" — anything that would otherwise need a loop inside a loop.
