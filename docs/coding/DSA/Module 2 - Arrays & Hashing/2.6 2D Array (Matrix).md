A 2D array is an array of arrays — a grid of rows and columns. It's the standard representation for matrices, boards, and grids in DSA problems (image processing, pathfinding, game boards).

---

## Declaration and Creation

```java
// Method 1 — literal initialization
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// Method 2 — create empty, fill later
int[][] grid = new int[3][4];   // 3 rows, 4 cols, all 0

// Method 3 — jagged array (rows of different lengths)
int[][] jagged = new int[3][];
jagged[0] = new int[]{1, 2};
jagged[1] = new int[]{3, 4, 5};
jagged[2] = new int[]{6};
```

**Note:** `new int[3][4]` creates a rectangular matrix. `new int[3][]` creates a jagged array — you must allocate each row separately. Most DSA problems use rectangular matrices.

## Accessing Elements

```java
int[][] m = {{1,2,3},{4,5,6},{7,8,9}};

System.out.println(m[0][0]);      // 1 — first row, first col
System.out.println(m[1][2]);      // 6 — second row, third col
System.out.println(m[2][1]);      // 8 — third row, second col

System.out.println(m.length);     // 3 — number of rows
System.out.println(m[0].length);  // 3 — number of cols (in row 0)
```

- Indexing: `matrix[row][col]`. Row first, column second.
- `matrix.length` = number of rows. `matrix[0].length` = number of columns (assuming rectangular).

## Traversing

### Row-major (row by row)

```java
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        System.out.print(matrix[i][j] + " ");
    }
    System.out.println();
}
// 1 2 3
// 4 5 6
// 7 8 9
```

### Enhanced for

```java
for (int[] row : matrix) {
    for (int val : row) {
        System.out.print(val + " ");
    }
    System.out.println();
}
```

### Column-major (column by column)

```java
for (int j = 0; j < matrix[0].length; j++) {
    for (int i = 0; i < matrix.length; i++) {
        System.out.print(matrix[i][j] + " ");
    }
    System.out.println();
}
```

## Modifying

```java
int[][] m = {{1,2,3},{4,5,6},{7,8,9}};
m[1][1] = 99;     // modify in place
// m is now {{1,2,3},{4,99,6},{7,8,9}}
```

## Cost (Big-O)

| Operation | Time |
|---|---|
| Access `m[i][j]` | O(1) |
| Full traversal | O(rows × cols) |
| In-place modification | O(1) per cell |

## Common Pitfalls

- **Row vs column confusion:** `matrix[i][j]` — i is row, j is column. Mixing them up is the #1 bug.
- **Assuming square matrix:** not all matrices are n×n. Use `matrix.length` for rows and `matrix[0].length` for cols; don't assume they're equal.
- **Empty matrix:** check `matrix.length == 0` or `matrix[0].length == 0` before accessing.
- **Jagged arrays:** if rows have different lengths, `matrix[i].length` varies per row. Use `matrix[i].length` in the inner loop, not `matrix[0].length`.
- **Deep copy:** `Arrays.copyOf(matrix, matrix.length)` only copies the outer array (shallow copy). The inner arrays are shared. For a deep copy, loop and `Arrays.copyOf` each row.

## A Small Program: Transpose a Matrix

```java
public class Transpose {
    static int[][] transpose(int[][] m) {
        int rows = m.length;
        int cols = m[0].length;
        int[][] t = new int[cols][rows];
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                t[j][i] = m[i][j];
            }
        }
        return t;
    }

    public static void main(String[] args) {
        int[][] m = {{1,2,3},{4,5,6}};
        int[][] t = transpose(m);
        // t = {{1,4},{2,5},{3,6}}
        for (int[] row : t) System.out.println(Arrays.toString(row));
    }
}
```

## In Your Own Words

1. How do you get the number of rows and columns in a 2D array?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `matrix.length` gives the number of rows. `matrix[0].length` gives the number of columns (assuming rectangular). For jagged arrays, use `matrix[i].length` per row. Always check for empty matrix (`matrix.length == 0`) before accessing `matrix[0]`.

</details>

2. What is a jagged array, and when might you encounter one?

<details>
<summary>Show Answer</summary>

**Sample Answer:** A jagged array is a 2D array where rows have different lengths. In Java, `new int[3][]` creates a jagged array — you allocate each row separately. You might encounter them in problems with variable-length rows, but most DSA problems use rectangular matrices. When in doubt, use `matrix[i].length` in the inner loop.

</details>

3. How do you deep-copy a 2D array?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `Arrays.copyOf(matrix, matrix.length)` only copies the outer array (shallow copy) — inner arrays are shared. For a deep copy, create a new 2D array and copy each row: `int[][] copy = new int[m.length][]; for (int i = 0; i < m.length; i++) copy[i] = Arrays.copyOf(m[i], m[i].length);`.

</details>
