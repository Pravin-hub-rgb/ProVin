# 2.18 Maximum Subarray

**Problem:** Given an integer array, find the contiguous subarray with the largest sum and return that sum. (LeetCode #53)

**Link:** https://leetcode.com/problems/maximum-subarray/

---

## Which Data Structure, and Why?

You need the maximum sum of a contiguous subarray. The naive approach checks all subarrays → O(n²) or O(n³). The optimized approach: **Kadane's algorithm** — track a running sum; if it goes negative, reset to 0 (start fresh). No complex data structure — just two variables (`currentSum`, `maxSum`).

The insight: a negative running sum can only reduce any future subarray, so discard it and start over.

**Signal in the problem:** "maximum subarray sum" / "contiguous subarray with largest sum" → Kadane's algorithm. If the problem asks for the subarray itself (indices), track start/end too.

## Approach

**Brute force (O(n²) or O(n³)):** check all subarrays, compute sum.

**Optimized (O(n)):** Kadane's. Walk the array, maintaining `currentSum` (sum of current subarray). At each element: `currentSum = max(nums[i], currentSum + nums[i])`. If `currentSum` is better than `maxSum`, update `maxSum`. Reset when `currentSum` goes negative (by taking `max(nums[i], currentSum + nums[i])` — if currentSum is negative, nums[i] wins).

## Pseudocode

```
currentSum = 0
maxSum = -infinity
for each x in nums:
    currentSum = max(x, currentSum + x)
    maxSum = max(maxSum, currentSum)
return maxSum
```

## Java Code

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int currentSum = 0;
        int maxSum = Integer.MIN_VALUE;

        for (int x : nums) {
            currentSum = Math.max(x, currentSum + x);
            maxSum = Math.max(maxSum, currentSum);
        }
        return maxSum;
    }
}
```

## Line-by-line

- `currentSum = Math.max(x, currentSum + x)` — either start a new subarray at x (if currentSum is negative, x alone is bigger) or extend the current subarray.
- `maxSum` tracks the best `currentSum` ever seen.
- Initializing `maxSum = Integer.MIN_VALUE` handles all-negative arrays (returns the least negative, i.e., the max single element).

## Complexity

- Time: O(n) — single pass.
- Space: O(1) — two variables.

## Common Mistakes

- **Initializing `maxSum = 0`.** If all elements are negative, the answer should be the largest (least negative) element, not 0. Use `Integer.MIN_VALUE`.
- **Returning 0 for all-negative arrays.** The empty subarray is not allowed unless the problem says so. Check the problem statement.
- **Confusing with "maximum subarray" (indices).** If the problem asks for the subarray itself, track `start` and `end` indices alongside.
- **Divide and conquer (O(n log n))** — exists but Kadane's O(n) is simpler and faster.

## How to Explain (interview)

**Opening:** Maximum Subarray asks for the contiguous subarray with the largest sum. The brute force checks all subarrays — O(n²) or O(n³). Kadane's algorithm does it in O(n): walk the array keeping a running sum; at each element, either extend the current subarray or start fresh (if the running sum is negative). Track the maximum running sum seen. The reset works because a negative running sum only drags down future subarrays.

**The basic flow:**
```java
int current = 0, best = Integer.MIN_VALUE;
for (int x : nums) {
    current = Math.max(x, current + x);
    best = Math.max(best, current);
}
return best;
```

**The part that trips everyone up:** initializing `best = 0` instead of `Integer.MIN_VALUE` — fails on all-negative arrays. Also, the problem may want the subarray itself (indices), not just the sum.

**The mistakes to remember:**
- `maxSum = 0` instead of `Integer.MIN_VALUE` (wrong on all-negative input)
- Forgetting that the subarray must be contiguous and non-empty
- Returning 0 when the problem expects the least-negative element
