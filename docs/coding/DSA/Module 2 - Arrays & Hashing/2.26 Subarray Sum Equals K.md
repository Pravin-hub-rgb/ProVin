**Tier 2 problem.** (LeetCode #560)

**Problem:** Given an array of integers (can be negative) and an integer k, return the total number of contiguous subarrays whose sum equals k. (LeetCode #560)

**Link:** https://leetcode.com/problems/subarray-sum-equals-k/

---

## Which Technique, and Why?

"Count subarrays with sum = k" with possibly negative numbers → **Prefix Sum + HashMap**. Sliding window doesn't work (negatives break monotonicity). Use prefix sums: `sum(i..j) = prefix[j+1] - prefix[i]`. If this equals k, then `prefix[i] = prefix[j+1] - k`. Check if `prefix - k` was seen. O(n) time, O(n) space.

**Signal in the problem:** "subarray sum equals k" + "may contain negatives" → prefix sum + hash map. (Sliding window only works for all-positive arrays.)

## Approach

Walk the array, maintaining a running prefix sum. Use a HashMap to count how many times each prefix sum has been seen. For each element, check if `prefix - k` is in the map — if so, add that count to the result. Then record the current prefix.

## Pseudocode

```
prefixCount = {0: 1}  // empty prefix
prefix = 0, count = 0
for x in nums:
    prefix += x
    count += prefixCount.getOrDefault(prefix - k, 0)
    prefixCount.put(prefix, prefixCount.getOrDefault(prefix, 0) + 1)
return count
```

## Java Code

```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0, 1);  // empty prefix
        int prefix = 0, count = 0;

        for (int x : nums) {
            prefix += x;
            count += prefixCount.getOrDefault(prefix - k, 0);
            prefixCount.put(prefix, prefixCount.getOrDefault(prefix, 0) + 1);
        }
        return count;
    }
}
```

## Line-by-line

- `prefixCount` maps prefix sum → how many times it's been seen.
- `prefixCount.put(0, 1)` — the empty prefix (sum 0) before any element. Handles subarrays starting at index 0.
- `prefix += x` — running sum up to current index.
- `count += prefixCount.getOrDefault(prefix - k, 0)` — if `prefix - k` was seen, there's a subarray summing to k. Add the count (handles duplicate prefix sums).
- `prefixCount.put(prefix, ...)` — record current prefix for future.

## Complexity

- Time: O(n) — single pass.
- Space: O(n) — hash map stores up to n prefix sums.

## Common Mistakes

- **Using sliding window.** Sliding window requires all positive elements (monotonic sum). With negatives, it breaks. Use prefix sum + hash map.
- **Forgetting the empty prefix.** `prefixCount.put(0, 1)` is essential — handles subarrays starting at index 0.
- **Using `get` instead of `getOrDefault`.** `get` returns null for missing keys → NPE. Use `getOrDefault`.
- **Counting each subarray once.** The map counts occurrences, so duplicate prefix sums are handled correctly (multiple subarrays can sum to k).

**Opening:** Subarray Sum Equals K counts contiguous subarrays summing to k, even with negative numbers. Sliding window doesn't work (negatives break monotonicity). Prefix sum + hash map: `sum(i..j) = prefix[j+1] - prefix[i]`. At each index, check if `prefix - k` was seen. O(n) time, O(n) space.

**The basic flow:**
```java
Map<Integer, Integer> prefixCount = new HashMap<>();
```

**The part that trips everyone up:** the empty prefix (`prefixCount.put(0, 1)`). Without it, subarrays starting at index 0 are missed. Also, this works with **negatives** (sliding window doesn't).

**The mistakes to remember:**
- Using sliding window (fails with negatives)
- Forgetting the empty prefix (misses subarrays from index 0)
- Using `get` instead of `getOrDefault` (NPE)
- Confusing with "Subarray Sum Equals K II" (different constraints)
