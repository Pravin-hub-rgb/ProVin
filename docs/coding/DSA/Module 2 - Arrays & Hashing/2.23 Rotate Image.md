**Problem:** You are given an `n x n` 2D `matrix` representing an image, rotate the image by **90 degrees** (clockwise).

You have to rotate the image **in-place**, which means you have to modify the input 2D matrix directly. **DO NOT** allocate another 2D matrix and do the rotation.

**Link:** https://leetcode.com/problems/rotate-image/

---

## Example 1

**Input:** `matrix = [[1,2,3],[4,5,6],[7,8,9]]`

**Output:** `[[7,4,1],[8,5,2],[9,6,3]]`

**Explanation:** 90° clockwise rotation: row 0 becomes column n-1, row 1 becomes column n-2, etc.

---

## Example 2

**Input:** `matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,15,16]]`

**Output:** `[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]`

---

## Constraints

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

**Follow-up:** Can you do it in-place with O(1) extra space?

---

## Which Technique, and Why?

Rotate a matrix 90° clockwise in place → **transpose + reverse each row**. Transpose (swap `matrix[i][j]` with `matrix[j][i]`) then reverse each row. O(n²) time, O(1) space. No extra data structure.

**Signal in the problem:** "rotate matrix 90 degrees" + "in place" → transpose + reverse rows.

## Approach

Two steps:
1. Transpose: swap `matrix[i][j]` with `matrix[j][i]` for all i < j.
2. Reverse each row.

## Pseudocode

```
n = matrix.length
// transpose
for i from 0 to n-1:
    for j from i+1 to n-1:
        swap(matrix[i][j], matrix[j][i])
// reverse each row
for i from 0 to n-1:
    reverse(matrix[i])
```

## Java Code

```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;

        // Step 1: transpose
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }

        // Step 2: reverse each row
        for (int i = 0; i < n; i++) {
            int left = 0, right = n - 1;
            while (left < right) {
                int temp = matrix[i][left];
                matrix[i][left] = matrix[i][right];
                matrix[i][right] = temp;
                left++;
                right--;
            }
        }
    }
}
```

## Line-by-line

- `for (j = i + 1; ...)` — only swap upper triangle (i < j) to avoid double-swapping.
- Transpose swaps rows and columns.
- Reversing each row completes the 90° clockwise rotation.
- In place — no extra matrix.

## Complexity

- Time: O(n²) — transpose visits n²/2 cells, reverse visits n²/2.
- Space: O(1) — in place.

## Common Mistakes

- **Swapping the entire matrix (i, j) for all i, j.** This double-swaps — only swap i < j.
- **Reversing columns instead of rows.** After transpose, reverse **rows** for clockwise. For counter-clockwise: transpose then reverse columns (or reverse rows then transpose).
- **Using an extra matrix.** Works but O(n²) space. The problem usually wants in-place.
- **Not handling n = 1.** Single element — no-op. The loops handle this (no iterations).

## How to Explain (interview)

**Opening:** Rotate Image rotates an n×n matrix 90° clockwise in place. Two steps: transpose (swap rows and columns), then reverse each row. O(n²) time, O(1) space. No extra matrix needed.

**The basic flow:**
```java
// transpose
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++) swap(matrix[i][j], matrix[j][i]);
// reverse each row
for (int i = 0; i < n; i++) reverse(matrix[i]);
```

**The part that trips everyone up:** only swap the upper triangle (`j = i + 1`) to avoid double-swapping. Also, reverse **rows** after transpose (not columns) for clockwise rotation.

**The mistakes to remember:**
- Swapping all (i, j) pairs (double-swap)
- Reversing columns instead of rows (wrong rotation direction)
- Using extra matrix (O(n²) space, not in-place)
- Not handling n = 1 (single element)
