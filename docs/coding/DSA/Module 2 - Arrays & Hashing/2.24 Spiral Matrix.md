**Tier 2 problem.** (LeetCode #54)

**Problem:** Given an m×n matrix, return all elements in spiral order (clockwise, starting from top-left). (LeetCode #54)

**Link:** https://leetcode.com/problems/spiral-matrix/

---

## Which Technique, and Why?

"Return elements in spiral order" → **Four boundaries (top, bottom, left, right) + direction simulation**. Walk the perimeter, shrink boundaries, repeat. O(m × n) time, O(1) extra space.

**Signal in the problem:** "spiral order" / "spiral matrix" → boundary tracking (top, bottom, left, right).

## Approach

Maintain four boundaries: `top`, `bottom`, `left`, `right`. Traverse: left→right along top (then top++), top→bottom along right (then right--), right→left along bottom (then bottom--), bottom→top along left (then left++). Repeat until boundaries cross.

## Pseudocode

```
top = 0, bottom = m-1, left = 0, right = n-1
result = []
while top <= bottom and left <= right:
    for j from left to right: result.add(matrix[top][j]); top++
    for i from top to bottom: result.add(matrix[i][right]); right--
    if top <= bottom:
        for j from right down to left: result.add(matrix[bottom][j]); bottom--
    if left <= right:
        for i from bottom down to top: result.add(matrix[i][left]); left++
return result
```

## Java Code

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> result = new ArrayList<>();
        if (matrix == null || matrix.length == 0) return result;

        int top = 0, bottom = matrix.length - 1;
        int left = 0, right = matrix[0].length - 1;

        while (top <= bottom && left <= right) {
            for (int j = left; j <= right; j++) result.add(matrix[top][j]);
            top++;
            for (int i = top; i <= bottom; i++) result.add(matrix[i][right]);
            right--;
            if (top <= bottom) {
                for (int j = right; j >= left; j--) result.add(matrix[bottom][j]);
                bottom--;
            }
            if (left <= right) {
                for (int i = bottom; i >= top; i--) result.add(matrix[i][left]);
                left++;
            }
        }
        return result;
    }
}
```

## Line-by-line

- Four boundaries: `top`, `bottom`, `left`, `right`.
- First loop: left→right along `top` row, then `top++`.
- Second loop: top→bottom along `right` column, then `right--`.
- Third loop (if `top <= bottom`): right→left along `bottom` row, then `bottom--`.
- Fourth loop (if `left <= right`): bottom→top along `left` column, then `left++`.
- The `if` guards prevent double-processing when the matrix is a single row/column.

## Complexity

- Time: O(m × n) — visit every cell once.
- Space: O(1) extra (result array is output, not extra).

## Common Mistakes

- **Missing the `if` guards.** Without `if (top <= bottom)` and `if (left <= right)`, single-row or single-column matrices get double-processed.
- **Wrong boundary updates.** After traversing top row, `top++`. After right column, `right--`. Etc. Forgetting to update causes infinite loop.
- **Off-by-one in loops.** `j <= right` (inclusive), not `j < right`. The boundary is inclusive.
- **Confusing with "Spiral Matrix II"** (#59) — that one fills a matrix with numbers 1 to n² in spiral order. Same technique, different output.

## How to Explain (interview)

**Opening:** Spiral Matrix returns elements in clockwise spiral order. Four boundaries (top, bottom, left, right): traverse top row left→right, right column top→bottom, bottom row right→left, left column bottom→top. Shrink boundaries each pass. O(m×n) time, O(1) extra space.

**The basic flow:**
```java
while (top <= bottom && left <= right) {
    for (j = left; j <= right; j++) result.add(matrix[top][j]); top++;
    for (i = top; i <= bottom; i++) result.add(matrix[i][right]); right--;
    if (top <= bottom) for (j = right; j >= left; j--) result.add(matrix[bottom][j]); bottom--;
    if (left <= right) for (i = bottom; i >= top; i--) result.add(matrix[i][left]); left++;
}
```

**The part that trips everyone up:** the `if (top <= bottom)` and `if (left <= right)` guards. Without them, single-row or single-column matrices get double-processed (elements added twice).

**The mistakes to remember:**
- Missing the `if` guards (double-processing on single row/column)
- Wrong boundary updates (infinite loop)
- Off-by-one in loop conditions (inclusive boundaries)
- Confusing with Spiral Matrix II (#59) (fill instead of read)
