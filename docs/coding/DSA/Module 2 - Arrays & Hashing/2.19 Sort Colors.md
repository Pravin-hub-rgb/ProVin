# 2.19 Sort Colors

**Problem:** Given an array of 0s, 1s, and 2s, sort it in-place so all 0s come first, then 1s, then 2s. (LeetCode #75)

**Link:** https://leetcode.com/problems/sort-colors/

---

## Which Data Structure, and Why?

The array contains only 3 distinct values (0, 1, 2). Two approaches:
1. **Counting sort** — count 0s, 1s, 2s, then overwrite the array. O(n) time, O(1) space (fixed 3 counters). Simplest.
2. **Dutch National Flag algorithm** — single pass, three pointers (low, mid, high). O(n) time, O(1) space, one pass. The "in-place partitioning" pattern.

Why not `Arrays.sort`? That's O(n log n) — works but slower. The counting approach is O(n).

**Signal in the problem:** "sort 0s, 1s, 2s in place" / "only 3 distinct values" → counting sort or Dutch National Flag.

## Approach (Counting Sort — simplest)

Count how many 0s, 1s, 2s there are. Then overwrite the array: first all 0s, then all 1s, then all 2s.

## Approach (Dutch National Flag — one pass, in-place)

Three pointers: `low` (boundary of 0s), `mid` (current), `high` (boundary of 2s). Invariant: everything before `low` is 0, between `low` and `mid` is 1, after `high` is 2.

- `nums[mid] == 0` → swap with `low`, advance both `low` and `mid`.
- `nums[mid] == 1` → just advance `mid`.
- `nums[mid] == 2` → swap with `high`, decrement `high` (don't advance `mid` — the swapped-in value is unexamined).

## Pseudocode (Dutch National Flag)

```
low = 0, mid = 0, high = n - 1
while mid <= high:
    if nums[mid] == 0:
        swap(nums[low], nums[mid])
        low++; mid++
    else if nums[mid] == 1:
        mid++
    else: // nums[mid] == 2
        swap(nums[mid], nums[high])
        high--
```

## Java Code (Counting Sort)

```java
class Solution {
    public void sortColors(int[] nums) {
        int count0 = 0, count1 = 0, count2 = 0;
        for (int x : nums) {
            if (x == 0) count0++;
            else if (x == 1) count1++;
            else count2++;
        }
        int i = 0;
        while (count0-- > 0) nums[i++] = 0;
        while (count1-- > 0) nums[i++] = 1;
        while (count2-- > 0) nums[i++] = 2;
    }
}
```

## Java Code (Dutch National Flag)

```java
class Solution {
    public void sortColors(int[] nums) {
        int low = 0, mid = 0, high = nums.length - 1;
        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums, low, mid);
                low++; mid++;
            } else if (nums[mid] == 1) {
                mid++;
            } else {
                swap(nums, mid, high);
                high--;
            }
        }
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i]; a[i] = a[j]; a[j] = t;
    }
}
```

## Complexity

- Counting sort: O(n) time, O(1) space.
- Dutch National Flag: O(n) time, O(1) space (single pass, fewer writes).

## Common Mistakes

- **Using `Arrays.sort`** — O(n log n), slower than O(n). Works but not optimal.
- **Dutch National Flag: advancing `mid` after swapping with `high`.** Don't — the swapped-in value (from high) is unexamined. Only advance `mid` on 0 or 1.
- **Off-by-one in the while condition:** `mid <= high` (not `<`). When `mid == high`, that element still needs processing.
- **Assuming the array has only 0/1/2.** If other values exist, counting sort with 3 buckets breaks. Check constraints.

## How to Explain (interview)

**Opening:** Sort Colors sorts an array of 0s, 1s, and 2s in place. Counting sort is simplest: count 0s, 1s, 2s, then overwrite. O(n) time, O(1) space. The Dutch National Flag algorithm does it in one pass with three pointers (low, mid, high) maintaining the invariant: 0s before low, 1s between low and mid, 2s after high.

**The basic flow (Dutch National Flag):**
```java
int low = 0, mid = 0, high = nums.length - 1;
while (mid <= high) {
    if (nums[mid] == 0) { swap(nums, low, mid); low++; mid++; }
    else if (nums[mid] == 1) { mid++; }
    else { swap(nums, mid, high); high--; }
}
```

**The part that trips everyone up:** when swapping `mid` with `high`, do **not** advance `mid` — the value swapped in from `high` is unexamined. Also the while condition is `mid <= high`, not `mid < high`.

**The mistakes to remember:**
- Advancing `mid` after swapping with `high` (skips elements)
- Using `Arrays.sort` (O(n log n)) when O(n) is expected
- Forgetting the array is modified in place (void return)
