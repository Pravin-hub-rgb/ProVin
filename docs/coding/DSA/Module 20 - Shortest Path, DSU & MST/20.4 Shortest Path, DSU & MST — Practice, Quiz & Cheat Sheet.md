## Mini Quiz

1. What is the time complexity of Dijkstra's algorithm?
2. Why must Dijkstra skip stale heap entries?
3. What are the two optimizations that make DSU nearly O(1) per operation?
4. How does Kruskal's algorithm find an MST?
5. What is the difference between Dijkstra and Bellman-Ford?

<details>
<summary>Show Answer</summary>

**Sample Answers:**
1. O((V + E) log V) — V nodes, E edges. Each node is pushed to the heap at most E times (once per edge), each heap operation is O(log V). With a Fibonacci heap, it's O(E + V log V), but binary heap is standard.
2. The same node can be pushed to the heap multiple times (once per edge relaxation). When popped, if its distance is greater than the recorded distance, it's a stale entry — skip it. Without this check, you'd process outdated distances and get wrong results.
3. Path compression (flatten the tree during find) and union by rank (attach smaller tree to larger). Together, they give amortized inverse Ackermann time per operation — effectively O(1).
4. Sort all edges by weight. Process edges in order; if an edge connects two different components (DSU union returns true), add it to the MST. Stop when V-1 edges are added. O(E log E) for sorting.
5. Dijkstra: O((V+E) log V), requires non-negative weights, greedy (expands closest node). Bellman-Ford: O(V × E), handles negative weights (but not negative cycles), relaxes all edges V-1 times. Use Dijkstra when weights are non-negative (faster); Bellman-Ford when negatives are possible.

</details>

## One-Page Cheat Sheet

**Dijkstra:**
```java
int[] dist = new int[n + 1];
Arrays.fill(dist, Integer.MAX_VALUE);
dist[k] = 0;
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[1], b[1]));
pq.offer(new int[]{k, 0});
while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    if (cur[1] > dist[cur[0]]) continue;  // stale
    for (int[] edge : adj.get(cur[0])) {
        if (dist[cur[0]] + edge[1] < dist[edge[0]]) {
            dist[edge[0]] = dist[cur[0]] + edge[1];
            pq.offer(new int[]{edge[0], dist[edge[0]]});
        }
    }
}
```

**DSU (Union-Find):**
```java
class DSU {
    int[] parent, rank;
    DSU(int n) { parent = new int[n]; rank = new int[n]; for (int i = 0; i < n; i++) parent[i] = i; }
    int find(int x) { if (parent[x] != x) parent[x] = find(parent[x]); return parent[x]; }
    boolean union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false;
        if (rank[px] < rank[py]) { int t = px; px = py; py = t; }
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
        return true;
    }
}
```

**Kruskal's MST:**
```java
Arrays.sort(edges, (a, b) -> a[2] - b[2]); // sort by weight
DSU dsu = new DSU(n);
int total = 0, edgesUsed = 0;
for (int[] edge : edges) {
    if (dsu.union(edge[0], edge[1])) {
        total += edge[2];
        if (++edgesUsed == n - 1) break;
    }
}
```

**Complexities:** Dijkstra O((V+E) log V). DSU nearly O(1) per op. Kruskal O(E log E).

## In Your Own Words

1. When should you use Dijkstra vs Bellman-Ford?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Dijkstra: non-negative weights, O((V+E) log V). Bellman-Ford: handles negative weights (but not negative cycles), O(V × E). Use Dijkstra when weights are non-negative (faster). Use Bellman-Ford when negative weights are possible. If there's a negative cycle, neither works (Bellman-Ford can detect it).

</details>

2. What is Union-Find (DSU), and what are its two optimizations?

<details>
<summary>Show Answer</summary>
**Sample Answer:** DSU (Disjoint Set Union) groups nodes into sets with `find` (which set?) and `union` (merge sets). Path compression: during find, point each node directly to the root, flattening the tree. Union by rank: attach the shorter tree to the taller one. Together, operations are nearly O(1) (inverse Ackermann). Used for connectivity, cycle detection, and MST (Kruskal's).

</details>

3. How does Kruskal's algorithm find a Minimum Spanning Tree?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Sort all edges by weight. Process edges in order; add an edge if it connects two different components (DSU union returns true). Skip edges that would create a cycle. Stop when V-1 edges are added. The result is the MST. O(E log E) for sorting + O(E × α(V)) for DSU operations.

</details>
