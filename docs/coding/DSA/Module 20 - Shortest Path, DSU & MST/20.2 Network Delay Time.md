# 20.2 Network Delay Time

**Problem:** Given a network (edges with travel time) and a source node K, find the time for a signal to reach all nodes. Return -1 if not all reachable. (LeetCode #743)

**Link:** https://leetcode.com/problems/network-delay-time/

---

## Which Technique, and Why?

Weighted graph + shortest path from a source to all nodes → **Dijkstra's algorithm**. O((V + E) log V) time, O(V + E) space. (This is the worked example in 20.1 — repeated here as a solved problem.)

**Signal in the problem:** "network delay" / "shortest time to reach all nodes" / "weighted graph shortest path" → Dijkstra.

## Approach

Dijkstra from source K. Build adjacency list. Min-heap of {node, distance}. Relax edges. After processing, find the max distance. If any node is unreachable (infinity), return -1.

## Pseudocode

```
build adj: node -> list of {neighbor, weight}
dist = [infinity] * (n+1); dist[K] = 0
pq = min-heap of {node, dist}; pq.offer({K, 0})
while pq not empty:
    {node, d} = pq.poll()
    if d > dist[node]: continue  // stale
    for {next, w} in adj[node]:
        if dist[node] + w < dist[next]:
            dist[next] = dist[node] + w
            pq.offer({next, dist[next]})
maxDist = max(dist[1..n])
return maxDist == infinity ? -1 : maxDist
```

## Java Code

```java
class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        List<List<int[]>> adj = new ArrayList<>();
        for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
        for (int[] t : times) adj.get(t[0]).add(new int[]{t[1], t[2]});

        int[] dist = new int[n + 1];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[k] = 0;

        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[1], b[1]));
        pq.offer(new int[]{k, 0});

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int node = cur[0], d = cur[1];
            if (d > dist[node]) continue;  // stale entry
            for (int[] edge : adj.get(node)) {
                int next = edge[0], weight = edge[1];
                if (dist[node] + weight < dist[next]) {
                    dist[next] = dist[node] + weight;
                    pq.offer(new int[]{next, dist[next]});
                }
            }
        }

        int max = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == Integer.MAX_VALUE) return -1;
            max = Math.max(max, dist[i]);
        }
        return max;
    }
}
```

## Line-by-line

- Build adjacency list: `node → list of {neighbor, weight}`.
- `dist` array initialized to infinity; source `k` = 0.
- Min-heap of `{node, distance}`. Start with source.
- Pop closest node. Skip if stale (`d > dist[node]`).
- For each neighbor: relax edge (update if shorter path found), push to heap.
- After processing, find max distance. If any node unreachable → -1.

## Complexity

- Time: O((V + E) log V) — V nodes, E edges, heap operations O(log V).
- Space: O(V + E) — adjacency list + dist array + heap.

## Common Mistakes

- **Using Dijkstra with negative weights.** This problem has positive weights (travel times). If negatives exist, use Bellman-Ford.
- **Not skipping stale entries.** The same node can be pushed multiple times. `if (d > dist[node]) continue;` prevents processing stale entries.
- **Comparator overflow.** `(a, b) -> a[1] - b[1]` can overflow. Use `Integer.compare(a[1], b[1])`.
- **Off-by-one in node indexing.** Nodes are 1 to n. Array size n+1. Don't use 0-based indexing.
- **Not checking reachability.** If any node has dist = infinity → return -1.

## How to Explain (interview)

**Opening:** Network Delay Time finds the time for a signal to reach all nodes from a source. Dijkstra's algorithm: min-heap always expands the closest unvisited node. Relax edges, update distances. O((V+E) log V) time. Return the max distance, or -1 if any node is unreachable.

**The basic flow:**
```java
// build adj, dist (inf), dist[k]=0
// pq = min-heap of {node, dist}; start with {k, 0}
while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    if (cur[1] > dist[cur[0]]) continue;  // stale
    for (int[] edge : adj.get(cur[0])) {
        if (dist[cur[0]] + edge[1] < dist[edge[0]]) {
            dist[edge[0]] = dist[cur[0]] + edge[1];
            pq.offer(new int[]{edge[0], dist[edge[0]]});
        }
    }
}
```

**The part that trips everyone up:** skip stale heap entries (`if (d > dist[node]) continue`). Also, Dijkstra requires non-negative weights — if negatives exist, use Bellman-Ford.

**The mistakes to remember:**
- Not skipping stale entries (wrong distances)
- Dijkstra with negative weights (wrong answer)
- Comparator overflow
- Not checking reachability (return -1)
- Off-by-one in 1-based indexing
