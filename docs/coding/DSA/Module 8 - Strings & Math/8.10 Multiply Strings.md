# 8.10 Multiply Strings

**Tier 2 problem.** (LeetCode #43)

**Problem:** Given two non-negative integers as strings, return their product as a string. (LeetCode #43)

**Link:** https://leetcode.com/problems/multiply-strings/

---

## Which Technique, and Why?

"Multiply two big numbers (as strings)" → **Grade-school multiplication**. Since the numbers can be very large (beyond int/long range), you can't convert to int. Multiply digit by digit, store in an array, handle carries. O(m × n) time, O(m + n) space.

**Signal in the problem:** "multiply strings" / "big numbers" / "product as string" → manual multiplication with carry.

## Approach

Create a result array of size `m + n`. For each digit of num1 (from right) and num2 (from right), multiply, add to the corresponding position in the result array, handle carry. Then convert to string, skipping leading zeros.

## Pseudocode

```
m = num1.length, n = num2.length
result = new int[m + n]
for i from m-1 down to 0:
    for j from n-1 down to 0:
        mul = (num1[i] - '0') * (num2[j] - '0')
        pos1 = i + j, pos2 = i + j + 1
        sum = mul + result[pos2]
        result[pos2] = sum % 10
        result[pos1] += sum / 10
// convert to string, skip leading zeros
```

## Java Code

```java
class Solution {
    public String multiply(String num1, String num2) {
        if (num1.equals("0") || num2.equals("0")) return "0";

        int m = num1.length(), n = num2.length();
        int[] result = new int[m + n];

        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                int mul = (num1.charAt(i) - '0') * (num2.charAt(j) - '0');
                int pos1 = i + j;
                int pos2 = i + j + 1;
                int sum = mul + result[pos2];
                result[pos2] = sum % 10;
                result[pos1] += sum / 10;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int digit : result) {
            if (sb.length() == 0 && digit == 0) continue;  // skip leading zeros
            sb.append(digit);
        }
        return sb.toString();
    }
}
```

## Line-by-line

- `if (num1.equals("0") || num2.equals("0")) return "0"` — early exit for zero.
- `result = new int[m + n]` — the product of m-digit and n-digit numbers has at most m + n digits.
- `pos1 = i + j`, `pos2 = i + j + 1` — the two positions this multiplication affects.
- `mul + result[pos2]` — multiply and add to existing value (carry from previous).
- `result[pos2] = sum % 10` — current digit.
- `result[pos1] += sum / 10` — carry to the next position.
- Skip leading zeros when converting to string.

## Complexity

- Time: O(m × n) — nested loops.
- Space: O(m + n) — result array + StringBuilder.

## Common Mistakes

- **Converting to int/long.** The numbers can be very large (up to 200 digits). `Integer.parseInt` or `Long.parseLong` overflows. Must multiply manually.
- **Wrong position indices.** `pos1 = i + j`, `pos2 = i + j + 1`. Not `i + j - 1` or `i + j`.
- **Not handling carry.** `result[pos1] += sum / 10` (not `=`). The carry accumulates.
- **Leading zeros in result.** Skip them when building the string. If all zeros, return "0" (handled by early exit).

**Opening:** Multiply Strings multiplies two large numbers (as strings) that don't fit in int/long. Grade-school multiplication: multiply digit by digit, store in an array, handle carries. O(m×n) time, O(m+n) space.

**The part that trips everyone up:** positions `pos1 = i + j` and `pos2 = i + j + 1`. The carry is **added** (`+=`), not assigned (`=`). Also, skip leading zeros when converting to string.

**The mistakes to remember:**
- Converting to int/long (overflow for large inputs)
- Wrong position indices
- Using `=` instead of `+=` for carry
- Not handling leading zeros
- Not early-exiting on "0" input
