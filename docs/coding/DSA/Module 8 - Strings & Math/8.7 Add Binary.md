# 8.7 Add Binary

**Problem:** Given two binary strings, return their sum as a binary string. (LeetCode #67)

**Link:** https://leetcode.com/problems/add-binary/

---

## Which Technique, and Why?

Binary addition: add bit by bit from right to left, tracking carry. No complex data structure — just string manipulation and a carry variable. Use StringBuilder for efficient append (reverse at the end).

**Signal in the problem:** "add binary" / "binary strings" / "sum of two binary numbers" → bit-by-bit addition with carry, from right to left.

## Approach

Two pointers from the end of both strings. At each step: sum = bit1 + bit2 + carry. Append `sum % 2` to result. `carry = sum / 2`. After both strings are exhausted, if carry remains, append 1. Reverse the result (since we built it right-to-left).

## Pseudocode

```
i = a.length - 1, j = b.length - 1, carry = 0
result = StringBuilder
while i >= 0 or j >= 0 or carry > 0:
    sum = carry
    if i >= 0: sum += a[i] - '0'; i--
    if j >= 0: sum += b[j] - '0'; j--
    result.append(sum % 2)
    carry = sum / 2
return result.reverse().toString()
```

## Java Code

```java
class Solution {
    public String addBinary(String a, String b) {
        StringBuilder sb = new StringBuilder();
        int i = a.length() - 1;
        int j = b.length() - 1;
        int carry = 0;

        while (i >= 0 || j >= 0 || carry > 0) {
            int sum = carry;
            if (i >= 0) { sum += a.charAt(i) - '0'; i--; }
            if (j >= 0) { sum += b.charAt(j) - '0'; j--; }
            sb.append(sum % 2);
            carry = sum / 2;
        }

        return sb.reverse().toString();
    }
}
```

## Line-by-line

- `i`, `j` start at the last char of each string (rightmost bit).
- `sum = carry` — start with carry from previous position.
- Add bits from both strings if available (`a.charAt(i) - '0'` converts '0'/'1' to 0/1).
- `sb.append(sum % 2)` — the current bit (0 or 1).
- `carry = sum / 2` — carry to next position (0 or 1).
- Loop continues while either string has bits left or carry remains.
- `sb.reverse()` — we built the result right-to-left, so reverse to get the correct order.

## Complexity

- Time: O(max(m, n)) — single pass through both strings.
- Space: O(max(m, n)) — for the result StringBuilder.

## Common Mistakes

- **Not handling different lengths.** The `i >= 0` / `j >= 0` checks handle strings of different lengths.
- **Forgetting the final carry.** If carry remains after both strings are exhausted, append 1. The `carry > 0` condition in the while loop handles this.
- **Not reversing the result.** We append from right to left, so the result is backwards. Reverse at the end.
- **Using String concatenation instead of StringBuilder.** O(n²) due to immutability. Use StringBuilder.
- **Char to int conversion.** `a.charAt(i) - '0'` converts '0'→0, '1'→1. Don't use `Integer.parseInt(String.valueOf(c))` — slower.

## How to Explain (interview)

**Opening:** Add Binary adds two binary strings. Bit-by-bit addition from right to left with carry. Use StringBuilder (append, then reverse). Handle different lengths with bounds checks. Don't forget the final carry. O(n) time where n = max length.

**The basic flow:**
```java
StringBuilder sb = new StringBuilder();
int i = a.length() - 1, j = b.length() - 1, carry = 0;
while (i >= 0 || j >= 0 || carry > 0) {
    int sum = carry;
    if (i >= 0) sum += a.charAt(i--) - '0';
    if (j >= 0) sum += b.charAt(j--) - '0';
    sb.append(sum % 2);
    carry = sum / 2;
}
return sb.reverse().toString();
```

**The part that trips everyone up:** the while condition includes `carry > 0` (for the final carry). Also, reverse the StringBuilder at the end (we build right-to-left). And use `charAt(i) - '0'`, not `parseInt`.

**The mistakes to remember:**
- Forgetting the final carry (result missing a leading 1)
- Not reversing the result (backwards output)
- Using String concatenation (O(n²))
- Wrong loop condition (stops before handling carry)
