**Problem:** Implement `atoi` — convert a string to a 32-bit signed integer. Handle whitespace, sign, digits, and overflow. (LeetCode #8)

**Link:** https://leetcode.com/problems/string-to-integer-atoi/

## Which Technique, and Why?

"String to integer" with edge cases → **Character-by-character parsing with state machine**. Skip whitespace, detect sign, read digits, handle overflow (clamp to int range). O(n) time, O(1) space.

**Signal in the problem:** "atoi" / "string to integer" / "parse integer from string" → manual parsing with whitespace, sign, digits, overflow.

## Approach

1. Skip leading whitespace.
2. Detect sign (+ or -).
3. Read digits until non-digit.
4. Clamp to int range ([-2³¹, 2³¹-1]).
5. Apply sign.

## Pseudocode

```
i = 0
while i < n and s[i] == ' ': i++
sign = 1
if s[i] == '-': sign = -1; i++
elif s[i] == '+': i++
result = 0
while i < n and s[i] is digit:
    digit = s[i] - '0'
    if result > (MAX - digit) / 10: return sign == 1 ? MAX : MIN  // overflow
    result = result * 10 + digit
    i++
return result * sign
```

## Java Code

```java
class Solution {
    public int myAtoi(String s) {
        int i = 0, n = s.length();
        // skip whitespace
        while (i < n && s.charAt(i) == ' ') i++;

        // sign
        int sign = 1;
        if (i < n && (s.charAt(i) == '-' || s.charAt(i) == '+')) {
            if (s.charAt(i) == '-') sign = -1;
            i++;
        }

        // read digits
        int result = 0;
        while (i < n && Character.isDigit(s.charAt(i))) {
            int digit = s.charAt(i) - '0';
            // overflow check
            if (result > (Integer.MAX_VALUE - digit) / 10) {
                return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
            }
            result = result * 10 + digit;
            i++;
        }

        return result * sign;
    }
}
```

## Line-by-line

- Skip leading whitespace.
- Detect sign: '-' → -1, '+' → +1 (optional).
- Read digits: `s.charAt(i) - '0'` converts '0'-'9' to 0-9.
- Overflow check: if `result > (MAX - digit) / 10`, the next `result * 10 + digit` would overflow → clamp to MAX or MIN.
- Apply sign at the end.

## Complexity

- Time: O(n) — single pass.
- Space: O(1).

## Common Mistakes

- **Overflow.** Must check before multiplying. `result > (MAX - digit) / 10` is the safe check. Using `Integer.MAX_VALUE` directly overflows.
- **Leading zeros.** "000123" → 123. The loop handles this naturally (result stays 0 until a non-zero digit).
- **Non-digit characters.** Stop at the first non-digit. "123abc" → 123.
- **Whitespace in the middle.** "  12 34" → 12 (stops at space).
- **Empty string / only whitespace.** Returns 0.
- **Sign without digits.** "+-12" → 0 (sign is '+', then '-' is non-digit → stop).

## How to Explain (interview)

**Opening:** String to Integer (atoi) parses an integer from a string. Handle: leading whitespace, optional sign, digits (stop at first non-digit), overflow (clamp to int range). O(n) time, O(1) space. The overflow check is the tricky part.

**The basic flow:**
```java
// skip whitespace, detect sign
while (i < n && s.charAt(i) == ' ') i++;
int sign = 1;
if (i < n && (s.charAt(i) == '-' || s.charAt(i) == '+')) { ... }
// read digits with overflow check
while (i < n && isDigit(s.charAt(i))) {
    int digit = s.charAt(i) - '0';
    if (result > (MAX - digit) / 10) return sign == 1 ? MAX : MIN;
    result = result * 10 + digit;
    i++;
}
return result * sign;
```

**The part that trips everyone up:** the **overflow check**. `result > (MAX - digit) / 10` prevents overflow before it happens. Also, Java's `%` isn't relevant here, but the clamping to int range is.

**The mistakes to remember:**
- Overflow (must check before multiplying)
- Not stopping at non-digit characters
- Not handling leading whitespace
- Not handling sign without digits ("+-12" → 0)
- Empty string / only whitespace (return 0)
