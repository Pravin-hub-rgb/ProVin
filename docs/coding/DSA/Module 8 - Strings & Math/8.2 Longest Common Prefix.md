# 8.2 Longest Common Prefix

**Problem:** Given an array of strings, find the longest common prefix. Return `""` if none. (LeetCode #14)

**Link:** https://leetcode.com/problems/longest-common-prefix/

---

## Which Technique, and Why?

You need the common prefix of multiple strings → compare characters column by column (vertical scanning) or sort and compare first/last. No complex data structure — just string indexing.

**Signal in the problem:** "longest common prefix" → vertical scan (compare char by char across all strings) or sort + compare first and last.

## Approach

Vertical scanning: for each index `i` in the first string, check if all other strings have the same char at `i`. Stop at the first mismatch or when a string is too short.

Alternative: sort the array — the first and last strings will have the most different prefixes. Compare them char by char.

## Pseudocode

```
if strs is empty: return ""
for i from 0 to strs[0].length()-1:
    c = strs[0][i]
    for j from 1 to strs.length-1:
        if i >= strs[j].length() or strs[j][i] != c:
            return strs[0].substring(0, i)
return strs[0]
```

## Java Code

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        if (strs == null || strs.length == 0) return "";

        for (int i = 0; i < strs[0].length(); i++) {
            char c = strs[0].charAt(i);
            for (int j = 1; j < strs.length; j++) {
                if (i >= strs[j].length() || strs[j].charAt(i) != c) {
                    return strs[0].substring(0, i);
                }
            }
        }
        return strs[0];
    }
}
```

## Line-by-line

- Empty check first.
- Outer loop: index `i` into the first string (candidate prefix length).
- Inner loop: check all other strings at index `i`.
- `i >= strs[j].length()` — that string is shorter, so the prefix ends here.
- `strs[j].charAt(i) != c` — mismatch, prefix ends here.
- If all match, the entire first string is the common prefix.

## Complexity

- Time: O(n × m) where n = number of strings, m = min length (worst case: all strings identical).
- Space: O(1) extra (substring creates a new string, but that's the output).

## Common Mistakes

- **Not handling empty array** — `strs.length == 0` → NPE on `strs[0]`.
- **Not handling empty strings** — `strs = [""]` → the outer loop doesn't execute (length 0), returns `strs[0]` = `""`. Correct.
- **Index out of bounds** — when strings have different lengths, check `i >= strs[j].length()` before `charAt(i)`.
- **Using `==` for String comparison** — not relevant here (we compare chars), but good habit.

## How to Explain (interview)

**Opening:** Longest Common Prefix finds the shared prefix of all strings. Vertical scanning: compare characters column by column across all strings. Stop at the first mismatch or when a string runs out. O(n × m) time where n = number of strings, m = shortest length.

**The basic flow:**
```java
for (int i = 0; i < strs[0].length(); i++) {
    char c = strs[0].charAt(i);
    for (int j = 1; j < strs.length; j++) {
        if (i >= strs[j].length() || strs[j].charAt(i) != c)
            return strs[0].substring(0, i);
    }
}
return strs[0];
```

**The part that trips everyone up:** check `i >= strs[j].length()` **before** `charAt(i)` to avoid index out of bounds. Also handle empty array/strings.

**The mistakes to remember:**
- Not handling empty array (NPE)
- Index out of bounds on shorter strings
- Using horizontal scanning when vertical is simpler
