# 8.4 Find the Index of the First Occurrence in a String

**Problem:** Given two strings `haystack` and `needle`, return the index of the first occurrence of `needle` in `haystack`, or -1 if not found. (LeetCode #28)

**Link:** https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string/

---

## Which Technique, and Why?

Substring search in a string. Two approaches:
1. **Naive (brute force):** slide a window of size `needle.length()` across `haystack`, compare char by char. O(n × m) worst case.
2. **KMP algorithm:** O(n + m) using a failure function. Overkill for interviews unless asked.

For LeetCode and interviews, the naive approach is usually accepted (and often expected). The KMP is a "nice to know" for follow-up.

**Signal in the problem:** "find first occurrence of substring" → sliding window / string matching. Naive O(n×m) is fine unless constraints are huge.

## Approach (Naive)

For each starting position `i` in haystack, check if `haystack[i..i+m-1] == needle`. If all chars match, return `i`. If no match found, return -1.

## Pseudocode

```
n = haystack.length, m = needle.length
if m == 0: return 0
if m > n: return -1
for i from 0 to n - m:
    match = true
    for j from 0 to m - 1:
        if haystack[i+j] != needle[j]:
            match = false; break
    if match: return i
return -1
```

## Java Code

```java
class Solution {
    public int strStr(String haystack, String needle) {
        int n = haystack.length();
        int m = needle.length();

        if (m == 0) return 0;
        if (m > n) return -1;

        for (int i = 0; i <= n - m; i++) {
            int j = 0;
            while (j < m && haystack.charAt(i + j) == needle.charAt(j)) {
                j++;
            }
            if (j == m) return i;
        }
        return -1;
    }
}
```

## Line-by-line

- `m == 0` → empty needle is found at index 0 (per problem spec).
- `m > n` → needle can't fit → return -1.
- Outer loop: try each starting position `i` (up to `n - m`).
- Inner while: compare chars until mismatch or full match.
- `j == m` → all chars matched → return `i`.
- If no match found → return -1.

## Complexity

- Time: O(n × m) worst case (e.g., haystack = "aaaaa", needle = "aaab"). O(n) average with early termination.
- Space: O(1).

## Common Mistakes

- **Loop bound `i <= n - m` (not `i < n`).** If `i > n - m`, the needle can't fit.
- **Not handling empty needle.** Problem says empty needle returns 0.
- **Using `String.indexOf` directly.** Works (`return haystack.indexOf(needle)`) but doesn't show you understand the algorithm. In interviews, implement it.
- **KMP confusion.** KMP is O(n+m) but complex. Know it exists; naive is usually fine.

## How to Explain (interview)

**Opening:** Find the First Occurrence (strStr) searches for a substring in a string. The naive approach slides a window of size `needle.length()` across `haystack`, comparing char by char. O(n×m) worst case, O(1) space. KMP achieves O(n+m) but is rarely needed in interviews.

**The basic flow:**
```java
for (int i = 0; i <= n - m; i++) {
    int j = 0;
    while (j < m && haystack.charAt(i + j) == needle.charAt(j)) j++;
    if (j == m) return i;
}
return -1;
```

**The part that trips everyone up:** the loop bound is `i <= n - m` (not `i < n`), because the needle must fit. Also handle empty needle (return 0) and needle longer than haystack (return -1).

**The mistakes to remember:**
- Loop bound `i < n` instead of `i <= n - m` (index out of bounds or false matches)
- Not handling empty needle
- Using `indexOf` without understanding the algorithm
- Confusing with KMP (not needed unless asked)
