# 8.1 Strings & Math — The Pattern

## What This Problem Is Asking (Simple Terms)

String problems involve manipulating sequences of characters — reversing, searching, counting, converting formats, and building new strings. Math problems involve arithmetic operations, number theory, and mathematical properties applied to strings or numbers.

Key insight: **Strings are immutable in Java** (String class), so every modification creates a new object. For efficient manipulation, you often convert to `char[]` or `StringBuilder`.

---

## Example 1

**Input:** `s = "hello"`

**Output:** `"olleh"`

**Explanation:** Reverse the string.

---

## Example 2

**Input:** `s = "hello world"`

**Output:** `"dlrow olleh"`

**Explanation:** Reverse each word, but keep word order.

---

## Constraints

- `1 <= s.length <= 10^5`
- String consists of printable ASCII characters.

---

## Which Data Structure/Technique, and Why?

String problems involve **index-based access** and **immutability**. Java Strings are immutable, so modifications create new objects. For efficient manipulation:
- Use `char[]` for mutable character arrays
- Use `StringBuilder` for efficient string building

**Signal in the problem:** "reverse string," "reverse words," "palindrome," "anagram" → String manipulation with char array or StringBuilder.

---

## Approach

**Reverse a string:**
1. Convert string to `char[]`
2. Use two pointers (left, right) to swap characters from ends toward center
3. Convert back to String

### Pseudocode

```
chars = s.toCharArray()
left = 0, right = chars.length - 1
while left < right:
    swap(chars[left], chars[right])
    left++
    right--
return new String(chars)
```

### Java Code

```java
class Solution {
    public String reverseString(String s) {
        char[] chars = s.toCharArray();
        int left = 0, right = s.length() - 1;
        while (left < right) {
            char temp = chars[left];
            chars[left] = chars[right];
            chars[right] = temp;
            left++;
            right--;
        }
        return new String(chars);
    }
}
```

### Line-by-line

- `char[] chars = s.toCharArray()` — convert immutable String to mutable char array.
- `int left = 0, right = s.length() - 1` — two pointers at start and end.
- `while (left < right)` — swap until pointers meet.
- `char temp = chars[left]; chars[left] = chars[right]; chars[right] = temp;` — swap characters.
- `left++; right--;` — move pointers toward center.
- `return new String(chars)` — convert char array back to String.

## Complexity

- Time: O(n) — single pass through half the string.
- Space: O(n) — char array of size n.

## Common Mistakes

- **Forgetting to convert back to String** — `new String(chars)` needed.
- **Off-by-one in loop condition** — use `left < right`, not `left <= right`.
- **Not handling empty string** — empty string should return empty string.

---

## How to Explain (interview)

**Opening:** Reverse a string in-place using two pointers. Start from both ends, swap characters, and move inward until pointers meet.

**The basic flow:**
```java
char[] chars = s.toCharArray();
int left = 0, right = s.length() - 1;
while (left < right) {
    char temp = chars[left];
    chars[left] = chars[right];
    chars[right] = temp;
    left++;
    right--;
}
return new String(chars);
```

**The part that trips everyone up:**
- **`left < right`**: stop when pointers meet or cross.
- **`char[] chars = s.toCharArray()`**: strings are immutable in Java, so convert to char array for in-place modification.
- **`new String(chars)`**: convert char array back to String for return.

**The mistakes to remember:**
- Forgetting to convert char array back to String
- Using `left < right` incorrectly (should stop when they meet or cross)
- Not handling empty string
