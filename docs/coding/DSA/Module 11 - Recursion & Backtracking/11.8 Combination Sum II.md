**Problem:** Given an array that may contain duplicates, find all unique combinations that sum to target. Each number may be used **at most once**. (LeetCode #40)

**Link:** https://leetcode.com/problems/combination-sum-ii/

---

## Which Technique, and Why?

"Unique combinations summing to target, each number used at most once, with duplicates in input" ? **Backtracking with duplicate skipping and no reuse**. Sort first; skip duplicates at the same level (`i > start && nums[i] == nums[i-1]`); pass `i + 1` (no reuse). O(2^n) time.

**Signal in the problem:** "combinations" + "each number used at most once" + "may contain duplicates" ? backtracking + sort + skip + no reuse.

## Approach

Sort the array. Backtrack: for each candidate from `start`, if adding doesn't exceed target, add, recurse with `i + 1` (no reuse), undo. Skip duplicates at the same level. Prune with `break`.

## Pseudocode

```
sort candidates
result = []
backtrack(candidates, target, 0, [], result, 0)
return result

backtrack(candidates, target, start, current, result, sum):
    if sum == target: result.add(copy); return
    if sum > target: return
    for i from start to candidates.length-1:
        if i > start and candidates[i] == candidates[i-1]: continue  // skip dup
        if sum + candidates[i] > target: break  // prune
        current.add(candidates[i])
        backtrack(candidates, target, i + 1, current, result, sum + candidates[i])  // i+1 (no reuse)
        current.remove(last)
```

## Java Code

```java
class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates);
        List<List<Integer>> result = new ArrayList<>();
        backtrack(candidates, target, 0, new ArrayList<>(), result, 0);
        return result;
    }

    private void backtrack(int[] candidates, int target, int start, List<Integer> current, List<List<Integer>> result, int sum) {
        if (sum == target) {
            result.add(new ArrayList<>(current));
            return;
        }
        if (sum > target) return;

        for (int i = start; i < candidates.length; i++) {
            if (i > start && candidates[i] == candidates[i - 1]) continue;  // skip dup
            if (sum + candidates[i] > target) break;  // prune
            current.add(candidates[i]);
            backtrack(candidates, target, i + 1, current, result, sum + candidates[i]);
            current.remove(current.size() - 1);
        }
    }
}
```

## Line-by-line

- `Arrays.sort` — groups duplicates, enables skip.
- `sum == target` ? record copy, return.
- `sum > target` ? prune.
- `if (i > start && candidates[i] == candidates[i-1]) continue` — skip duplicates at the same level.
- `backtrack(..., i + 1, ...)` — pass `i + 1` (no reuse).
- `if (sum + candidates[i] > target) break` — prune (sorted).

## Complexity

- Time: O(2^n) — each element included or not.
- Space: O(n) — recursion depth.

## Common Mistakes

- **Passing `i` instead of `i + 1`.** That allows reuse (that's Combination Sum #1). For "at most once," use `i + 1`.
- **Wrong skip condition.** `i > start` (not `i > 0`) — skip duplicates at the same level only.
- **Not sorting.** Duplicates must be adjacent for the skip to work.
- **Using `continue` for pruning.** Use `break` (sorted, later elements are bigger).

## How to Explain (interview)

**Opening:** Combination Sum II finds unique combinations (each number used at most once, duplicates in input). Sort first. Backtrack: skip duplicates at the same level (`i > start && nums[i] == nums[i-1]`), pass `i + 1` (no reuse), prune with `break`. O(2^n) time.

**The basic flow:**
```java
Arrays.sort(candidates);
void backtrack(int start, List<Integer> cur, int sum) {
    if (sum == target) { result.add(new ArrayList<>(cur)); return; }
    if (sum > target) return;
    for (int i = start; i < candidates.length; i++) {
        if (i > start && candidates[i] == candidates[i-1]) continue;
        if (sum + candidates[i] > target) break;
        cur.add(candidates[i]);
        backtrack(i + 1, cur, sum + candidates[i]);
        cur.remove(cur.size() - 1);
    }
}
```

**The part that trips everyone up:** the skip condition `i > start` (not `i > 0`) and no reuse (`i + 1`, not `i`). Also, `break` for pruning (not `continue`).

**The mistakes to remember:**
- Passing `i` instead of `i + 1` (allows reuse — wrong problem)
- Wrong skip condition (`i > 0` instead of `i > start`)
- Not sorting (duplicates not adjacent)
- Using `continue` instead of `break` for pruning
