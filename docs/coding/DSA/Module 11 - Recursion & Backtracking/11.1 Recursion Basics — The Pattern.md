# 17.1 Trie — The Pattern

## What This Problem Is Asking (Simple Terms)

A **Trie** (pronounced "try") or prefix tree is a tree-like data structure that stores a dynamic set of strings. Each node represents a single character, and paths from root to leaf represent complete strings.

Tries are ideal for:
- **Prefix-based search**: "autocomplete" functionality
- **Prefix matching**: "does any word start with 'pre'?"
- **String storage**: efficiently storing many strings with shared prefixes
- **Dictionary/lookup**: fast lookup of whether a word exists

---

## Example 1

**Input:** `["Trie","insert","search","search","startsWith","search"]`, `[[],["apple"],["apple"],["app"],["app"]]`

**Output:** `[null,null,null,false,true]`

**Explanation:**
- `insert("apple")` — inserts "apple"
- `search("apple")` → `true` (exists)
- `search("app")` → `false` (not inserted as complete word)
- `startsWith("app")` → `true` ("app" is prefix of "apple")
- `search("app")` → `false` (still not inserted as complete word)

---

## Example 2

**Input:** `["Trie","insert","search","search","startsWith","insert","search"]`, `[[],["a"],["a"],["a"],["a"],["a"],["a"]]`

**Output:** `[null,null,true,true,false,true]`

**Explanation:** After inserting "a" once, searching for "a" returns true. Inserting again doesn't change anything.

---

## Constraints

- `1 <= word.length, prefix.length <= 2000`
- `words[i]` and `prefix` consist of lowercase English letters.
- At most `3 * 10^4` calls in total to `insert`, `search`, and `startsWith`.

---

## Which Technique, and Why?

**Trie** (prefix tree) is ideal for:
- **Prefix-based search**: "autocomplete", "startsWith"
- **Prefix matching**: "does any word start with prefix P?"
- **String storage**: storing many strings with shared prefixes efficiently
- **Dictionary/lookup**: fast existence checks for words

**Signal in the problem:** "prefix", "autocomplete", "startsWith", "dictionary", "word search" → Trie

---

## Approach

**Trie structure:**
- Each node has 26 children (one for each letter a-z)
- `isEndOfWord` flag marks end of a complete word

**Operations:**
1. **Insert**: traverse/create nodes for each character, mark end
2. **Search**: traverse following characters, check end-of-word flag
3. **StartsWith**: traverse following characters, check if path exists

### Pseudocode (Trie)

```
class TrieNode:
    children = array of 26 TrieNode (null initially)
    isEnd = false

class Trie:
    root = new TrieNode()
    
    insert(word):
        node = root
        for char in word:
            index = char - 'a'
            if node.children[index] == null:
                node.children[index] = new TrieNode()
            node = node.children[index]
        node.isEnd = true
    
    search(word):
        node = searchPrefix(word)
        return node != null && node.isEnd
    
    startsWith(prefix):
        node = searchPrefix(prefix)
        return node != null
    
    searchPrefix(prefix):
        node = root
        for char in prefix:
            index = char - 'a'
            if node.children[index] == null: return null
            node = node.children[index]
        return node
```

### Java Code (Trie)

```java
class Trie {
    private class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean isEnd = false;
    }
    
    private TrieNode root;
    
    public Trie() {
        root = new TrieNode();
    }
    
    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (node.children[i] == null) {
                node.children[i] = new TrieNode();
            }
            node = node.children[i];
        }
        node.isEnd = true;
    }
    
    public boolean search(String word) {
        TrieNode node = searchPrefix(word);
        return node != null && node.isEnd;
    }
    
    public boolean startsWith(String prefix) {
        TrieNode node = searchPrefix(prefix);
        return node != null;
    }
    
    private TrieNode searchPrefix(String prefix) {
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            int i = c - 'a';
            if (node.children[i] == null) return null;
            node = node.children[i];
        }
        return node;
    }
}
```

### Line-by-line

- `TrieNode[] children = new TrieNode[26]` — one slot per lowercase letter
- `boolean isEnd` — marks end of a complete word
- `node.children[i]` — navigate to child node for character `i`
- `node.isEnd = true` — mark end of word

## Complexity

- Time: O(L) per operation where L = length of word
- Space: O(N * 26) where N = total number of characters in all inserted words

## Common Mistakes

- **Forgetting `isEnd` flag** — need to mark end of word to distinguish prefix from complete word
- **Not handling empty string** — empty string should be handled (root.isEnd = true)
- **Not using `isEnd` flag** — need to distinguish between prefix and complete word

## How to Explain (interview)

**Opening:** Trie (prefix tree) is a tree where each node represents a character, and paths from root represent words. Perfect for prefix-based operations.

**The basic flow:**
```java
class Trie {
    private TrieNode[] children = new TrieNode[26];
    private boolean isEnd = false;
    
    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (node.children[i] == null) node.children[i] = new TrieNode();
            node = node.children[i];
        }
        node.isEnd = true;
    }
    
    public boolean search(String word) {
        TrieNode node = searchPrefix(word);
        return node != null && node.isEnd;
    }
    
    public boolean startsWith(String prefix) {
        TrieNode node = searchPrefix(prefix);
        return node != null;
    }
    
    private TrieNode searchPrefix(String prefix) {
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            int i = c - 'a';
            if (node.children[i] == null) return null;
            node = node.children[i];
        }
        return node;
    }
}
```

**The part that trips everyone up:**
- **`isEnd` flag** — needed to distinguish between prefix and complete word
- **`node.children[i] == null`** — check if child exists before traversing
- **`new ArrayList<>(current)`** — must add copy to result, not reference

**The mistakes to remember:**
- Forgetting `isEnd` flag — can't distinguish prefix from complete word
- Not using `new ArrayList<>(current)` — result will reference same mutable list
- Not handling empty string — empty string is valid word
