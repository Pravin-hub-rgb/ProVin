# 11.14 Word Search

**Problem:** Given a 2D board of characters and a word, return true if the word exists in the grid (letters adjacent horizontally/vertically, no reuse). (LeetCode #79)

**Link:** https://leetcode.com/problems/word-search/

---

## Which Technique, and Why?

"Find a word in a grid" → **Backtracking on a grid**. DFS from each cell matching the first char; try all 4 directions; mark visited (temporarily) to avoid reuse. O(n × m × 4^L) time where L = word length.

**Signal in the problem:** "word search" / "find word in grid" / "adjacent letters" → DFS backtracking with visited marking.

## Approach

For each cell: if it matches `word[0]`, DFS. In DFS: if index == word.length → found. Mark cell as visited (e.g., set to '#'), try all 4 neighbors, unmark (restore). Return true if any neighbor succeeds.

## Pseudocode

```
for each cell (i, j):
    if board[i][j] == word[0] and dfs(board, i, j, 0, word): return true
return false

dfs(board, i, j, index, word):
    if index == word.length: return true
    if out of bounds or board[i][j] != word[index]: return false
    temp = board[i][j]
    board[i][j] = '#'  // mark visited
    found = dfs(i+1,j,index+1) or dfs(i-1,j,index+1) or dfs(i,j+1,index+1) or dfs(i,j-1,index+1)
    board[i][j] = temp  // unmark
    return found
```

## Java Code

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[0].length; j++) {
                if (board[i][j] == word.charAt(0) && dfs(board, i, j, 0, word)) {
                    return true;
                }
            }
        }
        return false;
    }

    private boolean dfs(char[][] board, int i, int j, int index, String word) {
        if (index == word.length()) return true;
        if (i < 0 || j < 0 || i >= board.length || j >= board[0].length || board[i][j] != word.charAt(index)) {
            return false;
        }

        char temp = board[i][j];
        board[i][j] = '#';  // mark visited

        boolean found = dfs(board, i + 1, j, index + 1, word) ||
                        dfs(board, i - 1, j, index + 1, word) ||
                        dfs(board, i, j + 1, index + 1, word) ||
                        dfs(board, i, j - 1, index + 1, word);

        board[i][j] = temp;  // unmark (backtrack)
        return found;
    }
}
```

## Line-by-line

- Outer loops: try every cell as a starting point (must match `word[0]`).
- `dfs`: base case `index == word.length()` → found the whole word.
- Boundary check: out of bounds or char mismatch → false.
- `temp = board[i][j]; board[i][j] = '#'` — mark visited (prevents reuse).
- Try all 4 directions with `index + 1`.
- `board[i][j] = temp` — undo the mark (backtrack) so other paths can use this cell.
- Short-circuit with `||`.

## Complexity

- Time: O(n × m × 4^L) where n×m = grid size, L = word length. Worst case explores all paths.
- Space: O(L) — recursion depth (the grid is modified in place, no visited array).

## Common Mistakes

- **Not unmarking the cell.** If you set `board[i][j] = '#'` and don't restore it, other starting points/paths can't use that cell. Always restore.
- **Not checking bounds first.** Check `i < 0 || j < 0 || i >= board.length || j >= board[0].length` before accessing `board[i][j]`.
- **Not checking char match.** `board[i][j] != word.charAt(index)` → return false.
- **Modifying the board when not allowed.** This problem allows in-place modification. If not, use a `visited` boolean array.
- **Stack overflow on long words.** Deep recursion. Use iterative DFS if needed (rare).

## How to Explain (interview)

**Opening:** Word Search finds a word in a grid (adjacent horizontally/vertically, no reuse). DFS backtracking: mark the current cell as visited (e.g., '#'), try all 4 neighbors for the next char, then unmark (restore) to allow other paths. O(n × m × 4^L) time, O(L) space.

**The basic flow:**
```java
boolean dfs(board, i, j, index, word) {
    if (index == word.length()) return true;
    if (out of bounds or board[i][j] != word.charAt(index)) return false;
    char temp = board[i][j];
    board[i][j] = '#';  // mark
    boolean found = dfs(i+1,j,index+1) || dfs(i-1,j,index+1) || dfs(i,j+1,index+1) || dfs(i,j-1,index+1);
    board[i][j] = temp;  // unmark
    return found;
}
```

**The part that trips everyone up:** you must **unmark** the cell after exploring (`board[i][j] = temp`). Without this, other paths can't use that cell. Also, mark visited with a temp char, not a separate array (saves space).

**The mistakes to remember:**
- Not unmarking (blocks other paths)
- Not checking bounds before accessing (NPE/ArrayIndexOutOfBounds)
- Not checking char match
- Stack overflow on long words
- Modifying input when problem forbids it
