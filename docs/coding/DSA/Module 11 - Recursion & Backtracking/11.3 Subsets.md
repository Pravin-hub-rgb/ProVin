# 11.3 Subsets

**Problem:** Given an integer array (may contain duplicates? No — distinct here), return all possible subsets (the power set). (LeetCode #78)

**Link:** https://leetcode.com/problems/subsets/

---

## Which Technique, and Why?

"Generate all subsets" → **Backtracking**. At each element, you either include it or not. The "choose → explore → undo" pattern. O(2^n × n) time.

**Signal in the problem:** "all subsets" / "power set" / "generate all combinations" → backtracking.

## Approach

Backtrack: parameters `start` (current index), `current` (built subset). At each node, record a copy of `current` (including the empty set). Then for each element from `start` onward, add it, recurse with `i + 1`, undo.

## Pseudocode

```
result = []
backtrack(nums, 0, [], result)
return result

backtrack(nums, start, current, result):
    result.add(copy of current)
    for i from start to nums.length-1:
        current.add(nums[i])
        backtrack(nums, i + 1, current, result)
        current.remove(last)
```

## Java Code

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        backtrack(nums, 0, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(int[] nums, int start, List<Integer> current, List<List<Integer>> result) {
        result.add(new ArrayList<>(current));  // record (including empty set)

        for (int i = start; i < nums.length; i++) {
            current.add(nums[i]);               // choose
            backtrack(nums, i + 1, current, result); // explore
            current.remove(current.size() - 1);  // undo
        }
    }
}
```

## Line-by-line

- `result.add(new ArrayList<>(current))` — record a copy at every node, including the empty set (first call records `[]`).
- `for (i = start; ...)` — try each remaining element as the next choice.
- `current.add(nums[i])` — choose.
- `backtrack(nums, i + 1, ...)` — recurse with next starting index (no reuse).
- `current.remove(...)` — undo.

## Complexity

- Time: O(2^n × n) — 2^n subsets, each copy is O(n).
- Space: O(n) — recursion depth (plus output).

## Common Mistakes

- **Not recording the empty set.** The first `result.add` (before the loop) records `[]`. Don't skip it.
- **Not copying.** `result.add(current)` stores a reference — later modifications corrupt results. Use `new ArrayList<>(current)`.
- **Forgetting to undo.** `current.remove(...)` is essential.
- **Passing `i` instead of `i + 1`.** That allows reuse (wrong for subsets — each element used at most once).

## How to Explain (interview)

**Opening:** Subsets generates the power set of an array. Backtracking: at each node, record the current subset (including empty), then for each remaining element, choose it, recurse, undo. O(2^n × n) time.

**The basic flow:**
```java
void backtrack(int start, List<Integer> cur) {
    result.add(new ArrayList<>(cur));  // record
    for (int i = start; i < nums.length; i++) {
        cur.add(nums[i]);
        backtrack(i + 1, cur);
        cur.remove(cur.size() - 1);
    }
}
```

**The part that trips everyone up:** record the current subset **at every node** (including the root, which gives the empty set). Also, copy the list when recording (`new ArrayList<>(cur)`).

**The mistakes to remember:**
- Not recording the empty set
- Storing references instead of copies
- Forgetting to undo
- Passing `i` instead of `i + 1` (allows reuse)
