**Problem:** Given a string of digits (2-9), return all possible letter combinations that the number could represent (phone keypad mapping). (LeetCode #17)

**Link:** https://leetcode.com/problems/letter-combinations-of-a-phone-number/

---

## Which Technique, and Why?

"Generate all letter combinations from digit mapping" ? **Backtracking over digits**. For each digit, try each of its letters; recurse to the next digit. O(4^n) time (max 4 letters per digit), O(n) space.

**Signal in the problem:** "letter combinations" / "phone number" / "digits to letters" ? backtracking over the digit array.

## Approach

Backtrack over digits. Parameters: `index` (current digit), `current` (built string). Base: `index == digits.length()` ? record. For each letter of `digits[index]`, append, recurse with `index + 1`, undo.

## Pseudocode

```
if digits is empty: return []
map = {"2":"abc", "3":"def", ..., "9":"wxyz"}
result = []
backtrack(digits, 0, "", result, map)
return result

backtrack(digits, index, current, result, map):
    if index == digits.length():
        result.add(current)
        return
    for each letter in map[digits[index]]:
        backtrack(digits, index + 1, current + letter, result, map)
```

## Java Code

```java
class Solution {
    public List<String> letterCombinations(String digits) {
        List<String> result = new ArrayList<>();
        if (digits == null || digits.length() == 0) return result;

        String[] map = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};

        backtrack(digits, 0, new StringBuilder(), result, map);
        return result;
    }

    private void backtrack(String digits, int index, StringBuilder current, List<String> result, String[] map) {
        if (index == digits.length()) {
            result.add(current.toString());
            return;
        }

        String letters = map[digits.charAt(index) - '0'];
        for (char c : letters.toCharArray()) {
            current.append(c);
            backtrack(digits, index + 1, current, result, map);
            current.deleteCharAt(current.length() - 1);
        }
    }
}
```

## Line-by-line

- `map` — array indexed by digit: `map[2] = "abc"`, etc. Index 0 and 1 are empty (no letters).
- Empty digits ? return empty list (problem spec).
- `backtrack`: if `index == digits.length()`, record the built string.
- For each letter of the current digit: append, recurse (next digit), delete (undo).
- Using `StringBuilder` for efficient append/delete.

## Complexity

- Time: O(4^n × n) — 4 letters per digit, n digits, and O(n) to build each string.
- Space: O(n) — recursion depth + StringBuilder.

## Common Mistakes

- **Not handling empty input.** Empty digits ? empty list (not a list with one empty string).
- **Wrong map indexing.** `digits.charAt(index) - '0'` converts '2' ? 2. The map array is indexed by digit value.
- **Forgetting to undo.** `current.deleteCharAt(...)` after recursion.
- **Using String instead of StringBuilder.** String concatenation in a loop is O(n²). StringBuilder is O(n) amortized.

## How to Explain (interview)

**Opening:** Letter Combinations generates all letter combinations from a digit string (phone keypad). Backtracking: for each digit, try each of its letters, recurse to the next digit, undo. O(4^n × n) time where 4 is max letters per digit. Handle empty input (return empty list).

**The basic flow:**
```java
String[] map = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
void backtrack(String digits, int index, StringBuilder current) {
    if (index == digits.length()) { result.add(current.toString()); return; }
    for (char c : map[digits.charAt(index) - '0'].toCharArray()) {
        current.append(c);
        backtrack(digits, index + 1, current);
        current.deleteCharAt(current.length() - 1);
    }
}
```

**The part that trips everyone up:** empty input returns an **empty list**, not a list with one empty string. Also, `map[digits.charAt(index) - '0']` — the `- '0'` converts char to int index.

**The mistakes to remember:**
- Not handling empty input (returns wrong result)
- Wrong map indexing (forgetting `- '0'`)
- Forgetting to undo (deleteCharAt)
- Using String instead of StringBuilder (O(n²))
