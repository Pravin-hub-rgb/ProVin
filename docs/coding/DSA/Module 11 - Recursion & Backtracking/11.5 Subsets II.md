# 11.5 Subsets II

**Problem:** Given an array that may contain duplicates, return all unique subsets. (LeetCode #90)

**Link:** https://leetcode.com/problems/subsets-ii/

---

## Which Technique, and Why?

"Generate all subsets with duplicates" → **Backtracking with duplicate skipping**. Sort the array first; skip duplicates at the same recursion level. O(2^n × n) time, O(n) space (recursion).

**Signal in the problem:** "subsets" + "may contain duplicates" / "unique subsets" → backtracking + sort + skip duplicates.

## Approach

Sort the array. Backtrack: at each level, try each element from `start` onward. Skip if `nums[i] == nums[i-1]` and `i > start` (same level duplicate). Record a copy of current at every node.

## Pseudocode

```
sort nums
result = []
backtrack(nums, 0, [], result)
return result

backtrack(nums, start, current, result):
    result.add(copy of current)
    for i from start to nums.length-1:
        if i > start and nums[i] == nums[i-1]: continue  // skip duplicate
        current.add(nums[i])
        backtrack(nums, i + 1, current, result)
        current.remove(last)
```

## Java Code

```java
class Solution {
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();
        backtrack(nums, 0, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(int[] nums, int start, List<Integer> current, List<List<Integer>> result) {
        result.add(new ArrayList<>(current));

        for (int i = start; i < nums.length; i++) {
            if (i > start && nums[i] == nums[i - 1]) continue;  // skip duplicate at same level
            current.add(nums[i]);
            backtrack(nums, i + 1, current, result);
            current.remove(current.size() - 1);
        }
    }
}
```

## Line-by-line

- `Arrays.sort(nums)` — sorting groups duplicates together, enabling the skip.
- `result.add(new ArrayList<>(current))` — record a copy at every node (including empty set).
- `if (i > start && nums[i] == nums[i-1]) continue` — skip duplicates at the same recursion level. `i > start` ensures we don't skip the first occurrence in a level (which is allowed).
- `current.add` / `backtrack` / `remove` — choose, explore, undo.

## Complexity

- Time: O(2^n × n) — 2^n subsets, each copy is O(n).
- Space: O(n) — recursion stack depth (plus output storage).

## Common Mistakes

- **Not sorting first.** Without sorting, duplicates aren't adjacent, so the skip doesn't work.
- **Skip condition wrong.** `i > start` (not `i > 0`) — you only skip duplicates within the same level, not across levels. The first occurrence at each level is allowed.
- **Storing references instead of copies.** `result.add(current)` corrupts results. Use `new ArrayList<>(current)`.
- **Forgetting to undo.** `current.remove(...)` after recursion is essential.

## How to Explain (interview)

**Opening:** Subsets II generates all unique subsets of an array that may contain duplicates. Sort first (groups duplicates). Backtrack: at each level, try each element from `start` onward, skipping duplicates at the same level (`i > start && nums[i] == nums[i-1]`). Record a copy of current at every node. O(2^n × n) time.

**The basic flow:**
```java
Arrays.sort(nums);
void backtrack(int start, List<Integer> current) {
    result.add(new ArrayList<>(current));
    for (int i = start; i < nums.length; i++) {
        if (i > start && nums[i] == nums[i-1]) continue;
        current.add(nums[i]);
        backtrack(i + 1, current);
        current.remove(current.size() - 1);
    }
}
```

**The part that trips everyone up:** the skip condition is `i > start` (not `i > 0`). This ensures the first occurrence at each level is kept, but subsequent duplicates at the same level are skipped.

**The mistakes to remember:**
- Not sorting (duplicates not adjacent)
- Wrong skip condition (`i > 0` instead of `i > start`)
- Storing references instead of copies
- Forgetting to undo
