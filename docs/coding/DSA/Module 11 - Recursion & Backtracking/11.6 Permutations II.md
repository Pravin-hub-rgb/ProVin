**Problem:** Given an array that may contain duplicates, return all unique permutations. (LeetCode #47)

**Link:** https://leetcode.com/problems/permutations-ii/

---

## Which Technique, and Why?

"Generate all unique permutations with duplicates" ? **Backtracking with duplicate skipping**. Sort the array; skip an element if it's equal to the previous element AND the previous element hasn't been used in this branch. O(n × n!) time, O(n) space.

**Signal in the problem:** "permutations" + "may contain duplicates" / "unique permutations" ? backtracking + sort + used-array skip.

## Approach

Sort the array. Backtrack with a `used` boolean array. For each position, try each unused element; skip if `nums[i] == nums[i-1] && !used[i-1]` (duplicate at the same level). Mark used, recurse, unmark.

## Pseudocode

```
sort nums
result = []
used = boolean array (size n)
backtrack(nums, used, current, result)
return result

backtrack(nums, used, current, result):
    if current.size == nums.length: result.add(copy); return
    for i from 0 to nums.length-1:
        if used[i]: continue
        if i > 0 and nums[i] == nums[i-1] and !used[i-1]: continue  // skip duplicate
        used[i] = true
        current.add(nums[i])
        backtrack(nums, used, current, result)
        current.remove(last)
        used[i] = false
```

## Java Code

```java
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        backtrack(nums, used, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(int[] nums, boolean[] used, List<Integer> current, List<List<Integer>> result) {
        if (current.size() == nums.length) {
            result.add(new ArrayList<>(current));
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
            used[i] = true;
            current.add(nums[i]);
            backtrack(nums, used, current, result);
            current.remove(current.size() - 1);
            used[i] = false;
        }
    }
}
```

## Line-by-line

- `Arrays.sort(nums)` — groups duplicates.
- `used[i]` — tracks which elements are in the current permutation.
- `if (used[i]) continue` — skip already-used elements.
- `if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue` — skip duplicates at the same level. The `!used[i-1]` check means: if the previous duplicate hasn't been used in this branch, skip (it would produce a duplicate permutation).
- `used[i] = true` / `current.add` ? choose. Recurse. Undo both.

## Complexity

- Time: O(n × n!) — n! permutations, each takes O(n) to build.
- Space: O(n) — recursion stack + used array (+ output).

## Common Mistakes

- **Wrong skip condition.** `!used[i-1]` (not `used[i-1]`). If the previous duplicate is NOT used, this is a duplicate at the same level ? skip. If it IS used, this is a legitimate different branch.
- **Not sorting.** Without sorting, duplicates aren't adjacent, so the skip doesn't work.
- **Storing references.** Use `new ArrayList<>(current)` when recording.
- **Forgetting to undo `used[i]`.** Must set `used[i] = false` after recursion.

## How to Explain (interview)

**Opening:** Permutations II generates all unique permutations of an array with duplicates. Sort first. Backtrack with a `used` array. Skip an element if it's a duplicate of the previous AND the previous hasn't been used in this branch (`i > 0 && nums[i] == nums[i-1] && !used[i-1]`). O(n × n!) time.

**The basic flow:**
```java
Arrays.sort(nums);
boolean[] used = new boolean[n];
void backtrack(...) {
    if (current.size() == n) { result.add(new ArrayList<>(current)); return; }
    for (int i = 0; i < n; i++) {
        if (used[i]) continue;
        if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;
        used[i] = true; current.add(nums[i]);
        backtrack(...);
        current.remove(...); used[i] = false;
    }
}
```

**The part that trips everyone up:** the skip condition uses `!used[i-1]` (not `used[i-1]`). This means: if the previous duplicate hasn't been used yet in this branch, skip (it's a duplicate at this level). If it has been used, this is a different branch — don't skip.

**The mistakes to remember:**
- Using `used[i-1]` instead of `!used[i-1]` (wrong skip)
- Not sorting (duplicates not adjacent)
- Forgetting to undo `used[i]`
- Storing references instead of copies
