**Problem:** Given a string of digits, return all possible valid IP addresses that can be formed by inserting dots. (LeetCode #93)

**Link:** https://leetcode.com/problems/restore-ip-addresses/

---

## Which Technique, and Why?

"Restore valid IP addresses from a digit string" ? **Backtracking with constraints**. An IP address has 4 parts, each 0–255, no leading zeros (except "0" itself). Try placing dots at valid positions, recurse, undo.

**Signal in the problem:** "restore IP addresses" / "valid IP" / "insert dots" ? backtracking with validity checks.

## Approach

Backtrack: parameters `start` (current position), `parts` (list of IP parts so far). If `parts.size() == 4` and `start == s.length()` ? valid IP, record. Otherwise, try substrings of length 1, 2, 3 starting at `start`; if valid (0–255, no leading zeros), add, recurse, undo.

## Pseudocode

backtrack(s, 0, [], result)
return result

## Java Code

```java
class Solution {
    public List<String> restoreIpAddresses(String s) {
        List<String> result = new ArrayList<>();
        backtrack(s, 0, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(String s, int start, List<String> parts, List<String> result) {
        if (parts.size() == 4) {
            if (start == s.length()) {
                result.add(String.join(".", parts));
            }
            return;
        }
        if (start == s.length()) return;

        for (int len = 1; len <= 3; len++) {
            if (start + len > s.length()) break;
            String part = s.substring(start, start + len);
            if (isValid(part)) {
                parts.add(part);
                backtrack(s, start + len, parts, result);
                parts.remove(parts.size() - 1);
            }
        }
    }

    private boolean isValid(String part) {
        if (part.length() > 1 && part.charAt(0) == '0') return false; // leading zero
        int val = Integer.parseInt(part);
        return val >= 0 && val <= 255;
    }
}
```

## Line-by-line

- `parts.size() == 4` ? if `start == s.length()`, we've used all chars ? valid IP. Record.
- `start == s.length()` with `parts.size() < 4` ? ran out of chars ? invalid.
- `for (len = 1; len <= 3)` — try substrings of length 1, 2, 3.
- `start + len > s.length()` ? break (not enough chars).
- `isValid(part)` — no leading zeros (except "0" itself), value 0–255.
- Add, recurse, undo.

## Complexity

- Time: O(3^4) = O(1) — at most 3 choices per of 4 parts, bounded by string length = 12.
- Space: O(1) — recursion depth 4.

## Common Mistakes

- **Leading zeros.** "01" is invalid; "0" is valid. Check `part.length() > 1 && part.charAt(0) == '0'`.
- **Not checking `start == s.length()` when parts == 4.** If parts == 4 but chars remain unused ? invalid.
- **Not breaking when `start + len > s.length()`.** Use `break` (not `continue`) since longer lengths also fail.
- **Integer parsing.** `Integer.parseInt("00")` = 0, which passes the range check. The leading-zero check catches this.

## How to Explain (interview)

**Opening:** Restore IP Addresses generates all valid IPs from a digit string. Backtracking: try substrings of length 1–3 at each position; if valid (no leading zeros, 0–255), add and recurse. Base case: 4 parts and all chars used. O(1) time (bounded by 4 parts × 3 lengths).

**The basic flow:**
```java
void backtrack(String s, int start, List<String> parts) {
    if (parts.size() == 4) { if (start == s.length()) result.add(join(parts)); return; }
    for (int len = 1; len <= 3; len++) {
        if (start + len > s.length()) break;
        String part = s.substring(start, start + len);
        if (isValid(part)) { parts.add(part); backtrack(s, start + len, parts); parts.remove(...); }
    }
}
```

**The part that trips everyone up:** validity — no leading zeros (`"01"` invalid, `"0"` valid) and value 0–255. Also, the base case requires **both** 4 parts AND all chars used.

**The mistakes to remember:**
- Leading zeros not handled ("01" should be invalid)
- Base case only checks parts == 4 (misses unused chars)
- Using `continue` instead of `break` for length overflow
- `Integer.parseInt("00")` = 0 (passes range check — leading-zero check catches it)
