**Tier 2 problem.** (LeetCode #1020)

**Problem:** Given a binary grid, return the number of land cells (1s) that are not connected to the boundary (completely surrounded by water or border). (LeetCode #1020)

**Link:** https://leetcode.com/problems/number-of-enclaves/

---

## Which Technique, and Why?

"Number of enclaves" = land cells not connected to the border. **Reverse the problem:** mark all land connected to the border (DFS from border 1s), then count unmarked land. O(m × n) time, O(m × n) space (recursion) or O(1) if modifying in place.

**Signal in the problem:** "enclaves" / "not connected to boundary" / "surrounded by water" → reverse: mark border-connected land, count the rest.

## Approach

1. DFS from all '1's on the border, marking them as '0' (or visited).
2. Count remaining '1's in the grid.

## Pseudocode

```
for each border cell:
    if grid[i][j] == 1: dfs(i, j)  // sink border-connected land
count = 0
for each cell:
    if grid[i][j] == 1: count++
return count

dfs(i, j):
    if out of bounds or grid[i][j] != 1: return
    grid[i][j] = 0  // sink
    dfs(i+1,j); dfs(i-1,j); dfs(i,j+1); dfs(i,j-1)
```

## Java Code

```java
class Solution {
    public int numEnclaves(int[][] grid) {
        int m = grid.length, n = grid[0].length;

        // Sink all border-connected land
        for (int i = 0; i < m; i++) {
            if (grid[i][0] == 1) dfs(grid, i, 0);
            if (grid[i][n - 1] == 1) dfs(grid, i, n - 1);
        }
        for (int j = 0; j < n; j++) {
            if (grid[0][j] == 1) dfs(grid, 0, j);
            if (grid[m - 1][j] == 1) dfs(grid, m - 1, j);
        }

        // Count remaining land (enclaves)
        int count = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) count++;
            }
        }
        return count;
    }

    private void dfs(int[][] grid, int i, int j) {
        if (i < 0 || j < 0 || i >= grid.length || j >= grid[0].length || grid[i][j] != 1) return;
        grid[i][j] = 0;
        dfs(grid, i + 1, j);
        dfs(grid, i - 1, j);
        dfs(grid, i, j + 1);
        dfs(grid, i, j - 1);
    }
}
```

## Line-by-line

- Sink all land connected to the border (DFS from border '1's, mark as '0').
- Count remaining '1's — these are enclaves (not connected to border).

## Complexity

- Time: O(m × n) — visit every cell.
- Space: O(m × n) worst case (recursion). O(1) if modifying in place.

## Common Mistakes

- **Finding enclaves directly.** Harder. Reverse: mark border-connected land, count the rest.
- **Not sinking all border land.** Check all four borders (top, bottom, left, right).
- **Modifying input when not allowed.** Use a visited array instead.
- **Confusing with Surrounded Regions (#130).** Same reverse approach, different output (count vs flip).

## How to Explain (interview)

**Opening:** Number of Enclaves counts land cells not connected to the border. Reverse the problem: mark all border-connected land (DFS from border 1s, sink to 0), then count remaining 1s. O(m×n) time, O(1) extra space (modifying in place).

**The basic flow:**
```java
// sink border-connected land
for (border cells) if (grid[i][j] == 1) dfs(i, j);
// count remaining 1s
for (all cells) if (grid[i][j] == 1) count++;
return count;
```

**The part that trips everyone up:** reverse the problem — find safe land (connected to border) instead of enclaves. Also, check all four borders.

**The mistakes to remember:**
- Finding enclaves directly (harder)
- Not checking all four borders
- Modifying input when problem forbids it
- Confusing with Surrounded Regions (#130) (count vs flip)
