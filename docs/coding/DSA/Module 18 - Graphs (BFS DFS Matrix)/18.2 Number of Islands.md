# 18.2 Number of Islands

**Problem:** Given a 2D grid of '1's (land) and '0's (water), count the number of islands. An island is a group of '1's connected horizontally or vertically. (LeetCode #200)

**Link:** https://leetcode.com/problems/number-of-islands/

---

## Which Technique, and Why?

Count connected components in a grid → **DFS flood fill** (or BFS). Each '1' found starts a new island; sink the entire island to avoid re-counting. O(m × n) time, O(m × n) space (recursion) or O(1) if modifying in place.

**Signal in the problem:** "number of islands" / "connected components in a grid" → flood fill (DFS or BFS) + count.

## Approach

Scan every cell. When you find a '1', increment count and sink the entire island (DFS/BFS marking all connected '1's as '0').

## Pseudocode

```
count = 0
for each cell (i, j):
    if grid[i][j] == '1':
        count++
        dfs(grid, i, j)   // sink the island
return count

dfs(grid, i, j):
    if out of bounds or grid[i][j] != '1': return
    grid[i][j] = '0'     // mark visited
    dfs(grid, i+1, j)    // down
    dfs(grid, i-1, j)    // up
    dfs(grid, i, j+1)    // right
    dfs(grid, i, j-1)    // left
```

## Java Code

```java
class Solution {
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) return 0;
        int count = 0;

        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                if (grid[i][j] == '1') {
                    count++;
                    dfs(grid, i, j);
                }
            }
        }
        return count;
    }

    private void dfs(char[][] grid, int i, int j) {
        if (i < 0 || j < 0 || i >= grid.length || j >= grid[0].length || grid[i][j] != '1') {
            return;
        }
        grid[i][j] = '0';  // sink
        dfs(grid, i + 1, j);
        dfs(grid, i - 1, j);
        dfs(grid, i, j + 1);
        dfs(grid, i, j - 1);
    }
}
```

## Line-by-line

- Outer loops scan every cell. A '1' means a new island.
- `dfs` sinks the entire island by marking cells as '0'.
- Boundary checks prevent out-of-bounds and re-visiting.
- Each cell visited at most once → O(m × n) time.

## Complexity

- Time: O(m × n) — visit every cell once.
- Space: O(m × n) worst case (recursion stack for a grid of all '1's). O(1) if modifying in place (no separate visited array).

## Common Mistakes

- **Not sinking/marking visited.** Infinite loop or re-counting.
- **Modifying input when problem forbids it.** Use a `visited` boolean array instead.
- **Stack overflow on large grids.** Use iterative DFS (explicit stack) or BFS (queue) for large inputs.
- **Off-by-one in bounds.** `i >= grid.length` and `j >= grid[0].length`.

## How to Explain (interview)

**Opening:** Number of Islands counts connected components of '1's in a grid. Scan every cell; when you find a '1', increment count and flood-fill (DFS) the entire island, marking visited cells as '0'. Each cell visited once → O(m×n) time. O(1) extra space if modifying in place.

**The basic flow:**
```java
for each cell:
    if grid[i][j] == '1':
        count++
        dfs(grid, i, j)  // sink the island
// dfs: if out of bounds or not '1', return; mark '0'; recurse 4 neighbors
```

**The part that trips everyone up:** marking visited (sink to '0' or use visited array). Without it, infinite loop or re-counting. Also, distinguish 4-directional vs 8-directional.

**The mistakes to remember:**
- Not marking visited (infinite loop / re-count)
- Modifying input when problem forbids it
- Stack overflow on large grids (use iterative/BFS)
- Wrong neighbor directions (4 vs 8)
- Off-by-one in bounds checks
