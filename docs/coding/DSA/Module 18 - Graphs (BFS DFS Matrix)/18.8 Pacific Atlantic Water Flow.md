# 18.8 Pacific Atlantic Water Flow

**Tier 2 problem.** (LeetCode #417)

**Problem:** Given an m×n matrix of heights, find cells from which water can flow to both the Pacific (top/left) and Atlantic (bottom/right) oceans. (LeetCode #417)

**Link:** https://leetcode.com/problems/pacific-atlantic-water-flow/

---

## Which Technique, and Why?

"Water flows from a cell to adjacent cells with height ≤ current." Find cells that can reach both oceans. **Reverse the flow:** instead of checking from each cell (O((mn)²)), start from the ocean borders and flow inward (water flows uphill in reverse). Mark cells reachable from Pacific and Atlantic separately. Intersection = answer. O(m × n) time.

**Signal in the problem:** "water flow" / "reach both oceans" / "Pacific and Atlantic" → reverse flow from borders (BFS/DFS from ocean edges).

## Approach

1. DFS/BFS from all Pacific border cells (top row + left column), marking reachable cells.
2. DFS/BFS from all Atlantic border cells (bottom row + right column), marking reachable cells.
3. Return cells marked in both.

## Pseudocode

```
pacific = boolean[m][n], atlantic = boolean[m][n]
// DFS from Pacific borders
for each cell in top row and left column: dfs(cell, pacific)
// DFS from Atlantic borders
for each cell in bottom row and right column: dfs(cell, atlantic)
// collect cells marked in both
```

## Java Code

```java
class Solution {
    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        int m = heights.length, n = heights[0].length;
        boolean[][] pacific = new boolean[m][n];
        boolean[][] atlantic = new boolean[m][n];

        for (int i = 0; i < m; i++) {
            dfs(heights, i, 0, pacific, 0);       // left border (Pacific)
            dfs(heights, i, n - 1, atlantic, 0);  // right border (Atlantic)
        }
        for (int j = 0; j < n; j++) {
            dfs(heights, 0, j, pacific, 0);       // top border (Pacific)
            dfs(heights, m - 1, j, atlantic, 0);  // bottom border (Atlantic)
        }

        List<List<Integer>> result = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (pacific[i][j] && atlantic[i][j]) {
                    result.add(Arrays.asList(i, j));
                }
            }
        }
        return result;
    }

    private void dfs(int[][] h, int r, int c, boolean[][] visited, int prevHeight) {
        if (r < 0 || c < 0 || r >= h.length || c >= h[0].length || visited[r][c] || h[r][c] < prevHeight) return;
        visited[r][c] = true;
        dfs(h, r + 1, c, visited, h[r][c]);
        dfs(h, r - 1, c, visited, h[r][c]);
        dfs(h, r, c + 1, visited, h[r][c]);
        dfs(h, r, c - 1, visited, h[r][c]);
    }
}
```

## Line-by-line

- `pacific` and `atlantic` — boolean grids marking reachable cells.
- DFS from Pacific borders (top row + left col): water flows "uphill" (height ≥ prev).
- DFS from Atlantic borders (bottom row + right col): same.
- Intersection: cells reachable from both.

## Complexity

- Time: O(m × n) — visit every cell at most twice (once per ocean).
- Space: O(m × n) — two boolean grids + recursion stack.

## Common Mistakes

- **Flowing downhill (forward).** Water flows from high to low. In reverse, you go from low (ocean) to high (uphill). The condition is `h[r][c] >= prevHeight`, not `<=`.
- **Not marking visited.** Without visited, infinite loop. Mark when enqueuing/pushing.
- **Starting from only one border.** Pacific = top + left. Atlantic = bottom + right. You need all four borders.
- **Stack overflow on large grids.** Use iterative DFS (stack) or BFS (queue) for large inputs.

**The part that trips everyone up:** reverse the flow — go **uphill** (`h[r][c] >= prevHeight`), not downhill. Water flows from high to low; in reverse, you climb from the ocean (height 0) upward.

**The mistakes to remember:**
- Flowing downhill instead of uphill (wrong direction)
- Not marking visited (infinite loop)
- Missing borders (need top+left for Pacific, bottom+right for Atlantic)
