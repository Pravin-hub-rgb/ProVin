# 18.10 Number of Provinces

**Tier 2 problem.** (LeetCode #547)

**Problem:** Given an adjacency matrix of a graph, return the number of connected components (provinces). (LeetCode #547)

**Link:** https://leetcode.com/problems/number-of-provinces/

---

## Which Technique, and Why?

"Number of connected components" → **DFS/BFS/Union-Find**. O(n²) time (matrix), O(n) space. DFS is simplest.

**Signal in the problem:** "number of provinces" / "connected components" / "adjacency matrix" → DFS/BFS/DSU.

## Approach (DFS)

For each unvisited node, DFS to mark all connected nodes as visited. Count the number of DFS calls.

## Pseudocode

```
visited = boolean[n]
count = 0
for i from 0 to n-1:
    if !visited[i]:
        count++
        dfs(i)
return count

dfs(i):
    visited[i] = true
    for j from 0 to n-1:
        if isConnected[i][j] and !visited[j]:
            dfs(j)
```

## Java Code

```java
class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        boolean[] visited = new boolean[n];
        int count = 0;

        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                count++;
                dfs(isConnected, visited, i);
            }
        }
        return count;
    }

    private void dfs(int[][] isConnected, boolean[] visited, int i) {
        visited[i] = true;
        for (int j = 0; j < isConnected.length; j++) {
            if (isConnected[i][j] == 1 && !visited[j]) {
                dfs(isConnected, visited, j);
            }
        }
    }
}
```

## Complexity

- Time: O(n²) — adjacency matrix, each DFS visits all neighbors.
- Space: O(n) — visited array + recursion stack.

## Common Mistakes

- **Using adjacency list on a matrix input.** The input is a matrix — use it directly. Converting to adjacency list wastes time.
- **Not marking visited before recursing.** Mark `visited[i] = true` before exploring neighbors (prevents infinite loops on cycles).
- **Stack overflow on large graphs.** Use iterative DFS or BFS for large n.
- **Confusing with "Number of Islands" (#200).** Same idea (count components), but islands use a grid (4-dir neighbors), provinces use an adjacency matrix (all pairs).

**The basic flow:**
```java
int count = 0;
for (int i = 0; i < n; i++) {
```

**The mistakes to remember:**
