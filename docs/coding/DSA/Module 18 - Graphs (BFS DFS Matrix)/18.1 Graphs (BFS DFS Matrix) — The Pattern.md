# 18.1 Graphs (BFS DFS Matrix) — The Pattern

## What This Problem Is Asking (Simple Terms)

A **graph** is a collection of nodes (vertices) connected by edges. Graphs can be:
- **Undirected**: edges go both ways
- **Directed**: edges have direction
- **Weighted**: edges have weights/costs
- **Unweighted**: all edges have equal weight

Common graph problems:
- **BFS/DFS**: traverse all nodes
- **Shortest path**: find shortest path between nodes
- **Cycle detection**: detect cycles
- **Topological sort**: order tasks with dependencies
- **Connected components**: find connected groups
- **MST**: minimum spanning tree

---

## Example 1

**Input:** `graph = [[1,2],[0,2],[0,1,3],[2]]`, `start = 0`

**Output:** `[0,1,2,3]` (BFS order)

**Explanation:** BFS from node 0: visit 0, then 1 and 2, then 3.

## Example 2

**Input:** `numCourses = 2`, `prerequisites = [[1,0]]`

**Output:** `[0,1]`

**Explanation:** Take course 0 first, then course 1.

## Constraints

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `0 <= nums[i] <= 10^4`

---

## Which Technique, and Why?

**Graph traversal** uses BFS or DFS:
- **BFS**: level-by-level, good for shortest path in unweighted graphs
- **DFS**: depth-first, good for cycle detection, topological sort

**Signal in the problem:** "graph," "graph traversal," "connected components," "shortest path" → Graph traversal

---

## Approach

**BFS:**
```
queue = [start]
visited = {start}
result = []
while queue:
    node = queue.pop(0)
    result.append(node)
    for neighbor in graph[node]:
        if neighbor not in visited:
            visited.add(neighbor)
            queue.append(neighbor)
return result
```

### Java Code (BFS)

```java
class Solution {
    public List<Integer> bfs(int[][] graph, int start) {
        List<Integer> result = new ArrayList<>();
        boolean[] visited = new boolean[graph.length];
        Queue<Integer> queue = new LinkedList<>();
        
        queue.offer(start);
        visited[start] = true;
        
        while (!queue.isEmpty()) {
            int node = queue.poll();
            result.add(node);
            for (int neighbor : graph[node]) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    queue.offer(neighbor);
                }
            }
        }
        return result;
    }
}
```

### Line-by-line

- `queue.offer(start)` — add start node to queue
- `visited[start] = true` — mark start as visited
- `while (!queue.isEmpty())` — process until queue empty
- `int node = queue.poll()` — get next node to process
- `result.add(node)` — add to result
- `if (!visited[neighbor])` — check if neighbor visited
- `queue.offer(neighbor)` — add neighbor to queue

## Complexity

- Time: O(V + E) — visit each node and edge once
- Space: O(n) — queue and visited array

## Common Mistakes

- **Not marking visited when adding to queue** — can add same node multiple times
- **Using DFS instead of BFS** — BFS gives shortest path in unweighted graphs
- **Not handling disconnected components** — need to iterate all nodes

## How to Explain (interview)

**Opening:** Graph traversal visits all nodes in a graph. BFS uses queue for level-order traversal, DFS uses stack/recursion for depth-first traversal.

**The basic flow:**
```java
Queue<Integer> queue = new LinkedList<>();
boolean[] visited = new boolean[n];
queue.offer(start);
visited[start] = true;
while (!queue.isEmpty()) {
    int node = queue.poll();
    result.add(node);
    for (int neighbor : graph[node]) {
        if (!visited[neighbor]) {
            visited[neighbor] = true;
            queue.offer(neighbor);
        }
    }
}
```

**The part that trips everyone up:**
- **Marking visited when adding to queue** — prevents adding same node multiple times
- **Using adjacency list** — efficient graph representation
- **Handling disconnected components** — need to iterate all nodes

**The mistakes to remember:**
- Forgetting to mark visited when adding to queue
- Using wrong data structure (stack vs queue)
- Not handling disconnected components
