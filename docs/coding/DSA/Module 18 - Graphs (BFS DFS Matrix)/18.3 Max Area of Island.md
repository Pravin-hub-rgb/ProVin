# 18.3 Max Area of Island

**Problem:** Given a 2D grid of 0s and 1s, find the maximum area of an island (connected group of 1s). Return 0 if no island. (LeetCode #695)

**Link:** https://leetcode.com/problems/max-area-of-island/

---

## Which Technique, and Why?

"Maximum area of an island" = "largest connected component" → **DFS flood fill returning area**. Same as Number of Islands, but instead of counting, sum the area of each island and track the max. O(m × n) time.

**Signal in the problem:** "max area" / "largest island" / "largest connected component" → flood fill returning size.

## Approach

Scan every cell. When you find a '1', DFS to compute the area of that island (count cells), update max. Sink cells as you go (mark '0').

## Pseudocode

```
maxArea = 0
for each cell (i, j):
    if grid[i][j] == 1:
        area = dfs(grid, i, j)
        maxArea = max(maxArea, area)
return maxArea

dfs(grid, i, j):
    if out of bounds or grid[i][j] != 1: return 0
    grid[i][j] = 0   // sink
    return 1 + dfs(i+1,j) + dfs(i-1,j) + dfs(i,j+1) + dfs(i,j-1)
```

## Java Code

```java
class Solution {
    public int maxAreaOfIsland(int[][] grid) {
        if (grid == null || grid.length == 0) return 0;
        int maxArea = 0;

        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                if (grid[i][j] == 1) {
                    maxArea = Math.max(maxArea, dfs(grid, i, j));
                }
            }
        }
        return maxArea;
    }

    private int dfs(int[][] grid, int i, int j) {
        if (i < 0 || j < 0 || i >= grid.length || j >= grid[0].length || grid[i][j] != 1) {
            return 0;
        }
        grid[i][j] = 0;  // sink
        return 1 + dfs(grid, i + 1, j) + dfs(grid, i - 1, j) +
                   dfs(grid, i, j + 1) + dfs(grid, i, j - 1);
    }
}
```

## Line-by-line

- Outer loop scans every cell. A '1' starts a new island.
- `dfs` returns the area: 1 (current cell) + areas of all 4 neighbors.
- Sinking (`grid[i][j] = 0`) prevents re-counting.
- `maxArea` tracks the largest island found.

## Complexity

- Time: O(m × n) — visit every cell once.
- Space: O(m × n) worst case (recursion stack). O(1) extra if modifying in place.

## Common Mistakes

- **Not sinking cells.** Re-counting or infinite loop.
- **Returning 0 for no islands.** If the grid has no 1s, `maxArea` stays 0. Correct.
- **Stack overflow on large grids.** Use iterative DFS or BFS for large inputs.
- **Confusing with Number of Islands (#200).** Same pattern, but return the max area instead of the count.

## How to Explain (interview)

**Opening:** Max Area of Island finds the largest connected group of 1s. DFS flood fill: when you find a 1, recursively count all connected 1s (sinking as you go). Track the max area. O(m×n) time, O(m×n) space for recursion (O(1) if modifying in place).

**The basic flow:**
```java
int dfs(grid, i, j) {
    if (out of bounds or grid[i][j] != 1) return 0;
    grid[i][j] = 0;  // sink
    return 1 + dfs(i+1,j) + dfs(i-1,j) + dfs(i,j+1) + dfs(i,j-1);
}
```

**The part that trips everyone up:** sinking (`grid[i][j] = 0`) prevents re-counting. The area is `1 + sum of neighbor areas`. Return 0 for out-of-bounds or water.

**The mistakes to remember:**
- Not sinking (re-counting / infinite loop)
- Stack overflow on large grids
- Confusing with Number of Islands (count vs area)
- Off-by-one in bounds checks
