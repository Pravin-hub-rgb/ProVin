# 18.7 Surrounded Regions

**Tier 2 problem.** (LeetCode #130)

**Problem:** Given a 2D board of 'X' and 'O', capture all 'O's that are surrounded by 'X' (flip them to 'X'). Border 'O's and their connected 'O's are not captured. (LeetCode #130)

**Link:** https://leetcode.com/problems/surrounded-regions/

---

## Which Technique, and Why?

"Capture surrounded regions" → **DFS/BFS from border 'O's**. Instead of finding surrounded regions directly, find all 'O's connected to the border (they're safe). Mark them (e.g., 'T'). Then flip all remaining 'O's to 'X' and all 'T's back to 'O'. O(m × n) time, O(m × n) space (recursion) or O(1) if modifying in place.

**Signal in the problem:** "surrounded regions" / "capture" / "border" → reverse the problem: mark safe 'O's from the border, then flip the rest.

## Approach

1. Mark all 'O's connected to the border as safe (e.g., 'T') using DFS/BFS from border 'O's.
2. Flip all remaining 'O's to 'X' (they're surrounded).
3. Flip all 'T's back to 'O' (safe regions).

## Pseudocode

```
// Step 1: mark border-connected 'O's as 'T'
for each border cell:
    if grid[i][j] == 'O': dfs(i, j)  // mark 'O' -> 'T'
// Step 2: flip remaining 'O' to 'X'
for each cell:
    if grid[i][j] == 'O': grid[i][j] = 'X'
// Step 3: flip 'T' back to 'O'
for each cell:
    if grid[i][j] == 'T': grid[i][j] = 'O'
```

## Java Code

```java
class Solution {
    public void solve(char[][] board) {
        if (board == null || board.length == 0) return;
        int m = board.length, n = board[0].length;

        // Step 1: mark border-connected 'O's
        for (int i = 0; i < m; i++) {
            if (board[i][0] == 'O') dfs(board, i, 0);
            if (board[i][n - 1] == 'O') dfs(board, i, n - 1);
        }
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O') dfs(board, 0, j);
            if (board[m - 1][j] == 'O') dfs(board, m - 1, j);
        }

        // Step 2: flip remaining 'O' to 'X'
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') board[i][j] = 'X';
            }
        }

        // Step 3: flip 'T' back to 'O'
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'T') board[i][j] = 'O';
            }
        }
    }

    private void dfs(char[][] board, int i, int j) {
        if (i < 0 || j < 0 || i >= board.length || j >= board[0].length || board[i][j] != 'O') return;
        board[i][j] = 'T';
        dfs(board, i + 1, j);
        dfs(board, i - 1, j);
        dfs(board, i, j + 1);
        dfs(board, i, j - 1);
    }
}
```

## Line-by-line

- Step 1: DFS from every 'O' on the border, marking them 'T' (safe).
- Step 2: every remaining 'O' is surrounded → flip to 'X'.
- Step 3: flip 'T' back to 'O'.

## Complexity

- Time: O(m × n) — visit every cell.
- Space: O(m × n) worst case (recursion stack). O(1) if modifying in place (no separate visited array).

## Common Mistakes

- **Finding surrounded regions directly.** This is hard (need to check if a region touches the border). The reverse approach (mark safe from border) is much simpler.
- **Not marking border 'O's.** If you skip the border, safe regions get captured.
- **Modifying during the flip step.** Don't flip 'O' to 'X' before marking safe 'O's as 'T' — you'd lose the distinction.
- **Stack overflow on large boards.** Use iterative DFS or BFS for large inputs.
