**Tier 2 problem.** (LeetCode #785)

**Problem:** Given an undirected graph, determine if it is bipartite (can be colored with 2 colors such that no two adjacent nodes have the same color). (LeetCode #785)

**Link:** https://leetcode.com/problems/is-graph-bipartite/

---

## Which Technique, and Why?

"Bipartite check" → **BFS/DFS with 2-coloring**. Color a node, then color all neighbors the opposite color. If you find a neighbor with the same color → not bipartite. O(V + E) time, O(V) space.

**Signal in the problem:** "bipartite" / "2-coloring" / "divide into two sets" → BFS/DFS coloring.

## Approach

BFS (or DFS): for each unvisited node, color it 0, then BFS: for each neighbor, if unvisited, color it `1 - currentColor`; if visited, check it has the opposite color. If same color → not bipartite.

## Pseudocode

```
color = array of -1 (unvisited)
for each node:
    if color[node] == -1:
        color[node] = 0
        queue = [node]
        while queue not empty:
            u = queue.poll()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    queue.offer(v)
                elif color[v] == color[u]:
                    return false
return true
```

## Java Code

```java
class Solution {
    public boolean isBipartite(int[][] graph) {
        int n = graph.length;
        int[] color = new int[n];
        Arrays.fill(color, -1); // -1 = unvisited

        for (int i = 0; i < n; i++) {
            if (color[i] == -1) {
                color[i] = 0;
                Queue<Integer> q = new ArrayDeque<>();
                q.offer(i);
                while (!q.isEmpty()) {
                    int u = q.poll();
                    for (int v : graph[u]) {
                        if (color[v] == -1) {
                            color[v] = 1 - color[u];
                            q.offer(v);
                        } else if (color[v] == color[u]) {
                            return false;
                        }
                    }
                }
            }
        }
        return true;
    }
}
```

## Line-by-line

- `color` array: -1 = unvisited, 0/1 = colors.
- For each unvisited node: color it 0, BFS.
- For each neighbor: if unvisited, color opposite and enqueue. If visited, check opposite color.
- `color[v] == color[u]` → same color adjacent → not bipartite → return false.

## Complexity

- Time: O(V + E) — visit every node and edge.
- Space: O(V) — color array + queue.

## Common Mistakes

- **Not handling disconnected components.** The graph may be disconnected. Loop over all nodes to start BFS from each unvisited one.
- **Using DFS without cycle handling.** DFS works but needs a "visiting" state to detect odd-length cycles. BFS with coloring is simpler.
- **Wrong color assignment.** `color[v] = 1 - color[u]` (0→1, 1→0). Using `color[v] = color[u] + 1` gives 0,1,2,... (wrong).
- **Confusing with "is it a tree."** A tree is always bipartite. This problem is for general graphs.

## How to Explain (interview)

**Opening:** Is Graph Bipartite checks if a graph can be 2-colored. BFS: color a node, color all neighbors the opposite color. If you find an adjacent node with the same color → not bipartite. O(V+E) time, O(V) space. Handle disconnected components by looping over all nodes.

**The basic flow:**
```java
int[] color = new int[n]; Arrays.fill(color, -1);
for (int i = 0; i < n; i++) {
    if (color[i] == -1) {
        color[i] = 0;
        Queue<Integer> q = new ArrayDeque<>(); q.offer(i);
        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : graph[u]) {
                if (color[v] == -1) { color[v] = 1 - color[u]; q.offer(v); }
                else if (color[v] == color[u]) return false;
            }
        }
    }
}
return true;
```

**The part that trips everyone up:** handle **disconnected components** (loop over all nodes). Also, an odd-length cycle makes a graph non-bipartite — the coloring naturally detects this.

**The mistakes to remember:**
- Not handling disconnected components
- Wrong color assignment (1 - color, not color + 1)
- Confusing with tree (trees are always bipartite)
- Using DFS without proper cycle handling (BFS is simpler)
