**Tier 2 problem.** (LeetCode #994)

**Problem:** Given a grid with 0 (empty), 1 (fresh orange), 2 (rotten orange), find the minimum time until no fresh orange remains (rot spreads to 4-directional neighbors each minute). Return -1 if impossible. (LeetCode #994)

**Link:** https://leetcode.com/problems/rotting-oranges/

---

## Which Technique, and Why?

"Minimum time for rot to spread" → **BFS (multi-source)**. Start with all rotten oranges in the queue. BFS level by level (each level = one minute). When a fresh orange is reached, mark it rotten and enqueue. Count levels. If any fresh remains → -1. O(m × n) time, O(m × n) space.

**Signal in the problem:** "minimum time" / "rotting spreads" / "minutes" → BFS (shortest path in unweighted grid).

## Approach

Multi-source BFS. Enqueue all initially rotten oranges. BFS level by level. For each level (minute), process all current rotten, rot their fresh neighbors. Count minutes. After BFS, if any fresh remains → -1.

## Pseudocode

```
queue = all rotten oranges (with their positions)
minutes = 0
while queue not empty:
    size = queue.size()
    changed = false
    for i from 0 to size-1:
        (r, c) = queue.poll()
        for each neighbor (4-dir):
            if in bounds and grid[nr][nc] == 1:
                grid[nr][nc] = 2
                queue.offer((nr, nc))
                changed = true
    if changed: minutes++
return (any fresh remaining) ? -1 : minutes
```

## Java Code

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Queue<int[]> q = new ArrayDeque<>();
        int fresh = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) q.offer(new int[]{i, j});
                else if (grid[i][j] == 1) fresh++;
            }
        }

        if (fresh == 0) return 0;
        int minutes = 0;
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

        while (!q.isEmpty() && fresh > 0) {
            int size = q.size();
            for (int i = 0; i < size; i++) {
                int[] cur = q.poll();
                for (int[] d : dirs) {
                    int nr = cur[0] + d[0], nc = cur[1] + d[1];
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1) {
                        grid[nr][nc] = 2;
                        fresh--;
                        q.offer(new int[]{nr, nc});
                    }
                }
            }
            minutes++;
        }
        return fresh == 0 ? minutes : -1;
    }
}
```

## Line-by-line

- Enqueue all initially rotten oranges. Count fresh.
- If no fresh → return 0.
- BFS level by level (each level = one minute). Process all current rotten, rot fresh neighbors.
- `fresh--` on each rot. `minutes++` per level.
- After BFS: if `fresh == 0` → return minutes; else → -1 (some unreachable).

## Complexity

- Time: O(m × n) — visit every cell once.
- Space: O(m × n) — queue holds up to m×n cells.

## Common Mistakes

- **Not checking if all fresh are rotted.** Return -1 if `fresh > 0` after BFS.
- **Counting minutes incorrectly.** Each BFS level = one minute. Don't increment per cell.
- **Not handling "no fresh" case.** If `fresh == 0` initially, return 0 (not -1).
- **Modifying the grid.** This problem allows it. If not, use a visited array.
