**Tier 2 problem.** (LeetCode #542)

**Problem:** Given a binary matrix, find the distance of the nearest 0 for each cell. (LeetCode #542)

**Link:** https://leetcode.com/problems/01-matrix/

---

## Which Technique, and Why?

"Nearest 0 for each cell" → **Multi-source BFS**. Start with all 0s in the queue (distance 0). BFS level by level: each level increases distance by 1. O(m × n) time, O(m × n) space. (DFS would be O((mn)²) in the worst case.)

**Signal in the problem:** "nearest 0" / "distance to nearest" → multi-source BFS (start from all 0s).

## Approach

Multi-source BFS. Enqueue all cells with value 0 (distance 0). BFS: for each cell, its unvisited neighbors get distance = current + 1. Mark visited when enqueuing.

## Pseudocode

```
queue = all cells with value 0
dist = copy of matrix (0s stay 0, 1s become infinity)
while queue not empty:
    (r, c) = queue.poll()
    for each neighbor (4-dir):
        if in bounds and dist[nr][nc] == infinity (unvisited):
            dist[nr][nc] = dist[r][c] + 1
            queue.offer((nr, nc))
return dist
```

## Java Code

```java
class Solution {
    public int[][] updateMatrix(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int[][] dist = new int[m][n];
        Queue<int[]> q = new ArrayDeque<>();

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (mat[i][j] == 0) {
                    dist[i][j] = 0;
                    q.offer(new int[]{i, j});
                } else {
                    dist[i][j] = Integer.MAX_VALUE;
                }
            }
        }

        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            for (int[] d : dirs) {
                int nr = cur[0] + d[0], nc = cur[1] + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && dist[nr][nc] == Integer.MAX_VALUE) {
                    dist[nr][nc] = dist[cur[0]][cur[1]] + 1;
                    q.offer(new int[]{nr, nc});
                }
            }
        }
        return dist;
    }
}
```

## Line-by-line

- `dist[i][j] = 0` for 0s (they're their own nearest 0). `Integer.MAX_VALUE` for 1s (unvisited).
- Enqueue all 0s (multi-source BFS).
- BFS: for each cell, check 4 neighbors. If unvisited (MAX_VALUE), set distance = current + 1, enqueue.
- BFS guarantees the first time a cell is reached is via the shortest path.

## Complexity

- Time: O(m × n) — visit every cell once.
- Space: O(m × n) — dist array + queue.

## Common Mistakes

- **Single-source BFS from each 1.** O((mn)²) — too slow. Multi-source BFS from all 0s is O(mn).
- **Using DFS.** DFS doesn't give shortest path. BFS is needed.
- **Not marking visited when enqueuing.** Mark `dist[nr][nc]` when enqueuing, not when processing. Otherwise, the same cell gets enqueued multiple times.
- **Modifying the input.** This problem allows it (you can use `mat` as the dist array). If not, use a separate array.

**The part that trips everyone up:** multi-source BFS (start from ALL 0s, not one). Also, mark visited when **enqueuing** (not when processing) to avoid duplicates.

**The mistakes to remember:**
- Single-source BFS (O((mn)²) — too slow)
- Using DFS (doesn't give shortest path)
- Marking visited when processing (duplicates in queue)
