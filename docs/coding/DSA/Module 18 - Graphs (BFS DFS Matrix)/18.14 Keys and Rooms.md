**Tier 2 problem.** (LeetCode #841)

**Problem:** Given n rooms (0 to n-1) where room 0 is unlocked and each room contains keys to other rooms, determine if you can visit all rooms. (LeetCode #841)

**Link:** https://leetcode.com/problems/keys-and-rooms/

---

## Which Technique, and Why?

"Can you visit all rooms?" → **DFS/BFS** on the graph (rooms are nodes, keys are directed edges). Start from room 0, traverse all reachable rooms. If all n rooms are visited → true. O(V + E) time, O(V) space.

**Signal in the problem:** "keys and rooms" / "can you visit all rooms" / "unlock" → DFS/BFS reachability from room 0.

## Approach

DFS from room 0. Mark visited. For each key in the current room, if the room isn't visited, DFS into it. After traversal, check if all rooms are visited.

## Pseudocode

```
visited = boolean[n]
dfs(0)
for i from 0 to n-1:
    if !visited[i]: return false
return true

dfs(room):
    visited[room] = true
    for key in rooms[room]:
        if !visited[key]: dfs(key)
```

## Java Code

```java
class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size();
        boolean[] visited = new boolean[n];
        dfs(rooms, 0, visited);

        for (boolean v : visited) {
            if (!v) return false;
        }
        return true;
    }

    private void dfs(List<List<Integer>> rooms, int room, boolean[] visited) {
        visited[room] = true;
        for (int key : rooms.get(room)) {
            if (!visited[key]) dfs(rooms, key, visited);
        }
    }
}
```

## Line-by-line

- `visited` tracks which rooms have been entered.
- DFS from room 0: mark visited, recurse on all keys (if not visited).
- After DFS, check if all rooms are visited.

## Complexity

- Time: O(V + E) where V = n rooms, E = total keys.
- Space: O(V) — visited array + recursion stack.

## Common Mistakes

- **Not starting from room 0.** Room 0 is the only initially unlocked room. Start DFS from 0.
- **Not checking all rooms.** After DFS, verify every room is visited. If any is unvisited → false.
- **Stack overflow on deep graphs.** Use iterative DFS or BFS for large inputs.
- **Infinite loop on cycles.** The `if (!visited[key])` check prevents re-visiting.

## How to Explain (interview)

**Opening:** Keys and Rooms checks if all rooms are reachable from room 0. DFS: start at room 0, mark visited, recurse on all keys. If all rooms visited → true. O(V+E) time, O(V) space.

**The basic flow:**
```java
boolean[] visited = new boolean[n];
dfs(0, visited);
for (boolean v : visited) if (!v) return false;
return true;
```

**The part that trips everyone up:** start from **room 0 only** (it's the only unlocked room). Also, check **all rooms** are visited after DFS (not just count).

**The mistakes to remember:**
- Starting from a room other than 0
- Not checking all rooms visited
- Stack overflow on deep graphs (use iterative)
- Infinite loop without visited check
