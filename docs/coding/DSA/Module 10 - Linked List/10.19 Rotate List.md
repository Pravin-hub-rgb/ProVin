# 10.19 Rotate List

**Tier 2 problem.** (LeetCode #61)

**Problem:** Given a linked list and k, rotate the list to the right by k places. (LeetCode #61)

**Link:** https://leetcode.com/problems/rotate-list/

---

## Which Technique, and Why?

"Rotate list right by k" → **Find the new tail, connect tail to head (make it circular), then break at the new tail.** O(n) time, O(1) space. Handle k > n by `k %= n`.

**Signal in the problem:** "rotate linked list" / "rotate right by k" → find new tail, make circular, break.

## Approach

1. Find length n. If n == 0 or k % n == 0, return head.
2. k = k % n (handle k > n).
3. New tail is at position `n - k - 1` (0-indexed). New head is at `n - k`.
4. Traverse to new tail, save new head, break the link, connect old tail to old head.

## Pseudocode

```
if head == null or head.next == null or k == 0: return head
// find length
n = 1, tail = head
while tail.next != null: tail = tail.next; n++
k = k % n
if k == 0: return head
// find new tail (n - k - 1 steps from head)
newTail = head
for i from 0 to n - k - 2: newTail = newTail.next
newHead = newTail.next
newTail.next = null
tail.next = head
return newHead
```

## Java Code

```java
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) return head;

        // Find length and tail
        int n = 1;
        ListNode tail = head;
        while (tail.next != null) {
            tail = tail.next;
            n++;
        }

        k = k % n;
        if (k == 0) return head;

        // Find new tail (n - k - 1 steps from head)
        ListNode newTail = head;
        for (int i = 0; i < n - k - 1; i++) {
            newTail = newTail.next;
        }
        ListNode newHead = newTail.next;
        newTail.next = null;   // break
        tail.next = head;       // connect old tail to old head
        return newHead;
    }
}
```

## Line-by-line

- Find `n` and `tail` in one pass.
- `k = k % n` — handle k > n (rotating by n is a no-op).
- `if (k == 0) return head` — no rotation needed.
- `newTail` is `n - k - 1` steps from head (the node before the new head).
- `newHead = newTail.next` — the new head.
- `newTail.next = null` — break the list.
- `tail.next = head` — connect old tail to old head (circular, then break).

## Complexity

- Time: O(n) — two passes (find length, find new tail).
- Space: O(1) — only pointers.

## Common Mistakes

- **Not handling k > n.** `k = k % n` is essential. Without it, k = 100 on a 3-node list would crash (loop out of bounds).
- **Off-by-one in new tail position.** New tail is at `n - k - 1` (0-indexed). New head is at `n - k`. The loop runs `n - k - 1` times from head.
- **Not handling k % n == 0.** If k is a multiple of n, no rotation → return head.
- **Single node / empty list.** Return head immediately.

## How to Explain (interview)

**Opening:** Rotate List rotates right by k. Find length n, compute k % n. Find the new tail (n-k-1 steps from head), break the list, connect old tail to old head. O(n) time, O(1) space.

**The basic flow:**
```java
int n = 1; ListNode tail = head;
while (tail.next != null) { tail = tail.next; n++; }
k = k % n;
if (k == 0) return head;
ListNode newTail = head;
for (int i = 0; i < n - k - 1; i++) newTail = newTail.next;
ListNode newHead = newTail.next;
newTail.next = null;
tail.next = head;
return newHead;
```

**The part that trips everyone up:** `k = k % n` (handle k > n). Also, new tail is at `n - k - 1` (not `n - k`). And break before connecting (order matters).

**The mistakes to remember:**
- Not handling k > n (crash or wrong result)
- Off-by-one in new tail position
- Not handling k % n == 0 (no-op)
- Not handling empty/single node list
