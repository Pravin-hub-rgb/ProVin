# 10.11 Intersection of Two Linked Lists

**Problem:** Given two singly linked lists, find the node where they intersect (merge). Return null if no intersection. (LeetCode #160)

**Link:** https://leetcode.com/problems/intersection-of-two-linked-lists/

---

## Which Technique, and Why?

Find the intersection of two linked lists → **Two pointers with length equalization**. Traverse both lists; when one reaches the end, redirect it to the head of the other. Both pointers traverse the same total length (lenA + lenB), so they meet at the intersection (or both reach null). O(n + m) time, O(1) space.

**Signal in the problem:** "intersection of two linked lists" / "find the merge point" → two pointers with redirect, or hash set (O(n) space).

## Approach

Two pointers `a` and `b` starting at `headA` and `headB`. Advance both by one. When `a` reaches null, redirect to `headB`. When `b` reaches null, redirect to `headA`. They'll meet at the intersection (or both become null). The redirect equalizes the path lengths.

## Pseudocode

```
a = headA, b = headB
while a != b:
    a = (a == null) ? headB : a.next
    b = (b == null) ? headA : b.next
return a   // or b — they're equal
```

## Java Code

```java
class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if (headA == null || headB == null) return null;

        ListNode a = headA;
        ListNode b = headB;

        while (a != b) {
            a = (a == null) ? headB : a.next;
            b = (b == null) ? headA : b.next;
        }
        return a;  // null if no intersection
    }
}
```

## Line-by-line

- `a` and `b` start at their respective heads.
- Each step: advance by one. If a pointer reaches null, redirect to the other list's head.
- After redirection, both pointers traverse `lenA + lenB` total nodes.
- They meet at the intersection because both have traveled the same distance.
- If no intersection, both reach null simultaneously → return null.

## Complexity

- Time: O(n + m) — each pointer traverses at most n + m nodes.
- Space: O(1) — two pointers.

## Common Mistakes

- **Modifying the lists.** Don't change next pointers. The redirect is on the local pointer variables, not the list nodes.
- **Not handling null.** If either list is empty, no intersection → return null. Check early.
- **Using a visited set.** Works (O(n) space) but wastes memory. Two pointers is O(1) space.
- **Infinite loop.** The redirect ensures both pointers traverse the same total length, so they always meet (at intersection or null). No infinite loop.

**The mistakes to remember:**
- Modifying the list (changing next pointers) — don't
- Not handling null lists
- Using a visited set (O(n) space, unnecessary)
- Thinking the lists must be the same length (they don't — the redirect handles it)
