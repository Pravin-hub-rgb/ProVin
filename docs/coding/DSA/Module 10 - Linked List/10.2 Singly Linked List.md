# 10.2 Singly Linked List

A singly linked list is a chain of nodes where each node holds a value and a pointer (`next`) to the next node. The last node's `next` is `null`. You can only traverse forward.

---

## The Node

```java
class ListNode {
    int val;
    ListNode next;

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

- `val` holds the data.
- `next` points to the next node (or `null` if last).
- Constructor takes the value; `next` defaults to null.

## Building a List

```java
ListNode head = new ListNode(1);
head.next = new ListNode(2);
head.next.next = new ListNode(3);
// list: 1 -> 2 -> 3 -> null
```

In practice, you'll write helper methods to build/print lists from arrays. The shape above is what matters.

## Traversing

```java
ListNode cur = head;
while (cur != null) {
    System.out.print(cur.val + " -> ");
    cur = cur.next;
}
System.out.println("null");
```

- Start at `head`, follow `next` until `null`.
- This traversal pattern (`cur = cur.next`) is the foundation of all linked list problems.

## Insertion

```java
// Insert at head (O(1))
ListNode newNode = new ListNode(0);
newNode.next = head;
head = newNode;   // list: 0 -> 1 -> 2 -> 3 -> null

// Insert at tail (O(n) — must traverse)
ListNode cur = head;
while (cur.next != null) cur = cur.next;
cur.next = new ListNode(4);  // list: ... -> 3 -> 4 -> null

// Insert after a given node (O(1))
ListNode node = head.next;   // node with value 1
ListNode newNode = new ListNode(99);
newNode.next = node.next;
node.next = newNode;         // list: 1 -> 99 -> 2 -> ...
```

## Deletion

```java
// Delete head (O(1))
head = head.next;

// Delete a node by value (O(n) — must find it)
ListNode cur = head;
while (cur.next != null && cur.next.val != target) {
    cur = cur.next;
}
if (cur.next != null) {
    cur.next = cur.next.next;  // skip the target node
}
```

## Cost (Big-O)

| Operation | Time |
|---|---|
| Access by index | O(n) (no random access) |
| Insert at head | O(1) |
| Insert at tail | O(n) (must traverse) |
| Insert after known node | O(1) |
| Delete head | O(1) |
| Delete by value | O(n) |
| Search | O(n) |

## Common Pitfalls

- **Losing the rest of the list.** When inserting/deleting, save `next` before overwriting. `newNode.next = node.next; node.next = newNode;` (not the reverse).
- **Null pointer.** `cur.next` when `cur` is null → NPE. Always check `cur != null` before accessing `cur.next`.
- **Modifying head without updating.** If you delete the head, update `head = head.next`. Forgetting this loses the new head.
- **Off-by-one in traversal.** `while (cur != null)` visits all nodes. `while (cur.next != null)` stops at the last node (useful for insertion at tail).

## A Small Program: Build and Print a List

```java
public class BuildList {
    static ListNode build(int[] arr) {
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;
        for (int x : arr) {
            cur.next = new ListNode(x);
            cur = cur.next;
        }
        return dummy.next;
    }

    static void print(ListNode head) {
        ListNode cur = head;
        while (cur != null) {
            System.out.print(cur.val + " -> ");
            cur = cur.next;
        }
        System.out.println("null");
    }

    public static void main(String[] args) {
        ListNode head = build(new int[]{1, 2, 3, 4, 5});
        print(head);  // 1 -> 2 -> 3 -> 4 -> 5 -> null
    }
}
```

**Note:** The `dummy` node technique (a sentinel node before the head) simplifies insertion logic — you never have to special-case the head.

## In Your Own Words

1. What is the shape of a singly linked list node?

<details>
<summary>Show Answer</summary>

**Sample Answer:** A node has a value field (`val`) and a `next` pointer to the next node. The last node's `next` is `null`. Shape: `class ListNode { int val; ListNode next; ListNode(int val) { this.val = val; this.next = null; } }`. This is the foundation of all linked list problems.

</details>

2. Why is insertion at the head O(1) but insertion at the tail O(n)?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Insertion at head: create a new node, point its `next` to the current head, update head → O(1), no traversal needed. Insertion at tail: you must traverse from head to find the last node (O(n)), then attach the new node. To make tail insertion O(1), maintain a `tail` pointer (doubly linked list or a separate tail reference).

</details>

3. What is the dummy node technique, and why is it useful?

<details>
<summary>Show Answer</summary>

**Sample Answer:** A dummy (sentinel) node is a placeholder node placed before the head. It simplifies insertion/deletion logic because you never special-case the head — the head is always `dummy.next`. After building, return `dummy.next`. This eliminates null checks for empty lists and head modifications.

</details>
