**Problem:** Given two non-empty linked lists representing two non-negative integers (digits stored in reverse order), add them and return the sum as a linked list. (LeetCode #2)

**Link:** https://leetcode.com/problems/add-two-numbers/

---

## Which Technique, and Why?

Add two numbers stored as linked lists → **digit-by-digit addition with carry**, walking both lists simultaneously. No data structure needed — just pointer manipulation and a carry variable. O(max(m,n)) time, O(max(m,n)) space (for the result list).

**Signal in the problem:** "add two numbers represented as linked lists" / "digits in reverse order" → walk both, add digit by digit, track carry, build result list.

## Approach

Walk both lists simultaneously. At each step: sum = digit1 + digit2 + carry. Create a new node with `sum % 10`. Carry = `sum / 10`. Continue until both lists are exhausted and carry is 0.

## Pseudocode

```
dummy = new ListNode(0)
current = dummy
carry = 0
while l1 != null or l2 != null or carry > 0:
    val1 = (l1 != null) ? l1.val : 0
    val2 = (l2 != null) ? l2.val : 0
    sum = val1 + val2 + carry
    current.next = new ListNode(sum % 10)
    current = current.next
    carry = sum / 10
    if l1 != null: l1 = l1.next
    if l2 != null: l2 = l2.next
return dummy.next
```

## Java Code

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;
        int carry = 0;

        while (l1 != null || l2 != null || carry > 0) {
            int val1 = (l1 != null) ? l1.val : 0;
            int val2 = (l2 != null) ? l2.val : 0;
            int sum = val1 + val2 + carry;

            current.next = new ListNode(sum % 10);
            current = current.next;
            carry = sum / 10;

            if (l1 != null) l1 = l1.next;
            if (l2 != null) l2 = l2.next;
        }

        return dummy.next;
    }
}
```

## Line-by-line

- `dummy` — sentinel before the result head. Simplifies the first-node case.
- `val1`/`val2` — digit from each list, or 0 if that list is exhausted.
- `sum = val1 + val2 + carry` — total at this position.
- `sum % 10` — the digit to store (0–9).
- `carry = sum / 10` — carry to next position (0 or 1, since max sum is 9+9+1=19).
- Advance `l1`/`l2` if not null.
- Loop condition includes `carry > 0` — handle final carry (e.g., 9+9=18 → result has an extra 1).
- Return `dummy.next` — the actual head.

## Complexity

- Time: O(max(m, n)) — single pass through both lists.
- Space: O(max(m, n)) — for the result list (new nodes).

## Common Mistakes

- **Forgetting the final carry.** If the last addition produces a carry (e.g., 5+5=10), you need an extra node with value 1. The `carry > 0` condition handles this.
- **Not handling different lengths.** The `l1 != null ? l1.val : 0` ternary handles lists of different lengths.
- **Modifying the input lists.** If you advance `l1`/`l2` (as above), you're modifying the caller's lists. Usually fine for LeetCode, but if the problem says "don't modify," copy first.
- **Returning `current` instead of `dummy.next`.** `current` ends at the tail; `dummy.next` is the head.
- **Not using a dummy.** Without it, the first node needs special-casing.

## How to Explain (interview)

**Opening:** Add Two Numbers adds two numbers stored as linked lists (digits in reverse order). Walk both lists simultaneously: add digits + carry, store `sum % 10`, carry `sum / 10`. Use a dummy node for the result. Handle different lengths (treat missing as 0) and final carry. O(n) time, O(n) space.

**The basic flow:**
```java
ListNode dummy = new ListNode(0), cur = dummy;
int carry = 0;
while (l1 != null || l2 != null || carry > 0) {
    int sum = carry;
    if (l1 != null) { sum += l1.val; l1 = l1.next; }
    if (l2 != null) { sum += l2.val; l2 = l2.next; }
    cur.next = new ListNode(sum % 10);
    cur = cur.next;
    carry = sum / 10;
}
return dummy.next;
```

**The part that trips everyone up:** the loop condition includes `carry > 0` (for the final carry). Also, digits are in **reverse order**, so you add from the head — no need to reverse.

**The mistakes to remember:**
- Forgetting the final carry (result missing a digit)
- Not handling different lengths
- Returning `current` instead of `dummy.next`
- Modifying input lists (if problem forbids)
