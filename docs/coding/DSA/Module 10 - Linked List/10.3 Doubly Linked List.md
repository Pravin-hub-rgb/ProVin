A doubly linked list is a chain of nodes where each node holds a value and two pointers: `next` (forward) and `prev` (backward). You can traverse in both directions. Insertion and deletion at a known position are O(1) (no need to find the previous node).

---

## The Node

```java
class DoublyNode {
    int val;
    DoublyNode prev;
    DoublyNode next;

    DoublyNode(int val) {
        this.val = val;
        this.prev = null;
        this.next = null;
    }
}
```

- `val` holds the data.
- `prev` points to the previous node (or `null` if head).
- `next` points to the next node (or `null` if tail).

## Building a List

```java
DoublyNode head = new DoublyNode(1);
DoublyNode second = new DoublyNode(2);
DoublyNode third = new DoublyNode(3);

head.next = second;
second.prev = head;
second.next = third;
third.prev = second;
// list: null <- 1 <-> 2 <-> 3 -> null
```

## Traversing

```java
// Forward
DoublyNode cur = head;
while (cur != null) {
    System.out.print(cur.val + " <-> ");
    cur = cur.next;
}
System.out.println("null");

// Backward (from tail)
cur = tail;
while (cur != null) {
    System.out.print(cur.val + " <-> ");
    cur = cur.prev;
}
System.out.println("null");
```

## Insertion (O(1) at a known position)

```java
// Insert after a given node
void insertAfter(DoublyNode node, int val) {
    DoublyNode newNode = new DoublyNode(val);
    newNode.next = node.next;
    newNode.prev = node;
    if (node.next != null) {
        node.next.prev = newNode;
    }
    node.next = newNode;
}

// Insert at head (O(1))
DoublyNode insertHead(DoublyNode head, int val) {
    DoublyNode newNode = new DoublyNode(val);
    newNode.next = head;
    if (head != null) head.prev = newNode;
    return newNode;
}
```

**The key:** always update **both** `prev` and `next` pointers. Four pointer updates for an insertion in the middle.

## Deletion (O(1) at a known position)

```java
void deleteNode(DoublyNode node) {
    if (node.prev != null) {
        node.prev.next = node.next;
    }
    if (node.next != null) {
        node.next.prev = node.prev;
    }
    // node is now detached; GC will clean it up
}
```

## Cost (Big-O)

| Operation | Time |
|---|---|
| Access by index | O(n) |
| Insert at head | O(1) |
| Insert at tail (with tail pointer) | O(1) |
| Insert after known node | O(1) |
| Delete known node | O(1) |
| Search | O(n) |
| Traverse forward/backward | O(n) |

## Singly vs Doubly

| Feature | Singly | Doubly |
|---|---|---|
| Pointers per node | 1 (next) | 2 (prev, next) |
| Memory per node | less | more (extra pointer) |
| Traversal | forward only | both directions |
| Delete a known node | O(n) (need to find prev) | O(1) (prev is stored) |
| Insert after known node | O(1) | O(1) |
| Reverse | O(n) with 3 pointers | O(n) (just swap prev/next) |

**Use doubly when:** you need backward traversal or O(1) deletion at a known position. **Use singly when:** memory is tight or you only traverse forward. In DSA interviews, singly linked lists are more common.

## Common Pitfalls

- **Forgetting to update both pointers.** Insertion/deletion in a doubly list requires updating `prev` AND `next`. Missing one breaks the chain.
- **Null checks.** When inserting at head, `head.prev` is null — don't dereference it. When deleting the last node, `node.next` is null — don't dereference it.
- **Java's built-in LinkedList.** `java.util.LinkedList` is a doubly linked list. In DSA interviews, you usually build your own `ListNode` (singly) — interviews want to see pointer manipulation.
- **Memory overhead.** Doubly lists use ~2x the pointer memory. For large lists, this matters.

## In Your Own Words

1. What is the advantage of a doubly linked list over a singly linked list?

<details>
<summary>Show Answer</summary>

**Sample Answer:** O(1) deletion at a known node (prev is stored, no traversal needed) and backward traversal. In a singly list, deleting a known node requires finding its predecessor (O(n)). The cost: extra memory per node (one more pointer) and more complex insert/delete logic (must update both prev and next).

</details>

2. How many pointer updates are needed to insert a node in the middle of a doubly linked list?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Four: (1) newNode.next = node.next, (2) newNode.prev = node, (3) node.next.prev = newNode (if node.next != null), (4) node.next = newNode. All four are needed — missing any breaks the chain. If inserting at the tail (node.next == null), skip step 3.

</details>

3. When would you choose a singly linked list over a doubly linked list?

<details>
<summary>Show Answer</summary>

**Sample Answer:** When memory is tight (singly uses half the pointer memory), when you only traverse forward, or when the problem specifically asks for singly (most DSA interview problems). Singly lists are simpler to implement and debug. Use doubly when you need O(1) deletion at a known position or backward traversal.

</details>
