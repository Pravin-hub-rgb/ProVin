**Problem:** Given a node in a singly linked list (not the head), delete it in O(1) time without access to the head. (LeetCode #237)

**Link:** https://leetcode.com/problems/delete-node-in-a-linked-list/

---

## Which Technique, and Why?

You can't delete a node in a singly linked list in O(1) normally (you need the predecessor). But the trick: **copy the next node's value into the current node, then delete the next node.** This effectively removes the current node's value in O(1) without needing the head or predecessor.

**Signal in the problem:** "delete node in O(1)" + "no access to head" + "given the node to delete" → copy-next-value trick.

## Approach

Copy `node.next.val` into `node.val`. Then set `node.next = node.next.next`. The node's value is now replaced; the original node is "deleted" (its value is gone). The next node is removed from the list.

## Pseudocode

```
node.val = node.next.val
node.next = node.next.next
```

## Java Code

```java
class Solution {
    public void deleteNode(ListNode node) {
        node.val = node.next.val;
        node.next = node.next.next;
    }
}
```

## Line-by-line

- `node.val = node.next.val` — copy the next node's value into the current node.
- `node.next = node.next.next` — skip the next node (remove it from the list).
- The current node now holds the next node's value and points to the node after that. The original value is gone, and the next node is unlinked.

## Complexity

- Time: O(1) — two pointer operations.
- Space: O(1).

## Common Mistakes

- **Deleting the tail node.** If `node.next == null`, this approach fails (no next node to copy from). The problem guarantees the node is not the tail.
- **Trying to find the predecessor.** You don't have access to the head, so you can't traverse. The copy trick is the only O(1) way.
- **Not handling the case where node is null.** Problem guarantees a valid node.
- **Confusing with "Remove Nth From End" (#19).** That problem gives you the head and n; this one gives you the node directly. Different approach.

## How to Explain (interview)

**Opening:** Delete Node in a Linked List deletes a node in O(1) without access to the head. The trick: copy the next node's value into the current node, then skip the next node (`node.next = node.next.next`). This effectively removes the current node's value. O(1) time, O(1) space. Only works if the node is not the tail.

**The basic flow:**
```java
node.val = node.next.val;
node.next = node.next.next;
```

**The part that trips everyone up:** this only works if the node is **not the tail** (needs a next node to copy from). The problem guarantees this. Also, you're not actually deleting the node — you're overwriting its value and unlinking the next node.

**The mistakes to remember:**
- Trying to find the predecessor (impossible without head)
- Deleting the tail (no next node to copy from — problem guarantees non-tail)
- Not understanding that you're copying values, not moving nodes
