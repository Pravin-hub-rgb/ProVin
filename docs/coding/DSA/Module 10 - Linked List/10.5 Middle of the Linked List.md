# 10.5 Middle of the Linked List

**Problem:** Given the head of a linked list, return the middle node. If two middles, return the second. (LeetCode #876)

**Link:** https://leetcode.com/problems/middle-of-the-linked-list/

---

## Which Technique, and Why?

Find the middle of a linked list → **Slow & Fast pointers**. Slow moves 1 step, fast moves 2 steps. When fast reaches the end, slow is at the middle. O(n) time, O(1) space. No counting needed.

Why not count first? Counting works (O(n) time, O(1) space) but requires two passes. Slow/fast does it in one pass.

**Signal in the problem:** "middle of linked list" / "find the middle node" → slow & fast pointers (1 step vs 2 steps).

## Approach

`slow = head`, `fast = head`. While `fast != null && fast.next != null`: `slow = slow.next`, `fast = fast.next.next`. Return `slow`.

## Pseudocode

```
slow = head, fast = head
while fast != null and fast.next != null:
    slow = slow.next
    fast = fast.next.next
return slow
```

## Java Code

```java
class Solution {
    public ListNode middleNode(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }
}
```

## Line-by-line

- `slow` and `fast` start at head.
- `fast` moves 2 steps per iteration, `slow` moves 1.
- When `fast` reaches the end (null or last node), `slow` is at the middle.
- For even length (2 middles), `fast` ends at null → `slow` is the second middle. For odd length, `fast` ends at the last node → `slow` is the exact middle.

## Complexity

- Time: O(n) — single pass.
- Space: O(1) — two pointers.

## Common Mistakes

- **Loop condition `fast.next != null` only.** If the list has odd length, `fast` ends at the last node (not null). You need `fast != null && fast.next != null` to handle both cases.
- **Returning the first middle for even length.** The problem says return the second middle. The slow/fast approach naturally returns the second middle. If you need the first, use a different technique (count first).
- **Null head.** If head is null, the loop doesn't execute, returns null. Correct.
- **Single node.** `fast.next == null` → loop doesn't execute, returns head. Correct.

## How to Explain (interview)

**Opening:** Middle of Linked List finds the middle node using slow & fast pointers. Slow moves 1 step, fast moves 2. When fast reaches the end, slow is at the middle. For even length, returns the second middle. O(n) time, O(1) space.

**The basic flow:**
```java
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
}
return slow;
```

**The part that trips everyone up:** the loop condition must be `fast != null && fast.next != null` (both). For even length, fast ends at null → slow is the second middle. For odd, fast ends at the last node.

**The mistakes to remember:**
- Loop condition missing `fast != null` (NPE on odd-length lists)
- Returning first middle instead of second (problem spec)
- Not handling empty list (returns null — correct)
