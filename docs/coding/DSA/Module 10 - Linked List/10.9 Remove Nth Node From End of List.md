# 10.9 Remove Nth Node From End of List

**Problem:** Given a linked list, remove the nth node from the end and return the head. (LeetCode #19)

**Link:** https://leetcode.com/problems/remove-nth-node-from-end-of-list/

---

## Which Technique, and Why?

Remove the nth node from the end → **Two pointers with a gap of n** (fast & slow). Advance fast by n first, then move both together. When fast reaches the end, slow is at the node before the target. O(n) time, O(1) space.

Why not count first? Counting works (O(n) time, two passes) but two pointers does it in one pass.

**Signal in the problem:** "remove nth from end" / "nth from the end" → fast & slow with a gap of n.

## Approach

Use a dummy node (handles edge case of removing head). Advance `fast` by n+1 (so `slow` ends up one before the target). Then move both until `fast` is null. Remove `slow.next`.

## Pseudocode

```
dummy = new ListNode(0, head)
fast = dummy, slow = dummy
for i from 0 to n: fast = fast.next   // advance fast by n+1
while fast != null:
    fast = fast.next
    slow = slow.next
slow.next = slow.next.next   // remove target
return dummy.next
```

## Java Code

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode fast = dummy;
        ListNode slow = dummy;

        // Advance fast by n+1
        for (int i = 0; i <= n; i++) {
            fast = fast.next;
        }

        // Move both until fast reaches end
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
        }

        // Remove the target node
        slow.next = slow.next.next;
        return dummy.next;
    }
}
```

## Line-by-line

- `dummy` — sentinel before head. Handles the edge case of removing the head (n = length).
- Advance `fast` by `n + 1` (so `slow` ends up one node before the target).
- Move both `fast` and `slow` until `fast` is null. `slow` is now at the node before the target.
- `slow.next = slow.next.next` — skip the target node.
- Return `dummy.next` (the new head, possibly changed).

## Complexity

- Time: O(n) — single pass (fast traverses n, slow traverses n-n).
- Space: O(1) — two pointers + dummy.

## Common Mistakes

- **Off-by-one in the gap.** Advance `fast` by `n + 1`, not `n`. If you advance by `n`, `slow` lands on the target itself, and you can't remove it (you need the predecessor). The dummy + n+1 trick puts `slow` one before the target.
- **Not using a dummy node.** Without it, removing the head (n = length) requires special-casing. The dummy eliminates this.
- **Null pointer when n > length.** Problem guarantees n ≤ length, but defensive code checks `fast != null` in the first loop.
- **Returning `head` instead of `dummy.next`.** If the head was removed, `head` is stale. Return `dummy.next`.

## How to Explain (interview)

**Opening:** Remove Nth From End removes the nth node from the end in one pass. Fast & slow pointers with a gap of n: advance fast by n+1, then move both together. When fast reaches null, slow is one node before the target. Use a dummy node to handle the edge case of removing the head. O(n) time, O(1) space.

**The basic flow:**
```java
ListNode dummy = new ListNode(0); dummy.next = head;
ListNode fast = dummy, slow = dummy;
for (int i = 0; i <= n; i++) fast = fast.next;
while (fast != null) { fast = fast.next; slow = slow.next; }

```

**The mistakes to remember:**
- Advancing by n instead of n+1 (slow lands on target, can't remove)
- Not using dummy (edge case: removing head)
- Returning `head` instead of `dummy.next`
- Null pointer if n > length (problem guarantees n ≤ length)
