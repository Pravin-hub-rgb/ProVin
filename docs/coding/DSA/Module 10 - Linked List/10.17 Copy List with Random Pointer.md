**Tier 2 problem.** (LeetCode #138)

**Problem:** Given a linked list where each node has `next` and `random` pointers, create a deep copy. (LeetCode #138)

**Link:** https://leetcode.com/problems/copy-list-with-random-pointer/

---

## Which Technique, and Why?

"Deep copy a linked list with random pointers" → **HashMap (original → copy)** or **interleaving trick** (O(1) space). The HashMap approach is simpler: create a copy of each node, store the mapping, then wire up next and random. O(n) time, O(n) space.

**Signal in the problem:** "copy list with random pointer" / "deep copy" → HashMap (original → copy) or interleaving (O(1) space).

## Approach (HashMap — simplest)

1. First pass: create a copy of each node, store `map[original] = copy`.
2. Second pass: wire up `copy.next = map[original.next]` and `copy.random = map[original.random]`.

## Pseudocode

```
map = empty (original -> copy)
cur = head
while cur != null:
    map[cur] = new Node(cur.val)
    cur = cur.next
cur = head
while cur != null:
    map[cur].next = map[cur.next]
    map[cur].random = map[cur.random]
    cur = cur.next
return map[head]
```

## Java Code

```java
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;

        Map<Node, Node> map = new HashMap<>();
        Node cur = head;

        // Pass 1: create copies
        while (cur != null) {
            map.put(cur, new Node(cur.val));
            cur = cur.next;
        }

        // Pass 2: wire next and random
        cur = head;
        while (cur != null) {
            map.get(cur).next = map.get(cur.next);
            map.get(cur).random = map.get(cur.random);
            cur = cur.next;
        }

        return map.get(head);
    }
}
```

## Line-by-line

- Pass 1: create a copy of each node, store in map. `map.get(cur.next)` handles null (returns null).
- Pass 2: wire `next` and `random` using the map. `map.get(cur.next)` returns the copy of the next node (or null if cur.next is null).
- Return `map.get(head)` — the copy of the head.

## Complexity

- Time: O(n) — two passes.
- Space: O(n) — the map.

## Common Mistakes

- **Not handling null.** `map.get(null)` returns null (HashMap allows null keys). This works, but be aware.
- **Shallow copy.** `new Node(cur.val)` creates a new node, but you must wire `next` and `random` separately. Forgetting this gives a list of disconnected nodes.
- **Modifying the original.** Don't change the original list's pointers. The HashMap approach doesn't modify anything.
- **Interleaving trick (O(1) space):** insert copy nodes between originals, wire randoms, then separate. More complex but saves space. Know it exists.

## How to Explain (interview)

**Opening:** Copy List with Random Pointer creates a deep copy. HashMap approach: (1) create a copy of each node, store original → copy mapping. (2) Wire next and random using the map. O(n) time, O(n) space. The interleaving trick achieves O(1) space but is more complex.

**The basic flow:**
```java
Map<Node, Node> map = new HashMap<>();
// Pass 1: create copies
for (Node cur = head; cur != null; cur = cur.next) map.put(cur, new Node(cur.val));
// Pass 2: wire
for (Node cur = head; cur != null; cur = cur.next) {
    map.get(cur).next = map.get(cur.next);
    map.get(cur).random = map.get(cur.random);
}
return map.get(head);
```

**The part that trips everyone up:** `map.get(cur.next)` returns null when `cur.next` is null (HashMap allows null keys). This is fine — it correctly sets `copy.next = null`. Also, the map stores original → copy, not the other way around.

**The mistakes to remember:**
- Not handling null (map.get(null) returns null — works but verify)
- Shallow copy without wiring (disconnected nodes)
- Modifying the original list
- Interleaving trick (O(1) space) — know it exists but HashMap is simpler
