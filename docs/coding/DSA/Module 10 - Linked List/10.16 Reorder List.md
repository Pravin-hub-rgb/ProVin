# 10.16 Reorder List

**Tier 2 problem.** (LeetCode #143)

**Problem:** Given a linked list, reorder it as L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → ... (LeetCode #143)

**Link:** https://leetcode.com/problems/reorder-list/

---

## Which Technique, and Why?

"Reorder list (first, last, second, second-last, ...)" → **Find middle + reverse second half + merge two halves**. Three steps: (1) find middle (slow/fast), (2) reverse second half, (3) interleave the two halves. O(n) time, O(1) space.

**Signal in the problem:** "reorder" / "interleave first and second half" → find middle + reverse + merge.

## Approach

1. Find the middle (slow & fast).
2. Reverse the second half.
3. Merge the two halves by alternating nodes.

## Pseudocode

```
// Step 1: find middle
slow = head, fast = head
while fast != null and fast.next != null:
    slow = slow.next
    fast = fast.next.next

// Step 2: reverse second half
prev = null, curr = slow
while curr != null:
    next = curr.next
    curr.next = prev
    prev = curr
    curr = next
// prev is new head of reversed second half

// Step 3: merge
first = head, second = prev
while second.next != null:
    temp1 = first.next
    temp2 = second.next
    first.next = second
    second.next = temp1
    first = temp1
    second = temp2
```

## Java Code

```java
class Solution {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null) return;

        // Step 1: find middle
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // Step 2: reverse second half
        ListNode prev = null, curr = slow;
        while (curr != null) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }

        // Step 3: merge
        ListNode first = head, second = prev;
        while (second.next != null) {
            ListNode temp1 = first.next;
            ListNode temp2 = second.next;
            first.next = second;
            second.next = temp1;
            first = temp1;
            second = temp2;
        }
    }
}
```

## Line-by-line

- Step 1: slow/fast find middle. For even length, slow is the second middle (start of second half).
- Step 2: reverse second half starting from slow. `prev` is the new head.
- Step 3: interleave: `first.next = second`, `second.next = first.next (old)`. Advance both.
- `while (second.next != null)` — stop when second half is exhausted. (Second half ≤ first half in length.)

## Complexity

- Time: O(n) — three passes (find middle, reverse, merge).
- Space: O(1) — in place.

## Common Mistakes

- **Not finding the middle correctly.** For even length, slow should be the second middle. The slow/fast with `fast != null && fast.next != null` gives this.
- **Not reversing the second half.** Without reversal, you can't interleave from the end.
- **Merge loop condition.** `second.next != null` (not `second != null`). When second is the last node, its next is null — stop. (If you use `second != null`, you'd access `second.next` when second is null → NPE.)
- **Modifying the list when not allowed.** This problem expects in-place modification.

## How to Explain (interview)

**Opening:** Reorder List interleaves first and second halves: L0 → Ln → L1 → Ln-1 → ... Three steps: (1) find middle (slow & fast), (2) reverse second half, (3) merge by alternating nodes. O(n) time, O(1) space.

**The basic flow:**
```java
// 1. find middle
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; }
// 2. reverse second half
ListNode prev = null, curr = slow;
while (curr != null) { ListNode next = curr.next; curr.next = prev; prev = curr; curr = next; }
// 3. merge
ListNode first = head, second = prev;
while (second.next != null) {
    ListNode t1 = first.next, t2 = second.next;
    first.next = second; second.next = t1;
    first = t1; second = t2;
}
```

**The part that trips everyone up:** the merge loop condition is `second.next != null` (not `second != null`). Also, save `temp1` and `temp2` before rewiring — otherwise you lose references.

**The mistakes to remember:**
- Wrong middle for even length
- Not reversing second half before merging
- Merge loop condition `second != null` (NPE on last node)
- Not saving temp references before rewiring
