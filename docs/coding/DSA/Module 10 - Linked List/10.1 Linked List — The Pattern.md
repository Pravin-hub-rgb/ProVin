# 10.1 Linked List — The Pattern

## What This Problem Is Asking (Simple Terms)

A **Linked List** is a linear data structure where elements (nodes) are not stored in contiguous memory locations. Each node contains data and a reference (pointer) to the next node. Unlike arrays, linked lists allow efficient insertion/deletion at any position but require O(n) time for access by index.

---

## Example 1

**Input:** `head = [1,2,3,4,5]`, `val = 3`

**Output:** `[1,2,4,5]`

**Explanation:** Remove node with value 3.

---

## Example 2

**Input:** `head = []`, `val = 1`

**Output:** `[]`

**Explanation:** Empty list remains empty.

---

## Constraints

- The number of nodes in the list is in the range `[0, 10^4]`.
- `1 <= Node.val <= 50`
- `0 <= val <= 50`

---

## Which Data Structure/Technique, and Why?

Linked List traversal uses **pointer manipulation** to traverse and modify nodes. The key technique is maintaining pointers (current, previous, next) to manipulate links between nodes.

**Signal in the problem:** "linked list", "delete node", "insert node", "reverse linked list" → Linked List pointer manipulation.

---

## Approach

**Iterative traversal with pointer manipulation:**
1. Initialize `current = head`, `prev = null`.
2. Traverse while `current != null`.
3. For deletion: when `current.val == val`, bypass current node: `prev.next = current.next`.
4. Move both pointers: `prev = current`, `current = current.next`.

### Pseudocode (Delete Node)

```
dummy = new ListNode(0)
dummy.next = head
prev = dummy, curr = head
while curr != null:
    if curr.val == val:
        prev.next = curr.next
    else:
        prev = curr
    curr = curr.next
return dummy.next
```

### Java Code

```java
class Solution {
    public ListNode removeElements(ListNode head, int val) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy, curr = head;
        while (curr != null) {
            if (curr.val == val) {
                prev.next = curr.next;
            } else {
                prev = curr;
            }
            curr = curr.next;
        }
        return dummy.next;
    }
}
```

### Line-by-line

- `ListNode dummy = new ListNode(0);` — dummy node to handle edge case of removing head.
- `dummy.next = head` — dummy points to original head.
- `ListNode prev = dummy, curr = head;` — prev tracks node before current, curr traverses.
- `while (curr != null)` — traverse until end.
- `if (curr.val == val)` — found node to delete.
- `prev.next = curr.next;` — bypass current node (delete it).
- `else { prev = curr; }` — only move prev when not deleting.
- `curr = curr.next;` — move to next node.
- `return dummy.next;` — return new head (original head might be deleted).

## Complexity

- Time: O(n) — single pass.
- Space: O(1) — only two pointers.

## Common Mistakes

- **Not using dummy node** — need special handling for deleting head node.
- **Not moving prev when not deleting** — prev should only move when we keep current node.
- **Forgetting to move curr** — always move curr to next node.

---

## How to Explain (interview)

**Opening:** Linked List traversal uses pointer manipulation. To delete a node, track previous node and bypass current node by setting `prev.next = curr.next`.

**The basic flow:**
```java
ListNode dummy = new ListNode(0);
dummy.next = head;
ListNode prev = dummy, curr = head;
while (curr != null) {
    if (curr.val == val) {
        prev.next = curr.next;
    } else {
        prev = curr;
    }
    curr = curr.next;
}
return dummy.next;
```

**The part that trips everyone up:**
- **Dummy node** — handles edge case of deleting head node.
- **prev only moves when not deleting** — prev stays when we delete curr, so prev.next still points to curr.next.
- **curr always moves** — curr = curr.next always executes.

**The mistakes to remember:**
- Forgetting dummy node — can't delete head node.
- Not moving prev when not deleting — prev.next would point to wrong node.
- Forgetting to move curr — infinite loop.
