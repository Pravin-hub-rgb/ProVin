## DSLR Box Jaisa — Sab Built-in Milta Hai

Socho tum DSLR camera ka box kharidte ho. Andar kya — camera + lens + memory card + strap **sab pehle se ek box mein**. Ready to shoot. Tum sirf nikalo aur use karo.

Usse alag, React app banana `create-react-app` jaisa — ek box ek cheez deta hai, baaki accessories alag alag install karne padte hain (router, eslint, build config). **`create-next-app` woh camera box hai** — routing, rendering, linting, TypeScript, dev-server — **sab ready** ek command mein. Isliye "zero config feel" — kaam shuru karo, setup nahi.

## create-next-app — The Command

Terminal mein:

```bash
npx create-next-app@latest
```

It will ask questions. Modern defaults — choose:
- TypeScript? `Yes`
- ESLint? `Yes` (linting — best practice)
- Tailwind? `Yes` (styling) / tumhare choice
- App Router? `Yes` (App Router use karo — 0.7)
- Import alias? `Yes` default (`@/`)

Ye sab ONE command pehle se **tooling** bana deta hai jo aapne React mein manually configure ki thi.

## What You Get — Folder Structure

```
my-app/
├── app/
│   ├── layout.tsx        → root layout (html, body, header)
│   ├── page.tsx          → home page (/)
│   └── globals.css       → global styles
├── public/               → static assets (images, files)
├── package.json
├── next.config.ts        → Next.js config
├── tsconfig.json
├── next-env.d.ts
└── .gitignore
```

"app/" folder = App Router route structure (0.7). "public/" = static files jo URL se serve hote hain (`/logo.png`).

### Commands (package.json scripts)

| Command | Kya Karta Hai |
|---|---|
| `npm run dev` | Dev server (localhost:3000), hot reload |
| `npm run build` | Production build (SSG/SSR/ISR generate) |
| `npm start` | Production build run |
| `npm run lint` | ESLint run |

## Import Alias — `@/`

`create-next-app` default `@/` alias set karta hai — matlab `@/components/Header` = project root se. Modular/structure ke liye clean imports (relative `../../` ki jagah).

```tsx
import Header from "@/components/Header";  // root-based, clean
```

## Running — First Success

```bash
cd my-app
npm run dev
```

Browser mein `http://localhost:3000` — default Next.js starter page. Ab editing shuru — `app/page.tsx` edit karo, save karo, hot-reload se dekh lo. **Ye tumhara First Next.js page** 🎉

## What It Is NOT

⚠️ **create-next-app = bloat nahi.** Har cheez configured hai, but `public/`, `package.json` etc. tujhe useful/chahiye cheeze hi. Yeh barebone starter hai (Vite CRA se halka bhi hai).

⚠️ **Ye feewas tools se upar jake zero config nahi kehna** — TypeScript/ESLint explicit chalenge with `Yes`. But wo pehle se setup ho jaata hai.
