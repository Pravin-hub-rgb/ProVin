Module 0 ka aakhri chapter. Ab tak humne saare concepts dekhe — SSR, SSG, ISR, RSC, hydration, caching, file-based routing. Last piece: **project ko kaise create karein** jisme yeh sab configure ho.

## create-next-app vs Manual React Setup

React app banane mein (jaise `create-react-app`) routing, ESLint, build config wagera **alag-alag install/configure** karne padte hain. **`create-next-app` yeh sab ek command mein de deta hai** — routing, rendering, linting, TypeScript, dev-server sab ready. Isliye "zero config feel" — kaam shuru karo, setup nahi.

## create-next-app — The Command

Terminal mein:

```bash
npx create-next-app@latest
```

Command chalate hi ye questions puchta hai — modern defaults choose karo: **TypeScript** `Yes`, **ESLint** `Yes` (linting best practice), **Tailwind** `Yes` (styling) ya tumhare choice, **App Router** `Yes` (0.7 wala structure), aur **import alias** `Yes` (default `@/`). Ye sab ek hi command pehle se **tooling** bana deta hai jo React mein manually configure karni padti thi.

## What You Get — Folder Structure

```
my-app/
├── app/
│   ├── layout.tsx        → root layout (html, body, header)
│   ├── page.tsx          → home page (/)
│   └── globals.css       → global styles
├── public/               → static assets (images, files)
├── package.json
├── next.config.ts        → Next.js config
├── tsconfig.json
├── next-env.d.ts
└── .gitignore
```

"app/" folder = App Router route structure (0.7). "public/" = static files jo URL se serve hote hain (`/logo.png`).

### Commands (package.json scripts)

| Command | Kya Karta Hai |
|---|---|
| `npm run dev` | Dev server (localhost:3000), hot reload |
| `npm run build` | Production build (SSG/SSR/ISR generate) |
| `npm start` | Production build run |
| `npm run lint` | ESLint run |

## Import Alias — `@/`

`create-next-app` default `@/` alias set karta hai — matlab `@/components/Header` = project root se. Modular/structure ke liye clean imports (relative `../../` ki jagah).

```tsx
import Header from "@/components/Header";  // root-based, clean
```

## Running — First Success

```bash
cd my-app
npm run dev
```

Browser mein `http://localhost:3000` — default Next.js starter page. Ab editing shuru — `app/page.tsx` edit karo, save karo, hot-reload se dekh lo. **Ye tumhara First Next.js page.**

## What It Is NOT

⚠️ **create-next-app = bloat nahi.** Jo files milti hain (`app/`, `public/`, `package.json`) sab zaroori cheezein hain — barebone starter hai (CRA/Vite se halka).

⚠️ **Ye zero-config nahi, prompt-based config hai** — TypeScript/ESLint explicit `Yes` chunna padta hai. Par wo ek baar setup ho jaata hai.
