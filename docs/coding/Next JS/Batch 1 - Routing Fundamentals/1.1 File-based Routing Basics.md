React Router mein jab tumne pehli baar routing set kiya tha, toh kya kiya tha? `<Routes>` aur `<Route>` likhe the — "ye path hai, ye component render karo." Har route ke liye ek `<Route>` tag. Yaad hai? Ab socho — agar tumhe 5 pages banane ho toh 5 `<Route>` tags likhne padenge, har ek mein path aur element.

Next.js mein ye sab khatam. **Folder banao, `page.tsx` daal do — route ban gaya.** Chal dekhte hain kaise.

---

## Manual Approach — React Router Mein Kya Karte The

React Router mein routing aisa dikhta tha:

```tsx
// App.tsx — React Router
import { Routes, Route } from 'react-router-dom';
import Home from './pages/Home';
import About from './pages/About';
import Contact from './pages/Contact';

export default function App() {
  return (
    <Routes>
      <Route path="/" element={<Home />} />
      <Route path="/about" element={<About />} />
      <Route path="/contact" element={<Contact />} />
    </Routes>
  );
}
```

Har route ke liye ek `<Route>` tag — path likho, component batao. 5 pages ho toh 5 tags. 50 pages ho toh 50 tags. **Config manual hai.**

---

## Better Approach — Next.js Ka File-based Routing

Next.js mein koi `<Route>` config nahi likhna. **Folder ka naam = URL path.** Har folder mein `page.tsx` ho — wo us route ka content hai.

```
app/
├── page.tsx          →  /          (home)
├── about/
│   └── page.tsx      →  /about
└── contact/
    └── page.tsx      →  /contact
```

Bas. Koi config file nahi, koi `<Routes>` nahi. Folder structure hi routing hai.

---

## Syntax — Folder + page.tsx = Route

Rule bilkul simple hai:

1. `app/` folder banao (ya already hoga `create-next-app` se)
2. Usme sub-folders banao — har folder ek route hai
3. Har folder mein `page.tsx` file — ye us route ka actual content hai

```
app/
├── page.tsx          →  /          (home)
├── about/
│   └── page.tsx      →  /about
└── contact/
    └── page.tsx      →  /contact
```

**Visual mapping:**

```
Folder:        about/page.tsx     →  URL:  /about
Folder:        contact/page.tsx   →  URL:  /contact
Root:          page.tsx           →  URL:  /
```

## Minimal Example — Sirf 3 Pages

Chal banate hain — teen static pages: Home, About, Contact.

**Step 1: `app/page.tsx` (Home)**

```tsx
export default function Home() {
  return <h1>Home Page</h1>;
}
```

**Step 2: `app/about/page.tsx`**

```tsx
export default function About() {
  return <h1>About Page</h1>;
}
```

**Step 3: `app/contact/page.tsx`**

```tsx
export default function Contact() {
  return <h1>Contact Page</h1>;
}
```

Bas. Ab browser mein `/about` jao — "About Page" dikhega. `/contact` jao — "Contact Page." **Koi `<Route>` config nahi, koi setup nahi — folder structure hi routing hai.**

## Build-up — Full Example with Layout

Ab thoda real banaate hain. Har page pe ek heading ho, aur bottom mein ek footer:

**`app/page.tsx` (Home)**

```tsx
export default function Home() {
  return (
    <div>
      <h1>Home</h1>
      <p>Welcome to my site</p>
      <footer>© 2026 My Site</footer>
    </div>
  );
}
```

**`app/about/page.tsx`**

```tsx
export default function About() {
  return (
    <div>
      <h1>About</h1>
      <p>This is about page</p>
      <footer>© 2026 My Site</footer>
    </div>
  );
}
```

Notice kiya? Footer **har page pe repeat** ho raha hai. Agar 10 pages ho toh 10 baar footer likhna padega. Ye toh galat hai — DRY principle violate ho raha hai.

Iska fix hai: **Layouts.** Agla concept — `layout.tsx` se ye repeat khatam karenge.

---

## `page.tsx` Ka Rule — Name Fixed Hai

Ek important rule: file ka naam **`page.tsx` hi hona chahiye.** `index.tsx`, `Home.tsx`, kuch bhi doosra nahi chalega. Next.js specifically `page.tsx` dhundhta hai — ye convention hai.

```
✅ app/about/page.tsx     →  /about route banega
❌ app/about/index.tsx    →  route nahi banega
❌ app/about/Home.tsx     →  route nahi banega
```

## What It Is NOT

⚠️ **File-based routing = sirf Next.js mein nahi.** Aur bhi frameworks hain jo file-based routing use karte hain (Remix, SvelteKit). Par Next.js ka App Router iska sabse polished version hai.

⚠️ **Folder = URL sirf normal folders ke liye.** `[slug]` ya `(group)` folders URL mein nahi dikhte — ye aage samjhenge.

⚠️ **`page.tsx` ke alawa aur bhi conventions hain** — `layout.tsx`, `loading.tsx`, `error.tsx`. Ye sab aage aayenge.

---

Ab hum jante hain ki pages kaise banate hain. Par ek problem dekhi — footer har page pe repeat ho raha hai. Agla concept: **Nested Layouts** — `layout.tsx` se ye repeat khatam karenge.
