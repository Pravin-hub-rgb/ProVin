## Ab Tak Fetch, Ab Axios

3.1–3.3 mein humne har HTTP call `fetch()` se ki thi. Ab se **axios** use karenge. Kyon? Dekho.

`fetch()` browser mein **built-in** hai — koi install nahi karna padta. Par har baar POST ke liye 3 cheezein manually likhni padti hain:

```tsx
const res = await fetch("/api/reviews", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ productId, text, rating }),
});
const review = await res.json();
```

**Axios** ek **library** hai (kisi aur ne banayi aur share ki hai) jo ye sab khud karti hai. Upar wala pura code isme bas itna:

```tsx
const res = await axios.post("/api/reviews", { productId, text, rating });
const review = res.data;
```

Dekha? No `method`, no `headers`, no `JSON.stringify` — axios khud object ko JSON mein convert karta hai. Aur **`res.data`** — axios response ka JSON already parse karke `data` naam ki property mein daal deta hai. `.json()` nahi bulana padta.

### Fetch vs Axios — Basic Comparison

| Kaam | `fetch()` | Axios |
|------|-----------|-------|
| GET | `fetch(url)` → `res.json()` | `axios.get(url)` → `res.data` |
| POST | `fetch(url, { method, headers, body })` + `JSON.stringify` | `axios.post(url, data)` — auto JSON |
| PUT | `method: "PUT"` + body | `axios.put(url, data)` |
| DELETE | `method: "DELETE"` | `axios.delete(url)` |
| JSON | Khud `.json()` bulana padta hai | Already parsed — `res.data` |
| Error | `res.ok` khud check karo | 2xx ke alawa khud throw + `error.response` |
| Dependency | Built-in | `bun add axios` |

### Kyun Axios?

1. **Kam code** — method, headers, JSON.stringify teeno likhne ki zaroorat nahi
2. **Auto JSON** — send bhi, receive bhi (`.json()` nahi)
3. **Better errors** — `fetch()` galat request pe bhi resolve ho jaata hai (khud `res.ok` check karna padta hai), axios galat pe **throw** karta hai — `catch (error)` mein directly aa jaata hai

Par **`fetch()` galat nahi hai** — built-in hai, koi dependency nahi. Axios bas zyada convenient hai. Aaj kal zyada project axios use karte hain, isliye ise seekhna fayde ka hai.

## Step 2: Route Handler - API Endpoints

```tsx
// app/api/reviews/route.ts
import { NextResponse } from "next/server";
import { getAllReviews, addReview } from "@/lib/reviews";

// GET /api/reviews - Saare reviews lao
export async function GET() {
  const reviews = getAllReviews();
  return NextResponse.json(reviews);
}

// POST /api/reviews - Naya review banao
export async function POST(request: Request) {
  const body = await request.json();

  // Validation
  if (!body.text || !body.productId || !body.rating) {
    return NextResponse.json(
      { error: "Text, productId, aur rating zaroori hai" },
      { status: 400 }
    );
  }

  const review = addReview({
    productId: body.productId,
    text: body.text,
    rating: body.rating,
  });

  if (!review) {
    return NextResponse.json(
      { error: "Review add nahi ho paya — text ya rating galat hai" },
      { status: 400 }
    );
  }

  return NextResponse.json(review, { status: 201 });
}
```

```tsx
// app/api/reviews/[id]/route.ts
import { NextResponse } from "next/server";
import { getReviewById, updateReview, deleteReview } from "@/lib/reviews";

// GET /api/reviews/1 - Ek review lao (edit page ke prefill ke liye)
export async function GET(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const review = getReviewById(Number(id));

  if (!review) {
    return NextResponse.json({ error: "Review nahi mila" }, { status: 404 });
  }

  return NextResponse.json(review);
}

// PUT /api/reviews/1 - Review edit karo (3.2 ka find + spread pattern)
export async function PUT(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const body = await request.json();

  if (!body.text || !body.rating) {
    return NextResponse.json(
      { error: "Text aur rating zaroori hai" },
      { status: 400 }
    );
  }

  const updated = updateReview(Number(id), {
    text: body.text,
    rating: Number(body.rating),
  });

  if (!updated) {
    return NextResponse.json({ error: "Review nahi mila" }, { status: 404 });
  }

  return NextResponse.json(updated);
}

// DELETE /api/reviews/1 - Review delete karo
export async function DELETE(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const deleted = deleteReview(Number(id));

  if (!deleted) {
    return NextResponse.json({ error: "Review nahi mila" }, { status: 404 });
  }

  return NextResponse.json({ message: "Review delete ho gaya" });
}
```

#### Step 4b: Pending State Add Karo

Ab `pending` state add karte hain — jab request chal rahi ho toh button "Loading..." dikhe:

```tsx
"use client";

import { useState } from "react";
import { useRouter } from "next/navigation";
import axios from "axios";

export function ReviewForm({ productId }: { productId: number }) {
  const router = useRouter();
  const [text, setText] = useState("");
  const [rating, setRating] = useState(5);
  const [pending, setPending] = useState(false);  // ← Naya state

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setPending(true);  // ← Request shuru

    try {
      await axios.post("/api/reviews", {
        productId,
        text,
        rating,
      });

      setText("");
      setRating(5);
      router.refresh();  // ← Next.js khud page refresh karega
    } catch (error) {
      console.error("Error:", error);
    } finally {
      setPending(false);  // ← Request khatam
    }
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-2 border p-4 rounded">
      <h3 className="font-bold">Naya Review Likho</h3>

      <div>
        <label>Rating:</label>
        <select
          value={rating}
          onChange={(e) => setRating(Number(e.target.value))}
          className="border p-1 rounded ml-2"
        >
          {[1, 2, 3, 4, 5].map((n) => (
            <option key={n} value={n}>
              {"⭐".repeat(n)}
            </option>
          ))}
        </select>
      </div>

      <textarea
        value={text}
        onChange={(e) => setText(e.target.value)}
        placeholder="Apna review likho..."
        className="w-full border p-2 rounded"
        rows={3}
      />

      <button
        type="submit"
        disabled={pending}
        className="bg-blue-500 text-white px-4 py-2 rounded disabled:bg-gray-400"
      >
        {pending ? "Loading..." : "Submit Review"}
      </button>
    </form>
  );
}
```

Dekho kya badla:
1. **`pending` state** — request shuru hone pe `true`, khatam hone pe `false`
2. **`disabled={pending}`** — button disable ho jaata hai loading ke dauran
3. **`try/catch`** — error aaye toh handle ho jaaye. Ab `if (!res.ok)` check ki zaroorat bhi nahi — axios khud non-2xx response pe throw kar deta hai, isliye `catch` mein seedha aa jaata hai
4. **`router.refresh()`** — naya comment dikhne ke liye page refresh

**Par ye bhi perfect nahi hai** — `router.refresh()` better hai par abhi bhi `useState` se pending state manage karni pad rahi hai. Version 2 (Server Actions) mein `useActionState` se built-in milega.

#### Step 4c: Success/Error Messages Add Karo

Ab `message` state add karte hain — user ko dikhe ki review add ho gaya ya nahi:

```tsx
"use client";

import { useState } from "react";
import axios from "axios";

export function ReviewForm({ productId }: { productId: number }) {
  const [text, setText] = useState("");
  const [rating, setRating] = useState(5);
  const [pending, setPending] = useState(false);
  const [message, setMessage] = useState("");  // ← Naya state

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setPending(true);
    setMessage("");

    try {
      await axios.post("/api/reviews", {
        productId,
        text,
        rating,
      });

      setMessage("Review add ho gaya!");
      setText("");
      setRating(5);
      window.location.reload();
    } catch (error) {
      if (axios.isAxiosError(error)) {
        setMessage(error.response?.data?.error || "Error: Review add nahi ho paya");
      } else {
        setMessage("Error: Review add nahi ho paya");
      }
    } finally {
      setPending(false);
    }
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-2 border p-4 rounded">
      <h3 className="font-bold">Naya Review Likho</h3>

      <div>
        <label>Rating:</label>
        <select
          value={rating}
          onChange={(e) => setRating(Number(e.target.value))}
          className="border p-1 rounded ml-2"
        >
          {[1, 2, 3, 4, 5].map((n) => (
            <option key={n} value={n}>
              {"⭐".repeat(n)}
            </option>
          ))}
        </select>
      </div>

      <textarea
        value={text}
        onChange={(e) => setText(e.target.value)}
        placeholder="Apna review likho..."
        className="w-full border p-2 rounded"
        rows={3}
      />

      <button
        type="submit"
        disabled={pending}
        className="bg-blue-500 text-white px-4 py-2 rounded disabled:bg-gray-400"
      >
        {pending ? "Loading..." : "Submit Review"}
      </button>

      {message && (
        <p className={message.startsWith("Error") ? "text-red-500" : "text-green-500"}>
          {message}
        </p>
      )}
    </form>
  );
}
```

Dekho kya badla — sirf 2 cheezein:
1. **`message` state** — success ya error message store karta hai
2. **`{message && ...}`** — message hai toh dikhao, nahi toh mat dikhao

Green for success, red for error. Simple.

**Ek naya axios concept:** `axios.isAxiosError(error)` check karta hai ki error axios ka hai ya nahi. Hai toh server ka message `error.response?.data?.error` se milta hai — wahi `{ error: "..." }` jo route handler ne bheja tha. Isliye ab generic "Error" ki jagah **asli reason** dikhega — jaise "Text, productId, aur rating zaroori hai". Agar error axios ka nahi hai (jaise network band), toh pehle wala generic message.

**Notice kiya?** Version 1 mein **har cheez manually** karni padti hai — pending state bhi, error handling bhi, page refresh bhi. Version 2 (Server Actions) mein ye sab built-in milega.

## Step 6: Detail Page — View + Edit (Dynamic Route)

Ab woh **edit flow** jodte hain jo 3.2 mein seekha tha. Jab user review list mein "Edit →" dabata hai toh `/reviews/2` khulta hai. Us page pe review + **Edit button** dikhta hai, aur click pe **form khul jaata hai**:

```tsx
// app/reviews/[id]/page.tsx
"use client";

import { useEffect, useState } from "react";
import axios from "axios";

export default function ReviewPage({ params }: { params: Promise<{ id: string }> }) {
  const [review, setReview] = useState<{ id: number; productId: number; text: string; rating: number; createdAt: string } | null>(null);
  const [editing, setEditing] = useState(false);   // ← edit mode ON/OFF
  const [editText, setEditText] = useState("");
  const [editRating, setEditRating] = useState(5);

  useEffect(() => {
    params.then(({ id }) => {
      const load = async () => {
        const res = await axios.get(`/api/reviews/${id}`);
        const data = res.data;
        setReview(data);
        setEditText(data.text);
        setEditRating(data.rating);
      };
      load();
    });
  }, [params]);

  if (!review) return <p>Loading...</p>;

  const handleUpdate = async (e: React.FormEvent) => {
    e.preventDefault();

    const res = await axios.put(`/api/reviews/${review.id}`, {
      text: editText,
      rating: editRating,
    });

    const updated = res.data;
    setReview(updated);   // naya review dikhao
    setEditing(false);    // form band karo
  };

  return (
    <div className="max-w-md mx-auto p-4 border rounded">
      {editing ? (
        // EDIT MODE — form khula hai
        <form onSubmit={handleUpdate} className="space-y-2">
          <div>
            <label>Rating:</label>
            <select
              value={editRating}
              onChange={(e) => setEditRating(Number(e.target.value))}
              className="border p-1 rounded ml-2"
            >
              {[1, 2, 3, 4, 5].map((n) => (
                <option key={n} value={n}>{"⭐".repeat(n)}</option>
              ))}
            </select>
          </div>
          <textarea
            value={editText}
            onChange={(e) => setEditText(e.target.value)}
            className="w-full border p-2 rounded"
            rows={3}
          />
          <div className="flex gap-2">
            <button type="submit" className="bg-green-500 text-white px-4 py-2 rounded">
              Save
            </button>
            <button type="button" onClick={() => setEditing(false)} className="text-gray-500 text-sm">
              Cancel
            </button>
          </div>
        </form>
      ) : (
        // VIEW MODE — review + Edit button
        <>
          <p>{"⭐".repeat(review.rating)}</p>
          <p className="text-lg">{review.text}</p>
          <button
            onClick={() => setEditing(true)}
            className="mt-3 bg-blue-500 text-white px-4 py-2 rounded"
          >
            Edit
          </button>
        </>
      )}
    </div>
  );
}
```

Ye **bilkul 3.2 ka detail-page pattern hai** — `params.then` se id nikalte hain, `axios.get("/api/reviews/${id}")` se wo ek review late hain, `editing` boolean se view/edit toggle karte hain. Fark bas itna ki ab **rating** bhi edit hoti hai (`editRating`), aur pehle se prefill hoti hai (`setEditRating(data.rating)`). Axios mein GET ka `res.data` hi parsed JSON hai — `.json()` nahi bulana padta.

`axios.put(...)` bhi wahi kaam hai — fetch mein `method: "PUT"` + headers + `JSON.stringify` likhna padta tha, yahan sirf data object diya.

Pura flow:

```
User list mein "Edit →" dabata hai (Link → /reviews/2)
    ↓
app/reviews/[id]/page.tsx loads → axios.get("/api/reviews/2") → review dikha
    ↓
"Edit" button click → setEditing(true) → form khula (text + rating prefilled)
    ↓
Save click → handleUpdate → PUT /api/reviews/2 → updated review
    ↓
setReview(updated) + setEditing(false) → naya data dikha, form band
```

**Polish baad mein aayega** — pending state, error handling, `useActionState`. Version 2 (Server Actions) mein ye chhota padega.

## Route Handler Version Ka Summary

| Step | Kya Kiya |
|------|----------|
| 1 | Data layer banaya (reviews.ts) |
| 2 | Route Handler banaya (GET, POST, PUT, DELETE) |
| 3 | Server Component - review list + "Edit →" Link |
| 4 | Client Component - form + manual pending state |
| 5 | Main page - sab jod diya |
| 6 | Detail page - `/reviews/[id]` pe Edit button → form → PUT |

**Boilerplate dekho:**
- Route file (2 files - `[id]/route.ts` aur `route.ts`)
- PUT handler + `getReviewById`/`updateReview` manually
- Detail page (`/reviews/[id]/page.tsx`) ke liye `useEffect` + `params.then` + manual form state — 3.2 wala boilerplate
- Client mein `axios` — GET/POST/PUT, auto JSON, `res.data`
- Manual `useState` for pending state
- Manual `router.refresh()` for refresh

**Ab Version 2 (Server Actions) banate hain - dekhna kitna kam code hoga.**
