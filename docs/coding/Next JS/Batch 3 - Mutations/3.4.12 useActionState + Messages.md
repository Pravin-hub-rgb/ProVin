## SOCH: Pending State + Messages Kyun Chahiye?

Socho tum restaurant mein order de rahe ho. Button dabaya — aur kuch nahi hua. 10 second tak kuch pata nahi — order gaya ya nahi. Frustrating hai.

Wahi yahan — agar user "Submit" dabaye aur kuch na dikhe toh confused ho jaayega. Chahiye:
- **Pending state** — "Adding..." dikhe jab tak server se response na aaye
- **Success message** — "Review add ho gaya!" green mein
- **Error message** — "Text zaroori hai!" red mein

Route Handler version mein ye sab `useState` se manually kiya tha. Server Actions mein **built-in** hai.

## Step 1: useActionState Lagao

```tsx
// app/components/ReviewFormServer.tsx
"use client";

import { useEffect, useActionState } from "react";
import { addReviewAction, FormState } from "../actions";

const initialState: FormState = {
  success: false,
  message: "",
};

export function ReviewFormServer({ productId }: { productId: number }) {
  const [state, formAction, isPending] = useActionState(
    addReviewAction,
    initialState
  );

  return (
    <form action={formAction} className="space-y-3 border p-4 rounded bg-white mt-4">
      <h3 className="font-bold">Naya Review Likho</h3>

      <input type="hidden" name="productId" value={productId} />

      <div>
        <label className="block text-sm font-medium mb-1">Rating:</label>
        <select name="rating" defaultValue={5} className="border p-2 rounded w-full" disabled={isPending}>
          {[1, 2, 3, 4, 5].map((n) => (
            <option key={n} value={n}>
              {"⭐".repeat(n)}
            </option>
          ))}
        </select>
      </div>

      <div>
        <label className="block text-sm font-medium mb-1">Review:</label>
        <textarea
          name="text"
          placeholder="Apna review likho..."
          className="w-full border p-2 rounded"
          rows={3}
          disabled={isPending}
        />
      </div>

      <button
        type="submit"
        disabled={isPending}
        className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600 disabled:bg-gray-400"
      >
        {isPending ? "Adding..." : "Submit Review"}
      </button>

      {state.message && (
        <p className={state.success ? "text-green-500" : "text-red-500"}>
          {state.message}
        </p>
      )}
    </form>
  );
}
```

**Line by line — kya badla:**

1. **`import { useEffect, useActionState } from "react"`** — dono naye imports.

2. **`initialState`** — shuru ka state: `{ success: false, message: "" }`. Action return karega toh ye badlega.

3. **`useActionState(addReviewAction, initialState)`** — ye magic hai. Ye 3 cheezein deta hai:
   - **`state`** — action ka return value (`{ success, message }`)
   - **`formAction`** — wrapped version of `addReviewAction` — form `action` mein lagao
   - **`isPending`** — `true` jab action chal raha hai, `false` jab khatam

4. **`action={formAction}`** — ab `addReviewAction` ki jagah `formAction` lagao. Ye `useActionState` ka wrapped version hai — state manage karta hai.

5. **`disabled={isPending}`** — button, select, textarea — sab disable ho jaye loading ke dauran.

6. **`{isPending ? "Adding..." : "Submit Review"}`** — button ka text change.

7. **`{state.message && ...}`** — message hai toh dikhao. `state.success` true ho toh green, false ho toh red.

## Kya Hua Behind the Scenes?

```
User "Submit Review" click karta hai
    ↓
isPending = true (automatically)
    ↓
Button "Adding..." dikhaata hai, form disable hota hai
    ↓
addReviewAction call hota hai server pe
    ↓
Action return karta hai: { success: true, message: "Review add ho gaya!" }
    ↓
state = { success: true, message: "Review add ho gaya!" }
isPending = false (automatically)
    ↓
Green message dikhta hai: "Review add ho gaya!"
revalidatePath → page refresh → naya review dikhta hai
```

## Route Handler vs Server Action — Pending State

| Route Handler (3.4.7) | Server Action (ye) |
|----------------------|-------------------|
| `const [pending, setPending] = useState(false)` | `isPending` from `useActionState` |
| `setPending(true)` in handleSubmit | Automatic |
| `setPending(false)` in finally | Automatic |
| `const [message, setMessage] = useState("")` | `state.message` from `useActionState` |
| `setMessage("Success!")` manually | Action return se automatic |
| `{message && <p>...` | `{state.message && <p>...` |

**Dekho — 2 useState gayab!** Route Handler mein `pending` + `message` ke liye alag state tha. Yahan sab `useActionState` se mil jaata hai.

## Common Mistakes

1. **`useActionState` `react` se import karo** — `react-dom` se nahi. React 19 mein naam badla hai.
2. **`initialState` zaroori hai** — `useActionState` ko pata hona chahiye shuru ka state kya hai.
3. **`formAction` lagao, `addReviewAction` nahi** — `action={addReviewAction}` galat hai — TypeScript error aayega. `formAction` use karo.
4. **`state.message` check karo** — `{state.message && ...}` — message empty ho toh mat dikhao.

## Kya Bana?

Ab form complete hai:
- Submit karne pe review save hota hai
- Loading dikhti hai
- Success/error messages aate hain
- Form disable hota hai loading ke dauran
- Page auto-refresh hota hai

**Par abhi sirf add hai.** Delete aur edit nahi hai. Agla step — delete button.
