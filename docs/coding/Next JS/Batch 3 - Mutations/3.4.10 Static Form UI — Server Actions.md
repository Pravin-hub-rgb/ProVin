## Kyun Pehle UI?

Wahi pattern — Route Handler version mein bhi pehle form UI banaya tha (3.4.7 Step 1). Pehle dikhao kaise dikhega, phir functionality jodao. Do cheezein ek saath mat karo.

## Step 1: Static Form — Kuch Nahi Karta

Form banate hain — textarea + rating select + submit button. Abhi submit kuch nahi karega — sirf UI hai.

```tsx
// app/components/ReviewFormServer.tsx
"use client";

export function ReviewFormServer({ productId }: { productId: number }) {
  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    console.log("Form submit hua — par abhi kuch nahi hota");
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-3 border p-4 rounded bg-white mt-4">
      <h3 className="font-bold">Naya Review Likho</h3>

      <input type="hidden" name="productId" value={productId} />

      <div>
        <label className="block text-sm font-medium mb-1">Rating:</label>
        <select name="rating" defaultValue={5} className="border p-2 rounded w-full">
          {[1, 2, 3, 4, 5].map((n) => (
            <option key={n} value={n}>
              {"⭐".repeat(n)}
            </option>
          ))}
        </select>
      </div>

      <div>
        <label className="block text-sm font-medium mb-1">Review:</label>
        <textarea
          name="text"
          placeholder="Apna review likho..."
          className="w-full border p-2 rounded"
          rows={3}
        />
      </div>

      <button
        type="submit"
        className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
      >
        Submit Review
      </button>
    </form>
  );
}
```

**Notice kiya?** Route Handler version ke form se **2 cheezein alag hain:**

1. **`defaultValue={5}` vs `value={5}`** — Route Handler mein `value={rating}` + `onChange` use kiya tha (controlled). Yahan `defaultValue` hai (uncontrolled). Kyunki ab React ko manage nahi karna — form data mein sirf `name` aur `value` chahiye.

2. **`name="text"`, `name="rating"`** — Route Handler mein `value={text}` + `onChange` se data React state mein jaata tha. Yahan `name` attribute se data form mein rahta hai — `FormData` se server action directly lega.

**`"use client"` kyun hai?** Abhi sirf `console.log` hai — par baad mein server action call hoga. Server action form se data leta hai — form client pe hai toh component bhi client pe hoga.

**Hidden input:** `<input type="hidden" name="productId" value={productId} />` — user ko dikhta nahi, par form submit mein data jaata hai. Server action mein `formData.get("productId")` se milega.

## Kya Badla Route Handler Se?

| Route Handler Form (3.4.7) | Server Action Form (ye) |
|---------------------------|------------------------|
| `value={text}` — controlled | `name="text"` — uncontrolled |
| `value={rating}` — controlled | `name="rating" defaultValue={5}` |
| `onChange={setText}` | Nahi chahiye |
| `useState` for text, rating | Zero useState |
| `onSubmit={handleSubmit}` | Same — abhi |

**Notice kiya?** Route Handler form mein **3 useState** the (text, rating, pending). Server Action form mein **zero** — sirf submit handler hai jo abhi `console.log` karta hai.

**Kyun?** Route Handler mein React ko data manage karna padta tha — `axios.post()` ko data dena tha. Server Action mein form khud data rakhta hai — `FormData` se server action directly lega. React ki zaroorat nahi.

---

## Common Mistakes

1. **`name` attribute mat bhoolo** — `formData.get("text")` tab kaam karega jab form field ka `name="text"` ho. Bina `name` ke `null` milega.
2. **`defaultValue` vs `value` confuse mat karo** — `defaultValue` initial value hai, baad mein React control nahi karta. `value` controlled hai — har keystroke pe state update hota hai. Server Actions mein `defaultValue` better hai.
3. **`"use client"` zaroori hai** — form client pe hai, server action call hoga — isliye client component chahiye.
