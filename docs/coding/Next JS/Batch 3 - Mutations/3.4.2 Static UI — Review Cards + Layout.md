3.4.1 mein plan banaya — kya banana hai, data kaisa hoga. Ab **pehle UI dekhte hain** — hardcoded data ke saath. Koi data layer nahi, koi fetch nahi — bas screen pe kya dikhega, wo confirm karenge.

---

## Kyun Hardcoded Pehle?

Socho tum ek restaurant ka menu bana rahe ho. Pehle menu ka layout banao — kya dikhega, kahan dikhega. Phir prices aur items baad mein daalo. Agar ek saath sab karo toh pata nahi chalta ki layout galat hai ya data galat hai.

Wahi yahan hai — pehle **UI confirm karo** (kaise dikhega), phir **data layer** lagao (kahan se aayega data). Do cheezein ek saath mat karo.

## Step 3: Review Card Component

Ab har review ko ek card ki tarah dikhayenge. Component banate hain — taaki list mein baar baar repeat ho.

```tsx
// app/components/ReviewCard.tsx
export function ReviewCard({
  text,
  rating,
  createdAt,
}: {
  text: string;
  rating: number;
  createdAt: string;
}) {
  return (
    <div className="border p-3 rounded bg-white shadow-sm">
      <div className="flex justify-between items-center mb-2">
        <span className="text-lg">{"⭐".repeat(rating)}</span>
        <span className="text-sm text-gray-500">{createdAt}</span>
      </div>
      <p className="text-gray-700">{text}</p>
    </div>
  );
}
```

**`{"⭐".repeat(rating)}` kya hai?** JavaScript ka `repeat()` method — string ko baar baar repeat karta hai. Agar `rating = 3` hai toh `"⭐⭐⭐"` ban jaayega. Simple trick — loops ki zaroorat nahi.

**Props dekho** — `text`, `rating`, `createdAt`. Koi `id` nahi, koi `productId` nahi — kyunki abhi card ko sirf dikhna hai, kuch karna nahi. Baad mein jab edit/delete aayega toh `id` chahiye hoga — tab add karenge. **Sirf utna hi jo abhi zaroori hai.**

## Step 4: Product Section Component

Ab har product ka section — product ka naam + uske reviews ka list.

```tsx
// app/components/ProductSection.tsx
import { ReviewCard } from "./ReviewCard";

export function ProductSection({
  name,
  reviews,
}: {
  name: string;
  reviews: { id: number; text: string; rating: number; createdAt: string }[];
}) {
  return (
    <div className="border p-4 rounded mb-6">
      <h2 className="text-xl font-bold mb-3">{name}</h2>

      {reviews.length === 0 ? (
        <p className="text-gray-500">Abhi koi review nahi hai.</p>
      ) : (
        <div className="space-y-2">
          {reviews.map((review) => (
            <ReviewCard
              key={review.id}
              text={review.text}
              rating={review.rating}
              createdAt={review.createdAt}
            />
          ))}
        </div>
      )}
    </div>
  );
}
```

**Notice kiya?** `reviews.length === 0` check hai — agar koi review nahi hai toh message dikhe. `map()` se har review ko `ReviewCard` mein convert kar rahe hain. `key={review.id}` — React ko pata chale kaunsa element kaunsa hai.

Ab main page — data array + ProductSection + ReviewCard.

  },

    id: 3,
    productId: 2,
    text: "Excellent! Sabse best product hai market mein.",
    rating: 5,
    createdAt: "2025-01-17",
  },
  {
    id: 4,
    productId: 2,
    text: "Mujhe pasand nahi aaya. Waste of money.",

  },
];

export default function ReviewsPage() {
  const product1Reviews = reviews.filter((r) => r.productId === 1);
  const product2Reviews = reviews.filter((r) => r.productId === 2);

  return (

      <h1 className="text-2xl font-bold mb-6">Reviews & Ratings</h1>
      <ProductSection name="Product 1" reviews={product1Reviews} />
      <ProductSection name="Product 2" reviews={product2Reviews} />
    </div>
  );

**`filter()` yaad hai?** 3.4.1 mein explain kiya tha — `reviews.filter((r) => r.productId === 1)` se sirf Product 1 ke reviews aayenge. Same data, do alag jagah se filter ho raha hai.

## Common Mistakes

1. **`key` mat bhoolo** — `reviews.map()` mein `key={review.id}` zaroor do. Nahi toh React warning aayega.
2. **Hardcoded data abhi temporary hai** — ye baad mein hatt jaayega. Abhi sirf UI confirm karne ke liye hai.
3. **Component names PascalCase** — `ReviewCard`, `ProductSection` — lowercase mat rakhna (`reviewCard` galat hai).

## Kya Bana?

| File | Kya Hai |
|------|---------|
| `app/layout.tsx` | Navbar + main container |
| `app/reviews/page.tsx` | Main page — hardcoded data + filter + sections |
| `app/components/ReviewCard.tsx` | Ek review ka card — stars + text + date |
| `app/components/ProductSection.tsx` | Product ka naam + reviews ki list |

Abhi ye sab **static** hai — data page ke andar hai, kisi external source se nahi aa raha. Agar naya review add karna ho toh code mein jaake array mein manually add karna padega. **Ye sustainable nahi hai.**

---

## Problem Jo Abhi Hai

1. **Data do jagah hai** — agar Product 3 add karna ho toh array bhi change karo aur `reviews.filter()` bhi change karna padega. DRY violation.
2. **Naya review add nahi ho sakta** — user ko koi form nahi dikh raha.
3. **Edit/Delete nahi hai** — existing review badalna ho toh code mein jaake manually change karo.

In problems ko solve karna agle steps ka kaam hai. Sabse pehle **data layer** banayenge — taaki data ek jagah rahe aur functions se manage ho.
