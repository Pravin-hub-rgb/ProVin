Route Handler version mein CRUD complete ho gaya — par **boilerplate bahut hai**. Har operation ke liye route file + axios call + useState + try/catch + reload. Ab **Server Actions** se same features banayenge — par pehle sochte hain kyun chahiye.

---

## SOCH: Server Actions Kyun?

Route Handler version mein kya ho raha hai — jab bhi form submit hota hai:

1. Client mein `axios.post("/api/reviews", data)` — manually call
2. Server pe `POST()` function — manually return
3. Client mein `useState(false)` for pending — manually manage
4. Client mein `try/catch` — manually handle
5. Client mein `window.location.reload()` — manually refresh

**5 cheezein manually** — har operation ke liye. Agar 3 operations hain (add, edit, delete) toh **15 jagah boilerplate**.

Server Actions mein ye sab automatic ho jaata hai:
- Form `action={addReview}` — automatic call (axios nahi chahiye)
- Server action function — data leta hai, return karta hai (route file nahi chahiye)
- `useActionState` — pending state + message automatic (useState nahi chahiye)
- `revalidatePath` — page refresh automatic (reload nahi chahiye)

**Boilerplate almost zero.**

## Kya Change Hoga?

| Route Handler Version | Server Actions Version |
|----------------------|----------------------|
| `axios.post("/api/reviews", data)` | `action={addReviewAction}` |
| `useState` for pending | `isPending` from `useActionState` |
| `useState` for message | `state.message` from `useActionState` |
| `window.location.reload()` | `revalidatePath("/reviews")` |
| Route file (`/api/reviews/route.ts`) | `app/actions.ts` — sirf functions |
| `try/catch` + `if (!res.ok)` | Return value (`success` + `message`) |

---

## Kya Seekhoge?

1. **Server Action** kya hai — form seedha server function call karta hai
2. **`"use server"`** — directive jo batata hai ye file server pe chalegi
3. **`useActionState`** — pending state + messages built-in
4. **`revalidatePath`** — data change ho toh page auto-refresh
5. **Hidden input** — user ko dikhaye bina data bhejna
6. **`defaultValue` vs `value`** — uncontrolled vs controlled
