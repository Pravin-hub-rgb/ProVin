3.4.13 mein delete ho gaya. Ab **edit flow** banayenge — detail page pe edit button, form khule, data prefill ho, save ho. Wahi 3.4.8 ka pattern — par ab server action se.

## SOCH: Edit Ka Kya Chahiye?

1. Detail page pe "Edit" button — click pe form khule
2. Form mein purane data prefill ho (text + rating)
3. "Save" click pe `updateReviewAction` call ho
4. `revalidatePath` se page refresh ho
5. Form band ho jaaye

Route Handler version mein ye `useEffect` + `axios.get()` + `useState` se kiya tha. Server Action mein — **Server Component seedha data layer se data lega** (3.4.6 ka pattern), phir client form sirf edit toggle + action handle karega.

## Step 1: updateReviewAction Banayo

```tsx
// app/actions.ts (mein deleteReviewAction ke baad add karo)

export async function updateReviewAction(
  prevState: FormState,
  formData: FormData
): Promise<FormState> {
  const id = Number(formData.get("id"));
  const text = (formData.get("text") as string) || "";
  const rating = Number(formData.get("rating"));

  if (!text) {
    return { success: false, message: "Review text zaroori hai!" };
  }

  const updated = updateReview(id, { text, rating });

  if (!updated) {
    return { success: false, message: "Review nahi mila!" };
  }

  revalidatePath(`/reviews/${id}`);
  revalidatePath("/reviews");
  return { success: true, message: "Review update ho gaya!" };
}
```

**Same pattern — 4 steps:**
1. FormData se data nikalo (`id`, `text`, `rating`)
2. Validation
3. `updateReview(id, { text, rating })` call karo
4. Result return karo + `revalidatePath`

**`revalidatePath` 2 jagah** — `/reviews/${id}` (detail page) aur `/reviews` (list page). Dono jagah naya data dikhna chahiye.

## Step 2: Detail Page — Server Component + Client Form

Detail page ab **do parts** mein hai:
1. **Server Component** — data layer se seedha data lega (no axios, no useEffect)
2. **Client Component** — edit toggle + form + action

```tsx
// app/reviews/[id]/page.tsx
import { getReviewById } from "@/lib/reviews";
import { notFound } from "next/navigation";
import Link from "next/link";
import { EditReviewForm } from "../../components/EditReviewForm";

export default async function ReviewPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const review = getReviewById(Number(id));

  if (!review) {
    notFound();
  }

  return (
    <div className="max-w-md mx-auto p-4 border rounded bg-white">
      <Link href="/reviews" className="text-blue-500 hover:underline text-sm mb-4 block">
        Wapas List pe
      </Link>

      <div className="flex justify-between items-center mb-3">
        <span className="text-2xl">{"⭐".repeat(review.rating)}</span>
        <span className="text-sm text-gray-500">{review.createdAt}</span>
      </div>

      <p className="text-lg mb-4">{review.text}</p>

      <EditReviewForm review={review} />
    </div>
  );
}
```

**Notice kiya?** Server Component hai — `getReviewById()` seedha call. Koi `useState`, koi `useEffect`, koi `axios`. Data already hai — `review` object mein. `EditReviewForm` ko as prop de diya.

## Step 3: EditReviewForm — Client Component

```tsx
// app/components/EditReviewForm.tsx
"use client";

import { useState, useEffect, useActionState } from "react";
import { updateReviewAction, FormState } from "../actions";

const initialState: FormState = {
  success: false,
  message: "",
};

export function EditReviewForm({
  review,
}: {
  review: { id: number; text: string; rating: number };
}) {
  const [editing, setEditing] = useState(false);
  const [state, formAction, isPending] = useActionState(updateReviewAction, initialState);

  useEffect(() => {
    if (state.success) {
      setEditing(false);
    }
  }, [state]);

  return (
    <div className="mt-3">
      {editing ? (
        <form action={formAction} className="space-y-2">
          <input type="hidden" name="id" value={review.id} />

          <div>
            <label className="block text-sm font-medium mb-1">Rating:</label>
            <select name="rating" defaultValue={review.rating} className="border p-2 rounded w-full">
              {[1, 2, 3, 4, 5].map((n) => (
                <option key={n} value={n}>
                  {"⭐".repeat(n)}
                </option>
              ))}
            </select>
          </div>

          <textarea
            name="text"
            defaultValue={review.text}
            className="w-full border p-2 rounded"
            rows={3}
          />

          <div className="flex gap-2">
            <button
              type="submit"
              disabled={isPending}
              className="bg-green-500 text-white px-4 py-2 rounded disabled:bg-gray-400"
            >
              {isPending ? "Saving..." : "Save"}
            </button>
            <button
              type="button"
              onClick={() => setEditing(false)}
              className="text-gray-500 px-4 py-2 rounded"
            >
              Cancel
            </button>
          </div>
        </form>
      ) : (
        <button
          onClick={() => setEditing(true)}
          className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
        >
          Edit
        </button>
      )}
    </div>
  );
}
```

**Line by line:**

1. **`useState(false)` — `editing`** — view/edit toggle. Button click pe `true`, cancel ya success pe `false`.

2. **`useActionState(updateReviewAction, initialState)`** — same pattern — `state`, `formAction`, `isPending`.

3. **`useEffect(() => { if (state.success) setEditing(false) }, [state])`** — action success ho toh form band ho jaaye. `state.success` true hoga toh editing `false` ho jaayega.

4. **`defaultValue={review.text}` + `defaultValue={review.rating}`** — Server Component se aaya data prefill ho raha hai. `defaultValue` — uncontrolled, form data mein direct.

5. **`<input type="hidden" name="id" value={review.id} />`** — action ko pata chale kaunsa review update karna hai.

6. **`Cancel` button** — `type="button"` (submit nahi) — `setEditing(false)` se form band.

## Pura Edit Flow

```
User "Edit" click karta hai → setEditing(true) → form khula
    ↓
Form mein purana data prefill hai (defaultValue)
    ↓
User text/rating badalta hai
    ↓
"Save" click → action={updateReviewAction} → server action call
    ↓
updateReview(id, { text, rating }) → reviews.json update
    ↓
revalidatePath → page refresh
    ↓
state.success = true → useEffect → setEditing(false) → form band
```

## Common Mistakes

1. **`useEffect` mein `state.success` check karo** — `state` pe depend karo, `state.success` nahi. React warning aayega.
2. **`defaultValue` vs `value`** — `defaultValue` use karo — uncontrolled. `value` se React state manage karni padti hai.
3. **Hidden input ka `name="id"`** — `formData.get("id")` se review ID milegi. Galat `name` ho toh `null` aayega.
4. **`revalidatePath` 2 jagah** — detail page aur list page dono refresh ho jaayein.
