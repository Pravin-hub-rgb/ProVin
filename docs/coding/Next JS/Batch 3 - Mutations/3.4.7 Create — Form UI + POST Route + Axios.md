Ab tak reviews sirf **dikh** rahe hain — add nahi ho rahe. Ab naya review add karne ka form banayenge. Par pehle sirf **form UI** — does nothing, sirf dikhta hai. Phir route banayenge, phir connect karenge.

---

## Kyun Pehle UI?

Socho tum ek restaurant mein ho — waiter aata hai aur bolta hai "order kya hoga?" Pehle menu dikhata hai (options), phir order leta hai. Agar seedha order le le bina menu dikhaye toh confusion hoga.

Wahi yahan — pehle form dikhao (kya fields hain, kaise dikhta hai), phir functionality jodao (submit kya karega).

---

## Step 1: Form UI — Sirf Dikh Raha Hai

Pehle form banate hain — textarea + rating select + submit button. Abhi submit kuch nahi karega — sirf UI hai.

```tsx
// app/components/ReviewForm.tsx
"use client";

import { useState } from "react";

export function ReviewForm({ productId }: { productId: number }) {
  const [text, setText] = useState("");
  const [rating, setRating] = useState(5);

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    console.log("Form submitted:", { productId, text, rating });
    setText("");
    setRating(5);
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-3 border p-4 rounded bg-white mt-4">
      <h3 className="font-bold">Naya Review Likho</h3>

      <div>
        <label className="block text-sm font-medium mb-1">Rating:</label>
        <select
          value={rating}
          onChange={(e) => setRating(Number(e.target.value))}
          className="border p-2 rounded w-full"
        >
          {[1, 2, 3, 4, 5].map((n) => (
            <option key={n} value={n}>
              {"⭐".repeat(n)}
            </option>
          ))}
        </select>
      </div>

      <div>
        <label className="block text-sm font-medium mb-1">Review:</label>
        <textarea
          value={text}
          onChange={(e) => setText(e.target.value)}
          placeholder="Apna review likho..."
          className="w-full border p-2 rounded"
          rows={3}
        />
      </div>

      <button
        type="submit"
        className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
      >
        Submit Review
      </button>
    </form>
  );
}
```

**Line by line:**

1. **`"use client"`** — form hai, interactive hai (`useState`, `onChange`, `onSubmit`) — client component chahiye.

2. **`useState("")`** — text ka state — initially empty. User type karega toh `setText` se update hoga.

3. **`useState(5)`** — rating ka state — default 5 stars.

4. **`handleSubmit`** — abhi sirf `console.log` — data kahan ja raha hai, dikhta hai. Form submit hone pe page reload hota hai — `e.preventDefault()` se rokte hain.

5. **`setText("")` + `setRating(5)`** — submit ke baad form clear ho jaaye.

6. **`<select value={rating} onChange={...}>`** — controlled component — React state aur select ek saath chalte hain.

7. **`[1,2,3,4,5].map()`** — 5 options — har option mein stars.

8. **`<textarea value={text} onChange={...}>`** — controlled textarea — user type kare toh state update ho.

## Step 3: POST Route Banayo

Ab form ka data kahan jaayega? Server pe. Uske liye **POST route** chahiye.

```tsx
// app/api/reviews/route.ts (mein GET ke baad add karo)
import { NextResponse } from "next/server";
import { getAllReviews, getReviewsByProduct, addReview } from "@/lib/reviews";

// ... GET function jo pehle tha ...

export async function POST(request: Request) {
  const body = await request.json();

  // Validation
  if (!body.text || !body.productId || !body.rating) {
    return NextResponse.json(
      { error: "Text, productId, aur rating zaroori hai" },
      { status: 400 }
    );
  }

  const review = addReview({
    productId: body.productId,
    text: body.text,
    rating: body.rating,
  });

  if (!review) {
    return NextResponse.json(
      { error: "Review add nahi ho paya — text ya rating galat hai" },
      { status: 400 }
    );
  }

  return NextResponse.json(review, { status: 201 });
}
```

**Line by line:**

1. **`export async function POST()`** — POST method handle karega. Function name `POST` hona chahiye — HTTP method se match.

2. **`await request.json()`** — request body se JSON data nikalo. Client ne jo bheja hai wo milega.

3. **Validation** — 3 cheezein zaroori hain: `text`, `productId`, `rating`. Agar koi missing ho toh 400 error.

4. **`addReview()`** — data layer ka function — naya review add karega + file mein save karega.

5. **Agar `null` return** — data layer ne reject kiya (validation fail). 400 error.

6. **`{ status: 201 }`** — "Created" — resource ban gaya. 200 ki jagah 201 REST best practice hai.

## Step 4: Form Se POST Route Connect Karo

Ab form mein `console.log` hata ke `axios.post` lagao.

## Step 5: Pending State Add Karo

Ab user ko pata chale ki request chal rahi hai — button "Loading..." dikhe.

```tsx
// app/components/ReviewForm.tsx
"use client";

import { useState } from "react";
import axios from "axios";

export function ReviewForm({ productId }: { productId: number }) {
  const [text, setText] = useState("");
  const [rating, setRating] = useState(5);
  const [pending, setPending] = useState(false);

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setPending(true);

    try {
      await axios.post("/api/reviews", {
        productId,
        text,
        rating,
      });

      setText("");
      setRating(5);
      window.location.reload();
    } catch (error) {
      console.error("Error:", error);
    } finally {
      setPending(false);
    }
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-3 border p-4 rounded bg-white mt-4">
      <h3 className="font-bold">Naya Review Likho</h3>

      <div>
        <label className="block text-sm font-medium mb-1">Rating:</label>
        <select
          value={rating}
          onChange={(e) => setRating(Number(e.target.value))}
          className="border p-2 rounded w-full"
          disabled={pending}
        >
          {[1, 2, 3, 4, 5].map((n) => (
            <option key={n} value={n}>
              {"⭐".repeat(n)}
            </option>
          ))}
        </select>
      </div>

      <div>
        <label className="block text-sm font-medium mb-1">Review:</label>
        <textarea
          value={text}
          onChange={(e) => setText(e.target.value)}
          placeholder="Apna review likho..."
          className="w-full border p-2 rounded"
          rows={3}
          disabled={pending}
        />
      </div>

      <button
        type="submit"
        disabled={pending}
        className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600 disabled:bg-gray-400"
      >
        {pending ? "Adding..." : "Submit Review"}
      </button>
    </form>
  );
}
```

**Dekho kya badla:**
1. **`pending` state** — request shuru ho toh `true`, khatam ho toh `false`
2. **`setPending(true)`** — handleSubmit ke shuru mein
3. **`setPending(false)`** — `finally` mein — chahe success ho ya error
4. **`disabled={pending}`** — button, select, textarea — sab disable ho jaye loading ke dauran
5. **`{pending ? "Adding..." : "Submit Review"}`** — button ka text change
6. **`window.location.reload()`** — submit ke baad page refresh — naya review dikhe

## Step 6: Success/Error Messages Add Karo

Ab user ko dikhe ki review add ho gaya ya nahi.

```tsx
// app/components/ReviewForm.tsx
"use client";

import { useState } from "react";
import axios from "axios";

export function ReviewForm({ productId }: { productId: number }) {
  const [text, setText] = useState("");
  const [rating, setRating] = useState(5);
  const [pending, setPending] = useState(false);
  const [message, setMessage] = useState("");

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setPending(true);
    setMessage("");

    try {
      await axios.post("/api/reviews", {
        productId,
        text,
        rating,
      });

      setMessage("Review add ho gaya!");
      setText("");
      setRating(5);
      window.location.reload();
    } catch (error) {
      if (axios.isAxiosError(error)) {
        setMessage(error.response?.data?.error || "Error: Review add nahi ho paya");
      } else {
        setMessage("Error: Review add nahi ho paya");
      }
    } finally {
      setPending(false);
    }
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-3 border p-4 rounded bg-white mt-4">
      <h3 className="font-bold">Naya Review Likho</h3>

      <div>
        <label className="block text-sm font-medium mb-1">Rating:</label>
        <select
          value={rating}
          onChange={(e) => setRating(Number(e.target.value))}
          className="border p-2 rounded w-full"
          disabled={pending}
        >
          {[1, 2, 3, 4, 5].map((n) => (
            <option key={n} value={n}>
              {"⭐".repeat(n)}
            </option>
          ))}
        </select>
      </div>

      <div>
        <label className="block text-sm font-medium mb-1">Review:</label>
        <textarea
          value={text}
          onChange={(e) => setText(e.target.value)}
          placeholder="Apna review likho..."
          className="w-full border p-2 rounded"
          rows={3}
          disabled={pending}
        />
      </div>

      <button
        type="submit"
        disabled={pending}
        className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600 disabled:bg-gray-400"
      >
        {pending ? "Adding..." : "Submit Review"}
      </button>

      {message && (
        <p className={message.startsWith("Error") ? "text-red-500" : "text-green-500"}>
          {message}
        </p>
      )}
    </form>
  );
}
```

**Kya badla:**
1. **`message` state** — success ya error message store
2. **`setMessage("Review add ho gaya!")`** — success pe
3. **`setMessage(error.response?.data?.error)`** — error pe — server ka asli message
4. **`axios.isAxiosError(error)`** — type check — TypeScript ko pata chale ki `error.response` hai
5. **`{message && ...}`** — message hai toh dikhao, green for success, red for error

## Common Mistakes

1. **`e.preventDefault()` mat bhoolo** — bina iske page reload ho jaayega aur form data ud jaayega.
2. **`disabled={pending}` mat bhoolo** — loading ke dauran dobara submit ho sakta hai agar button disable nahi hai.
3. **`window.location.reload()` vs `router.refresh()`** — dono kaam karte hain. `router.refresh()` (Next.js) better hai par abhi kaam chal jaayega. Aage server actions mein `revalidatePath` aayega.
4. **Validation server pe karo, client pe mat bharoso** — client pe validation bypass ho sakta hai. Server pe hamesha check karo.
