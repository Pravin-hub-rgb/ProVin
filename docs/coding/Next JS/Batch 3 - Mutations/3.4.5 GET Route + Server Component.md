3.4.4 mein client component banaya — `axios.get("/api/reviews")` call ho raha hai. Par route exist nahi karta — error aa raha hai. Ab **GET route banayenge** — taaki client ko data mil sake.

---

## SOCH: Route Kyun Chahiye?

Client component (`ReviewList`) directly data layer call nahi kar sakta — `fs` module client pe kaam nahi karta. Isliye beech mein **ek middleman** chahiye — jo server pe ho, data layer se data le, aur client ko de. Wahi **Route Handler** hai (3.1 mein seekha tha).

```
Client (ReviewList) → axios.get("/api/reviews") → GET Route (server) → getAllReviews() → reviews.json
                                                                          ↑
                                                                    Data layer yahan call hoga
```

---

## Step 1: GET Route Banayo

```tsx
// app/api/reviews/route.ts
import { NextResponse } from "next/server";
import { getAllReviews, getReviewsByProduct } from "@/lib/reviews";

export async function GET(request: Request) {
  const { searchParams } = new URL(request.url);
  const productId = searchParams.get("productId");

  if (productId) {
    const reviews = getReviewsByProduct(Number(productId));
    return NextResponse.json(reviews);
  }

  const reviews = getAllReviews();
  return NextResponse.json(reviews);
}
```

**Line by line:**

1. **`import { NextResponse }`** — response bhejne ke liye. `NextResponse.json()` se JSON response jaata hai.

2. **`import { getAllReviews, getReviewsByProduct }`** — data layer se functions.

3. **`export async function GET()`** — GET method handle karega. Ye 3.1 mein seekha tha — `GET`, `POST`, `PUT`, `DELETE` — function name HTTP method se match hona chahiye.

4. **`new URL(request.url)`** — request ka URL parse karo. `?productId=1` jaisa query param nikalne ke liye.

5. **`searchParams.get("productId")`** — URL se `productId` nikalo. Agar hai toh number mein convert karo, nahi toh `null`.

6. **Agar `productId` hai** — `getReviewsByProduct()` se sirf us product ke reviews. Agar nahi — `getAllReviews()` se saare reviews.

7. **`NextResponse.json(reviews)`** — JSON response bhejo.

## Ab Compare Karo: Client Fetch vs Server Component

3.4.4 mein jo `ReviewList` banaya — wo **Client Component** tha (`"use client"`). Ab ek aur version banate hain — **Server Component** — jo directly data layer call kare, bina axios ke.

### Server Component Version:

```tsx
// app/components/ReviewListServer.tsx
import { getReviewsByProduct } from "@/lib/reviews";

export function ReviewListServer({ productId }: { productId: number }) {
  const reviews = getReviewsByProduct(productId);

  if (reviews.length === 0) {
    return <p className="text-gray-500">Abhi koi review nahi hai.</p>;
  }

  return (
    <div className="space-y-2">
      <h3 className="font-bold">Reviews ({reviews.length})</h3>
      {reviews.map((review) => (
        <div key={review.id} className="border p-2 rounded bg-white">
          <div className="flex justify-between items-center mb-1">
            <span>{"⭐".repeat(review.rating)}</span>
            <span className="text-sm text-gray-500">{review.createdAt}</span>
          </div>
          <p className="text-gray-700">{review.text}</p>
        </div>
      ))}
    </div>
  );
}
```

**Notice kiya?** Koi `"use client"` nahi, koi `useState`, koi `useEffect`, koi `axios`. Seedha `getReviewsByProduct()` call — data layer se directly. **Server Component hai** — isliye `fs` module seedha kaam karta hai.

### Client vs Server — Comparison:

| | Client Component (3.4.4) | Server Component (ye) |
|---|---|---|
| **`"use client"`** | Haan | Nahi |
| **Data fetch** | `useEffect` + `axios.get()` | Direct function call |
| **`useState`** | Haan (reviews, loading) | Nahi |
| **Loading state** | Haan ("Loading...") | Nahi (server pe data ready milta hai) |
| **Code kitna** | Zyada (~40 lines) | Kam (~25 lines) |
| **Kab use karein** | Jab interactivity chahiye (click, form) | Jab sirf data dikhana hai |

---

## Kaunsa Use Karein?

**Server Component** tab use karo jab:
- Sirf data dikhana hai (read-only)
- Koi interactivity nahi (click, form, input)
- Zyada code nahi chahiye
- Performance better chahiye (server pe data ready milta hai)

**Client Component** tab use karo jab:
- Form hona chahiye (inputs, submit)
- Click handlers honi chahiye
- State manage karni ho (loading, pending, messages)
- Real-time updates chahiye

**Abhi ke liye:** Reviews sirf dikhane hain — toh Server Component better hai. Par agle steps mein form aayega (add review), edit aayega, delete aayega — tab Client Component chahiye hoga. Isliye dono versions rakhenge — Server Component list ke liye, Client Components form/buttons ke liye.

## Common Mistakes

1. **`"use client"` galat jagah** — Server Component mein mat lagao — `fs` module kaam nahi karega.
2. **GET route mein validation mat bhoolo** — Agar `productId` galat type ka hai toh `Number(productId)` se `NaN` aa sakta hai.
3. **`NextResponse.json()` mat bhoolo** — Route Handler se response `NextResponse.json()` se jaata hai. Agar `return` karo bina JSON ke toh client ko kuch nahi milega.
4. **Query params parse karna mat bhoolo** — `new URL(request.url).searchParams.get("productId")` — seedha `request.body` mat padho GET mein.

## Problem Jo Abhi Hai

Abhi sirf **list page** hai — saare reviews dikh rahe hain. Par **detail page** nahi hai — jab user kisi review pe click kare toh uska poora detail dikhe. Aur **form** nahi hai — naya review add nahi ho sakta.

Agle step mein **detail page** banayenge — `/reviews/[id]` — jismein ek review ka poora text dikhega. Uske liye **GET single route** chahiye — jo ek review ka data de.
