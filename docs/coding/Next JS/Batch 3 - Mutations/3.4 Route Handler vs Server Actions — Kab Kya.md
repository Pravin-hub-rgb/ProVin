Ab tak do approaches seekhi hain — Route Handlers (3.1) aur Server Actions (3.3). Dono data change karne ke liye hain. Par **kab kya use karna hai?**

Ye sabse important question hai. Dono seekh liye, par agar galat jagah use karoge toh problem hogi.

---

## SOCH: Kab Kya Hota Hai?

Man lo tum ek restaurant mein ho:
- **Menu padhna hai** → GET request (kuch nahi badalte)
- **Order dena hai** → POST request (naya order)
- **Order change karna hai** → PUT request
- **Order cancel karna hai** → DELETE request

Par sawaal ye hai — **kya tum waiter ko seedha bologe ya kitchen mein jaake khud bologe?**

- **Waiter ko bologe** = Route Handler (API layer hai)
- **Kitchen mein jaake bologe** = Server Action (seedha function call)

Dono tareeke kaam karte hain — par har jagah dono nahi chalte.

---

## COMPARISON: Kab Kya Use Karein?

| Scenario | Route Handler | Server Actions |
|----------|---------------|----------------|
| Sirf Next.js app hai | ✅ Chalega | ✅ Better — kam boilerplate |
| External client hai (mobile app, another website) | ✅ Zaroori hai | ❌ Nahi chalega |
| Third-party API banana hai | ✅ Zaroori hai | ❌ Nahi chalega |
| Simple form submission | ✅ Chalega | ✅ Better — easy |
| Complex file upload | ✅ Better — control zyada | ⚠️ Limited |
| Payment processing (Stripe, Razorpay) | ✅ Zaroori hai | ❌ Nahi chalega |
| Microservices architecture | ✅ Zaroori hai | ❌ Nahi chalega |
| Quick CRUD operations | ✅ Chalega | ✅ Better — kam code |

---

## Rule of Thumb

```
Kya external client hai? (mobile app, third-party website)
  → Haan → Route Handler
  → Nahi → Neeche jao

Kya complex operation hai? (file upload, payment, 3rd-party API)
  → Haan → Route Handler
  → Nahi → Neeche jao

Kya simple form hai? (comment, profile update, feedback)
  → Haan → Server Action
  → Nahi → Route Handler
```

## Same Feature — Dono Tareekon Se

Ek comment add karne ka feature banate hain — dono tareekon se dikhata hoon:

### Route Handler Version

```tsx
// app/api/comments/route.ts
import { NextResponse } from "next/server";

export async function POST(request: Request) {
  const body = await request.json();
  const comment = { id: Date.now(), text: body.text };
  return NextResponse.json(comment, { status: 201 });
}
```

```tsx
// Client Component
"use client";

import { useState } from "react";

export default function CommentForm() {
  const [text, setText] = useState("");

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    const res = await fetch("/api/comments", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ text }),
    });
    const comment = await res.json();
    console.log("Added:", comment);
    setText("");
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={text} onChange={(e) => setText(e.target.value)} />
      <button type="submit">Submit</button>
    </form>
  );
}
```

**Boilerplate:** Route file + `fetch()` call + headers + JSON.stringify + state management

### Server Action Version

```tsx
// app/actions.ts
"use server";

export async function addComment(formData: FormData) {
  const text = formData.get("comment") as string;
  const comment = { id: Date.now(), text };
  console.log("Added:", comment);
  return { success: true };
}
```

```tsx
// Client Component
import { addComment } from "./actions";

export default function CommentForm() {
  return (
    <form action={addComment}>
      <input name="comment" />
      <button type="submit">Submit</button>
    </form>
  );
}
```

**Boilerplate:** Almost zero — sirf function + form

## Fark Kya Hai?

| | Route Handler | Server Action |
|---|---|---|
| **Boilerplate** | Zyada | Kam |
| **Client code** | `fetch()`, headers, JSON.stringify | Sirf `action={function}` |
| **Control** | Tumhe pata hai kya ho raha hai | Next.js hidden layer handle karta hai |
| **Debug** | Easy — network tab mein dikhata hai | Mushkil — hidden endpoint |
| **External access** | Haan — koi bhi call kar sakta hai | Nahi — sirf Next.js app |

---

## Kab Route Handler Choose Karo?

1. **External client hai** — mobile app, third-party website
2. **API share karni hai** — doosra project use karega
3. **Complex logic hai** — file upload, payment, email
4. **Debugging chahiye** — network tab mein sab dikhe
5. **REST standard follow karna hai** — industry practice

## Kab Server Action Choose Karo?

1. **Sirf Next.js app hai** — koi external client nahi
2. **Simple form hai** — comment, feedback, profile update
3. **Kam code chahiye** — boilerplate reduce karna hai
4. **Quick iteration hai** — jaldi banana hai
5. **Progressive enhancement chahiye** — JavaScript off bhi chale

---

## Dono Ek Sath Bhi Use Kar Sakte Ho!

Har jagah choose nahi karna — dono ek saath kaam karte hain:

```tsx
// Route Handler — external clients ke liye
// app/api/comments/route.ts
export async function POST(request: Request) {
  // ...
}

// Server Action — sirf Next.js form ke liye
// app/actions.ts
"use server";
export async function addComment(formData: FormData) {
  // ...
}
```

Same feature, do tareekon se — external client Route Handler use karega, Next.js form Server Action.

---

## Nutshell

Route Handler aur Server Actions dono data change karne ke liye hain. Route Handler **universal** hai — har jagah kaam aata hai, par boilerplate zyada hai. Server Action **Next.js specific** hai — boilerplate kam hai, par sirf Next.js app mein chalta hai. **Rule of thumb:** External client hai ya complex operation → Route Handler. Simple form, sirf Next.js app → Server Action.

## What It Is NOT

⚠️ **Server Action = "Route Handler se better" nahi.** Dono alag alag jagah kaam aate hain. Server Action boilerplate kam karta hai, par control bhi kam hota hai.

⚠️ **Route Handler = "purana tareeka" nahi.** Ye fundamental hai — har web developer ko aana chahiye. REST API universal hai, sirf Next.js mein nahi.

⚠️ **Decision = "hamesha ek hi choose karo" nahi.** Dono ek saath use kar sakte hain — har jagah choose nahi karna.
