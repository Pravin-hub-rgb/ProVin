3.4.5 mein GET route banaya — ab saare reviews dikh rahe hain. Par abhi sirf **list page** hai — agar kisi review ka detail dekhna ho toh koi jagah nahi hai. Ab **detail page** banayenge — `/reviews/[id]`.

---

## SOCH: Detail Page Kyun Chahiye?

List page pe 4 reviews dikh rahe hain — har ek chhota sa card hai. Par agar kisi review ka **poora text** padhna ho, ya **edit/delete** karna ho — toh us review pe click karke uska detail page khule. Zomato socho — restaurant list mein sab restaurants dikh rahe hain, par kisi pe click karo toh uska poora menu, ratings, reviews dikhte hain.

Wahi yahan — list pe click → detail page.

---

## Step 1: GET Single Route

Pehle route banayenge — jo ek review ka data de.

```tsx
// app/api/reviews/[id]/route.ts
import { NextResponse } from "next/server";
import { getReviewById } from "@/lib/reviews";

export async function GET(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const review = getReviewById(Number(id));

  if (!review) {
    return NextResponse.json(
      { error: "Review nahi mila" },
      { status: 404 }
    );
  }

  return NextResponse.json(review);
}
```

**Line by line:**

1. **`[id]/route.ts`** — dynamic route hai. `[id]` ka matlab URL mein koi bhi number aa sakta hai — `/api/reviews/1`, `/api/reviews/2`, etc.

2. **`{ params }: { params: Promise<{ id: string }> }`** — ye Next.js 15 pattern hai. `params` ek promise hai — `await` karna padta hai. `id` string aata hai (URL se), isliye `Number(id)` se convert karte hain.

3. **`getReviewById(Number(id))`** — data layer se ek review dhoondo.

4. **Agar nahi mila** — 404 status + error message.

5. **Agar mila** — JSON response mein review bhejo.

## Step 2: Detail Page Banayo

Ab page banayenge — `/reviews/[id]/page.tsx`. Ye **Server Component** hai — seedha data layer se data lega.

```tsx
// app/reviews/[id]/page.tsx
import { getReviewById } from "@/lib/reviews";
import { notFound } from "next/navigation";
import Link from "next/link";

export default async function ReviewPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const review = getReviewById(Number(id));

  if (!review) {
    notFound();
  }

  return (
    <div className="max-w-md mx-auto p-4 border rounded bg-white">
      <Link href="/reviews" className="text-blue-500 hover:underline text-sm mb-4 block">
        ← Wapas List pe
      </Link>

      <div className="flex justify-between items-center mb-3">
        <span className="text-2xl">{"⭐".repeat(review.rating)}</span>
        <span className="text-sm text-gray-500">{review.createdAt}</span>
      </div>

      <p className="text-lg mb-4">{review.text}</p>

      <div className="border-t pt-3 text-sm text-gray-500">
        Review ID: {review.id} | Product: {review.productId}
      </div>
    </div>
  );
}
```

**Line by step:**

1. **`async function`** — Server Component hai, isliye `async` use kar sakte hain. `await params` directly.

2. **`getReviewById(Number(id))`** — data layer se seedha call. `fs` module directly kaam karta hai — kyunki server pe chal raha hai.

3. **`notFound()`** — agar review nahi mila toh Next.js ka 404 page dikhao. `next/navigation` se import hota hai.

4. **`Link href="/reviews"`** — wapas list page pe jaane ka link.

5. **Stars + text + date** — wahi same pattern jo list page mein tha.

## Step 3: List Page Mein Link Add Karo

Ab list page mein har review pe link hona chahiye — click karke detail page khule.

**ReviewListServer** update karo:

```tsx
// app/components/ReviewListServer.tsx
import Link from "next/link";
import { getReviewsByProduct } from "@/lib/reviews";

export function ReviewListServer({ productId }: { productId: number }) {
  const reviews = getReviewsByProduct(productId);

  if (reviews.length === 0) {
    return <p className="text-gray-500">Abhi koi review nahi hai.</p>;
  }

  return (
    <div className="space-y-2">
      <h3 className="font-bold">Reviews ({reviews.length})</h3>
      {reviews.map((review) => (
        <div key={review.id} className="border p-2 rounded bg-white">
          <div className="flex justify-between items-center mb-1">
            <span>{"⭐".repeat(review.rating)}</span>
            <span className="text-sm text-gray-500">{review.createdAt}</span>
          </div>
          <p className="text-gray-700">{review.text}</p>
          <Link
            href={`/reviews/${review.id}`}
            className="text-blue-500 hover:underline text-sm mt-2 block"
          >
            View Detail →
          </Link>
        </div>
      ))}
    </div>
  );
}
```

**Kya badla?** Sirf ek cheez — `Link` add hua. `href={`/reviews/${review.id}`}` — dynamic URL. Agar `review.id = 1` hai toh `/reviews/1` pe le jaayega.

## Dynamic Route `[id]` Kya Hai?

3.1 mein seekha tha — `[id]` matlab URL mein koi bhi value aa sakti hai:

```
/reviews/1    → id = "1"   → review 1 dikhega
/reviews/2    → id = "2"   → review 2 dikhega
/reviews/999  → id = "999" → review nahi mila → 404
```

Next.js automatically `params` mein ye `id` de deta hai. Humein sirf use karna hai.

---

## Common Mistakes

1. **`params` ka type** — Next.js 15 mein `params` ek **promise** hai: `{ params: Promise<{ id: string }> }`. `await` mat bhoolo.
2. **`Number(id)` mat bhoolo** — URL se string aata hai. Data layer mein number chahiye — `Number()` se convert karo.
3. **`notFound()` mat bhoolo** — Agar review nahi mila toh 404 dikhao. Bina check ke render karoge toh error aayega.
4. **`Link` mat bhoolo** — List page mein "View Detail →" link hona chahiye — bina link ke user detail page nahi pahunch payega.

## Problem Jo Abhi Hai

1. **Naya review add nahi ho sakta** — koi form nahi hai.
2. **Edit nahi hai** — existing review badal nahi sakte.
3. **Delete nahi hai** — review hata nahi sakte.

Sabse pehle **form** banayenge — naya review add karne ke liye. Uske liye:
- Pehle **form UI** (does nothing — sirf dikhta hai)
- Phir **POST route** banayenge
- Phir **axios** se connect karenge
