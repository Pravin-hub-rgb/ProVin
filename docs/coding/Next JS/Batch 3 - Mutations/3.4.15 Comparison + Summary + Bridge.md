## Route Handler vs Server Actions — Final Comparison

| Feature | Route Handler (v1) | Server Actions (v2) |
|---------|-------------------|-------------------|
| Route files | 2 files (`/api/reviews/route.ts`, `/api/reviews/[id]/route.ts`) | 0 files (`actions.ts` mein functions) |
| Client fetch | `axios.post()` — manual call | `action={function}` — automatic |
| Pending state | `useState` manually | `isPending` from `useActionState` |
| Error handling | `try/catch` + `useState` | Return value (`success` + `message`) |
| Page refresh | `window.location.reload()` | `revalidatePath` in action |
| Boilerplate | Zyada — 5 cheezein manually | Kam — 3 cheezein automatic |
| External clients | Support karta hai | Nahi |
| Debugging | Network tab mein dikhta hai | Server pe hota hai |

## Kab Kya Use Karein?

### Route Handler — Tab jab:
- **External client hai** — mobile app, third-party website
- **API share karni hai** — doosra project bhi data chahiye
- **Complex operations hain** — multiple steps, background processing
- **Debugging chahiye** — network tab mein sab dikhta hai

### Server Actions — Tab jab:
- **Sirf Next.js app hai** — external client nahi
- **Simple form submissions hain** — add, edit, delete
- **Kam code chahiye** — boilerplate avoid karna hai
- **Quick iteration chahiye** — jaldi banao, jaldi badlo

## Key Concepts Recap

| Concept | Kya Seekha | Kab Use Hota Hai |
|---------|-----------|-----------------|
| Route Handler | API endpoint banana | GET, POST, PUT, DELETE |
| Server Action | Form → server function | Simple CRUD |
| axios | HTTP client | Client se server ko call |
| `fs` module | File read/write | JSON file storage |
| Dynamic route `[id]` | URL parameter | `/reviews/1`, `/reviews/2` |
| `useActionState` | Pending + messages | Forms mein |
| `revalidatePath` | Auto refresh | Data change ke baad |
| Server Component | Direct data layer call | Read-only pages |
| Client Component | Interactive UI | Forms, buttons, state |
| Hidden input | User ko dikhaye bina data | Server action ko ID bhejna |
| `defaultValue` | Uncontrolled form field | Server Actions mein better |

## Common Mistakes — Final Checklist

- Route Handler mein method name galat? Function name HTTP method se match hona chahiye
- Server Action mein `"use server"` bhoola? Bina iske function client pe chalega — error
- `params` await nahi kiya? Next.js 15 mein params promise hai — await zaroori
- Validation sirf client pe? Server pe hamesha check karo — client bypass ho sakta hai
- `revalidatePath` bhoola? Naya data nahi dikhega — purana cache dikhega
- `key` nahi di map mein? React warning aayega — hamesha key do
- Loading state nahi hai? Flicker hoga — pehle empty, phir data
- `useActionState` `react-dom` se import kiya? Galat hai — `react` se import karo (React 19)
- `action={addReviewAction}` lagaya seedha? Galat hai — `formAction` use karo

1. **Route Handler aur Server Actions mein se tum kya choose karoge? Kyun?**
   <details><summary>Sample Answer</summary>Agar sirf Next.js app hai toh Server Actions — kam code, boilerplate nahi. Agar API share karni hai ya external client hai toh Route Handler. Dono ka apna jagah hai.</summary></details>

2. **Server Components aur Client Components mein kya fark hai?**
   <details><summary>Sample Answer</summary>Server Components server pe render hota hai — data direct milega, `useState` nahi chahiye. Client Components browser pe chalte hain — interactive hai, `useState` + `useEffect` chahiye.</summary></details>

3. **Data layer function `getAllReviews()` mein `readFileSync` kyun hai?**
   <details><summary>Sample Answer</summary>Har baar fresh data padhna hota hai — agar kisi ne naya review add kiya ho toh wo dikhe. Agar `readFileSync` na ho toh purana cache dikhega.</summary></details>

4. **Ye project agar database lagana ho toh kya badlega?**
   <details><summary>Sample Answer</summary>Sirf `lib/reviews.ts` ka andar badlega — `readFileSync` hata ke Prisma/Mongoose lagao. Baaki sab same rahega — page, form, routes — kuch nahi badlega. Yahi abstraction ka fayda hai.</summary></details>

5. **Server Actions external clients ke liye kyun nahi hain?**
   <details><summary>Sample Answer</summary>Server Actions Next.js specific hain — sirf Next.js app se call ho sakte hain. External clients (mobile app, Python) sirf HTTP requests bhej sakte hain — isliye route handler chahiye.</summary></details>
