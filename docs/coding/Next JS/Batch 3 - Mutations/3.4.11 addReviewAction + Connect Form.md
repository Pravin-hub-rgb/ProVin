3.4.10 mein form UI banaya — par submit kuch nahi karta. Ab **addReviewAction** banayenge aur form se connect karenge.

---

## SOCH: Action Kya Hai?

Route Handler mein kya hota hai:
1. Client `axios.post("/api/reviews", data)` call karta hai
2. Server pe `POST()` function data leta hai
3. Response wapas jaata hai

Server Action mein ye sab **same hai** — par ek step kam:
1. Form `action={addReviewAction}` lagao
2. Server pe function data leta hai
3. Response wapas jaata hai

**Axios, fetch, route file — teeno gayab.** Sirf function hai.

## Step 1: addReviewAction Banayo

```tsx
// app/actions.ts
"use server";

import { addReview } from "@/lib/reviews";
import { revalidatePath } from "next/cache";

export type FormState = {
  success: boolean;
  message: string;
};

export async function addReviewAction(
  prevState: FormState,
  formData: FormData
): Promise<FormState> {
  const text = formData.get("text") as string;
  const rating = Number(formData.get("rating"));
  const productId = Number(formData.get("productId"));

  // Validation
  if (!text) {
    return { success: false, message: "Review text zaroori hai!" };
  }

  if (!rating || rating < 1 || rating > 5) {
    return { success: false, message: "Rating 1 se 5 honi chahiye!" };
  }

  // Data layer call
  addReview({ productId, text, rating });

  // Page refresh
  revalidatePath("/reviews");

  return { success: true, message: "Review add ho gaya!" };
}
```

**Line by line:**

1. **`"use server"`** — ye file server actions hai. Sab functions server pe chalenge. Client pe sirf call ho sakte hain, execute nahi.

2. **`import { revalidatePath } from "next/cache"`** — Next.js ka function — data change ho toh page dobara render karo.

3. **`FormState` type** — return type define karta hai: `success` boolean + `message` string. Client ko pata chale kya hua.

4. **`prevState: FormState`** — `useActionState` ka pehla param — purana state. Abhi use nahi karenge (agla step mein aayega), par type signature mein chahiye.

5. **`formData: FormData`** — form se data aata hai. `formData.get("text")` se text milega — **`name` attribute se match hota hai.**

6. **Validation** — empty text ya galat rating ho toh error return.

7. **`addReview({ productId, text, rating })`** — data layer ka function — reviews.json mein save karega.

8. **`revalidatePath("/reviews")`** — Next.js ko bolta hai ki "/reviews" page ka data purana ho gaya hai, dobara render karo. Isliye naya review dikh jaata hai bina page reload ke.

9. **Return** — `success: true` + message.

## Step 2: Form Se Connect Karo

Ab form mein `console.log` hata ke `action` lagao.

```tsx
// app/components/ReviewFormServer.tsx
"use client";

import { addReviewAction, FormState } from "../actions";

const initialState: FormState = {
  success: false,
  message: "",
};

export function ReviewFormServer({ productId }: { productId: number }) {
  return (
    <form action={addReviewAction} className="space-y-3 border p-4 rounded bg-white mt-4">
      <h3 className="font-bold">Naya Review Likho</h3>

      <input type="hidden" name="productId" value={productId} />

      <div>
        <label className="block text-sm font-medium mb-1">Rating:</label>
        <select name="rating" defaultValue={5} className="border p-2 rounded w-full">
          {[1, 2, 3, 4, 5].map((n) => (
            <option key={n} value={n}>
              {"⭐".repeat(n)}
            </option>
          ))}
        </select>
      </div>

      <div>
        <label className="block text-sm font-medium mb-1">Review:</label>
        <textarea
          name="text"
          placeholder="Apna review likho..."
          className="w-full border p-2 rounded"
          rows={3}
        />
      </div>

      <button
        type="submit"
        className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
      >
        Submit Review
      </button>
    </form>
  );
}
```

**Kya badla?**

1. **`import { addReviewAction, FormState }`** — action import hua
2. **`initialState`** — abhi use nahi ho raha, par type signature mein chahiye (agla step mein aayega)
3. **`action={addReviewAction}`** — `onSubmit` ki jagah `action`! Form submit hone pe `addReviewAction` automatically call hoga.

**Notice kiya?** Koi `useState` nahi, koi `axios` nahi, koi `try/catch` nahi — sirf `action={addReviewAction}`.

## Kya Hua — Behind the Scenes?

```
User "Submit Review" click karta hai
    ↓
Form ka action trigger hota hai — addReviewAction call hota hai
    ↓
Server pe: formData.get("text") → text mila
Server pe: formData.get("rating") → rating mila
Server pe: formData.get("productId") → productId mila
    ↓
addReview({ productId, text, rating }) → reviews.json mein save
    ↓
revalidatePath("/reviews") → page dobara render
    ↓
User ko updated page dikhta hai — naya review saath mein
```

**Dekho — ye Route Handler se** **same kaam hai** — par code almost half hai. Koi `axios.post()` nahi, koi `try/catch` nahi, koi `window.location.reload()` nahi.

## Route Handler vs Server Action — Abhi Ka Comparison

| Route Handler (3.4.7) | Server Action (ye) |
|----------------------|-------------------|
| `onSubmit={handleSubmit}` | `action={addReviewAction}` |
| `const res = await axios.post(...)` | Sirf function name |
| `setText("")` + `setRating(5)` | Nahi chahiye (form reset nahi hua abhi) |
| `window.location.reload()` | `revalidatePath` — automatic |
| 10+ lines handler code | 0 lines — action function alag hai |

**Ek cheez missing hai** — pending state aur messages. Abhi form submit hone pe kuch dikhta nahi — loading nahi, success message nahi. Agla step mein `useActionState` se ye dono add karenge.

## Common Mistakes

1. **`"use server"` mat bhoolo** — bina iske function client pe chalega — error aayega.
2. **`name` attribute mat bhoolo** — `formData.get("text")` tab kaam karega jab form field ka `name="text"` ho.
3. **`revalidatePath` mat bhoolo** — bina iske naya data nahi dikhega — purana cache dikhega.
4. **`prevState` param mat bhoolo** — `useActionState` ka pehla param hota hai — abhi use nahi kar rahe, par type signature mein chahiye.

## Agle Step Mein Kya Hoga?

Ab **`useActionState`** lagayenge — pending state aur messages add karenge. Submit karne pe "Adding..." dikhega, success pe green message, error pe red message. Ye sab built-in milega — manually `useState` nahi chahiye.
