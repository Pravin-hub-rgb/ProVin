## SOCH: Delete Ka Pattern Same Hai

Add form mein kya kiya:
1. `addReviewAction` banaya — data layer call + revalidatePath
2. Form mein `action={formAction}` lagaya
3. `useActionState` se pending + messages

Delete mein **wahi same** — sirf function alag hai (`deleteReviewAction`) aur hidden input mein `reviewId` hoga.

---

## Step 1: deleteReviewAction Banayo

```tsx
// app/actions.ts (mein addReviewAction ke baad add karo)

export async function deleteReviewAction(
  prevState: FormState,
  formData: FormData
): Promise<FormState> {
  const id = Number(formData.get("id"));

  const deleted = deleteReview(id);

  if (!deleted) {
    return { success: false, message: "Review nahi mila!" };
  }

  revalidatePath("/reviews");
  return { success: true, message: "Review delete ho gaya!" };
}
```

**Same pattern — 3 steps:**
1. FormData se `id` nikalo (`formData.get("id")`)
2. `deleteReview(id)` call karo
3. Result return karo + `revalidatePath`

## Step 2: DeleteButton Component Banayo

```tsx
// app/components/DeleteButtonServer.tsx
"use client";

import { useEffect, useActionState } from "react";
import { deleteReviewAction, FormState } from "../actions";

const initialState: FormState = {
  success: false,
  message: "",
};

export function DeleteButtonServer({ reviewId }: { reviewId: number }) {
  const [state, formAction, isPending] = useActionState(
    deleteReviewAction,
    initialState
  );

  useEffect(() => {
    if (state.message) {
      console.log(state.message);
    }
  }, [state]);

  return (
    <form action={formAction}>
      <input type="hidden" name="id" value={reviewId} />
      <button
        type="submit"
        disabled={isPending}
        className="text-red-500 hover:text-red-700 text-sm disabled:text-gray-400"
      >
        {isPending ? "Deleting..." : "Delete"}
      </button>
    </form>
  );
}
```

**Notice kiya?** ReviewForm aur DeleteButton **same pattern hai:**
- Dono mein `action={formAction}` hai
- Dono mein `useActionState` se state + isPending aata hai
- Dono mein hidden input hai

Fark sirf: ReviewForm mein `name="text"` + `name="rating"`, DeleteButton mein `name="id"`.

## Step 3: ReviewListServer Mein Lagao

Ab review list mein har review ke neeche delete button lagao.

```tsx
// app/components/ReviewListServer.tsx
import Link from "next/link";
import { getReviewsByProduct } from "@/lib/reviews";
import { DeleteButtonServer } from "./DeleteButtonServer";

export function ReviewListServer({ productId }: { productId: number }) {
  const reviews = getReviewsByProduct(productId);

  if (reviews.length === 0) {
    return <p className="text-gray-500">Abhi koi review nahi hai.</p>;
  }

  return (
    <div className="space-y-2">
      <h3 className="font-bold">Reviews ({reviews.length})</h3>
      {reviews.map((review) => (
        <div key={review.id} className="border p-2 rounded bg-white">
          <div className="flex justify-between items-center mb-1">
            <span>{"⭐".repeat(review.rating)}</span>
            <span className="text-sm text-gray-500">{review.createdAt}</span>
          </div>
          <p className="text-gray-700">{review.text}</p>
          <div className="flex items-center gap-4 mt-2">
            <Link
              href={`/reviews/${review.id}`}
              className="text-blue-500 hover:underline text-sm"
            >
              View Detail
            </Link>
            <DeleteButtonServer reviewId={review.id} />
          </div>
        </div>
      ))}
    </div>
  );
}
```

**Kya badla?** Sirf ek cheez — `DeleteButtonServer` import hua aur har review ke neeche lag gaya.

## Route Handler Delete vs Server Action Delete

| Route Handler (3.4.8) | Server Action (ye) |
|----------------------|-------------------|
| `onClick={handleDelete}` | `action={formAction}` |
| `window.confirm()` | Abhi nahi hai (agla step) |
| `axios.delete(url)` | Sirf hidden input + action |
| `useState(false)` for pending | `isPending` from `useActionState` |
| `try/catch` | Automatic |
| 15+ lines | 10 lines |

## Common Mistakes

1. **Hidden input ka `name="id"`** — `formData.get("id")` se review ID milega. Galat `name` ho toh `null` aayega.
2. **Delete button form ke andar hai** — `DeleteButtonServer` ka pura component ek `<form>` hai. Ye normal hai — server action form se data leta hai.
3. **Confirm popup nahi hai** — Abhi seedha delete ho jaayega. Agla step mein `window.confirm()` add karenge.
