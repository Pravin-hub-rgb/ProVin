3.4.2 mein UI banaya — 4 hardcoded reviews the page ke andar. Par problem thi: **data do jagah hai** aur **naya review add nahi ho sakta**. Ab data layer banayenge — data ek jagah rahega, functions se manage hoga.

---

## Data Layer Kya Hai?

Socho tum ek library mein ho. Kitabein alag shelf pe hain (data), par tum seedha shelf pe jaake kitab nahi uthate — librarian se bolte ho "mujhe ye kitab chahiye" (function). Librarian jaake kitab laata hai.

Data layer wahi **librarian** hai — page ko pata nahi hota ki data kahan hai (array, file, database), page sirf function call karta hai. Aage jab data source badlega (JSON → database), page ka code nahi badlega — sirf function ka andar badlega.

## Step 2: Review Type

Ab `lib/reviews.ts` banao. Sabse pehle **type** define karo — data ka shape.

```tsx
// lib/reviews.ts
export type Review = {
  id: number;
  productId: number;
  text: string;
  rating: number;
  createdAt: string;
};
```

**`type` kyun?** TypeScript ka contract hai — ye fix karta hai ki har review mein ye 5 fields honge. Agar koi field miss ho jaaye toh compiler error aayega. 3.4.1 mein detail mein explain kiya tha.

**`export` kyun?** Taaki baaki files is type ko import kar sakein — `import { Review } from "@/lib/reviews"`.

## Step 3: File Path — Data Kahan Hai?

```tsx
// lib/reviews.ts (mein add karo type ke baad)
import { readFileSync, writeFileSync } from "fs";
import path from "path";

const filePath = path.join(process.cwd(), "app", "lib", "reviews.json");
```

**`fs` module kya hai?** Node.js ka built-in module hai — file system se kaam karta hai. `readFileSync` se file padho, `writeFileSync` se file likho.

**`path.join()` kyun?** File ka complete path banana hota hai. `"app/lib/reviews.json"` hardcode mat karo — `path.join` se cross-platform kaam karega (Windows/Linux/Mac).

**`process.cwd()` kya hai?** Current working directory — project ka root folder. Ye dynamic hai — kahi bhi run karo, sahi path milega.

## Step 4: `getAllReviews()` — Saare Reviews Lao

```tsx
// lib/reviews.ts
export function getAllReviews(): Review[] {
  const data = readFileSync(filePath, "utf-8");
  return JSON.parse(data);
}
```

**Step by step:**
1. `readFileSync(filePath, "utf-8")` — file se raw string padho
2. `JSON.parse(data)` — string ko JavaScript array mein convert karo
3. Return karo — `Review[]` type (array of reviews)

**Return type `Review[]` kyun?** TypeScript ko pata chale ki ye array hai aur har element `Review` type ka hai. Agar galat data aaye toh compiler pakad lega.

---

## Step 5: `getReviewsByProduct()` — Ek Product Ke Reviews

```tsx
// lib/reviews.ts
export function getReviewsByProduct(productId: number): Review[] {
  return getAllReviews().filter((r) => r.productId === productId);
}
```

**`filter()` yaad hai?** Array mein se saare matching elements dhoondhta hai. `getAllReviews()` se saare reviews aaye, phir `filter((r) => r.productId === productId)` se sirf us product ke reviews aaye.

**Notice kiya?** `getAllReviews()` call ho raha hai — same function, repeat use. Abhi ye `readFileSync` se padh raha hai. Agar aage database lagao toh sirf `getAllReviews()` ka andar badlega — `getReviewsByProduct()` ka code nahi badlega. **Yahi abstraction ka fayda hai.**

## Step 6: `addReview()` — Naya Review Add Karo

```tsx
// lib/reviews.ts
export function addReview(data: Omit<Review, "id" | "createdAt">): Review | null {
  if (!data.text || !data.text.trim()) return null;
  if (!data.rating || data.rating < 1 || data.rating > 5) return null;

  const reviews = getAllReviews();
  const newReview: Review = {
    ...data,
    text: data.text.trim(),
    id: reviews.length + 1,
    createdAt: new Date().toISOString().split("T")[0],
  };
  reviews.push(newReview);
  writeFileSync(filePath, JSON.stringify(reviews, null, 2));
  return newReview;
}
```

**`Omit<Review, "id" | "createdAt">` kya hai?** TypeScript utility type — ye bolta hai "Review type jaisa ho, par `id` aur `createdAt` chhod do." Kyunki ye dono function khud generate karega — user ko ye nahi dena padega.

**Function kya kar raha hai — 4 steps:**
1. **Validation** — empty text ya galat rating ho toh `null` return
2. **Seed data se padho** — `getAllReviews()` se saare reviews
3. **Naya review banao** — `id` (length + 1), `createdAt` (aaj ki date)
4. **File mein likho** — `writeFileSync` se save karo

**`JSON.stringify(reviews, null, 2)` — `null, 2` kyun?** Pretty print — file mein indent ho, ek line mein na aaye. Padhne mein easy hota hai.

## Step 7: `updateReview()` — Review Edit Karo

```tsx
// lib/reviews.ts
export function updateReview(
  id: number,
  data: { text: string; rating: number }
): Review | null {
  const reviews = getAllReviews();
  const index = reviews.findIndex((r) => r.id === id);

  if (index === -1) return null;

  const updated: Review = { ...reviews[index], ...data, text: data.text.trim() };
  reviews[index] = updated;
  writeFileSync(filePath, JSON.stringify(reviews, null, 2));
  return updated;
}
```

**`findIndex()` kya hai?** Array mein se pehla matching element ka **index** dhoondhta hai. `find()` element return karta hai, `findIndex()` position return karta hai.

**`-1` ka matlab?** Agar `findIndex` ko element nahi mila toh `-1` return hota hai. Iska matlab "review nahi mila" — isliye `null` return.

**`{ ...reviews[index], ...data }` — spread kya hai?** Purane review ki saari properties copy hoti hain (`id`, `productId`, `createdAt`), phir `data` ki nayi (`text`, `rating`) overwrite hoti hain. **`id` aur `createdAt` safe rehte hain** kyunki `data` mein woh nahi hain.

## Step 8: `deleteReview()` — Review Delete Karo

```tsx
// lib/reviews.ts
export function deleteReview(id: number): boolean {
  const reviews = getAllReviews();
  const index = reviews.findIndex((r) => r.id === id);

  if (index === -1) return false;

  reviews.splice(index, 1);
  writeFileSync(filePath, JSON.stringify(reviews, null, 2));
  return true;
}
```

**`splice(index, 1)` kya hai?** Array se ek element hataata hai — `index` position se, `1` element. `splice(2, 1)` — 3rd element hata dega.

**`true/false` return kyun?** `true` = delete ho gaya, `false` = review nahi mila. Caller ko pata chale ki kya hua.

## Poora Data Layer — Ek Saath

```tsx
// lib/reviews.ts
import { readFileSync, writeFileSync } from "fs";
import path from "path";

const filePath = path.join(process.cwd(), "app", "lib", "reviews.json");

export type Review = {
  id: number;
  productId: number;
  text: string;
  rating: number;
  createdAt: string;
};

export function getAllReviews(): Review[] {
  const data = readFileSync(filePath, "utf-8");
  return JSON.parse(data);
}

export function getReviewsByProduct(productId: number): Review[] {
  return getAllReviews().filter((r) => r.productId === productId);
}

export function addReview(data: Omit<Review, "id" | "createdAt">): Review | null {

    createdAt: new Date().toISOString().split("T")[0],
  };
  reviews.push(newReview);
  writeFileSync(filePath, JSON.stringify(reviews, null, 2));
  return newReview;
}

export function updateReview(
  id: number,
  data: { text: string; rating: number }
): Review | null {
  const reviews = getAllReviews();
  const index = reviews.findIndex((r) => r.id === id);

  if (index === -1) return null;

  const updated: Review = { ...reviews[index], ...data, text: data.text.trim() };
  reviews[index] = updated;
  writeFileSync(filePath, JSON.stringify(reviews, null, 2));
  return updated;
}

export function deleteReview(id: number): boolean {

  const index = reviews.findIndex((r) => r.id === id);

  reviews.splice(index, 1);

  return true;
}
```

## Common Mistakes

1. **`readFileSync` galat path pe** — `process.cwd()` se project root milta hai. Agar path galat hai toh `ENOENT` error aayega. File ka path `app/lib/reviews.json` hona chahiye.
2. **Validation na karo** — `addReview` mein empty text ya galat rating check karo. Nahi toh galat data save ho jaayega.
3. **`findIndex` vs `find` confuse** — `find` element return karta hai, `findIndex` index. Delete/update mein index chahiye — isliye `findIndex`.
4. **File baad mein save karo** — Pehle changes karo, phir `writeFileSync`. Agar pehle save kar diya toh purana data ud jaayega.

## Problem Jo Abhi Hai

Abhi data layer hai, par page ko pata nahi ki data kahan se aata hai. Page abhi bhi hardcoded array use kar raha hai. Agla step — **page ko data layer se jodna** — `getAllReviews()` call karke data dikhana.

Aur sabse pehla kaam — **axios install karna**. Ab tak `fetch()` use kiya tha (3.1-3.3). Ab se axios use karenge — zyada concise hai, kam code likhna padta hai. 3.4.1 mein bataya tha — ab practice karenge.
