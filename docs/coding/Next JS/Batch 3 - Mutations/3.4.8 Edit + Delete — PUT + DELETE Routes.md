# Edit + Delete — PUT + DELETE Routes (3.4.8)

## Where We Left Off

In 3.4.7, we built the create flow — a form that POSTs to the API and shows pending states and error messages. Now we need **edit** and **delete** functionality. Let's start with delete since it's simpler.

## Understanding the Pattern

Every mutation follows the same flow:
1. User clicks a button (edit, delete, save)
2. Client calls the API with axios
3. API calls the data layer to modify data
4. Client updates the UI

Delete and edit follow the exact same pattern — just different methods (DELETE vs PUT) and different data.

---

## Delete Flow

### Step 1: DELETE Route

Create the DELETE handler in the dynamic route:

```tsx
// app/api/reviews/[id]/route.ts — add DELETE
import { NextResponse } from "next/server";
import { getReviewById, deleteReview, updateReview } from "@/lib/reviews";

export async function GET(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const review = getReviewById(Number(id));

  if (!review) {
    return NextResponse.json({ error: "Review not found" }, { status: 404 });
  }
  return NextResponse.json(review);
}

export async function DELETE(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const deleted = deleteReview(Number(id));

  if (!deleted) {
    return NextResponse.json({ error: "Review not found" }, { status: 404 });
  }

  return NextResponse.json({ message: "Review deleted successfully" });
}
```

### Step 2: Delete Button Component

```tsx
// app/components/DeleteButton.tsx
"use client";

import axios from "axios";

export function DeleteButton({ reviewId }: { reviewId: number }) {
  const handleDelete = async () => {
    if (!confirm("Are you sure you want to delete this review?")) return;

    try {
      await axios.delete(`/api/reviews/${reviewId}`);
      window.location.reload();
    } catch (err) {
      console.error("Delete failed:", err);
    }
  };

  return (
    <button
      onClick={handleDelete}
      className="text-red-500 hover:text-red-700 text-sm font-medium"
    >
      Delete
    </button>
  );
}
```

### Step 3: Add DeleteButton to Detail Page

```tsx
// app/reviews/[id]/page.tsx
import { DeleteButton } from "../../components/DeleteButton";

// ... inside the component, after the review text:
<DeleteButton reviewId={review.id} />
```

### How DELETE Works

- `DELETE /api/reviews/3` — The `3` comes from the URL
- No request body — DELETE just needs the ID from the URL
- The route reads `params.id`, calls `deleteReview()`, returns a success message
- The button confirms, calls axios.delete, then reloads

## Edit Flow

### Step 1: PUT Route

```tsx
// app/api/reviews/[id]/route.ts — add PUT
export async function PUT(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const body = await request.json();

  if (!body.text || !body.rating) {
    return NextResponse.json(
      { error: "text and rating are required" },
      { status: 400 }
    );
  }

  const updated = updateReview(Number(id), {
    text: body.text,
    rating: Number(body.rating),
  });

  if (!updated) {
    return NextResponse.json({ error: "Review not found" }, { status: 404 });
  }

  return NextResponse.json(updated);
}
```

### Step 2: Detail Page with Edit Form

The detail page needs to switch between view mode and edit mode:

```tsx
// app/reviews/[id]/page.tsx
"use client";

import axios from "axios";
import { useEffect, useState } from "react";
import Link from "next/link";
import { DeleteButton } from "../../components/DeleteButton";

type Review = {
  id: number;
  productId: number;
  text: string;
  rating: number;
  createdAt: string;
};

export default function ReviewPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const [review, setReview] = useState<Review | null>(null);
  const [editing, setEditing] = useState(false);
  const [editText, setEditText] = useState("");
  const [editRating, setEditRating] = useState(5);

  useEffect(() => {
    const load = async () => {
      const { id } = await params;
      const res = await axios.get(`/api/reviews/${id}`);
      setReview(res.data);
      setEditText(res.data.text);
      setEditRating(res.data.rating);
    };
    load();
  }, [params]);

  if (!review) return <p>Loading...</p>;

  const handleUpdate = async (e: React.FormEvent) => {
    e.preventDefault();

    try {
      const res = await axios.put(`/api/reviews/${review.id}`, {
        text: editText,
        rating: editRating,
      });
      setReview(res.data);
      setEditing(false);
    } catch (err) {
      console.error("Update failed:", err);
    }
  };

  return (
    <div className="max-w-md mx-auto p-4 border rounded bg-white">
      <Link href="/reviews" className="text-blue-500 text-sm mb-4 block">
        ← Back to Reviews
      </Link>

      {editing ? (
        <form onSubmit={handleUpdate} className="space-y-3">
          <div>
            <label className="block text-sm mb-1">Rating:</label>
            <select
              value={editRating}
              onChange={(e) => setEditRating(Number(e.target.value))}
              className="border p-2 rounded w-full"
            >
              {[1, 2, 3, 4, 5].map((n) => (
                <option key={n} value={n}>{"⭐".repeat(n)}</option>
              ))}
            </select>
          </div>

          <div>
            <label className="block text-sm mb-1">Review:</label>
            <textarea
              value={editText}
              onChange={(e) => setEditText(e.target.value)}
              className="w-full border p-2 rounded"
              rows={3}
            />
          </div>

          <div className="flex gap-2">
            <button type="submit" className="bg-green-500 text-white px-4 py-2 rounded">
              Save
            </button>
            <button
              type="button"
              onClick={() => setEditing(false)}
              className="text-gray-500 px-4 py-2"
            >
              Cancel
            </button>
          </div>
        </form>
      ) : (
        <>
          <div className="flex justify-between items-center mb-3">
            <span className="text-2xl">{"⭐".repeat(review.rating)}</span>
            <span className="text-sm text-gray-500">{review.createdAt}</span>
          </div>
          <p className="text-lg mb-4">{review.text}</p>
          <div className="flex gap-4">
            <button
              onClick={() => setEditing(true)}
              className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
            >
              Edit
            </button>
            <DeleteButton reviewId={review.id} />
          </div>
        </>
      )}
    </div>
  );
}
```

### What Changed

- **Client Component** — needs `useState` and `useEffect` for interactivity
- **View vs Edit modes** — `editing` state toggles between display and form
- **Prefill** — `setEditText(review.text)` and `setEditRating(review.rating)` fill the form with existing values
- **PUT request** — `axios.put()` sends the updated text and rating

## CRUD Complete — Route Handler Version

All four operations work via Route Handlers + axios:

```
Operation   Route                    Method   Data Source
─────────────────────────────────────────────────────────────
Read all    /api/reviews             GET      ?productId=1
Read one    /api/reviews/{id}        GET      URL param
Create      /api/reviews             POST     Request body
Update      /api/reviews/{id}        PUT      Request body
Delete      /api/reviews/{id}        DELETE   URL param
```

The full Route Handler version is complete. We have:
- GET routes (list + single)
- POST route (create)
- PUT route (update)
- DELETE route (delete)
- Client components fetching with axios
- Manual state management for every operation

**That's a lot of boilerplate** — and this is where Server Actions make a dramatic difference. Let's see that next.

## Common Mistakes

- **DELETE body** — DELETE typically has no body. The ID comes from the URL via `params`, not `request.json()`.
- **PUT validation** — Same validation as POST. Don't forget to validate on the server.
- **`confirm()` for delete** — Always confirm destructive actions. Users make mistakes.
- **`window.location.reload()`** — Simple but slow. Server Actions solve this with `revalidatePath`.

## In Your Own Words

<details>
<summary>Question 1: Why does the detail page become a Client Component for editing?</summary>
<p><strong>answer:</strong> Editing requires interactive state: `editing` toggle, `editText`, `editRating` — these need `useState`. The form's `handleSubmit` calls `axios.put()` asynchronously. Click handlers (`onClick`) only work in Client Components.</p>
</details>

<details>
<summary>Question 2: What's the difference between PUT and DELETE in terms of what they send?</summary>
<p><strong>Answer:</strong> PUT sends updated data in the request body — you're replacing the resource. DELETE sends nothing in the body — it just needs the ID from the URL. PUT's body contains `text` and `rating`; DELETE needs only `id` from the URL path.</p>
</details>

<details>
<summary>Question 3: Why do we prefill the form with `setEditText` and `setEditRating`?</summary>
<p><strong>Answer:</strong> The user is editing an existing review. They need to see the current text and rating so they can make targeted changes. If the form started empty, they'd lose context of what they're editing.</p>
</details>

<details>
<summary>Question 4: Why does PUT return the updated review in the response?</summary>
<p><strong>Answer:</strong> The response contains the updated data so the client can immediately reflect changes without a separate fetch. `setReview(res.data)` updates the UI instantly. Without this, you'd need a separate GET to see the updated review.</p>
</details>
