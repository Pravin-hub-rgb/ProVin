### Step 2: DELETE Route Banayo

```tsx
// app/api/reviews/[id]/route.ts (mein GET ke baad add karo)
import { NextResponse } from "next/server";
import { getReviewById, deleteReview } from "@/lib/reviews";

// ... GET function jo pehle tha ...

export async function DELETE(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const deleted = deleteReview(Number(id));

  if (!deleted) {
```

### Step 3: Button Se Route Connect Karo

Ab `DeleteButton` ko client component banao aur axios se connect karo.

```tsx
// app/components/DeleteButton.tsx
"use client";

import { useState } from "react";
import axios from "axios";

export function DeleteButton({ reviewId }: { reviewId: number }) {
  const [pending, setPending] = useState(false);

  const handleDelete = async () => {
    const confirmDelete = window.confirm("Kya sach mein delete karna hai?");
    if (!confirmDelete) return;

    setPending(true);

    try {
      await axios.delete(`/api/reviews/${reviewId}`);
      window.location.reload();
    } catch (error) {
      console.error("Delete failed:", error);
    } finally {
      setPending(false);
    }
  };

  return (
    <button
      onClick={handleDelete}
      disabled={pending}
      className="text-red-500 hover:text-red-700 text-sm disabled:text-gray-400"
    >
      {pending ? "Deleting..." : "Delete"}
    </button>
  );
}
```

**Line by line:**

1. **`window.confirm()`** — browser ka built-in popup — "Kya sach mein delete karna hai?" Agar OK click kare toh `true`, Cancel pe `false`.

2. **`axios.delete(`/api/reviews/${reviewId}`)** — DELETE request. URL mein review ID hai.

3. **`window.location.reload()`** — page refresh — deleted review gayab ho jaayega.

4. **`pending` state** — "Deleting..." dikhe loading ke dauran.

## Edit Flow

Delete ho gaya. Ab **Edit** — existing review badalna. Ye thoda complex hai — pehle form khulega, phir data prefill hoga, phir save hoga.

### Step 1: Detail Page Mein Edit Button

Pehle detail page pe "Edit" button lagao — click pe form khule.

```tsx
// app/reviews/[id]/page.tsx
"use client";

import { useEffect, useState } from "react";
import axios from "axios";
import Link from "next/link";

export default function ReviewPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const [review, setReview] = useState<{
    id: number;
    productId: number;
    text: string;
    rating: number;
    createdAt: string;
  } | null>(null);
  const [editing, setEditing] = useState(false);
  const [editText, setEditText] = useState("");
  const [editRating, setEditRating] = useState(5);

  useEffect(() => {
    params.then(({ id }) => {
      const load = async () => {
        const res = await axios.get(`/api/reviews/${id}`);
        setReview(res.data);
        setEditText(res.data.text);
        setEditRating(res.data.rating);
      };
      load();
    });
  }, [params]);

  if (!review) return <p>Loading...</p>;

  const handleUpdate = async (e: React.FormEvent) => {
    e.preventDefault();

    try {
      const res = await axios.put(`/api/reviews/${review.id}`, {
        text: editText,
        rating: editRating,
      });

      setReview(res.data);
      setEditing(false);
    } catch (error) {
      console.error("Update failed:", error);
    }
  };

  return (
    <div className="max-w-md mx-auto p-4 border rounded bg-white">
      <Link href="/reviews" className="text-blue-500 hover:underline text-sm mb-4 block">
        ← Wapas List pe
      </Link>

      {editing ? (
        <form onSubmit={handleUpdate} className="space-y-3">
          <div>
            <label className="block text-sm font-medium mb-1">Rating:</label>
            <select
              value={editRating}
              onChange={(e) => setEditRating(Number(e.target.value))}
              className="border p-2 rounded w-full"
            >
              {[1, 2, 3, 4, 5].map((n) => (
                <option key={n} value={n}>
                  {"⭐".repeat(n)}
                </option>
              ))}
            </select>
          </div>
          <div>
            <label className="block text-sm font-medium mb-1">Review:</label>
            <textarea
              value={editText}
              onChange={(e) => setEditText(e.target.value)}
              className="w-full border p-2 rounded"
              rows={3}
            />
          </div>
          <div className="flex gap-2">
            <button
              type="submit"
              className="bg-green-500 text-white px-4 py-2 rounded"
            >
              Save
            </button>
            <button
              type="button"
              onClick={() => setEditing(false)}
              className="text-gray-500 px-4 py-2 rounded"
            >
              Cancel
            </button>
          </div>
        </form>
      ) : (
        <>
          <div className="flex justify-between items-center mb-3">
            <span className="text-2xl">{"⭐".repeat(review.rating)}</span>
            <span className="text-sm text-gray-500">{review.createdAt}</span>
          </div>
          <p className="text-lg mb-4">{review.text}</p>
          <button
            onClick={() => setEditing(true)}
            className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
          >
            Edit
          </button>
        </>
      )}
    </div>
  );
}
```

**Notice kiya?** Detail page ab **Client Component** ban gaya — `"use client"`. Kyunki ab interactivity hai — `editing` state, form, click handlers.

**Pehle Server Component tha** (3.4.6 mein) — ab Client Component. **Kyun?** Ab edit functionality chahiye — form, state, click — ye sab client pe hota hai.

### Step 2: PUT Route Banayo

```tsx
// app/api/reviews/[id]/route.ts (mein GET + DELETE ke baad add karo)
import { NextResponse } from "next/server";
import { getReviewById, updateReview, deleteReview } from "@/lib/reviews";

// ... GET aur DELETE functions jo pehle the ...

export async function PUT(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const body = await request.json();

  if (!body.text || !body.rating) {
    return NextResponse.json(
      { error: "Text aur rating zaroori hai" },
      { status: 400 }
    );
  }

  const updated = updateReview(Number(id), {
    text: body.text,
    rating: Number(body.rating),
  });

  if (!updated) {
    return NextResponse.json(
      { error: "Review nahi mila" },
      { status: 404 }
    );
  }

  return NextResponse.json(updated);
}
```

**`PUT` function** — POST ke jaisa hai, par `updateReview()` call hota hai. ID URL se aata hai, data body se.

## Common Mistakes

1. **`window.confirm()` mat bhoolo** — Delete se pehle confirm karo. Accidental delete hota hai.
2. **Edit form mein `defaultValue` vs `value`** — Abhi `value` (controlled) use kar rahe hain. `defaultValue` (uncontrolled) bhi chalta hai par controlled better hai.
3. **PUT route mein validation** — Text aur rating dono zaroori hain. Agar koi missing ho toh 400.
4. **`params` await mat bhoolo** — Next.js 15 mein `params` promise hai.

## Route Handler Version Complete!

Ab Route Handler version ka saara CRUD ready hai:
- **GET** — reviews dikhao

- **PUT** — review edit karo
- **DELETE** — review delete karo

- Route file mein function

- `try/catch` for error
