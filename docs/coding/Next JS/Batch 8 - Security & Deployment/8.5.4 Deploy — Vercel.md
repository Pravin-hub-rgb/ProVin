## Step 7 — Post-Deploy Security Check

On the live site, open **DevTools → Sources tab** (Chrome) or **Debugger tab** (Firefox):

1. Search for the `DATABASE_URL` value
2. Search for `AUTH_SECRET` (if present)
3. Search for any `NEXT_PUBLIC_`

**Expected:** Nothing should be found. If a secret appears in the client bundle, it's a security issue — that secret is exposed to users.
