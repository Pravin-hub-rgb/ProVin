# MCP Setup — Install, Configure, Connect (8.6.1)

## Where We Left Off

In 8.6 we learned what MCP is — a protocol that lets your AI coding assistant connect to your running codebase instead of relying on pasted code. Now, let's set it up.

## Broader Goal

- Install `@cloud/mcp` CLI
- Generate `.mcp.json` for your Next.js project
- Connect your AI agents (Cursor, Gemini, VS Code, Codex)

## Manual → Better

| Without MCP | With MCP Setup |
|---|---|
| You manually copy-paste files into chats | Install `@cloud/mcp`, run one command, `.mcp.json` auto-configures |
| Each AI agent needs separate setup instructions | One `.mcp.json` configures Cursor, Gemini, VS Code, Codex at once |

## Step 1 — Install the MCP CLI

```bash
npm install -g @cloud/mcp
```

This gives you the `cloud` CLI with MCP commands. Verify it works:

```bash
cloud mcp --help
```

## Step 2 — Add the Next.js MCP Server

From your Next.js project root:

```bash
npx add @next/mcp-tool@latest
```

**What this does:**

1. Installs the Next.js MCP dev tool.
2. Prompts: "Which AI agents should this connect to?" — choose Cursor, Gemini, VS Code, Codex, or "all agents."
3. **Auto-creates `.mcp.json`** in your project root — this file configures each AI agent.

## Step 3 — Verify `.mcp.json`

After running the command, you will have a `.mcp.json` that looks like this:

```json
{
  "mcpServers": {
    "next-dev-tool": {
      "command": "npx",
      "args": ["next", "dev-tool"],
      "env": {
        "PORT": "3000"
      }
    }
  }
}
```

**Line-by-line:**

- **`mcpServers`** — the top-level key that MCP-aware AI agents read.
- **`next-dev-tool`** — the name of the MCP server (you can rename it).
- **`command: "npx"`** — how to launch the server.
- **`args: ["next", "dev-tool"]`** — the Next.js MCP dev tool command.
- **`env`** — optional environment variables passed to the server.

> **Important:** Add `.mcp.json` to your `.gitignore` if your config references secret paths or if you want different configs per environment.

```gitignore
.mcp.json
```

## Step 4 — Verify Your .gitignore

```bash
# Check if .mcp.json is ignored
git check-ignore .mcp.json
```

If it returns `.mcp.json`, it's properly ignored. If not, add it:

```bash
echo ".mcp.json" >> .gitignore
```

> **Never commit secrets.** If your `.mcp.json` contains references to secret paths or API keys, make sure it's in `.gitignore`.

## Step 5 — Start Your Dev Server

MCP connects to your **running** Next.js development server:

```bash
npm run dev
```

Leave this running. MCP reads your app's structure from the live dev server — it cannot connect to a stopped app.

## Verify the Setup

Once the dev server is running and your AI agent is configured:

1. Open your AI coding assistant (Cursor, Gemini, VS Code, Codex).
2. The agent should now have access to an MCP tool called `next-dev-tool` (or whatever you named it).
3. You can ask: "How many routes does my app have?" — the agent calls `get routes` and reads the actual structure.

## Common Mistakes

- ❌ **Forgetting to start the dev server** — MCP connects to your **running** app. No `npm run dev` = MCP can't read anything.
- ❌ **Committing `.mcp.json` with secrets** — if your config references secret paths, add to `.gitignore`.
- ❌ **Installing MCP globally outside the project** — the `.mcp.json` must be in your project root for the tool to find your app.
- ❌ **Not selecting the right AI agent** — the setup prompt asks which agents to configure. If you skip Cursor but use Cursor, it won't work.

## What It Is NOT

- **It is not a standalone tool.** MCP works **with** your AI coding assistant — it doesn't replace it.
- **It is not complex.** The setup is literally two commands and one config file. The complexity is in **using** the tools, which we cover next.
- **It is not for production.** This is development-time tooling only.

## In Your Own Words

1. What two commands install and configure MCP?

<details>
<summary>Sample Answer</summary>

**Answer:** `npm install -g @cloud/mcp` (installs the CLI) and `npx add @next/mcp-tool@latest` (installs the Next.js tool and generates `.mcp.json`).

</details>

2. Why must you have `npm run dev` running before using MCP?

<details>
<summary>Sample Answer</summary>

**Answer:** MCP connects to your running Next.js development server to read routes, files, and logic. The dev server serves the app's structure. Without it running, MCP has no codebase to inspect.

</details>

3. What does `.mcp.json` do?

<details>
<summary>Sample Answer</summary>

**Answer:** It configures your AI coding agents (Cursor, Gemini, VS Code, Codex) to connect to the Next.js MCP server. It specifies the command, args, and environment for the MCP server. Auto-generated by `npx add @next/mcp-tool`.

</details>
