## Audit Checklist (What to Check)

### 1. Environment Variables
- [ ] Does `.env.local` exist?
- [ ] Is `.env` / `.env.local` listed in `.gitignore`?
- [ ] Is `DATABASE_URL` only on the server (used in Server Component)?
- [ ] Is there no `NEXT_PUBLIC_DATABASE_URL`? (secret exposed to client)
- [ ] Is `AUTH_SECRET` (if it exists) strong?

### 2. `NEXT_PUBLIC_` Audit
- [ ] Are there any `NEXT_PUBLIC_` variables in the project?
- [ ] If yes — do they genuinely need the client?
- [ ] Is any secret showing up in the client bundle? (DevTools → Sources check)

### 3. Input Handling
- [ ] If there's a form, is there server-side validation?
- [ ] Are you using Server Actions? (CSRF built-in)
- [ ] Is client input going straight to the database without validation?

### 4. Error Boundaries
- [ ] Does `app/global-error.tsx` exist?
- [ ] Are there route-level `error.tsx` files?
- [ ] Is the error hierarchy correct? (route → layout → global)

### 5. Build Check
- [ ] Is `npm run build` successful?
- [ ] Are there any warnings/errors in the build?
- [ ] Has it been tested in production mode with `npm run start`?

### 6. Config Security
- [ ] Is `remotePatterns` correct in `next.config.ts`? (only trusted domains)
- [ ] Are there any unnecessary headers/rewrites?
