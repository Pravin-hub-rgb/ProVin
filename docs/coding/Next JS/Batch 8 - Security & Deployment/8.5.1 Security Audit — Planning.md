## Audit Checklist (Kya Check Karna Hai)

### 1. Environment Variables
- [ ] `.env.local` exist karti hai?
- [ ] `.gitignore` mein `.env` / `.env.local` listed hai?
- [ ] `DATABASE_URL` sirf server pe hai (Server Component mein use ho raha hai)?
- [ ] Koi `NEXT_PUBLIC_DATABASE_URL` toh nahi hai? (secret client mein expose)
- [ ] `AUTH_SECRET` (agar hai) strong hai?

### 2. `NEXT_PUBLIC_` Audit
- [ ] Project mein koi `NEXT_PUBLIC_` variable hai?
- [ ] Agar hai — toh kya woh genuinely client ko chahiye?
- [ ] Client bundle mein koi secret toh nahi dikh raha? (DevTools → Sources check)

### 3. Input Handling
- [ ] Koi form hai toh server-side validation hai?
- [ ] Server Actions use ho rahe hain? (CSRF built-in)
- [ ] Client input seedha database mein ja raha hai bina validation ke?

### 4. Error Boundaries
- [ ] `app/global-error.tsx` exist karti hai?
- [ ] Route-level `error.tsx` files hain?
- [ ] Error hierarchy sahi hai? (route → layout → global)

### 5. Build Check
- [ ] `npm run build` successful hai?
- [ ] Build mein koi warning/error toh nahi?
- [ ] `npm run start` se locally production mode test ho raha hai?

### 6. Config Security
- [ ] `next.config.ts` mein `remotePatterns` sahi hai? (sirf trusted domains)
- [ ] Koi unnecessary header/rewrite toh nahi?
