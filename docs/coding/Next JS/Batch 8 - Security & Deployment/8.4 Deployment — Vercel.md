Ab tak Photo Gallery local machine pe chal raha hai — `npm run dev` se `localhost:3000` pe. Local machine pe sab theek hai, par **duniya ko dikhana hai toh live URL chahiye.** Abhi sirf tum dekh sakte ho — baaki koi nahi.

Manual approach: VPS/Virtual server lo, Node.js install karo, `npm run build` karo, `npm start` chalao, nginx proxy lagao, SSL certificate setup karo, server maintain karo (RAM, updates, backups). Yeh sab karo — tab jaake app live hoti hai. **Bahut zyada kaam hai.**

Ab Vercel dekhte hain — jo itna aasan hai ki **git push se deploy ho jaata hai.**

## Manual Approach — Self-Host (Problem)

Self-host mein kya karna padta hai:

1. **Server lo** — AWS/DigitalOcean/VPS, Node.js install
2. **Code deploy karo** — git clone, `npm install`, `npm run build`, `npm start`
3. **Reverse proxy** — nginx ya Apache se port forwarding
4. **SSL certificate** — Let's Encrypt ya manually
5. **Env vars** — server pe `.env` set karo
6. **Maintain karo** — server update, RAM monitoring, backups
7. **Domain setup** — DNS records configure

Yeh sab karo — tab jaake app live hoti hai. Aur jab update aaye (naya code push) — dobara build + restart. **Har deploy manual hai.**

---

## CONCEPT — Vercel (Zero-Config Deploy)

Vercel Next.js creators ka platform hai. Yeh sab kuch **automatic** karta hai:

- **Git push = deploy** — `git push` karo, Vercel automatically build + deploy kar deta hai
- **Environment variables** — Vercel dashboard pe set karo, `.env` file ki zaroorat nahi
- **SSL/TLS** — automatic (Let's Encrypt)
- **Preview deployments** — har PR pe alag preview URL
- **Server-side features** — ISR, Image Optimization, Edge Middleware sab kaam karte hain
- **Zero-config** — `next.config.ts` mein kuch extra nahi karna padta (mostly)

## CODE — Deploy Se Pehle: `npm run build`

Deploy karne se pehle **local build** check karo — production build mein koi error toh nahi:

```bash
npm run build
```

Yeh command **production build** banata hai — same jo Vercel pe banega. Agar local build mein error aata hai — pehle fix karo. Production build aur `npm run dev` mein fark hai:

- `npm run dev` — development mode, hot reload, error overlay
- `npm run build` — production build, optimized, static generation, strict checks

Build successful ho toh `npm run start` se locally test kar sakte ho production mode.

## CODE — Vercel Pe Deploy (Step by Step)

### Step 1: GitHub Pe Push

```bash
git add .
git commit -m "Photo Gallery ready for deploy"
git push origin main
```

Code GitHub pe hona chahiye — Vercel wahan se pull karega.

### Step 2: Vercel Mein Import

1. [vercel.com](https://vercel.com) pe jao → Sign in with GitHub
2. **"Add New..."** → **"Project"**
3. Apna GitHub repo select karo
4. Vercel automatically detect karega ki **Next.js project** hai
5. **"Deploy"** button dabao

Bas. Build shuru ho jaayegi. 1-2 minute mein deploy ho jaayega.

### Step 3: Environment Variables Set Karo

Vercel dashboard → **Settings** → **Environment Variables**:

| Key | Value | Environment |
|---|---|---|
| `DATABASE_URL` | `postgresql://...` | Production, Preview |
| `AUTH_SECRET` | `cX8v7K9m...` | Production, Preview |

Yeh variables sirf Vercel ke server pe hain — client bundle mein nahi (kyunki `NEXT_PUBLIC_` nahi lagaya).

### Step 4: Domain (Optional)

Vercel automatically ek `.vercel.app` URL deta hai. Custom domain chahiye toh:
- Vercel dashboard → **Settings** → **Domains**
- Apna domain add karo
- DNS records set karo (vercel batata hai)

## CONCEPT — Preview vs Production Deployments

Vercel do tarah ke deployments karta hai:

| Type | Kab banta hai | URL |
|---|---|---|
| **Preview** | Har PR (pull request) pe | `preview-abc123.vercel.app` |
| **Production** | `main` branch pe push pe | `teri-app.vercel.app` |

**Preview deployment** — PR ke liye alag URL. Team members review kar sakte hain bina production affect kiye. Merge ho jaaye toh production deploy hota hai.

**Production deployment** — `main` branch pe push = live deploy. Yehi tumhara production URL hai.

## Nutshell

Vercel pe deploy karna: **git push = live app.** `npm run build` se pehle locally check karo, phir Vercel pe import karo, env vars set karo, deploy. Har PR pe preview URL milta hai, main branch pe production deploy hota hai. ## What It Is NOT

- **Vercel = "sab kuch free" nahi.** Free tier pe limited builds/month hain. Paid plan pe unlimited. Par personal projects ke liye free kaafi hai.
- **`npm run dev` = production build nahi.** Development mode hot reload + error overlay deta hai. Production build `npm run build` se hoti hai — optimized, static generation, strict checks.
- **Deploy = "done" nahi.** Deploy ke baad verify karo — routes, images, errors, security. Deploy karna aasan hai, verify karna zaroori.
- **Preview deployment = "staging environment" nahi.** Preview temporary hota hai — PR merge hone ke baad band ho jaata hai. Staging ke liye alag environment setup karna padega.
