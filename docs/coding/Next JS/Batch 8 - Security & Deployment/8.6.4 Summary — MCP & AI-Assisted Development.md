## What Is MCP — At a Glance

**MCP** (Model Context Protocol) lets your AI coding assistant connect to your real codebase instead of relying on pasted code:

```bash
npm install -g @cloud/mcp                    # install CLI
npx add @next/mcp-tool@latest                # generate .mcp.json
npm run dev                                   # start your app
# → Ask your AI: "how many routes?" → get routes returns them live
```

## MCP Tools Recap

| Tool | Command | Use Case |
|---|---|---|
| `get routes` | Lists all routes | "What routes does my app have?" |
| `get route` | Reads a route file | "Show me /blog/[slug]" |
| `get component` | Reads a component | "How does TodoList work?" |

## next-browser Recap

```bash
npm run dev            # terminal 1
npx next-browser       # terminal 2 — inspect from editor
```

Experimental — inspects your running app from VS Code without opening a browser.

## In Your Own Words

1. What single tool does MCP provide that replaces manual route listing?

<details>
<summary>Sample Answer</summary>

**Answer:** `get routes` — it auto-discovers all routes from your app's filesystem. No need to manually list your `app/` directory.

</details>

2. Why must the dev server be running before using MCP?

<details>
<summary>Sample Answer</summary>

**Answer:** MCP connects to the running Next.js dev server to read routes, files, and logic. Without the dev server running, there's no live app for MCP to inspect.

</details>
