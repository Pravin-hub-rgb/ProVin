**File:** `app/photo/[id]/page.tsx` — detail

**Concept:** Detail page pe bada image — fixed height cell nahi — full-width image. **`width`/`height` props** (7.2) — Unsplash URL se dimensions nahi pata — `fill` + aspect ratio container best hai. Container `aspect-video` ya fixed `h-96` — image fill:

```tsx
// app/photo/[id]/page.tsx
import type { Metadata } from "next";
import Image from "next/image";
import Link from "next/link";
import { notFound } from "next/navigation";
import prisma from "@/lib/prisma";

async function getPhoto(id: number) {
  return prisma.photo.findUnique({ where: { id } });
}

export async function generateMetadata({
  params,
}: {
  params: Promise<{ id: string }>;
}): Promise<Metadata> {
  const { id } = await params;
  const photo = await getPhoto(Number(id));

  if (!photo) {
    return { title: "Photo Not Found" };
  }

  return {
    title: photo.title,
    description: photo.description ?? photo.alt,
  };
}

export default async function PhotoPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const photo = await getPhoto(Number(id));

  if (!photo) {
    notFound();
  }

  return (
    <section>
      <Link href="/" className="text-sm text-zinc-500">
        &larr; Back to gallery
      </Link>

      <div className="relative mt-4 h-96 w-full">
        <Image
          src={photo.src}
          alt={photo.alt}
          fill
          sizes="(max-width: 768px) 100vw, 700px"
          className="rounded-lg object-cover"
        />
      </div>
      <h1 className="mt-4 text-2xl font-bold">{photo.title}</h1>
      <p className="mt-1 text-zinc-600">{photo.description}</p>
    </section>
  );
}
```

**`<div className="relative mt-4 h-96 w-full">`** — detail image ka container — `relative` (fill ke liye) + `h-96` (fixed height — CLS nahi). **`<Image fill sizes="...700px">`** — container ko bharo, max ~700px (detail view width). `object-cover` — crop. `generateMetadata` + data read **wahi** — sirf image optimized.

**Roadmap (T)**: "before/after size compare". Yeh project wala test — asli proof ki `next/image` kaam kar raha hai:

2. **Ab (after — `<Image>`):** Naya page → wahi photo → `next/image` ka optimized version (thumbnail `~15-30KB` WebP, detail bhi chhota). **~70-80% chhoti file.**

**TEST details:**

- Network tab → grid pe kisi image ka size vs detail pe wahi image — `sizes` ke hisaab se alag versions (grid thumbnail chhota, detail bada).
- DevTools → Performance → Record → reload → **Layout Shift ≈ 0** — `fill` + fixed containers se koi shift nahi.

## Nutshell

Optimization: `next/font/google` se Inter — layout pe `variable: "--font-inter"` + CSS `font-family: var(--font-inter)` — self-hosted + no CLS. `next/image` — `remotePatterns` (Unsplash) config + `<Image>` grid pe (`fill` + `relative h-40` container) aur detail pe (`fill` + `relative h-96` container) — `sizes` prop se srcset optimized, fixed containers se CLS ≈ 0. Before/after compare — **~70-80% chhoti files.**

## What It Is NOT

- **`<Image fill>` = `<img>` ka rename nahi.** `next/image` server pe optimize karta hai + srcset generate + dimensions se CLS control. Sirf tag change nahi — 7.2 ka asli machinery.
- **`fill` + `relative` container = "hack" nahi.** Yeh `next/image` ka **designed pattern** hai jab image dimensions pata nahi (remote URLs). Container ka size = layout reservation — CLS prevention. `relative` parent ke bina `fill` kaam nahi karta (absolute positioning chahiye).
- **`sizes` prop = "optional sugar" nahi.** Browser ko batata hai image kitni jagah legi — Next.js isi se srcset optimize karta hai (chhoti jagah = chhoti image). Galat sizes = bada image chhoti jagah — bandwidth waste.
- **`remotePatterns` = "kisi bhi URL ko allow" nahi.** Security allowlist — sirf `images.unsplash.com`. Koi aur domain pe error aayega jab tak config mein add na ho. Intentional — external images trusted nahi by default.
- **Inter ka fayda = "sirf look better" nahi.** `next/font` self-host + preload karta hai + fallback adjust (no FOUC/CLS — 7.3/7.4). Look bonus hai, asli fayda performance + stability.
