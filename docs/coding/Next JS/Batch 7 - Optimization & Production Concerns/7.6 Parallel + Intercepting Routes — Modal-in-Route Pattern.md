# Parallel + Intercepting Routes — Modal-in-Route Pattern

## SOCH — Modal Ka URL Wala Puzzle

Ek aam pattern — kisi image pe click karte ho, **modal** khulta hai (background blur, photo detail). Par Instagram wala trick yeh hai ki modal ka ek **URL hota hai** — `/photo/123`. Aur:

1. Click pe modal khulta hai, **URL `/photo/123` ho jaata hai** — share kar sakte ho
2. Modal mein hi navigate karte ho — **poore page ka reload nahi**
3. **Back button** dabao toh modal close, same page wapas
4. URL direct kholo toh (kisi aur ne share kiya) — **full photo page** khulta hai, modal nahi

Yeh "modal-with-URL" pattern do cheezon se banta hai — **Parallel Routes** (ek hi URL pe do screens) aur **Intercepting Routes** (browser URL ko intercept karke modal dikhana).

## CONCEPT — Do Concepts, Ek Pattern

### Parallel Routes — Ek URL Pe Do Screens

Ek page ka layout aap dekh rahe ho. Kya ho agar ek hi URL pe **do independent screens** simultaneously render hon — ek main content, ek modal (agar khola ho)? Isi ko kehte hain **Parallel Routes** — do ya zyada `page.tsx` ek hi route mein, sirf unki **slots** alag.

Syntax — folder ke andar `@` prefix wale folders (slots):

```
app/
├── layout.tsx              ← dono slots render karta hai
├── page.tsx                ← children (root page)
├── @main/
│   ├── page.tsx            ← main content (gallery grid)
│   └── default.tsx         ← fallback (mandatory!)
└── @modal/
    ├── page.tsx            ← root pe kuch nahi (null)
    ├── default.tsx         ← fallback (mandatory!)
    └── (.)gallery/
        └── [id]/
            └── page.tsx    ← photo modal (intercepted)
```

**`@main`** aur **`@modal`** — yeh **slots** hain. Next.js **automatic** inhe root `layout.tsx` ko **props** bhej deta hai — koi import nahi chahiye. Folder name `@main` → prop `main`, folder name `@modal` → prop `modal`.

```tsx
// app/layout.tsx
export default function RootLayout({ children, main, modal }) {
  return (
    <html lang="en">
      <body>
        {children}     {/* implicit slot — app/page.tsx */}
        {main}         {/* @main slot — gallery grid */}
        {modal}        {/* @modal slot — photo modal */}
      </body>
    </html>
  );
}
```

**Important:** `{children}` hatao mat! Yeh **implicit slot** hai — `app/page.tsx` ka content. Uske saath `{main}` aur `{modal}` **add** karo.

Do screens, ek URL pe, side-by-side render. Main content + overlay modal.

### Intercepting Routes — URL Ko Pattern Se Todna

Ab Instagram trick — click pe URL `/gallery/1` dikhta hai, par modal khulta hai (page reload nahi). Par direct `/gallery/1` kholo toh **full page**. Isi URL-change-but-layout-hack ko karte hain **Intercepting Routes**.

Syntax — folder ka naam `(.)` prefix se shuru:

```
app/
├── @modal/
│   └── (.)gallery/         ← "gallery ko intercept karo"
│       └── [id]/
│           └── page.tsx    ← click pe yeh modal dikhega
└── gallery/
    └── [id]/
        └── page.tsx        ← direct visit pe yeh full page
```

**`(.)gallery`** — "intercept `gallery` route." Jab user gallery se `gallery/1` pe navigate karta hai (Link click), browser URL `/gallery/1` dikhata hai, par Next.js ko pata hai ki **user ne page se click kiya** — toh `@modal/(.)gallery/[id]` render karta hai (modal). Jab koi URL **directly** kholta hai (ya refresh) — Next.js `gallery/[id]` full page render karta hai.

`(.)` ke alawa aur bhi matchers hain:
- `(.)` — same level
- `(..)` — one level up
- `(..)(..)` — two levels up
- `(...)` — root se start

### Kya Chahiye — Har Slot Ko 3 Files

Parallel routes mein **har slot** ko teen files chahiye:

| File | Kya karta hai | Zaroorat |
|------|---------------|----------|
| `page.tsx` | Root level pe kya dikhe | Haan (slot ke parent route pe) |
| `default.tsx` | Jab slot match na ho toh fallback | **Mandatory** — bina error |
| `(.)route/page.tsx` | Intercepted content (modal) | Haan (modal pattern ke liye) |

**`@modal/page.tsx`** — Root `/` pe kuch nahi dikhana (null). Bina iske interception kaam nahi karta — redirect ho jaata hai.

**`@modal/default.tsx`** — Jab koi route match na ho toh fallback. `null` return karo.

**`@main/default.tsx`** — Same — null return. Bina iske build error: *"Missing required default.js file for parallel route"*.

## CODE — Step-by-Step Build (Humne Kiya)

### Step 1 — Layout Me Slots Add Karo

```tsx
// app/layout.tsx
export default function RootLayout({ children, main, modal }: LayoutProps<"/">) {
  return (
    <html lang="en" className={`${geistSans.variable} ${geistMono.variable} h-full antialiased`}>
      <body className="min-h-full flex flex-col">{children}{main}{modal}</body>
    </html>
  );
}
```

**Pehle sirf `{children}` tha.** Ab uske saath `{main}` aur `{modal}` add kiye. Function signature me bhi props add karo — `{ children, main, modal }`.

### Step 2 — Root Page Empty Karo

```tsx
// app/page.tsx
export default function Home() {
  return null;
}
```

`@main` grid dikhayega — `children` ko empty rakhna hai taaki duplicate na ho.

### Step 3 — Har Slot Ka Default.tsx Banao

```tsx
// app/@main/default.tsx
export default function Default() {
  return null;
}

// app/@modal/default.tsx
export default function Default() {
  return null;
}
```

**Yeh step skip mat karo.** Bina `default.tsx` ke build error aata hai: *"Missing required default.js file for parallel route"*.

### Step 4 — Root Level Pe @modal/page.tsx

```tsx
// app/@modal/page.tsx
export default function ModalPage() {
  return null;
}
```

**Yeh sabse tricky step hai.** Bina iske, jab image pe click karte ho toh modal nahi khulta — seedha `/gallery/1` pe redirect ho jaata hai 404 ke saath. Kyunki `@modal` slot ko root pe bhi ek page chahiye hota hai.

### Step 5 — Grid Banao (@main/page.tsx)

```tsx
// app/@main/page.tsx
import Image from "next/image";
import { fetchPhotos } from "@/app/lib/photos";
import Link from "next/link";

export default async function GalleryGrid() {
  const photos = await fetchPhotos();
  return (
    <div className="flex flex-wrap gap-4">
      {photos.map((photo) => (
        <Link key={photo.id} href={`/gallery/${photo.id}`}>
          <Image src={photo.src} alt={photo.alt} width={250} height={250} />
        </Link>
      ))}
    </div>
  );
}
```

**`Link` se wrap karo** — taaki click pe soft navigation ho (interception kaam kare). Direct `<Image>` pe click karna hota toh `<a>` tag lagana padta.

### Step 6 — Modal Banao (@modal/(.)gallery/[id]/page.tsx)

```tsx
// app/@modal/(.)gallery/[id]/page.tsx
import Image from "next/image";
import { fetchPhotos } from "@/app/lib/photos";
import { CloseButton } from "@/app/components/CloseButton";
import { ModalOverlay } from "@/app/components/ModalOverlay";

export default async function PhotoModal({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const photos = await fetchPhotos();
  const photo = photos.find((p) => p.id === parseInt(id));
  if (!photo) return null;
  return (
    <ModalOverlay>
      <CloseButton />
      <Image src={photo.src} alt={photo.alt} width={photo.width} height={photo.height} />
      <p className="mt-2 text-center">{photo.title}</p>
    </ModalOverlay>
  );
}
```

**Next.js 16 me `params` Promise hai** — `params: Promise<{ id: string }>`. `await params` karo pehle. Purane version me `params: { id: string }` tha — ab nahi.

### Step 7 — Standalone Full Page Banao

```tsx
// app/gallery/[id]/page.tsx
import Image from "next/image";
import { fetchPhotos } from "@/app/lib/photos";

export default async function PhotoPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const photos = await fetchPhotos();
  const photo = photos.find((p) => p.id === Number(id));
  if (!photo) return <p>Photo not found</p>;
  return (
    <main className="p-8">
      <Image src={photo.src} alt={photo.alt} width={800} height={800} />
      <h1>{photo.title}</h1>
    </main>
  );
}
```

Jab koi URL **directly** open kare (ya refresh kare) — yeh full page dikhta hai. Modal nahi.

### Step 8 — Client Components (Close + Backdrop)

Modal me interactive elements chahiye — close button, backdrop click. Par modal page **Server Component** hai (async `params`). Toh alag client components banao:

```tsx
// app/components/CloseButton.tsx
"use client";
import { useRouter } from "next/navigation";

export function CloseButton() {
  const router = useRouter();
  return (
    <button
      onClick={() => router.back()}
      className="absolute top-2 right-2 bg-black/50 text-white rounded-full w-8 h-8 flex items-center justify-center hover:bg-black/70 cursor-pointer"
    >
      ✕
    </button>
  );
}
```

```tsx
// app/components/ModalOverlay.tsx
"use client";
import { useRouter } from "next/navigation";
import { ReactNode } from "react";

export function ModalOverlay({ children }: { children: ReactNode }) {
  const router = useRouter();
  return (
    <div
      className="fixed inset-0 bg-black/30 flex items-center justify-center z-50"
      onClick={() => router.back()}
    >
      <div onClick={(e) => e.stopPropagation()} className="bg-white p-4 rounded-lg relative max-w-lg">
        {children}
      </div>
    </div>
  );
}
```

**`stopPropagation()`** — modal content pe click ho toh backdrop pe event na jaye (modal close na ho). Backdrop pe click = close. Modal content pe click = kuch na ho.

### Final Folder Structure

```

├── layout.tsx                          ← slots: children, main, modal
├── page.tsx                            ← null (empty)
├── @main/
```

## COMMON PITFALLS — Errors Jo Humne Face Kiye

### 1. `main is not defined`

```
ReferenceError: main is not defined
at RootLayout (app\layout.tsx:26:61)
```

**Kya hua:** JSX me `{main}` aur `{modal}` use kiye, par function signature me nahi likha.

**Fix:**
```tsx
// Galat — sirf children
export default function RootLayout({ children }: LayoutProps<"/">) {

// Sahi — children + main + modal
export default function RootLayout({ children, main, modal }: LayoutProps<"/">) {
```

### 2. `Missing required default.js file for parallel route`

```
Error: Missing required default.js file for parallel route at //@main
```

**Kya hua:** `@main/default.tsx` empty file thi (0 lines, koi export nahi).

**Fix:** Har slot me `default.tsx` me export hona chahiye:
```tsx
export default function Default() {
  return null;
}
```

### 3. Redirect instead of Modal

```
Click on image → /gallery/1 → 404 Not Found
```

**Kya hua:** `@modal/page.tsx` nahi tha. Bina root-level page ke, slot interception support nahi karta.

**Fix:** `@modal/page.tsx` banao:
```tsx
export default function ModalPage() {
  return null;
}
```

### 4. `Property 'params' does not exist on type 'Promise'`

```
Property 'params' does not exist on type 'Promise<{ params: { id: string; }; }>'
```

**Kya hua:** Params type galat tha — `Promise<{ params: { id: string } }>` (double wrap).

**Fix:** Next.js 16 me params alag Promise hai:
```tsx
// Galat
{ params }: Promise<{ params: { id: string } }>

// Sahi
{ params }: { params: Promise<{ id: string }> }
```

### 5. Turbopack Crash — HMR Error

```
FATAL: An unexpected Turbopack error occurred
```

**Kya hua:** `.next` cache corrupt ho gayi file changes ke baad.

**Fix:** Server band karo, `.next` folder delete karo, restart karo:
```
Ctrl+C
Remove-Item -Recurse -Force .next
npm run dev
```

## TEST — Pattern Ka Farak Dekho

1. Gallery se photo pe click → **URL `/gallery/1`** hota hai, modal khulta hai (page reload nahi).
2. **Backdrop** pe click → modal close, gallery wapas.
3. **Close button (✕)** pe click → modal close, gallery wapas.
4. URL `/gallery/1` ko **naye tab mein kholo** → full photo page, modal nahi.
5. Browser **Back** button → modal close (ya previous page).

Yeh behaviour — click = modal, direct = full page — **Intercepting Routes** ka signature hai.

## Nutshell

Parallel Routes + Intercepting Routes milke **modal-in-route pattern** banate hain (Instagram-style photo modal). **Parallel Routes** — ek URL pe do independent screens render karte hain slots (`@modal`, `@main`) ke through; layout mein dono slot render hote hain. Slot names automatic props bante hain — koi import nahi. `{children}` implicit hai — hatao mat. **Intercepting Routes** — `(.)gallery` folder syntax se URL ko intercept karte hain: page se click = modal, direct visit = full page. Har slot ko `default.tsx` mandatory hai. `@modal/page.tsx` bhi zaroori hai (root level pe), warna interception kaam nahi karta. **`params` Next.js 16 me Promise hai** — `await params` karo. Interactive elements (close button, backdrop click) ke liye `"use client"` components alag banao.

## What It Is NOT

- **Parallel Routes = "nested routes" nahi.** Nested routes ek-dusre ke andar render hote hain (parent-child). Parallel routes ek hi URL pe **independent** screens hain — side-by-side, do slots.
- **Intercepting Routes = "redirect" nahi.** Redirect URL change karta hai aur page reload hota hai. Intercepting browser ke URL ko **wahi rakhta hai** par render alag component karta hai (click = modal, direct = full page) — bina reload ke.
- **`(.)` prefix = "folder ko hide karna" nahi.** URL se `(.)` hata diya jaata hai — par iska actual purpose navigation ke time intercept karna hai. Kaam alag hai.
- **Modal = "sirf CSS overlay" nahi.** Overlay styling ka hissa hai, par pattern ka core URL handling hai — back button, shareable URL, direct vs click distinction. Yehi to modal ko pro banata hai.
- **`default.tsx` = "optional" nahi.** Har slot me mandatory hai. Bina iske build error aata hai. Har slot ko ek fallback chahiye.
- **`@modal/page.tsx` = "skip kar sakte ho" nahi.** Root level pe page.tsx hona zaroori hai — bina interception kaam nahi karta.
