## Batch Spine — "Manual → Better"

The core principle of this batch: **feel the old way first, then see Next.js's better solution.** This plays out four times in Batch 7:

| Topic | Manual (feel the problem first) | Better (Next.js solution) |
|---|---|---|
| Images | `<img>` — LCP slow, causes text shift, downloads for every size | `next/image` — automatic optimization, srcset/sizes, responsive |
| Fonts | Google Fonts `<link>` / `@font-face` — text FOUC + shift | `next/font` — self-hosted, preloaded, no layout shift |
| Loading | Entire page waits on data | Streaming with Suspense — section-by-section progressive load |
| Modal | Client-state modal — no URL, breaks on refresh/back | Parallel + Intercepting Routes — modal in URL (Instagram pattern) |

Each topic: first **feel the problem** (manual), then **the solution** (Next.js built-in). This is how the "why" becomes clear, not just the "how."
