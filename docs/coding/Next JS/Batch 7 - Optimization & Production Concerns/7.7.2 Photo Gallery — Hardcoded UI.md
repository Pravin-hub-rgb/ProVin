## TEST + Problem Highlight

**TEST:** `/` pe hero + grid (3 photos), `/photo/1` pe full detail, `/photo/999` pe 404. Design confirm.

**Problem — data teen jagah hai (DRY violation):**

Abhi photos hardcoded hain **do pages mein copy** (home + detail) — same data, do arrays. Aur asli problem — plan (7.7.1) kehta hai Photo Gallery ka data **database** mein hoga (Prisma + Neon). Is UI ko real banane ke liye:

- Duplicate arrays hatao
- Database se data lao (`prisma.photo.findMany()` / `findUnique`)
- Images optimize karo (`next/image` — 7.7.4)
- Font optimize karo (`next/font` — 7.7.4)

Yeh sab 7.7.3 (data layer) + 7.7.4 (optimization) mein hoga. **UI ka code mostly wahi rahega** — sirf data source badlega. Yahi planning + hardcoded-first ka fayda — UI confirm ho gayi, ab data layer bas plug-in karni hai.

## Nutshell

Hardcoded UI: `/` pe hero + grid (`{ id, title, description, src, alt }` map, Link se `/photo/[id]`), `/photo/[id]` pe full detail (`params` async — `const { id } = await params` + `photos.find` + `if (!photo) notFound()`). Images plain `<img>` (next/image 7.7.4 mein). Data do pages mein duplicate — DRY violation + database se replace karni hai — 7.7.3 ka kaam.

## What It Is NOT

- **Hardcoded UI = "final data" nahi.** Yeh static demo hai — UI + data shape validate karne ke liye. Asli data Neon database se aayega (7.7.3). Is file ka code UI pattern hai, data nahi.
- **Plain `<img>` = "is project ka final image approach" nahi.** Abhi UI focus hai. `next/image` (optimization) 7.7.4 mein aayega — tab images optimize hongi. Is part mein intentionally simple rakha.
- **Photos array dono pages mein copy = "sahi pattern" nahi.** Yeh DRY violation hai — same data do jagah. 7.7.3 mein data layer (single source) ise fix karega — pages phir ek function call karenge.
- **`photos.find` + `Number(id)` = "final data lookup" nahi.** Abhi JS array se match hai. 7.7.3 mein `prisma.photo.findUnique({ where: { id } })` hoga. Par logic ka idea wahi hai — id se photo.
- **Layout = "har page pe copy karo" nahi.** Layout ek baar define hota hai — dono pages uske andar. Header gallery ka shared brand hai.
