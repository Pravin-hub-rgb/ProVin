# next/font — No Layout Shift

## SOCH — "Better" Ka Matlab

7.3 ki problems yaad karo:

1. **FOUC** — text fallback se custom font pe flash
2. **Layout shift** — fallback vs custom font widths alag → CLS
3. **Network dependency** — Google Fonts ke server pe depend
4. **Extra requests** — har weight ki alag font file

Ab kya hota agar ek cheez ho jo: font ko **self-host** kare (koi external request nahi), **preload** kare, aur fallback ko **adjust** kare taaki shift na ho? That's `next/font` — Next.js ka built-in font system.

## CONCEPT — `next/font` Kya Karta Hai

`next/font` do cheezein karta hai jo manual approach nahi kar sakta:

- **Self-hosted fonts** — Google Fonts se font download karke **apne server pe bundle** kar deta hai. Koi external request nahi — koi Google CDN dependency nahi. Deploy pe bhi font aapke app ke saath aata hai.
- **Automatic font optimization** — Next.js font files ko build time pe download karta hai, optimize karta hai, aur **preload** kar deta hai. Font ki request aapke own server pe hoti hai — fast.
- **`adjustFontFallback`** — yeh asli magic hai. Fallback font (Arial) ki size `adjust` ki jaati hai taaki custom font ke aspect-ratio ke match ho — **swap hone pe koi layout shift nahi.** CLS = 0.
- **CSS variables** — font ko CSS variable mein expose karta hai (`--font-inter`), jisse aap component mein use kar sakte ho.

Ek line mein — **`next/font` font ko build time pe download + self-host karta hai, preload karta hai, aur fallback adjust karke zero layout shift deta hai.**

## CODE — `next/font/google` Se Inter

7.3 wale layout ko badalte hain — `<link>` tags hatake `next/font`:

**File:** `app/layout.tsx` — Google Fonts link → `next/font/google`

```tsx
// app/layout.tsx
import { Inter } from "next/font/google";
import "./globals.css";

const inter = Inter({ subsets: ["latin"], variable: "--font-inter" });

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en" className={inter.variable}>
      <body>{children}</body>
    </html>
  );
}
```

**`import { Inter } from "next/font/google"`** — Inter font import (Next.js ke Google Fonts collection se). **`Inter({ subsets: ["latin"], variable: "--font-inter" })`** — font config: `subsets: ["latin"]` (sirf needed characters — file chhoti), `variable: "--font-inter"` (CSS variable mein expose). **`<html className={inter.variable}>`** — CSS variable html element pe mila — ab aap CSS mein `--font-inter` use kar sakte ho.

Ab CSS mein font apply karo:

```css
/* app/globals.css */
body {
  font-family: var(--font-inter), Arial, sans-serif;
}
```

**`var(--font-inter)`** — `next/font` ka self-hosted font. **`, Arial, sans-serif`** — fallback (agar font nahi aaya). Par `next/font` ne Inter ki fallback adjustment kar di — Arial ko Inter ke aspect-ratio se match — swap pe koi shift nahi.

### CSS Variables Kyun?

`variable: "--font-inter"` ka matlab — font class ko `<html>` pe lagate ho, aur CSS variable se har jagah use kar sakte ho. Yeh acha pattern hai kyunki:

- Font family ko CSS variable banate ho — ek jagah change karo, sab jagah badal jaata hai
- Tailwind mein bhi use ho sakta hai (`font-family: var(--font-inter)`)
- Multiple fonts manage karna easy — `--font-heading`, `--font-body`

### `next/font/local` — Khud Ke Font Files

Google Fonts nahi, apni `.woff2` files hain toh:

```ts
// app/layout.tsx
import localFont from "next/font/local";

const myFont = localFont({ src: "./fonts/MyFont.woff2" });
```

**`next/font/local`** — aapki local font files. Par Photo Gallery mein Google Fonts (Inter) hi enough hai — local ka mention itna hi ki pata ho ki exist karta hai.

## Nutshell

`next/font` 7.3 ki saari manual font problems solve karta hai: **self-hosted** (Google CDN dependency nahi — build time pe download + bundle), **preloaded** (own server se fast), aur **`adjustFontFallback`** (fallback ko custom font se match — zero layout shift). Google Fonts ke liye `next/font/google`, khud ke files ke liye `next/font/local`. Font ko CSS variable mein expose karo (`variable: "--font-inter"`) aur `<html>` pe lagao.

## What It Is NOT

- **`next/font` = "Google Fonts ka shortcut" nahi.** Yeh font ko **self-host** karta hai — build time pe download + optimize + bundle. Sirf `<link>` tag ki jagah nahi hai.
- **`adjustFontFallback` = "sirf Arial set karna" nahi.** Yeh fallback font ka size dynamically adjust karta hai taaki swap pe CLS na ho. Manual `font-family: Inter, Arial` mein yeh automatic adjustment nahi hoti.
- **`subsets: ["latin"]` = "optional setting" nahi.** Isse sirf needed characters ki file bundle hoti hai — font file chhoti, fast. Galat subset = missing characters.
- **`next/font` = "server pe font file serve karta hai" ka matlab "slow" nahi.** Self-hosted = apne server se (fast, controlled). External CDN slow ho sakta hai (region/latency).

</details>

<details>

**Sample Answer:** Font files bahut badi hoti hain (har language/character set). `subsets: ["latin"]` sirf English characters wala subset bundle karta hai — file chhoti, load fast. Hindi/Devanagari chahiye toh alag subset.
