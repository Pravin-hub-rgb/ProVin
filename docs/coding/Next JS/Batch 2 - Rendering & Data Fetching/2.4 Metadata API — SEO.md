Jab tum Google pe kuch search karte ho — "best next js course" — toh results mein kya dikhta hai? Har result mein ek **title** hota hai, ek **description** (chhoti si line), aur ek URL. Google ye sab **page ke metadata** se uthata hai — HTML ke `<head>` section mein `<title>` aur `<meta name="description">` tags.

React course mein ye sab manually karte the — `<title>` tag, `<meta>` tags, har page pe alag. Aur jaise hi data dynamic hua (blog post ka title), meta bhi dynamic karna padta tha. Next.js mein iska better solution hai — **Metadata API** aur `generateMetadata`. Chalo seekhte hain.

---

## Manual Approach — React Mein Manual `<head>` Tags

React mein metadata manually manage karte the:

```tsx
// React — manual head tags
import { useEffect } from 'react';

export default function BlogPost() {
  useEffect(() => {
    document.title = "My Blog Post";   // browser tab title
  }, []);

  return <h1>My Blog Post</h1>;
}
```

`document.title` set karte the — koi `<meta name="description">` nahi, koi Open Graph nahi. Aur jaise hi page dynamic hua, `useEffect` mein title change karna padta tha. **Manual, fragile, aur SEO ke liye kharab** — Google useEffect-se-set title ko thik se crawl nahi karta (kabhi JS ke bina page dekhta hai).

---

## Better Approach — Next.js Metadata API

Next.js mein metadata **server-side** set hota hai — HTML ke andar seedha, `useEffect` ki zaroorat nahi. Do tareeke hain:

### Static Metadata — `export const metadata`

File se metadata export karo — simple object:

```tsx
// app/about/page.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "About Me | Pravin",
  description: "Main ek full-stack developer hun — Next.js, React, TypeScript.",
};

export default function About() {
  return <h1>About Me</h1>;
}
```

Next.js ise page ke HTML ke `<head>` mein daal dega — browser tab mein title, search engine ko description. **Server-side, koi useEffect nahi.**

### Dynamic Metadata — `generateMetadata`

Ab asli power — metadata ko **dynamic** banana. Blog post ka title hi uski metadata banna chahiye. `generateMetadata` function export karo jo `params` se data fetch karke metadata return kare:

```tsx
// app/blog/[slug]/page.tsx
import type { Metadata } from "next";
import { getPostBySlug } from "@/lib/posts";

interface PageProps {
  params: Promise<{ slug: string }>;
}

export async function generateMetadata({ params }: PageProps): Promise<Metadata> {
  const { slug } = await params;
  const post = getPostBySlug(slug);

  if (!post) {
    return { title: "Post Not Found" };
  }

  return {
    title: post.title,
    description: post.excerpt,
  };
}

export default async function BlogPost({ params }: PageProps) {
  const { slug } = await params;
  const post = getPostBySlug(slug);
  // ... render
}
```

**Dekho pattern:** `generateMetadata` ko `params` milta hai (1.3 se yaad — Next.js call karta hai!), post fetch karta hai, aur title/description return karta hai. Har slug ka apna title — `/blog/pehla-post` pe "Mera Pehla Blog Post" title dikhega.

> **Important:** Page render hone se pehle `generateMetadata` chalata hai — Next.js isse SEO ke liye HTML mein daal deta hai.

## Metadata Template — Root Layout Mein Default

Sab pages ka title "site | page name" jaisa hona chahiye — har page pe repeat nahi karna. Root `layout.tsx` mein **template** define karo:

```tsx
// app/layout.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: {
    default: "Pravin | Full-Stack Developer",
    template: "%s | Pravin",
  },
  description: "Pravin ka portfolio — Next.js, React, TypeScript.",
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

Ab jab kisi page mein `title: "Projects"` set karte ho, toh template use hoga → "Projects | Pravin". Default wo hai jab page kuch set na kare. **Ek jagah define, sab pages pe consistent.**

## Open Graph — Social Media Share

LinkedIn/WhatsApp pe link share karte ho toh ek preview dikhta hai — title, description, image. Wo **Open Graph** tags hain:

```tsx
export const metadata: Metadata = {
  title: "My Blog Post",
  description: "Post ka excerpt.",
  openGraph: {
    title: "My Blog Post",
    description: "Post ka excerpt.",
    images: ["https://example.com/blog-image.png"],
  },
};
```

`openGraph` object se social platforms ko preview data milta hai. Baad mein aage batches mein ise aur detail mein use karenge.

## Minimal Example — Product Page With Metadata

Ab 2.1 ke product page mein metadata jodte hain:

```tsx
// app/products/page.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "Products",
  description: "Hamari products ki list — latest tech gadgets.",
};

interface Product {
  id: number;
  title: string;
  price: number;
}

interface ProductsResponse {
  products: Product[];
}

export default async function ProductsPage() {
  const res = await fetch("https://dummyjson.com/products", {
    next: { revalidate: 60 },
  });
  const data: ProductsResponse = await res.json();

  return (
    <main>
      <h1>Products</h1>
      <ul>
        {data.products.map((product) => (
          <li key={product.id}>
            {product.title} — ${product.price}
          </li>
        ))}
      </ul>
    </main>
  );
}
```

Ab browser tab mein "Products | Pravin" dikhega (layout template se), aur description SEO ke liye HTML mein hai.

## Nutshell

Metadata SEO ka base hai — title + description. Next.js mein `export const metadata` (static) ya `generateMetadata` (dynamic) se set hota hai, server-side. Root layout mein `template` se consistent titles. Open Graph se social preview. React ke manual `<title>` tags se better kyunki server-side render hota hai — Google usko properly crawl karta hai.

---

## Common Mistakes

- ❌ `generateMetadata` mein page ka data dobara fetch karna — page aur metadata dono alag fetch karte hain to waste. Same data ko shared function se lao ya `cache()` use karo (aage batch mein).
- ❌ Metadata mein `any` type — `Metadata` type import karo (`import type { Metadata } from "next"`), saari fields typed hain.
- ❌ `generateMetadata` ko async banana bhoolna jab fetch ho raha ho — `await params` aur `await fetch` ke liye async zaroori hai.
- ❌ Root layout mein `title` string ke roop mein likhna jab template use kar rahe ho — `{ default, template }` object use karo, warna template override ho jayega.
- ❌ Description na dena — title important hai, par description Google result mein chhota text hai, wo bhi zaroori hai.

## What It Is NOT

⚠️ **Metadata = "sirf browser tab title" nahi.** Title, description, Open Graph, Twitter cards — sab SEO + social sharing ke liye. Google, LinkedIn, WhatsApp sab yahi HTML tags padhte hain.

⚠️ **Metadata = "visibility" guarantee nahi.** SEO metadata set karne se page Google mein turant nahi aa jata. Metadata **rank hone ke liye zaroori condition** hai, par guarantee nahi.

⚠️ **`generateMetadata` = "render-time fetch" nahi.** Ye build time (static) ya request time (dynamic) pe chal sakta hai — rendering strategy (2.3) se decide hota hai. `generateMetadata` khud strategy nahi badalta.
