# Doc 4.0 — Fetching from Public API with TanStack Query

## Cheat Sheet (Quick Recall)

- TanStack Query: `useQuery({ queryKey, queryFn })` for fetching.
- Handles loading/error/success states, caching, refetch, stale data.
- `useMutation` for POST/PUT/DELETE.
- `QueryClientProvider` wraps app.
- Better than raw `useEffect`+fetch (caching, dedup, retry).

### SOCH

Movie browser mein movies public API se fetch hongi (TMDB). Raw `useEffect`+`fetch` kaam karta hai lekin caching, retry, loading states manually handle karne padte hain. TanStack Query yeh sab handle karta hai. Pehle raw fetch (feel problem), phir TanStack Query (solution), phir query key, caching, refetch.

### CONCEPT

**Raw fetch (problem):**

```tsx
const [movies, setMovies] = useState([]);
const [loading, setLoading] = useState(true);
const [error, setError] = useState(null);

useEffect(() => {
  setLoading(true);
  fetch("https://api.example.com/movies")
    .then((r) => r.json())
    .then(setMovies)
    .catch(setError)
    .finally(() => setLoading(false));
}, []);
```

Manual loading/error/caching/retry — boilerplate.

**TanStack Query (solution):**

```tsx
import { useQuery } from "@tanstack/react-query";

const { data, isLoading, isError, error, refetch } = useQuery({
  queryKey: ["movies"],
  queryFn: async () => {
    const res = await fetch("https://api.example.com/movies");
    if (!res.ok) throw new Error("Failed");
    return res.json();
  },
});
```

- `data` — fetched data (undefined while loading).
- `isLoading` — true initially.
- `isError` / `error` — error state.
- `refetch` — manual refetch.

**Setup (QueryClientProvider):**

```tsx
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";

const queryClient = new QueryClient();

export default function RootLayout() {
  return (
    <QueryClientProvider client={queryClient}>
      <Stack />
    </QueryClientProvider>
  );
}
```

**Query key:** array identifying query; caching/refetch based on it. `["movies", { page }]` for paginated.

**Stale time / cache:**

```tsx
useQuery({ queryKey: ["movies"], queryFn, staleTime: 5 * 60 * 1000 }); // 5 min fresh
```

**useMutation (POST/PUT/DELETE):**

```tsx
const mutation = useMutation({
  mutationFn: (newMovie) => fetch("/api/movies", { method: "POST", body: JSON.stringify(newMovie) }),
  onSuccess: () => queryClient.invalidateQueries({ queryKey: ["movies"] }),
});
mutation.mutate({ title: "New" });
```

## Common Mistakes

- `QueryClientProvider` missing → `useQuery` error.
- Query key unstable (new object each render) → infinite refetch.
- `isLoading` vs `isFetching` confuse — `isLoading` initial only.
- Error not thrown in queryFn (fetch doesn't throw on 404) → check `res.ok`.

## What It Is NOT

- ❌ TanStack Query is **not** a state manager — server state only.
- ❌ It does **not** replace Redux/Zustand for client state.
- ❌ `isLoading` is **not** `isFetching`.
