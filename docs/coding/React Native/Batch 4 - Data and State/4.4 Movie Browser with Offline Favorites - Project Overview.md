**Favorites store (Zustand + AsyncStorage):**

```tsx
const useFavStore = create((set, get) => ({
  favorites: [] as number[],
  load: async () => {
    const raw = await AsyncStorage.getItem("favorites");
    set({ favorites: raw ? JSON.parse(raw) : [] });
  },
  toggle: async (id: number) => {
    const ids = get().favorites;
    const next = ids.includes(id) ? ids.filter((i) => i !== id) : [...ids, id];
    set({ favorites: next });
    await AsyncStorage.setItem("favorites", JSON.stringify(next));
  },
}));
```

## Common Mistakes

- API key in code (use env vars — Batch 7).
- Query key unstable (new object) → infinite refetch.
- Favorites not persisted → lost on close.
- `enabled` missing on search → fetch empty query.
