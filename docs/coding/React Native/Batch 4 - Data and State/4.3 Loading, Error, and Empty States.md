# Doc 4.3 — Loading, Error, and Empty States

## Cheat Sheet (Quick Recall)

- Loading: spinner/skeleton while fetching.
- Error: message + retry button.
- Empty: "No results" message + CTA.
- Pattern: `isLoading` → spinner; `isError` → error+retry; `data?.length === 0` → empty; else list.
- Skeleton screens better than spinners for perceived speed.

### SOCH

### CONCEPT

**Loading state:**

```tsx
if (isLoading) {
  return (
    <View className="flex-1 items-center justify-center">
      <ActivityIndicator size="large" />
    </View>
  );
}
```

**Error state:**

```tsx
if (isError) {
  return (
    <View className="flex-1 items-center justify-center p-4">
      <Text className="text-red-500 mb-4">{error?.message ?? "Something went wrong"}</Text>
      <Pressable onPress={() => refetch()} className="bg-blue-500 px-4 py-2 rounded">
        <Text className="text-white">Retry</Text>
      </Pressable>
    </View>
  );
}
```

**Empty state:**

```tsx
if (!data || data.length === 0) {
  return (
    <View className="flex-1 items-center justify-center p-4">
      <Text className="text-gray-500 mb-2">No movies found</Text>
      <Pressable onPress={() => refetch()}>
        <Text className="text-blue-500">Refresh</Text>
      </Pressable>
    </View>
  );
}
```

**Combined pattern:**

```tsx
const { data, isLoading, isError, error, refetch } = useQuery(...);

if (isLoading) return <Loading />;
if (isError) return <Error message={error?.message} onRetry={refetch} />;
if (!data?.length) return <Empty onRefresh={refetch} />;
return <MovieList data={data} />;
```

**Skeleton screens (advanced):**

Instead of spinner, show placeholder shapes (gray boxes) that mimic content. Better perceived speed. Libraries: `react-native-skeleton-placeholder`.

**Pull-to-refresh:**

```tsx
<FlatList
  data={data}
  refreshing={isFetching && !isLoading}
  onRefresh={refetch}
  ...
/>
```

### CODE (gradual)

Stage 1 — No states (problem: blank screen):

```tsx
const { data } = useQuery(...);
return <FlatList data={data} ... />; // blank while loading
```

Stage 2 — Loading spinner:

```tsx
if (isLoading) return <ActivityIndicator />;
```

Stage 3 — Error + retry:

```tsx
if (isError) return <ErrorView onRetry={refetch} />;
```

Stage 4 — Empty state:

```tsx
if (!data?.length) return <EmptyView />;
```

Stage 5 — Combined + pull-to-refresh:

```tsx
<FlatList data={data} refreshing={isFetching && !isLoading} onRefresh={refetch} ... />
```

## Common Mistakes

- `isLoading` ke bajaye `isFetching` use (spinner flickers on refetch).
- Error state mein retry nahi dena → user stuck.
- Empty state na dikhana → blank screen confuses.
- Skeleton na use karna jab simple spinner kaafi hai (over-engineering).

## What It Is NOT

- ❌ `isLoading` is **not** `isFetching`.
- ❌ Empty state is **not** error state.
- ❌ Spinner is **not** always best — skeleton for lists.
