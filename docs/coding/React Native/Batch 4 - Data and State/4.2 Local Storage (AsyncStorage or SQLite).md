# Doc 4.2 — Local Storage (AsyncStorage or SQLite)

## Cheat Sheet (Quick Recall)

- AsyncStorage: simple key-value, async, string only (JSON.stringify).
- SQLite (expo-sqlite): relational, queries, larger data.
- Use AsyncStorage for small prefs/favorites; SQLite for structured/large data.
- Always handle load (async) + loading state.

## Where We Are So Far

## Main Content

### THINK

Favorites are in global state (Zustand). But state is lost when the app closes. Offline favorites are needed → persist. AsyncStorage is simple key-value (small data). SQLite is structured/large data. First AsyncStorage (simple), then SQLite (complex), then choose.

### CONCEPT

**AsyncStorage (key-value):**

```tsx
import AsyncStorage from "@react-native-async-storage/async-storage";

// Save
await AsyncStorage.setItem("favorites", JSON.stringify(favIds));

// Load
const raw = await AsyncStorage.getItem("favorites");
const favs = raw ? JSON.parse(raw) : [];

// Remove
await AsyncStorage.removeItem("favorites");
```

- String only → `JSON.stringify`/`parse`.
- Async → await.
- Small data (prefs, favorites, tokens? no — tokens → SecureStore).

**SQLite (expo-sqlite):**

```tsx
import * as SQLite from "expo-sqlite";

const db = await SQLite.openDatabaseAsync("movies.db");

await db.execAsync(`
  CREATE TABLE IF NOT EXISTS favorites (id TEXT PRIMARY KEY, title TEXT, poster TEXT);
`);

await db.runAsync("INSERT INTO favorites (id, title, poster) VALUES (?, ?, ?)", [id, title, poster]);

const rows = await db.getAllAsync("SELECT * FROM favorites");
```

- Relational, queries, larger data.
- Async API.

**When to use which:**

| Need | Pick |
|------|------|
| Small prefs, favorites (ids), theme | AsyncStorage |
| Structured data, search, large lists | SQLite |
| Tokens/secrets | SecureStore (not these) |

**Loading state on app start:**

```tsx
const [loaded, setLoaded] = useState(false);
useEffect(() => {
  (async () => {
    const raw = await AsyncStorage.getItem("favorites");
    setFavorites(raw ? JSON.parse(raw) : []);
    setLoaded(true);
  })();
}, []);
if (!loaded) return <ActivityIndicator />;
```

### CODE (gradual)

Stage 1 — In-memory (problem: lost on close):

```tsx
const [favorites, setFavorites] = useState<string[]>([]);
```

Stage 2 — AsyncStorage save:

```tsx
const saveFavs = async (ids: string[]) => {
  await AsyncStorage.setItem("favorites", JSON.stringify(ids));
};
```

Stage 3 — AsyncStorage load on mount:

```tsx
useEffect(() => {
  (async () => {
    const raw = await AsyncStorage.getItem("favorites");
    if (raw) setFavorites(JSON.parse(raw));
  })();
}, []);
```

Stage 4 — SQLite (structured):

```tsx
const db = await SQLite.openDatabaseAsync("app.db");
await db.execAsync("CREATE TABLE IF NOT EXISTS favs (id TEXT PRIMARY KEY, title TEXT)");
```

Stage 5 — Loading state:

```tsx
if (!loaded) return <ActivityIndicator />;
```

## Common Mistakes

- Storing an object directly in AsyncStorage (strings only).
- Not handling the async load → flash of empty state.
- Storing tokens in AsyncStorage (insecure) — use SecureStore.
- Assuming SQLite queries are sync (they are async).
