### CONCEPT

**What is NativeWind:**

Tailwind CSS for React Native. Tailwind classes (`flex-1`, `bg-white`, `p-4`) `className` prop se apply hote hain. Behind the scenes same `StyleSheet` generate hota hai.

**Setup (Expo):**

```bash
npx expo install nativewind tailwindcss
npx tailwindcss init
```

Configure `babel.config.js`:

```js
module.exports = function (api) {
  api.cache(true);
  return {
    presets: ["babel-preset-expo"],
    plugins: ["nativewind/babel"],
  };
};
```

Configure `tailwind.config.js`:

```js
module.exports = {
  content: ["./app/**/*.{js,jsx,ts,tsx}", "./components/**/*.{js,jsx,ts,tsx}"],
  theme: { extend: {} },
  plugins: [],
};
```

**Usage:**

```tsx
import { View, Text } from "react-native";

<View className="flex-1 bg-white p-4">
  <Text className="text-lg font-bold text-gray-800">Hello</Text>
</View>
```

**Dark mode:**

```tsx
<View className="bg-white dark:bg-black">
  <Text className="text-black dark:text-white">Hello</Text>
</View>
```

**When StyleSheet, when NativeWind:**

- NativeWind: rapid styling, Tailwind familiarity, theming.
- StyleSheet: complex platform-specific (shadows), libraries expect it, precise control.
- Learn both — many projects use StyleSheet.

### CODE (gradual)

Stage 1 — StyleSheet (Batch 1 way):

```tsx
<View style={{ flex: 1, backgroundColor: "#fff", padding: 16 }}>
  <Text style={{ fontSize: 18, fontWeight: "bold" }}>Hello</Text>
</View>
```

Stage 2 — NativeWind equivalent:

```tsx
<View className="flex-1 bg-white p-4">
  <Text className="text-lg font-bold">Hello</Text>
</View>
```

Stage 3 — Dark mode:

```tsx
<View className="flex-1 bg-white dark:bg-black p-4">
  <Text className="text-black dark:text-white">Hello</Text>
</View>
```

Stage 4 — Mixed (NativeWind + StyleSheet for shadow):

```tsx
<View className="bg-white p-4 rounded-xl" style={{ elevation: 4 }}>
  <Text className="text-lg">Card</Text>
</View>
```

## Common Mistakes

- Babel plugin configure na karna → `className` kaam nahi karega.
- `content` paths galat in tailwind config → classes purge ho jayengi.
- StyleSheet completely bhoolna — many libs expect it.
- Tailwind web classes assume (hover, focus) — RN mein limited.

## What It Is NOT

- ❌ NativeWind is **not** a replacement for StyleSheet — both coexist.
- ❌ Tailwind web classes (hover) are **not** all available in RN.
- ❌ Setup is **not** automatic — babel + config needed.
