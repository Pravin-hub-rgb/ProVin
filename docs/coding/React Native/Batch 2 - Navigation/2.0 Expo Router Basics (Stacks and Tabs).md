# Doc 2.0 — Expo Router Basics (Stacks and Tabs)

## Cheat Sheet (Quick Recall)

- Expo Router = file-based routing; files in `app/` become routes.
- `_layout.tsx` defines layout for a folder (Stack/Tab navigator).
- `Stack` for stack navigation; `Tabs` for bottom tabs.
- Navigate with `Link` or `router.push()`/`router.replace()`.
- Route groups: folders in parentheses `(group)` don't affect URL.

### CONCEPT

**File-based routing:**

- `app/index.tsx` → `/`
- `app/about.tsx` → `/about`
- `app/notes/[id].tsx` → `/notes/:id` (dynamic)

**Layouts (`_layout.tsx`):**

Folder mein `_layout.tsx` define karta hai ki us folder ke screens kaise navigate honge (Stack/Tabs).

**Stack navigator:**

```tsx
// app/_layout.tsx
import { Stack } from "expo-router";

export default function RootLayout() {
  return <Stack />;
}
```

Default Stack: push/pop with back button.

**Tab navigator:**

```tsx
// app/(tabs)/_layout.tsx
import { Tabs } from "expo-router";

export default function TabLayout() {
  return (
    <Tabs>
      <Tabs.Screen name="index" options={{ title: "Home" }} />
      <Tabs.Screen name="settings" options={{ title: "Settings" }} />
    </Tabs>
  );
}
```

Bottom tabs with icons/titles.

**Navigation (programmatic):**

```tsx
import { router } from "expo-router";
router.push("/notes/123");
router.replace("/login");
router.back();
```

**Declarative:**

```tsx
import { Link } from "expo-router";
<Link href="/about">About</Link>
```

**Route groups:** `(auth)`, `(tabs)` folders URL mein nahi aate — grouping only.

### CODE (gradual)

Stage 1 — Static two screens (no nav):

```tsx
// app/index.tsx
export default function Home() { return <Text>Home</Text>; }
// app/about.tsx
export default function About() { return <Text>About</Text>; }
```

Save, manually URL change nahi kar sakte (no nav).

Stage 2 — Stack layout:

```tsx
// app/_layout.tsx
import { Stack } from "expo-router";
export default function RootLayout() { return <Stack />; }
```

Now screens stack pe push/pop honge (back button).

Stage 3 — Link between screens:

```tsx
import { Link } from "expo-router";
<Link href="/about">Go to About</Link>
```

Stage 4 — Programmatic nav:

```tsx
import { router } from "expo-router";
<Pressable onPress={() => router.push("/about")}>Go</Pressable>
```

Stage 5 — Tabs layout:

```tsx
// app/(tabs)/_layout.tsx
import { Tabs } from "expo-router";
export default function TabLayout() {
  return (
    <Tabs>
      <Tabs.Screen name="index" options={{ title: "Home" }} />
      <Tabs.Screen name="settings" options={{ title: "Settings" }} />
    </Tabs>
  );
}
```

## Common Mistakes

- `_layout.tsx` missing → default behavior confusing.
- Route group folders `(tabs)` ko URL mein include karna — nahi aate.
- `router.push` vs `router.replace` confuse — push back stack add, replace nahi.
- Dynamic route file `[id].tsx` ko normal file samajhna.

## Summary

- Expo Router = file-based; `_layout.tsx` = navigator (Stack/Tabs).
- Navigate via `Link` or `router.push/replace/back`.
- Route groups `(name)` URL mein nahi aate.

<details>
<summary>Sample Answer</summary>

**Answer:** Stack for push/pop flows (detail screens); Tabs for top-level sections (bottom bar).

## What It Is NOT

- ❌ Expo Router is **not** React Router — file-based, not config-based.
- ❌ Route groups are **not** URL segments.
- ❌ `_layout.tsx` is **not** optional for custom navigation.
