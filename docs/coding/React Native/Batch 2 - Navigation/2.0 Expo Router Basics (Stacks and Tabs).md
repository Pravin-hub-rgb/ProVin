# Doc 2.0 — Expo Router Basics (Stacks and Tabs)

## Cheat Sheet (Quick Recall)

- Expo Router = file-based routing; files in `app/` become routes.
- `_layout.tsx` defines the layout for a folder (Stack/Tab navigator).
- `Stack` for stack navigation; `Tabs` for bottom tabs.
- Navigate with `Link` or `router.push()`/`router.replace()`.
- Route groups: folders in parentheses `(group)` do not affect the URL.

### CONCEPT

**File-based routing:**

- `app/index.tsx` → `/`
- `app/about.tsx` → `/about`
- `app/notes/[id].tsx` → `/notes/:id` (dynamic)

**Layouts (`_layout.tsx`):**

A `_layout.tsx` in a folder defines how that folder's screens navigate (Stack/Tabs).

**Stack navigator:**

```tsx
// app/_layout.tsx
import { Stack } from "expo-router";

export default function RootLayout() {
  return <Stack />;
}
```

Default Stack: push/pop with a back button.

**Tab navigator:**

```tsx
// app/(tabs)/_layout.tsx
import { Tabs } from "expo-router";

export default function TabLayout() {
  return (
    <Tabs>
      <Tabs.Screen name="index" options={{ title: "Home" }} />
      <Tabs.Screen name="settings" options={{ title: "Settings" }} />
    </Tabs>
  );
}
```

Bottom tabs with icons/titles.

**Programmatic navigation:**

```tsx
import { router } from "expo-router";
router.push("/notes/123");
router.replace("/login");
router.back();
```

**Declarative navigation:**

```tsx
import { Link } from "expo-router";
<Link href="/about">About</Link>
```

**Route groups:** `(auth)`, `(tabs)` folders do not appear in the URL — grouping only.

### CODE (gradual)

Stage 1 — Static two screens (no nav):

```tsx
// app/index.tsx
export default function Home() { return <Text>Home</Text>; }
// app/about.tsx
export default function About() { return <Text>About</Text>; }
```

Save — you cannot change URLs manually (no nav).

Stage 2 — Stack layout:

```tsx
// app/_layout.tsx
import { Stack } from "expo-router";
export default function RootLayout() { return <Stack />; }
```

Now screens push/pop on the stack (back button available).

Stage 3 — Link between screens:

```tsx
import { Link } from "expo-router";
<Link href="/about">Go to About</Link>
```

Stage 4 — Programmatic nav:

```tsx
import { router } from "expo-router";
<Pressable onPress={() => router.push("/about")}>Go</Pressable>
```

Stage 5 — Tabs layout:

```tsx
// app/(tabs)/_layout.tsx
import { Tabs } from "expo-router";
export default function TabLayout() {
  return (
    <Tabs>
      <Tabs.Screen name="index" options={{ title: "Home" }} />
      <Tabs.Screen name="settings" options={{ title: "Settings" }} />
    </Tabs>
  );
}
```

## Common Mistakes

- Missing `_layout.tsx` → confusing default behavior.
- Including route group folders like `(tabs)` in the URL — they do not appear.
- Confusing `router.push` vs `router.replace` — push adds to the back stack, replace does not.
- Treating a dynamic route file `[id].tsx` as a normal file.

## Try It Yourself

## Summary

- Expo Router is file-based; `_layout.tsx` defines the navigator (Stack/Tabs).
- Navigate via `Link` or `router.push/replace/back`.
- Route groups `(name)` do not appear in the URL.

## What It Is NOT

- ❌ Expo Router is **not** React Router — file-based, not config-based.
- ❌ Route groups are **not** URL segments.
- ❌ `_layout.tsx` is **not** optional for custom navigation.
