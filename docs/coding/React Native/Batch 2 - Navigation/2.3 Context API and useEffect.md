# Doc 2.3 — Context API and useEffect

## Cheat Sheet (Quick Recall)

- `createContext` + `Provider` + `useContext` for global state without prop drilling.
- `useEffect` runs after render; the dependency array controls when.
- Cleanup function in `useEffect` prevents leaks.
- Context for auth/theme/notes; not for high-frequency updates (use Redux/Zustand).

### CONCEPT

**Context API:**

```tsx
// contexts/NotesContext.tsx
import { createContext, useContext, useState, ReactNode } from "react";

type Note = { id: string; title: string; body: string };
type Ctx = { notes: Note[]; addNote: (n: Note) => void };

const NotesContext = createContext<Ctx | null>(null);

export function NotesProvider({ children }: { children: ReactNode }) {
  const [notes, setNotes] = useState<Note[]>([]);
  const addNote = (n: Note) => setNotes((prev) => [...prev, n]);
  return <NotesContext.Provider value={{ notes, addNote }}>{children}</NotesContext.Provider>;
}

export const useNotes = () => useContext(NotesContext)!;
```

- `createContext` creates the container.
- `Provider` supplies the value.
- `useContext` consumes it (custom hook `useNotes`).
- Avoids prop drilling.

**useEffect:**

```tsx
useEffect(() => {
  // runs after render
  return () => {
    // cleanup before next run / unmount
  };
}, [deps]);
```

- `[]` → run once on mount.
- `[x]` → run when `x` changes.
- Cleanup → prevents leaks (timers, subscriptions).

**Fetch on mount:**

```tsx
useEffect(() => {
  let ignore = false;
  fetchNotes().then((data) => {
    if (!ignore) setNotes(data);
  });
  return () => { ignore = true; };
}, []);
```

The ignore flag prevents state updates after unmount.

### CODE (gradual)

Stage 1 — Context (no effect):

```tsx
const NotesContext = createContext<Note[]>([]);
// Provider + consumer
```

Stage 2 — Provider with state + add:

```tsx
function NotesProvider({ children }) {
  const [notes, setNotes] = useState<Note[]>([]);
  const addNote = (n) => setNotes((p) => [...p, n]);
  return <NotesContext.Provider value={{ notes, addNote }}>{children}</NotesContext.Provider>;
}
```

Stage 3 — useEffect fetch on mount:

```tsx
useEffect(() => {
  fetch("/api/notes").then((r) => r.json()).then(setNotes);
}, []);
```

Stage 4 — Cleanup (ignore flag):

```tsx
useEffect(() => {
  let ignore = false;
  fetch("/api/notes").then((r) => r.json()).then((d) => { if (!ignore) setNotes(d); });
  return () => { ignore = true; };
}, []);
```

Stage 5 — Timer cleanup (memory leak prevention):

```tsx
useEffect(() => {
  const id = setInterval(() => setTick((t) => t + 1), 1000);
  return () => clearInterval(id);
}, []);
```

## Common Mistakes

- Using Context for high-frequency updates (re-renders the entire tree) — use Redux/Zustand.
- Missing `useEffect` dependencies → infinite loop or stale data.
- Missing cleanup → memory leak (timers/subscriptions).
- State update after unmount → warning; use an ignore flag.

## Summary

- Context: `createContext` + `Provider` + `useContext` for shared state.
- useEffect: side effects after render; deps control timing; cleanup prevents leaks.
- Use an ignore flag for fetch cleanup.
