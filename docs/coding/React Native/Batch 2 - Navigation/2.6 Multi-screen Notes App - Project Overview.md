### CONCEPT

**Goal:** Multi-screen notes app:

- Notes list (tab) → tap → detail screen.
- Add note (form) → saves to Context.
- Settings tab (profile/logout).
- Login gate for protected notes.
- NativeWind styling + safe areas.

**Screens:**

```
app/
├── _layout.tsx          # AuthProvider + Stack
├── login.tsx            # Login screen
├── (tabs)/
│   ├── _layout.tsx      # Tabs: Notes + Settings
│   ├── index.tsx        # Notes list
│   └── settings.tsx     # Settings
├── notes/
│   └── [id].tsx         # Note detail
└── add-note.tsx         # Add note form
```

**Data model:**

```ts
type Note = { id: string; title: string; body: string; createdAt: number };
```

Field reasons:

- `id` — unique handle for detail route + delete.
- `title` — list item + detail header.
- `body` — detail content.
- `createdAt` — sort order.

**State (Context):**

```tsx
const [notes, setNotes] = useState<Note[]>([]);
const addNote = (n: Note) => setNotes((p) => [n, ...p]);
const deleteNote = (id: string) => setNotes((p) => p.filter((n) => n.id !== id));
```

### CODE (sample pieces)

Context provider:

```tsx
type Note = { id: string; title: string; body: string; createdAt: number };

const NotesContext = createContext<{ notes: Note[]; addNote: (n: Note) => void; deleteNote: (id: string) => void } | null>(null);

export function NotesProvider({ children }) {
  const [notes, setNotes] = useState<Note[]>([]);
  const addNote = (n: Note) => setNotes((p) => [n, ...p]);
  const deleteNote = (id: string) => setNotes((p) => p.filter((n) => n.id !== id));
  return <NotesContext.Provider value={{ notes, addNote, deleteNote }}>{children}</NotesContext.Provider>;
}
```

Detail screen:

```tsx
const { id } = useLocalSearchParams<{ id: string }>();
const { notes } = useNotes();
const note = notes.find((n) => n.id === id);
if (!note) return <Text>Not found</Text>;
```

## Common Mistakes

- Context provider not wrapping app root → `useNotes` null.
- Dynamic route param not typed → runtime errors.
- Auth check in component instead of layout → flash of protected content.
- Safe area missing → content under notch.
