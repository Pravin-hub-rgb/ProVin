# Doc 2.5 — Safe Areas and Tab Layout

## Cheat Sheet (Quick Recall)

- `SafeAreaView` from `react-native-safe-area-context` keeps content clear of notch/home indicator.
- Tab layout in `app/(tabs)/_layout.tsx` with `Tabs` + `Tabs.Screen`.
- Tab icons via `options={{ tabBarIcon }}` (Ionicons/Expo vector icons).
- Safe area + tab bar = content not hidden behind tab bar or notch.

## Main Content

### SOCH

NativeWind ready. Lekin phone pe notch aur tab bar content ko hide kar sakte hain. Safe areas (notch/home indicator) + tab bar (bottom) ke liye proper layout chahiye. Pehle safe area (single screen), phir tab layout (bottom tabs), phir combine (safe area + tabs).

### CONCEPT

**SafeAreaView:**

```tsx
import { SafeAreaView } from "react-native-safe-area-context";

<SafeAreaView style={{ flex: 1 }}>
  {/* content clear of notch/home indicator */}
</SafeAreaView>
```

Expo sets up `react-native-safe-area-context` by default.

**Tab layout:**

```tsx
// app/(tabs)/_layout.tsx
import { Tabs } from "expo-router";
import { Ionicons } from "@expo/vector-icons";

export default function TabLayout() {
  return (
    <Tabs screenOptions={{ tabBarActiveTintColor: "#007AFF" }}>
      <Tabs.Screen
        name="index"
        options={{
          title: "Notes",
          tabBarIcon: ({ color }) => <Ionicons name="list" size={24} color={color} />,
        }}
      />
      <Tabs.Screen
        name="settings"
        options={{
          title: "Settings",
          tabBarIcon: ({ color }) => <Ionicons name="settings" size={24} color={color} />,
        }}
      />
    </Tabs>
  );
}
```

**Safe area + tabs (combined):**

Tabs automatically handle bottom safe area for tab bar. Content area mein `SafeAreaView` ya `useSafeAreaInsets` use karo for top notch.

```tsx
import { useSafeAreaInsets } from "react-native-safe-area-context";

const insets = useSafeAreaInsets();
<View style={{ paddingTop: insets.top, flex: 1 }}>...</View>
```

### CODE (gradual)

Stage 1 — SafeAreaView single screen:

```tsx
<SafeAreaView className="flex-1 bg-white">
  <Text className="p-4">Content clear of notch</Text>
</SafeAreaView>
```

Stage 2 — Tab layout (no icons):

```tsx
<Tabs>
  <Tabs.Screen name="index" options={{ title: "Notes" }} />
  <Tabs.Screen name="settings" options={{ title: "Settings" }} />
</Tabs>
```

Stage 3 — Add icons:

```tsx
<Tabs.Screen name="index" options={{ title: "Notes", tabBarIcon: ({ color }) => <Ionicons name="list" size={24} color={color} /> }} />
```

Stage 4 — Safe area insets in content:

```tsx
const insets = useSafeAreaInsets();
<View style={{ paddingTop: insets.top, flex: 1 }}>...</View>
```

## Common Mistakes

- Core `SafeAreaView` use karna (deprecated).
- Tab bar ke peeche content chhupna — `useSafeAreaInsets` ya `SafeAreaView` use karo.
- Tab icon missing → default placeholder.
- Route group `(tabs)` ko URL mein include karna.

1. How do you keep content away from the notch?

**Answer:** Use `SafeAreaView` or `useSafeAreaInsets` from `react-native-safe-area-context`.

</details>

2. Where is the tab layout defined?

<details>
<summary>Sample Answer</summary>

**Answer:** In `app/(tabs)/_layout.tsx`.

**Answer:** Via `tabBarIcon` in `Tabs.Screen` options.

</details>

4. Why use route groups like `(tabs)`?

<details>
<summary>Sample Answer</summary>

**Answer:** To group routes without affecting the URL.

</details>

5. What does `useSafeAreaInsets` return?

<details>
<summary>Sample Answer</summary>

**Answer:** Insets for top/bottom/left/right safe areas.

</details>

## What It Is NOT

- ❌ Core `SafeAreaView` is **not** recommended (deprecated).
- ❌ Tab bar does **not** auto-handle content padding (use insets).
- ❌ Route groups are **not** URL segments.
