# Doc 2.1 — Dynamic Routes and Detail Screen

## Cheat Sheet (Quick Recall)

- Dynamic route file: `app/notes/[id].tsx` → `/notes/:id`.
- Read param: `useParams()` from `expo-router` → `{ id }`.
- Pass data via param or fetch by id.
- `useLocalSearchParams()` for query params.
- Always handle missing/invalid id (guard).

## Main Content

### SOCH

Notes app mein notes list hogi, aur har note ka detail screen. URL mein note id hoga (`/notes/123`). Dynamic route chahiye. Web pe React Router `:id`; Expo Router mein `[id].tsx` file. Pehle dynamic route file, phir param read, phir data fetch/show, phir guard (invalid id).

### CONCEPT

**Dynamic route file:**

File name in brackets: `app/notes/[id].tsx` → route `/notes/:id`.

**Read param:**

```tsx
import { useLocalSearchParams } from "expo-router";

export default function NoteDetail() {
  const { id } = useLocalSearchParams<{ id: string }>();
  return <Text>Note: {id}</Text>;
}
```

- `useLocalSearchParams` returns object with route params.
- Type with generic for safety.

**Data handling:**

- Option A: pass data via param (limited, URL length).
- Option B: fetch by id (TanStack Query, Batch 4).
- For now: local array lookup by id.

**Guard (invalid id):**

```tsx
const note = notes.find((n) => n.id === id);
if (!note) return <Text>Not found</Text>;
```

### CODE (gradual)

Stage 1 — Static detail (hardcoded):

```tsx
// app/notes/detail.tsx
export default function Detail() {
  return <Text>Note title here</Text>;
}
```

Stage 2 — Dynamic route file + param read:

```tsx
// app/notes/[id].tsx
import { useLocalSearchParams } from "expo-router";
import { Text, View } from "react-native";

export default function NoteDetail() {
  const { id } = useLocalSearchParams<{ id: string }>();
  return (
    <View style={{ flex: 1, padding: 16 }}>
      <Text>Note ID: {id}</Text>
    </View>
  );
}
```

Save, navigate `/notes/123` → "Note ID: 123".

Stage 3 — Data lookup:

```tsx
const { id } = useLocalSearchParams<{ id: string }>();
const note = notes.find((n) => n.id === id);
```

Stage 4 — Guard + render:

```tsx
if (!note) return <Text>Not found</Text>;
return (
  <View style={{ flex: 1, padding: 16 }}>
    <Text style={{ fontSize: 20, fontWeight: "bold" }}>{note.title}</Text>
    <Text>{note.body}</Text>
  </View>
);
```

Stage 5 — Navigate from list:

```tsx
// app/index.tsx (list)
import { router } from "expo-router";
<Pressable onPress={() => router.push(`/notes/${note.id}`)}>
  <Text>{note.title}</Text>
</Pressable>
```

## Common Mistakes

- `useParams` (React Router) use karna — Expo Router mein `useLocalSearchParams`.
- Param type ignore karna — string vs number confusion.
- Guard missing → crash on invalid id.
- Data pass via param overuse — URL length limits.

## Summary

- Dynamic route: `[id].tsx` → `/notes/:id`.
- Read with `useLocalSearchParams<{ id: string }>()`.
- Guard invalid id; navigate via `router.push`.

## What It Is NOT

- ❌ Dynamic route is **not** a normal file — brackets matter.
- ❌ `useLocalSearchParams` is **not** `useParams` (React Router).
- ❌ Param is **not** auto-fetched data — you fetch/lookup yourself.
