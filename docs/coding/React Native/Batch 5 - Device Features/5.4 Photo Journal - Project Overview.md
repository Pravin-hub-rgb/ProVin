### CONCEPT

**Goal:** Photo journal:

- Capture photo (camera) or pick from gallery.
- Add note + auto-capture location.
- Save entry (uri, note, location, date).
- Gallery view (list of entries).
- Detail view (photo + note + map link).
- Daily reminder notification.

**Data model:**

```ts
type JournalEntry = {
  id: string;
  uri: string;
  note: string;
  latitude: number | null;
  longitude: number | null;
  createdAt: number;
};
```

Field reasons:

- `id` — unique handle for delete/detail.
- `uri` — photo file uri.
- `note` — user text.
- `latitude/longitude` — location tag (nullable if denied).
- `createdAt` — sort order.

**Screens:**

```
app/
├── index.tsx        # Journal list (FlatList of entries)
├── capture.tsx      # Camera + note + location + save
└── entry/
    └── [id].tsx     # Detail view
```

**Build steps (gradual):**

   - **Checkpoint:** list shows, button visible.

   - **Checkpoint:** deny each → fallback UI.

### CODE (sample pieces)

Capture flow:

```tsx
const takePhoto = async () => {
  const photo = await cameraRef.current?.takePictureAsync();
  if (!photo) return;
  const loc = await Location.getCurrentPositionAsync({ accuracy: Location.Accuracy.Balanced });
  setCaptured({ uri: photo.uri, latitude: loc.coords.latitude, longitude: loc.coords.longitude });
};
```

Save entry:

```tsx
const saveEntry = async () => {
  const entry: JournalEntry = {
    id: Date.now().toString(),
    uri: captured.uri,
    note,
    latitude: captured.latitude,
    longitude: captured.longitude,
    createdAt: Date.now(),
  };
  await saveToStorage(entry);
  router.back();
};
```

## Common Mistakes

- Permission denied not handled → crash/blank.
- Camera ref null (capture before ready) → guard.
- Location fetch blocking UI → show loading.
- Photo uri not persisted (file deleted) → copy to app storage (FileSystem).
