# Doc 5.2 — Local Notifications and Reminders

## Cheat Sheet (Quick Recall)

- `expo-notifications`: schedule local notifications.
- `scheduleNotificationAsync({ content, trigger })`.
- Permission: `requestPermissionsAsync`.
- Handle received notification: `addNotificationReceivedListener`.
- Handle tap: `addNotificationResponseReceivedListener`.

## Main Content

### SOCH

Photo journal mein daily reminder chahiye ("time to take a photo"). Local notifications (device pe schedule) use karo. Push notifications (server) advanced; local enough for reminders. Pehle permission, phir schedule, phir handle received/tap.

### CONCEPT

**Permission:**

```tsx
import * as Notifications from "expo-notifications";

const { status } = await Notifications.requestPermissionsAsync();
if (status !== "granted") { /* handle */ }
```

**Schedule notification:**

```tsx
await Notifications.scheduleNotificationAsync({
  content: {
    title: "Photo time!",
    body: "Take your daily photo",
    data: { screen: "camera" },
  },
  trigger: {
    seconds: 60, // or { hour: 9, minute: 0, repeats: true }
  },
});
```

**Trigger types:**

- `{ seconds: 60 }` — after 60s.
- `{ date: new Date(...) }` — at specific date.
- `{ hour, minute, repeats: true }` — daily at time.

**Handle received (app foreground):**

```tsx
Notifications.addNotificationReceivedListener((notification) => {
  console.log("Received:", notification);
});
```

**Handle tap (user tapped notification):**

```tsx
Notifications.addNotificationResponseReceivedListener((response) => {
  const screen = response.notification.request.content.data.screen;
  router.push(screen);
});
```

**Cancel:**

```tsx
await Notifications.cancelScheduledNotificationAsync(notificationId);
await Notifications.cancelAllScheduledNotificationsAsync();
```

**Notification handler (foreground display):**

```tsx
Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowAlert: true,
    shouldPlaySound: true,
    shouldSetBadge: false,
  }),
});
```

### CODE (gradual)

Stage 1 — Permission:

```tsx
const { status } = await Notifications.requestPermissionsAsync();
```

Stage 2 — Schedule (60s later):

```tsx
await Notifications.scheduleNotificationAsync({
  content: { title: "Reminder", body: "Take a photo" },
  trigger: { seconds: 60 },
});
```

Stage 3 — Handle tap (navigate):

```tsx
Notifications.addNotificationResponseReceivedListener((r) => {
  router.push("/camera");
});
```

Stage 4 — Daily repeating:

```tsx
trigger: { hour: 9, minute: 0, repeats: true }
```

## Common Mistakes

- Permission na mangna → notification nahi aayega.
- `setNotificationHandler` na set karna → foreground mein nahi dikhega.
- Background pe test na karna → local notification sirf background mein dikhta hai (foreground mein handler se).
- Trigger date past → immediate fire.

## What It Is NOT

- ❌ Local notifications are **not** push notifications (no server).
- ❌ Foreground display is **not** automatic — set handler.
- ❌ Repeating trigger is **not** for one-time.
