## Main Content

### SOCH

Photo journal mein har photo ke saath location (lat/long) save karna hai. `expo-location` use karo. Pehle permission, phir current position, phir watch (live tracking), phir accuracy.

### CONCEPT

**Permission:**

```tsx
import * as Location from "expo-location";

const { status } = await Location.requestForegroundPermissionsAsync();
if (status !== "granted") {
  // show message
}
```

**Current position:**

```tsx
const location = await Location.getCurrentPositionAsync({
  accuracy: Location.Accuracy.High,
});
console.log(location.coords.latitude, location.coords.longitude);
```

**Watch position (live):**

```tsx
const subscription = await Location.watchPositionAsync(
  { accuracy: Location.Accuracy.High, timeInterval: 5000, distanceInterval: 10 },
  (loc) => console.log(loc.coords)
);
// cleanup: subscription.remove();
```

**Background location (advanced):**

Needs `requestBackgroundPermissionsAsync` + `app.json` config (`location` background mode). Only when app in background tracking needed.

**Reverse geocoding:**

```tsx
const [place] = await Location.reverseGeocodeAsync({
  latitude, longitude,
});
console.log(place.city, place.country);
```

### CODE (gradual)

Stage 1 — Permission:

```tsx
const { status } = await Location.requestForegroundPermissionsAsync();
if (status !== "granted") return <Text>Permission denied</Text>;
```

Stage 2 — Current position:

```tsx
const loc = await Location.getCurrentPositionAsync({ accuracy: Location.Accuracy.High });
setLocation(loc.coords);
```

Stage 3 — Display:

```tsx
<Text>Lat: {location.latitude}, Lng: {location.longitude}</Text>
```

Stage 4 — Watch position (live):

```tsx
const sub = await Location.watchPositionAsync({ timeInterval: 5000 }, (l) => setLocation(l.coords));
// cleanup on unmount
```

Stage 5 — Reverse geocode:

```tsx
const [place] = await Location.reverseGeocodeAsync(location);
setText(`${place.city}, ${place.country}`);
```

## Common Mistakes

- Permission na mangna → location null.
- Background location config missing → crash in background.
- `watchPositionAsync` cleanup na karna → battery drain + leak.
- Accuracy too high → slow fetch.

## Summary

- `expo-location`: permission → `getCurrentPositionAsync` / `watchPositionAsync`.
- `Accuracy` enum for precision.
- Background needs separate permission + config.
- Reverse geocode for address.

## What It Is NOT

- ❌ Foreground permission is **not** background permission.
- ❌ `watchPositionAsync` does **not** auto-cleanup.
- ❌ High accuracy is **not** always needed (slower).
