# Doc 5.0 — Camera and Image Picker

## Cheat Sheet (Quick Recall)

- `expo-image-picker`: `launchImageLibraryAsync` (gallery) + `launchCameraAsync` (camera).
- Returns `{ canceled, assets: [{ uri, width, height }] }`.
- `expo-camera`: `CameraView` for live preview + photo capture.
- Permissions: `requestCameraPermissionsAsync`, `requestMediaLibraryPermissionsAsync`.
- Save image: `FileSystem` or upload.

## Main Content

### THINK

The photo journal needs photo capture + gallery pick. `expo-image-picker` is simplest (launch camera/gallery, get a uri). For a live camera preview, `expo-camera`. First image picker (simple), then camera (live preview), then save/display.

### CONCEPT

**Image Picker (gallery/camera):**

```tsx
import * as ImagePicker from "expo-image-picker";

// Gallery
const result = await ImagePicker.launchImageLibraryAsync({
  mediaTypes: ImagePicker.MediaTypeOptions.Images,
  allowsEditing: true,
  aspect: [4, 3],
  quality: 1,
});

if (!result.canceled) {
  const uri = result.assets[0].uri;
  // use uri
}

// Camera
const result = await ImagePicker.launchCameraAsync({
  allowsEditing: true,
  aspect: [4, 3],
  quality: 1,
});
```

**Camera (live preview):**

```tsx
import { CameraView, useCameraPermissions } from "expo-camera";

export default function CameraScreen() {
  const [permission, requestPermission] = useCameraPermissions();
  const cameraRef = useRef<CameraView>(null);

  if (!permission) return <View />;
  if (!permission.granted) {
    return <Pressable onPress={requestPermission}><Text>Grant camera permission</Text></Pressable>;
  }

  const takePhoto = async () => {
    const photo = await cameraRef.current?.takePictureAsync();
    console.log(photo.uri);
  };

  return (
    <View style={{ flex: 1 }}>
      <CameraView ref={cameraRef} style={{ flex: 1 }} facing="back" />
      <Pressable onPress={takePhoto}><Text>Take Photo</Text></Pressable>
    </View>
  );
}
```

**Permissions:**

```tsx
const [status] = await ImagePicker.requestCameraPermissionsAsync();
if (status !== "granted") { /* show message */ }
```

### CODE (gradual)

Stage 1 — Permission check:

```tsx
const [permission, requestPermission] = useCameraPermissions();
if (!permission?.granted) return <Pressable onPress={requestPermission}><Text>Grant</Text></Pressable>;
```

Stage 2 — Image picker (gallery):

```tsx
const pickImage = async () => {
  const result = await ImagePicker.launchImageLibraryAsync({ mediaTypes: ImagePicker.MediaTypeOptions.Images });
  if (!result.canceled) setImage(result.assets[0].uri);
};
```

Stage 3 — Display picked image:

```tsx
{image && <Image source={{ uri: image }} style={{ width: 200, height: 200 }} />}
```

Stage 4 — Camera capture:

```tsx
const cameraRef = useRef<CameraView>(null);
const takePhoto = async () => { const photo = await cameraRef.current?.takePictureAsync(); setImage(photo.uri); };
```

### TEST

Three questions:

1. Which function opens the gallery? (`launchImageLibraryAsync`)
2. Which function captures a photo with the camera? (`takePictureAsync` on a CameraView ref)
3. Which function requests permission? (`requestCameraPermissionsAsync` / `useCameraPermissions`)

**Checkpoint:** Gallery pick → image displays. Camera → capture → image displays. Permission denied → prompt shows.

## Common Mistakes

- Not requesting permission → camera will not open.
- Not checking `result.canceled` → crash on cancel.
- Accessing `assets[0]` without a check.
- Camera preview without the `facing` prop (default is back).

## What It Is NOT

- ❌ The image picker is **not** a live preview — use `CameraView` for that.
- ❌ Permissions are **not** automatic — request them explicitly.
- ❌ Cancel is **not** an error — handle it gracefully.
