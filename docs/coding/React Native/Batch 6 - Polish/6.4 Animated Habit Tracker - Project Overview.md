### CONCEPT

**Goal:** Animated habit tracker:

- Add habit (name, frequency).
- Daily check-in (animated checkmark).
- Streak counter (animated number).
- Swipe to delete.
- Progress ring (animated).
- Dark mode + theming.
- Smooth 60fps.

**Data model:**

```ts
type Habit = {
  id: string;
  name: string;
  streak: number;
  completedDates: string[]; // ISO dates
  createdAt: number;
};
```

Field reasons:

- `id` — unique handle.
- `name` — display.
- `streak` — current streak count (animated).
- `completedDates` — history for streak calc.
- `createdAt` — sort.

**Screens:**

```
app/
├── index.tsx        # Habit list with check-in
├── add-habit.tsx    # Add form
└── stats.tsx        # Streak stats
```

**Animations:**

- Check-in: scale + checkmark draw (Reanimated).
- Streak number: animated counter.
- Swipe to delete: RNGH pan + Reanimated.
- Progress ring: animated SVG circle (react-native-svg + Reanimated).

**Build steps (gradual):**

1. Static skeleton: list with hardcoded habits + check button.
   - **Checkpoint:** list shows, button visible.
2. Check-in: toggle done → animated checkmark (scale).
   - **Checkpoint:** tap → checkmark animates.
3. Streak: calculate + animated number.
   - **Checkpoint:** streak updates on check-in.
4. Swipe to delete: RNGH + Reanimated.
   - **Checkpoint:** swipe left → delete.
5. Progress ring: animated circle.
   - **Checkpoint:** ring fills based on completion %.
6. Dark mode + theming.
   - **Checkpoint:** toggle theme → colors change.
7. Performance: React.memo + useCallback + FlatList perf.
   - **Checkpoint:** smooth 60fps scroll.

### CODE (sample pieces)

Check animation:

```tsx
const scale = useSharedValue(1);
const checkScale = useSharedValue(0);

const toggle = () => {
  checkScale.value = withSpring(done ? 0 : 1);
  scale.value = withSequence(withSpring(0.9), withSpring(1));
};
```

Swipe to delete:

```tsx
const translateX = useSharedValue(0);
const pan = Gesture.Pan()
  .onUpdate((e) => { if (e.translationX < 0) translateX.value = e.translationX; })
  .onEnd((e) => {
    if (e.translationX < -100) translateX.value = withTiming(-300, {}, () => runOnJS(onDelete)(id));
    else translateX.value = withSpring(0);
  });
```

## Common Mistakes

- Animations on the JS thread → jank.
- Swipe threshold too sensitive → accidental deletes.
- Progress ring not cleaned up → memory leak.
- `React.memo` missing → re-render on every check.
