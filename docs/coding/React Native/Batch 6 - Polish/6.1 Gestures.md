# Doc 6.1 — Gestures

## Cheat Sheet (Quick Recall)

- `react-native-gesture-handler` (RNGH) for gestures.
- `Gesture.Pan()`, `Gesture.Tap()`, `Gesture.Pinch()`.
- `GestureDetector` wraps the component.
- Combine with Reanimated shared values for smooth gesture-driven animation.
- `Gesture.Pan().onUpdate((e) => { translateX.value = e.translationX; })`.

## Main Content

### THINK

Animations are ready (6.0). But user-driven interactions are needed (swipe to delete, drag to reorder, pinch to zoom). RN's built-in `PanResponder` works but is complex. Combine RNGH + Reanimated for smooth gesture-driven animations. First basic tap/pan, then combine with Reanimated, then swipe-to-delete.

### CONCEPT

**Setup:**

```bash
npx expo install react-native-gesture-handler react-native-reanimated
```

Wrap the app root with `GestureHandlerRootView`.

**Basic tap gesture:**

```tsx
import { Gesture, GestureDetector } from "react-native-gesture-handler";

const tap = Gesture.Tap().onEnd(() => {
  console.log("tapped");
});

<GestureDetector gesture={tap}>
  <Animated.View>...</Animated.View>
</GestureDetector>
```

**Pan gesture (drag):**

```tsx
const translateX = useSharedValue(0);

const pan = Gesture.Pan()
  .onUpdate((e) => {
    translateX.value = e.translationX;
  })
  .onEnd(() => {
    translateX.value = withSpring(0);
  });

const animatedStyle = useAnimatedStyle(() => ({
  transform: [{ translateX: translateX.value }],
}));

<GestureDetector gesture={pan}>
  <Animated.View style={animatedStyle}>Drag me</Animated.View>
</GestureDetector>
```

**Swipe to delete:**

```tsx
const translateX = useSharedValue(0);

const pan = Gesture.Pan()
  .onUpdate((e) => {
    if (e.translationX < 0) translateX.value = e.translationX; // only left
  })
  .onEnd((e) => {
    if (e.translationX < -100) {
      translateX.value = withTiming(-300, {}, () => runOnJS(onDelete)());
    } else {
      translateX.value = withSpring(0);
    }
  });
```

**Pinch (zoom):**

```tsx
const scale = useSharedValue(1);

const pinch = Gesture.Pinch()
  .onUpdate((e) => {
    scale.value = e.scale;
  })
  .onEnd(() => {
    scale.value = withSpring(1);
  });
```

**Combining gestures:**

```tsx
const composed = Gesture.Simultaneous(pan, pinch);
// or Gesture.Exclusive(tap, pan)
```

## Common Mistakes

- Missing `GestureHandlerRootView` → gestures will not work.
- Wrong import for `Animated` (RN vs reanimated).
- Forgetting `runOnJS` when calling a JS function from a worklet.
- Mismatch between gesture and animation thread (use shared values).

## What It Is NOT

- ❌ RNGH is **not** the built-in `PanResponder` — a separate library.
- ❌ Gestures do **not** work without `GestureHandlerRootView`.
- ❌ Worklets cannot call JS functions directly (use `runOnJS`).
