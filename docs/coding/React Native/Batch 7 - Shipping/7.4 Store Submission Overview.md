### CONCEPT

**Android (Google Play Console):**

1. Create app in Play Console.
2. Upload AAB (Android App Bundle) — `eas build --profile production --platform android`.
3. Store listing: title, description, screenshots, icon.
4. Content rating questionnaire.
5. Privacy policy URL.
6. Submit for review (~hours to days).

**iOS (App Store Connect):**

1. Create app in App Store Connect.
2. Upload archive — `eas build --profile production --platform ios` or Xcode.
3. TestFlight (beta testing).
4. Store listing: title, description, screenshots, keywords.
5. Privacy policy URL + age rating.
6. Submit for review (~1-3 days).

**EAS Submit (automation):**

```bash
eas submit --platform android
eas submit --platform ios
```

Uploads build to store automatically (needs store credentials).

**Store listing assets:**

- Icon (512x512 for Play, 1024x1024 for App Store).
- Screenshots (multiple sizes).
- Feature graphic (Play Store).
- Description (short + full).
- Privacy policy URL.

**Review tips:**

- Provide demo account if login required.
- Clear description of app purpose.
- No placeholder content.
- Handle permissions gracefully (explain why).

### CODE (gradual)

Stage 1 — Production build:

```bash
eas build --profile production --platform android
eas build --profile production --platform ios
```

Stage 2 — Submit via EAS:

```bash
eas submit --platform android
eas submit --platform ios
```

Stage 3 — Store listing (manual in console).

### TEST

**Checkpoint:** Production build bana, EAS submit kar (or manual upload), store listing complete.

## Common Mistakes

- Privacy policy missing → rejection.
- Screenshots wrong size → rejection.
- Demo account missing for login-required app → rejection.
- Permissions not explained → rejection.
