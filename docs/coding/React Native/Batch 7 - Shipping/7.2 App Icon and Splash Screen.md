# Doc 7.2 — App Icon and Splash Screen

## Cheat Sheet (Quick Recall)

- App icon: `app.json` → `icon` (1024x1024 PNG).
- Splash: `app.json` → `splash.image` + `backgroundColor`.
- Use `expo-splash-screen` for custom splash control.
- Adaptive icon (Android): `adaptiveIcon.foregroundImage` + `backgroundColor`.
- Generate assets: `npx expo install expo-splash-screen` then configure.

### CONCEPT

**app.json config:**

```json
{
  "expo": {
    "name": "HabitTracker",
    "slug": "habit-tracker",
    "icon": "./assets/icon.png",
    "splash": {
      "image": "./assets/splash.png",
      "resizeMode": "contain",
      "backgroundColor": "#ffffff"
    },
    "android": {
      "adaptiveIcon": {
        "foregroundImage": "./assets/adaptive-icon.png",
        "backgroundColor": "#ffffff"
      }
    },
    "ios": {
      "supportsTablet": true
    }
  }
}
```

**Asset requirements:**

- Icon: 1024x1024 PNG (no transparency for iOS).
- Splash: 1284x2778 (or any, `resizeMode: "contain"`).
- Adaptive icon (Android): 1024x1024 foreground + background color.

**Custom splash (expo-splash-screen):**

```tsx
import * as SplashScreen from "expo-splash-screen";

SplashScreen.preventAutoHideAsync();

export default function App() {
  const [ready, setReady] = useState(false);

  useEffect(() => {
    (async () => {
      await loadFonts();
      await SplashScreen.hideAsync();
      setReady(true);
    })();
  }, []);

  if (!ready) return null;
  return <RootLayout />;
}
```

Keep splash until fonts/data load → smooth transition.

**Generate assets (optional):**

```bash
npx expo install expo-splash-screen
# Use Figma/Canva for design
```

## Common Mistakes

- Icon not 1024x1024 → build warning/rejection.
- Transparency in iOS icon → rejection.
- Splash `backgroundColor` mismatch → flash.
- `preventAutoHideAsync` without `hideAsync` → stuck splash.

## What It Is NOT

- ❌ Icon is **not** any size — 1024x1024 required.
- ❌ Splash is **not** automatic custom — configure in `app.json`.
- ❌ `preventAutoHideAsync` is **not** optional for custom splash.
