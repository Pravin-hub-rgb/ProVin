## Main Content

### THINK

All batches are complete: components, navigation, lists/forms, data/state, device features, polish, shipping. Now the capstone — pick your best app (habit tracker or movie browser), polish it, ship it. First plan (choose app, polish list, ship checklist), then build.

### CONCEPT

**Choose the app:** Habit tracker (Batch 6) or Movie browser (Batch 4). Pick one and polish.

**Polish checklist:**

- [ ] All features working (no crashes).
- [ ] Loading/error/empty states everywhere.
- [ ] Dark mode fully themed.
- [ ] Animations smooth (60fps).
- [ ] Accessibility (labels, roles).
- [ ] Error boundaries.
- [ ] Env vars configured.
- [ ] Icon + splash custom.
- [ ] Tests for critical paths.
- [ ] README + screenshots + demo video.

**Ship checklist:**

- [ ] Production build (`eas build --profile production`).
- [ ] Store listing complete (title, description, screenshots).
- [ ] Privacy policy URL.
- [ ] Content rating.
- [ ] Submit (`eas submit`).
- [ ] TestFlight/internal testing before public.

**Portfolio:**

- GitHub repo with a clean README.
- Demo video (screen recording).
- Screenshots (light + dark).
- Tech stack + features list.
- Live store link (after approval).

### CODE (gradual)

Stage 1 — Pick the app + audit features.

Stage 2 — Add missing polish (states, dark mode, a11y).

Stage 3 — Tests for critical paths.

Stage 4 — Production build.

Stage 5 — Store submission.

Stage 6 — Portfolio (README, video, screenshots).

### TEST

Final verification:

| Check | Expected |
|-------|----------|
| All features | Working, no crashes |
| Dark mode | Fully themed |
| States | Loading/error/empty present |
| Animations | 60fps smooth |
| Tests | Green |
| Build | Production build success |
| Store | Listing complete, submitted |

**Checkpoint (final):** App submitted to the store + portfolio ready.

## Common Mistakes

- Shipping without testing (crashes in review).
- Missing privacy policy → rejection.
- Placeholder content in store listing.
- No demo account for a login-required app.
