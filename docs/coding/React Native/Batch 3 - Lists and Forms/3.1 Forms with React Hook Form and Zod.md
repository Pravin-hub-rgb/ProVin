# Doc 3.1 — Forms with React Hook Form and Zod

## Cheat Sheet (Quick Recall)

- RHF: `useForm()` → `register`/`Controller` + `handleSubmit`.
- RN uses `Controller` (not `register`) because inputs are not native HTML.
- Zod: schema validation; `zodResolver` connects to RHF.
- Errors via `formState.errors.field.message`.
- Manual controlled inputs first (feel the problem), then RHF+Zod (solution).

### CONCEPT

**Manual controlled inputs (the problem):**

```tsx
const [amount, setAmount] = useState("");
const [category, setCategory] = useState("");
const [errors, setErrors] = useState({});

const validate = () => {
  const e: any = {};
  if (!amount) e.amount = "Amount required";
  if (!category) e.category = "Category required";
  setErrors(e);
  return Object.keys(e).length === 0;
};

const handleSubmit = () => {
  if (validate()) { /* save */ }
};
```

Boilerplate, manual validation, error state management — tedious.

**RHF + Zod (the solution):**

```tsx
import { useForm, Controller } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";
import { z } from "zod";

const schema = z.object({
  amount: z.string().min(1, "Amount required"),
  category: z.string().min(1, "Category required"),
  note: z.string().optional(),
});

type FormValues = z.infer<typeof schema>;

export default function ExpenseForm() {
  const { control, handleSubmit, formState: { errors } } = useForm<FormValues>({
    resolver: zodResolver(schema),
  });

  const onSubmit = (data: FormValues) => console.log(data);

  return (
    <View>
      <Controller
        control={control}
        name="amount"
        render={({ field: { onChange, onBlur, value } }) => (
          <TextInput
            value={value}
            onChangeText={onChange}
            onBlur={onBlur}
            keyboardType="numeric"
            placeholder="Amount"
          />
        )}
      />
      {errors.amount && <Text className="text-red-500">{errors.amount.message}</Text>}

      <Controller
        control={control}
        name="category"
        render={({ field: { onChange, onBlur, value } }) => (
          <TextInput value={value} onChangeText={onChange} onBlur={onBlur} placeholder="Category" />
        )}
      />
      {errors.category && <Text className="text-red-500">{errors.category.message}</Text>}

      <Pressable onPress={handleSubmit(onSubmit)}>
        <Text>Add Expense</Text>
      </Pressable>
    </View>
  );
}
```

**Why `Controller` in RN:** RHF's `register` works with native HTML inputs (web). RN inputs are components, not native HTML, so use `Controller` to bridge.

**Zod schema:** defines shape + validation rules; `z.infer` gives the TS type. Single source of truth for validation + types.

## Common Mistakes

- Using `register` in RN — it will not work; use `Controller`.
- Forgetting to import `zodResolver`.
- Rendering `errors.amount` (object) instead of `errors.amount.message` (string).
- Schema type and form type mismatch.
- Skipping validation by calling `onSubmit` directly instead of `handleSubmit`.

## What It Is NOT

- ❌ `register` is **not** for RN — use `Controller`.
- ❌ Zod is **not** only validation — also type inference.
- ❌ RHF is **not** magic — a schema is still needed.
