### CONCEPT

**Goal:** Expense tracker:

- Add expense: amount, category, note, date.
- List expenses (FlatList) with category filter.
- Total sum display.
- Delete expense.
- Empty state.

**Data model:**

```ts
type Expense = {
  id: string;
  amount: number;
  category: "Food" | "Transport" | "Shopping" | "Bills" | "Other";
  note: string;
  date: string; // ISO
};
```

Field reasons:

- `id` — unique handle for delete.
- `amount` — numeric, validated min > 0.
- `category` — union (only 5 categories).
- `note` — optional description.
- `date` — ISO string for sorting/filtering.

**Zod schema:**

```ts
const schema = z.object({
  amount: z.string().min(1, "Amount required").refine((v) => !isNaN(Number(v)) && Number(v) > 0, "Must be positive number"),
  category: z.enum(["Food", "Transport", "Shopping", "Bills", "Other"]),
  note: z.string().optional(),
});
```

**Screens:**

```
app/
├── index.tsx        # Expense list + total + filter
└── add-expense.tsx  # Form (RHF+Zod)
```

**Build steps (gradual):**

1. Static skeleton: FlatList with hardcoded expenses + total + filter chips.
   - **Checkpoint:** list shows hardcoded data, total correct.
2. RHF+Zod form: amount/category/note inputs.
   - **Checkpoint:** empty submit → errors; valid submit → console.log.
3. Wire form → Context: add expense, navigate back, list updates.
   - **Checkpoint:** add expense → appears in list, total updates.
4. Delete expense: swipe/button → remove.
   - **Checkpoint:** delete → list + total update.
5. Keyboard handling + validation UX polish.
   - **Checkpoint:** keyboard does not cover; errors inline; submit disabled.
6. Empty state + pull-to-refresh.
   - **Checkpoint:** no expenses → empty message.

### CODE (sample pieces)

Context:

```tsx
type Expense = { id: string; amount: number; category: ExpenseCategory; note: string; date: string };

const ExpensesContext = createContext<{ expenses: Expense[]; add: (e: Expense) => void; remove: (id: string) => void } | null>(null);
```

Total:

```tsx
const total = expenses.reduce((sum, e) => sum + e.amount, 0);
```

Filter:

```tsx
const [filter, setFilter] = useState<ExpenseCategory | "All">("All");
const filtered = filter === "All" ? expenses : expenses.filter((e) => e.category === filter);
```

## Common Mistakes

- Amount stored as string not converted to number → total NaN.
- Category union mismatch (typo) → TS error.
- FlatList inside ScrollView → virtualization breaks.
- Keyboard covering the submit button.
