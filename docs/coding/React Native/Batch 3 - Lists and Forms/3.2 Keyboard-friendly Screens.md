# Doc 3.2 — Keyboard-friendly Screens

## Cheat Sheet (Quick Recall)

- `KeyboardAvoidingView` pushes content up when keyboard opens.
- `behavior`: iOS `"padding"`, Android `"height"`.
- Dismiss on outside tap: `TouchableWithoutFeedback` + `Keyboard.dismiss()`.
- `keyboardShouldPersistTaps` on ScrollView/FlatList.
- `inputAccessoryView` for toolbar above keyboard (iOS).

### CONCEPT

**The problem:**

Keyboard screen ka bottom ~40% cover karta hai. Agar input bottom pe hai, keyboard ke peeche chhup jata hai. User dekh nahi sakta kya type kar raha hai.

**Solution: KeyboardAvoidingView:**

```tsx
import { KeyboardAvoidingView, Platform, ScrollView } from "react-native";

<KeyboardAvoidingView
  behavior={Platform.OS === "ios" ? "padding" : "height"}
  style={{ flex: 1 }}
>
  <ScrollView keyboardShouldPersistTaps="handled">
    {/* inputs */}
  </ScrollView>
</KeyboardAvoidingView>
```

- `behavior="padding"` (iOS): padding add karke content upar push.
- `behavior="height"` (Android): height adjust.
- `keyboardShouldPersistTaps="handled"`: tap on ScrollView doesn't dismiss keyboard unless handled.

**Dismiss on outside tap:**

```tsx
import { TouchableWithoutFeedback, Keyboard } from "react-native";

<TouchableWithoutFeedback onPress={Keyboard.dismiss}>
  <View style={{ flex: 1 }}>
    {/* inputs */}
  </View>
</TouchableWithoutFeedback>
```

**inputAccessoryView (iOS toolbar):**

```tsx
import { InputAccessoryView, Button } from "react-native";

<InputAccessoryView nativeID="toolbar">
  <Button title="Done" onPress={Keyboard.dismiss} />
</InputAccessoryView>

<TextInput inputAccessoryViewID="toolbar" />
```

"Done" button keyboard ke upar.

### CODE (gradual)

Stage 1 — Problem (no handling):

```tsx
<View style={{ flex: 1, justifyContent: "flex-end", padding: 16 }}>
  <TextInput placeholder="Amount" />
</View>
```

Keyboard open → input cover.

Stage 2 — KeyboardAvoidingView:

```tsx
<KeyboardAvoidingView behavior={Platform.OS === "ios" ? "padding" : "height"} style={{ flex: 1 }}>
  <View style={{ flex: 1, justifyContent: "flex-end", padding: 16 }}>
    <TextInput placeholder="Amount" />
  </View>
</KeyboardAvoidingView>
```

Stage 3 — Dismiss on outside tap:

```tsx
<TouchableWithoutFeedback onPress={Keyboard.dismiss}>
  <KeyboardAvoidingView ...>
    <View>...</View>
  </KeyboardAvoidingView>
</TouchableWithoutFeedback>
```

Stage 4 — ScrollView integration:

```tsx
<KeyboardAvoidingView ...>
  <ScrollView keyboardShouldPersistTaps="handled">
    {inputs}
  </ScrollView>
</KeyboardAvoidingView>
```

## Common Mistakes

- `behavior` galat (iOS pe `"height"`) → layout break.
- `KeyboardAvoidingView` ko `flex: 1` na dena → kaam nahi karega.
- `keyboardShouldPersistTaps` missing → tap pe keyboard dismiss (annoying).
- ScrollView ke andar input without avoiding view → cover.

## What It Is NOT

- ❌ `KeyboardAvoidingView` is **not** automatic — behavior set karna padta hai.
- ❌ It does **not** work without `flex: 1`.
- ❌ `keyboardShouldPersistTaps` is **not** default — set explicitly.
