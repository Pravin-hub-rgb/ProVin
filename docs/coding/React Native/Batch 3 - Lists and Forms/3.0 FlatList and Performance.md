## Main Content

### THINK

The notes app used `ScrollView` (small list). The expense tracker will have a long transactions list (100+). `ScrollView` renders all items at once → slow. `FlatList` is virtualized — only visible items render. First basic `FlatList`, then components (header/empty/footer), then performance props.

### CONCEPT

**Basic usage:**

```tsx
import { FlatList, Text, View } from "react-native";

<FlatList
  data={expenses}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => (
    <View className="p-4 border-b border-gray-200">
      <Text>{item.title} — ₹{item.amount}</Text>
    </View>
  )}
/>
```

- `data` — the array.
- `renderItem` — renders each item.
- `keyExtractor` — unique key (id).

**Built-in components:**

- `ItemSeparatorComponent` — divider between items.
- `ListHeaderComponent` — top header.
- `ListEmptyComponent` — empty state.
- `ListFooterComponent` — bottom (loading spinner).

```tsx
<FlatList
  data={expenses}
  keyExtractor={(i) => i.id}
  renderItem={renderItem}
  ItemSeparatorComponent={() => <View className="h-px bg-gray-200" />}
  ListEmptyComponent={() => <Text>No expenses yet</Text>}
  ListHeaderComponent={() => <Text className="text-xl font-bold p-4">Expenses</Text>}
/>
```

**Performance props:**

- `getItemLayout` — precompute layout for fixed-height items (fastest).
- `initialNumToRender` — first render count (default 10).
- `maxToRenderPerBatch` — per batch render (default 10).
- `windowSize` — viewport multiplier (default 21).
- `removeClippedSubviews` — remove offscreen views (Android).

```tsx
<FlatList
  data={expenses}
  keyExtractor={(i) => i.id}
  renderItem={renderItem}
  getItemLayout={(_, index) => ({ length: 60, offset: 60 * index, index })}
  initialNumToRender={15}
  maxToRenderPerBatch={10}
  windowSize={5}
/>
```

**Pull-to-refresh:**

```tsx
<FlatList
  data={expenses}
  keyExtractor={(i) => i.id}
  renderItem={renderItem}
  refreshing={isRefreshing}
  onRefresh={handleRefresh}
/>
```

## Common Mistakes

- Missing `keyExtractor` → warning + bugs.
- Inline `renderItem` function → re-rend on every scroll (use `useCallback` or a separate component).
- Wrong `getItemLayout` offset → wrong scroll position.
- `FlatList` inside `ScrollView` → virtualization breaks.

4. When should you use `getItemLayout`?

<details>
<summary>Sample Answer</summary>

**Answer:** When items have fixed height — precomputes layout for faster scrolling.

5. Why avoid inline `renderItem` functions?

<details>
<summary>Sample Answer</summary>

**Answer:** They recreate on each render, causing unnecessary re-renders; use `useCallback` or a separate component.

## What It Is NOT

- ❌ `FlatList` is **not** for short lists — `ScrollView` is simpler.
- ❌ `FlatList` inside `ScrollView` breaks virtualization.
- ❌ `getItemLayout` is **not** for variable-height items.
