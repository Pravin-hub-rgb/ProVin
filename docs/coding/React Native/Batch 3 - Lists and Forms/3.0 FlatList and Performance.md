- Props: `data`, `renderItem`, `keyExtractor`.

- Performance: `getItemLayout`, `windowSize`, `maxToRenderPerBatch`, `initialNumToRender`.
- `ScrollView` for small lists; `FlatList` for long/dynamic lists.

### CONCEPT

**Basic usage:**

```tsx
import { FlatList, Text, View } from "react-native";

<FlatList
  data={expenses}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => (
    <View className="p-4 border-b border-gray-200">
      <Text>{item.title} — ₹{item.amount}</Text>
    </View>
  )}
/>
```

- `data` — array.
- `renderItem` — each item render.
- `keyExtractor` — unique key (id).

**Built-in components:**

- `ItemSeparatorComponent` — divider between items.
- `ListHeaderComponent` — top header.
- `ListEmptyComponent` — empty state.
- `ListFooterComponent` — bottom (loading spinner).

```tsx
<FlatList
  data={expenses}
  keyExtractor={(i) => i.id}
  renderItem={renderItem}
  ItemSeparatorComponent={() => <View className="h-px bg-gray-200" />}
  ListEmptyComponent={() => <Text>No expenses yet</Text>}
  ListHeaderComponent={() => <Text className="text-xl font-bold p-4">Expenses</Text>}
/>
```

**Performance props:**

- `getItemLayout` — fixed height items ka layout precompute (fastest).
- `initialNumToRender` — first render count (default 10).
- `maxToRenderPerBatch` — per batch render (default 10).
- `windowSize` — viewport multiplier (default 21).
- `removeClippedSubviews` — offscreen views remove (Android).

```tsx
<FlatList
  data={expenses}
  keyExtractor={(i) => i.id}
  renderItem={renderItem}
  getItemLayout={(_, index) => ({ length: 60, offset: 60 * index, index })}
  initialNumToRender={15}
  maxToRenderPerBatch={10}
  windowSize={5}
/>
```

**Pull-to-refresh:**

```tsx
<FlatList
  data={expenses}
  keyExtractor={(i) => i.id}
  renderItem={renderItem}
  refreshing={isRefreshing}
  onRefresh={handleRefresh}
/>
```

## Common Mistakes

- `keyExtractor` missing → warning + bugs.
- Inline `renderItem` function → re-render each scroll (use `useCallback` or separate component).
- `getItemLayout` galat offset → wrong scroll position.
- `FlatList` inside `ScrollView` → virtualization break.

1. Why use `FlatList` instead of `ScrollView`?

<details>
<summary>Sample Answer</summary>

**Answer:** `FlatList` virtualizes (renders only visible items), so long lists stay fast.

</details>

2. What are the three required props of `FlatList`?

<details>
<summary>Sample Answer</summary>

**Answer:** `data`, `renderItem`, `keyExtractor`.

</details>

3. What prop shows a component when the list is empty?

<details>
<summary>Sample Answer</summary>

**Answer:** `ListEmptyComponent`.

</details>

4. When should you use `getItemLayout`?

<details>
<summary>Sample Answer</summary>

**Answer:** When items have fixed height — precomputes layout for faster scrolling.

</details>

5. Why avoid inline `renderItem` functions?

<details>
<summary>Sample Answer</summary>

**Answer:** They recreate on each render, causing unnecessary re-renders; use `useCallback` or separate component.

</details>

## What It Is NOT

- ❌ `FlatList` is **not** for short lists — `ScrollView` simpler.
- ❌ `FlatList` inside `ScrollView` breaks virtualization.
- ❌ `getItemLayout` is **not** for variable-height items.
