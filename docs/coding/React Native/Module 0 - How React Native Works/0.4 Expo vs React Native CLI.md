# Doc 0.4 — Expo vs React Native CLI

## Cheat Sheet (Quick Recall)

- Expo: `npx create-expo-app`, minutes setup, no Android Studio for Expo Go, EAS cloud builds.
- RN CLI: `npx react-native init`, hours setup, needs Android Studio/Xcode, full native control.
- Course uses Expo — fast start on real phone.
- Pick RN CLI only for deep native needs Expo can't handle.

## Main Content

### SOCH

Expo samajh aaya — tooling layer. Lekin Expo ek hi option nahi hai. React Native CLI bhi hai — purana, zyada control deta hai, lekin setup heavy hai. Reader ko dono dekhne chahiye taaki samajh aaye "hum Expo kyun choose kar rahe hain" — bina comparison ke choice arbitrary lagti hai.

### CONCEPT

**Expo (Managed Workflow):**

- Setup: `npx create-expo-app`
- Run: `npx expo start`, QR scan with Expo Go
- Native modules: Expo SDK ya config plugins
- Builds: EAS cloud
- Pros: zero native setup, fast start, great DX
- Cons: limited to what Expo supports (mostly fine for learning)

**React Native CLI (Bare):**

- Setup: `npx react-native init MyApp`
- Run: Android Studio / Xcode + emulator or device
- Native modules: manual linking (autolinking helps)
- Builds: local native builds
- Pros: full control, any native module
- Cons: heavy setup, steep learning curve

Side-by-side:

| | Expo | RN CLI |
|---|---|---|
| Setup time | Minutes | Hours |
| Needs Android Studio | No (for Expo Go) | Yes |
| Native module freedom | Mostly (SDK + plugins) | Full |
| Build process | Cloud (EAS) | Local |
| Best for | Learning, prototyping, most apps | Deep native needs |

**Course recommendation:** Expo. Goal real apps on own phone fast. Expo setup friction remove karta hai. Bare workflow later if needed (eject possible).

### CODE

Expo:

```bash
npx create-expo-app my-app
cd my-app
npx expo start
```

RN CLI (for reference, not course):

```bash
npx react-native init MyApp
cd MyApp
npx react-native run-android   # needs Android Studio + emulator
```

Line-by-line:

- Expo: three commands, phone pe QR scan, done.
- CLI: init + native build, Android Studio/emulator required.
