# Doc 0.4 — Expo vs React Native CLI

## Cheat Sheet (Quick Recall)

- Expo: `npx create-expo-app`, minutes of setup, no Android Studio for Expo Go, EAS cloud builds.
- RN CLI: `npx react-native init`, hours of setup, needs Android Studio/Xcode, full native control.
- This course uses Expo — fast start on a real phone.
- Pick RN CLI only for deep native needs Expo cannot handle.

## Main Content

### THINK

Expo is clear — a tooling layer. But Expo is not the only option. The React Native CLI also exists — older, gives more control, but has heavy setup. The reader should see both so it is clear "why are we choosing Expo" — without a comparison the choice looks arbitrary.

### CONCEPT

**Expo (Managed Workflow):**

- Setup: `npx create-expo-app`
- Run: `npx expo start`, scan QR with Expo Go
- Native modules: Expo SDK or config plugins
- Builds: EAS in the cloud
- Pros: zero native setup, fast start, great DX
- Cons: limited to what Expo supports (mostly fine for learning)

**React Native CLI (Bare):**

- Setup: `npx react-native init MyApp`
- Run: needs Android Studio / Xcode + emulator or device
- Native modules: manual linking (autolinking helps)
- Builds: local native builds
- Pros: full control, any native module
- Cons: heavy setup, steep learning curve

Side by side:

| | Expo | RN CLI |
|---|---|---|
| Setup time | Minutes | Hours |
| Needs Android Studio | No (for Expo Go) | Yes |
| Native module freedom | Mostly (SDK + plugins) | Full |
| Build process | Cloud (EAS) | Local |
| Best for | Learning, prototyping, most apps | Deep native needs |

**Course recommendation:** Expo. The goal is real apps on your own phone, fast. Expo removes setup friction. You can always eject to bare later if needed.

### CODE (gradual)

Expo:

```bash
npx create-expo-app my-app
cd my-app
npx expo start
```

RN CLI (for reference, not this course):

```bash
npx react-native init MyApp
cd MyApp
npx react-native run-android   # needs Android Studio + emulator
```

Line by line:

- Expo: three commands, scan the QR on the phone, done.
- CLI: init + native build, Android Studio/emulator required.
