# Doc 0.5 — Expo Go vs Development Builds

## Cheat Sheet (Quick Recall)

- Expo Go: pre-built generic app, scan QR, instant start, limited to bundled modules.
- Dev build: your own binary via EAS, contains your native code, reloads JS like Expo Go.
- Course: Expo Go first (Batches 1–6), dev builds in Batch 7 for capstone shipping.
- Switch when: custom native module, real app behavior testing, store prep.

## Main Content

### SOCH

Expo choose kar liya. Lekin Expo mein bhi do tareeke hain app preview karne ke: Expo Go (generic viewer) aur development builds (apna binary). Dono mein code reload hota hai, lekin capabilities alag hain. Agar yeh difference nahi samjhe, toh "yeh module Expo Go mein nahi chal raha" wali confusion aayegi. Isliye abhi clear karna hai.

### CONCEPT

**Expo Go:**

- Pre-built app (app stores se install).
- `npx expo start` ka QR scan karo → tumhara JS bundle Expo Go ke andar run hota hai.
- Pros: zero setup, instant start.
- Limits: sirf Expo Go mein bundled modules available. Agar tum native module add karo jo Expo Go mein nahi hai → kaam nahi karega.

**Development builds:**

- Tumhara own app binary, EAS se build, tumhara native code contain karta hai.
- Phone pe ek baar install; phir JS reload hota hai like Expo Go.
- Pros: koi bhi native module kaam karega; real app jaisa behave karta hai.
- Cons: build step chahiye (cloud ya local).

**When to switch:**

- Stay on Expo Go: Batches 1–6 (learning).
- Switch to dev builds when:
  - Custom native module add karo jo Expo Go mein nahi.
  - Real app behavior test karna (icon, splash, deep links).
  - Store submission prep (Batch 7).

### CODE

Expo Go workflow (current):

```bash
npx expo start
# scan QR with Expo Go
```

Dev build workflow (later, Batch 7):

```bash
npx eas build --profile development
# install binary on phone, then npx expo start
```

Line-by-line:

- Expo Go: sirf start + scan.
- Dev build: EAS build (cloud) → binary install → phir start.

## Common Mistakes

- Expo Go mein custom native module add karke confuse hona.
- Dev builds ko "production build" samajhna — dev build debugging ke liye hai.
- Expo Go limitations ko React Native ki limitation samajhna.
