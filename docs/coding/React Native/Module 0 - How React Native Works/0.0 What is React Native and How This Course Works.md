# Doc 0.0 — What is React Native and How This Course Works

## Cheat Sheet (Quick Recall)

- React Native builds real Android/iOS apps using React's component model, rendering native views, not HTML.
- Expo (`create-expo-app`) gives project setup, dev server with QR code, SDK modules, and cloud builds.
- Course: Module 0 (theory) + 7 batches, one project per batch, ending in a shipped capstone.
- Styling: plain `StyleSheet` in Batch 1, then NativeWind from Batch 2.
- Carry-over from React: components, props, state, hooks, Context, Redux Toolkit, TanStack Query, RHF, Zod.

## Main Content

### SOCH

React seekh chuke ho, TypeScript basics aate hain. Ab mobile app banana hai — Android aur iPhone dono pe, ek hi codebase se. Native (Kotlin/Swift) seekhna nahi hai. React Native yahi problem solve karta hai: React ka component model use karke real native apps banana. Lekin pehle yeh clear hona chahiye ki course kaise structured hai, taaki reader ko pata ho "abhi kya kar rahe hain" aur "overall kahan khade hain."

### CONCEPT

React Native ek framework hai jo React ka component model use karta hai lekin browser ke bajaye phone ke operating system ke real native views render karta hai. Expo iske upar tooling layer hai — project setup, dev server, QR-based preview on phone, aur cloud builds.

Course ka structure:

- **Module 0** (yeh module) — theory only. Under the hood kaise kaam karta hai. Koi app code nahi.
- **Batch 1** — Core components (`View`, `Text`, `Image`, `ScrollView`, `Pressable`, `TextInput`), Flexbox, `StyleSheet`. Project: To-do list app.
- **Batch 2** — Navigation with Expo Router, Context, NativeWind, safe areas. Project: Multi-screen notes app.
- **Batch 3** — `FlatList`, forms with React Hook Form + Zod, keyboard handling. Project: Expense tracker.
- **Batch 4** — Fetching with TanStack Query, global state, local storage. Project: Movie browser.
- **Batch 5** — Camera, location, notifications, permissions. Project: Photo journal.
- **Batch 6** — Animations with Reanimated, gestures, theming, performance. Project: Animated habit tracker.
- **Batch 7** — EAS dev builds, Jest, app icon/splash, env config, store submission. Project: Capstone.

Prerequisites (yeh already aane chahiye):

- JavaScript basics (variables, functions, arrays, objects, Promises, async/await)
- React basics (components, props, state, hooks)
- HTML/CSS basics (helpful, not strictly required)
- No native (Kotlin/Swift) knowledge needed

## Common Mistakes

- React Native ko "React for web but on phone" samajhna — yeh galat hai, yeh native views render karta hai, HTML nahi.
- Expo ko React Native ka replacement samajhna — Expo tooling hai, React Native concepts same hain.
- Prerequisites skip karna — bina React basics ke yeh course mushkil hoga.

## What It Is NOT

- ❌ React Native is **not a browser app** — it renders real native views, not HTML.
- ❌ React Native is **not React for web** — `div` and `p` do not exist; you use `View` and `Text`.
- ❌ React Native is **not magic** — it still runs JavaScript; understanding the runtime matters.
- ❌ React Native is **not only for simple apps** — production apps (Instagram, Shopify, Discord) use it.
- ❌ React Native is **not a replacement for learning native** — for deep platform features you may still need native code.
