# Doc 0.0 — What is React Native

## Cheat Sheet (Quick Recall)

- React Native builds real Android/iOS apps using React's component model, rendering native views, not HTML.
- Expo (`create-expo-app`) gives project setup, dev server with QR code, SDK modules, and cloud builds.
- Course: Module 0 (theory) + 7 batches, one project per batch, ending in a shipped capstone.
- Styling: plain `StyleSheet` in Batch 1, then NativeWind from Batch 2.
- Carry-over from React: components, props, state, hooks, Context, Redux Toolkit, TanStack Query, RHF, Zod.

## Main Content

### THINK

You already know React and TypeScript basics. Now you want to build mobile apps — for both Android and iPhone, from one codebase. You do not want to learn native (Kotlin/Swift). React Native solves exactly this: it lets you build real native apps using React's component model. But first it must be clear how the course is structured, so the reader always knows "what am I doing now" and "where do I stand overall".

### CONCEPT

React Native is a framework that uses React's component model but renders the phone's operating system's real native views instead of the browser. Expo sits on top of it as a tooling layer — project setup, dev server, QR-based preview on the phone, and cloud builds.

(See the React Native Roadmap doc for how this course is structured, the module breakdown, and prerequisites.)

## Common Mistakes

- Thinking React Native is "React for web but on phone" — it is wrong; it renders native views, not HTML.
- Thinking Expo replaces React Native — Expo is tooling; React Native concepts are the same.
- Skipping prerequisites — without React basics this course will be hard.

## What It Is NOT

- ❌ React Native is **not a browser app** — it renders real native views, not HTML.
- ❌ React Native is **not React for web** — `div` and `p` do not exist; you use `View` and `Text`.
- ❌ React Native is **not magic** — it still runs JavaScript; understanding the runtime matters.
- ❌ React Native is **not only for simple apps** — production apps (Instagram, Shopify, Discord) use it.
- ❌ React Native is **not a replacement for learning native** — for deep platform features you may still need native code.
