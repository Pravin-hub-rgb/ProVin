# Doc 1.4 — TextInput

## Cheat Sheet (Quick Recall)

- `TextInput` = text entry; controlled via `value` + `onChangeText` (gives string).
- Props: `placeholder`, `secureTextEntry`, `keyboardType`, `autoCapitalize`, `autoCorrect`, `multiline`, `maxLength`, `editable`.
- Keyboard handling: `KeyboardAvoidingView` + `Keyboard.dismiss()` on outside tap.
- `onChangeText` gives string, not event (unlike web `onChange`).

### CONCEPT

**Basic usage (controlled):**

```tsx
import { TextInput, View, Text } from "react-native";
import { useState } from "react";

export default function App() {
  const [text, setText] = useState("");

  return (
    <View style={{ padding: 16 }}>
      <TextInput
        value={text}
        onChangeText={setText}
        placeholder="Type here"
        style={{ borderWidth: 1, borderColor: "#ccc", padding: 12, borderRadius: 8 }}
      />
      <Text>{text}</Text>
    </View>
  );
}
```

- `value` + `onChangeText` = controlled (recommended). Tu state own karta hai.
- Uncontrolled: `defaultValue` + ref (less common).

**Common props:**

- `placeholder` / `placeholderTextColor`
- `secureTextEntry` — passwords.
- `keyboardType` — `"default"`, `"numeric"`, `"email-address"`, `"phone-pad"`.
- `autoCapitalize` — `"none"`, `"sentences"`, `"words"`, `"characters"`.
- `autoCorrect` — boolean.
- `multiline` — textarea-like.
- `maxLength` — limit characters.
- `editable` — disable input.

```tsx
<TextInput
  placeholder="Email"
  keyboardType="email-address"
  autoCapitalize="none"
  autoCorrect={false}
/>
```

**Keyboard handling:**

Keyboard screen ka bottom cover karta hai. `KeyboardAvoidingView` content ko upar push karta hai. Outside tap pe dismiss: `TouchableWithoutFeedback` + `Keyboard.dismiss()`.

```tsx
import { KeyboardAvoidingView, Platform, TouchableWithoutFeedback, Keyboard } from "react-native";

<KeyboardAvoidingView behavior={Platform.OS === "ios" ? "padding" : "height"} style={{ flex: 1 }}>
  <TouchableWithoutFeedback onPress={Keyboard.dismiss}>
    <View>{/* inputs */}</View>
  </TouchableWithoutFeedback>
</KeyboardAvoidingView>
```

## Common Mistakes

- `onChangeText` ko event expect karna — yeh string deta hai, not event.
- `onChange` (web) use karna — RN mein `onChangeText`.
- Keyboard handling ignore karna — inputs cover ho jate hain.
- `multiline` pe height auto-grow expect karna — manually handle.

## What It Is NOT

- ❌ `TextInput` is **not** HTML input — many CSS props nahi apply.
- ❌ `onChangeText` is **not** `onChange` — string deta hai.
- ❌ `multiline` does **not** auto-grow without height handling.
