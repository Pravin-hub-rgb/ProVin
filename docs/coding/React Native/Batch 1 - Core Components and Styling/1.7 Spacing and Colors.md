### CONCEPT

**Spacing:**

- `padding` / `margin` — all sides.
- `paddingHorizontal`, `paddingVertical`, `marginHorizontal`, `marginVertical`.
- `paddingTop/Right/Bottom/Left` (same for margin).
- `gap` — spacing between flex children.

```tsx
const styles = StyleSheet.create({
  card: {
    padding: 16,
    marginHorizontal: 12,
    marginBottom: 8,
    gap: 8,
  },
});
```

**Colors:**

- Hex: `"#ff5733"`, `"#333"`.
- RGB/RGBA: `"rgb(255, 87, 51)"`, `"rgba(0,0,0,0.5)"`.
- Named colors limited; prefer hex/rgba.

**Safe areas:**

Phones have notches and home indicators. Content can hide behind them. Use `SafeAreaView` from `react-native-safe-area-context` (core `SafeAreaView` deprecated).

```tsx
import { SafeAreaView } from "react-native-safe-area-context";

<SafeAreaView style={{ flex: 1 }}>
  {/* content stays clear of notch/home indicator */}
</SafeAreaView>
```

Expo sets up `react-native-safe-area-context` by default.

**Dark mode basics:**

`useColorScheme` detect karta hai light/dark aur colors switch karo.

```tsx
import { useColorScheme } from "react-native";

const scheme = useColorScheme(); // "light" | "dark" | null
const bg = scheme === "dark" ? "#000" : "#fff";
```

### CODE (gradual)

Stage 1 — Padding/margin:

```tsx
<View style={{ padding: 16, margin: 8, backgroundColor: "#eee" }}>
  <Text>Card</Text>
</View>
```

Stage 2 — Directional spacing:

```tsx
<View style={{ paddingHorizontal: 12, paddingVertical: 8, gap: 4 }}>
  <Text>Row 1</Text>
  <Text>Row 2</Text>
</View>
```

Stage 3 — Safe area wrap:

```tsx
<SafeAreaView style={{ flex: 1 }}>
  <View style={{ flex: 1, padding: 16 }}>
    <Text>Content clear of notch</Text>
  </View>
</SafeAreaView>
```

Stage 4 — Dark mode hook:

```tsx
const scheme = useColorScheme();
const bg = scheme === "dark" ? "#000" : "#fff";
<View style={{ flex: 1, backgroundColor: bg }} />
```

## Common Mistakes

- Core `SafeAreaView` use karna (deprecated) — `react-native-safe-area-context` use karo.
- `gap` support assume karna bina RN version check — modern RN mein supported.
- Colors inherit expect karna — RN mein explicit set karo per component.
- Hex shorthand `"#333"` vs full `"#333333"` — both work, consistent raho.
