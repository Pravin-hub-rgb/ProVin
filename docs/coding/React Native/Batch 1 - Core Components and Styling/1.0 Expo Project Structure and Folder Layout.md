# Doc 1.0 — Expo Project Structure and Folder Layout

## Cheat Sheet (Quick Recall)

- Create: `npx create-expo-app my-app` → `cd my-app` → `npx expo start`.
- `app/` = screens (file-based routing, Expo Router); `app/index.tsx` = home.
- `assets/` = images/fonts/icons.
- `app.json` = app config (name, icon, splash, plugins).
- Fast Refresh updates on save; shake phone or `r` to reload; `j` for debugger.

### CONCEPT

**Project create:**

```bash
npx create-expo-app my-app
cd my-app
npx expo start
```

- `npx create-expo-app my-app` — naya Expo project create karta hai with defaults (TypeScript, Expo Router).
- `cd my-app` — project folder mein ja.
- `npx expo start` — dev server start, QR code dikhata hai. Scan with Expo Go → app khulega.

**Folder layout:**

```
my-app/
├── app/                  # Screens (file-based routing, Expo Router)
│   └── index.tsx         # Home screen
├── assets/               # Images, fonts, icons
├── components/           # Reusable components
├── constants/            # Colors, theme values
├── app.json              # App config (name, icon, splash)
├── package.json          # Dependencies and scripts
├── tsconfig.json         # TypeScript config
└── .gitignore
```

Key files:

- `app/` — screens. Expo Router mein file path = route. `app/index.tsx` = `/`.
- `assets/` — static files. Images `require('./assets/...')` ya URL se.
- `app.json` — app name, icon, splash, orientation, plugins configure karta hai.
- `package.json` — dependencies + scripts (`start`, `android`, `ios`, `web`).

**Entry point:**

`app/index.tsx` tumhara pehla screen hai. Edit karo, save karo — phone update hota hai (Fast Refresh).

**Reloading:**

- Fast Refresh: save pe app update, state preserve jab possible.
- Shake phone (ya terminal mein `r`) → full reload.
- `j` → debugger open.

### CODE

Entry point edit:

```tsx
import { Text, View } from "react-native";

export default function HomeScreen() {
  return (
    <View style={{ flex: 1, justifyContent: "center", alignItems: "center" }}>
      <Text>Hello React Native</Text>
    </View>
  );
}
```

Line-by-line:

- `import { Text, View } from "react-native"` — native building blocks import kiye (not from "react").
- `export default function HomeScreen()` — screen component, Expo Router isse route bana leta hai.
- `<View style={{...}}>` — container with flex centering.
- `<Text>Hello React Native</Text>` — screen pe text dikhayega.

## Common Mistakes

- `app/index.tsx` ke bajaye root `index.js` edit karna (Expo Router mein `app/` use hota hai).
- `app.json` mein name/slug change karke confused hona — yeh app identity hai.
- Fast Refresh ke state preserve behavior ko "bug" samajhna.

## What It Is NOT

- ❌ `app/` is **not** optional — Expo Router needs it for routing.
- ❌ `app.json` is **not** `package.json` — different purposes.
- ❌ Fast Refresh is **not** full reload — state preserve hota hai jab possible.
