# Doc 1.0 — Expo Project Structure and Folder Layout

## Cheat Sheet (Quick Recall)

- Create: `npx create-expo-app my-app` → `cd my-app` → `npx expo start`.
- `app/` = screens (file-based routing, Expo Router); `app/index.tsx` = home.
- `assets/` = images/fonts/icons.
- `app.json` = app config (name, icon, splash, plugins).
- Fast Refresh updates on save; shake the phone or press `r` to reload; `j` opens the debugger.

### CONCEPT

**Create the project:**

```bash
npx create-expo-app my-app
cd my-app
npx expo start
```

- `npx create-expo-app my-app` — creates a new Expo project with sensible defaults (TypeScript, Expo Router).
- `cd my-app` — enter the project folder.
- `npx expo start` — starts the dev server and shows a QR code. Scan it with Expo Go and the app opens.

**Folder layout:**

```
my-app/
├── app/                  # Screens (file-based routing, Expo Router)
│   └── index.tsx         # Home screen
├── assets/               # Images, fonts, icons
├── components/           # Reusable components
├── constants/            # Colors, theme values
├── app.json              # App config (name, icon, splash)
├── package.json          # Dependencies and scripts
├── tsconfig.json         # TypeScript config
└── .gitignore
```

Key files:

- `app/` — screens. In Expo Router the file path becomes the route. `app/index.tsx` is `/`.
- `assets/` — static files. Images loaded via `require('./assets/...')` or an `Image` with a URL.
- `app.json` — configures app name, icon, splash screen, orientation, and plugins.
- `package.json` — dependencies and scripts (`start`, `android`, `ios`, `web`).

**Entry point:**

`app/index.tsx` is your first screen. Edit it and save — the phone updates instantly.

**Reloading:**

- Fast Refresh updates the app on save, preserving state when possible.
- Shake the phone (or press `r` in the terminal) to reload fully.
- Press `j` to open the debugger.

### CODE (gradual)

Edit the entry point:

```tsx
import { Text, View } from "react-native";

export default function HomeScreen() {
  return (
    <View style={{ flex: 1, justifyContent: "center", alignItems: "center" }}>
      <Text>Hello React Native</Text>
    </View>
  );
}
```

Line by line:

- `import { Text, View } from "react-native"` — imports the native building blocks (not from "react").
- `export default function HomeScreen()` — a screen component; Expo Router turns it into a route.
- `<View style={{...}}>` — a container with centered flex layout.
- `<Text>Hello React Native</Text>` — text shown on screen.

## Common Mistakes

- Editing the root `index.js` instead of `app/index.tsx` (Expo Router uses `app/`).
- Confusing `app.json` with `package.json` — different purposes.
- Treating Fast Refresh like a full reload — state is preserved when possible.

## What It Is NOT

- ❌ `app/` is **not** optional — Expo Router needs it for routing.
- ❌ `app.json` is **not** `package.json` — different purposes.
- ❌ Fast Refresh is **not** a full reload — state is preserved when possible.
