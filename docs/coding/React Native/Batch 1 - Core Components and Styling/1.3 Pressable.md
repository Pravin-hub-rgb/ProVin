# Doc 1.3 — Pressable

## Cheat Sheet (Quick Recall)

- `Pressable` = tappable element; `onPress`, `onLongPress`, `onPressIn/Out`.
- Pressed styling via function style: `style={({ pressed }) => ({...})}`.
- `hitSlop` expands the tappable area; `disabled` disables; `android_ripple` for Android ripple.
- Prefer `Pressable` over `TouchableOpacity` for new code.

## Main Content

### THINK

The to-do app needs tasks to be tapped — toggle complete, delete. On the web there is `button`/`onClick`; in React Native there is `Pressable`. First basic tap, then pressed styling (visual feedback), then props (hitSlop, disabled, ripple). If this is not understood, the to-do app's buttons will feel "dead".

### CONCEPT

**Basic usage:**

```tsx
import { Pressable, Text } from "react-native";

<Pressable onPress={() => console.log("pressed")}>
  <Text>Tap me</Text>
</Pressable>
```

**Pressed styling:**

```tsx
<Pressable
  onPress={() => setCount((c) => c + 1)}
  style={({ pressed }) => ({
    padding: 12,
    backgroundColor: pressed ? "#ddd" : "#eee",
    borderRadius: 8,
  })}
>
  <Text>Press me</Text>
</Pressable>
```

**Common props:**

- `onPress` — fires on tap.
- `onLongPress` — fires on long tap.
- `onPressIn` / `onPressOut` — fires on press start/end.
- `disabled` — disables interaction.
- `hitSlop` — expands the tappable area without changing visuals.
- `android_ripple` — ripple effect on Android.

```tsx
<Pressable
  onPress={handleDelete}
  hitSlop={8}
  android_ripple={{ color: "#ccc" }}
  style={({ pressed }) => ({ opacity: pressed ? 0.6 : 1 })}
>
  <Text>Delete</Text>
</Pressable>
```

**Pressable vs TouchableOpacity:**

- `TouchableOpacity` fades opacity on press (older, still common).
- `Pressable` is the modern, flexible option with full control over pressed styling.
- Prefer `Pressable` for new code.

### CODE (gradual)

Stage 1 — Static button (no handler):

```tsx
<Pressable style={{ padding: 12, backgroundColor: "#eee", borderRadius: 8 }}>
  <Text>Tap me</Text>
</Pressable>
```

Save and check — it shows but nothing happens on tap.

Stage 2 — Add onPress (console.log):

```tsx
<Pressable onPress={() => console.log("tapped")} style={{...}}>
  <Text>Tap me</Text>
</Pressable>
```

Tap and check the console — "tapped" should print.

Stage 3 — Pressed styling:

```tsx
<Pressable
  onPress={() => console.log("tapped")}
  style={({ pressed }) => ({
    padding: 12,
    backgroundColor: pressed ? "#ccc" : "#eee",
    borderRadius: 8,
  })}
>
  <Text>Tap me</Text>
</Pressable>
```

Tap and observe the visual change.

Stage 4 — Real action (to-do toggle):

```tsx
<Pressable onPress={() => toggleTask(task.id)} style={({ pressed }) => ({ opacity: pressed ? 0.6 : 1 })}>
  <Text>{task.title}</Text>
</Pressable>
```

## Common Mistakes

- Treating `Pressable` as a `button` — there is no default styling; style it yourself.
- Writing `onClick` instead of `onPress` — RN uses `onPress`.
- Expecting `onPress` to fire when `disabled` is true — it will not.
- Ignoring accessibility — add `accessibilityRole="button"` and `accessibilityLabel`.

## What It Is NOT

- ❌ `Pressable` is **not** a `button` — no default styling.
- ❌ `Pressable` does **not** handle keyboard focus by default.
- ❌ `onPress` does **not** fire if `disabled` is true.
