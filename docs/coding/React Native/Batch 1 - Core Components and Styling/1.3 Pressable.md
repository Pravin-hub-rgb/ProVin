# Doc 1.3 — Pressable

## Cheat Sheet (Quick Recall)

- `Pressable` = tappable element; `onPress`, `onLongPress`, `onPressIn/Out`.
- Pressed styling via function style: `style={({ pressed }) => ({...})}`.
- `hitSlop` expands tappable area; `disabled` disables; `android_ripple` for Android ripple.
- Prefer `Pressable` over `TouchableOpacity` for new code.

## Main Content

### SOCH

To-do app mein tasks pe tap karna hoga — toggle complete, delete. Web pe `button`/`onClick` hota hai; RN mein `Pressable` hai. Pehle basic tap, phir pressed styling (visual feedback), phir props (hitSlop, disabled, ripple). Agar yeh nahi samjha, to-do app mein buttons "dead" feel honge.

### CONCEPT

**Basic usage:**

```tsx
import { Pressable, Text } from "react-native";

<Pressable onPress={() => console.log("pressed")}>
  <Text>Tap me</Text>
</Pressable>
```

**Pressed styling:**

```tsx
<Pressable
  onPress={() => setCount((c) => c + 1)}
  style={({ pressed }) => ({
    padding: 12,
    backgroundColor: pressed ? "#ddd" : "#eee",
    borderRadius: 8,
  })}
>
  <Text>Press me</Text>
</Pressable>
```

**Common props:**

- `onPress` — tap pe fire.
- `onLongPress` — long tap.
- `onPressIn` / `onPressOut` — press start/end.
- `disabled` — interaction disable.
- `hitSlop` — tappable area expand (visuals nahi badlte).
- `android_ripple` — Android ripple effect.

```tsx
<Pressable
  onPress={handleDelete}
  hitSlop={8}
  android_ripple={{ color: "#ccc" }}
  style={({ pressed }) => ({ opacity: pressed ? 0.6 : 1 })}
>
  <Text>Delete</Text>
</Pressable>
```

**Pressable vs TouchableOpacity:**

- `TouchableOpacity` opacity fade on press (older, common).
- `Pressable` modern, flexible, full control.
- New code mein `Pressable` prefer karo.

### CODE (gradual)

Stage 1 — Static button (no handler):

```tsx
<Pressable style={{ padding: 12, backgroundColor: "#eee", borderRadius: 8 }}>
  <Text>Tap me</Text>
</Pressable>
```

Save, dekho — dikhta hai lekin tap pe kuch nahi hota.

Stage 2 — Add onPress (console.log):

```tsx
<Pressable onPress={() => console.log("tapped")} style={{...}}>
  <Text>Tap me</Text>
</Pressable>
```

Tap kar, console check — "tapped" print hona chahiye.

Stage 3 — Pressed styling:

```tsx
<Pressable
  onPress={() => console.log("tapped")}
  style={({ pressed }) => ({
    padding: 12,
    backgroundColor: pressed ? "#ccc" : "#eee",
    borderRadius: 8,
  })}
>
  <Text>Tap me</Text>
</Pressable>
```

Tap kar, visual change dekho.

Stage 4 — Real action (to-do toggle):

```tsx
<Pressable onPress={() => toggleTask(task.id)} style={({ pressed }) => ({ opacity: pressed ? 0.6 : 1 })}>
  <Text>{task.title}</Text>
</Pressable>
```

## Common Mistakes

- `Pressable` ko `button` samajhna — default styling nahi, khud style karo.
- `onPress` ko `onClick` likhna — RN mein `onPress`.
- `disabled` true pe `onPress` expect karna — nahi chalega.
- Accessibility ignore karna — `accessibilityRole="button"`, `accessibilityLabel` add karo.

## Khud Try Karo

1. `Pressable` with `onLongPress` bana — long press pe alert.
2. `hitSlop={10}` add kar, chhote button pe tap area dekho.
3. `android_ripple={{ color: "blue" }}` add kar (Android device pe dekho).

## Summary

- `Pressable` = tappable; `onPress`, `onLongPress`, `onPressIn/Out`.
- Pressed styling via function style `{ pressed }`.
- `hitSlop`, `disabled`, `android_ripple` useful props.
- New code mein `Pressable` > `TouchableOpacity`.

## What It Is NOT

- ❌ `Pressable` is **not** a `button` — no default styling.
- ❌ `Pressable` does **not** handle keyboard focus by default.
- ❌ `onPress` does **not** fire if `disabled` is true.
