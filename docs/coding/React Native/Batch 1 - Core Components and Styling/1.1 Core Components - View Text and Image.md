# Doc 1.1 — Core Components: View, Text, Image

## Cheat Sheet (Quick Recall)

- `View` = container (like `div`); supports flexbox + styling; nests children.
- `Text` = displays strings; all text must be inside `Text`; supports `fontSize`, `color`, `fontWeight`.
- `Image` = displays pictures; needs `width`/`height`; `resizeMode`: cover/contain/stretch/center.
- Local: `source={require("./assets/x.png")}`; remote: `source={{ uri: "https://..." }}`.

## Main Content

### SOCH

Project run ho raha hai, `app/index.tsx` edit kar sakte hain. Lekin web pe jaise `div`, `p`, `img` use karte the, yahan woh nahi hain. React Native ka apna building blocks hain — `View`, `Text`, `Image`. Pehle yeh teen samajhna padega, phir layout (Flexbox), phir styling. Agar yeh basic nahi samjhe, aage ka code alien lagega.

### CONCEPT

**View — container:**

`View` ek container hai, web ka `div` jaisa. Children hold karta hai, flexbox layout support karta hai, styling support karta hai.

```tsx
import { View } from "react-native";

<View style={{ flex: 1, backgroundColor: "#f5f5f5" }}>
  {/* children */}
</View>
```

- `View` nest ho sakta hai.
- Text directly show nahi hota — `Text` use karo.

**Text — strings:**

`Text` strings display karta hai. All text `Text` ke andar hona chahiye (web jaisa raw text in div nahi).

```tsx
import { Text } from "react-native";

<Text style={{ fontSize: 18, fontWeight: "bold", color: "#333" }}>
  Hello React Native
</Text>
```

- `Text` nest ho sakta hai inline styling ke liye.
- `fontSize`, `color`, `fontWeight` yahan apply hote hain.

**Image — pictures:**

`Image` local assets ya remote URLs display karta hai.

```tsx
import { Image } from "react-native";

// Local asset
<Image source={require("./assets/logo.png")} style={{ width: 100, height: 100 }} />

// Remote URL
<Image
  source={{ uri: "https://example.com/photo.jpg" }}
  style={{ width: 200, height: 200 }}
/>
```

- Always `width` + `height` do (auto-size nahi hota).
- `resizeMode`: `"cover"`, `"contain"`, `"stretch"`, `"center"`.

**Combining (card example):**

```tsx
import { View, Text, Image } from "react-native";

export default function Card() {
  return (
    <View style={{ padding: 16, backgroundColor: "white", borderRadius: 12 }}>
      <Image
        source={{ uri: "https://picsum.photos/200" }}
        style={{ width: "100%", height: 150, borderRadius: 8 }}
        resizeMode="cover"
      />
      <Text style={{ marginTop: 8, fontSize: 16, fontWeight: "600" }}>
        A photo card
      </Text>
    </View>
  );
}
```

Stage 3 — Styling (padding, background):

```tsx
<View style={{ padding: 16, backgroundColor: "white" }}>

```

## Common Mistakes

- Raw text `View` ke andar daalna → crash.
- `Image` ko dimensions na dena → nahi dikhega.
- `require` path galat dena → red error screen.
- Web jaisa CSS properties expect karna (`display: block` etc.) — RN mein nahi hain.

## Khud Try Karo

## Summary

- `View` = container, `Text` = strings, `Image` = pictures.
- Text hamesha `Text` ke andar; Image ko dimensions dena padta hai.
- Local: `require`, remote: `{ uri }`.

## What It Is NOT

- ❌ `View` is **not** a `div` — only flexbox, no CSS grid/all CSS props.
- ❌ `Text` is **not** optional — raw text outside `Text` crashes.
- ❌ `Image` does **not** auto-size — provide dimensions.
