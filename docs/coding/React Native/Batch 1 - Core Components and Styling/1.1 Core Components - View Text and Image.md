# Doc 1.1 — Core Components: View, Text, Image

## Cheat Sheet (Quick Recall)

- `View` = container (like `div`); supports flexbox + styling; nests children.
- `Text` = displays strings; all text must be inside `Text`; supports `fontSize`, `color`, `fontWeight`.
- `Image` = displays pictures; needs `width`/`height`; `resizeMode`: cover/contain/stretch/center.
- Local: `source={require("./assets/x.png")}`; remote: `source={{ uri: "https://..." }}`.

## Main Content

### THINK

The project runs and `app/index.tsx` can be edited. But unlike the web, where `div`, `p`, and `img` exist, React Native has its own building blocks — `View`, `Text`, `Image`. These three need to be understood first, then layout (Flexbox), then styling. Without the basics, later code will feel alien.

### CONCEPT

**View — container:**

`View` is a container, like `div` on the web. It holds children, supports flexbox layout, and supports styling.

```tsx
import { View } from "react-native";

<View style={{ flex: 1, backgroundColor: "#f5f5f5" }}>
  {/* children */}
</View>
```

- `View` can nest.
- Text is not shown directly — use `Text`.

**Text — strings:**

`Text` displays strings. All text must be inside a `Text` component (unlike the web, where text can sit in a `div`).

```tsx
import { Text } from "react-native";

<Text style={{ fontSize: 18, fontWeight: "bold", color: "#333" }}>
  Hello React Native
</Text>
```

- `Text` can nest for inline styling.
- `fontSize`, `color`, `fontWeight` apply here.

**Image — pictures:**

`Image` displays pictures from local assets or remote URLs.

```tsx
import { Image } from "react-native";

// Local asset
<Image source={require("./assets/logo.png")} style={{ width: 100, height: 100 }} />

// Remote URL
<Image
  source={{ uri: "https://example.com/photo.jpg" }}
  style={{ width: 200, height: 200 }}
/>
```

- Always give `width` and `height` (no auto-sizing).
- `resizeMode`: `"cover"`, `"contain"`, `"stretch"`, `"center"`.

**Combining them (card example):**

```tsx
import { View, Text, Image } from "react-native";

export default function Card() {
  return (
    <View style={{ padding: 16, backgroundColor: "white", borderRadius: 12 }}>
      <Image
        source={{ uri: "https://picsum.photos/200" }}
        style={{ width: "100%", height: 150, borderRadius: 8 }}
        resizeMode="cover"
      />
      <Text style={{ marginTop: 8, fontSize: 16, fontWeight: "600" }}>
        A photo card
      </Text>
    </View>
  );
}
```

### CODE (gradual)

Stage 1 — Static skeleton (decide what shows on screen first):

```tsx
<View>
  <Text>Hello</Text>
</View>
```

Stage 2 — Add image (hardcoded dimensions):

```tsx
<View>
  <Image source={{ uri: "https://picsum.photos/100" }} style={{ width: 100, height: 100 }} />
  <Text>Hello</Text>
</View>
```

Stage 3 — Add styling (padding, background):

```tsx
<View style={{ padding: 16, backgroundColor: "white" }}>
  <Image source={{ uri: "https://picsum.photos/100" }} style={{ width: 100, height: 100, borderRadius: 8 }} />
  <Text style={{ marginTop: 8, fontSize: 16 }}>Hello</Text>
</View>
```

After each stage, save and check the phone — the layout is confirmed.

## Common Mistakes

- Putting raw text inside a `View` — crashes.
- Not giving `Image` dimensions — it will not show.
- Wrong `require` path — red error screen.
- Expecting web CSS properties (`display: block`, etc.) — not available in RN.

## Summary

- `View` = container, `Text` = strings, `Image` = pictures.
- Text must always be inside `Text`; `Image` needs dimensions.
- Local: `require`; remote: `{ uri }`.

## What It Is NOT

- ❌ `View` is **not** a `div` — only flexbox, no CSS grid/all CSS props.
- ❌ `Text` is **not** optional — raw text outside `Text` crashes.
- ❌ `Image` does **not** auto-size — provide dimensions.
