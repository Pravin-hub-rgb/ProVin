# Doc 1.5 — Flexbox in React Native

## Cheat Sheet (Quick Recall)

- Default `flexDirection` = `column` (web = `row`); `alignItems` default `stretch`.
- No `display: block/inline` — everything is flex.
- `flex: 1` fills available space; `gap` for spacing between children.
- Units = dp (density-independent pixels); screen size via `useWindowDimensions`.
- No CSS Grid in RN core.

## Main Content

### THINK

Components (`View`, `Text`, `Image`, `ScrollView`, `Pressable`, `TextInput`) are understood. But how to arrange them on screen? On the web there is CSS (flexbox/grid/block). In RN there is only Flexbox — but the defaults differ from the web. If the defaults are not understood, the "why is this not centering" confusion will come. So first the differences, then patterns.

### CONCEPT

**Defaults (different from web):**

- `flexDirection` default = **`column`** (web = `row`).
- `alignItems` default = **`stretch`**.
- No `display: block/inline` — everything is flex.

**Common patterns:**

Center content:

```tsx
<View style={{ flex: 1, justifyContent: "center", alignItems: "center" }}>
  <Text>Centered</Text>
</View>
```

Row with space between:

```tsx
<View style={{ flexDirection: "row", justifyContent: "space-between", alignItems: "center" }}>
  <Text>Left</Text>
  <Text>Right</Text>
</View>
```

Fixed header + scrolling body:

```tsx
<View style={{ flex: 1 }}>
  <View style={{ height: 60, backgroundColor: "#eee" }}>
    <Text>Header</Text>
  </View>
  <ScrollView style={{ flex: 1 }}>
    {/* content */}
  </ScrollView>
</View>
```

**Key properties:**

| Property | Values |
|----------|--------|
| `flexDirection` | `row`, `column`, `row-reverse`, `column-reverse` |
| `justifyContent` | `flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly` |
| `alignItems` | `flex-start`, `center`, `flex-end`, `stretch`, `baseline` |
| `flex` | number (grow factor); `flex: 1` fills space |
| `gap` | spacing between children |
| `flexWrap` | `wrap` for wrapping |

**Units:**

- No `px`, `rem`, `em`, `%` (except width/height percentages).
- Numbers = dp (density-independent pixels), auto-scaled across devices.
- Use `Dimensions` or `useWindowDimensions` for screen-based sizing.

```tsx
import { useWindowDimensions } from "react-native";

const { width, height } = useWindowDimensions();
```

**No CSS Grid in RN core** — use flexbox or libraries.

### CODE (gradual)

Stage 1 — Default column (no flexDirection):

```tsx
<View style={{ flex: 1 }}>
  <Text>First</Text>
  <Text>Second</Text>
</View>
```

Observe — vertical stack (column default).

Stage 2 — Row:

```tsx
<View style={{ flexDirection: "row", gap: 8 }}>
  <Text>Left</Text>
  <Text>Right</Text>
</View>
```

Stage 3 — Centered:

```tsx
<View style={{ flex: 1, justifyContent: "center", alignItems: "center" }}>
  <Text>Centered</Text>
</View>
```

Stage 4 — Fill space:

```tsx
<View style={{ flex: 1 }}>
  <View style={{ flex: 1, backgroundColor: "red" }} />
  <View style={{ flex: 2, backgroundColor: "blue" }} />
</View>
```

Blue takes 2x the space of red.

## Common Mistakes

- Assuming the web default (`row`) — RN uses `column`.
- Expecting `%` for margins/padding — prefer `flex`/`gap`.
- Not giving the parent `flex: 1` — the child will not fill.
- Expecting CSS Grid — not in RN core.

## Try It Yourself

1. Build a row with 3 boxes of equal width (`flex: 1` each).
2. Add `gap: 12` and observe the spacing.
3. Print the screen width with `useWindowDimensions`.

## Summary

- Flexbox is the only layout; default `column`.
- `flex: 1` fills space; `gap` for spacing; `justifyContent`/`alignItems` for alignment.
- Units are dp; screen size via `useWindowDimensions`; no CSS Grid.
