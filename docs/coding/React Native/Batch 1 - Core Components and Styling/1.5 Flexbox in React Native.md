# Doc 1.5 — Flexbox in React Native

## Cheat Sheet (Quick Recall)

- Default `flexDirection` = `column` (web = `row`); `alignItems` default `stretch`.
- No `display: block/inline` — everything flex.
- `flex: 1` fills available space; `gap` for spacing between children.
- Units = dp (density-independent pixels); screen size via `useWindowDimensions`.
- No CSS Grid in RN core.

## Main Content

### SOCH

Components (`View`, `Text`, `Image`, `ScrollView`, `Pressable`, `TextInput`) samajh aaye. Lekin screen pe kaise arrange karein? Web pe CSS (flexbox/grid/block) hota hai. RN mein sirf Flexbox hai — lekin defaults web se alag hain. Agar defaults nahi samjhe, toh "kyun yeh center nahi ho raha" wali confusion aayegi. Isliye pehle differences, phir patterns.

### CONCEPT

**Defaults (web se different):**

- `flexDirection` default = **`column`** (web = `row`).
- `alignItems` default = **`stretch`**.
- No `display: block/inline` — everything flex.

**Common patterns:**

Center content:

```tsx
<View style={{ flex: 1, justifyContent: "center", alignItems: "center" }}>
  <Text>Centered</Text>
</View>
```

Row with space-between:

```tsx
<View style={{ flexDirection: "row", justifyContent: "space-between", alignItems: "center" }}>
  <Text>Left</Text>
  <Text>Right</Text>
</View>
```

Fixed header + scrolling body:

```tsx
<View style={{ flex: 1 }}>
  <View style={{ height: 60, backgroundColor: "#eee" }}>
    <Text>Header</Text>
  </View>
  <ScrollView style={{ flex: 1 }}>
    {/* content */}
  </ScrollView>
</View>
```

**Key properties:**

| Property | Values |
|----------|--------|
| `flexDirection` | `row`, `column`, `row-reverse`, `column-reverse` |
| `justifyContent` | `flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly` |
| `alignItems` | `flex-start`, `center`, `flex-end`, `stretch`, `baseline` |
| `flex` | number (grow factor); `flex: 1` fills space |
| `gap` | spacing between children |
| `flexWrap` | `wrap` for wrapping |

**Units:**

- No `px`, `rem`, `em`, `%` (except width/height %).
- Numbers = dp (density-independent pixels), auto-scaled.
- Screen size: `useWindowDimensions`.

```tsx
import { useWindowDimensions } from "react-native";
const { width, height } = useWindowDimensions();
```

**No CSS Grid in RN core** — flexbox use karo ya libraries.

### CODE (gradual)

Stage 1 — Default column (no flexDirection):

```tsx
<View style={{ flex: 1 }}>
  <Text>First</Text>
  <Text>Second</Text>
</View>
```

Dekho — vertical stack (column default).

Stage 2 — Row:

```tsx
<View style={{ flexDirection: "row", gap: 8 }}>
  <Text>Left</Text>
  <Text>Right</Text>
</View>
```

Stage 3 — Centered:

```tsx
<View style={{ flex: 1, justifyContent: "center", alignItems: "center" }}>
  <Text>Centered</Text>
</View>
```

Stage 4 — Fill space:

```tsx
<View style={{ flex: 1 }}>
  <View style={{ flex: 1, backgroundColor: "red" }} />
  <View style={{ flex: 2, backgroundColor: "blue" }} />
</View>
```

Blue 2x red space lega.

## Common Mistakes

- Web ka default (`row`) assume karna — RN mein `column`.
- `%` for margins/padding expect karna — prefer `flex`/`gap`.
- `flex: 1` parent pe nahi dena — child fill nahi karega.
- CSS Grid expect karna — RN core mein nahi.

## Khud Try Karo

1. Ek row bana jisme 3 boxes equal width (`flex: 1` each).
2. `gap: 12` add kar, spacing dekho.
3. `useWindowDimensions` se screen width print kar.

## Summary

- Flexbox only layout; default `column`.
- `flex: 1` fills space; `gap` for spacing; `justifyContent`/`alignItems` for alignment.
- Units dp; screen size `useWindowDimensions`; no CSS Grid.
