# Doc 1.8 — Props, State, and Events from React

## Cheat Sheet (Quick Recall)

- Props/state/hooks carry over unchanged: `useState`, `useReducer`, `useRef`, Context, Redux, TanStack Query.
- Events differ: `onPress` (not `onClick`), `onChangeText` gives string (not event).
- `onChangeText` receives typed string directly; no `e.target.value`.
- Keyboard: `KeyboardAvoidingView` (no `position: fixed`).

### CONCEPT

**Props (same as React):**

```tsx
type GreetingProps = { name: string; color?: string };

function Greeting({ name, color = "#333" }: GreetingProps) {
  return <Text style={{ color }}>{`Hello, ${name}`}</Text>;
}

<Greeting name="Vin" />
```

- TypeScript interfaces same.
- Destructuring, defaults, children same.

**State (same as React):**

```tsx
const [count, setCount] = useState(0);
```

- `useState`, `useReducer`, `useRef` unchanged.
- State update → re-render, same as web.

**Events (RN differences):**

| Web | React Native |
|-----|--------------|
| `onClick` | `onPress` (Pressable) |
| `onChange` (input) | `onChangeText` (TextInput) — gives string |
| `onSubmit` | `onSubmitEditing` (TextInput) |

```tsx
<Pressable onPress={() => setCount((c) => c + 1)}>
  <Text>Count: {count}</Text>
</Pressable>

<TextInput
  value={text}
  onChangeText={setText}
  onSubmitEditing={() => console.log("submitted", text)}
/>
```

**What's different:**

- No DOM events (no `onClick`, `onMouseEnter`).
- Touch events: `onPress`, `onLongPress`, `onPressIn/Out`.
- `onChangeText` gives string, not event.
- `KeyboardAvoidingView` for keyboard (no `position: fixed`).

### CODE (gradual)

Stage 1 — Props (static):

```tsx
function Greeting({ name }: { name: string }) {
  return <Text>Hello, {name}</Text>;
}
<Greeting name="Vin" />
```

Stage 2 — State (counter):

```tsx
const [count, setCount] = useState(0);
<Pressable onPress={() => setCount((c) => c + 1)}>
  <Text>Count: {count}</Text>
</Pressable>
```

Stage 3 — Event difference (onChangeText):

```tsx
const [text, setText] = useState("");
<TextInput value={text} onChangeText={setText} />
<Text>{text}</Text>
```

Stage 4 — Combined (props + state + event):

```tsx
type TaskProps = { title: string; onToggle: () => void };
function TaskItem({ title, onToggle }: TaskProps) {
  return (
    <Pressable onPress={onToggle}>
      <Text>{title}</Text>
    </Pressable>
  );
}
```

## Common Mistakes

- `onClick` likhna — RN mein `onPress`.
- `onChangeText` se event expect karna — string aata hai.
- `e.target.value` use karna — RN mein nahi hota.
- Web jaise DOM events expect karna — nahi hain.
