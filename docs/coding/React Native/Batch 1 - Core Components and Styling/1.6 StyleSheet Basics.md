# Doc 1.6 — StyleSheet Basics

## Cheat Sheet (Quick Recall)

- `StyleSheet.create({...})` defines styles as JS objects with camelCase keys.
- Use `style={styles.x}` or array `style={[styles.a, styles.b, { color: "red" }]}`.
- `StyleSheet.create` validates keys, registers once (performance), keeps JSX clean.
- Platform-specific: `Platform.select({ ios: {...}, android: {...} })`.
- No CSS selectors/cascading/global stylesheet.

## Main Content

### SOCH

Flexbox samajh aaya — layout arrange kar sakte hain. Lekin abhi styling (colors, fonts, padding) inline objects se kar rahe hain — messy. Web pe CSS files hain; RN mein `StyleSheet` hai. Pehle basic usage, phir `StyleSheet.create` ka fayda, phir combining styles, phir platform-specific.

### CONCEPT

**Basic usage:**

```tsx
import { StyleSheet, Text, View } from "react-native";

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Hello</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: "#fff",
    alignItems: "center",
    justifyContent: "center",
  },
  title: {
    fontSize: 24,
    fontWeight: "bold",
    color: "#333",
  },
});
```

**Why `StyleSheet.create`?**

- **Validation:** invalid style keys dev time pe catch.
- **Performance:** styles once register, ID se reference.
- **Readability:** JSX clean.

Inline objects (`style={{ color: "red" }}`) bhi possible, lekin reusable ke liye `StyleSheet.create` prefer.

**Combining styles:**

```tsx
<Text style={[styles.base, styles.bold, { color: "red" }]}>
  Combined
</Text>
```

Later styles override earlier for same property.

**Platform-specific:**

```tsx
import { Platform } from "react-native";

const styles = StyleSheet.create({
  shadow: {
    ...Platform.select({
      ios: { shadowColor: "#000", shadowOpacity: 0.2, shadowRadius: 4 },
      android: { elevation: 4 },
    }),
  },
});
```

### CODE (gradual)

Stage 1 — Inline style (messy):

```tsx
<View style={{ flex: 1, backgroundColor: "#fff", padding: 16 }}>
  <Text style={{ fontSize: 24, color: "#333" }}>Hello</Text>
</View>
```

Save, dekho — kaam karta hai lekin messy.

Stage 2 — `StyleSheet.create`:

```tsx
const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: "#fff", padding: 16 },
  title: { fontSize: 24, color: "#333" },
});

<View style={styles.container}>
  <Text style={styles.title}>Hello</Text>
</View>
```

Stage 3 — Combining:

```tsx
<Text style={[styles.title, styles.bold, { color: "red" }]}>Hello</Text>
```

Stage 4 — Platform-specific shadow:

```tsx
const styles = StyleSheet.create({
  card: {
    padding: 16,
    ...Platform.select({
      ios: { shadowColor: "#000", shadowOpacity: 0.2, shadowRadius: 4 },
      android: { elevation: 4 },
    }),
  },
});
```

## Common Mistakes

- Inline objects everywhere — messy, no validation.
- Style keys kebab-case likhna — RN camelCase chahiye (`backgroundColor`).
- CSS selectors expect karna — RN mein nahi hain.
- Global stylesheet expect karna — per-component styles.

## Summary

- `StyleSheet.create` = styles as JS objects, camelCase keys.
- Combine via array; override later.
- `Platform.select` for platform-specific.
- No selectors/cascading/global.

## What It Is NOT

- ❌ `StyleSheet` is **not** CSS — no selectors/cascading.
- ❌ Styles are **not** strings — JS objects, camelCase.
- ❌ No global stylesheet — per-component (or shared via imports).
