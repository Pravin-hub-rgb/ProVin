# Doc 1.2 — ScrollView

## Cheat Sheet (Quick Recall)

- `ScrollView` = scrollable container for content taller than the screen.
- Default vertical; horizontal with the `horizontal` prop.
- `contentContainerStyle` styles the inner container.
- Not virtualized — use `FlatList` for long lists (Batch 3).
- Props: `showsVerticalScrollIndicator`, `keyboardShouldPersistTaps`, `refreshControl`.

## Main Content

### THINK

In 1.1 a card was built. But if there are 30 cards on screen, not all will show — the screen is small. On the web there is `overflow: scroll`; in React Native there is `ScrollView`. First understand how `ScrollView` works, then its limitations (no virtualization), then `FlatList` (later).

### CONCEPT

**Basic usage:**

```tsx
import { ScrollView, Text, View } from "react-native";

export default function App() {
  return (
    <ScrollView>
      {Array.from({ length: 30 }).map((_, i) => (
        <View key={i} style={{ padding: 16 }}>
          <Text>Row {i + 1}</Text>
        </View>
      ))}
    </ScrollView>
  );
}
```

- `ScrollView` scrolls vertically by default.
- For horizontal scrolling: `<ScrollView horizontal>`.

**Horizontal ScrollView:**

```tsx
<ScrollView horizontal showsHorizontalScrollIndicator={false}>
  {items.map((item) => (
    <View key={item.id} style={{ width: 120, marginRight: 12 }}>
      <Text>{item.title}</Text>
    </View>
  ))}
</ScrollView>
```

**Useful props:**

- `contentContainerStyle` — style the inner container (padding, gap).
- `showsVerticalScrollIndicator` / `showsHorizontalScrollIndicator` — toggle scrollbars.
- `keyboardShouldPersistTaps` — keep the keyboard open when tapping outside inputs.
- `refreshControl` — pull-to-refresh (with `RefreshControl`).

**ScrollView vs FlatList:**

- `ScrollView` renders **all** children at once. Fine for small lists.
- `FlatList` renders only visible items (virtualized). Use it for long lists (Batch 3).

For now, `ScrollView` is enough. Switch to `FlatList` when lists get long.

## Common Mistakes

- `ScrollView` inside a `ScrollView` (same direction) → gesture conflict.
- 1000+ items in `ScrollView` → slow (use `FlatList`).
- Confusing `contentContainerStyle` with `style` — use `contentContainerStyle` for the inner container.
- Ignoring keyboard handling → inputs get covered (handled in Batch 3).

## Summary

- `ScrollView` = scrollable container; vertical by default, `horizontal` for horizontal.
- `contentContainerStyle` for inner padding/gap.
- Not virtualized — use `FlatList` for long lists (Batch 3).

## What It Is NOT

- ❌ `ScrollView` is **not** virtualized — 1000 items will be slow.
- ❌ `ScrollView` inside a same-direction `ScrollView` → gesture conflict.
- ❌ `ScrollView` does **not** auto-scroll to inputs.
