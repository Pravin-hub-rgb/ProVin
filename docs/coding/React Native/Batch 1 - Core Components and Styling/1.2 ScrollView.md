# Doc 1.2 — ScrollView

## Cheat Sheet (Quick Recall)

- `ScrollView` = scrollable container for content taller than screen.
- Default vertical; horizontal with `horizontal` prop.
- `contentContainerStyle` styles inner container.
- Not virtualized — use `FlatList` for long lists (Batch 3).
- Props: `showsVerticalScrollIndicator`, `keyboardShouldPersistTaps`, `refreshControl`.

## Main Content

### SOCH

1.1 mein card banaya. Lekin agar screen pe 30 cards hon, toh sab nahi dikhenge — screen chhoti hai. Web pe `overflow: scroll` hota hai; React Native mein `ScrollView` use hota hai. Pehle yeh samajhna hai ki `ScrollView` kaise kaam karta hai, phir limitations (virtualization nahi), phir `FlatList` (baad mein).

### CONCEPT

**Basic usage:**

```tsx
import { ScrollView, Text, View } from "react-native";

export default function App() {
  return (
    <ScrollView>
      {Array.from({ length: 30 }).map((_, i) => (
        <View key={i} style={{ padding: 16 }}>
          <Text>Row {i + 1}</Text>
        </View>
      ))}
    </ScrollView>
  );
}
```

- Default vertical scroll.
- Horizontal: `<ScrollView horizontal>`.

**Horizontal example:**

```tsx
<ScrollView horizontal showsHorizontalScrollIndicator={false}>
  {items.map((item) => (
    <View key={item.id} style={{ width: 120, marginRight: 12 }}>
      <Text>{item.title}</Text>
    </View>
  ))}
</ScrollView>
```

**Useful props:**

- `contentContainerStyle` — inner container style (padding, gap).
- `showsVerticalScrollIndicator` / `showsHorizontalScrollIndicator` — scrollbar toggle.
- `keyboardShouldPersistTaps` — keyboard open rakhna jab input ke bahar tap ho.
- `refreshControl` — pull-to-refresh (`RefreshControl` ke saath).

**ScrollView vs FlatList:**

- `ScrollView` sab children ek saath render karta hai. Small lists ke liye fine.
- `FlatList` sirf visible items render karta hai (virtualized). Long lists ke liye (Batch 3).

### CODE (gradual)

Stage 3 — ScrollView wrap:

```tsx

      <Text>Row {i + 1}</Text>
    </View>
  ))}

```

Ab scroll hoga. Stage 4 — inner padding:

```tsx
<ScrollView contentContainerStyle={{ padding: 16, gap: 8 }}>
  ...

```

## Common Mistakes

- `ScrollView` inside `ScrollView` (same direction) → gesture conflict.
- 1000+ items in `ScrollView` → slow (use `FlatList`).
- `contentContainerStyle` vs `style` confuse karna — inner container ke liye `contentContainerStyle`.
- Keyboard covering inputs → `KeyboardAvoidingView` (Batch 3) use karo.

## Summary

- `ScrollView` = scrollable container; vertical default, `horizontal` for horizontal.
- `contentContainerStyle` for inner padding/gap.
- Not virtualized — long lists ke liye `FlatList` (Batch 3).

## What It Is NOT

- ❌ `ScrollView` is **not** virtualized — 1000 items slow honge.
- ❌ `ScrollView` inside same-direction `ScrollView` → gesture conflict.
- ❌ `ScrollView` does **not** auto-scroll to inputs.
