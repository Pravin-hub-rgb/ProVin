Tools give an agent power. But power without direction is just chaos. An agent needs to figure out *what to do first, what to do second, and what to do third*. That's planning.

There are two approaches agents take, and you've seen both:

**1. Reactive (step-by-step):** The agent doesn't plan ahead. It just looks at the current situation and asks "what should I do next?" This is the basic ReAct loop you learned in 2.2. It works fine for simple tasks where each step is obvious from the previous result. Need to fix a bug? Read the error → find the file → edit the line → test again. Each step tells you what comes next.

**2. Planned (divide and conquer):** The agent first creates a full plan — a list of steps — and then executes them one by one. This is better for complex tasks where you'd get lost without a map.

Here's how "Build me a landing page" plays out with the second approach:

1. Agent thinks: *"I need a landing page. That means: create a project folder, write the HTML, write the CSS, add content, and test it in a browser."*
2. Agent creates the folder: `mkdir landing-page`
3. Agent writes `index.html` with a headline, subtext, and a CTA button
4. Agent writes `styles.css` with a clean modern design
5. Agent opens `index.html` in the browser to verify it works
6. Agent reports back: "Your landing page is ready at landing-page/index.html"

The key difference? The agent spent a few seconds *thinking about the whole task* before touching anything. That upfront thinking means it doesn't get halfway through and realize it forgot something important.

You've seen Cline do this. When you give it a big task like "build a full-stack todo app," Cline often pauses, thinks, then says something like "Here's my plan: first I'll set up the backend with Express, then create the React frontend, then connect them." That's the planned approach. Then it executes step by step, and if something goes wrong, it adapts.

The best agents do both. They start with a plan, then react to what happens during execution. If step 3 fails, they don't just blindly retry — they update the plan.

This is where the real magic happens. An agent that can plan, execute, and replan in real time feels less like a tool and more like a teammate.
