By now you've got the picture: agents think, act, observe, plan, use tools, and get things done. But this isn't theory. Agents are shipping in real products that people use every day. Let's look at where they show up.

![Where Agents Live Today — Coding, Research, Browser, and Business Agents](/diagrams/agenticai/agent-landscape.svg)

**Coding agents** — This is your world. Cline, opencode, Cursor, Kodu, Devin, GitHub Copilot (in agent mode). These agents live inside your editor or terminal. They read and write code, run commands, debug errors, and sometimes even push to GitHub. They're the most mature category because code is structured, tools are well-defined, and the feedback loop is fast — you know immediately if the code works or not.

**Research agents** — Perplexity, ChatGPT with web search, Claude's research mode. Give them a question, they search the web, read multiple sources, cross-reference, and come back with a synthesized answer. No more digging through ten tabs. They do the digging for you.

**Browser agents** — These are agents that control a web browser. Claude's computer use feature (where it moves a cursor and clicks things), Operator (OpenAI's browser agent), and various open-source projects. They can fill out forms, navigate multi-step workflows, and interact with sites that don't have APIs. It's like having someone screenshare with you, but that someone is an AI.

**Business agents** — These handle the boring stuff. Sort emails, update CRM records, generate invoices, draft replies, schedule meetings. Tools like Lindy, AutoGPT, and custom AI workflows let you point an agent at a business process and say "handle this." They're less flashy than coding agents, but they save real hours.

**The trend:** 2024 was the year agents went from demo to production. 2025 is when they started becoming expected. Every major AI company is building agent infrastructure — not just better models, but better *tools for agents to use*. The model is the brain, but the tools and the loop are the body.

Here's what that means for you: The skills you're building right now — understanding how agents think, how they plan, what tools they use — are directly applicable to the wave of products coming. When you use Cline or opencode today, you're not just using a code helper. You're piloting one of the first generation of real AI agents.

## What It Is NOT

Agents are **not** a replacement for human judgment — not yet. Current agents are great at executing well-defined tasks within clear boundaries, but they can't set their own goals, exercise real judgment, or handle truly novel situations without supervision. An agent can write code for a feature you describe, but it can't decide which features your product needs. It's like a very capable executive assistant: they can schedule meetings, draft emails, and organize your calendar, but you still decide what your priorities are.

### In Your Own Words

<details>
<summary>1. Which category of agent (coding, research, browser, business) do you think will improve fastest? Why?</summary>

**Sample Answer:** Coding agents. The feedback loop is the tightest — you run the code and instantly know if it works. That makes it easy to measure improvement and train better models. Research and business agents have fuzzier success criteria (was that summary good enough?), which slows the improvement cycle. Code either compiles or it doesn't.

</details>

<details>
<summary>2. Pick a category *not* listed above. Where else could agents live? (Healthcare? Education? Gaming?)</summary>

**Sample Answer:** Healthcare — an agent that reads lab results, checks them against patient history, highlights anomalies, and drafts a preliminary report for the doctor. It wouldn't diagnose (that's the doctor's job), but it could save hours of chart review per patient. The key is keeping the human in the loop for decisions.

</details>

<details>
<summary>3. What's something agents can do *today* that would have sounded like science fiction five years ago?</summary>

**Sample Answer:** An agent that takes a GitHub issue, reads the codebase, implements the fix, writes tests, and opens a pull request — all without human intervention. Five years ago, that sounded like hiring a junior developer. Today, Cline or opencode does it from a terminal command. The sci-fi part isn't the intelligence — it's the autonomy.

</details>

<details>
<summary>4. Do you trust a browser agent to handle your online shopping? What would it take for you to trust it?</summary>

**Sample Answer:** Not yet. I'd trust it to research and compare products, but not to enter payment details or complete a purchase. For me to trust it fully, I'd need: (1) a clear log of every action it took, (2) a confirmation step before any financial transaction, and (3) a money-back guarantee from the provider if the agent makes a purchase error. Trust is earned through transparency and safety nets.

</details>

<details>
<summary>5. Of the four categories, which one do you think is most dangerous if the agent malfunctions? Why?</summary>

**Sample Answer:** Browser agents, because they operate in the wildest environment. A coding agent breaks your code — you can undo it with git. A research agent gives bad info — you can fact-check. But a browser agent could accidentally buy something, delete an account, or send a message you didn't approve. The attack surface is huge because the browser is the gateway to everything: email, banking, social media, work apps.

</details>
