By now you've got the picture: agents think, act, observe, plan, use tools, and get things done. But this isn't theory. Agents are shipping in real products that people use every day. Let's look at where they show up.

**Coding agents** — This is your world. Cline, Cursor, Kodu, Devin, GitHub Copilot (in agent mode). These agents live inside your editor or terminal. They read and write code, run commands, debug errors, and sometimes even push to GitHub. They're the most mature category because code is structured, tools are well-defined, and the feedback loop is fast — you know immediately if the code works or not.

**Research agents** — Perplexity, ChatGPT with web search, Claude's research mode. Give them a question, they search the web, read multiple sources, cross-reference, and come back with a synthesized answer. No more digging through ten tabs. They do the digging for you.

**Browser agents** — These are agents that control a web browser. Claude's computer use feature (where it moves a cursor and clicks things), Operator (OpenAI's browser agent), and various open-source projects. They can fill out forms, navigate multi-step workflows, and interact with sites that don't have APIs. It's like having someone screenshare with you, but that someone is an AI.

**Business agents** — These handle the boring stuff. Sort emails, update CRM records, generate invoices, draft replies, schedule meetings. Tools like Lindy, AutoGPT, and custom AI workflows let you point an agent at a business process and say "handle this." They're less flashy than coding agents, but they save real hours.

**The trend:** 2024 was the year agents went from demo to production. 2025 is when they started becoming expected. Every major AI company is building agent infrastructure — not just better models, but better *tools for agents to use*. The model is the brain, but the tools and the loop are the body.

Here's what that means for you: The skills you're building right now — understanding how agents think, how they plan, what tools they use — are directly applicable to the wave of products coming. When you use Cline today, you're not just using a code helper. You're piloting one of the first generation of real AI agents.
