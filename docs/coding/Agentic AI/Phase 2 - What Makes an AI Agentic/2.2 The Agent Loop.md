So an agent doesn't just answer — it *acts*. But how does it decide what to do next? It follows a loop. A simple, repeatable pattern that runs until the job is done.

It's called the **ReAct pattern** (short for Reason + Act, though you'll also hear "Think-Act-Observe"). Here's what it looks like:

**Think → Act → Observe → Think → Act → Observe → ... → Done**

Let's break down each step:

**Think:** The model looks at where it is and where it needs to go. It asks itself: "What's the next thing I should do to make progress on this goal?" This isn't magic — it's the same prediction engine you learned about in Phase 1, but now pointed at a different kind of question: "What action should I take next?"

**Act:** The model doesn't just output text to you. It calls a *tool* — a function that does something in the real world. Read a file. Write a file. Run a command. Search the web. This is the key difference from a chatbot. The model's output gets *executed*, not just displayed.

**Observe:** The tool returns a result. The model reads it. Maybe the file was created successfully. Maybe there was an error. Maybe the search returned ten links. This new information becomes part of the model's context.

Then the loop repeats. The model thinks again, armed with new information. Act again. Observe again. Over and over until the original goal is met.

This is exactly what Cline does when you give it a task. Watch the next time you use it:

1. You say "build a todo app with React"
2. Cline *thinks* about what to do first
3. Cline *acts*: runs `npx create-react-app todo-app`
4. Cline *observes*: the output says it installed successfully
5. Cline *thinks*: "Good, now I need to create the components"
6. Cline *acts*: writes `TodoList.js`
7. Cline *observes*: file saved successfully
8. …and so on until your todo app is running

You're watching the ReAct loop in real time. Every time Cline shows you its reasoning before running a command, that's the "Think" step. Every command it runs is an "Act." Every result it reads back is an "Observe."

This loop is the engine that makes an agent an agent. Without it, you just have a very smart text generator.
