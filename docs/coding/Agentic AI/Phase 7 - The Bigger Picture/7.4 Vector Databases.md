When you have multiple agents handling lots of information, you need better memory systems. The context window of a single LLM call is limited — even the big ones top out at a couple hundred thousand tokens. For real-world applications, that's not enough.

This is where vector databases come in.

A vector database stores text as mathematical representations called **embeddings**. An embedding takes a piece of text — a sentence, a paragraph, a whole document — and converts it into a list of numbers (a vector). The trick is that similar texts produce similar vectors.

Think about it like this: the vector for "dogs playing in the park" will be close to the vector for "puppies running outside," but far from the vector for "quantum physics equations." The database can search by **meaning**, not just keywords.

The main vector databases you'll hear about:

- **Pinecone** — fully managed, easy to start with, paid
- **Chroma** — open source, runs locally, great for prototyping
- **Weaviate** — open source, supports hybrid search (vector + keyword)
- **Qdrant** — open source, fast, written in Rust

Here's how an agent uses a vector database in practice:

1. You feed the agent's past conversations, documents, or project files into the database. Each piece gets converted to an embedding and stored.
2. When the agent needs to answer a question, it converts the question into an embedding.
3. It searches the vector database for the closest vectors — the pieces of text most *meaningfully* related to the question.
4. It pulls those relevant pieces into the context window.
5. Now the LLM has the relevant information right in its context, without needing to fit the entire history.

This is how AI coding tools "remember" your past projects across sessions. When Cline or Cursor suggests something based on your older code, it's likely pulling from a vector database. This is called **RAG** (Retrieval Augmented Generation) — retrieve relevant information first, then generate the answer.

Vector databases are the bridge between the limited context window of an LLM and the unlimited information you want it to work with.
