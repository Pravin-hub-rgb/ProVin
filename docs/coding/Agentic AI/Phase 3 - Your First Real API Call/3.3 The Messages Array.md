# 3.3 The Messages Array

The most important part of that API call was the `messages` array. Let's understand it properly, because everything else we build — multi-turn conversations, system prompts, tool calling — depends on getting this right.

## Why an Array?

A single prompt-response exchange isn't very useful. You want to have a conversation, where each new message builds on everything said before. The `messages` array represents that history. Each element is one turn in the conversation.

The model doesn't remember anything between API calls. That's not a limitation — it's by design. Every request is stateless. If you want the model to know what was said earlier, you have to include it in the `messages` array. This is called **providing context**.

Think of it like email. Each time you send an email to someone, you might include the previous email thread below your new message. Without that thread, the recipient has no idea what you're talking about. The `messages` array is your email thread.

## Roles

Each message has a `role` field. Two roles matter right now:

- **`"user"`**: Something a human said. That's you.
- **`"assistant"`**: Something the model said. That's Claude.

The model learns from the alternating pattern. You send user, it responds assistant. You send user again, it responds assistant again. The conversation alternates.

Here's what a two-turn conversation looks like:

```javascript
import Anthropic from "@anthropic-ai/sdk";
import dotenv from "dotenv";
dotenv.config();

const client = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY });

const message = await client.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 1024,
  messages: [
    { role: "user", content: "What's the capital of France?" },
    { role: "assistant", content: "The capital of France is Paris." },
    { role: "user", content: "What's the population of that city?" }
  ],
});

console.log(message.content[0].text);
```

The model sees the full history: its previous answer, your follow-up question, and the context of what "that city" refers to. Without the assistant's previous response in the array, the model wouldn't know what "that city" meant.

Try removing the assistant's turn and see what happens.

## Building a Conversation Manually

In a real app, you'd build the messages array dynamically. Here's a simple chat loop:

```javascript
import Anthropic from "@anthropic-ai/sdk";
import dotenv from "dotenv";
dotenv.config();

const client = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY });
const conversation = [];

async function ask(question) {
  conversation.push({ role: "user", content: question });

  const response = await client.messages.create({
    model: "claude-sonnet-4-20250514",
    max_tokens: 1024,
    messages: conversation,
  });

  const reply = response.content[0].text;
  conversation.push({ role: "assistant", content: reply });
  return reply;
}

const answer1 = await ask("Name three programming languages.");
console.log("First answer:", answer1);

const answer2 = await ask("Which one is best for beginners?");
console.log("Second answer:", answer2);
```

Each call appends to `conversation`, so the model always has full context. This is exactly how every chatbot works at the most basic level.

## The System Prompt

You might have noticed the `messages` array only has `"user"` and `"assistant"` roles. There's a third piece: the **system prompt**.

The system prompt is a special instruction that sets the model's behavior. It's not part of the conversation history — it's guidance that applies to the entire interaction. You pass it as a separate parameter:

```javascript
const message = await client.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 1024,
  system: "You are a grumpy librarian. Answer every question with a sigh and some mild annoyance.",
  messages: [
    { role: "user", content: "What's the capital of France?" }
  ],
});
```

The system prompt influences the model's tone, personality, constraints, and capabilities. It's where you'd put things like "You are a helpful coding assistant" or "Answer only in Spanish" or "Never mention that you're an AI."

The key difference: the **system prompt** is consistent across the whole conversation, while **messages** evolve turn by turn. Most AI coding tools put their entire personality and instruction set in the system prompt. Cline's system prompt is paragraphs long — it defines the tool schema, the thinking protocol, the output format. Everything.
