# Introductory Video Script

---

Hey, welcome to **Agentic AI for Vibe Coders**.

This is the course for you if — you've been using Cline, opencode, Copilot, whatever — you give it a prompt, the project gets done, but you don't really know what's happening in the background.

You know a little bit. Plan mode. Build mode. Context window. Tokens. You've heard these words. But it's fuzzy. You kinda nod along when people talk about agentic AI, but you're not 100% sure how it all fits together.

This course is for that exact person.

---

**After this course**, you can simply write in your resume: I understand Agentic AI. Put it as a skill. When someone brings it up at a meetup or in an interview, you won't nod along pretending — you'll actually have points to add to the conversation.

---

So the course is divided into **seven phases**. Here's the tree:

[Show the full mermaid tree diagram]

**Phase 1 — How AI Models Actually Work**
We start from absolute zero. What is a language model? What are tokens? What is a context window? How does your request travel from your keyboard to a data center and back? What does temperature actually do? No fluff, just real understanding.

**Phase 2 — What Makes an AI Agentic**
Chatbot vs Agent — what's the real difference? The ReAct loop: Think, Act, Observe. What tools can agents use? How do they plan? Where do agents live in the real world today?

**Phase 3 — Your First Real API Call**
We get hands-on. Setting up, making your first API call, understanding the messages array, reading the raw response object, handling errors. You'll see the JSON going back and forth — no magic.

**Phase 4 — Tool Calling: The Heart of Agents**
This is the big one. What tool calling actually is. How to define tools. We build a calculator agent, then add multiple tools with a dispatcher, and finally the full tool calling loop — the while loop that powers every agent out there.

**Phase 5 — Memory and Context Management**
Why do LLMs forget everything between calls? Four types of memory. How to manage conversation history. System prompts. And finally RAG — how agents work with knowledge that doesn't fit in the context window.

**Phase 6 — Building Real Agents: 3 Projects**
Three real Next.js projects. A Weather Agent that calls an API and returns natural answers. A File Summarizer that reads your files and produces a summary. And a Research Agent that searches the web, decides how many times to search, and writes a full report.

**Phase 7 — The Bigger Picture**
Frameworks like LangChain and CrewAI. MCP Servers — the USB for AI tools. Multi-agent systems. Vector databases. Where this is all going. And how to put all of this on your LinkedIn and resume.

You started as a vibe coder using the tool. You'll finish as someone who actually *understands* the tool.
