## What Scraping Is — From RSS Feeds

You'll think — "YouTube, Anthropic blog, OpenAI blog — how do I get data from them? There are no API keys." **RSS feeds** are the answer.

**RSS** is a standard format that almost every blog/channel provides — a simple XML file containing the latest items (title, link, date, description). Free, no API key. Every source has its own RSS URL:

- **YouTube channel:** `https://www.youtube.com/feeds/videos.xml?channel_id=YOUR_CHANNEL_ID`
- **Anthropic blog:** `https://www.anthropic.com/rss.xml` (or blog listing page)
- **OpenAI blog:** `https://openai.com/blog/rss.xml`

Open any RSS URL in the browser — you'll see XML. That's the data we'll parse.

## Normalization — Same Shape from Every Source

Problem: every source's RSS has a slightly different format. YouTube's item has `videoId`, Anthropic's has `link`, OpenAI's has `guid`. So we create a **normalized shape** — every scraper converts its source's data into this shape:

```javascript
// Normalized article shape
{
  source: "youtube" | "anthropic" | "openai",
  title: string,
  url: string,
  published_at: date,
  raw_content: string   // transcript snippet or blog excerpt
}
```

Now only **one shape** reaches the database, no matter which source it came from. That's normalization — every scraper converts its source's format → common shape.

## YouTube Scraper

```javascript
// scrapers/youtube.js
const Parser = require('rss-parser');
const parser = new Parser();

const CHANNEL_URL = 'https://www.youtube.com/feeds/videos.xml?channel_id=UCX6OQ3DkcsbYNE6H8uQQuVA';

async function fetchNewItems() {
  const feed = await parser.parseURL(CHANNEL_URL);

  return feed.items.slice(0, 10).map((item) => ({
    source: 'youtube',
    title: item.title,
    url: item.link,
    published_at: new Date(item.pubDate),
    raw_content: item.contentSnippet || '',
  }));
}

module.exports = { fetchNewItems };
```

**Understand:**
- We installed `rss-parser` — `parser.parseURL()` fetches + parses the feed
- `feed.items` = the items in the feed (videos)
- `.slice(0, 10)` = only the 10 latest (limit — not the whole feed)
- `.map()` = convert each item into the normalized shape
- `item.contentSnippet` = YouTube's excerpt

## Anthropic Scraper

```javascript
// scrapers/anthropic.js
const Parser = require('rss-parser');
const parser = new Parser();

const BLOG_URL = 'https://www.anthropic.com/news/rss.xml';

async function fetchNewItems() {
  const feed = await parser.parseURL(BLOG_URL);

  return feed.items.slice(0, 10).map((item) => ({
    source: 'anthropic',
    title: item.title,
    url: item.link,
    published_at: new Date(item.pubDate),
    raw_content: item.contentSnippet || item.content || '',
  }));
}

module.exports = { fetchNewItems };
```

Same pattern — only the URL and source name differ.

> **Note:** If the exact RSS URL doesn't work, you can scrape the blog listing page with `cheerio` (parse HTML). `rss-parser` gives more, but the concepts are the same. Try RSS first.

## Main Scraper — Run All of Them

```javascript
// scrapers/index.js
const youtube = require('./youtube');
const anthropic = require('./anthropic');
const openai = require('./openai');

async function scrapeAll() {
  const results = await Promise.all([
    youtube.fetchNewItems(),
    anthropic.fetchNewItems(),
    openai.fetchNewItems(),
  ]);

  const allItems = results.flat();  // [[...], [...], [...]] → [...]
  console.log(`Total ${allItems.length} items scraped`);
  return allItems;
}

module.exports = { scrapeAll };

// Only when run directly: node scrapers/index.js
if (require.main === module) {
  scrapeAll().then(console.log).catch(console.error);
}
```

**Understand:**
- `Promise.all([...])` — all three scrapers run **in parallel** (don't wait for each other)
- `results.flat()` — merges the three arrays into one
- `require.main === module` — execute only when run directly (`node scrapers/index.js`), not when imported

## Common Mistakes

- ❌ Wrong/outdated RSS URL — the feed won't parse. Confirm by opening the URL in the browser.
- ❌ Taking all items (without `.slice`) — too many come the first time, the DB fills up. Add a limit.
- ❌ Each scraper returning a different shape — breaks the whole point of normalization. All must return `{source, title, url, published_at, raw_content}`.
- ❌ Leaving `published_at` as a string — make a proper Date object with `new Date(item.pubDate)` (for the DB timestamp).
- ❌ Running scrapers sequentially — use `Promise.all` for parallel (fast).

## What It Is NOT

⚠️ **Scraping = not unethical/illegal (if you follow the rules).** RSS feeds are publicly designed for this. (Web scraping legal points are a separate topic — respect rate limits and terms of service.)

⚠️ **RSS = not just blogs.** Podcasts, YouTube, news sites — all provide RSS. Its use is very wide.

⚠️ **`rss-parser` = not "only RSS parsing", it also fetches.** `parseURL()` does both fetch + parse internally. No separate `fetch` needed.

⚠️ **Scraper = not the full transcript of "raw content".** YouTube's `contentSnippet` is a small excerpt — enough for ranking. Getting the full transcript is more work + slower.
