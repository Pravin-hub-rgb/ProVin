8.5 mein Aggregator Agent ne har article ko score kiya (1-10) aur DB mein save kiya. Ab doosra agent — **Digest Agent.** Aggregator ne rank ki, Digest summarise karta hai. Yehi hai multi-agent system ka asli feel — do agents, alag-alag kaam, milke ek result.

## Digest Agent Kya Karta Hai

Top-scored articles (5-8) lo, aur unse ek **chhota, readable markdown digest** likho — 1 paragraph overview + har article ke liye ek bullet.

```
Input:  top 5-8 articles by score
Agent:  "in sab mein story kya hai? kya worth reading hai?"
Output: markdown digest (paragraph + bullets)
```

Ye **cooperating agents** ka flow hai:

```
[Aggregator Agent] score + rank karta hai
        ↓  (top articles pass hoti hain)
[Digest Agent] unhe summarize karke digest banata hai
```

Aggregator ki output (scores) Digest ki input hai. Ek agent doosre ka kaam use karta hai.

## Top Articles Query

Pehle top-rated articles nikalte hain — `ORDER BY score DESC LIMIT 6`:

```javascript
// db/getTopArticles.js
const pool = require('../db');

async function getTopArticles(limit = 6) {
  const result = await pool.query(
    `SELECT source, title, url, score, reason
     FROM articles
     WHERE ranked = true
     ORDER BY score DESC
     LIMIT $1`,
    [limit]
  );
  return result.rows;
}

module.exports = { getTopArticles };
```

- `ORDER BY score DESC` — highest score pehle
- `LIMIT $1` — sirf top 6
- Sirf `ranked = true` wale — jo 8.5 ne rank kiye

## Digest Generate Karna

```javascript
// agents/digest.js
require('dotenv').config();
const Groq = require('groq-sdk');
const { getTopArticles } = require('../db/getTopArticles');

const client = new Groq({ apiKey: process.env.GROQ_API_KEY });

async function generateDigest() {
  const articles = await getTopArticles(6);
  if (articles.length === 0) {
    console.log('No ranked articles to digest');
    return null;
  }

  const response = await client.chat.completions.create({
    model: 'llama-3.3-70b-versatile',
    messages: [
      {
        role: 'system',
        content: `You write concise daily AI news digests.
Write markdown: one short overview paragraph, then a bullet per article.
Include the source and score.`,
      },
      {
        role: 'user',
        content: articles
          .map((a) => `- ${a.title} (${a.source}, score ${a.score}): ${a.reason}`)
          .join('\n'),
      },
    ],
  });

  return response.choices[0].message.content;
}
```

**Notice kya fark hai Aggregator se:**
- **No tools** — Digest ko structured output nahi chahiye, free text (markdown) chahiye
- **Input formatted** — articles ko ek readable list bana ke user message mein bheja
- **Output = `message.content`** — seedha text response

Isliye Digest ek "sachcha agent" hai jo content generate karta hai, jabki Aggregator tool-calling se structured scoring karta tha. **Do alag patterns, do alag kaam.**

## Digest Save Karna

Digest ko `digests` table mein save karo (8.2 ka schema yaad hai — `content` + `created_at`):

```javascript
// db/saveDigest.js
const pool = require('../db');

async function saveDigest(content) {
  await pool.query(
    `INSERT INTO digests (content) VALUES ($1)`,
    [content]
  );
  console.log('Digest saved');
}
```

Main file mein jodte hain:

```javascript
const { saveDigest } = require('../db/saveDigest');

async function main() {
  const digest = await generateDigest();
  if (digest) {
    console.log('\n=== DIGEST ===\n');
    console.log(digest);
    await saveDigest(digest);
  }
}

if (require.main === module) {
  main().then(() => process.exit(0)).catch((e) => {
    console.error(e);
    process.exit(1);
  });
}
```

## Full Pipeline — Sab Agents Ek Saath

Ab 8.3 (scrape) → 8.4 (insert) → 8.5 (aggregate) → 8.6 (digest) sab ek `index.js` mein jodte hain:

```javascript
// index.js — full pipeline
require('dotenv').config();
const { scrapeAll } = require('./scrapers');
const { insertArticles } = require('./db/insertArticles');
const { processArticles } = require('./agents/aggregator');
const { generateDigest } = require('./agents/digest');
const { saveDigest } = require('./db/saveDigest');

async function main() {
  console.log('Step 1: Scraping...');
  const items = await scrapeAll();
  await insertArticles(items);

  console.log('Step 2: Aggregating...');
  await processArticles();

  console.log('Step 3: Digesting...');
  const digest = await generateDigest();
  if (digest) {
    await saveDigest(digest);
  }

  console.log('Done!');
}

main()
  .then(() => process.exit(0))
  .catch((err) => {
    console.error('Pipeline failed:', err);
    process.exit(1);
  });
```

`node index.js` — poora system ek command mein: scrape → store → rank → summarize → save. **Yeh hai tumhara multi-agent system.**

## Common Mistakes

- ❌ Top articles ko bina `ORDER BY score DESC` le lena — digest mehngi articles se nahi banna chahiye
- ❌ Digest ko `LIMIT` ke bina bhejna — 50 articles ka context overload ho jayega. 5-8 kaafi hai
- ❌ Aggregator wale tool-calling pattern ko Digest mein copy karna — Digest ko free text chahiye (markdown), tools nahi
- ❌ Input ko readable format mein na bhejna — agent ko clean list do (`title (source, score): reason`), wo better summary dega
- ❌ Empty digest/empty articles handle na karna — agar koi article nahi toh `getTopArticles` empty array, check karo

## What It Is NOT

⚠️ **Digest = "poore news ka report" nahi.** Yeh sirf top 5-8 ranked articles ka chhota summary hai — tumhare profile ke hisaab se relevant ones.

⚠️ **Digest agent = aggregator ka duplicate nahi.** Aggregator *kaunsa relevant hai* decide karta hai (score), Digest *kya story hai* likhta hai (summary). Alag jobs.

⚠️ **Digest = "poore context ka raw dump" nahi.** Context window overload mat karo — sirf top few articles ke clean summaries bhejo. Yahi good agent design hai.

⚠️ **Yeh abhi ek "batch" system hai, live nahi.** Roz ek baar chalta hai (scheduling 8.7 mein). Real-time push notifications isse alag (aage jake).
