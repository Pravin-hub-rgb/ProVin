In 8.5 the Aggregator Agent scored every article (1-10) and saved it to the DB. Now the second agent — **Digest Agent.** The Aggregator ranks, the Digest summarizes. This is the real feel of a multi-agent system — two agents, different jobs, working together to produce one result.

## What the Digest Agent Does

Take the top-scored articles (5-8) and write a **short, readable markdown digest** from them — one paragraph overview + one bullet per article.

```
Input:  top 5-8 articles by score
Agent:  "what's the story across all of these? what's worth reading?"
Output: markdown digest (paragraph + bullets)
```

This is the **cooperating agents** flow:

```
[Aggregator Agent] scores + ranks
        ↓  (top articles pass through)
[Digest Agent] summarizes them into a digest
```

The Aggregator's output (scores) is the Digest's input. One agent uses another's work.

## Top Articles Query

First, fetch the top-rated articles — `ORDER BY score DESC LIMIT 6`:

```javascript
// db/getTopArticles.js
const pool = require('../db');

async function getTopArticles(limit = 6) {
  const result = await pool.query(
    `SELECT source, title, url, score, reason
     FROM articles
     WHERE ranked = true
     ORDER BY score DESC
     LIMIT $1`,
    [limit]
  );
  return result.rows;
}

module.exports = { getTopArticles };
```

- `ORDER BY score DESC` — highest score first
- `LIMIT $1` — only top 6
- Only `ranked = true` ones — those ranked in 8.5

## Generating the Digest

```javascript
// agents/digest.js
require('dotenv').config();
const Groq = require('groq-sdk');
const { getTopArticles } = require('../db/getTopArticles');

const client = new Groq({ apiKey: process.env.GROQ_API_KEY });

async function generateDigest() {
  const articles = await getTopArticles(6);
  if (articles.length === 0) {
    console.log('No ranked articles to digest');
    return null;
  }

  const response = await client.chat.completions.create({
    model: 'llama-3.3-70b-versatile',
    messages: [
      {
        role: 'system',
        content: `You write concise daily AI news digests.
Write markdown: one short overview paragraph, then a bullet per article.
Include the source and score.`,
      },
      {
        role: 'user',
        content: articles
          .map((a) => `- ${a.title} (${a.source}, score ${a.score}): ${a.reason}`)
          .join('\n'),
      },
    ],
  });

  return response.choices[0].message.content;
}
```

**Notice what's different from the Aggregator:**
- **No tools** — the Digest doesn't need structured output, free text (markdown) is what's wanted
- **Input formatted** — articles turned into a readable list and sent in the user message
- **Output = `message.content`** — direct text response

That's why the Digest is a "true agent" that generates content, while the Aggregator did structured scoring via tool-calling. **Two different patterns, two different jobs.**

## Saving the Digest

Save the digest to the `digests` table (remember 8.2's schema — `content` + `created_at`):

```javascript
// db/saveDigest.js
const pool = require('../db');

async function saveDigest(content) {
  await pool.query(
    `INSERT INTO digests (content) VALUES ($1)`,
    [content]
  );
  console.log('Digest saved');
}
```

Wire it into the main file:

```javascript
const { saveDigest } = require('../db/saveDigest');

async function main() {
  const digest = await generateDigest();
  if (digest) {
    console.log('\n=== DIGEST ===\n');
    console.log(digest);
    await saveDigest(digest);
  }
}

if (require.main === module) {
  main().then(() => process.exit(0)).catch((e) => {
    console.error(e);
    process.exit(1);
  });
}
```

Run it:

```bash
node agents/digest.js
```

## Full Pipeline — All Agents Together

Now wire 8.3 (scrape) → 8.4 (insert) → 8.5 (aggregate) → 8.6 (digest) into one `index.js`:

```javascript
// index.js — full pipeline
require('dotenv').config();
const { scrapeAll } = require('./scrapers');
const { insertArticles } = require('./db/insertArticles');
const { processArticles } = require('./agents/aggregator');
const { generateDigest } = require('./agents/digest');
const { saveDigest } = require('./db/saveDigest');

async function main() {
  console.log('Step 1: Scraping...');
  const items = await scrapeAll();
  await insertArticles(items);

  console.log('Step 2: Aggregating...');
  await processArticles();

  console.log('Step 3: Digesting...');
  const digest = await generateDigest();
  if (digest) {
    await saveDigest(digest);
  }

  console.log('Done!');
}

main()
  .then(() => process.exit(0))
  .catch((err) => {
    console.error('Pipeline failed:', err);
    process.exit(1);
  });
```

`node index.js` — the whole system in one command: scrape → store → rank → summarize → save. **This is your multi-agent system.**

## Common Mistakes

- ❌ Taking top articles without `ORDER BY score DESC` — the digest shouldn't be built from cheap articles
- ❌ Sending digest without `LIMIT` — context overload with 50 articles. 5-8 is enough
- ❌ Copying the Aggregator's tool-calling pattern into the Digest — the Digest needs free text (markdown), no tools
- ❌ Not sending input in readable format — give the agent a clean list (`title (source, score): reason`), it'll write a better summary
- ❌ Not handling empty digest/empty articles — if there are no articles, `getTopArticles` returns an empty array, check it

## What It Is NOT

⚠️ **Digest = not "a report of all the news".** It's only a short summary of the top 5-8 ranked articles — the ones relevant to your profile.

⚠️ **Digest agent = not a duplicate of the aggregator.** The Aggregator decides *which* is relevant (score), the Digest writes *what the story is* (summary). Different jobs.

⚠️ **Digest = not "a raw dump of all context".** Don't overload the context window — send only clean summaries of the top few articles. That's good agent design.

⚠️ **This is a "batch" system right now, not live.** It runs once a day (scheduling in 8.7). Real-time push notifications are a different thing (later).
