Enough theory. Let's build a working calculator agent from scratch. We'll define a tool, wire it up, call the model, execute the tool, and send the result back. You'll see the entire tool calling loop in action.

Create a new file called `calculator-agent.mjs` and follow along. Every line is explained.

### Step 1: Imports and Setup

```javascript
import Anthropic from "@anthropic-ai/sdk";

const anthropic = new Anthropic();
```

We import the Anthropic SDK and create a client. You'll need your `ANTHROPIC_API_KEY` set in your environment or you can pass it directly: `new Anthropic({ apiKey: "sk-..." })`.

### Step 2: Define the Tool

```javascript
const tools = [
  {
    name: "calculator",
    description: "Evaluate a mathematical expression. Returns the numeric result.",
    input_schema: {
      type: "object",
      properties: {
        expression: {
          type: "string",
          description: "The mathematical expression to evaluate, like '2 + 2' or 'Math.sqrt(16)'"
        }
      },
      required: ["expression"]
    }
  }
];
```

We define one tool called `calculator`. It takes one required parameter: `expression`, a string. The model will fill in `expression` when it calls this tool.

### Step 3: The Actual Tool Function

```javascript
function calculator(expression) {
  try {
    const result = eval(expression);
    return String(result);
  } catch (err) {
    return `Error: ${err.message}`;
  }
}
```

This is the JavaScript function that actually does the work. When the model asks for the calculator, *our code* will call this function, not the model.

- `eval(expression)` evaluates the expression string as JavaScript code
- We wrap it in try/catch because bad input would crash our program
- We return a string because we're going to send the result back to the model

**Warning:** `eval` is dangerous in production. We use it here for simplicity. A real app would use a safe expression parser like `mathjs`.

### Step 4: Call the Model with the Tool

```javascript
const messages = [
  { role: "user", content: "What is 144 * 37 + 12?" }
];

const response = await anthropic.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 1024,
  system: "You are a helpful assistant with a calculator tool. Use it when the user asks you math questions.",
  messages: messages,
  tools: tools
});
```

We send a message asking for a calculation. We include our tools array so the model knows the calculator exists.

### Step 5: Check the Model's Response

After the API call, `response.content` is an array of content blocks. The model can return multiple blocks: text, tool_use, etc.

```javascript
for (const block of response.content) {
  if (block.type === "text") {
    console.log("Assistant:", block.text);
  } else if (block.type === "tool_use") {
    console.log("Tool call:", block.name, "with input", block.input);
  }
}
```

When the model decides to use the calculator, it returns a content block where `type` is `"tool_use"`. The `block.name` tells us *which* tool, and `block.input` has the parameters.

### Step 6: Execute the Tool and Send the Result Back

```javascript
for (const block of response.content) {
  if (block.type === "tool_use") {
    // Step 6a: Execute the tool function
    const result = calculator(block.input.expression);

    // Step 6b: Add the assistant's tool_use to conversation history
    messages.push({
      role: "assistant",
      content: response.content
    });

    // Step 6c: Add the tool result
    messages.push({
      role: "user",
      content: [
        {
          type: "tool_result",
          tool_use_id: block.id,
          content: result
        }
      ]
    });

    // Step 6d: Call the model again with the result
    const finalResponse = await anthropic.messages.create({
      model: "claude-sonnet-4-20250514",
      max_tokens: 1024,
      system: "You are a helpful assistant with a calculator.",
      messages: messages,
      tools: tools
    });

    console.log("Final answer:", finalResponse.content[0].text);
  }
}
```

This is the critical part. Let's trace through it:

1. The model said "I want to call calculator with expression = '144 * 37 + 12'"
2. **Our code** runs `calculator("144 * 37 + 12")` which returns `"5340"`
3. We push the model's original response (with the tool_use block) into the message history — this tells the API that the model *did* call a tool
4. We push a `tool_result` message containing the result `"5340"` — this is how the model "sees" the tool output
5. We call the API again, and now the model reads the result and gives us the final answer

### The Full Script

Here's everything together in one file:

```javascript
import Anthropic from "@anthropic-ai/sdk";

const anthropic = new Anthropic();

const tools = [
  {
    name: "calculator",
    description: "Evaluate a mathematical expression. Returns the numeric result.",
    input_schema: {
      type: "object",
      properties: {
        expression: {
          type: "string",
          description: "The mathematical expression to evaluate"
        }
      },
      required: ["expression"]
    }
  }
];

function calculator(expression) {
  try {
    const result = eval(expression);
    return String(result);
  } catch (err) {
    return `Error: ${err.message}`;
  }
}

const messages = [
  { role: "user", content: "What is 144 * 37 + 12?" }
];

const response = await anthropic.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 1024,
  system: "You are a helpful assistant with a calculator tool.",
  messages: messages,
  tools: tools
});

for (const block of response.content) {
  if (block.type === "tool_use") {
    const result = calculator(block.input.expression);

    messages.push({ role: "assistant", content: response.content });
    messages.push({
      role: "user",
      content: [
        {
          type: "tool_result",
          tool_use_id: block.id,
          content: result
        }
      ]
    });

    const finalResponse = await anthropic.messages.create({
      model: "claude-sonnet-4-20250514",
      max_tokens: 1024,
      system: "You are a helpful assistant with a calculator tool.",
      messages: messages,
      tools: tools
    });

    console.log("Assistant:", finalResponse.content[0].text);
  }
}
```

### What Actually Happens

When you run this, here is what the model outputs on the first call (you'd see this if you logged the response):

```
Content block 1: {
  type: "tool_use",
  id: "toolu_abc123",
  name: "calculator",
  input: { expression: "144 * 37 + 12" }
}
```

No text. Just a tool_use block. The model skipped the chit-chat and went straight to "I need the calculator."

After your code runs the calculator and sends back `"5340"`, the model responds with:

```
Content block 1: {
  type: "text",
  text: "144 * 37 + 12 equals 5,340."
}
```

That's the full loop. The model asked, you executed, the model answered.

### Key Takeaway

The model never does math. It told you the expression. You evaluated it. It read the result and formatted the answer. The model is the brain; your code is the body.

One tool is good. But agents usually have multiple options, and the model needs to choose. That's next.
