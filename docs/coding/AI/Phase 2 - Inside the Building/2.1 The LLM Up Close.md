The map is complete — but the LLM circle itself was only ever a label. Phase 1 ended with chatbots and agents as wrappers, arrows pointing at a model we never opened. So let's open it. Just the LLM, nothing else: what it actually is, what it actually does, and the one sentence you can say to anyone and be correct.

Everything starts from one skill. Strip away every use case — code writing, essays, translations, exam answers — and an LLM does exactly one thing: look at some text, predict what comes next. Answer a question? It's continuing the text "Question: ... Answer:". Write a program? Continuing the text of a program. Summarize? The same article, continued shorter at the top. Every impressive behavior is that same move in a different disguise.

And now the name you kept reaching for. You said it yourself: *"I just really want a name for it, a vocabulary for it."* Here it is, locked:

> **An LLM is a model trained on a very large amount of text data, and it uses what it learned to predict the next text.**

Three parts, and you already own all three. **Model** — the trained result, the big file of parameters from 1.2. **Trained on a very large amount of text data** — that's the "language" and the "large" from 1.4. **Predict the next text** — the one skill above. Say that sentence to anyone and you're correct. No "something", no mystery box.

One more thing you circled without quite landing: different LLMs *feel* different. Claude, ChatGPT, Gemini — one sharper at code, one at writing, one at reasoning. Is that different kinds of model? No. Different LLMs differ in a few ordinary ways: what text they trained on, how big they are, and how they were tuned afterward — that third one opens in a later phase; for now, just know it exists. Same category, same skill, different flavors. Not new circles on the diagram.

Here's the friendly twist that organizes everything after this file. On its own, an LLM is powerful and limited at the same time. It does its one skill brilliantly — and it has three hard limits no training removes. That's the whole reason the words you've been hearing exist: **RAG, tools, agents — they're not random additions, they're fixes for those limits**, one fix per limit.

Before moving on, the nots, so nothing sticks wrong. The LLM is not a database or a search engine — it predicts from learned patterns, it doesn't look anything up. It's not "doing things on its own" — it does one thing very well, and everything else is that in disguise. Claude vs ChatGPT vs Gemini are not different species — flavors of one category. And it is not unlimited — three limits, next file.
