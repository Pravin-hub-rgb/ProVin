The last file named the smallest unit the LLM reads: tokens. But how does a model get good at predicting them in the first place? We've said "it learns patterns from data" and "training nudges the numbers" — now open that black box. Phase 4 starts with the giant first pass: pre-training.

**Pre-training** is the stage where the model learns language by playing a guessing game, billions of times. It's shown a piece of real text with a word hidden, and it has to guess the hidden word. At first its guesses are terrible. Each time it's wrong, its internal numbers — the parameters, the learned values inside the model — get nudged a tiny bit so the right answer becomes more likely next time. Repeat that across a huge amount of text, and it gets very good at predicting what comes next.

A concrete picture. Take the sentence "The cat sat on the mat." We show the model only "The cat sat on the" and hide the last word. At the start, its numbers are random, so it might guess "banana." The real answer was "mat," so it was wrong. Training then nudges its parameters a tiny bit, so next time "mat" becomes slightly more likely and "banana" slightly less. Now repeat that with billions of sentences from books, websites, and code. After all those nudges, the guesses become very good. Think of a student with a stack of flashcards, each with a sentence and the last word covered, guessing and adjusting after every wrong answer.

The nudging has a name: **backpropagation**. The model guesses the next token, the guess is compared to the real one, and the error is sent backward through the network, adjusting each link's number a little bit. Backpropagation is a technique for neural networks: the network is made of nodes connected by links, each link carrying a number called a weight, and when the model guesses wrong, each weight gets adjusted a little. So it's not that the data gets refined as it passes each link — it's the links themselves that get tuned, so the next guess comes out better.

Two things to keep straight. First, there are two ways to hide the word, and models use one or the other. **Autoregressive** (next-word prediction): the model only sees what came before, like "The cat sat on the," and guesses the next word. Then that new word is added, and it guesses the one after that, one token at a time, left to right. This is how chat-style LLMs like Claude and ChatGPT are trained, and it's also exactly how they write replies to you — one token at a time, each based on everything before it. **Masked** (fill in the blank): a word is hidden in the middle, like "The cat blank on the mat," and the model sees words on both sides and fills in the blank ("sat"). Masked models can look both directions, so they understand context better, but they're not built for writing long text one token at a time — they're used more for understanding tasks like search and classifying text. Both methods learn through the same guess, compare, and nudge step.

Second, the clean split between training and using. Backpropagation happens only during training, to adjust the numbers. During inference — the forward run when real input arrives — the numbers are frozen, and the data just flows forward through the layers to make a prediction. Training uses guess, compare, and backpropagation to set the numbers; inference only uses those finished numbers to predict. It's mostly the numbers, the weights, that get tuned, while the formulas stay the same — the structure of the math is fixed by the design, and only the numbers inside it are learned.

One consequence worth holding: because an autoregressive model writes one token at a time, each token depending on everything before it, an unlucky pick can snowball — a weird word appears, and the following tokens build on it into gibberish. The model isn't unaware of the rules; it just made an unlikely pick. When you point it out, your message goes on the table, and the model can see the odd text sitting there, which nudges its next predictions back toward normal text. The "my bad, I accidentally wrote it" reply is just the model predicting a natural-sounding apology, not a real memory of making a mistake.

The nots. Pre-training is *not* the whole of training — it's phase one; tuning comes after. Backpropagation is *not* part of inference — it only runs during training. Autoregressive is *not* the only method — masked exists, for models built to understand rather than write. And guessing wrong during training is *not* a failure — it's the mechanism; every wrong guess is what drives the nudging.
