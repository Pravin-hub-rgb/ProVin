The main diagram stopped at generative AI — the branch that creates new content instead of labeling it. Time for the zoomed-in view: what actually lives *inside* that circle. Because "generative AI" isn't one model. It's a family — siblings that each generate a different *kind* of content — and one of those siblings is the model everything you've used is built on.

```
Generative AI
├── LLM            (text)
├── Image models   (images)
├── Audio models   (sound)
├── Music models   (songs)
└── Video models   (video)

[ multimodal ] = a property, not a circle
```

Five siblings, each a deep learning model trained on one kind of data to generate that kind of content. Two placement calls before we zoom further. **Coding models don't get their own circle** — code is text, so a coding model is normally just an LLM trained heavily on code; it belongs inside the LLM circle, not beside it. And **multimodal is not a container** — a model that handles several kinds at once (text *plus* images) has a *property*, not a bigger circle holding the others; draw it as an overlap or a label underneath: "spans more than one." One note on the siblings: *audio* is the broad family — speech recognition, text-to-speech, sound effects; *music* is the narrower branch, composing songs. Two siblings or music nested in audio — either works, as long as you know music is the more specific one.

Now the sibling chatbots and agents are built around: the **LLM**. Three words, one at a time. **Language** — it works with human language: words, sentences, and also code, since code is a kind of language too. **Model** — the trained result from 1.2: the big file of parameters holding learned patterns. **Large** — two things are huge: the amount of text it trained on, and the number of parameters, often billions.

> **An LLM — a large language model — is a very large deep learning model trained on text, that generates language by predicting what comes next.**

What it actually does is a trick you already know from your phone: you type "I'm going to the" and the keyboard suggests "store". Predict the next word. An LLM does exactly that, at scale: you give it a question, it predicts the first word of the answer, then the next, then the next, over and over until a full reply is assembled. That's all the fluent writing you see — and your own instinct from the start was right: *it predicts*. Summarizing, translating, writing code — the same next-word prediction applied to different prompts.

Why is language *the* special one among the siblings? Because language is so flexible. Code, emails, essays, questions — all text. So one LLM can write code, answer questions, and summarize documents, all with the same single skill. That's why the LLM is the sibling that got famous, and the one chatbots and agents are wrapped around.

Which brings the drawing rule that catches the most mistakes: **chatbots and agents are not circles inside the LLM.** The LLM is the *model*; chatbots and agents are *applications wrapped around it* — products with screens, chat boxes, tool connections. On the diagram, they go **outside as boxes touching the LLM circle**, arrows pointing at the model they're built on.

Besides chatbot and agent, the arrow list gets a few more: **assistants** (voice and coding — chatbots tuned for a job), **search and question-answering tools** (questions over documents or the web), **writing and summarizing tools** (email drafters, meeting summarizers), **translation tools**, and **automation workflows** (the LLM is one step in a bigger process, like sorting incoming support tickets). Chatbot and agent are the two big ones; the rest are mostly flavors of those. Full detail on both — and the agent's *tools* — is the next file. Here we're just placing them: boxes outside, arrows in.

Complete diagram, main map plus zoom:

```
AI
└── Machine Learning
    └── Deep Learning
        ├── Discriminative AI  (labels / decides)
        └── Generative AI      (creates new content)
            ├── LLM  ←── [chatbot] [agent] [assistant] ...
            ├── Image models
            ├── Audio models
            ├── Music models
            └── Video models

multimodal = property (spans more than one of the above)
```

That's the vocabulary map. Every major AI word now has a slot: technique circles on the inside, model siblings in generative AI, applications out on the arrows.

Quick precision test — a friend says "ChatGPT is a generative AI model". Fix it: close, but ChatGPT is an *application* — a chatbot wrapped around a model. The model inside is an LLM, sitting inside generative AI (a branch of deep learning, inside machine learning, inside AI). "ChatGPT is an application built on an LLM, which is a generative AI model."

The nots: the LLM is not the whole of generative AI — one sibling, the text one, with image, audio, music, video beside it. Multimodal is not a model type or a container — a property, drawn as overlap or note. Generative AI does not "understand" or "imagine" — it generates by predicting patterns learned in training; impressive output, same next-piece mechanism. And a coding model is not a separate species — code is text, an LLM trained heavily on code.
