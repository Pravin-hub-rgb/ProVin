---

## The Old Way — Rules a Human Writes

The traditional way to build software is simple: a programmer writes exact rules, and the program follows them. To catch spam email, you might write:

```js
function isSpam(email) {
  // Rule 1: any email with these phrases is spam
  if (email.body.includes("free money")) return true;
  if (email.body.includes("you won a prize")) return true;

  // Rule 2: emails from unknown senders with links are suspicious
  if (!email.knownSender && email.body.includes("http")) return true;

  // Otherwise, assume it's fine
  return false;
}
```

Read it top to bottom: if a phrase appears, mark it as spam. The programmer decides what counts as suspicious, writes it down, and the program obeys.

It works — until spammers notice. They change "free money" to "free m0ney", then to "you've been selected". You'd be writing rules forever, chasing every new spelling. The knowledge lives in the programmer's head, and the programmer has to keep updating it by hand.

---

## The New Way — Patterns From Examples

Machine learning flips this. Instead of writing the rules, you hand the computer thousands of example emails, each one already labeled **spam** or **not spam**. The computer studies them and works out the patterns on its own — which phrases, which structures, which combinations show up in spam.

Then a brand-new email arrives, one nobody has ever seen. The computer uses the patterns it found to make a call.

**Machine learning is software that learns patterns from examples instead of following rules a human wrote.**

The programmer no longer writes the knowledge in. The machine *pulls it out of the examples*. That one sentence is the foundation under everything else in this course — chatbots, LLMs, agents, all of it.

## What "AI" Actually Stands For

Now the name itself. **AI** stands for **artificial intelligence** — break it in two:

- **Intelligence** is the ability to learn, understand, and make decisions. Humans and animals do this naturally.
- **Artificial** just means it's made by people — built into a machine instead of born.

So AI is a machine that can do things we'd normally need human thinking for: understanding a sentence, recognizing a face in a photo, deciding if an email is spam.

One sharpening, because it's a common mix-up: AI does **not** copy how the brain works on the inside. It only produces *similar results* — recognizing a cat in a photo, the same way a human would. What happens under the hood is numbers and math, not biology.

---

## Learning From Seen and Unseen Data

Machine learning needs two kinds of data, and the difference matters:

- **Training data** — the examples the model learns from. The thousands of labeled emails above. This is data it has *seen*.
- **Test data** — a separate pile of examples the model never touched during learning, saved to check whether it actually learned something.

(If you've ever built a trading algorithm, this is the same idea as in-sample and out-of-sample data — build on one part, verify on a part the algorithm never ran on.)

Why bother separating them? Because of a trap with a name: **overfitting**. That's when a model does great on the training data — it "answers" every example it studied perfectly — but fails on new data. It didn't learn patterns; it *memorized the answers*. Like a student who recites the textbook but can't handle a question from a different book.

Test data catches this. Score high on data you've seen, low on data you haven't → you memorized. Score high on both → you actually learned.

**Quick check:** in your own words, what's the difference between training data and test data?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Training data is what the model studies — the seen, in-sample examples it adjusts itself on until its predictions get good. Test data is held back completely, unseen, and is only used afterward to check whether the model learned real patterns or just memorized answers. High test scores mean it generalizes; a big gap between training and test scores is overfitting.

</details>

## What AI Is NOT

Clearing a few things before moving on:

- **AI is not a brain.** No neurons, no consciousness. Inside it's layers of numbers and math — it produces human-like *results*, not human-like *thinking*.
- **AI does not look things up.** When a model answers you, it isn't searching a database or reading files. It's using patterns learned during training. (That has consequences we'll hit later — hallucinations and all.)
- **AI is not all machine learning.** The oldest AI systems were hand-written rules, no learning involved. But almost everything you hear about today — chatbots, image recognition, recommendation feeds — is machine learning.
- **AI is not one single thing.** It's the biggest circle in a nested map, and the rest of this phase fills in the circles inside it.
