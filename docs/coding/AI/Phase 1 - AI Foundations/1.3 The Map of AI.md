The last file gave us the pipeline — data to application. But that's the *process* side. The naming side is still a mess: the news says "AI", your tools say "machine learning", someone else says "deep learning" or "generative AI". Are these different things? Competitors? Versions of each other?

They're none of those. They're **nested** — each one a smaller circle sitting inside the previous one. Once you see the nesting, every new AI word either has a slot in the diagram or is an application wrapped around the outside of it.

We'll go one circle at a time, outermost first, and stop after each for a check.

---

## Circle 1 — AI (the biggest)

**AI, artificial intelligence, is the biggest circle: any software that does things we normally think need human intelligence** — understanding language, recognizing images, making decisions.

Everything else in this course is a smaller circle *inside* this one. When someone says "AI" as a blanket term, they mean the whole territory.

Nothing new here — we defined this in file 1.1. It's circle one because every term that follows is a *specific way* of doing AI.

---

## Circle 2 — Machine Learning (inside AI)

**Machine learning sits inside AI. It's the part of AI where the software learns patterns from data instead of following rules a programmer wrote.**

The name itself carries the logic: *machine learning* — the **machine learns**. The training step from the pipeline is the learning part: the machine adjusts its own internal numbers until predictions get good. A programmer never types the knowledge in; the machine pulls it out of the examples.

Two placement notes:

- **The pipeline from file 1.2 — data, training, model, testing, inference, application — is the machine learning process.** You've already placed it: it lives in this circle.
- **Not all AI is machine learning.** The oldest AI systems were hand-written rules (the spam filter from 1.1 before we flipped it) — that's AI with no learning at all. But almost all the AI you hear about today is machine learning.

**Quick check:** why is "the machine learns" an accurate name for this circle?

**Sample Answer:** Because the knowledge isn't written in by a programmer — the training step is literally the machine adjusting its own parameters, learning patterns from the data by itself. Human writes the examples and the process; the machine discovers the rules. It learns, hence machine learning.

## Circle 3 — Deep Learning (inside machine learning)

**Deep learning is machine learning done through a many-layered neural network.** Same idea — learn from data — with one difference in the *how*.

A **neural network** is many layers of tiny units stacked one after another. Data goes in at the first layer; each layer passes a transformed version to the next; the last layer gives the output. During training, the connections between layers get adjusted until the outputs become accurate.

The word **deep** just means *many layers*. More layers → the network can pick up more complicated patterns — a face in a photo, the structure of a sentence. (A "shallow" network with one layer can only catch simple patterns.)

One correction people need here: neural networks were *inspired* by how brain neurons connect, but it's a loose inspiration, not a copy. Inside, they're layers of numbers and math — no real synapses, no biology. Same rule as AI itself: similar results, not a copied brain.

**Quick check:** what does "deep" mean in deep learning, and what does it *not* mean?

<details>
<summary>Show Answer</summary>

**Sample Answer:** "Deep" means many layers stacked in the network — data passes through layer after layer, each transforming it a bit more. More layers let it learn more complicated patterns. It does *not* mean smart, mysterious, or brain-like — under the hood it's just numbers and math, inspired by neurons loosely but not copying them.

</details>

---

## Circle 4a — Discriminative AI (inside deep learning)

Here the map branches. Deep learning models come in two flavors based on what they're *built to do*.

**Discriminative AI** (also called **predictive AI**) takes an input and decides something about it:

- a photo in → "cat" or "dog"
- an email in → "spam" or "not spam"
- a transaction in → "fraudulent" or "legit"

The name fits: it **discriminates** — it tells things apart. It labels, classifies, decides. It answers "what *is* this?"

Most of classic machine learning lives here: classifiers, fraud detectors, spam filters.

---

## Circle 4b — Generative AI (inside deep learning)

**Generative AI is deep learning built to create something new instead of labeling something existing.**

A discriminative model looks at a photo and says "cat". A generative model writes a paragraph that never existed, paints an image nobody took, produces a voice no one recorded. It answers "make me *new* something."

How can it create? Because during training it learned the patterns of its data so well that it can produce new examples that *follow* those patterns — new text that reads like real text, new images that look like real images.

One honest note so the map stays clean: **discriminative vs generative is a useful split, not a hard wall.** Some models blend both — but as a starting picture, two branches under deep learning works well.

(You met this word back in file 1.2's neighborhood: *generative AI* is the family chatbots and LLMs belong to. Now it has its slot — right here, circle 4b.)

**Quick check:** discriminative vs generative — one sentence each.

<details>

**Sample Answer:** Discriminative (predictive) AI takes an input and decides something about it — labels it, tells it apart from other things: cat vs dog, spam vs not spam. Generative AI creates new content that didn't exist before — new text, images, audio — by producing examples that follow patterns it learned. One classifies, the other creates.

</details>

---

## What the Nesting Is NOT

- **These are not competing products or versions.** "Deep learning" isn't the upgrade of "machine learning" like v2 of a library — it's one *style* of doing it, sitting inside it.
- **The circles are not industries or companies.** They're categories of technique. OpenAI, Google, Meta all work *across* circles.
- **Generative AI is not the whole of AI.** It's circle 4b — the newest, loudest branch, but a spam classifier (discriminative) is just as much AI.
- **Applications are not circles.** Chatbots and agents do not sit *inside* any of these circles — they're products wrapped around models. That's the diagram's outer edge, handled in file 1.5.
