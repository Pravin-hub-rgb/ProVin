The pipeline gave you the process — but the naming side is still a mess. The news says "AI", your tools say "machine learning", someone else says "deep learning" or "generative AI". Different things? Competitors? Versions of each other?

None of those. They're **nested** — each one a smaller circle sitting inside the previous one. Once you see the nesting, every new AI word either has a slot in the diagram or is an application wrapped around the outside of it. One circle at a time, outermost first.

**Circle one — AI, the biggest.** Any software that does things we normally think need human intelligence: understanding language, recognizing images, making decisions. Everything else in this course is a smaller circle *inside* this one. Nothing new — we defined it in 1.1. It's circle one because every term that follows is a specific *way* of doing AI.

**Circle two — machine learning, inside AI.** The part where software learns patterns from data instead of following rules a programmer wrote. The name carries the logic: *machine learning* — the machine learns. The training step from the pipeline is the learning part: the machine adjusts its own numbers until predictions get good; a programmer never types the knowledge in.

Two placement notes. The pipeline from 1.2 — data, training, model, testing, inference, application — *is* the machine learning process; you've already placed it, it lives in this circle. And not all AI is machine learning — the oldest systems were hand-written rules, AI with no learning at all — but almost all the AI you hear about today is.

Why does "the machine learns" fit? Because the knowledge isn't written in — training is literally the machine adjusting its own parameters, discovering patterns from data by itself. Human writes the examples; machine discovers the rules.

**Circle three — deep learning, inside machine learning.** Same idea — learn from data — with one difference in the *how*. Deep learning uses a **neural network**: many layers of tiny units stacked one after another. Data goes in at the first layer, each layer passes a transformed version to the next, the last layer gives the output. During training, the connections between layers get adjusted until the outputs become accurate. The word *deep* just means *many layers* — more layers, more complicated patterns: a face in a photo, the structure of a sentence.

One correction people need here: neural networks were *inspired* by how brain neurons connect, but it's a loose inspiration, not a copy. Inside, they're layers of numbers and math — no real synapses, no biology. Same rule as AI itself: similar results, not a copied brain.

Now the map branches. Deep learning comes in two flavors, built for different purposes.

**Circle four-a — discriminative AI** (also called **predictive AI**): takes an input and *decides* something about it. Photo in → "cat" or "dog". Email in → "spam" or "not spam". Transaction in → "fraudulent" or "legit". The name fits: it *discriminates* — tells things apart. Labels, classifies, decides. Answers "what *is* this?" Most of classic machine learning lives here — you already built this circle's spirit in 1.1 with the spam classifier.

**Circle four-b — generative AI**: deep learning built to *create* something new instead of labeling something existing. A discriminative model looks at a photo and says "cat"; a generative model writes a paragraph that never existed, paints an image nobody took, produces a voice no one recorded. How can it create? Because training taught it the patterns of its data so well that it can produce new examples that *follow* those patterns.

You caught the sibling relationship yourself — if generative creates, something must label, and it does: discriminative vs generative, two branches under deep learning. One honest note so the map stays clean: it's a useful split, not a hard wall — some models blend both. But as a starting picture, two branches works.

```
AI
└── Machine Learning
    └── Deep Learning
        ├── Discriminative AI  (labels / decides)
        └── Generative AI      (creates new content)
```

Four circles, each inside the last — and per your own call when drawing it: stop the *main* diagram here at generative AI. What sits inside it deserves its own zoomed-in diagram, which is the next file.

The nots: these are not competing products or versions — deep learning isn't an upgrade of machine learning like v2 of a library; it's one *style* of doing it, inside it. Not industries or companies — categories of technique; everyone works across circles. Generative AI is not the whole of AI — circle four-b, the loudest branch, but a spam classifier is just as much AI. And applications are not circles — chatbots and agents don't sit *inside* any of these; they're products wrapped around models, the diagram's outer edge, handled in 1.5.

2. What makes deep learning "deep", and how is it different from plain machine learning?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Deep means the network has many layers — data goes in at layer one, each layer transforms it and passes it on, and the last layer outputs the result; during training the connections between layers get adjusted. Plain machine learning can use simpler structures (like one layer or hand-designed features). Deep learning's difference is *how* it learns: through a many-layered neural network, which lets it pick up complicated patterns like faces and sentences on its own.

</details>
