# 4.5.1 Project Start — E-Commerce Store

## Goal

Is poore 4.5 series mein ek E-Commerce Store banayenge — product listing grid, product detail page with dynamic route, shopping cart with add/remove/quantity, checkout form with RHF + Zod validation, order confirmation. Tailwind responsive. Accessible (keyboard navigation, focus management, ARIA, screen-reader).

<ecommerce-demo></ecommerce-demo>

---

Shuru karte hain project setup se.

```
bun create vite@latest ecommerce-store --template react-ts
cd ecommerce-store
bun run dev
```

Browser mein Vite ka default page dikhega. `src/App.tsx` kholo, saara boilerplate hatao, bas ek heading rakho:

```tsx
function App() {
  return <h1 className="text-3xl font-bold p-8">E-Commerce Store</h1>
}

export default App
```

Tailwind set karte hain:

```
bun add tailwindcss @tailwindcss/vite
```

`vite.config.ts`:

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

`src/index.css`:

```css
@import "tailwindcss";
```

Browser dekh — heading Tailwind se styled dikhni chahiye.

Project ready. Agle step mein product listing banayenge.
