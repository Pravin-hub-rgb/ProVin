## Step 2 — `useForm` Returns `register` and `handleSubmit`

Import `useForm` from `react-hook-form` and call it inside the component:

```tsx

import { useForm } from 'react-hook-form'

export default function ContactForm() {
  const result = useForm()
  console.log(result)

  return (...)
}
```

Check the browser console — you'll see a big object with lots of stuff. Right now we only care about two things: `register` and `handleSubmit`. We'll get to the rest later.

Remove the console.log and destructure what we need:

```tsx
const { register, handleSubmit } = useForm()
```

---
## Step 3 — What Is `register`?

`register` is a **function**.

Let's call it and log the result:

```tsx
const { register, handleSubmit } = useForm()
console.log(register('name'))
```

Browser console will show something like this:

```js
{
  name: 'name',
  onChange: [Function],
  onBlur: [Function],
  ref: [Function]
}
```

An object with:

**`name: 'name'`** — the string you passed in

**`onChange`** — a function that tracks the value — the same thing you used to write manually: `onChange={(e) => setName(e.target.value)}`

**`onBlur`** — fires when the input loses focus. React Hook Form uses this for validation.

**`ref`** — React Hook Form keeps a direct reference to the input element. This is how it reads the value directly from the DOM — no `useState` needed.

---
## The String You Pass to `register`

`register('name')` — the `'name'` string is the **name of the field**. You decide what it is.

This is the key that will appear in the `data` object when the form is submitted:

```
register('name')   →   data.name will be available on submit
register('email')  →   data.email will be available on submit
```

Remove the console.log. Now apply `register` to the inputs.

---
## Step 4 — How to Spread `register` Onto an Input

`register('name')` returns an object — `name`, `onChange`, `onBlur`, `ref`.

You could spread all those properties onto the input manually:

```tsx
const fieldProps = register('name')

<input
  name={fieldProps.name}
  onChange={fieldProps.onChange}
  onBlur={fieldProps.onBlur}
  ref={fieldProps.ref}
/>
```

But that's even more verbose. The spread operator `...` is the shortcut — "take all properties from this object and apply them here":

```tsx
<input {...register('name')} />
```

Internally, that's exactly what happens — but in one line.

## Step 5 — Register the Inputs

import { useForm } from 'react-hook-form'

export default function ContactForm() {

## Step 6 — Getting Data on Submit

"Inputs are registered. How do I get the data when the form is submitted?"

Use `handleSubmit` — it takes your function, and when the form submits, it calls your function with all the data:

```tsx
<form
  onSubmit={handleSubmit((data) => {
    console.log(data)
  })}
  className="flex flex-col gap-4"
>
```

`handleSubmit` wraps your submit handler. It prevents the default browser reload (no need for `e.preventDefault()`), runs validation, and if everything's valid, calls your function with `data`.

## TypeScript — Define a Type

Right now TypeScript doesn't know what fields are in the form — you could write `register('anything')` and get no error.

Create a type:

```tsx
type FormFields = {
  name: string
  email: string
}
```

Pass it to `useForm` — in angle brackets:

```tsx
const { register, handleSubmit } = useForm<FormFields>()
```

Now try `register('phone')` — TypeScript errors because `phone` isn't in `FormFields`. Type-safe.

## Complete `ContactForm.tsx` Now

```tsx

import { useForm } from 'react-hook-form'

type FormFields = {
  name: string
  email: string
}

export default function ContactForm() {
  const { register, handleSubmit } = useForm<FormFields>()

  return (
    <form
      onSubmit={handleSubmit((data) => {
        console.log(data)
      })}
      className="flex flex-col gap-4"
    >
      <div>
        <label className="block text-sm font-medium mb-1">Name</label>
        <input
          type="text"
          placeholder="Enter your name"
          className="border border-gray-300 rounded px-3 py-2 w-full"
          {...register('name')}
        />
      </div>
      <div>
        <label className="block text-sm font-medium mb-1">Email</label>
        <input
          type="email"
          placeholder="Enter your email"
          className="border border-gray-300 rounded px-3 py-2 w-full"
          {...register('email')}
        />
      </div>
      <button
        type="submit"
        className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
      >
        Submit
      </button>
    </form>
  )
}
```

## See the Difference — Side by Side

**Manual (in 4.3):**
```tsx
const [formData, setFormData] = useState({ name: '', email: '' })
function handleChange(e) {
  setFormData({ ...formData, [e.target.name]: e.target.value })
}
<form onSubmit={(e) => { e.preventDefault(); console.log(formData) }}>
  <input name="name" value={formData.name} onChange={handleChange} />
  <input name="email" value={formData.email} onChange={handleChange} />
</form>
```

**Now — React Hook Form:**
```tsx
const { register, handleSubmit } = useForm<FormFields>()
<form onSubmit={handleSubmit((data) => console.log(data)}>
  <input {...register('name')} />
  <input {...register('email')} />
</form>
```

No `useState`. No `handleChange`. No `e.preventDefault()`. Just spread and go.
