
Products array do jagah hai — App.tsx aur ProductDetail.tsx. Ab dono jagah same data use karte hain, toh shared file mein nikaal lo.

`src/types.ts` — Product type banate hain. Abhi sirf itna chahiye:

```ts
export interface Product {
  id: number
  name: string
  price: number
  image: string
  category: string
}
```

`src/data.ts` — products array yahan daalo:

```ts
import type { Product } from './types'

export const products: Product[] = [
  { id: 1, name: "Wireless Headphones", price: 2499, image: "https://picsum.photos/id/1/400/400", category: "electronics" },
  { id: 2, name: "Cotton T-Shirt", price: 799, image: "https://picsum.photos/id/20/400/400", category: "clothing" },
  { id: 3, name: "Running Shoes", price: 3999, image: "https://picsum.photos/id/30/400/400", category: "footwear" },
]
```

Ab `App.tsx` se local array hatao, import karo:

```tsx
import { products } from './data'
```

`ProductDetail.tsx` se bhi hatao, import karo:

```tsx
import { products } from '../data'
```

`ProductCard.tsx` — ab type Product hai, use karlo:

```tsx
import type { Product } from '../types'

interface ProductCardProps {
  product: Product
}

export default function ProductCard({ product }: ProductCardProps) {
  // ...
}
```

Ab ProductCard spread ki jagah `product` object le raha hai — cleaner hai. App.tsx mein bhi update karo:

```tsx
<ProductCard key={product.id} product={product} />
```

Agle step mein cart functionality add karenge.
