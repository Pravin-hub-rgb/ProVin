## Chaining — How to Add Rules

In Zod, you add rules by **chaining** — connect with a dot:

```ts
z.string().min(1); // string + at least 1 character
z.string().min(2).max(50); // string + min 2 + max 50
```

"Chain" the next rule onto the previous. Like building a sentence — each rule adds a condition.

---
## Add a Rule to the Name Field

The name shouldn't be empty:

```tsx
name: z.string().min(1, "Name is required");
```

`.min(1, 'message')` — at least 1 character. Zero characters = empty = fail.

Add the rule to the schema:

```tsx
const formSchema = z.object({
  name: z.string().min(1, "Name is required"),
  email: z.string(),
});
```

Submit with an empty name — now an error appears, because `.min(1)` is a rule. It auto-populates `formState.errors` — same pattern as 4.4.3. Email is still just `z.string()` — no rule yet, so no error.

## Display the Error in the UI

We already have `formState: { errors }` from 4.4.4. Now that `.min(1)` is added, errors populate automatically. Show them:

```tsx
<div>
  <label className="block text-sm font-medium mb-1">Name</label>
  <input
    type="text"
    placeholder="Enter your name"
    className="border border-gray-300 rounded px-3 py-2 w-full"
    {...register("name")}
  />
  {errors.name && (
    <p className="text-red-500 text-sm mt-1">{errors.name.message}</p>
  )}
</div>
```

**`{errors.name && (...)}`** — if `errors.name` exists (i.e., there's an error), render the `<p>`.

**`{errors.name.message}`** — the message you defined in the schema — "Name is required".

Submit with empty name — "Name is required" shows on screen ✅

Fill in the name — submit again — error clears automatically ✅

## Email Rule — Zod v4's New Syntax

In older Zod (v3), you'd write `z.string().email()`. That's been deprecated in Zod v4.

Now use the **top-level** `z.email()`:

```tsx
email: z.email("Email is not in the right format");
```

`z.email('message')` — Zod checks the email format itself. No regex needed.

Update the schema:
```tsx
const formSchema = z.object({
  name: z.string().min(1, "Name is required"),
  email: z.email("Email is not in the right format"),
});
```

Add error display under the email input:

```tsx
{
  errors.email && (
    <p className="text-red-500 text-sm mt-1">{errors.email.message}</p>
  );
}
```

Type "abc" — submit — "Email is not in the right format" ✅

Type "abc@gmail.com" — submit — no error ✅
