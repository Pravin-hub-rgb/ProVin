# 4.5.9 Order Confirmation — E-Commerce Store

Pehle CartContext mein `PLACE_ORDER` action add karte hain — order place hone ke baad cart empty ho jaye.

`src/context/CartContext.tsx` — reducer mein case add karo:

```tsx
case 'PLACE_ORDER':
  return []
```

Types mein bhi add karo:

```tsx
type CartAction =
  | { type: 'ADD'; product: { id: number; name: string; price: number; image: string } }
  | { type: 'REMOVE'; productId: number }
  | { type: 'UPDATE_QTY'; productId: number; quantity: number }
  | { type: 'PLACE_ORDER' }
```

`src/pages/OrderConfirmed.tsx`:

```tsx
import { Link } from 'react-router-dom'

export default function OrderConfirmed() {
  return (
    <div className="max-w-md mx-auto p-8 text-center mt-20">
      <div className="text-6xl mb-4">&#10003;</div>
      <h1 className="text-3xl font-bold mb-4">Order Confirmed!</h1>
      <p className="text-gray-600 mb-8">Your order has been placed successfully.</p>
      <Link
        to="/"

        Continue Shopping

    </div>
  )

```

Ab `App.tsx` — saare routes ek saath:

```tsx
import { useState } from 'react'
import { Routes, Route, Link } from 'react-router-dom'
import ProductCard from './components/ProductCard'
import CartDrawer from './components/CartDrawer'
import ProductDetail from './pages/ProductDetail'
import Checkout from './pages/Checkout'
import OrderConfirmed from './pages/OrderConfirmed'
import { useCart } from './context/CartContext'
import { products } from './data'

function HomePage() {
  const [cartOpen, setCartOpen] = useState(false)
  const { items } = useCart()

  return (
    <div className="max-w-6xl mx-auto p-8">
      <div className="flex justify-between items-center mb-8">
        <h1 className="text-3xl font-bold">E-Commerce Store</h1>
        <button
          onClick={() => setCartOpen(true)}
          className="relative bg-gray-100 px-4 py-2 rounded hover:bg-gray-200 focus:outline-none focus:ring-2 focus:ring-blue-400"
          aria-label={`Open cart, ${items.length} items`}
        >
          Cart ({items.length})
        </button>
      </div>
      <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6">
        {products.map((product) => (
          <Link key={product.id} to={`/product/${product.id}`}>
            <ProductCard product={product} />
          </Link>
        ))}
      </div>
      <CartDrawer isOpen={cartOpen} onClose={() => setCartOpen(false)} />
    </div>
  )
}

export default function App() {
  return (
    <Routes>
      <Route path="/" element={<HomePage />} />
      <Route path="/product/:id" element={<ProductDetail />} />
      <Route path="/checkout" element={<Checkout />} />
      <Route path="/order-confirmed" element={<OrderConfirmed />} />
    </Routes>
  )
}
```

Flow complete: Product list → Add to cart → Cart drawer → Checkout → RHF+Zod validation → Place order → Cart empty → Order confirmation page.
