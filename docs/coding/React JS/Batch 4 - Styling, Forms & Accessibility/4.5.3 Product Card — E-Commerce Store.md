
Card ka component alag file mein banate hain. Props aise hi define karo — abhi interface alag file mein nahi, inline hi rakhte hain.

`src/components/ProductCard.tsx`:

```tsx
interface ProductCardProps {
  id: number
  name: string
  price: number
  image: string
}

export default function ProductCard({ id, name, price, image }: ProductCardProps) {
  return (
    <div className="border rounded-lg overflow-hidden shadow-sm hover:shadow-md transition-shadow">
      <img
        src={image}
        alt={name}
        className="w-full h-64 object-cover"
      />
      <div className="p-4">
        <h2 className="text-lg font-semibold">{name}</h2>
        <p className="text-xl font-bold text-green-600 mt-2">₹{price}</p>
        <button
          className="mt-3 bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600 w-full focus:outline-none focus:ring-2 focus:ring-blue-400"
          aria-label={`Add ${name} to cart`}
        >
          Add to Cart
        </button>
      </div>
    </div>
  )
}
```

`App.tsx` mein import karo aur card replace karo:

```tsx
import ProductCard from './components/ProductCard'

// inside return
{products.map((product) => (
  <ProductCard key={product.id} {...product} />
))}
```

Focus ring aur aria-label add kiye — keyboard navigation aur screen-reader ke liye. Button pe Tab karo, focus ring dikhegi.

Agle step mein product detail page banayenge — iske liye router chahiye.
