## Step 2 — Extract `formState` and `errors`

Back in the earlier session we only pulled `register` and `handleSubmit` from `useForm()`. Now we also need `formState` — which holds the errors.

Before:
```tsx
const { register, handleSubmit } = useForm<FormFields>()
```

Update it:
```tsx
const { register, handleSubmit, formState: { errors } } = useForm<FormFields>()
```

What's `formState: { errors }`?

`formState` is a big object with lots of info about the form — `errors`, `isDirty`, `isSubmitting`, and more.

We only need `errors` right now — so we destructure it directly from `formState`.

`errors` is an object — each field has its own error:

```js
{
  name: { type: 'required', message: '...' },
  email: { type: 'pattern', message: '...' }
}
```

Right now `errors` is an empty object `{}` — no errors.

### Nested Destructuring — Understood

```tsx
const { register, handleSubmit, formState: { errors } } = useForm<FormFields>()
```

This does two things in one line:

1. Pulls `register`, `handleSubmit`, and `formState` out of `useForm()`
2. From `formState`, pulls out `errors` — one step deep

**Without nesting — the normal way:**
```tsx
const { register, handleSubmit, formState } = useForm()
formState.errors  // → have to write formState.errors everywhere
```

**With nesting — shortcut:**
```tsx
const { formState: { errors } } = useForm()
errors  // → just use errors directly, no formState. prefix needed
```

**Colon `:` confusion — rename vs nesting:**
```tsx
const { formState: fs } = useForm()        // ⬅ RENAME — create variable 'fs'
const { formState: { errors } } = useForm() // ⬅ NESTING — go inside, pull errors

// Difference:
// Rename: colon followed by a variable name (fs)
// Nest:   colon followed by { } curly braces — "go inside"
```

**Same thing, different style:**
```tsx
const formState = useForm().formState  // pull the whole formState out
const errors = formState.errors        // then pull errors

// Or one line — same nested destructuring:
const { formState: { errors } } = useForm()
```

Nested destructuring is standard in the RHF community — because `errors` is used everywhere.

## Step 3 — Add Validation Rules in `register`

Remember `register('name')` — you just passed a string?

You can pass a second argument — an **object of rules**:

```tsx
{...register('name', {
  required: 'Name is required'
})}
```

First argument — `'name'` — the field name

Second argument — `{ required: 'Name is required' }` — the rules

`required` means "this field can't be empty." And the string `'Name is required'` is the error message.

---
## Step 4 — Connection: How `register` Rules Flow Into `errors`

This is the most important part — understand it.

When you write in `register`:
```tsx
{...register('name', {
  required: 'Name is required'
})}
```

React Hook Form internally notes: "the `name` field has a `required` rule, and if it fails, the message is `'Name is required'`."

When the user submits with an empty field — React Hook Form checks — name is empty — rule fails — it puts the error in the `errors` object:
```js
errors = {
  name: {
    type: 'required',          // ← which rule failed
    message: 'Name is required'  // ← the same message you passed in register
  }
}
```

So `errors.name.message` gives you the message you set up with `required`.

---
## Step 5 — Display Errors in the UI

`errors.name` exists — `errors.name.message` has the message. Show it:

```tsx
<div>
  <label className="block text-sm font-medium mb-1">Name</label>
  <input
    type="text"
    placeholder="Enter your name"
    className="border border-gray-300 rounded px-3 py-2 w-full"
    {...register('name', {
      required: 'Name is required'
    })}
  />
  {errors.name && (
    <p className="text-red-500 text-sm mt-1">{errors.name.message}</p>
  )}
</div>
```

`{errors.name && <p>...</p>}` — if `errors.name` exists, show the `<p>`.

`{errors.name.message}` — the message you set in `register` — `'Name is required'`

Submit with an empty name — "Name is required" shows on screen ✅

Type in the name — submit again — error disappears automatically ✅

**React Hook Form auto-clears errors — you don't have to manually call `setErrors({})`.**

## Step 6 — Add Email Validation Too

Email needs two rules:

**`required`** — can't be empty

**`pattern`** — must match an email format

```tsx
<div>
  <label className="block text-sm font-medium mb-1">Email</label>
  <input
    type="email"
    placeholder="Enter your email"
    className="border border-gray-300 rounded px-3 py-2 w-full"
    {...register('email', {
      required: 'Email is required',
      pattern: {
        value: /^[^\s@]+@[^\s@]+\.[^\s@]+$/,
        message: 'Email is not in the right format'
      }
    })}
  />
  {errors.email && (
    <p className="text-red-500 text-sm mt-1">{errors.email.message}</p>
  )}
</div>
```

`pattern` is an object:
- `value` — a regex that checks the email format
- `message` — shown if the value doesn't match the pattern

Same flow — `pattern.message` shows up in `errors.email.message`.

Type "abc" — submit — "Email is not in the right format" ✅

Type "abc@gmail.com" — submit — no error ✅

## Complete `ContactForm.tsx` — Clean

```tsx

import { useForm } from 'react-hook-form'

type FormFields = {
  name: string
  email: string
}

export default function ContactForm() {
  const { register, handleSubmit, formState: { errors } } = useForm<FormFields>()

  return (
    <form
      onSubmit={handleSubmit((data) => {
        console.log(data)
      })}
      className="flex flex-col gap-4"
    >
      <div>
        <label className="block text-sm font-medium mb-1">Name</label>
        <input
          type="text"
          placeholder="Enter your name"
          className="border border-gray-300 rounded px-3 py-2 w-full"
          {...register('name', {
            required: 'Name is required'
          })}
        />
        {errors.name && (
          <p className="text-red-500 text-sm mt-1">{errors.name.message}</p>
        )}
      </div>

      <div>
        <label className="block text-sm font-medium mb-1">Email</label>
        <input
          type="email"
          placeholder="Enter your email"
          className="border border-gray-300 rounded px-3 py-2 w-full"
          {...register('email', {
            required: 'Email is required',
            pattern: {
              value: /^[^\s@]+@[^\s@]+\.[^\s@]+$/,
              message: 'Email is not in the right format'
            }
          })}
        />
        {errors.email && (
          <p className="text-red-500 text-sm mt-1">{errors.email.message}</p>
        )}
      </div>

      <button
        type="submit"
        className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
      >
        Submit
      </button>
    </form>
  )
}
```
