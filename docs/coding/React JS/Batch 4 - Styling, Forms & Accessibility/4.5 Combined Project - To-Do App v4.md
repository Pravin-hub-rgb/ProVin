| Batch 4 Concept | To-Do App v4 Mein |
|---|---|
| **Tailwind CSS** | Full app restyled — colors, spacing, shadows, rounded corners, hover effects, transitions |
| **Responsive Design** | Mobile-first grid, responsive navbar, adaptive layout |

## Abhi Tak Kya Hua

3.4 mein To-Do App v3 banaya tha — React Router ke saath multi-page setup, dynamic routes (`/tasks/:id`), protected routes for `/settings`, NavLink with active state, AuthContext, 404 page. Functionally app complete thi — routing kaam karta tha, login/logout hota tha, task CRUD the.

Lekin visually? Batch 4 ke starting mein hi discuss kiya tha — v3 **functional hai par visually unpolished**. Ab v4 mein wahi app lekar, Batch 4 ke saare concepts apply karenge:

1. **Tailwind CSS** — poori app ko style karo, responsive banao
2. **Accessibility** — ARIA labels, focus management, keyboard nav, skip link
3. **React Hook Form + Zod** — task add form ko upgrade karo (validation + auto types)

Koi naya feature nahi add kar rahe — sirf existing features ko polish kar rahe hain. Real life mein bhi yahi hota hai — pehle functionality, phir polish.

## Step 2 — Types with Zod Schema

Pehle types define karte hain — is baar Zod schema se auto-generated types ke saath:

```ts
// types.ts
import { z } from "zod";

// Task schema — form validation ke liye
export const taskSchema = z.object({
  title: z.string().min(1, "Task title is required").max(100, "Title too long"),
  category: z.string().min(1, "Select a category"),
});

export type TaskFormData = z.infer<typeof taskSchema>;

export interface Task {
  id: number;
  title: string;
  completed: boolean;
  category: string;
}

export type FilterStatus = "all" | "active" | "completed";
```

## Step 5 — Task Form with RHF + Zod

Yahan sabse important change hai — 3.4 mein task add karne ke liye sirf ek `<input>` tha bina validation ke. Ab proper form banayenge RHF + Zod ke saath:

```tsx
// components/TaskForm.tsx
import { useForm } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";
import { taskSchema, type TaskFormData } from "../types";

interface TaskFormProps {
  onAdd: (data: TaskFormData) => void;
  categories: string[];
}

export default function TaskForm({ onAdd, categories }: TaskFormProps) {
  const {
    register,
    handleSubmit,
    reset,
    formState: { errors },
  } = useForm<TaskFormData>({
    resolver: zodResolver(taskSchema),
    defaultValues: { title: "", category: "" },
  });

  const submitHandler = (data: TaskFormData) => {
    onAdd(data);
    reset();
  };

  return (
    <form
      onSubmit={handleSubmit(submitHandler)}
      noValidate
      className="bg-white dark:bg-gray-800 rounded-xl p-6 shadow-sm border border-gray-200 dark:border-gray-700 mb-6"
      aria-label="Add new task"
    >
      <h2 className="text-lg font-semibold text-gray-800 dark:text-white mb-4">
        Add New Task
      </h2>

      {/* Title Field */}
      <div className="mb-4">
        <label htmlFor="task-title" className="block text-sm font-medium text-gray-700 dark:text-gray-300 mb-1">
          Task Title
        </label>
        <input
          id="task-title"
          type="text"
          {...register("title")}
          placeholder="What needs to be done?"
          className={`w-full border rounded-lg px-3 py-2 text-gray-800 dark:text-white bg-white dark:bg-gray-700 focus:outline-none focus:ring-2 focus:ring-blue-500 transition-colors ${
            errors.title
              ? "border-red-500 dark:border-red-400"
              : "border-gray-300 dark:border-gray-600"
          }`}
          aria-invalid={!!errors.title}
          aria-describedby={errors.title ? "task-title-error" : undefined}
        />
        {errors.title && (
          <span id="task-title-error" role="alert" className="text-red-600 dark:text-red-400 text-sm mt-1 block">
            {errors.title.message}
          </span>
        )}
      </div>

      {/* Category Field */}
      <div className="mb-4">
        <label htmlFor="task-category" className="block text-sm font-medium text-gray-700 dark:text-gray-300 mb-1">
          Category
        </label>
        <select
          id="task-category"
          {...register("category")}
          className={`w-full border rounded-lg px-3 py-2 text-gray-800 dark:text-white bg-white dark:bg-gray-700 focus:outline-none focus:ring-2 focus:ring-blue-500 transition-colors ${
            errors.category
              ? "border-red-500 dark:border-red-400"
              : "border-gray-300 dark:border-gray-600"
          }`}
          aria-invalid={!!errors.category}
          aria-describedby={errors.category ? "task-category-error" : undefined}
        >
          <option value="">-- Select category --</option>
          {categories.map((cat) => (
            <option key={cat} value={cat}>
              {cat}
            </option>
          ))}
        </select>
        {errors.category && (
          <span id="task-category-error" role="alert" className="text-red-600 dark:text-red-400 text-sm mt-1 block">
            {errors.category.message}
          </span>
        )}
      </div>

      <button
        type="submit"
        className="w-full bg-blue-600 hover:bg-blue-700 text-white font-medium py-2.5 px-4 rounded-lg transition-colors focus:outline-none focus:ring-2 focus:ring-blue-500 focus:ring-offset-2 dark:focus:ring-offset-gray-800"
      >
        Add Task
      </button>
    </form>
  );
}
```

**v3 se changes:**
- `<input>` ko RHF `register` se replace kiya
- Zod validation — title required + max length, category required
- Error messages with `role="alert"` for screen readers
- `aria-invalid` for error state
- Tailwind styling — full polished design
- Category dropdown added (from categories fetched in useEffect, same as v2)

## Step 6 — TaskItem with Tailwind + Accessibility

```tsx
// components/TaskItem.tsx
import type { Task } from "../types";

interface TaskItemProps {
  task: Task;
  onToggle: (id: number) => void;
  onDelete: (id: number) => void;
}

export default function TaskItem({ task, onToggle, onDelete }: TaskItemProps) {
  const taskId = `task-${task.id}`;

  return (
    <div
      className={`flex items-center gap-3 p-4 rounded-lg border transition-all ${
        task.completed
          ? "bg-green-50 dark:bg-green-900/20 border-green-200 dark:border-green-800"
          : "bg-white dark:bg-gray-800 border-gray-200 dark:border-gray-700"
      }`}
    >
      {/* Checkbox */}
      <input
        id={taskId}
        type="checkbox"
        checked={task.completed}
        onChange={() => onToggle(task.id)}
        className="h-5 w-5 rounded border-gray-300 dark:border-gray-600 text-blue-600 focus:ring-2 focus:ring-blue-500 cursor-pointer"
      />

      {/* Task Content */}
      <label
        htmlFor={taskId}
        className={`flex-1 cursor-pointer ${
          task.completed
            ? "line-through text-gray-400 dark:text-gray-500"
            : "text-gray-800 dark:text-gray-200"
        }`}
      >
        <span className="font-medium">{task.title}</span>
        <span className="ml-2 text-xs text-gray-400 dark:text-gray-500 bg-gray-100 dark:bg-gray-700 px-2 py-0.5 rounded-full">
          {task.category}
        </span>
      </label>

      {/* Delete Button */}
      <button
        onClick={() => onDelete(task.id)}
        className="text-red-500 hover:text-red-700 dark:text-red-400 dark:hover:text-red-300 transition-colors p-1 rounded focus:outline-none focus:ring-2 focus:ring-red-500"
        aria-label={`Delete task: ${task.title}`}
      >
        ✕
      </button>
    </div>
  );
}
```

**Accessibility in TaskItem:**
- `htmlFor` + `id` on checkbox — label click se checkbox toggle
- `aria-label` on delete button — screen reader "Delete task: Buy groceries"
- Focus ring on both checkbox and delete button
- Color-coded states — green for completed, with dark mode support

## Step 8 — Dashboard Page

```tsx
// pages/Dashboard.tsx
import { useState, useEffect } from "react";
import { useAuth } from "../context/AuthContext";
import TaskForm from "../components/TaskForm";
import TaskItem from "../components/TaskItem";
import type { Task, FilterStatus, TaskFormData } from "../types";

export default function Dashboard() {
  const [tasks, setTasks] = useState<Task[]>([]);
  const [filter, setFilter] = useState<FilterStatus>("all");
  const [categories, setCategories] = useState<string[]>(["general", "work", "personal"]);
  const { user, login } = useAuth();

  // Categories fetch (simulated — real mein API se aayega)
  useEffect(() => {
    // setTimeout se API call simulate kar sakte ho
    setCategories(["general", "work", "personal", "health", "finance"]);
  }, []);

  const addTask = (data: TaskFormData) => {
    const newTask: Task = {
      id: Date.now(),
      title: data.title.trim(),
      completed: false,
      category: data.category,
    };
    setTasks((prev) => [newTask, ...prev]);
  };

  const toggleTask = (id: number) => {
    setTasks((prev) => prev.map((t) => (t.id === id ? { ...t, completed: !t.completed } : t)));
  };

  const deleteTask = (id: number) => {
    setTasks((prev) => prev.filter((t) => t.id !== id));
  };

  const filteredTasks = tasks.filter((t) => {
    if (filter === "active") return !t.completed;
    if (filter === "completed") return t.completed;
    return true;
  });

  const remainingCount = tasks.filter((t) => !t.completed).length;

  return (
    <div>
      {/* Header */}
      <div className="flex items-center justify-between mb-6">
        <h1 className="text-2xl font-bold text-gray-800 dark:text-white">📋 Dashboard</h1>
        {!user && (
          <button
            onClick={() => login("DemoUser")}
            className="text-sm bg-gray-200 dark:bg-gray-700 hover:bg-gray-300 dark:hover:bg-gray-600 text-gray-700 dark:text-gray-200 px-4 py-2 rounded-lg transition-colors focus:outline-none focus:ring-2 focus:ring-blue-500"
          >
            Login (Demo)
          </button>
        )}
      </div>

      {/* Task Form */}
      <TaskForm onAdd={addTask} categories={categories} />

      {/* Filter Bar */}
      <div className="flex gap-2 mb-4" role="group" aria-label="Filter tasks">
        {(["all", "active", "completed"] as const).map((f) => (
          <button
            key={f}
            onClick={() => setFilter(f)}
            className={`px-4 py-1.5 rounded-lg text-sm font-medium transition-colors focus:outline-none focus:ring-2 focus:ring-blue-500 ${
              filter === f
                ? "bg-blue-600 text-white"
                : "bg-gray-100 dark:bg-gray-700 text-gray-600 dark:text-gray-300 hover:bg-gray-200 dark:hover:bg-gray-600"
            }`}
            aria-pressed={filter === f}
          >
            {f.charAt(0).toUpperCase() + f.slice(1)}
          </button>
        ))}
      </div>

      {/* Task Count */}
      <p className="text-sm text-gray-500 dark:text-gray-400 mb-4">
        {remainingCount} / {tasks.length} tasks remaining
      </p>

      {/* Task List */}
      {filteredTasks.length === 0 ? (
        <p className="text-gray-400 dark:text-gray-500 text-center py-12">
          {tasks.length === 0 ? "No tasks yet. Add one above!" : "No tasks match this filter."}
        </p>
      ) : (
        <div className="space-y-3" role="list" aria-label="Task list">
          {filteredTasks.map((task) => (
            <TaskItem key={task.id} task={task} onToggle={toggleTask} onDelete={deleteTask} />
          ))}
        </div>
      )}

      {/* Clear Completed */}
      {tasks.some((t) => t.completed) && (
        <button
          onClick={() => setTasks((prev) => prev.filter((t) => !t.completed))}
          className="mt-4 text-sm text-red-600 dark:text-red-400 hover:text-red-800 dark:hover:text-red-300 transition-colors focus:outline-none focus:ring-2 focus:ring-red-500 rounded px-2 py-1"
        >
          Clear completed
        </button>
      )}
    </div>
  );
}
```

## Step 9 — Settings Modal with Focus-Trap

Batc 4.2 ka focus-trap pattern yahan modal mein implement karte hain:

```tsx
// pages/Settings.tsx
import { useState, useRef, useEffect } from "react";
import { useAuth } from "../context/AuthContext";

export default function Settings() {
  const { user, logout } = useAuth();
  const [showConfirm, setShowConfirm] = useState(false);
  const modalRef = useRef<HTMLDivElement>(null);
  const confirmBtnRef = useRef<HTMLButtonElement>(null);

  const getFocusable = (): HTMLElement[] => {
    if (!modalRef.current) return [];
    const sel = 'button, a[href], input, [tabindex]:not([tabindex="-1"])';
    return Array.from(modalRef.current.querySelectorAll<HTMLElement>(sel));
  };

  useEffect(() => {
    if (showConfirm) {
      const focusable = getFocusable();
      focusable[0]?.focus();
    }
  }, [showConfirm]);

  const handleKeyDown = (e: React.KeyboardEvent) => {
    if (e.key === "Escape") {
      setShowConfirm(false);
      return;
    }
    if (e.key === "Tab") {
      const focusable = getFocusable();
      const first = focusable[0];
      const last = focusable[focusable.length - 1];
      if (e.shiftKey && document.activeElement === first) {
        e.preventDefault();
        last?.focus();
      } else if (!e.shiftKey && document.activeElement === last) {
        e.preventDefault();
        first?.focus();
      }
    }
  };

  return (
    <div>
      <h1 className="text-2xl font-bold text-gray-800 dark:text-white mb-6">⚙️ Settings</h1>

      {!user ? (
        <div className="bg-white dark:bg-gray-800 rounded-xl p-6 shadow-sm text-gray-600 dark:text-gray-300">
          Please log in from the Dashboard to access settings.
        </div>
      ) : (
        <div className="bg-white dark:bg-gray-800 rounded-xl p-6 shadow-sm border border-gray-200 dark:border-gray-700">
          <p className="text-gray-700 dark:text-gray-200 mb-2">
            Logged in as: <strong>{user}</strong>
          </p>
          <p className="text-gray-500 dark:text-gray-400 text-sm mb-6">
            Click below to log out. A confirmation dialog will appear.
          </p>

          <button
            ref={confirmBtnRef}
            onClick={() => setShowConfirm(true)}
            className="bg-red-600 hover:bg-red-700 text-white px-6 py-2 rounded-lg font-medium transition-colors focus:outline-none focus:ring-2 focus:ring-red-500"
          >
            Logout
          </button>
        </div>
      )}

      {/* Confirmation Modal with Focus-Trap */}
      {showConfirm && (
        <div
          className="fixed inset-0 bg-black/50 flex items-center justify-center z-50"
          onClick={() => setShowConfirm(false)}
        >
          <div
            ref={modalRef}
            role="dialog"
            aria-modal="true"
            aria-labelledby="confirm-title"
            onKeyDown={handleKeyDown}
            onClick={(e) => e.stopPropagation()}
            className="bg-white dark:bg-gray-800 rounded-xl p-6 max-w-sm w-full mx-4 shadow-xl"
          >
            <h2 id="confirm-title" className="text-lg font-semibold text-gray-800 dark:text-white mb-3">
              Confirm Logout
            </h2>
            <p className="text-gray-600 dark:text-gray-300 mb-6">
              Are you sure you want to log out?
            </p>
            <div className="flex gap-3 justify-end">
              <button
                onClick={() => setShowConfirm(false)}
                className="px-4 py-2 rounded-lg bg-gray-100 dark:bg-gray-700 text-gray-700 dark:text-gray-200 font-medium hover:bg-gray-200 dark:hover:bg-gray-600 transition-colors focus:outline-none focus:ring-2 focus:ring-gray-400"
              >
                Cancel
              </button>
              <button
                onClick={() => {
                  logout();
                  setShowConfirm(false);
                }}
                className="px-4 py-2 rounded-lg bg-red-600 hover:bg-red-700 text-white font-medium transition-colors focus:outline-none focus:ring-2 focus:ring-red-500"
              >
                Logout
              </button>
            </div>
          </div>
        </div>
      )}
    </div>
  );
}
```

## What It Is NOT

- **v4 mein koi naya feature nahi add kiya** (tasks, categories, theme, auth — sab v3 jaisa hai). Sirf styling, accessibility, aur form validation upgrade ki hai.
- **Skip link sirf keyboard users ke liye visible hai.** `sr-only` class se visual users ke liye hidden hai, lekin focus hone par visible ho jata hai (`focus:not-sr-only`).
- **RHF + Zod form sirf task add ke liye replace kiya.** Baaki forms (login, edit) abhi bhi un-touched hain — real project mein sab forms ko upgrade karna hoga.
- **Focus-trap sirf settings modal mein implement kiya.** Agar aur modals add karoge (task edit modal, confirmation dialogs), toh unmein bhi focus-trap lagana padega.

<summary>v4 mein accessibility ke liye kaun-se specific changes kiye hain?</summary>

(1) Skip link for keyboard users — navbar skip karke directly main content pe jaa sakte hain. (2) aria-label on all icon-only buttons (theme toggle, delete). (3) aria-invalid + aria-describedby on form fields for error association. (4) role="alert" on error messages. (5) focus:ring-2 on all interactive elements for visible focus indicator. (6) aria-pressed on filter buttons to indicate active state. (7) role="dialog" + aria-modal + aria-labelledby on confirmation modal. (8) Focus-trap in modal — Tab cycle within modal, Escape to close.
</details>

<details>
<summary>Focus-trap confirmation modal mein kaise kaam karta hai?</summary>

Jab "Logout" button click karte hain, `showConfirm` state true hoti hai. Modal render hota hai with `role="dialog"` and `aria-modal="true"`. useEffect detects modal open → first focusable button pe focus (Cancel). handleKeyDown: Escape → modal close + focus wapas Logout button pe. Tab on last element → cycle to first. Shift+Tab on first → cycle to last. Backdrop click → modal close. Yeh pattern ensure karta hai ki keyboard user ka focus modal ke andar hi rahe.
</details>

<details>
<summary>Dark mode v4 mein kaise implement hua hai? Tailwind ka dark: prefix kya karta hai?</summary>

ThemeContext already v2 mein banaya tha (dark/light toggle). v4 mein Tailwind ke `dark:` prefix ka use kiya — component ke className mein `dark:` prefix ke saath dark mode styles add kiye. Jaise: `bg-white dark:bg-gray-800`, `text-gray-800 dark:text-white`. Jab DOM mein parent element pe `.dark` class hoti hai (jo ThemeContext add karta hai), Tailwind automatically `dark:` prefix wali classes apply karta hai. Isse ek hi component file mein light aur dark mode dono defined hain, alag CSS files ki zaroorat nahi.
</details>
