## `z.infer` — Auto-Generate TypeScript Type from Schema

So far we've been manually writing the `FormFields` type:

```tsx
type FormFields = {
  name: string
  email: string
}
```

But this is **duplicate** — the same fields are already in the schema. If the schema changes, we have to update the type manually.

**Double maintenance** — change one place, forget the other, get a bug.

## Solution: `z.infer`

Zod's `z.infer` auto-generates the TypeScript type from the schema:

```tsx
const formSchema = z.object({
  name: z.string().min(1, 'Name is required'),
  email: z.email('Email is not in the right format'),
})

// Auto-generate the type from the schema
type FormFields = z.infer<typeof formSchema>
```

**`z.infer<typeof formSchema>`** — "extract the TypeScript type from `formSchema`."

Zod figures it out:
- `z.string()` → `string`
- `z.email()` → `string`
- `.min(1)` → still `string` (it's a validation rule, doesn't change the type)

So `FormFields` is automatically:

```ts
type FormFields = {
  name: string
  email: string
}
```

Now use this type in `useForm`:

```tsx
const { register, handleSubmit, formState: { errors } } = useForm<FormFields>({
  resolver: zodResolver(formSchema)
})
```

Now if you change the schema — the type updates automatically. No more double maintenance.

## Complete `ContactForm.tsx` — Final Version

```tsx

import { useForm } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'
import { z } from 'zod'

// Step 1: Create the schema
const formSchema = z.object({
  name: z.string().min(1, 'Name is required'),
  email: z.email('Email is not in the right format'),
})

// Step 2: Auto-generate the type from the schema
type FormFields = z.infer<typeof formSchema>

export default function ContactForm() {
  // Step 3: Pass both the type and resolver to useForm
  const { register, handleSubmit, formState: { errors } } = useForm<FormFields>({
    resolver: zodResolver(formSchema)
  })

  return (
    <form
      onSubmit={handleSubmit((data) => {
        console.log(data)
      })}
      className="flex flex-col gap-4 max-w-md"
    >
      {/* Name */}
      <div>
        <label className="block text-sm font-medium mb-1">Name</label>
        <input
          type="text"
          placeholder="Enter your name"
          className="border border-gray-300 rounded px-3 py-2 w-full"
          {...register('name')}
        />
        {errors.name && (
          <p className="text-red-500 text-sm mt-1">{errors.name.message}</p>
        )}
      </div>

      {/* Email */}
      <div>
        <label className="block text-sm font-medium mb-1">Email</label>
        <input
          type="email"
          placeholder="Enter your email"
          className="border border-gray-300 rounded px-3 py-2 w-full"
          {...register('email')}
        />
        {errors.email && (
          <p className="text-red-500 text-sm mt-1">{errors.email.message}</p>
        )}
      </div>

      <button
        type="submit"
        className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
      >
        Submit
      </button>
    </form>
  )
}
```
