3. npm / npx (Node.js) and Bun Equivalents

When you install Node.js, you get these two command-line tools:

Tool	Purpose
npm	Package installer — permanently downloads/installs any JavaScript library into your project (e.g. npm install react)
npx	Package executor — runs a package once without permanently installing it (e.g. npx create-vite)

npx's specific use case is project-scaffolding tools — tools that run only once (to create a project) and don't need to be kept permanently afterward.

Bun has two equivalent tools that do exactly the same job:

Node.js/npm	Bun
npm install	bun install
npx create-vite	bunx create-vite
npm run dev	bun run dev

The concept is identical in both — only the command name differs. Now we'll build an actual project using these tools — but before creating a project, it's important to understand which tool we'll use to create it, because that same tool will also run the dev server and create the final build.
