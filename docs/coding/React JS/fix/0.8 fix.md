3. npm / npx (Node.js) aur Bun ke Equivalents

Node.js install hone ke saath ye do command-line tools milte hain:
Tool	Kaam
npm	Package installer — kisi bhi JavaScript library ko project mein permanently download/install karta hai (e.g. npm install react)
npx	Package executor — kisi package ko permanently install kiye bina, ek baar ke liye directly run karta hai (e.g. npx create-vite)

npx ka specific use-case project-scaffolding tools hote hain — jaise koi tool jo sirf ek baar chalta hai (project banane ke liye), aur uske baad usse permanently rakhne ki zaroorat nahi hoti.

Bun mein exactly yehi kaam karne wale do equivalent tools hain:
Node.js/npm	Bun
npm install	bun install
npx create-vite	bunx create-vite
npm run dev	bun run dev

Concept dono mein identical hai — sirf command ka naam alag hai. Ab in tools ka use karke ek actual project banayenge — lekin project banane se pehle ye samajhna zaroori hai ki kis tool se banayenge, kyunki wahi tool dev server bhi chalayega aur final build bhi banayega.

### Bas ek chhoti technical correction

Tumhare notes mein ye line bhi thodi misleading hai:

> **"npm install → bun install"**

Actually `bun install` ka primary kaam **`package.json` mein listed dependencies install karna** hai (jaise `npm install` bina package name ke). Agar kisi specific package ko add karna ho, to Bun mein aam taur par:

```bash
bun add react
```

use kiya jaata hai, jo `npm install react` ke equivalent ke zyada close hai.

Isliye agar tum Bun bhi properly cover kar rahe ho, to comparison kuch aisa hona chahiye:

| Node.js             | Bun                |
| ------------------- | ------------------ |
| `npm install`       | `bun install`      |
| `npm install react` | `bun add react`    |
| `npx create-vite`   | `bunx create-vite` |
| `npm run dev`       | `bun run dev`      |

## Ek aur chhoti correction

Ek technical detail jo notes mein accurate honi chahiye:

`create-vite` **React ko khud install nahi karta**. Wo project scaffold karta hai (files aur `package.json` banata hai). Uske baad jab tum:

```bash
npm install
```

chalate ho, tab `package.json` mein listed dependencies (`react`, `react-dom`, `vite`, etc.) project ke andar install hoti hain.

Isliye actual sequence hota hai:

```text
npx create-vite my-app
        │
        ▼
Project files + package.json create

        │
        ▼
npm install

        │
        ▼
React, ReactDOM, Vite, TypeScript, etc. install

        │
        ▼
npm run dev
```

Mujhe lagta hai ye sequence notes mein diagram ke saath dikhana chahiye. Ek baar ye click ho gaya, to `npm`, `npx`, `Vite`, `create-vite`, aur baad mein `bun`, `bunx` sab naturally samajh aa jayenge.
Project scaffolding क्या होता है ना भाई इतना बड़ा word drop करने से तो भाई बस तुमने statement लिख लिख दी तुमको समझा थोड़ी ना. It is a project scaffolding and build tool मतलब समझ नहीं.🤣🤣 Arre haan bhai, pakad liya.

**Wo "project scaffolding aur build tool" maine hi likha tha** jab rewrite kar raha tha. Aur ab jab tumne usko question kiya, tab mujhe realize hua ki **main bhi wahi galti kar gaya** jo hum original notes mein point out kar rahe the.

Aur ye actually ek achhi learning hai course design ke liye.

Maine bhi assume kar liya tha ki:

> "Project scaffolding" aur "build tool" common terms hain.

Lekin **beginner ke liye ye bhi jargon hi hai.**

> **Agar kisi sentence mein koi naya technical word hai, aur uske bina bhi explanation di ja sakti hai, to pehle technical word use mat karo.**

Example.

❌ Aisa nahi.

> Vite is a project scaffolding and build tool.

Reader:

> "Accha... matlab? 🤡"

✅ Aise.

> Socho tumhe ek naya React project banana hai.
>
> Agar koi tool na ho, to tumhe manually folders banane padenge, files create karni padengi, React install karna padega, TypeScript configure karna padega aur development server setup karna padega.
>
> Ye repetitive kaam har project mein same hota hai.
>
> Isliye Vite naam ka tool bana hai. Ye naya project automatically ready kar deta hai taaki tum seedha coding shuru kar sako.
>
> **Project ka initial structure automatically create karne ki process ko Project Scaffolding kehte hain.**

Ab "Project Scaffolding" ek **naya word** nahi lagta.

Wo bas us explanation ka naam ban gaya.

---

Waise hi "Build Tool".

❌ Galat.

> Vite is a build tool.

Reader:

> "Build??"

---

✅ Sahi.

> Browser TypeScript aur JSX ko directly execute nahi kar sakta.
>
> Isliye ek tool un files ko browser ke samajhne layak JavaScript mein convert karta hai aur development server bhi chalata hai.
>
> Aise tools ko Build Tools kehte hain.
>
> React mein hum Vite use karenge.
