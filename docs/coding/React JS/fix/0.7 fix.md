TypeScript vs JavaScript — Key Differences

Yeh dono code dekho — JS aur TS side by side:

// JavaScript — koi type check nahi
function add(a, b) {
  return a + b;
}
add(5, "10"); // "510" — may be bug, but JS doesn't care

// TypeScript — types defined
function add(a: number, b: number): number {
  return a + b;
}
add(5, "10"); // ❌ Error: Argument of type 'string' not assignable to parameter of type 'number'

TypeScript error development time mein dikhata hai. Browser mein jaane se pehle hi pata chal jaata hai.
Basic Types (Quick Revision)

// Basic types
let name: string = "Vin";
let age: number = 25;
let isLearning: boolean = true;
let data: null = null;
let notDefined: undefined = undefined;

// Arrays
let fruits: string[] = ["apple", "mango", "banana"];
let numbers: Array<number> = [1, 2, 3]; // same as number[]

// Objects
let user: { name: string; age: number } = {
  name: "Vin",
  age: 25,
};

// Union types — multiple types allow
let id: string | number = "abc123";
id = 456; // ✅ allowed (number bhi ho sakta hai)
// id = true; // ❌ Error

// Any — kuch bhi (avoid karo, type safety khatam)
let loose: any = "hello";
loose = 42; // no error
loose = true; // no error — but ab type checking ka fayda nahi

// Unknown — any jaisa but safe (use karo jab type nahi pata)
let input: unknown = "hello";
// input.toUpperCase(); // ❌ Error — pehle type check karo
if (typeof input === "string") {
  input.toUpperCase(); // ✅ Ab safe hai
}

type vs interface

Dono se object shapes define kar sakte ho. Fark minor hai but important:

// type
type User = {
  name: string;
  age: number;
};

// interface
interface IUser {
  name: string;
  age: number;
}

// Dono ka use same:
function greet(user: User) {
  return `Hello, ${user.name}`;
}

Feature	type	interface
Object shape	✅	✅
Extend	& (intersection)	extends
Add new props (declaration merging)	❌	✅
Union types	✅	❌
Primitives	✅	❌
Best for	Complex types, unions, primitives	Objects, class implementation

React mein mostly interface use karte hain component props ke liye. Type use karte hain unions, utility types ke liye.

// Props ke liye interface prefer karo
interface ButtonProps {
  label: string;
  onClick: () => void;
  variant?: "primary" | "secondary";
}

// Union types ke liye type prefer karo
type Status = "loading" | "success" | "error";

Function Typing

// Function with typed params and return
function add(a: number, b: number): number {
  return a + b;
}

// Arrow function
const multiply = (a: number, b: number): number => a * b;

// Void return (kuch return nahi karta)
function log(message: string): void {
  console.log(message);
}

// Optional parameter
function greet(name: string, greeting?: string): string {
  return `${greeting || "Hello"}, ${name}`;
}

Ye woh types hain jo React mein regularly use hote hain:

// Component props

Pehla Component — TypeScript Ke Saath

src/App.tsx ko replace karo:

import { useState } from "react";

// Props interface define kiya
interface GreetingProps {
  name: string;
  age?: number; // Optional prop
}

// Component — typed props ke saath
function Greeting({ name, age }: GreetingProps) {
  return (
    <div>
      <h1>Hello, {name}!</h1>
      {age && <p>Age: {age}</p>}
    </div>
  );
}

// Main App component
function App() {
  const [count, setCount] = useState<number>(0);

  return (
    <div>
      <Greeting name="Vin" age={25} />
      
      <p>Count: {count}</p>
      <button onClick={() => setCount((c) => c + 1)}>
        Increment
      </button>
    </div>
  );
}

export default App;

## Ek aur suggestion

Tumhare roadmap mein ek **parallel TypeScript track** add karna bhi bahut accha rahega.

```
React Module 0
        │
        ├── TS Warm-up (Basics only)
        │
React Module 1
        │
        ├── TS: Interfaces & Props
        │
React Module 2
        │
        ├── TS: Generics (useState, useRef)
        │
React Module 3
        │
        ├── TS: Event Types
        │
React Module 4
        │
        ├── TS: Advanced Types (type, utility types)
```

Is approach ka fayda ye hai ki **student ko kabhi bhi "ye topic out of the blue aa gaya" wali feeling nahi aayegi.** Har TypeScript concept usi waqt introduce hoga jab React uski demand karega. Mujhe lagta hai ye tumhare course ka sabse strong design decision ho sakta hai.
