## Step 2 — Types (Normalized State Design)

Pehla decision — **state structure**. Do options hain:

**Nested (denormalized):**
```ts
{
  columns: [
    { id: "todo", title: "To Do", cards: [{ id, title, ... }] }
  ]
}
```
Problem: card update karna hai toh poori column array find karni padti hai. Card move karna hai toh ek column se nikaal ke doosre mein daalna. Complex operations cumbersome.

**Normalized (recommended):**
```ts
{
  columns: {
    todo: { id: "todo", title: "To Do", cardIds: ["card1", "card2"] },
    progress: { id: "progress", title: "In Progress", cardIds: ["card3"] },
    done: { id: "done", title: "Done", cardIds: [] }
  },
  cards: {
    card1: { id: "card1", title: "...", description: "...", assignee: "...", priority: "high" }
  },
  columnOrder: ["todo", "progress", "done"]
}
```

Fayda: card update ke liye sirf `cards.card1` change karo — koi column find/update nahi. Card move: sirf dono columns ke `cardIds` arrays update. **O(1) lookup** for any card. Yeh wahi approach hai jo industry-standard libraries (Redux docs, `react-beautiful-dnd`) recommend karti hain.

```ts
// types.ts
export interface Card {
  id: string;
  title: string;
  description: string;
  assignee: string;
  priority: "low" | "medium" | "high";
}

export interface Column {
  id: string;
  title: string;
  cardIds: string[];
}

export interface BoardState {
  columns: Record<string, Column>;
  cards: Record<string, Card>;
  columnOrder: string[];
}
```

`Record<string, Column>` ek object hai jahan keys column IDs hain. Jaise lookup table — `columns["todo"]` instantly column dega. Fast aur simple.

## Step 3 — Zustand Store with Undo/Redo

Ab normalized state ke saath store banate hain. Lekin undo/redo bhi chahiye.

**Undo/Redo ka concept:** Har state change se pehle, current state ka snapshot save karo. `undo` = previous snapshot pe wapas jao. `redo` = future snapshot pe aage jao.

Zustand ka built-in `history` middleware nahi hai, lekin custom wrapper bana sakte hain:

```ts
// stores/boardStore.ts
import { create } from "zustand";
import { persist } from "zustand/middleware";
import type { BoardState, Card, Column } from "../types";

interface BoardActions {
  addCard: (columnId: string, card: Card) => void;
  updateCard: (cardId: string, updates: Partial<Card>) => void;
  deleteCard: (cardId: string) => void;
  moveCard: (cardId: string, fromCol: string, toCol: string, toIndex?: number) => void;
  addColumn: (column: Column) => void;
  undo: () => void;
  redo: () => void;
}

type BoardStore = BoardState & BoardActions & {
  past: BoardState[];
  future: BoardState[];
};

const initialState: BoardState = {
  columns: {
    todo: { id: "todo", title: "To Do", cardIds: [] },
    progress: { id: "progress", title: "In Progress", cardIds: [] },
    done: { id: "done", title: "Done", cardIds: [] },
  },
  cards: {},
  columnOrder: ["todo", "progress", "done"],
};

function snapshot(state: BoardStore): BoardState {
  return {
    columns: state.columns,
    cards: state.cards,
    columnOrder: state.columnOrder,
  };
}

export const useBoardStore = create<BoardStore>()(
  persist(
    (set, get) => ({
      ...initialState,
      past: [],
      future: [],

      addCard: (columnId, card) => {
        set((state) => ({
          past: [...state.past, snapshot(state)],
          future: [],
          cards: { ...state.cards, [card.id]: card },
          columns: {
            ...state.columns,
            [columnId]: {
              ...state.columns[columnId],
              cardIds: [...state.columns[columnId].cardIds, card.id],
            },
          },
        }));
      },

      updateCard: (cardId, updates) => {
        set((state) => ({
          past: [...state.past, snapshot(state)],
          future: [],
          cards: {
            ...state.cards,
            [cardId]: { ...state.cards[cardId], ...updates },
          },
        }));
      },

      deleteCard: (cardId) => {
        set((state) => {
          const columnId = state.columnOrder.find((colId) =>
            state.columns[colId].cardIds.includes(cardId)
          );
          if (!columnId) return state;
          return {
            past: [...state.past, snapshot(state)],
            future: [],
            cards: Object.fromEntries(
              Object.entries(state.cards).filter(([id]) => id !== cardId)
            ),
            columns: {
              ...state.columns,
              [columnId]: {
                ...state.columns[columnId],
                cardIds: state.columns[columnId].cardIds.filter(
                  (id) => id !== cardId
                ),
              },
            },
          };
        });
      },

      moveCard: (cardId, fromCol, toCol, toIndex) => {
        set((state) => {
          const fromColumn = state.columns[fromCol];
          const toColumn = state.columns[toCol];
          const fromCardIds = fromColumn.cardIds.filter((id) => id !== cardId);
          const toCardIds = [...toColumn.cardIds];
          toIndex !== undefined
            ? toCardIds.splice(toIndex, 0, cardId)
            : toCardIds.push(cardId);

          return {
            past: [...state.past, snapshot(state)],
            future: [],
            columns: {
              ...state.columns,
              [fromCol]: { ...fromColumn, cardIds: fromCardIds },
              [toCol]: { ...toColumn, cardIds: toCardIds },
            },
          };
        });
      },

      addColumn: (column) => {
        set((state) => ({
          past: [...state.past, snapshot(state)],
          future: [],
          columns: { ...state.columns, [column.id]: column },
          columnOrder: [...state.columnOrder, column.id],
        }));
      },

      undo: () => {
        set((state) => {
          if (state.past.length === 0) return state;
          const previous = state.past[state.past.length - 1];
          return {
            past: state.past.slice(0, -1),
            future: [snapshot(state), ...state.future],
            columns: previous.columns,
            cards: previous.cards,
            columnOrder: previous.columnOrder,
          };
        });
      },

      redo: () => {
        set((state) => {
          if (state.future.length === 0) return state;
          const next = state.future[0];
          return {
            future: state.future.slice(1),
            past: [...state.past, snapshot(state)],
            columns: next.columns,
            cards: next.cards,
            columnOrder: next.columnOrder,
          };
        });
      },
    }),
    {
      name: "kanban-board",
      partialize: (state) => ({
        columns: state.columns,
        cards: state.cards,
        columnOrder: state.columnOrder,
        // past/future persist nahi karte — undo/redo session-level hai
      }),
    }
  )
);
```

**Key decisions in store:**

| Decision | Kyun |
|----------|------|
| `past` and `future` in store | Har mutation se pehle snapshot save. Undo = past pop, future push. |
| `snapshot()` function | Pure state copy — ensure karta hai ki mutations store bahar na jayein |
| `partialize` in persist | Sirf board state persist karo, undo history nahi (session-level) |
| Card move with `filter` + `splice` | Immutable update pattern — purani array change nahi karte |
| `Object.fromEntries` for delete | Filter out deleted card from cards object |

**State diagram — Card move karte waqt:**

```
User drags card from "todo" to "progress"
    │
    ├── snapshot(state) → save to past
    ├── future = [] (clear redo stack)
    │
    ├── fromColumn.cardIds = [..., cardId] → filter out cardId
    ├── toColumn.cardIds = [...toColumn.cardIds, cardId] → add cardId
    │
    ├── columns updated → UI re-renders
    │
    └── undo available → one click back
```

## Step 4 — Generic UI Components

Ab components banate hain jo generic hain — `<Card<T>>` aur `<Column<T>>` kisi bhi data type ke saath kaam karein.

### Generic Card<T>

Card component ko data type ka pata nahi hona chahiye. Bas render karo jo content diya jaye:

```tsx
// components/Card.tsx
import { memo, type ReactNode } from "react";

interface CardProps<T> {
  card: T;
  renderContent: (card: T) => ReactNode;
  onDragStart: (cardId: string) => void;
}

function GenericCard<T extends { id: string }>({
  card,
  renderContent,
  onDragStart,
}: CardProps<T>) {
  return (
    <div
      draggable
      onDragStart={() => onDragStart(card.id)}
      className="card"
    >
      {renderContent(card)}
    </div>
  );
}

export const Card = memo(GenericCard) as typeof GenericCard;
```

**What's happening:**

| Line | Kya Hai |
|------|---------|
| `<T extends { id: string }>` | Generic constraint — koi bhi type jiska `id: string` ho |
| `renderContent: (card: T) => ReactNode` | Render prop — caller decide karta hai card ka UI |
| `draggable` + `onDragStart` | HTML5 drag and drop — native browser API |
| `memo(GenericCard)` | React.memo — same props = skip re-render (Batch 5) |

**Card ka actual content decide karega caller:**

```tsx
<Card<CardData>
  card={card}
  renderContent={(c) => (
    <div>
      <h3>{c.title}</h3>
      <p>{c.description}</p>
      <span className={`priority-${c.priority}`}>{c.priority}</span>
    </div>
  )}
  onDragStart={handleDragStart}
/>
```

### Generic Column<T>

Column bhi generic — kisi bhi type ke cards ka container:

```tsx
// components/Column.tsx
import { memo, useCallback, type ReactNode, type DragEvent } from "react";
import { Card } from "./Card";

interface ColumnProps<T> {
  column: { id: string; title: string; cardIds: string[] };
  cards: T[];
  renderCardContent: (card: T) => ReactNode;
  onDragStart: (cardId: string) => void;
  onDrop: (columnId: string) => void;
  columnId: string;
}

function GenericColumn<T extends { id: string }>({
  column,
  cards,
  renderCardContent,
  onDragStart,
  onDrop,
  columnId,
}: ColumnProps<T>) {
  const handleDragOver = useCallback((e: DragEvent) => {
    e.preventDefault(); // drop allow karne ke liye zaroori
  }, []);

  const handleDrop = useCallback(() => {
    onDrop(columnId);
  }, [columnId, onDrop]);

  return (
    <div
      onDragOver={handleDragOver}
      onDrop={handleDrop}
      className="column"
    >
      <h2>{column.title} ({cards.length})</h2>
      {cards.map((card) => (
        <Card<T>
          key={card.id}
          card={card}
          renderContent={renderCardContent}
          onDragStart={onDragStart}
        />
      ))}
    </div>
  );
}

export const Column = memo(GenericColumn) as typeof GenericColumn;
```

**HTML5 Drag & Drop — teen events:**

| Event | Column Mein | Card Mein |
|-------|-------------|-----------|
| `onDragStart` | — | Card apne card ID ko store karega |
| `onDragOver` | `preventDefault()` — allow drop | — |
| `onDrop` | Column ko pata chalega ki card drop hua | — |

### Board Component

Ab Board component mein sab jodte hain:

```tsx
// components/Board.tsx
import { useCallback, useState } from "react";
import { useBoardStore } from "../stores/boardStore";
import { Column } from "./Column";
import { AddCardForm } from "./AddCardForm";
import type { Card as CardType } from "../types";

export function Board() {
  const { columns, cards, columnOrder, moveCard, addCard, undo, redo } =
    useBoardStore();
  const [draggedCardId, setDraggedCardId] = useState<string | null>(null);

  const handleDragStart = useCallback((cardId: string) => {
    setDraggedCardId(cardId);
  }, []);

  const handleDrop = useCallback(
    (targetColumnId: string) => {
      if (!draggedCardId) return;
      // Find source column
      const sourceColumnId = columnOrder.find((colId) =>
        columns[colId].cardIds.includes(draggedCardId)
      );
      if (!sourceColumnId || sourceColumnId === targetColumnId) return;
      moveCard(draggedCardId, sourceColumnId, targetColumnId);
      setDraggedCardId(null);
    },
    [draggedCardId, columnOrder, columns, moveCard]
  );

  const handleAddCard = useCallback(
    (columnId: string, card: CardType) => {
      addCard(columnId, card);
    },
    [addCard]
  );

  return (
    <div>
      <div className="toolbar">
        <button onClick={undo}>↩ Undo</button>
        <button onClick={redo}>↪ Redo</button>
      </div>
      <div className="board">
        {columnOrder.map((colId) => {
          const column = columns[colId];
          const columnCards = column.cardIds
            .map((cardId) => cards[cardId])
            .filter(Boolean);

          return (
            <div key={colId} className="column-wrapper">
              <Column<CardType>
                column={column}
                cards={columnCards}
                columnId={colId}
                renderCardContent={(card) => (
                  <div>
                    <h3>{card.title}</h3>
                    <p>{card.description}</p>
                    <span className={`priority-${card.priority}`}>
                      {card.priority}
                    </span>
                  </div>
                )}
                onDragStart={handleDragStart}
                onDrop={handleDrop}
              />
              <AddCardForm columnId={colId} onAdd={handleAddCard} />
            </div>
          );
        })}
      </div>
    </div>
  );
}
```

**Flow — User card drag karta hai:**

```
User drags card from "todo" column
    │
    ├── Card's onDragStart → setDraggedCardId("card-1")
    │
    ▼
User drops on "progress" column
    │
    ├── Column's onDrop fires → handleDrop("progress")
    │
    ├── Find source column: "todo" (jisme card-1 hai)
    ├── moveCard("card-1", "todo", "progress") called
    │
    ├── Zustand store updates:
    │   ├── past: [snapshot]
    │   ├── future: []
    │   ├── todo.cardIds: filter out card-1
    │   └── progress.cardIds: push card-1
    │
    ├── React re-renders only:
    │   ├── "todo" column (cardIds changed — length update)
    │   └── "progress" column (cardIds changed — new card)
    │   (Other columns stay — Zustand selective subscription)
    │
    └── draggedCardId reset to null
```

## Step 5 — Custom Hook: useBoard

Custom hooks mein wrap karo complex operations ko. Jaise — kisi card ko find karna, ya board statistics calculate karna:

```ts
// hooks/useBoard.ts
import { useBoardStore } from "../stores/boardStore";
import { useMemo } from "react";

export function useBoard() {
  const columns = useBoardStore((s) => s.columns);
  const cards = useBoardStore((s) => s.cards);
  const columnOrder = useBoardStore((s) => s.columnOrder);

  const stats = useMemo(() => {
    const totalCards = Object.keys(cards).length;
    const perColumn = columnOrder.map((colId) => ({
      column: columns[colId].title,
      count: columns[colId].cardIds.length,
    }));
    return { totalCards, perColumn };
  }, [cards, columns, columnOrder]);

  const getCard = (cardId: string) => cards[cardId];

  const getCardsInColumn = (columnId: string) =>
    columns[columnId]?.cardIds
      .map((id) => cards[id])
      .filter(Boolean) ?? [];

  return { stats, getCard, getCardsInColumn };
}
```

**Kya return kar raha hai:**
- `stats` — computed values (memoized — sirf tab change hoga jab cards ya columns change ho)
- `getCard` — O(1) lookup for any card
- `getCardsInColumn` — Get all cards for a column (normalized se denormalized)

## Step 6 — Preferences Store with useLocalStorage

User preferences ke liye alag store — theme, default priority, waghera:

```ts
// stores/prefsStore.ts
import { create } from "zustand";
import { persist } from "zustand/middleware";

interface PrefsStore {
  theme: "light" | "dark";
  defaultPriority: "low" | "medium" | "high";
  setTheme: (theme: "light" | "dark") => void;
  setDefaultPriority: (p: "low" | "medium" | "high") => void;
}

export const usePrefsStore = create<PrefsStore>()(
  persist(
    (set) => ({
      theme: "light",
      defaultPriority: "medium",
      setTheme: (theme) => set({ theme }),
      setDefaultPriority: (priority) => set({ defaultPriority: priority }),
    }),
    { name: "kanban-prefs" }
  )
);
```

## Step 7 — Performance Optimizations (Batch 5 Carry Forward)

### React.memo on Card (Already Done)

GenericCard `memo` mein wrap hai. Jab column ke cards list change hota hai, sirf woh cards re-render hote hain jinka actual data change hua. Baaki cards same rehte hain.

### useCallback for Handlers

Board component mein saare handlers `useCallback` mein wrap hain. Column aur Card components ko stable function references milte hain — React.memo ka shallow comparison kaam karta hai.

### Selective Zustand Subscriptions

Har component sirf utna state subscribe karta hai jitna use karta hai. Ye pattern components ke andar use hota hai — jaise `Column.tsx` mein card count, ya `Card.tsx` ke wrapper mein specific card:

```tsx
// kisi component ke andar (e.g. Column.tsx)
// Sirf count subscribe — card content change pe re-render nahi hoga
const cardCount = useBoardStore((s) => s.columns[colId].cardIds.length);

// Sirf specific card subscribe
const card = useBoardStore((s) => s.cards[cardId]);
```

## Step 8 — AddCardForm

Card add karne ka form. `src/components/` folder mein `AddCardForm.tsx` nayi file banao:

```tsx
// components/AddCardForm.tsx
import { useState, useCallback, type FormEvent } from "react";
import type { Card } from "../types";

interface AddCardFormProps {
  columnId: string;
  onAdd: (columnId: string, card: Card) => void;
}

export function AddCardForm({ columnId, onAdd }: AddCardFormProps) {
  const [isOpen, setIsOpen] = useState(false);

  const handleSubmit = useCallback(
    (e: FormEvent<HTMLFormElement>) => {
      e.preventDefault();
      const form = e.currentTarget;
      const formData = new FormData(form);

      const card: Card = {
        id: `card-${Date.now()}`,
        title: formData.get("title") as string,
        description: formData.get("description") as string,
        assignee: formData.get("assignee") as string,
        priority: (formData.get("priority") as Card["priority"]) || "medium",
      };

      if (!card.title.trim()) return;
      onAdd(columnId, card);
      form.reset();
      setIsOpen(false);
    },
    [columnId, onAdd]
  );

  if (!isOpen) {
    return (
      <button onClick={() => setIsOpen(true)}>+ Add Card</button>
    );
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="title" placeholder="Title" required />
      <textarea name="description" placeholder="Description" />
      <input name="assignee" placeholder="Assignee" />
      <select name="priority" defaultValue="medium">
        <option value="low">Low</option>
        <option value="medium">Medium</option>
        <option value="high">High</option>
      </select>
      <button type="submit">Add</button>
      <button type="button" onClick={() => setIsOpen(false)}>Cancel</button>
    </form>
  );
}
```

**Data flow:**

```
User Action (drag card, click undo, submit form)
    │
    ▼
Zustand Store Action (moveCard, undo, addCard)
    │
    ├── Snapshot → past[]
    ├── State update → new columns/cards
    │
    ▼
Zustand publishes changes
    │
    ├── Column subscribed to columns[colId].cardIds → re-renders
    ├── Card subscribed to cards[cardId] → re-renders if changed
    ├── Other columns/cards → skip (no relevant state change)
    │
    ▼
React.memo blocks unchanged cards → minimal DOM updates
```

**Sample Answer:** Normalized state mein `columns` aur `cards` alag dictionaries hain. Card update karna hai toh seedha `cards[cardId]` access karo — O(1). Card move karna hai toh sirf dono columns ke `cardIds` arrays update. Nested mein card dhundhne ke liye har column ki array traverse karni padti — O(n). 2. Undo/redo implement karne ke liye past/future arrays mein kya store karte ho? Poora state ya sirf changed part?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Poora state snapshot store karte hain (columns, cards, columnOrder). Undo/redo sirf tab kaam karta hai jab snapshot complete ho — partial snapshot se state corrupt ho sakti hai. Lekin poori store nahi — sirf woh parts jo mutations se affect hote hain. Is Kanban mein hum `columns`, `cards`, aur `columnOrder` ka snapshot lete hain. `past` aur `future` arrays ko `persist` middleware ke `partialize` se exclude kiya — undo history sirf session ke liye hai, page refresh pe reset hoti hai. Undo stack bhout bada nahi rakhna chahiye — 50-100 snapshots enough hain.

4. Zoustand ka selective subscription Kanban Board mein kaise performance improve karta hai?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Zustand selective subscription se har component sirf utna state subscribe karta hai jitna use karta hai. Example: `Column` component `s.columns[colId].cardIds` subscribe karta hai — jab kisi card ka content change hota hai (updateCard), lekin cardIds nahi badla, toh Column re-render nahi hota. Sirf woh `Card` component re-render hota hai jiska data change hua. 5. Kanban Board ka architecture teen layers mein divide hai — Store, Hooks, Components. Har layer ka responsibility kya hai? Ek layer doosre se kaise communicate karti hai?

<details>
<summary>Show Answer</summary>

**Sample Answer:** (1) **Store (Zustand)** — state management. Data store karna, mutations handle karna (addCard, moveCard), persistence. State ka "source of truth." Koi UI logic nahi. (2) **Hooks (Custom)** — business logic. Computed values (stats), data composition (getCardsInColumn), complex operations. Store ko wrap karta hai, components ke liye ready-to-use interface provide karta hai. (3) **Components (UI)** — rendering. Store/hooks se data leta hai, user interaction pe store actions call karta hai. Koi state mutation logic nahi. Communication: Component → Store action → State change → Component re-render (via selector). Hooks ek "middle layer" hai jo store ke raw data ko component-friendly format mein convert karta hai.

</details>
