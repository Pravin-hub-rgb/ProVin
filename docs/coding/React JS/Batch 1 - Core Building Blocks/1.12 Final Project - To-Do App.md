## Step 3 — Add Task: Inline Build (Pehla Piece)

Ab task add karne ka logic likhte hain — pehle directly App.tsx mein, baad mein extract karenge.

**Soch:** User input type kare, Add dabaye. To input ki value track karni hai aur Add click par naya task add karna hai.

**handleAdd function:**

```tsx
const handleAdd = (text: string) => {
  const newTask: Task = {
    id: Date.now(),
    text,
    completed: false,
  };
  setTasks([...tasks, newTask]);
  console.log("✅ Task added:", newTask);
  console.log("📋 New tasks:", [...tasks, newTask]);
};
```

`Date.now()` — unique ID generate karne ka simple tareeka. Milliseconds since 1970 — almost guaranteed unique.

**Ab input + button ka JSX daalo — `useState<string>` controlled component pattern:**

```tsx
const [inputText, setInputText] = useState("");

const handleInputChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  setInputText(e.target.value);
};

const handleAddClick = () => {
  if (inputText.trim() === "") {
    console.log("⚠️ Empty input — ignoring");
    return;
  }
  handleAdd(inputText.trim());
  setInputText("");
  console.log("🧹 Input cleared");
};
```

**JSX mein daalo:**

```tsx
return (
  <div>
    <h1>To-Do App</h1>
    <div>
      <input
        type="text"
        value={inputText}
        onChange={handleInputChange}
        placeholder="Enter a task..."
      />
      <button onClick={handleAddClick}>Add</button>
    </div>
  </div>
);
```

## Step 4 — TaskInput Component: Extraction

**Soch:** Input wala code abhi App.tsx mein hai. Lekin yeh ek independent UI piece hai — alag component banta hai.

**Kyun extract?** Readability — App.tsx ka kaam hai orchestrate karna, input logic nahi.

`src/components/TaskInput.tsx`:

```tsx
import { useState } from "react";

interface TaskInputProps {
  onAdd: (text: string) => void;
}

function TaskInput({ onAdd }: TaskInputProps): JSX.Element {
  const [text, setText] = useState("");

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setText(e.target.value);
  };

  const handleClick = () => {
    if (text.trim() !== "") {
      onAdd(text.trim());
      setText("");
      console.log("🧹 TaskInput: cleared after add");
    } else {
      console.log("⚠️ TaskInput: empty submission blocked");
    }
  };

  return (
    <div>
      <input
        type="text"
        value={text}
        onChange={handleChange}
        placeholder="Enter a task..."
      />
      <button onClick={handleClick}>Add</button>
    </div>
  );
}

export default TaskInput;
```

**Ab App.tsx mein import karo aur inline code hatao:**

```tsx
import TaskInput from "./components/TaskInput";

// ... existing code

return (
  <div>
    <h1>To-Do App</h1>
    <TaskInput onAdd={handleAdd} />
  </div>
);
```

## Step 5 — Tasks Render Karna

Abhi tasks add ho rahe hain lekin UI mein dikh nahi rahe. Ab render karte hain.

**Soch:** `tasks` array hai, `.map()` se har task ke liye JSX return karoge.

**Kyun .map()?** Kyonki JSX expressions ke andar for loop nahi likh sakte. `.map()` ek expression hai jo array of JSX return karta hai.

**Pehle inline render in App.tsx — ek simple version:**

```tsx
return (
  <div>
    <h1>To-Do App</h1>
    <TaskInput onAdd={handleAdd} />
    <div>
      {tasks.map((task) => (
        <div key={task.id}>
          <span>{task.text}</span>
        </div>
      ))}
    </div>
    {tasks.length === 0 && <p>No tasks yet. Add one above!</p>}
  </div>
);
```

`key={task.id}` — har task ka unique id. React ko identity chahiye efficient DOM updates ke liye.

`tasks.length === 0 && <p>...</p>` — conditional rendering (&& pattern). Jab list khaali hai tab dikhao.

## Step 6 — Toggle Complete (Checkbox)

**Soch:** Ab har task ke saath checkbox chahiye. Check karne par text cross out ho. Phir se uncheck karne par normal ho.

**Kyun toggle state?** Har task ka `completed` property hai — `false` se `true` aur wapas. Yeh **array update** ka pattern hai — `.map()` se sirf ek item update karo, baaki wahi rahne do.

**Pehle standalone concept — array update with .map():**

```js
const items = [
  { id: 1, name: "Milk", bought: false },
  { id: 2, name: "Eggs", bought: false },
];

const updated = items.map((item) =>
  item.id === 1 ? { ...item, bought: true } : item
);
console.log(updated);
// → [{ id: 1, name: "Milk", bought: true }, { id: 2, name: "Eggs", bought: false }]
```

Sirf wahi item change hua jiska id match kiya. Baaki ka reference same.

**Ab App.tsx mein handleToggle add karo:**

```tsx
const handleToggle = (id: number) => {
  const updated = tasks.map((task) =>
    task.id === id ? { ...task, completed: !task.completed } : task
  );
  console.log("🔄 Toggling task id:", id);
  console.log("📋 Before:", [...tasks]);
  console.log("📋 After:", updated);
  setTasks(updated);
};
```

**Ab render mein checkbox daalo:**

```tsx
{tasks.map((task) => (
  <div key={task.id}>
    <input
      type="checkbox"
      checked={task.completed}
      onChange={() => {
        console.log("☑️ Checkbox clicked for task:", task.id);
        handleToggle(task.id);
      }}
    />
    <span
      style={{
        textDecoration: task.completed ? "line-through" : "none",
        opacity: task.completed ? 0.6 : 1,
        marginLeft: "8px",
      }}
    >
      {task.text}
    </span>
  </div>
))}
```

`checked={task.completed}` — checkbox ka state task ke completed property se controlled hai.

`textDecoration: task.completed ? "line-through" : "none"` — conditional style, ternary operator.

**Test karo:**
1. "Learn React" add karo
2. Checkbox click karo — console mein "☑️ Checkbox clicked" aur "Toggling task id" dikhe
3. Text line-through ho jaye, opacity kam ho
4. Dobara checkbox click karo — wapas normal

## Step 7 — Delete Task

**Soch:** Har task ke saath ek Delete button chahiye jo task hata de.

**Kyun .filter()?** Delete ka matlab hai — original array se woh item hata do jiska id match kare. `.filter()` naya array return karta hai jisme sirf wohi items hain jo condition pass karein.

**Pehle standalone concept — .filter() for removal:**

```js
const items = [
  { id: 1, name: "Milk" },
  { id: 2, name: "Eggs" },
];

const afterDelete = items.filter((item) => item.id !== 1);
console.log(afterDelete);
// → [{ id: 2, name: "Eggs" }]
```

`item.id !== 1` — jiska id 1 hai, usko hata do (filter out). Baaki sab allowed.

**Ab App.tsx mein handleDelete add karo:**

```tsx
const handleDelete = (id: number) => {
  const remaining = tasks.filter((task) => task.id !== id);
  console.log("🗑️ Deleting task id:", id);
  console.log("📋 Before:", [...tasks]);
  console.log("📋 After:", remaining);
  setTasks(remaining);
};
```

**Render mein delete button daalo:**

```tsx
{tasks.map((task) => (
  <div key={task.id}>
    <input
      type="checkbox"
      checked={task.completed}
      onChange={() => handleToggle(task.id)}
    />
    <span
      style={{
        textDecoration: task.completed ? "line-through" : "none",
        opacity: task.completed ? 0.6 : 1,
        marginLeft: "8px",
      }}
    >
      {task.text}
    </span>
    <button
      onClick={() => {
        console.log("🗑️ Delete clicked for task:", task.id);
        handleDelete(task.id);
      }}
      style={{ marginLeft: "12px" }}
    >
      Delete
    </button>
  </div>
))}
```

## Step 9 — Filter (All / Active / Completed)

**Soch:** Abhi saare tasks dikhte hain. User sirf active (incomplete) tasks dekhna chahe ya sirf completed? Filter chahiye.

**Kyun FilterStatus union type?** Filter sirf teen values mein se ek ho sakti hai — `"all"`, `"active"`, `"completed"`. Union type TypeScript enforce karega ki koi aur value set na ho.

**Pehle standalone concept — .filter() with boolean property:**

```js
const tasks = [
  { id: 1, text: "Milk", completed: false },
  { id: 2, text: "Eggs", completed: true },
];

const active = tasks.filter((t) => !t.completed);
console.log(active); // → [{ id: 1, text: "Milk", completed: false }]

const completed = tasks.filter((t) => t.completed);
console.log(completed); // → [{ id: 2, text: "Eggs", completed: true }]
```

**App.tsx mein filter state add karo:**

```tsx
const [filter, setFilter] = useState<FilterStatus>("all");
console.log("🔍 Current filter:", filter);
```

**filteredTasks logic — return se pehle:**

```tsx
const filteredTasks = tasks.filter((task) => {
  if (filter === "active") return !task.completed;
  if (filter === "completed") return task.completed;
  return true; // "all" — saare tasks
});

console.log("🔍 Filtered tasks:", filteredTasks);
```

**Render mein `tasks.map` ki jagah `filteredTasks.map` karo:**

```tsx
{filteredTasks.map((task) => (
  <TaskItem key={task.id} task={task} onToggle={handleToggle} onDelete={handleDelete} />
))}
```

**Ab FilterBar component banate hain:**

`src/components/FilterBar.tsx`:

```tsx
import type { FilterStatus } from "../types";

interface FilterBarProps {
  currentFilter: FilterStatus;
  onFilterChange: (filter: FilterStatus) => void;
}

function FilterBar({ currentFilter, onFilterChange }: FilterBarProps): JSX.Element {
  const filters: FilterStatus[] = ["all", "active", "completed"];

  console.log("🔘 FilterBar rendering, current:", currentFilter);

  return (
    <div>
      {filters.map((filter) => (
        <button
          key={filter}
          onClick={() => {
            console.log("🔘 Filter changed to:", filter);
            onFilterChange(filter);
          }}
          style={{
            fontWeight: currentFilter === filter ? "bold" : "normal",
            marginRight: "8px",
          }}
        >
          {filter.charAt(0).toUpperCase() + filter.slice(1)}
        </button>
      ))}
    </div>
  );
}

export default FilterBar;
```

Naya pattern notice kiya? Button labels hardcode karne ki jagah `.map()` se generate kiye. `filter.charAt(0).toUpperCase() + filter.slice(1)` — pehla letter capital, baaki same. "all" → "All", "active" → "Active", "completed" → "Completed".

**App.tsx mein FilterBar import karo:**

```tsx
import FilterBar from "./components/FilterBar";
import type { Task, FilterStatus } from "./types";
```

**Render mein daalo — TaskInput aur list ke beech mein:**

```tsx
<FilterBar currentFilter={filter} onFilterChange={setFilter} />
```

import type { Task } from "../types";
import TaskItem from "./TaskItem";

interface TaskListProps {
  tasks: Task[];
  onDelete: (id: number) => void;
  onToggle: (id: number) => void;
}

function TaskList({ tasks, onDelete, onToggle }: TaskListProps): JSX.Element {

}

## Complete App.tsx — Assembled View

Ab tak jo App.tsx bana hai, woh yahan assembled form mein hai. Already build kar chuke ho, bas ek saath dekho:

```tsx
import { useState } from "react";
import TaskInput from "./components/TaskInput";
import FilterBar from "./components/FilterBar";
import TaskList from "./components/TaskList";
import type { Task, FilterStatus } from "./types";

function App() {
  const [tasks, setTasks] = useState<Task[]>([]);
  const [filter, setFilter] = useState<FilterStatus>("all");

  console.log("🏠 App re-render. Tasks:", tasks.length, "Filter:", filter);

  const handleAdd = (text: string) => {
    const newTask: Task = { id: Date.now(), text, completed: false };
    setTasks([...tasks, newTask]);
  };

  const handleDelete = (id: number) => {
    setTasks(tasks.filter((task) => task.id !== id));
  };

  const handleToggle = (id: number) => {
    setTasks(
      tasks.map((task) =>
        task.id === id ? { ...task, completed: !task.completed } : task
      )
    );
  };

  const handleClearCompleted = () => {
    setTasks(tasks.filter((task) => !task.completed));
  };

  const filteredTasks = tasks.filter((task) => {
    if (filter === "active") return !task.completed;
    if (filter === "completed") return task.completed;
    return true;
  });

  return (
    <div>
      <h1>To-Do App</h1>
      <TaskInput onAdd={handleAdd} />
      <FilterBar currentFilter={filter} onFilterChange={setFilter} />
      <TaskList
        tasks={filteredTasks}
        onDelete={handleDelete}
        onToggle={handleToggle}
      />
      <div>
        <span>
          {tasks.filter((task) => !task.completed).length} / {tasks.length} items left
        </span>
        <button onClick={handleClearCompleted} style={{ marginLeft: "16px" }}>
          Clear Completed
        </button>
      </div>
    </div>
  );
}

export default App;
```

Har line already likh chuke ho step-by-step. Yeh assembled view hai — production ka waisa hi code.
