## Abhi Tak Kya Hua

1.4 mein component ko alag file mein rakhna seekha — `components/` folder, `export default`, `import` from relative path. Components ka code static tha — hardcoded data. Ab component ko **dynamic** banana hai, uske liye **props** chahiye. Lekin props ke types define karne ke liye pehle **interface** samajhna zaroori hai.

## Broader Goal

Interface ek object ka "shape" define karta hai — ki us object mein kaun-kaun si properties hongi aur unka type kya hoga. Yeh TypeScript ka core concept hai. 1.5.2 mein ise props ke saath use karenge. Pehle pure TypeScript level par interface ko solid karo.

## Step 1 — Problem Feel Karo

Soch: "Ek object bana rahe hoon `{ name: "Vin", age: 25 }`. Kya main ensure kar sakta hoon ki is object mein hamesha `name` (string) aur `age` (number) hi rahe?"

Without TypeScript — koi guarantee nahi. Koi bhi property add/remove/change kar sakta hai. Is problem ka solution TypeScript ka **interface** hai.

## Step 2 — Pehla Interface

**Concept:** Interface define karta hai ki ek object ka **shape** kya hoga.

```ts
interface User {
  name: string;
  age: number;
}

const user: User = { name: "Vin", age: 25 };     // ✅
const bad: User = { name: "Vin" };                 // ❌ 'age' missing
const bad2: User = { name: "Vin", age: "25" };     // ❌ age should be number
```

`interface User { }` ne define kiya — "jo bhi `User` type ka hoga, usme `name: string` aur `age: number` hona chahiye". TypeScript ab enforce karega.

### Interface Ka Naam

- PascalCase — `User`, `Product`, `ProfileCardProps`
- Noun — `User`, `Task`, `Config`
- Props interface ka convention: `ComponentNameProps` — `ProfileCardProps`

## Step 3 — Interface Ko Export/Import Karna

Interface ek type hai — use doosri files mein bhi use kar sakte ho:

`types.ts`:

```ts
export interface User {
  name: string;
  age: number;
}
```

`App.tsx`:

```tsx
import type { User } from "./types";

const user: User = { name: "Vin", age: 25 };
```

`import type` use karo — yeh sirf type import hai, runtime bundle mein nahi aayega.

## Step 4 — Multiple Properties + Nested Objects

Interface mein simple types, arrays, aur nested objects sab aa sakte hain:

```ts
interface Address {
  city: string;
  pincode: number;
}

interface User {
  name: string;
  age: number;
  address: Address;        // nested interface
  skills: string[];        // array of strings
  metadata: Record<string, string>;  // dynamic keys
}
```

## Step 5 — Interface Reuse

Interface ko multiple jagah use kar sakte ho. Isse consistency rehti hai:

```ts
interface User {
  name: string;
  age: number;
}

function greet(user: User) {
  return `Hello, ${user.name}`;
}

function isAdult(user: User) {
  return user.age >= 18;
}
```

## Summary

- `interface` = object ka shape define karna
- Syntax: `interface Name { prop1: type1; prop2: type2 }`
- Type enforce karta hai — wrong property = compile-time error
- PascalCase naming convention (`User`, `Product`)
- `export interface` + `import type` — reuse across files
- Nested interfaces, arrays, complex types — sab support karta hai
- Props interface convention: `ComponentNameProps`

## Agla Step

Interface samajh aa gaya. Ab ise React mein **props** ke saath use karenge — component ko type-safe data pass karna, `interface ComponentProps` pattern, aur component reusability.
