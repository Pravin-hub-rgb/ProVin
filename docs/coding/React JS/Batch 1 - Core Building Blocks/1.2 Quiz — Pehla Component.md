
## MCQ

Q: React component ke do main rules kya hain?
A. Capital letter name aur JSX return — component ke do basic rules hain
B. Small letter name aur string return — component ke rules yahi hote hain
C. Number se shuru naam aur array return — component ka standard tarika
D. Underscore se shuru naam aur number return — component ka convention hai
> A. Component ke do rules hain: (1) naam capital letter se shuru ho — `ProfileCard`, `Button`, `Header`. (2) function JSX return kare. Dono rules follow nahi karoge to React component ko recognize nahi karega.

> B. Capital letter React ko batata hai "yeh mera custom component hai". `div` React ko regular HTML tag lagta hai. `ProfileCard` React ko custom component lagta hai aur ise render karta hai.

## ShortAnswer

Q: React component kya hai? Do main rules examples ke saath explain karo. Component ko kaise use karte hain?

<details>
<summary>Sample Answer</summary>

**Answer:** React component ek JavaScript function hai jo JSX return karta hai. Do strict rules hain:

**Rule 1 — Capital letter name:** Function ka naam capital letter se shuru hona chahiye.
```tsx
// ❌ Galt — lowercase
function profileCard() { return <div>...</div>; }

// ✅ Sahi — capital letter
function ProfileCard() { return <div>...</div>; }
```

**Rule 2 — Returns JSX:** Function ko JSX return karna chahiye jo React render karega.

**Use:** Component ko HTML tag ki tarah use karte hain:
```tsx
<ProfileCard />
<ProfileCard></ProfileCard>
```

Capital letter kyun? React ko distinguish karna hota hai — `div` = HTML tag, `ProfileCard` = custom component.

</details>

Q: Component aur regular function mein 3 main fark kya hain? Compare karo.

<details>
<summary>Sample Answer</summary>

**Answer:** Teen main fark:

**1. Syntax of use:**
- Regular function: `greet("Vin")` — normal function call
- Component: `<Greet name="Vin" />` — JSX tag syntax

**2. Return value:**
- Regular function: Kuch bhi return kar sakta hai — string, number, object, array
- Component: Sirf JSX return karta hai (jo React render karta hai)

**3. Naming convention:**
- Regular function: `greet` (lowercase)
- Component: `Greet` (capital letter)

**Bonus — Re-render:**
- Regular function: Manually call karna padta hai agar dobara chalana hai
- Component: React automatically re-render karta hai jab state ya props change ho

**Analogy:** Component ek special function hai jise React VIP treatment deta hai — special calling syntax, automatic re-render, aur lifecycle management.

</details>
