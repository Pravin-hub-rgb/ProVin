## Abhi Tak Kya Hua

1.8 mein TypeScript Generics clear hua — `useState<T>` ka `T` explicitly dena seekha. Ab arrays ke saath `useState` use karna seekhenge. Ek simple list banayenge jisme items add, display, aur delete kar sakte hain.

## Broader Goal

Ab tak `useState` numbers aur strings ke saath use kiya. Real apps mein arrays aur objects store karte hain. Socho ek grocery list, ek to-do app, ek blog post list — sab arrays hain. Is chapter mein **array state** aur **list rendering** seekhenge.

Kya banayenge? Ek "List App" — jisme:
- Input field mein type karo → Add button dabao → list mein item add ho
- Har item ke saath Delete button ho
- List khali ho toh "No items yet" dikhe

## Step 1 — Array State Declare Karna

**Soch:** "Ek list chahiye jisme items store karun. Multiple strings. Pehle numbers aur strings store kiye — ab array store karna hai."

**Kyun:** Single value (number, string) se kaam nahi chalega. Multiple items chahiye — ek array.

**Concept:** `useState<string[]>([])`

Yeh dekho:
- `useState(...)` — wahi hook hai
- `<string[]>` — generic type. `T` ki jagah `string[]` (array of strings) daala. TypeScript ko bata rahe hain: "Is state mein strings ka array store hoga"
- `[]` — initial value. Empty array. Starting mein list mein kuch nahi hai

> **Yaad rakho:** 1.8 mein seekha tha — `useState([])` likhne se TypeScript infer karega `never[]`. Isliye explicit `<string[]>` dena padta hai.

**Code — pehle sirf state declare karte hain aur console mein dekhte hain:**

```tsx
import { useState } from "react";

function App() {
  const [items, setItems] = useState<string[]>([]);

  console.log("items state:", items); // → []

  return <div>Check console</div>;
}

export default App;
```

**Test:** Browser console mein `items state: []` dikhna chahiye. Empty array confirm ho gaya.

## Step 2 — Pehla Item Add Karna (Spread Operator)

**Soch:** "State declare ho gayi. Ab kuch add karna hai. Jaise `input` state mein `setInput("")` karte the, waise array mein bhi set karunga?"

**Kyun:** Button dabane par ek item add ho. Lekin array ke saath trick hai — direct modify nahi kar sakte.

**Concept — Immutability Rule:**

New coder sochta hai: "Simple hai — `items.push("Milk")` likh doonga."

```tsx
// ❌ Yeh kaam nahi karega — socho kyun?
const handleAdd = () => {
  items.push("Milk");    // Array mein add ho gaya
  setItems(items);       // State set kar diya
};
```

**Kyun nahi karega?** React state ko **reference se compare** karta hai. `items.push("Milk")` ne existing array ko mutate kar diya — wahi array hai, wahi reference hai. `setItems(items)` mein wahi purana reference diya. React sochega: "Yeh toh wahi array hai — kuch change nahi hua. Re-render nahi karna."

**Solution:** Naya array reference banana padega. Spread operator `...` yeh karta hai.

**Concept — Spread Operator:**

```tsx
const original = [1, 2, 3];
const copy = [...original, 4]; // → [1, 2, 3, 4]
```

`...original` ka matlab: "original array ke saare elements lo aur naye array mein copy karo." Phir `, 4` — naya element end mein add karo. Total: ek naya array bana, original unchanged.

**Ab code — handleAdd function:**

```tsx
function App() {
  const [items, setItems] = useState<string[]>([]);
  console.log("Items state:", items); // har render par current state

  const handleAdd = () => {
    const newItem = "Item " + (items.length + 1);
    setItems([...items, newItem]);
  };

  return (
    <div>
      <h1>List App</h1>
      <button onClick={handleAdd}>Add Item</button>
    </div>
  );
}
```

**Test:** Console kholo. Button dabao → `after add: ["Item 1"]`. Dobara dabao → `after add: ["Item 1", "Item 2"]`. Array grow kar raha hai.

## Step 3 — Items Display Karna (.map)

**Soch:** "Items add ho rahe hain state mein. Ab screen pe dikhane hain."

**Kyun:** Manually `items[0]`, `items[1]` likhna possible nahi — pata nahi kitne items honge. Dynamic rendering chahiye.

**Concept — `.map()` method:**

`.map()` ek array method hai. Har element ke liye kuch return karta hai:

```tsx
const names = ["Alice", "Bob", "Charlie"];
names.map((name) => name.toUpperCase());
// → ["ALICE", "BOB", "CHARLIE"]
```

React mein `.map()` ka use JSX return karne ke liye hota hai:

```tsx
{items.map((item, index) => (
  <li key={index}>{item}</li>
))}
```

- `item` — array ka har element
- `index` — 0, 1, 2... position
- `key={index}` — React ko har element ki identity batata hai. Zaroori hai — iske bina React warning dega.

**Ab JSX mein map karo:**

```tsx
return (
  <div>
    <h1>List App</h1>
    <button onClick={handleAdd}>Add Item</button>
    <ul>
      {items.map((item, index) => (
        <li key={index}>{item}</li>
      ))}
    </ul>
  </div>
);
```

**Test:** Button do baar dabaao → screen pe "Item 1" aur "Item 2" dikhe.

## Step 4 — Empty State Dikhana

**Soch:** "List khali hai toh kuch nahi dikhega. User confuse hoga."

**Kyun:** Better UX — user ko batana chahiye ki kya karna hai.

**Concept — Conditional Rendering with `&&`:**

```tsx
{items.length === 0 && <p>No items yet. Click "Add Item" above!</p>}
```

`&&` operator ka kaam: Pehli condition `true` hai toh aage wala JSX render karo. `false` hai toh kuch mat karo.

Jab `items.length === 0` (`true`) → `<p>` render hoga.
Jab koi item add ho gaya (`false`) → `<p>` render nahi hoga.

Socho aise: "Agar list khali hai, tabhi yeh message dikhao."

**Add karo:**

```tsx
return (
  <div>
    <h1>List App</h1>
    <button onClick={handleAdd}>Add Item</button>
    {items.length === 0 && <p>No items yet. Click "Add Item" above!</p>}
    <ul>
      {items.map((item, index) => (
        <li key={index}>{item}</li>
      ))}
    </ul>
  </div>
);
```

**Test:** Page load karo → "No items yet" dikhe. Button dabao → message gayab, item dikhe.

## Step 5 — User Input Se Item Add Karna

**Soch:** "Hardcoded "Item 1", "Item 2" ki jagah user jo chahe woh add kare."

**Kyun:** Real app mein user apna content daalta hai.

**Concept:** Controlled input (1.7 se pata hai) + array state. Input field ka value ek alag `useState("")` mein store karo, Add button par items array mein daal do.

```tsx
function App() {
  const [items, setItems] = useState<string[]>([]);
  const [input, setInput] = useState("");

  const handleAdd = () => {
    if (input.trim() === "") return; // empty input ignore karo
    setItems([...items, input.trim()]);
    setInput(""); // input field clear karo
  };

  return (
    <div>
      <h1>List App</h1>
      <div>
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          placeholder="Enter an item..."
        />
        <button onClick={handleAdd}>Add</button>
      </div>
      {items.length === 0 && <p>No items yet. Add one above!</p>}
      <ul>
        {items.map((item, index) => (
          <li key={index}>{item}</li>
        ))}
      </ul>
    </div>
  );
}
```

**Har line ka matlab:**

- `const [input, setInput] = useState("")` — input field ke text ko track karta hai
- `input.trim()` — leading/trailing spaces hatao. Agar sirf spaces hai toh empty treat karo
- `setItems([...items, input.trim()])` — naya item spread se add karo
- `setInput("")` — add karne ke baad input field clear karo
- `value={input}` — controlled input. Input field ka value state se aata hai

**Test:** Input mein "Milk" type karo → Add dabao → list mein "Milk" dikhe. Input auto-clear ho jaye. "Eggs" add karo → list mein dono dikhe.

## Step 6 — Delete Item (.filter)

**Soch:** "Items add ho rahe hain. Ab delete bhi karna hai."

**Kyun:** User galat item delete kare ya koi item kaam ho jaye toh hata de.

**Concept — `.filter()` method:**

`.filter()` ek array method hai. Condition ke hisaab se naya array banata hai — jo match kare woh naye array mein jaata hai, jo match na kare woh hat jaata hai.

```tsx
const nums = [1, 2, 3, 4, 5];
nums.filter((num) => num > 2); // → [3, 4, 5]
```

Delete ke liye: "Jis index ka item delete karna hai, usko chhod kar baaki sab rakh lo."

```tsx
items.filter((_, i) => i !== index)
```

- `_` — current item (humain item nahi chahiye, sirf index chahiye)
- `i` — index
- `i !== index` — jo index match kare, use hatao (filter out karo)

**Code — Delete button add karo:**

```tsx
const handleDelete = (index: number) => {
  setItems(items.filter((_, i) => i !== index));
};

return (
  <div>
    <h1>List App</h1>
    <div>
      <input
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="Enter an item..."
      />
      <button onClick={handleAdd}>Add</button>
    </div>
    {items.length === 0 && <p>No items yet. Add one above!</p>}
    <ul>
      {items.map((item, index) => (
        <li key={index}>
          {item}
          <button onClick={() => handleDelete(index)}>Delete</button>
        </li>
      ))}
    </ul>
  </div>
);
```

**Test:** "Milk" add karo → "Eggs" add karo → Milk ke Delete dabao → sirf "Eggs" dikhe. Saare delete karo → "No items yet" message dikhe.

## Final Code

```tsx
import { useState } from "react";

export default function App() {
  const [items, setItems] = useState<string[]>([]);
  const [input, setInput] = useState("");

  const handleAdd = () => {
    if (input.trim() === "") return;
    setItems([...items, input.trim()]);
    setInput("");
  };

  const handleDelete = (index: number) => {
    setItems(items.filter((_, i) => i !== index));
  };

  return (
    <div>
      <h1>List App</h1>
      <div>
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          placeholder="Enter an item..."
        />
        <button onClick={handleAdd}>Add</button>
      </div>
      {items.length === 0 ? (
        <p>No items yet. Add one above!</p>
      ) : (
        items.map((item, index) => (
          <div key={index} className="item-row">
            <span>{item}</span>
            <button onClick={() => handleDelete(index)}>Delete</button>
          </div>
        ))
      )}
    </div>
  );
}
```

## Summary

- `useState<string[]>([])` — array store karne ke liye
- **Spread operator** `[...array, newItem]` — naya array reference banata hai (immutability)
- **`.map()`** — har item ke liye JSX render karta hai
- **`key={index}`** — React ko unique identity batata hai
- **`.filter()`** — item delete karne ke liye naya array banata hai
- **Empty state** — `items.length === 0 && ...` / ternary operator
