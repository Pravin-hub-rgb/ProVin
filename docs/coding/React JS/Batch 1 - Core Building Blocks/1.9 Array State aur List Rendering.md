## Where We Left Off

In 1.8, we learned TypeScript generics – the `<T>` type variable. We saw when to use explicit generics (`useState<Item[]>([])`, `useState<string | null>(null)`) versus letting TypeScript infer. Now we'll use `useState` with arrays to build a real list app.

## Broader Goal

So far we've used `useState` with numbers and strings. Real apps store **arrays and objects** in state. Think of a grocery list, a to-do app, a list of blog posts — all arrays. In this chapter, we'll learn **array state** and **list rendering**.

We'll build a "List App" where you can:
- Type in an input field → click Add → item appears in the list
- Each item has a Delete button
- An empty list shows a friendly message

## Step 1 – Declaring Array State

**Think:** "I need to store a list of items. Previously we stored single values (a number, a string). Now I need multiple."

**Why:** A single value can't hold a list. You need an array.

**Concept:** `useState<string[]>([])`

Look at this:
- `useState(...)` – the same hook we know and use
- `<string[]>` – a generic type. `T` is replaced with `string[]` (an array of strings). You're telling TypeScript "this state will store an array of strings"
- `[]` – the initial value. An empty array. The list starts empty.

> **Remember:** From 1.8, `useState([])` makes TypeScript infer `never[]`. That's why we pass `<string[]>` explicitly.

**Code – first just declare the state and check the console:**

```tsx
import { useState } from "react";

function App() {
  const [items, setItems] = useState<string[]>([]);

  console.log("items state:", items); // → []

  return <div>Check console</div>;
}

export default App;
```

**Test:** Open the browser console. You should see `items state: []`. Empty array confirmed.

## Step 2 – Adding the First Item (Spread Operator)

**Think:** "State is declared. Now I need to add something. With simple state, I used `setInput("")`. Can I do the same with arrays?"

**Why:** When a button is clicked, an item should be added to the list. But arrays have a trick – you can't mutate them directly.

**Concept – Immutability Rule:**

A beginner might think: "Easy – just push to the array:"

```tsx
// ❌ This won't work – think about why
const handleAdd = () => {
  items.push("Milk");    // item added to array
  setItems(items);       // state set
};
```

**Why it doesn't work:** React compares state by **reference**. `items.push("Milk")` mutates the existing array – it's the same reference. `setItems(items)` passes the same old reference. React thinks: "same reference – nothing changed. No need to re-render."

**Solution:** Create a new array reference. The **spread operator** `...` does this.

**Concept – Spread Operator:**

```tsx
const original = [1, 2, 3];
const copy = [...original, 4]; // → [1, 2, 3, 4]
```

`...original` means "take all elements from the original array and copy them into a new array." Then `, 4` appends the new element at the end. Total: a brand new array, original untouched.

**Now the `handleAdd` function:**

```tsx
function App() {
  const [items, setItems] = useState<string[]>([]);
  console.log("Items state:", items); // every render logs current state

  const handleAdd = () => {
    const newItem = "Item " + (items.length + 1);
    setItems([...items, newItem]);
  };

  return (
    <div>
      <h1>List App</h1>
      <button onClick={handleAdd}>Add Item</button>
    </div>
  );
}
```

**Test:** Open the console. Click Add Item → `after add: ["Item 1"]`. Click again → `after add: ["Item 1", "Item 2"]`. The array grows.

## Step 3 – Displaying Items (.map)

**Think:** "We can add items to state. But how do we show them on screen?"

**Why:** You can't access `items[0]`, `items[1]` manually – you don't know how many items there are. You need dynamic rendering.

**Concept – `.map()` method:**

`.map()` is an array method. It iterates over each element and returns something for each:

```tsx
const names = ["Alice", "Bob", "Charlie"];
names.map((name) => name.toUpperCase());
// → ["ALICE", "BOB", "CHARLIE"]
```

In React, `.map()` renders JSX for each element:

```tsx
{items.map((item, index) => (
  <li key={index}>{item}</li>
))}
```

- `item` – each element in the array
- `index` – 0, 1, 2 ... the position
- `key={index}` – tells React the unique identity of each element. Required – without it, React warns.

**Now render in JSX:**

```tsx
return (
  <div>
    <h1>List App</h1>
    <button onClick={handleAdd}>Add Item</button>
    <ul>
      {items.map((item, index) => (
        <li key={index}>{item}</li>
      ))}
    </ul>
  </div>
);
```

**Test:** Click the button twice → the screen shows "Item 1" and "Item 2".

## Step 4 – Showing Empty State

**Think:** "When the list is empty, nothing shows. The user might be confused."

**Why:** Better UX – the user should know what to do.

**Concept – Conditional Rendering with `&&` operator:**

```tsx
{items.length === 0 && <p>No items yet. Click "Add Item" above!</p>}
```

The `&&` operator: if the left side is truthy, render the right side. If `items.length === 0` (true), the `<p>` renders. Once an item is added (false), the `<p>` disappears.

Think of it as: "Show the message only when the list is empty."

**Add it:**

```tsx
return (
  <div>
    <h1>List App</h1>
    <button onClick={handleAdd}>Add Item</button>
    {items.length === 0 && <p>No items yet. Click "Add Item" above!</p>}
    <ul>
      {items.map((item, index) => (
        <li key={index}>{item}</li>
      ))}
    </ul>
  </div>
);
```

**Test:** Load the page → "No items yet..." shows. Click Add → the message disappears, the item shows.

## Step 5 – Adding Items from User Input

**Think:** "Instead of hardcoded 'Item 1', 'Item 2', let the user type their own content."

**Why:** Real apps collect user input.

**Concept:** Controlled input (from 1.7) + array state. Store the input text in a separate `useState("")`, and when Add is clicked, push it into the items array.

```tsx
function App() {
  const [items, setItems] = useState<string[]>([]);
  const [input, setInput] = useState("");

  const handleAdd = () => {
    if (input.trim() === "") return; // ignore empty input
    setItems([...items, input.trim()]);
    setInput(""); // clear input after add
  };

  return (
    <div>
      <h1>List App</h1>
      <div>
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          placeholder="Enter an item..."
        />
        <button onClick={handleAdd}>Add</button>
      </div>
      {items.length === 0 && <p>No items yet. Add one above!</p>}
      <ul>
        {items.map((item, index) => (
          <li key={index}>{item}</li>
        ))}
      </ul>
    </div>
  );
}
```

**What each line does:**

- `const [input, setInput] = useState("")` – tracks what the user is typing
- `input.trim()` – strips leading/trailing whitespace. If it's only spaces, treat as empty
- `setItems([...items, input.trim()])` – uses spread to add the new item to a new array
- `setInput("")` – clears input after adding
- `value={input}` – controlled input: the input field's value comes from state

**Test:** Type "Milk" → click Add → "Milk" appears in the list. Input auto-clears. Type "Eggs" → both show up.

## Step 6 – Deleting Items (.filter)

**Think:** "Items are added. Now I need to delete them."

**Why:** Users need to remove items, whether they added them by mistake or the task is done.

**Concept – `.filter()` method:**

`.filter()` is an array method. It creates a new array with only the elements that match a condition:

```tsx
const nums = [1, 2, 3, 4, 5];
nums.filter((num) => num > 2); // → [3, 4, 5]
```

For deletion: "Remove the item at this index, keep everything else."

```tsx
items.filter((_, i) => i !== index)
```

- `_` – the current item itself (we don't need it, just the index)
- `i` – the index
- `i !== index` – keep everything except the one being deleted

**Code – add the delete button:**

```tsx
const handleDelete = (index: number) => {
  setItems(items.filter((_, i) => i !== index));
};

return (
  <div>
    <h1>List App</h1>
    <div>
      <input
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="Enter an item..."
      />
      <button onClick={handleAdd}>Add</button>
    </div>
    {items.length === 0 && <p>No items yet. Add one above!</p>}
    <ul>
      {items.map((item, index) => (
        <li key={index}>
          {item}
          <button onClick={() => handleDelete(index)}>Delete</button>
        </li>
      ))}
    </ul>
  </div>
);
```

**Test:** Add "Milk" and "Eggs". Click Delete on Milk → only "Eggs" remains. Delete everything → "No items yet" message shows.

## Final Code

```tsx
import { useState } from "react";

export default function App() {
  const [items, setItems] = useState<string[]>([]);
  const [input, setInput] = useState("");

  const handleAdd = () => {
    if (input.trim() === "") return;
    setItems([...items, input.trim()]);
    setInput("");
  };

  const handleDelete = (index: number) => {
    setItems(items.filter((_, i) => i !== index));
  };

  return (
    <div>
      <h1>List App</h1>
      <div>
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          placeholder="Enter an item..."
        />
        <button onClick={handleAdd}>Add</button>
      </div>
      {items.length === 0 ? (
        <p>No items yet. Add one above!</p>
      ) : (
        items.map((item, index) => (
          <div key={index} className="item-row">
            <span>{item}</span>
            <button onClick={() => handleDelete(index)}>Delete</button>
          </div>
        ))
      )}
    </div>
  );
}
```

## Summary

- `useState<string[]>([])` – for storing arrays in state
- **Spread operator** `[...array, newItem]` – creates a new array reference (immutability)
- **`.map()`** – renders JSX for each array item
- **`key={index}`** – tells React the unique identity of each element
- **`.filter()`** – creates a new array excluding deleted items
- **Empty state** – `items.length === 0 && ...` or ternary operator
