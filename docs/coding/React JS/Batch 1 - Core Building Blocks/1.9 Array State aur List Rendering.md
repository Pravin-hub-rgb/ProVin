# 1.9 — Array State aur List Rendering

## Abhi Tak Kya Hua

1.7 mein `useState` seekha — counter banaya, controlled input form banaya. 1.8 mein TypeScript Generics ka concept clear hua. Ab arrays ke saath useState use karna seekhenge — list of items ko store karna, display karna, add karna, delete karna.

## Broader Goal

Ab tak `useState` ka use numbers aur strings ke saath kiya. Lekin real apps mein arrays aur objects store karte hain. Is chapter mein **array state** manage karna seekhenge — ek simple list jisme items add, display, aur delete kar sako.

## Step 1 — Array State

Ek simple list banate hain jisme items hain. Initially empty array:

```tsx
import { useState } from "react";

function App() {
  const [items, setItems] = useState<string[]>([]);

  const handleAdd = () => {
    const newItem = "Item " + (items.length + 1);
    setItems([...items, newItem]);
  };

  return (
    <div>
      <h1>List App</h1>
      <button onClick={handleAdd}>Add Item</button>
      <ul>
        {items.map((item, index) => (
          <li key={index}>{item}</li>
        ))}
      </ul>
      {items.length === 0 && <p>No items yet. Click "Add Item" above!</p>}
    </div>
  );
}

export default App;
```

**Key concepts:**

1. `useState<string[]>([])` — state array of strings, initially empty. `<string[]>` generic batata hai ki array mein strings hain.
2. `[...items, newItem]` — spread operator. Purane array ko copy karo aur naya item add karo
3. `{items.map(...)}` — array ke har element ke liye `<li>` render karo
4. `key={index}` — React ko har element ki unique identity batata hai
5. `items.length === 0 && <p>No items yet...</p>` — conditional rendering with `&&` operator

## Step 2 — Immutability Rule

Soch: "Direct push kyun nahi kar sakte? `items.push(newItem)` likhne se kya hoga?"

**Concept:** React mein state ko **directly modify nahi** kar sakte. `items.push(newItem)` se array change ho jayega, lekin React ko pata nahi chalega. React ko naya **array reference** chahiye.

```tsx
// ❌ Galat — React ko pata nahi chalega
items.push(newItem);
setItems(items);

// ✅ Sahi — naya array create karo
setItems([...items, newItem]);
```

Spread operator `...items` original array ke saare elements ko naye array mein copy karta hai. Phir `newItem` end mein add hota hai. Yeh naya array React ko batata hai ki "state change hui hai, re-render karo".

Same for delete:

```tsx
// ❌ Galat
delete items[id];

// ✅ Sahi — filter se naya array banao
setItems(items.filter((_, i) => i !== index));
```

## Step 3 — Add Item With Input

Button se hardcoded items add karne ki jagah, input field se user apna item add kare:

```tsx
function App() {
  const [items, setItems] = useState<string[]>([]);
  const [input, setInput] = useState("");

  const handleAdd = () => {
    if (input.trim() !== "") {
      setItems([...items, input.trim()]);
      setInput("");
    }
  };

  return (
    <div>
      <h1>List App</h1>
      <input
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="Enter an item..."
      />
      <button onClick={handleAdd}>Add</button>
      <ul>
        {items.map((item, index) => (
          <li key={index}>
            {item}
            <button onClick={() => setItems(items.filter((_, i) => i !== index))}>
              Delete
            </button>
          </li>
        ))}
      </ul>
      {items.length === 0 && <p>No items yet. Add one above!</p>}
    </div>
  );
}
```

## Step 4 — Extract ItemList Component

App bada ho raha hai. List rendering ka logic alag component mein nikaalte hain:

`src/components/ItemList.tsx`:

```tsx
interface ItemListProps {
  items: string[];
  onDelete: (index: number) => void;
}

function ItemList({ items, onDelete }: ItemListProps): JSX.Element {
  return (
    <div>
      {items.length === 0 && <p>No items yet. Add one above!</p>}
      <ul>
        {items.map((item, index) => (
          <li key={index}>
            {item}
            <button onClick={() => onDelete(index)}>Delete</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

export default ItemList;
```

`App.tsx` ab cleaner ho gaya:

```tsx
import { useState } from "react";
import ItemList from "./components/ItemList";

function App() {
  const [items, setItems] = useState<string[]>([]);
  const [input, setInput] = useState("");

  const handleAdd = () => {
    if (input.trim() !== "") {
      setItems([...items, input.trim()]);
      setInput("");
    }
  };

  const handleDelete = (index: number) => {
    setItems(items.filter((_, i) => i !== index));
  };

  return (
    <div>
      <h1>List App</h1>
      <input value={input} onChange={(e) => setInput(e.target.value)} placeholder="Enter an item..." />
      <button onClick={handleAdd}>Add</button>
      <ItemList items={items} onDelete={handleDelete} />
    </div>
  );
}

export default App;
```

## Summary

- `useState<string[]>([])` — array state with strings
- State immutability: naya array reference do (`...spread`, `.filter()`)
- `.map()` — array ke har element ke liye JSX render karo
- `key` prop — har list item ke liye zaroori
- Controlled input + array state — add/delete pattern
- Empty state — conditional rendering with `&&`
