# 1.12.6 — Step 6: Search + Category Filter

## Where We Left Off

Favorite toggle works (1.12.5). Now add search and category filter — one piece at a time.

### Step 6.1 — Search by Name Only

**Think:** User types in a search box, list filters to contacts whose name contains the typed text. Only one filter for now.

**State addition:**

```tsx
const [search, setSearch] = useState("");
```

**Filtered contacts (by name only):**

```tsx
const filteredContacts = contacts.filter((contact) => {
  return contact.name.toLowerCase().includes(search.toLowerCase());
});
```

`.includes()` – string method: checks if search text is contained in the name. `.toLowerCase()` makes it case-insensitive.

**Search input (controlled):**

```tsx
<input
  value={search}
  onChange={(e) => setSearch(e.target.value)}
  placeholder="Search by name..."
/>
```

**Console check** – type "mi" → only contacts with "mi" in name show. Clear the box → all return. Empty result → "No contacts found."

### Step 6.2 — Add Category Filter (Keep Search, Combine)

**Think:** Search (6.1) already works. Now add a second, independent filter: category. We don't replace search — we keep it and add category on top. A contact shows only if it passes BOTH.

**State addition (new, alongside `search`):**

```tsx
const [categoryFilter, setCategoryFilter] = useState<CategoryFilter>("all");
```

**Filtered contacts (search AND category — search from 6.1, category new):**

```tsx
const filteredContacts = contacts.filter((contact) => {
  const matchesSearch = contact.name.toLowerCase().includes(search.toLowerCase());
  const matchesCategory = categoryFilter === "all" || contact.category === categoryFilter;
  return matchesSearch && matchesCategory;
});
```

We compute each predicate separately, then combine with `&&`. Search is unchanged from 6.1; category is the new piece.

**Category filter buttons:**

```tsx
<div>
  {(["all", "family", "work", "friend"] as CategoryFilter[]).map((cat) => (
    <button
      key={cat}
      onClick={() => setCategoryFilter(cat)}
      style={{ fontWeight: categoryFilter === cat ? "bold" : "normal" }}
    >
      {cat.charAt(0).toUpperCase() + cat.slice(1)}
    </button>
  ))}
</div>
```

Union type + conditional styling (from 1.10). `cat.charAt(0).toUpperCase() + cat.slice(1)` capitalizes the first letter ("all" → "All").

**Console check** – search "mi" → only matching names. Click "Work" → only work contacts among matches. Combine freely. Both filters are live; neither replaces the other.

### Step 6.3 — Verify the Combination

**Think:** Both filters are now live together. Quick verification that they don't fight each other.

**Render `filteredContacts` (already done in 6.1):**

```tsx
{filteredContacts.length === 0 ? (
  <p>No contacts found.</p>
) : (
  filteredContacts.map((contact) => (
    <div key={contact.id}>
      {/* ... contact card */}
    </div>
  ))
)}
```

**Console check** – type "mi" AND click "Work": only work contacts with "mi" in name. Clear search → all work contacts. Switch category to "All" → all contacts with "mi". Remove both → all contacts. Neither filter replaces the other.
