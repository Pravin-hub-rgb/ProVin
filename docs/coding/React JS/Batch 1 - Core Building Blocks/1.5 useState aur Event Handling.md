# 1.5 — useState aur Event Handling

## Abhi Tak Kya Hua

1.4 mein children prop aur composition pattern seekha — Card aur Container layout components banaye. To-Do app ka basic structure ready hai. Lekin abhi tak koi interactivity nahi hai — sab static hai. Button dabane se kuch nahi hota.

## Broader Goal

React ki sabse important cheez seekhenge — **state**. Jab tak state nahi hogi, app kuch bhi yaad nahi rakh sakti. User ne kitni baar button dabaya? Kaunsa task complete hua? Sab state mein store hota hai.

Counter mini-project banayenge — increment/decrement/reset. Phir event handling ka TypeScript typing dekhenge. Iske baad To-Do app actual kaam karega.

## Step 1 — Problem Feel Karo

Soch: "Button dabane par count badhe. Lekin jab component re-render hota hai, toh variable reset ho jata hai. Count kaise yaad rakhe?"

`App.tsx` mein try karo:

```tsx
function App() {
  let count = 0;

  const handleClick = () => {
    count = count + 1;
    console.log(count); // console mein 1, 2, 3...
  };

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={handleClick}>Increment</button>
    </div>
  );
}
```

Console mein count badhega, lekin screen par `Count: 0` hi dikhega. Kyun?

**Problem:** `let count = 0` ek local variable hai. Jab component re-render hota hai, yeh dobara `0` set ho jata hai. React ko pata nahi chalta ki count change hua hai kyunki yeh React ke tracking system ke bahar hai.

Isliye **state** chahiye — React ko batana padta hai ki "yeh value track karo, jab change ho toh re-render karo".

## Step 2 — useState Hook

**Concept:** `useState` ek React hook hai jo state variable create karta hai. Jab state change hoti hai, component automatically re-render hota hai.

```tsx
import { useState } from "react";

function App() {
  const [count, setCount] = useState<number>(0);
  // count = current value (0)
  // setCount = function jo value change karta hai
  // <number> = TypeScript type (optional — infer ho jata hai)
  // (0) = initial value

  const handleClick = () => {
    setCount(count + 1);
  };

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={handleClick}>Increment</button>
    </div>
  );
}
```

**Breakdown:**

1. `import { useState } from "react"` — React se useState hook import karo
2. `useState<number>(0)` — ek state variable create karo jiska initial value `0` hai aur type `number` hai
3. `const [count, setCount] = useState(0)` — array destructuring. `count` current value hai, `setCount` function hai jo value change karta hai
4. `setCount(count + 1)` — state update karo. React automatically component re-render karega

Browser mein check karo — ab button dabane par count screen par bhi badhega.

## Step 3 — TypeScript Generics in useState

Soch: "`useState<number>(0)` mein `<number>` kyun likha? Kya TypeScript infer nahi kar sakta?"

**Concept — Type Inference:** TypeScript automatically infer kar leta hai type initial value se:

```tsx
const [count, setCount] = useState(0);
// TypeScript infer karta hai → useState<number>
```

Isliye `<number>` explicitly likhna optional hai. Lekin jab initial value nahi dete ya complex type hota hai, tab explicit type dena padta hai:

```tsx
const [user, setUser] = useState<User | null>(null);
// null initial value — TypeScript infer nahi kar sakta ki User type hoga
```

Abhi ke liye `<number>` explicit rakhdo — practice ke liye. Baad mein inference par bharosa karoge.

## Step 4 — Counter Mini-Project

Soch: "Ek proper Counter banate hain — increment, decrement, reset, aur negative value rokna."

`src/components/Counter.tsx`:

```tsx
import { useState } from "react";

function Counter(): JSX.Element {
  const [count, setCount] = useState<number>(0);

  const increment = () => {
    setCount(count + 1);
  };

  const decrement = () => {
    if (count > 0) {
      setCount(count - 1);
    }
  };

  const reset = () => {
    setCount(0);
  };

  return (
    <div>
      <h2>Counter: {count}</h2>
      <button onClick={increment}>+1</button>
      <button onClick={decrement}>-1</button>
      <button onClick={reset}>Reset</button>
    </div>
  );
}

export default Counter;
```

`App.tsx` mein import karo:

```tsx
import Counter from "./components/Counter";

function App() {
  return (
    <div>
      <h1>Mini Projects</h1>
      <Counter />
    </div>
  );
}
```

**Event handling breakdown:**

`onClick={increment}` — `onClick` ek prop hai jo function leta hai. Jab button click hota hai, React yeh function call karta hai. 

Agar aise likho:

```tsx
<button onClick={setCount(count + 1)}>+1</button> // ❌ Galat
```

Yeh function call kar dega immediately, click par nahi. Hamesha function reference do, call nahi:

```tsx
<button onClick={() => setCount(count + 1)}>+1</button> // ✅ Sahi
```

## Step 5 — Event TypeScript Typing

Soch: "Button click toh theek hai. Lekin input field mein user type kare toh kaise handle karein? Aur TypeScript mein event ka type kya hota hai?"

`Counter` ke neeche ek input field daalte hain jo count set kare:

```tsx
import { useState } from "react";

function Counter(): JSX.Element {
  const [count, setCount] = useState<number>(0);
  const [inputValue, setInputValue] = useState<string>("");

  const handleInputChange = (event: React.ChangeEvent<HTMLInputElement>) => {
    setInputValue(event.target.value);
  };

  const setFromInput = () => {
    const num = parseInt(inputValue, 10);
    if (!isNaN(num)) {
      setCount(num);
      setInputValue("");
    }
  };

  return (
    <div>
      <h2>Counter: {count}</h2>
      <button onClick={() => setCount(count + 1)}>+1</button>
      <button onClick={() => setCount(count > 0 ? count - 1 : 0)}>-1</button>
      <button onClick={() => setCount(0)}>Reset</button>
      <div>
        <input
          type="number"
          value={inputValue}
          onChange={handleInputChange}
          placeholder="Set count..."
        />
        <button onClick={setFromInput}>Set</button>
      </div>
    </div>
  );
}
```

**Event types in React:**

| Event | TypeScript Type |
|---|---|
| Input change | `React.ChangeEvent<HTMLInputElement>` |
| Button click | `React.MouseEvent<HTMLButtonElement>` |
| Form submit | `React.FormEvent<HTMLFormElement>` |
| Key press | `React.KeyboardEvent<HTMLInputElement>` |

React ke saare event types `React` namespace mein hain. `<HTMLInputElement>` wala generic part batata hai ki kaunsa DOM element event trigger kar raha hai.

**`onChange` vs `onInput`:** React mein `onChange` HTML ke `onInput` ki tarah behave karta hai — har character change par trigger hota hai. 0.6 (Synthetic Events) mein padha tha.

## Step 6 — To-Do App Mein State Add Karna

Soch: "Counter ban gaya. Ab To-Do app mein state add karte hain — task list store karein aur user ka input handle karein."

`src/components/TaskInput.tsx` ko actual kaam karne layak banao:

```tsx
import { useState } from "react";

interface TaskInputProps {
  onAdd: (text: string) => void;
}

function TaskInput({ onAdd }: TaskInputProps): JSX.Element {
  const [text, setText] = useState<string>("");

  const handleChange = (event: React.ChangeEvent<HTMLInputElement>) => {
    setText(event.target.value);
  };

  const handleAdd = () => {
    if (text.trim() !== "") {
      onAdd(text);
      setText("");
    }
  };

  return (
    <div>
      <input
        type="text"
        value={text}
        onChange={handleChange}
        placeholder="Enter a task..."
      />
      <button onClick={handleAdd}>Add</button>
    </div>
  );
}

export default TaskInput;
```

**Important concepts:**

1. **Controlled input:** `value={text}` + `onChange={handleChange}` — input ki value state mein store hai. User type karta hai → `onChange` trigger → `setText` state update → React re-render → input updated. Isse **controlled component** kehte hain.

2. **`text.trim() !== ""`** — empty task add nahi hone dena. Trim whitespace remove karta hai.

3. **`setText("")` add ke baad** — input clear karo taaki user next task type kar sake.

## Step 7 — TypeScript Inference Advantage

Soch: "`useState<string>("")` mein `<string>` likhna zaroori hai?"

Try karo — `useState("")` likho. TypeScript infer karega ki type `string` hai. Kyunki initial value `""` (empty string) hai.

```tsx
const [text, setText] = useState(""); // TypeScript infer → string
```

Same for counter:
```tsx
const [count, setCount] = useState(0); // TypeScript infer → number
```

Lekin kya hoga agar type complex ho?

```tsx
const [tasks, setTasks] = useState([]); // TypeScript infer → never[]
```

Empty array se TypeScript type infer nahi kar sakta. Isliye explicit type dena padega:

```tsx
const [tasks, setTasks] = useState<Task[]>([]);
```

1.8 mein yeh detail mein dekhenge jab Task type define karenge.

## Summary

- `useState` — state variable create karta hai, change par re-render trigger karta hai
- Syntax: `const [state, setState] = useState<Type>(initialValue)`
- Array destructuring — `state` (current value), `setState` (update function)
- Event types: `React.ChangeEvent<HTMLInputElement>`, `React.MouseEvent<HTMLButtonElement>`
- Controlled input: `value` + `onChange` — React state se input controlled hota hai
- Type inference: TypeScript initial value se type infer kar leta hai (mostly)
