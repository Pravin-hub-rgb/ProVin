# 1.12 — Final Project: Contact Book (Overview)

## Where We Left Off

We've covered all the concepts in Batch 1 — components, props, state with `useState` and generics, events with `ChangeEvent`/`MouseEvent`, conditional rendering (ternary, `&&`), lists and keys (`.map()` with `key`), TypeScript types (interfaces, union types, `import type`), generics, and composition (children, Container). Eleven docs, eleven concepts.

Now we'll build a **final project** that uses everything together — a complete **Contact Book** (address book). This time, we build from scratch, **one piece at a time**, like a real project develops. No pre-built code, no boilerplate.

## Broader Goal

In this project we'll build a **complete Contact Book from scratch** — add contacts (name, phone, optional email, category), search by name, filter by category, mark favorites, delete, and show a count. All written by hand.

At the end, there's a working app that demonstrates every concept from Batch 1. But we don't start with the full app — we start with just state and a single contact addition, then gradually expand into multiple components.

The project is split into one file per step so you can follow along without scrolling one giant document:
