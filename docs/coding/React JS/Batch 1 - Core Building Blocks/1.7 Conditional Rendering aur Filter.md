# 1.7 — Conditional Rendering aur Filter

## Abhi Tak Kya Hua

1.6 mein To-Do app ka working version banaya — tasks add, display, delete ho rahe hain. State management samajh aa gayi. Lekin ek problem hai — tasks ko complete mark nahi kar sakte, aur koi filter nahi hai (All / Active / Completed).

## Broader Goal

React mein **conditional rendering** seekhenge — components ko conditions ke basis par show/hide karna. Toggle complete status implement karenge, aur filter buttons add karenge. Yeh real apps mein har jagah use hota hai — loading states, empty states, error states, sab conditional rendering hai.

## Step 1 — Task Type Mein completed Add Karo

Soch: "Task ke paas abhi sirf `id` aur `text` hai. Complete status track karne ke liye `completed` property chahiye."

`src/types.ts`:

```ts
export interface Task {
  id: number;
  text: string;
  completed: boolean;
}
```

Ab `App.tsx` mein `handleAdd` ko update karo — naye task ka `completed: false` set karo:

```tsx
const handleAdd = (text: string) => {
  const newTask: Task = {
    id: Date.now(),
    text,
    completed: false,
  };
  setTasks([...tasks, newTask]);
};
```

## Step 2 — Toggle Complete — Conditional Rendering Ka Pehla Use Case

Soch: "User task par click kare toh complete/uncomplete toggle ho. Lekin condition ke basis par different UI dikhana hai."

**Concept — Conditional rendering:** JSX ke andar conditions laga sakte ho:

1. **Ternary operator:** `completed ? <s>text</s> : <span>text</span>`
2. **&& operator:** `completed && <span>✓ Done</span>`
3. **if-else:** function ke andar if-else se different JSX return karo

`App.tsx` mein `handleToggle` add karo:

```tsx
const handleToggle = (id: number) => {
  setTasks(
    tasks.map((task) =>
      task.id === id ? { ...task, completed: !task.completed } : task
    )
  );
};
```

**`handleToggle` breakdown:**
- `.map()` har task par loop karega
- Agar `task.id === id`, toh naya object banao with `completed` flipped
- Nahi toh wahi task return karo (unchanged)
- Purane array ko mutate nahi kiya — naya array reference diya

`TaskList.tsx` mein toggle implement karo:

```tsx
import type { Task } from "../types";

interface TaskListProps {
  tasks: Task[];
  onDelete: (id: number) => void;
  onToggle: (id: number) => void;
}

function TaskList({ tasks, onDelete, onToggle }: TaskListProps): JSX.Element {
  return (
    <div>
      {tasks.map((task) => (
        <div key={task.id}>
          <input
            type="checkbox"
            checked={task.completed}
            onChange={() => onToggle(task.id)}
          />
          <span
            style={{
              textDecoration: task.completed ? "line-through" : "none",
              opacity: task.completed ? 0.6 : 1,
            }}
          >
            {task.text}
          </span>
          <button onClick={() => onDelete(task.id)}>Delete</button>
        </div>
      ))}
      {tasks.length === 0 && <p>No tasks yet. Add one above!</p>}
    </div>
  );
}

export default TaskList;
```

**Conditional rendering examples in this code:**

1. `checked={task.completed}` — checkbox ka state condition se set hota hai
2. `textDecoration: task.completed ? "line-through" : "none"` — ternary operator se style change
3. `opacity: task.completed ? 0.6 : 1` — completed tasks ko faded dikhana
4. `tasks.length === 0 && <p>No tasks...</p>` — && operator se empty state

`App.tsx` mein `handleToggle` pass karo:

```tsx
<TaskList tasks={tasks} onDelete={handleDelete} onToggle={handleToggle} />
```

Test karo — checkbox click karne par text line-through ho jana chahiye aur opacity kam ho jani chahiye.

## Step 3 — Filter Buttons — Teen Conditions

Soch: "Saare tasks dikh rahe hain. User sirf active ya sirf completed tasks dekhna chahe toh?"

Filter ke liye teen states chahiye:
- `all` — saare tasks
- `active` — sirf incomplete tasks
- `completed` — sirf complete tasks

**Union type use karenge:**

`src/App.tsx` mein filter state add karo:

```tsx
type FilterStatus = "all" | "active" | "completed";

function App() {
  const [tasks, setTasks] = useState<Task[]>([]);
  const [filter, setFilter] = useState<FilterStatus>("all");
  // ...
}
```

`FilterStatus` ek **union type** hai — teen possible values mein se ek. TypeScript ensure karega ki sirf yahi teen values use ho.

Filter logic:

```tsx
const filteredTasks = tasks.filter((task) => {
  if (filter === "active") return !task.completed;
  if (filter === "completed") return task.completed;
  return true; // "all" — saare tasks
});
```

## Step 4 — Filter Component

`src/components/FilterBar.tsx`:

```tsx
type FilterStatus = "all" | "active" | "completed";

interface FilterBarProps {
  currentFilter: FilterStatus;
  onFilterChange: (filter: FilterStatus) => void;
}

function FilterBar({ currentFilter, onFilterChange }: FilterBarProps): JSX.Element {
  return (
    <div>
      <button
        onClick={() => onFilterChange("all")}
        style={{ fontWeight: currentFilter === "all" ? "bold" : "normal" }}
      >
        All
      </button>
      <button
        onClick={() => onFilterChange("active")}
        style={{ fontWeight: currentFilter === "active" ? "bold" : "normal" }}
      >
        Active
      </button>
      <button
        onClick={() => onFilterChange("completed")}
        style={{ fontWeight: currentFilter === "completed" ? "bold" : "normal" }}
      >
        Completed
      </button>
    </div>
  );
}

export default FilterBar;
```

**Style conditional rendering:** `fontWeight` condition ke basis par bold ho raha hai — jo filter active hai woh bold dikhega.

`App.tsx` mein integrate karo:

```tsx
import { useState } from "react";
import Container from "./components/Container";
import TaskInput from "./components/TaskInput";
import TaskList from "./components/TaskList";
import FilterBar from "./components/FilterBar";
import type { Task } from "./types";

type FilterStatus = "all" | "active" | "completed";

function App() {
  const [tasks, setTasks] = useState<Task[]>([]);
  const [filter, setFilter] = useState<FilterStatus>("all");

  const handleAdd = (text: string) => {
    const newTask: Task = { id: Date.now(), text, completed: false };
    setTasks([...tasks, newTask]);
  };

  const handleDelete = (id: number) => {
    setTasks(tasks.filter((task) => task.id !== id));
  };

  const handleToggle = (id: number) => {
    setTasks(
      tasks.map((task) =>
        task.id === id ? { ...task, completed: !task.completed } : task
      )
    );
  };

  const filteredTasks = tasks.filter((task) => {
    if (filter === "active") return !task.completed;
    if (filter === "completed") return task.completed;
    return true;
  });

  return (
    <Container>
      <h1>To-Do App</h1>
      <TaskInput onAdd={handleAdd} />
      <FilterBar currentFilter={filter} onFilterChange={setFilter} />
      <TaskList tasks={filteredTasks} onDelete={handleDelete} onToggle={handleToggle} />
    </Container>
  );
}

export default App;
```

Test karo:
1. Kuch tasks add karo, kuch complete mark karo
2. "Active" filter dabao — sirf incomplete tasks dikhne chahiye
3. "Completed" filter dabao — sirf completed tasks
4. "All" — saare wapas

## Step 6 — Task Count (Extra Conditional Rendering)

Soch: "Kitne tasks active hain yeh dikhana hai — `3 items left` type."

`App.tsx` mein `return` ke andar `TaskList` ke neeche:

```tsx
<p>
  {tasks.filter((task) => !task.completed).length} items left
</p>
```

Conditional rendering ka ek aur use case:

```tsx
{
  tasks.length > 0 && (
    <p>
      {tasks.filter((task) => !task.completed).length} / {tasks.length} tasks remaining
    </p>
  );
}
```

Agar koi task nahi hai toh kuch mat dikhao. Agar hai toh "3 / 5 tasks remaining" dikhao.

## Summary

- Conditional rendering: `&&`, ternary `? :`, if-else
- Union types: `type FilterStatus = "all" | "active" | "completed"`
- `.filter()` — array ko condition ke basis par filter karo
- `.map()` with condition — specific items ka different UI
- Inline styles `style={{ }}` with conditional values
- Common types ko share karo — type duplication avoid karo
