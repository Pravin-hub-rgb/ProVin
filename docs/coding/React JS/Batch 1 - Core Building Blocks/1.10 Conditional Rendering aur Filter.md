# 1.10 — Conditional Rendering aur Filter

## Abhi Tak Kya Hua

1.9 mein array state aur list rendering seekhi — items add, display, delete ho rahe hain. Lekin abhi tak conditional rendering nahi seekhi — items ko conditions ke basis par show/hide karna.

## Broader Goal

React mein **conditional rendering** seekhenge — components ko conditions ke basis par show/hide karna. Toggle flag implement karenge, aur filter buttons add karenge. Yeh real apps mein har jagah use hota hai — loading states, empty states, error states, sab conditional rendering hai.

## Step 1 — Item Type Mein flag Add Karo

Soch: "Item ke paas abhi sirf `id` aur `text` hai. Flag status track karne ke liye `flagged` property chahiye."

`src/types.ts`:

```ts
export interface Item {
  id: number;
  text: string;
  flagged: boolean;
}
```

Ab `App.tsx` mein `handleAdd` ko update karo — naye item ka `flagged: false` set karo:

```tsx
const handleAdd = (text: string) => {
  const newItem: Item = {
    id: Date.now(),
    text,
    flagged: false,
  };
  setItems([...items, newItem]);
};
```

## Step 2 — Toggle Flag — Conditional Rendering Ka Pehla Use Case

Soch: "User item par click kare toh flag/unflag toggle ho. Lekin condition ke basis par different UI dikhana hai."

**Concept — Conditional rendering:** JSX ke andar conditions laga sakte ho:

1. **Ternary operator:** `flagged ? <strong>text</strong> : <span>text</span>`
2. **&& operator:** `flagged && <span>⭐</span>`
3. **if-else:** function ke andar if-else se different JSX return karo

`App.tsx` mein `handleToggleFlag` add karo:

```tsx
const handleToggleFlag = (id: number) => {
  setItems(
    items.map((item) =>
      item.id === id ? { ...item, flagged: !item.flagged } : item
    )
  );
};
```

**`handleToggleFlag` breakdown:**
- `.map()` har item par loop karega
- Agar `item.id === id`, toh naya object banao with `flagged` flipped
- Nahi toh wahi item return karo (unchanged)
- Purane array ko mutate nahi kiya — naya array reference diya

`ItemList.tsx` mein flag toggle implement karo:

```tsx
import type { Item } from "../types";

interface ItemListProps {
  items: Item[];
  onDelete: (id: number) => void;
  onToggleFlag: (id: number) => void;
}

function ItemList({ items, onDelete, onToggleFlag }: ItemListProps): JSX.Element {
  return (
    <div>
      {items.map((item) => (
        <div key={item.id}>
          <button
            onClick={() => onToggleFlag(item.id)}
            style={{
              background: item.flagged ? "#ffd700" : "#eee",
              border: "1px solid #ccc",
              borderRadius: "4px",
              cursor: "pointer",
              padding: "2px 8px",
              marginRight: "8px",
            }}
          >
            {item.flagged ? "★" : "☆"}
          </button>
          <span
            style={{
              fontWeight: item.flagged ? "bold" : "normal",
            }}
          >
            {item.text}
          </span>
          <button onClick={() => onDelete(item.id)}>Delete</button>
        </div>
      ))}
      {items.length === 0 && <p>No items yet. Add one above!</p>}
    </div>
  );
}

export default ItemList;
```

**Conditional rendering examples in this code:**

1. `item.flagged ? "★" : "☆"` — ternary operator se icon change
2. `background: item.flagged ? "#ffd700" : "#eee"` — ternary operator se style change
3. `fontWeight: item.flagged ? "bold" : "normal"` — flagged items ko bold dikhana
4. `items.length === 0 && <p>No items...</p>` — && operator se empty state

`App.tsx` mein `handleToggleFlag` pass karo:

```tsx
<ItemList items={items} onDelete={handleDelete} onToggleFlag={handleToggleFlag} />
```

Test karo — button click karne par star icon toggle hona chahiye aur text bold ho jana chahiye.

## Step 3 — Filter Buttons — Teen Conditions

Soch: "Saare items dikh rahe hain. User sirf flagged ya unflagged items dekhna chahe toh?"

Filter ke liye teen states chahiye:
- `all` — saare items
- `flagged` — sirf flagged items
- `unflagged` — sirf unflagged items

**Union type use karenge:**

`src/App.tsx` mein filter state add karo:

```tsx
type FilterStatus = "all" | "flagged" | "unflagged";

function App() {
  const [items, setItems] = useState<Item[]>([]);
  const [filter, setFilter] = useState<FilterStatus>("all");
  // ...
}
```

`FilterStatus` ek **union type** hai — teen possible values mein se ek. TypeScript ensure karega ki sirf yahi teen values use ho.

Filter logic:

```tsx
const filteredItems = items.filter((item) => {
  if (filter === "flagged") return item.flagged;
  if (filter === "unflagged") return !item.flagged;
  return true; // "all" — saare items
});
```

## Step 4 — Filter Component

`src/components/FilterBar.tsx`:

```tsx
type FilterStatus = "all" | "flagged" | "unflagged";

interface FilterBarProps {
  currentFilter: FilterStatus;
  onFilterChange: (filter: FilterStatus) => void;
}

function FilterBar({ currentFilter, onFilterChange }: FilterBarProps): JSX.Element {
  return (
    <div>
      <button
        onClick={() => onFilterChange("all")}
        style={{ fontWeight: currentFilter === "all" ? "bold" : "normal" }}
      >
        All
      </button>
      <button
        onClick={() => onFilterChange("flagged")}
        style={{ fontWeight: currentFilter === "flagged" ? "bold" : "normal" }}
      >
        Flagged
      </button>
      <button
        onClick={() => onFilterChange("unflagged")}
        style={{ fontWeight: currentFilter === "unflagged" ? "bold" : "normal" }}
      >
        Unflagged
      </button>
    </div>
  );
}

export default FilterBar;
```

**Style conditional rendering:** `fontWeight` condition ke basis par bold ho raha hai — jo filter active hai woh bold dikhega.

`App.tsx` mein integrate karo:

```tsx
import { useState } from "react";
import Container from "./components/Container";
import ItemInput from "./components/ItemInput";
import ItemList from "./components/ItemList";
import FilterBar from "./components/FilterBar";
import type { Item } from "./types";

type FilterStatus = "all" | "flagged" | "unflagged";

function App() {
  const [items, setItems] = useState<Item[]>([]);
  const [filter, setFilter] = useState<FilterStatus>("all");

  const handleAdd = (text: string) => {
    const newItem: Item = { id: Date.now(), text, flagged: false };
    setItems([...items, newItem]);
  };

  const handleDelete = (id: number) => {
    setItems(items.filter((item) => item.id !== id));
  };

  const handleToggleFlag = (id: number) => {
    setItems(
      items.map((item) =>
        item.id === id ? { ...item, flagged: !item.flagged } : item
      )
    );
  };

  const filteredItems = items.filter((item) => {
    if (filter === "flagged") return item.flagged;
    if (filter === "unflagged") return !item.flagged;
    return true;
  });

  return (
    <Container>
      <h1>Flagged Items</h1>
      <ItemInput onAdd={handleAdd} />
      <FilterBar currentFilter={filter} onFilterChange={setFilter} />
      <ItemList items={filteredItems} onDelete={handleDelete} onToggleFlag={handleToggleFlag} />
    </Container>
  );
}

export default App;
```

Test karo:
1. Kuch items add karo, kuch flag mark karo (star icon click)
2. "Flagged" filter dabao — sirf flagged items dikhne chahiye
3. "Unflagged" filter dabao — sirf unflagged items
4. "All" — saare wapas


## Step 6 — Item Count (Extra Conditional Rendering)

Soch: "Kitne items flagged hain yeh dikhana hai."

`App.tsx` mein `return` ke andar `ItemList` ke neeche:

```tsx
<p>
  Flagged: {items.filter((item) => item.flagged).length} / {items.length} items
</p>
```

Conditional rendering ka ek aur use case — sirf tab dikhao jab items hoon:

```tsx
{
  items.length > 0 && (
    <p>
      Flagged: {items.filter((item) => item.flagged).length} / {items.length} items
    </p>
  );
}
```

Agar koi item nahi hai toh kuch mat dikhao. Agar hai toh "Flagged: 3 / 5 items" dikhao.

## Summary

- Conditional rendering: `&&`, ternary `? :`, if-else
- Union types: `type FilterStatus = "all" | "flagged" | "unflagged"`
- `.filter()` — array ko condition ke basis par filter karo
- `.map()` with condition — specific items ka different UI
- Inline styles `style={{ }}` with conditional values
- Common types ko share karo — type duplication avoid karo
