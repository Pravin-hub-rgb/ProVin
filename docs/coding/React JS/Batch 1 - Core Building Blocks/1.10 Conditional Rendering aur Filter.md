## Abhi Tak Kya Hua

1.9 mein array state seekhi — `useState<string[]>([])` se items store kiye, spread operator se add kiye, `.filter()` se delete kiye, `.map()` se render kiye. Ek baat aur thi — `items.length === 0 && <p>...</p>` se empty state dikhayi. Yeh **conditional rendering** ka pehla jhalak tha. Ab isko detail mein explore karenge.

## Broader Goal

Hum ek **Flagged Items** app banayenge — 1.9 wala todo app, lekin ab strings ki jagah objects hain. Har item ke saath ek **flag** (star) toggle kar sakte hain. Phir **filter buttons** se sirf flagged ya unflagged items dekh sakte hain. Saath mein **item count** bhi dikhayenge.

Yeh sab karte hue yeh concepts seekhenge:
- **Ternary operator `? :`** aur **`&&`** — JSX mein conditional rendering
- **`.map()` with condition** — specific item update karna
- **Union types** — `"all" | "flagged" | "unflagged"`
- **`.filter()` with property** — objects ki property check karna

## Step 1 — Scaffold: Full App

Naya App.tsx banate hain — ab strings ki jagah `Item` objects use karenge. 1.9 jaisa hi pattern hai, bas ab object version hai.

**src/types.ts** file banao:

```ts
export interface Item {
  id: number;
  text: string;
  flagged: boolean;
}
```

**App.tsx** — puora code. Yeh 1.9 ki tarah kaam karta hai, bas strings ki jagah `Item` objects:

```tsx
import { useState } from "react";
import type { Item } from "./types";

export default function App() {
  const [items, setItems] = useState<Item[]>([]);
  const [input, setInput] = useState("");

  console.log("Items:", items);

  const handleAdd = () => {
    if (input.trim() === "") return;
    const newItem: Item = {
      id: Date.now(),
      text: input.trim(),
      flagged: false,
    };
    setItems([...items, newItem]);
    setInput("");
  };

  const handleDelete = (id: number) => {
    setItems(items.filter((item) => item.id !== id));
  };

  return (
    <div>
      <h1>Flagged Items</h1>
      <div>
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          placeholder="Add item..."
        />
        <button onClick={handleAdd}>Add</button>
      </div>
      <div>
        {items.length === 0 ? (
          <p>No items yet. Add one above!</p>
        ) : (
          items.map((item) => (
            <div key={item.id}>
              <span>{item.text}</span>
              <button onClick={() => handleDelete(item.id)}>Delete</button>
            </div>
          ))
        )}
      </div>
    </div>
  );
}
```

**Test karo** — items add aur delete ho rahe hain. Ab is app mein conditional rendering add karenge — toggle flag, filter buttons, item count.

## Step 2 — Toggle Flag (Array Update With .map() + Condition)

**Soch:** "User kisi item ka star click kare toh flag toggle ho — `flagged: true` ho ya `false`."

**Problem:** 1.9 mein delete karte the `.filter()` se — poori item hata dete the. Ab humein item ko **update** karna hai, delete nahi. Direct push karte hain?

```tsx
// ❌ Socho — yeh kaam karega?
items[0].flagged = true;
setItems(items);
```

Nahi karega. Same array reference — React ignore karega. Immutability rule: naya array banao.

**Concept — `.map()` with condition (standalone):**

`.map()` har element par loop karta hai aur kuch return karta hai. Condition laga sakte ho — kuch elements ko change karo, baaki wahi rahne do:

```tsx
const nums = [1, 2, 3, 4, 5];

const result = nums.map((n) => {
  if (n > 2) return n * 10;  // condition match → change
  return n;                    // otherwise → unchanged
});

console.log(result); // → [1, 2, 30, 40, 50]
```

Sirf wahi elements change hue jo condition (`n > 2`) match kare.

**Ab is concept ko app mein lagao — handleToggleFlag:**

```tsx
const handleToggleFlag = (id: number) => {
  setItems(
    items.map((item) => {
      if (item.id === id) {
        return { ...item, flagged: !item.flagged };
      }
      return item;
    })
  );
};
```

`...item` ka matlab: item ki saari existing properties copy karo, sirf `flagged` ko flip kar do.

**console.log se verify:**

```tsx
const handleToggleFlag = (id: number) => {
  const updated = items.map((item) => {
    if (item.id === id) return { ...item, flagged: !item.flagged };
    return item;
  });
  console.log("After toggle:", updated);
  setItems(updated);
};
```

Add karo "Milk". Console se uska `id` copy karo. Call karo `handleToggleFlag(thatId)`. Console mein dekho — sirf us item ka flagged `false` → `true` hua.

## Step 3 — Conditional Rendering Concepts (Ternary + &&)

**Soch:** "Toggle logic ready hai. Ab UI mein condition ke basis par different dikhana hai. Flagged item ka star yellow, text bold. Non-flagged ka grey star, normal text."

**Kyun:** Wahi button ya text different render karna hai — yeh conditional rendering ka core use case hai.

Standalone examples dekho pehle.

**Concept — Ternary Operator `? :`:**

```js
const age = 20;
const label = age >= 18 ? "Adult" : "Minor";
console.log(label); // → "Adult"
```

Pattern: `condition ? valueIfTrue : valueIfFalse`

React JSX mein:

```tsx
const isMorning = true;
return <p>{isMorning ? "🌅" : "🌙"}</p>;
```

Yeh ternary **inline** JSX expression hai — `{}` ke andar directly use kar sakte ho.

**Concept — `&&` Operator:**

```js
const isLoggedIn = true;
isLoggedIn && console.log("Welcome!");
// → "Welcome!"
```

`&&` ka kaam: pahli value truthy hai toh aage badho, falsy hai toh ruk jao.

React mein — "sirf tab dikhao jab condition true ho":

```tsx
const hasNotification = true;
return <div>{hasNotification && <span>🔔</span>}</div>;
```

Dono concepts React mein har jagah dikhenge. Ab app mein lagate hain.

## Step 4 — Conditional UI in App

**Soch:** "Concepts clear hain. Ab App.tsx mein star toggle button aur conditional styles add karte hain."

Step 1 ke scaffold mein har item sirf text + delete button dikhata hai. Ab usme **star button** add karte hain jo flag toggle kare. Ek ek karke conditional rendering lagate hain.

Pehle — item rendering mein star button daalo, simple `"Toggle"` text ke saath:

```tsx
{items.map((item) => (
  <div key={item.id}>
    <button onClick={() => handleToggleFlag(item.id)}>Toggle</button>
    <span>{item.text}</span>
    <button onClick={() => handleDelete(item.id)}>Delete</button>
  </div>
))}
```

Notice: `key={item.id}` — id-based key. Item ke paas unique id hai, isliye index ki jagah id use karo.

Test karo — toggle button se flag `true`/`false` ho raha hai. Ab is button ko star icon banate hain.

**Star icon — ternary:**

```tsx
<button onClick={() => handleToggleFlag(item.id)}>
  {item.flagged ? "★" : "☆"}
</button>
```

Condition check: `item.flagged` true hai to yellow star (`★`), false hai to outline star (`☆`).

**Background color — ternary:**

```tsx
<button
  onClick={() => handleToggleFlag(item.id)}
  style={{
    background: item.flagged ? "#ffd700" : "#eee",
    border: "1px solid #ccc",
    borderRadius: "4px",
    cursor: "pointer",
    padding: "2px 8px",
    marginRight: "8px",
  }}
>
  {item.flagged ? "★" : "☆"}
</button>
```

**Text bold — ternary:**

```tsx
<span style={{ fontWeight: item.flagged ? "bold" : "normal" }}>
  {item.text}
</span>
```

Har line ek conditional rendering ka use case hai. Tino **ternary** operator use kar rahe hain.

**Test karo:**
1. "Milk" add karo → star grey (`☆`) dikhe, text normal
2. Star click karo → star yellow (`★`), text bold
3. Dobara click karo → wapas grey, normal

## Step 5 — Filter Buttons (Union Type + .filter)

**Soch:** "Abhi saare items dikhte hain. User sirf flagged ya sirf unflagged items dekhna chahe?"

**Problem:** Abhi koi filter nahi hai. State tracking kare — "kaunsa filter active hai" — aur uske hisaab se items dikhao.

Tees possible filter values chahiye:
- `"all"` — saare items
- `"flagged"` — sirf flagged
- `"unflagged"` — sirf unflagged

TypeScript mein teen specific string values ka type banane ke liye **union type** use karte hain.

**Concept — Union Type (standalone):**

```ts
type TrafficLight = "red" | "yellow" | "green";

let light: TrafficLight = "red";  // ✅
light = "blue";                    // ❌ TypeScript error
```

`|` ka matlab "ya toh yeh value, ya woh". Sirf di hui values allow hain.

**Concept — `.filter()` with property (review from 1.9, ab objects ke saath):**

1.9 mein `.filter()` se strings delete karte the. Ab objects ki property check karenge:

```ts
const items: Item[] = [
  { id: 1, text: "Milk", flagged: true },
  { id: 2, text: "Eggs", flagged: false },
];

const flaggedItems = items.filter((item) => item.flagged);
console.log(flaggedItems); // → [Milk]

const unflaggedItems = items.filter((item) => !item.flagged);
console.log(unflaggedItems); // → [Eggs]
```

**Ab App.tsx mein filter state add karo:**

```tsx
type FilterStatus = "all" | "flagged" | "unflagged";

function App() {
  const [items, setItems] = useState<Item[]>([]);
  const [filter, setFilter] = useState<FilterStatus>("all");
  const [input, setInput] = useState("");
  // ...
}
```

Notice: Union type ki value `"all"` initial state — starting mein saare items dikhenge.

**Filter logic add karo — App function ke andar, return se pehle:**

```tsx
const filteredItems = items.filter((item) => {
  if (filter === "flagged") return item.flagged;
  if (filter === "unflagged") return !item.flagged;
  return true; // "all" — sab kuch
});

console.log("Current filter:", filter, "Filtered:", filteredItems); // verify
```

**Ab UI mein 3 filter buttons daalo — ItemInput aur list ke beech mein:**

```tsx
<div>
  <button
    onClick={() => setFilter("all")}
    style={{ fontWeight: filter === "all" ? "bold" : "normal" }}
  >
    All
  </button>
  <button
    onClick={() => setFilter("flagged")}
    style={{ fontWeight: filter === "flagged" ? "bold" : "normal" }}
  >
    Flagged
  </button>
  <button
    onClick={() => setFilter("unflagged")}
    style={{ fontWeight: filter === "unflagged" ? "bold" : "normal" }}
  >
    Unflagged
  </button>
</div>
```

Yeh conditional styling ka naya use case — jo filter active hai uska font bold.

**`items.map` ki jagah `filteredItems.map` karo:**

```tsx
{filteredItems.map((item) => (
  // ... same rendering
))}
```

**App.tsx ka puora return:**

```tsx
return (
  <div>
    <h1>Flagged Items</h1>

    <div>
      <input
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="Enter an item..."
      />
      <button onClick={handleAdd}>Add</button>
    </div>

    <div>
      <button
        onClick={() => setFilter("all")}
        style={{ fontWeight: filter === "all" ? "bold" : "normal" }}
      >
        All
      </button>
      <button
        onClick={() => setFilter("flagged")}
        style={{ fontWeight: filter === "flagged" ? "bold" : "normal" }}
      >
        Flagged
      </button>
      <button
        onClick={() => setFilter("unflagged")}
        style={{ fontWeight: filter === "unflagged" ? "bold" : "normal" }}
      >
        Unflagged
      </button>
    </div>

    <div>
      {filteredItems.map((item) => (
        <div key={item.id}>
          <button
            onClick={() => handleToggleFlag(item.id)}
            style={{
              background: item.flagged ? "#ffd700" : "#eee",
              border: "1px solid #ccc",
              borderRadius: "4px",
              cursor: "pointer",
              padding: "2px 8px",
              marginRight: "8px",
            }}
          >
            {item.flagged ? "★" : "☆"}
          </button>
          <span style={{ fontWeight: item.flagged ? "bold" : "normal" }}>
            {item.text}
          </span>
          <button onClick={() => handleDelete(item.id)}>Delete</button>
        </div>
      ))}
    </div>

    {items.length === 0 && <p>No items yet. Add one above!</p>}
  </div>
);
```

**Test karo:**
1. "Milk" add karo, flag karo. "Eggs" add karo, flag mat karo
2. **Flagged** button dabao → sirf "Milk" dikhe
3. **Unflagged** dabao → sirf "Eggs" dikhe
4. **All** dabao → dono wapas
5. Flag kisi item ka toggle karo → filter list instantly update ho

## Step 7 — Item Count (Extra Conditional Rendering)

**Soch:** "Kitne items hain aur kitne flagged hain — yeh dikhana hai."

**Kyun:** User ko summary chahiye.

```tsx
{
  items.length > 0 && (
    <p>
      Flagged: {items.filter((item) => item.flagged).length} / {items.length} items
    </p>
  );
}
```

Yeh `&&` conditional rendering — sirf tab dikhao jab items hoon. `items.filter((item) => item.flagged).length` count karta hai kitne flagged hain.

Agar koi item nahi hai toh kuch nahi dikhega. Agar hai toh "Flagged: 2 / 3 items" dikhega.

## Summary

- **Interface** — object ki shape define karta hai (`Item { id, text, flagged }`)
- **`.map()` with condition** — specific item update, baaki unchanged
- **Ternary `? :`** — `condition ? trueValue : falseValue` — inline conditional in JSX
- **`&&` operator** — `condition && <JSX>` — sirf tab render jab condition truthy ho
- **Union type** — `"all" | "flagged" | "unflagged"` — specific set of values enforce karta hai
- **`.filter()` with property** — `items.filter(item => item.flagged)` — condition ke hisaab se naya array
- **Conditional styles** — `style={{ property: condition ? value1 : value2 }}`
- **Immutability** — `.map()` aur `.filter()` se naya array banate hain, mutate nahi karte
