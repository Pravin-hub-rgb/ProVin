# Project Setup — Vite + React + TypeScript

## Node.js Kya Hai?

Node.js ek **JavaScript runtime** hai. Matlab — browser ke bahar JavaScript chalane ka engine.

Tum jaante ho ki browser (Chrome, Firefox) JavaScript samajhta hai. Lekin browser ke bahar — terminal mein, server par — JavaScript kaise chalegi? Uske liye chahiye Node.js.

```
Browser → JavaScript ko browser mein chalata hai
Node.js → JavaScript ko terminal/server par chalata hai
```

React project banane ke liye Node.js chahiye kyunki:
- `npm` (Node Package Manager) uske saath aata hai — packages install karne ke liye
- Dev server chalane ke liye
- Build process ke liye

**Already installed hai ya nahi?** Terminal mein check karo:

```bash
node --version
npm --version
```

Agar version number aaya, toh installed hai. Agar error aaya, toh [nodejs.org](https://nodejs.org) se download karo.

## Bun Kya Hai?

Bun bhi ek JavaScript runtime hai — Node.js ka **modern alternative**. Node.js ne JavaScript runtime ka concept diya, aur Bun ne use aur fast aur developer-friendly banaya.

```
Node.js → 2009 mein aaya, legacy hai, sabse zyada use hota hai
Bun → 2023 mein aaya, fast hai, built-in features zyada hain
```

Bun kyun better ho sakta hai:
- **Fast** — Node.js se 4x tak speed mein packages install karta hai
- **Built-in TypeScript support** — alag se TypeScript configure nahi karna padta
- **Built-in bundler, test runner, package manager** — teen tools ek mein

React project **Node.js aur Bun dono se create kar sakte ho**. Main yahan dono dikhaunga. Jo bhi use karo, concept same hai.

**Already installed hai ya nahi?**

```bash
bun --version
```

Agar nahi hai toh [bun.sh](https://bun.sh) se install karo.

## npm / npx Kya Hai?

| Tool | Kya Hai? | Example |
|------|----------|---------|
| `npm` | Package installer — JavaScript libraries download karta hai | `npm install react` |
| `npx` | Package executor — package install kiye bina ek baar run karta hai | `npx create-react-app` |

**Analogy:** npm ek **grocery app** hai jaise Zepto ya Blinkit. Tumhe "React" chahiye — app se order karte ho, woh download ho kar tumhare project mein aa jata hai. npx ek **sample tester** hai — poora packet khareede bina ek sample taste kar sakte ho.

Bun mein equivalent hai `bun` (npm ki jagah) aur `bunx` (npx ki jagah).

| Node.js/Traditional | Bun |
|---------------------|-----|
| `npm install` | `bun install` |
| `npx create-vite` | `bunx create-vite` |
| `npm run dev` | `bun run dev` |

## Vite Kya Hai?

Vite ek **build tool** hai — React project banane, development server chalane, aur final build banane ke liye.

Vite se pehle **Create React App (CRA)** use hota tha. CRA webpack-based tha — slow, heavy, outdated. React official documentation ab Vite recommend karta hai.

Vite fast kyun hai? Kyunki ye **ES modules** use karta hai development mein. Matlab — jab tum code change karte ho, poora project rebuild nahi hota, sirf change wala module reload hota hai. yehi HMR (Hot Module Replacement) hai — jiske baare mein aage padhenge.

## Step-by-Step: Project Create Karna

### Step 1: Folder Banao

Pehle ek folder banao jahan project rakhna chahte ho. Terminal mein us folder mein jao:

```bash
cd Desktop
mkdir react-course
cd react-course
```

### Step 2: Project Create Karo

**Node.js ke saath:**

```bash
npx create-vite@latest . -- --template react-ts
```

**Bun ke saath:**

```bash
bunx create-vite@latest . -- --template react-ts
```

Ye command:
- Current folder (`.`) mein project banayega
- `react-ts` template use karega — React + TypeScript pre-configured
- Vite as build tool set karega

### Step 3: Dependencies Install Karo

**Node.js:**

```bash
npm install
```

**Bun:**

```bash
bun install
```

Ye command `package.json` mein listed saari libraries download karega. Ek `node_modules` folder banta hai jisme saari installed libraries hoti hain.

> **Note:** Agar npm use kar rahe ho, `package-lock.json` banta hai. Agar Bun use kar rahe ho, `bun.lock` banta hai — dono ka kaam same hai: exact versions track karna.

### Step 4: Development Server Start Karo

**Node.js:**

```bash
npm run dev
```

**Bun:**

```bash
bun run dev
```

Ye terminal mein kuch aisa dikhayega:

```
  VITE v6.x.x  ready in 200ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

Ab browser mein `http://localhost:5173` kholo. Tera pehla React app chal raha hai! 🎉

## HMR — Hot Module Replacement

Ab jab bhi code change karoge, browser automatically update ho jayega bina page refresh kiye. Is feature ko **Hot Module Replacement (HMR)** kehte hain.

```
Tumne code change kiya
        ↓
Vite sirf change wala module replace karta hai
        ↓
Browser update ho jata hai — state preserve rehti hai
        ↓
Poore page ka refresh nahi hota
```

HMR fast development ke liye game-changer hai. CRA mein ek chhota change karne ke baad bhi 2-3 second lagte the reload mein. Vite mein ye almost instant hota hai.

## Project Folder Structure

```
react-course/
├── index.html              # Entry HTML file — Vite ise serve karta hai
├── package.json            # Project info + dependencies ki list
├── tsconfig.json           # TypeScript configuration
├── tsconfig.app.json       # TS config specifically for app code
├── tsconfig.node.json      # TS config for Node.js tools (Vite config)
├── vite.config.ts          # Vite configuration
├── public/                 # Static files (images, fonts)
└── src/
    ├── main.tsx            # Entry point — React app yahan start hota hai
    ├── App.tsx             # Root component — sab kuch yahan se shuru hota hai
    ├── App.css
    ├── index.css
    └── vite-env.d.ts       # Vite ke type declarations
```

### Har File Kya Karti Hai?

**`index.html`** — Browser sabse pehle ye file load karta hai. Isme ek `<div id="root">` hai jahan React app mount hota hai. Aur ek `<script type="module" src="/src/main.tsx">` hai jo React app ko load karta hai.

**`package.json`** — Project ka "identity card." Isme name, version, dependencies, scripts sab likha hota hai. Jab `npm install` karte ho, ye file padh ke sab packages download karta hai.

**`tsconfig.json`** — TypeScript ka configuration file. Ye batata hai ki TypeScript kaise behave karega — kaun si strictness, kaun se features allow hain, etc.

**`src/main.tsx`** — Entry point. Is file mein `ReactDOM.createRoot()` call hota hai jo React app ko `<div id="root">` ke andar render karta hai.

**`src/App.tsx`** — Root component. Tum apna React app yahan likhna shuru karoge.

## Pehla React Component

Ab `src/App.tsx` ko replace karo:

```tsx
interface GreetingProps {
  name: string;
  age?: number;
}

function Greeting({ name, age }: GreetingProps) {
  return (
    <div>
      <h1>Hello, {name}!</h1>
      {age && <p>Age: {age}</p>}
    </div>
  );
}

function App() {
  return (
    <div>
      <Greeting name="Vin" age={25} />
    </div>
  );
}

export default App;
```

Ye code kya kar raha hai?

1. `GreetingProps` — ek interface hai jo batata hai ki `Greeting` component ko `name` (string, required) aur `age` (number, optional) props chahiye
2. `Greeting` — ek component hai jo `name` aur optional `age` display karta hai
3. `App` — root component jo `Greeting` ko render karta hai

Notice karo ki yahan `useState` nahi hai, `useRef` nahi hai, koi Generics nahi hai. Sirf simple TypeScript — basic types + interface. Yahi philosophy hai — ek concept tab introduce karo jab actually zaroorat ho.

Browser mein jaake dekho — "Hello, Vin!" aur "Age: 25" dikhna chahiye.
