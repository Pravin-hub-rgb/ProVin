## STAGE 1 — Types Kyun? (Type Contract)

### SOCH

Hardcoded `6.7.5.2` me `hardcoded: Expense[]` ka `Expense` interface tha — par `amount: 20` ko `amount: "20"` string bhi likh sakte the, `category` typo `"Foodd"` bhi, `ExpenseStaticApp` me `e.amount` ka `reduce` string concat `“2050”` bug ban jaata. TS type hota toh compile pe pakda jaata. Pehle bina type wala dard dekho, phir type ka “kyun”.

### CONCEPT

`interface Expense` = **contract** — har expense me `id/title/amount/category/date` hona hi chahiye, `amount` `number` hi hoga. `type FilterStatus` = `"all" | string` — `setFilter` me galat type pe TS error. `6.7.2` me `CounterState` interface yaad karo — wahi pattern.

### CODE

Bina type (galat):

```ts
// ❌ Galat — bina type, typo silent
const hardcoded = [{ id:"1", title:"Chai", amt: 20, category:"Food" }];
// amt vs amount — compile error nahi, runtime pe e.amount undefined, total NaN
```

Type ke saath (sahi) — naya file `src/rtk/expenseTypes.ts` (is stage me banate hain, pehle nahi — import tabhi jab zaroorat):

```ts
// src/rtk/expenseTypes.ts
export interface Expense {
  id: string;
  title: string;
  amount: number; // number kyun — total reduce numeric sum, string hota toh "20"+"50"="2050"
  category: string;
  date: string; // ISO string — future "aaj ke expenses" filter ke liye
}

export type FilterStatus = "all" | string; // "all" explicit, baaki dynamic category
```

| Field | Kyun (UI se) |
|---|---|
| `id` | `key={e.id}` + `deleteExpense(id)` unique, `Date.now().toString()` se banega |
| `amount: number` | `total = items.reduce((s,e)=>s+e.amount,0)` numeric sum — string bug avoid |
| `date` | Abhi list me nahi dikhayenge par `6.7.5.5` me “aaj ke” filter extend — isliye rakha |

### TEST

`hardcoded: Expense[] = [{id:"1", title:"Chai", amt:20, ...}]` likh ke `tsc` check — `Property 'amt' does not exist` error aayega, `amount` suggest karega. `6.7.2` wala `PayloadAction` yaad karo — type se hi payload safety aati hai.

**Nutshell:** Type contract woh TS interface hai jo har object ka shape compile pe lock karta hai — typo/missing field turant error, runtime bug pehle hi pakda jaata hai.

## STAGE 2 — expensesSlice (Sync Reducers — add/delete/setFilter)

### SOCH

Hardcoded `6.7.5.2` me `filter` `useState` se, `handleAdd` me `console.log`, `hardcoded` array const. Ab in teeno ko alag `expensesSlice` me kaise le jayein taaki koi bhi component `dispatch(addExpense(...))` se add kare, `useAppSelector` se `items` padhe — bina prop drilling? Pehle `initialState` socho.

### CONCEPT

`createSlice` me `initialState` = `{items: Expense[], filter: FilterStatus}`. `reducers` me 3 case reducers: `addExpense (PayloadAction<Expense>)`, `deleteExpense (PayloadAction<string>)`, `setFilter (PayloadAction<FilterStatus>)`. Har reducer `state.items.push` jaisa mutate likhega — Immer naya object auto (`6.7.2`).

### CODE

Naya file `src/rtk/expensesSlice.ts` — is stage me banate hain:

```ts
// src/rtk/expensesSlice.ts
import { createSlice, type PayloadAction } from "@reduxjs/toolkit";
import type { Expense, FilterStatus } from "./expenseTypes";

interface ExpensesState {
  items: Expense[];
  filter: FilterStatus;
}

const initialState: ExpensesState = {
  items: [
    { id: "1", title: "Chai", amount: 20, category: "Food", date: "2026-08-25" },
    { id: "2", title: "Bus", amount: 50, category: "Travel", date: "2026-08-25" },
    { id: "3", title: "Samosa", amount: 30, category: "Food", date: "2026-08-25" },
  ],
  filter: "all",
};

const expensesSlice = createSlice({
  name: "expenses",
  initialState,
  reducers: {
    addExpense: (state, action: PayloadAction<Expense>) => {
      state.items.push(action.payload);
    },
    deleteExpense: (state, action: PayloadAction<string>) => {
      state.items = state.items.filter((e) => e.id !== action.payload);
    },
    setFilter: (state, action: PayloadAction<FilterStatus>) => {
      state.filter = action.payload;
    },
  },
});

export const { addExpense, deleteExpense, setFilter } = expensesSlice.actions;
export default expensesSlice.reducer;
```

Har line ka “kyun”:

| Code | Kyun |
|------|------|
| `initialState.items` me 3 hardcoded expenses | `6.7.5.2` wala `hardcoded` array yahan shift — ab single source of truth, `6.7.5.2` ke duplication ka fix |
| `filter: "all"` | `6.7.5.2` wala `useState("all")` ka replacement — ab global, FilterBar + List dono `useAppSelector` se padhenge |
| `addExpense: (state, action: PayloadAction<Expense>)` | `Expense` type se `action.payload` me `title/amount/category` auto-complete, `amount` string bhejoge toh TS error |
| `state.items.push(action.payload)` | Mutate jaisa — Immer naya array auto, `6.7.1` wala `return {items:[...state.items, payload]}` nahi |
| `state.items = state.items.filter(...)` | `filter` se naya array assign — Immer draft me assign allowed |

## STAGE 3 — categoriesSlice (Async) + Store (Single Source)

### SOCH

`6.7.5.2` me categories hardcoded `["Food","Travel","Shopping"]` the, par `6.7.4` me `fetchCategories` thunk se `["Beef","Chicken",...]` API se aaye the — real app me categories dynamic chahiye. Plus in dono slices (`expenses`, `categories`) ko kahaan jodna hai taaki `useAppSelector(s => s.expenses.items)` aur `s.categories.items` dono ek `store` se aayein? Store me.

### CONCEPT

`categoriesSlice` wahi `6.7.4` wali, `extraReducers` me `fetchCategories.pending/fulfilled/rejected`. `store.ts` me `configureStore({reducer: {expenses, categories}})` — `combineReducers` auto, `RootState` auto.

### CODE

`src/rtk/categoriesSlice.ts` ko `6.7.4` se copy karo, par is doc me adapt — yahan `items` `string[]` hi, `status/error` wahi:

```ts
// src/rtk/categoriesSlice.ts — STAGE 3 (6.7.4 se adapt, is stage me file banti hai agar pehle nahi bani)
import { createSlice, createAsyncThunk } from "@reduxjs/toolkit";

interface CatState {
  items: string[];
  status: "idle" | "loading" | "succeeded" | "failed";
  error: string | null;
}

const initialState: CatState = { items: ["Food", "Travel", "Shopping"], status: "idle", error: null };

export const fetchCategories = createAsyncThunk("categories/fetch", async () => {
  const res = await fetch("https://www.themealdb.com/api/json/v1/1/categories.php");
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  const json = await res.json();
  return json.categories.map((c: any) => c.strCategory).slice(0, 5) as string[];
});

const categoriesSlice = createSlice({
  name: "categories",
  initialState,
  reducers: {},
  extraReducers: (builder) => {
    builder
      .addCase(fetchCategories.pending, (state) => { state.status = "loading"; state.error = null; })
      .addCase(fetchCategories.fulfilled, (state, action) => { state.status = "succeeded"; state.items = action.payload; })
      .addCase(fetchCategories.rejected, (state, action) => { state.status = "failed"; state.error = action.error.message ?? "Kuch gadbad hui"; });
  },
});

export default categoriesSlice.reducer;
```

Store — `src/rtk/store.ts` ko **update** karo (is stage me, pehle `counter` tha, ab expenses):

```ts
import { configureStore } from "@reduxjs/toolkit";
import expensesReducer from "./expensesSlice";

export const store = configureStore({

export type AppDispatch = typeof store.dispatch;
```

## Common Mistakes

*   **`Expense` me `amount: string` rakh diya:** Input se string aata hai par store me `number` — `Number(amount)` karke dispatch nahi kiya toh `reduce` string concat `“2050”`. `PayloadAction<Expense>` me `amount` number hai toh string bhejoge TS error.
*   **`initialState` me `filter: "All"` capital:** `6.7.5.2` me `filter` `"all"` lowercase tha, yahan `"All"` kiya toh `filtered = items.filter(e => filter==="all" || ...)` kabhi `all` match nahi, `All` pe empty. Case-sensitive string literal — TS `FilterStatus` me `"all"` literal se pakda jaata.
*   **`store.ts` me `reducer: expensesReducer` (singular) likh diya:** `configureStore({reducer: expensesReducer})` se `RootState` shape `Expense[]` ban jayega, `s.expenses.items` nahi `s.items` hota — `useAppSelector(s => s.expenses.items)` pe error `Property 'expenses' does not exist`.
*   **`createAsyncThunk` ko `reducers` me daala:** `reducers: {fetchCategories: ...}` — `fetchCategories` thunk hai, `reducers` sync ke liye, `extraReducers` me `builder.addCase` — galat jagah pe `pending` property nahi milegi.

## Khud Try Karo

1.  `expensesSlice.ts` me `deleteExpense` ke `filter` ki jagah `state.items.splice(0,1)` try karo — UI me kya hoga? Immer `splice` mutate allow karta hai par `filter` vs `splice` me kaunsa predictable (filter naya array, splice mutating)?
2.  `categoriesSlice` me `initialState.items` ko `[]` khali karke `fetchCategories` na dispatch karo — `ExpenseForm` ka `select` empty hota? `6.7.5.4` me iska fallback kaise handle karenge?
3.  `store.ts` me `reducer: {expenses: expensesReducer}` ki jagah `reducer: {exp: expensesReducer}` karke `useAppSelector(s => s.expenses.items)` pe TS error kya aata? `RootState` ka shape kaise badla?

## What It Is NOT

*   **NOT component:** Is doc me koi `ExpenseForm.tsx` nahi — `6.7.5.4` me banega, abhi sirf data.
*   **NOT persist:** Refresh pe `expenses` reset — `6.7.5.5` me optional `redux-persist` ya `localStorage` sync add karenge, abhi jaan-bujh ke nahi — `Zustand persist` `6.4:478` se compare tab karenge.
*   **NOT plain Redux:** `createSlice` + `createAsyncThunk` RTK hai — plain Redux me `switch` + `CounterAction` union `6.7.1` jaisa har slice me.

## Summary

*   Types = contract — `Expense` 5 fields UI se justified, `amount` number.
*   `expensesSlice` = sync `add/delete/setFilter` — Immer `push`/`filter`.
*   `categoriesSlice` = async `fetchCategories` pending/fulfilled/rejected.
*   `store` = `expenses + categories` combined, `RootState` auto.
