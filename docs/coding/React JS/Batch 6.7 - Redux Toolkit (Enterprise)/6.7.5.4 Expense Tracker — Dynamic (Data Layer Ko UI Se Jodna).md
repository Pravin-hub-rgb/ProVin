## STAGE 1 — List + Filter + Stats Ko Store Se Jodna

### SOCH

Hardcoded `ExpenseStaticApp.tsx` me `const [filter,setFilter]=useState("all")` local tha, `filtered = hardcoded.filter(...)` bhi local. Ab `expensesSlice` me `filter` global hai — `FilterBar` aur `ExpenseList` dono ko wahi `filter` chahiye. Local `useState` hatana padega, `useAppSelector` se `s.expenses.items` + `s.expenses.filter`, `dispatch(setFilter(cat))` se update. Pehle List + Stats ko jodte hain, Form agle stage me.

### CONCEPT

`useAppSelector` = `6.7.3` wala typed `useSelector` — store ka koi slice padhna. `dispatch` = parchi bhejna. List me derived `filtered` + `total` wahi `6.7.5.2` wala `filter`/`reduce` logic — sirf source `hardcoded` ki jagah `store`.

### CODE

Naya file `src/components/ExpenseList.tsx` banao — is stage me, Hardcoded UI ke `map` ko yahan le jayenge:

```tsx
// src/components/ExpenseList.tsx — STAGE 1
import { useAppSelector, useAppDispatch } from "../rtk/hooks";
import { deleteExpense } from "../rtk/expensesSlice";

export function ExpenseList() {
  const { items, filter } = useAppSelector((s) => s.expenses);
  const dispatch = useAppDispatch();

  const filtered = items.filter((e) => filter === "all" || e.category === filter);

  if (filtered.length === 0) return <p>No expenses for {filter}.</p>;

  return (
    <div>
      {filtered.map((e) => (
        <div key={e.id} style={{ display: "flex", justifyContent: "space-between", padding: 8, border: "1px solid #ddd", marginBottom: 6 }}>
          <span>{e.title} — ₹{e.amount} ({e.category})</span>
          <button onClick={() => dispatch(deleteExpense(e.id))}>Delete</button>
        </div>
      ))}
    </div>
  );
}
```

import { useAppSelector } from "../rtk/hooks";

export function Stats() {
  const { items, filter } = useAppSelector((s) => s.expenses);
  const filtered = items.filter((e) => filter === "all" || e.category === filter);
  const total = filtered.reduce((sum, e) => sum + e.amount, 0);

## STAGE 2 — Form Ko Dispatch Se Jodna (console.log -> real)

### SOCH

`6.7.5.2 STAGE 3` me `handleAdd` me `console.log({title, amount})` tha — click + values capture verify. Ab wahi `handleAdd` ko `dispatch(addExpense(...))` se replace karna hai — par `amount` string -> `Number`, `id` generate, `date` ISO, validation `title.trim` + `amount>0`.

### CONCEPT

`addExpense` ka `PayloadAction<Expense>` poora `Expense` object leta hai — `title/amount/category/date/id` sab. Form ke `useState` wahi rahenge `title/amount/category` (local), par submit pe `dispatch`.

### CODE

Naya file `src/components/ExpenseForm.tsx` — is stage me:

```tsx
// src/components/ExpenseForm.tsx — STAGE 2
import { useState } from "react";
import { useAppDispatch, useAppSelector } from "../rtk/hooks";
import { addExpense } from "../rtk/expensesSlice";

export function ExpenseForm() {
  const [title, setTitle] = useState("");
  const [amount, setAmount] = useState("");
  const [category, setCategory] = useState("Food");
  const dispatch = useAppDispatch();
  const categories = useAppSelector((s) => s.categories.items);

  const handleAdd = () => {
    const numAmount = Number(amount);
    if (!title.trim() || !numAmount || numAmount <= 0) return;
    dispatch(
      addExpense({
        id: `exp-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`,
        title: title.trim(),
        amount: numAmount,
        category,
        date: new Date().toISOString(),
      })
    );
    setTitle("");
    setAmount("");
  };

  return (
    <div style={{ display: "flex", gap: 8, marginBottom: 12 }}>
      <input placeholder="Title e.g. Chai" value={title} onChange={(e) => setTitle(e.target.value)} />
      <input placeholder="Amount e.g. 20" type="number" value={amount} onChange={(e) => setAmount(e.target.value)} />
      <select value={category} onChange={(e) => setCategory(e.target.value)}>
        {categories.map((cat) => (
          <option key={cat} value={cat}>{cat}</option>
        ))}
      </select>
      <button onClick={handleAdd}>Add</button>
    </div>
  );
}
```

| Code | Kyun |
|------|------|
| `useState` for `title/amount/category` | Form ke local state — global store me nahi, `6.7.0 What It Is NOT` — `isModalOpen` local |
| `Number(amount)` + `>0` | Input string -> number, `NaN` + negative block — `6.7.5.3` wala `amount: number` contract |
| `id: exp-${Date.now()}-...` | `key` + delete unique, `Date.now()` simple, `crypto.randomUUID()` bhi chalega |
| `categories.map` for `<option>` | Dynamic categories — `["Food",...]` hardcoded nahi, `fetchCategories` se `["Beef",...]` bhi ayenge |
| `setTitle("")` after dispatch | UX — add ke baad form clear, `6.5:277` wala `inputRef.current?.focus()` yahan bhi add kar sakte ho |

## STAGE 3 — App.tsx + Categories Fetch Wireup (Dynamic Complete)

### SOCH

Categories abhi `initialState` `["Food","Travel","Shopping"]` se. Real API se `["Beef","Chicken",...]` lane ke liye `6.7.4` wala `dispatch(fetchCategories())` kaha call karein? `App` mount pe `useEffect` me — `6.2` wala `useEffect` + `fetch` nahi, RTK thunk dispatch.

### CONCEPT

`useEffect(() => { dispatch(fetchCategories()) }, [dispatch])` — `dispatch` stable hai `useAppDispatch` se, `fetchCategories` thunk auto `pending -> fulfilled`.

### CODE

Final `App.tsx` — Hardcoded UI `6.7.5.2` ka `ExpenseStaticApp` replace, Data Layer se Dynamic:

```tsx
// src/App.tsx — STAGE 3 final Dynamic
import { useEffect } from "react";
import { useAppDispatch, useAppSelector } from "./rtk/hooks";
import { fetchCategories } from "./rtk/categoriesSlice";
import { ExpenseForm } from "./components/ExpenseForm";
import { FilterBar } from "./components/FilterBar";
import { ExpenseList } from "./components/ExpenseList";
import { Stats } from "./components/Stats";

export default function App() {
  const dispatch = useAppDispatch();
  const { status, error } = useAppSelector((s) => s.categories);

  useEffect(() => {
    dispatch(fetchCategories());
  }, [dispatch]);

  return (
    <main style={{ maxWidth: 640, margin: "0 auto", padding: 16 }}>
      <h1>💰 Expense Tracker — RTK</h1>
      <Stats />
      {status === "loading" && <p>⏳ Loading categories...</p>}
      {status === "failed" && <p style={{ color: "red" }}>❌ {error}</p>}
      <ExpenseForm />
      <FilterBar />
      <ExpenseList />
    </main>
  );
}
```

| Code | Kyun |
|------|------|
| `useEffect dispatch(fetchCategories())` | Mount pe API call — `6.7.4` wala `createAsyncThunk`, `Provider` ke andar `useAppDispatch` available |
| `status === "loading"` | `categoriesSlice` ka `status` — `6.7.4` wala `pending/fulfilled/rejected` |
| `ExpenseForm` ke `select` me `categories` | `fetchCategories` ke baad `["Beef",...]` ayenge, Form me `Food` ki jagah `Beef` options dikhenge — proof `categories` global |

## Common Mistakes (Dynamic Me)

*   **`useAppSelector(s => s.expenses)` object return:** `const {items, filter} = useAppSelector(s => s.expenses)` har `categories` change pe bhi re-render — `6.7.3 STAGE 4` wala trap. Alag `const items = useAppSelector(s => s.expenses.items)` better, ya `items` + `filter` dono `expenses` ke hain toh saath chalega par `categories` change pe nahi.
*   **`dispatch` ko `useEffect` deps se nikala:** `useEffect(() => {dispatch(fetchCategories())}, [])` — `eslint` `exhaustive-deps` warning, `dispatch` stable hai `useAppDispatch` se par deps me `dispatch` rakho — `6.1` Rules of Hooks wala discipline.
*   **`amount` string dispatch kiya:** `dispatch(addExpense({amount}))` jahan `amount` string — TS `PayloadAction<Expense>` me `amount: number` error nahi dikhaya? `Number(amount)` convert bhool gaye — total `reduce` string concat `“2050”`.
*   **Provider bhool gaye `main.tsx` me:** `useAppSelector` ko `could not find react-redux context` — `6.7.3 STAGE 1` wala `Provider` `main.tsx` me wrap check karo.
