## STAGE 2 — HARDCODED LIST + FILTER (local state, abhi bhi RTK nahi)

### SOCH

Skeleton me 2 rows hardcoded `<p>` the. Ab unhe array se `map` se banao, aur filter button se `Food` filter karo — par **RTK ke bina**, local `useState` se, taaki UI ka `filter` logic confirm ho. RTK me bhi wahi filter `slice` me jayega `6.7.5.3` me — par UI ka logic pehle local se verify.

### CONCEPT

`useState` se `filter` state, `hardcodedExpenses.filter(e => filter==="all" || e.category===filter)` derived list, `total = filtered.reduce((s,e)=>s+e.amount,0)` — `6.5:318` wala `filteredTasks` pattern yaad karo.

### CODE

`ExpenseStaticApp.tsx` ko **update** karo — hardcoded array + local filter:

```tsx
// src/components/ExpenseStaticApp.tsx — STAGE 2 updated
import { useState } from "react";

interface Expense {
  id: string;
  title: string;
  amount: number;
  category: string;
  date: string;
}

const hardcoded: Expense[] = [
  { id: "1", title: "Chai", amount: 20, category: "Food", date: "2026-08-25" },
  { id: "2", title: "Bus", amount: 50, category: "Travel", date: "2026-08-25" },
  { id: "3", title: "Samosa", amount: 30, category: "Food", date: "2026-08-25" },
];

export function ExpenseStaticApp() {
  const [filter, setFilter] = useState<string>("all");

  const filtered = hardcoded.filter((e) => filter === "all" || e.category === filter);
  const total = filtered.reduce((sum, e) => sum + e.amount, 0);

  return (
    <main style={{ maxWidth: 640, margin: "0 auto", padding: 16 }}>
      <h1>💰 Expense Tracker — Hardcoded</h1>
      <p>Total: ₹{total} ({filtered.length} expenses) — Filter: {filter}</p>

      <div style={{ display: "flex", gap: 8, marginBottom: 12 }}>
        <input placeholder="Title e.g. Chai" />
        <input placeholder="Amount e.g. 20" type="number" />
        <select defaultValue="Food">
          <option>Food</option>
          <option>Travel</option>
          <option>Shopping</option>
        </select>
        <button>Add</button>
      </div>

      <div style={{ display: "flex", gap: 8, marginBottom: 12 }}>
        {["all", "Food", "Travel", "Shopping"].map((cat) => (
          <button
            key={cat}
            onClick={() => setFilter(cat)}
            style={{ fontWeight: filter === cat ? 700 : 400 }}
          >
            {cat}
          </button>
        ))}
      </div>

      <div>
        {filtered.map((e) => (
          <div key={e.id} style={{ display: "flex", justifyContent: "space-between", padding: 8, border: "1px solid #ddd", marginBottom: 6 }}>
            <span>{e.title} — ₹{e.amount} ({e.category})</span>
            <button>Delete</button>
          </div>
        ))}
        {filtered.length === 0 && <p>No expenses for {filter}.</p>}
      </div>
    </main>
  );
}
```

Har naya code kyun:

| Code | Kyun |
|------|------|
| `hardcoded` array component ke bahar | Static data — render ke andar hota toh har render pe naya array, `useMemo` trap |
| `useState<string>("all")` | `FilterStatus` ka local version — RTK me `expensesSlice.filter` banega |
| `filtered = hardcoded.filter(...)` | Derived — original `hardcoded` change nahi, sirf view change |
| `total = filtered.reduce(...)` | Stats ke liye — `6.5:320` wala `completedCount` jaisa derived |
| `key={e.id}` | `0.3 Reconciliation` wala `key` prop — `id` stable, index nahi |

// src/components/ExpenseStaticApp.tsx — STAGE 3 form state add (existing file update, sirf naya highlight)
import { useState } from "react";
// ... hardcoded + filter as before

export function ExpenseStaticApp() {
  const [filter, setFilter] = useState<string>("all");
  const [title, setTitle] = useState("");
  const [amount, setAmount] = useState("");
  const [category, setCategory] = useState("Food");

  const filtered = hardcoded.filter((e) => filter === "all" || e.category === filter);
  const total = filtered.reduce((sum, e) => sum + e.amount, 0);

  const handleAdd = () => {
    console.log("Add clicked:", { title, amount: Number(amount), category });
  };

  return (
    <main style={{ maxWidth: 640, margin: "0 auto", padding: 16 }}>
      <h1>💰 Expense Tracker — Hardcoded + Form state</h1>
      <p>Total: ₹{total} ({filtered.length} expenses)</p>

      <div style={{ display: "flex", gap: 8, marginBottom: 12 }}>
        <input placeholder="Title e.g. Chai" value={title} onChange={(e) => setTitle(e.target.value)} />
        <input placeholder="Amount e.g. 20" type="number" value={amount} onChange={(e) => setAmount(e.target.value)} />
        <select value={category} onChange={(e) => setCategory(e.target.value)}>
          <option>Food</option>
          <option>Travel</option>
          <option>Shopping</option>
        </select>
        <button onClick={handleAdd}>Add</button>
      </div>

      {/* Filter + List same as STAGE 2 */}
      <div style={{ display: "flex", gap: 8, marginBottom: 12 }}>
        {["all", "Food", "Travel", "Shopping"].map((cat) => (
          <button key={cat} onClick={() => setFilter(cat)} style={{ fontWeight: filter === cat ? 700 : 400 }}>
            {cat}
          </button>
        ))}
      </div>
      <div>
        {filtered.map((e) => (
          <div key={e.id} style={{ display: "flex", justifyContent: "space-between", padding: 8, border: "1px solid #ddd", marginBottom: 6 }}>
            <span>{e.title} — ₹{e.amount} ({e.category})</span>
            <button>Delete</button>
          </div>
        ))}
      </div>

  );
}

## Yahan Tak Kya Dard Dikh Raha Hai? (Agle Doc Ka Reason)

Hardcoded array ab **ek jagah** hai — `hardcoded` const. Lekin socho `6.7.5.3` ke bina aage kya hota:

*   `ExpenseStaticApp` me `hardcoded` + `filter` + `title/amount/category` + `handleAdd console.log` sab ek file me — `App.tsx overloaded` `6.5:66` wali problem.
*   Kal `ExpenseForm` alag component banaya toh `hardcoded` ko prop drilling se 3 jagah pass karna padta.
*   `Add` ka real logic `hardcoded.push` mutate hota — `6.7.1` wala mutate bug, plus refresh pe reset (no persist).

Isi duplication + prop drilling + mutate + no persist ka solution `6.7.5.3 Data Layer` — `expensesSlice` + `categoriesSlice` + `store` — ek source of truth, har component `useAppSelector` se padhe, `dispatch` se likhe.

## Common Mistakes (Hardcoded UI Me)

*   **`key={index}` lagana:** `hardcoded.map((e, idx) => <div key={idx}>)` — `6.5:340` `0.3 Reconciliation` wala trap — delete pe wrong row delete, input state shuffle. Hamesha `key={e.id}` stable.
*   **Hardcoded array render ke andar:** `function ExpenseStaticApp(){ const hardcoded = [...] }` — har render pe naya array reference, `useEffect` deps me infinite loop, `React.memo` fail. Bahar rakho.
*   **Seedha dynamic `dispatch` likh diya:** Form ka `onChange` bina `console.log` verify ke RTK dispatch — error aaye toh pata nahi form galat ya slice galat. Hamesha `STAGE 4 console.log` pehle.
*   **`amount` ko string hi dispatch karna:** Input `value` string hai, `NaN` check nahi — total `reduce` string concat `“20” + “50” = “2050”`. `Number(amount)` + `>0` check zaroori.

## What It Is NOT

*   **NOT RTK store:** Abhi koi `createSlice`, `Provider`, `useAppSelector` nahi — sirf local `useState` + `hardcoded` array.
*   **NOT final persist:** Refresh pe `hardcoded` reset — `6.7.5.3` me `redux-persist` ya `localStorage` sync nahi, abhi jaan-bujh ke nahi.
*   **NOT API fetch:** Categories abhi hardcoded `["Food","Travel","Shopping"]` — `6.7.5.3` me `fetchCategories` thunk se `["Beef",...]` ayenge.

## Summary

*   Static skeleton -> Hardcoded array + `map` + `key={id}` + local `filter` + `total reduce` -> Form `useState` + `console.log` verify.
*   UI confirm — `Food` filter `₹50`, `All` `₹100`, form values console me sahi.
*   Dard visible — data ek file me, prop drilling, mutate bug, no persist — agla doc `6.7.5.3` me slices.
