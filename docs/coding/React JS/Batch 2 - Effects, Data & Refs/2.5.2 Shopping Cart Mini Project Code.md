# 2.5.2 — Shopping Cart Mini Project Code

## Goal

Ek simple store banayenge — product list, cart summary with item count, add/remove functionality. State share karna seekhenge do siblings ke beech. 0 se shuru.

### Step 2 — Products data array banao

**SOCH:** Hardcoded HTML ki jagah ek array se products render karein. Data alag rakhna better hai.

**CONCEPT:** Array of objects — har product ka `id`, `name`, `price`. `.map()` se array ko JSX mein convert karo.

```tsx
const products = [
  { id: 1, name: "React Mug", price: 12 },
  { id: 2, name: "Dev Sticker Pack", price: 5 },
  { id: 3, name: "TypeScript Tote", price: 15 },
  { id: 4, name: "Node.js Cap", price: 10 },
];

function App() {
  return (
    <div>
      <h1>Store</h1>
      <div>
        <h3>Products</h3>
        {products.map((p) => (
          <div key={p.id}>
            <span>{p.name} — ${p.price}</span>
          </div>
        ))}
      </div>
      <div>
        <h3>Cart</h3>
        <p>0 items</p>
      </div>
    </div>
  );
}
```

`key={p.id}` — React ko har item ki unique identity batana zaroori hai jab array render karo. `id` unique hai, isliye key.

**TEST:** Same UI dikh raha hai, lekin ab data array se aa raha hai. ✅

### Step 5 — "Add to Cart" button lagao

**SOCH:** Har product ke saath ek "+ Add" button. Click karne par product cart mein add hona chahiye. Lekin abhi cart mein state hai hi nahi — sirf hardcoded "0 items".

Pehle button daalo (bina logic ke):

```tsx
function ProductList({ items }: { items: typeof products }) {
  return (
    <div>
      <h3>Products</h3>
      {items.map((p) => (
        <div key={p.id}>
          <span>{p.name} — ${p.price}</span>

        </div>
      ))}
    </div>

}
```

**TEST:** Buttons dikh rahe hain. Click karne par kuch nahi hota. ✅ (intentionally)

### Step 6 — Problem: Cart ko pata nahi chal raha

**SOCH:** CartSummary mein "0 items" hardcoded hai. Jab ProductList mein add karein, toh CartSummary ko bhi pata chalna chahiye. Lekin dono siblings hain — directly communicate nahi kar sakte.

Agar `ProductList` mein `cartItems` state rakhun, toh `CartSummary` use access nahi kar sakta — scope ka issue. Agar global variable rakhun, toh React ko pata nahi chalega.

**CONCEPT:** Siblings share data nahi kar sakte directly. State common parent mein rakhni padegi. Dono children props ke through access karenge.

### Step 7 — Lift cartItems to App

**SOCH:** State `App` mein banao. `cartItems` — ek string array jo product names store karega. `CartSummary` ko count do, `ProductList` ko callback do add karne ke liye.

```tsx
function App() {
  const [cartItems, setCartItems] = useState<string[]>([]);

  return (
    <div>
      <h1>Store</h1>
      <ProductList items={products} onAddToCart={(name: string) => setCartItems(prev => [...prev, name])} />
      <CartSummary itemCount={cartItems.length} />
    </div>
  );
}
```

**Line by line:**
- `useState<string[]>([])` — empty array se shuru
- `(name: string) => setCartItems(prev => [...prev, name])` — callback jo naya item array mein add karta hai
- `cartItems.length` — count CartSummary ko bhej rahe hain

### Step 8 — Props dono components mein do

**CartSummary** — `itemCount` prop receive karo:

```tsx
function CartSummary({ itemCount }: { itemCount: number }) {
  return (
    <div>
      <h3>Cart</h3>
      <p>{itemCount} items</p>
    </div>
  );
}
```

**ProductList** — `onAddToCart` callback prop receive karo aur button mein use karo:

```tsx
function ProductList({ items, onAddToCart }: { items: typeof products; onAddToCart: (name: string) => void }) {
  return (
    <div>
      <h3>Products</h3>
      {items.map((p) => (
        <div key={p.id}>
          <span>{p.name} — ${p.price}</span>
          <button onClick={() => onAddToCart(p.name)}>+ Add</button>
        </div>
      ))}
    </div>
  );
}
```

**Data flow:**

```
App (cartItems state)
  ├── ProductList    ← receives "onAddToCart" callback
  │                    click → App ka setCartItems call → cartItems.length++
  └── CartSummary    ← receives "itemCount" prop
                       re-render → {itemCount} updated!
```

**TEST:** "+ Add" click karo — CartSummary ka count badh raha hai? ✅

### Step 9 — Bonus: Remove button in CartSummary

**SOCH:** Cart mein har item ke saath "✕" button do jo cart se hata de.

Pehle `App` mein `onRemove` callback banao:

```tsx
<CartSummary
  itemCount={cartItems.length}
  items={cartItems}
  onRemove={(name: string) => setCartItems(prev => prev.filter(item => item !== name))}
/>
```

`filter` — ek naya array return karta hai bina us item ke. `item !== name` — jiska naam match kare, use hata do.

Ab `CartSummary` mein items list + remove button:

```tsx
function CartSummary({ itemCount, items, onRemove }: { itemCount: number; items: string[]; onRemove: (name: string) => void }) {
  return (
    <div>
      <h3>Cart</h3>
      <p>{itemCount} items</p>
      {items.map((name, i) => (
        <div key={i}>
          <span>{name}</span>
          <button onClick={() => onRemove(name)}>✕</button>
        </div>
      ))}
    </div>
  );
}
```

**TEST:** Add karo → list mein dikhe. ✕ click karo → hat jaye. Count bhi update ho. ✅

## Final Code

```tsx
import { useState } from "react";

const products = [
  { id: 1, name: "React Mug", price: 12 },
  { id: 2, name: "Dev Sticker Pack", price: 5 },
  { id: 3, name: "TypeScript Tote", price: 15 },
  { id: 4, name: "Node.js Cap", price: 10 },
];

function ProductList({ items, onAddToCart }: { items: typeof products; onAddToCart: (name: string) => void }) {
  return (
    <div>
      <h3>Products</h3>
      {items.map((p) => (
        <div key={p.id}>
          <span>{p.name} — ${p.price}</span>
          <button onClick={() => onAddToCart(p.name)}>+ Add</button>
        </div>
      ))}
    </div>
  );
}

function CartSummary({ itemCount, items, onRemove }: { itemCount: number; items: string[]; onRemove: (name: string) => void }) {
  return (
    <div>
      <h3>Cart</h3>
      <p>{itemCount} items</p>
      {items.map((name, i) => (
        <div key={i}>
          <span>{name}</span>
          <button onClick={() => onRemove(name)}>✕</button>
        </div>
      ))}
    </div>
  );
}

export default function App() {
  const [cartItems, setCartItems] = useState<string[]>([]);

  return (
    <div>
      <h1>Store</h1>
      <ProductList items={products} onAddToCart={(name) => setCartItems(prev => [...prev, name])} />
      <CartSummary itemCount={cartItems.length} items={cartItems} onRemove={(name) => setCartItems(prev => prev.filter(item => item !== name))} />
    </div>
  );
}
```
