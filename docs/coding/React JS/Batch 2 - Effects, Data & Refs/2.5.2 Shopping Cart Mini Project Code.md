### Step 2 — Products data array

**Think:** Replace hardcoded HTML with an array to render products. Keeping data separate is cleaner.

**Concept — Array of objects:** Each product has `id`, `name`, and `price`. Use `.map()` to convert the array into JSX.

```tsx
const products = [
  { id: 1, name: "React Mug", price: 12 },
  { id: 2, name: "Dev Sticker Pack", price: 5 },
  { id: 3, name: "TypeScript Tote", price: 15 },
  { id: 4, name: "Node.js Cap", price: 10 },
];

function App() {
  return (
    <div>
      <h1>Store</h1>
      <div>
        <h3>Products</h3>
        {products.map((p) => (
          <div key={p.id}>
            <span>{p.name} — ${p.price}</span>
          </div>
        ))}
      </div>
      <div>
        <h3>Cart</h3>
        <p>0 items</p>
      </div>
    </div>
  );
}
```

`key={p.id}` — React needs to know which item is which when rendering an array. `id` is unique, so use it as the key.

**Test:** Same UI, but now the data comes from the array. ✅

### Step 6 — Problem: Cart doesn't know

**Think:** `CartSummary` has "0 items" hardcoded. When we add from `ProductList`, `CartSummary` should also update. But they're siblings — they can't talk directly.

If `cartItems` state lives inside `ProductList`, `CartSummary` can't access it — that's a scope issue. If we use a global variable, React won't know about it (no re-render).

**Concept — Siblings can't share state directly:** State must live in a common parent. Both children receive data via props.

### Step 7 — Lift cartItems to App

**Think:** Put state in `App`. `cartItems` — a string array of product names. `CartSummary` receives the count, `ProductList` receives a callback to add items.

```tsx
function App() {
  const [cartItems, setCartItems] = useState<string[]>([]);

  return (
    <div>
      <h1>Store</h1>
      <ProductList items={products} onAddToCart={(name: string) => setCartItems(prev => [...prev, name])} />
      <CartSummary itemCount={cartItems.length} />
    </div>
  );
}
```

**Line by line:**
- `useState<string[]>([])` — starts with empty array
- `(name: string) => setCartItems(prev => [...prev, name])` — callback that adds a new item to the array
- `cartItems.length` — pass the count to CartSummary

**Concept — Data flow (Lifting State Up):**

```tsx
App (holds cartItems state)
  ├── ProductList    ← receives "onAddToCart" callback
  │                    click → calls App's setCartItems → cartItems.length grows
  └── CartSummary    ← receives "itemCount" prop
                        re-renders → {itemCount} updates!
```

**Test:** Click "+ Add" — does CartSummary's count increase? ✅

### Step 8 — Pass props to both components

**CartSummary** — receive `itemCount` prop:

```tsx
function CartSummary({ itemCount }: { itemCount: number }) {
  return (
    <div>
      <h3>Cart</h3>
      <p>{itemCount} items</p>
    </div>
  );
}
```

**ProductList** — receive `onAddToCart` callback and use it on the button:

```tsx
function ProductList({ items, onAddToCart }: { items: typeof products; onAddToCart: (name: string) => void }) {
  return (
    <div>
      <h3>Products</h3>
      {items.map((p) => (
        <div key={p.id}>
          <span>{p.name} — ${p.price}</span>
          <button onClick={() => onAddToCart(p.name)}>+ Add</button>
        </div>
      ))}
    </div>
  );
}
```

> **Think ahead:** If `ProductList` had its own `cartItems` state, what problem would that create?
>
> `<details>`
> <summary>Sample Answer</summary>
> `CartSummary` can't read `ProductList`'s state — siblings can't access each other's state. The count in the cart would never update.
> `</details>`

### Step 9 — Bonus: Remove button in CartSummary

**Think:** Each cart item gets a "✕" button that removes it from the cart.

First, add an `onRemove` callback in `App`:

```tsx
<CartSummary
  itemCount={cartItems.length}
  items={cartItems}
  onRemove={(name: string) => setCartItems(prev => prev.filter(item => item !== name))}
/>
```

`filter` — returns a new array without the matching item. `item !== name` — if the name matches, filter it out.

Now `CartSummary` receives `items` and a remove button:

```tsx
function CartSummary({ itemCount, items, onRemove }: { itemCount: number; items: string[]; onRemove: (name: string) => void }) {
  return (
    <div>
      <h3>Cart</h3>
      <p>{itemCount} items</p>
      {items.map((name, i) => (
        <div key={i}>
          <span>{name}</span>
          <button onClick={() => onRemove(name)}>✕</button>
        </div>
      ))}
    </div>
  );
}
```

**Test:** Add → shows in list. Click ✕ → removed. Count updates too. ✅

## Final Code

```tsx
import { useState } from "react";

const products = [
  { id: 1, name: "React Mug", price: 12 },
  { id: 2, name: "Dev Sticker Pack", price: 5 },
  { id: 3, name: "TypeScript Tote", price: 15 },
  { id: 4, name: "Node.js Cap", price: 10 },
];

function ProductList({ items, onAddToCart }: { items: typeof products; onAddToCart: (name: string) => void }) {
  return (
    <div>
      <h3>Products</h3>
      {items.map((p) => (
        <div key={p.id}>
          <span>{p.name} — ${p.price}</span>
          <button onClick={() => onAddToCart(p.name)}>+ Add</button>
        </div>
      ))}
    </div>
  );
}

function CartSummary({ itemCount, items, onRemove }: { itemCount: number; items: string[]; onRemove: (name: string) => void }) {
  return (
    <div>
      <h3>Cart</h3>
      <p>{itemCount} items</p>
      {items.map((name, i) => (
        <div key={i}>
          <span>{name}</span>
          <button onClick={() => onRemove(name)}>✕</button>
        </div>
      ))}
    </div>
  );
}

export default function App() {
  const [cartItems, setCartItems] = useState<string[]>([]);

  return (
    <div>
      <h1>Store</h1>
      <ProductList items={products} onAddToCart={(name) => setCartItems(prev => [...prev, name])} />
      <CartSummary itemCount={cartItems.length} items={cartItems} onRemove={(name) => setCartItems(prev => prev.filter(item => item !== name))} />
    </div>
  );
}
```
