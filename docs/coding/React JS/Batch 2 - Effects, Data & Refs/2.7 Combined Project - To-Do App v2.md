## Step 3 — ThemeContext (Context API)

Yaad hai 2.6 mein `useTheme()` custom hook banaya tha? Wohi pattern yahan bhi use karenge. Theme toggle ka logic ek hi jagah — `ThemeContext.tsx`:

**Step 3a — Types + createContext + useTheme hook:**

```ts
// context/ThemeContext.tsx
import { createContext, useContext, type ReactNode } from "react";

type Theme = "light" | "dark";

interface ThemeContextValue {
  theme: Theme;
  toggleTheme: () => void;
}

const ThemeContext = createContext<ThemeContextValue | undefined>(undefined);

export function useTheme(): ThemeContextValue {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error("useTheme must be used within ThemeProvider");
  return ctx;
}
```

**Step 3b — ThemeProvider with useMemo for stable value:**

Ab `ThemeProvider` banayenge. 2.6 mein dekha tha ki context value har render pe naya reference banati hai, jisse unnecessary re-renders hote hain. `useCallback` se `toggleTheme` stable rahega (kabhi naya reference nahi banega), aur `useMemo` se `value` tabhi change hogi jab `theme` change ho. Yeh pattern complex apps mein performance ke liye critical hai.

```tsx
import { useState, useCallback, useMemo } from "react";

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setTheme] = useState<Theme>("light");
  const toggleTheme = useCallback(() => {
    setTheme((prev) => (prev === "light" ? "dark" : "light"));
  }, []);

  const value = useMemo(() => ({ theme, toggleTheme }), [theme]);

  return <ThemeContext value={value}>{children}</ThemeContext>;
}
```

**Phase 3 — useRef for auto-focus:**

```tsx
function TaskInput({ onAdd }: { onAdd: (text: string) => void }) {
  const [text, setText] = useState("");
  const inputRef = useRef<HTMLInputElement>(null);

  useEffect(() => {
    inputRef.current?.focus();
  }, []);

  const handleClick = () => {
    console.log("Adding:", text);
  };

  return (
    <div>
      <input ref={inputRef} value={text} onChange={(e) => setText(e.target.value)} placeholder="Add a task..." />
      <button onClick={handleClick}>Add</button>
    </div>
  );
}
```

Page load — cursor automatically input mein aaya? ✅

**Phase 4 — Actual logic replace karo (console.log → onAdd):**

```tsx
const handleClick = () => {
  if (text.trim() !== "") {
    onAdd(text.trim());

};
```

**Step 5d — useEffect for categories API fetch (2.2 ka ignore pattern):**


## Common Mistakes

1. **useTheme() ko ThemeProvider ke bahar use karna** — Error aayega "must be used within ThemeProvider". Isliye `ToDoApp` ko `ThemeProvider` ke andar render kiya.
2. **Categories fetch mein error handling bhoolna** — Abhi sirf success case handle hai. Agar API down hui, `categories` empty array rahega. Production mein `try/catch` daalna chahiye (khud try karo section mein practice hai).
3. **TaskInput ka useRef cleanup bhoolna** — Input unmount pe automatically React DOM ref clean up kar deta hai, lekin agar koi side effect ref ke saath attach kiya hai toh cleanup zaroori hai.
4. **Context value ko memoize na karna** — `ThemeContext` mein `useMemo` use kiya hai. Bhoologe toh har render pe naya object reference → saare consuming components re-render.

## Khud Try Karo

1. Code likho — ThemeContext mein ek `isDark` helper add karo jo boolean return kare, aur use karo styling mein.
   
   <details>
   <summary>Sample Answer</summary>
   Context value mein `isDark: theme === "dark"` add karo. Phir `const { isDark } = useTheme();` se kahi bhi use karo — `background: isDark ? "#1a1a2e" : "#fff"`.
   </details>

2. Predict karo — agar `TaskInput` ka `useEffect([])` hata do toh kya hoga?

   <details>
   <summary>Sample Answer</summary>
   Input pe auto-focus nahi hoga. User ko manually input click karna padega type karne se pehle. UseEffect har render ke baad focus karta hai — lekin `[]` hone ki wajah se sirf mount pe ek baar focus hota hai.
   </details>

3. Modify karo — `categories` fetch mein error state bhi add karo (abhi sirf `setCategories` hai, error handle nahi hai).

   <details>
   <summary>Sample Answer</summary>
   `const [catError, setCatError] = useState<string | null>(null)` add karo. Fetch mein `try/catch` daalo, error pe `setCatError(err.message)`. UI mein `{catError && <p>❌ {catError}</p>}` dikhao.
   </details>
