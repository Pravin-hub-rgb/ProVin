# 2.5.1 — Accordion Mini Project Code

## Goal

Ek simple accordion banayenge. Pehle sirf ek section jo open/close hota hai. Phir doosra section add karenge — tab pata chalega ki "arey dono ek saath khul gaye?" Phir state lift karke fix karenge.

---

### Step 1 — Static HTML (single section)

**SOCH:** Ek section — heading + content. Koi state nahi, koi button nahi. Sirf HTML.

```tsx
function App() {
  return (
    <div>
      <h1>Accordion</h1>
      <h2>What is React?</h2>
      <p>React is a JavaScript library for building user interfaces.</p>
    </div>
  );
}
```

**TEST:** Browser mein content dikh raha hai. ✅

### Step 2 — h2 ko button mein badlo (clickable banao)

**SOCH:** Abhi `<h2>` sirf display karta hai — user click nahi kar sakta. Hume chahiye ki user click kare aur content show/hide ho. Isliye `<h2>` ki jagah `<button>` daalo. Button ka text wahi rahega, bas ab clickable ho gaya.

```tsx
function App() {
  return (
    <div>
      <h1>Accordion</h1>
      <button>What is React? ▼</button>
      <p>React is a JavaScript library for building user interfaces.</p>
    </div>
  );
}
```

Arrow (▼) visually batata hai ki yeh ek expandable section hai — closed hai toh ▼, open hai toh ▲.

**TEST:** Button dikh raha hai? Click karne par abhi kuch nahi hota — aage step mein logic dalenge. ✅

---

### Step 3 — Button pe onClick + useState daalo (toggle logic)

**SOCH:** Button click par content show/hide karna hai. Iske liye `useState` chahiye jo track kare ki currently open hai ya nahi. `false` = closed, `true` = open. Click karne par current value ka opposite set karo.

**CONCEPT — useState:** `useState(false)` — `false` matlab shuru mein chhupa hua. `setIsActive(!isActive)` — current value ka opposite set karo (true → false, false → true).

**CONCEPT — Conditional rendering:** `{isActive && <p>...}</p>` — agar `isActive` true hai toh `<p>` render hoga, nahi toh nahi. `&&` operator: left side true hai toh right side execute hota hai.

```tsx
import { useState } from "react";

function App() {
  const [isActive, setIsActive] = useState(false);

  return (
    <div>
      <h1>Accordion</h1>
      <button onClick={() => setIsActive(!isActive)}>
        What is React? {isActive ? "▲" : "▼"}
      </button>
      {isActive && <p>React is a JavaScript library for building user interfaces.</p>}
    </div>
  );
}
```

**TEST:** Button click karo → content show/hide ho raha hai? ▲ / ▼ bhi change ho raha hai? ✅

---

### Step 4 — Panel component banao (pattern reuse)

**SOCH:** Yeh pattern (button + toggle + conditional content) baad mein dubara use karenge. Isliye ek alag `Panel` component bana lo. `title` aur `children` props lo.

**CONCEPT — Component extraction:** Jab same HTML pattern repeat hone wala ho, toh alag component banao. `children` prop special hai — jo `<Panel>` ke andar likhoge, woh `{children}` mein aa jayega.

```tsx
function Panel({ title, children }: { title: string; children: React.ReactNode }) {
  const [isActive, setIsActive] = useState(false);

  return (
    <div>
      <button onClick={() => setIsActive(!isActive)}>
        {title} {isActive ? "▲" : "▼"}
      </button>
      {isActive && <div>{children}</div>}
    </div>
  );
}
```

Ab `App` clean ho gaya:

```tsx
function App() {
  return (
    <div>
      <h1>Accordion</h1>
      <Panel title="What is React?">
        <p>React is a JavaScript library for building user interfaces.</p>
      </Panel>
    </div>
  );
}
```

**TEST:** Same behavior — button click → toggle. Par ab component reusable hai. ✅

### Step 5 — Doosra Panel add karo (problem discover)

**SOCH:** Ab doosra section bhi add karte hain — "What is Lifting State Up?". Same `Panel` component reuse karo. Copy-paste karo.

```tsx
function App() {
  return (
    <div>
      <h1>Accordion</h1>
      <Panel title="What is React?">
        <p>React is a JavaScript library for building user interfaces.</p>
      </Panel>
      <Panel title="What is Lifting State Up?">
        <p>Moving state to a common parent so siblings can share data.</p>
      </Panel>
    </div>
  );
}
```

**TEST:**
1. Panel 1 click karo → content dikhta hai ✅
2. Panel 2 click karo → woh bhi content dikhata hai ✅
3. Lekin — **dono ek saath khule hain!** ❌

Yeh accordion nahi hai. Accordion mein sirf ek panel khulna chahiye. Lekin abhi har panel ka apna alag `useState` hai — dono ek doosre ko nahi jaante.

```
Panel 1 — const [isActive, setIsActive] = useState(false)  ← apna state
Panel 2 — const [isActive, setIsActive] = useState(false)  ← apna state, alag!
```

**Problem:** React mein data top → bottom jaata hai. Siblings (Panel 1 aur Panel 2) directly communicate nahi kar sakte. Isliye ek common parent (App) mein state rakhni padegi.

### Step 6 — Lift State to App (Obvious Approach — But Wrong)

**SOCH:** Problem clear hai — har Panel ka apna `useState` hai, isliye ek doosre ko nahi jaante. Lifting State Up ka pattern yaad hai? State child se nikaal kar common parent mein daalo. Toh pehla obvious attempt: `useState` App mein rakho, dono panels ko ek hi `isActive` boolean do.

Lekin pehle `Panel` ko controlled banao — apna state nahi, props se control:

```tsx
function Panel({ title, children, isActive, onToggle }: { title: string; children: React.ReactNode; isActive: boolean; onToggle: () => void }) {
  return (
    <div>
      <button onClick={onToggle}>
        {title} {isActive ? "▲" : "▼"}
      </button>
      {isActive && <div>{children}</div>}
    </div>
  );
}
```

Ab `App` mein ek single `isActive` state:

```tsx
export default function App() {
  const [isActive, setIsActive] = useState(false);

  return (
    <div>
      <h1>Accordion</h1>
      <Panel title="What is React?" isActive={isActive} onToggle={() => setIsActive(!isActive)}>
        <p>React is a JavaScript library for building user interfaces.</p>
      </Panel>
      <Panel title="What is Lifting State Up?" isActive={isActive} onToggle={() => setIsActive(!isActive)}>
        <p>Moving state to a common parent so siblings can share data.</p>
      </Panel>
    </div>
  );
}
```

**TEST:**
1. Panel 1 click → dono khul gaye ❌
2. Panel 2 click → dono band ho gaye ❌

**Problem:** `isActive` ek hi variable hai — dono panels use share kar rahe hain. Boolean `true` ya `false` sirf "sab open" ya "sab closed" bata sakta hai. Lekin hume chahiye "Panel 1 khule, Panel 2 band rahe" — ek boolean distinguish nahi kar sakta.

### Step 7 — `activeIndex`: State Ka Sahi Shape

**SOCH:** Ek room mein do bulbs hain. Ek single switch dono bulbs ko ek saath ON ya OFF karta hai — boolean ki tarah (`true` = sab ON, `false` = sab OFF). Lekin hum chahte hain ki kabhi bulb 1 jale, kabhi bulb 2 jale, kabhi dono band rahein. Ek switch kaam nahi karega — hume ek dial chahiye jo number select kare: "1" = bulb 1, "2" = bulb 2, "OFF" = sab band.

React mein bhi yehi hai. `isActive: boolean` sirf "sab open / sab closed" bata sakta hai — KAUNSA panel open hai, yeh nahi. Isliye hume `activeIndex: number | null` chahiye.

**CONCEPT — `number | null`:**

| Value | Matlab |
|---|---|
| `null` | Koi panel nahi khula |
| `0` | Panel 1 (index 0) khula hai |
| `1` | Panel 2 (index 1) khula hai |

Har panel apna index compare karega:

```tsx
<Panel isActive={activeIndex === 0} ... />   // Panel 1: true sirf jab activeIndex exactly 0
<Panel isActive={activeIndex === 1} ... />   // Panel 2: true sirf jab activeIndex exactly 1
```

`===` comparison operator hai — `activeIndex === 0` true/false return karta hai. Panel 1 ko `true` milega sirf jab `activeIndex` exactly `0` hai. Panel 2 tabhi active hoga jab `activeIndex` exactly `1` hai.

**Toggle logic — ternary operator:**

```
Agar yeh panel already active hai → null karo (band karo)
Nahi toh → iska index set karo (isay active karo)
```

```tsx
// Panel 1 ke liye:
onToggle={() => setActiveIndex(activeIndex === 0 ? null : 0)}

// Agar activeIndex already 0 hai → null (band). Nahi → 0 set kar.
```

```tsx
// Panel 2 ke liye:
onToggle={() => setActiveIndex(activeIndex === 1 ? null : 1)}

// Same logic, sirf index 1 hai.
```

**Poora code:**

```tsx
export default function App() {
  const [activeIndex, setActiveIndex] = useState<number | null>(null);

  return (
    <div>
      <h1>Accordion</h1>
      <Panel
        title="What is React?"
        isActive={activeIndex === 0}
        onToggle={() => setActiveIndex(activeIndex === 0 ? null : 0)}
      >
        <p>React is a JavaScript library for building user interfaces.</p>
      </Panel>
      <Panel
        title="What is Lifting State Up?"
        isActive={activeIndex === 1}
        onToggle={() => setActiveIndex(activeIndex === 1 ? null : 1)}
      >
        <p>Moving state to a common parent so siblings can share data.</p>
      </Panel>
    </div>
  );
}
```

**Data flow — Panel 1 click (jab koi nahi khula):**

```
1. User clicks Panel 1 → onToggle() call
2. activeIndex abhi null hai → activeIndex === 0 → false
3. false ? null : 0 → 0 mila → setActiveIndex(0)
4. React re-render
5. Panel 1: isActive={0 === 0} → true ✅ (khul gaya)
6. Panel 2: isActive={0 === 1} → false ❌ (band raha)
```

**Data flow — Panel 1 click (jab pehle se khula hai):**

```
1. activeIndex abhi 0 hai → activeIndex === 0 → true
2. true ? null : 0 → null mila → setActiveIndex(null)
3. React re-render
4. Panel 1: isActive={null === 0} → false ❌ (band ho gaya)
5. Panel 2: isActive={null === 1} → false ❌ (band hi tha)
```

**TEST:**
1. Panel 1 click → khul gaya ✅
2. Panel 2 click → Panel 1 band, Panel 2 khula ✅
3. Panel 2 dobara click → band ho gaya ✅
4. Kabhi dono ek saath nahi khulte ✅

## Final Code

```tsx
import { useState } from "react";

function Panel({ title, children, isActive, onToggle }: { title: string; children: React.ReactNode; isActive: boolean; onToggle: () => void }) {
  return (
    <div>
      <button onClick={onToggle}>
        {title} {isActive ? "▲" : "▼"}
      </button>
      {isActive && <div>{children}</div>}
    </div>
  );
}

export default function App() {
  const [activeIndex, setActiveIndex] = useState<number | null>(null);

  return (
    <div>
      <h1>Accordion</h1>
      <Panel
        title="What is React?"
        isActive={activeIndex === 0}
        onToggle={() => setActiveIndex(activeIndex === 0 ? null : 0)}
      >
        <p>React is a JavaScript library for building user interfaces.</p>
      </Panel>
      <Panel
        title="What is Lifting State Up?"
        isActive={activeIndex === 1}
        onToggle={() => setActiveIndex(activeIndex === 1 ? null : 1)}
      >
        <p>Moving state to a common parent so siblings can share data.</p>
      </Panel>
    </div>
  );
}
```

## What It Is NOT

- **Global state nahi hai** — state App mein hai (common parent), kisi global store mein nahi. Har accordion instance ka apna `activeIndex` hoga agar do alag pages par ho.
- **Sirf boolean kaafi nahi** — `isActive: boolean` do panels distinguish nahi kar sakta. State ka shape bhi matter karta hai, sirf location nahi.
- **Hardcoded index fix nahi hai** — `activeIndex === 0` aur `activeIndex === 1` hardcoded likhna manually karna pada. Baad mein seekhenge ki arrays ke saath automatically kaise karein.
- **Prop drilling ka solution nahi hai** — yeh sirf 2 level deep hai. Deep tree ke liye Context API chahiye hogi.

## Common Mistakes

1. **Lift karte waqt state ka shape nahi badalna** — `isActive` boolean le kar App mein lift kiya, par wohi boolean dono panels ko diya → dono ek saath toggle hue. State location + shape dono important hain.
2. **Ek panel ka index galti se duplicate karna** — agar dono panels `activeIndex === 0` check karein, toh dono ek saath khulenge (wahi boolean wali problem).
3. **Ternary operator bhoolna** — `setActiveIndex(0)` sirf set karta hai, toggle nahi. Toggle ke liye pehle check karna padega ki kya yeh already active hai.
4. **Type bhoolna** — `useState<number | null>(null)` ki jagah `useState(null)` likh diya → TypeScript infer karega `null` type, aur `activeIndex === 0` pe error dega.

   </details>

## In Your Own Words

1. Accordion project mein `isActive` (boolean) ki jagah `activeIndex` (number | null) kyun use kiya?

   <details>
   <summary>Sample Answer</summary>

   Boolean sirf "open ya closed" bata sakta hai — ek value dono panels ke liye same hoti hai. Isliye jab humne `isActive` App mein rakha, dono panels ek saath open/close hote the. `activeIndex` specific batata hai KAUNSA panel open hai — `0` = panel 1, `1` = panel 2, `null` = koi nahi. Har panel apna index compare karta hai (`=== 0`, `=== 1`), isliye sirf ek panel active rehta hai.
   </details>

2. Lift State Up ke 2 steps kya hain jo humne is file mein kiye?

   <details>
   <summary>Sample Answer</summary>

   Step 1: State (useState) Panel se nikaal kar App mein daala. Step 2: Data prop mein diya (`isActive`, `onToggle`) — Panel ab controlled component ban gaya (apna state nahi, parent control karta hai). Step 6 mein yeh kiya. Phir ek additional step: state ka shape bhi change kiya (boolean → activeIndex) kyunki boolean distinguish nahi kar sakta.
   </details>

3. `activeIndex: number | null` mein `null` ka kya matlab hai?

   <details>
   <summary>Sample Answer</summary>

   `null` matlab "koi panel nahi khula." Yeh initial state hai — shuru mein sab band. Jab user open panel ko dobara click kare, tab bhi `null` set hota hai (band karne ke liye). Agar teen panels hote, toh `0`, `1`, `2` open states hoti, aur `null` matlab sab band.
   </details>

4. Ternary operator `activeIndex === 0 ? null : 0` kaise kaam karta hai?

   <details>
   <summary>Sample Answer</summary>

   Yeh ek inline if-else hai. Pehle condition check hoti hai: `activeIndex === 0` (kya yeh panel already active hai?). Agar true → `null` return (band karo). Agar false → `0` return (active karo). Toggle logic: already khula hai toh band, band hai toh khol.
   </details>

5. Agar 4 panels hote (`activeIndex` 0, 1, 2, 3), toh code mein kya badalta?

   <details>
   <summary>Sample Answer</summary>

   Sirf teen cheezein badalti: (1) `useState<number | null>(null)` wahi rahega — number type hai, koi limit nahi. (2) Har naye panel ke liye `isActive={activeIndex === N}` aur `onToggle={() => setActiveIndex(activeIndex === N ? null : N)}` — N = 0, 1, 2, 3. (3) State logic wahi hai — ek number track karta hai kaunsa panel active hai. Isliye `number | null` scalable hai, boolean nahi.
   </details>
