# 2.5.1 — Accordion Mini Project Code

## Goal

Ek simple accordion banayenge. Pehle sirf ek section jo open/close hota hai. Phir doosra section add karenge — tab pata chalega ki "arey dono ek saath khul gaye?" Phir state lift karke fix karenge.

---

### Step 1 — Static HTML (single section)

**SOCH:** Ek section — heading + content. Koi state nahi, koi button nahi. Sirf HTML.

```tsx
function App() {
  return (
    <div>
      <h1>Accordion</h1>
      <h2>What is React?</h2>
      <p>React is a JavaScript library for building user interfaces.</p>
    </div>
  );
}
```

**TEST:** Browser mein content dikh raha hai. ✅

---

### Step 2 — h2 ko button mein badlo (clickable banao)

**SOCH:** Abhi `<h2>` sirf display karta hai — user click nahi kar sakta. Hume chahiye ki user click kare aur content show/hide ho. Isliye `<h2>` ki jagah `<button>` daalo. Button ka text wahi rahega, bas ab clickable ho gaya.

```tsx
function App() {
  return (
    <div>
      <h1>Accordion</h1>
      <button>What is React? ▼</button>
      <p>React is a JavaScript library for building user interfaces.</p>
    </div>
  );
}
```

Arrow (▼) visually batata hai ki yeh ek expandable section hai — closed hai toh ▼, open hai toh ▲.

**TEST:** Button dikh raha hai? Click karne par abhi kuch nahi hota — aage step mein logic dalenge. ✅

---

### Step 3 — Button pe onClick + useState daalo (toggle logic)

**SOCH:** Button click par content show/hide karna hai. Iske liye `useState` chahiye jo track kare ki currently open hai ya nahi. `false` = closed, `true` = open. Click karne par current value ka opposite set karo.

**CONCEPT — useState:** `useState(false)` — `false` matlab shuru mein chhupa hua. `setIsActive(!isActive)` — current value ka opposite set karo (true → false, false → true).

**CONCEPT — Conditional rendering:** `{isActive && <p>...}</p>` — agar `isActive` true hai toh `<p>` render hoga, nahi toh nahi. `&&` operator: left side true hai toh right side execute hota hai.

```tsx
import { useState } from "react";

function App() {
  const [isActive, setIsActive] = useState(false);

  return (
    <div>
      <h1>Accordion</h1>
      <button onClick={() => setIsActive(!isActive)}>
        What is React? {isActive ? "▲" : "▼"}
      </button>
      {isActive && <p>React is a JavaScript library for building user interfaces.</p>}
    </div>
  );
}
```

**TEST:** Button click karo → content show/hide ho raha hai? ▲ / ▼ bhi change ho raha hai? ✅

---

### Step 4 — Panel component banao (pattern reuse)

**SOCH:** Yeh pattern (button + toggle + conditional content) baad mein dubara use karenge. Isliye ek alag `Panel` component bana lo. `title` aur `children` props lo.

**CONCEPT — Component extraction:** Jab same HTML pattern repeat hone wala ho, toh alag component banao. `children` prop special hai — jo `<Panel>` ke andar likhoge, woh `{children}` mein aa jayega.

```tsx
function Panel({ title, children }: { title: string; children: React.ReactNode }) {
  const [isActive, setIsActive] = useState(false);

  return (
    <div>
      <button onClick={() => setIsActive(!isActive)}>
        {title} {isActive ? "▲" : "▼"}
      </button>
      {isActive && <div>{children}</div>}
    </div>
  );
}
```

Ab `App` clean ho gaya:

```tsx
function App() {
  return (
    <div>
      <h1>Accordion</h1>
      <Panel title="What is React?">
        <p>React is a JavaScript library for building user interfaces.</p>
      </Panel>
    </div>
  );
}
```

**TEST:** Same behavior — button click → toggle. Par ab component reusable hai. ✅

2. Panel 2 click karo → woh bhi content dikhata hai ✅

Yeh accordion nahi hai. Accordion mein sirf ek panel khulna chahiye. Lekin abhi har panel ka apna alag `useState` hai — dono ek doosre ko nahi jaante.

```
Panel 1 — const [isActive, setIsActive] = useState(false)  ← apna state
Panel 2 — const [isActive, setIsActive] = useState(false)  ← apna state, alag!
```

**Problem:** React mein data top → bottom jaata hai. Siblings (Panel 1 aur Panel 2) directly communicate nahi kar sakte. Isliye ek common parent (App) mein state rakhni padegi.

---

### Step 6a — Lift `isActive` to App (pehla attempt, simple)

**SOCH:** State `Panel` ke andar hai — isliye ek panel doosre ko nahi jaanta. Pahla kadam: state `App` mein rakh do. `Panel` se `useState` hatao, props ke through control karo.

**CONCEPT — Lifting State Up:** State child se nikaal kar common parent mein daalna. Data props mein do (down), actions callbacks mein do (up).

Pehle `Panel` ko controlled banao — apna state nahi, props se control:

```tsx
function Panel({ title, children, isActive, onToggle }: { title: string; children: React.ReactNode; isActive: boolean; onToggle: () => void }) {
  return (
    <div>
      <button onClick={onToggle}>
        {title} {isActive ? "▲" : "▼"}
      </button>
      {isActive && <div>{children}</div>}
    </div>
  );
}
```

Ab `App` mein ek single `isActive` state:

```tsx
export default function App() {
  const [isActive, setIsActive] = useState(false);

  return (
    <div>
      <h1>Accordion</h1>
      <Panel title="What is React?" isActive={isActive} onToggle={() => setIsActive(!isActive)}>
        <p>React is a JavaScript library for building user interfaces.</p>
      </Panel>
      <Panel title="What is Lifting State Up?" isActive={isActive} onToggle={() => setIsActive(!isActive)}>
        <p>Moving state to a common parent so siblings can share data.</p>
      </Panel>
    </div>
  );
}
```

**TEST:**
1. Panel 1 click karo — content dikhta hai ✅
2. Panel 2 click karo — woh bhi content dikhata hai ✅
3. Lekin... **dono ek saath toggle ho rahe hain!** ❌

Click Panel 1 → dono khule. Click Panel 2 → dono band. Click again → dono khule.

### Step 6b — Problem: Ek `isActive` dono ke liye kaam nahi karta

**SOCH:** `isActive` ek hi variable hai — dono panels use share kar rahe hain. Isliye click karne par dono ek saath react karte hain. Hume chahiye ki har panel ka apna **identity** ho — pehla panel alag, doosra alag. Ek boolean (true/false) kaafi nahi.

**CONCEPT:** Do panels hain — unki identity index se identify karo: Panel 1 = index 0, Panel 2 = index 1. State ab `activeIndex` rakhega — `number | null`. `null` = koi nahi khula. `0` = pehla khula. `1` = doosra khula.

```
Single boolean → dono panels same state share karte hain
Index (0, 1, null) → har panel ko apna index check karta hai
```

### Step 6c — `isActive` se `activeIndex` mein switch karo

**SOCH:** Problem clear hai — `isActive` ek single boolean hai, dono panels use share kar rahe hain. Hum chahte hain ki har panel ka apna indicator ho — "yeh active hai ya nahi." Lekin do alag boolean rakhna bhi sahi nahi — kya hoga 10 panels ho toh?

**CONCEPT — Index identify karta hai ki kaunsa panel active hai:** Do panels hain. Unki identity unke index se define karo. Panel 1 ka index `0`, Panel 2 ka index `1`. State ab yeh track karegi: **"kaunse index wala panel currently open hai?"**

```
State types:
  boolean (true/false) — sirf "open ya closed" bata sakta hai, "kaunsa" nahi
  number | null — null = koi nahi, 0 = panel 1, 1 = panel 2
```

Isliye `isActive: boolean` ki jagah `activeIndex: number | null` use karenge.

---

**Step 6c.1 — State type change karo**

Pehle state ka type change karo — boolean se number | null:

```tsx
const [activeIndex, setActiveIndex] = useState<number | null>(null);
```

`null` matlab "shuru mein koi panel nahi khula." Agar Panel 1 click ho → `setActiveIndex(0)`. Agar Panel 2 → `setActiveIndex(1)`.

---

**Step 6c.2 — `isActive` prop ka logic change karo**

Ab `isActive` prop ko boolean ki jagah comparison se calculate karna padega.

Pehle (galat — dono same):
```tsx
<Panel isActive={isActive} ... />   // same value dono ko
<Panel isActive={isActive} ... />   // same value dono ko
```

Ab (sahi — har panel apna index check karta hai):
```tsx
isActive={activeIndex === 0}   // Panel 1 tabhi active jab activeIndex exactly 0
isActive={activeIndex === 1}   // Panel 2 tabhi active jab activeIndex exactly 1
```

Yeh kaam karta hai kyunki:
- `===` ek comparison operator hai — `activeIndex === 0` true/false return karta hai
- Panel 1 ko `isActive` prop mein `true` milega sirf jab `activeIndex` exactly `0` hai
- Panel 2 ko `isActive` prop mein `true` milega sirf jab `activeIndex` exactly `1` hai

---

**Step 6c.3 — `onToggle` callback ka logic change karo**

Ab `onToggle` bhi change karna padega. Pehle hum `setIsActive(!isActive)` karte the (toggle boolean). Ab boolean nahi hai — number hai. Logic ab hoga:

> "Agar yeh panel already active hai (activeIndex iske index ke barabar hai), toh null kar do (band). Nahi toh iska index set kar do (yeh active)."

Panel 1 ke liye:
```tsx
onToggle={() => setActiveIndex(activeIndex === 0 ? null : 0)}
```

Line by line samajh:
- `activeIndex === 0` — check: kya yeh panel already active hai?
- `? null : 0` — ternary operator. Agar haan (already active) → null (band karo). Nahi → 0 (active karo)

Panel 2 ke liye:
```tsx
onToggle={() => setActiveIndex(activeIndex === 1 ? null : 1)}
```

Same logic, sirf index `1` hai kyunki yeh doosra panel hai.

---

**Step 6c.4 — Complete code**

```tsx
export default function App() {
  const [activeIndex, setActiveIndex] = useState<number | null>(null);

  return (
    <div>
      <h1>Accordion</h1>
      <Panel
        title="What is React?"
        isActive={activeIndex === 0}
        onToggle={() => setActiveIndex(activeIndex === 0 ? null : 0)}
      >
        <p>React is a JavaScript library for building user interfaces.</p>
      </Panel>
      <Panel
        title="What is Lifting State Up?"
        isActive={activeIndex === 1}
        onToggle={() => setActiveIndex(activeIndex === 1 ? null : 1)}
      >
        <p>Moving state to a common parent so siblings can share data.</p>
      </Panel>
    </div>
  );
}
```

**Data flow — click Panel 1:**
1. `onToggle={() => setActiveIndex(activeIndex === 0 ? null : 0)}` — yeh callback call hua
2. ActiveIndex abhi `null` hai (ya 1) — `activeIndex === 0` false hai
3. Ternary: `false ? null : 0` → `0` set hua
4. React re-render karta hai
5. Panel 1: `isActive={activeIndex === 0}` → `activeIndex` ab `0` hai → `true` ✅
6. Panel 2: `isActive={activeIndex === 1}` → `activeIndex` ab `0` hai → `false` ❌
7. Sirf Panel 1 dikh raha hai

**Data flow — Panel 1 click karo jab already open hai:**
1. `activeIndex === 0` true hai
2. Ternary: `true ? null : 0` → `null` set hua
3. React re-render
4. Panel 1: `isActive={null === 0}` → `false` ❌
5. Dono band ho gaye

---

2. Panel 2 click → Panel 1 band, Panel 2 khula ✅
3. Panel 2 dobara click → band ho gaya ✅

## Final Code

```tsx
import { useState } from "react";

function Panel({ title, children, isActive, onToggle }: { title: string; children: React.ReactNode; isActive: boolean; onToggle: () => void }) {

        {title} {isActive ? "▲" : "▼"}

```
