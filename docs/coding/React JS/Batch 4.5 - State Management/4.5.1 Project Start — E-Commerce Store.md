
## Goal

In this 4.5 series, we'll build an E-Commerce Store — product listing grid, product detail page with dynamic routes, shopping cart with add/remove/quantity, checkout form with RHF + Zod validation, and order confirmation. All styled with Tailwind. Accessible throughout — keyboard navigation, focus management, ARIA, screen-reader friendly.

<ecommerce-demo></ecommerce-demo>

---

Let's start with project setup.

```
bun create vite@latest ecommerce-store --template react-ts
cd ecommerce-store
bun run dev
```

Browser shows Vite's default page. Open `src/App.tsx`, wipe the boilerplate, keep just a heading:

```tsx
function App() {
  return <h1 className="text-3xl font-bold p-8">E-Commerce Store</h1>
}

export default App
```

Set up Tailwind:

```
bun add tailwindcss @tailwindcss/vite
```

In `vite.config.ts`:

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

In `src/index.css`:

```css
@import "tailwindcss";
```

Browser shows the heading, styled by Tailwind.

Project is ready. Next step — build the product listing.
