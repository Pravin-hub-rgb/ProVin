## Step 1 — Visualizer Component

Pehle ek helper component banate hain jo render count track kare. Yeh har component ke andar use hoga.

**Pehle intuitive approach sochte hain — ek counter increment karo har render pe:**

```tsx
// ❌ Kaam nahi karega
export default function RenderCount({ label }: { label: string }) {
  let count = 0
  count++ // Local variable — har render pe reset ho jayega
  return <p>{label} rendered: {count} times</p>
}
```

`let count = 0` component function ke andar hai — har render pe dobara `0` set hota hai, `count++` useless. Count hamesha 1 dikhega.

**Module-level variable try karte hain — component ke bahar:**

```tsx
// ❌ React 19 error
const counts: Record<string, number> = {}

export default function RenderCount({ label }: { label: string }) {
  counts[label] = (counts[label] ?? 0) + 1 // Error!
  return <p>{label} rendered: {counts[label]} times</p>
}
```

React 19 error dega: *"Modifying a variable defined outside a component is not allowed."* React chahta hai ki render phase mein components **pure** rahein — sirf props aur state padho, koi side effect mat karo.

**useRef try karte hain — component ke andar persistent storage:**

```tsx
// ❌ React 19 error
import { useRef } from 'react'

export default function RenderCount({ label }: { label: string }) {
  const count = useRef(0)
  count.current++          // Error: Cannot access refs during render
  return <p>{label} rendered: {count.current} times</p>
}
```

React 19: *"Cannot access refs during render."* `ref.current` sirf event handlers ya effects mein access kar sakte ho, render mein nahi.

**useEffect try karte hain — render ke baad increment:**

```tsx
// ❌ Infinite loop
import { useEffect, useState } from 'react'

export default function RenderCount({ label }: { label: string }) {
  const [count, setCount] = useState(0)

  useEffect(() => {
    setCount(c => c + 1) // Effect → setState → re-render → effect → ...
  })

  return <p>{label} rendered: {count} times</p>
}
```

`useEffect` har render ke baad chalta hai. `setCount` state change karta hai → component re-render → effect dobara chalta hai → `setCount` phir call → **infinite loop**. React crash ho jayega.

**Toh render count track kaise karein React 19 mein?**

Pehle ek baat samajh lo — React ka rendering **do phases** mein hota hai:

### Phase 1: Render Phase (blueprint banana)

Jab tumhara component function call hota hai — JSX return hota hai — React sochta hai "kya change karna hai?"

Yahan koi bhi **side effect** (variable modify karna, API call, console.log) mana hai. React chahta hai ki yeh phase **pure** ho — sirf props/padho, JSX do.

Agar tum render phase mein module-level variable change karoge toh React error dega: *"Modifying a variable defined outside a component is not allowed."*

### Phase 2: Commit Phase (actual construction)

React ne decide kar liya ki kya change karna hai. Ab woh asli DOM ko update karta hai. Yahan side effects chala sakte ho — `useEffect` yahan chalta hai, `Profiler` ka `onRender` yahan chalta hai.

### Analogy

Socho tum ek architect ho:

| Phase | Architect ki tarah | React ki tarah |
|-------|-------------------|----------------|
| **Render** | Blueprint banao — kya banana hai decide karo | Component function call karo, JSX lo |
| **Commit** | Asli construction karo — deewar banao, paint karo | DOM update karo, effects chalao |

Blueprint banaate waqt tum deewar nahi toda sakte (side effect). Construction waqt toda sakte ho. React bhi yahi karta hai.

### Ab solution

React ka built-in `Profiler` component hota hai. Iska `onRender` callback **commit phase** mein chalta hai — matlab blueprint ban chuka hai, ab asli construction chal rahi hai. Yahan module-level variable modify kar sakte hain:

```tsx
// ✅ React 19 compatible
import { Profiler } from 'react'

const counts: Record<string, number> = {}

export default function RenderCount({ label }: { label: string }) {
  return (
    <Profiler id={label} onRender={() => { counts[label] = (counts[label] ?? 0) + 1 }}>
      <div className="text-xs text-gray-400 mb-1">
        {label} rendered: {counts[label] ?? 0} times
      </div>
    </Profiler>
  )
}
```

Ab samjho kyun error nahi aata:

| Step | Kaunsa Phase | Kya ho raha hai |
|------|-------------|-----------------|
| 1️⃣ | **Render** | Component function call hua → `<div>` evaluate hua → `{counts[label] ?? 0}` **padha** (modify nahi) ✅ |
| 2️⃣ | **Commit** | React ne `<div>` ko DOM mein daala → `onRender` fire hua → `counts[label]++` **modify** kiya ✅ |

Do alag phases — render mein padho, commit mein likho. React khush.

**Ek chhota catch:** Pehli render pe display `0` dikhega kyunki commit phase abhi tak nahi hua (counts[label] increment nahi hua). Lekin jaise hi koi button click karega — naya render trigger hoga — tab `counts[label]` ki value 1 hogi, display sahi dikhega.

## Step 2 — Problem Dikhane Wala Version

Pehle woh version banate hain jisme koi optimization nahi — taaki problem clearly dikhe:

```tsx
// App.tsx
import { useState } from 'react'
import RenderCount from './RenderCount'

function ExpensiveCard({ value }: { value: number }) {
  return (
    <div className="border p-4 rounded">
      <RenderCount label="ExpensiveCard" />
      <p>Value: {value}</p>
    </div>
  )
}

function Sidebar() {
  return (
    <div className="border p-4 rounded bg-gray-50">
      <RenderCount label="Sidebar" />
      <p>Sidebar — kuch nahi badalta</p>
    </div>
  )
}

export default function App() {
  const [count, setCount] = useState(0)
  const [value, setValue] = useState(42)

  return (
    <div className="p-8 space-y-4">
      <RenderCount label="App" />
      
      <div className="space-x-2">
        <button onClick={() => setCount(c => c + 1)}>
          Re-render App ({count})
        </button>
        <button onClick={() => setValue(v => v + 1)}>
          Change Value ({value})
        </button>
      </div>

      <div className="flex gap-4">
        <ExpensiveCard value={value} />
        <Sidebar />
      </div>
    </div>
  )
}
```

Ab browser mein dekh. Har baar koi bhi button click karo — sab components re-render ho rahe hain:
- `App` — obviously, state change hui
- `ExpensiveCard` — value change nahi hui, phir bhi render ho raha
- `Sidebar` — kuch change nahi hua, phir bhi render ho raha

## Step 3 — React.memo Lagao

Pehle `Sidebar` ko memo karte hain — iske koi props nahi, kabhi change nahi hona chahiye:

```tsx
// App.tsx
import { memo } from 'react'

const Sidebar = memo(function Sidebar() {
  return (
    <div className="border p-4 rounded bg-gray-50">
      <RenderCount label="Sidebar" />
      <p>Sidebar — kuch nahi badalta</p>
    </div>
  )
})
```

Ab `ExpensiveCard` ko bhi memo karo:

```tsx
// App.tsx
interface ExpensiveCardProps {
  value: number
}

const ExpensiveCard = memo(function ExpensiveCard({ value }: ExpensiveCardProps) {
  return (
    <div className="border p-4 rounded">
      <RenderCount label="ExpensiveCard" />
      <p>Value: {value}</p>
    </div>
  )
})
```

Ab test karo:

- Pehli baar render — sab 1 baar
- "Re-render App" click — sirf `App` render hoga. `ExpensiveCard` aur `Sidebar` skip. Dekha? `value` change nahi hui, isliye memo ne render skip kiya.
- "Change Value" click — `App` re-render, `ExpensiveCard` re-render (kyunki `value` change hui), `Sidebar` skip.

## Step 4 — Problem — Inline Function Se Memo Toot Gaya

Ab `ExpensiveCard` mein `onClick` prop add karte hain — jaise real app mein event handler hota hai. Pura component dikh raha hai ab — saath mein problem bhi:

```tsx
// App.tsx
import { memo, useState } from 'react'
import RenderCount from './RenderCount'

const ExpensiveCard = memo(function ExpensiveCard({
  value, onClick
}: {
  value: number
  onClick: () => void
}) {
  return (
    <div className="border p-4 rounded">
      <RenderCount label="ExpensiveCard" />
      <button
        onClick={onClick}
        className="bg-red-500 text-white px-4 py-2 rounded m-2 cursor-pointer"
      >
        Expensive Card Click
      </button>
      <p>Value: {value}</p>
    </div>
  )
})

export default function App() {
  const [count, setCount] = useState(0)
  const [value, setValue] = useState(42)

  const handleClick = () => {                // ❌ Har render pe naya function
    console.log('card clicked')
  }

  return (
    <div className="p-8 space-y-4">
      <RenderCount label="App" />

      <div className="space-x-2">
        <button onClick={() => setCount(c => c + 1)}>
          Re-render App ({count})
        </button>
        <button onClick={() => setValue(v => v + 1)}>
          Change Value ({value})
        </button>
      </div>

      <ExpensiveCard value={value} onClick={handleClick} />
      <Sidebar />
    </div>
  )
}
```

Ab "Re-render App" click karo — `ExpensiveCard` phir se render ho raha hai! `Sidebar` theek hai (usme koi prop nahi badla) lekin `ExpensiveCard` memo fail ho gaya.

**Kyun?** `handleClick` ek regular function hai jo `App()` ke andar define hai. Har baar `App` re-render hota hai — ek naya `handleClick` function memory mein banta hai. Naya reference = naya `onClick` prop = `Object.is(oldFn, newFn)` → false → memo re-render.

Memo sirf tab render skip karta hai jab props ka reference **same** ho. Inline function har render pe naya reference banata hai — memo useless.

## Step 5 — useCallback Se Fix

```tsx
// App.tsx
import { useCallback } from 'react'

const handleClick = useCallback(() => {
  console.log('card clicked')
}, []) // koi dependency nahi — kabhi change nahi hoga
```

Ab test karo — `ExpensiveCard` phir se skip kar raha hai. Function reference stable ho gaya.

## Step 6 — useMemo — Derived Data Cache Karna

Ab ek heavy calculation add karte hain — socho ek function hai jo bahut time leta hai:

```tsx
// App.tsx
function slowCalculation(num: number): number {
  console.log('⚡ slow calculation chal raha hai')
  let result = 0
  for (let i = 0; i < 10000000; i++) {
    result += num * i
  }
  return result
}

function App() {
  const [count, setCount] = useState(0)
  const [value, setValue] = useState(42)

  const computed = slowCalculation(value) // ❌ Har render pe chal raha hai

  return (
    // ...
    <p>Computed: {computed}</p>
    // ...
  )
}
```

Har baar "Re-render App" click pe `slowCalculation` chal raha hai — chahe `value` change nahi hui. Browser freeze ho raha hai.

UseMemo se fix:

```tsx
const computed = useMemo(() => slowCalculation(value), [value])
```

Ab `slowCalculation` sirf tab chalega jab `value` change ho. Count change pe — cached result use hoga.

## Step 7 — Final Component Tree with All Optimizations

```tsx
import { useState, useMemo, useCallback, memo } from 'react'

const Sidebar = memo(function Sidebar() {
  return (
    <div className="border p-4 rounded bg-gray-50">
      <RenderCount label="Sidebar" />
      <p>Sidebar — static content</p>
    </div>
  )
})

const ExpensiveCard = memo(function ExpensiveCard({
  value, onClick
}: {
  value: number
  onClick: () => void
}) {
  return (
    <div className="border p-4 rounded" onClick={onClick}>
      <RenderCount label="ExpensiveCard" />
      <p>Value: {value}</p>
    </div>
  )
})

export default function App() {
  const [count, setCount] = useState(0)
  const [value, setValue] = useState(42)

  const handleClick = useCallback(() => {
    console.log('card clicked')
  }, [])

  const computed = useMemo(() => {
    console.log('⚡ heavy calculation')
    let result = 0
    for (let i = 0; i < 10000000; i++) result += value * i
    return result
  }, [value])

  return (
    <div className="p-8 space-y-4">
      <button onClick={() => setCount(c => c + 1)}>
        Re-render App ({count})
      </button>
      <button onClick={() => setValue(v => v + 1)}>
        Change Value ({value})
      </button>
      <p>Computed: {computed}</p>
      <ExpensiveCard value={value} onClick={handleClick} />
      <Sidebar />
    </div>
  )
}
```

Render counts dekhna:

| Action | App | ExpensiveCard | Sidebar | slowCalculation |
|--------|-----|---------------|---------|-----------------|
| Initial | 1 | 1 | 1 | चला |
| Re-render App | 2 | 1 (skip) | 1 (skip) | nahi chala |
| Change Value | 3 | 2 | 1 (skip) | chala (value change) |
| Re-render App | 4 | 2 (skip) | 1 (skip) | nahi chala |
