## Step 1 — Static Gallery Component

Pehle gallery component banate hain — yeh directly import hoga (lazy nahi, kyunki yeh initial page hai):

```tsx
// Gallery.tsx
import { Link } from 'react-router-dom'

const images = [
  { id: 1, src: 'https://picsum.photos/id/1/400/300', title: 'Mountain' },
  { id: 2, src: 'https://picsum.photos/id/10/400/300', title: 'Forest' },
  { id: 3, src: 'https://picsum.photos/id/100/400/300', title: 'Lake' },
  { id: 4, src: 'https://picsum.photos/id/200/400/300', title: 'City' },
]

export default function Gallery() {
  return (
    <div className="p-8">
      <h1 className="text-2xl font-bold mb-6">Image Gallery</h1>
      <div className="grid grid-cols-2 gap-4">
        {images.map(img => (
          <Link
            key={img.id}
            to={`/image/${img.id}`}
            className="block border rounded overflow-hidden hover:shadow-lg transition-shadow"
          >
            <img src={img.src} alt={img.title} className="w-full h-48 object-cover" />
            <p className="p-2 text-center font-medium">{img.title}</p>
          </Link>
        ))}
      </div>
    </div>
  )
}
```

## Step 2 — Image Detail Component (Heavy)

Ab detail component banate hain — yeh deliberately "heavy" rakhenge taaki lazy loading justify ho:

```tsx
// ImageDetail.tsx
import { useParams, Link } from 'react-router-dom'

const images = [
  { id: 1, src: 'https://picsum.photos/id/1/800/600', title: 'Mountain', desc: 'A beautiful mountain landscape' },
  { id: 2, src: 'https://picsum.photos/id/10/800/600', title: 'Forest', desc: 'Deep green forest pathway' },
  { id: 3, src: 'https://picsum.photos/id/100/800/600', title: 'Lake', desc: 'Calm lake at sunset' },
  { id: 4, src: 'https://picsum.photos/id/200/800/600', title: 'City', desc: 'City skyline at night' },
]

export default function ImageDetail() {
  const { id } = useParams<{ id: string }>()
  const image = images.find(img => img.id === Number(id))

  if (!image) return <div className="p-8 text-center">Image nahi mili</div>

  // Simulating heavy processing
  const start = Date.now()
  while (Date.now() - start < 100) { /* heavy loop */ }

  return (
    <div className="p-8">
      <Link to="/" className="text-blue-500 underline mb-4 block">← Back to Gallery</Link>
      <img src={image.src} alt={image.title} className="w-full max-w-2xl rounded-lg" />
      <h2 className="text-xl font-bold mt-4">{image.title}</h2>
      <p className="text-gray-600 mt-2">{image.desc}</p>
    </div>
  )
}
```

## Step 3 — App.tsx — Lazy Import Detail Route

Ab App.tsx mein Gallery direct import karo, ImageDetail lazy import karo:

```tsx
// App.tsx
import { lazy, Suspense } from 'react'
import { BrowserRouter, Routes, Route } from 'react-router-dom'
import Gallery from './Gallery'

// ImageDetail ek alag chunk banega — tab load hoga jab user /image/:id pe jayega
const ImageDetail = lazy(() => import('./ImageDetail'))

export default function App() {
  return (
    <BrowserRouter>
      <Suspense fallback={
        <div className="p-8 text-center text-gray-500">
          Image load ho rahi hai...
        </div>
      }>
        <Routes>
          <Route path="/" element={<Gallery />} />
          <Route path="/image/:id" element={<ImageDetail />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  )
}
```

---

## Step 4 — Verify — Network Tab

Network tab (F12 → Network) kholo aur:

1. Page reload karo — sirf Gallery ka chunk download hoga (initial route / hai)
2. Kisi image pe click karo — `/image/:id` route activate hota hai
3. Naya chunk download ho raha hai — woh `ImageDetail.tsx` ka chunk hai
4. Suspense fallback dikhta hai (loading text) jab tak chunk load na ho
5. Chunk load → ImageDetail render → fallback replace

---

## Step 5 — Preloading (Optional)

Agar chahte ho ki hover pe hi chunk preload ho jaye (click pe delay na ho) — toh `React.lazy` ke `import()` ko manually call kar sakte ho:

```tsx
// Gallery.tsx meLink hover pe preload
import { Link } from 'react-router-dom'

function preloadImageDetail() {
  // React.lazy import wahi hai — pehle se call karo toh cache ho jayega
  import('./ImageDetail')
}

// Link mein onMouseEnter
<Link
  to={`/image/${img.id}`}
  onMouseEnter={preloadImageDetail}
  // ...
>
```

Ab user link pe hover karega — chunk download start ho jayega. Click karega — instantly render (already downloaded). Delay zero.

## Summary

✅ **Gallery** — synchronous import — initial page  
✅ **ImageDetail** — lazy import — alag chunk, tab load hota hai jab user detail page pe jaye  
✅ **Suspense fallback** — "Image load ho rahi hai..." — chunk download time dikhta hai  
✅ **Network tab** — verify kiya ki chunk on-demand download ho raha hai  
✅ **Preloading** — hover pe chunk download start — click pe zero delay  
✅ Route-level splitting — sabse common real-world pattern
