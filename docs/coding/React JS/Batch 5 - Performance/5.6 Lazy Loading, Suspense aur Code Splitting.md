## Abhi Tak Kya Hua

5.5 mein useReducer seekha — complex state management central function mein.

Ab baat karte hain **app load time** ki — jab app bada hota hai, bundle size bada hota hai, user ko load hone mein time lagta hai. Iska solution hai — code splitting.

---

## Problem — Ek Hi Bundle Mein Sab Kuch

Jab Vite / Webpack build karta hai, toh saara code ek (ya few) JavaScript files mein bundle hota hai. Chahe user sirf login page dekhna chahe — poora app ka code download ho raha hai.

Socho ek app jisme:
- Dashboard (heavy charts)
- User Profile (large form)
- Analytics (complex tables)
- Settings

User login page kholta hai — us waqt woh sirf login form dekhna chahta hai. Lekin browser Dashboard, Profile, Analytics — sabka code download kar raha hai. Unnecessary. Loading time zyada. User experience kharab.

**Yeh problem kyun hai?** Bundler saara code ek saath pack karta hai. Koi "yeh component abhi nahi chahiye, baad mein download hoga" ka concept nahi hota — jab tak hum code splitting use na karein.

---

## Code Splitting — Kya Hai

Code splitting ka matlab hai — bundle ko chhote-chhote parts mein todna. Har part (chunk) tab load hota hai jab actually zaroorat ho.

Iske do fayde hain:
1. **Initial load fast** — pehle sirf woh code download jo abhi chahiye
2. **On-demand loading** — baaki chunks baad mein load hote hain, jab user related page/feature pe jaye

---

## React.lazy + Suspense — Kya Hai

React.lazy ek function hai jo component ko "lazy" banata hai — matlab component ka code tab download hoga jab woh actually render ho raha hai, pehle nahi.

Suspense ek component hai jo "loading state" handle karta hai — jab lazy component load ho raha hota hai, tab Suspense ka fallback dikhta hai.

Syntax:

```tsx
const LazyComponent = React.lazy(() => import('./HeavyComponent'))

// Use with Suspense:
<Suspense fallback={<p>Loading...</p>}>
  <LazyComponent />
</Suspense>
```

**Kya hota hai internally?** `React.lazy()` ek function leta hai jo dynamic `import()` return karta hai. Jab `LazyComponent` render hota hai, React internally `import()` call karta hai. Download start hota hai. Component Suspense ke under hai toh — "loading" fallback dikhta hai. Download complete → component render hota hai.

Visual mapping:

```
User clicks "Show Chart"
    │
    ▼
LazyComponent render
    │
    ├── Chunk already loaded?
    │   ├── Yes → Render immediately
    │   └── No → Show Suspense fallback, start download
    │
    ▼
Chunk downloaded
    │
    ▼
Component renders, Suspense fallback disappears
```

## Minimal Code — Lazy Component

```tsx
import { lazy, Suspense, useState } from 'react'

// Lazy import — HeavyChart ka code alag chunk mein jayega
const HeavyChart = lazy(() => import('./HeavyChart'))

export default function Dashboard() {
  const [showChart, setShowChart] = useState(false)

  return (
    <div>
      <button onClick={() => setShowChart(true)}>
        Show Chart
      </button>

      {showChart && (
        <Suspense fallback={<div className="p-4 text-gray-500">Chart load ho raha hai...</div>}>
          <HeavyChart />
        </Suspense>
      )}
    </div>
  )
}
```

```tsx
// HeavyChart.tsx — yeh alag chunk banega
export default function HeavyChart() {
  return <div>{/* Heavy chart rendering */}</div>
}
```

Browser Network tab kholo. Button click karo — ek naya `.js` file download hota dikhega. Woh HeavyChart ka chunk hai. Pehle download nahi hua tha — abhi load hua, jab actually zaroorat padi.

---

## Flow — Jab Button Click Hota Hai

1. `showChart` state true hoti hai
2. React `HeavyChart` render karne lagta hai
3. `React.lazy` trigger hota hai — internal `import()` call start hota hai
4. Browser HeavyChart.tsc ka chunk download karta hai
5. React Suspense fallback dikhata hai (loading text)
6. Download complete → Suspense fallback hatata hai → HeavyChart render hota hai

## Build Up — Route-Level Splitting

Real app mein route level pe splitting hoti hai — har route ka apna chunk:

```tsx
import { lazy, Suspense } from 'react'
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom'

const Home = lazy(() => import('./routes/Home'))
const Dashboard = lazy(() => import('./routes/Dashboard'))
const Analytics = lazy(() => import('./routes/Analytics'))
const Settings = lazy(() => import('./routes/Settings'))

export default function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/dashboard">Dashboard</Link>
        <Link to="/analytics">Analytics</Link>
        <Link to="/settings">Settings</Link>
      </nav>

      <Suspense fallback={<div className="p-8 text-center">Page load ho raha hai...</div>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/dashboard" element={<Dashboard />} />
          <Route path="/analytics" element={<Analytics />} />
          <Route path="/settings" element={<Settings />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  )
}
```

Ab har route ka code alag chunk mein hai. User "/" kholta hai — sirf Home ka chunk download hota hai. Dashboard pe jata hai tab Dashboard ka chunk download hota hai. Initial load time fast.

## Kab Lazy Loading Lagao, Kab Nahi

**❌ Mat lagao jab:**
- Component chhota hai — bundle overhead se lazy ka overhead zyada ho sakta hai
- Component almost hamesha chahiye (initial render mein hi) — toh lazy unnecessary delay hai
- SSR environments mein — React.lazy server-side nahi chalta

**✅ Lagao jab:**
- Heavy components (charts, rich text editors, image editors)
- Routes jo user baad mein visit kare
- Components jo conditional hain (modal, drawer, tab content)
- Third-party libraries jo heavy hoon (moment.js, lodash)

---

## Common Mistake — Suspense Bhool Jana

React.lazy ka component Suspense ke bahar use karo toh error aata hai:

```tsx
// ❌ Galat — Suspense nahi hai
const HeavyChart = lazy(() => import('./HeavyChart'))
function App() {
  return <HeavyChart /> // Error: A component suspended while rendering
}

// ✅ Sahi — Suspense wrapping
function App() {
  return (
    <Suspense fallback={<p>Loading...</p>}>
      <HeavyChart />
    </Suspense>
  )
}
```

## Summary

✅ **Code Splitting** — bundle ko chhote chunks mein todna  
✅ **React.lazy** — dynamic import — component tab load hota hai jab render ho  
✅ **Suspense** — loading state handle karta hai — fallback prop mein dikhao  
✅ **Route-level splitting** — sabse common pattern — har route ka alag chunk  
✅ Heavy components ko lazy karo, chhote components ko nahi  
✅ Suspense ke bahar lazy component nahi chal sakta
