**Problem:** You are given an array `people` where `people[i]` is the weight of the `i`th person, and an integer `limit` representing the maximum weight a boat can carry. Each boat carries at most **two** people at the same time, provided the sum of the weight of those people is at most `limit`.

Return the minimum number of boats to carry every given person. (LeetCode #881)

**Link:** https://leetcode.com/problems/boats-to-save-people/

---

## What This Problem Is Asking (Simple Terms)

You have people with different weights and boats with a weight limit. Each boat can carry at most 2 people. You need to find the minimum number of boats to carry everyone.

The greedy strategy: pair the heaviest person with the lightest person if they fit together; otherwise, the heaviest goes alone.

For example, `people = [1,2]`, `limit = 3` → both fit in one boat → 1 boat.
`people = [3,2,2,1]`, `limit = 3` → `[3]`, `[2,1]` → 2 boats.

---

## Example 1

**Input:** `people = [1,2]`, `limit = 3`

**Output:** `1`

**Explanation:** 1 boat (1, 2).

---

## Example 2

**Input:** `people = [3,2,2,1]`, `limit = 3`

**Output:** `3`

**Explanation:** 3 boats (3), (2, 1), (2).

## Example 3

**Input:** `people = [3,5,3,4]`, `limit = 5`

**Output:** `4`

**Explanation:** 4 boats (3), (5), (3), (4).

## Constraints

- `1 <= people.length <= 5 * 10^4`
- `1 <= people[i] <= limit <= 3 * 10^4`

**Follow-up:** Could you solve it in O(n log n) time?

---

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could try all possible pairings and find the minimum number of boats. But this is exponential — too many combinations.

### Brute Force Pseudocode

```
minBoats = infinity
try all ways to pair people into groups of 1 or 2:
    if all pairs fit within limit: minBoats = min(minBoats, number of groups)
return minBoats
```

### Why Brute Force Is Slow

Exponential — too many pairing combinations.

---

## Which Data Structure/Technique, and Why?

"Minimum boats, at most 2 people, weight limit" → **Greedy + Two Pointers**. Sort weights. Pair the heaviest with the lightest if they fit; otherwise the heaviest goes alone. O(n log n) time, O(1) space.

**Signal in the problem:** "minimum boats" + "at most 2 people" + "weight limit" → sort + two pointers (pair heaviest with lightest).

---

## Optimized Approach (Greedy + Two Pointers)

Sort weights. Two pointers: `left` (lightest), `right` (heaviest). If `weights[left] + weights[right] <= limit`, pair them (`left++`, `right--`). Else, heaviest goes alone (`right--`). Count boats.

### Pseudocode

```
sort weights
left = 0, right = n - 1
boats = 0
while left <= right:
    if weights[left] + weights[right] <= limit:
        left++   // pair lightest with heaviest
    right--      // heaviest always goes (alone or paired)
    boats++
return boats
```

### Java Code

```java
class Solution {
    public int numRescueBoats(int[] people, int limit) {
        Arrays.sort(people);
        int left = 0, right = people.length - 1;
        int boats = 0;

        while (left <= right) {
            if (people[left] + people[right] <= limit) {
                left++;
            }
            right--;
            boats++;
        }
        return boats;
    }
}
```

### Line-by-line

- `Arrays.sort(people)` — sort weights to pair lightest with heaviest.
- `left = 0` — lightest person.
- `right = people.length - 1` — heaviest person.
- `if people[left] + people[right] <= limit` — can pair them? If yes, `left++` (lightest is taken).
- `right--` — heaviest always goes (alone or paired).
- `boats++` — count this boat.

## Complexity

- Time: O(n log n) — sort dominates, two-pointer scan is O(n).
- Space: O(1) — only three pointers.

## Common Mistakes

- **Not sorting first** — two pointers requires sorted weights.
- **Pairing lightest with heaviest incorrectly** — always pair the current lightest with current heaviest.
- **Counting boats incorrectly** — increment boats every iteration (each iteration handles the heaviest person).
- **Loop condition** — `left <= right`, not `left < right` (when `left == right`, one person remains).

## How to Explain (interview)

**Opening:** Boats to Save People finds the minimum boats to carry everyone, with at most 2 people per boat and a weight limit. Sort weights, then use two pointers: pair the heaviest with the lightest if they fit; otherwise the heaviest goes alone. O(n log n) time, O(1) space.

**The basic flow:**
```java
Arrays.sort(people);
int left = 0, right = people.length - 1;
int boats = 0;
while (left <= right) {
    if (people[left] + people[right] <= limit) left++;
    right--;
    boats++;
}
return boats;
```

**The part that trips everyone up:** `right--` happens every iteration (heaviest always goes), and `boats++` happens every iteration too. `left++` only happens when pairing is possible.

**The mistakes to remember:**
- Not sorting first
- Wrong loop condition (`left < right` instead of `left <= right`)
- Not counting `boats++` every iteration
