**Problem:** You are visiting a farm with a single row of fruit trees arranged from left to right. The trees are represented by an integer array `fruits` where `fruits[i]` is the type of fruit the `i`th tree produces.

You want to collect as much fruit as possible. However, you have only two baskets, and each basket can only hold a single type of fruit. There is no limit on the amount of fruit each basket can hold.

Starting from any tree of your choice, you must pick exactly one fruit from every tree (including the start tree) while moving to the right. The picked fruits must fit in one of your baskets.

Once you reach a tree with fruit that cannot fit in your baskets, you must stop.

Return the maximum number of fruits you can pick. (LeetCode #904)

**Link:** https://leetcode.com/problems/fruit-into-baskets/

---

## What This Problem Is Asking (Simple Terms)

You have an array of fruit types. You can pick fruit from a contiguous subarray, but you can only hold **two distinct types** of fruit at a time. Find the longest contiguous subarray with at most 2 distinct values.

For example, `fruits = [1,2,1]` → you can pick all 3 (types 1 and 2). `fruits = [0,1,2,2]` → you can pick `[1,2,2]` (types 1 and 2), length 3.

You return just the count, not the subarray itself.

---

## Example 1

**Input:** `fruits = [1,2,1]`

**Output:** `3`

**Explanation:** We can pick from all 3 trees (types 1 and 2).

---

## Example 2

**Input:** `fruits = [0,1,2,2]`

**Output:** `3`

**Explanation:** We can pick from trees [1,2,2] (types 1 and 2). If we started at tree 0, we could only pick [0,1] (length 2).

---

## Example 3

**Input:** `fruits = [1,2,3,2,2]`

**Output:** `4`

**Explanation:** We can pick from trees [2,3,2,2] (types 2 and 3).

---

## Constraints

- `1 <= fruits.length <= 10^5`
- `0 <= fruits[i] < fruits.length`

**Follow-up:** Could you solve it in O(n) time and O(1) space?

---

## Brute Force Approach (The Simplest Way)

Before optimizing, think like a beginner: how would you solve this by hand?

You could check every possible subarray, count distinct types in it, and track the longest one with at most 2 distinct types.

### Brute Force Pseudocode

```
maxLen = 0
for i from 0 to n-1:
    for j from i to n-1:
        if distinct types in fruits[i..j] <= 2:
            maxLen = max(maxLen, j - i + 1)
return maxLen
```

### Why Brute Force Is Slow

O(n²) — too slow for n = 10^5.

---

## Which Data Structure/Technique, and Why?

"Maximum number of fruits with at most 2 types" → **Sliding Window (variable size)**. Maintain a window with at most 2 distinct fruit types. Expand right; if distinct types > 2, shrink left. O(n) time, O(2) = O(1) space.

**Signal in the problem:** "longest subarray" + "at most 2 types" → sliding window with frequency map.

---

## Optimized Approach (Sliding Window)

Variable-size window. Expand `right`; add `fruits[right]` to frequency map. While distinct types > 2, shrink `left` (decrement `fruits[left]` from map, remove if 0, `left++`). Update `maxLen`.

### Pseudocode

```
count = empty map (fruit -> count)
left = 0, maxLen = 0
for right from 0 to n-1:
    count[fruits[right]]++
    while count.size() > 2:
        count[fruits[left]]--
        if count[fruits[left]] == 0:
            count.remove(fruits[left])
        left++
    maxLen = max(maxLen, right - left + 1)
return maxLen
```

### Java Code

```java
class Solution {
    public int totalFruit(int[] fruits) {
        Map<Integer, Integer> count = new HashMap<>();
        int left = 0, maxLen = 0;

        for (int right = 0; right < fruits.length; right++) {
            count.put(fruits[right], count.getOrDefault(fruits[right], 0) + 1);
            while (count.size() > 2) {
                count.put(fruits[left], count.get(fruits[left]) - 1);
                if (count.get(fruits[left]) == 0) {
                    count.remove(fruits[left]);
                }
                left++;
            }
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

### Line-by-line

- `count.put(fruits[right], ...)` — add current fruit to window.
- `while count.size() > 2` — too many distinct types, shrink from left.
- `count.put(fruits[left], ... - 1)` — remove left fruit from window.
- `if count.get(...) == 0: count.remove(...)` — remove zero-count entries to keep `size()` accurate.
- `left++` — shrink window.
- `maxLen = Math.max(maxLen, right - left + 1)` — update best.

## Complexity

- Time: O(n) — each fruit enters and leaves the window at most once.
- Space: O(1) — map holds at most 3 entries (2 distinct + 1 temporarily).

## Common Mistakes

- **Not removing zero-count entries from map** — `count.size()` would be wrong.
- **Not using `while` instead of `if`** — after shrinking, might still have > 2 types.
- **Window size off-by-one:** `right - left + 1`.
- **Assuming exactly 2 types instead of at most 2** — window can have 1 or 2 types.

## How to Explain (interview)

**Opening:** Fruit Into Baskets asks for the longest contiguous subarray with at most 2 distinct values. Sliding window: expand right, add to frequency map; when distinct types > 2, shrink left. O(n) time, O(1) space.

**The basic flow:**
```java
Map<Integer, Integer> count = new HashMap<>();
int left = 0, maxLen = 0;
for (int right = 0; right < fruits.length; right++) {
    count.put(fruits[right], count.getOrDefault(fruits[right], 0) + 1);
    while (count.size() > 2) {
        count.put(fruits[left], count.get(fruits[left]) - 1);
        if (count.get(fruits[left]) == 0) count.remove(fruits[left]);
        left++;
    }
    maxLen = Math.max(maxLen, right - left + 1);
}
return maxLen;
```

**The part that trips everyone up:** removing zero-count entries from the map — otherwise `count.size()` won't reflect the actual number of distinct types.

**The mistakes to remember:**
- Not removing zero-count entries (size() stays wrong)
- Using `if` instead of `while` for shrinking
- Window size is `right - left + 1`
