## ✅ What is Fetch?

✅ Fetch is a function built directly into the browser. You do not need to install anything to use it.

✅ All it does: it makes a request to another computer over the internet, and gives you back the response.

✅ Fetch always returns a Promise. This is why you use it with `await`.

---

## ✅ Basic GET Request

For simple GET requests you only need one argument: the URL.

```js
async function getUser() {
  const res = await fetch('https://api.example.com/user/1');

  if (!res.ok) {
    throw new Error(`HTTP error: ${res.status}`);
  }

  const data = await res.json();
  return data;
}
```

✅ GET is the default method. You don't need to specify it.

✅ **Important:** `fetch` only rejects on network failure. It will NOT reject on 404, 500 or other HTTP errors. You must check `res.ok` manually.

## ✅ POST Request

For any request that sends data you need the second options object.

Let's break this down completely:

```js
async function createUser(userData) {
  const res = await fetch('/api/users', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(userData)
  });

  return await res.json();
}
```

✅ Fetch takes 2 arguments:
1.  **URL** → where you are sending the request
2.  **Options object** → all the settings for this request

---

✅ What each part means:

| Property | What it does |
|---|---|
| `method: 'POST'` | What operation you want to do. `POST` = create new. |
| `headers` | Metadata about the request. This tells the server what you are sending. |
| `Content-Type: 'application/json'` | This is the most important header. It tells the server: "I am sending you JSON data". |
| `body` | The actual data you want to send to the server. |
| `JSON.stringify(userData)` | The internet only understands strings. You cannot send JavaScript objects directly. You must convert them to JSON string first. |

✅ **If you forget `Content-Type` header:**
Most servers will just ignore your body completely. This is the #1 mistake everyone makes when learning fetch.

✅ **If you forget `JSON.stringify()`:**
You will send `[object Object]` as text. All your data will be garbage.

---

## ✅ Other methods:

```js
method: 'PUT'     // replace full existing resource
method: 'PATCH'   // update only part of the resource
method: 'DELETE'  // remove resource
```

## 🧠 Interview Questions

> ❓ Does fetch throw an error on 404?
> No. Fetch only rejects on network failure. You must always check response.ok.

> ❓ What is the difference between fetch and axios?
> Axios automatically transforms JSON, automatically rejects on HTTP errors, and has many extra features. Fetch is built into the browser.

> ❓ What does response.json() do?
> It reads and parses the response body from JSON string into JavaScript object.
