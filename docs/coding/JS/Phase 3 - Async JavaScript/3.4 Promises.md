Promises were created specifically to fix callback hell.

---

## ✅ What is a Promise?

A Promise is an object that represents the eventual result of an asynchronous operation.

✅ It can only be in one of 3 states:
- `pending` → still running, no result yet
- `fulfilled` → success, we have a value
- `rejected` → failure, we have an error

---

## ✅ Creating a Promise:

```js
const promise = new Promise((resolve, reject) => {
  // do async work here

  setTimeout(() => {
    const success = true;
    if (success) {
      resolve("✅ Data received");
    } else {
      reject("❌ Something went wrong");
    }
  }, 1000);
});
```

✅ `resolve()` = call this when operation succeeds
✅ `reject()` = call this when operation fails

---

## ✅ Using a Promise:

```js
promise
  .then((data) => console.log(data))   // runs on success
  .catch((err) => console.log(err))    // runs on failure
  .finally(() => console.log("Done")); // always runs
```

✅ Promises are chainable. No more nested hell.

---

## ✅ Promise Combinators

| Method | Behaviour |
|---|---|
| `Promise.all()` | Waits for **all** to resolve. Fails immediately if any fail. |
| `Promise.allSettled()` | Waits for **all** to finish. Returns all results, success or failure. |
| `Promise.race()` | Returns the **first** one to finish, success or failure. |
| `Promise.any()` | Returns the **first successful** one. Only fails if all fail. |

---

## ✅ Example:

```js
Promise.all([ fetch('/user'), fetch('/posts'), fetch('/comments') ])
  .then(([ user, posts, comments ]) => {
    // All 3 completed successfully
  });
```

## 🧠 Interview Questions

> ❓ What are the 3 states of a Promise?
> Pending, Fulfilled, Rejected.

> ❓ What is the difference between Promise.all() and Promise.allSettled()?
> Promise.all fails immediately if any promise fails. Promise.allSettled waits for all and returns every result.

> ❓ What is the difference between Promise.race() and Promise.any()?
> Promise.race returns first one to finish regardless of success/failure. Promise.any returns first successful one.
