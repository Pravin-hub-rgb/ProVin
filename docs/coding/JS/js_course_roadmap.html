JavaScript Course Roadmap for Fullstack/Frontend Interviews — 6 phases covering all must-know concepts

🔥 asked a lot very frequent in interviews
must know core concept, can't skip
1
The absolute basics — JS foundations
Variables, types, functions — understand this before anything else
var / let / const
Difference, when to use which. Block scope vs function scope.
🔥 asked a lot
Data types
Primitive vs reference types. typeof, null vs undefined.
must know
Functions
Regular, arrow functions, default params, rest params.
must know
Scope
Global, local, block scope. Lexical scope — foundation for closures.
🔥 asked a lot
Hoisting
var hoisted to undefined. let/const in temporal dead zone. Functions fully hoisted.
🔥 asked a lot
Type coercion
== vs ===. Implicit conversions that trip people up.
must know
2
Core concepts — the interview favorites
Closures, this, prototype — these come up in nearly every interview
Closures
A function remembers variables from outer scope even after outer function finishes. Used in data privacy, callbacks, counters.
🔥 asked a lot
this keyword
How this changes with context — regular fn, arrow fn, object method, new keyword, call/apply/bind.
🔥 asked a lot
Prototype & prototype chain
Every object has __proto__. How JS looks up properties up the chain. Foundation of inheritance.
🔥 asked a lot
Classes
ES6 class syntax. constructor, methods, extends, super. Classes = syntax sugar over prototypes.
must know
call, apply, bind
Manually set this. call/apply invoke immediately, bind returns a new function.
🔥 asked a lot
IIFE
Immediately Invoked Function Expression. Avoids polluting global scope.
must know
3
Async JavaScript — how JS handles time
Event loop, promises, async/await — heavily tested
Synchronous vs Asynchronous
Sync = one at a time, blocks. Async = continues while waiting (API calls, timers).
🔥 asked a lot
Event Loop
Call stack + web APIs + callback queue + microtask queue. How JS is single-threaded but non-blocking.
🔥 asked a lot
Callbacks
Function passed to another function to run later. Leads to callback hell — why promises exist.
must know
Promises
Object representing future value. .then(), .catch(), .finally(). Promise.all, Promise.race.
🔥 asked a lot
async / await
Cleaner syntax over promises. await pauses until promise resolves. try/catch for errors. Same power, better readability.
🔥 asked a lot
Fetch API
Making HTTP requests in the browser. Works with async/await. Handling JSON responses.
must know
4
Arrays, objects & functional patterns
You'll use these every single day as a dev
Array methods
map, filter, reduce, find, forEach, some, every, flat, flatMap. Know all of these cold.
🔥 asked a lot
Destructuring
Pull values out of arrays/objects cleanly. Used everywhere in React.
must know
Spread & Rest
... operator. Spread to expand, rest to collect. Copying arrays/objects without mutation.
must know
Higher-order functions
Functions that take or return other functions. map/filter are examples.
🔥 asked a lot
Memoization
Cache results of expensive function calls. Return cached result if same input seen before. Performance pattern.
🔥 asked a lot
Currying
Transforming f(a,b) into f(a)(b). Partial application of functions.
must know
Pure functions
Same input always gives same output. No side effects. Foundation of good JS and React.
must know
Optional chaining & nullish
obj?.prop and ?? operator. Avoids "cannot read property of undefined" errors.
must know
5
DOM & browser — making things interactive
Events, delegation, bubbling — real frontend work
DOM manipulation
querySelector, getElementById, createElement, appendChild, innerHTML. The basics of changing a page.
must know
Event handling
addEventListener, removeEventListener. Click, keydown, input events.
must know
Event bubbling
Events travel up the DOM tree — child to parent. stopPropagation to stop it.
🔥 asked a lot
Event delegation
Attach one listener on parent instead of many on children. Efficient and handles dynamic elements.
🔥 asked a lot
Debounce & throttle
Control how often a function fires. Debounce = wait until stopped. Throttle = limit rate.
🔥 asked a lot
localStorage / sessionStorage
Persisting data in browser. Difference between the two.
must know
6
Advanced & modern JS — senior-level topics
Learn after phases 1–5 are solid. These show depth.
Modules (import/export)
ES6 module system. Named vs default exports. Used in every React project.
must know
Error handling
try/catch/finally. Custom errors. Handling promise rejections properly.
must know
Generators & iterators
function* syntax. yield. Custom iteration. Good to know, rarely asked at junior level.
WeakMap / WeakRef
Memory-efficient structures. Advanced garbage collection topics.
Design patterns
Singleton, Observer, Factory. Show you can write scalable code.
must know
Memory & performance
Memory leaks, garbage collection, avoiding re-renders. Important for fullstack.
must know
After JS is done → React
useState, useEffect, useRef, useCallback, useMemo → props/state → Context API → React Router → then a project. All the React stuff makes sense once JS is solid.
