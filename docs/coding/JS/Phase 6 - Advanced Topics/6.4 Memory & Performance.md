## ✅ Garbage Collection

✅ JavaScript automatically cleans up memory for you.
✅ It removes anything that has no references pointing to it.
✅ If something still has a reference it will stay in memory forever.

✅ This is not magic. This is very simple.

---

## ✅ Memory Leaks

✅ A memory leak is when memory is never released even though it is no longer needed.
✅ This is why your browser tab starts using 2GB RAM.

✅ Most common causes in order:

1. ❌ Forgotten event listeners
2. ❌ Timers that are never cleared
3. ❌ Global variables
4. ❌ Closures holding references

---

## ✅ 1. Event Listener Leaks

✅ This is the #1 most common memory leak in all JavaScript applications.

```js
// ❌ MEMORY LEAK
function setup() {
  const hugeArray = new Array(1000000).fill('data');

  document.addEventListener('click', function() {
    console.log(hugeArray);
  });
}
```

✅ That huge array will stay in memory forever. Forever.

✅ ✅ Correct way:
```js
// ✅ NO LEAK
function setup() {
  const hugeArray = new Array(1000000).fill('data');

  function handleClick() {
    console.log(hugeArray);
  }

  document.addEventListener('click', handleClick);

  // ✅ Return cleanup function
  return function cleanup() {
    document.removeEventListener('click', handleClick);
  };
}
```

✅ This is exactly what React useEffect cleanup function does.

---

## ✅ 2. Timer Leaks

✅ Always clear your timers.

```js
// ❌ MEMORY LEAK
const interval = setInterval(() => {
  console.log("running forever");
}, 1000);
```

✅ ✅ Correct way:
```js
// ✅ Always keep reference
const interval = setInterval(() => {}, 1000);

// ✅ Always clear when you are done
clearInterval(interval);
```

## ✅ How to check for leaks

✅ Open Chrome DevTools -> Memory tab
✅ Take heap snapshot
✅ Do the action multiple times
✅ If memory keeps going up you have a leak.

## 🧠 Interview Questions

> ❓ What causes memory leaks in JavaScript?
> The most common causes are forgotten event listeners, timers that are never cleared, global variables and closures holding references.

> ❓ How does garbage collection work?
> JavaScript uses mark and sweep garbage collection. Any object that is no longer reachable is automatically removed.

> ❓ What is the purpose of cleanup functions?
> To remove event listeners, clear timers and release references so that memory can be garbage collected.
