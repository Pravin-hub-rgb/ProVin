
A normal function runs to completion and returns one value. When you call it, it executes all its code and returns a single result. You can't pause it midway.

A generator is a function that can pause and resume. It yields one value at a time, and the next time you call it, it continues from where it left off. You can walk away in between. Come back later, call it again, and it continues right where it left off.

Generators are functions that can **pause in the middle** and **resume later**. They can return multiple values over time, instead of all at once. You will almost never write them yourself, but they power a lot of modern JavaScript features that you use every day.

---

## ✅ What are generators?

✅ Normal functions run once and return once.
✅ Generator functions can pause and resume.
✅ They can return multiple values over time.

✅ Use `function*` syntax:

```js
function* counter() {
  let i = 0;

  while (true) {
    yield i++;
  }
}
```

✅ `yield` pauses the function and returns the value.

---

## ✅ Using generators

```js
const gen = counter();

console.log(gen.next().value); // 0
console.log(gen.next().value); // 1
console.log(gen.next().value); // 2
console.log(gen.next().value); // 3
```

✅ Every time you call `.next()` the function resumes running until it hits the next `yield`.

✅ You will almost never need to write a generator.

## How to Explain

Generators are functions that can pause mid-execution and resume later, producing multiple values over time instead of one. They use function* syntax and yield to pause. They're rarely written directly in application code but power async/await, iteration, and many library internals.

**The basic flow:**
```js
function* counter() {
  let i = 0
  while (true) { yield i++ }
}
const gen = counter()
gen.next().value // 0
gen.next().value // 1
```

Each next() call resumes the function until the next yield, which pauses and returns the value. The function state — including local variables — is preserved between calls.

**The part that trips everyone up:**

Calling a generator function doesn't run its body. It returns an iterator object. The code only executes when you call .next(). Forgetting this means your generator never runs and produces nothing.

**The mistakes to remember:**
- Calling the generator without .next(), so the body never executes
- Confusing yield with return — yield pauses, return ends the generator
- Using generators for simple cases where a regular function or array would be clearer
