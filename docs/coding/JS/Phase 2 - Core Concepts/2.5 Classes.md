## ✅ What is a class?

✅ A class is a blueprint for creating objects.
✅ It defines what properties and methods all objects created from it will have.

```js
class Car {
  constructor(color) {
    this.color = color;
    this.speed = 0;
  }

  accelerate() {
    this.speed += 10;
  }
}
```

---

## ✅ Creating objects from class

✅ Use the `new` keyword:

```js
const myCar = new Car("red");

console.log(myCar.color); // red
console.log(myCar.speed); // 0

myCar.accelerate();
console.log(myCar.speed); // 10
```

✅ You can make as many cars as you want. Every one is separate.

## ✅ Constructor

✅ `constructor` is a special method that runs automatically when you create a new object.
✅ This is where you set all the initial values.

```js
class User {
  constructor(name, age) {
    // ✅ Always assign parameters to `this` here
    this.name = name;
    this.age = age;
    this.createdAt = new Date();
  }
}
```

✅ Never forget to put `this.` in front of everything.

## ✅ Inheritance

✅ One class can extend another class.
✅ You get all the properties and methods from the parent class.

```js
class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    console.log(`${this.name} makes a sound`);
  }
}
```

✅ Now extend it:
```js
class Dog extends Animal {
  bark() {
    console.log("Woof!");
  }
}
```

✅ Usage:
```js
const dog = new Dog("Max");
dog.speak(); // Max makes a sound
dog.bark(); // Woof!
```

---

## ✅ super() keyword

✅ This is the #1 thing everyone gets confused about.

✅ When you extend a class, you **must** call `super()` inside your constructor before you can use `this`.

```js
class Cat extends Animal {
  constructor(name, color) {
    // ✅ Call parent constructor first
    super(name);
    // ✅ Only now you can use this
    this.color = color;
  }
}
```

✅ `super()` calls the constructor of the parent class.
✅ Always first line. Always.
✅ If you forget this you will get the most famous JavaScript error.

---

## ✅ Overriding methods

✅ You can replace a method from the parent class:

```js
class Duck extends Animal {
  speak() {
    console.log("Quack quack!");
  }
}
```

✅ Now when you call `speak()` it will use the new one.

## ✅ Practice Examples

✅ Example 1: User system
```js
class User {
  constructor(email, password) {
    this.email = email;
    this.password = password;
  }

  login() {
    console.log("User logged in");
  }
}

class Admin extends User {
  constructor(email, password, role) {
    super(email, password);
    this.role = role;
  }

  deleteUser() {
    console.log("Admin deleted user");
  }
}
```

## 🧠 Interview Questions

> ❓ What is the purpose of super()?
> It calls the constructor of the parent class. Must be called before using this in child constructor.

> ❓ What is the difference between class and object?
> Class is the blueprint. Object is the actual instance created from the class.

> ❓ Can a class extend multiple classes?
> No. JavaScript does not support multiple inheritance.

## 🎯 Interview Ready Answer

> "Classes in JavaScript are blueprints for creating objects. They support inheritance through the extends keyword. When extending a class the super() function must be called in the child constructor before accessing this. Classes are syntactic sugar over JavaScript's prototype system."
