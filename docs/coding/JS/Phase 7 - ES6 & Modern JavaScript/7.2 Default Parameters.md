# 7.2 — Default Parameters

Function parameters can have default values.

```js
function greet(name = "stranger") {
  return `Hello, ${name}!`;
}

greet("Vin");      // "Hello, Vin!"
greet();           // "Hello, stranger!"
greet(undefined);  // "Hello, stranger!" (undefined triggers default)
greet(null);       // "Hello, null!" (null does NOT trigger default)
```

**Arrow functions with defaults:**

```js
const multiply = (a = 1, b = 1) => a * b;
multiply();       // 1
multiply(5);      // 5
multiply(5, 3);   // 15
```

**Key rule:** default triggers on `undefined`, not `null`.

## Common Mistakes

- Expecting `null` to trigger default (it does not).
- Putting default params before required params.
- Using default params with destructuring incorrectly.

## Try It Yourself

1. Write a function with two default params.
2. Call it with `undefined` and `null`.
3. Use default params in an arrow function.

## Summary

- Default params: `function fn(x = 0) {}`.
- Triggers on `undefined`, not `null`.

## What It Is NOT

- `null` does **not** trigger default.
- Default params are **not** the same as `||` fallback.
