# 7.7 — Project: ES6 Feature Showcase

## What This Project Is

A small browser app that uses every ES6 feature from this phase in one place. It is a feature showcase, not a new concept.

## Features

- **Default parameters** — a greeting function with defaults.
- **for...of** — iterate over an array of items.
- **Map & Set** — track unique tags and a lookup map.
- **Symbol** — private property keys.
- **Object shorthand** — clean object creation.

## Build Steps

1. Create `index.html` with a `<script type="module">`.
2. Write a `greet(name = "stranger")` function.
3. Use `for...of` to render a list.
4. Use a `Set` to deduplicate tags.
5. Use a `Map` for id → name lookup.
6. Use a `Symbol` for a private id.
7. Use object shorthand for a config object.

## Checkpoint

- Open in browser, verify all features work.
- Explain each feature used.

## Common Mistakes

- Forgetting `type="module"` on the script tag.
- Using `for...in` on arrays.
- Assuming two Symbols with same description are equal.
