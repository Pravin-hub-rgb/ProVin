# 7.6 — Object Shorthand

## Cheat Sheet (Quick Recall)

- Shorthand property names: `{ name, age }` instead of `{ name: name, age: age }`.
- Method shorthand: `greet() { return "hi"; }`.
- Computed property names: `{ [key]: value }`.

## Object Shorthand

ES6 allows shorthand property names and method definitions:

```js
const name = "Vin";
const age = 25;

// Before ES6
const user = { name: name, age: age, greet: function() { return "hi"; } };

// ES6 shorthand
const user2 = { name, age, greet() { return "hi"; } };

// Method shorthand
const calculator = {
  add(a, b) { return a + b; },
  subtract(a, b) { return a - b; },
};

// Computed property names
const key = "dynamic";
const obj = { [key]: "value" }; // { dynamic: "value" }
```

## Common Mistakes

- Mixing shorthand and long form incorrectly.
- Forgetting computed property names need brackets.
- Using arrow functions in method shorthand (no `this`).

## Summary

- Shorthand: `{ name, age }`.
- Method shorthand: `greet() {}`.
- Computed: `{ [key]: value }`.

## What It Is NOT

- Arrow functions in method shorthand **do not** get `this`.
- Shorthand is **not** for all properties — only when variable name matches key.
