# 7.4 — Map & Set

## `Set` — collection of unique values

```js
const set = new Set([1, 2, 2, 3]);
// Set {1, 2, 3} — duplicates removed

set.add(4);       // Set {1, 2, 3, 4}
set.has(2);       // true
set.delete(2);    // Set {1, 3, 4}
set.size;         // 3

// Remove duplicates from array
const unique = [...new Set([1, 2, 2, 3])]; // [1, 2, 3]
```

## `Map` — key-value pairs, any type as key

```js
const map = new Map();
map.set("name", "Vin");
map.set(42, "answer");
map.set({ id: 1 }, "object key");

map.get("name");   // "Vin"
map.has(42);       // true
map.size;          // 3
map.delete("name");

// Iterate
for (const [key, value] of map) {
  console.log(key, value);
}

// Convert
const obj = Object.fromEntries(map);  // Map → Object
const m = new Map(Object.entries(obj)); // Object → Map
```

**Map vs Object:**

| Feature | Object | Map |
|---------|--------|-----|
| Key types | string, symbol | any type |
| Key order | insertion order (mostly) | insertion order (guaranteed) |
| Size | `Object.keys(obj).length` | `map.size` |
| Iteration | `for...in`, `Object.keys()` | `for...of`, `.forEach()` |
| Performance | slower for frequent add/remove | faster for frequent add/remove |

## Common Mistakes

- Using `Map` when `Object` is fine (string keys).
- Forgetting that `Map` keys are compared by reference.
- Using `Set` when array is enough.

## Try It Yourself

1. Remove duplicates from an array with `Set`.
2. Create a `Map` with non-string keys.
3. Convert between `Map` and `Object`.

## Summary

- `Set`: unique values, `.add()`, `.has()`, `.delete()`, `.size`.
- `Map`: any key type, `.set()`, `.get()`, `.has()`, `.delete()`, `.size`.

## What It Is NOT

- `Map` is **not** `Object` — Map allows any key type.
- `Set` is **not** `Array` — Set removes duplicates.
