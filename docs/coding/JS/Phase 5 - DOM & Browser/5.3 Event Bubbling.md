## ✅ What is Event Bubbling?

✅ When you click an element, the event does not stop at that element.

✅ It travels **UP** through every single parent element all the way to the top of the document.

```html
<div id="grandparent">
  <div id="parent">
    <button id="child">Click Me</button>
  </div>
</div>
```

```js
child.addEventListener("click", () => console.log("child"));
parent.addEventListener("click", () => console.log("parent"));
grandparent.addEventListener("click", () => console.log("grandparent"));
document.addEventListener("click", () => console.log("document"));
```

✅ If you click the button this will log:
```
child
parent
grandparent
document
```

✅ Every single one fires. In that order.

---

## ✅ Stopping Bubbling

✅ If you don't want this to happen:
```js
child.addEventListener("click", function(event) {
  event.stopPropagation();
});
```

✅ Now only the child event will fire. None of the parents will receive the event.

---

## ✅ Capturing Phase

✅ There is also a third phase that happens first before bubbling:

```
CAPTURING PHASE → TARGET PHASE → BUBBLING PHASE
```

✅ During capturing phase event travels **DOWN** from document to target.

✅ To listen during capturing phase:
```js
parent.addEventListener("click", handler, { capture: true });
```

✅ 99% of the time you will never need this. Bubbling is default.

## 🧠 Interview Questions

> ❓ Explain event bubbling
> When an event fires on an element it propagates upwards through all ancestor elements.

> ❓ What is the order of event phases?
> Capturing → Target → Bubbling

> ❓ How do you stop event bubbling?
> event.stopPropagation()

> ❓ What is the difference between stopPropagation and stopImmediatePropagation?
> stopPropagation stops bubbling. stopImmediatePropagation also stops other listeners on the same element.

## 🎯 Interview Ready Answer

> "Event bubbling is the mechanism by which events propagate upwards from the target element through all ancestor elements to the top of the document. This is the default behaviour and enables event delegation patterns. Bubbling can be stopped with event.stopPropagation()."

That is the full correct answer.
