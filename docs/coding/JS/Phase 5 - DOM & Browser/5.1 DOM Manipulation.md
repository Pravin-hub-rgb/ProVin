This is what frontend developers actually do. This is the real job.

But first — what is the DOM?

The DOM stands for **Document Object Model**. Fancy name, simple idea.

Imagine your HTML is a **blueprint of a house** drawn on paper. Rooms, doors, windows — all marked on the blueprint. The browser reads that blueprint and builds an actual 3D house out of it. That house is the DOM.

Every `<div>`, every `<button>`, every `<p>` tag in your HTML becomes an **object** in the DOM — a living, breathing thing you can interact with. DOM manipulation is you walking through that house and changing things: painting walls, moving furniture, adding new rooms, or tearing things down.

The `document` object is your **key to the front door**. It is the entry point. Without `document`, you cannot access anything on the page. Every DOM operation starts with `document.something(...)`.

## ✅ Selecting Elements

✅ Get single element:
```js
const button = document.querySelector("#submit-button");
const card = document.querySelector(".card");
```

✅ Get multiple elements:
```js
const allButtons = document.querySelectorAll("button");
const inputs = document.querySelectorAll("input.required");
```
✅ Returns a NodeList. You can loop over it with `forEach()`.

✅ Older methods that still work:
```js
document.getElementById("id");
document.getElementsByClassName("class");
document.getElementsByTagName("div");
```

---

## ✅ Creating Elements

Once you can find existing elements on the page, the next thing you need is to create **new** ones — adding a new item to a list, displaying new data from the server, showing a notification.

```js
const div = document.createElement("div");
```

This creates an element in memory. It is not on the page yet — just floating in JS memory, invisible. You need to set its content and insert it into the document (which we will cover next).

✅ Set content safely:
```js
div.textContent = "Hello World";
```

❌ Never use this unless you are 100% sure:
```js
div.innerHTML = "<strong>Hello</strong>";
```
✅ This parses HTML. This is how XSS attacks happen.

---

## ✅ Adding Classes & Attributes

Now that you have an element, you need to style it or attach extra data to it. That is what classes and attributes are for.

Classes control how elements look. Attributes store extra data (like IDs, disabled state, or custom data for JavaScript logic).

```js
div.classList.add("card");
div.classList.remove("hidden");
div.classList.toggle("active");
div.classList.contains("loading");
```

✅ Attributes:
```js
div.setAttribute("data-id", "123");
div.getAttribute("data-id");
div.removeAttribute("disabled");
```

---

## ✅ Inserting into page

Creating an element only makes it in memory. It is floating in JavaScript land, invisible. To actually see it on the screen, you need to insert it into the document tree — attach it to a parent that already exists on the page.

```js
document.body.appendChild(div);
parent.appendChild(child);
```

✅ Modern methods:
```js
parent.append(div);
parent.prepend(div);
element.before(otherElement);
element.after(otherElement);
```

---

## ✅ Removing elements

What if you need to delete something from the page — like dismissing a notification, removing a deleted todo item, or closing a modal?

```js
element.remove();
```

✅ Old way:
```js
parent.removeChild(child);
```

## 🧠 Interview Questions

> ❓ What is the difference between textContent and innerHTML?
> textContent is plain text only. innerHTML parses HTML and is a security risk.

> ❓ What is the difference between querySelector and getElementById?
> querySelector uses CSS selectors. getElementById is slightly faster.

> ❓ What does querySelectorAll return?
> A NodeList. Not an array. You can call forEach() on it.
