## What This Topic Is Asking (Simple Terms)

A Card Stack is a UI component where cards are stacked on top of each other with depth (scale, opacity, z-index). "Up" moves the last card to the front, "Down" moves the first card to the back. You can add new cards via a form. The stack persists in localStorage.

---

## The Problem

You have a stack of cards. You need to:
1. Show only the top 3 cards with depth (scale, opacity, z-index)
2. "Up" button moves the last card to the front
3. "Down" button moves the first card to the back
4. "Add" form adds a new card to the front
5. Persist the stack in localStorage (survives page refresh)

---

## Step 1 - The HTML Structure

```html
<div id="stack">
  <div class="card">
    <img src="photo1.jpg" alt="Card 1">
    <p>Card 1</p>
  </div>
  <div class="card">
    <img src="photo2.jpg" alt="Card 2">
    <p>Card 2</p>
  </div>
  <div class="card">
    <img src="photo3.jpg" alt="Card 3">
    <p>Card 3</p>
  </div>
</div>

<button id="upBtn">Up</button>
<button id="downBtn">Down</button>

<form id="addForm">
  <input name="name" placeholder="Card name" required>
  <input name="img" placeholder="Image URL" required>
  <button type="submit">Add</button>
</form>
```

---

## Step 2 - The updateStack Function

```js
const stack = document.querySelector("#stack");

function updateStack() {
  const cards = stack.querySelectorAll(".card");
  // Only style the top 3 cards
  for (let i = 0; i < 3 && i < cards.length; i++) {
    cards[i].style.zIndex = String(cards.length - i);
    cards[i].style.transform = `translateY(${i * 10}px) scale(${1 - i * 0.02})`;
    cards[i].style.opacity = String(1 - i * 0.2);
  }
  // Hide the rest
  for (let i = 3; i < cards.length; i++) {
    cards[i].style.display = "none";
  }
}

updateStack(); // initial call
```

**Why cap at 3?** Showing all cards creates visual clutter. Only the top 3 are visible with depth, the rest are hidden.

---

## Step 3 - Up Button (move last to front)

```js
document.querySelector("#upBtn").addEventListener("click", () => {
  const last = stack.lastElementChild;
  if (last) {
    stack.insertBefore(last, stack.firstElementChild);
    updateStack();
  }
});
```

**What happens:** The last card is moved before the first card. `insertBefore` moves it (doesn't copy). Then `updateStack` re-applies the depth styles.

---

## Step 4 - Down Button (move first to back)

```js
document.querySelector("#downBtn").addEventListener("click", () => {
  const first = stack.firstElementChild;
  if (first) {
    stack.appendChild(first); // moves first to the end
    updateStack();
  }
});
```

---

## Step 5 - Add Form (create new card)

```js
document.querySelector("#addForm").addEventListener("submit", (e) => {
  e.preventDefault();
  const data = new FormData(e.target);

  const card = document.createElement("div");
  card.className = "card";
  card.innerHTML = `<img src="${data.get("img")}"><p>${data.get("name")}</p>`;

  stack.insertBefore(card, stack.firstElementChild);
  localStorage.setItem("stack", stack.innerHTML);
  updateStack();
  e.target.reset();
});
```

**Bugs hit during development:**
- **Duplicates on re-render** — if the page reloads, the hardcoded cards + localStorage cards both show. Fix: clear the container first with `innerHTML = ""`, then load from localStorage.
- **`forEach` styled all cards** — the loop styled every card, not just the top 3. Fix: cap the loop at 3.

---

## Step 6 - Persist to localStorage

```js
// On page load: restore from localStorage
const saved = localStorage.getItem("stack");
if (saved) {
  stack.innerHTML = saved;
  updateStack();
}

// On add: save to localStorage (already in Step 5)
```

**Checkpoint:** Stack shows depth; Up/Down move cards; add persists after refresh.

---

## Common Mistakes

- **Not clearing before restoring** — if you `innerHTML = saved` without clearing first, you get duplicates (hardcoded + saved). Clear first: `stack.innerHTML = ""`, then `stack.innerHTML = saved`.
- **Styling all cards instead of top 3** — cap the loop: `for (let i = 0; i < 3 && i < cards.length; i++)`.
- **Forgetting to call `updateStack()` after DOM changes** — after insert/append/remove, the depth styles are stale. Always re-apply.
- **Using `innerHTML` for user input** — XSS risk. In a real app, use `textContent` or sanitize. Here it's a demo, so `innerHTML` is fine.

---

## What This Topic Is NOT

- ❌ Card Stack is not the same as a **carousel** — a carousel shows one item at a time with arrows. A card stack shows multiple items with depth.
- ❌ `insertBefore` is not the same as **`appendChild`** — `insertBefore` inserts at a specific position, `appendChild` always adds to the end.
- ❌ This is not a **React** component — it's vanilla JS DOM manipulation. In React, you'd use state and `map()`.

## In Your Own Words

1. Why do we need `updateStack()` after every DOM change (Up, Down, Add)?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Because the depth styles (z-index, transform, opacity) are calculated based on the card's position in the DOM. When you move a card (Up/Down/Add), the order changes, but the old styles are still applied. `updateStack()` recalculates and re-applies the styles for the new order. Without it, the visual depth would be wrong after the first interaction.

</details>

2. Why do we cap the styling loop at 3 cards instead of styling all of them?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Styling all cards creates visual clutter — 10 cards with decreasing opacity would look messy. Only the top 3 are visible with depth (scale, opacity, z-index). The rest are hidden (`display: none`). This creates the "stack" effect where only a few cards peek out from behind.

</details>

3. What's the bug if you restore from localStorage without clearing the container first?

<details>
<summary>Show Answer</summary>

**Sample Answer:** You get duplicates — the hardcoded cards from HTML plus the saved cards from localStorage. The result is 6 cards instead of 3. Fix: clear first (`stack.innerHTML = ""`), then `stack.innerHTML = saved`, then `updateStack()`.

</details>

## Cheat Sheet (Quick Recall)

**Select:** `document.querySelector("#stack")`, `stack.querySelectorAll(".card")`.

**Move last to front:** `stack.insertBefore(stack.lastElementChild, stack.firstElementChild)`.

**Move first to back:** `stack.appendChild(stack.firstElementChild)`.

**Create element:** `document.createElement("div")`, set `className`, `innerHTML`, then `insertBefore`/`appendChild`.

**Persist:** `localStorage.setItem("stack", stack.innerHTML)` on add. On load: `stack.innerHTML = saved; updateStack()`.

**Depth styling:** Cap at 3 cards. `zIndex = length - i`, `transform = translateY(i*10px) scale(1 - i*0.02)`, `opacity = 1 - i*0.2`.

**Key rule:** Always re-apply styles after DOM changes. Always clear before restoring. Always cap the loop.
