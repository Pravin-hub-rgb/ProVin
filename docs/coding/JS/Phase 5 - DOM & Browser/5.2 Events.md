Everything that happens in the browser is an event. This is how you make things interactive.

---

## ✅ Adding Event Listeners

✅ Basic click event:
```js
const button = document.querySelector("#submit");

button.addEventListener("click", function() {
  console.log("Button was clicked!");
});
```

✅ Most common events:
- `click`
- `submit`
- `input`
- `change`
- `keydown`
- `load`
- `scroll`

---

## ✅ Event Object

✅ Every handler receives an event object:
```js
button.addEventListener("click", function(event) {
  console.log(event);
});
```

✅ Most useful properties and methods:
```js
event.preventDefault();      // Stop default browser behaviour
event.stopPropagation();     // Stop event bubbling up
event.target;                // The actual element that was clicked
event.currentTarget;         // The element that the listener is attached to
```

---

## ✅ Removing Event Listeners

❌ This does **NOT** work:
```js
button.addEventListener("click", function() {});
button.removeEventListener("click", function() {});
```
✅ These are two different functions.

✅ This works:
```js
function handleClick() {
  console.log("clicked");
}

button.addEventListener("click", handleClick);
button.removeEventListener("click", handleClick);
```
✅ You must pass the **exact same function reference**.

---

## ✅ Event Delegation

✅ Best practice for dynamic elements:
```js
document.addEventListener("click", function(event) {
  if (event.target.matches(".delete-button")) {
    console.log("Delete button clicked");
  }
});
```
✅ Works even for buttons that are created after page load.

## 🧠 Interview Questions

> ❓ What is the difference between target and currentTarget?
> target is the actual element clicked. currentTarget is the element that has the listener attached.

> ❓ Why won't my removeEventListener work?
> You must pass the exact same function reference that you used to add it.

> ❓ What is event delegation?
> Attaching a single listener to a parent element instead of multiple listeners on child elements.
