## What is a data type?

A box can hold anything. But there are 7 different types of things that JavaScript understands natively.

These are not complicated. You already know all of them.

---

## ✅ The 7 primitive types

There are only 7. That's it. Everything else is just an object.

| Type | What it is | Example |
|---|---|---|
| `string` | Text. Any words. Any characters. | `"hello"` |
| `number` | Any number. Whole numbers, decimals, negatives. | `22` |
| `boolean` | Only two possible values. True or false. | `true` |
| `undefined` | You made the box. But you never put anything inside it. | `undefined` |
| `null` | You made the box. And you intentionally put an empty box inside it. | `null` |
| `symbol` | For unique identifiers that can never collide. You will almost never use this. | `Symbol()` |
| `bigint` | For numbers larger than 9007199254740991. You will almost never use this. | `123n` |

That is everything.

99% of the time you will only ever use the first 5. And 90% of the time you will only use the first 3.

---

## ✅ What about objects and arrays?

Don't worry about this right now. We will cover objects and arrays properly in the next lectures.

For now just remember this one sentence:

> Anything that is not one of those 7 primitive types, is an object.

That is all you need to know for now. We will explain everything else properly when we get to it.

## 🚨 The most important rule in JavaScript

**Variables do not have types. Values have types.**

The box does not care what you put inside it. You can put a string in there, then take it out and put a number in there later. JavaScript does not care at all.

```js
let thing = "hello";

thing = 22; // ✅ Perfectly fine. No error.
thing = true; // ✅ Also perfectly fine.
```

This is both the best and worst thing about JavaScript.

---

## How to check what type something is

Use `typeof` operator. That is it.

```js
typeof "hello"    // ✅ "string"
typeof 22         // ✅ "number"
typeof true       // ✅ "boolean"
typeof undefined  // ✅ "undefined"
typeof null       // ❌ "object" - this is a famous 27 year old bug. It will never be fixed.
```

Everyone knows about the null bug. Everyone just accepts it. No one will ever fix it.

---

## 🧠 Important thing no one tells you

There are no integer types. There are no float types. There are no double types. There is only `number`.

Every single number in JavaScript is the exact same type. It doesn't matter if it is 5, 3.14, or -100. They are all just `number`.

## 🚨 Interview Questions

These are the exact questions you will get asked:

1.  **Question:** How many primitive data types are there in JavaScript?
    **Answer:** 7

2.  **Question:** Name all primitive data types.
    **Answer:** string, number, boolean, undefined, null, symbol, bigint.

3.  **Question:** What does typeof null return?
    **Answer:** "object". This is a historical bug that will never be fixed.

4.  **Question:** What is the difference between null and undefined?

    **Analogy Answer:**
    - `undefined` = I made a box. I never put anything inside it.
    - `null` = I made a box. I opened it up and I put a sign that says "there is intentionally nothing here".

    **Technical Answer:**
    - `undefined` is the default value that JavaScript automatically assigns to every box you create.
    - `null` is a value that *you* manually assign, when you want to explicitly say "this is empty on purpose".

    ✅ Real example:
    ```js
    // I made a box. I never put anything inside.
    let username;

    console.log(username); // ✅ undefined. JavaScript did this.

    // Now I come along and intentionally set it to empty
    username = null;

    console.log(username); // ✅ null. I did this.
    ```

    This is the only difference. One is done automatically by JavaScript. One is done intentionally by you.

5.  **Question:** Is array a primitive type?
    **Answer:** No. Arrays are objects.
