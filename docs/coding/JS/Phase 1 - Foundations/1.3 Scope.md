## What is scope?

Scope answers exactly one question:
> **Where can this variable be accessed from?**

That is it. That is all scope ever means. Nothing more. Nothing less.

---

## ✅ The 3 types of scope you actually need

1.  Global Scope
2.  Function Scope
3.  Block Scope

That is everything.

---

## 🌍 Global Scope

If you declare a variable outside everything, it becomes global.

```js
let name = "Pravin";

function show() {
  console.log(name); // ✅ Works
}

show(); // Pravin
```

Since `name` is global, everyone can access it from anywhere.

> 📝 Note: You should almost never use global variables in real code.

---

## 🏠 Function Scope

A variable declared inside a function belongs **only** to that function.

```js
function test() {
  let age = 20;
  console.log(age); // ✅ Works
}

test();

console.log(age); // ❌ ERROR. Does not exist.
```

Because `age` only exists inside `test()`.

This is called **function scope**.

---

## 🧱 Block Scope

A block is anything inside `{ }` curly braces. This includes `if`, `for`, `while`, or just plain `{ }`.

```js
if (true) {
  let city = "Mumbai";
}

console.log(city); // ❌ ERROR. Does not exist.
```

`city` only exists inside that specific block.

That is **block scope**.

## ✅ The difference between var, let, and const

This is where 90% of confusion comes from. This is the most important part.

---

### `var` → Function Scoped

```js
function demo() {
  if (true) {
    var x = 10;
  }

  console.log(x); // ✅ Works!
}
```

Even though `x` was declared inside `if`, it is available outside the block.

Why?

Because `var` **completely ignores block scope**. It always uses function scope.

So as long as it is inside the same function, it works.

---

### `let` and `const` → Block Scoped

```js
function demo() {
  if (true) {
    let y = 20;
  }

  console.log(y); // ❌ ERROR. Does not exist.
}
```

Because `let` stays inside the block.

`const` behaves **exactly the same way** for scope.

## 🚨 The Golden Rule of Scope

This rule will never break. Ever.

✅ **Inner scope can always access outer scope.**
❌ **Outer scope can never access inner scope.**

---

### Example 1: Inner can see Outer

```js
if (true) {
  let a = 5;

  if (true) {
    console.log(a); // ✅ Works
  }
}
```

Inner block can access variables from outer block.

---

### Example 2: Outer cannot see Inner

```js
if (true) {
  let b = 10;
}

console.log(b); // ❌ ERROR
```

Outer scope cannot access variables declared inside inner scope.

## 🏠 House Analogy

This is the simplest mental model that will never let you down.

Think of scope like rooms inside a house:

| Scope | Equivalent |
|---|---|
| Global Scope | Whole house |
| Function Scope | One bedroom |
| Block Scope | Closet inside the bedroom |

Now:
✅ If something is in the house → everyone can use it
✅ If something is in the bedroom → only people in that bedroom
✅ If something is in the closet → only people inside that closet

And most importantly:
✅ People in the closet can see the bedroom
❌ People in the bedroom cannot see inside the closet

That is **exactly** how scope works.

## 📋 Final Summary

| Keyword | Scope type |
|---|---|
| `var` | Function Scope |
| `let` | Block Scope |
| `const` | Block Scope |

✅ Rules:
- Inner scope can always access outer scope
- Outer scope can never access inner scope
- `var` ignores block boundaries
- `let` and `const` respect block boundaries

## 🎯 Interview Ready Answer

> "Scope defines where a variable can be accessed. In JavaScript, `var` is function-scoped, meaning it is accessible anywhere inside the function where it is declared, even outside blocks like `if` or `for`. `let` and `const` are block-scoped, so they are only accessible within the block they are declared in. Inner scopes can access outer variables, but outer scopes cannot access inner ones."

That is the full correct answer for any interview.
