## What This Topic Is Asking (Simple Terms)

Objects are collections of key-value pairs. They're JavaScript's way of grouping related data together. You've already used objects (`{ name: "Vin", age: 25 }`) — now let's see how to create, access, modify, and destructure them, plus the spread operator for copying and merging.

---

## Object Basics

```js
const user = {
  name: "Vin",
  age: 25,
  city: "Delhi",
  isActive: true,
};

// Access
user.name;        // "Vin" (dot notation)
user["age"];      // 25 (bracket notation — useful for dynamic keys)

// Modify
user.age = 26;
user.email = "vin@dev.com";  // add new property

// Delete
delete user.city;  // removes the property

// Check if property exists
"name" in user;           // true
user.hasOwnProperty("name"); // true
```

### Dynamic Keys

```js
const key = "name";
const value = "Vin";

const obj = {
  [key]: value,  // computed property name
};
// obj = { name: "Vin" }

// Access with variable
const fieldName = "age";
user[fieldName] = 26;  // user.age = 26
```

## Destructuring

Extract properties from an object into variables:

```js
const user = { name: "Vin", age: 25, city: "Delhi" };

// Basic destructuring
const { name, age } = user;
// name = "Vin", age = 25

// Rename
const { name: userName, age: userAge } = user;
// userName = "Vin", userAge = 25

// Default values
const { name, country = "India" } = user;
// country = "India" (not in user, so default is used)

// Nested destructuring
const user2 = { name: "Vin", address: { city: "Delhi", zip: 110001 } };
const { address: { city, zip } } = user2;
// city = "Delhi", zip = 110001
```

### Destructuring in Function Parameters

```js
function greet({ name, age }) {
  console.log(`Hello ${name}, you are ${age}`);
}

greet({ name: "Vin", age: 25 }); // "Hello Vin, you are 25"

// With defaults
function createUser({ name, role = "user" } = {}) {
  return { name, role };
}
createUser({ name: "Vin" });  // { name: "Vin", role: "user" }
createUser();                 // { name: undefined, role: "user" }
```

### Array Destructuring

```js
const arr = [1, 2, 3];
const [a, b, c] = arr;
// a = 1, b = 2, c = 3

// Skip elements
const [first, , third] = arr;
// first = 1, third = 3

// Rest
const [head, ...tail] = arr;
// head = 1, tail = [2, 3]

// Swap
let x = 1, y = 2;
[x, y] = [y, x];
// x = 2, y = 1
```

## Spread Operator (`...`)

### Copying Objects

```js
const original = { name: "Vin", age: 25 };
const copy = { ...original };
// copy = { name: "Vin", age: 25 }
// copy is a NEW object — modifying copy doesn't affect original

copy.age = 26;
// original.age is still 25
```

### Merging Objects

```js
const defaults = { theme: "light", lang: "en" };
const userPrefs = { theme: "dark" };

const settings = { ...defaults, ...userPrefs };
// settings = { theme: "dark", lang: "en" }
// Later spread overrides earlier — "dark" wins
```

### Adding/Overriding Properties

```js
const user = { name: "Vin", age: 25 };
const updated = { ...user, age: 26, email: "vin@dev.com" };
// updated = { name: "Vin", age: 26, email: "vin@dev.com" }
```

### Spread in Arrays

```js
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];

const combined = [...arr1, ...arr2];  // [1, 2, 3, 4, 5, 6]
const copy = [...arr1];               // shallow copy
const withExtra = [0, ...arr1, 99];   // [0, 1, 2, 3, 99]
```

## Rest Operator (`...`) in Objects

Collect remaining properties:

```js
const user = { name: "Vin", age: 25, city: "Delhi", country: "India" };

const { name, ...rest } = user;
// name = "Vin"
// rest = { age: 25, city: "Delhi", country: "India" }

// In function parameters
function logUser({ name, ...details }) {
  console.log(name);    // "Vin"
  console.log(details); // { age: 25, city: "Delhi", country: "India" }
}
```

## Object Methods

```js
const user = { name: "Vin", age: 25 };

Object.keys(user);    // ["name", "age"]
Object.values(user);  // ["Vin", 25]
Object.entries(user); // [["name", "Vin"], ["age", 25]]

// Convert entries back to object
Object.fromEntries([["name", "Vin"], ["age", 25]]); // { name: "Vin", age: 25 }

// Freeze (prevent any changes)
const frozen = Object.freeze({ x: 1 });
frozen.x = 99;  // silently fails (or throws in strict mode)
frozen.x;       // 1

// Seal (prevent adding/removing, but allow modifying existing)
const sealed = Object.seal({ x: 1 });
sealed.x = 99;  // works
sealed.y = 2;   // fails (can't add)
```

## Common Mistakes

- **Mutating objects directly** — `user.age = 26` changes the original. Use spread: `{ ...user, age: 26 }`.
- **Shallow copy isn't deep** — `{ ...obj }` copies top-level properties, but nested objects are still references. `{ ...obj, nested: { ...obj.nested } }` for one level deep.
- **Destructuring non-existent properties** — `const { x } = {}` gives `undefined`, not an error. Use defaults: `const { x = 0 } = {}`.
- **Rest must be last** — `const { ...rest, name } = user` is a SyntaxError. Rest collects everything remaining, so it must be the last property.
- **Spread order matters** — `{ ...defaults, ...overrides }` — later properties override earlier ones.

## What This Topic Is NOT

- ❌ Objects are not the same as **Maps** — objects have string/symbol keys, Maps can have any type as keys. Objects have prototype chain, Maps don't. Maps have `.size`, objects need `Object.keys().length`.
- ❌ Spread (`...`) is not the same as **rest** (`...`) — spread *expands* an object/array into individual elements. Rest *collects* remaining elements into an array/object. Same syntax, opposite direction.
- ❌ Destructuring is not the same as **unpacking** — destructuring creates new variables. The original object is unchanged.
- ❌ `Object.freeze` is not the same as **`const`** — `const` prevents reassignment of the variable. `Object.freeze` prevents modification of the object's properties.

## In Your Own Words

1. What's the difference between spread (`...`) and rest (`...`)? Give an example of each.

<details>
<summary>Show Answer</summary>

**Sample Answer:** Spread *expands* — it takes an object/array and spreads its elements into a new one: `const copy = { ...user }` or `const combined = [...arr1, ...arr2]`. Rest *collects* — it gathers remaining elements into a new array/object: `const { name, ...rest } = user` (rest = `{ age, city }`). Same syntax, opposite direction. Spread = "take apart and spread out." Rest = "gather up the leftovers."

</details>

2. Why use destructuring in function parameters? What problem does it solve?

<details>
<summary>Show Answer</summary>

**Sample Answer:** It makes the function's expected input clear and avoids repetitive `obj.property` access. `function greet({ name, age })` is clearer than `function greet(user) { console.log(user.name, user.age) }`. It also supports defaults: `function createUser({ name, role = "user" })`. And it's self-documenting — the parameter list shows exactly what fields are needed.

</details>

3. What's the difference between a shallow copy (`{ ...obj }`) and a deep copy? When does it matter?

<details>
<summary>Show Answer</summary>

**Sample Answer:** A shallow copy copies top-level properties, but nested objects are still references: `const copy = { ...original }; copy.nested.x = 99` also changes `original.nested.x`. A deep copy creates entirely new objects at every level. It matters when you have nested objects/arrays and need to modify one without affecting the other. For shallow, use spread. For deep, use `structuredClone(obj)` (modern) or `JSON.parse(JSON.stringify(obj))` (older, loses functions/dates).

</details>

## Cheat Sheet (Quick Recall)

**Access:** `obj.key` (dot) or `obj["key"]` (bracket, for dynamic keys).

**Destructure:** `const { name, age = 18 } = user;` — extract with defaults.

**Rename:** `const { name: userName } = user;`

**Spread (copy/merge):** `{ ...obj }`, `{ ...a, ...b }`, `{ ...obj, key: newValue }`.

**Rest (collect):** `const { name, ...rest } = user;` — must be last.

**Array spread:** `[...arr1, ...arr2]`, `[0, ...arr, 99]`.

**Object methods:** `Object.keys()`, `Object.values()`, `Object.entries()`, `Object.fromEntries()`.

**Freeze/Seal:** `Object.freeze(obj)` (no changes), `Object.seal(obj)` (modify existing, no add/remove).

**Key rule:** Spread = expand (outward). Rest = collect (inward). Same `...` syntax, opposite direction.
