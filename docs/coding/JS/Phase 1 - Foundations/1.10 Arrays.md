## What This Topic Is Asking (Simple Terms)

Arrays are ordered lists of values. You've used them before (`[1, 2, 3]`), but there's a whole toolkit of methods for adding, removing, transforming, and searching through them. This is where JavaScript becomes powerful for data processing.

---

## Array Basics

```js
const arr = [1, 2, 3, 4, 5];

arr.length;       // 5
arr[0];           // 1 (first element)
arr[arr.length - 1]; // 5 (last element)
arr[10];          // undefined (out of bounds)
```

### Adding and Removing

```js
const fruits = ["apple", "banana"];

// Add to end
fruits.push("cherry");      // ["apple", "banana", "cherry"] — returns new length (3)

// Remove from end
fruits.pop();               // ["apple", "banana"] — returns removed element ("cherry")

// Add to start
fruits.unshift("mango");    // ["mango", "apple", "banana"] — returns new length (3)

// Remove from start
fruits.shift();             // ["apple", "banana"] — returns removed element ("mango")

// Add/remove at specific position
fruits.splice(1, 0, "grape");  // insert "grape" at index 1
// ["apple", "grape", "banana"]

fruits.splice(1, 1);           // remove 1 element at index 1
// ["apple", "banana"]
```

### Slicing (Non-Mutating)

```js
const arr = [1, 2, 3, 4, 5];

arr.slice(1, 3);    // [2, 3] — elements from index 1 to 2 (end not included)
arr.slice(2);       // [3, 4, 5] — from index 2 to end
arr.slice(-2);      // [4, 5] — last 2 elements
arr.slice();        // [1, 2, 3, 4, 5] — shallow copy
```

**Important:** `slice` doesn't mutate the original array. `splice` does.

## Iteration Methods

### `forEach` — run a function for each element (no return value)

```js
const nums = [1, 2, 3];
nums.forEach((n, i) => {
  console.log(n, i); // 1 0, 2 1, 3 2
});
```

### `map` — transform each element, return new array

```js
const nums = [1, 2, 3];
const doubled = nums.map((n) => n * 2);
// doubled = [2, 4, 6]
// nums is still [1, 2, 3] (map doesn't mutate)
```

### `filter` — keep elements that pass a test, return new array

```js
const nums = [1, 2, 3, 4, 5];
const evens = nums.filter((n) => n % 2 === 0);
// evens = [2, 4]
```

### `reduce` — combine all elements into a single value

```js
const nums = [1, 2, 3, 4, 5];
const sum = nums.reduce((acc, n) => acc + n, 0);
// sum = 15

// Find max
const max = nums.reduce((a, b) => (a > b ? a : b));
// max = 5

// Count occurrences
const fruits = ["apple", "banana", "apple", "cherry"];
const counts = fruits.reduce((acc, fruit) => {
  acc[fruit] = (acc[fruit] || 0) + 1;
  return acc;
}, {});
// counts = { apple: 2, banana: 1, cherry: 1 }
```

### `find` / `findIndex` — first element matching a condition

```js
const users = [{ id: 1, name: "Vin" }, { id: 2, name: "Amit" }];
const user = users.find((u) => u.id === 2);     // { id: 2, name: "Amit" }
const idx = users.findIndex((u) => u.id === 2); // 1
const missing = users.find((u) => u.id === 99);  // undefined
```

### `some` / `every` — check if any/all elements pass a test

```js
const nums = [1, 2, 3, 4, 5];
nums.some((n) => n > 4);   // true (at least one is > 4)
nums.every((n) => n > 0);  // true (all are > 0)
nums.every((n) => n > 3);  // false (not all are > 3)
```

### `sort` — sorts in place (mutates!)

```js
const nums = [3, 1, 4, 1, 5];
nums.sort();               // [1, 1, 3, 4, 5] (works for strings, but NOT numbers!)

// For numbers, always pass a comparator:
nums.sort((a, b) => a - b);  // ascending: [1, 1, 3, 4, 5]
nums.sort((a, b) => b - a);  // descending: [5, 4, 3, 1, 1]

// Sorting strings
const names = ["Charlie", "Alice", "Bob"];
names.sort();  // ["Alice", "Bob", "Charlie"] (works for strings)
```

### `reverse` — reverses in place

```js
const arr = [1, 2, 3];
arr.reverse(); // [3, 2, 1] — mutates original
```

## Chaining Methods

Array methods return arrays, so you can chain them:

```js
const users = [
  { name: "Vin", age: 25, active: true },
  { name: "Amit", age: 17, active: false },
  { name: "Priya", age: 30, active: true },
];

// Get names of active adult users, sorted alphabetically
const result = users
  .filter((u) => u.active && u.age >= 18)
  .map((u) => u.name)
  .sort();

// result = ["Priya", "Vin"]
```

## `includes`, `indexOf`, `lastIndexOf`

```js
const arr = [1, 2, 3, 2];

arr.includes(2);        // true
arr.includes(99);       // false
arr.indexOf(2);         // 1 (first occurrence)
arr.lastIndexOf(2);     // 3 (last occurrence)
arr.indexOf(99);        // -1 (not found)
```

## Common Mistakes

- **`sort()` without comparator on numbers** — `[10, 2, 1].sort()` gives `[1, 10, 2]` (string sort). Always pass `(a, b) => a - b`.
- **Mutating methods vs non-mutating** — `push`, `pop`, `splice`, `sort`, `reverse` mutate. `map`, `filter`, `reduce`, `slice` don't. Know which is which.
- **Forgetting `reduce`'s initial value** — `arr.reduce((a, c) => a + c)` works for non-empty arrays, but throws on empty arrays. Always pass initial value: `arr.reduce((a, c) => a + c, 0)`.
- **Using `forEach` when you need a return value** — `forEach` returns `undefined`. Use `map` if you need a new array.

---

## What This Topic Is NOT

- ❌ Arrays are not the same as **Sets** — arrays allow duplicates, Sets don't. Arrays are ordered, Sets are (insertion) ordered but optimized for membership checks.
- ❌ `map` is not the same as **`forEach`** — `map` returns a new array, `forEach` returns `undefined`.
- ❌ `splice` is not the same as **`slice`** — `splice` mutates, `slice` doesn't.
- ❌ `find` is not the same as **`filter`** — `find` returns the first match (or `undefined`), `filter` returns all matches (or `[]`).

## In Your Own Words

1. What's the difference between `map`, `filter`, and `reduce`? When would you use each?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `map` transforms each element and returns a new array of the same length: `[1,2,3].map(n => n*2)` → `[2,4,6]`. Use when you want to change each item. `filter` keeps elements that pass a test, returns a (possibly shorter) array: `[1,2,3,4].filter(n => n%2===0)` → `[2,4]`. Use when you want to remove items. `reduce` combines all elements into a single value: `[1,2,3].reduce((a,c) => a+c, 0)` → `6`. Use when you want a single result (sum, max, count, object).

</details>

2. Why does `sort()` need a comparator function for numbers? What happens without it?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Without a comparator, `sort()` converts elements to strings and sorts lexicographically. `[10, 2, 1].sort()` gives `[1, 10, 2]` because "1" < "10" < "2" in string order. With a comparator `(a, b) => a - b`, it sorts numerically: `[1, 2, 10]`. Always pass a comparator for numbers.

</details>

3. Which array methods mutate the original array, and which return a new array?

<details>
<summary>Show Answer</summary>

**Sample Answer:** Mutating (change original): `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`. Non-mutating (return new array): `map`, `filter`, `reduce`, `slice`, `concat`, `find`, `some`, `every`, `includes`, `indexOf`. If you need to keep the original, use non-mutating methods or copy first: `[...arr].sort()`.

</details>

## Cheat Sheet (Quick Recall)

**Add/Remove:** `push` (end), `pop` (end), `unshift` (start), `shift` (start), `splice` (anywhere, mutates).

**Transform:** `map` (transform each), `filter` (keep matching), `reduce` (combine to one value).

**Search:** `find` (first match), `findIndex` (index of first match), `includes` (boolean), `indexOf`/`lastIndexOf` (position).

**Check:** `some` (any match?), `every` (all match?).

**Sort:** `sort((a,b) => a-b)` ascending, `sort((a,b) => b-a)` descending. Always pass comparator for numbers.

**Safe (non-mutating):** `slice`, `map`, `filter`, `reduce`, `concat`, `find`, `includes`.

**Mutating:** `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`.
