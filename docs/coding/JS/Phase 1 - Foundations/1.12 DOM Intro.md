## What This Topic Is Asking (Simple Terms)

The DOM (Document Object Model) is the browser's live tree representation of your HTML. JavaScript can select elements from this tree, change their text, style, attributes, and even add or remove elements. This is how you make web pages interactive without reloading.

---

## DOM Basics

```js
// The browser parses your HTML into a tree
// <html>
//   <body>
//     <h1 id="title">Hello</h1>
//     <p class="text">World</p>
//     <button id="btn">Click me</button>
//   </body>
// </html>

// Select elements
const h1 = document.getElementById("title");
const p = document.querySelector(".text");
const btn = document.querySelector("#btn");
const allP = document.querySelectorAll("p"); // NodeList
```

### Selection Methods

```js
// By ID (returns single element or null)
document.getElementById("title");

// By class name (returns HTMLCollection - live)
document.getElementsByClassName("card");

// By tag name (returns HTMLCollection - live)
document.getElementsByTagName("p");

// CSS selector (returns first match or null)
document.querySelector(".card");        // first .card
document.querySelector("#btn");        // element with id btn
document.querySelector("div > p");     // first p inside a div

// CSS selector (returns NodeList - static)
document.querySelectorAll(".card");     // all .card elements
document.querySelectorAll("ul li");     // all li inside ul
```

**`querySelector` vs `querySelectorAll`:** `querySelector` returns the first match (or `null`). `querySelectorAll` returns a `NodeList` of all matches (empty if none). Use `querySelector` for one element, `querySelectorAll` for many.

**`HTMLCollection` vs `NodeList`:** Both are array-like. `HTMLCollection` is *live* (updates when DOM changes). `NodeList` from `querySelectorAll` is *static* (snapshot). Convert to array: `Array.from(collection)` or `[...collection]`.

## Changing Content

```js
const el = document.querySelector("#title");

// Text (safe - no HTML parsing)
el.textContent = "New Title";
el.innerText = "New Title";     // similar, but respects CSS visibility

// HTML (parses HTML - XSS risk if from user input!)
el.innerHTML = "<b>Bold</b> text";

// Clear content
el.textContent = "";
el.innerHTML = "";
```

**`textContent` vs `innerHTML`:** `textContent` treats everything as text (safe). `innerHTML` parses HTML (dangerous with user input — XSS risk). Use `textContent` for user data, `innerHTML` only for trusted HTML.

## Changing Styles

```js
const el = document.querySelector("#title");

// Inline styles (camelCase for CSS properties)
el.style.color = "red";
el.style.fontSize = "24px";
el.style.backgroundColor = "yellow";
el.style.display = "none";      // hide
el.style.display = "block";     // show

// CSS classes (preferred approach)
el.classList.add("active");
el.classList.remove("active");
el.classList.toggle("active");   // add if missing, remove if present
el.classList.contains("active"); // true/false

// Replace all classes
el.className = "new-class another-class";
```

**Best practice:** Use `classList` (add/remove/toggle) instead of `style`. Keep styling in CSS, use JS only for state changes (add/remove classes).

## Changing Attributes

```js
const img = document.querySelector("img");

// Get/set attributes
img.getAttribute("src");          // "photo.jpg"
img.setAttribute("src", "new.jpg");
img.setAttribute("alt", "A photo");

// Direct property access (works for standard attributes)
img.src = "new.jpg";
img.alt = "A photo";

// Remove attribute
img.removeAttribute("alt");

// Check if attribute exists
img.hasAttribute("src");  // true

// Data attributes
// <div data-user-id="42" data-role="admin">
const div = document.querySelector("div");
div.dataset.userId;     // "42"
div.dataset.role;       // "admin"
div.dataset.userId = "99";  // updates data-user-id
```

## Creating and Removing Elements

```js
// Create
const div = document.createElement("div");
div.className = "card";
div.textContent = "Hello";

// Append to parent
const container = document.querySelector("#container");
container.appendChild(div);

// Insert at specific position
const firstChild = container.firstChild;
container.insertBefore(div, firstChild); // insert before first child

// Remove
div.remove();               // modern
container.removeChild(div); // older way

// Clone
const clone = div.cloneNode(true); // true = deep clone (includes children)
```

### Clearing a Container

```js
const container = document.querySelector("#list");
container.innerHTML = "";  // removes all children (simple but can be slow)
// Or:
while (container.firstChild) {
  container.removeChild(container.firstChild);
}
```

## Event Handling

```js
const btn = document.querySelector("#btn");

// Add event listener
btn.addEventListener("click", (event) => {
  console.log("Clicked!", event.target);
});

// Remove event listener (needs same function reference)
function handleClick() { console.log("clicked"); }
btn.addEventListener("click", handleClick);
btn.removeEventListener("click", handleClick);

// Common events
btn.addEventListener("click", handler);
input.addEventListener("input", handler);     // on every keystroke
input.addEventListener("change", handler);     // on blur (after change)
input.addEventListener("keydown", handler);   // key pressed
form.addEventListener("submit", handler);      // form submitted
window.addEventListener("scroll", handler);   // page scrolled
window.addEventListener("load", handler);     // page loaded
```

### Event Object

```js
btn.addEventListener("click", (e) => {
  e.target;           // the element that was clicked
  e.currentTarget;    // the element the listener is attached to
  e.preventDefault();  // stop default behavior (link navigation, form submit)
  e.stopPropagation(); // stop event from bubbling up
  e.type;             // "click"
});
```

## Tree Navigation

```js
const el = document.querySelector(".card");

el.parentElement;          // parent element
el.children;               // HTMLCollection of child elements
el.firstElementChild;      // first child element
el.lastElementChild;       // last child element
el.nextElementSibling;     // next sibling element
el.previousElementSibling; // previous sibling element
el.closest(".container");  // nearest ancestor matching selector
```

## Common Mistakes

- **Using `innerHTML` with user input** — XSS risk. Use `textContent` for user data.
- **Forgetting `e.preventDefault()`** — form submits and page reloads. Always prevent default in form handlers.
- **Querying before DOM is ready** — `document.querySelector("#btn")` returns `null` if the script runs before the HTML is parsed. Put `<script>` at the end of `<body>`, or use `DOMContentLoaded` event, or use `defer` attribute.
- **Modifying NodeList while iterating** — `querySelectorAll` returns a static NodeList, but removing elements during iteration causes index shifts. Convert to array first: `[...nodeList].forEach(...)`.
- **Using `getElementsByClassName` expecting an array** — it returns an `HTMLCollection`, not an array. Use `Array.from()` or spread to convert.

---

## What This Topic Is NOT

- ❌ DOM manipulation is not the same as **React** — React uses a virtual DOM and manages updates declaratively. Direct DOM manipulation is imperative (you tell the browser exactly what to change).
- ❌ `querySelector` is not the same as **jQuery** — `querySelector` is native browser API. jQuery was a library that wrapped DOM methods for cross-browser compatibility (mostly unnecessary now).
- ❌ `innerHTML` is not the same as **`textContent`** — `innerHTML` parses HTML (can execute scripts), `textContent` treats everything as text (safe).

## In Your Own Words

1. What's the difference between `querySelector` and `querySelectorAll`? When would you use each?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `querySelector` returns the first matching element (or `null`). `querySelectorAll` returns a `NodeList` of all matches (empty if none). Use `querySelector` when you need one element (e.g., `#btn`, `.header`). Use `querySelectorAll` when you need all matching elements (e.g., all `.card` elements). `querySelectorAll` returns a static snapshot; `getElementsByClassName` returns a live collection that updates with the DOM.

</details>

2. Why is `innerHTML` dangerous with user input, and what should you use instead?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `innerHTML` parses the string as HTML — if it contains `<script>`, the browser executes it (XSS attack). `textContent` treats everything as plain text — `<script>` shows as text, doesn't execute. Always use `textContent` for user-provided data. Only use `innerHTML` for trusted content (your own HTML strings).

</details>

3. What's the difference between `HTMLCollection` and `NodeList`?

<details>
<summary>Show Answer</summary>

**Sample Answer:** `HTMLCollection` (from `getElementsByClassName`, `getElementsByTagName`) is *live* — it updates automatically when the DOM changes. `NodeList` (from `querySelectorAll`) is *static* — a snapshot at the time of query. Both are array-like but not arrays. Convert with `Array.from()` or spread `[...collection]` to use array methods like `map`, `filter`.

</details>

## Cheat Sheet (Quick Recall)

**Select:** `getElementById`, `querySelector` (first match), `querySelectorAll` (all matches).

**Change text:** `textContent` (safe), `innerHTML` (parses HTML — XSS risk).

**Change style:** `el.style.property = "value"` (camelCase), `el.classList.add/remove/toggle/contains`.

**Change attributes:** `getAttribute`, `setAttribute`, `removeAttribute`, `hasAttribute`, `dataset` (data-*).

**Create/Remove:** `createElement`, `appendChild`, `insertBefore`, `remove`, `removeChild`, `cloneNode`.

**Events:** `addEventListener(event, handler)`, `removeEventListener(event, handler)`. Common: `click`, `input`, `change`, `submit`, `keydown`, `scroll`, `load`.

**Event object:** `e.target` (clicked element), `e.preventDefault()` (stop default), `e.stopPropagation()` (stop bubbling).

**Tree nav:** `parentElement`, `children`, `firstElementChild`, `lastElementChild`, `nextElementSibling`, `previousElementSibling`, `closest(selector)`.

**Key rule:** `textContent` for user data (safe). `innerHTML` only for trusted HTML. Put `<script>` at end of `<body>` or use `defer`.<|end|>
