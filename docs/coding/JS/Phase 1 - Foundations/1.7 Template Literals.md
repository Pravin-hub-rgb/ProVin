## What are Template Literals?

Template Literals let you create strings without all the annoying concatenation.

Use backtick `` ` `` characters instead of quotes.

```js
const name = "Arjun";

// ❌ Old way
console.log("Hello " + name + ", you are " + (20 + 1) + " years old");

// ✅ New way
console.log(`Hello ${name}, you are ${20 + 1} years old`);
```

---

## ✅ Two super powers:

### 1. You can put any JavaScript expression inside `${ }`

Anything that returns a value works:
- Variables
- Calculations
- Function calls
- Ternary operators
- Literally anything

```js
const age = 22;

console.log(`You are ${age > 18 ? "adult" : "minor"}`);
```

---

### 2. Multi line strings work perfectly

Before template literals you had to do this garbage:
```js
const html = "<div>" +
  "<p>" + name + "</p>" +
  "</div>";
```

Now you just write normally:
```js
const html = `
  <div>
    <p>${name}</p>
  </div>
`;
```

✅ All new lines and spaces are preserved exactly as you write them.
