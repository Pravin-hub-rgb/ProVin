These are the two most useful features added to JavaScript in the last 10 years.

---

## ✅ Before these existed

This is what everyone used to write:
```js
let city;
if (user && user.address && user.address.city) {
  city = user.address.city;
} else {
  city = undefined;
}
```

✅ This was horrible. Everyone wrote this 100 times every day.

---

## ✅ Optional Chaining `?.`

✅ This was invented specifically to fix this problem:
```js
const city = user?.address?.city;
```

✅ That's it. One line. Exactly the same thing.

✅ It will stop and return `undefined` immediately if anything in the chain is null or undefined. It will never throw an error.

✅ Works with arrays:
```js
const firstHobby = user?.hobbies?.[0];
```

✅ Works with methods:
```js
const age = user?.getAge?.();
```

---

## ✅ Nullish Coalescing `??`

✅ Provides a fallback value **ONLY** for `null` and `undefined`.

✅ This is wrong:
```js
const count = user.count || 10;
```
❌ If `user.count` is `0` it will still use 10. That is almost never what you want.

✅ This is correct:
```js
const count = user.count ?? 10;
```

✅ If `user.count` is `0` → it will use `0`. Not 10.
✅ If `user.count` is `""` → it will use `""`. Not 10.
✅ If `user.count` is `false` → it will use `false`. Not 10.
✅ **Only** if it is `null` or `undefined` → it will use 10.

---

## ✅ Perfect pattern

✅ This is what everyone writes now:
```js
const city = user?.address?.city ?? "Unknown";
```

✅ No errors. Correct defaults. One line. Perfect.

## 🧠 Interview Questions

> ❓ What is the difference between `||` and `??`?
> `||` treats 0, empty string and false as falsy. `??` only falls back for null and undefined.

> ❓ What does optional chaining do?
> Safely accesses nested properties without throwing errors if any intermediate property is null or undefined.

> ❓ Can you use optional chaining on the left side of an assignment?
> No. You cannot write `user?.address?.city = "Delhi"`.

## 🎯 Interview Ready Answer

> "Optional chaining `?.` allows safe access of nested properties without throwing errors when intermediate values are null or undefined. Nullish coalescing `??` provides fallback values only for null and undefined, correctly preserving valid falsy values like 0 and empty string. These two operators are the standard way to handle null safety in modern JavaScript."

That is the full correct answer.
