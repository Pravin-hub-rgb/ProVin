## ✅ What is a Higher Order Function?

✅ Simple definition:

> Any function that either:
> 1.  **Accepts another function as an argument**
> 2.  **Returns another function**

That is it. That is the full definition.

---

## ✅ All array methods are Higher Order Functions

This is why `.map()` works:

```js
arr.map(function(item) {
  return item * 2;
});
```

✅ You are passing a function into `map()`. Therefore `map()` is a higher order function.

✅ All of these are higher order functions:
- `map`, `filter`, `reduce`
- `forEach`, `some`, `every`
- `setTimeout`, `setInterval`
- `addEventListener`

---

## ✅ Function that returns another function

This is the real magic. This uses closures.

```js
function multiplier(factor) {
  return function(number) {
    return number * factor;
  };
}
```

✅ Usage:
```js
const double = multiplier(2);
const triple = multiplier(3);

double(5); // 10
triple(5); // 15
```

✅ This is the most powerful pattern in JavaScript. This is how you create reusable logic.

## ✅ React use cases

✅ Event handlers:
```jsx
function handleDelete(id) {
  return function() {
    deleteItem(id);
  };
}

{items.map(item => (
  <button onClick={handleDelete(item.id)}>Delete</button>
))}
```

✅ This is how everyone writes React event handlers.

---

## ✅ Common mistakes:

❌ Don't invoke the function when passing it. Pass the reference.

```js
setTimeout(doSomething(), 1000); // ❌ WRONG - runs immediately
setTimeout(doSomething, 1000);   // ✅ CORRECT
```

## 🧠 Interview Questions

> ❓ Name 3 examples of higher order functions in JavaScript.
> map, filter, reduce, setTimeout, addEventListener.

> ❓ What is the advantage of higher order functions?
> They enable code reuse, composition, and allow you to create abstract reusable logic.

> ❓ Are arrow functions higher order functions?
> Only if they accept or return another function.
