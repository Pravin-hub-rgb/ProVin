# 1.3 Build Up — Typed Feed Module (3 Symbols)

> **Now build a real feed class** — 3 symbols, OHLC shape, per-symbol routing.

## Problem: Hardcoded Single Symbol

The 1.2 example only handled `AAPL`. Real trading feeds handle many symbols. How? **One interval, N symbols.**

## Solution: Feed Class with Multiple Symbols

```typescript
// 1.3-feed-partial.ts
interface OHLC {
  symbol: string
  open: number
  high: number
  low: number
  close: number
  timestamp: number
}

interface FeedEvent {
  type: "tick"
  data: OHLC
}

class SimulatedFeed {
  private prices: Map<string, number> = new Map()
  private ticker: NodeJS.Timeout | null = null
  private tickCount = 0

  constructor(private symbols: string[]) {
    // Initialize prices for each symbol at 100.00
    for (const symbol of symbols) {
      this.prices.set(symbol, 100)
    }
  }

  private makeTick(symbol: string): OHLC {
    const current = this.prices.get(symbol) ?? 100
    const change = (Math.random() - 0.5) * 2  // ±$1 random walk
    const next = current + change

    const tick: OHLC = {
      symbol,
      open: current,
      high: Math.max(current, next),
      low: Math.min(current, next),
      close: next,
      timestamp: Date.now(),
    }

    this.prices.set(symbol, next)
    return tick
  }

  start(): void {
    this.ticker = setInterval(() => {
      this.tickCount++
      for (const symbol of this.symbols) {
        const tick = this.makeTick(symbol)
        // For now, just log — subscribers come in 3.0
        console.log(`${tick.symbol}: $${tick.close.toFixed(2)}`)
      }
    }, 500)
  }

  stop(): void {
    if (this.ticker) {
      clearInterval(this.ticker)
      this.ticker = null
      console.log("feed stopped")
    }
  }
}

// Test it
const feed = new SimulatedFeed(["AAPL", "MSFT", "GOOGL"])
feed.start()
setTimeout(() => feed.stop(), 3000)
```

## Line-by-Line Explanation

### `private prices: Map<string, number>`
- **What:** Stores current price per symbol
- **Why:** Avoids global variables — data scoped to the class instance
- **Map vs Object:** Map allows any type as key, preserves insertion order, size is O(1)

### `private ticker: NodeJS.Timeout | null = null`
- **What:** Stores the interval ID
- **Why `| null`:** Before `start()`, it's null. TypeScript knows to check before calling `clearInterval`

### `constructor(private symbols: string[])`
- **What:** Parameter property — shorthand for `this.symbols = symbols`
- **Why:** Fewer lines, same result

### `makeTick` method
- **What:** Generates a realistic OHLC tick from previous price
- **Why:** Random walk (`Math.random() - 0.5`) simulates realistic price movement
- **`Math.max`/`Math.min`:** Ensures high ≥ close ≥ low

### `start()` / `stop()`
- **start:** Creates interval, stores ID
- **stop:** Clears interval, null check prevents double-stop

**Run:** `npx tsx 1.3-feed-partial.ts`

## Common Mistakes

```typescript
// ❌ Forgetting null check
stop() {
  clearInterval(this.ticker)  // TS error: Object is possibly null
}

// ❌ Using Object instead of Map
private prices = {}  // prices["AAPL"] = 100 — works but less safe
```

## What It Is NOT

- **NOT emitting events yet** — subscribers come in 3.0
- **NOT handling pause/resume** — that's 5.0
- **NOT the production streamer** — no protobuf, no real WebSocket

## Bridge — This IS `streamer.ts` Architecture

Your `SimulatedFeed.start()` → `streamer.ts`'s `connect()`:
- Same `setInterval` loop → same `tickCount++`
- Same per-symbol data tracking → `streamer.ts` keeps per-symbol protobuf state
- Same cleanup-on-stop → `streamer.ts` cleanup on disconnect
