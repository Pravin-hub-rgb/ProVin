# 3.2 Minimal Code — Basic EventEmitter

> **Yaar, abhi sirf EventEmitter ka basic example.** No feed, no OHLC — just events firing.

## The Code

```typescript
// 3.2-minimal.ts
import { EventEmitter } from "events"

// Step 1: Extend (or just instantiate)
class MyFeed extends EventEmitter {}

// Step 2: Create instance
const feed = new MyFeed()

// Step 3: Attach listeners
feed.on("hello", (name: string) => {
  console.log(`Hello, ${name}!`)
})

feed.on("goodbye", () => {
  console.log("Goodbye!")
})

// Step 4: Emit events
feed.emit("hello", "TypeScript")  // Hello, TypeScript!
feed.emit("goodbye")              // Goodbye!

console.log("--- Listeners attached:", feed.listenerCount("hello"))
```

## Why This Matters

Real `streamer.ts` is 2000+ lines, but this 12-line file has the exact same pattern:

```
streamer.ts (real):
  extends EventEmitter
  on("tick", handler)  ← 5 handlers in a Map
  emit("tick", ohlc)   ← once per WebSocket message

3.2 (this file):
  extends EventEmitter
  on("hello", handler) ← 2 handlers
  emit("hello", name)  ← once
```

Same `on`/`emit` API. Same loose coupling. Just less data.

## Run It

```bash
npx tsx 3.2-minimal.ts
```

## What It Is NOT

- **NOT a real feed.** No price data, no interval, no Map routing
- **NOT typed channels.** Real streamer uses typed channels like `emit("tick", ohlc: OHLC)`
