# 2.4 Testing — Verify Transitions

> **After writing code — you must test it, otherwise anything can run.**

## Test File

```typescript
// 2.4-test-machine.ts
import { PositionMachine } from "./2.3-position-machine"

// Test suite for position transitions
console.log("=== TEST: Valid Transitions ===\n")

const manager = new PositionMachine("TEST")

// Test 1: Full normal cycle
console.log("Test 1: idle → watching → enter → exit → idle")
let results: string[] = []

results.push(manager.watch() ? "watch PASS" : "watch FAIL")
results.push(manager.enter(150) ? "enter PASS" : "enter FAIL")
results.push(manager.exit() ? "exit PASS" : "exit FAIL")
results.push(manager.reset() ? "reset PASS" : "reset FAIL")

for (const r of results) console.log(r)

// Test 2: Double entry prevention
console.log("\nTest 2: Prevent double entry")
const manager2 = new PositionMachine("AAPL")

manager2.watch()      // ✅ watching
const entered = manager2.enter(100)  // ✅ first enter
const doubleEntered = manager2.enter(105)  // ❌ second enter
console.log(doubleEntered ? "PROBLEM: double entry allowed!" : "GOOD: double entry blocked")

// Test 3: Signal routing
console.log("\nTest 3: Signals route correctly")
const mgr3 = new PositionMachine("MSFT")
mgr3.watch()

// Simulate incoming signal while watching
mgr3.onSignal("long")  // should enter
console.log("Status after signal:", mgr3.getStatus())

mgr3.onSignal("long")  // should NOT double-enter
console.log("Status after 2nd signal:", mgr3.getStatus())

// Test 4: Invalid from idle
console.log("\nTest 4: Cannot enter from idle")
const mgr4 = new PositionMachine("GOOGL")
const enteredFromIdle = mgr4.enter(100)  // should FAIL
console.log(enteredFromIdle ? "PROBLEM: entered from idle!" : "GOOD: cannot enter from idle")
```

```bash
npx tsx 2.4-test-machine.ts
```

## 90-Second Explanation Script

> "State machine guarantees a stock is in exactly **one phase** — so **double entries can't happen**. Each transition is validated against a table (`idle → watching`, `watching → in_position`, `in_position → exited`). If a second entry signal arrives, the machine is already in `in_position`, so the table says `in_position → in_position` is not allowed — the entry is rejected. That's the interview answer."

## Common Test Mistake

```typescript
// ❌ Not testing invalid cases
test("watch works") {
  manager.watch()  // only tests happy path
}

// ✅ Test both valid AND invalid
test("cannot enter from idle") {
  expect(manager.enter(100)).toBe(false)
}
```
