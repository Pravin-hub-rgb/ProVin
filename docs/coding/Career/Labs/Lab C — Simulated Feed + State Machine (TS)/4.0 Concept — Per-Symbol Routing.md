# 4.0 Concept — Per-Symbol Routing

> **Yaar, feed se n ticks aate hain — symbol A, symbol B, symbol C.** 
> Koi toh decide karega ki tick A ke liye A machine ko milega ya B machine ko.

## What Routing Is

Routing is the glue: **feed emits, machines receive only what's theirs.**

```
SimulatedFeed (emits ALL symbols)
    ↓  tick: { symbol: "AAPL", close: 152.3 }
Map<string, PositionMachine> (router)
    ↓  managers.get("AAPL").onTick(152.3)
PositionMachine for AAPL
    ↓  status check, transition logic
```

## Why A Map (O(1) Lookup)

```typescript
// ❌ Slow: linear scan O(n)
const machines = [
  new PositionMachine("AAPL"),
  new PositionMachine("MSFT"),
]
for (const m of machines) {
  if (m.symbol === tick.symbol) m.onTick(tick.close)
}

// ✅ Fast: direct lookup O(1)
const managers = new Map([
  ["AAPL", new PositionMachine("AAPL")],
  ["MSFT", new PositionMachine("MSFT")],
])
managers.get(tick.symbol)?.onTick(tick.close)
```

## What It Is

1. **Map** — `Map<string, PositionMachine>` where key is symbol name
2. **Lookup** — `managers.get("AAPL")` returns the machine for that symbol
3. **Route** — `feed.on("tick", tick => managers.get(tick.symbol)?.onTick(tick.close))`

## What It Is NOT

- **NOT per-symbol intervals.** Feed uses ONE interval for ALL symbols
- **NOT direct method calls.** Machines don't call `feed.getTicks("AAPL")` — feed pushes to them

## Real-World Bridge

`TradeStack/frontend/src/lib/live-trader/streamer.ts`:
- `private symbolHandlers = new Map<string, SymbolHandler>()` (line 55)
- `const handler = this.symbolHandlers.get(symbol)` (line 210)
- `handler?.handleTick(ohlc)` (line 212)

Your routing = their routing. Same pattern, same O(1) lookup.

## Common Mistake

```typescript
// ❌ Wrong: routing logic inside feed
class Feed {
  tickAll() {
    for (const symbol of this.symbols) {
      // DON'T process routing inside feed
      this.machineA.onTick(priceA)
      this.machineB.onTick(priceB)
    }
  }
}

// ✅ Correct: feed emits, consumers decide
feed.on("tick", (tick) => {
  managers.get(tick.symbol)?.onTick(tick.close)
})
```

The feed doesn't know HOW routing works — it just emits. The **consumer side** owns the routing logic.
