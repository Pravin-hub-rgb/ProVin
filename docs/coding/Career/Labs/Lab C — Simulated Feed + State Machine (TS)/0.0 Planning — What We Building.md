## 4 Sawal (The 4 Questions — always answer these first)

### 1. Kya banana hai?
- A TypeScript simulation: feed emits fake OHLC ticks for 3 stocks, each symbol has a position state machine, you see state changes print
- **Learning goal:** When you later read `streamer.ts`, you recognize the pattern — not "what is this?" but "oh, that's just the simulator I built, but with real WebSocket"
- **Not a:** Real trading bot. No real money, no Upstox, no risk management

### 2. Kaunse symbols?
- `AAPL`, `MSFT`, `GOOGL` — 3 symbols keeps it manageable
- Each gets its own `PositionManager` (state machine)
- Real TradeStack handles 100+ symbols on the same pattern

### 3. Data ka shape kya?
```typescript
interface OHLC {
  symbol: string    // which stock
  open: number      // opening price
  high: number      // high this tick
  low: number       // low this tick
  close: number     // close price
  timestamp: number // when
}
```
Each field has a reason — no random data.

### 4. Data flow kaise hoga?
```
Feed (setInterval)
  → emits "tick" event for each symbol
    → each symbol's PositionManager.onTick() receives it
  → emits "signal" event (once per N ticks)
    → PositionManager.onSignal() processes state transition
```

**Key insight:** One feed, N subscribers, per-symbol routing. **Not** N interval timers (that breaks the event loop lesson).
