# 1.2 Minimal Code — Basic Interval

> **Ab ek chhota sa working example banao. Seedha feed module mat banao abhi.**

## Build: Basic Tick Logger

```typescript
// 1.2-minimal.ts
interface OHLC {
  symbol: string
  price: number
  timestamp: number
}

function makeTick(symbol: string): OHLC {
  return {
    symbol,
    price: Math.random() * 100,
    timestamp: Date.now(),
  }
}

const id = setInterval(() => {
  const tick = makeTick("AAPL")
  console.log(`[${tick.symbol}] $${tick.price.toFixed(2)}`)
}, 500)

// Stop after 5 seconds
setTimeout(() => {
  clearInterval(id)
  console.log("stopped")
}, 5000)
```

## Line-by-Line

| Line | Kya karta hai | Kyu |
|------|---------------|-----|
| `interface OHLC` | Type for price data | Compile-time safety — agar `.price` missing ho toh error milega |
| `makeTick` | Generates one tick object | Isolated function = testable |
| `setInterval` | Runs callback every 500ms | The "feed" — repeats |
| `console.log` | Prints tick | You see output |
| `setTimeout` | Cleanup timer after 5s | Without this, feed runs forever |

**Run:** `npx tsx 1.2-minimal.ts`

## Observe Karein

Terminal mein ticks aa raha hai every 500ms tak 5 seconds. Phir "stopped" aata hai. **Process exits cleanly** — kyunki maine `clearInterval` call kiya.

## Common Mistake

```typescript
// ❌ Missing cleanup — process hangs
setInterval(() => {
  console.log("tick")
}, 500)
// Ctrl+C se bhi band karna padta hai — unclean exit
```

## What It Is NOT

- **NOT a real feed.** Random prices, single symbol, no reconnect logic
- **NOT scalable.** Real feed handles 100+ symbols, real network, real disconnect handling

## Bridge

Real `streamer.ts` replaces `setInterval` with a WebSocket that pushes real ticks. But the **loop + tick shape** is identical — you just swap the source.
