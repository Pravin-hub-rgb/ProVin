# 2.1 Syntax — Transition Tables

> **Chal karte hain — ek table banate hain jismein likha ho ke kaunse states ek-dusre mein ja sakte hain.**

## Transition Table as Object

```typescript
// transition-table.ts
type Status = "idle" | "watching" | "in_position" | "exited"

const ALLOWED_TRANSITIONS: Record<Status, Status[]> = {
  idle: ["watching"],                    // idle → watching only
  watching: ["in_position", "idle"],     // watching → enter or reset
  in_position: ["exited", "idle"],       // position → exit or hard reset
  exited: ["idle"],                       // exited → idle to restart
}
```

## Line-by-Line

### `type Status = "idle" | ...`
- **Kya:** TypeScript union type — status EXACTLY one of these strings
- **Kyun:** Compile error agar `"watching"` typo karo (like `"watchingg"`) — TS catches it

### `ALLOWED_TRANSITIONS: Record<Status, Status[]>`
- **Kya:** Object where every `Status` key maps to an array of allowed next statuses
- **Kyun:** O(1) lookup — check any transition in constant time

### `"idle": ["watching"]`
- **Kya:** From idle, only go to watching
- **Kyun:** You can't jump from "not doing anything" directly to "in a trade" — must watch first

## Validation Function

```typescript
function canTransition(from: Status, to: Status): boolean {
  const allowed = ALLOWED_TRANSITIONS[from]
  return allowed.includes(to)
}

// Examples
canTransition("idle", "watching")     // true
canTransition("idle", "in_position")   // false — must watch first
canTransition("watching", "idle")     // true
```

## Common Mistakes

```typescript
// ❌ String typo passes silently
ALLOWED_TRANSITIONS["idl"]  // undefined — no error at runtime!

// ✅ With Record type, undefined key causes TS error
```

```typescript
// ❌ Array mutation risk
ALLOWED_TRANSITIONS.idle.push("exited")  // mutates the table!

// ✅ Make it readonly
const ALLOWED_TRANSITIONS: Readonly<Record<Status, readonly Status[]>> = ...
```

## What It Is NOT

- **NOT a class.** Just a data table — no methods, no state
- **NOT dynamic.** Table is static — changes require code edit (intentional design choice)
