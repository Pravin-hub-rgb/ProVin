# 4.1 Syntax — Map-Based Subscription

> **Remember the Map syntax.** `new Map()`, `.set()`, `.get()`, `.get()?.method()` — these are used in streamer.ts too.

## The Map Syntax

```typescript
// Create a Map
const managers = new Map<string, PositionMachine>()

// Add entries: .set(key, value)
managers.set("AAPL", new PositionMachine("AAPL"))
managers.set("MSFT", new PositionMachine("MSFT"))
managers.set("GOOGL", new PositionMachine("GOOGL"))

// Get entries: .get(key) — returns value or undefined
const aapl = managers.get("AAPL")  // PositionMachine | undefined

// Safe access: optional chaining
managers.get("AAPL")?.onTick(152.3)  // only calls if exists

// Check existence
if (managers.has("AAPL")) {
  managers.get("AAPL")!.onTick(152.3)  // ! = definitely exists
}
```

## Map vs Object

| Map | Object |
|-----|--------|
| `new Map()` | `{}` |
| `.set(key, val)` | `obj[key] = val` |
| `.get(key)` | `obj[key]` |
| `.has(key)` | `key in obj` |
| **Any key type** | String/symbol only |
| **Ordered iteration** | No order guarantee (pre-ES2015) |

**Why Map wins here:** Symbol names are strings, but Map is semantically correct for key-value lookups with iteration. Plus `.get()` returns `undefined` cleanly.

## In PositionMachine Context

```typescript
// Import the PositionMachine from 2.3
class PositionMachine {
  constructor(public symbol: string) {}
  // ... (same as 2.3)
}

// The subscription Map
const managers = new Map<string, PositionMachine>([
  ["AAPL", new PositionMachine("AAPL")],
  ["MSFT", new PositionMachine("MSFT")],
  ["GOOGL", new PositionMachine("GOOGL")],
])

// Subscribe each machine to its own state
for (const mgr of managers.values()) {
  mgr.watch()  // idle → watching
}

// Check all states
for (const [symbol, mgr] of managers) {
  console.log(`${symbol}: ${mgr.getStatus()}`)  // "watching"
}
```

## What It Is NOT

- **NOT a regular array.** Maps don't have `.length`, use `.size`
- **NOT guaranteed order in all contexts.** Although ES2015+ Map preserves insertion order, don't rely on it for logic

## Run It

```typescript
// 4.1-syntax-map.ts
const managers = new Map<string, PositionMachine>([
  ["AAPL", new PositionMachine("AAPL")],
  ["MSFT", new PositionMachine("MSFT")],
])

console.log("Map size:", managers.size)       // 2
console.log("Has AAPL?", managers.has("AAPL"))  // true
console.log("MSFT state:", managers.get("MSFT")?.getStatus())  // watching

managers.get("TSLA")?.getStatus()  // undefined — no crash
```
