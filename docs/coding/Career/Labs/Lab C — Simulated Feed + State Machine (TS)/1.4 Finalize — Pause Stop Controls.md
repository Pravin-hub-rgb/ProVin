## Pause/Resume Simulation

```typescript
// 1.4-feed-full.ts
// (continued from 1.3 — add pause/resume methods)

pause(): void {
  if (this.ticker) {
    clearInterval(this.ticker)
    this.ticker = null
    console.log("[feed] paused (simulating disconnect)")
  }
}

resume(): void {
  if (!this.ticker) {
    this.start()  // restart the interval
    console.log("[feed] resumed (simulating reconnect)")
  }
}

// Test pause/resume cycle
const feed = new SimulatedFeed(["AAPL", "MSFT", "GOOGL"])
feed.start()

setTimeout(() => {
  console.log("--- pausing feed ---")
  feed.pause()
}, 3000)

setTimeout(() => {
  console.log("--- resuming feed ---")
  feed.resume()
}, 5000)

// Final cleanup
setTimeout(() => {
  feed.stop()
  process.exit(0)
}, 8000)
```

## Line-by-Line: pause/resume

| Line | Kya karta | Kyu zaroori |
|------|-----------|-------------|
| `if (this.ticker)` | Double-check timer exists | Paise when not started = no-op |
| `clearInterval(this.ticker)` | Stop the loop | Same pattern as 1.2 |
| `this.ticker = null` | Clear reference | So `resume()` knows we're paused |
| `if (!this.ticker)` in resume | Only resume if paused | No double-start |
| `this.start()` in resume | Restarts interval | Re-enters the feed loop |

## Observe Karein

```
AAPL: $100.43
MSFT: $99.87
... (3 seconds) ...
--- pausing feed ---
[feed] paused (simulating disconnect)
(no ticks for 2 seconds)
--- resuming feed ---
[feed] resumed (simulating reconnect)
AAPL: $101.12  ← price continues from where it left off
```

**Key insight:** Prices **continue** from where they paused. `this.prices` Map persists across pause/resume — no data loss.

## Real WebSocket vs Simulation

| Real `streamer.ts` | Lab C Simulation |
|---|---|
| `WebSocket` connection → drops → `onclose` fires | `clearInterval` → feed silent |
| `reconnect-with-backoff` → retries with delay | `setInterval` restart → immediate |
| Protobuf messages on reconnect | Same `prices` Map keeps state |

The **state preservation** pattern is identical — your `Map<string, number>` = their in-memory symbol state.

## Common Mistake

```typescript
// ❌ Re-creating feed on resume
resume() {
  this.feed = new SimulatedFeed(this.symbols)  // prices reset!
  this.feed.start()
}
```

**Fix:** Same instance, restart interval only. Prices persist.

## What It Is NOT

- **NOT real disconnect logic.** Real WebSocket has network errors, authentication timeouts, server-side drops.
- **NOT production reconnect.** Real code uses exponential backoff (wait longer between each retry).

## Bridge

When you read `streamer.ts` in M6 and see the `reconnect()` method, you'll think: "Oh, that's just my pause/resume but smarter — it waits longer each time." The concept is the same, the complexity is in the retry strategy.
