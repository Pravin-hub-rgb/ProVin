# 1.1 Syntax — Timer Setup in TypeScript

> **Let's build a working interval.**

## Syntax

```typescript
const intervalId: NodeJS.Timeout = setInterval(
  callback: () => void,
  delayMs: number
): NodeJS.Timeout
```

**3 things:**
1. `callback` — what runs?
2. `delayMs` — after how long? (500 = half a second)
3. `intervalId` — store it, for cleanup

## Minimal Example

```typescript
// 1.0-minimal.ts
let count = 0

const id = setInterval(() => {
  count++
  console.log(`tick ${count}`)

  if (count >= 3) {
    clearInterval(id)  // stop after 3 ticks
    console.log("done")
  }
}, 500)
```

**Run:** `npx tsx 1.0-minimal.ts`
**Output:**
```
tick 1
tick 2
tick 3
done
```

## Two TypeScript rules here

1. **Type of `intervalId`** — In the Node ecosystem it's `NodeJS.Timeout`. In the browser it's `number`. Different types for different environments — that's why TypeScript can get confused. Annotate explicitly:

```typescript
const id: ReturnType<typeof setInterval> = setInterval(() => {}, 1000)
```

2. **Callback signature** — returns `() => void`, no value. Returning something won't error (void allows ignoring), but void is cleaner.

## Common Mistake

```typescript
// ❌ This doesn't work in TypeScript
const id = setInterval(console.log("hi"), 1000)
// console.log executes immediately — returns undefined
// setInterval(undefined, 1000) — does nothing
```

**Fix — wrap in an arrow function:**
```typescript
// ✅
const id = setInterval(() => console.log("hi"), 1000)
```
