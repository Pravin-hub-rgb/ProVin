# 1.1 Syntax — Timer Setup in TypeScript

> **Chal karte hain — ek working interval banate hain.**

## Syntax

```typescript
const intervalId: NodeJS.Timeout = setInterval(
  callback: () => void,
  delayMs: number
): NodeJS.Timeout
```

**3 cheezein:**
1. `callback` — kya chalega?
2. `delayMs` — kitne der mein? (500 = half second)
3. `intervalId` — store karo, cleanup ke liye

## Minimal Example

```typescript
// 1.0-minimal.ts
let count = 0

const id = setInterval(() => {
  count++
  console.log(`tick ${count}`)

  if (count >= 3) {
    clearInterval(id)  // stop after 3 ticks
    console.log("done")
  }
}, 500)
```

**Run:** `npx tsx 1.0-minimal.ts`
**Output:**
```
tick 1
tick 2
tick 3
done
```

## TypeScript ke 2 rules yahan

1. **Type of `intervalId`** — Node ecosystem mein `NodeJS.Timeout` type hoti hai. Browser mein `number` hoti hai. Dono environments ke liye alag types — isliye TypeScript ko confuse ho sakta hai. Explicit annotate karo:

```typescript
const id: ReturnType<typeof setInterval> = setInterval(() => {}, 1000)
```

2. **Callback signature** — `() => void` return karta hai, koi value nahi. Agar return karo diya toh TS error nahi dega (void allows ignoring), but cleaner hai void.

## Common Mistake

```typescript
// ❌ This doesn't work in TypeScript
const id = setInterval(console.log("hi"), 1000)
// console.log executes immediately — returns undefined
// setInterval(undefined, 1000) — does nothing
```

**Fix — wrap in arrow function:**
```typescript
// ✅
const id = setInterval(() => console.log("hi"), 1000)
```
