# 4.0 Build feed.ts

> **Open with:** Your timer from `2.0` printed OHLC ticks. Now you'll refactor it into a **reusable feed module** that emits ticks for any number of symbols — like TradeStack's real `streamer.ts`.
>
> **Connect to previous:** In `2.0`, the feed was inline in one script. `3.0` showed state machines per-symbol. Now you separate concerns: the feed produces data, machines consume it.

## What You Build

A `feed.ts` module that:
1. Emits OHLC ticks per symbol on a timer
2. Emits occasional "signal" events (once per N ticks per symbol)
3. Supports pause/resume (disconnect/reconnect)
4. Has callback subscribers — any module can listen

```typescript
import { EventEmitter } from "events"

export interface OHLC {
  symbol: string
  open: number
  high: number
  low: number
  close: number
  timestamp: number
}

export type FeedEvent =
  | { type: "tick"; data: OHLC }
  | { type: "signal"; symbol: string; direction: "long" | "short" }

export class SimulatedFeed extends EventEmitter {
  private prices: Map<string, number> = new Map()
  private ticker: NodeJS.Timeout | null = null
  private tickCount = 0

  constructor(private symbols: string[], private intervalMs: number = 500) {
    super()
  }

  private makeTick(symbol: string): OHLC {
    const currentPrice = this.prices.get(symbol) ?? 100
    const change = (Math.random() - 0.5) * 2
    const newPrice = Math.max(1, currentPrice + change)
    this.prices.set(symbol, newPrice)

    return {
      symbol,
      open: currentPrice,
      high: Math.max(currentPrice, newPrice),
      low: Math.min(currentPrice, newPrice),
      close: newPrice,
      timestamp: Date.now(),
    }
  }

  start(): void {
    if (this.ticker) return

    this.ticker = setInterval(() => {
      this.tickCount++

      for (const symbol of this.symbols) {
        // Every 5 ticks, emit a signal (once per N ticks per symbol)
        if (this.tickCount % 5 === 0) {
          const direction: "long" | "short" = Math.random() > 0.5 ? "long" : "short"
          this.emit("signal", { type: "signal", symbol, direction })
        }

        // Always emit a tick
        this.emit("tick", { type: "tick", data: this.makeTick(symbol) })
      }
    }, this.intervalMs)

    console.log(`[feed] started: ${this.symbols.length} symbols, ${this.intervalMs}ms interval`)
  }

  pause(): void {
    if (this.ticker) {
      clearInterval(this.ticker)
      this.ticker = null
      console.log("[feed] paused (simulating disconnect)")
    }
  }

  resume(): void {
    if (!this.ticker) {
      this.start()
    }
  }
}
```

## How to Use It

```typescript
// This code goes in 5.0 or 6.0 — for now, just test feed.ts alone
const feed = new SimulatedFeed(["AAPL", "MSFT", "GOOGL"])

feed.on("tick", (event) => {
  console.log(`[${event.data.symbol}] $${event.data.close.toFixed(2)}`)
})

feed.on("signal", (event) => {
  console.log(`[SIGNAL] ${event.symbol} → ${event.direction}`)
})

feed.start()

// Pause after 3 seconds, resume after 2
setTimeout(() => feed.pause(), 3000)
setTimeout(() => feed.resume(), 5000)
```

## What This Solves

| Old problem (inline timer) | New solution (feed module) |
|---|---|
| Hard-coded symbols | Symbols passed in constructor |
| No reuse | Can create multiple feeds |
| No subscribe pattern | EventEmitter lets modules listen independently |
| No pause/resume | pause() / resume() methods |

## What It Is NOT

- **NOT a real WebSocket client.** `EventEmitter` is local — in-memory. Real `streamer.ts` uses `WebSocket` class, same emitter pattern.
- **NOT production-ready code.** No retry logic, no protobuf, no real market data. You're extracting the **shape**.

## Bridge — TradeStack's Real Feed

`TradeStack/frontend/src/lib/live-trader/streamer.ts`:
- ✅ Emits ticks per symbol on a timer/event
- ✅ EventEmitter-style subscriber pattern (`on("tick", ...)`)
- ✅ Pause/resume = reconnect-with-backoff
- ❌ Protobuf messages instead of JSON
- ❌ Real Upstox WebSocket instead of `setInterval`

Your `SimulatedFeed` is **1:1 the same shape** — just the transport layer is different.
