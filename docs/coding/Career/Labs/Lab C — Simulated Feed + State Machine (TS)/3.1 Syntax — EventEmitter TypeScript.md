# 3.1 Syntax — EventEmitter in TypeScript

> **Let's build a type-safe EventEmitter with TypeScript.**

## Extending EventEmitter in TypeScript

```typescript
// 3.1-typed-emitter.ts
import { EventEmitter } from "events"

interface FeedEventMap {
  tick: (data: OHLC) => void
  signal: (data: { symbol: string; direction: "long" | "short" }) => void
  pause: () => void
  resume: () => void
}

interface OHLC {
  symbol: string
  open: number
  high: number
  low: number
  close: number
  timestamp: number
}

// Typed emitter — events are type-checked
class FeedEmitter extends EventEmitter {
  // Override emit to use type map
  emit<K extends keyof FeedEventMap>(
    event: K,
    ...args: Parameters<FeedEventMap[K]>
  ): boolean {
    return super.emit(event, ...args)
  }

  // Override on — type-checked listener
  on<K extends keyof FeedEventMap>(
    event: K,
    listener: FeedEventMap[K]
  ): this {
    return super.on(event, listener as (...args: any[]) => void)
  }
}
```

## Line-by-Line

### `interface FeedEventMap`
- **What:** Map of event name → listener function signature
- **Why:** `tick` takes `OHLC`, `signal` takes `{ symbol, direction }` — TS enforces this

### `emit<K extends keyof FeedEventMap>(event: K, ...args)`
- **What:** Generic typed emit
- **Why:** `emit("tick", badData)` — TS will reject if `badData` doesn't match `OHLC`

### `on<K extends keyof FeedEventMap>(event: K, listener: FeedEventMap[K])`
- **What:** Generic typed listener
- **Why:** `on("tick", (symbol) => ...)` — TS knows `tick` listener receives `OHLC`, not `string`

## Using the Typed Emitter

```typescript
const feed = new FeedEmitter()

// ✅ Correct — listener receives OHLC
feed.on("tick", (ohlc: OHLC) => {
  console.log(`${ohlc.symbol}: $${ohlc.close.toFixed(2)}`)
})

// ❌ TS error — tick listener doesn't take a string
feed.on("tick", (str: string) => { })  // Compile error!

// ✅ Emit with correct type
feed.emit("tick", {
  symbol: "AAPL",
  open: 149,
  high: 151,
  low: 148,
  close: 150.5,
  timestamp: Date.now(),
})
```

## Common Mistakes

```typescript
// ❌ Untyped EventEmitter — no type safety
const feed = new EventEmitter()
feed.emit("tick", "this-string-will-compile-but-is-wrong")

// ✅ Typed — wrong emit type fails at compile
const feed = new FeedEmitter()
feed.emit("tick", "wrong")  // TS error: string not assignable to OHLC
```

```typescript
// ❌ Forgetting import
class Feed { ... }  // no EventEmitter import

// ✅ Import from Node built-in
import { EventEmitter } from "events"
```

## What It Is NOT

- **NOT React EventEmitter.** This is Node's `events` module — same pattern, different package
- **NOT a replacement for React state.** This is for cross-module communication — not UI updates

## Bridge
