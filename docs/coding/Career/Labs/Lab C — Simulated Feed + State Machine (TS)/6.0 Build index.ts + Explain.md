> **Open with:** You built the feed (4.0), the machines (5.0), and the state logic (3.0). Now you wire them together: each symbol gets one machine, the feed routes ticks/signals to the right machine.

> **Connect to previous:** `4.0` emits ticks for all symbols. `5.0` has machines per symbol. Now they connect.

## What You Build

```typescript
import { SimulatedFeed, OHLC } from "./4.0"
import { PositionManager } from "./5.0"

const SYMBOLS = ["AAPL", "MSFT", "GOOGL"]

function main() {
  // 1. Create the feed
  const feed = new SimulatedFeed(SYMBOLS, 500)

  // 2. Create one position manager per symbol
  const managers: Record<string, PositionManager> = {}
  for (const symbol of SYMBOLS) {
    managers[symbol] = new PositionManager(symbol)
  }

  // 3. Wire feed → managers
  feed.on("tick", (event) => {
    const mgr = managers[event.data.symbol]
    if (mgr) mgr.onTick(event)
  })

  feed.on("signal", (event) => {
    const mgr = managers[event.symbol]
    if (mgr) mgr.onSignal(event)
  })

  // 4. Start everyone watching
  for (const mgr of Object.values(managers)) {
    mgr.watch()  // idle → watching
  }

  // 5. Start the feed
  feed.start()

  // 6. Demo: pause/resume cycle (disconnect/reconnect)
  setTimeout(() => {
    console.log("\n--- PAUSING FEED (simulating disconnect) ---\n")
    feed.pause()
  }, 3000)

  setTimeout(() => {
    console.log("\n--- RESUMING FEED (simulating reconnect) ---\n")
    feed.resume()
  }, 5000)

  // 7. Demo: invalid transition (try to enter from idle — should fail)
  setTimeout(() => {
    console.log("\n--- DEMO: Invalid transition ---")
    managers["AAPL"].enter  // undefined, not a method — correct, you must use watch() first
    // The state machine prevents entering a position without watching first
  }, 7000)

  // 8. Cleanup after 10 seconds
  setTimeout(() => {
    console.log("\nDone. State machines survived disconnect/resume.")
    process.exit(0)
  }, 10000)
}

main()
```

## The Two Sentences You Must Say Aloud

1. **"One process, N subscriptions, callbacks per tick — the event loop is doing the concurrency."**
   - 1 process (Node single thread)
   - N subscriptions (3 PositionManagers + feed = 4 listeners)
   - Callbacks per tick (tick → onTick, signal → onSignal)
   - Event loop handles all of them without threads

2. **"The state machine guarantees a stock is in exactly one phase, so double entries can't happen."**
   - Exactly one status string at any time (`status` field)
   - Double entry blocked: `enter` only valid from `watching`, and after entering, status is `in_position` (not `watching`), so a second `enter` would be rejected
