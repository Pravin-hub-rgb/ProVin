> **Open with:** You already ran `npx tsx` in Agentic AI Phase 3.1. This lab uses the same tool — but writes TypeScript files, not just one script.
>
> **Connect to previous:** In Phase 3.1, you set up `package.json` with `"type": "module"` and installed packages. Lab C reuses that setup pattern — only the content (what the code does) changes.

TypeScript feels scary if you've only written JavaScript. The reality: you're already writing TypeScript in your Next.js and Agentic AI projects (VS Code shows `const [state, dispatch]` with autocomplete — that's TS inference working). This section strips away framework scaffolding and runs pure `.ts` files so you can see the language directly.

## What Changes from JavaScript

| JavaScript (what you know) | TypeScript (what you write) |
|---|---|
| `const symbol = "AAPL"` | `const symbol: string = "AAPL"` |
| function returns anything → hope | function signature says the shape |
| Object passed around → hope it has `.price` | Interface says `{ price: number; symbol: string }` |
| Error: "Cannot read property 'price' of undefined" at runtime | Error: "Property 'price' does not exist on type '{ symbol: string }'" at compile time |

## Key TypeScript Concepts You Need

### 1. Type Annotations
```typescript
const symbol: string = "AAPL"           // can't assign a number later
const price: number = 150.50
const isOpen: boolean = true
```

### 2. Interfaces for Data Shapes
```typescript
interface OHLC {
  symbol: string       // stock ticker
  open: number         // opening price
  high: number         // highest price this tick
  low: number          // lowest price this tick
  close: number        // closing price
  timestamp: number    // unix timestamp
}
```

### 3. Type Inference
TypeScript guesses types so you don't annotate everything:
```typescript
const price = 150.50     // inferred as number
const items = [1, 2, 3]  // inferred as number[]

// But when you're unsure, annotate:
const items: number[] = []
```

### 4. Functions with Types
```typescript
function formatPrice(price: number): string {
  return `$${price.toFixed(2)}`
}
```

### 5. Console Output
```typescript
const tick: OHLC = {
  symbol: "AAPL",
  open: 150,
  high: 151,
  low: 149,
  close: 150.5,
  timestamp: Date.now()
}

console.log(`${tick.symbol}: ${formatPrice(tick.close)}`)
```

Run it:
```bash
npx tsx 1.0.ts
# Output: AAPL: $150.50
```

## What It Is NOT

- **NOT a TypeScript course.** You won't learn generics, decorators, or strict mode advanced tricks here. You need just enough typing to catch bugs before runtime — the rest is "figure it out as you build."
- **NOT a migration.** You're writing `.ts` from the start — no converting existing `.js` files.
