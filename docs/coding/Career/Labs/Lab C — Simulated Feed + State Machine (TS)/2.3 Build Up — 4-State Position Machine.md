# 2.3 Build Up — 4-State Position Machine

> **Now build TradeStack's real 4 states** — add `in_position` and `exited`.

## Full State Machine with Transition Table

```typescript
// 2.3-position-machine.ts
type Status = "idle" | "watching" | "in_position" | "exited"

const ALLOWED: Record<Status, Status[]> = {
  idle: ["watching"],
  watching: ["in_position", "idle"],
  in_position: ["exited", "idle"],
  exited: ["idle"],
}

interface PositionState {
  symbol: string
  status: Status
  entryPrice: number | null
}

class PositionMachine {
  private state: PositionState

  constructor(symbol: string) {
    this.state = {
      symbol,
      status: "idle",
      entryPrice: null,
    }
  }

  getStatus(): Status {
    return this.state.status
  }

  private tryAction(action: "watch" | "enter" | "exit" | "reset", price?: number): boolean {
    const actionToStatus: Record<string, Status> = {
      watch: "watching",
      enter: "in_position",
      exit: "exited",
      reset: "idle",
    }

    const target = actionToStatus[action]
    if (!target) {
      console.log(`  ❌ INVALID ACTION: ${this.state.symbol} cannot "${action}"`)
      return false
    }

    const current = this.state.status
    if (ALLOWED[current].includes(target)) {
      // Log the transition
      console.log(`  ${this.state.symbol}: ${current} → ${target}`)

      this.state.status = target
      if (target === "in_position" && price !== undefined) {
        this.state.entryPrice = price
      }
      if (target === "idle") {
        this.state.entryPrice = null
      }
      return true
    }

    console.log(`  ❌ INVALID TRANSITION: ${this.state.symbol} cannot go ${current} → ${target}`)
    return false
  }

  // Public methods for each transition
  watch(): boolean {
    return this.tryAction("watch")
  }

  enter(price: number): boolean {
    return this.tryAction("enter", price)
  }

  exit(): boolean {
    return this.tryAction("exit")
  }

  reset(): boolean {
    return this.tryAction("reset")
  }

  // Handle incoming tick
  onTick(price: number): void {
    // In real TradeStack: trailing stop, P&L tracking, alerts
    // Here: just log
    console.log(`  [tick] ${this.state.symbol}: $${price.toFixed(2)} (state: ${this.state.status})`)
  }

  // Handle incoming signal
  onSignal(direction: "long" | "short"): void {
    if (this.state.status === "watching") {
      this.tryAction("enter", direction === "long" ? this.state.entryPrice ?? 0 : undefined)
    } else if (this.state.status === "in_position") {
      this.tryAction("exit")
    }
  }
}

// Test it
const manager = new PositionMachine("AAPL")

manager.watch()     // ✅ idle → watching
manager.watch()     // ❌ watching → watching (NOT in allowed list)
manager.enter(150)  // ✅ watching → in_position
manager.enter(155)  // ❌ in_position → in_position (not allowed)
manager.exit()      // ✅ in_position → exited
manager.reset()     // ✅ exited → idle

console.log("Final state:", manager.getStatus())
```

## Line-by-Line Key Points

### `state: PositionState`
- **What:** Tracks symbol, status, AND entry price
- **Why:** Real position manager tracks P&L — need entry point

### `tryAction`
- **What:** Central validation gate for ALL transitions
- **Why:** One place where logic lives = easy to audit and test
- **`return boolean`:** Caller knows if action succeeded

### `ALLOWED[current].includes(target)`
- **What:** O(1) lookup in pre-computed table
- **Why:** Fast rejection of illegal moves

## Observe

```
  AAPL: idle → watching
  ❌ INVALID TRANSITION: AAPL cannot go watching → watching
  AAPL: watching → in_position
  ❌ INVALID TRANSITION: AAPL cannot go in_position → in_position
  AAPL: in_position → exited
  AAPL: exited → idle
Final state: idle
```

**Key insight:** The machine **rejects double-entry**. `enter()` from `in_position` logs INVALID — the position is already entered. This is what prevents "double entries" in interviews.

## Common Mistakes

```typescript
// ❌ Direct state mutation — bypasses validation
manager.state.status = "in_position"

// ✅ All transitions go through tryAction
manager.enter(150)
```

```typescript
// ❌ Action allowed even without precondition
enter()  // should require "watching" state

// ✅ Checked against ALLOWED table
```

## What It Is NOT

- **NOT 11 states.** TradeStack's real machines use 11 — you're building the skeleton
- **NOT connected to feed.** `onTick`/`onSignal` receive data manually — wiring comes in 4.0

## Bridge

- Uses `ALLOWED_TRANSITIONS` pattern (exact same table concept)
