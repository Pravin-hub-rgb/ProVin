# 2.2 Minimal Code — Simple State Machine

> **Try it with just 2 states first** — add complexity later.

## Build: 2-State Watcher

```typescript
// 2.2-minimal-machine.ts
type Status = "idle" | "watching"

function tryTransition(current: Status, action: "watch" | "stop"): Status {
  if (current === "idle" && action === "watch") {
    return "watching"
  }
  if (current === "watching" && action === "stop") {
    return "idle"
  }
  console.log(`INVALID: cannot ${action} from ${current}`)
  return current
}

// Test
let state: Status = "idle"
console.log("Start:", state)

state = tryTransition(state, "watch")   // idle → watching ✅
console.log("After watch:", state)

state = tryTransition(state, "enter")   // watching → ? (invalid action)
console.log("After enter:", state)      // still watching

state = tryTransition(state, "stop")   // watching → idle ✅
console.log("After stop:", state)

state = tryTransition(state, "stop")   // idle → idle (invalid)
console.log("After stop:", state)      // still idle
```

**Run:** `npx tsx 2.2-minimal-machine.ts`

## Line-by-Line

| Line | What it does | Why |
|------|--------------|-----|
| `type Status = "idle" \| "watching"` | Union type | TS prevents typos |
| `action: "watch" \| "stop"` | Discriminated action | TS requires exact match |
| `return "watching"` | State change | Pure function — no side effects |
| `console.log(INVALID)` | Reject bad transition | You SEE what's blocked |
| `return current` | No-op on invalid | Function always returns a valid state |

## Observe

```
Start: idle
After watch: watching
INVALID: cannot enter from watching
After enter: watching
After stop: idle
INVALID: cannot stop from idle
After stop: idle
```

**Key insight:** Invalid transitions are **logged but don't crash**. A real trading system can't crash on bad data.

## Common Mistake

```typescript
// ❌ Throwing errors on invalid transitions
function tryTransition(current, action) {
  if (current === "idle" && action === "watch") return "watching"
  throw new Error(`Invalid: ${current} + ${action}`)  // process crashes
}

// ✅ Graceful rejection — log + return same state
function tryTransition(current, action) {
  // ... valid transitions ...
  console.log(`INVALID: ${current} → ${action}`)
  return current  // caller decides what to do
}
```
