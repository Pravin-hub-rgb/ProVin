# 1.1 What is Algorithmic Trading

"Algo trading" sounds like — big servers, complex math, Wall Street types. But at its core it starts from a very simple thought: *"if this happens, I will do this."* That's it. That is a trading idea. Algorithmic trading is the name for converting that idea into clear rules and letting the computer execute them. In this file we'll formally understand what algo trading is, how it is structured, and — equally important — what it is NOT.

## Definition — In One Line

> **Algorithmic trading = converting a trading idea into clear rules and letting the computer execute those rules.**

Broken down step by step:

1. You have a **trading idea**
2. You convert that idea into **clear rules**
3. You write the rules as **code**
4. You **deploy the code in the market** — it keeps running automatically, without manual interaction

It doesn't start with coding — it starts with a clear trading idea and a testable hypothesis. Foundation first, then Python, APIs, indicators.

### Understand Through an Example — EMA Crossover

Take a simple strategy:

- **9 EMA / 33 EMA crossover** — upside crossover = LONG entry, downside = SHORT entry
- Target 1:2, Stop Loss defined

This is a set of rules. Following it consistently by hand is hard because fear, greed, and mood get in the way. In algo trading: same rules → code → deploy → the code **monitors the market 24×7**.

## The Structure of Algo Trading

Every algo system has 3 parts:

- **Input:** Price action based, indicator based, volume based, time frame based — *"if this happens then do this"*
- **Logic:** The strategy's rules — decision making
- **Output:** Order execution

Here's one thing to understand — the biggest strength of algo trading: once a logic is coded, the computer can **repeat that same logic 1000 times — without getting emotional.** This repeatability is the biggest strength of algo trading.

## The 3 Levels of Automation

Not every algo is fully automated. There are three levels:

**1. Manual:** You do everything yourself — search, analyze, execute.

**2. Semi-Automated:** The algo generates a signal (Telegram/notification), but YOU take the trade yourself. Example — a client receives an MCX signal via Telegram, checks it manually, then takes the trade.

**3. Fully Automated:** Signal + Entry + Exit + Reports — the algo does everything itself. End-to-end: from signal to Excel report.

In this course we'll reach fully automated — from beginner to advanced.

## The Four Pillars of Algo Trading

Every algo trading system needs these 4 things:

**1. Data:** The stock's OHLCV data — Open, High, Low, Close, Volume — backtesting runs on this. Data comes first — without data there's no backtest at all.

**2. Logic:** The strategy's rules — the ones that make decisions. No matter how good your strategy is, if you can't convert it into code, you can't do anything in the live market.

**3. Execution:** Connecting the Python API to the broker — placing orders.

**4. Monitoring:** Accountability — tracking how the strategy is performing. Monitoring is just as important; otherwise you won't even know whether the strategy is right or wrong.

- Cloud servers/VPS have become cheaper
- And the biggest reason: **60%+ of FNO volumes are already automated** — algos are replacing manual traders

The market has shifted. Learn now and you become a systematic trader — not manual, but rules-based. By the end of this course, with practice, you'll have real projects.

## Nutshell

Algo trading = trading idea → clear rules → code → deploy, without manual interaction. The structure is simple: Input → Logic → Output. There are 3 levels of automation — manual, semi (signals only), fully (end-to-end). Remember the 4 pillars of every system: Data, Logic, Execution, Monitoring. And this is a tool, not a magic machine.

## What It Is NOT

Many people come in with fake expectations — let's clear them now:

- ❌ **"I'll pull 100% returns"** — no one gets 100% consistent returns. No one.
- ❌ **It's not a money-making machine** — it's just a better way to trade.
- ❌ **There's no secret strategy** — it's a systematic approach, not magic.
- ❌ **You don't need to be a math genius** — math helps, but it's not required.

Algo trading removes inconsistency and emotions — it doesn't guarantee profit on every trade. It's a tool — if your strategy is great, the tool works great.
