## Code Walkthrough — Reversal Ka Core!

```python
action = request.form.get("action").lower()     # "BUY" aaya → "buy"
real_action = "sell" if action == "buy" else "buy"   # ← FLIP!!
```

Dekho reversal kitna-SIMPLE hai:

```text
User ne "buy" bheja   → real_action = "SELL"
User ne "sell" bheja  → real_action = "BUY"

SIRF EK-VARIABLE ulta — baaki-sab (symbol, qty) untouched!
```

Aur order-request-dict (jo-AI ne diya):

```python
request_order = {
    "action":  mt5.TRADE_ACTION_DEAL,
    "symbol":  symbol,           # e.g., "BTCUSD"
    "volume":  float(lot),       # lot-size
    "type":    mt5.ORDER_TYPE_BUY if real_action == "buy"
               else mt5.ORDER_TYPE_SELL,
    "price":   current_price     ← live-price chahiye!
}
```

## ⚠️ Jo Step ORIGINAL Material SKIP Kar Gaya — Hum ADD Karte Hain!

Dict banane ke baad usse BHEJNA bhi toh-padega!

Original-notes me yeh-decisive-step ELIDE tha —

hum add-karte-hain:

```python
# LIVE-PRICE lo (dict me "price" kahan-se aayegi?):
tick = mt5.symbol_info_tick(symbol)
request_order["price"] = tick.ask if real_action == "buy" else tick.bid

# ORDER BHEJO:
result = mt5.order_send(request_order)

# RETCODE-CHECK — placement ≠ success (7.1 ka lesson!):
if result.retcode != mt5.TRADE_RETCODE_DONE:
    print(f"ORDER FAILED: retcode={result.retcode}")
else:
    print(f"Order FILLED @ {result.price}")
```

```text
symbol_info_tick()   → live buy/sell-price nikalta hai
order_send()         → order ACTUALLY bhejta hai!
retcode              → result ka STATUS-code
TRADE_RETCODE_DONE   → "successfully-filled!" wala code
```

**Bina-retcode-check ke tumhe pata-hi-nahi-chalega**

order hua ya SILENTLY-fail — 7.1 wali-placement≠fill yaad hai?!

## MT5 Ke Practical Gotchas

MT5 desktop-IPC hai (cloud-API NAHI!) — apne-quirks:

```text
1. ALGO-TRADING ENABLED hona-chahiye!
   MT5-toolbar ka-button + Tools→Options→Expert-Advisors
   Band ho → order_send SILENTLY-FAIL hota-hai!!

2. TERMINAL-LOGIN zaroori
   MT5-app me broker-account (demo) logged-in ho!

3. SYMBOL-NAMING
   Brokers suffix-lagate-hain: BTCUSD.a, BTCUSD.raw...
   EXACT-symbol check-karo (symbol-list se!)

4. FILLING-MODES
   Kuch-brokers FOK/IOC maangte-hain;
   galat-mode = REJECTION (retcode-batayega!)

5. TWO-PROCESS-REALITY:
   MT5-band = sab-DEAD! App chalti-rehni-chahiye!!
```

## Ab Wo TWIST — Kya Yeh Strategy SACH Me Kaam Karegi?

Ruk-ke-soch **4.6-wale-goggles se:**

Friend ki 10-mein-7-trades-loss.

Par kitne BADE losses? Agar:

```text
7-losers  × −₹1,000 = −₹7,000
3-winners × +₹5,000 = +₹15,000

NET PROFIT = ₹8,000!! 😱
```

Matlab woh-trader **PROFITABLE ho-sakta-hai despite-70%-losing-trades!**

(asymmetry — avg-WIN bada, avg-LOSS chhota!)

Usko REVERSE-karna DISASTER ho-jayega!

Reverse-logic TABHI kaam-karti-hai jab:

```text
Losses BADE aur-frequent + wins CHHOTE-rare
(asymmetric OPPOSITE-direction me!)
```

Lesson:

> **Build kar-SAKTE-ho ≠ build-karna-CHAHIE!**
>
> Coder-hone ka fayda yahi — hypothesis ko TEST kar-sakte-ho!
> Backtest the-reverse-version! Assumptions pe orders nahi!

## What It Is NOT

- ❌ **Frontend/backend-split ≠ do-alag-apps.** Ek-hi-system ke do-LAYERS hain — HTML-form backend ke routes-pe POST karta-hai; backend-response deta hai. Flask dono ko JODTA hai (template-serve karke)!
- ❌ **mt5.initialize() = connection-GUARANTEE nahi.** Woh sirf ATTACH-attempt hai — terminal-chal-rahi-ho, account-logged-in ho, algo-trading-enabled ho, tabhi-orders jayenge! Har-step ka-status-check karo (mt5.last_error()).
- ❌ **70%-losing-trades = losing-trader NAHI!** Win-rate bina-PAYOFF-RATIO ke meaningless (4.6!!). Reverse-strategy-demand isi-MISUNDERSTANDING se nikli-thi — client-ne MAGNITUDE dekha-hi-nahi!
