## Strategy Rules

Humari 4.4 wali EMA crossover yaad hai? Yeh uska upgraded version hai — ek extra filter add hota hai: **retest**.

| | Long | Short |
|---|---|---|
| Trigger | Bullish crossover (9 ↑ 33) | Bearish cross under (9 ↓ 33) |
| Condition | Uske baad **retest** mile | Uske baad **retest** mile |
| Extra filter | Retest candle **strong** ho (body ≥ 80%) | Same |
| Stop Loss | **Previous candle ka LOW** | Previous candle ka HIGH |
| Target | **1:3** (risk × 3) | 1:3 |

Flow ek line mein: *crossover hua → price wapas EMA ke paas aaya (retest) → strong candle bani → ENTRY.*

### Strong Candle Rule — Body ≥ 80%

Formula (candle anatomy — Module 2 se familiar):

```text
Body   = |Close − Open|
Range  = High − Low
Body % = (Body ÷ Range) × 100
```

Worked example:

```text
High=100, Low=0, Close=80, Open=20
Range = 100 − 0   = 100
Body  = 80 − 20   = 60
Body% = 60 ÷ 100  = 60%  → ❌ STRONG NAHI (80 chahiye)
```

Logic: strong body = decisive move (buyers/sellers ne poore candle control kiya); lambi wicks = indecision. Retest ke baad strong candle milna = reversal confirmed with conviction.

### Retest Kya Hai?

> **Retest = crossover ke baad price wapas EMA zone ko touch/kiss kare** — wohi entry trigger hai.

Code-level definition (jo AI ko batani padegi):

```text
Long side:  retest candle ka HIGH > dono EMA values
            (matlab candle EMA-zone touch karke upar hi bani)
Short side: mirror logic
```

⚠️ **Opposite-crossover rule:** bullish crossover ke baad retest dhoondhna hai — par beech mein agar **cross under** ho gaya toh signal FAIL, trade skip. Prompt mein clearly bolna padega: *"find retest AFTER crossover and BEFORE opposite crossover."* Yeh detail miss karne pe AI galat signals dega.

## AI Se Pine Script Likhwana

### Tool Selection — Yeh Table Yaad Rakho

| Tool | Pine Knowledge | Verdict |
|---|---|---|
| ❌ ChatGPT | Sirf v4/v5 tak | Pine ke liye AVOID |
| ✅ Grok (free) | v5 + v6 dono | Use karo |
| ✅ DeepSeek | v6 solid | Use karo |

ChatGPT Python ke liye fine hai — sirf Pine mein purana syntax deta hai jo v6 pe error deta hai.

### Prompt Structure — Kya-Kya Batana Hai

Achha prompt = achha output. Checklist:

```text
1. Char cheezein define karo:
   - Long entry, long exit, short entry, short exit

2. Indicators: 9 EMA & 33 EMA crossovers

3. Har condition DETAIL mein:
   - Crossover ke baad, opposite crossover se PEHLE, retest find karo
   - Retest = candle high > dono EMAs (long side)
   - Retest candle strong — body ≥ 80%
   - Entry conditions met → trade
   - SL = previous candle low (long) / high (short)
   - Target = risk ka 3x

4. Suggestion do (optional):
   "You can create a function that checks if a candle
    is strong based on its OHLC values"

5. Flow rules:
   - Visual signals entries/exits pe dikhe
   - ONE ENTRY AT A TIME — pichli trade close hone ke
     baad hi nayi entry (warna overlapping trades!)
```

Woh last point critical hai — AI aksar bhool jaata hai ki ek waqt mein ek hi position honi chahiye (4.5 ka entry-flag concept, ab AI-prompt form mein!).

### Debug Loop — Error Fix Pattern

Grok output copy → Pine Editor paste → Run → **errors aayenge. Normal hai.** Fix loop:

```text
"This is the code: [poora code]
 This is the error: [error message]
 In this line: [line number]
 Now give me correct code without error."
```

Repeat until clean. Real errors jo aaye the:
- **Local/global scope** — Python jaisa hi concept (3.3 yaad kar): function ke andar ke variables bahar nahi dikhte
- **Price scale misalignment** — EMA lines candles se align nahi hui → AI ko bola *"EMA value not aligned with charts"* → `force_overlay` type fix hua

💡 **Cross-questioning tip:** log seedha jawab lete hain, cross-questions nahi karte. Poochho: *"yeh line kya kar rahi hai?"*, *"yeh condition kyun?"* — tabhi samjhoge AI actually kya likh raha hai, warna blind copy hogi aur live market mein debugging impossible.

### Sabse Bada Gap — Costs

Original backtest mein **commission aur slippage configure nahi hue the**. 5-min scalping pe yeh fatal hai:

- Har trade pe brokerage + taxes + slippage lagta hai
- 5-min TF = zyada trades = costs compound hoti hain
- **70% growth minus real costs = dramatically alag picture**

Fix simple hai — Strategy Tester ke properties mein:

```text
Initial capital → apna actual capital
Order size      → apna qty
Commission      → e.g., 0.03% (broker rate)
Slippage ticks  → minimum 1-2
```

Dobara chalao. Jo number ab mile, WAHI honest candidate hai. Ho sakta hai strategy phir bhi achhi rahe — par ab pata hoga ki number real hai. Aur yaad rakho: 1 mahine + 1 stock = starting point, verdict nahi (5.4 ka multi-asset rule baaki hai).

## Nutshell

Vijay Trader ki strategy: 9/33 EMA crossover → retest (candle EMA zone touch kare) → strong candle (body ≥ 80%) → entry; SL = previous candle low/high; target 1:3; opposite crossover se pehle retest warna signal fail. AI workflow: Grok/DeepSeek for Pine (ChatGPT v4/v5-only trap!), structured prompt (4 outcomes + detailed conditions + one-entry-at-a-time), debug loop (code + error + line number), cross-questioning over blind copying. Aur sabse important: impressive backtest numbers pe costs-check — commission/slippage set karke hi verdict.

## What It Is NOT

- ❌ **AI-written = verified nahi.** AI confidently galtiyan karta hai — scope errors, misaligned plots, missing guards. Tera role: run, error-feed, AUR samajhna kya likh raha hai.
- ❌ **Retest ki definition universal nahi hai.** "High > both EMAs" ek loose working-def hai; wick-touch vs body-through farq capture nahi hota. Strict chahiye toh prompt mein precisely define karo.
- ❌ **Backtest profit = live guarantee nahi** — especially bina costs ke. Strategy Tester default result ideal-world ka hai; broker statement real-world ka.

1. Retest kya hai aur "opposite crossover se pehle" rule kyun critical?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Retest = crossover ke baad price wapas EMA zone ko touch kare — confirmation ki move genuine hai. Prompt mein explicitly: "AFTER crossover and BEFORE opposite crossover."

2. Strong candle filter ka math aur logic?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Body% = |close−open| ÷ (high−low) × 100. Example: H=100, L=0, O=20, C=80 → body=60, range=100 → 60% < 80% → REJECT. Logic: high body = decisive conviction move; lambi wicks = indecision/rejection. Retest ke baad strong candle = genuine continuation ka confirmation. Trade-off: filter trades ghatata hai par quality badhata hai — classic precision/recall trade.

</details>

3. AI prompt mein kaunsi cheezein specify karni zaroori hain (top 4)?

<details>
<summary>Sample Jawab</summary>

**Jawab:** (1) Chaar outcomes clearly: long entry/exit, short entry/exit — har condition detail mein (retest def, strong-candle def, SL/target math). (2) Sequence constraints: retest BEFORE opposite crossover. (3) Position rules: one entry at a time — overlapping trades block. (4) Output requirements: visual signals + strategy version for backtest. Bonus: strong-candle function suggestion dena — modular code milta hai jo debug karna easy.

</details>

4. 70% monthly growth result ko kaise scrutinize karoge?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Checklist: (1) Costs configured? Commission/slippage set karke re-run — high-frequency strategies pe yeh sabse bada gap hai. (2) Window kitna chhota? 1 mahine = single regime; 6+ mahine across regimes chahiye. (3) Ek instrument? Multi-stock/multi-asset proof do. (4) Smooth curve? Too-good = curve-fit symptom. Phir bhi achha rahe toh forward-test (paper trading) before real money. Skepticism free hai, losses mehengi hain.

</details>

5. ChatGPT se Pine Script kyun avoid, Grok/DeepSeek se kyun?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Pine Script niche language hai jiska version history turbulent raha (v4→v5→v6 breaking changes). ChatGPT ki training data v4/v5-heavy hai — v6 syntax pe outdated patterns deta hai jo compile nahi hote ya silently galat behave karte hain. Grok/DeepSeek ke models newer versions cover karte hain. Rule: tool apni strength ke hisaab se — Python ke liye ChatGPT fine, Pine ke liye nahi.

</details>
