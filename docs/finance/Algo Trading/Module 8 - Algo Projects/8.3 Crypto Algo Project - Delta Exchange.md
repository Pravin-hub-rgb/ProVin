## Safety-Gaps Jo Original-Me Rahi — Tu BETTER Banna!

Original-session me yeh cheezein GLOSS ho gayi thin —

production ke liye address-karna zaroori:

### 1. Position-State Memory

```text
PROBLEM: server-restart hua → usko NAHI pata rahega
         ki position-open-thi → ORPHANED-EXPOSURE!

FIX: startup pe broker-se positions-FETCH karo
     + state-file/db maintain karo har-trade ke baad!
```

### 2. Duplicate-Alerts

Fast-candles pe TradingView MULTIPLE-alerts fire karta-hai —

DOUBLE-ORDERS lagenge!

Fix: idempotency-guard (7.1!) — same-candle second-signal IGNORE!

### 3. Demo vs Real URL

`api.india.delta.exchange` (demo) vs real-endpoint ALAG —

switch karte-waqt env-var badlo, CODE nahi!

### 4. Ngrok URL-Rotation

Restart pe URL-badla = TradingView-update karna padega...

Cloud-deployment iska PERMANENT-fix hai (agli-files!)
