# 9.4 Order Blocks

## Definition — Keep SIMPLE!

> **BULLISH-OB = impulsive-UP-move's immediately-preceding LAST-RED-candle!**
>
> **BEARISH-OB = impulsive-DOWN-move's immediately-preceding last-GREEN-candle!**

Focus on THREE-keywords:

```text
1. LAST opposite-candle!
   (right before move started!)

2. IMPULSIVE move!
   (not slow-drift — EXPLOSIVE!)

3. BREAKS STRUCTURE!
   (move gave BOS/CHoCH — 9.3's FILTER!)
```

### Example (Bullish-OB):

```text
... 98.5↓ 98.2↓ [98.0 RED] → 101↑ 103↑ 104↑
                   ↑↑↑↑↑↑↑↑↑↑↑
         THIS is bullish-OB-zone:
         98.0-candle's LOW to HIGH!!

Move broke swing-high? YES (100+) → VALID-OB ✅
```

## WHY It Works?! (Logic)

Story is:

```text
In that red-candle institutions ACCUMULATED buying!
(that's why price didn't fall further!)

Then their FULL order-flow RELEASED!
(explosive-move + BOS!)

But their UNFILLED-buy-orders REMAINED
in upper range!!
```

Now when price RETURNS to that zone:

```text
→ SAME unfilled-orders ACTIVATE!
  (institutions complete position!)
→ New trend-followers also take "discount-entry"!
→ RESULT: bounce from zone! Demand-zone behaves!
```

Whether story 100%-ACCURATE (no LEDGER visible!)...

statistically these zones REACT because

**MANY traders mark SAME-definition zones!**

= SELF-FULFILLING order-clustering!

Both explanations' net-effect SAME: zone has INTEREST!

## VALIDITY-Rules — Not Every OB!

Don't make random-red-candles into OB!

CHECKLIST:

| Rule | WHY |
|---|---|
| 1. Move BROKE STRUCTURE (BOS/CHoCH!) | Otherwise just NORMAL-pullback-candle! |
| 2. Move IMPULSIVE (big bodies, low wicks!) | SIGNATURE of INSTITUTIONAL-aggression! |
| 3. OB still UNMITIGATED! | Mitigated = fuel-BURNED! |
| 4. FRESH-zones > old-zones | Already traded on old! |

### What is MITIGATION?!

```text
Price returned to OB-zone + REACTED (bounced!)
→ zone MITIGATED!
→ its main FUEL used!!
```

Second-time same-zone don't expect STRONG-reaction!

Hence SMC-traders always ask:

*"Is this FRESH-OB or already-TESTED?!"*

## How Trade Happens?! (Template)

Bullish-OB-example:

```text
1. CONTEXT: uptrend-structure (HH-HL!) or bullish-CHoCH!

2. Impulsive-leg gave BOS
   → candle right before that leg = RED-candle = MARK-OB!

3. WAIT: price RETURNS to OB-zone!

4. CONFIRMATION (optional-but-recommended!):
   BULLISH rejection-candle in OB-zone!
   (lower-wick / engulfing!)

5. ENTRY: on confirmation-CLOSE!
   (or aggressive on zone-touch!)

6. SL: slightly BELOW OB's LOW!

7. TARGET: next LIQUIDITY-pool!
   (old-high — BSL!!)
   Risk-Reward: minimum 1:2!!
```

See — **target also comes from LIQUIDITY!!** (9.2!)

Whole-system CONNECTING! 🔗

## Refinement-Tip — Make OB THIN!

Taking entire candle body+wick...

Advanced-traders use REFINED-version:

```text
REFINED:  PRECISE entries + TIGHT-SL! ✅
FULL:     easy for beginners!
```

Start with FULL-candle-zone;

refinement is later-game!

## Nutshell

OB = last opposite-candle before impulsive STRUCTURE-BREAKING move! Logic: unfilled institutional-orders there (or self-fulfilling-clustering!). VALIDITY: structure-break + impulse + UNMITIGATED + fresh! Trade-template: context → zone-TAP → confirmation → SL-below-OB-low → target = OPPOSITE-liquidity-pool (1:2+)! Mitigated-zone = SPENT-fuel. Refined-OB (only-open-level!) = advanced-option!

## What It Is NOT

- ❌ **Not every opposite-candle = OB!!** STRUCTURE-BREAK-filter is MOST-critical — without it this is just "RED-CANDLE" found in every DOWNTICK! Quality-control comes from this rule!
- ❌ **Not GUARANTEED-bounce-zone!** Strong-trends push OBs through without major-reaction (especially NEWS-moves!). Hence SL-MANDATORY — zone-failure is VALID-outcome that must be BUDGETED!
- ❌ **Not MAGIC-levels!** "Institutional-orders-sit-there" is UNVERIFIABLE-claim (nobody has exchange-LEDGER!). What's verifiable: zones STATISTICALLY-react because ENOUGH-traders see them. Focus on EDGE, not MECHANISM-debate!
