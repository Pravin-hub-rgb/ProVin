# 9.5 Fair Value Gaps (FVG)

## What is IMBALANCE?!

In normal-market, at every price-level

BUYERS and sellers BOTH active —

continuous-AUCTION!

But when big-news/order-flow comes:

```text
Price: 100 → 104 → 110 (three-candles, ONE-direction FAST!)

Levels between 100-104 (101, 102, 103!) never
got proper TWO-SIDED-trading!!

Buyers so DESPERATE they bought straight-up!!
```

This is **IMBALANCE:**

some price-levels never got "FAIRLY-traded"!

SMC says: market later revisits these gaps

to "complete" fair-value!

## FVG Detection-Rule — THREE-Candle-Pattern!

FVG detected from three CONSECUTIVE-candles:

```text
BULLISH-FVG:
Candle-1: high = 100
Candle-2: BIG-green-candle (98 → 108)
Candle-3: low = 106

GAP = Candle-1 HIGH (100) to Candle-3 LOW (106)!
= This zone never got "TOUCHED" in trading!
```

**Rule in one-line:**

> **Candle-1's high and Candle-3's low DON'T-OVERLAP**
> → space between = FVG!!

(Bearish-FVG-MIRROR: candle-1-low vs candle-3-high!)

⚠️ Notice: **MIDDLE-candle creates gap but gap NOT-defined by its body!**

Only candles 1 and 3's EXTREMES!!

People make THIS-mistake!

## Visual — See to Understand!

```text
           |    |
         | |    |   ← candle-3 (low-106)
         | |  █ |
         | |  █ |   ← candle-2 (BIG-green!)
       █ | |  █ |
     → █ █ █  █ |
       ↑ ↑
       candle-1     GAP-ZONE: 100–106!
       (high-100)   = BULLISH-FVG!!
```

Gap-zone 100-106 never traded!

Now if price returns to 105 —

it's in **UNTRADED-TERRITORY!** 🏜️

## How to TRADE from FVG?!

Template (bullish-FVG, uptrend-context!):

```text
1. CONTEXT: bullish-structure (BOS happened!)

2. Impulsive-move LEFT an FVG!

3. Price PULLBACKS
   → ENTERS FVG-zone!

4. CONFIRMATION: BULLISH reaction-candle inside zone!

5. ENTRY: on confirmation-CLOSE!

6. SL: BELOW FVG!
   (or below candle-1's low — SAFER!)

7. TARGET: next LIQUIDITY / recent-HIGH!
```

**CONFLUENCE-bonus:** if FVG and OB OVERLAP

(same-area!) — zone DOUBLE-strong!

Two INDEPENDENT-footprints at one-place!! 🔥🔥

## Fill is NOT Mandatory — Honest-Framing!

"Market fills EVERY-gap 100%" — **MYTH!**

Truth:

```text
✅ After fast-moves, pullback-tendency STRONG!
   (overextension-fatigue!)

✅ FVG-zones act as MAGNETS/support during those pullbacks!

⚠️ PARTIAL-fills more common than FULL-fills!
```

Hence in trade-plan:

**Watch FVG-tap + REACTION, don't blindly place limit-order!**

## Inversion-FVG (IFVG) — Quick-Advanced-Note!

One TWIST:

if price **BREAKS THROUGH** FVG with close...

that SAME-gap flips role **COMPLETELY!!**

```text
BULLISH-FVG-BROKEN = now BEARISH-resistance!!
```

Logic: support that FAILED

becomes failed-buyers' baggage!

For now just remember NAME;

use in advanced-contexts!

## Nutshell

FVG = 3-candle-imbalance: candle-1-high vs candle-3-low NO-overlap (bullish!)! Meaning: levels never FAIRLY-traded! Use: after impulsive-leg, pullback-magnet/entry-zone; confluence-with-OB = STRONG!! Full-fill NOT-guaranteed — reaction-based-entry! **IFVG: broken-gap flips-role!** Middle-candle doesn't create gap — extremes 1-and-3 MATTER!

## What It Is NOT

- ❌ **FVG ≠ daily-chart-opening-gap!** Daily "gap-up" (yesterday-close vs today-open) is DIFFERENT-concept! FVG is INTRADAY candle-to-candle-imbalance — same-word, DIFFERENT-thing!!
- ❌ **"Every-gap-fills!" NO!** In strong-trend MOMENTUM, FVGs stay UNFILLED for days (those become EXHAUSTION-memory, not tradeable!). "100%-fill" statistics are SURVIVORSHIP-flavored-claims!
- ❌ **Gap-SIZE ≠ strength DIRECTLY!** Big-gap may say move was AGGRESSIVE — but TRADEABILITY comes from location+context (WITH-structure!), not size-ALONE!
