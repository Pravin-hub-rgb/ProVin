## Step 1 — Swings Detect Karna (Fractal Method)

Sabse pehle swings chahiye. Standard objective definition — fractal:

```python
import pandas as pd

def find_swings(df, window=3):
    """Swing high: apne dono taraf ke `window` candles se upar.
       Swing low: mirror. Returns index lists."""
    sh_idx, sl_idx = [], []
    highs, lows = df["high"].values, df["low"].values

    for i in range(window, len(df) - window):
        if highs[i] == max(highs[i-window : i+window+1]):
            sh_idx.append(i)
        if lows[i] == min(lows[i-window : i+window+1]):
            sl_idx.append(i)

    return sh_idx, sl_idx
```

⚠️ **Look-ahead alert:** candle i ka swing status `window` candles BAAD mein confirm hota hai. Isliye backtest loop mein swing ko **i + window pe use karo**, i pe nahi. Yehi woh fix hai jo 90% YouTube-backtests miss karte hain.

## Step 2 — BOS / CHoCH Detection

State machine approach (4.5 ka pattern!):

```python
def detect_breaks(df, sh_idx, sl_idx, confirm_delay=3):
    events = []   # (index, type, level)
    last_sh = last_sl = None
    trend = None                    # "up" / "down"

    sh_set, sl_set = set(sh_idx), set(sl_idx)

    for i in range(len(df)):
        # swings CONFIRMED hona ab tak (delay ke saath)
        c = df.iloc[i]

        if last_sh and c["close"] > last_sh[1]:
            ev = "BOS" if trend == "up" else "CHOCH"
            events.append((i, ev, last_sh[1]))
            trend = "up"
            last_sh = None                      # consumed
        elif last_sl and c["close"] < last_sl[1]:
            ev = "BOS" if trend == "down" else "CHOCH"
            events.append((i, ev, last_sl[1]))
            trend = "down"
            last_sl = None

        # naya swing AVAILABLE hua (confirm-delay ke baad)
        j = i - confirm_delay
        if j >= 0:
            if j in sh_set and last_sh is None:
                last_sh = (j, df.iloc[j]["high"])
            if j in sl_set and last_sl is None:
                last_sl = (j, df.iloc[j]["low"])

    return events
```

Samajh: `trend` flag decide karta hai ki counter-break CHoCH hai ya continuation BOS — bilkul 9.3 ke rules ke hisaab se.

## Step 3 — FVG Detect Karna

Yeh sabse seedha hai — 3-candle rule (9.5) seedha code:

```python
def find_fvgs(df, min_gap=0.0):
    fvgs = []
    for i in range(2, len(df)):
        c1, c3 = df.iloc[i-2], df.iloc[i]

        if c1["high"] < c3["low"]:          # bullish imbalance
            gap = c3["low"] - c1["high"]
            if gap >= min_gap:
                fvgs.append({"type": "bullish", "bottom": c1["high"],
                             "top": c3["low"], "created_at": i})

        elif c1["low"] > c3["high"]:        # bearish imbalance
            gap = c1["low"] - c3["high"]
            if gap >= min_gap:
                fvgs.append({"type": "bearish", "top": c1["low"],
                             "bottom": c3["high"], "created_at": i})
    return fvgs
```

`min_gap` filter noise chhote gaps ko hata deta hai (parameter hai — 5.4 wale ranges-style tune karo).
