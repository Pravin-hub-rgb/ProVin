# 6.3 Traffic Light Strategy Backtest — Angel One

## Strategy Rules

```text
TRAFFIC LIGHT RULES:
- Price-action based (NO indicator)
```

Candles red-green ALTERNATE —

Alternating pairs = **tug-of-war zone** —

Mark that entire range.

Whichever side FINALLY breaks = winner side!

## Data Fetch — Angel One + Chunking

```python
from datetime import date, timedelta
from login import smart_api          # 3.12's session
import pandas as pd

def fetch_chunked(start, end):
    all_candles = []
    current = start

    while current < end:                        # until range ends
        chunk_end = min(current + timedelta(days=30), end)
        raw = smart_api.get_candle_data(
            exchange="NSE",
            tradingsymbol="NIFTY",
            interval="FIVE_MINUTE",
            fromdate=current.isoformat(),
            todate=chunk_end.isoformat()
        )
        all_candles.extend(raw["data"]["candles"])   # add this chunk
        current = chunk_end                          # move ahead

    df = pd.DataFrame(all_candles,
                      columns=["time","open","high","low","close","volume"])
    return df

df = fetch_chunked(date(2024,1,1), date(2024,12,31))
```

```text
Jan 1 → Jan 31 data     (chunk 1)
Feb 1 → Feb 29 data     (chunk 2)
...keep extending...
Until December! Full year ready ✅
```

Each chunk ~30 days. `timedelta(days=30)` = "date 30 days later."

## Pair Detector — New Helper Function

```python
def is_green(c):
    return c["close"] > c["open"]

def is_red(c):
    return c["close"] < c["open"]

def is_alternating_pair(prev_c, curr_c):
    """Two candles whose colors are DIFFERENT"""
    return (is_green(prev_c) and is_red(curr_c)) or \
           (is_red(prev_c) and is_green(curr_c))
```

```python
is_alternating_pair(prev, curr)
```

Read: *"(previous GREEN and this RED) OR (previous RED and this GREEN)"*

= colors alternating = pair found!

### 🔑 Look-Ahead Prevention In Action!

Notice function design:

> Only **CURRENT + PREVIOUS** candle passed.
>
> **FUTURE candles NOT accessible!**

Remember 4.1's look-ahead bias?

In live trading future doesn't exist —

so backtest should also show only what's visible LIVE!

Design principle: limit data access via FUNCTION BOUNDARIES —

then bias becomes structurally IMPOSSIBLE.
