# 6.2 Opening Range Breakout (ORB) Backtest — Zerodha

## Strategy Rules — Pehle Ekdum Clear

```text
ORB RULES:
Instrument : Stock (Reliance example)
Open Time  : 9:15 AM
RANGE      : Pehli 15-min candle (9:15-9:30) ka HIGH & LOW
             = "opening range"
Execution  : 5-minute chart pe
BREAK UP   → LONG entry 🟢
BREAK DOWN → SHORT entry 🔴
STOP LOSS  = opposite side of range
TARGET     = 1:2 risk-reward
```

### Logic Samajho — Yeh Kaam Kyun Karta Hai?

Market open hone ke baad ke pehle 15 minutes mein

**bade players apni position banate hain.**

Jo range banti hai woh din ka "battlefield" hai.

```text
Range ke UPAR break → buyers jeet rahe hain → din bullish?
Range ke NEECHE break → sellers jeet rahe → din bearish?
```

### Risk-Reward Math (1:2 Ka Matlab)

Example numbers se:

```text
Range high: 2500 | Range low: 2480
BUY @ 2500 (breakout pe)
SL @ 2480 (range low)        → RISK = ₹20
Target @ 2540                → REWARD = ₹40

1 risk pe 2 reward! Ek jeet = do haar cover!
```

## Code Architecture — Building Blocks

### Helper Functions (3.3 ka use!)

```python
def is_green(candle):
    return candle["close"] > candle["open"]     # upar band hui = green

def is_red(candle):
```


### State Machine — Wohi Flag Pattern!

4.5 wala `entry` flag yahan bhi hero hai:

```python
in_trade = False       # abhi position open hai?
direction = None       # "LONG" ya "SHORT"
entry_price = sl = target = None
trades = []
```

## Main Loop — Day-wise ORB Logic

Ek din ka demo samjho, phir loop saare dinon pe:

```python
df["date_only"] = df["date"].dt.date     # har candle kis DIN ki hai
df["time"] = df["date"].dt.time          # aur us din ke andar ka TIME

for day, day_df in df.groupby("date_only"):      # ek-ek DIN alag karo
    day_df = day_df.reset_index(drop=True)

    # --- OPENING RANGE: pehli TEEN 5-min candles (9:15-9:30)
    or_high = day_df.iloc[0:3]["high"].max()     # teeno ki sabse badi high
    or_low  = day_df.iloc[0:3]["low"].min()      # teeno ki sabse choti low
    risk = or_high - or_low                       # range ki width

    in_trade = False

    for i in range(3, len(day_df)):              # range KE BAAD ki candles
        c = day_df.iloc[i]
        price = c["close"]

        if not in_trade:
            # LONG: close range-high ke UPAR gaya?
            if price > or_high:
                in_trade = True
                direction = "LONG"
                entry_price = price
                sl = or_low                      # opposite bound
                target = entry_price + 2 * (entry_price - sl)   # 1:2!

            # SHORT: close range-low ke NEECHE?
            elif price < or_low:
                in_trade = True
                direction = "SHORT"
                entry_price = price
                sl = or_high                     # mirror!
                target = entry_price - 2 * (sl - entry_price)

        else:
            # Position open hai — SL ya TARGET check karo
            hit_sl = price <= sl if direction == "LONG" else price >= sl
            hit_tg = price >= target if direction == "LONG" else price <= target

            if hit_sl:
                pnl = (sl - entry_price) if direction == "LONG" else (entry_price - sl)
                trades.append({"day": day, "dir": direction, "pnl": pnl * qty})
                in_trade = False
            elif hit_tg:
                pnl = (target - entry_price) if direction == "LONG" else (entry_price - target)
                trades.append({"day": day, "dir": direction, "pnl": pnl * qty})
                in_trade = False
```

Lamba lag raha hai? Andar se padho —

**sirf 3 concepts repeat ho rahe hain!**

### Concept 1 — Opening Range Nikalna

```python
or_high = day_df.iloc[0:3]["high"].max()
```

```text
iloc[0:3]        → positions 0,1,2 (TEESRI NAHI! stop excluded — 3.7 rule!)
["high"]         → unki high column
.max()           → teeno mein se SABSE BADI high
```

Pehli 3 candles (9:15, 9:20, 9:25) = 15-minute window.

Unki max high = range top. Mirror mein min low = range bottom.

### Concept 2 — Entry Conditions

```python
if price > or_high:
    ...LONG setup...
elif price < or_low:
    ...SHORT setup...
```

Range ke UPAR gaya → LONG. NEECHE gaya → SHORT.

SL opposite bound pe, target 2x door (1:2!).

```python
target = entry_price + 2 * (entry_price - sl)
```

Padho: `(entry − sl)` = RISK hai.

`2 × risk` = reward. `entry + reward` = target!

### Concept 3 — Exit Checks (SL/Target)

```python
hit_sl = price <= sl if direction == "LONG" else price >= sl
```

Yeh **ternary** hai (3.8-style one-line if):

```text
LONG hai?  → SL hit jab price SL se NEECHE
SHORT hai? → SL hit jab price SL se UPAR
(mirror logic!)
```

## ⚠️ Ek Aur Formula Correction!

Original material mein phir se likha tha:

> *"PnL = entry price − exit price (long)"* ← **ULTA HAI!**

4.5 wala hi rule dobara:

```text
✅ Long trade PnL = EXIT − ENTRY
   (100 khareeda, 110 becha = +10 PROFIT!)
```

Short mein ulta: `entry − exit`.

Sign errors backtests ko silently poison karte hain —

**apne code mein comment daal do:** `# long jeet = exit > entry?`

## Time Filter — Late Breakouts Se Bachav

Ek improvement jo real traders add karte hain:

**entries sirf subah ki window mein!**

Dopahar ka "breakout" wohi signal nahi hota — stale move hota hai.


## Nutshell

ORB = zero-indicator: first 15-min range (pehli 3 candles ka max-high/min-low) → breakout above = LONG (SL=low, target 1:2), below = SHORT mirror. Workflow: rules comments mein → Kite data → helper functions (`is_green/is_red`) → state-machine + flag → day-wise `groupby`. ⚠️ PnL correction phir se: long = exit − entry! Time-filter late breakouts rokta hai. Assignment = apna vs AI code diff karna — asli quant skill yahi hai.

## What It Is NOT

- ❌ **Zero-indicator ≠ zero-logic.** Indicator nahi hai par rules POORE hain — range definition, breakout definition, SL/target math. Price-action bhi precisely define hona chahiye.
- ❌ **ORB har din trade nahi leti.** Range ke andar rahi price (no breakout) → NO TRADE. No-trade bhi decision hai — forced entries account killers!
- ❌ **1:2 target universal law nahi.** Parameter hai — 1:1, 1:3 test karo (broad ranges!). Volatile stock pe same RR alag behave karega.

**In Your Own Words**

1. Opening range kaise banti hai? 5-min chart pe kyun execute?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Range = open ke baad first 15 minutes (9:15–9:30) ki combined high-low. 5-min chart pe = pehli TEEN candles; unka max high = top, min low = bottom. Execution 5-min pe isliye: (a) breakout confirmation FINER milti hai — 15-min candle wait karte move miss hota; (b) SL/target placement precise hota hai. Definition (range) aur execution-timeframe (candles) alag cheezein hain.

</details>

2. Long trade mein entry/SL/target math dikhao.

<details>
<summary>Sample Jawab</summary>

**Jawab:** Range high 2500, low 2480 maan lo. Breakout close 2502 pe entry. SL = opposite bound = 2480 → risk = ₹22. Target 1:2 = 44 points upar = 2546. Code: target = entry + 2*(entry − sl). Short MIRROR: entry below low, SL = high, target neeche 2x distance. Math simple: ek winner (44) do losers (22×2) cover karta hai.

</details>

3. Time filter kyun zaroori?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Opening-range ka significance TIME-bound hai! Subah ka breakout institutional momentum = signal. Dopahar ka same-level cross = stale drift (profit booking, news) = noise. Bina cutoff strategy random afternoon "breakouts" bhi legi jo edge nahi rakhte. Cutoff parameter hai — broad-range style tune karo (9:45/10:15/10:45), plateau dekho.

</details>

4. Do codes ke results alag kyun aate hain (3 reasons)?

<details>
<summary>Sample Jawab</summary>

**Jawab:** (1) Breakout TRIGGER difference — ek close-based, doosra wick/high-based; intraday noise me ye dozens of trades change kar deta hai. (2) Same-candle CONFLICT — agar ek candle me SL bhi touch aur target bhi, konsa PEHLE count hua? Assumption matters. (3) ENTRY timing — breakout candle ke close ya agle open? Plus costs included ya nahi. Lesson: results differ = assumptions differ. Code diff karke exact line dhundo — professional debugging yahi hai.

</details>
