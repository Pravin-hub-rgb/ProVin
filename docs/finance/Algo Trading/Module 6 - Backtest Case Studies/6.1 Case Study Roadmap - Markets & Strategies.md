## Indicator-Based Kyun? SMC Kahan Hai?

Ek honest choice explain kar do. Tumne YouTube pe **SMC (Smart Money Concepts)** suna hoga — fair value gaps, order blocks, trend/support lines. Woh sab **exclude** kiya gaya hai abhi, kyunki:

- SMC/pure price-action ke liye raw Python mein complex code likhna padta hai (lines detect karna, zones banana) — beginner ke liye galat starting point
- Indicator-based strategies se **technical foundation** strong hota hai — loop, signals, PnL, metrics sab practice ho jaata hai
- Advanced concepts (fair value, trend lines) aage **Pine Script / TradingView** pe cover honge (Module 8)

Pehle chalna seekho, phir bhaagna.

## Jargon Check — Options Wali Baatein

Roadmap mein jo naam aaye, unka quick decoder (details 2.2 se yaad kar):

| Term | Matlab |
|---|---|
| **ATM** | Strike = current price ke paas |
| **OTM** | Out-of-the-money — call ka strike price SE UPAR, put ka SE NEECHE (abhi "bekaar" wale options — saste hote hain) |
| **Straddle** | ATM Call + ATM Put dono SELL (ya buy) ek saath |
| **Short Strangle** | OTM Call + OTM Put dono SELL — wider range, safer-ish |
| **"920"** ⚠️ | **Time hai, strike nahi!** 9:20 AM = market open ke baad ki entry window jab expiry-day selling hoti hai. Bahut log isko strike number samajh ke confuse hote hain! |

Aur ek important flag: options backtesting ke liye sirf OHLC candles kaafi nahi — **option chain data** chahiye (strikes, premiums, expiry dates). Yeh "different type of data" fetch karna padta hai — Module 3 wali APIs isi ka base hain. Options case studies aage detailed module mein aayengi.

## Famous Strategies Jo Code Karenge

Do legendary Indian trading-community strategies:

**1. ORB (Opening Range Breakout)** — Abhishek Kejriwal ke naam se famous:
```text
First 15-min candle ka high-low range mark karo
→ Upar breakout = BUY, Neeche breakout = SELL
```
(5.2 mein preview mil chuka tha!)

**2. Traffic Light Strategy** — Power of Stocks (Subasish) ki famous price-action setup:
```text
Green/red candle pairs ka pattern
→ Range breakout pe entry
```

Dono ka **poora backtest** hum code karenge — ORB Zerodha (Kite Connect) data pe, Traffic Light Angel One (SmartAPI) data pe. Wohi brokers jo Module 3 mein sikhaye!

**In Your Own Words**

1. SMC-style strategies abhi kyun exclude hain?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Kyunki unmein price structure detect karne ka custom code chahiye (trend lines, support zones, fair value gaps manually define karna) — beginner ke liye complexity galat jagah hai. Indicator-based strategies pehle lo: unmein signal calculation ready-made hoti hai (EMA/RSI), toh focus backtest mechanics pe rehta hai. Foundation strong hone ke baad SMC aage Pine Script/TradingView tooling ke saath aayega.

</details>

2. "920 Strangle" mein 920 ka matlab kya hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Time — 9:20 AM. Market open (9:15) ke thodi der baad expiry-day option selling ki entry window hoti hai, isliye strategies apne naam mein "920" rakhti hain. Common confusion: log ise strike price 920 samajh lete hain. Decoder rule: option-selling context mein "920" almost hamesha morning entry time hai, strike nahi.

</details>

3. Options backtesting ke liye OHLC candles kyun kaafi nahi?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Kyunki options strategy underlying price pe decide hoti hai par TRADE specific strikes ke premiums pe hota hai. Chahiye: option chain data — available strikes, unke premiums (CE/PE), expiry dates, IV. Underlying Nifty ka OHLC milega par 26000 CE ka premium nahi — woh alag se fetch karna padta hai. Isliye "different type of data" — Module 3 ki APIs (Dhan/Kite etc.) isi ka gateway hain.

</details>

4. ORB ka core rule 2 line mein batao.

<details>
<summary>Sample Jawab</summary>

**Jawab:** Market open ke baad first 15-minute candle ka high aur low mark karo — yehi "opening range" hai. Phir: price range ke UPAR breakout hua → BUY (bullish day expected); NEECHE breakout → SELL/side (bearish day). Logic: opening range institutional activity define karti hai, usse break hona din ki direction ka signal mana jaata hai. Poora coded backtest agli file mein.

</details>
