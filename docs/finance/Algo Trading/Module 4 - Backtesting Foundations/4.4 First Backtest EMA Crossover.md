# 4.4 First Backtest: EMA Crossover Strategy

## Strategy Definition — Rules Likho Pehle

Yeh rahi humari pehli strategy:

| Component | Detail |
|---|---|
| **Indicator** | 9 EMA + 21 EMA |
| **Timeframe** | 5-minute candles |
| **Stock** | Reliance |
| **Entry** | 9 EMA crosses ABOVE 21 → BUY 🟢 |
| **Exit** | 9 EMA crosses BELOW 21 → SELL 🔴 |
| **Short-selling** | ❌ Nahi — sirf buy side |

Rules ek line mein:

```text
BUY jab 9 EMA crosses ABOVE 21 EMA
SELL jab 9 EMA crosses BELOW 21 EMA
```

Do baatein notice karo:

```text
1. NO target, NO stop-loss — jaan-boojh ke!
   (yeh learning-strategy hai; SL/target Module 5 mein aayenge)

2. Strategy define karne ki 5 CHEEZEIN mandatory:
   indicator + timeframe + instrument + entry + exit
   Koi ek missing = strategy ADHOORI = test impossible!
```

## ⚠️ Ek Zaroori Correction — EMA Wali Galti

Original cohort notes mein likha tha:

> *"EMA = last N candles ke close ka average"* ← GALAT!

Aur example diya: `(18+17+16+18+17) ÷ 5 = 17.2`

**Yeh actually SMA hai!** True EMA recursive hota hai (4.2 yaad kar):

```text
SMA = sab barabar                    ← wahi upar wala example
EMA = α×Close + (1−α)×EMA_kal        ← ASLI EMA
```

Kyun matter karta hai?

Manual-average se nikale signals aur library-EMA ke signals

ALAG din pe aayenge → trades alag → results alag → CONFUSION!

Isliye hum poore course mein TRUE EMA hi use karenge

(`talib.EMA` ya `ewm(adjust=False)`).

## NaN Values — Shuruat Ke Khaali Dabbe

Jab indicators calculate karo, shuruat mein `NaN` aata hai:

```text
NaN = "Not a Number" = KHAALI dabba
```

| Indicator | Kitni rows NaN |
|---|---|
| 9 EMA | ~pehli 9 rows |
| 21 EMA | ~pehli 21 rows |
| 200 EMA | ~pehli 200 rows |

**Kyun?** 21-EMA ko 21 candles chahiye history —

row 1 pe history HAI HI NAHI! 😅

Fix simple:

```python
df = df.dropna().reset_index(drop=True)
```

```text
dropna()                → NaN wali rows UDAO
reset_index(drop=True)  → numbering phir se 0,1,2... karo
```

Data loss nahi hua — sirf woh rows gayi jinme indicator EXIST hi nahi karta tha.

## Full Setup Script — Sab Jodke

Ab ek complete script jo backtest-ready data banaye:

```python
import pandas as pd
import talib

# STEP 1: Data load
df = pd.read_csv("reliance_5min.csv")
df.columns = [c.lower() for c in df.columns]

# STEP 2: Indicators banao
df["ema_9"] = talib.EMA(df["close"], timeperiod=9)
df["ema_21"] = talib.EMA(df["close"], timeperiod=21)

# STEP 3: Warm-up rows saaf karo
df = df.dropna().reset_index(drop=True)

print(df[["close", "ema_9", "ema_21"]].head())
print(f"Candles ready: {len(df)}")
```

Output:

```text

0  2456.3  2455.1  2452.8
1  2458.0  2456.1  2453.9
...
Candles ready: 1471
```

Data clean. Indicators ready. Ab bas har candle pe RULES check karne hain!

## Iteration — Backtest Ka Engine

Backtest ka core = ek loop jo HAR candle pe jaata hai:

```python
for i in range(len(df)):
    fast_now = df["ema_9"][i]      # is candle ki fast EMA
    slow_now = df["ema_21"][i]     # is candle ki slow EMA
    close_now = df["close"][i]     # is candle ka close
    # ...yahan conditions check hongi (agli file!)
```

Har round mein `i` agle candle pe jump karta hai:

```text
i = 0 → pehli candle
i = 1 → doosri candle
...
i = 1470 → aakhri candle
```

### Kyun Loop Zaroori Hai? Pandas Toh Hai Na?

Achha sawal! Pandas se filtering toh hoti hai...

Par backtest mein **ORDER matters**:

```text
Pehle BUY hua → phir EXIT hua → phir DOOSRA buy → ...
```

Yeh sequence track karna hai — kaunsa trade kab shuru, kab khatam.

Woh sequential story hai, isliye loop natural fit hai.

(Loop types recap: `range(len(df))` hi use hota hai —

`for x in list` values deta hai, positions nahi!)

## Nutshell

Strategy = indicator + timeframe + instrument + entry + exit (5 cheezein mandatory). Humari pehli strategy: 9/21 EMA crossover, 5-min Reliance, long-only, no SL/target (learning version!). ⚠️ Correction: "N candles ka average" SMA hai — true EMA recursive. ## What It Is NOT

- ❌ **Yeh tradable strategy nahi hai.** No SL, no target, no position-sizing — learning vehicle hai! Real money ke liye risk-layers chahiye (Module 5).
- ❌ **"Last N ka average" = EMA NAHI.** Woh SMA hai. EMA bolna hai toh recursive formula hona chahiye — warna naam galat hai.
- ❌ **dropna() se data loss nahi hota.** Sirf warm-up rows jaati hain jinme indicator exist hi nahi karta — woh analysis ke KAAM ki nahi thi.
