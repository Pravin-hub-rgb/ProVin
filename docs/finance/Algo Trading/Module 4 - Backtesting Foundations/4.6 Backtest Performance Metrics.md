### Metric 8: Max Drawdown — Biggest Hole

Drawdown = fall from any PEAK of equity.

Code:

```python
running_max = report["equity"].cummax()     # highest point so far
drawdown = (report["equity"] - running_max) / running_max * 100
max_dd = drawdown.min()

print(f"Max Drawdown: {max_dd:.1f}%")
```

Line by line:

```text
.cummax()                    → remembers "MAX so far" at each point
equity − running_max         → how much BELOW peak now
÷ running_max × 100          → in percentage
.min()                       → deepest dip
```

**Why scary?**

50% drawdown means capital became HALF...

and to come back need **100% gain!**

(Math: 100 → 50 → back to 100 = +50 on 50 = +100%!)

Plus psychology: that phase BREAKS trader.
