Pichli file ke end mein humare paas sirf ek number tha — `net_pnl`. Par soch: do strategies ka net profit same hai, toh kya dono equally achhi hain? Ek ne 2 trades mein banaya, doosri ne 500 mein. Ek ka journey smooth tha, doosri wali beech mein 60% doob gayi thi. **Scoreboard chahiye** — aur wohi performance metrics hain.

# 4.6 Backtest Performance Metrics

## Cricket Analogy — Strategy Ka Scorecard

Jaise batsman ko judge karne ke liye sirf total runs nahi dekhte — average, strike rate, consistency sab dekhte hain — waise hi strategy ka scorecard multiple metrics se banta hai.

⚠️ Is file ka sabse bada lesson pehle hi: **Win rate akele kaafi nahi hai.** 90% win rate wali strategy bhi paisa uda sakti hai. Jaise-jaise aage badhenge, samajh aa jayega kaise.

(~10–11 core metrics kaafi hain. 50+ advanced metrics — Calmar ratio wagera — abhi ki zaroorat nahi.)

## Trade Report — Pehle Data Structure Banao

Metrics calculate karne se pehle har trade ka structured record chahiye. 4.5 wale loop ko thoda upgrade karte hain — ab sirf PnL nahi, poora trade detail log karenge:

```python
import pandas as pd

qty = 10
initial_capital = 100000
entry = False
buy_price = 0.0
buy_time = None
trades = []

for i in range(len(df)):
    fast_now = df["ema_9"][i]
    slow_now = df["ema_21"][i]

    if fast_now > slow_now and not entry:
        entry = True
        buy_price = df["close"][i]
        buy_time = df["time"][i]

    elif fast_now < slow_now and entry:
        sell_price = df["close"][i]
        pnl = (sell_price - buy_price) * qty      # corrected formula
        trades.append({
            "entry_time": buy_time,
            "exit_time": df["time"][i],
            "side": "LONG",
            "entry_price": buy_price,
            "exit_price": sell_price,
            "pnl": pnl,
        })
        entry = False

report = pd.DataFrame(trades)
print(report.head())
```

Report ke columns ka matlab:

| Column | Matlab |
|---|---|
| Entry time / Exit time | Kab liya, kab nikala |
| Side | Long ya Short |
| Entry price / Exit price | Buy/sell rates |
| PnL | Per-trade result |

Aur iske upar **equity column** judta hai:

```python
report["equity"] = initial_capital + report["pnl"].cumsum()
```

`cumsum()` = running total. Har exit ke baad capital kitna hua — yehi equity curve ka raw data hai. Final capital = `initial + total PnL`, obviously.

## Core Metrics — Ek-Ek Karke

Ab report DataFrame se saare metrics nikalte hain:

```python
winners = report[report["pnl"] > 0]     # boolean filtering — 3.7 wali skill!
losers  = report[report["pnl"] <= 0]
```

**1. Net Profit:**
```python
net_profit = report["pnl"].sum()
```
Final equity − initial equity. Company jaisi baat hai: revenue ₹8cr ho sakta hai par matter karta hai net profit.

**2. Total Trades:**
```python
total_trades = len(report)
```

**3. Win Rate:**
```python
win_rate = len(winners) / total_trades * 100
```

**4–5. Average Win / Average Loss:**
```python
avg_win  = winners["pnl"].mean()    # e.g. +₹11
avg_loss = losers["pnl"].mean()     # e.g. −₹21
```

Yahan aata hai course ka **shock example**: ek strategy ka win rate **85.44%** tha — phir bhi total **₹13,000 ka LOSS**! Kaise? Kyunki average loss (−₹21) average win (+₹11) se lagbhag double tha. Chhote-chhote jeet te raho, aur jab haaro toh do gunna haaro. Math dekho:

```text
100 trades, 85 winners × +11 = +935
             15 losers  × −21 = −315... 
```
(Real example mein losses aur bhi asymmetric the — point yeh hai ki ratio matters, sirf count nahi.)

**6. Expectancy — Per Trade Ka Sach:**
```python
expectancy = net_profit / total_trades    # e.g. −₹7 per trade
```
Har trade "average" mein kitna deta hai? Negative expectancy = har trade mein market ko paisa de rahe ho — chahe win rate kuch bhi ho. Yeh sabse honest single number hai.

**7. Profit Factor** (4.1 ki table se yaad hai?):
```python
profit_factor = winners["pnl"].sum() / abs(losers["pnl"].sum())
```
Gross kitna kamaya vs gross kitna khoya. 1.5+ = healthy, <1 = losing.

## Equity Curve — Journey Ka Graph

Numbers table se achha ek graph hota hai. Matplotlib (4.3 mein install kiya):

```python
import matplotlib.pyplot as plt

plt.figure(figsize=(12, 5))
plt.plot(report["exit_time"], report["equity"])
plt.title("Equity Curve")
plt.ylabel("Capital")
plt.show()
```

Achhi equity curve = upar jaati hui seedhi-ish line (smooth growth). Gaddhe (dips) = drawdown phases. Isko dekh ke turant feel aa jaati hai strategy ki journey ki.

**8. Max Drawdown — Sabse Bada Gaddha:**

Peak-to-trough drop — equity ke kisi peak se uske baad ke sabse neeche point tak ka girawat:

```python
running_max = report["equity"].cummax()          # ab tak ka highest equity
drawdown = (report["equity"] - running_max) / running_max * 100
max_dd = drawdown.min()
print(f"Max Drawdown: {max_dd:.1f}%")
```

`cummax()` har point pe ab-tak-ka-max rakhta hai; current equity minus that peak = kitne neeche hai hum apne best se. Kyun matter karta hai? Agar max DD 50% hai matlab kabhi aisa phase aaya tha jismein capital aadha ho gaya — **aur woh recover karne ke liye 100% gain chahiye!** Psychology + math dono brutal hain.

**9. CAGR — Annualized Growth:**

Simple version: ₹1L → ₹1.2L ek saal mein = **20% CAGR**. Multi-year data pe proper annualization formula lagta hai ((final/initial)^(1/years) − 1) — jab backtest 3–5 saal ka hoga tab use karenge. Abhi concept yaad rakho: *har saal average kitna badha.*

**10. Sharpe Ratio — Risk-Adjusted Return:**

```text
Sharpe ≈ Avg Return ÷ Volatility (returns ka std dev)
```

Idea: Do strategies same return deti hain — jo **kam ups-and-downs** ke saath dete, woh better hai. Sharpe high = smooth straight-ish curve. Popular shorthand: "Sharpe 3 = har ₹1 risk pe ₹3 return."

⚠️ Ek honesty note: yeh simplified version hai. Proper Sharpe mein risk-free rate subtract hota hai aur returns ko annualize karna padta hai — exact values thodi alag aayengi. Abhi intuition pakdo: **high Sharpe = smooth ride.**

## Nutshell

Strategy ka scorecard ~10 metrics ka hota hai: Net Profit, Trade Count, Win Rate, Avg Win/Loss, Expectancy, Profit Factor, Equity Curve, Max Drawdown, CAGR, Sharpe. Sabse bada lesson: **85% win rate bhi lose kar sakti hai** agar avg loss avg win se bada ho — asymmetry matters. Expectancy per-trade ka sach batata hai. Max DD recovery math brutal hai (50% DD → 100% gain needed). Sharpe = smoothness score. Trade report DataFrame banate ho toh sab metrics 5 lines mein nikal aate hain. Aur influencer claims ko code se verify karo.

## What It Is NOT

- ❌ **High win rate ≠ good strategy.** Win rate distribution ka ek side hai; avg win/loss ratio doosri. Dono milke expectancy banate hain — woh decide karta hai.
- ❌ **Metrics backtest pe calculated hain — future promise nahi.** Yeh scoreboard past performance ka hai; live behavior alag ho sakta hai (4.1 ka deviation rule).
- ❌ **Sharpe/CAGR ke simplified versions ≠ research-grade numbers.** Risk-free rate, annualization, benchmarking — advanced versions Module 6+ mein refine honge. Abhi direction samajhna kaafi hai.
