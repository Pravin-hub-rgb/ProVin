# 3.8 Data & API Overview

## What is Market Data?

Exchange records price every second.

That raw data is broken into **candles** — by time:

```text
9:15 - 9:20 all data → one 5-minute candle
9:20 - 9:25 all data → next candle
...
```

Each candle = that 5 minute's story, in 5 numbers.

## OHLCV — What's Inside a Candle

Each candle has **5 things**:

```text
O-H-L-C-V

O = OPEN    → first price that formed in those 5 min
H = HIGH    → highest price
L = LOW     → lowest price
C = CLOSE   → LAST price (most important!)
V = VOLUME  → how many shares traded
```

Example — one Reliance candle:

```text
Open:   2450   ← first trade at 9:15 happened at this
High:   2460   ← went up to here midway
Low:    2448   ← and fell down to here
Close:  2457   ← last trade at 9:20
Volume: 125000 ← this many shares traded
```

**Close is most important** — because it's final decided price. That's why indicators are mostly calculated on close (EMA in 4.x will also be built from close).

## How Data Table Looks

Thousands of candles = pandas DataFrame (previous file's hero!):

```text
        time                 open    high     low    close  volume
0  2024-01-01 09:15:00     2450.0  2460.0  2448.0   2457.0  125000
1  2024-01-01 09:20:00     2457.0  2461.0  2452.0   2455.0  110000
2  2024-01-01 09:25:00     2455.0  2459.0  2450.0   2458.0   98000
...each row = one candle
```

Each row = one candle. Each column = one letter of OHLCV.

That's it. This format is standard for whole course.

## API — Ordering Goods From Shop

**API** full form: Application Programming Interface.

Forget full form — understand simple:

> API = way to TALK to another system. You ask, it gives.

Restaurant analogy:

```text
You don't talk to chef directly — you tell WAITER.
Waiter takes order → carries to kitchen → brings food back.

API = waiter:
Your code gives order → carries to broker's server →
brings data back
```

### Historical Data Flow

Our use-case: *"Broker ji, give last month's 5-min candles of Reliance."*

```text
Your Python code
    ↓ request
Broker's API (waiter)
    ↓ from own database
Candles back to your code
    ↓ pandas DataFrame
BACKTEST READY! 🎉
```

## 🔑 The Golden Pattern — Course's Theme

Every broker looks different... but inside they're **SAME**:

```text
STEP 1: CONNECT      → give credentials, make client
STEP 2: AUTHENTICATE → get access token (permission slip)
STEP 3: FETCH        → say "give this data"
STEP 4: CONVERT      → make pandas DataFrame
```

Function names will differ — Dhan has `historydailydata()`, Zerodha has `historical_data()`...

But pattern is SAME.

Once understood, new broker = just changing names. That's why don't stress — instead of learning 6 new things, you'll see 1 pattern repeated 6 times.

## Nutshell

Market data = candles: OHLCV (Open-High-Low-Close-Volume) in time-buckets. Close most important — final decided price. Each candle = one DataFrame row. API = waiter — your code requests, broker returns data. 6 sources to learn (Dhan/Zerodha/Angel/Groww/Delta/MT5) but golden pattern is ONE: **connect → authenticate → fetch → DataFrame.**

## What It Is NOT

- ❌ **API is not a website.** Website is for humans (to look at); API is for CODE (structured data). Open API URL in browser and you'll see weird JSON-text — normal, it's not made for humans.
- ❌ **OHLCV column names are not universal.** Some write `timestamp`, some `time`; some `vol`, some `volume`. Structure same, names different — so make habit of verifying with `df.head()` on every source.
- ❌ **Free data ≠ unlimited data.** Brokers put limits: how old data, what resolution, how many requests per day. That's why tricks like chunked-fetching come in later files.

3. Golden pattern's 4 steps? Approach for new broker?

<details>
<summary>Sample Answer</summary>

**Answer:** (1) CONNECT — initialize client with credentials, (2) AUTHENTICATE — get token/login permission slip, (3) FETCH — call historical-data function (give symbol + timeframe + dates), (4) CONVERT — make response into pandas DataFrame. 4. Why is close price most important?

<details>
<summary>Sample Answer</summary>

**Answer:** Because close = that period's FINAL consensus — after all buyers/sellers finished their work. High/Low can be temporary extremes (one big order made a wick); close is settled value. That's why indicators like EMA, RSI are calculated on close prices, and candle patterns focus on body (open-close). In backtest too decisions mostly happen on close.

</details>
