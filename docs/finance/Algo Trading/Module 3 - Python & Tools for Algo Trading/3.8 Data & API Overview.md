# 3.8 Data & API Overview — Historical Candlestick Data

## Historical Data Kya Hota Hai

**Historical data = past candles ka data** — backtesting ke liye yehi chahiye hota hai. Live trading mein historical ki zaroorat nahi (wo alag story hai).

Har candle ke andar **OHLCV structure** hota hai:

| Field | Kya Hai |
|---|---|
| **Time** | Candle kis time slot ki hai (9:15, 9:20... agar 5-min candles hain) |
| **Open** | Candle shuru hone wala price |
| **High** | Us slot ka highest price |
| **Low** | Us slot ka lowest price |
| **Close** | Candle khatam hone wala price |
| **Volume** | Us slot mein kitna trade hua |

### Candle Banti Kaise Hai

5-min candle example: candle 9:15 se 9:20 tak ki hai, toh usmein us window ka saara price action hai. Price upar gaya, neeche aaya, upar gaya — time khatam → candle ban gayi.

Candle ka color close decide karta hai:

- Close > Open → **Green candle**
- Close < Open → **Red candle**

## Har Market Mein Same Structure

Ab woh insight jo poore module ki foundation hai. Teen markets ka data dekho:

- **Reliance stock (Indian):** open, high, low, close, volume — sab mila
- **Nifty 50 index:** same structure, **lekin volume nahi aata!**
- **Bitcoin-USD (crypto):** wapas OHLCV sab mila

Ek exception yaad rakh: **index ka volume nahi hota** (Nifty 50 ek index hai, individual stock nahi — isliye traded quantity ka concept apply nahi hota). Baaki sab — stocks, forex, crypto — mein structure identical hai.

Isliye "secret sauce" yeh hai: jo backtesting process stocks pe seekhoge, wohi crypto aur forex pe chalega. Bas data source badalta hai.

## Data Fetching Ka Universal Process

Yeh poore course ka sabse important line ho sakti hai:

> **Process har broker ke saath same hai: Login → Fetch → Use.**

1. **Login** — har broker ka login process alag hai (yehi asli difference hai!)
2. **Fetch data** — historical ya live data lao
3. **Pandas DataFrame mein convert karo**
4. **Strategy apply / backtest karo**

Broker se kya-kya mil sakta hai:

- Historical data — past candles (mahino/saal ka)
- Live/tick data — real-time prices
- Option chain data
- Orders place/modify/cancel
- Positions check

Hum pehle historical data se shuru karenge — backtesting ke liye yehi chahiye.

## Nutshell

Historical data = past candles ka OHLCV data — Time, Open, High, Low, Close, Volume. Green candle jab close > open, red jab close < open. Structure stocks/forex/crypto mein same; sirf index (Nifty) mein volume nahi aata. Process universal: login → fetch → DataFrame → strategy — bas login ka tareeka har broker ka alag. ChatGPT se kaam karana hai toh detailed prompt do.

## What It Is NOT

- ❌ **Historical data live trading mein use nahi hota.** Woh sirf backtesting/testing ke liye hai. Live trading ke liye tick/websocket data chahiye — woh alag topic hai.
- ❌ **Index data mein volume ka hona zaroori nahi.** Nifty/BankNifty indexes hain, stocks nahi — unka volume column blank aayega. Error nahi hai, normal hai.
- ❌ **Data vendor khareedna zaroori nahi.** Paid data vendors mehnge hote hain — broker APIs free mein kaam karte hain (bas apna account chahiye).
