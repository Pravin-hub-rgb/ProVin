# 3.10 Dhan API Historical Data Fetching

## Setup — DhanHQ Library

Dhan ne apni official Python library banai hai — `dhan-hq`. Install:

```bash
pip install dhan-hq
```

Import pattern:

```python
from dhan_hq import dhanhq
```

Library mein already built-in functions hote hain: `dhan.placeorder` (order lagana), `dhan.getorderlist` (orders dekhna), `dhan.cancelorder` (cancel karna), aur jo humein abhi chahiye — `dhan.historydailydata` (historical data).

Tip agar function nahi mile toh: GitHub pe library ka source code khula hota hai — wahan jaake dekh sakte ho.

## Login — Client ID + Access Token

Dhan mein sirf do cheezein chahiye:

```python
from dhan_hq import dhanhq

dhan = dhanhq.DhanHq(
    client_id="YOUR_CLIENT_ID",
    access_token="YOUR_ACCESS_TOKEN"
)
```

**Access token kaise banaye:**

1. Dhan account mein login karo
2. **Trading API** section mein jao
3. **Generate Access Token** click karo
4. Naam do (jaise "test")
5. Token copy kar lo — bas!

Na API key maangi gayi, na secret. Yehi Dhan ki simplicity hai.

⚠️ Ek warning: access token expire ho sakta hai. Agar code chalate waqt authentication error aaye, toh sabse pehle fresh token generate karo.

## Historical Data Fetch Karna

Ab asli kaam — candle data:

```python
data = dhan.historydailydata(
    security_id="TCS",
    exchange="NSE",
    from_date="2022-08-19",
    to_date="2022-09-19",
    instrument_type="EQUITY"
)
```

Parameters samajh lo:

| Parameter | Kya Hai | Example |
|---|---|---|
| `security_id` | Stock ka ID | `"TCS"` ya numeric ID |
| `exchange` | Kaunsa exchange | `"NSE"` / `"BSE"` |
| `from_date` | Start date | `"2022-08-19"` |
| `to_date` | End date | `"2022-09-19"` |
| `instrument_type` | Kis type ka instrument | `"EQUITY"` / `"OPTION"` / `"FUTURE"` / `"COMMODITY"` |

Jo data aayega, usko pandas DataFrame mein convert karo (`pd.DataFrame(data["data"])`) — phir wahi familiar structure: date, open, high, low, close columns.

## Do Common Errors Aur Unke Lessons

Yeh file ke sabse valuable hisse hain — real debugging stories:

### Error 1: `cannot import name dhan_context`

ChatGPT se seedha code copy kiya toh yeh error aata hai. Kyun? ChatGPT ka code purani library version ka hota hai — libraries update hoti rehti hain.

**Fix:** GitHub repo ya official docs dekho. Current version ka sahi import pattern wahi milega.

**Lesson:** *"ChatGPT se directly code mat maano — apni library ka docs dekho."* ChatGPT starting point hai, final answer nahi.

### Error 2: `symbol unexpected argument`

Code mein `symbol="TCS"` likha toh yeh error aaya:

```python
# WRONG:
dhan.historydailydata(symbol="TCS", ...)

# RIGHT:
dhan.historydailydata(security_id="TCS", ...)
```

Dhan ka parameter naam `security_id` hai, `symbol` nahi. Har API ke apne parameter names hote hain — docs mein check karo.

## Nutshell

Dhan = simplest login: `pip install dhan-hq`, client ID + access token se initialize, token website se generate hota hai (no key/secret). Data fetch: `dhan.historydailydata()` with security_id, exchange, dates, instrument_type. Do debugging lessons: ChatGPT ka code purana ho sakta hai — official docs follow karo; parameter names har API ke alag hote hain — `security_id`, `symbol` guess mat karo, verify karo.

## What It Is NOT

- ❌ **Dhan ka process unique nahi hai.** Jo yahan seekha — initialize karo, fetch karo, DataFrame banao — wohi har broker pe chalega. Sirf login steps badalte hain.
- ❌ **`security_id` hamesha stock ka naam nahi hota.** Kuch APIs numeric ID maangti hain (jaise Zerodha instrument_token). Docs dekho ki teri API kya expect karti hai.
- ❌ **Token expire hona bug nahi hai.** Security feature hai. Expire hua toh naya generate karo — panic ki zaroorat nahi.
