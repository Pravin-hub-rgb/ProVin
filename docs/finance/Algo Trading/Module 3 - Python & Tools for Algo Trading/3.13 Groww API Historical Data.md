# 3.13 Groww API Historical Data

## Setup — Sabse Chhota Flow

Groww ka naya platform **Groww Cloud** hai — APIs manage karne ke liye clean jagah.

Poora setup sirf 5 steps mein:

1. Groww account mein login karo → **Trading APIs** section → "take me there"
2. **Generate new API** karo — naam do (`test`)
3. **API Key + API Secret** copy kar lo (secret dobara nahi dikhegi!)
4. Library install karo:

```bash
pip install grow_api
```

5. Access token generate karo code se

## Login — Key Secret Se Token

Wohi pattern jo 3.9 mein seekha tha — key/secret one-time, token roz ka kaam:

```python
from grow_api import GrowApi

# Initialize with API key + secret
grow = GrowApi(api_key="YOUR_API_KEY", api_secret="YOUR_SECRET")

# Access token lo
access_token = grow.get_access_token()

# DONE! Ready to fetch
```

Aur storage ka rule bhi same hai — keys directly code mein nahi:

```python
# ❌ WRONG:
api_key = "XNXU-XXXX..."

# ✅ RIGHT:
import os
api_key = os.getenv("GROW_API_KEY")
api_secret = os.getenv("GROW_SECRET")
```

Ya `tokens.py` file banao aur `.gitignore` mein daal do — 3.9 ka security section yaad kar.

Docs ke liye Google karo: `grow api docs` — Groww Cloud documentation mein complete examples milte hain.

## Historical Data Fetch Karna

Function ka naam: `get_historical_candle_data()`:

```python
candle_data = grow.get_historical_candle_data(
    symbol="RELIANCE",
    interval="5minute",
    from_date="2022-01-08",
    to_date="2022-01-15"
)
```

| Parameter | Kya Hai | Examples |
|---|---|---|
| `symbol` | Trading symbol | `"RELIANCE"`, `"TCS"`, `"NIFTY"` |
| `interval` | Timeframe | `"1minute"`, `"5minute"`, `"15minute"`, `"1hour"`, `"1day"` |
| `from_date` / `to_date` | Date range | `"2022-01-08"` |

Interval flexible hai — 1min, 5min, 10min, 15min jo chahiye.

Response ko pandas DataFrame mein convert karo (same as always):

```python
import pandas as pd

df = pd.DataFrame(candle_data["data"])
print(df.head())
print(f"Total candles: {len(df)}")
```

OHLCV columns ready — ab yeh data seedha backtesting mein ja sakta hai.

## Chaar Brokers Ka Recap — Pattern Pakka Karo

Ruk ke dekho kitna consistent raha sab kuch:

| Broker | Login Ke Liye Chahiye | Fetch Function |
|---|---|---|
| Dhan | client_id + access token | `historydailydata()` |
| Zerodha | 3-token dance (login.py se) | `historical_data()` |
| Angel One | key + MPIN + TOTP | `get_candle_data()` |
| Groww | key + secret → token | `get_historical_candle_data()` |

Function names alag, parameter names alag — par flow identical: **initialize → authenticate → fetch → DataFrame.** Ab tujhe naya broker mile toh docs kholo, in 4 cheezon ke naam dhundo, aur kaam ho gaya.

## Nutshell

Groww = simplest Indian broker API. Setup: Groww Cloud pe key+secret generate (one-time), `pip install grow_api`, code se access token. Fetch: `get_historical_candle_data(symbol, interval, from_date, to_date)` → DataFrame. Chaar brokers ke baad pattern crystal clear hai — initialize, authenticate, fetch, convert. Naya broker = sirf naam badalte hain, logic wahi rehta hai.

## What It Is NOT

- ❌ **"Sabse easy" matlab kam powerful nahi.** Groww ka API utna hi capable hai data/orders ke liye jitna doosron ka. Easy ≠ basic.
- ❌ **Key + secret runtime mein har request pe nahi jaate.** Sirf token generation ke liye ek baar use hote hain — phir token hi saari requests ka hero hota hai (3.9 ka model).
- ❌ **Groww Cloud sirf dashboard nahi hai.** Wahi se API keys generate/manage hoti hain — tera algo ka control center hai.
