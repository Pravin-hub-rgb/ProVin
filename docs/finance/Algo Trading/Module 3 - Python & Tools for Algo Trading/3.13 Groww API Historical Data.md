```text
1. Groww account → go to Trading APIs section

4. Save in tokens.py
5. Install library:
```


Platform name: **Groww Cloud** — keys managed here.

## Login — Two-Line Job

```python
from grow_api import GrowApi
from tokens import grow_key, grow_secret     # from tokens.py (habit!)

grow = GrowApi(api_key=grow_key, api_secret=grow_secret)

access_token = grow.get_access_token()
```

Line by line:

```python
GrowApi(api_key=..., api_secret=...)   ← gave ID + password
grow.get_access_token()                ← got badge — done!
```

That's it?! Yes that's it.

No Zerodha-style dance. No Angel One-style OTP.

Key + secret → token. Done.

(That's the standard 3.9 flow — Groww added nothing extra.)

## Historical Data Fetch

```python
response = grow.get_historical_candle_data(
    symbol="RELIANCE",         ← name works (not number!)
    interval="5minute",
    from_date="2024-01-01",
    to_date="2024-02-01"
)

print(response["status"])      # should be "success"
```

Parameters look familiar? Symbol, interval, dates —

same three things every broker asks. Only names differ.

Bonus: Groww has **no chunking tension** — big date-range comes in one request (Angel One required chunks — seen in 6.x).

## Convert → DataFrame (As Always)

```python
import pandas as pd

df = pd.DataFrame(response["data"]["candles"])
print(df.head())
print(f"Total candles: {len(df)}")
```

Golden pattern's Step 4 — done!

## Nutshell

Groww = simplest broker: key+secret → get_access_token() → get_historical_candle_data(symbol, interval, dates) → DataFrame. No dance, no TOTP, no chunking. Real lesson after four brokers: **pattern is constant (connect→auth→fetch→convert), vocabulary changes.** New broker = find 5 things in docs: login style, function name, parameters, response shape — then apply pattern.

## What It Is NOT

- ❌ **Simple ≠ less powerful.** Groww's API is as capable as others. Easy ≠ basic — just less friction in setup.
- ❌ **Key+secret don't go with every request.** They're used only ONCE to GENERATE token; after that badge (token) does all work — same 3.9 model.
- ❌ **Groww Cloud is not just dashboard.** That's your API-control-center — generate/manage keys, see usage. Don't mistake it as separate thing.

When multi-broker systems are built (Module 8 projects), each broker's limits matter in design — chunking-support ones need wrapper function, simple ones don't.
