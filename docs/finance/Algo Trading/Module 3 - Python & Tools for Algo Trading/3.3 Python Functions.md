Loops se repetition ka kaam solve ho gaya. Ab ek aur problem — maan le tere program mein 10 alag jagah average nikalna hai. Kya wahi 4-line code 10 baar copy-paste karega? Copy-paste karne se pehle ruk — iska solution hai **function**. Ek baar likho, hazaar baar call karo.

# 3.3 Python Functions

## Function Kya Hota Hai

**Function = statements ka group** jo ek specific task karta hai.

Aur mazedaar baat — tu functions pehle se hi use kar raha hai! `print()`, `len()`, `type()` — yeh sab functions hain. Kisi ne banaye the, humne sirf use kiye:

```python
print(len("Rahul"))   # 9  (len ek built-in function hai)
```

Ab hum **apne khud ke functions** banayenge.

## Kyun Zaroori Hai

Problem dekh pehle. 3 numbers ka average nikalna hai:

```python
num1 = int(input("Enter 1: "))
num2 = int(input("Enter 2: "))
num3 = int(input("Enter 3: "))
print((num1 + num2 + num3) / 3)
```

Yeh code ek jagah likhna theek hai. Par agar 1000-line ke program mein 10 alag jagah average chahiye? 10 baar copy-paste? ❌ Aur kal ko logic badalna pada toh 10 jagah jaake fix karna padega.

Solution: **function banao ek baar, call karo jitni baar chaaho.**

## Function Kaise Banate Hain — def

`def` = definition. Python ko batata hai ki function ban rahe ho:

```python
def avg():
    num1 = int(input("Enter 1: "))
    num2 = int(input("Enter 2: "))
    num3 = int(input("Enter 3: "))
    print((num1 + num2 + num3) / 3)

avg()    # call kar diya — kaam ho gaya
```

Banane ke steps: `def` → function ka naam → `()` → `:` → phir indent mein andar ka code. Call karne ke liye bas naam + `()` likho.

Functions do tarah ke hote hain:

- **Built-in:** Python ke saath aate hain — `print()`, `len()`, `type()`
- **User-defined:** Tum banate ho — `avg()`, `greet()`, `add()`

## Parameters vs Arguments

Ab function ko flexible banate hain. Hardcoded 3 inputs ki jagah — values bahar se do:

```python
def avg(n1, n2, n3):      # n1, n2, n3 = PARAMETERS
    print((n1 + n2 + n3) / 3)

avg(2, 2, 2)              # 2, 2, 2 = ARGUMENTS → output 2.0
```

Yahan terminology clear kar lo, interview mein bhi poocha jaata hai:

- **Parameter** = function define karte waqt likha naam (placeholder) — `n1, n2, n3`
- **Argument** = function call karte waqt di gayi actual value — `2, 2, 2`

Ek rule: parameters ki count match karni padti hai. 3 parameters hain aur 2 arguments diye → error aayega: *"missing 1 required positional argument."* Error message padhoge toh samajh aa jayega kya missing hai.

Aur example:

```python
def add(num1, num2):
    print(num1 + num2)

add(10, 20)      # 30
```

## Return — Value Wapas Lao

Ab tak hum print kar rahe the. Par ek problem — printed value **store nahi hoti.** Agar average nikalke usko aage use karna hai (jaise kisi variable mein rakhna), toh `return` chahiye:

```python
def add(num1, num2):
    return num1 + num2

a = add(10, 20)     # a = 30 ✅ store ho gaya
print(a)
```

Farak samajh:

- `print()` sirf screen pe dikhata hai — value gayab
- `return` value **wapas deta hai** caller ko — variable mein store kar sakte ho, aage use kar sakte ho

Rule simple hai: agar value aage kaam aayegi toh `return`, sirf dikhana hai toh `print`.

## Default Values — Optional Arguments

Parameter ko default value de sakte ho — jab argument na do toh default chalega:

```python
def greet(name="Babu"):
    print("Hello " + name)

greet()             # Hello Babu  (default use hua)
greet("Rahul")      # Hello Rahul (diya hua use hua)
```

Yeh tab useful hai jab kisi parameter ka common value ho jo har baar dena bekaar lage.

## Nutshell

Function = statements ka group for one task — ek baar `def` karo, jitni baar chaaho call karo. **Parameter** define time ka placeholder, **argument** call time ki actual value — count match honi chahiye. `return` value wapas deta hai (store/use karne layak), `print` sirf dikhata hai. Default values se arguments optional ban jaate hain.

## What It Is NOT

- ❌ **Function banana = extra kaam nahi, bachat hai.** Shuru mein lagta hai "itna formal kyun?" — par jis din 1000-line program mein same logic 10 jagah chahiye hoga, us din function hi bachayega.
- ❌ **`return` aur `print` same cheez nahi hain.** Print karke value kho gayi; return karke value haath mein hai. Backtesting mein results hamesha return karke store karte hain.
- ❌ **Function ke andar sab kuch daalna zaroori nahi.** Ek function = ek kaam. Average nikalta hai toh average hi nikale — input lena, format karna, save karna sab usi mein mat thopo.
