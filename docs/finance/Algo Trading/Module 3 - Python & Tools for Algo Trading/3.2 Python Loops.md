# 3.2 Python Loops (while & for)

## Loop Kya Hota Hai

**Loop = repetition** — ek hi kaam baar-baar karna, bina code repeat kiye:

```python
# bekaar tareeka
print(1)
print(2)
print(3)
# ... aise 100 lines

# sahi tareeka = loop (2 line)
```

Bina loop ke 100 lines likhni padengi. Loop mein wahi kaam 2-3 lines mein ho jaata hai.

Python mein do tarah ke loops hote hain — **while** aur **for**.

## While Loop — "Jab Tak"

While loop bolta hai: *"jab tak condition true hai, tab tak chalte raho."*

```python
i = 0
while i < 10:
    print(i)
    i = i + 1      # increment zaroori!
```

Kaise chalta hai, step by step:

1. `i = 0` se shuru
2. Check: kya `i < 10` hai? Haan (0 < 10) → andar jao
3. Print karo `i` (0 dikhega), phir `i = i + 1` → ab i = 1
4. Wapas check: kya `1 < 10` hai? Haan → phir se chalao
5. Jab `i = 10` ho jayega → condition false → loop exit

Aur yahan **sabse common beginner mistake** hai — increment (`i = i + 1`) bhool jaana. Increment nahi likha toh `i` hamesha 0 hi rahega, condition hamesha true rahegi, aur loop **kabhi nahi rukega**. Isko **infinite loop** kehte hain — program hang ho jayega. Agar kabhi galti se infinite loop chal jaye, `Ctrl + C` dabake roko.

Chhota sa variation: agar 10 tak print karna hai including 10, toh `while i <= 10:` likho.

## For Loop & range()

For loop mostly `range()` ke saath use hota hai:

```python
for i in range(1, 11):     # 1 se 10 tak (11 exclude)
    print(i)
```

`range()` ke andar 3 values aa sakti hain: `range(start, stop, step)`. Examples se samajh:

| Code | Output |
|---|---|
| `range(1, 11)` | 1,2,3...10 (11 exclude) |
| `range(1, 11, 2)` | 1,3,5,7,9 (step 2 — odd numbers) |
| `range(11)` | 0,1,2...10 (start default 0) |

Yahan wohi purana rule wapas aata hai jo strings mein dekha tha — **stop value hamesha exclude hoti hai (n-1 tak jaata hai).** `range(1, 11)` mein 11 include nahi hota.

Range ko aankhon se dekhna ho toh list mein convert kar sakte ho:

```python
print(list(range(1, 11)))   # [1, 2, 3, ..., 10]
```

### For Loop Sirf Numbers Pe Nahi

For loop kisi bhi list par seedha chal sakta hai — har item ek-ek karke milta hai:

```python
L = ["Rahul", "Abdul", "Heman"]
for i in L:
    print(i)        # teeno naam ek-ek karke print honge
```

Yeh backtesting mein roz kaam aayega — candle data ki list pe loop laga ke har candle process karni hogi.

## Nutshell

Loop = repetition — 100 line code ki jagah 2 line. **While:** `while condition:` jab tak true, tab tak chalega — increment bhoola toh infinite loop. **For:** `for i in range(start, stop, step):` — stop hamesha excluded. Range ke bina bhi chalega — kisi bhi list pe directly for loop laga sakta hai.

## What It Is NOT

- ❌ **Loop = sirf numbers print karne ka tool nahi.** Asli use backtesting mein hai — hazaron candles pe same logic run karna.
- ❌ **While har jagah better nahi hota.** Jab iterations ki count pata hai (jaise 1-100), for + range cleaner hai. While tab use karo jab condition pe depend hai.
- ❌ **Infinite loop = computer kharab nahi hua.** Bas increment bhool gaye ho — `Ctrl + C` se rok lo, fix karo, re-run.

2. `range(1, 11)` aur `range(1, 11, 2)` kya output dete hain?

<details>
<summary>Sample Jawab</summary>

**Jawab:** `range(1, 11)` deta hai 1,2,3,...,10 — start 1 included, stop 11 excluded (n-1 rule). `range(1, 11, 2)` mein teesra argument step hai — 1 se shuru, har baar 2 jump: 1,3,5,7,9. Step negative bhi ho sakta hai ulte counting ke liye.

</details>

<details>

Jaise `L = ["a", "b", "c"]` pe `for x in L:` chalaya toh pehle x="a", phir "b", phir "c". Backtesting mein yehi pattern roz use hoga — candles ki list pe loop laga ke har candle ka indicator calculate karna.
