# 3.2 Python Loops (while & for)

## There Are Two Types of Loops

```text
while → "As long as this is true, keep doing"
for   → "Do this one by one for ALL these items"
```

Both will be understood. First `while`.

## While Loop — The "As Long As" One

Real life example:

> **As long as** stomach isn't full, keep eating.
> Stomach full? Stop. Done.

In Python exactly like this:

```python
count = 1                    # Step 1: start counting

while count <= 5:            # Step 2: as long as count is less/equal 5...
    print(f"Count: {count}") # Step 3: ...keep printing
    count = count + 1        # Step 4: increase count!
```

Output:

```text
Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
```

Printed 5 times. We wrote only 4 lines. 😎

### Line-by-Line Understanding

```python
count = 1
```

Made a box, name `count`, put 1 inside.

This box keeps the counting.

```python
while count <= 5:
```

Python asks every round: *"is count still less than or equal to 5?"*

- Yes? → run the code inside, ask again
- No? → loop ENDED, move ahead

(`<=` means: "less OR equal." This is called a condition.)

```python
    print(f"Count: {count}")
```

Show current count each round.

(Notice indentation — `print` is a bit INSIDE. This shows it's inside the loop.)

```python
    count = count + 1
```

**Most important line!**

Take value from box (`count`) → add 1 → put back in same box.

`1` → `2` → `3` → `4` → `5`...

And when it became `6` → condition failed (`6 <= 5` false) → loop stopped.

## ⚠️ Biggest Beginner Trap — Infinite Loop

If that last line (`count = count + 1`) was forgotten?

```python
count = 1
while count <= 5:
    print("Count: ...")
    # count not increased at all! 😱
```

What happens?

`count` stays `1` always.

Condition stays true always.

Print keeps going... **FOREVER.**

```text
Count: ...
Count: ...
Count: ...
(infinite! 💀)
```

This is called an **infinite loop** — loop never stops.

To stop, press `Ctrl + C` in terminal.

**Golden rule: inside a while loop always keep something that will one day FAIL the condition.**

## Wait — Did While Make Sense?

```text
✅ while = "as long as condition is true, repeat"
✅ Python checks condition every round
✅ The count + 1 line is what ENDS the loop
✅ Forgot it? = infinite loop 💀
```

Now the second loop — the more popular one.

## For Loop — For a List

While is a bit raw, right? Had to make the counting box yourself, increase it yourself.

**For loop does all this itself.**

Real life example:

> There are 5 rotis on the plate. Apply ghee on each one, one by one.
> Rotis finished? Done.

In Python:

```python
for i in range(1, 6):
    print(f"Ghee applied on Roti #{i}")
```

Output:

```text
Ghee applied on Roti #1
Ghee applied on Roti #2
Ghee applied on Roti #3
Ghee applied on Roti #4
Ghee applied on Roti #5
```

5 lines output — we wrote only 2!

### Line-by-Line

```python
for i in range(1, 6):
```

```text
for        → "for each item"
i          → small box, new value comes each round
range(1,6) → list of numbers: 1, 2, 3, 4, 5
```

Meaning: *"put each number from 1 to 5 in i, one by one, and run the code inside each time."*

Python itself:
- makes the count
- increases it
- stops when list ends

Zero tension. That's why people prefer for.

### ⚠️ The Biggest Secret of range

Look carefully:

```python
range(1, 6)   →  1, 2, 3, 4, 5
```

Where did 6 go?! We wrote 6!

**Rule: in range(start, stop), the STOP number is NOT INCLUDED.**

```text
range(1, 6)  →  1 to 5      (not 6!)
range(0, 3)  →  0, 1, 2     (not 3!)
range(1, 11) →  1 to 10     (not 11!)
```

This rule will feel odd right now. But remember — **stop is always EXCLUDED.**

Ahead in backtesting its use will come and then it'll become clear that this design is smart.

For now: **think +1.** `range(1, 6)` = "1 to 6-1=5."

## Wait — While vs For

```text
while → runs on condition ("as long as...")
        Had to manage counting box yourself

for   → runs on list/items ("for each...")
        Python manages everything itself ✅
```

Simple rule: **if there's a list of items, use FOR.** If condition-based, use WHILE.

## For Loop Not Only on Numbers!

Works on every letter of text too:

```python
for letter in "HELLO":
    print(letter)
```

Output:

```text
H
E
L
L
O
```

Each letter came into `letter` box one by one, and printed.

Ahead this will also run on candle data — "check each candle one by one." That's what backtesting is! (We'll meet in Module 4.)

## One More Useful Thing — break

Sometimes you need to stop the loop midway.

> Eating rotis, stomach got full? You stop midway. Don't finish the whole plate.

```python
for i in range(1, 11):
    if i == 5:
        print("Enough! Stomach full")
        break
    print(f"Roti #{i}")
```

Output:

```text
Roti #1
Roti #2
Roti #3
Roti #4
Enough! Stomach full
```

```text
break → stop the loop RIGHT THERE, ignore rest
```

(Small note: `if i == 5` is a new concept — "if". This will come in detail in next files. For now understand: *"if i is 5, then..."*)

## Nutshell

Loop = machine for repeating. **While:** "as long as condition is true" — counting box must be increased yourself or infinite loop (stop with Ctrl+C). **For:** automatic on range/list — `range(1,6)` = 1,2,3,4,5 (**stop EXCLUDED**, always!). Works on strings/lists too. `break` = stop midway. Backtesting = for loop over candles — just a bigger version of this.

## What It Is NOT

- ❌ **Loop ≠ copy-pasting same code.** Copy-paste is hard to change; in loop change ONE place, applies to all rounds. That's why loop is the professional way.
- ❌ **6 will come in range(1,6) — NO!** Stop is excluded. This mistake causes off-by-one errors that are hardest to catch. Remember the +1 rule.
- ❌ **While and for are not competitors.** Each has its own job: condition-driven → while, items-driven → for. Both must be known.

1. What's the basic difference between while and for loop?

<details>
<summary>Sample Answer</summary>

**Answer:** While runs on condition — "As long as count <= 5, do." It keeps running as long as condition is true; counting box must be increased by us. For runs on list — "For each in range(1,6), do" — Python itself makes count, increases, stops. If items are there, use for; if only condition, use while.

</details>

2. What numbers will `range(1, 6)` give and what is the stop-excluded rule?

<details>
<summary>Sample Answer</summary>

**Answer:** 1, 2, 3, 4, 5 — not six. Rule: in range(start, stop), start is included, stop is EXCLUDED. So shortcut: goes up to stop-1. Examples: range(0,3) = 0,1,2 | range(1,11) = 1 to 10. Beginner trap is this — to get 5 items write range(1,6), range(0,5) or range(5), learned slowly.

</details>

3. What is an infinite loop, why does it happen, how to stop it?

<details>
<summary>Sample Answer</summary>

**Answer:** Loop that never stops. Happens when while's condition NEVER becomes false — usually because increasing count was forgotten (count = count + 1 line missing), so count stays 1 always and condition stays true. Terminal freezes printing. To stop: Ctrl + C. Prevention: always keep that line in while loop which will fail the condition.

</details>
