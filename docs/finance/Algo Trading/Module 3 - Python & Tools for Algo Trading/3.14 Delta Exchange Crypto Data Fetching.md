## The Twist — Koi Library Nahi, Sirf requests

Ab tak har broker ne apni library di thi (`dhan-hq`, `kiteconnect`, `grow_api`...). Delta ne kuch nahi diya. Uska approach:

> *"Website pe jo data dikh raha hai, uska ek backend API endpoint hai. Seedha us endpoint ko hit karo."*

Jaise browser mein right-click → Inspect karke dekh sakte ho ki page ka data kis URL se aa raha hai — waise hi hum direct us URL ko `requests` library se hit karenge. Yeh web-scraping jaisa concept hai, par legal aur structured (public API endpoint hai).

## Bitcoin Historical Data Fetch Karna

Poora working code dekho:

```python
import requests
import pandas as pd
import time

# Step 1: URL + parameters define karo
url = "https://api.delta.exchange/api/v2/tickers/btcusd/ohlc"
params = {
    "resolution": 300,        # seconds mein — 300 = 5 minute
    "symbol": "BTCUSD",
    "start_time": int(time.time()) - (62 * 24 * 3600),   # 62 din pehle
    "end_time": int(time.time())                          # abhi
}

# Step 2: Fetch
response = requests.get(url, params=params)
raw_data = response.json()

# Step 3: DataFrame banao
candles = raw_data["result"]["candles"]
df = pd.DataFrame(candles, columns=["time", "open", "high", "low", "close", "volume"])

print(df.head())
print(f"Total candles: {len(df)}")
```

Chalao — **4000+ candles** aayengi, roughly 62 din ka 5-minute data. Free mein. Bina account ke.

### Parameters Samajho

| Parameter | Kya Hai | Values |
|---|---|---|
| `resolution` | Timeframe — **seconds mein** | `60` (1min), `300` (5min), `900` (15min) |
| `symbol` | Trading pair | `"BTCUSD"`, `"ETHUSD"` |
| `start_time` / `end_time` | Date range | Unix timestamps |

Do naye concepts notice karo:

- **Resolution seconds mein hota hai** (minutes mein nahi) — 5 minute = 300 seconds
- **Unix timestamp** format — `time.time()` current time deta hai, minus karke past dates banate hain

## Data vs Trading — Ek Important Line

Abhi humne sirf **data fetch** kiya — isliye koi key nahi maangi gayi. Par jab **orders place** karne ho (real trading), tab security chahiye hogi:

| Feature | Data Fetching | Trading |
|---|---|---|
| API Key | ❌ Not needed | ✅ Required |
| Login | ❌ Not needed | ✅ Required |
| IP Whitelist | ❌ Not needed | ✅ Required |
| Signature | ❌ Not needed | ✅ Required |

Trading setup (key, secret, signature generation) aage ke modules mein detail se aayega. Abhi backtesting ka data to mil gaya — free mein.

## Nutshell

Delta Exchange = crypto data ka easiest source. Koi official library nahi — `requests` se seedha API endpoint hit karo: `api.delta.exchange/api/v2/tickers/btcusd/ohlc` with resolution (seconds!), symbol, start/end times. 4000+ candles free mein, bina account. Symbol change karke koi bhi coin — ETHUSD, SOLUSD. Data free, trading ke liye baad mein key+signature chahiye hoga. Golden insight: har broker ka tool alag hai (libraries vs raw requests), par process same hai.

## What It Is NOT

- ❌ **"No official library" matlab API weak nahi hai.** Endpoint fully capable hai — bas packaging nahi di. Khud ka chhota wrapper function likh loge toh wahi library ban jayegi.
- ❌ **Data fetching = trading access nahi.** Bina key ke data milta hai, par order place karne ke liye full auth setup (key + secret + IP whitelist + signature) zaroori hai.
- ❌ **Unix timestamps human dates nahi hote.** `1692748800` jaise numbers aate hain — pandas se readable datetime mein convert kar sakte ho. Confuse mat hona output dekh ke.
