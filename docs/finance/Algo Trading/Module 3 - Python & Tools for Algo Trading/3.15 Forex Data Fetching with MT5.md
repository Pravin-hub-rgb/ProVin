# 3.15 Forex Data Fetching with MT5 Python

## MT5 Kya Hai

**MetaTrader 5** ek popular trading platform hai — forex traders ispe hi zyadatar kaam karte hain. Iska Python library version bhi hai (`MetaTrader5`) jisse tu apne Python code se MT5 ke data tak pahunch sakta hai.

Indian market mein broker APIs use kiye; forex/crypto mein **MT5 se data lena sabse aasaan rasta** hai. Ek baat clear kar loon pehle hi — hum sirf **data fetch** kar rahe hain, trade nahi. `mt5` library ka use abhi sirf data ke liye hoga.

## Requirements — Kya Chahiye

Char cheezein:

1. **MT5 Desktop App** — laptop pe MetaTrader 5 install hona chahiye (MT5.com se free)
2. **MT5 Account** — app mein koi bhi account connected ho (demo chalega!)
3. **Python library:** `pip install MetaTrader5`
4. **Code** — pre-made structure paste karke configure karna hai

Yahan ek naya concept hai jo Indian brokers mein nahi tha: **desktop app chahiye.** MT5 cloud service nahi hai — tere computer pe chalne wala software hai, aur Python usi se connect hota hai.

## Core Functions — Sirf 3 Cheezein

```text
mt5.initialize()   → MT5 app ko open/connect karta hai
mt5.shutdown()     → connection close karta hai
mt5.copy_rates_from_pos(symbol, timeframe, start_pos, count)
                   → historical candles return karta hai
```

Poora flow step by step:

1. **`mt5.initialize()`** — MT5 desktop app se connection banao
2. **Symbol define karo** — `EURUSD`, `USDJPY`, `BTCUSD` — koi bhi pair
3. **Timeframe set karo** — `mt5.TIMEFRAME_M1` (1 min), `M5` (5 min), `H1` (hourly)
4. **`copy_rates_from_pos()`** call karo — past ke N candles mil jaate hain
5. **DataFrame convert** — pandas se analyze ready
6. **`mt5.shutdown()`** — end mein connection band karna mat bhoolna

## Output Mein Kya Aata Hai

MT5 ka data thoda extra rich hota hai:

| Column | Kya Hai |
|---|---|
| `time` | Candle timestamp |
| `open` / `high` / `low` / `close` | OHLC — familiar four |
| `tick_volume` | Trading volume |
| `spread` | Spread value |
| `real_volume` | Actual volume |

Dekha? OHLCV toh wahi hai jo har market mein aata tha (3.8 yaad kar) — bas upar se `spread` aur volume ke do variants bonus mein. Zyada data, koi nuksaan nahi.

Aur symbol change karna? Ek line badlo:

- `EURUSD` ki jagah `USDJPY` — Japanese Yen pairs ka data
- `EURUSD` ki jagah `BTCUSD` — crypto bhi isi se!

Sab symbols ek hi interface se.

## Practical Notes

Kuch cheezein shuru mein hi clear kar doon:

- **Code copy-paste karo.** Scratch se likhne mein time waste hai — ChatGPT se bhi similar template mil jayega. Configuration (symbol, timeframe) teri job hai.
- **Timezone UTC hota hai** data mein — initially dimaag mat lagao, jab backtesting mein time alignment chahiye hoga tab handle karenge.
- **Sirf data ke liye hai.** Live trading ke liye alag setup chahiye — woh future module ka topic.

## Nutshell

Forex/crypto data ka easiest raasta: MT5 desktop app + `pip install MetaTrader5`. Flow: `initialize()` → symbol + `TIMEFRAME_*` define → `copy_rates_from_pos()` → DataFrame → `shutdown()`. Output mein OHLCV + spread + volumes. Symbol badlo toh EURUSD se USDJPY se BTCUSD — sab ek interface se. Poore module ka pattern complete hua: har market ka data, ab backtesting ke liye taiyaar.

## What It Is NOT

- ❌ **MT5 = sirf forex ka tool nahi.** Crypto symbols (BTCUSD) bhi isi se milte hain — multi-market platform hai.
- ❌ **Python se MT5 connect = live trading shuru.** Abhi sirf data read kar rahe ho. Orders bhejne ke liye alag auth aur risk setup chahiye.
- ❌ **Demo account kamzor nahi hota.** Data fetching ke liye demo account bilkul kaafi hai — real money ki zaroorat nahi padti seekhne ke liye.
