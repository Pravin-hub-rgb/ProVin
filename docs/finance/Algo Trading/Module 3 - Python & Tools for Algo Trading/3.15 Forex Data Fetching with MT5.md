## Core Flow — Sirf Teen Functions

```python
import MetaTrader5 as mt5

# STEP 1: Connect
mt5.initialize()

# STEP 2: Data maango
rates = mt5.copy_rates_from_pos("EURUSD", mt5.TIMEFRAME_M5, 0, 500)

# STEP 3: Band karo
mt5.shutdown()
```

Teen functions, teen kaam:

```text
initialize()           → "app se connect ho raha hun"
copy_rates_from_pos()  → "candles do!"
shutdown()             → "kaam khatam, connection band"
```

### copy_rates Ke Parameters

```python
mt5.copy_rates_from_pos(
    "EURUSD",              ← konsa pair/symbol
    mt5.TIMEFRAME_M5,      ← timeframe (M5 = 5-minute)
    0,                     ← kahan se start (0 = ABHI se)
    500                    ← kitni candles chahiye
)
```

Timeframes ke naam:

```text
TIMEFRAME_M1  → 1 minute
TIMEFRAME_M5  → 5 minute
TIMEFRAME_H1  → 1 hour
TIMEFRAME_D1  → daily
```

(M = minutes, H = hours, D = days — simple!)

## Nutshell

MT5 = desktop app + Python bridge (`pip install MetaTrader5`). Flow teen functions: `initialize()` connect, `copy_rates_from_pos(symbol, TIMEFRAME_M5, 0, count)` fetch, `shutdown()` band. Output = OHLCV + bonus spread/volume columns. Forex + crypto dono isi se. Requirements: app installed + demo account connected. ## What It Is NOT

- ❌ **MT5 = sirf forex nahi.** Crypto symbols (BTCUSD) bhi isi se milte hain — multi-market platform hai. Naam forex se juda hai par scope bada hai.
- ❌ **Python-MT5 connect = live trading shuru.** Abhi sirf DATA read ho raha hai. Orders ke liye terminal permissions + order functions + risk setup chahiye — woh alag phase hai (M8).
