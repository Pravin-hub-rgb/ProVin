## Bitcoin Historical Data

```python
import requests
import pandas as pd
import time

# STEP 1: URL + parameters
url = "https://api.delta.exchange/api/v2/tickers/btcusd/ohlc"

params = {
    "resolution": 300,                    # in seconds! 300 = 5 min
    "symbol": "BTCUSD",
    "start": int(time.time()) - 86400,    # 1 day ago (86400 sec)
    "end": int(time.time())               # now
}

# STEP 2: Fetch!
response = requests.get(url, params=params)
data = response.json()

# STEP 3: DataFrame
candles = data["result"]["candles"]
df = pd.DataFrame(candles, columns=["time", "open", "high", "low", "close", "volume"])

print(df.head())
print(f"Total candles: {len(df)}")
```

Output:

```text
      time     open     high      low    close   volume
0  1704082500  42000.0  42100.0  41950.0  42050.0  125.5
...
Total candles: 288
```

## Two New Concepts in Detail

### 1. Resolution — In Seconds!

Indian brokers said minutes ("5minute").

Delta takes **seconds:**

| Resolution | Meaning |
|---|---|
| `60` | 1-minute candles |
| `300` | 5-minute candles (60 × 5) |
| `900` | 15-minute candles |
| `3600` | 1-hour candles |

Crypto runs 24/7 and ultra-short timeframes exist too —

so seconds became universal unit.

### 2. Unix Timestamp

```text
Normal date:   "1 January 2024, 9:15 AM"
Unix time:     1704082500
```

BOTH are SAME moment! Just format different.

Unix = "how many seconds since 1 Jan 1970" — one big number.

Computers process numbers fast, so APIs give this.

Need readable date? Pandas will convert (learn later).

## What It Is NOT

- ❌ **requests.get() looks like browser, isn't browser.** It doesn't render pages, show images — only RAW response. Perfect for APIs (we want raw JSON anyway!), not for websites.
- ❌ **Unix timestamp isn't weird, it's standard.** Every major system (Linux, databases, APIs) uses it. Pandas converts to readable date in one line: pd.to_datetime(df["time"], unit="s") — no need to memorize now.
- ❌ **No-key data ≠ no-security platform.** Only READ-only public data is open. Your account/orders/money are behind full security — trading side will have full auth (keys + IP whitelist + signatures) when that phase comes.

<details>

Reason: crypto 24/7 + ultra-short timeframes (even 10-sec candles exist) — seconds is universal unit. Translation trick: minutes × 60 = seconds for resolution.

3. What is Unix timestamp? Decode example.

<details>
<summary>Sample Answer</summary>

**Answer:** Writing time as ONE NUMBER — "how many seconds since 1 Jan 1970 00:00 UTC." Example: 1704082500 ≈ 1 Jan 2024 ~9:15 AM IST. Why used: computers process numbers fast, no timezone confusion (universal reference), sorting trivial (bigger number = later time). time.time() gives current unix second; subtract to get past dates (-86400 = yesterday).

</details>
