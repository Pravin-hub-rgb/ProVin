## Data Types — Values Ke Types

Soch zindagi ki cheezein:

```text
Paani   → liquid
Pathhar → solid
Hawa    → gas
```

Sab alag TYPE ke hain, treatment alag hota hai.

Waise hi Python mein values ke types hote hain. **Chaar main types** yaad rakho:

### Type 1: Integer (poora number)

```python
age = 21          ← poora number, decimal nahi
candles = 1500
```

Inko bolte hain **int**.

### Type 2: Float (decimal wala number)

```python
price = 2456.75   ← point wala number
```

Inko **float**.

Stock prices hamesha float hi hote hain — 2456.75 jaise.

### Type 3: String (text)

```python
name = "Rahul"    ← quotes mein = text
symbol = "RELIANCE"
```

Inko **string**.

Quotes dekho → string samjho. Simple rule.

### Type 4: Boolean (sirf do values)

```python
is_market_open = True     ← haan
has_position = False      ← na
```

Sirf `True` ya `False`. Kuch aur nahi.

Inko **bool**.

Yeh switch jaisa hai — ON ya OFF. Aur algo trading mein yeh bahut use hoga ("position open hai? True/False").

### Type Check Karne Ka Trick


## Sabse Zaroori Trap — Yahan Sab Phaste Hain

Dhyan se dekho. Yeh example course ke sabse important examples mein se hai.

```python
a = "10"     ← quotes hain = STRING (text)
b = "20"     ← yeh bhi string
print(a + b)
```

Output kya aayega?

`30`? Nahi bhai...

```text
1020
```

😱 Kya hua?!

Simple: `"10"` number NAHI tha — **text** tha (quotes ki wajah se).

Text + text = **jod do** (jaise "Ra" + "hul" = "Rahul").

Isliye "10" + "20" = "1020". Jodna, jama nahi.

### Sahi Tareeka

```python
a = 10      ← bina quotes = asli NUMBER
b = 20
print(a + b)
```

```text
30
```

✅ Ab maths hua!

### Yaad Rakhne Ka Tareeka

```text
Quotes hain?        → text hai → + ka matlab JODDO
Quotes NAHI hain?   → number hai → + ka matlab JAMA
```

Yeh ek line future mein tujhe ghanton ki debugging se bachayegi. Promise.

## F-String — Text Aur Number Milane Ka Jaadu

Ek problem: text aur number ko saath print karna ho toh?

```python
name = "Rahul"
age = 21
print("Mera naam hai " + name + " aur age " + age)
```

❌ ERROR! Kyunki text + number jodna Python ko pasand nahi.

Solution: **f-string.** Bas string ke pehle `f` laga do:

```python
print(f"Mera naam hai {name} aur age {age}")
```

```text
Mera naam hai Rahul aur age 21
```

Kaam ho gaya! ✅

Kaise chala:

```text
f"..."          → f lagao string ke pehle
{name}          → curly brackets mein variable likho
                  Python value nikal ke chipka dega
```

Aur maths bhi andar kar sakte ho:

```python
price = 100
qty = 5
print(f"Total: {price * qty}")
```

```text
Total: 500
```

Yeh trick har jagah use hogi aage. Pakka yaad rakhna.

## Bonus — User Se Baat Karna (input)

Ab tak humne values khud likhi code mein.

User se pooch sakte bhi ho:

```python
name = input("Apna naam batao: ")
print(f"Hello {name}!")
```

Chalao:

```text
Apna naam batao: Rahul    ← user ne type kiya
Hello Rahul!
```

```text
input("...")   → user se poocho
name = ...     → jawab dabbe mein rakho
```

Ek choti warning: `input()` hamesha **string** deta hai — number maango ge toh bhi text milega. Number chahiye toh convert karna padta hai (`int()` se) — woh agle files mein aayega.

## Nutshell

Programming = computer ko step-by-step instructions. Python sabse aasan aur trading ki favourite language. `print()` screen pe dikhata hai. Variables = labelled dabbey jo values rakhte hain (aur badal sakte hain). Chaar types: int (poora number), float (decimal), string (quotes wala text), bool (True/False switch). Sabse bada trap: quotes wala "10" text hai, number nahi — isliye "10"+"20"="1020". f-string se text aur number saath print karte hain: `f"Total: {price*qty}"`.

## What It Is NOT

- ❌ **Programming = maths ka genius hona zaroori nahi.** Jodna-ghatana aati hai? Kaam chalega. Logic zyada matter karti hai, calculations kam.
- ❌ **Variable = permanent nahi.** Dabbe mein nayi value daali toh purani ud gayi — yeh feature hai, bug nahi.
- ❌ **"10" aur 10 same cheez NAHI.** Pehla string (text), doosra int (number). Python ke liye dono alag species hain. Yeh ek line samajh li toh aadhi beginner errors khatam.
