## Variables — The Box That Holds Value

Remember school bag? One pocket has tiffin, other has pencil.

Everything has its own place — and a name (which pocket holds what).

**Variable is exactly like this:**

> Variable = a labelled box in which you keep a value

```python
age = 21
```

This line means:

```text
age    → box's name (you gave the name)
=      → "put this in" sign
21     → value kept inside the box
```

Meaning: *"Python, make a box named `age`, put 21 in it."*

Now whenever you write `age`, Python will understand 21:

```python
print(age)
```

```text
21
```

Pulled value from `age` box and showed it.

### The Box Can Change

```python
price = 100
print(price)     # 100

price = 150      # put new value
print(price)     # 150 — old one gone!
```

Same box, value inside changed. Old value GONE.

### Two-Three Boxes Together

```python
name = "Rahul"       # text box
age = 21             # number box
city = "Mumbai"      # another text box
```

Each variable does different work.

And yes — **you have to give the name yourself**, anything:

```python
box1 = 10          ✅ works
my_price = 99      ✅ good — meaningful name
x = 5              ✅ works, but what does x mean?
```

Tip: **give meaningful names.** You'll thank yourself a month later.

## Data Types — Types of Values

Think of life's things:

```text
Water   → liquid
Stone   → solid
Air     → gas
```

All different TYPES, treatment is different.

Similarly Python has types of values. Remember **four main types**:

### Type 1: Integer (whole number)

```python
age = 21          ← whole number, no decimal
candles = 1500
```

These are called **int**.

### Type 2: Float (decimal number)

```python
price = 2456.75   ← number with point
```

These are **float**.

Stock prices are always float — like 2456.75.

### Type 3: String (text)

```python
name = "Rahul"    ← in quotes = text
symbol = "RELIANCE"
```

These are **string**.

See quotes → string. Simple rule.

### Type 4: Boolean (only two values)

```python
is_market_open = True     ← yes
has_position = False      ← no
```

Only `True` or `False`. Nothing else.

These are **bool**.

This is like a switch — ON or OFF. And in algo trading this will be used a lot ("is position open? True/False").

### Trick to Check Type

You can ask what type something is:

```python
print(type(price))
```

```text
<class 'float'>
```

Python will tell you.

## The Most Important Trap — Here Everyone Gets Stuck

Look carefully. This is one of the most important examples in the course.

```python
a = "10"     ← quotes = STRING (text)
b = "20"     ← this is also string
print(a + b)
```

What will be the output?

`30`? No brother...

```text
1020
```

😱 What happened?!

Simple: `"10"` was NOT a number — it was **text** (because of quotes).

Text + text = **join them** (like "Ra" + "hul" = "Rahul").

So "10" + "20" = "1020". Joining, not adding.

### Correct Way

```python
a = 10      ← without quotes = real NUMBER
b = 20
print(a + b)
```

```text
30
```

✅ Now math happened!

### Remember Like This

```text
Quotes?        → text → + means JOIN
No quotes?     → number → + means ADD
```

This one line will save you hours of debugging in the future. Promise.

## F-String — The Magic to Mix Text and Number

One problem: what if text and number need to be printed together?

```python
name = "Rahul"
age = 21
print("My name is " + name + " and age " + age)
```

❌ ERROR! Because text + number joining isn't liked by Python.

Solution: **f-string.** Just put `f` before the string:

```python
print(f"My name is {name} and age {age}")
```

```text
My name is Rahul and age 21
```

Done! ✅

How it worked:

```text
f"..."          → put f before string
{name}          → put variable in curly brackets
                  Python pulls value and pastes it
```

And you can do math inside too:

```python
price = 100
qty = 5
print(f"Total: {price * qty}")
```

```text
Total: 500
```

This trick will be used everywhere ahead. Remember it for sure.

## Bonus — Talking to User (input)

So far we wrote values ourselves in code.

You can also ask the user:

```python
name = input("Tell your name: ")
print(f"Hello {name}!")
```

Run:

```text
Tell your name: Rahul    ← user typed
Hello Rahul!
```

```text
input("...")   → ask the user
name = ...     → keep answer in box
```

Small warning: `input()` always returns a **string** — even if you ask for a number, you'll get text. If you need a number, you have to convert it (`int()` etc.) — that comes in later files.

## Nutshell

Programming = step-by-step instructions to computer. Python is the easiest and trading's favourite language. `print()` shows on screen. Variables = labelled boxes that hold values (and can change). Four types: int (whole number), float (decimal), string (quoted text), bool (True/False switch). Biggest trap: quoted "10" is text, not number — that's why "10"+"20"="1020". f-string mixes text and number: `f"Total: {price*qty}"`.

## What It Is NOT

- ❌ **Programming doesn't require being a math genius.** Can add-subtract? Enough. Logic matters more, calculations less.
- ❌ **Variable is not permanent.** Put new value in box, old one is gone — this is a feature, not a bug.
- ❌ **"10" and 10 are NOT the same thing.** First is string (text), second is int (number). For Python both are different species. Understand this one line and half of beginner errors disappear.
