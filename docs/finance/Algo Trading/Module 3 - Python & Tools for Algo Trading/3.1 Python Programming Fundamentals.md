# 3.1 Python Programming Fundamentals

## Programming Kya Hota Hai?

Simple definition: **programming = computer ko instructions dena, uski language mein.**

Tujhe Hindi/English aati hai, dost samajh jaata hai. Computer ko Hindi nahi aati — use **Python** jaisi language chahiye. Tu Python mein instruction likhega, computer wahi karega. Bas yehi programming hai.

Aur Python hi kyun? Teen reasons:

- Algo trading ke liye **sabse easy aur effective** language hai
- **Badi community** — koi bhi problem ho, solution online mil jayega, free resources bharpur hain
- **Reuse** — ek baar likho, baar-baar call karo (functions wali file mein detail dekhenge)

## Setup — Python Aur VS Code

Do cheezein install karni hain:

1. **Python** — YouTube pe search kar: `install python in windows 11` (ya Mac ke liye)

Ek rule yaad rakh: **hamesha usi folder ke andar kaam karo** taaki saari files sahi jagah save hon.

### File Extension Kya Hoti Hai

File ka extension batata hai wo kis type ki hai:

- `.py` = Python file
- `.txt` = text file
- `.png` / `.jpg` = image
- `.mp3` / `.mp4` = audio/video

Humara saara code `.py` files mein jayega — isse computer ko pata chalta hai "yeh Python code hai."

## Pehla Code

Tradition hai duniya ki — har programmer ki shuruaat isi se hoti hai:

```python
print("Hello World")
```

`Ctrl + S` se save karo, phir Run button dabao → terminal mein output aa jayega. `print()` ke andar jo bhi likhoge, as-it-is screen pe dikhega.

Ek cheez dhyan rakh — **quotes lagana zaroori hai.** Bina quotes likhne pe error aayega. Aur `#` se shuru hone wali line **comment** hoti hai — Python use ignore kar deta hai. Comments isliye likhte hain ki ek mahine baad jab code wapas kholega, toh samajh aaye ki yeh line kya kar rahi thi.

## Variables — Value Ka Dabba

Variable = ek container jo value store karta hai. Jaise ghar mein dabbe mein saamaan rakhte ho, waise variable mein value rakhte ho:

```python
a = 10
name = "Rahul"
print(a)      # 10
print(name)   # Rahul
```

Yahan `a` dabbe mein `10` pada hai, `name` dabbe mein `"Rahul"`.

### Data Types — 5 Types

| Type | Naam | Example |
|---|---|---|
| Integer | `int` | `10`, `1000` |
| String | `str` | `"hello"` |
| Float | `float` | `10.2` |
| Boolean | `bool` | `True` / `False` |
| None | `NoneType` | `None` |

Ek trap hai jo beginners ko pakadti hai — `"10"` aur `10` alag cheezein hain! Quotes ke andar wala string hai, bina quotes wala integer. `type()` function se check kar sakte ho:

```python
print(type(10))     # <class 'int'>
print(type("10"))   # <class 'str'>
print(type(10.2))   # <class 'float'>
```

### Variable Ke Naam Ke Rules

- Letters, numbers, underscore allowed — `data1`, `my_name` ✅
- Space ki jagah underscore: `my_name` ✅
- Number se start mat karo: `1data` ❌
- Special characters nahi: `@name`, `#name` ❌
- Space nahi: `my name` ❌

## Operators — Math Aur Comparisons

4 tarah ke operators hote hain:

**Arithmetic** (`+ - * / %`) — math ke liye. `%` wala special hai: remainder deta hai. `10 % 2` = `0` kyunki 10 ko 2 se divide karne pe remainder zero bachta hai.

**Assignment** (`=`, `+=`, `-=`) — value assign karne ke liye. Shortcut: `a += 10` ka matlab `a = a + 10`.

**Comparison** (`==`, `>`, `<`, `>=`, `<=`) — True/False return karta hai:

```python
print(10 == 10)    # True
print(100 > 120)   # False
```

**Logical** (`and`, `or`, `not`) — conditions combine karne ke liye.

Sabse zaroori baat jo half beginners ko confuse karti hai: **`=` assignment hai, `==` equality check hai.** `x = 5` matlab x ke dabbe mein 5 daal do. `x == 5` matlab pooch rahe ho "kya x 5 hai?" — jawab True ya False.

## Input Aur Type Casting

`input()` se user se data maangte hain:

```python
name = input("Apna naam batao: ")
```

Lekin ek catch hai — **`input()` by default string leta hai.** Numbers maange bhi toh string hi degi. Dekh:

```python
num1 = input("Enter number 1: ")
num2 = input("Enter number 2: ")
print(num1 + num2)    # "10" + "20" = "1020" ❌ add nahi hua, join hua!
```

Isliye numbers ke liye **type casting** karni padti hai — ek type ko doosre mein convert karna:

```python
num1 = int(input("Enter number 1: "))
num2 = int(input("Enter number 2: "))
print(num1 + num2)    # ab sahi 30 aayega ✅
```

## Strings — Thoda Deep

String likhne ke 3 tarike: single quote `'...'`, double quote `"..."`, triple quote `'''...'''`. Sab chalega.

Ab strings ki asli power — indexing aur slicing:

```python
a = "apple"
print(len(a))     # 5  (kitne characters)
print(a[0])       # a  (pehla character)
print(a[0:3])     # app (index 0,1,2 — 3 include NAHI hota!)
print(a[-1])      # e  (-1 = last character)
```

Do rules pakad lo:

- **Indexing 0 se shuru hoti hai** — computer 1 se ginnna pasand nahi karta
- **Slicing mein stop index exclude hota hai** — `a[0:3]` matlab index 0,1,2 (3 nahi)

Kuch useful string functions:

- `len(a)` — length
- `a.endswith("le")` — last mein "le" hai? → True/False
- `a.count("p")` — "p" kitni baar aaya
- `a.capitalize()` — first letter capital

## Nutshell

Programming = computer ko instructions dena Python mein. Setup: Python + VS Code, `.py` files mein code. Variable = container; 5 data types — int, str, float, bool, None; `"10"` ≠ `10`. Operators 4 tarah ke — arithmetic, assignment, comparison, logical; `=` assign karta hai, `==` poochta hai. `input()` hamesha string deta hai — numbers ke liye `int()` casting. Strings mein indexing 0 se, slicing mein stop excluded, `-1` last character.

## What It Is NOT

- ❌ **Programming = ratta nahi.** Syntax yaad karne se nahi aati — logic sochne se aati hai. Syntax Google/ChatGPT se mil jaata hai.
- ❌ **Error = failure nahi.** Red text aana normal hai — message padho, fix karo, re-run karo. Har programmer ka daily routine hai.
- ❌ **Python sirf algo trading ke liye nahi hai** — web development, data science, machine learning sab mein use hota hai. Tu bas apne kaam ke liye seekh raha hai.
