## List vs Array — This is NumPy's Point

You've seen lists:

```python
prices = [100, 200, 300]
```

Fine... but one problem: list is **slow** on big data.

NumPy's **array** = same thing, but supercharged:

```python
import numpy as np

prices = np.array([100, 200, 300])
print(prices)
print(type(prices))
```

```text
[100 200 300]
<class 'numpy.ndarray'>
```

```text
np.array([...])    → converted list to array
ndarray            → "n-dimensional array" — array's full name
```

Looks same! So what's the difference?

## Difference #1 — One Command on Entire Data

If each number in list must be doubled:

```python
# List way (tiring):
prices = [100, 200, 300]
new_list = []
for p in prices:
    new_list.append(p * 2)
print(new_list)
```

```text
[200, 400, 600]
```

Wrote loop, managed counting...

In array? See:

```python
# Array way (relaxed):
arr = np.array([100, 200, 300])
print(arr * 2)
```

```text
[200 400 600]
```

ONE LINE. 😎

Wrote `arr * 2` and array itself doubled EVERY element.

This is called **vectorized operation** — "operation on entire group at once."

### Analogy

Teacher says to class of 30 kids:

```text
Slow way:   "Rahul multiply by 2" → "Priya multiply by 2" → one by one...
Fast way:   "EVERYONE multiply by 2!" → all did at once
```

Vectorized = second way. One instruction, entire group executes.

## Difference #2 — Speed (Matters on Big Data)

"But my data is small, list will work too?"

Will work now. But in trading:

```text
1 year of 1-min data = ~75,000 candles
5 years of             = ~3,75,000 candles
```

Process that much data with loop → seconds.

With array? Milliseconds.

NumPy is built on C language underneath — which is very fast. That's why they say "numpy is fast."

And pandas (next file!) is built on top of numpy. Chain understand:

```text
C language (fastest)
    ↑
numpy (fast maths)
    ↑
pandas (tables) ← our main tool
```

## One-Two Useful Things

```text

**Biggest / smallest:**

```

See the pattern?

```text

```

## Nutshell

Jupyter = cell-based notebook, run with `Shift + Enter`. Trading's 3 libraries: pandas (tables ⭐), numpy (fast maths), matplotlib (graphs). `import numpy as np` — np nickname is convention. `np.array([...])` = supercharged list. Superpower: vectorized operations — `arr * 2` on entire data at once (teacher's "EVERYONE do it!" style). On big data loop vs array = seconds vs milliseconds. `.mean()`, `.max()` etc tools built-in.

## What It Is NOT

- ❌ **NumPy is not tables.** It handles flat lines/boxes of numbers. Tables with column names (like candle data) = pandas's job — next file!
- ❌ **List isn't useless.** For small mixed-data work list is fine (`["RELIANCE", 100, True]`). Make array when ONLY numbers and speed/performance matter.
- ❌ **Vectorized ≠ magic, it's design.** Optimized loops in C-code run inside — you just don't have to write them. Understand: "one instruction, all elements."

2. Difference between list and numpy array? With example?

<details>
<summary>Sample Answer</summary>

**Answer:** Both hold values, but on array ONE command runs on entire data (vectorized). Doubling in list = for-loop + append + new list (3 steps). In array = just `arr * 2` (1 step). And speed: array is C-based, gunna faster than loop on big data. Rule: pure numbers + big data → array; mixed/small stuff → list.

</details>

3. "Teacher telling class at once" analogy is for which concept?

<details>
<summary>Sample Answer</summary>

**Answer:** Vectorized operation. Slow way: teacher tells each kid individually "multiply your number by 2" (loop over elements). Fast way: "EVERYONE multiply your number by 2" — one instruction, all execute. In code: `arr * 2` — array applies operation on each element itself. No need to write loop. This is secret of both numpy/pandas readability + speed.

</details>

<details>
