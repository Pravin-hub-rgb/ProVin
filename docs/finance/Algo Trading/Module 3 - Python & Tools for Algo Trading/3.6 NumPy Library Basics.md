## NumPy Fast Kyun Hai? — List vs Array

Asli sawaal yeh hai: jab Python list already hai, toh NumPy array ki zaroorat kyun?

| Python List | NumPy Array |
|---|---|
| Flexible but **slow** | **Fast** (C language mein built) |
| Har element alag pointer se store | Continuous memory block |
| Loop lagana padta hai | **Vectorized** operations (no loop) |
| Math manually likhni padti hai | Built-in math functions |

Simple words mein:

- Python list har element ko alag jagah rakh ke pointer se link karti hai — flexible hai par memory zyada khaati hai aur slow hai
- NumPy array saara data ek continuous block mein rakhta hai aur C-speed pe compute karta hai

Aur backtesting mein exactly wahi chahiye — hazaron candles ke prices pe calculations, seconds mein. Speed = NumPy.

## Arrays Banana

```python
import numpy as np

arr1 = np.array([1, 2, 3])            # 1D array
arr2 = np.array([[1, 2, 3], [4, 5, 6]])   # 2D array
print(type(arr1))                      # <class 'numpy.ndarray'>
```

Rules simple:

- `np.array()` ke andar list do → 1D array banega
- List ke andar list do → 2D array banega (jaise table)
- Type hamesha `numpy.ndarray` aayega

3D array bhi hota hai par rarely use hota hai — abhi 1D aur 2D kaafi hain.

Wohi kaam Python list se bhi ho sakta hai, sawaal speed ka hai. Jab hazaron values pe math karni ho, NumPy faster + memory efficient hai — bas.

## Nutshell

Backtesting ki 3 libraries: pandas (data), numpy (compute), matplotlib (graphs). Code likhna Jupyter Notebook (.ipynb) mein — cell likho, Shift+Enter run. `pip install numpy` → `import numpy as np`. NumPy fast hai kyunki C-based, continuous memory, vectorized operations — loop ki zaroorat nahi. `np.array([1,2,3])` se array banta hai, type `numpy.ndarray`.

## What It Is NOT

- ❌ **NumPy = pandas ka replacement nahi.** Dono alag kaam karte hain — numpy computing karta hai, pandas data manage karta hai (agli file). Aur mazedaar baat — pandas ke andar NumPy hi chal raha hota hai.
- ❌ **Har jagah NumPy zaroori nahi.** Real code mein sirf ~10% hissa numpy hota hai. Simple counting/printing ke liye normal list hi kaafi hai. Jab bulk math aaye tab numpy.
- ❌ **Vectorized = koi magic function nahi.** Matlab bas itna hai — loop manually likhne ki zaroorat nahi, operation poore array pe ek saath apply hota hai.
