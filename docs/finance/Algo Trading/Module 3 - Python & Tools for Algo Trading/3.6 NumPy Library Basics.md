## List vs Array — Yahi Hai NumPy Ka Point

Tune lists dekhi hain:

```python
prices = [100, 200, 300]
```

Theek hai... par ek problem: list **dheemi** hai bade data pe.

NumPy ka **array** = same cheez, par supercharged:

```python
import numpy as np

prices = np.array([100, 200, 300])
print(prices)
print(type(prices))
```

```text
[100 200 300]
<class 'numpy.ndarray'>
```

```text
np.array([...])    → list ko array mein convert kiya
ndarray            → "n-dimensional array" — array ka full naam
```

Dikhne mein same! Toh farq kya?

## Farq #1 — Array Pe EK Command, Poore Data Pe

List mein har number ko double karna ho toh:

```python
# List wala tareeka (thakan wala):
prices = [100, 200, 300]
new_list = []
for p in prices:
    new_list.append(p * 2)
print(new_list)
```

```text
[200, 400, 600]
```

Loop likha, khud ginti sambhali...

Array mein? Dekho:

```python
# Array wala tareeka (aaram wala):
arr = np.array([100, 200, 300])
print(arr * 2)
```

```text
[200 400 600]
```

EK LINE. 😎

`arr * 2` likha aur array ne KHUD apne HAR element ko double kar diya.

Isko bolte hain **vectorized operation** — "poore group pe ek saath operation."

### Analogy

Teacher class mein 30 bachcho se bole:

```text
Slow way:   "Rahul 2 gunna kar" → "Priya 2 gunna kar" → ek-ek karke...
Fast way:   "SAB LOG 2 GUNNA KARO!" → sabne ek saath kar liya
```

Vectorized = doosra tareeka. Ek instruction, poora group execute.

## Farq #2 — Speed (Bade Data Pe Matter Karta Hai)

"Par mera toh chota data hai, list bhi toh chalegi?"

Abhi chalega. Par trading mein:

```text
1 saal ka 1-min data = ~75,000 candles
5 saal ka            = ~3,75,000 candles
```

Itna data loop se process karoge toh seconds lagenge.

Array se? Milliseconds.

NumPy andar se C language pe bana hai — jo bahut tez hai. Isliye "numpy fast hai" bolte hain.

Aur pandas (agli file!) numpy ke upar hi bana hai. Chain samjho:

```text
C language (sabse fast)
   ↑
numpy (fast maths)
   ↑
pandas (tables) ← humara main tool
```

## Ek Do Useful Cheezein

```python
arr = np.array([10, 20, 30, 40])
```

**Average:**

```python

```

```text
25.0
```

**Sabse bada / chota:**

```python
print(arr.max())    # 40
print(arr.min())    # 10
```

Dekha pattern?

```text
array.tool()   → array khud apne baare mein bata raha hai
```

Yeh functions-array wala pattern agle files mein har jagah aayega.

## Ruk — NumPy Ka Saar

```text
✅ import numpy as np   → nickname np
✅ np.array([..])       → list se array
✅ arr * 2              → poore array pe ek command (vectorized!)
✅ .mean(), .max(), .min() → ready-made tools
✅ Reason: speed on BIG data
```

## Nutshell

Jupyter = cell-based notebook, `Shift + Enter` se run. Trading ki 3 libraries: pandas (tables ⭐), numpy (fast maths), matplotlib (graphs). `import numpy as np` — np nickname convention hai. `np.array([...])` = supercharged list. Superpower: vectorized operations — `arr * 2` poore data pe ek saath (teacher ka "SAB karo!" style). Bade data pe loop vs array = seconds vs milliseconds. `.mean()`, `.max()` jaise tools built-in.

## What It Is NOT

- ❌ **NumPy = tables nahi.** Woh numbers ki flat lines/boxes handle karta hai. Tables with column names (candle data jaisi) = pandas ka kaam — agli file!
- ❌ **List useless nahi ho gayi.** Chote mixed-data kaam ke liye list theek hai (`["RELIANCE", 100, True]`). Array jab banao jab SIRF numbers ho aur speed/performance matter kare.
- ❌ **Vectorized = magic nahi, design hai.** Andar C-code optimized loops hi chalte hain — bas tujhe likhne ki zaroorat nahi padti. Samajh lo: "ek instruction, sab elements."
