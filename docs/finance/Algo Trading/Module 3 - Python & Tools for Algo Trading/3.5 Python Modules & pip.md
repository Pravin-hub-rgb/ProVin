Ab tak tu sab kuch scratch se likh raha tha. Par soch — duniya mein lakhs of developers hain jinhone already woh code likh rakha hai jo tujhe chahiye. Math functions, data tools, sab ready hai. Usko dobara likhne ka time waste kyun kare? **Modules** isi problem ka solution hain — dusre ka likha code, tera reuse.

# 3.5 Python Modules & pip

## Module Kya Hota Hai

**Module = bunch of Python code** jo kisi aur ne likha hai aur hum **import** karke use karte hain.

Andar se aisa hota hai:

```
Tu likhta hai:   my_func()        # tere liye 1 line
Uske peeche:     1000 lines ka code jo kisi aur ne pehle se likh rakha
```

Ek confusion yahan clear kar doon — **module, package, library** — teeno same cheez ke naam hain. Log interchangeably bolte hain. Confuse mat hona.

## Built-in vs External Modules

Do categories hain:

| Type | Install karna padta? | Example |
|---|---|---|
| **Built-in** | ❌ Python ke saath hi aate hain | `math`, `random` |
| **External** | ✅ `pip install` se install karna padta | `pandas`, `numpy`, `sklearn` |

Built-in modules ko sirf `import` karna hota hai — kuch install nahi. External modules ko pehle install karna padta hai.

## pip — Package Installer

`pip` wo tool hai jo external modules install karta hai:

```bash
pip install pandas
pip install pygame
```

Do baatein:

- Agar module already installed hai toh `requirement already satisfied` ka message aayega — koi dikkat nahi, bas confirm ho gaya.
- Mac users: `pip3 install <module>` try karo agar plain `pip` kaam na kare.

Aur haan — `uv` bhi yaad hai 1.1 se? Wohi kaam karta hai, bas faster. Dono mein se jo setup ho, chalega.

## Module Kaise Use Karte Hain — import

```python
import math
print(math.sqrt(4))       # 2.0
print(math.factorial(5))  # 120
```

Pattern simple hai: **`import` karo, phir dot notation se use karo** — `module_name.function()`.

Do dhyan dene wali baatein:

- Exact name likhna padta hai — `math` sahi hai, `Math` nahi. Case-sensitive hai.
- Module ke andar hazaron functions hote hain — dot lagane pe sab accessible ho jate hain (VS Code khud suggestions dikha dega).

### Nickname — Alias

Lambe naam ka shortcut de sakte ho `as` se:

```python
import math as m
print(m.sqrt(16))        # 4.0

import pandas as pd      # industry standard
import numpy as np       # industry standard
```

`pd` aur `np` wale aliases poori industry follow karti hai — tum bhi wahi karo taaki tera code sabko familiar lage.

## Random Module — Ek Practical Example

`random` built-in module hai — random values generate karta hai:

```python
import random

print(random.random())          # 0 se 1 ke beech random float (0.73...)
print(random.randint(1, 10))    # 1 se 10 tak random integer
colors = ["red", "green", "blue"]
print(random.choice(colors))    # list se ek random item
```

Useful functions:

- `random.random()` — 0 se 1 ke beech random float
- `random.randint(a, b)` — a se b tak random integer (dono include)
- `random.randrange(start, stop)` — range mein random (stop exclude)
- `random.choice(list)` — list se ek item randomly
- `random.shuffle(list)` — list ko shuffle kar deta hai


Isi tarah `datetime` (dates/Time), `sklearn` (machine learning), `tensorflow` (deep learning) — sab modules hain, sab isi tareeke se explore kar sakte ho. Self-learning ka superpower yehi hai.

## Nutshell

Module = dusre ka likha code jo import karke use karte ho (module = package = library). Built-in (`math`, `random`) sirf import karo; external (`pandas`, `numpy`) pehle `pip install`. Dot notation se use karo — `module.function()`. Alias industry-standard hai: `pandas as pd`, `numpy as np`. Aur jab bhi naya module mile, ChatGPT prompt se intro + examples le lo.

## What It Is NOT

- ❌ **Module use karna = cheating nahi.** Professional coding mein 90% kaam modules se hota hai. Scratch se sab likhna beginner ki galti hai, badge nahi.
- ❌ **Sab modules built-in nahi hote.** `math`, `random` import-only hain, par `pandas` pehle `pip install` karne padega — warna `No module named 'pandas'` error aayega.
- ❌ **Alias apni marzi se bhi de sakte ho, par standard mat todo.** `import pandas as pd` likhna universal convention hai — apna weird alias doge toh tera code padhne wala confuse hoga.
