# 3.5 Python Modules & pip

## Module Kya Hota Hai?

> **Module = doosre programmers ka likha hua code-pack jo tu apne code mein use kar sakta hai.**

Real-life example:

Tujhe calculator chahiye. Kya khud transistors jod ke banayega?

Nahi — bazaar ka calculator kharido, USE karo.

Waise hi:

```text
Dates ka kaam?        → date module use karo
Maths ke formulas?    → math module
Excel-jaisi tables?   → pandas module (trading mein yehi chalega!)
Graphs banana?        → matplotlib module
```

Lakhs of programmers ne in cheezon ko bana rakha hai — tested, fast, free.

Tu sirf **import** karega aur use karega. Bas.

## Import — Dukaan Se Lao

```python
import math

print(math.sqrt(16))
```

```text
4.0
```

Line-by-line:

```python
import math       ← "math naam ka module LAO yahan"
```

Bas itna. Ab `math` ke saare tools tere paas hain.

```python
math.sqrt(16)     ← "math ke andar se sqrt (square root) nikalo"
                     16 ka square root = 4
```

Pattern yaad rakh:

```text
module_ka_naam.tool_ka_naam()
```

Dabba kholo → tool uthao → use karo.

## Ruk — Abhi Tak Kya Hua?

```text
✅ Module = ready-made code ka pack (dukaan ka samaan)
✅ import math → lao
✅ math.sqrt(16) → use karo
```

Ek problem baaki hai: yeh `math` toh Python ke saath aata hai.

Par `pandas`? Woh dukaan mein nahi — **online store** mein hai!

## pip — Online Store Ka Delivery Boy

**pip = Python ka app store / delivery service.**

Duniya bhar ke programmers ne apne modules banaye aur ek bade online store pe daal diye (usko PyPI bolte hain).

Tujhe jo chahiye, bas order kar:

```bash
pip install pandas
```

Yeh terminal/CMD mein likhte ho (VS Code ke andar wale mein):

```text
pip        → delivery boy ko bulaya
install    → "yeh samaan lao"
pandas     → item ka naam
```

Kuch seconds mein download-install done. ✅

Ab code mein use kar sakte ho:

```python
import pandas          # ab available hai!
```

## Ek Common Problem + Fix

Kabhi-kabhi `pip install` ke baad bhi import pe error aata hai:

```text
ModuleNotFoundError: No module named 'pandas'
```

Matlab: *"pandas naam ki cheez yahan nahi mili."*

Top 2 wajah:

```text
1. Install hi nahi kiya        → pip install pandas chalao
2. Galat terminal mein kiya    → wahi terminal use karo jismein
                                 code chal raha hai (VS Code ka)
```

Aur ek pro-tip jo aage kaam aayegi: **project ki saari libraries ek list file mein** rakhna achhi practice hai (`requirements.txt`) — taaki doosra computer/project le toh ek hi command mein sab install ho jaye:

```bash
pip install -r requirements.txt
```

Abhi bas dekh liya — Module 8 deployment mein iska full use hoga.

## Import Ke Do Style

```python
# Style 1: Poora module lao
import math
print(math.sqrt(16))

# Style 2: Sirf ek tool nikal lo (shortcut)
from math import sqrt
print(sqrt(16))          # math. likhne ki zaroorat nahi!
```

Dono sahi hain.

Style 1 zyada common — clear rehta hai tool kahan se aaya.

## Nutshell

Module = ready-made code pack (dukaan ka samaan) — `import module_name` se laao, `module.tool()` se use karo. pip = online store ka delivery boy — `pip install name` se download. Trading ke heroes: pandas (tables), numpy (fast maths), matplotlib (graphs), requests (internet data). Error "No module named X" = install nahi ya galat terminal. Doosron ka code reuse karna weakness nahi — SMARTNESS hai. Duniya ki best programmers bhi modules use karti hain!

## What It Is NOT

- ❌ **Module use karna = cheating nahi.** Interview mein poochte hain "library use karogi ya khud likhoge?" — jawab har baar LIBRARY! Kyunki woh tested, fast, aur battle-hardened hoti hai. Tera time problem-solving ka hai, wheel reinvent karne ka nahi.
- ❌ **pip install = code mein add nahi hota.** Install computer pe download karta hai; phir bhi code mein `import` likhna PADEGA. Dono steps alag hain: install (ek baar) → import (har file mein).
- ❌ **Sab modules Python ke saath nahi aate.** Kuch built-in hain (math, random), bahut saare store se milne hain (pandas, numpy). Built-in wale direct import, baaki pehle pip install.
