# 3.5 Python Modules & pip

## What is a Module?

> **Module = code-pack written by other programmers that you can use in your code.**

Real-life example:

You need a calculator. Will you solder transistors yourself?

No — buy calculator from market, USE it.

Same way:

```text
Date work?        → use date module
Maths formulas?   → math module
Excel-like tables? → pandas module (this one runs trading!)
Graphs?           → matplotlib module
```

Lakhs of programmers have built these — tested, fast, free.

You just **import** and use. That's it.

## Import — Bring From Shop

```python
import math

print(math.sqrt(16))
```

```text
4.0
```

Line by line:

```python
import math       ← "bring math named module here"
```

Just that. Now all of `math`'s tools are with you.

```python
math.sqrt(16)     ← "take sqrt (square root) from inside math"
                      square root of 16 = 4
```

Remember pattern:

```text
module_name.tool_name()
```

Open box → pick tool → use.

## pip — Delivery Boy of Online Store

**pip = Python's app store / delivery service.**

Programmers worldwide built their modules and put them in one big online store (called PyPI).

Whatever you want, just order:

```bash
pip install pandas
```

You write this in terminal/CMD (inside VS Code's):

```text
pip        → called delivery boy
install    → "bring this goods"
pandas     → item's name
```

Download-install done in a few seconds. ✅

Now use in code:

```python

```

## One Common Problem + Fix

Sometimes after `pip install`, import still gives error:

```text
ModuleNotFoundError: No module named 'pandas'
```

Meaning: *"pandas named thing not found here."*

Top 2 reasons:

```text
1. Didn't install at all        → run pip install pandas
2. Installed in wrong terminal  → use same terminal where
                                  code runs (VS Code's)
```

And one pro-tip that'll help ahead: **keep all project libraries in one list file** (`requirements.txt`) — so when another computer/project takes it, all install with one command:

```bash
pip install -r requirements.txt
```

Just saw it now — full use in Module 8 deployment.

## Two Styles of Import

```python
# Style 1: Bring whole module
import math
print(math.sqrt(16))

# Style 2: Take just one tool (shortcut)
from math import sqrt
print(sqrt(16))          # no need to write math.!
```

Both are correct.

Style 1 is more common — clear where tool came from.

## Nutshell

Module = ready-made code pack (shop's goods) — bring with `import module_name`, use with `module.tool()`. pip = online store's delivery boy — download with `pip install name`. Trading heroes: pandas (tables), numpy (fast maths), matplotlib (graphs), requests (internet data). Error "No module named X" = not installed or wrong terminal. Reusing others' code isn't weakness — it's SMARTNESS. World's best programmers use modules too!

## What It Is NOT

- ❌ **Using module ≠ cheating.** In interviews they ask "will you use library or write yourself?" — answer is always LIBRARY! Because it's tested, fast, and battle-hardened. Your time is for problem-solving, not reinventing wheel.
- ❌ **pip install ≠ added to code.** Install downloads to computer; you STILL must write `import` in code. Two separate steps: install (once) → import (in every file).
- ❌ **Not all modules come with Python.** Some are built-in (math, random), many come from store (pandas, numpy). Built-in ones import directly, others need pip install first.
