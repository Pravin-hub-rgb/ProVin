# 3.7 Pandas Library Basics

## Pandas Kya Hai

Pandas ek powerful open-source library hai **data manipulation, cleaning aur analysis** ke liye. Ek interesting technical detail — pandas NumPy ke upar built hai (NumPy C mein hai, pandas usi pe khadi hai), isliye pandas bhi fast hai.

Do core data types hote hain pandas mein:

| Type | Matlab |
|---|---|
| **Series** | 1-dimensional labeled array |
| **DataFrame** | 2-dimensional labeled table — jaise Excel sheet |

Install aur import:

```bash
pip install pandas
```

```python
import pandas as pd     # industry standard = pd

```

## Series — List Plus Label

Series = 1D labeled array. Simple list hai + har value ka index:

```python
import pandas as pd

s = pd.Series([1, 2, 3, 4, 5])
print(s)
# 0    1
# 1    2
# 2    3   (index automatically 0,1,2...)
# dtype: int64
```

Apna custom index bhi de sakte ho:

```python
s = pd.Series(["apple", "mango", "banana"], index=["a", "b", "c"])
print(s)
# a    apple
# b    mango
# c    banana
```

Sochoge dictionary jaisa hi hai? Haan — dono label+value store karte hain. Par Series dictionary se strong hai kyunki usme bahut saare built-in functions hote hain aur wo NaN (empty values) ko handle kar sakti hai. Dictionary yeh sab nahi karti.

## DataFrame — Excel Sheet Python Mein

**DataFrame = 2D table** — rows + columns + labels. Multiple Series milakar banta hai:

```python
data = {
    "roll": [101, 102, 103],
    "name": ["Rahul", "Rohan", "Ashu"],
    "marks": [95, 67, 89]
}
df = pd.DataFrame(data)
print(df)
#    roll   name  marks
# 0   101  Rahul     95
# 1   102  Rohan     67
# 2   103   Ashu     89
```

Yehi structure backtesting mein roz dikhega — candle data bhi aise hi DataFrame mein aata hai: date column, open, high, low, close, volume columns.

## Data Import Karna — Excel / CSV / URL

Asli power ab aati hai. File se direct data DataFrame mein:

```python
df = pd.read_excel("testing.xlsx")     # Excel file
df = pd.read_csv("testing2.csv")       # CSV file
df = pd.read_csv("https://example.com/data.csv")   # URL se bhi!
```

CSV kya hai? **Comma Separated Values** — plain text file jismein values commas se separate hain. Excel se lighter hota hai (same data, chhota file), isliye broker APIs zyadatar CSV/JSON dete hain.

Ek practical warning: file pehle Jupyter mein **upload** karni padti hai — warna local path se read karne pe `FileNotFoundError` aayega.

Aur broker data ke baare mein ek note — do type ka milta hai:
- **Candle (OHLC)** data — open, high, low, close, volume wali table
- **Tick-by-tick** data — har price movement, JSON format mein

Dono ko clean karke use karte hain — cleaning isi file mein aage seekhenge.

## Data Explore Karna

Data load karne ke baad pehla kaam — dekho usme hai kya:

| Function | Kaam |
|---|---|
| `df.head()` | Pehli 5 rows |
| `df.tail()` | Last 5 rows (`.tail(10)` = last 10) |
| `df.info()` | Columns, data types, memory usage |
| `df.describe()` | Statistical summary (mean, min, max...) |
| `df.shape` | `(rows, columns)` tuple |

```python
print(df.head())      # top 5 rows dikho
print(df.info())      # kis column ka type kya hai
print(df.shape)       # (244, 7) — 244 rows, 7 columns
```

`info()` sabse pehle chalana habit bana lo — batata hai kaunsa column int hai, float hai, ya object (string). Aur NaN = empty value hoti hai jo pandas handle kar sakta hai.

## Select, Filter Karna

### Columns

```python
df["actor"]              # single column → Series milti hai
df[["actor", "imdb"]]    # multiple columns → DataFrame milta hai
```

### Rows — iloc vs loc

| Method | Access by |
|---|---|
| `df.iloc[0]` | **Index number** (position 0,1,2...) |
| `df.loc[0]` | **Label** (agar label string hai) |

```python
df.iloc[0]        # position se pehli row
df.iloc[0:3]      # rows 0,1,2 (stop excluded — purana rule!)
```

Specific cell badalna ho:

```python
df.iloc[0, 2] = 2    # row 0, column 2 ki value = 2
```

### Filtering — Sabse Zyada Use Hone Wala

```python
df[df["imdb"] > 8]     # sirf wo rows jinki imdb rating 8 se zyada
```

Pattern dhyan se: `df[condition]` — condition ke andar dobara `df` likhna padta hai. Double bracket wala concept hai.

Multiple conditions ke liye `&` use karo, aur har condition ko apne brackets mein rakho:

```python
df[(df["imdb"] > 7) & (df["year"] == 2016)]
```

Backtesting mein filtering roz ka kaam hai — "sirf woh candles jahan EMA cross hua" — bas aisa hi condition likhoge.

## Cleaning — NaN Handle Karna

Real-world data mein empty values hoti hain (NaN). Handle karne ke tools:

```python
df.isna()                    # kahan-kahan NaN hai (True/False map)
df.fillna(10)                # NaN ki jagah 10 bhar do
df.drop("column_name", axis=1)   # poora column delete
```

Ek achhi baat — notebook mein changes permanent nahi hote jab tak file dobara re-read na karo. Matlab experiment karo, galti karo, restart — original data safe hai.

## Nutshell

Pandas = data manipulation/cleaning/analysis library, NumPy ke upar built. Do structures: **Series** (1D labeled array) aur **DataFrame** (2D table, Excel jaisa). Import karo `read_excel`/`read_csv`/URL se. Explore karo `head/tail/info/describe/shape`. Select karo columns `df["col"]`, rows `iloc` (position) / `loc` (label). Filter karo `df[df["col"] > val]` — conditions mein `&` use karo. Clean karo `isna/fillna/drop`. Bas — backtesting ka data side ready!

## What It Is NOT

- ❌ **pandas = Excel ka replacement sirf nahi.** Excel dekhne ke liye hai; pandas automation ke liye — hazaron rows pe filtering, calculation, analysis seconds mein, code se.
- ❌ **`df["col"]` aur `df[["col"]]` same nahi hain.** Single bracket → Series (ek column), double bracket → DataFrame (table). Return type alag hai, isliye aage operations bhi alag chalenge.
- ❌ **Notebook mein change karna = file mein save hona nahi.** Jo changes cell run karke kiye wo memory mein hain. Original CSV/Excel untouched rehta hai jab tak explicitly save na karo — isliye experimentation safe hai.
