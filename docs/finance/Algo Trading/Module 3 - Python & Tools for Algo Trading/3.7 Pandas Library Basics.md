## DataFrame — Python's Excel Sheet

> **DataFrame = table with rows and columns** — exactly like Excel sheet.

This is pandas's HERO object. Whole course revolves around it:

```text
Candle data?      → in DataFrame
Backtest results? → in DataFrame
Broker response?  → in DataFrame
```

### Make First DataFrame

```python
import pandas as pd

data = {
    "symbol": ["RELIANCE", "TCS", "INFY"],
    "price": [2450, 3800, 1550]
}

df = pd.DataFrame(data)
print(df)
```

Output:

```text
      symbol  price
0  RELIANCE   2450
1       TCS   3800
2      INFY   1550
```

Understand what was done:

```python
data = {...}          → made dictionary: name → list of values
pd.DataFrame(data)    → pandas made TABLE from it
df                    → caught table in a variable
```

See output: columns (`symbol`, `price`) + rows (0, 1, 2) + values.

Exactly Excel. Just now control will be through code.

## Filtering — Sieving Data

Question: "show only those candles where close is ABOVE 2500."

Real life: Excel's filter button.

In pandas, one line:

```python
big_candles = df[df["close"] > 2500]
```

Read line from inside (Python runs like this):

```text
df["close"] > 2500   → check on each row: close > 2500?
                       result = True/False list

df[ ...True/False...]  → KEEP rows where True
                        discard where False
```

Output: only candles whose closing was 2500+. ✅

This pattern — `df[condition]` — **is the heart of backtesting:**

```python
# Upcoming examples (just see now):
winners  = report[report["pnl"] > 0]      # only winning trades
losers   = report[report["pnl"] <= 0]     # only losing trades
```

Module 4 will calculate metrics with this!

## Grabbing Rows — iloc

To grab row by position:

```python
print(df.iloc[0])       # FIRST row (position 0)
print(df.iloc[-1])      # LAST row
```

```text
iloc[0]   → "give row at position 0"
iloc[-1]  → minus = count from BACK → last row
```

⚠️ One rule that will save from backtest bug in 4.x:

`df.iloc[0:3]` = positions **0, 1, 2** — position 3 NOT!

**Stop number is EXCLUDED** (remember range(1,6)? Same design!)

```text
iloc[a:b]  → from a to b-1 (not b!)
```


See `.mean()` / `.max()` — NumPy tools work on pandas columns too! (Because column inside is array — remember the chain?)

## Nutshell

DataFrame = Python's Excel (rows + columns) — hero object of whole course. Load file with `pd.read_csv()` (1 line!), peek first 5 rows with `df.head()`. Extract column with `df["col"]`; multiple with double brackets. **Filtering:** `df[df["close"] > 2500]` — only rows where condition TRUE survive (core of backtesting!). `iloc[0]` first row, `iloc[-1]` last, and in `iloc[a:b]` b is EXCLUDED. Tools like `.mean()`/`.max()` work directly on columns.

## What It Is NOT

- ❌ **Pandas is not Excel.** Looks like Excel but: automation, thousands of files, complex maths — all these are beyond Excel, daily routine for pandas. Excel clicks; pandas runs code.
- ❌ **`df["close"]` doesn't give a copy — gives view/reference.** Column is part of original table; changes in it can affect original. For safe play use `.copy()` (detail comes later).
- ❌ **Single bracket vs double bracket not same:** `df["close"]` = ONE column (Series). `df[["open","close"]]` = small TABLE (DataFrame). Double brackets means "give list of columns." Output shape will differ.
