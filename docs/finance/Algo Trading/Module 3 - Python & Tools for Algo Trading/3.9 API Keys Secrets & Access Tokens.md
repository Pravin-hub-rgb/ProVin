Overview samajh aa gaya — process sabka same hai. Ab pehla practical step: broker tujhe apna account kaise access dega? Yahan **API key, secret aur access token** ka system aata hai. Ghar-chabi wali analogy se poora concept pakka ho jayega.

# 3.9 API Keys, Secrets & Access Tokens

## Chabi Analogy — Ek Baar Mein Samajh

Broker account teri **house** hai. Us house mein andar jaane ke liye chabi chahiye:

- **Broker account** = tere paise aur trades wali house
- **API key + API secret** = us ghar ki chabi
- Jo bhi is chabi rakh lega, wo tere ghar mein kuch bhi kar sakta hai — orders laga sakta hai, data nikal sakta hai

Aur jo bhi tu broker pe manually karta hai (orders, data fetch, positions check) — wahi sab API ke through code se hoga.

## Teen Terms — Kaun Kya Hai

| Term | Kya Hai |
|---|---|
| **API Key** | Unique ID jo tera broker account identify karti hai |
| **API Secret** | Bahut lambi encrypted string — password jaisi |
| **Access Token** | Temporary permission slip — "is session mein trade/data allowed" |

Sabse important warning: agar kisi ke paas teri **key aur secret dono** ho gayi, toh uske paas **100% account access** hai. Wo tere naam se order laga sakta hai, data nikal sakta hai — kuch bhi. Isliye yeh do cheezein bank card jaisi treat kar.

## Har Broker Ki Apni Library

Har broker ne apni API ki apni Python library banayi hai:

| Broker | Library | Notes |
|---|---|---|
| Groww | `grow_api` | Easy setup, Groww Cloud platform |
| Angel One | `smart-api-python` | TOTP required |
| Dhan | `dhan-hq` | Sirf access token chahiye |
| Zerodha | `kiteconnect` | Request token flow |
| Delta Exchange | `requests` | No official library — direct endpoints |
| Binance | `python-binance` / `requests` | Crypto |

Ek insight jo worth hai — *"jab tak limited brokers pakde ho, limited rahoge."* Saare brokers ek baar dekh lo, phir similarities aur differences khud dikhne lagenge. Login har jagah alag hai, baaki process same (pichli file yaad kar).

## Keys Generate Karna — Groww Example

Practically dekhte hain:

1. Apne broker account mein login karo (jaise groww.in)
2. **Trading APIs** section mein jao
3. "Generate new API" click karo — naam do (jaise "test")
4. Do cheezein milti hain:
   - **API Key:** `XNXU-XXXX-XXXX-XXXX` format ki string
   - **API Secret:** bahut lambi encrypted string

Do zaroori baatein:

- Generate karte **hi copy kar lo** — secret dobara screen pe nahi dikhti
- Demo/testing ke liye banayi key ko kaam hone ke baad **delete kar do**

## Access Token — Permission Slip Ka System

Ab flow samajh — key/secret seedhe har request mein nahi jaati:

1. Tu API key + secret deti hai broker ko
2. Broker check karta hai — permission hai?
3. Haan → **access token generate** hota hai
4. Ab saari requests isi token ke saath jaati hain — orders, data fetch, sab

Matlab key/secret one-time setup hai; roz ka kaam access token se hota hai.

Python mein pattern aisa dikhta hai (Groww example):

```bash
pip install grow_api
```

```python
from grow_api import GrowApi

api = GrowApi(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_SECRET_HERE"
)

access_token = api.get_access_token()
# Ab data fetch / trade ready
```

Har library ke apne docs hote hain — `[library name] docs` Google karo, official documentation mil jayegi examples ke saath.

## Security — Ye Rules Todo Mat

| Practice | Kyun |
|---|---|
| ✅ Key/secret kabhi share mat karo | Jiske paas hai, uske paas poora account hai |
| ✅ Separate file mein rakho | `tokens.py`, `.env`, ya environment variables |
| ✅ `.gitignore` lagao | Tokens file GitHub pe upload = account hack |
| ❌ Code mein directly hardcode mat karo | `api_key = "xxx"` likha toh repo leak pe sab gaya |

Wrong vs right storage:

```text
❌ WRONG — code mein directly:
ACCESS_TOKEN = "eyJhbGciOiJIUzI1NiIs..."

✅ RIGHT — separate file:
import tokens
ACCESS_TOKEN = tokens.access_token

✅ YA environment variables:
import os
api_key = os.getenv("GROW_API_KEY")
```

GitHub pe galti se tokens upload hue toh koi bhi tera account control kar sakta hai. `.gitignore` mein tokens file daalna pehla habit bana lo.

## Nutshell

API key + secret = broker account ki chabi (dono milengi toh 100% access). Access token = temporary permission slip jo inhi se generate hota hai — roz ka kaam isi se hota hai. Har broker ki apni library hai (`grow_api`, `dhan-hq`, `kiteconnect`...) — pip install karo, docs padho. Security non-negotiable: kabhi share mat karo, separate file + `.gitignore`, hardcoding kabhi nahi.

## What It Is NOT

- ❌ **Access token permanent password nahi hai.** Temporary hota hai — expire hota hai (broker ke hisaab se hours/din). Expire hua toh dobara generate karo — normal process hai.
- ❌ **API key akeli kaafi nahi hoti.** Zyadatar brokers mein key + secret dono chahiye. Sirf key leak hona kam danger hai, dono leak = full compromise.
- ❌ **Demo key real account risk nahi hoti — par delete karna best practice hai.** Test/demo keys ka scope limited hota hai, par hygiene maintain karo.

1. API key, API secret aur access token — teeno ka role apne words mein batao.

**Jawab:** API key = unique ID jo batati hai ye kis account ki request hai. API secret = lambi encrypted string jo proof karti hai ki request asli owner ki hai — dono milkar account ki chabi hain. 2. Agar kisi ko tumhari API key aur secret dono mil gayi, toh wo kya-kya kar sakta hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** 100% account access. Wo tere naam se orders place kar sakta hai, positions dekh sakta hai, data fetch kar sakta hai — matlab teri strategy copy bhi aur manipulate bhi. Paise seedhe nahi nikal sakta (wo broker ke withdrawal rules se hota hai), par trading se nuksaan karwa sakta hai. Isliye key+secret ko bank credentials jaisa treat karo — kabhi share nahi, kabhi hardcode nahi.

</details>

3. Tokens ko store karne ka right tareeka kya hai aur wrong tareeka kya?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Wrong: main code mein directly likhna — `api_key = "XNXU..."`. Agar ye code GitHub pe gaya toh sabko key mil gayi. Right: alag file mein rakho (`tokens.py`) aur import karo, ya environment variables use karo (`os.getenv("GROW_API_KEY")`). Aur `.gitignore` mein tokens file daalna mat bhoolna taaki git track hi na kare.

</details>

4. "Limited brokers pakdo ge toh limited rahoge" — iska matlab kya hai?

<details>
<summary>Sample Jawab</summary>

Phir naya broker aaye ya company switch karni pade, 1-2 din mein shift ho jaoge. Jo sirf ek pe atak gaya, wo har naye tool ko "mushkil" maanega.

</details>
