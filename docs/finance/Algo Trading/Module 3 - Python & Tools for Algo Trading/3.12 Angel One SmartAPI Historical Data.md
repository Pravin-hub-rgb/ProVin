## Login — Ab TOTP Aayega

Angel One ka login 4 cheezein maangta hai: API key + username + password (MPIN) + **TOTP**.

### TOTP Kya Hai?

TOTP = Time-based OTP. Ek 6-digit code jo **har 30 second mein badal jaata hai** — jaise bank apps ka OTP, par automatic.

Manual entry karna pagalpan hai (30 second mein expire!). Isliye `pyotp` library se programmatically generate karte hain:

```bash
pip install pyotp
```

```python
from smartapi import SmartConnect
import pyotp

# Step 1: Initialize
smart_api = SmartConnect(api_key="YOUR_API_KEY")

# Step 2: TOTP dynamically generate karo
totp = pyotp.TOTP("YOUR_TOTP_SECRET")
totp_token = totp.now()          # current 6-digit code

# Step 3: Session generate karo
session = smart_api.generateSession(
    username="YOUR_USERNAME",
    password="YOUR_MPIN",
    totp=totp_token
)
```

Aur is session se **do tokens** milte hain:

```python
access_token = session["data"]["access_token"]    # short-term
refresh_token = session["data"]["refresh_token"]  # longer-term
```

### Chaar Tokens Ka Summary

| Token | Kaam | Lifetime |
|---|---|---|
| API Key | App identification | Permanent |
| Access Token | Trade/data access | Short-term |
| Refresh Token | Access token dobara generate karna | Longer-term |
| TOTP Secret | 6-digit codes generate karna | Permanent (settings se milti hai) |

Refresh token ka fayda: access token expire hua toh poora login dobara nahi karna padta — refresh token se naya access token mil jaata hai.

⚠️ TOTP secret kahan se milegi? Angel One app → Settings → API section → TOTP secret copy karo. Yehi string `pyotp.TOTP()` mein jaati hai.

## Common Login Errors

**Error 1: `invalid TOTP / six digit TOTP does not match`**

Sabse common error. Wajah: TOTP manually enter kiya (30 second mein change ho gayi!) ya galat secret copy kiya. Fix: `pyotp` se dynamic generation hi use karo — `.now()` hamesha fresh code dega.

**Error 2: Feed token / refresh token missing**

Session properly generate nahi hua. Credentials aur TOTP flow re-check karo.

**Error 3: Same code baar-baar run karne pe fail**

Wohi purana lesson — login logic ko **alag `login.py` file** mein rakho, main code se import karo:

```python
from login import smart_api    # Zerodha wala pattern yahan bhi!
```

## Response Format — Thoda Different Hai

Yahan ek twist hai. Data ek nested dict ke andar **lists** ki form mein aata hai:

```python
{
    "status": "success",
    "data": {
        "candles": [
            ["2022-01-08T09:15:00+0530", 2450.0, 2460.0, 2445.0, 2455.0, 100000],
            ...
        ]
    }
}
```

Har candle ek list hai jismein position se pata chalta hai kya hai:

| Index | Meaning |
|---|---|
| 0 | Timestamp |
| 1 | Open |
| 2 | High |
| 3 | Low |
| 4 | Close |
| 5 | Volume |

Zerodha mein named dict tha; yahan positional list hai. Isliye DataFrame banate waqt **column names khud dene padte hain:**

```python
import pandas as pd

columns = ["time", "open", "high", "low", "close", "volume"]
df = pd.DataFrame(raw_data["data"]["candles"], columns=columns)

print(df.head())
print(f"Total candles: {len(df)}")
```

Output bilkul clean:

```
                        time   open   high    low  close  volume
0  2022-01-08T09:15:00+0530  2450.0 2460.0 2445.0 2455.0  100000
1  2022-01-08T09:20:00+0530  2455.0 2465.0 2450.0 2460.0   95000
```

Chota pro tip: timestamps mein `+0530` timezone suffix dikhe toh pandas se easily convert/clean ho jaata hai — panic mat karo.

## Nutshell

Angel One SmartAPI = same process + TOTP twist. Login: API key + username + MPIN + pyotp-generated TOTP → `generateSession()` → access token + refresh token. TOTP har 30 sec badalti hai — manual kabhi nahi, `pyotp.TOTP(secret).now()` always. Data: `get_candle_data()` — response mein candles **positional lists** hoti hain, isliye DataFrame banate waqt column names khud dena padta hai. Login alag file mein rakho — har broker pe wohi best practice.

## What It Is NOT

- ❌ **TOTP = SMS/email OTP nahi.** Woh app-based authenticator ka time-based code hai jo har 30 second badalta hai. Isliye automation possible hai — SMS OTP automation safe/appropriate nahi hota.
- ❌ **Refresh token = doosra access token nahi.** Uska sirf ek kaam hai — expire hue access token ko regenerate karna. Trading calls refresh token se nahi jaati.
- ❌ **Candles list format universal nahi hai.** Zerodha dicts deta hai, Angel One lists deta hai. Har broker ka response shape alag ho sakta hai — docs dekho, assume mat karo.
