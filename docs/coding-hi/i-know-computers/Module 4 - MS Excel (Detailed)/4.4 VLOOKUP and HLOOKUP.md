In the last chapter, we learned formulas and functions. Now let's learn one of the most powerful Excel functions — **Lookup functions**. VLOOKUP, HLOOKUP, and XLOOKUP find a value in your data and return related information from somewhere else. These are used everywhere in offices for looking up prices, employee details, student results, and more. In the next chapter, we'll learn sorting and filtering.

### What is Lookup?

Lookup means **searching data to find an answer**. Imagine you have an employee table with Name, Designation, Department, and Salary. You type a person's name and want Excel to automatically show their Salary. That's a lookup.

There are three types:
- **VLOOKUP** — searches **vertically** (column-wise). It checks columns.
- **HLOOKUP** — searches **horizontally** (row-wise). It checks rows.
- **XLOOKUP** — does both. It can search any direction.

### Important Lookup Rules (Same for All Three)

Before we start, understand these rules:

1. **Exact match always:** Use `FALSE` or `0` — this means "find exactly this value." If you use `TRUE`, Excel finds the closest match which often gives wrong answers.
2. **Absolute references:** Lock your table range with `$` signs (like `$A$1:$D$10`) so when you copy the formula, the table doesn't move.
3. **Spelling matters:** If the name says "Rahul" but you typed "Rahul " (space at the end), lookup won't find it.

---

### VLOOKUP — Vertical Lookup

V = Vertical. VLOOKUP searches down **columns**. Think of it like: you have a list of names in column B, and you want Excel to look up each name and bring back their salary from column D.

**Syntax:**
```
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
```

| Part | What It Means | Example |
|---|---|---|
| `lookup_value` | The value you want to search for | `I2` (cell containing the name) |
| `table_array` | The entire table range | `$B$1:$E$10` (include all columns you need) |
| `col_index_num` | Which column number to return from | `3` (1st col = 1, 2nd col = 2, etc.) |
| `range_lookup` | `FALSE` for exact match | `0` or `FALSE` (always use this) |

#### 🤔 lookup_value — Which cell to use? (Common Confusion)

The `lookup_value` is the **form input cell** where you type what you want to search. It is NOT a cell from the data table itself.

Look at this setup:

```
         DATA TABLE (columns A-D)                     FORM (column I)

   |    A         B        C          D          |     I
---+---------------------------------------------+----------
 1 | Designation  Name     Department  Salary    |     
 2 | CEO          Vishali  Sales       95000     |  Asmita   ← You type the name here (I2)
 3 | Manager      Bharat   Marketing   65000     |  =VLOOKUP(I2, $B$1:$D$4, 3, 0)
 4 | Analyst      Asmita   IT          55000     |  → Result: 55000
```

- **I2** is the lookup_value — the cell where you typed `Asmita` (form input)
- **$B$1:$D$4** is the table array — the data table
- VLOOKUP takes `"Asmita"` from I2, searches for it in column B (Name — first column of the array), finds it in row 4, and returns column 3 (Salary = 55000)

So the name **Asmita** exists in **two places**:
1. In the **data table** (B4) — where your stored data lives
2. In the **form input** (I2) — where you type what to search

The lookup_value always points to the **form input cell** (the search bar). VLOOKUP matches it against the first column of the data table.

> **Think of it like Google:** You type something in the search box (form input) → Google searches its database (data table) → shows you the result. The search box is your lookup_value, the database is your table array.

#### ⚠️ CRITICAL RULE — VLOOKUP Only Searches Right

**VLOOKUP can only look to the RIGHT.** It checks the first column of your table array, finds the matching row, and returns a value from a column to the RIGHT. It cannot return anything from the LEFT of the lookup column.

This means: **your lookup column MUST be the first column in the table array**, and the column you want to return must be to its right.

Example dataset:

| A | B | C | D |
|---|---|---|---|
| Designation | Name | Department | Salary |
| CEO | Vishali | Sales | 95000 |
| Manager | Bharat | Marketing | 65000 |
| Analyst | Asmita | IT | 55000 |

If you want to search by **Name** (column B) and return **Salary** (column D):
- Your table array must start from column B: `$B$1:$D$4` (not from column A)
- Salary is the 3rd column in this range (B=1, C=2, D=3), so `col_index_num` = 3

If you try to get **Designation** (column A) using VLOOKUP by Name — **it won't work** because Designation is to the LEFT of Name. VLOOKUP cannot see it.

```
=VLOOKUP("Asmita", $B$1:$D$4, 3, 0)
```
Returns: 55000 (Salary)

```
=VLOOKUP("Asmita", $B$1:$D$4, 1, 0)
```
Returns: Asmita (Name itself — column 1 of the array)

#### Step-by-Step Example

1. Type this data in Excel starting from A1:
   - A1: Designation, B1: Name, C1: Department, D1: Salary
   - A2: CEO, B2: Vishali, C2: Sales, D2: 95000
   - A3: Manager, B3: Bharat, C3: Marketing, D3: 65000
   - A4: Analyst, B4: Asmita, C4: IT, D4: 55000

2. In cell I2 (or any empty cell), type a name: `Asmita`

3. In cell I3, enter this formula:
   ```
   =VLOOKUP(I2, $B$1:$D$4, 3, 0)
   ```
   Result: 55000 (Asmita's Salary)

4. In cell I4, enter this formula:
   ```
   =VLOOKUP(I2, $B$1:$D$4, 2, 0)
   ```
   Result: IT (Asmita's Department)

> **💡 Tip:** Notice the table array starts from column B, not A. Because Name is our lookup column, it must be the first column in the array.

### HLOOKUP — Horizontal Lookup

H = Horizontal. HLOOKUP searches across **rows** instead of columns. Use it when your data is arranged left-to-right (categories in the first row, values below).

**Syntax:**
```
=HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])
```

| Part | What It Means |
|---|---|
| `lookup_value` | What you're searching for |
| `table_array` | The table range |
| `row_index_num` | Which row number to return from (1st row = 1, 2nd row = 2, etc.) |
| `range_lookup` | `0` for exact match |

#### ⚠️ CRITICAL RULE — HLOOKUP Only Searches Down

**HLOOKUP can only search BELOW** the lookup row. If your lookup value is in row 1, it can only return values from rows 2, 3, 4 etc. — never from above.

Example data arranged horizontally:

| A | B | C | D |
|---|---|---|---|
| **Row 1** | Jan | Feb | Mar |
| **Row 2** | 15000 | 18000 | 12000 |
| **Row 3** | 5000 | 5500 | 4800 |

To find February's Sales (Row 2):
```
=HLOOKUP("Feb", $A$1:$D$3, 2, 0)
```
Returns: 18000

### XLOOKUP — The Modern Solution

XLOOKUP is newer and better. It replaces both VLOOKUP and HLOOKUP. The biggest advantage: **XLOOKUP can search BOTH left and right** (and above and below). No more "must be first column" rule.

**Syntax:**
```
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
```

| Part | What It Means | Options |
|---|---|---|
| `lookup_value` | What you're searching for | A cell reference like `I2`, or type directly like `"Asmita"` |
| `lookup_array` | Where to search (a single column or row) | `$B$1:$B$4` (the Name column) |
| `return_array` | What to return (same size as lookup_array) | `$D$1:$D$4` (the Salary column) |
| `if_not_found` | Optional — custom message if nothing found | `"Not found"` or leave blank for `#N/A` |
| `match_mode` | Optional — how to match | `0` = exact match (default), `-1` = exact or next smaller, `1` = exact or next larger, `2` = wildcard match |
| `search_mode` | Optional — search direction | `1` = first to last (default), `-1` = last to first, `2` = binary search (sorted ascending), `-2` = binary search (sorted descending) |

**match_mode explained:**
- `0` (default) — exact match. Same as VLOOKUP with FALSE. Use this 99% of the time.
- `-1` — exact match or next smaller item. Useful for grade tables or tax slabs.
- `1` — exact match or next larger item.
- `2` — wildcard match (`*` for any characters, `?` for single character).

**search_mode explained:**
- `1` (default) — search from first to last. Normal top-to-bottom search.
- `-1` — search from last to first. Useful when you want the most recent entry.
- `2` — binary search (data must be sorted ascending). Faster on huge datasets.
- `-2` — binary search (data must be sorted descending). Faster on huge datasets.

> **💡 For beginners:** Just leave match_mode and search_mode blank. They use defaults (0 and 1) which work perfectly for most cases.

#### XLOOKUP Can Search Left!

Using the same employee data:

| A | B | C | D |
|---|---|---|---|
| Designation | Name | Department | Salary |

To search by **Name** (column B) and return **Designation** (column A — which is to the LEFT):
```
=XLOOKUP(I2, $B$1:$B$4, $A$1:$A$4)
```
Returns: CEO (Vishali's Designation)

VLOOKUP cannot do this. XLOOKUP can.

To search by **Name** and return **Salary** (to the RIGHT):
```
=XLOOKUP(I2, $B$1:$B$4, $D$1:$D$4)
```
Returns: 95000

**Advantages of XLOOKUP over VLOOKUP:**
- No column index number — select the return column directly
- Can search left or right
- Can show a custom message if not found (like `"Not found"`)
- Your lookup column doesn't need to be the first in the table

#### XLOOKUP with "Not Found"

```
=XLOOKUP(I2, $B$1:$B$4, $D$1:$D$4, "Name not found")
```
If you type a name that doesn't exist, instead of showing `#N/A`, it shows "Name not found".

### Common VLOOKUP Errors

| Error | Meaning | Fix |
|---|---|---|
| `#N/A` | Value not found | Check spelling, spaces, or data type — or use XLOOKUP with a custom "not found" message |
| `#REF!` | Column number is out of range | Your `col_index_num` is larger than the number of columns in your table array |
| Wrong result | Got a different value | You probably used `TRUE` instead of `FALSE` — exact match gives wrong results with TRUE |

**Why lookups fail:**
- The lookup column is not the **first column** of the table array (VLOOKUP only) — fix by adjusting the table array or switch to XLOOKUP
- Extra **spaces** — clean with `=TRIM()`
- Numbers stored as **text** — format both columns consistently
- Lookup value doesn't exist in the data — double-check spelling

### 🧠 Chapter Summary

> ✅ **VLOOKUP** = vertical lookup in columns. Searches first column, returns from right.  
> ✅ **Syntax:** `=VLOOKUP(value, table, col_number, 0)`  
> ✅ **HLOOKUP** = horizontal lookup in rows. Searches first row, returns from below.  
> ✅ **Syntax:** `=HLOOKUP(value, table, row_number, 0)`  
> ✅ **XLOOKUP** = newer, better. Can search left, right, above, below.  
> ✅ **Syntax:** `=XLOOKUP(value, lookup_col, return_col, "Not found", 0, 1)`  
> ✅ **match_mode:** `0` = exact (default), `-1` = exact or next smaller, `1` = exact or next larger, `2` = wildcard  
> ✅ **search_mode:** `1` = first to last (default), `-1` = last to first, `2` = binary ascending, `-2` = binary descending  
> ✅ **Always use 0 (FALSE)** for exact match — TRUE gives unpredictable results  
> ✅ **VLOOKUP limitation:** lookup column must be first in the table array — XLOOKUP has no such limit

### 🎯 Real Task

1. Open a new Excel sheet. Create this employee table in A1:D4:
   - A1: Designation, B1: Name, C1: Department, D1: Salary
   - A2: CEO, B2: Vishali, C2: Sales, D2: 95000
   - A3: Manager, B3: Bharat, C3: Marketing, D3: 65000
   - A4: Analyst, B4: Asmita, C4: IT, D4: 55000

2. In a cell (say F2), type a name: `Bharat`

3. Use VLOOKUP to get Bharat's Salary:
   ```
   =VLOOKUP(F2, $B$1:$D$4, 3, 0)
   ```
   Result should be 65000. (Table array starts from B because Name is the lookup column.)

4. Use XLOOKUP to get Bharat's Designation (to the LEFT of Name):
   ```
   =XLOOKUP(F2, $B$1:$B$4, $A$1:$A$4)
   ```
   Result should be "Manager". Notice XLOOKUP could look LEFT — VLOOKUP cannot do this.

5. **Error testing:** Type a name that doesn't exist (like "Rahul") in F2. VLOOKUP shows `#N/A`. Now try XLOOKUP with a custom message:
   ```
   =XLOOKUP(F2, $B$1:$B$4, $D$1:$D$4, "Not found")
   ```
   Instead of `#N/A`, it shows "Not found".

6. **Bonus — match_mode with grades:** Create a grade table in F10:G13 — F10: 0, F11: 33, F12: 60, F13: 75 and G10: "Fail", G11: "Pass", G12: "First", G13: "Distinction". In H2, type a score like `50`. Then try:
   ```
   =XLOOKUP(H2, $F$10:$F$13, $G$10:$G$13, "Invalid", -1)
   ```
   Result: "Pass" (50 is between 33 and 60, so it finds 33 — the next smaller — and returns "Pass"). This is how grade lookups work in schools.
