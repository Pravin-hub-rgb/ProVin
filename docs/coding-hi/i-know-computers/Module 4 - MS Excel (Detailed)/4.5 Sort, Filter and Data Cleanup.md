In an office, you'll often get messy data that needs to be cleaned before it can be used. In the next chapter, we'll learn Pivot Tables for summarizing data.


### Sorting Data

**Simple sort:** Click any cell in the column you want to sort → Data tab → Sort A to Z (ascending) or Sort Z to A (descending).

**Multi-level sort (sort by one column, then another):**
1. Click anywhere in your data
2. Data → Sort
3. **Sort by:** First column (e.g., "Result" — Pass/Fail)
4. Click **Add Level**
5. **Then by:** Second column (e.g., "Total" — Largest to Smallest)

| Example | Steps | Result |
|---|---|---|
| **Single sort** | Column "Total" → Sort Largest to Smallest | Highest marks at top |
| **Multi sort** | Sort by Result, then by Total | All Pass students listed by highest marks, then all Fail students |

> **💡 Tip:** Before sorting, make sure your data has no merged cells in the column you're sorting by. Select the entire data range (not just one column) so related rows stay together.

### Filtering Data

Filter **hides** rows that don't match your condition — it doesn't delete them.

**To turn on Filter:**
- Click anywhere in your data → Data → Filter (or `Ctrl+Shift+L`)
- Small dropdown arrows appear in each header

**To filter:**
- Click the dropdown arrow in the column you want to filter
- Check or uncheck values to show/hide
- Or use **Number Filters** → Greater Than, Less Than, Between, etc.

**To clear filter:** Click the same dropdown → "Clear Filter From..." or press `Ctrl+Shift+L` to turn off Filter entirely.

**Practical examples:**
  - Filter "Result" column → show only "Pass" → you see only passing students
  - Filter "Total" → Number Filters → Greater Than → 200 → shows only high scorers
  - Filter "Department" → uncheck everything except "Sales" → shows only sales team

### Data Cleanup

**Remove Duplicates:**
1. Select your data range (or click any cell in the data)
2. Data → Remove Duplicates
3. Choose which columns to check for duplicates
4. Click OK — Excel tells you how many duplicates were removed

**TRIM function (remove extra spaces):**
  - `=TRIM(A2)` — removes extra spaces before, after, and between words in A2
  - Copy the formula down, then copy-paste as values to replace the original data

**Change text case:**
  - `=UPPER(A2)` — all capital letters (e.g., RAHUL)
  - `=LOWER(A2)` — all lowercase (e.g., rahul)
  - `=PROPER(A2)` — first letter of each word capitalized (e.g., Rahul Sharma)

**Find & Replace:**
  - `Ctrl+H` — Find what: type the value to find → Replace with: type new value
  - Click Replace All to replace all instances at once
  - Useful for fixing spelling mistakes or updating values in bulk

### Data Validation — Dropdown Lists

  Data Validation lets you **control what can be entered in a cell**. The most common use is creating a **dropdown list** so users can only select from predefined options — no typos, no wrong entries.

  **Create a dropdown list:**

  1. Select the cell(s) where you want the dropdown
  2. Data tab → Data Validation (or Data → Data Tools → Data Validation)
  3. In the dialog: Allow → **List**
  4. In "Source", type your options separated by commas: `Pass,Fail` (no spaces needed)
  5. Click OK — a dropdown arrow appears in the cell

  *Example: You have a "Result" column. Instead of letting people type "Pass", "pass", "PASS", "paas" — create a dropdown with only "Pass" and "Fail". No typos possible.*

  **Other Data Validation types:**

  | Allow | What It Does | Example |
  |---|---|---|
  | **Whole Number** | Accepts only numbers within a range | Between 0 and 100 (for marks) |
  | **Decimal** | Accepts decimal numbers | Between 0.00 and 10.00 (for ratings) |
  | **Date** | Accepts only dates within a range | After 01-Jan-2024 |
  | **Text Length** | Limits character count | Max 10 characters (for phone numbers) |

  > **⚠️ Data Validation is NOT security:** It only prevents wrong entries during manual typing. If someone copies and pastes data into the cell, validation won't stop it.

  > **💡 Pro tip:** Use Data Validation for ANY column where data must be consistent — Status columns (Active/Inactive), Department columns (Sales/IT/Marketing), or Grade columns (A/B/C/D/F).

### Conditional Formatting — Automatic Colors

  Conditional Formatting changes a cell's appearance **automatically** based on its value. No need to manually color "Pass" cells green and "Fail" cells red — Excel does it for you.

  **Common uses in offices:**

  | Scenario | What to Do | Result |
  |---|---|---|
  | **Highlight Pass/Fail** | Select Result column → Conditional Formatting → Highlight Cell Rules → "Equal To" → type "Pass" → choose green fill | All "Pass" cells turn green automatically |
  | **Mark low marks** | Select marks column → Conditional Formatting → Highlight Cell Rules → "Less Than" → type 33 → choose red fill | Marks below 33 turn red — failing students visible instantly |
  | **Top performers** | Select column → Conditional Formatting → Top/Bottom Rules → Top 10% → choose green | Top 10% students highlighted |
  | **Duplicate values** | Select column → Conditional Formatting → Highlight Cell Rules → Duplicate Values → choose red | Duplicate entries highlighted — easy to spot and fix |
  | **Data bars** | Select column → Conditional Formatting → Data Bars → choose gradient | Each cell gets a bar proportional to its value — instant visual comparison |
  | **Color scales** | Select column → Conditional Formatting → Color Scales → green-yellow-red | Highest values green, mid yellow, lowest red — like a heat map |

  **How to apply:**

  1. Select the range you want to format (e.g., G2:G51 — the Result column)
  2. Home → Conditional Formatting → choose a rule
  3. Set the condition and format
  4. Click OK — formatting applies instantly and updates automatically if values change

  > **💡 Rule priority:** If you apply multiple rules to the same range, the rule higher in the list wins. You can reorder rules in Conditional Formatting → Manage Rules.

  > **⚠️ What Conditional Formatting is NOT:** It doesn't change the actual value in the cell. It only changes how the cell looks. A cell colored red still contains the same number — only the appearance changes.
