In the last chapter, we learned Pivot Tables for summarizing data. Now let's make that data visual with **charts**. A chart can show patterns in your data instantly — which subject students are weak in, how sales are trending, what percentage pass vs fail. In the next chapter, we'll finish Excel with printing, sharing, and protecting your work.


### Why Charts Matter

Numbers in a table are hard to understand quickly. A chart shows the same data visually, and patterns become obvious in seconds.

| Data | Chart Shows Instantly |
|---|---|
| Monthly sales numbers | Which month had the highest sales? Is there a trend? |
| Subject-wise averages | Which subject is the class weak in? |
| Pass vs Fail | What percentage of students passed? |

---

### Chart Types

| Chart Type | Best For | Example |
|---|---|---|
| **Bar / Column** | Comparing categories | Average marks by subject |
| **Line** | Showing trends over time | Monthly sales Jan-Dec |
| **Pie** | Showing parts of a whole | Pass vs Fail percentage |
| **Scatter** | Relationship between two values | Study hours vs exam scores |

> **💡 Tip:** Use **Column charts** for most office needs. They're easy to read and look professional. Pie charts are best when you have 2-5 categories.

---

### Creating a Chart

1. **Select your data** (including headers)
2. **Insert → Charts section** → choose a chart type
3. The chart appears on your sheet

**For a bar chart showing subject averages:**
1. Create a small table with subject names and their averages
2. Select both columns
3. Insert → Column Chart (first option)
4. A bar chart appears instantly

---

### Customizing Charts

Once the chart is created, you can customize it:

| Element | How to Edit |
|---|---|
| **Chart Title** | Click the title text → type a new title |
| **Axis Titles** | Chart Design → Add Chart Element → Axis Titles |
| **Colors** | Chart Design → Change Colors |
| **Data Labels** | Chart Design → Add Chart Element → Data Labels |
| **Move Chart** | Chart Design → Move Chart → New Sheet (creates a separate chart sheet) |

**Double-click** any element (bars, axis, legend) to open the Format pane on the right with detailed options.

---

### Creating a Dashboard

A **dashboard** combines multiple charts and tables on one sheet for a quick overview.

**Steps:**
1. Create your charts on separate sheets or next to each other
2. Copy a chart: right-click the chart → **Copy** (or `Ctrl+C`)
3. Go to a new sheet → **Paste** (`Ctrl+V`)
4. Arrange the charts side by side
5. Add titles and labels

> **💡 Tip:** Hold **Alt** while dragging a chart to snap it to the grid lines — this makes alignment perfect.

---

### Charts and Pivot Tables

You can create a chart directly from a Pivot Table:
1. Click anywhere in the Pivot Table
2. Insert → Chart → choose a type
3. The chart updates automatically when you refresh the Pivot Table
