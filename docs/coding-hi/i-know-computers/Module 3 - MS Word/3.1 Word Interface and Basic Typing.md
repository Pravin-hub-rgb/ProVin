# Module 3 — MS Word

**Why this module matters:**  
Every office uses Word for letters, reports, notices, and forms. Knowing how to create a properly formatted document makes you look professional and capable.


In Module 2, we learned how to use the internet and email safely. Now let's move to creating documents — the most common task in any office. **Microsoft Word** is where letters, reports, notices, and memos are made. In this chapter, we'll understand Word's interface and learn basic typing and saving. In the next chapter, we'll format text to make documents look professional.

### Word Interface

When you open Word, you see several parts. Here's what each one does:

![Word Interface — Annotated](/diagrams/iknowcomputers/word-interface.svg)

| Part | Location | What It Does |
|---|---|---|
| **Ribbon** | Top (tabs: Home, Insert, Design, etc.) | All tools are organized here in tabs |
| **Quick Access Toolbar** | Top-left corner | Save, Undo, Redo — always visible |
| **Document Area** | Center (white space) | Where you type your content |
| **Status Bar** | Bottom | Word count, page number, zoom slider |
| **Ruler** | Top and left of the document | Shows margins — drag to adjust |
| **Scroll Bar** | Right side | Move up and down through the document |

> **💡 Tip:** If you ever can't find a tool, use the **Search** bar at the very top of the ribbon (Alt+Q) — just type what you need.

---

### Creating and Saving a Document

| Action | How to Do It | Shortcut |
|---|---|---|
| **New blank document** | File → New → Blank Document | `Ctrl+N` |
| **Save for the first time** | File → Save As → choose location and name | `Ctrl+S` |
| **Save changes** | Just press Ctrl+S — it overwrites the file | `Ctrl+S` |
| **Save as a different format** | File → Save As → choose format (PDF, etc.) | `F12` |
| **Open an existing document** | File → Open → browse to the file | `Ctrl+O` |

**File naming tip:** Use a clear name like `MeetingNotes_Oct2024.docx` — not `document1.docx`.

### Basic Typing Tips

| Key | What It Does |
|---|---|
| **Enter** | Start a new paragraph (adds space above) |
| **Shift+Enter** | New line within the same paragraph (no extra space) |
| **Tab** | Indent the first line of a paragraph |
| **Backspace** | Delete the character before the cursor |
| **Delete** | Delete the character after the cursor |
| **Arrow keys** | Move the cursor through text |
| **Ctrl+Arrow** | Jump one word at a time |
| **Ctrl+Home** | Go to the very beginning of the document |
| **Ctrl+End** | Go to the very end of the document |

### Word Count

The status bar at the bottom shows the word count automatically. Click on it to see more details — characters, paragraphs, lines.

You can also go to **Review → Word Count** for the full breakdown.

> **💡 Office tip:** Many office tasks ask for documents with a specific word count (like "500 words minimum"). Keep an eye on the word count as you type.
