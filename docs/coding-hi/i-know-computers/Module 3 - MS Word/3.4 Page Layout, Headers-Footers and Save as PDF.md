### Page Layout

Go to the **Layout** tab on the ribbon to adjust the page settings:

| Setting | Options | When to Use |
|---|---|---|
| **Margins** | Normal (1 inch), Narrow (0.5 inch), Wide (1.5 inch) or Custom | Narrow saves paper, Normal is standard |
| **Orientation** | Portrait (tall) or Landscape (wide) | Portrait for letters, Landscape for wide tables |
| **Size** | A4 (standard in India), Letter (US), or Custom | Always A4 for Indian offices |
| **Columns** | 1, 2, or 3 columns | Newsletters or brochures |

**Page Break (Ctrl+Enter):**
  A page break forces content to start on the next page — useful when a chapter or section should begin on a new page.
  - Place your cursor where you want the new page to start
  - Press `Ctrl+Enter` — everything after the cursor jumps to the next page
  - Or: Insert → Page Break

  > **⚠️ Don't press Enter repeatedly to reach a new page.** That creates messy formatting that breaks when you edit text above. Always use `Ctrl+Enter` (Page Break) instead.

**To change margins:**
  - Layout → Margins → choose from the list or click "Custom Margins"
  - In the dialog box, enter exact values for Top, Bottom, Left, Right

> **💡 Office tip:** For documents that will be printed and filed, use **Narrow margins** to save paper. For formal letters, use **Normal margins**.

### Headers and Footers

A **header** appears at the top of every page. A **footer** appears at the bottom of every page.

**What goes in a header:** Document title, company name, logo, chapter name  
**What goes in a footer:** Page numbers, date, file name, confidentiality notice

**To add a header or footer:**
1. Go to **Insert → Header** (or Footer)
2. Choose a style from the gallery (or "Blank" for a simple one)
3. Type your content
4. Double-click outside the header/footer area to close it

> **💡 Tip:** Font in headers and footers is usually smaller than the main text — 8pt to 10pt is standard.

---

### Page Numbers

**To add page numbers:**
  - Insert → Page Number → choose a position (Top of Page, Bottom of Page, etc.)
  - Choose a style

**To start page numbering from a specific number:**
  - Insert → Page Number → Format Page Numbers → Start at: 1 (or any number)

**To remove page numbers from the first page (title page):**
  - Double-click the header/footer area → check **Different First Page**
  - Now the first page can have no page number while the rest have it

### Print Preview and Printing

Always check **Print Preview** before printing — it shows exactly how the document will look on paper.

**To open Print Preview:**
  - `Ctrl+P` — the Print dialog opens with a preview on the right side

**What to check in the preview:**
  - Is any text cut off at the margins?
  - Are page breaks in the right place?
  - Does the table fit on one page?
  - Is the header/footer visible?

**To print:** Click the Print button (or select "Microsoft Print to PDF" to save as PDF instead)

---

### Save as PDF

PDF (Portable Document Format) is the standard format for sharing documents. Anyone can open a PDF — they don't need Word installed.

**Method 1 — Save As:**
  - File → Save As → choose a location → in "Save as type" dropdown, select **PDF** → Save

**Method 2 — Print to PDF:**
  - `Ctrl+P` → in the printer dropdown, select **Microsoft Print to PDF** → Print → choose a location

> **💡 Office tip:** Always send **PDF** files to people outside your company. Send **Word (.docx)** only when the person needs to edit the document.

### Professional Documents — Business Letter

  A **business letter** is a formal letter sent to customers, partners, or government offices. Every office writes these.

  **Standard business letter format:**

  ```
  [Your Company Name]
  [Your Address]
  [City, State, PIN]

  Date: [DD-Mon-YYYY]

  To,
  [Recipient's Name]
  [Recipient's Designation]
  [Company Name]
  [Address]

  Subject: [Clear subject line — what this letter is about]

  Dear [Sir/Ma'am/Name],

  [Opening paragraph — introduce yourself and state the purpose]

  [Body paragraph — main details, explanation, or request]

  [Closing paragraph — next steps, thank you, or call to action]

  Yours faithfully / Sincerely,

  (Your Signature)

  [Your Typed Name]
  [Your Designation]
  [Phone / Email]
  ```

  **Key formatting tips for business letters:**
  - Use a professional font: **Calibri** or **Times New Roman**, size **11pt or 12pt**
  - Line spacing: **1.15** or **1.5** — not too tight, not too loose
  - Left-align everything (not justified for letters)
  - Add a blank line between paragraphs (don't indent first lines)
  - Keep it to **one page** if possible

  > **💡 In Indian offices:** "Yours faithfully" is used when you start with "Dear Sir/Ma'am" (formal). "Yours sincerely" is used when you start with the person's name (e.g., "Dear Mr. Sharma").

### Professional Documents — Office Memo

  A **memo** (memorandum) is used for internal communication within a company — informing staff about policy changes, meetings, or announcements.

  **Standard memo format:**

  ```
  MEMORANDUM

  TO:     [All Staff / Department Name / Individual Name]
  FROM:   [Your Name / Manager Name]
  DATE:   [DD-Mon-YYYY]
  SUBJECT: [Clear subject line]

  [Body — start directly, no greetings needed]

  [Use bullet points for multiple items]

  [Closing — action required or next steps]
  ```

  **Difference between a letter and a memo:**

  | Feature | Business Letter | Office Memo |
  |---|---|---|
  | **Sent to** | People outside the company | People inside the company |
  | **Format** | Formal — address, salutation, signature | Simple — To, From, Date, Subject |
  | **Greeting** | Dear Sir/Ma'am | No greeting needed |
  | **Signature** | Yes — full name and designation | Initials or name at the end |
  | **Language** | Formal and polite | Direct and to the point |
