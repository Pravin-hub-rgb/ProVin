# Module 1 — OS, Files, Folders & Shortcuts

**Why this chapter matters:**
Knowing how to manage Windows — find files instantly, compress folders, clean up disk space, take screenshots, and keep the system secure — makes you self-sufficient. You won't need to call IT for small tasks.

### 🔍 Windows Search — Find Anything Instantly

  Instead of clicking through folders to find a file, use **Windows Search** — it searches your entire computer in seconds.

  **How to search:**
  - Press `Windows + S` (or click the search bar next to the Start button)
  - Type what you're looking for — file name, program name, or even a word inside a document
  - Results appear instantly — click to open

  **Advanced search tips:**

  | What You Want | Type This | Example |
  |---|---|---|
  | A file by name | The file name (or part of it) | `marksheet` finds any file with "marksheet" in the name |
  | A specific program | The program name | `excel` opens Excel, `chrome` opens Chrome |
  | A document by content | A word that's inside the document | `invoice` finds any document containing "invoice" |
  | A setting | The setting name | `printer` opens printer settings, `bluetooth` opens Bluetooth settings |

  > **💡 Pro tip:** Press `Windows + S`, type `calc` → opens Calculator. Type `notepad` → opens Notepad. This is the fastest way to open any program.

  > **⚠️ What Search is NOT:** Search doesn't find files on external drives (USB, external HDD) by default. It only searches your main computer drives.

### 🗜️ ZIP Files — Compress and Extract

  A **ZIP file** is like a suitcase — it packs multiple files (or a whole folder) into one smaller package. Useful for emailing multiple files or saving space.

  **Create a ZIP file (compress):**
  1. Select the file(s) or folder you want to compress
  2. Right-click → **Send to** → **Compressed (zipped) folder**
  3. A new `.zip` file appears with the same name — rename it if needed

  *Example: You have 10 photos totalling 50MB. Select them all → right-click → Send to → Compressed folder → they become one 45MB `.zip` file. Much easier to email.*

  **Extract a ZIP file (unzip):**
  1. Right-click the `.zip` file
  2. Choose **Extract All** (or "Extract Here" with third-party tools)
  3. Choose a destination folder → click Extract
  4. The original files appear in the destination folder

  **What you can ZIP:**
  - Multiple files into one package
  - A whole folder (including sub-folders) into one ZIP
  - Large files to make them smaller (though some files like photos don't shrink much)

  > **⚠️ ZIP is NOT encryption:** Anyone can open a ZIP file and see its contents. ZIP files can have a password, but that's a separate feature — basic ZIP doesn't protect your files.

### 🧹 Disk Cleanup — Free Up Space

  Over time, Windows accumulates temporary files, old downloads, and system junk. **Disk Cleanup** removes these safely.

  **How to run Disk Cleanup:**
  1. Press `Windows + S`, type `disk cleanup`, press Enter
  2. Select the drive you want to clean (usually C:)
  3. Windows scans and shows you what can be deleted
  4. Check the boxes for files you want to remove:

  | What to Delete | Description | Safe to Delete? |
  |---|---|---|
  | **Temporary Internet Files** | Cached web pages from browsers | ✅ Yes — they'll reload when needed |
  | **Recycle Bin** | Deleted files still sitting in Recycle Bin | ✅ Yes if you've checked what's inside |
  | **Temporary files** | Files created by programs temporarily | ✅ Yes — most are leftovers |
  | **Windows Update Cleanup** | Old update files after Windows updated | ✅ Yes — frees the most space |
  | **Downloads** | Files in your Downloads folder | ⚠️ Only if you don't need them |

  5. Click **OK** → **Delete Files** — the space is freed up

  > **💡 How much space can you free?** A typical Disk Cleanup frees 2-5 GB. If Windows recently updated, it can free 10-20 GB.

  > **💡 Office habit:** Run Disk Cleanup once a month to keep your computer running smoothly.

### 📸 Screenshots — Capture Your Screen

  Taking a screenshot (capturing an image of your screen) is useful for showing errors, saving information, or creating tutorials.

  **Methods to take screenshots in Windows:**

  | Method | What It Does | Best For |
  |---|---|---|
  | **Print Screen (PrtScn)** | Copies the entire screen to clipboard — paste (`Ctrl+V`) into Paint, Word, or an email | Quick captures |
  | **Alt + Print Screen** | Copies only the **active window** to clipboard | Capturing just one program |
  | **Windows + Shift + S** | Opens **Snipping Tool** — select a rectangular area, a window, or the full screen | Precise captures — saves as image automatically |
  | **Windows + PrtScn** | Saves the entire screen as a PNG file in `Pictures → Screenshots` | Saving screenshots automatically |

  **Snipping Tool (Windows + Shift + S) — most useful:**
  1. Press `Windows + Shift + S` — the screen dims
  2. Drag to select the area you want to capture
  3. The screenshot is copied to clipboard AND shown as a notification
  4. Click the notification to open and save it, or paste directly (`Ctrl+V`) where you need it

  > **💡 Office use:** Need to show IT support an error message? Take a screenshot with `Windows + Shift + S` and paste it into an email. They'll see exactly what you see.

### 🛡️ Windows Defender — Built-in Antivirus

  Windows comes with a built-in antivirus called **Microsoft Defender**. It's free, always running, and good enough for most office work.

  **Check if Defender is active:**
  1. Press `Windows + S`, type `Windows Security`, press Enter
  2. Look at **Virus & threat protection** — it should show a green checkmark
  3. If it shows yellow or red, click it and follow the instructions to turn protection on

  **Run a manual scan:**
  1. Windows Security → **Virus & threat protection**
  2. Click **Scan options** → choose **Full scan** (takes longer but checks everything)
  3. Click **Scan now** — Defender checks every file on your computer
  4. If threats are found, click **Remove or quarantine**

  > **⚠️ Do NOT install two antivirus programs:** Having both Defender and another antivirus (like Norton or McAfee) causes conflicts and slows your computer. Use one — Defender is enough for most offices.

  **Real-time protection:**
  - Defender runs **constantly in the background** — when you download a file, it scans it immediately
  - If it finds a threat, it blocks the file and notifies you
  - You don't need to do anything — it just works

### 💿 Software Install and Uninstall

  As a computer operator, you'll need to install new software and remove old ones.

  **Installing software:**
  1. Download the installer from the **official website** (e.g., `7-zip.org` for 7-Zip)
  2. Open the Downloads folder → double-click the `.exe` or `.msi` file
  3. If Windows shows a warning ("Windows protected your PC"), click **More info** → **Run anyway** (this happens for less common software)
  4. Follow the installer steps:
     - **License agreement** → Accept
     - **Install location** → Leave as default (usually `C:\Program Files`)
     - **Additional offers** → Uncheck any extra software offers (browser toolbars, etc.)
  5. Click **Install** → wait for completion → **Finish**
  6. The program appears in the Start Menu and is ready to use

  **Uninstalling software:**
  1. Press `Windows + S`, type `Add or remove programs`, press Enter
  2. Scroll through the list or search for the program name
  3. Click the three dots (⋮) next to the program → **Uninstall**
  4. Follow the uninstaller steps → **Yes** to confirm

  > **💡 Why uninstall?** Old programs take up space and sometimes run in the background, slowing your computer. Uninstall anything you don't use.

  > **⚠️ Be careful:** Only uninstall programs you recognize. Don't remove things like "Microsoft Visual C++" or "Device drivers" — those are needed by Windows.

### ⚙️ Control Panel and Settings

  **Settings** (modern) and **Control Panel** (old) are where you configure your computer.

  **How to open Settings:**
  - `Windows + I` (quickest way)
  - Or click Start → Settings (gear icon)

  **Common settings you'll use:**

  | Setting | How to Find It | What You Can Do |
  |---|---|---|
  | **Display** | Settings → System → Display | Change screen resolution, brightness, text size |
  | **Sound** | Settings → System → Sound | Change speaker volume, microphone, sound devices |
  | **Bluetooth** | Settings → Bluetooth & devices | Connect wireless mouse, keyboard, speaker |
  | **Printers** | Settings → Bluetooth & devices → Printers | Add a printer, see printer queue, set default printer |
  | **User Accounts** | Settings → Accounts | Change password, add new user, manage family |
  | **Network** | Settings → Network & Internet | Connect to WiFi, see network status, troubleshoot |
  | **Update & Security** | Settings → Update & Security | Check for Windows updates, run Windows Security |

  > **💡 Settings vs Control Panel:** Windows is moving everything to the modern **Settings** app. But some old options are still in **Control Panel** only. If you can't find something in Settings, search for it in Control Panel (`Windows + S` → type `control panel`).
