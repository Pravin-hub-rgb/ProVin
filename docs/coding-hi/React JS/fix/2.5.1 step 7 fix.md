## Sabse Important Point

`onToggle` aur `isActive` dono `activeIndex` use karte hain, lekin dono ka kaam alag hai.

* `onToggle` → **State update karta hai.**
* `isActive` → **Updated state ko dekhkar UI render karta hai.**

Isliye pehle **button click → state update → React re-render → `isActive` evaluate → panel open/close** hota hai.
