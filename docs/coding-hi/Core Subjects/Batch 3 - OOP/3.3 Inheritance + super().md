Ek class apni properties aur methods doosri class ko de sakti hai — bina dobara likhe. `extends` se child class parent ki properties/methods leti hai. Ye sab **inheritance** hai — ek type dusri type ki properties/methods leta hai.

Database mein bhi yahi hai — **parent table** aur **child table**. Child table parent ki properties inherit karta hai (foreign key ke through).

---

# Inheritance

## Inheritance Kya Hai

**Inheritance** = ek class (child) dusri class (parent) ki properties aur methods ko **reuse** kar sakti hai, bina dobara likhe.

```typescript
// Parent class
class Vehicle {
  constructor(public brand: string, public speed: number) {}

  displayInfo(): string {
    return `${this.brand} chal raha hai ${this.speed} km/h par`;
  }
}

// Child class — Vehicle se inherit
class Car extends Vehicle {
  constructor(brand: string, speed: number, public doors: number) {
    super(brand, speed); // Parent constructor call karna zaroori hai
  }

  honk(): string {
    return "Pom Pom!";
  }
}

const myCar = new Car("Honda", 120, 4);
console.log(myCar.displayInfo()); // Vehicle se inherited method
console.log(myCar.honk()); // Car ka apna method
```

**Database analogy:**
```
Vehicle (parent)          Car (child)
─────────────            ──────────────
brand: string     ───►   brand: string (inherited)
speed: number     ───►   speed: number (inherited)
displayInfo()     ───►   displayInfo() (inherited)
                        doors: number (child ka apna)
                        honk() (child ka apna)
```

## extends — Inheritance Ka Keyword

`extends` se child class parent se inherit karti hai:

```typescript
class Parent {
  constructor(public name: string) {}

  greet(): string {
    return `Hello, ${this.name}`;
  }
}

class Child extends Parent {
  constructor(name: string, public age: number) {
    super(name); // Parent ka constructor call karo — pehla line mein hona chahiye
  }

  introduce(): string {
    return `${this.greet()}! I'm ${this.age} years old.`;
    // greet() parent se inherited hai
  }
}

const child = new Child("Vin", 25);
console.log(child.introduce()); // "Hello, Vin! I'm 25 years old."
```

## super() — Parent Constructor Call Karna

`super()` = parent class ka constructor call karna. **Child class ke constructor mein pehla line mein `super()` hona zaroori hai.**

```typescript
class Vehicle {
  constructor(public brand: string) {
    console.log(`Vehicle created: ${brand}`);
  }
}

class Car extends Vehicle {
  constructor(brand: string, public doors: number) {
    super(brand); // ✅ Parent constructor called first
    // Ab this.brand available hai
    console.log(`Car created with ${doors} doors`);
  }
}

// Agar super() nahi likha:
class BadCar extends Vehicle {
  constructor(brand: string) {
    // ❌ Error! Must call super() first
    // console.log(this.brand); // Error! this abhi initialize nahi hua
  }
}
```

**TypeScript rule:** `super()` constructor mein **pehla statement** hona chahiye. Uske baad `this` access kar sakte ho.

## Method Overriding — Child Ka Apna Version

Child class parent ke method ko apne tarike se **redefine** kar sakti hai — ye **method overriding** hai.

```typescript
class Shape {
  area(): number {
    return 0; // Default — 0 area
  }

  describe(): string {
    return `Shape with area ${this.area()}`;
  }
}

class Circle extends Shape {
  constructor(public radius: number) {
    super();
  }

  // Method overriding — parent ka method override
  override area(): number {
    return Math.PI * this.radius * this.radius;
  }
}

class Rectangle extends Shape {
  constructor(public width: number, public height: number) {
    super();
  }

  override area(): number {
    return this.width * this.height;
  }
}

const shapes: Shape[] = [new Circle(5), new Rectangle(4, 6)];
shapes.forEach(shape => console.log(shape.area()));
// Circle: 78.54, Rectangle: 24
// Same method call, different behavior
```

**`override` keyword:** TypeScript mein `override` lagana best practice hai — taaki pata chale ki ye parent ka method override ho raha hai. Agar parent mein method nahi hoga toh error aayega.

## Types of Inheritance

### Single Inheritance
```
Animal → Dog
Ek parent, ek child
```

### Multilevel Inheritance
```
Animal → Mammal → Dog
Chain: A → B → C
```

### Hierarchical Inheritance
```
Vehicle → Car
Vehicle → Truck
Vehicle → Bike
Ek parent, multiple children
```

### Multiple Inheritance — TypeScript Mein Nahi Hoti

```typescript
// ❌ TypeScript/JavaScript mein multiple inheritance nahi hoti
class Flyable { fly() {} }
class Swimmable { swim() {} }

// class Duck extends Flyable, Swimmable { } // ❌ Error!
```

**Solution: Interfaces use karo:**
```typescript
interface Flyable {
  fly(): void;
}

interface Swimmable {
  swim(): void;
}

class Duck implements Flyable, Swimmable {
  fly() { console.log("Flying"); }
  swim() { console.log("Swimming"); }
}
```

**Database analogy:** Single inheritance = one parent table. Multiple inheritance = many-to-many relationship (junction table).

## DukaanOS Context

```typescript
// Base class
class InventoryItem {
  constructor(
    public id: string,
    public name: string,
    protected quantity: number
  ) {}

  isAvailable(): boolean {
    return this.quantity > 0;
  }

  reduceStock(amount: number): void {
    if (amount > this.quantity) throw new Error("Insufficient stock");
    this.quantity -= amount;
  }
}

// Child class — specific item type
class PerishableItem extends InventoryItem {
  constructor(
    id: string,
    name: string,
    quantity: number,
    public expiryDate: Date
  ) {
    super(id, name, quantity);
  }

  isExpired(): boolean {
    return new Date() > this.expiryDate;
  }

  // Override — perishable item ka alag behavior
  override isAvailable(): boolean {
    return this.quantity > 0 && !this.isExpired();
  }
}

const milk = new PerishableItem("1", "Milk", 10, new Date("2024-01-15"));
console.log(milk.isAvailable()); // false — expired hai
milk.reduceStock(5); // ✅ inherited method
console.log(milk.isExpired()); // ✅ child ka apna method
```

## What It Is NOT

⚠️ **Inheritance = code copy-paste nahi.** Inheritance se code **reuse** hota hai — ek jagah likho, baaki jagah inherit karo. Copy-paste se duplication hota hai.

⚠️ **Inheritance = hamesha sahi nahi.** Composition (objects ko embed karna) sometimes better hai inheritance se. "Has-a" relationship ke liye composition, "is-a" ke liye inheritance.

⚠️ **Multiple inheritance = TypeScript mein nahi.** C++ mein hoti hai, TypeScript mein nahi. Solution: Interfaces use karo.

## In Your Own Words

1. `extends` keyword kya karta hai? `super()` kyun zaroori hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** `extends` se child class parent se inherit karti hai — parent ki properties/methods reuse karti hai. `super()` parent ka constructor call karta hai — child class ke constructor mein pehla line mein hona zaroori hai, taaki parent initialize ho jaaye aur `this` available ho jaaye.

</details>

2. Method overriding kya hai? TypeScript mein `override` keyword kyun use karte ho?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Method overriding = child class parent ke method ko apne tarike se redefine karti hai. Jaise Circle `area()` override karke apna area calculate karta hai. `override` keyword se TypeScript check karta hai ki parent mein method hai — agar nahi hai toh error aata hai.

</details>

3. TypeScript mein multiple inheritance kyun nahi hoti? Solution kya hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Multiple inheritance mein ek class do parents se extend karti hai — diamond problem hoti hai (konsa method use karun?). TypeScript/JavaScript mein ye nahi hota. Solution: Interfaces use karo — `class Duck implements Flyable, Swimmable`. Interfaces sirf contract define karte hain, implementation child class deti hai.

</details>

4. `extends` aur `implements` mein kya fark hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** `extends` = inheritance — parent ki properties + methods + implementation inherit karta hai. `implements` = contract — sirf method signatures define hote hain, implementation child class deti hai. `extends` mein `super()` hota hai, `implements` mein nahi.

</details>
