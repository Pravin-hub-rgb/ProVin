## 4 Core Tools (FastAPI ke dil ki baatein)

FastAPI itna flexible framework hai ki kuch bhi kar sakta hai — lekin uske 90% kaam **in 4 tools** se hote hain. Rozi jindagi me bas yahi 4 baar use karoge.

Pehle ek relatable example se samajhte hain. Socho tum **dawai ki dukaan** ja rahe ho.

Dawai chahiye. Counter pe gaya. BOLA — *"Mujhe 5 strip chahiye, orange wali."* Dukaandar ne dekha aur pucha — *"Panadol chalega?"* Tumne bola — *"Haan."*

Ab ise decode karte hain:

| Dawai dukaan | FastAPI me |
|---|---|
| *"5 strip chahiye"* — **kitna**, kahan se lena (path) | **Path parameter** — `/api/stocks/{symbol}` |
| *"orange wali, zyada stock me se filter"* — **filter, option** | **Query parameter** — `?limit=10&sector=IT` |
| Dukaandar ke paas **list hai** — GET | **GET request** — data nikalna |
| Tumne **di diya** (order diya) — POST | **POST request** — naya data bhejna |
| Dukaandar ne **check kiya** ki tumhe allergy toh nahi | **Pydantic** — data validate karna |
| Dukaandar ki **khud ki list/register** me likha | **SQLite** — data save karna |

Bas yahi 4 tools hain. Ye 4 milke poora CRUD ban jaata hai.

## "Manual → Better" — ek nazar

Ye pattern poori course me chalega. Pehle se hi dekh lo:

| Pehle (dard) | Phir (FastAPI) |
|-------------|-----------------|
| URL khud string parse karo (`if "/stocks/" in url`) | **Path param** — `symbol` seedha function me |
| Filter ke liye query string khud padho | **Query param** — `?limit=10` automatic |
| Data validate karne ke liye 20 `if` statements | **Pydantic** — 1 class, automatic 422 |
| Data memory me list me rakhо (restart pe gayab) | **SQLite** — file me, restart pe bhi |

## Kyun TradeStack Ka Shape?

Tumne TradeStack banaya hai — asli wala, `backend/server.py` wala. To sawal ye hai — **Phase 1 me hum wahi kyun nahi padhte?**

Teen wajah:

1. **Asli server 930 lines hai, 48 endpoints hain, 14 modules.** Usko shuru se padhoge toh doob jaoge. Chhota banao, poora samjho, phir bade ko padho — tab wo bada lagega nahi, chhota lagega.

2. **Asli code me kuch cheezein aise hain jo seekhne se pehle confusing lagti hain** — jaise `BackgroundTasks`, multiprocessing, cache fallback. Bina foundation ke woh sirf dikhti hain ki "ye kya hai." Foundation ke baad woh samajh me aati hain.

3. **Interview me koi nahi poochta "bade server ka code padhao."** Wo poochta hai *"FastAPI kya hai, ek endpoint kaise likhte ho."* Chhota project tumhe wo answer khud se dene layak banata hai — bina bade code ki copying kiye.

Toh chhota banate hain, pura samajhte hain. Phir Phase 3 me asli `server.py` khologe aur har line samjhoge — kyunki tumhare paas foundation hai.
