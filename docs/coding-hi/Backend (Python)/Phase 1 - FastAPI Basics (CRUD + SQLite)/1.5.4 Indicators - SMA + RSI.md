## Manual Tareeka (dard wala)

Socho tu Python me **bina pandas** RSI calculate karna chahta hai. Ye karega:

```python
def calculate_rsi(prices, period=14):
    # Price changes nikaal
    changes = [prices[i] - prices[i-1] for i in range(1, len(prices))]

    # Gain aur loss alag karo
    gains = [c if c > 0 else 0 for c in changes]
    losses = [-c if c < 0 else 0 for c in changes]

    # Last 'period' ka average
    avg_gain = sum(gains[:period]) / period
    avg_loss = sum(losses[:period]) / period

    # RSI formula
    rs = avg_gain / avg_loss if avg_loss > 0 else 0
    rsi = 100 - (100 / (1 + rs))
    return rsi
```

Ye **ek symbol ke liye theek hai.** Par ab socho — tumhare paas **2000 stocks hain**, har ek ke liye ye chalana hai. Aur har stock ke **kya 60 din ke prices** hain.

Ye **loop chalayega** — 2000 stocks × har stock ke liye internal loops. Python loop **slow** hai — ek ek value process karta hai, ek ek karke.

**Abhi 5 stocks pe koi dikkat nahi.** Par TradeStack pe 2000 stocks hain, aur real scanner me har stock ke liye **13 alag indicators** compute karne hote hain. Ye manual loops **minutes** le lenge. **Yahi problem pandas solve karta hai.**

## Concept: Pandas Kya Hai (Simple Bhasha Me)

Pandas ek **library** hai jo tables (dataframes) ke saath kaam karti hai. Lekin isme ek **special baat** hai jo isko trading/analytics me perfect banati hai:

**Pandas ka kaam rows pe, aur wo C-level pe chalta hai.**

Samajho — jab tum Python loop likhte ho:
```python
total = 0
for price in prices:
    total += price     # ek ek karke, dheere dheere
```
Har iteration me Python ka overhead hai — bohot slow for 2000 stocks.

Pandas me same kaam **ek line** me hota hai:
```python
total = prices.sum()   # saare prices ek saath, tez
```
Ye internally C code use karta hai — bahut tez.

**Analogy:** Socho 2000 students ki height calculate karni hai average nikalne ke liye.
- **Python loop** — ek ek student ko ruler lagao, likho, next. Dheere.
- **Pandas** — sabko ek line khadi karo, ek experiment se height nikaalo. Tez.

Pandas do cheezein deta hai jo is project me chahiye:
1. **DataFrame** — table (jaise Excel) jisme fast operations ho sakein
2. **Vectorized operations** — columns pe ek saath math

def init_db():
    DB_PATH.parent.mkdir(parents=True, exist_ok=True)

    conn = get_conn()

    # stocks table (pehle se hai)
    conn.execute("""
        CREATE TABLE IF NOT EXISTS stocks (
            id INTEGER PRIMARY KEY AUTOINCREMENT,

            name TEXT NOT NULL,
            sector TEXT,
            last_price REAL,
            active INTEGER DEFAULT 1
        )
    """)

    # NEW: prices table — time-series data
    conn.execute("""
        CREATE TABLE IF NOT EXISTS prices (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            symbol TEXT NOT NULL,
            date TEXT NOT NULL,
            open REAL,
            high REAL,
            low REAL,
            close REAL,
            UNIQUE(symbol, date)          # ek symbol, ek date — dobara nahi

    """)

    conn.close()

**`UNIQUE(symbol, date)` composite key** — ek hi symbol, ek hi date dobara insert nahi ho sakta. Ye real data me zaroori hai (agar bhavcopy dobara download ho jaaye, duplicate na aayein).

def seed_prices():
    conn = get_conn()

    # Table pehle se banao (agar nahi bani)
    conn.execute("""
        CREATE TABLE IF NOT EXISTS prices (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            symbol TEXT NOT NULL,
            date TEXT NOT NULL,
            open REAL, high REAL, low REAL, close REAL,
            UNIQUE(symbol, date)
        )
    """)

    count = 0
    with open(CSV_PATH) as f:
        reader = csv.DictReader(f)
        for row in reader:
            try:
                conn.execute(
                    """INSERT INTO prices (symbol, date, open, high, low, close)
                       VALUES (?, ?, ?, ?, ?, ?)""",
                    (
                        row["symbol"],
                        row["date"],
                        float(row["open"]),
                        float(row["high"]),
                        float(row["low"]),
                        float(row["close"]),
                    )
                )
                count += 1
            except sqlite3.IntegrityError:
                pass    # duplicate (symbol, date) — skip (idempotent seed)

    conn.commit()
    conn.close()
    print(f"Seeded {count} price rows")


if __name__ == "__main__":
    seed_prices()

## Step 4: `app/indicators.py` — Ab Asli Kaam (SMA + RSI)

Ab wo file jo poore project ka dil hai. Naya file `app/indicators.py`:

```python
"""
Technical indicators — pandas se.
Real TradeStack me 13 indicators hain; yahan 2 (SMA, RSI) se seekhte hain.
"""
import pandas as pd


def calculate_sma(prices: pd.Series, period: int = 20) -> float:
    """Simple Moving Average — last 'period' closing prices ka average."""
    return float(prices.rolling(window=period).mean().iloc[-1])


def calculate_rsi(prices: pd.Series, period: int = 14) -> float:
    """
    Relative Strength Index (0-100).
    RSI < 30 = oversold, RSI > 70 = overbought.
    """
    delta = prices.diff()          # consecutive prices ka difference
    gain = (delta.where(delta > 0, 0)).rolling(window=period).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window=period).mean()

    rs = gain / loss                # relative strength
    rsi = 100 - (100 / (1 + rs))     # RSI formula
    return float(rsi.iloc[-1])


def get_price_series(conn, symbol: str, limit: int = 60) -> pd.Series:
    """Database se ek symbol ke closing prices lao — pandas Series me."""
    rows = conn.execute(
        "SELECT date, close FROM prices WHERE symbol = ? ORDER BY date LIMIT ?",
        (symbol, limit)
    ).fetchall()

    if not rows:
        raise ValueError(f"No price data for {symbol}")

    # list of tuples -> DataFrame -> Series (sirf close ka)
    df = pd.DataFrame(rows, columns=["date", "close"])
    return df["close"]
```

**Dekho kya hua — pure Python loops khatam!**

- `prices.rolling(window=20).mean()` — last 20 ka average, **ek line**. No loop.
- `prices.diff()` — consecutive difference, vectorized.
- `.where(delta > 0, 0)` — jahan gain nahi, wahan 0.
- `.rolling(window=14).mean()` — average gain/loss.
- `100 - (100 / (1 + rs))` — RSI formula.

**Compare karo:**
- Manual: ~10 lines, har stock ke liye loop, slow.
- Pandas: ~6 lines, **poora column ek saath**, fast.

**Yehi vectorization hai.** TradeStack me bhi har indicator aise hi pandas me likha hai (`src/indicators.py`). Tu wahi kar raha hai — bas 2 indicators (SMA, RSI), wo 13.

**`get_price_series` ka kaam** — database se `close` prices nikal ke pandas Series banana. Ye **bridge** hai database aur calculation ke beech. Data pandas ko deta hai, pandas calculate karta hai.

import pandas as pd
from .db import get_conn, init_db
from .indicators import get_price_series, calculate_sma, calculate_rsi

# ... (pehle wala code)

@app.get("/api/indicators/{symbol}")
def get_indicators(symbol: str, period: int = 20):
    """
    Ek symbol ke SMA aur RSI nikalo.
    Path param: symbol (jaise /api/indicators/RELIANCE)
    Query param: period (SMA ka window)
    """
    conn = get_conn()

        prices = get_price_series(conn, symbol, limit=60)
    except ValueError as e:
        raise HTTPException(status_code=404, detail=str(e))
    finally:
        conn.close()

    if len(prices) < 20:

    trend = "bullish" if current > sma else "bearish"

    return {
        "symbol": symbol,
        "last_close": current,
        "sma": round(sma, 2),
        "rsi": round(rsi, 2),
        "trend": trend,
        "data_points": len(prices),
    }

## Extra: Kyun Data Frame Kaam Karta Hai (Vectorization Samjho)

Ye ek chhoti si cheez hai jo bahut important hai — **kyunki interview me poochha jaata hai "pandas vectorized kyun?"**

**Sochne ka tareeqa:**
- Jab tum `prices.rolling(20).mean()` likhte ho, pandas **saare 60 prices** ek saath process karta hai — ek C loop me.
- Har ek ke liye last 20 ka average nikalta hai — **ek hi pass me**, poori column ke liye.
- Manual loop me tum **60 baar alag loop** chalate — ek bar first 20 ka avg, doosri bar next 20, etc.

**Interview ka jawab (yaad rakhna):** *"Pandas vectorized operations C-level pe chalte hain. Manual Python loop me har element pe interpreter overhead aata hai — pandas ko ek hi bulk operation me saare elements pe apply karna hota hai. Isliye jab data large ho (hazaar stocks, minute-level candles), pandas dramatically faster hai. Mere scanner me 2000 stocks × 13 indicators compute karne ka kaam pandas me seconds me ho jaata hai, jo manual loops me minutes le raha."*

---

## Common Mistakes

1. **`period` se zyada data na ho.** `rolling(window=20)` ke liye kam se kam 20 values chahiye. Kam data pe `NaN` aayega. Guard lagaya (`if len(prices) < 20`).

2. **`.iloc[-1]` bhoolna.** `rolling().mean()` poora Series return karta hai. Aakhri value chahiye to `.iloc[-1]` lagana mat bhoolna, warna error aayega.

3. **`float()` cast na karna.** `.iloc[-1]` sometimes `numpy.float64` deta hai, kabhi `NaN`. `float()` cast karke return karo, aur JSON-safe banao.

4. **`NaN` handle na karna.** Pehle `period` rows ka RSI `NaN` hota hai (pichhle prices nahi hain). `round(NaN)` crash ho sakta hai ya `null` jayega. Guard rakhna.

5. **Seed na chalana.** `prices` table khaali hoga to endpoint `ValueError` dega. Pehle `python -m app.seed` chalao.

6. **Data types galat daalna CSV se.** `close` string aa sakta hai CSV se — `float(row["close"])` cast zaroori hai, warna SQLite me text chala jayega.

7. **Indicators me seed badalna.** `seed_prices.py` me `random.seed(42)` fix hai. Agar badal doge, har baar alag data — testing confuse hogi.

## Nutshell

- **pandas DataFrame** — fast table operations. `prices` table se data lao → Series me convert → indicators compute.
- **SMA** = `prices.rolling(20).mean()` — last 20 closing ka average. Current price se upar = bullish.
- **RSI** = formula with `diff()`, gain/loss averaging. RSI < 30 = oversold, > 70 = overbought.
- **Vectorization** = bulk operation in one pass (C-level), bahut faster than Python loop. Yehi pandas ka core fayda.
- **`prices` table** with `UNIQUE(symbol, date)` — time-series data store karne ke liye.
