2.1 mein tumne sikha WebSocket kya hai — ek persistent two-way connection. Ab sawal hai: kaise track karo kaun connected hai? Agar 5 log chat open karein, to tumhe pata hona chahiye kaun kaun hai aur sabko message kaise bhejo.

Yahi kaam **ConnectionManager** karta hai. Yeh duniya ka sabse simple pattern hai — ek dictionary jo connection IDs ko WebSocket objects se map karti hai.

# 2.2 ConnectionManager — Tracking Who's Connected

## Think — Coat Check at a Restaurant

Socho ek restaurant jisme coat check hai. Jab tum andar aate ho, coat de dete ho aur ticket (your ID) milta hai. Coat check wala likhta hai: "Ticket #42 → Vin ka coat." Jab tum jaate ho, ticket do, woh coat dhundh ke entry remove karta hai.

ConnectionManager same hai. Jab client connect karta hai, unka WebSocket object ID ke saath store karo. Jab disconnect karte hain, remove karo. Jab broadcast karna hai, sab stored connections loop karke har ek ko send karo.

## Concept — ConnectionManager Pattern

```python
from fastapi import WebSocket
from typing import List

class ConnectionManager:
    def __init__(self):
        # Dictionary: connection_id -> WebSocket object
        self.active_connections: dict[str, WebSocket] = {}

    async def connect(self, websocket: WebSocket, connection_id: str):
        await websocket.accept()
        self.active_connections[connection_id] = websocket

    def disconnect(self, connection_id: str):
        if connection_id in self.active_connections:
            del self.active_connections[connection_id]

    async def send_personal(self, message: str, connection_id: str):
        if connection_id in self.active_connections:
            await self.active_connections[connection_id].send_text(message)

    async def broadcast(self, message: str):
        for connection_id, websocket in self.active_connections.items():
            await websocket.send_text(message)
```

Har method:
- `connect()` — WebSocket handshake accept karo aur connection store karo
- `disconnect()` — dictionary se connection remove karo
- `send_personal()` — ek specific connection ko message bhejo
- `broadcast()` — ALL connections ko message bhejo

## The FastAPI Endpoint

```python
from fastapi import FastAPI, WebSocket
from uuid import uuid4

app = FastAPI()
manager = ConnectionManager()

@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    # Generate a unique ID for this connection
    connection_id = str(uuid4())
    
    # Connect and store
    await manager.connect(websocket, connection_id)
    
    try:
        while True:
            # Wait for a message from this client
            data = await websocket.receive_text()
            # Broadcast to everyone (including sender)
            await manager.broadcast(f"User {connection_id[:8]}: {data}")
    except Exception:
        # Client disconnected (closed browser, network drop, etc.)
        manager.disconnect(connection_id)
```

Har line:
- `uuid4()` — har connection ke liye unique ID generate karta hai (track karne ke liye kaun kaun hai)
- `manager.connect()` — handshake accept aur dictionary mein store
- `while True` — messages listen karta rehta hai
- `manager.broadcast()` — sab connected clients ko bhejta hai
- `except Exception` — disconnection handle karta hai (browser closed, network dropped)

## What ConnectionManager Is NOT

- ❌ **Not a database** — connections memory mein hain, restart pe lost
- ❌ **Not authentication** — koi bhi connect kar sakta hai, no identity verification
- ❌ **Not scalable** — sab connections ek process, ek machine mein

## Nutshell

**ConnectionManager = connection_id → WebSocket ka dictionary. connect() store karta hai, disconnect() remove, broadcast() sabko bhejta hai. Kisi bhi real-time multi-user app ka foundation.**

## Common Mistakes

- ❌ **"broadcast() is automatic"** — nahi, manually loop karke send karna padta hai
- ❌ **"disconnect() is called automatically"** — nahi, except block mein khud call karna padta hai
- ❌ **"uuid4() is the only way to identify"** — nahi, usernames, tokens, ya koi bhi unique identifier use kar sakte ho

## In Your Own Words

1. ConnectionManager kya store karta hai aur kyun?

<details>
<summary>Sample Answer</summary>

**Answer:** Yeh connection_id → WebSocket object ka dictionary store karta hai. Isse track kar sakte ho kaun connected hai, specific user ko message bhej sakte ho (send_personal), ya sabko broadcast. Iske bina connections distinguish nahi kar sakte.

</details>

2. WebSocket loop ke around `try/except` kyun chahiye?

<details>
<summary>Sample Answer</summary>

**Answer:** Kyunki client kabhi bhi disconnect ho sakta hai (browser close, network drop). Jab aisa hota hai, `receive_text()` exception throw karta hai. Except block catch karta hai aur `disconnect()` call karke dictionary clean karta hai. Iske bina disconnected clients dictionary mein forever reh jayenge (memory leak).

</details>

3. `send_personal` aur `broadcast` mein kya difference hai?

<details>
<summary>Sample Answer</summary>

**Answer:** `send_personal` ek specific connection ko bhejta hai (by ID). `broadcast` ALL connections ko bhejta hai. Chat app mein private messages ke liye `send_personal` aur room messages ke liye `broadcast` use karo.

</details>
