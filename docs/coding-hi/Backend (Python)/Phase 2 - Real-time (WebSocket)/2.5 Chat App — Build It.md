## Step 2 — room_manager.py (2.3 se)

```python
# room_manager.py
from fastapi import WebSocket
from collections import deque
from typing import Dict, List

class RoomManager:
    def __init__(self, history_size: int = 30):
        self.rooms: Dict[str, List[WebSocket]] = {}
        self.history: Dict[str, deque] = {}
        self.users: Dict[WebSocket, str] = {}   # websocket -> username
        self.history_size = history_size

    async def connect(self, websocket: WebSocket, room_id: str, username: str):
        await websocket.accept()

        if room_id not in self.rooms:
            self.rooms[room_id] = []
            self.history[room_id] = deque(maxlen=self.history_size)

        self.rooms[room_id].append(websocket)
        self.users[websocket] = username

        # Catch-up history
        for old in self.history[room_id]:
            await websocket.send_text(old)

        await self.broadcast(room_id, f"[system] {username} joined {room_id}")

    def disconnect(self, websocket: WebSocket, room_id: str):
        if room_id in self.rooms and websocket in self.rooms[room_id]:
            self.rooms[room_id].remove(websocket)
        name = self.users.pop(websocket, "anon")
        return name

    async def broadcast(self, room_id: str, message: str):
        if room_id in self.history:
            self.history[room_id].append(message)

        dead: List[WebSocket] = []
        for ws in list(self.rooms.get(room_id, [])):
            try:
                await ws.send_text(message)
            except Exception:
                dead.append(ws)
        for ws in dead:
            if ws in self.rooms.get(room_id, []):
                self.rooms[room_id].remove(ws)
            self.users.pop(ws, None)

    def room_users(self, room_id: str) -> List[str]:
        return [self.users[ws] for ws in self.rooms.get(room_id, [])]

    def room_list(self) -> List[str]:
        return list(self.rooms.keys())
```

2.3 se naya: `users` dict (websocket -> username) taaki "kaun online hai" dikha sake aur names announce kar sake. `room_users()` aur `room_list()` REST endpoints feed karte hain.

## Step 3 — main.py

```python
# main.py
import json
from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from fastapi.responses import FileResponse
from room_manager import RoomManager

app = FastAPI(title="Chat App")
manager = RoomManager(history_size=30)

@app.get("/")
async def index():
    return FileResponse("static/index.html")

@app.get("/api/rooms")
async def list_rooms():
    return {"rooms": manager.room_list()}

@app.websocket("/ws/{room_id}")
async def room_endpoint(websocket: WebSocket, room_id: str):
    # Username query param se aata hai: /ws/general?user=Vin
    username = websocket.query_params.get("user", "anon")
    await manager.connect(websocket, room_id, username)
    try:
        while True:
            raw = await websocket.receive_text()
            try:
                payload = json.loads(raw)
                text = payload.get("text", raw)
            except json.JSONDecodeError:
                text = raw

            message = f"{username}: {text}"
            await manager.broadcast(room_id, message)
    except WebSocketDisconnect:
        name = manager.disconnect(websocket, room_id)
        await manager.broadcast(room_id, f"[system] {name} left {room_id}")

if __name__ == "__main__":
    import uvicorn
    uvicorn.run("main:app", host="0.0.0.0", port=8000, reload=True)
```

Har part:
- `GET /` HTML client serve karta hai.
- `GET /api/rooms` active rooms list (room picker ke liye useful).
- `/ws/{room_id}?user=Vin` — room path se, username query param se. Clean separation.
- Disconnect pe real username announce (jo `disconnect` return karta hai).

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8" />
  <title>Chat App</title>
  <style>
    body { font-family: sans-serif; max-width: 720px; margin: 20px auto; }
    #log { height: 360px; overflow: auto; border: 1px solid #ccc; padding: 8px; }
    .sys { color: #888; font-style: italic; }
    input { padding: 6px; }
    button { padding: 6px 12px; }
  </style>
</head>
<body>
  <h2>Chat App</h2>
  <div>
    <input id="user" placeholder="your name" value="anon" />
    <input id="room" placeholder="room" value="general" />
    <button onclick="connect()">Connect</button>
    <button onclick="disconnect()">Disconnect</button>
  </div>
  <div id="log"></div>
  <div style="margin-top:8px;">
    <input id="msg" placeholder="message" style="width:80%;" />
    <button onclick="send()">Send</button>
  </div>

  <script>
    let ws = null;
    const log = document.getElementById("log");

    function append(text, sys=false) {
      const div = document.createElement("div");
      div.textContent = text;
      if (sys || text.startsWith("[system]")) div.className = "sys";
      log.appendChild(div);
      log.scrollTop = log.scrollHeight;
    }

    function connect() {
      const user = document.getElementById("user").value || "anon";
      const room = document.getElementById("room").value || "general";
      ws = new WebSocket(`ws://localhost:8000/ws/${room}?user=${encodeURIComponent(user)}`);
      ws.onopen = () => append(`[system] connected to ${room}`, true);
      ws.onmessage = (e) => append(e.data);
      ws.onclose = () => append("[system] disconnected", true);
      ws.onerror = () => append("[system] error", true);
    }

    function disconnect() { if (ws) ws.close(); }

    function send() {
      const input = document.getElementById("msg");
      if (!ws || ws.readyState !== 1) { append("[system] not connected", true); return; }
      ws.send(JSON.stringify({ text: input.value }));
      input.value = "";
    }

    document.getElementById("msg").addEventListener("keydown", (e) => {
      if (e.key === "Enter") send();
    });
  </script>
</body>
</html>
```

## Jo Tumne Banaya (Recap)

| Feature | Kahan hai |
|---------|-----------|
| WebSocket handshake + loop | `main.py` endpoint |
| Connection tracking | `RoomManager.rooms` |
| Room isolation | `broadcast(room_id)` single room tak scoped |
| Message history (last 30) | `deque(maxlen=30)` per room |
| Join/leave announcements | `connect()` / `disconnect()` |
| Usernames | query param `?user=` + `users` dict |
| Browser UI | `static/index.html` |
| Room listing | `GET /api/rooms` |

## What It Is NOT

- ❌ **Production-ready nahi** — no auth, no persistence, no rate limiting, client pe no reconnect logic.
- ❌ **Scalable nahi** — ek process, in-memory state. Multi-instance ke liye Redis pub/sub add karo.
- ❌ **Secure nahi** — usernames self-declared (koi bhi "admin" claim kar sakta hai). Real apps identity verify karte hain (JWT) `connect()` se pehle.
- ❌ **Persistent nahi** — restart se sab history wipe. `broadcast()` me SQLite/Postgres writes add karo real persistence ke liye.
- ❌ **REST ka replacement nahi** — `/api/rooms` abhi bhi HTTP hai. WebSocket sirf live stream ke liye use karo.

## Nutshell

**Full chat app = RoomManager (rooms + history + users) + FastAPI WebSocket endpoint + browser client. 2.1-2.3 ka assembly, no new concepts. Same pattern trading streams (2.4) power karta hai room_id ki jagah symbol se.**

## Common Mistakes

- ❌ **"Username from client trusted hai"** — self-declared names demos ke liye fine, real apps ke liye dangerous. Server-side verify karo.
- ❌ **"Client pe no reconnect"** — dropped connection dropped hi rehti hai. Real UX ke liye `onclose` reconnect with backoff add karo.
- ❌ **"Blocking the event loop"** — heavy work (DB queries, ML) WebSocket loop me `await` ya background tasks ke bina mat karo.
- ❌ **"One global manager vs per-room"** — room dicts wala ek manager simpler hai than many managers. Centralized rakho.
- ❌ **"Browser clients ke liye CORS bhoolna"** — frontend different origin pe ho to `CORSMiddleware` add karo. Same-origin (FastAPI serve) se avoid hota hai.

## In Your Own Words

1. Walk through kya hota hai jab Tab A room "general" me "hi" send karta hai aur Tab B "trading" me hai.

<details>
<summary>Sample Answer</summary>

**Answer:** Tab A ka message `/ws/general` hit karta hai, `broadcast("general", "Vin: hi")` `history["general"]` me store karta hai aur `rooms["general"]` ke har WebSocket ko bhejta hai (Tab A aur any other general members). Tab B `rooms["trading"]` me hai, to wo kabhi receive nahi karta. Room isolation hold karti hai.

</details>

2. Kaise persistence add karoge taaki history server restart survive kare?

<details>
<summary>Sample Answer</summary>

**Answer:** `broadcast()` me message ko room_id keyed SQLite/Postgres table me bhi `INSERT` karo. `connect()` me in-memory deque ke bajaye (ya uske saath) us room_id ke last N rows load karo. Deque hot cache ke roop me rakho.

</details>

3. Username query param se kyun liya, pehle WebSocket message se nahi?

<details>
<summary>Sample Answer</summary>

**Answer:** Query param connection time pe available hota hai, loop start hone se pehle, to `connect()` immediately name announce kar sakta hai. First-message approach extra round-trip aur "waiting for identity" state maangta hai. Dono kaam karte hain; query param demos ke liye simpler.

</details>

4. Ek room me do users same username choose karein to kya break hoga?

<details>
<summary>Sample Answer</summary>

**Answer:** Mechanically kuch nahi break hoga — messages same name do baar dikhenge. Par confusing hai. Real apps unique names enforce karte hain (ya user ID name ke saath show karte hain). Is demo ke liye acceptable.

</details>

5. Is chat app ko live price ticker (TradeStack jaisa) me kaise adapt karoge?

<details>
<summary>Sample Answer</summary>

**Answer:** room_id ko symbol se replace karo. Client-to-client messaging remove karo. Upstox se connect karne wala upstream task add karo jo har tick pe `broadcast(symbol, tick)` call kare. New subscribers ko current price de ne ke liye `latest[symbol]` cache rakho. Subscribe/unsubscribe commands join/leave replace karte hain.

</details>
