Ab tak tumhara Phase 1 project docker-compose se chal raha hoga. Ab verify karo ki sab kuch **theek se kaam karta hai** — data persists hai ya nahi, endpoints sahi se respond karte hain ya nahi, aur phir dekho kaise ye TradeStack ke saath jod sakta hai.

## Step 1: Verify all endpoints work in container

```bash
# 1. Start container (clean start)
docker compose up --build -d
# -d = detached mode (background)

# 2. Health check
curl -s http://localhost:8000/health | python -m json.tool
# Expected: {"status": "ok", "db": "connected"} (or similar)

# 3. Create a stock (seed)
curl -s -X POST http://localhost:8000/api/stocks \
  -H "Content-Type: application/json" \
  -d '{"symbol": "DOCKER", "name": "Docker Test", "sector": "IT"}' | python -m json.tool
# Expected: 201 Created with ID

# 4. Read it back (verify DB works in container)
curl -s http://localhost:8000/api/stocks | python -m json.tool
# Expected: list including DOCKER stock

# 5. Run indicator
curl -s http://localhost:8000/api/indicators/DOCKER | python -m json.tool
# Expected: SMA, RSI values

# 6. Run scan
curl -s "http://localhost:8000/api/scan?min_rsi=0&max_rsi=50" | python -m json.tool
# Expected: scan results matching RSI criteria
```

Agar sab kuch above jaise respond karta hai → **containerization successful**.

## Step 2: Verify data persistence (the important test)

```bash
# 1. Container down karo (data host pe hone chahiye)
docker compose down

# 2. Host machine pe check karo: data/ folder me DB file hai kya?
ls -la data/
# Expected: settings.db (or equivalent SQLite file)

# 3. Container phir se up karo
docker compose up -d
# Note: --build nahi laga — same image use hoga

# 4. DB wapas aayi hai kya?
curl -s http://localhost:8000/api/stocks | python -m json.tool
# Expected: DOCKER stock still present (data persisted across down/up)
```

Agar DOCKER stock phir se aata hai → **volume mount theek hai**. Data container ke bahar bacha rahega.

## Step 3: What breaks inside container?

Common issues + fixes:

| Problem | Cause | Fix |
|---------|-------|-----|
| `500 Internal Server Error` on POST | DB path `./data/` relative path issue | Volume mount path verify karo `./data:/app/data` |
| Port `8000` already in use | Host machine pe 8000 conflict | `docker compose down` ya `8001:8000` |
| Permission denied on `data/` | Linux file permissions | `chmod -R 777 data/` host pe, ya Docker user fix |
| `/health` works but `/api/scan` fails | Python package missing in container | `requirements.txt` me add karo, rebuild (`--build`) |
| DB file container me visible nahi | Volume mount galat | `./data:/app/data` ka double-check karo |

## Step 4: Bridge to TradeStack

Phase 1 mini-project → TradeStack kaise jodenge?

### TradeStack folder structure (real):
```
tradestack/
├── backend/               # TradeStack ka actual backend
│   ├── server.py           # 930 lines, FastAPI app
│   ├── src/
│   │   ├── db.py
│   │   ├── scanner.py
│   │   ├── indicators/
│   │   └── ...
│   ├── requirements.txt
│   └── Dockerfile          # <-- yeh banayenge
├── docker-compose.yml      # root pe
└── data/
    └── trades.db           # SQLite (WAL mode)
```

### TradeStack Dockerfile (copy from Appendix A + adjust):
```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["uvicorn", "server:app", "--host", "0.0.0.0", "--port", "8000"]
```

**Changes from Appendix A:**
- `COPY . .` → `COPY backend .` (context `backend/` folder se)
- `app.main:app` → `server:app` (TradeStack ka entry point)

### TradeStack docker-compose.yml:
```yaml
version: "3.8"
services:
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: tradestack-backend
    ports:
      - "5000:8000"          # TradeStack port 5000
    volumes:
      - ./data:/app/data      # TradeStack ka data/ folder
    restart: unless-stopped
```

**TradeStack ke 16 labs se compare:**

| Phase 1 mini-project | TradeStack |
|---------------------|------------|
| `app/main.py` | `server.py` |
| `app/db.py` | `backend/src/db.py` |
| `app/scanner.py` | `backend/src/scanner.py` |
| `data/settings.db` | `data/trades.db` |
| Port 8000 | Port 5000 |

**Ekhi pattern.** Docker seekh lo Phase 1 project pe, TradeStack pe direct laga lo.

## Common Mistakes Checklist

- [ ] `requirements.txt` has ALL dependencies (not just FastAPI)
- [ ] Volume mount path `./data:/app/data` matches where app writes DB
- [ ] `CMD ["uvicorn", "app.main:app", ...]` — app path correct
- [ ] `.dockerignore` excludes `venv/`, `__pycache__/`, `data/`
- [ ] Port mapping doesn't conflict with host
- [ ] DB path inside container matches volume mount target
