## Ye Course Kya Hai — 1 Line Mein

**Backend = screen ke peeche ka hissa jo data store karta hai, requests process karta hai, aur bhejta hai — isse FastAPI (Python) se seekhenge, kyunki tumhara TradeStack hi isi pe bana hai.**

## Common Mistakes

- ❌ **"Backend sirf database hai"** — database toh ek hissa hai. Backend mein routing, validation, authentication, business logic — sab hota hai.
- ❌ **"Frontend seekh lo toh backend apne aap aa jayega"** — dono alag duniya hain. Frontend sirf dikhaata hai, backend sochta hai aur decide karta hai.
- ❌ **"Python aati hai toh FastAPI aa jayega"** — Python language hai, framework nahi. Framework seekhna alag step hai.

## What This Course Is NOT

- ❌ **Flask course** — Flask sirf ek jagah comparison mein aayega. Build hum FastAPI se karenge.
- ❌ **Django course** — sirf jaankari ke liye.
- ❌ **Python syntax course** — Python basics already maani gayi hai (pehle python notes kar lo).
- ❌ **Frontend course** — frontend tum already jaante ho, yahan toh usse call karenge.

**In Your Own Words**

1. Backend kya hota hai, apne words mein? (Yeh soch ke answer karo ki jab tum kisi website pe login karte ho toh data kahan jaata hai?)

<details>
<summary>Sample Jawab</summary>

**Jawab:** Backend screen ke peeche ka wo hissa hai jahan data store hota hai, aur jo requests process karta hai. Jaise login karte waqt, password seedha browser mein saved nahi hota — woh backend ke paas jaata hai, wahan validate hota hai, aur response aata hai ki "login sahi" ya "galat". Jo user dekhta hai wo frontend hai, jo na dikhe wo backend.

</details>

2. Is course mein hum kaunsa framework seekhenge, aur kyun?

<details>
<summary>Sample Jawab</summary>

**Jawab:** FastAPI. Kyunki woh modern hai (auto docs, built-in validation, real-time support) aur sabse badi baat — tumhara TradeStack (`backend/server.py`) bilkul FastAPI pe bana hai. Jo seekhenge, wohi apne project mein dikhega aur kaam aayega.

</details>

3. Phase 0 mein project banaa toh jayega?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Nahi. Phase 0 pure understanding ke liye hai — backend ki duniya ka map. Code sirf Phase 1 se shuru hoga (0.5 mein chhota Hello World wahan bhi aata hai setup karte waqt, lekin poora project Phase 1 mein).

</details>

4. Ek website ka backend kyun chahiye? Sirf frontend se kaam kyun nahi chalta?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Kyunki data user ke browser ke andar nahi rehna chahiye. Agar sab frontend mein hota, toh kisi bhi user ke paas jo data website ka hai, woh kisi aur ke liye bhi accessible ho jaata. Backend data ko ek protected jagah (server/database) mein rakhta hai aur rules decide karta hai ki kaun kya dekh sakta hai. Frontend sirf us data ko dikhaata hai jo backend ne allow kiya.

</details>
