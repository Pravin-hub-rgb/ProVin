Pichli file mein humne dekha tha ki client server ko request bhejta hai aur server response wapas bhejta hai. Ab sawaal yeh hai — woh "request" aur "response" asli mein likhi kaise jaati hai? Isliye is file mein HTTP ke basics samajhte hain, jo internet ka "language" hai.

# 0.2 HTTP Basics — Request, Response, Methods, Status Codes

## Soch — Post Office Ka Example

Maan lo tum ek dost ko letter bhejna chahte ho. Letter ke andar kya hota hai?
1. **Kisko bhejna hai** — address/pata (destination)
2. **Kya bhejna hai** — content (message)
3. **Kya karna hai** — "yeh order kar raha hoon" ya "yeh poochh raha hoon"

Ab jab browser server se baat karta hai, toh wahi cheez hoti hai — HTML ke roop mein, aur isi "bhasha" ko **HTTP** kehte hain.

## Concept — HTTP

**HTTP (HyperText Transfer Protocol)** internet ki language hai — jis rules ke hisaab se client aur server baat karte hain. Jab tu koi URL kholta hai, toh bhejta hai ek **HTTP request**, aur wapas aata hai **HTTP response**.

Ek request mein kya hota hai:
```
METHOD /path  HTTP/version
```

- **METHOD** — batata hai kya action karna hai (request ka "verb")
- **/path** — kisi resource ko access karna hai (URL ka hissa)
- **HTTP version** — jo version use ho raha hai (jaise HTTP/1.1)

## Request Methods (Sabse Important)

Methods bataate hain ki request kya karna chahti hai. 4 bade:

| Method | Kya karta hai | Real-world example |
|--------|---------------|-------------------|
| **GET** | Data **paana** (read) | Website kholna, search karna |
| **POST** | Naya **data create/bhejna** | Login form submit, naya post banana |
| **PUT** | Poora data **update** karna | Poori file badalna |
| **DELETE** | Data **delete** karna | Post hataana |

Real-world example: GET = "mujhe yeh page/page list do", POST = "yah naya record bana do".

## Status Codes — Server Ka Jawab

Jab server response bhejta hai, woh bhi ek code ke saath jaata hai — **HTTP status code** — jo batata hai ki request ka natija kya hua.

| Code | Matlab | Real jagah |
|------|--------|------------|
| **200** | OK — sab sahi | Page load hua |
| **201** | Created — nayi cheez bani | POST ke baad naya record |
| **404** | Not Found — woh page/data nahi mila | Galt URL |
| **500** | Server error — server ki galti | Koi bug server mein |
| **401/403** | Unauthorized / Forbidden — permission nahi | Login needed |

**Yaad rakhne wali baat:** 4xx matlab client ki galti (galat URL/request), 5xx matlab server ki galti (bug server side). 2xx sab theek.

## Nutshell

**HTTP = client-server ki bhasha. GET/POST/PUT/DELETE actions hain, status codes (200/404/500) results hain.**

## What HTTP Is NOT

- ❌ **HTTP = HTTPS nahi** — HTTPS = HTTP + encryption (SSL). Aaj almost sab HTTPS hai.
- ❌ **HTTP sirf browser ke liye nahi** — mobile app, API calls, sab use karte hain.
- ❌ **Status code random number nahi** — har code ka khaas matlab hai, clients usko samajhte hain.

## Common Mistakes

- ❌ **"GET aur POST mein sirf naam ka farak hai"** — nahi. GET data sirf padhta hai, POST data bhejta hai. GET se server pe kuch badalta nahi, POST se badalta hai.
- ❌ **"Status code server khud choose karta hai"** — partially true. Server code assign karta hai, par code request ke result pe depend karta hai. Agar data mil gaya toh 200, nahi mila toh 404, server crash hua toh 500.
- ❌ **"HTTP sirf web browsers use karte hain"** — nahi. Mobile apps, IoT devices, sab HTTP use karte hain data exchange ke liye.

**In Your Own Words**

1. GET aur POST mein kya farak hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** GET data ko **read/paane** ke liye hota hai (page kholna, search). POST data ko **create/bhejne** ke liye (login, naya item banana). GET se data nahi banta, POST se banta hai.

</details>

2. 200, 404, 500 — inka matlab kya hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** 200 = sab theek (OK), 404 = woh page/resource nahi mila (client ki galti — galat URL), 500 = server pe koi problem/galti hui (server ki galti).

</details>

3. HTTP request mein 4 core cheezein kya hoti hain?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Method (GET/POST), URL/path (kis resource ko jaa rahe), version, aur headers (extra info like language). In short — request mein action + resource hota hai.

</details>
