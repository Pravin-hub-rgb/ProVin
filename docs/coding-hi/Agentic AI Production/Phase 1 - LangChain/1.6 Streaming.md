# 1.6 Streaming

Jab tak tumne `model.invoke()` use kiya, jab tak poora jawab ready na ho, tumhe kuch nahi milta. Yeh ek **blocking** call hai — sab kuch aa jaata hai ready. Par real users ke liye ye feel "slow" hai, khaaskar lambi tarah ke answers mein.

**Streaming** matlab — response ko blocks mein lete ho, jaise hi model generate karta hai. Pehla chhota sa chunk turant milta hai, phir agla, phir agla. Jaise WhatsApp barf dayi ke water flow — har drip pakde jao, poori bottle ke liye wait na karo.

## `invoke` vs `stream` — Feel the Difference

Yeh do model calls hai, same question, do alag experience:

**Invoke (saara ek saath):**
```python
response = model.invoke("Tell me a long story about a robot.")
print(response.content)   # poori kahani ek saath print
```

**Stream (chunk-chunk):**
```python
for chunk in model.stream("Tell me a long story about a robot."):
    print(chunk.content, end="")
```

Fark samjho:

* `model.invoke(...)` — ek model call. Pura jawab ready hone pe `response.content` milta hai. Tab tak screen khali.
* `model.stream(...)` — ek **iterator** deta hai — ek sequence jisse `for` loop mein iterate karte ho.
* `for chunk in model.stream(...)` — har loop round mein `chunk` me model ka thoda sa naya text aata hai (ek shabd ya do).
* `chunk.content` — us chunk ka text part.
* `print(chunk.content, end="")` — print karo full: `end=""` ka matlab hai "har print ke baad nayi line mat daalo", taaki saare chunks ek hi line mein continue ho.

Iska asar? `invoke` pe tum 5 second blank screen dekhte ho phir achanak poora paragraph. `stream` pe pehla shabd turant dikhta hai aur uske baad text badta rehta hai — jaise typing.

## Streaming That Still Gathers the Full Answer

Kabhi kabhi tumhe streaming bhi karni hai aur poora jawab bhi chahiye (sab chunks ko jor ke). Simple:

```python
full_text = ""
for chunk in model.stream("Explain recursion simply."):
    print(chunk.content, end="")
    full_text += chunk.content   # chunks jodo

print()   # nayi line
print("FULL:", full_text)   # poora jawab ek string mein
```

* `full_text = ""` — ek khaali string jisme pure chunks collect karoge.
* `full_text += chunk.content` — har chunk ko add karo.
* Loop ke baad `full_text` — poora jawab, ek string mein. Streaming ka fayda bhi aur pura text bhi.

## Where Do You Really Use This?

Socho ek customer-support agent. User sawaal deta hai, aur jab tak model poora jawab ready kare, woh screen blank dekhta hai — mehsoos "laggy". Streaming se answer turant type hota rehta hai. Isliye ChatGPT, Claude — sab streaming use karte hain.

## What It Is NOT

⚠️ **Streaming = turant jawab nahi.** Iska matlab ye nahi ki "instant answer" mil gaya. Wahi ek process hai — model poora text generate karta hai, bas tumhe chhote-chhote pieces mein milta hai jaise hi bante hain. Total time same rehta hai; sirf feel fast hota hai.

⚠️ **`model.stream()` alag koi nayi cheez nahi — wahi ek model request hai.** Bas response ka tareeka badalta hai: `invoke` pura one-shot deta hai, `stream` wahi text chunks mein deta hai. Duniya ke saare model streaming natif hota.

<summary>1. `model.invoke()` aur `model.stream()` mein kya fark?</summary>

**Jawab:** `invoke()` pura jawab ek saath ready hone ke baad deta hai — tab tak screen blank. `stream()` jawab ko chunks mein return karta hai — jaisi hi generate hota hai, har chunk milta jata hai. Dono ek hi model request — bas response ke tareeke alag: ek saath vs pieces.

</details>

<details>
<summary>2. `print(chunk.content, end="")` mein `end=""` kyun lagata?</summary>

**Jawab:** `print()` by default har call ke baad nayi line daata deta hai. `end=""` batat hai "nayi line mat daalo" taaki saare chunks ek hi line mein jude rahein — bina `end=""` ke har chunk apni line pe aata jo ult karte hai.

</details>

<details>
<summary>3. Streaming se actual speed badh jati hai model generation ki? Kya change hota hai?</summary>

**Jawab:** Nahin model ki generation speed nahi badhti — poora text same time mein banta hai. Fark response deliver karne mein hai. `invoke` poori cheez ready hone ka wait karta hai; `stream` har ready piece turant dikha deta hai. Isliye user ko fast lagta hai though time same.
