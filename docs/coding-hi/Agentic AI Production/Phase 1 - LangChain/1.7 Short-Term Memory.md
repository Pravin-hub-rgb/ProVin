Ab ek baat jo shayad tumne notice ki hogi — jab tak tum history khud messages list mein bhej rahe the, sab theek. Par jaise hi program band hua, sab gayab. Agli baar model ko kuch yaad nahi. Introduction course 5.1 mein isi problem ko **stateless** keh ke seekha tha.

Soch — WhatsApp chhodo, ab ye socho: ek dost jisse baat karte waqt woh har baar bhool jaata hai ki tumne pehle kya kaha. Frustrating na? Isi liye agents ko **memory** chahiye.

# 1.7 Short-Term Memory

**Short-term memory** matlab — ussi conversation ke kuch samay ke liye yaad rakhna. Iska kaam hai un messages ko rakhna jo is agent ke andar abhi abhi hue. Isi se conversation turant chat jaisi feel karta hai — model ko yaad hota hai ki tumne pehle kya kaha.

LangChain mein simple tareeka hai `InMemoryChatMessageHistory` — ek object jo tumhari conversation ko store karta hai. "In-memory" matlab — ye sab RAM (random access memory) mein rehta hai; program band hote hi reset ho jaata hai. Abhi ke liye ye kaafi hai — persistent memory aage advanced tarike se dekhenge.

## `InMemoryChatMessageHistory` — Setup

```python
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.chat_history import InMemoryChatMessageHistory

load_dotenv()

model = init_chat_model("llama-3.3-70b-versatile")

chat_history = InMemoryChatMessageHistory()
```

* `from langchain_core.chat_history import InMemoryChatMessageHistory` — conversation storage class import karta hai. "Chat history" = baat ka pura record.
* `chat_history = InMemoryChatMessageHistory()` — ek object banata hai jo tumhari conversation store karega. Iske andar saare messages jaate hain.

Ab isme messages add karo:

```python
from langchain_core.messages import HumanMessage

chat_history.add_user_message("Mera naam Vin hai.")
chat_history.add_ai_message("Namaste Vin! Kaise madad karoon?")

print(chat_history.messages)
```

* `chat_history.add_user_message("...")` — tumhara message history mein add karta hai (HumanMessage ke roop mein).
* `chat_history.add_ai_message("...")` — model ka jawab history mein add karta hai.
* `chat_history.messages` — poori list, jisse tum dekh sakte ho kya-kya yaad hai.

## Use the History With the Model

Ab asli trick — pichli baat ko model ko bhejo taaki wo "yaad" rakhe. Simple: history ke messages + naya sawaal, sab model ko do:

```python
# user ka naya sawaal
new_user_message = HumanMessage("Mera naam kya hai, kya yaad hai?")

# history ke purane messages + naya sawaal mila ke bhejo
full_context = chat_history.messages + [new_user_message]
response = model.invoke(full_context)

print(response.content)   # "Tumhara naam Vin hai" — yaad hai! (agar history mein add hua)
```

Line by line:

1. `new_user_message = HumanMessage("...")` — naya sawaal model ka poochh raha hai: "mera naam kya hai?"
2. `chat_history.messages + [new_user_message]` — list jodo. Left side mein puri purani history, right side mein naya sawaal. Yeh combined list model bhejt hai.
3. `response = model.invoke(full_context)` — model ko poora context milta hai — pehle "Mera naam Vin hai" aur ab "name kya?". Isliye jawab mein yaad hota hai ki naam Vin hai.
4. `print(response.content)` — jawab.

Aur zaroori — naye jawab ko bhi history mein add karo, taaki agla sawaal connected rahe. Extra step:

```python
chat_history.add_ai_message(response.content)
```

Ab agla sawaal bhi pichle jawab ke saath context mein milega. Conversation grow karti jati hai.

### In-memory = restart pe reset

Ek zaroori baat — `InMemoryChatMessageHistory` RAM mein rehta hai. Jaise hi program band ya restart hota hai, saara history reset. Iska matlab har program run hai tabhi memory kaam karta hai; agar server restart jaisa koi baat aaye toh sab gayab. Aage Phase 2 mein tum **checkpointer** dekhnge — jaise ek "save game" jo state ko disk/database mein bachata hai.

## What It Is NOT

⚠️ **Short-term memory = LLM ko "yaad" karna nahi.** Model khud kuch store nahi karta. Model ek stateless formula hai — tum hi history ko list mein bhejte rahe ho. "Memory" sirf ek pattern hai jisme tum history wapas bhejta ke model ko.

⚠️ **In-memory ≠ persistent.** Ye sirf RAM mein rehta hai. Program band = history gayab. Abhi ke liye ye kaafi hai — aage phases mein persistent (sustani) memory se dekhenge jo baat program restart ke baad bhi yaad rakhti hai.
