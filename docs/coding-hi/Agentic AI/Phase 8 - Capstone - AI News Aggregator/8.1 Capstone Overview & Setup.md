## Kya Bana Rahe Hain

Ek system jo **roz din mein ek baar automatically** yeh karta hai:

1. **Scrape karta hai** — kuch sources se naya content (YouTube channel RSS, Anthropic blog, OpenAI blog)
2. **Store karta hai** — Postgres database mein
3. **Aggregator Agent** — naye items ko rank karta hai tumhare profile ke hisaab se ("mujhe agentic AI, tool calling, MCP se matlab hai")
4. **Digest Agent** — top-ranked items se ek chhota daily summary likhta hai
5. **Deploy + schedule** — free pe, bina tumhare haath lagaye roz chalta hai

**AI News Aggregator** — ye poora system hai, ek script nahi. Aur isko "real system" banane wale teen features hain jo Phase 6 ke projects mein nahi the:
- **Persistence** (database — data save hota hai, har baar naya nahi)
- **Multiple cooperating agents** (aggregator → digest, do alag agents milke kaam karte hain)
- **Real deployment + schedule** (roz chalta hai, bina trigger kiye)

Interviewer ke nazar mein yahi cheez "toy script" ko "real system" se alag karti hai.

## Setup — Accounts Aur Keys (Day 1)

Chal shuru karte hain. Teen accounts banane hain:

### 1. Groq (LLM)
- [console.groq.com](https://console.groq.com) kholo — free signup, no card
- API key banao (API Keys → Create)
- Isko `GROQ_API_KEY` kehkar rakho
- **Note:** Groq OpenAI-compatible hai — agar Phase 3-4 mein OpenAI SDK style use kiya tha, code barely change hota hai (bas base URL + key swap)

### 2. Supabase (Database)
- [supabase.com](https://supabase.com) — free project banao
- Project dashboard mein **Project Settings → Database → Connection string** se `DATABASE_URL` le lo
- Isko bhi safe rakho

### 3. Node.js Project
Terminal mein:

```bash
mkdir ai-news-aggregator
cd ai-news-aggregator
npm init -y
```

Ab packages install karte hain:

```bash
npm install dotenv rss-parser pg groq-sdk
npm install -D nodemon
```

| Package | Kya hai |
|---|---|
| `dotenv` | `.env` file se secrets load karta hai |
| `rss-parser` | RSS feeds ko parse karta hai (scraping ke liye) |
| `pg` | Postgres client — raw SQL queries |
| `groq-sdk` | Groq ke LLM se baat karne ka SDK |

> **Drizzle ORM?** Capstone mein `pg` + raw SQL use karenge (seedha samajh aata hai). Drizzle/Prisma ka mention 8.4 mein aayega as "better option" — pehle raw tarike se samjho, phir better.

### 4. `.env` File

Project root mein `.env` banao:

```bash
# .env (kabhi commit mat karna!)
GROQ_API_KEY=your_groq_key_here
DATABASE_URL=postgresql://your_supabase_connection_string
```

Aur `.gitignore` banao:

```gitignore
# .gitignore
node_modules
.env
```

**Critical rule:** `.env` **kabhi** Git pe push nahi hoti. `node_modules` bhi nahi. Yeh dono `.gitignore` mein hain — isliye safe.

### 5. Scripts Setup

`package.json` mein scripts add karo:

```json
{
  "scripts": {
    "scrape": "node scrapers/index.js",
    "rank": "node agents/aggregator.js",
    "digest": "node agents/digest.js",
    "run": "node index.js"
  }
}
```

(Ye scripts baad mein banaenge — abhi sirf names confirm ho gaye.)

## Sabse Pehle Test — Environment Chal Raha Hai?

Ek chhota test file banao — check karo ki keys load ho rahi hain:

```javascript
// test-env.js
require('dotenv').config();

console.log("GROQ_API_KEY set hai:", Boolean(process.env.GROQ_API_KEY));
console.log("DATABASE_URL set hai:", Boolean(process.env.DATABASE_URL));
```

Run karo:

```bash
node test-env.js
```

Dono `true` dikhna chahiye. Agar `false` aaya — `.env` file mein keys galat likhi hain ya dotenv load nahi ho raha.

> **Tip:** Kisi bhi secret ko `console.log` karke full print mat karo — sirf `Boolean(...)` se "set hai ya nahi" check karo. Logs mein secret leak nahi hona chahiye.

## Common Mistakes

- ❌ `.env` ko Git commit karna — secrets leak. `.gitignore` mein hai, confirm kar lo.
- ❌ Keys ko code mein hardcode karna — `process.env.KEY` hi use karo.
- ❌ `.env` file ko project root se alag jagah rakhna — dotenv root mein dhundhta hai.
- ❌ Keys ko `console.log` karke test karna — sirf `Boolean()` se check karo.
- ❌ `pg` aur `drizzle` dono install karna (confusion) — pehle `pg` se raw SQL samjho, baad mein upgrade kar sakte ho.
