## Scraping Kya Hai — RSS Feeds Se

Tum sochoge — "YouTube, Anthropic blog, OpenAI blog — inse data kaise laaun? API keys toh nahi hain." **RSS feeds** iska jawab hai.

**RSS** ek standard format hai jo almost har blog/channel deta hai — ek simple XML file jisme latest items hote hain (title, link, date, description). Free, no API key. Har source ka ek RSS URL hota hai:

- **YouTube channel:** `https://www.youtube.com/feeds/videos.xml?channel_id=YOUR_CHANNEL_ID`
- **Anthropic blog:** `https://www.anthropic.com/rss.xml` (ya blog listing page)
- **OpenAI blog:** `https://openai.com/blog/rss.xml`

Browser mein koi bhi RSS URL kholo — XML dikhega. Wahi data hai jise hum parse karenge.

## Normalization — Har Source Se Same Shape

Problem: Har source ka RSS thoda alag format hota hai. YouTube ke item mein `videoId` hota hai, Anthropic ke mein `link`, OpenAI ke mein `guid`. Isliye hum ek **normalized shape** banate hain — har scraper apne source ka data is shape mein convert karta hai:

```javascript
// Normalized article shape
{
  source: "youtube" | "anthropic" | "openai",
  title: string,
  url: string,
  published_at: date,
  raw_content: string   // transcript snippet ya blog excerpt
}
```

Ab database pe sirf **ek hi shape** aayegi, chahe kisi bhi source se ho. Yehi normalization hai — har scraper apne source ka format → common shape.

## YouTube Scraper

```javascript
// scrapers/youtube.js
const Parser = require('rss-parser');
const parser = new Parser();

const CHANNEL_URL = 'https://www.youtube.com/feeds/videos.xml?channel_id=UCX6OQ3DkcsbYNE6H8uQQuVA';

async function fetchNewItems() {
  const feed = await parser.parseURL(CHANNEL_URL);

  return feed.items.slice(0, 10).map((item) => ({
    source: 'youtube',
    title: item.title,
    url: item.link,
    published_at: new Date(item.pubDate),
    raw_content: item.contentSnippet || '',
  }));
}

module.exports = { fetchNewItems };
```

**Samjho:**
- `rss-parser` install kiya tha — `parser.parseURL()` se feed fetch + parse
- `feed.items` = feed ke items (videos)
- `.slice(0, 10)` = sirf 10 latest (limit — poori feed nahi)
- `.map()` = har item ko normalized shape mein convert
- `item.contentSnippet` = YouTube ka excerpt

## Anthropic Scraper

```javascript
// scrapers/anthropic.js
const Parser = require('rss-parser');
const parser = new Parser();

const BLOG_URL = 'https://www.anthropic.com/news/rss.xml';

async function fetchNewItems() {
  const feed = await parser.parseURL(BLOG_URL);

  return feed.items.slice(0, 10).map((item) => ({
    source: 'anthropic',
    title: item.title,
    url: item.link,
    published_at: new Date(item.pubDate),
    raw_content: item.contentSnippet || item.content || '',
  }));
}

module.exports = { fetchNewItems };
```

Same pattern — bas URL aur source name alag.

> **Note:** RSS URL exact ho na ho toh blog listing page se `cheerio` se scrape kar sakte ho (HTML parse karke). `rss-parser` se zyada cheezein milti hain, par concepts same. Pehle RSS try karo.

## Main Scraper — Sab Ko Run Karna

```javascript
// scrapers/index.js
const youtube = require('./youtube');
const anthropic = require('./anthropic');
const openai = require('./openai');

async function scrapeAll() {
  const results = await Promise.all([
    youtube.fetchNewItems(),
    anthropic.fetchNewItems(),
    openai.fetchNewItems(),
  ]);

  const allItems = results.flat();  // [[...], [...], [...]] → [...]
  console.log(`Total ${allItems.length} items scraped`);
  return allItems;
}

module.exports = { scrapeAll };

// Sirf run karne ke liye: node scrapers/index.js
if (require.main === module) {
  scrapeAll().then(console.log).catch(console.error);
}
```

**Samjho:**
- `Promise.all([...])` — teeno scrapers **parallel** chalti hain (wait nahi karte ek doosre ka)
- `results.flat()` — teen arrays ko ek array mein merge
- `require.main === module` — sirf jab direct run karo (`node scrapers/index.js`) tab execute, jab import ho tab nahi

## Common Mistakes

- ❌ RSS URL galat/outdated — feed parse nahi hoga. Browser mein URL khol ke confirm karo.
- ❌ Sab items lena (bina `.slice`) — pehli baar bahut saare aayenge, DB bhara jayega. Limit lagao.
- ❌ Har scraper alag shape return karna — normalization ka poora point kharab. Sab `{source, title, url, published_at, raw_content}` hi return karein.
- ❌ `published_at` string rehna — `new Date(item.pubDate)` se proper Date object banao (DB timestamp ke liye).
- ❌ Scrapers ko sequentially run karna — `Promise.all` se parallel (fast).

## What It Is NOT

⚠️ **Scraping = unethical/illegal nahi (agar rules follow karo).** RSS feeds publically designed hain isi liye. (Web scraping ke legal points alag topic hai — rate limits, terms of service respect karo.)

⚠️ **RSS = sirf blogs nahi.** Podcasts, YouTube, news sites — sab RSS dete hain. Iska use bahut wide hai.

⚠️ **`rss-parser` = "sirf RSS parse" nahi, ye fetch bhi karta hai.** `parseURL()` internally fetch + parse dono karta hai. Alag se `fetch` nahi lagana.

⚠️ **Scraper = "raw content" ka poora transcript nahi.** YouTube ka `contentSnippet` ek chhota excerpt hai — kaafi hai ranking ke liye. Full transcript lena zyada kaam + slow.
