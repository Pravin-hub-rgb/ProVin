**Delete all merged branches:**

If you haven't already, clean up every merged branch:

```bash
git branch --merged main | grep -v "main" | xargs git branch -d
```

And delete remote branches:

```bash
# Check which remote branches are no longer needed
git branch -r --merged origin/main | grep -v "main" | ForEach-Object { $_.Trim().Replace("origin/", "") } | ForEach-Object { git push origin --delete $_ }
```

(Review the dry run before running — make sure you're not deleting something active.)

**Push to GitHub (if it's not already there):**

```bash
git push origin main
```
