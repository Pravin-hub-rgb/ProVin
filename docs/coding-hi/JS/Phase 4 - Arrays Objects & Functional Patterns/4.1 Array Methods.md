These are the most important functions in all of JavaScript. You will use these every single day.

---

## ✅ The most important rule:

✅ **All modern array methods are pure functions.** They do not modify the original array. They return a new array.

✅ This is the foundation of React. This is why React works.

---

## 📋 Reference Table

| Method | What it does | Returns |
|---|---|---|
| `.map()` | Transform every element | New array, same length |
| `.filter()` | Keep elements that pass test | New array, same or shorter length |
| `.reduce()` | Convert array into anything | Any single value |
| `.find()` | Find first match | Single element / undefined |
| `.findIndex()` | Find index of first match | Number / -1 |
| `.some()` | At least one matches | Boolean |
| `.every()` | All match | Boolean |
| `.forEach()` | Iterate, side effects only | Nothing |
| `.flat()` | Remove nesting | New flattened array |
| `.flatMap()` | Map + flat in one step | New array |
| `.includes()` | Value exists | Boolean |
| `.slice()` | Get portion of array | New array |
| `.splice()` | Modify array in place | Nothing |
| `.sort()` | Sort in place | Nothing |

## ✅ .map()

You have an array of numbers `[1, 2, 3]`. You need every number doubled — `[2, 4, 6]`.

You could write a `for` loop:

```js
const nums = [1, 2, 3];
const doubled = [];
for (let i = 0; i < nums.length; i++) {
  doubled.push(nums[i] * 2);
}
```

It works. But it is verbose, and you have to manage the loop counter, the condition, and the new array yourself. Every time you write this pattern, you risk off-by-one errors.

✅ `map()` does this in one clean line. It takes an array, transforms **every single element** using a function, and returns a new array of the same length:

```js
const nums = [1, 2, 3];
const doubled = nums.map(n => n * 2); // [2, 4, 6]
```

✅ **React use case — Rendering lists:**
```jsx
function UserList({ users }) {
  return users.map(user => (
    <UserCard 
      key={user.id} 
      name={user.name} 
      avatar={user.avatar}
    />
  ));
}
```

✅ **Always use `map()` when you need a new array. Never use `forEach()`.**

## ✅ .filter()

What if you have an array and you only want the items that match a certain condition? Like only even numbers, or only active users, or only products that are in stock.

```js
const nums = [1, 2, 3, 4, 5];
const evens = [];
for (let i = 0; i < nums.length; i++) {
  if (nums[i] % 2 === 0) {
    evens.push(nums[i]);
  }
}
```

✅ `filter()` does this in one line. It keeps every element that returns `true` from the test function, and drops everything else:

```js
const evens = nums.filter(n => n % 2 === 0); // [2, 4]
```

The new array is always the same length or shorter. Nothing is modified. Pure.

✅ **React use case:**
```js
const activeUsers = users.filter(user => user.isActive);
```

## ✅ .reduce()

What if you need to turn an array into something completely different — not another array of the same length, but a single value like a sum, or a lookup object, or a string?

A `for` loop can do it:

```js
const nums = [1, 2, 3];
let total = 0;
for (let i = 0; i < nums.length; i++) {
  total += nums[i];
}
```

But anytime you need to **accumulate** values into a single result, `reduce()` is the right tool. It is the most powerful array method because it can turn an array into absolutely anything:

```js
const nums = [1, 2, 3];
const total = nums.reduce((acc, curr) => acc + curr, 0); // 6
```

The pattern: `reduce` takes a function and a starting value. The function runs for every element, and each time it receives the "accumulator" (the running result so far) plus the current element. Whatever you return becomes the new accumulator for the next iteration.

✅ Build lookup object:
```js
const usersById = users.reduce((acc, user) => {
  acc[user.id] = user;
  return acc;
}, {});
```

✅ This is the method no one ever teaches you properly but everyone uses.

## ✅ .find()

What if you need to find one specific item in an array by some condition — like a user with a specific ID?

```js
const users = [
  { id: 1, name: "Arjun" },
  { id: 2, name: "Priya" },
  { id: 3, name: "Rahul" }
];
```

A `for` loop can do it, but you still have to manage the loop, the break, and the return value:

```js
let found = null;
for (let i = 0; i < users.length; i++) {
  if (users[i].id === 3) {
    found = users[i];
    break;
  }
}
```

✅ `find()` does this in one line. It goes through the array, returns the **first** element where the test returns `true`, and stops immediately after:

```js
const user = users.find(u => u.id === 3);
// { id: 3, name: "Rahul" }
```

✅ Returns `undefined` if no match is found.
✅ **Important:** Returns a single object, **not an array**.

## ✅ .some()

What if you only need to know whether **at least one** item meets a condition? Not the item itself, not all of them — just a yes/no answer.

For example: "Does this cart have any out-of-stock items?" or "Is there at least one admin in this user list?"

```
const nums = [1, 2, 3, 4, 5];
// Is there at least one even number? → Yes (2)
```

✅ `some()` returns `true` if **AT LEAST ONE** element passes the test. It stops scanning as soon as it finds a match:

```js
const hasAdmin = users.some(u => u.role === "admin");
```

✅ **React use case:**
```js
const hasOutOfStock = cartItems.some(item => !item.inStock);
```

---

## ✅ .every()

What if you need to verify that **every single item** meets a condition? Like "Are all users active?" or "Is every form field filled in?"

```
const nums = [2, 4, 6, 8];
// Are all numbers even? → Yes
```

✅ `every()` returns `true` only if **ALL** elements pass the test. It stops the moment it finds one that fails:

```js
const allActive = users.every(u => u.isActive);
```

✅ **React use case:**
```js
const formIsValid = fields.every(field => field.value !== "");
```

## ✅ Common mistakes:

❌ **Do NOT use `map()` for side effects.** Use `forEach()`.
❌ **Do NOT use `forEach()` when you need a new array.** Use `map()`.
❌ **Never modify elements inside `map()` / `filter()`.**
❌ **Always provide initial value to `reduce()`.**

## 🧠 Interview Questions

> ❓ What is the difference between `map()` and `forEach()`?
> map returns a new array, forEach returns nothing and is only for side effects.

> ❓ Which array methods mutate the original array?
> splice, sort, reverse, push, pop, shift, unshift. All others are immutable.

> ❓ Why are immutable array methods so important in React?
> Because React only re-renders when references change. Immutable operations return new references.
