Biryani ki plate ka socho — chef ne layers rakhi hain: neeche rice, upar chicken, sabse upar masala. Ab tum plate ulti kar do (flip). Kya hoga? Masala neeche, rice upar — **poori order ulti**. Wahi to Reverse ka matlab hai: sequence ko ulta karna.

Ab 1.4 Two Pointers ke doosre variant pe aate hain: **left/right** wala — dono ungliyan alag-alag end se, ek dusre ki taraf. ## Problem 2: Reverse an Array

> **Statement:** Ek array do. Uska **ulta** bana ke return karo — last element pehle, pehla element last.

**Input:**
```
arr = [1, 2, 3, 4, 5]
```

**Output:**
```
[5, 4, 3, 2, 1]
```

**Constraints yaad rakho:**
- **In-place** — nayi array banane ki mana hai, original me hi ulta karna hai (interviews me aksar yehi kehte hain)
- Empty array (`[]` → `[]`) aur single element (`[7]` → `[7]`) — dono same rehte hain, kuch karna nahi
- Strings bhi array jaise hain — wahi pattern reverse string pe bhi chalta hai

---

## Pehle Khud Socho (Code Mat Likho)

1. Agar in-place ka constraint na ho, toh kaise karte? (Sabse easy tareeka — phir optimize karoge)
2. In-place me — bina nayi array ke, kya karna hoga? (Hint: 1.3 ke Template 3 me dekha tha — swap wala scene)
3. Middle element ka kya hoga odd-length array me? (Jaise `[1,2,3]` — `3` wala beech ka element swap hoga ya nahi?)

Jawab sochne ke baad hi code likho — `test.js` me apna attempt, phir neeche compare.

## Approach 1: Brute Force — Nayi Array (Asaan, Par In-Place Nahi)

Sabse seedha tareeka — pichhe se chalo, nayi array me bharo:

```js
function reverseBrute(arr) {
  let result = [];                    // nayi khali array

  for (let i = arr.length - 1; i >= 0; i--) {
    result.push(arr[i]);              // pichhe se value utha ke daalo
  }

  return result;
}

console.log(reverseBrute([1, 2, 3, 4, 5]));  // [5, 4, 3, 2, 1]
```

Yeh kaam kar leta hai, time O(n) bhi hai. Lekin do problems: (1) **Space O(n)** — nayi array banayi, (2) **original array change nahi hui** — kuch interviews me "in-place karo, original me hi ulta karo" kehte hain. Toh isse aage badhna padega.

---

## Approach 2: Two Pointers (In-Place) — The Real Solution

Yeh wahi code hai jo 1.4 me kiya tha. Ab thoda aur deeply samjho **kyun** kaam karta hai:

```js
function reverseInPlace(arr) {
  let left = 0;                       // shuru se
  let right = arr.length - 1;         // end se

  while (left < right) {
    // Swap — dono ungliyon wali values badlo
    [arr[left], arr[right]] = [arr[right], arr[left]];

    left++;                           // left ungli aage
    right--;                          // right ungli peeche
  }

  return arr;                         // original hi ulta ho gaya
}

console.log(reverseInPlace([1, 2, 3, 4, 5]));  // [5, 4, 3, 2, 1]
console.log(reverseInPlace([]));               // []
console.log(reverseInPlace([7]));              // [7]
```

**Har line samjho:**

1. `left = 0`, `right = arr.length - 1` — do ungliyan, dono end pe.
2. `while (left < right)` — jab tak ungliyan cross nahi karti. `left === right` pe wohi element hai — swap karke fayda nahi. Isliye `<`, `<=` nahi.
3. Swap — destructuring (1.3 me Template 3 tha). Purane tareeke se bhi chalta hai (temp variable se) — interview me jo aaye woh likho.
4. `left++`, `right--` — dono ek-ek kadam andar. Har step pe ek pair swap ho jata hai.

**Chalta hua dekho — `[1, 2, 3, 4, 5]`:**

```
left=0, right=4 → swap(0,4) → [5, 2, 3, 4, 1]
left=1, right=3 → swap(1,3) → [5, 4, 3, 2, 1]
left=2, right=2 → left < right FALSE → ruk jao ✅
```

Sirf 2 swap me pura array ulta. Middle element (`3`) chhoda hi nahi gaya kyunki woh apni sahi jagah pe already hai — ulti sequence me middle wahi rehta hai.

**Complexity:** Time O(n/2) ≈ O(n) — aadhe iterations. Space O(1) — sirf do variables, koi nayi array nahi.

> **Yahi pattern 1.4 me Container With Most Water me bhi tha** — left/right ungliyan. Ek hi pattern se reverse, palindrome, two-sum, container — sab solve. Isliye bolta hoon, pattern library hi asli skill hai.

## Ek Aur Tareeka — JavaScript Ke Built-ins (Kab Chalta Hai, Kab Nahi)

JavaScript me `reverse()` built-in method hai:

```js
let arr = [1, 2, 3, 4, 5];
arr.reverse();
console.log(arr);  // [5, 4, 3, 2, 1]
```

Yeh bhi **in-place** karta hai aur O(n) hai. Toh isko use karke solution kyu nahi likh dete?

**Kyunki interview me built-in use karte dikhaoge toh interviewer poochhega "built-in ke bina karo"** — aur wahi asli test hai. Built-in use karna aana chahiye (production code me karo), lekin interview me **logic dikhana** zyada valuable hai. DSA practice ka point yeh hai ki tum `reverse()` ke andar kya hota hai woh khud bana pao.

Ek aur baat — built-in `reverse()` original array ko change karta hai (in-place hai), par kuch log isko copy pe use karte hain:

```js
let reversed = [...arr].reverse();   // copy banao, phir ulta karo
```

Iska fayda: original safe. Par isme bhi O(n) extra space hai. Interview me yeh sab bolna — "mujhe built-in bhi pata hai, par loop wala in-place bhi bata sakta hoon" — aisa impression best hota hai.

## Variations — Interviewer Isko Twist Karega

### Variation 1: Subarray Reverse (Kisi Hissay Ka Ultana)

Pura array nahi — sirf `start` se `end` tak ka hissa ulta karo:

```js
function reverseRange(arr, start, end) {
  let left = start;
  let right = end;

  while (left < right) {
    [arr[left], arr[right]] = [arr[right], arr[left]];
    left++;
    right--;
  }

  return arr;
}

console.log(reverseRange([1, 2, 3, 4, 5], 1, 3));  // [1, 4, 3, 2, 5]
```

Bas `left = 0` ki jagah `left = start`, `right = arr.length - 1` ki jagah `right = end`. Yahi chhota sa change 1.3.2 (Rotate Array) ka solution hai — hint de diya maine!

### Variation 2: Reverse a String

String array nahi hai, par uske characters ko index se access kar sakte hain — toh wahi pattern:

```js
function reverseString(s) {
  let chars = s.split("");          // string → character array
  let left = 0;
  let right = chars.length - 1;

  while (left < right) {
    [chars[left], chars[right]] = [chars[right], chars[left]];
    left++;
    right--;
  }

  return chars.join("");            // wapas string
}

console.log(reverseString("hello"));  // "olleh"
```

Note: `s.split("")` O(n) space leti hai — par string immutable hai, isliye bina array ke nahi kar sakte. Yahi answer interview me bolna — "string immutability ke karan ek array copy chahiye".

### Variation 3: Reverse aur Palindrome — Same Coin Ke Do Pehlu

Palindrome check karna hai toh **reverse karke compare** karo:

```js
function isPalindrome(s) {
  return s === s.split("").reverse().join("");
}

console.log(isPalindrome("racecar"));  // true
console.log(isPalindrome("hello"));    // false
```

Par yeh O(n) space leta hai (copy + reverse). 1.4 me wala two-pointer version O(1) space me karta tha. Interview me "space optimize karo" bole toh two-pointer wala do — wahi difference dikhta hai.

---

## What It Is NOT

- ❌ **Reverse = sort.** Ulti order = reverse. Sorted order = chhote se bade. Dono bilkul alag. `[3, 1, 2]` reverse karne pe `[2, 1, 3]` aata hai — sorted `[1, 2, 3]` nahi!
- ❌ **Built-in `reverse()` use karna hi solution nahi.** Production code me use karo, interview me logic dikhao. "Built-in ke bina" ka follow-up hamesha aata hai.
- ❌ **`left <= right` loop galat hai.** Equal hone pe wohi element swap hota hai — bekar kaam. `left < right` hi sahi hai (odd-length me middle element chhodo).
- ❌ **Reverse me space O(n) "theek" nahi hai.** Extra array wala solution kaam kar leta hai, par "in-place" constraint pe fail. Two pointers ka O(1) space hi interview answer hai.

## Interview Tips

1. **Pehle brute force bolo, phir optimize.** "Pehle nayi array se karta — O(n) space. Ab in-place karta hoon — two pointers se O(1) space." Yeh flow dikhane se interviewer ko pata chalta hai tum process jaante ho.
2. **Middle element ka question aayega** — "odd-length me kya hota hai?" Answer: middle element apni sahi jagah pe hai, swap nahi hota, isliye loop `left < right` pe rukta hai.
3. **Built-in method ka mention karo** — "JavaScript ka `reverse()` bhi in-place hai, par main manually bata raha hoon logic ke liye" — yeh bolna knowledge dikhata hai.
4. **String version ready rakho** — interviewer "string bhi reverse karo" bol sakta hai. `split` → `reverse` → `join` ya two pointers — dono ready honi chahiye.

5. Reverse aur sort me kya fark hai? Kisi bhi array pe dono ka result kabhi same ho sakta hai?

<details>
<summary>Show Answer</summary>
