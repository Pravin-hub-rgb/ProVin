Gol dinner table ka socho — 8 dost baithe hain, aur sabko ek seat aage shift hona hai: jo seat 7 pe tha woh 0 pe, jo 0 pe tha woh 1 pe... poori table ghoom rahi hai, koi order nahi chhodta, bas sab apni-apni position badal rahe hain. Isko hi kehte hain **rotation**.

1.3 Arrays me tumne swap pattern dekha tha — do ungliyan dono end se, `[a, b] = [b, a]` (Template 3). Usi se reverse banta hai: pehla-aakhri swap, phir andar ki taraf. Aaj usi reverse ko **teen baar** use karke array ko rotate karenge. Aur 1.3.1 me jo discipline seekha (empty check pehle, `arr[0]` base) woh aaj ke edge cases me kaam aayega.

## Problem 2: Rotate Array by k Steps

> **Statement:** Ek array do aur ek number `k`. Array ko **right rotate** karo `k` steps ke liye — matlab last ke `k` elements ko front pe le aao, baaki sab peeche dhakel do.

**Input:**
```
arr = [1, 2, 3, 4, 5, 6, 7], k = 3
```

**Output:**
```
[5, 6, 7, 1, 2, 3, 4]
```

**Constraints yaad rakho:**
- **Right rotation** (LeetCode 189 ka default) — right side ke elements front pe aate hain
- **In-place** — nayi array banane ki mana hai
- `k` array ki length se **bada** ho sakta hai — `k = 8`, length `7` bhi valid input hai
- `k = 0` ya `k = arr.length` → array **waise hi** rehta hai
- Empty array (`[]`) aur single element (`[7]`) — kuch karna hi nahi

---

## Pehle Khud Socho (Code Mat Likho)

1. `k = 3`, length 7 — last ke 3 elements front pe aa jaate hain. Agar `arr.pop()` karke `arr.unshift()` karo `k` baar, kitna time lagega? (Hint: `unshift` O(n) hai, 1.3 me dekha tha)
2. `k = 8`, length 7 — kya 8 baar rotate karna padega? 7 steps ke baad kya hota hai — socho, 7 baar rotate karo toh array kaisi dikhegi?
3. Agar nayi array banani allowed hoti, toh kaise karte?

Jawab sochne ke baad hi code likho — `test.js` me apna attempt, phir neeche compare.

## Approach 1: Brute Force Ka Baap — Bina Remainder Ke (Sabase Bura Code)

Kuch log interview me seedha yeh likhte hain — aur yeh **do tarah se** galat hai:

```js
var rotate = function(nums, k) {
    if (k > nums.length) return;          // BUG!
    for (let i = 0; i < k; i++) {
        let last = nums.pop();            // last element nikalo
        nums.unshift(last);               // front pe daalo
    }
};
```

**Galat 1: `if (k > nums.length) return;` — yeh ek bug hai.** Iska matlab hai "agar `k` length se bada hai, toh kuch mat karo". Toh `[1, 2, 3, 4, 5, 6, 7]` pe `k = 8` bhejo toh function turant return ho jaata hai — array **waise hi reh jaati hai**, rotate hi nahi hota! Aur `k = 8` koi galat input nahi hai — woh bilkul valid hai. Is line ka matlab hi galat hai.

**Galat 2: `unshift` O(n) hai.** 1.3 me padha tha — array ke front me element daalne ke liye saare baaki elements ek seat peeche khisakne padte hain. `k` baar `unshift` = total **O(n·k)**. `n = 10,000`, `k = 5,000` → 50 million steps.

**Chalta hua dekho — k = 8 pe kya ho raha hai (agar bug na hota):**

```
[1, 2, 3, 4, 5, 6, 7]   original
1 step:   [7, 1, 2, 3, 4, 5, 6]
2 steps:  [6, 7, 1, 2, 3, 4, 5]
3 steps:  [5, 6, 7, 1, 2, 3, 4]
...
7 steps:  [1, 2, 3, 4, 5, 6, 7]   ← wapas original!
8 steps:  [7, 1, 2, 3, 4, 5, 6]   ← k = 1 wala hi result
```

Dhyan se dekho — **7 steps ke baad array wapas original ho jaati hai**. Toh 8 baar rotate karna = 1 baar rotate karna. Baki 7 steps bekaar ka kaam hai. Isi chhoti si cheez ko exploit karta hai modulo — ab usko samjho.

## Modulo (%) — Asli Steps Kaise Nikaalte Hain

`a % b` ka matlab hai: `a` ko `b` se divide karo, aur **jo remainder (shesh) bacha woh lo**.

```
7 % 3 = 1     (7 me 3 do baar = 6, bacha 1)
8 % 7 = 1     (8 me 7 ek baar = 7, bacha 1)
5 % 3 = 2     (5 me 3 ek baar = 3, bacha 2)
3 % 3 = 0     (pura divide ho gaya, kuch nahi bacha)
6 % 3 = 0     (pura divide ho gaya)
```

Ab ise rotate se jodo. Upar dekha na ki **array ko apni length (n) jitni baar rotate karo toh wapas original**. Isliye `k` ka asli kaam sirf woh hai jo `k` me se poore chakkar nikaal ke bache:

| k | Asli steps (`k % 7`) | Result |
|---|---------------------|--------|
| 0 | 0 | `[1, 2, 3, 4, 5, 6, 7]` |
| 1 | 1 | `[7, 1, 2, 3, 4, 5, 6]` |
| 3 | 3 | `[5, 6, 7, 1, 2, 3, 4]` |
| 7 | 0 | `[1, 2, 3, 4, 5, 6, 7]` |
| **8** | **1** | `[7, 1, 2, 3, 4, 5, 6]` |
| 10 | 3 | `[5, 6, 7, 1, 2, 3, 4]` |

`k = 8` ka matlab nahi hai "8 baar ghumao" — matlab hai "7 ka poora chakkar 1 baar maro (wapas original), phir 1 extra step". **`8 % 7 = 1`.** `k = 10` = 7 ka ek chakkar + 3 extra = `10 % 7 = 3` → wahi result jo `k = 3` ka hai.

Yahi logic code me: **pehle hi `k = k % arr.length` karke asli steps nikaal lo** — phir usi hisaab se kaam karo. Bina remainder ke `k` baar pop/unshift karna isliye bekaar hai kyunki tumhara code un baar bhi rotate karega jo koi effect hi nahi dete.

## Approach 2: Brute Force + Remainder (Logic Ab Sahi, Performance Abhi Bhi Slow)

Approach 1 ka seedha fix — pehle remainder nikaal lo, phir rotate karo:

```js
function rotateBrute(arr, k) {
  if (arr.length === 0) return arr;      // empty check pehle — 1.3.1 wala discipline
  k = k % arr.length;                    // asli steps — 8 % 7 = 1, 10 % 7 = 3

  for (let i = 0; i < k; i++) {
    arr.unshift(arr.pop());              // last nikalo, front pe daalo
  }

  return arr;
}

console.log(rotateBrute([1, 2, 3, 4, 5, 6, 7], 3));  // [5, 6, 7, 1, 2, 3, 4]
console.log(rotateBrute([1, 2, 3, 4, 5, 6, 7], 8));  // [7, 1, 2, 3, 4, 5, 6] — 8 % 7 = 1 step
```

Ab answer sahi aata hai — `k = 8` pe 8 ke bajaye sirf 1 step chalta hai. **Lekin performance abhi bhi slow hai**: `unshift` O(n) hai, toh `k` chhota hone pe theek, par bade `k` aur `n` pe **O(n·k)** hi hai. Interview me ise "brute force + edge case fix" ke roop me bolo — phir optimal pe jao.

## Approach 3: Teen Reverses — The Real Solution (O(n) Time, O(1) Space)

Pehle ek chhota tool samjho, phir poora trick. Tool ka naam hai `reverseRange`.

### Step 1: reverseRange Kya Karta Hai

Yeh function array ke **kisi bhi hisse** ko ulta kar deta hai. `reverseRange(arr, start, end)` ka matlab: index `start` se index `end` tak wale elements ulta karo.

Kaise? **Do ungliyan.** Ek ungli `start` pe, ek `end` pe. Swap karo, dono ungliyan andar badho, phir swap karo, phir andar... jab tak dono mil na jaayein. Chhota example dekh lo:

```js
let arr = [1, 2, 3, 4, 5];
reverseRange(arr, 1, 3);
console.log(arr);   // [1, 4, 3, 2, 5]
```

```
Shuru:    [1, 2, 3, 4, 5]     ungliyan: start=1 (2 pe), end=3 (4 pe)
Swap:     [1, 4, 3, 2, 5]     ab start=2, end=2 — dono mil gaye, ruk jao
```

Sirf index 1 se 3 tak wale elements (`2, 3, 4`) ulta hue → `4, 3, 2`. Baaki (`1` aur `5`) wahi. Yeh `while (start < end)` wala loop hai — 1.3 Arrays ke Template 3 (swap pattern) jaisa hi, bas ab `start`/`end` tum decide karte ho.

Aur **pura array** ulta karna hai toh bas `reverseRange(arr, 0, arr.length - 1)` — 0 se last tak. Yahi ek function teeno steps me kaam aayega.

### Step 2: Ek Rule Yaad Rakh Lo — Do Baar Ulti = Original

`[1, 2, 3, 4, 5]` ko reverse karo → `[5, 4, 3, 2, 1]`. Phir se reverse karo → `[1, 2, 3, 4, 5]`. 

**Koi bhi hissa do baar ulta karo toh wapas original order.** Yeh simple fact poora trick unlock karta hai.

### Step 3: Reverse Se Rotate Kyun Ho Jaata Hai

Example lo: `[1, 2, 3, 4, 5, 6, 7]`, `k = 3`. Hume chahiye aakhri 3 elements (`5, 6, 7`) front pe: `[5, 6, 7, 1, 2, 3, 4]`.

**Step 3a — Pura array reverse karo:**

```
[1, 2, 3, 4, 5, 6, 7]
→ [7, 6, 5, 4, 3, 2, 1]
```

Dekho kya hua — jo 3 elements aage laane the (`5, 6, 7`), woh ab **front pe aa gaye**! Bas unka order ulta hai (`7, 6, 5` ki jagah). Aur baaki 4 (`1, 2, 3, 4`) peeche hain, unka order bhi ulta (`4, 3, 2, 1`).

**Step 3b — Pehle 3 elements phir se reverse karo:**

```
[7, 6, 5, 4, 3, 2, 1]
→ [5, 6, 7, 4, 3, 2, 1]
```

`7, 6, 5` ulta → `5, 6, 7`. Ab front wale 3 ka order sahi hai. (Do baar ulti = original — wahi rule.)

**Step 3c — Baaki 4 elements phir se reverse karo:**

```
[5, 6, 7, 4, 3, 2, 1]
→ [5, 6, 7, 1, 2, 3, 4]  ✅
```

Ho gaya. 

**Poora logic ek line me:** *Pehle pura ulta karo — aakhri wale elements front pe aa jaate hain (ulti order me). Phir dono hisson ko ulta karke order sahi kar do.* Teeno steps me bas `reverseRange` alag-alag ranges pe lagaya.

### Code

```js
function reverseRange(arr, start, end) {
  while (start < end) {
    [arr[start], arr[end]] = [arr[end], arr[start]];
    start++;
    end--;
  }
}

function rotate(arr, k) {
  if (arr.length === 0) return arr;
  k = k % arr.length;                    // asli steps — 8 % 7 = 1, 10 % 7 = 3
  if (k === 0) return arr;               // k = 0 ya k = n ka multiple — kuch nahi karna

  reverseRange(arr, 0, arr.length - 1);  // 1. pura ulta — aakhri wale front pe aa gaye
  reverseRange(arr, 0, k - 1);           // 2. pehle k elements ulta — unka order sahi
  reverseRange(arr, k, arr.length - 1);  // 3. baaki elements ulta — unka order sahi

  return arr;
}

console.log(rotate([1, 2, 3, 4, 5, 6, 7], 3));   // [5, 6, 7, 1, 2, 3, 4]
console.log(rotate([1, 2, 3, 4, 5, 6, 7], 8));   // [7, 1, 2, 3, 4, 5, 6] — 8 % 7 = 1
console.log(rotate([1, 2, 3], 10));              // [3, 1, 2] — 10 % 3 = 1
console.log(rotate([1, 2, 3], 0));               // [1, 2, 3]
console.log(rotate([1, 2, 3], 3));               // [1, 2, 3]
console.log(rotate([], 2));                      // []
```

Teeno calls — har call me `reverseRange` ka `start`/`end` decide karta hai kaunsa hissa ulta hai:

- `reverseRange(arr, 0, arr.length - 1)` → pura array (0 se last tak)
- `reverseRange(arr, 0, k - 1)` → pehle `k` elements (0 se `k - 1` tak)
- `reverseRange(arr, k, arr.length - 1)` → baaki elements (`k` se last tak)

**Har line samjho:**

- `if (arr.length === 0) return arr;` — empty check pehle, wahi 1.3.1 wala discipline.
- `k = k % arr.length;` — asli steps = remainder. `8 % 7 = 1`, `10 % 7 = 3`. Bina iske 8 baar reverse karte.
- `if (k === 0) return arr;` — `k = 0` ho ya `k` puri length ka multiple (`k = 6`, `n = 3` → `6 % 3 = 0`), toh kuch karna nahi. Early return se bekaar ke teen reverses bachte hain.

**Complexity:** Time **O(n)** — teen passes, par har element har pass me ek baar hi touch hota hai (constant 3), toh O(3n) = **O(n)**. Space **O(1)** — koi nayi array nahi, sirf do pointers `start`/`end`.

Aur brute force se farak? Pop + unshift O(n·k) tha, nayi array wala O(n) space leta tha. Yeh dono problems khatam — O(n) time **aur** O(1) space. Isliye yeh interview answer hai.

> **Yahi pattern ka fayda hai** — "do baar ulti = original" wala insight sirf rotate me nahi chalta. Aage "Reverse Words in a String" problem bhi isi pe banti hai: pura string ulta, phir har word ulta. Ek insight, kai problems. Isliye bolta hoon — pattern library hi asli skill hai.

## Variations — Interviewer Isko Twist Karega

### Variation 1: Left Rotation

Right rotation ka mirror — front ke elements peeche jate hain. Bas reverse ka order badlo:

```js
function rotateLeft(arr, k) {
  if (arr.length === 0) return arr;
  k = k % arr.length;
  if (k === 0) return arr;

  reverseRange(arr, 0, k - 1);            // 1. pehle k ulta
  reverseRange(arr, k, arr.length - 1);   // 2. baaki ulta
  reverseRange(arr, 0, arr.length - 1);   // 3. pura ulta

  return arr;
}

console.log(rotateLeft([1, 2, 3, 4, 5, 6, 7], 2));  // [3, 4, 5, 6, 7, 1, 2]
```

Right: pehle pura ulta, phir dono hisse ulta. Left: pehle dono hisse ulta, phir pura ulta. Ya shortcut yaad rakho — **left rotate by k = right rotate by (n - k)**. Ek hi function, `rotate(arr, n - k)`.

### Variation 2: Negative k

Kuch interviews me `k` negative bhi ho sakta hai (`k = -2` = left rotate by 2). Fix — modulo me double-wrap:

```js
function rotateAny(arr, k) {
  if (arr.length === 0) return arr;
  k = ((k % arr.length) + arr.length) % arr.length;  // negative ko positive banao
  if (k === 0) return arr;
  // ...teen reverses
}
```

Kyun double-wrap? `-2 % 3` JavaScript me `-2` deta hai (negative remainder). `+3` karo toh `1`, `% 3` phir se `1`. Formula yaad rakhne layak hai.

### Variation 3: Built-in Shortcut (Interview Me Nahi Dena)

JavaScript me `slice` + `concat` se ho jaata hai:

```js
function rotateBuiltin(arr, k) {
  if (arr.length === 0) return arr;
  k = k % arr.length;
  return arr.slice(-k).concat(arr.slice(0, arr.length - k));
}

console.log(rotateBuiltin([1, 2, 3, 4, 5, 6, 7], 3));  // [5, 6, 7, 1, 2, 3, 4]
```

Fast hai, par **nayi array return karta hai** — in-place nahi, space O(n). Production code me chalta hai, interview me reverse trick dikhao.

### Variation 4: String Rotation

Question bank me aage "Check if String is Rotation of Another" hai. Strings **immutable** hain (1.3 me padha tha) — toh characters ko array me nikalo, rotate karo, join karo:

```js
function rotateString(s, k) {
  let chars = s.split("");
  rotate(chars, k);            // upar wala wahi array wala rotate
  return chars.join("");
}

console.log(rotateString("hello", 2));  // "lohel"
```

`split` se `O(n)` space — immutable strings ke saath option nahi hai, interview me yeh bolna.

## What It Is NOT

- ❌ **`if (k > nums.length) return;` solution nahi hai — bug hai.** `k` length se bada ho toh rotate karna hota hai, wapas kuch na karna nahi. `k = 8`, length 7 → valid input, rotate karo (`8 % 7 = 1` step).
- ❌ **`k` baar pop + unshift "O(k)" nahi hai.** `unshift` O(n) hai — har baar saare elements shift hote hain. Total **O(n·k)**. Bade input pe uth hi nahi paata.
- ❌ **`slice` + `concat` in-place nahi hai.** Nayi array banati hai, space O(n). Constraint "in-place karo" ho toh fail.
- ❌ **Sort nahi hai.** Rotation order preserve karta hai (values ghumti hain), sort values ko arrange karta hai. Dono alag.
- ❌ **"Rotate k baar karo" matlab asli k steps nahi.** Modulo ke baad ka result hi asli kaam hai — k = 8, n = 7 → 1 step. Baaki 7 bekaar.

---

## Interview Tips

1. **Flow dikhao:** "Pehle brute force ka baap — bina remainder ke pop + unshift, O(n·k) aur `k > n` pe galat. Phir remainder se fix — `k %= n`. Phir nayi array se O(n) time, par space O(n). Ab optimal — teen reverses, O(n) time, O(1) space." Yeh progression hi marks laati hai.
2. **Modulo ka mention pehle karo** — "`k` badi ho sakti hai, toh pehle `k %= n`" bolna hi aadha kaam hai. Example do: "8 steps = 7 ka pura chakkar + 1 extra".
3. **Dry run dikhao** — `[1,2,3,4,5,6,7]` k=3 pe teen reverses haath se chala ke dikhana. Confidence wahi se aata hai.
4. **reverseRange reuse dikhana** — "yeh 1.3 ke swap pattern ka generalized version hai, bas teen ranges pe call kiya" — isse pattern library build karne ka proof milta hai.
5. **Left rotation ready rakho** — interviewer right ke baad left poochhta hi hai. "Left rotate = `rotate(arr, n - k)`" bolke cover karo.
