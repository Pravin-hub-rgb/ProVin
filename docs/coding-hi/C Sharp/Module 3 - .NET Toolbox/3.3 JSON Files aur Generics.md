# JSON, Files aur Generics

## JSON — C# mein kahan

JS mein `JSON.stringify`/`JSON.parse` built-in the. C# mein **`System.Text.Json`** namespace hai:

```csharp
using System.Text.Json;

// Object → JSON string
var student = new { Naam = "Vin", Marks = 90 };
string json = JsonSerializer.Serialize(student);
Console.WriteLine(json);     // {"Naam":"Vin","Marks":90}

// JSON string → Object
string data = "{\"Naam\":\"Vin\",\"Marks\":90}";
var obj = JsonSerializer.Deserialize<Person>(data);   // ❗ generic — <Person>
Console.WriteLine(obj.Naam);
```

Pattern JS se ekdum:

```javascript
JSON.stringify(obj)                    →  JsonSerializer.Serialize(obj)
JSON.parse(str)                        →  JsonSerializer.Deserialize<T>(str)
```

**`Deserialize<Person>`** — `<>` mein batana padta hai ki JSON ko kis type mein todna hai (JS `JSON.parse` kuch bhi bana deta tha — yahan type tay). JSON ka key C# property ke naam se match karta hai — naam badalna ho toh attribute:

```csharp
class User
{
    [JsonPropertyName("user_name")]    // JSON mein key "user_name" aayegi
    public string UserName { get; set; }
    public int Age { get; set; }       // ye "Age" hi aayega
}
```

## Files padhna/likhna — async wala tarika

```csharp
// Likho (string → file)
string content = "Line 1\nLine 2";
await File.WriteAllTextAsync("notes.txt", content);

// Padho (file → string)
string back = await File.ReadAllTextAsync("notes.txt");
Console.WriteLine(back);

// Kya file hai?
bool hai = File.Exists("notes.txt");
```

`File` class ke andar sab — `WriteAllText`, `ReadAllText`, `AppendAllText`, `Copy`, `Delete`. Module 3.2 wala rule yahan bhi: **`...Async` wala version** use karo (disk I/O rukne wala kaam hai).

Path wali galti se bachne ke liye:

```csharp
// ❌ relative path — kis folder se chala pata nahi (working directory issue)
await File.WriteAllTextAsync("notes.txt", content);

// ✅ explicit path (ya Path.Combine)
string folder = Path.Combine(Environment.CurrentDirectory, "data");
Directory.CreateDirectory(folder);   // folder nahi hai toh banao
string path = Path.Combine(folder, "notes.txt");
await File.WriteAllTextAsync(path, content);
```

**JSON + file = apna chhota database** (projects ke shuruaati din mein kaam aata hai):

```csharp
string json = JsonSerializer.Serialize(students, new JsonSerializerOptions { WriteIndented = true });
await File.WriteAllTextAsync("students.json", json);

string back = await File.ReadAllTextAsync("students.json");

```

`WriteIndented = true` — JSON sundar (indent wala), warna sab ek line.

## Generics — `List<int>` wala `<>` ka asli matlab

Tum `List<int>`, `Task<string>` likh chuke ho — ab andar ka raaz:

```csharp
// Bina generics ke — TIGHT BOX (har type ke liye alag code)
class IntList
{
    int[] items = new int[100];
    void Add(int x) { ... }
    int Get(int i) { ... }
}
class StringList
{
    string[] items = new string[100];    // copy-paste!
    ...
}
```

Generics se — **ek hi code, type bahar se**:

```csharp
class MyList<T>               // T = placeholder ("koi bhi type")
{
    private List<T> items = new List<T>();

    public void Add(T item)    { items.Add(item); }     // T jagah pe jo aaye
    public T Get(int i)        { return items[i]; }
}
```

```csharp
MyList<int> a = new MyList<int>();
MyList<string> b = new MyList<string>();
a.Add(5);        // T = int
b.Add("hi");     // T = string — ek hi class!
```

**Faayda:** ek baar likho, har type chalega — aur **type safe** (string daalne ki koshish toh compile error). JS mein iska alternative `any` tha (danger), yahan `T` se safety bani rehti hai.

Khud ka generic method bhi likh sakte ho:

```csharp
T FirstOf<T>(List<T> list)
{
    return list[0];         // koi bhi T, string ho ya int
}

FirstOf(new List<int> { 5, 6 });     // 5
FirstOf(new List<string> { "a" });   // "a"
```

**Constraints** se limit laga sakte ho:

```csharp
T MaxOf<T>(List<T> list) where T : IComparable<T>   // sirf compare ho sake wale types
{
    T best = list[0];
    for (int i = 1; i < list.Count; i++)
        if (list[i].CompareTo(best) > 0) best = list[i];
    return best;
}
```

`where T : IComparable<T>` — "T aisi ho jise compare kiya ja sake". Yahan interface + generic ek saath dikhe. .NET ke `List<T>`, `Dictionary<TKey,TValue>`, `Task<T>` sab isi pattern se bane hain — ab unka `<>` samajh aayega.

## Yeh kya NAHI hai

- **`JsonSerializer.Deserialize` magic nahi karta** — `<>` mein type deni padti hai, aur JSON keys + property names match hone chahiye (na ho toh `[JsonPropertyName]`).
- **File operations hamesha check karo** — `ReadAllText` jis file pe nahi uspe exception. `File.Exists` pehle, ya try-catch (exception handling module 5 mein detail).
- **Generics = `object` nahi** — purane C# mein sab `object` mein rakhte the (unbox karna padta tha, slow tha, type galti hoti thi). Generics compile-time pe type check karta hai, zero performance loss.

## Ek complete program — students ko file mein save/load

```csharp
// Program.cs
using System;
using System.Collections.Generic;
using System.IO;
using System.Text.Json;
using System.Threading.Tasks;

class Student
{
    public string Name { get; set; }
    public int Marks { get; set; }
}

class Program
{
    static async Task Main()
    {
        var students = new List<Student>
        {
            new Student { Name = "Vin", Marks = 90 },
            new Student { Name = "Rahul", Marks = 85 },
        };

        string path = Path.Combine(Environment.CurrentDirectory, "students.json");

        // Save
        string json = JsonSerializer.Serialize(students,
            new JsonSerializerOptions { WriteIndented = true });
        await File.WriteAllTextAsync(path, json);
        Console.WriteLine("Save ho gaya: " + path);

        // Load
        string back = await File.ReadAllTextAsync(path);
        var loaded = JsonSerializer.Deserialize<List<Student>>(back);

        // LINQ — load hue data pe sawaal
        var top = loaded.Where(s => s.Marks >= 88)
                        .Select(s => s.Name);
        Console.WriteLine("Topper: " + string.Join(", ", top));
    }
}
```

Save → Load → LINQ — teen modules ka use ek saath. Chala ke `students.json` file khol ke dekho.

## In Your Own Words

1. JS `JSON.stringify/parse` ka C# equivalent kya hai — `Deserialize<T>` mein `<T>` kyun?

<details>
<summary>Sample Jawab</summary>

**Jawab:** `JsonSerializer.Serialize(obj)` aur `JsonSerializer.Deserialize<T>(str)`. `<T>` isliye kyunki C# ko batana padta hai JSON ko kis type mein todna hai (`Deserialize<Person>`) — JS `JSON.parse` bina bataye kuch bhi bana deta tha, yahan type-safe hai.

</details>

2. Generics kya hai — `MyList<T>` bana kar samjhao, aur `object` wala purana tarika kyun bura tha?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Generics = ek hi code jo type bahar se leta hai (`<T>` placeholder). `MyList<int>` aur `MyList<string>` ek hi class use karte hain. `object` wale mein type galti compile-time nahi pakdi jaati thi aur value box/unbox hoti thi (slow); generics type-safe aur fast hain.

</details>

3. File mein JSON save karne ka complete 3-step flow batao.

<details>
<summary>Sample Jawab</summary>

**Jawab:** (1) Object ko `JsonSerializer.Serialize` se JSON string banao, (2) `File.WriteAllTextAsync(path, json)` se disk pe likho, (3) wapas: `ReadAllTextAsync` + `JsonSerializer.Deserialize<List<T>>(back)` se object banao.

</details>

4. `where T : IComparable<T>` constraint ka kya matlab hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Generic method mein condition — sirf wo types `T` mein aa sakti hain jo `IComparable` implement karti hain (matlab compare kar sakein). Isliye andar `CompareTo` jaisa method safely call ho sakta hai — random type aake code nahi todegi.

</details>
