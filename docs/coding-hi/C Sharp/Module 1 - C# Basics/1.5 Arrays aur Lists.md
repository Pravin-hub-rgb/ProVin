# Arrays aur Lists

## Array — fix size wala box

```csharp
string[] naam = { "Vin", "Rahul", "Sara" };   // 3 naam, ek array
int[] marks = { 90, 85, 78, 92 };             // 4 marks

Console.WriteLine(naam[0]);      // Vin — ZERO se shuru (JS wala)
Console.WriteLine(marks[2]);     // 78
Console.WriteLine(naam.Length);  // 3 — total count (JS: length)
```

Syntax ka hisaab:

- `string[]` = "string ka array" — type ke baad `[]`. `int[]` = int ka array.
- `{ ... }` = initial values seedhe.
- Index **0 se** shuru, `[]` se access, `.Length` se count — sab JS jaisa.

**Ek bada fark — size fix hai:**

```csharp
int[] marks = new int[3];    // 3 jagah, shuru mein sab 0
marks[0] = 90;
marks[1] = 85;
marks[2] = 78;
marks[3] = 95;    // ❌ IndexOutOfRangeException — jagah hi nahi thi!
```

JS mein `arr.push()` karke array apne aap badh jaata tha. C# array **banate waqt size tay** — baad mein nahi badlega. Isliye jab size pata na ho ya badhta rahega, tab array nahi — **List** use hoti hai.

Ek aur baat: `new int[3]` mein saare int **0 se init** hote hain (JS mein `undefined` tha). Strings `null`. C# khud default value bhar deta hai.

## List — badhne wala box (roz yahi use hoga)

```csharp
using System.Collections.Generic;   // file ke top pe — List yahan rehta hai

List<int> marks = new List<int>();   // khaali list, size free

marks.Add(90);                       // jod do (push jaisa)
marks.Add(85);
marks.Add(78);

Console.WriteLine(marks.Count);      // 3 — Count, length nahi!
Console.WriteLine(marks[0]);         // 90 — wahi [] indexing

marks.Remove(85);                    // value hatao
marks.RemoveAt(0);                   // index 0 hatao
bool hai = marks.Contains(78);       // true
```

`List<T>` — `T` ki jagah tumhara type. `List<string>` = string list, `List<int>` = int list. Yeh **generics** ka pehla nazara hai (module 3 mein detail — abhi bas: `<>` mein type likho).

Fark ka summary:

| | Array (`int[]`) | List (`List<int>`) |
|---|---|---|
| Size | fix, banate waqt | badhta-jhukta |
| Badhana | ❌ nahi | `Add()` |
| Count | `.Length` | `.Count` |
| Speed | thoda fast | bahut kam farak |
| Kab | size pata hai (hamesha 7 days) | size pata nahi (user kitne items daalega) |

Day-to-day kaam mein **List default** hai — array tab jab size constant ho.

## List pe loop karna

```csharp
List<string> city = new List<string> { "Dehradun", "Delhi", "Mumbai" };

foreach (string c in city)
{
    Console.WriteLine(c);
}
```

`foreach` + `List` = sabse aam jodi. Index chahiye ho:

```csharp
for (int i = 0; i < city.Count; i++)
{
    Console.WriteLine($"{i}: {city[i]}");
}
```

## List ke kaam ke methods (roz chahiye honge)

```csharp
List<int> n = new List<int> { 3, 1, 4, 1, 5 };

n.Sort();              // 1, 1, 3, 4, 5 — in-place sort
n.Reverse();           // 5, 4, 3, 1, 1
int idx = n.IndexOf(4); // 2 — kahan mila (-1 = nahi mila)
n.Clear();             // sab khaali

int total = n.Count;   // ab 0
```

Aur ek powerful cheez — **chhota box andar bada** (nested):

```csharp
List<List<int>> table = new List<List<int>>
{
    new List<int> { 1, 2, 3 },
    new List<int> { 4, 5, 6 }
};

Console.WriteLine(table[1][2]);   // 6 — pehle row, phir column
```

JSON ka array-of-arrays bilkul aisa hi dikhta hai — data laoge toh aise hi milega.

## Common galtiyan (JS se aayi aadat)

```csharp
List<int> marks = new List<int> { 90, 85 };

// 1. .length likh dena
Console.WriteLine(marks.length);   // ❌ C# mein .Length/.Count — small nahi chalta

// 2. Array jaisa badalna (List nahi toh error)
int[] arr = { 1, 2, 3 };
arr.Add(4);                        // ❌ array mein Add nahi hota

// 3. Type mismatch
List<int> nums = new List<int> { 1, 2, "teen" };  // ❌ string nahi

// 4. Empty jagah access
Console.WriteLine(marks[10]);       // ❌ exception — JS mein undefined tha, yahan crash
```

Point 4 yaad rakho — JS mein `arr[10]` chup-chaap `undefined` deta tha, C# mein **exception** fekta hai. Isliye access se pehle `Count` check karna achi aadat hai:

```csharp
if (idx < marks.Count)
{
    Console.WriteLine(marks[idx]);
}
```

## Ek complete program — student report card

```csharp
// Program.cs
List<int> marks = new List<int>();

Console.Write("Kitne subjects: ");
int count = int.Parse(Console.ReadLine());

for (int i = 1; i <= count; i++)
{
    Console.Write($"Subject {i} ka marks: ");
    marks.Add(int.Parse(Console.ReadLine()));   // seedha list mein
}

marks.Sort();                     // chhota-bada
int min = marks[0];
int max = marks[marks.Count - 1];  // aakhri = sabse bada (sorted)

int total = 0;
foreach (int m in marks) total += m;
double avg = (double)total / marks.Count;

Console.WriteLine($"Min: {min}, Max: {max}, Avg: {avg:F2}");
Console.WriteLine($"Sabse kam wale top 3: {string.Join(", ", marks.GetRange(0, Math.Min(3, marks.Count)))}");
```

`marks.Count - 1` — aakhri element ka index (count se ek kam, kyunki 0 se shuru). `:F2` formatting hai — 2 decimal tak. Loop + list + condition sab aa gaya.

Yeh kya NAHI hai:

- **Array `Add()` nahi leta** — array fix hai, List hi badhta hai. Confusion sabse aam galti hai.
- **`.Count` hai, `.length` nahi** (List ke liye). Array ke liye `.Length`. Capitalization matter karta hai.
- **Index bahar = exception** — JS wali `undefined` shanti nahi hai. Access se pehle size check.

## In Your Own Words

1. Array aur List — kaunsa kyun use karoge, teen fark batao.

<details>
<summary>Sample Jawab</summary>

**Jawab:** Array tab jab size pehle se fixed ho (7 din wala calendar) — `int[]`. List tab jab size pata nahi/badega (user kitne marks daalega) — `List<int>` with `Add()`. Fark: size, `.Length` vs `.Count`, aur array mein badhana nahi chalta.

</details>

2. `new int[3]` banane pe andar kya hota hai, aur JS mein same kaam karne pe kya milta tha?

<details>
<summary>Sample Jawab</summary>

**Jawab:** C# teenon jagah 0 se bhar deta hai (int ka default). JS mein array holes/undefined rehte the — `arr[0]` pe turant value nahi thi. C# hamesha default value deta hai taaki kabhi uninitialized na mile.

</details>

3. `marks[10]` jab list mein sirf 3 items hain — C# mein kya hoga vs JS?

<details>
<summary>Sample Jawab</summary>

**Jawab:** C# mein IndexOutOfRangeException — program crash. JS mein chup-chaap `undefined` milta tha. Isliye C# mein access se pehle `idx < marks.Count` check zaroori hai.

</details>

4. Nested list `table[1][2]` ka kya matlab hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** `table[1]` = doosri andar wali list (row 2), uske `[2]` = us row ka teesra element. Dono brackets alag-alag level ke hain — pehle bahar wala box, phir andar wala.

</details>

Data ab ek jagah jam gaya — variables, conditions, loops, lists. Par jab yeh sab ek hi file mein badhta hai toh code lamba aur dobara-dohrana wala ho jaata hai. Isliye JS mein functions seekhe the — ab wahi **methods** C# mein.
