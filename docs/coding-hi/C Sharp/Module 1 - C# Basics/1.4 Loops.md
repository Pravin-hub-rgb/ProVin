Tumne conditions mein dekha ki program decide kar sakta hai kaun sa raasta lena hai — par agar 10 students ke marks print karne ho toh 10 baar `Console.WriteLine` likhoge? Bilkul nahi. Wahi kaam baar-baar karne ke liye hote hain **loops** — aur JS ke `for`, `while`, `foreach` C# mein sab maujood hain.

# Loops — for, foreach, while

## for loop — counting wala

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine("Line " + i);
}
```

```
Line 1
Line 2
Line 3
Line 4
Line 5
```

Teen hisse bilkul JS wale hain:

1. `int i = 1` — shuruwat (counter banaya)
2. `i <= 5` — jab tak ye sahi hai, chalta rahega
3. `i++` — har round ke baad +1

Ek round = ek **iteration**. Fark sirf yeh ki counter ka type likhna pada (`int i`), baaki JS se copy-paste.

## foreach — list ke har item pe

```csharp
string[] naam = { "Vin", "Rahul", "Sara" };

foreach (string n in naam)
{
    Console.WriteLine(n);
}
```

`for (item in collection)` — JS ka `for...of` yahi hai. Array/list ke har element ek-ek baar `n` mein aata hai. C# mein aksar `foreach` hi prefer hota hai jab sirf traverse karna ho — index chahiye ho tab `for`.

## while — jab tak condition sahi

```csharp
int i = 1;
while (i <= 5)
{
    Console.WriteLine("Line " + i);
    i++;          // ❗ bahar nikalne ka intzaam khud karna padta hai
}
```

`for` aur `while` ka farq: `for` mein counter ka poora control ek jagah dikhta hai (start-check-increment), `while` mein sirf condition hoti hai — counter tum khud sambhalte ho. Isliye **bhool gaye `i++` toh infinite loop** — program ghoomta rahega (Ctrl+C se rokna padega). `for` mein yeh galti kam hoti hai.

Kab `while`: jab count tumhe pehle se na pata ho, jab tak user kuch na bole:

```csharp
string input = "";
while (input != "exit")
{
    Console.Write("Command (exit se band): ");
    input = Console.ReadLine();
    Console.WriteLine("Tumne likha: " + input);
}
```

Yahan pata nahi kitne rounds chalenge — isliye `while` sahi choice.

## do-while — kam se kam ek baar

```csharp
int ch;
do
{
    Console.Write("1-2-3 chuno: ");
    ch = int.Parse(Console.ReadLine());
} while (ch < 1 || ch > 3);
```

Fark: `while` mein pehle check hota hai, `do-while` mein **pehle ek baar chalta hai, phir check**. Menu-wale scenes mein perfect — user ko ek baar input dena hi padega.

## break aur continue — loop ko control karo

```csharp
// break — loop hi band karo
for (int i = 1; i <= 100; i++)
{
    if (i == 6) break;        // 6 pe ruk gaya
    Console.WriteLine(i);      // 1..5 print
}

// continue — yeh round chhod do, agla lo
for (int i = 1; i <= 5; i++)
{
    if (i == 3) continue;      // 3 wala round skip
    Console.WriteLine(i);      // 1,2,4,5
}
```

`break` = poora loop khatam. `continue` = bas yeh iteration chhod, agla shuru. JS bilkul same.

## Nested loops — ek ke andar ek

```csharp
// 5x5 ka box
for (int i = 0; i < 5; i++)
{
    for (int j = 0; j < 5; j++)
    {
        Console.Write("* ");
    }
    Console.WriteLine();   // har row ke baad nayi line
}
```

```
* * * * *
* * * * *
* * * * *
* * * * *
* * * * *
```

Bahar wala loop rows chalata hai, andar wala us row ke columns. Table/chessboard/pattern wale programs isi se bante hain. Cost samjho — 5x5 = 25 iterations, agar dono 100 pe gaye toh 10,000 — nested loop ka time **multiply** hota hai, add nahi.

## Infinite loop se bachna

```csharp
int i = 0;
while (true)          // condition hamesha true
{
    Console.WriteLine(i);
    i++;
    if (i > 10) break;   // ❗ bahar nikalne ka rasta zaroor de do
}
```

`while (true)` jaan-boojh ke bhi use hota hai (server loop waghera) — par andar kahin `break` ya return hona chahiye. Bhool gaye toh Ctrl+C.

## Ek complete program — FizzBuzz

```csharp
// 1 se 15 tak: 3 ka multiple toh Fizz, 5 ka toh Buzz, dono ka toh FizzBuzz
for (int i = 1; i <= 15; i++)
{
    if (i % 3 == 0 && i % 5 == 0)
        Console.WriteLine("FizzBuzz");
    else if (i % 3 == 0)
        Console.WriteLine("Fizz");
    else if (i % 5 == 0)
        Console.WriteLine("Buzz");
    else
        Console.WriteLine(i);
}
```

`%` + loop + condition — module 1 ki sab cheezein ek saath. Acchi practice hai, aaj hi chala ke dekho.

Yeh kya NAHI hai:

- **`for` ka syntax JS jaisa hai par type mandatory** — `for (int i = 0; ...)` chahiye, `for (i = 0; ...)` nahi chalega (undeclared variable C# ko manzoor nahi).
- **`foreach` mein loop ke andar item change nahi kar sakte** — `foreach (var n in arr) { n = "x"; }` error hai. Uska apna copy hota hai. Badalna ho toh `for` use karo.
- **`while` mein `i++` bhoolna = infinite loop** — compiler nahi rokta, condition hamesha true rehti hai. Loop likhne ke baad "bahar kaise niklunga?" hamesha socho.

## In Your Own Words

1. `for` aur `while` kab use karna chahiye — ek-ek example ke saath?

<details>
<summary>Sample Jawab</summary>

**Jawab:** `for` tab jab iterations ka count pata ho (1 se 10 tak) — counter, check, increment sab ek jagah. `while` tab jab pata na ho (jab tak user "exit" na bole) — par phir counter/intzaam khud sambhalna padta hai.

</details>

2. `break` aur `continue` mein kya fark hai — output ke saath samjhao.

<details>
<summary>Sample Jawab</summary>

**Jawab:** `break` poora loop hi band kar deta hai (aage ke iterations nahi honge). `continue` sirf current iteration chhod kar agla shuru karta hai — loop chalta rehta hai. Jaise 1-5 loop mein `i==3` pe continue toh 3 chhut jaata hai par 4,5 aate hain; break toh 3 pe hi band.

</details>

3. Nested loop ka time kaise badhta hai — 10x10 loop mein kitne iterations hote hain?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Bahar wala 10 baar chalta hai, aur har baar andar wala bhi 10 baar — total 10x10 = 100 iterations. Matlab iterations multiply hote hain; 100x100 ho gaye toh 10,000.

</details

4. `do-while` `while` se kyun alag hai — kis scene mein prefer karoge?

<details>
<summary>Sample Jawab</summary>

**Jawab:** `while` mein pehle condition check hoti hai (0 baar bhi chal sakta hai); `do-while` mein pehle ek baar body chalti hai, phir check. Jaise menu — user ko kam se kam ek baar dikhana hi hai, tab `do-while`.

</details>

Loops se tum baar-baar kar sakte ho — par har baar ek hi variable (`i`) ke saath. Ab chahiye ek dabba jismein **bohot saari cheezein** ek saath rakho — arrays aur lists.
