# 7.2 Ten-Game Training Block

**Ten-game training block** aapke plan ka first measured integration test hai. Ismein aap serial 10 games khelenge, ideally comparable Lichess rapid 10+0 games, aur har game ke baad apna move, decisive moment aur ek lesson likhenge. Har game ka purpose sirf rating ya result nahi, Balki plan ke tools ko real decisions mein test karna hai.

Agar aapke tournament pool mein rated games available hain, toh in games ko rated 10+0 record kijiye. Agar kisi temporary constraint se games unrated ho jaate hain, unhe honest label dein; unrated sample ko rated readiness evidence ki jagah use nahi kiya jayega. Is block ka output data aur review discipline hai, guaranteed points nahi.

## Block se pehle commitment likho

Aap ek chhoti commitment note kijiye: “Main next ___ din/dinon mein 10 realistic rated 10+0 games khelungi, aur har ke baad minimum review fields fill karunga.” Date, tournament ya pairings likhne se aapka plan flexible nahi, lekin accountable aur practical ban jaata hai.

Har game ke liye same baseline fields rakhiye: game number, rating snapshot, opponent rating, result, time-trouble flag, primary error, aur review status. Isse aap har game ko alag anecdote ki tarah nahi dekhte, balki ek dataset bana rahe hote ho. Dataset chhota bhi ho, honest ho to kaam karta hai.

## Ek game ka training loop

Game se pehle apna phase goal likhiye: development, tactical awareness, king safety, ya endgame conversion. Ek hi game mein sab kuch improve karne ka target na rakhiye; ek primary cue aur ek secondary reminder choose kijiye. Isse aapki attention practical aur measurable rehti hai.

Game ke baad pehle scoreboard result check kijiye, phir apna review log update kijiye. Har game ke liye kam se kam ek important position chuniye, jahan aapka move game ko meaningfully badal sakta tha. Upar apna move aur FEN likhiye, phir engine open karke best continuation, alternative aur opponent ka forcing reply compare kijiye.

Aap har game ka full 20-move annotation nahi kar rahe. Deep review ek decisive moment, ek alternative aur ek prevention cue par focused hona chahiye. Jaise ek practice rep mein ek technique focus hoti hai, waise ek game review mein ek learning target hona chahiye.

## Written review ka chhota format

Har reviewed game ke liye yeh template use kijiye:

- **Decisive moment:** Position ka FEN aur kya badla.
- **My move:** Main choice aur meri visible reason.
- **Better plan:** Engine alternative ya opponent ke forcing reply.
- **Lesson to error list:** Agle games ka observable cue.

Agar aap sirf “position kharab ho gayi” likh rahe ho, review abhi complete nahi hai. Aapko board par ek dekhne layak decision chahiye, jaise “king ke paas squares count nahi kiye” ya “knight capture ke baad central activity nahi dekhi.” Specific words future games mein trigger ban sakte hain.

## Metrics kaise padhein

Block ke end par paanch simple metrics dekhiye: total reviewed games, time-trouble games, most common error category, rating snapshots ka range, aur kitne assignments next week carry forward honge. Har metric ke saath ek short explanation likhiye, sirf number nahi.

Aap result aur rating ko context ke saath padhein. Ek block mein opponents ka pool, tournament duration aur sleep alag-alag ho sakte hain. Isliye ek single high rating ko “main ready hoon” na samjhein; repeated games aur written review zyada meaningful signal hain.

## 45-minute schedule

Ek din mein ek game khelne ka plan realistic ho sakta hai, lekin game review ko consume karne wala time bhi rakhiye. 15 minute pre-game warm-up aur goal, 15 minute game ke liye buffer, aur 15 minute initial review ke liye use kar sakte hain. Baaki time heavy study ya capstone preparation ko de sakte hain.

Agar aap tournament mein khelte hain, toh recovery routine 6.5 Tournament Routine and Recovery ke mutabiq chalaiye. Paani, break aur next-game checklist ko skip karke sirf score chase karna block ke data ko noisy bana dega. Sustainable routine woh hai jo 10 games ke end tak bhi survive kare.

## What It Is NOT

Ten-game block **sirf das games khelne ka naam nahi hai**. Bina review ke yeh block sirf volume produce karta hai, learning nahi. Minimum evidence har game ke baad ek focused position aur ek lesson hai.

Ten-game block **rating ka controlled experiment nahi hai** jismein aap har result ko predict kar sako. Opponent pool aur luck influence karte hain; aap apne decision process ko improve karke evidence collect kar sakte ho, outcome ko guarantee nahi.

Ten-game block **sab games ko easy opponent dhoondhkar complete karne ki permission nahi hai**. Realistic rated events aur fair selection use kijiye, opponent ko resource samjhein, aur result-pool gaming se bachein. Difficulty ko useful range mein rakhna hi real training hai.

Ab aapke paas ten games ka data aur recurring lessons ka first complete set hai. `7.3 Ten-Game Capstone` mein aap isi discipline ko final ten-game capstone mein use karenge, phir 20-game readiness decision karenge.
