Every car conversation and every racing video throws the same words around: 2JZ, twin turbo, V8, 1.5 litre petrol, turbo boost, clutch, drive shaft. The words sound impressive, and most people nod along without knowing what a single one of them means. If that is you, this course was written for your exact situation. By the last file, each of those words will be a concrete machine part in your head, connected to the part next to it, in the order they were actually invented.

# Engine - From Steam to Spec Sheets

## The one rule of this course

**No word in this course will be used before it is explained.** If a term like crankshaft or camshaft appears, it has either already been defined in an earlier file or it is defined right there in a bracket the first time it shows up. Nothing later will make sense without the earlier files, which is why this course is read strictly in order.

This course also starts from history on purpose. Engines were not designed all at once. Every part you will meet exists because the previous design hit a wall: the steam engine was too heavy, the single cylinder was too shaky, the two-stroke was too dirty, the carburetor was too rough. Learn the wall and the part that fixed it, and the machine explains itself.

Phase 8 adds the last layer: the support systems the spec sheet never names. A decoded machine is a map; a running machine also needs oil keeping metal off metal and coolant carrying the heat of every bang out to the air. Without those two loops, the beautiful machine from Phases 0-7 destroys itself in minutes.

## How to read this course

1. **Read in order, one file per sitting.** Each file begins from the previous file's ending. Reading file 3.2 before 1.3 will feel like joining a conversation mid-sentence.
2. **Finish each phase with its quiz.** Every phase ends with a quiz file in the same format: multiple choice, true/false, and short answers with hidden sample answers.
3. **Say it back before moving on.** Every lecture ends with an "In Your Own Words" section. If you cannot answer those questions without scrolling up, the next file will build on sand.

## What It Is NOT

This is not a mechanic's guide. You will not learn how to change oil, diagnose a rattling noise, or repair anything. It is a machine-understanding course: what each part is, what problem it solved, and how the parts chain together.

It is not a physics textbook. There is no math here beyond counts and sizes you can picture: centimetres of piston travel, turns per minute, litres of volume.

It is not about electric cars. Electric vehicles skip this entire machine - no cylinders, no fuel, no gears in the same sense. This course is about the engine that burned fuel, because that is where all these words come from.

## Bridge to the next file
