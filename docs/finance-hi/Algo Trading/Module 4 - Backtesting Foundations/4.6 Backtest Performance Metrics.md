## Trade Report — Har Trade Ka Record

```python
import pandas as pd

qty = 10
initial_capital = 100000
entry = False
buy_price = 0.0
buy_time = None
trades = []          # ab LIST OF DICTIONARIES banegi!

for i in range(len(df)):
    fast_now = df["ema_9"][i]
    slow_now = df["ema_21"][i]

    if fast_now > slow_now and not entry:
        entry = True
        buy_price = df["close"][i]
        buy_time = df["time"][i]           # KAB khareeda

    elif fast_now < slow_now and entry:
        sell_price = df["close"][i]
        pnl = (sell_price - buy_price) * qty      # ✅ sahi formula
        trades.append({
            "entry_time": buy_time,
            "exit_time": df["time"][i],
            "side": "LONG",
            "entry_price": buy_price,
            "exit_price": sell_price,
            "pnl": pnl,
        })
        entry = False

report = pd.DataFrame(trades)
print(report.head())
```


### Metric 8: Max Drawdown — Sabse Bada Gaddha

Drawdown = equity ke kisi PEAK se girawat.

Code:

```python
running_max = report["equity"].cummax()     # ab-tak ka highest point
drawdown = (report["equity"] - running_max) / running_max * 100
max_dd = drawdown.min()

print(f"Max Drawdown: {max_dd:.1f}%")
```

Line-by-line:

```text
.cummax()                    → har point pe "ab tak ka MAX" yaad rakhta hai
equity − running_max         → peak se kitne NEECHE hain abhi
÷ running_max × 100          → percentage mein
.min()                       → sabse GEHRA dip
```

**Kyun scary hai?**

50% drawdown matlab capital AADHA hua tha...

aur wapas aane ke liye **100% gain chahiye!**

(Math dekho: 100 → 50 → wapas 100 = +50 on 50 = +100%!)

Plus psychology: woh phase trader ko TOD deta hai.

### Metric 9-10: CAGR aur Sharpe (Quick)

**CAGR** = annualized growth:

```text
₹1L → ₹1.2L ek saal mein = 20% CAGR

(Multi-year formula baad mein — abhi concept: har saal avg kitna badha)
```

**Sharpe Ratio** = smoothness score:

```text
Sharpe ≈ Average Return ÷ Volatility

High Sharpe → smooth straight-ish curve 😌
Low Sharpe  → heart-attack roller coaster 🎢
```

⚠️ Honest note: yeh SIMPLIFIED version hai —

proper Sharpe mein risk-free rate subtract hota hai, annualization hoti hai...

Abhi INTUITION pakdo: high Sharpe = smooth ride.
