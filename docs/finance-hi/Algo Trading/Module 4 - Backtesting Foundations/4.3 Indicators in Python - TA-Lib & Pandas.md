## Method 1 — Pandas Se Khud Banao

### SMA — rolling()

```python
df["sma_9"] = df["close"].rolling(window=9).mean()
```

Line-by-line:

```text
df["close"]        → close column pakda
.rolling(window=9) → 9-candles ki khisakti hui window banayi
.mean()            → har window ka average nikala
df["sma_9"] = ...  → result NAYA column bana diya
```

Jaise sliding window — har candle pe pichle 9 ka average.

### EMA — ewm()

EMA recursive hai, isliye rolling se NAHI banegi.

Pandas ka dedicated function:

```python
df["ema_9"] = df["close"].ewm(span=9, adjust=False).mean()
```

Do parameters samajh:

```text
span=9         → α = 2/(9+1) auto-set (4.2 wala formula!)
adjust=False   → RECURSIVE form use karo (broker charts isi se match!)
```

⚠️ **`adjust=False` likhna MANDATORY hai!**

Default `adjust=True` ek DIFFERENT weighted-average deta hai

jo broker/TA-Lib values se match NAHI karega.

Trading ke liye hamesha `adjust=False`. Yaad kar lo!

## Ruk — Ek Nazar Mein

```text
✅ rolling(9).mean()  → SMA (simple average)
✅ ewm(span=9, adjust=False)  → EMA (recursive, sahi wala)
✅ TA-Lib fail? wheel/conda/pandas-ta — teen raaste
```

## Method 2 — TA-Lib Se (One-Liners!)

Ab production-grade:

```python
import talib

df["ema_9"]  = talib.EMA(df["close"], timeperiod=9)
df["ema_21"] = talib.EMA(df["close"], timeperiod=21)
```

Compare karo pandas se — SAME values aani chahiye:

```python
print(df[["ema_9"]].tail())    # aakhri values dekho
```

Baaki sab indicators bhi one-liners hain:

```python
# RSI
df["rsi"] = talib.RSI(df["close"], timeperiod=14)

# Bollinger Bands (3 lines return hoti hain!)
upper, middle, lower = talib.BBANDS(df["close"], timeperiod=20)

# MACD (3 cheezein return!)
macd_line, signal_line, hist = talib.MACD(df["close"])
df["macd"], df["macd_signal"] = macd_line, signal_line

# ATR
df["atr"] = talib.ATR(df["high"], df["low"], df["close"], timeperiod=14)
```

Pattern same har jagah:

```text
talib.TOOLNAME(OHLC columns, timeperiod=N) → result column
```

**VWAP** TA-Lib mein built-in nahi — manual banate hain:

```python
typical = (df["high"] + df["low"] + df["close"]) / 3   # typical price
tpv = typical * df["volume"]
df["vwap"] = tpv.cumsum() / df["volume"].cumsum()
```

```text
.cumsum()   → chalta hua total (running sum)
```

(price×volume ka total ÷ volume ka total = VWAP — 4.2 wala formula!)

## Crossover Detection — Event Pakadna

4.2 ka theory ab code! State toh simple hai:

```python
bullish_state = df["ema_9"] > df["ema_21"]     # True/False ki list
```

Par **EVENT** ke liye pichli candle bhi dekhni hai.

Magic tool: **`shift()`**

```python
prev_fast = df["ema_9"].shift(1)    # poori column ek jagah NEECHE khiski!
prev_slow = df["ema_21"].shift(1)
```

```text
shift(1) ka matlab:
Row 0 pe → NaN (pichli thi hi nahi)
Row 1 pe → Row 0 ki value
Row 5 pe → Row 4 ki value

Matlab: "ek candle PEECHHE ki value" ab isi row mein available!
```

Ab dono candles compare:

```python
crossed_up = (df["ema_9"] > df["ema_21"]) & (prev_fast <= prev_slow)
```

Padho andar se:

```text
Condition 1: aaj fast > slow        (abhi bullish hai)
Condition 2: kal fast <= slow       (kal bullish NAHI tha)
Dono True?                          → ABHI-ABHI cross hua! ✨
```

Count bhi kar lo:

```python
print(f"Total bullish crosses: {crossed_up.sum()}")
```

(`.sum()` True ko 1 ginta hai — kitne crosses hue!)

Yeh `shift()` pattern har backtest mein baar-baar aayega. **Yaad kar lo!**

## Nutshell

TA-Lib Windows pe C-file issue — solutions: prebuilt wheel / conda / pandas-ta fallback. Pandas: SMA = `rolling(9).mean()`, EMA = `ewm(span=9, adjust=False)` (adjust=False MANDATORY — warna broker se mismatch!). TA-Lib one-liners: `talib.EMA/RSI/ATR/BBANDS/MACD`. Crossover EVENT: current condition + `shift(1)` se pichli candle ki condition — dono check! Matplotlib se visual verification.

## What It Is NOT

- ❌ **`ewm()` default ≠ chart ka EMA.** Default adjust=True different weighted-average deta hai jo brokers se match nahi karega. Trading data = hamesha adjust=False.
- ❌ **TA-Lib compulsory nahi hai.** EMA toh pandas se bhi banti hai! TA-Lib sirf FAST + ready-made hai. pandas-ta pure-Python backup hai — koi bhi chalega.
- ❌ **Warm-up NaNs = error nahi.** Pehli N-1 rows mein NaN aana mathematically SAHI hai — 9 candles ka average tab tak exist hi nahi kar sakta! Backtest in rows ko skip karega, panic nahi.

**In Your Own Words**

1. rolling(9).mean() vs ewm(span=9) — output alag kyun?

<details>
<summary>Sample Jawab</summary>

**Jawab:** rolling(9).mean() = SMA — pichle 9 closes ka equal-weight average. ewm(span=9) = EMA — recursive formula, nayi candles heavy-weighted (α=2/10). Values alag isliye kyunki WEIGHTING hi alag hai — SMA slow react karti hai, EMA fast. Dono valid indicators hain bas dono ALAG hain — strategy mein jo likha usi pe test karo.

</details>

2. shift(1) crossover detection mein kya karta hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Event detect karne ke liye DO candles ka data chahiye — aaj ki state AUR kal ki. shift(1) poori column ko ek row neeche slide karta hai: row i pe row i−1 ki value aa jaati hai. Phir: (fast_aaj > slow_aaj) AND (fast_kal <= slow_kal) = kal nahi tha cross, aaj hua = EVENT! Bina shift ke sirf STATE pata hota — kab cross HUA pata nahi chalta.

</details>

3. TA-Lib pip se fail → teen options?

<details>
<summary>Sample Jawab</summary>

**Jawab:** (1) PREBUILT WHEEL: apne Python version ki .whl file download (cp311 = Py3.11), phir pip install filename.whl — compiler ki zaroorat nahi. (2) CONDA: conda install -c conda-forge ta-lib — prebuilt binaries handle. (3) FALLBACK: pip install pandas-ta — pure Python, thoda slow par sab indicators. Verify: import talib chalao.

</details>

4. Warm-up NaN rows ka kya karna hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Kuch NAHI — ignore/skip karo. 21-EMA ki pehli 20 rows mein value EXIST nahi kar sakti (data hi kam hai!). Handle: df.dropna() + reset_index(drop=True), ya loop start index aage rakhna. Ek warning: NaN pe comparison (>) False return karta hai SILENTLY — isliye clean start index better hai dropna ke saath.

</details>

5. adjust=False skip kar diya toh kya hoga?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Default adjust=True chalega — jo ek DIFFERENT weighted-average banata hai (recursive nahi). Result: teri "EMA" values broker-charts aur TA-Lib se MATCH nahi karengi — crossovers alag candles pe, trades alag, backtest results galat-compare. Silent bug hai (error nahi aayega!) isliye khatarnak. Muscle memory: trading data pe ewm likhte waqt adjust=False ALWAYS.

</details>
