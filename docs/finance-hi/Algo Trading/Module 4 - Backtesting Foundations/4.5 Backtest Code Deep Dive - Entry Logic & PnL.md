# 4.5 Backtest Code Deep Dive: Entry Logic & PnL

## Setup — Wahi Data

## Problem #1 — Dobara-Dobara Entry! 😱

Soch: strong trend chal raha hai.

9 EMA kai candles tak 21 se UPAR hai.

Agar rule bas yeh ho: *"fast > slow → BUY"*

...toh HAR CANDLE pe nayi BUY lag jayegi!!

```text
Candle 1: fast > slow → BUY ❗
Candle 2: fast > slow → BUY ❗
Candle 3: fast > slow → BUY ❗
...100 positions ban gayi!! 💀
```

Humein chahiye: **EK hi position at a time.**

## Solution — The Entry Flag 🚦

Ek switch rakhte hain:

```python
entry = False    # shuru mein: position NAHI hai
```

| Switch | Matlab |
|---|---|
| `entry = False` | Flat hain — naya entry ALLOWED |
| `entry = True` | Position already hai — dobara NAHI! |

Loop mein:

```python
if fast_now > slow_now and not entry:
    entry = True          # ab position li!
    buy_price = df["close"][i]
```

```text
not entry   → "jab switch OFF ho" = jab flat hon
and         → dono conditions TOGETHER true hon toh hi entry
```

Ab har candle pe check hota hai:

*"bullish HAI + humari position NAHI hai?"* → tabhi BUY!

## ⚠️⚠️ SABSE BADA CORRECTION — PnL Formula!

**Dhyan se padho — original material mein yahan BADA bug tha!**

Original notes mein likha tha:

```text
❌ GALAT (original material):
PnL = buy_price − sell_price

"Buy at 100, Sell at 110 → PnL = 100−110 = −10 (LOSS)" ❌
"Buy at 100, Sell at 90  → PnL = 100−90  = +10 (PROFIT)" ❌
```

**DONO ULTA HAIN!** 😱

Soch ke dekho apni dukaan ki tarah:

```text
Tune samaan 100 mein KHAREEDA
110 mein BECHA → jeb mein 10 ZYADA = PROFIT!
90 mein becha  → jeb mein 10 KAM  = LOSS!
```

Sahi formula:

```text
✅ SAHI:
PnL = sell_price − buy_price

Buy 100, Sell 110 → 110−100 = +10 PROFIT ✅
Buy 100, Sell 90  → 90−100  = −10 LOSS   ✅
```

### Kyun Yeh Itna Dangerous Hai?

Yeh **silent bug** hai:

```text
Code chal gaya        ✅
Koi error nahi aaya   ✅
Par har WINNER loss dikh raha, har LOSER profit!
Net result ULTA!
```

Tu sochega *"strategy kharab hai"* jabki CODE kharab tha.

Isliye hamesha SANITY CHECK karo:

> *"100 mein khareeda, 110 mein becha — mujhe +10 hona chahiye.
> Code kya bol raha hai?"*

Agar ajeeb lag raha hai → formulas verify karo PEHLE!

## Complete Working Code — Poora Engine!

Ab sab kuch jodke poora runnable script:

```python
qty = 10              # har trade mein kitne shares
entry = False         # switch: position hai ya nahi
buy_price = 0.0       # kitne mein kharida (yaad rakhne ke liye)
net_pnl = 0.0         # total profit/loss
trades = []           # har trade ka PnL list mein

for i in range(len(df)):
    fast_now = df["ema_9"][i]
    slow_now = df["ema_21"][i]

    # ENTRY: bullish + abhi flat hain
    if fast_now > slow_now and not entry:
        entry = True
        buy_price = df["close"][i]

    # EXIT: bearish + position open hai
    elif fast_now < slow_now and entry:
        sell_price = df["close"][i]
        pnl = (sell_price - buy_price) * qty    # ✅ SAHI FORMULA!
        net_pnl += pnl                           # total mein jodo
        trades.append(pnl)                       # log mein rakho
        entry = False                            # switch OFF — naya entry possible

print(f"Total trades:   {len(trades)}")
print(f"Winning trades: {sum(1 for t in trades if t > 0)}")
print(f"Net PnL:        {net_pnl:.2f}")
```

## Nutshell

Engine = loop + state machine. Entry flag (`not entry`) repeat-entries rokta hai; exit pe switch OFF. ⚠️ **CRITICAL FIX: PnL = sell − buy** (original material mein ULTA tha — "100 khareeda, 110 becha = +10" sanity-check hamesha!). `* qty` se real rupees aate hain. `elif` mutually-exclusive branches ke liye. `trades` list = agli file ke metrics ka raw material. Silent bugs sabse dangerous — sanity checks rakho!

## What It Is NOT

- ❌ **Production backtester nahi hai.** No SL/target/costs/slippage/partial-exits — minimal engine core-mechanics sikhane ke liye. Layers aage judengi.
- ❌ **Negative net_pnl = strategy useless, NAHI.** Ek dataset + no costs + no risk-management = abhi sirf draft results. Verdict se pehle multiple regimes + proper metrics chahiye.
- ❌ **State-entry vs event-entry yahan same result dete hain, par GENERAL rule nahi.** Flag ki wajah se practically equivalent hue (long-only, single position). Multi-position/pyramiding strategies mein farq CRITICAL hota.
