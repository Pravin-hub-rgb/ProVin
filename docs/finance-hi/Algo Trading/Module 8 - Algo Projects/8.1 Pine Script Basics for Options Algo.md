## Pehli Script — Hello World!

Pine Editor → Create new → Indicator. Ab yeh likho:

```pinescript
//@version=6
indicator("My First Indicator")
plot(close)
```

Save → Run ▶️ → chart pe EK LINE aa gayi (close ki line)!

**Badhai ho — tu ab Pine-coder hai!** 🎉

### Line-by-Line:


## Variables & Types — Python Ka Cousin!

Assignment Python jaisa hi:

```pinescript
a = 10        // int (poora number)
b = 10.0      // float (decimal)
c = true      // bool (True/False)

```

| Type | Example |
|---|---|
| int | `10` |
| float | `10.0` |
| bool | `true` / `false` |
| string | `"hello"` |
| color | `color.red` |

⚠️ Plot mein sirf NUMBERS plot hote hain — string NAHI!

**Named arguments** bhi Python jaise:

```pinescript
plot(close, title="My Line", color=color.red)
```

Naming-rules bhi same: case-sensitive (`Data` ≠ `data`),

number se start ❌, underscore ✅, space ❌.

Matlab tera Python-knowledge DIRECT transfer ho raha hai!

## Overlay — Chart Ke Upar Ya Neeche?

```pinescript
indicator("My Indicator", overlay=true)
```

| Setting | Result |
|---|---|
| `overlay=false` (default) | Plot NEECHE alag-pane mein |
| `overlay=true` | Plot PRICE-CHART ke upar! |

⚠️ Volume + overlay=true → scale-mismatch error

(volume crores mein, price hundreds!)

Fix: us plot pe alag se `force_overlay=true` lagao.

## Inputs — User Settings Banao!

Real indicators ki SETTINGS-PANEL kaise banti hai?

`input.*` functions se!

```pinescript
length = input.int(14, title="RSI Length", group="RSI Settings")
mult   = input.float(1.5, title="Multiplier", group="RSI Settings")
mode   = input.string("Buy", title="Mode",
                      options=["Buy", "Sell", "No Sell"])
useIt  = input.bool(true, title="Enable Filter")
```

Samajh:

```text
input.int(14, ...)   → number-box bana, DEFAULT 14
title=...            → settings-panel me yeh naam dikhega
group=...            → same-group inputs EK section me organize
options=[...]        → DROPDOWN menu!
```

Input-types ka menu:

| Type | UI Kya Banta |
|---|---|
| `input.int` | Number-box |
| `input.float` | Decimal-box |
| `input.string(options=)` | **DROPDOWN!** |
| `input.bool` | Checkbox ☑️ |

Yehi inputs strategy ko FLEXIBLE banate hain —

user settings se change kare, code edit kiye bina!

## Operators — Sab Python Jaisa!

| Category | Operators | Note |
|---|---|---|
| Arithmetic | `+ − * / %` | Modulus bhi hai! |
| Comparison | `== != > < >= <=` | Result **boolean** |
| Ternary | `condition ? this : that` | if-else one-liner! |
| Compound | `+=`, `-=` | Loops me kaam aayega |

**Ternary** naya hai sirf SYNTAX mein:

```pinescript
label = a > b ? "UP" : "DOWN"
```

Padho: *"agar a>b HAI toh 'UP', warna 'DOWN'"*

## ta.* Namespace — Ready-Made Indicators!

Sabse important namespace: **`ta.*`** —


## Nutshell

Pine = TradingView ki language; har indicator isi pe built ({ } se source dekho — protected exception!). Indicator = signals dikhata; Strategy = backtest simulate karta. First script: `//@version=6` + `indicator()` + `plot()` — version-line SACRED! OHLCV built-ins free-data dete per-candle. Syntax overall Python-jaisa (+ternary extra). Inputs se settings-panels (int/float/bool/DROPDOWN). `ta.*` namespace = ready indicators. Agli file: yeh sab REAL strategy pe — AI ke saath!

## What It Is NOT

- ❌ **Pine ≠ general programming language.** Woh trading-charts ke liye SPECIALIZED hai — files nahi likh sakta, databases nahi khol sakta. Uska job: compute + draw + alert on charts. Heavy-lifting (orders/servers) Python ki!
- ❌ **Indicator script = tradable system nahi.** Indicators sirf DIKHATE hain; orders nahi bhejte, positions track nahi karte. Strategy() + alert() combo hi automation tak le jaata hai.
- ❌ **LuxAlgo copy-paste = understanding NAHI.** Doosre ka code paste karna tabhi safe jab tu PADH sake. Warna live-market-debugging impossible!

**In Your Own Words**

1. Indicator vs Strategy script ka farq? Automation me kab kaunsa?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Indicator sirf COMPUTE+DRAW karta hai — signals visually dikhata hai, alerts de sakta hai, par trades SIMULATE nahi karta. Strategy() signals pe simulated-buy/sell execute karti hai — isliye Strategy-Tester metrics deti hai (win-rate, profit-curve). Flow: pehle indicator se logic VERIFY karo → phir strategy() version BACKTEST ke liye → automation me indicator+alert LIVE-signals ke liye.

</details>

2. `{}` curly-bracket click se kya milta hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Us indicator ka SOURCE-CODE (agar public ho)! Useful: (1) mystery-khatam — EMA/VWAP/MACD sab PURE-MATH hai jo tu already samajhta hai (4.2!), (2) real-world patterns seekhne milte hain — inputs organize, plot-styling, (3) apne-scripts ka debug-reference. Exception: protected-scripts (Neural-Momentum type) ka code creator ne LOCK kiya hota hai!

</details>

3. `//@version=6` line critical kyun hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Compiler ko batati hai script kis Pine-version ki syntax use karti hai. Versions me BREAKING-changes hote hain (v4→v5→v6 functions/behavior badle). Line delete/galat-version = compiler GALAT rules apply karega → errors ya silently-wrong-behavior! Copy-paste purane scripts (v4/v5 likhe) karte waqt version-mismatch hi common-error hai.

</details>

4. input.* functions real-indicators me kya enable karte? Dropdown example?

<details>
<summary>Sample Jawab</summary>

**Jawab:** User-configurable SETTINGS — code-edit kiye bina behavior tune! Har-input settings-panel widget banta hai: int→number-box, float→decimal, bool→checkbox, string+options→DROPDOWN. Example: mode = input.string("Buy", options=["Buy","Sell","No Sell"]) — user ko 3-option menu, script ko variable `mode` me selected-string. Group-parameter inputs ko sections me organize karta hai.

</details>

5. Pine vs Python — division-of-labor projects me?

<details>
<summary>Sample Jawab</summary>

**Jawab:** PINE = signal-layer — chart-pe logic chalata (crossovers detect), visuals deta, ALERTS fire karta (webhook-payload ke saath). PYTHON = execution-layer — webhook RECEIVE karta (7.2 Flask), parse karta, broker-API pe orders bhejta (7.1!). Dono webhooks se judte hain. Kyun-divide: Pine chart/data-feed ke PAAS hai (best-signal-detection); Python systems/orders/servers ke paas (best-execution). Agli-files me yehi combo build hoga!

</details>
