Ek scene soch.

Tere ghar mein roz chai banti hai. Aur roz tujhe poora recipe bolna padta hai:

```text
"Paani ubalo, patti daal, cheeni daal, doodh daal, chhaan ke do..."
```

Har baar. Bore ho gaya na?

Ab soch: agar ek baar recipe likh ke **fridge pe chipka de**, aur bas bol de *"chai bana"*?

**Bas yehi hai FUNCTION.**

> Function = code ka pack. Ek baar likho. Naam de do. Phir naam se call karo, jitni baar chaaho.

# 3.3 Python Functions

## Pehla Function Banate Hain

```python
def make_chai():
    print("Paani ubala")
    print("Patti daali")
    print("Doodh daala")
    print("Chai ready! ☕")
```

Yeh kya tha? Line-by-line:

```text
def           → "function define kar raha hun" ka keyword
make_chai     → function ka naam (tune diya)
()            → input ki jagah (abhi khaali — thodi der mein samjhenge)
:             → "ab iske andar ka code shuru"
    print...  → andar ke lines (ANDAR khisak kar likhe = iske hisse hain)
```

⚠️ Chalaya nahi abhi tak! Sirf PACK banaya hai.

Tiffin pack kar liya — khaana abhi nahi khaya.

## Call Karna — Asli Khel

Function ko use karne ko **call** karte hain. Naam + brackets:

```python
make_chai()
```

Output:

```text
Paani ubala
Patti daali
Doodh daala
Chai ready! ☕
```

Andar ki saari lines chal gayi!

Aur jaadu yeh hai — jitni baar chaaho:

```python
make_chai()
make_chai()
```

```text
(Chai ban gayi 2 baar!)
```

Do calls, double output. Code EK hi baar likha tha.

## Ruk — Abhi Tak Kya Hua?

```text
✅ def naam(): → function PACK banana
✅ naam()      → pack KHOLNA (call karna)
✅ Ek baar likho, infinite baar use karo
```

Yeh concept poori programming ki backbone hai. Aage backtest engine bhi ek bada function hi hoga.

## Input Dena — Parameters

Ab problem: chai toh ban gayi, par har banda alag maangta hai.

```text
Bhai: "kam cheeni wali"
Tu:   "kadak wali"
```

Ek hi recipe sab ke liye nahi chalegi — **input chahiye.**

Function mein input dena = **parameter**:

```python
def make_chai(sugar):
    print(f"Chai ban rahi hai {sugar} spoon cheeni ke saath")
```

Dekho kya hua:

```text
sugar    → parameter = input ka naam (dabbe jaisa)
()       → ab khaali nahi, isme naam likha
```

Ab call karte waqt value bhejo:

```python
make_chai(1)     # bhai ke liye
make_chai(3)     # tere liye
```

Output:

```text
Chai ban rahi hai 1 spoon cheeni ke saath
Chai ban rahi hai 3 spoon cheeni ke saath
```

Same function. Alag-alag result — kyunki input alag tha!

### Do Inputs Bhi Ho Sakte Hain

Comma laga do, done:

```python
def make_chai(sugar, milk_amount):
    print(f"{milk_amount} ml doodh, {sugar} spoon cheeni")

make_chai(2, 50)
```

```text
50 ml doodh, 2 spoon cheeni
```

Order ka dhyan: pehla input pehle parameter mein jaata hai.

## Output Wapas Lena — return

Ab tak function sirf PRINT kar raha tha.

Par ek aur kaam hota hai: **result wapas dena.**

Example se samajh — dukaan ka bill machine:

- Tum items dete ho (input)
- Woh calculation karti hai (andar ki process)
- Bill DETI hai (output) ← yeh `return` hai!

```python
def calculate_total(price, qty):
    total = price * qty
    return total
```

Line-by-line:

```text
price * qty     → andar maths hua
return total    → result BAHAR phek diya, caller ke haath mein
```

Ab call karo — aur result PAKDO:

```python
my_bill = calculate_total(100, 5)
print(my_bill)
```

```text
500
```

Kya hua:

```text
calculate_total(100, 5)  → function chala → 500 return kiya
my_bill = ...            → woh 500 my_bill dabbe mein aa gaya
```

### Print vs Return — Sabse Confusing Point (Ab Clear Karo)

| | `print` | `return` |
|---|---|---|
| Kya karta | Screen pe DIKHA deta hai | Result WAPAS deta hai |
| Use kar sakte baad mein? | ❌ gaya, bas dikha | ✅ dabbe mein pada hai |
| Analogy | Jhula dikhana | Tiffin dena |

```python
print(total)      # sirf dikhega, use nahi kar paoge aage
return total      # milega — save karo, bhejo aage, jodo...
```

Trading code mein **return hi zyada use hota hai** — kyunki results ko aage process karna hota hai (PnL calculate karke report banana, etc.).

## Ruk — Poora Flow Ek Nazar Mein

```python
def calculate_total(price, qty):   # PACK banaya (2 inputs)
    total = price * qty            # andar kaam kiya
    return total                   # result wapas diya

bill = calculate_total(100, 5)     # CALL kiya, result PAKDA
```

```text
Inputs → function → return → dabbe mein save
```

Yeh pattern har jagah repeat hoga. Yaad kar lo jaise apna phone number.

## Chota Sa Advanced Point — Andar Ki Baat Andar Hi Rehti Hai

Ek cheez jo baad mein confuse karegi, abhi clear kar dete hain:

```python
def my_function():
    secret = 42          ← yeh andar banaya
    print(secret)

my_function()            ✅ 42 dikhega (andar se access)
print(secret)            ❌ ERROR! Bahar se NAHI dikhega
```

Function ke andar bane variables **andar hi rehte hain.**

Jaise kitchen mein rakha samaan — bahar wale room mein nahi dikhega.

Isko scope kehte hain — abhi itna hi kaafi hai, detail aage aayegi.

## Functions Kyun Itne Zaroori Hain?

Teen solid reasons:

1. **Ek baar likho** — bug fix ek jagah karo, sab jagah fix ho gaya
2. **Naam padh ke samajh aata hai** — `calculate_total()` dekha toh matlab clear, andar ka code padhne ki zaroorat nahi
3. **Bade programs chote tukdon mein** — backtest engine = functions ka sangam: data lao function, signals nikalo function, orders bhejo function...

Module 4 ke har file mein functions hain. Yeh file unki ticket hai.

## Nutshell

Function = packed code with naam. `def` se banao, naam se call karo — jitni baar chaaho. Parameters = inputs (`def chai(sugar)`), call waqt values bhejo. `return` = result wapas dena — caller usse pakad ke save kar sakta hai (print sirf dikhata hai, return DETA hai). Function ke andar ke variables andar hi rehte hain (scope). Bade programs = chote functions ka sangam.

## What It Is NOT

- ❌ **Function banaya = chal gaya nahi.** Banana (def) alag hai, call karna alag. Tiffin pack kiya — khana nahi khaya! Call (`naam()`) karna bhool jaoge toh output kabhi nahi aayega.
- ❌ **return aur print same nahi.** Print = screen pe dikhana (result ud gaya). Return = result haath mein dena (aage use karo). Confusion karoge toh "function ne value di hi nahi" wale bugs aayenge.
- ❌ **Har code ko function banana zaroori nahi.** Chota one-time code seedha likho. Function tab banao jab code REUSE hona ho YA naam dena readability badhaye.
