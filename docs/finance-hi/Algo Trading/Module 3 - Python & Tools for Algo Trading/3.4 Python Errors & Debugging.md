# 3.4 Python Errors & Debugging

## Pehle Ek Baat — Error = Message Hai

Error dekhte hi ghabrana nahi.

Error actually Python ka **message** hai:

> *"Bhai ruk! Yahan kuch galat ho gaya. Main yeh bol raha hun..."*

Jaise gaadi ki warning light — engine kharab hai ya petrol kam hai, light toh HELP ke liye hi jalati hai.

Debugging = us message ko padh ke problem dhundhna.

**Debug** ka matlab hi hota hai "kide (bugs) nikalna" — code mein chhupe mistakes dhundhna.

## Errors Ke Do Bade Type

```text
1. Syntax Error    → likhte waqt grammar galat
                     (Python code padhte hi pakad leta hai)

2. Logical Error   → code chal gaya, par JAWAB galat
                     (sabse khatarnak — Python pakad NHI sakta!)
```

Ek-ek karke dekhte hain, examples ke saath.

## Syntax Error — Grammar Galat

Hindi mein bura vyakaran = baat samajh nahi aati.

Python mein bura grammar = **code chalta hi nahi.**

```python
for i in range(5)
    print(i)
```

Chalao... ERROR:

```text
SyntaxError: expected ':'
```

Padho message: *"expected ':'"* — colon (`:`) expect kiya tha!

Dekho line 1 — `range(5)` ke baad **colon bhool gaye.**

Fix:

```python
for i in range(5):     ← colon lagaya ✅
    print(i)
```

### Message Padhne Ka Tareeka (Formula)

```text
1. Error ka TYPE padho      (SyntaxError? NameError?)
2. LINE NUMBER dekho        (kaunsi line pe hua?)
3. MESSAGE padho            ("expected what?")
```

Yehi teen step har error pe. Bas.

## Runtime Errors — Chalte Waqt Blast

Syntax theek thi, code CHALA... phir beech mein phat gaya.

### Example 1: NameError

```python
print(profit)
```

```text
NameError: name 'profit' is not defined
```

Padho: *"profit naam ki koi cheez exist hi nahi karti."*

Matlab — tune `profit` dabba kabhi banaya hi nahi!

Ho sakta hai spelling galat ho:

```python
profitt = 100     ← yahan double-t likha
print(profit)     ← yahan single! Naam match nahi hua ❌
```

**Fix:** naam check karo — dono jagah EXACT same hon (spelling bhi, capital-small bhi).

`Profit` aur `profit` Python ke liye DO ALAG naam hain!

### Example 2: ZeroDivisionError

```python
total = 100
trades = 0
average = total / trades
```

```text
ZeroDivisionError: division by zero
```

Padho: *"zero se divide nahi kar sakta."*

Maths mein bhi 100 ÷ 0 = impossible na? Python bhi wahi bolti hai.

Real trading mein yeh tab aata hai jab trades = 0 ho aur average nikalo. Isliye code mein pehle check karte hain: *"trades zero toh nahi?"*

## Sabse Khatarnak — Logical Error

Ab dhyan se padho. Yeh wala sabse dangerous hai.

**Logical error mein:**

```text
✅ Code chalta hai
✅ Koi error NAHI aata
❌ Par jawab GALAT hai
```

Python kuch nahi bolega — use toh lagta hai sab sahi chala.

Yaad hai 3.1 wala trap?

```python
a = "10"       ← quotes = TEXT tha!
b = "20"
result = a + b
print(result)
```

Output: `1020`

Koi error nahi aaya. Code chal gaya.

Par agar yeh tera backtest hota aur profit/loss jod rahe hote... **poora result GALAT**, aur tujhe pata bhi nahi chalta. 😱

Isliye rule yaad rakho:

> **Error aana achha hai — woh problem DIKHATA hai.
> Silent galat answer — woh problem CHHUPATA hai.**

Aur ek famous example (note se): `"10" + "20"` type ka logical error hi note 29 ke PnL formula mein pada tha — poore cohort ne ulta PnL seekh liya kyunki code "chal raha tha." Humne Module 4 mein fix kiya.

## Debugging Ka Basic Process

Ab fix karna seekho. 4-step process — har error pe yehi:

```text
STEP 1: Error message PADHO (type + line number)
STEP 2: Us line pe JAO, aas-paas dekho
STEP 3: Print debugging karo
STEP 4: Fix karo → dobara chalao → repeat
```

### Step 3 Samjho — Print Debugging Kya Hai

Sabse simple debugging tool: **print daal ke andar jhaankna.**

Soch: chai theek nahi bani. Kya karoge?

Har step taste karoge na — paani theek? patti theek? doodh?

Code mein wahi:

```python
def calculate_average(trades):
    print(f"DEBUG: trades aaye = {trades}")     ← jhaanko!
    total = sum(trades)
    print(f"DEBUG: total nikla = {total}")      ← phir jhaanko!
    avg = total / len(trades)
    return avg
```

Chalao aur dekho — values kya aa rahi hain jo AANI CHAHIYE thi?

Jahan pehli baar galat value dikhi — **wahi bug hai.**

Itne se kaam ho jaata hai 90% cases mein.

### Ek Real Debug Story

```python
prices = [100, 200, 300]
print(prices[5])     ← 6th element maanga (0-4 hi hain!)
```

```text
IndexError: list index out of range
```

Padha: *"index range se bahar hai."*

List mein 3 items hain (positions 0,1,2). Maine 5 maang liya.

Fix: `print(prices[2])` — last valid position.

(Index 0 se start hota hai — yeh detail agle files mein.)

## Errors Ke Naam Yaad Rakho (Cheat Sheet)

| Error | Matlab | Common Wajah |
|---|---|---|
| `SyntaxError` | Grammar galat | Colon/bracket miss |
| `NameError` | Yeh naam exist nahi karta | Spelling galat / banaya nahi |
| `ZeroDivisionError` | 0 se divide? Nahi! | Trades = 0 |
| `IndexError` | Position range se bahar | Galat index maanga |
| **Logical** *(silent)* | Chala par jawab galat | "10"+"20" type traps |

Pehli 4 dikhengi turant. Paanchvi chupchaap hai — usse sabse zyada dar lagta hai.

## Nutshell

Error = Python ka help message, gaadi ki warning light jaisa. Process: message padho (type + line) → line pe jao → print-debugging se values jhaanko → fix → repeat. Syntax = grammar (code chalta hi nahi). Runtime (NameError/ZeroDivision/Index) = chalte waqt blast. Logical = SILENT killer — code chalega, jawab galat ("10"+"20" trap). Error dikhna achha hai; silent galat answer sabse bura.

## What It Is NOT

- ❌ **Error aana = tum galat programmer ho.** Nahi — errors har expert ki daily life hain. Skill errors se bachna nahi, errors ko FAST padhna hai. Message padhna seekh liya toh aadha developer ban gaye.
- ❌ **Debugging = guess-and-check nahi.** Random cheezein badal ke dekhna nahi — systematic process: padho, jhaanko (print), compare (kya hona chahiye vs kya hai), fix. Guessing time waste karti hai.
- ❌ **"No error" = sahi code nahi.** Sabse dangerous illusion yehi hai. Logical errors silent hote hain. Isliye outputs ko EXPECTED result se compare karna habit bana lo — "100+20=120 aana chahiye tha, aaya kya?"

1. Error message padhne ka 3-step formula?

<details>
<summary>Sample Jawab</summary>

**Jawab:** (1) TYPE — error ka naam padho (SyntaxError/NameError...) — naam hi half problem batata hai. (2) LINE NUMBER — kaunsi line pe phata, wahin jao (aas-paas bhi dekho, kabhi-kabhi asli galti upar hoti hai). (3) MESSAGE — Python ne exactly kya bola ("expected ':'", "not defined", "out of range")? Wahi hint hai. Teen step = har beginner error solve ho jaata hai.

</details>

2. Logical error sabse khatarnak kyun — jabki woh dikhta tak nahi?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Kyunki yeh INVISIBLE hai. Syntax/runtime errors loudly fail karte hain — pakde jaate hain, fix hote hain. Logical error mein code smoothly chalta hai, output bhi aata hai... par GALAT. Trading mein matlab: backtest results galat, aur tu unke basis pe real paisa laga dega! Isliye defence: outputs ko expected-se-compare karo, sanity checks rakho ("buy low sell high = positive PnL hona chahiye"), aur ajeeb results pe formulas verify karo.

</details>

3. Print debugging kaise kaam karta hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Code ke beech-beech mein print() daal ke variable ki CURRENT value dekhte ho: print(f"DEBUG: {value}"). Phir khud se poochte ho: "yeh value yahan kya honi chahiye thi?" Jahan actual vs expected pehli baar alag mile — bug wahin hai. Bilkul chai-banane jaisa: har step taste karo, jahan kadak badal gaya wahi step problem hai. Simplest debugger — aur surprisingly sabse effective.

</details>

4. NameError aaya "name 'proft' is not defined". Soch ke batao asli problem kya ho sakti hai?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Naam match nahi ho raha. Possibilities: (1) Spelling — kahin 'profit' likha, kahin 'proft' (ek t miss). (2) Capital-small mismatch — 'Profit' vs 'profit' (Python case-sensitive!). (3) Variable banaya hi nahi — use karne se pehle assignment miss ho gayi. Fix: dono jagah ke naam side-by-side likh ke letter-by-letter compare karo. 90% NameErrors spelling issues hi hote hain.

</details>
