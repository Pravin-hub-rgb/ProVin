# 3.2 Python Loops (while & for)

## Do Tarah Ke Loops Hote Hain

```text
while → "JAB TAK yeh sach hai, karte raho"
for   → "YEH SAARE items pe ek-ek karke karo"
```

Dono samjhenge. Pehle `while`.

## While Loop — "Jab Tak" Wala

Real life example:

> **JAB TAK** pet nahi bhara, khate raho.
> Pet bhara? Ruk jao. Done.

Python mein bilkul aisa hi:

```python
count = 1                    # Step 1: ginti shuru

while count <= 5:            # Step 2: JAB TAK count 5 se chota/barabar...
    print(f"Count: {count}") # Step 3: ...yeh print karte raho
    count = count + 1        # Step 4: ginti badhao!
```

Output:

```text
Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
```

5 baar print hua. Humne sirf 4 lines likhi. 😎

### Line-by-Line Samajh

```python
count = 1
```

Ek dabba banaya, naam `count`, andar 1 rakha.

Yeh ginti ka hisaab rakhne wala dabba hai.

```python
while count <= 5:
```

Python poochta hai har round pe: *"kya count abhi bhi 5 se chota ya barabar hai?"*

- Haan? → andar ka code chalao, phir se poocho
- Nahi? → loop KHATAM, aage badho

(`<=` ka matlab: "chota YA barabar." `<=` ko condition bolte hain.)

```python
    print(f"Count: {count}")
```

Har round mein current ginti dikha do.

(Indentation dhyan se — `print` thoda ANDAR hai. Yeh batata hai ki woh loop ke ANDAR hai.)

```python
    count = count + 1
```

**Sabse important line!**

Dabbe se value nikalo (`count`) → 1 jodo → wapas usi dabbe mein rakho.

`1` → `2` → `3` → `4` → `5`...

Aur jab `6` hua → condition fail (`6 <= 5` galat) → loop ruk gaya.

## ⚠️ Sabse Bada Beginner Trap — Infinite Loop

Agar woh last line (`count = count + 1`) likhna bhool gaye?

```python
count = 1
while count <= 5:
    print("Count: ...")
    # count badha hi nahi! 😱
```

Kya hoga?

`count` hamesha `1` hi rahega.

Condition hamesha sach rahegi.

Print hota rahega... **HAMESHA.**

```text
Count: ...
Count: ...
Count: ...
(infinite! 💀)
```

Isko **infinite loop** bolte hain — loop kabhi nahi rukta.

Rokna ho toh terminal mein `Ctrl + C` dabao.

**Golden rule: while loop ke andar hamesha kuch aisa rakho jo condition ko ek din FAIL karwaye.**

## Ruk — While Samajh Aaya?

```text
✅ while = "jab tak condition sach hai, repeat karo"
✅ Har round pe Python condition check karta hai
✅ count + 1 wali line hi loop ko KHTAM karti hai
✅ Bhool gaye? = infinite loop 💀
```

Ab doosra loop — zyada popular wala.

## For Loop — List Ke Liye

While thoda kachcha hai na? Ginti ka dabba bhi khud banana pada, badhana bhi khud.

**For loop yeh sab khud karta hai.**

Real life example:

> Thaali pe 5 rotiyan hain. Ek-ek karke sab pe ghee lagao.
> Roti khatam? Done.

Python mein:

```python
for i in range(1, 6):
    print(f"Roti #{i} pe ghee laga")
```

Output:

```text
Roti #1 pe ghee laga
Roti #2 pe ghee laga
Roti #3 pe ghee laga
Roti #4 pe ghee laga
Roti #5 pe ghee laga
```

5 lines output — humne likhi sirf 2!

### Line-by-Line

```python
for i in range(1, 6):
```

```text
for        → "har item ke liye"
i          → chota dabba, har round mein nayi value aayegi
range(1,6) → numbers ki list: 1, 2, 3, 4, 5
```

Matlab: *"i mein ek-ek number daalte jao (1 se 5 tak), aur har baar andar ka code chalao."*

Python khud:
- ginti banata hai
- badhata hai
- rukta hai jab list khatam

Zero tension. Isliye log for zyada pasand karte hain.

### ⚠️ range Ka Sabse Bada Secret

Dhyan se dekho:

```python
range(1, 6)   →  1, 2, 3, 4, 5
```

6 kahan gaya?! Humne toh 6 likha tha!

**Rule: range(start, stop) mein STOP WALA NUMBER INCLUDED NAHI HOTA.**

```text
range(1, 6)  →  1 se 5 tak      (6 nahi!)
range(0, 3)  →  0, 1, 2         (3 nahi!)
range(1, 11) →  1 se 10 tak     (11 nahi!)
```

Yeh rule abhi ajeeb lagega. Par yaad rakho — **stop hamesha EXCLUDED.**

Aage backtesting mein iska use hoga aur tab samajh aa jayega ki yeh design smart hai.

Bas abhi ke liye: **+1 karke socho.** `range(1, 6)` = "1 se 6-1=5 tak."

## Ruk — While vs For

```text
while → condition pe chalta hai ("jab tak...")
        Ginti ka khud dhyan rakhna pada

for   → list/items pe chalta hai ("har ek ke liye")
        Sab Python khud manage karta hai ✅
```

Simple rule: **items ki list ho toh FOR.** Condition-based ho toh WHILE.

## For Loop Sirf Numbers Pe Nahi!

Text ke har letter pe bhi chalega:

```python
for letter in "HELLO":
    print(letter)
```

Output:

```text
H
E
L
L
O
```

Har letter ek-ek karke `letter` dabbe mein aaya, aur print hua.

Aage yeh candle data pe bhi chalega — "har candle pe ek-ek karke check karo." Wohi toh backtesting hai! (Module 4 mein milenge.)

## Ek Aur Useful Cheez — break

Kabhi-kabhi beech mein loop rokna hota hai.

> Roti khate waqt pet bhar gaya? Beech mein hi ruk jaate ho na. Poora plate finish nahi karte.

```python
for i in range(1, 11):
    if i == 5:
        print("Bas! Pet bhar gaya")
        break
    print(f"Roti #{i}")
```

Output:

```text
Roti #1
Roti #2
Roti #3
Roti #4
Bas! Pet bhar gaya
```

```text
break → loop WAHIN ruk jao, baaki items ignore
```

(Chota note: `if i == 5` ek naya concept hai — "agar". Yeh agli-agle files mein detail se aayega. Abhi itna samajh: *"agar i 5 hai, toh..."*)

## Nutshell

Loop = repeat karne ki machine. **While:** "jab tak condition sach hai" — ginti ka dabba khud badhana padta hai warna infinite loop (Ctrl+C se roko). **For:** range/list ke items pe automatic — `range(1,6)` = 1,2,3,4,5 (**stop EXCLUDED**, hamesha!). Strings/lists pe bhi for chalta hai. `break` = beech mein ruk jao. Backtesting = for loop over candles — isi ka hi bada version.

## What It Is NOT

- ❌ **Loop = same code copy-paste nahi.** Copy-paste mein change karna mushkil; loop mein EK jagah badlo, sab rounds pe apply. Isliye loop hi professional tareeka hai.
- ❌ **range(1,6) mein 6 aayega — NAHI!** Stop excluded hota hai. Yeh bhoolne se off-by-one errors aate hain jo pakadna sabse mushkil hota hai. +1 rule yaad rakho.
- ❌ **While aur for competitors nahi hain.** Dono ka apna kaam: condition-driven ho toh while, items-driven ho toh for. Dono aane chahiye.

2. `range(1, 6)` kaunse numbers dega aur stop-excluded rule kya hai?

<details>
<summary>Sample Jawab</summary>
