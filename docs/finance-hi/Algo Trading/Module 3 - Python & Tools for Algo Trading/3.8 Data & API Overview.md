# 3.8 Data & API Overview

## Market Data Kya Hota Hai?

Exchange har second price record karta hai.

Us raw data ko tod ke **candles** banaye jaate hain — time ke hisaab se:

```text
9:15 - 9:20 ka saara data → ek 5-minute candle
9:20 - 9:25 ka saara data → agla candle
...
```

Har candle = us 5 minute ki kahani, 5 numbers mein.

## OHLCV — Candle Ke Andar Kya Hai

Har candle mein **5 cheezein** hoti hain:

```text
O-H-L-C-V

O = OPEN    → us 5 min mein PEHLI price jo bani
H = HIGH    → sabse UPAR wali price
L = LOW     → sabse NEECHE wali price
C = CLOSE   → AAKHIRI price (sabse important!)
V = VOLUME  → kitne shares trade hue
```

Example — Reliance ki ek candle:

```text
Open:   2450   ← 9:15 pe pehla trade itne pe hua
High:   2460   ← beech mein yahan tak gaya
Low:    2448   ← aur yahan tak girega
Close:  2457   ← 9:20 pe aakhri trade
Volume: 125000 ← itne shares kat gaye
```

**Close sabse zyada important** — kyunki final decided price hai. Isliye indicators zyadatar close pe lagte hain (4.x mein EMA bhi close se hi banegi).

## 🔑 The Golden Pattern — Course Ka Theme

Har broker alag dikhta hai... par andar se **SAME**:

```text
STEP 1: CONNECT      → credentials do, client banao
STEP 2: AUTHENTICATE → access token lo (permission slip)

```

Function ke naam alag honge — Dhan mein `historydailydata()`, Zerodha mein `historical_data()`...

## Nutshell

Market data = candles: time-buckets mein OHLCV (Open-High-Low-Close-Volume). Close sabse important — final decided price. Har candle = DataFrame ki ek row. API = waiter — tera code request deta hai, broker data lauta hai. 6 sources seekhenge (Dhan/Zerodha/Angel/Groww/Delta/MT5) par golden pattern EK hi: **connect → authenticate → fetch → DataFrame.**

## What It Is NOT

- ❌ **API = website nahi.** Website insaano ke liye (dekhne mein); API CODE ke liye (structured data). Browser mein API URL khologe toh ajeeb JSON-text dikhega — normal hai, woh humans ke liye nahi bani.
- ❌ **OHLCV ke column names universal NAHI hain.** Koi `timestamp` likhta hai koi `time`; koi `vol` koi `volume`. Structure same, naam alag — isliye har source pe `df.head()` se verify karna habit banao.
- ❌ **Free data = unlimited data nahi.** Brokers limits lagate hain: kitna purana data, kitni resolution, kitni requests per day. Isliye chunked-fetching jaise tricks agli files mein aayengi.
