## Bitcoin Historical Data

```python
import requests
import pandas as pd
import time

# STEP 1: URL + parameters
url = "https://api.delta.exchange/api/v2/tickers/btcusd/ohlc"

params = {
    "resolution": 300,                    # seconds mein! 300 = 5 min
    "symbol": "BTCUSD",
    "start": int(time.time()) - 86400,    # 1 din pehle (86400 sec)
    "end": int(time.time())               # abhi
}

# STEP 2: Fetch!
response = requests.get(url, params=params)
data = response.json()

# STEP 3: DataFrame
candles = data["result"]["candles"]
df = pd.DataFrame(candles, columns=["time", "open", "high", "low", "close", "volume"])

print(df.head())
print(f"Total candles: {len(df)}")
```

Output:

```text
      time     open     high      low    close   volume
0  1704082500  42000.0  42100.0  41950.0  42050.0  125.5
...
Total candles: 288
```

## Do Naye Concepts Detail Mein

### 1. Resolution — Seconds Mein!

Indian brokers minutes mein bolte the ("5minute").

Delta **seconds** mein leta hai:

| Resolution | Matlab |
|---|---|
| `60` | 1-minute candles |
| `300` | 5-minute candles (60 × 5) |
| `900` | 15-minute candles |
| `3600` | 1-hour candles |

Crypto 24/7 chalta hai aur bahut chote timeframes bhi exist karte hain —

isliye seconds universal unit ban gaye.

### 2. Unix Timestamp

```text
Normal date:   "1 January 2024, 9:15 AM"
Unix time:     1704082500
```

Dono SAME moment hain! Bas format alag.

Unix = "1 Jan 1970 se ab tak kitne seconds hue" — ek bada number.

Computers ko number fast lagta hai, isliye APIs yeh deti hain.

Readable date chahiye toh pandas convert kar dega (aage seekhenge).

## Nutshell

Library nahi? `requests` se seedha URL hit karo — Python ka browser. Delta public data: no key, no login, FREE. Flow: url + params dict → `requests.get(url, params=params)` → `.json()` → DataFrame. Naye concepts: resolution SECONDS mein (300=5min), Unix timestamps (seconds since 1970). Symbol badlo = koi bhi coin (BTCUSD→ETHUSD→SOLUSD), loop se multiple coins. Data free; TRADING ke liye key+setup chahiye (Module 8).

## What It Is NOT

- ❌ **requests.get() = browser jaisa DIKH raha hai, browser nahi hai.** Woh pages render nahi karta, images nahi dikhata — sirf RAW response laata hai. APIs ke liye perfect (humein raw JSON chahiye hi!), websites ke liye nahi.
- ❌ **Unix timestamp ajeeb nahi, standard hai.** Har major system (Linux, databases, APIs) isi ko use karti hai. Readable date banana pandas ka one-liner hai: pd.to_datetime(df["time"], unit="s") — abhi yaad karne ki zaroorat nahi.
- ❌ **No-key data = no-security platform nahi.** Sirf READ-only public data open hai. Tera account/orders/paise poore security ke peeche hain — trading side pe full auth (keys + IP whitelist + signatures) lagega jab wo phase aayega.
