# 3.10 Dhan API Historical Data

## Setup — Do Cheezein Pehle

**1. Library install (3.5 ka delivery boy):**

```bash
pip install dhanhq
```

`dhanhq` = Dhan ki official Python library. Isme saare ready-made functions hain.

**2. Credentials lo (3.9 wali keys):**

```text
Dhan app/web → Settings/API section →
CLIENT ID     (ID card)
ACCESS TOKEN  (visitor badge)
```

Dono copy karke `tokens.py` mein rakho (3.9 wala tareeka):

```python
# tokens.py
client_id = "1101234567"
access_token = "eyJhbGciOi..."     # lambi si random string hogi
```

Ab code likhte hain.

## Login — Client Banao

```python
from dhanhq import dhanhq
from tokens import client_id, access_token

dhan = dhanhq(client_id, access_token)
```

Line-by-line:

```python
from dhanhq import dhanhq      ← library se main class nikali
from tokens import ...          ← 3.9 wala tareeka: keys alag file se
dhan = dhanhq(client_id, ...)   ← "waiter" taiyaar! Ab orders de sakte hain
```

`dhan` ab hamara connection object hai — isi se saare requests jayenge.

Ek line mein login. Dhan easy hai na? 😎

## Historical Data Fetch — Asli Candles!

Ab woh moment. Reliance ki 5-min candles maangte hain:

```python
response = dhan.historydailydata(
    security_id="2885",        # Reliance ka ID number
    exchange_segment="NSE_EQ",
    instrument="EQUITY",
    interval="5",              # 5-minute candles
    from_date="2024-01-01",
    to_date="2024-02-01"
)

print(response["status"])      # kya hua?
print(response["data"][:2])    # pehli 2 candles dekho
```

Parameters ek-ek karke:

```text
security_id       → stock ka NUMBER (naam nahi!) — neeche samjhaya hai
exchange_segment  → kaunsa exchange (NSE_EQ = NSE equities)
instrument        → type (EQUITY = normal shares)
interval          → candle size ("5" = 5-minute, "60" = 1-hour...)
from/to_date      → kitne purane se kitne tak
```

Response mein candles aa jayengi — JSON format mein (dictionary jaisa).

### ⚠️ Security ID Kya Hai? (Common Confusion!)

Broker "RELIANCE" naam nahi samajhte — har stock ka **number** hota hai:

```text
RELIANCE → 2885
TCS      → 11536
INFY     → 1594
```

Yeh numbers broker ke docs/instruments list mein milte hain.

Naam likhoge toh error aayega — aur yehi agli section ka pehla error hai! 😄

## Do Real Errors (Maine Bhi Kiye The)

Errors normal hain — yeh do sabse common hain. Dekh lo, phir kabhi surprise nahi hoga.

### Error 1: Import ka rona

```text
ImportError: cannot import name 'dhan_context'
```

**Matlab:** library version purana/naya hai, import naam badal gaya.

**Fix:** Google karo `dhanhq import error` ya library ke GitHub/docs pe current import line dekho. Libraries update hoti rehti hain — import lines badal sakti hain. Lesson: **error aaye toh official docs = best dost.**

### Error 2: Symbol nahi chalega

```python
# ❌ GALAT:
dhan.historydailydata(symbol="RELIANCE", ...)
```

```text
TypeError: unexpected keyword argument 'symbol'
```

Python bolta hai: *"symbol naam ka koi input main leta hi nahi hun!"*

**Fix:** Dhan ko symbol nahi — **security_id** chahiye (upar wala number):

```python
# ✅ SAHI:
dhan.historydailydata(security_id="2885", ...)
```

Lesson: **har broker ke function ke input NAAME alag hote hain.** Docs dekho, guess mat karo.

## Ruk — Golden Pattern Verify Karo

```text
✅ STEP 1 CONNECT:     dhanhq(client_id, access_token)
✅ STEP 2 AUTHENTICATE: token ke saath login ho chuka
✅ STEP 3 FETCH:       historydailydata(...) call kiya
✅ STEP 4 CONVERT:     pd.DataFrame(response["data"])
```

Dekha? 3.8 wala pattern EXACTLY yahi tha. Ab yeh pattern har broker pe repeat dekhne waala hai.

## Nutshell

Dhan = easiest starter broker. Setup: `pip install dhanhq` + credentials tokens.py mein. Login: `dhanhq(client_id, access_token)` — ek line. Fetch: `historydailydata(security_id, interval, dates)` — **stock ka NUMBER (security_id) lagta hai, naam nahi!** Errors: import issues = docs check; wrong parameter names = TypeError aayega, correct naam docs se. Last step: response → `pd.DataFrame()` → backtest-ready table.

## What It Is NOT

- ❌ **`response` direct DataFrame nahi hai.** Woh JSON/dict hai (status + data keys wala). `.head()` jaise pandas tools tab milte hain jab `pd.DataFrame(response["data"])` convert karoge. Convert step skip mat karo.
- ❌ **security_id har broker mein same nahi hota.** 2885 sirf DHAN ka Reliance number hai. Zerodha/Angel ke paas alag numbering systems hain (instrument_token etc.). Har broker apni instruments-list deta hai — wahan se mapping lo.
- ❌ **Access token permanent nahi hai.** Din-bhar ya kuch ghante mein expire ho jaata hai (broker pe depend). Kal code chalaya aur "unauthorized" aaya? Token refresh/re-generate karo — code kharab nahi hua!
