## DataFrame — Python Ka Excel Sheet

> **DataFrame = rows aur columns wali table** — bilkul Excel sheet jaisi.

Yeh pandas ka HERO object hai. Poora course isi ke around ghoomta hai:

```text
Candle data?      → DataFrame mein
Backtest results? → DataFrame mein
Broker response?  → DataFrame mein
```

### Pehla DataFrame Banao

```python
import pandas as pd

data = {
    "symbol": ["RELIANCE", "TCS", "INFY"],
    "price": [2450, 3800, 1550]
}

df = pd.DataFrame(data)
print(df)
```

Output:

```text
      symbol  price
0  RELIANCE   2450
1       TCS   3800
2      INFY   1550
```

Samajh kya kiya:

```python
data = {...}          → dictionary banayi: naam → values ki list
pd.DataFrame(data)    → pandas ne usse TABLE bana diya
df                    → table ko ek variable mein pakda
```

Dekho output: columns (`symbol`, `price`) + rows (0, 1, 2) + values.

Bilkul Excel. Bas ab code se control hoga.

## Filtering — Data Ko Chhaanna

Sawal: "sirf woh candles dikhao jahan close 2500 se UPAR hai."

Real life: Excel ka filter button.

Pandas mein ek line:

```python
big_candles = df[df["close"] > 2500]
```

Line ko andar se padho (Python aise hi chalta hai):

```text
df["close"] > 2500   → har row pe check: close > 2500?
                       result = True/False ki list

df[ ...True/False...]  → jahan True, woh rows RAKHO
                         jahan False, udado
```

Output: sirf woh candles jinmein closing 2500+ thi. ✅

Yeh pattern — `df[condition]` — **backtesting ka dil hai:**

```python
# Aane wale examples (bas dekho abhi):
winners  = report[report["pnl"] > 0]      # sirf winning trades
losers   = report[report["pnl"] <= 0]     # sirf losing trades
```

Module 4 mein metrics yehi nikalenge!

## Rows Pakadna — iloc

Position se row nikalni ho toh:

```python
print(df.iloc[0])       # PEHLI row (position 0)
print(df.iloc[-1])      # AAKHIRI row
```

```text
iloc[0]   → "position 0 wali row do"
iloc[-1]  → minus = PEECHHE se ginti → last row
```

⚠️ Ek rule jo 4.x mein backtest bug se bachayega:

`df.iloc[0:3]` = positions **0, 1, 2** — position 3 NAHI!

**Stop wala number EXCLUDED hota hai** (range(1,6) wala yaad hai? Same design!)

```text
iloc[a:b]  → a SE b-1 tak (b nahi!)
```

## Nutshell

DataFrame = Python ka Excel (rows + columns) — poore course ka hero object. `pd.read_csv()` se file load (1 line!), `df.head()` se pehli 5 rows ka jhaanka. `df["col"]` se column nikalo; double brackets se multiple. **Filtering:** `df[df["close"] > 2500]` — condition TRUE wali rows hi bachti hain (backtesting ka core!). `iloc[0]` first row, `iloc[-1]` last, aur `iloc[a:b]` mein b EXCLUDED. Tools like `.mean()`/`.max()` direct columns pe chalte hain.

## What It Is NOT

- ❌ **Pandas = Excel nahi hai.** Dikhta Excel jaisa hai par: automation, hazaron files, complex maths — yeh sab Excel ke bas ki nahi, pandas ki daily routine hai. Excel click karta hai; pandas code chalata hai.
- ❌ **`df["close"]` copy nahi deta — view/reference deta hai.** Column original table ka hi hissa hai; usme badlav original pe bhi asar kar sakta hai. Safe khelna ho toh `.copy()` use karo (aage detail milegi).
- ❌ **Single bracket vs double bracket same nahi:** `df["close"]` = EK column (Series). `df[["open","close"]]` = chhoti TABLE (DataFrame). Double brackets matlab "columns ki LIST do." Output ka shape alag hoga.
