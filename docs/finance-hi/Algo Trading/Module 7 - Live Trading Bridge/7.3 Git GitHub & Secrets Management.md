# 7.3 Git, GitHub & Secrets Management

## Git Kya Hai — Mental Model Pehle

**Git = tere code ke SNAPSHOTS ka system.**

Har important change pe "photo" lete ho (**commit**),

aur kabhi bhi purani photo pe wapas ja sakte ho!

### Bina Git Ki Zindagi:

```text
final.py
final_v2.py
final_v2_REAL.py
final_v2_REAL_bhai_ab_toh_final.py    😩💀
```

Tumne bhi kiya hoga na? Sab ne kiya hai!

### Git Ki Duniya:

```text
project/
└── server.py     ← EK hi file... history Git ke paas SAFE!
```

Git kya deta hai:

```text
BACKUP   → laptop gaya? GitHub pe sab hai!
HISTORY  → kaunsi line KAB badli
UNDO     → naya change ne toda? pichle commit pe wapas!
```

## Core Commands — Sirf Paanch!

```bash
git init                       # is folder ko git-project BANAO (ek baar)
git status                     # kya badla? (sabse zyada use hone wala!)
git add .                      # saare changes agle snapshot ke liye STAGE karo
git commit -m "webhook added"  # SNAPSHOT lo + message likho
git log --oneline              # history dekho
```

Workflow HAMESHA yehi:

```text
EDIT → status → add → commit
```

Tips:

```text
Chote commits lo        → ek feature = ek commit
Meaningful messages     → "fix" nahi, "fix webhook duplicate alerts"
```

Future-tu current-tu ko dhanyawad dega! 🙏

## GitHub — Code Ka Ghar Internet Pe

Git LOCAL hai (tere machine pe).

**GitHub = git-repositories ka CLOUD-HOSTING!**

Yahan code upload hota hai taaki:

```text
✅ Remote-backup mile
✅ Deployment-platforms (Render!) DIRECT connect ho sakein
✅ Duniya ko dikha sakein (portfolio!)
```

("GitHub = Instagram for coders" — photos ki jagah CODE post karte ho!)

### Setup

```bash
# github.com pe account + NEW REPOSITORY banao
# (algo projects ke liye PRIVATE rakhna!)

git remote add origin https://github.com/tu/algo-project.git
git push -u origin main        # local commits → GitHub!
```

Aage se bas `git push` karne se sync!

Doosri machine pe kaam? `git pull` se latest lo.

## ⚠️ .gitignore — SABSE Important File!

**Yahi wo cheez hai jo 3.9 mein promise ki thi!**

> `.gitignore` = list un FILES ki jo Git me NAHI jaani chahiye!

Tere algo-project mein yeh MUST ignore hon:

```text
# .gitignore
tokens.py          # API KEYS!! Account-hack risk 💀
.env               # environment-secrets
__pycache__/       # Python-cache (useless noise)
venv/              # virtual-environment (hazaaron files, zero-value)
*.csv              # bada data (repo heavy)
```

Kaise kaam karta hai:

```bash
git add .
git status      # "tokens.py"... KAHIN NAHI DIKHA! ✅ auto-skip ho gaya
```

⚠️ **Ek baar COMMIT ho gayi toh .gitignore se nikalna KAAFI nahi!**

History mein phir bhi pada rahega!

History se nikalna complex hai...

asli fix: **KEYS ROTATE karo** (purani delete, nayi generate).

## Horror Story Jo ROZ Hoti Hai 😱

Developer ne `git push` kiya...

**30 SECONDS baad** bots ne keys scan kar li!

(GitHub pe automated scrapers 24x7 chalte hain!)

Crypto-mining/trading unke account se shuru!

```text
LESSON: Minutes matter karte hain!
```

Isliye rule:

> **Keys code mein LIKHI HI nahi jaani chahiye —
> toh push hone ka SAWAAL hi nahi!**

## Environment Variables — Keys Ka Sahi Ghar

Toh keys rakhhein KAHAN?

**Environment variables (env-vars)** —

operating-system/cloud ke paas stored values jo code mein

`os.getenv()` se milti hain:

```python
import os

API_KEY    = os.getenv("DHAN_API_KEY")     # code me sirf NAAM!
API_SECRET = os.getenv("DHAN_SECRET")
```

Code ab key ka **REFERENCE** leta hai, VALUE nahi!

### Locally — .env File (+ python-dotenv)

```text
# .env file (GITIGNORED!)
DHAN_API_KEY=xyz123...
DHAN_SECRET=abc789...
```

```bash
pip install python-dotenv
```

```python
from dotenv import load_dotenv
load_dotenv()                        # .env file load kar deta hai

api_key = os.getenv("DHAN_API_KEY")  # ab value mil gayi
```

`.env` gitignore mein hai → KABHI push nahi hogi. Perfect local-setup!

### Cloud Pe — Dashboard Mein

Render jaise platform pe env-vars **DASHBOARD-UI** se set hoti hain —

code mein kahin NAHI likhna padta!

```text
LOCAL:  .env file        → os.getenv()
CLOUD:  Render dashboard → os.getenv()

SAME CODE! Dono jagah! ✅✨
```

Yehi professional pattern hai.

## Leak Ho Gayi Toh? Emergency Steps 🚨

```text
1. TURANT ROTATE karo!
   Broker-dashboard → purani key REVOKE → nayi generate
   (yehi ASLI fix hai — bots ne copy kar li hogi!)

2. History-clean karo (secondary — rotation ke bina BEKAAR)

3. Broker-activity CHECK karo
   Suspicious trades? Support ko batao!
```

## requirements.txt — Dependencies Ki List

Deployment-platform ko batana padta hai kaunsi libraries install karni hain.

Hand-written list mein TYPO ho jaata hai

(asli cohort-notes mein ek library ka naam hi GALAT tha!) —

isliye auto-generate karo:

```bash
pip freeze > requirements.txt
```

Output:

```text
flask==3.0.0
pandas==2.1.4
requests==2.31.0
python-dotenv==1.0.0
```

Exact versions included —

"mere laptop pe chalta tha, cloud pe kyun nahi?" problem SOLVED!

**Yeh template Module 8 ke HAR project mein reuse hoga!**

## Nutshell

Git = snapshots (init/status/add/commit/log); GitHub = remote-ghar (remote-add + push). ⚠️ **.gitignore NON-NEGOTIABLE:** tokens.py/.env/__pycache__/venv kabhi commit NAHI. Keys ka ghar = env-vars: local `.env`+dotenv, cloud dashboard — code sirf `os.getenv()` karta hai. Leak = INSTANT rotation! Dependencies: `pip freeze > requirements.txt` (hand-written = typo-risk!). Yeh setup M8-deployment ki LICENSE hai!

## What It Is NOT

- ❌ **GitHub = backup-only tool nahi hai.** Backup side-benefit hai; asli power: history + undo + collaboration + deployment-integration. Git seekhne ka ROI poore career me milta hai!
- ❌ **Private repo = secrets safe, NAHI!** Private-repo me bhi keys commit karna galat practice — team-members, future-leaks, integrated-apps sab risk-surface hain. Rule SAME: keys env-vars me, code me KABHI nahi.
- ❌ **requirements.txt hand-edit karne wali file nahi!** `pip freeze` se generate hoti hai; manual-list outdated/typo-prone (REAL incident: course-notes me galat package-naam!). Naya package add ho → freeze RE-RUN karo.
