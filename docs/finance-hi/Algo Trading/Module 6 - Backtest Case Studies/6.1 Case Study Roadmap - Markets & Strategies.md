## Jargon Decoder — Options Wale Naam

Roadmap mein jo naam aaye, unka quick decoder:

| Term | Simple Matlab |
|---|---|
| **ATM** | Strike = current price ke sabse PAAS |
| **OTM** | "Abhi bekaar" wale options (saste hote hain) — call ka strike price se UPAR, put ka NEECHE |
| **Straddle** | ATM Call + ATM Put dono SELL ek saath |
| **Short Strangle** | OTM Call + OTM Put dono SELL — wider range |
| **"920"** ⚠️ | **TIME hai, strike nahi!!** 9:20 AM = market open ke baad ki entry window |

Woh last wala sabse common confusion hai!

Log "920 Strangle" dekh ke sochte hain strike 920 hai.

NAHI — matlab 9:20 baje ki entry strategy.

(2.2 mein options basics padhe the — premium, strikes. Detail case-studies mein aayegi.)

## Do Famous Strategies Jo CODE Karenge

**1. ORB (Opening Range Breakout)** — Abhishek Kejriwal ke naam se famous:

```text
Market open ke baad FIRST 15-min candle ka high-low mark karo
Upar breakout → BUY
Neeche breakout → SELL
```

(5.2 mein preview mil chuka tha!)

```text
Green/red candles ka ALTERNATING pattern dhundo
```

**In Your Own Words**

1. SMC-style strategies abhi kyun exclude?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Kyunki unme price-structure DETECT karne ka custom code chahiye — trend lines khud draw karna, support zones banana, fair-value gaps calculate karna. Beginner ke liye ye complexity galat jagah hai. Indicator-strategies mein signals ready-made bante hain (EMA/RSI), toh focus backtest-mechanics pe rehta hai: loops, flags, PnL, metrics. Foundation strong hone ke baad SMC Pine Script tooling ke saath aayega.

</details>

2. "920 Strangle" mein 920 ka matlab?

<details>
<summary>Sample Jawab</summary>

**Jawab:** TIME — 9:20 AM! Market open (9:15) ke thodi der baad expiry-day option-selling ki entry window hoti hai, isliye naam "920." Common confusion: log strike-price 920 samajh lete hain. Decoder rule: option-selling context mein "920" almost always morning ENTRY TIME hai, strike number kabhi nahi.

</details>

3. Options ke liye OHLC candles kaafi kyun nahi?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Kyunki options strategy UNDERLYING price pe decide hoti hai par TRADE specific strikes ke PREMIUMS pe hota hai! Chahiye: option chain data — available strikes, unke CE/PE premiums, expiry dates. Nifty ka OHLC milega par "26000 CE ka premium" nahi — woh alag se fetch karna padta hai. Isliye "different type of data" — Module 3 ki APIs isi ka gateway.

</details>

4. ORB ka core rule 2 line mein?

<details>
<summary>Sample Jawab</summary>

**Jawab:** Open ke baad first 15-minute candle ka HIGH aur LOW mark karo = "opening range." Phir: price UPAR break kare → BUY (bullish din expected); NEECHE break → SELL side. Logic: opening range institutional activity define karti hai; usse break hona = din ki direction ka signal. Poora coded version agli file mein!

</details>
