# 6.3 Traffic Light Strategy Backtest — Angel One

## Strategy Rules

```text
TRAFFIC LIGHT RULES:
- Price-action based (koi indicator NAHI)
- Alternating GREEN/RED candle PAIRS dhundo
  (double-green ya double-red allowed NAHI)
- Pair ka highest-high aur lowest-low = RANGE mark karo
- Range break → LINEAR ENTRY (seedha entry, koi wait nahi)
- Target = 1:2 (ORB jaisa)
- MAX 3 trades per day
- 3:25 PM pe sab positions FORCE-CLOSE
```

### Naam "Traffic Light" Kyun?

Candles red-green ALTERNATE hoti hain —

jaise traffic signal ke lights! Pattern dikha = "GO" milta hai.

### Logic Samajho

Alternating pairs = **tug-of-war zone** —

buyers-sellers baar-baar exchange kar rahe hain (indecision!).

Us poori range ko mark karo.

Jo side FINALLY break karegi = winner side!

### ORB Se Difference

```text
ORB            : range sirf SUBAH banti hai (9:15-9:30)
Traffic Light  : range DIN MEIN KAHIN BHI ban sakti hai
```

### Do Naye Risk Rules (ORB mein nahi the!)

```text
MAX 3 TRADES/DAY :
   Choppy din mein strategy baar-baar fake-breakout khayegi!
   Cap = worst-day damage BOUNDED (3 × SL)

3:25 PM SQUARE-OFF :
   Market 3:30 band — hum 3:25 pe khud nikal jaate hain.
   Overnight risk ZERO + har din fresh start!
```

Dono rules position-sizing family ke hain (2.4 ka concept!).

## Data Fetch — Angel One + Chunking

Login wahi 3.12 wala (login.py mein TOTP + generateSession).

**Naya concept: CHUNKING!**

⚠️ Angel One (aur Zerodha) EK request mein poore saal ka data NAHI dete —

API limits hoti hain!

Solution: date-range ko **tukdon (chunks) mein** maango:

```python
from datetime import date, timedelta
from login import smart_api          # 3.12 wala session
import pandas as pd

def fetch_chunked(start, end):
    all_candles = []
    current = start

    while current < end:                        # jab tak range khatam na ho
        chunk_end = min(current + timedelta(days=30), end)
        raw = smart_api.get_candle_data(
            exchange="NSE",
            tradingsymbol="NIFTY",
            interval="FIVE_MINUTE",
            fromdate=current.isoformat(),
            todate=chunk_end.isoformat()
        )
        all_candles.extend(raw["data"]["candles"])   # is chunk ko JODO
        current = chunk_end                          # aage badho

    df = pd.DataFrame(all_candles,
                      columns=["time","open","high","low","close","volume"])
    return df

df = fetch_chunked(date(2024,1,1), date(2024,12,31))
```

Loop samajh:

```text
Jan 1 → Jan 31 ka data lo     (chunk 1)
Feb 1 → Feb 29 ka data lo     (chunk 2)
...extend karte jao...
December tak! Poora saal ready ✅
```

Har chunk ~30 din. `timedelta(days=30)` = "30 din baad ki date."

## Pair Detector — Naya Helper Function

```python
def is_green(c):
    return c["close"] > c["open"]

def is_red(c):
    return c["close"] < c["open"]

def is_alternating_pair(prev_c, curr_c):
    """Do candles jinke colors ALAG-alag hon"""
    return (is_green(prev_c) and is_red(curr_c)) or \
           (is_red(prev_c) and is_green(curr_c))
```

```python
is_alternating_pair(prev, curr)
```

Padho: *"(pichli GREEN aur yeh RED) YA (pichli RED aur yeh GREEN)"*

= colors alternate ho rahe = pair mila!

### 🔑 Look-Ahead Prevention In Action!

Dhyan do function ke design pe:

> Sirf **CURRENT + PREVIOUS** candle pass hoti hain.
>
> **FUTURE candles accessible HI NAHI hain!**

4.1 wala look-ahead bias yaad hai?

Live trading mein future exist hi nahi karta —

toh backtest bhi wahi dikhaye jo LIVE mein dikhta!

Design-principle: data access ko FUNCTION BOUNDARIES se limit karo —

phir bias structurally IMPOSSIBLE ho jaata hai.

## Nutshell

Traffic Light = alternating green/red PAIR ka range-break. Pair detector sirf current+prev candles leta hai (**look-ahead structurally blocked!**). Naye risk-layers: max-3-trades/day counter + 3:25 PM force square-off. Data: SmartAPI CHUNKED fetching (30-din tukde, extend karte jao), Nifty token 3045. Report dict-of-lists → DataFrame → 4.6 metrics. Framework wahi ORB wala — tumne REUSABLE engine seekha hai!

## What It Is NOT

- ❌ **Alternating pairs = reversal signal NAHI.** Pair sirf INDECISION zone define karta hai; trade BREAKOUT pe hota hai (momentum direction mein!), reversal pe nahi.
- ❌ **Max-3 rule profit-limiter nahi — LOSS-limiter hai.** Choppy din mein fake breakouts ka damage cap hota hai (3 × SL). Achhe din mein 3 pe rukna discipline hai, greed-control.
- ❌ **Linear entry = careless entry nahi.** Confirmation skip karna SPEED ke liye conscious choice hai; tight pair-range SL usko compensate karta hai. Bina SL ke linear entry = gambling.
