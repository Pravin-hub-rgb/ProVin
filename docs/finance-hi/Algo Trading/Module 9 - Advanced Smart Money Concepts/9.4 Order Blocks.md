# 9.4 Order Blocks

## Definition — SIMPLE-Rakhо!

> **BULLISH-OB = impulsive-UP-move se-THEEK-pehle wali-LAST-RED-candle!**
>
> **BEARISH-OB = impulsive-DOWN-move se-pehle-wali-last-GREEN-candle!**

Dhyan-do-TEEN-keywords pe:

```text
1. LAST-opposite-candle!
   (move-shuru-hone-se-THEEK-pehle-wali!)

2. IMPULSIVE-move!
   (slow-drift NAHI — EXPLOSIVE!)

3. BREAKS-STRUCTURE!
   (us-move ne-BOS/CHoCH diya — 9.3 ka-FILTER!)
```

### Example (Bullish-OB):

```text
... 98.5↓ 98.2↓ [98.0 RED] → 101↑ 103↑ 104↑

        YAHI-bullish-OB-zone-hai:
        98.0-candle ka-LOW-se-HIGH tak!!

Move-ne-swing-high-TODA? HAAN (100+) → VALID-OB ✅
```

## Nutshell

OB = impulsive-STRUCTURE-BREAKING-move se-pehle ki-LAST-opposite-candle! Logic: wahan-UNFILLED-institutional-orders (ya-self-fulfilling-clustering!). VALIDITY: structure-break + impulse + UNMITIGATED + fresh! Trade-template: context → zone-TAP → confirmation → SL-below-OB-low → target = OPPOSITE-liquidity-pool (1:2+)! Mitigated-zone = SPENT-fuel. Refined-OB (sirf-open-level!) = advanced-option!

## What It Is NOT

- ❌ **Har-opposite-candle = OB NAHI!!** STRUCTURE-BREAK-filter sabse-ZAROORI hai — uske-BINA toh-yeh-sirf-"RED-CANDLE"-hai jo-har-DOWNTICK me-mil-jati! QUALITY-control isi-rule-se-aata!
- ❌ **GUARANTEED-bounce-zone NAHI!** Strong-trends OBs-ko bina-major-reaction ke-PAAR-kadh-dete (especially-NEWS-moves!). Isliye-SL-MANDATORY — zone-failure ek-VALID-outcome hai jisko-BUDGET-kiya-jaata-hai!
- ❌ **MAGIC-levels nahi!** "Institutional-orders-WAHIN-baithe" VERIFIABLE-claim NAHI (kisi-ke-paas-exchange-LEDGER-nahi!). Jo-verifiable-hai: zones-STATISTICALLY-react karte kyunki-enough-traders unhe-DEKHTE-hain. MECHANISM-pe-debate, EDGE-pe-focus!
